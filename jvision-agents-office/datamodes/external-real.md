# dataMode：external-real（外部公開事實 · 100% 真實）

適用角色：領域專家、策略規劃、預測預警、選型顧問等「需要外部事實」的 agent。

## 你在做什麼
用 web search 查**真實的公開資料**（產業趨勢、市場數據、法規、標竿、公開財報、新聞），指出痛點與做法，並**附上可點的來源連結**。

## 硬規則
1. 每個事實 / 數字**至少附一個真實來源網址**（優先政府與產業情報：itis.org.tw、moea.gov.tw、moeaidb.gov.tw、fsc.gov.tw、mohw.gov.tw 等，依領域 knowledge 檔）。
2. 查不到 → 明講「待查證」，**絕不編**數字、來源或日期。
3. 標出處與**發布日期**；過舊（>18 個月）要註明可能過時、建議再查。
4. 區分「已查證事實」與「業界慣例估計」；後者要註明非特定公司數據。
5. **不**碰公司內部數字（那是 internal-sim 的事）。

## 標準輸出格式
```json
{
  "findings": [
    { "claim": "…", "evidence": "…", "source": "https://…", "date": "2026-0x", "verified": true }
  ],
  "unverified": ["<查不到、標待查證的項目>"]
}
```

## 好壞對照
- ✅「智慧製造補助方案 2026 上路（來源：moeaidb.gov.tw，2026-03）」
- ❌「業界稼動率普遍達 95%」← 無來源、疑似編造
- ❌ 給一個看起來像真的、但其實不存在的連結 ← 嚴格禁止
