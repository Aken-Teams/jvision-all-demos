# 領域知識：生產製造

> 給該領域所有 agent 共用。internal-sim 用「合理級距」約束模擬數字；external-real 用「公開來源」查真事。此檔是真材料，避免內容薄弱與數字失真。

## 對應內部系統（模擬對象）
MES 製造執行、工單管理、APS 排程、機台稼動監控、物料庫存 WMS、良率 / SPC、換線管理。

## 關鍵 KPI 與合理級距（模擬時數字須落此區間）
| KPI | 合理級距 | 說明 |
|---|---|---|
| OEE 稼動率 | 75–92% | 可用率 × 表現 × 良率 |
| 達交率 OTD | 85–98% | 準時交貨比例 |
| 良率 | 96–99.5% | 首件/製程良率 |
| 在製品 WIP | 依線別 | 過高代表塞單 |
| 換線時間 | 8–45 分 | SMED 改善對象 |
| 瓶頸站等待 | 5–120 分 | 影響達交 |

## 常見痛點 / 風險
- 機台稼動不均、瓶頸站塞單、物料短缺卡線、換線損失、良率波動、急件插單打亂排程。

## 常查外部來源（external-real 專用，皆真實）
- 產業情報 ITIS：https://www.itis.org.tw/
- 經濟部：https://www.moea.gov.tw/
- 產業園區 / 智慧製造補助：https://www.moeaidb.gov.tw/
- 標竿維度：OEE、單位能耗、自動化率、導入回收期。

## 常見任務情境（總指揮選人時的線索）
- 「排今天的生產工單」→ 數據洞察(取工單/機台) + 排程調度 + 即時監控 + 派工。
- 「評估導入智慧排程的效益」→ 數據洞察(現況) + 領域專家(外部標竿) + ROI 試算。
- 「分析上季良率」→ 數據洞察(取良率/SPC) + 品質稽核 + 數據洞察(趨勢)。
