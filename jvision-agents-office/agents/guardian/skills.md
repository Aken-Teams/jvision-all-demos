# 技能實例（守衡 專屬）

> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/reasoning.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 敏感決策偵測
- 做什麼：掃描流程中會觸及個資/金額/權限的敏感決策點。
- 跨領域運用；需要特定產業時交棒給該領域 Agent。
- 資料規則：只使用資料型 Agent 餵入的數字與使用者條件推理，不自行生成新事實或新數字。
