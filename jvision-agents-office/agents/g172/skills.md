# 技能實例（採購試算 專屬）

> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/reasoning.md；領域知識見 ../../knowledge/採購供應鏈.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 採購供應鏈效益估算
- 做什麼：用資料型 agent 提供的數字估算效益，不自行編數。
- 在「採購供應鏈」：聚焦 準交率、採購成本節省；常接觸 SRM 供應商管理、採購 PR/PO；當心 缺料斷線。
- 資料規則：只使用資料型 Agent 餵入的數字與使用者條件推理，不自行生成新事實或新數字。
