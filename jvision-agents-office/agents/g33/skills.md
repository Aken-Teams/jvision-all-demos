# 技能實例（數據領域 專屬）

> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/external-real.md；領域知識見 ../../knowledge/數據治理.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 數據治理痛點診斷
- 做什麼：針對情境列出 3 個關鍵痛點，指出成因與影響，避免泛泛而談。
- 在「數據治理」：聚焦 資料品質分、主資料一致；常接觸 資料目錄、資料品質；當心 資料孤島。
- 資料規則：須以 web search 查證公開資料並附真實來源連結；查不到即標『待查證』，不杜撰數字或來源。

## 數據治理標竿比對
- 做什麼：以真實查證的產業標竿（KPI/做法）對照現況，指出落差。
- 在「數據治理」：聚焦 資料品質分、主資料一致；常接觸 資料目錄、資料品質；當心 資料孤島。
