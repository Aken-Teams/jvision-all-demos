# 技能實例（數據試算 專屬）

> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/reasoning.md；領域知識見 ../../knowledge/數據治理.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 效益估算
- 做什麼：用資料型 agent 提供的數字估算效益，不自行編數。
- 在「數據治理」：聚焦 資料品質分、主資料一致；常接觸 資料目錄、資料品質；當心 資料孤島。
- 資料規則：只使用資料型 Agent 餵入的數字與使用者條件推理，不自行生成新事實或新數字。
