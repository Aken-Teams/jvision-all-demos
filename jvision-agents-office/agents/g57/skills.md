# 技能實例（品管預測 專屬）

> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/external-real.md；領域知識見 ../../knowledge/品質管理.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 品質管理需求預測
- 做什麼：以歷史資料預測下期需求並給區間。
- 在「品質管理」：聚焦 首件良率、客訴率；常接觸 QMS 品質管理、SPC 統計製程；當心 製程失控。
- 資料規則：須以 web search 查證公開資料並附真實來源連結；查不到即標『待查證』，不杜撰數字或來源。
