# 技能實例（營建預測 專屬）

> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/external-real.md；領域知識見 ../../knowledge/營建工程.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 需求預測
- 做什麼：以歷史資料預測下期需求並給區間。
- 在「營建工程」：聚焦 進度達成、工安事故；常接觸 工程專案、進度/計價；當心 工期延誤。
- 資料規則：須以 web search 查證公開資料並附真實來源連結；查不到即標『待查證』，不杜撰數字或來源。
