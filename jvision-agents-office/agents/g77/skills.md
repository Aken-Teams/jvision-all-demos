# 技能實例（資安稽核 專屬）

> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/reasoning.md；領域知識見 ../../knowledge/資訊安全.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 資訊安全完整度檢查
- 做什麼：逐項對照基線檢查交付物是否齊全，輸出完整度百分比。
- 在「資訊安全」：聚焦 弱點修補時效、事件平均處理 MTTR；常接觸 SIEM/SOC、弱點掃描；當心 資料外洩。
- 資料規則：只使用資料型 Agent 餵入的數字與使用者條件推理，不自行生成新事實或新數字。
