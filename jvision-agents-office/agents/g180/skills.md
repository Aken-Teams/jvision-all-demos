> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/reasoning.md；領域知識見 ../../knowledge/法遵合規.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 法遵合規效益估算
- 做什麼：用資料型 agent 提供的數字估算效益，不自行編數。
- 在「法遵合規」：聚焦 稽核發現關閉率、政策覆蓋率；常接觸 GRC 治理合規、政策管理；當心 法規違反罰款。
- 資料規則：只使用資料型 Agent 餵入的數字與使用者條件推理，不自行生成新事實或新數字。
