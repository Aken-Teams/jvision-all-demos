# 技能實例（研發洞察 專屬）

> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/internal-sim.md；領域知識見 ../../knowledge/研發管理.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 研發管理指標分析
- 做什麼：彙整營運數據，算出關鍵指標與拆解貢獻。
- 在「研發管理」：聚焦 NPI 準時率、設變週期；常接觸 PLM 產品生命週期、BOM 管理；當心 設變失控。
- 資料規則：資料來自內部系統，數字須落合理級距並像真儀表板自然呈現（『是模擬』僅內部標記、不對客戶顯示）。
