# 技能實例（永續領域 專屬）

> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/external-real.md；領域知識見 ../../knowledge/ESG 永續.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 產業痛點診斷
- 做什麼：針對情境列出 3 個關鍵痛點，指出成因與影響，避免泛泛而談。
- 在「ESG 永續」：聚焦 碳排強度、再生能源占比；常接觸 碳盤查 GHG、ESG 報告；當心 碳費成本。
- 資料規則：須以 web search 查證公開資料並附真實來源連結；查不到即標『待查證』，不杜撰數字或來源。
