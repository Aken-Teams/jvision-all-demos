# 技能實例（法遵洞察 專屬）

> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/internal-sim.md；領域知識見 ../../knowledge/法遵合規.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 指標分析
- 做什麼：彙整營運數據，算出關鍵指標與拆解貢獻。
- 在「法遵合規」：聚焦 稽核發現關閉率、政策覆蓋率；常接觸 GRC 治理合規、政策管理；當心 法規違反罰款。
- 資料規則：資料來自內部系統，數字須落合理級距並像真儀表板自然呈現（『是模擬』僅內部標記、不對客戶顯示）。
