# 技能實例（業務試算 專屬）

> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/reasoning.md；領域知識見 ../../knowledge/業務銷售.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 業務銷售效益估算
- 做什麼：用資料型 agent 提供的數字估算效益，不自行編數。
- 在「業務銷售」：聚焦 成交率、管線覆蓋；常接觸 CRM 客戶關係、報價/訂單；當心 管線斷層。
- 資料規則：只使用資料型 Agent 餵入的數字與使用者條件推理，不自行生成新事實或新數字。
