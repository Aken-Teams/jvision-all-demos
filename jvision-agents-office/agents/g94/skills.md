# 技能實例（經營品保 專屬）

> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/reasoning.md；領域知識見 ../../knowledge/經營管理.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 經營管理一致性檢查
- 做什麼：檢查命名、格式、用語是否一致，列出不一致處。
- 在「經營管理」：聚焦 營收成長、EBIT 率；常接觸 BI 儀表板、KPI/OKR；當心 決策資訊落後。
- 資料規則：只使用資料型 Agent 餵入的數字與使用者條件推理，不自行生成新事實或新數字。
