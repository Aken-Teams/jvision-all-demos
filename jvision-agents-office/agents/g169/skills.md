# 技能實例（專案試算 專屬）

> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/reasoning.md；領域知識見 ../../knowledge/專案管理.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 專案管理效益估算
- 做什麼：用資料型 agent 提供的數字估算效益，不自行編數。
- 在「專案管理」：聚焦 準時達成 OTD、預算達成；常接觸 PMIS 專案系統、甘特/里程碑；當心 時程延誤。
- 資料規則：只使用資料型 Agent 餵入的數字與使用者條件推理，不自行生成新事實或新數字。
