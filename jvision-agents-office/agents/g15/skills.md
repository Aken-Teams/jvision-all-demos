# 技能實例（資安選型 專屬）

> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/external-real.md；領域知識見 ../../knowledge/資訊安全.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 資訊安全需求解析
- 做什麼：解析使用者一句話，抽出產業、規模、預算、痛點與想要的成果型態，輸出結構化需求清單。
- 在「資訊安全」：聚焦 弱點修補時效、事件平均處理 MTTR；常接觸 SIEM/SOC、弱點掃描；當心 資料外洩。
- 資料規則：須以 web search 查證公開資料並附真實來源連結；查不到即標『待查證』，不杜撰數字或來源。

## SIEM/SOC選型
- 做什麼：把需求對應到最貼近的產業做法與系統類型，輸出候選清單與匹配理由。

## 規模預算適配
- 做什麼：依公司規模與預算區間過濾方案，剔除過大或過貴者，輸出可負擔選項。

## 資訊安全方案比較
- 做什麼：對 2–4 個候選方案做多維度（功能/成本/導入期/風險）比較，輸出比較表。
- 在「資訊安全」：聚焦 弱點修補時效、事件平均處理 MTTR；常接觸 SIEM/SOC、弱點掃描；當心 資料外洩。
