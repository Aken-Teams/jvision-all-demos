# 技能實例（資產稽核 專屬）

> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/reasoning.md；領域知識見 ../../knowledge/資產管理.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 資產管理完整度檢查
- 做什麼：逐項對照基線檢查交付物是否齊全，輸出完整度百分比。
- 在「資產管理」：聚焦 資產利用率、盤點相符；常接觸 EAM 資產管理、折舊/盤點；當心 閒置資產。
- 資料規則：只使用資料型 Agent 餵入的數字與使用者條件推理，不自行生成新事實或新數字。
