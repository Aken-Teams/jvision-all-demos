# 技能實例（客服排程 專屬）

> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/internal-sim.md；領域知識見 ../../knowledge/客服管理.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 資源排程
- 做什麼：把任務排入資源與時段，輸出排程結果。
- 在「客服管理」：聚焦 首解率 FCR、SLA 達成；常接觸 工單/Ticket、知識庫；當心 SLA 逾時。
- 資料規則：資料來自內部系統，數字須落合理級距並像真儀表板自然呈現（『是模擬』僅內部標記、不對客戶顯示）。
