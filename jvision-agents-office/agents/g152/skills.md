# 技能實例（零售填料 專屬）

> 全域鐵則見 ../../POLICY.md；資料模式見 ../../datamodes/internal-sim.md；領域知識見 ../../knowledge/零售電商.md。
> 以下每個技能 = 做什麼 + 在本領域怎麼用 + 資料規則。

## 零售電商擬真資料
- 做什麼：依欄位與級距生成合乎產業常識的擬真樣本（自然呈現、不標模擬）。
- 在「零售電商」：聚焦 轉換率、客單價 AOV；常接觸 POS/OMS 訂單、商品/庫存；當心 缺貨/滯銷。
- 資料規則：資料來自內部系統，數字須落合理級距並像真儀表板自然呈現（『是模擬』僅內部標記、不對客戶顯示）。
