# JVision All Demos — Roadmap

## Product goal

Operate one JV company Demo website that lets visitors find, filter and open all 464 projects on a single domain, while retaining independently runnable source projects in the monorepo.

## Milestone 1 — Consolidate and make discoverable

- [x] Consolidate 464 projects into `jvision-all-demos`.
- [x] Publish the canonical project catalog in `projects-index.json`.
- [x] Route Hub demos through `/demos/<repo>/` on one domain.
- [x] Rebuild the homepage as a retrieval-first JV Demo catalog.
- [x] Add full-text search, suggestions, facets, sorting and URL-backed filters.

## Milestone 2 — Establish quality baseline

- [x] Apply a bright, professional SaaS baseline across the library.
- [x] Add responsive analytics and mobile audit tooling.
- [x] Add the Project Expert Agent and acceptance checks.
- [x] Record formal-site and mobile audit reports under `docs/`.

## Milestone 3 — Sustain quality

- [ ] Review any projects reported by future audits and apply targeted fixes.
- [ ] Enrich catalog metadata with human-friendly titles and search aliases where the current repository slug is not self-explanatory.
- [ ] Keep individual demo functionality, accessibility and statistics views consistent with the baseline.
- [ ] Maintain this context system as projects and requirements change.

## Milestone 4 — Operational hand-off

- [ ] Document the preferred self-hosted runtime and release procedure when the hosting environment is finalised.
- [ ] Define an editorial process for adding projects and updating `projects-index.json`.
