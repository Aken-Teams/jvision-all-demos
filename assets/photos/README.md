# 首頁照片

`welcome.html` 會找這四個檔名。**檔案不存在時整頁照常運作**——第一幕退回 SVG
神殿、第二幕退回石塊示意圖、第四幕就少一層背景，不會出現破圖或空相框。

| 檔名 | 用在哪 | 建議 |
|---|---|---|
| `01-temple-color.jpg` | 第一幕滿版背景（神殿） | 橫幅 16:9 以上，中央偏亮，標題壓在上面 |
| `02-temple-bw.jpg` | 第二幕的裱框圖版（未完成的形體） | 16:9，建造中的神殿最合題 |
| `03-industry-a.jpg` | 第四幕滿版背景 | 16:9，現代產業現場 |
| `04-industry-b.jpg` | 第四幕滿版背景（與 03 交替） | 16:9，構圖與 03 相近，溶接才順 |

## 放進來的方式

把檔案存成上面的名字放進這個資料夾就好，不需要改任何程式碼：

```bash
cp ~/Downloads/你的圖.jpg assets/photos/01-temple-color.jpg
```

## 幾件事

第四幕的照片上面鋪了一層象牙色（約 85% 不透明），所以深色或飽和的照片不會把整幕
拉出這頁的色調。要調整濃度改 `#act4::after` 的 gradient。

第一幕的標題後面有一塊象牙色暈罩，不論背景多複雜都讀得清楚。

檔案大小建議壓在 300KB 以內。這是開場第一眼，載得慢會直接看到空白。
