# 題目候選（2026-08-31）

既有 1950 題｜本次產 80 題｜通過 60｜重複或不合格 2

## 通過的題目

1. **建照條件履約檢核台**（construction-pm／營建工程）
   - 集中拆解建照附帶的交通、消防、綠建築與公共設施條件，管理期限、文件、責任單位及完成證據，避免交接漏項而延誤使用執照。
   - 差異：最像既有「建照補正文件追蹤台」，但該題管理主管機關退件後的補正；本題從建照核發起持續控管附帶條件履約。
   - repo：`jvision-building-permit-condition-control`
2. **工班出工界面協調台**（construction-pm／營建工程）
   - 依樓層、區域與工序協調各工班出工，先確認圖料、人力、機具及工作面條件，並處理撞期與臨時變動，降低到場待工和工序干擾。
   - 差異：最像既有「工地人員日報核薪台」，但該題核算已發生的出勤與工資；本題在出工前協調工作面及工種界面。
   - repo：`jvision-crew-workface-coordination`
3. **工項前置條件放行台**（construction-pm／營建工程）
   - 把每項施工前必備的圖說、材料、試驗、隱蔽查驗及工作面條件做成放行關卡，未達標不得開工，避免封板後返拆與工班待工。
   - 差異：最像既有「工地停工區復工放行台」，但該題處理停工後復工；本題管控正常工序首次開工前的技術與資源條件。
   - repo：`jvision-work-prerequisite-release`
4. **施工日誌缺漏稽核台**（construction-pm／營建工程）
   - 自動呈現施工日誌在人數、機具、天候、進度、停工事件與照片上的缺漏或矛盾，建立退補與簽認軌跡，保全工期爭議所需同期紀錄。
   - 差異：最像既有「施工日報資料匯流台」，但該題整併不同工區資料；本題專門查出單日日誌內部的缺漏、矛盾與遲補。
   - repo：`jvision-daily-log-gap-audit`
5. **預拌車澆置批次台**（construction-pm／營建工程）
   - 依澆置區與混凝土配比建立叫料批次，登錄每車出廠、到場、卸料、退料及方數，勾稽送貨單與供應商請款並辨識等候過久。
   - 差異：最像既有「混凝土試體送驗台」，但該題管理試體與試驗結果；本題管理澆置批次、車次物流及供料數量帳。
   - repo：`jvision-ready-mix-pour-batch`
6. **鄰房現況鑑定追蹤台**（construction-pm／營建工程）
   - 按門牌、樓層與構件管理施工前鄰房會勘，追蹤聯絡、入戶、照片定位、住戶簽認及拒訪紀錄，發生龜裂求償時快速比對基準證據。
   - 差異：最像既有「開挖支撐監測判讀台」，但該題監測施工期間地層與支撐數據；本題建立施工前鄰房實況與住戶簽認證據。
   - repo：`jvision-neighbor-condition-survey`
7. **施工便道維護排程台**（maintenance-cmms／營建工程）
   - 依便道路段管理坑洞、積泥、沉陷與承載問題，協調怪手、級配料和車流空檔安排維修，避免在灌漿或大量出土時封路造成車隊停等。
   - 差異：最像既有「工區封路申請協調台」，但該題管理各工班占用施工動線；本題管理施工便道本身的損壞、養護資源和復通。
   - repo：`jvision-access-road-maintenance`
8. **機具租賃工時計費台**（finance-ledger／營建工程）
   - 彙整租賃機具每日開工、待機、加班、故障與停租工時，依合約費率產生可核對計費明細，處理現場簽單與廠商月結表差異。
   - 差異：最像既有「機具租金計費核對台」，但該題以進退場天數及整月租金為主；本題聚焦按工時、待機與加班條款計費的租賃。
   - repo：`jvision-equipment-rental-hour-billing`
9. **材料到貨缺損索賠台**（procurement-srm／營建工程）
   - 在材料卸貨驗收時按採購單、批號與包裝記錄短少、破損或錯規，管理保留簽收、供應商回覆、補貨、折讓與求償期限。
   - 差異：最像既有「材料三單匹配審核台」，但該題確認訂單、收料與發票一致；本題處理實物缺損的保留簽收、補貨及索賠。
   - repo：`jvision-delivery-damage-claim`
10. **樓層材料限量叫料台**（warehouse-wms／營建工程）
   - 按棟別、樓層、工項與可堆置量控管材料叫料，合併重複需求並檢查現場餘料，避免超量配送、錯樓堆放及阻塞消防動線。
   - 差異：最像既有「現場材料保留領用台」，但該題處理既有庫存的保留與領退；本題控制材料由地面倉區分批叫送至樓層的數量。
   - repo：`jvision-floor-material-calloff`
11. **承攬合約缺件催辦台**（legal-case／營建工程）
   - 依分包合約與工種建立保險、證照、印鑑、保證及計畫書等必備文件清單，集中追蹤版本、效期、退補和進場前完成狀態。
   - 差異：最像既有「工班進場條件檢核台」，但該題同時檢查工作面、人員及施工條件；本題專管承攬合約法律與行政文件的收件催辦。
   - repo：`jvision-contract-document-readiness`
12. **追加減帳議價追蹤台**（finance-case／營建工程）
   - 彙整追加減工作的指示依據、施工前照片、數量計算、廠商報價與議價紀錄，追蹤暫定價、核定價及尚未談定的成本曝險。
   - 差異：最像既有「合約變更價款簽核台」，但該題控制正式變更的授權及帳務更新；本題聚焦核准前多輪數量、單價議價與未定價曝險。
   - repo：`jvision-variation-negotiation-tracker`
13. **業主變更選配結算台**（finance-ledger／營建工程）
   - 以戶別管理客變與選配項目的圖面版本、增減數量、價差、付款及退款，勾稽現場施工結果，避免做錯戶別、漏收追加款或重複退款。
   - 差異：最像既有「交屋修繕派工核銷台」，但該題處理完工缺失修繕；本題處理交屋前住戶選配變更的施工版本與價差帳。
   - repo：`jvision-owner-option-settlement`
14. **公設點交資產盤點台**（warehouse-wms／營建工程）
   - 按公設空間與設備位號盤點主機、備品、鑰匙、工具及操作文件，記錄實點數量、缺件責任和補交期限，支援建商向物業正式移交。
   - 差異：最像既有「公設點交缺件追蹤台」，但該題以跨單位缺件案件為核心；本題以逐項資產、備品、鑰匙和文件的實體盤點為核心。
   - repo：`jvision-common-facility-asset-handover`
15. **保固修繕期限管制台**（service-desk／營建工程）
   - 集中受理交付後保固案件，判定保固範圍、責任分包與服務期限，安排進場、複修及住戶確認，並攔截非保固損壞的免費派工。
   - 差異：最像既有「交屋缺失責任派工台」，但該題處理交屋驗收階段缺失；本題處理交付後保固期間的責任判定、服務期限與成本。
   - repo：`jvision-warranty-deadline-control`
16. **監造抽查缺失閉環台**（quality-qms／營建工程）
   - 管理監造抽查所開缺失的圖面位置、規範依據、責任工班、改善期限及複查結果，避免照片無法對位、重複開單或已改善卻未正式關閉。
   - 差異：最像既有「工地缺失限期改善台」，但該題涵蓋工地自主管理缺失；本題限定監造抽查案件及監造方正式複查權責。
   - repo：`jvision-supervision-defect-closure`
17. **公共工程查驗停留台**（quality-qms／營建工程）
   - 從品質計畫與排程建立停留點和見證點，提前通知承商及監造，管理備查文件、到場結果與放行範圍，防止未查驗即覆蓋施工。
   - 差異：最像既有「隱蔽工程封閉申請台」，但該題針對封板與回填前的隱蔽位置；本題涵蓋公共工程品質計畫中的各類停留點程序。
   - repo：`jvision-public-work-hold-point`
18. **標案資格文件檢核台**（legal-case／營建工程）
   - 把招標須知轉為資格、規格、用印、份數及電子檔規則，追蹤證明效期與最終封包版本，降低漏章、過期文件或命名錯誤造成廢標。
   - 差異：最像既有「印鑑用印授權稽核台」，但該題治理公司所有高風險用印；本題完整涵蓋營建標案資格文件從備件到封包送標。
   - repo：`jvision-bid-document-qualification`
19. **標單數量單價覆核台**（finance-case／營建工程）
   - 針對大量標單項次檢查單位、數量、公式、詢價來源與異常單價，建立雙人覆核及修正紀錄，避免漏估主要材料或錯列高風險單價。
   - 差異：最像既有「工程估量成本偏差預警雲」，但該題監控履約中的估量成本偏差；本題專門在投標前覆核標單公式、詢價與單價。
   - repo：`jvision-bid-unit-price-review`
20. **數量計算書覆核台**（construction-pm／營建工程）
   - 將數量計算式連結到圖號、樓層、構件與扣除規則，支援設計改版後差異重算及覆核註記，避免洞口漏扣、範圍重疊或重複計量。
   - 差異：最像既有「鋼筋進場噸數核對台」，但該題核對已到場鋼筋重量；本題在採購與計價前覆核各工項的圖面數量計算。
   - repo：`jvision-quantity-takeoff-review`
21. **工期展延事證彙整台**（legal-case／營建工程）
   - 依延誤事件串接日報、函文、照片、會議紀錄及排程要徑，建立同期通知、責任分析與申請天數試算，形成可提交的展延事證包。
   - 差異：最像既有「工程詢疑與設變分析台」，但該題判讀詢疑和設計變更內容；本題專注延誤事件的同期證據、要徑關聯及展延申請。
   - repo：`jvision-extension-evidence-package`
22. **局限空間進出許可台**（security-soc／營建工程）
   - 針對坑井、槽體與地下空間管理作業許可、氣體檢測、通風、救援配置與人員進出清點，確保換班後仍能辨識尚未退出者。
   - 差異：最像既有「高風險作業許可台」，但該題提供跨類型許可總管；本題具備局限空間特有的氣體檢測、救援配置與進出清點。
   - repo：`jvision-confined-space-entry-control`
23. **開挖支撐巡查交班台**（operations-console／營建工程）
   - 依支撐構件與開挖區記錄滲水、異音、變形及雨後巡查，將未結異常、封鎖範圍和處置進度完整交接給下一班。
   - 差異：最像既有「開挖支撐階段檢核台」，但該題在開挖階段轉換前決定放行；本題管理施工期間跨日夜班的連續巡查和異常交接。
   - repo：`jvision-excavation-shift-handover`
24. **現場圖說紅線整併台**（construction-pm／營建工程）
   - 集中收集各工區紙本或數位紅線註記，依圖號、位置與專業整併衝突內容，追蹤現場查證及設計確認，逐步形成可信竣工圖底稿。
   - 差異：最像既有「建築竣工智慧移交檢核台」，但該題檢查整體竣工移交完整度；本題專管施工期間紅線註記的收集、衝突整併與查證。
   - repo：`jvision-asbuilt-redline-consolidation`
25. **施工樣板核准留樣台**（quality-qms／營建工程）
   - 管理實體施工樣板的材料批次、施工步驟、核准照片、附帶修正與保留位置，讓後續大量施工和驗收都能依同一品質基準判定。
   - 差異：最像既有「樣品送審封樣管理台」，但該題核准單一材料樣品與色號；本題核准包含工法、收頭和觀感的實體施工樣板。
   - repo：`jvision-construction-mockup-approval`
26. **材料到場卸貨預約台**（logistics-fleet／營建工程）
   - 整合材料車到場時段、入口、卸貨區、吊車或堆高機需求及樓棟目的地，預先化解車輛撞期、機具不足與卸錯位置問題。
   - 差異：最像既有「機具進退場預約台」，但該題管理大型機具自身進退場；本題協調材料車、卸貨區與搬運機具的短時段作業。
   - repo：`jvision-unloading-appointment`
27. **機具進退場檢點台**（maintenance-cmms／營建工程）
   - 在租賃機具進場與退場時共同確認機況、附件、既有刮傷、證照及計費時點，保存雙方簽認，降低缺件賠償與逾期租金爭議。
   - 差異：最像既有「機具進退場預約台」，但該題解決場地與車流排程；本題處理機況、附件、責任與起停租時點的共同檢點。

   - 差異：最像既有「機具租賃工時計費台」，但該題彙總正常作業、待機和加班工時；本題處理故障事件、維修時效及停租責任。
