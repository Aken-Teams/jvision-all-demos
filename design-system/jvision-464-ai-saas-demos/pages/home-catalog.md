# Home Catalog｜Page Override

The JV Demo home page is a professional project retrieval interface, not a marketing landing page.

- Prioritize search, faceted filters, result count and clear project metadata above descriptive copy.
- Use the Master navy/blue enterprise palette with white surfaces and a light data-grid canvas.
- Keep the primary action as project search; the Agent is a secondary navigation target.
- Provide immediate suggestions, a useful no-result state, visible focus, keyboard navigation and shareable URL query state.
- On mobile, stack filters and cards; all actionable controls retain at least 44px height.
