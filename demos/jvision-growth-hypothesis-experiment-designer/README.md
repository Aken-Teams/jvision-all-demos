# 成長假設實驗設計器

> 將成長機會轉成可驗證假設、指標、樣本與停止條件。觸發後建立案件

將成長機會轉成可驗證假設、指標、樣本與停止條件。觸發後建立案件

**產業別：**業務銷售　|　**系統類型：**analytics-bi

## 功能模組

- **機會假設畫布** — 把觀察、目標客群、行為改變與預期結果組成假設。
- **成功指標設計** — 設定主指標、護欄指標、最小可偵測效果與基準值。
- **樣本規模規劃** — 依流量、效果量與檢定力估算樣本及實驗週期。
- **停止條件編排** — 定義成功、無效、傷害與資料品質異常的停止規則。
- **實驗風險評估** — 檢查偏差、互斥衝突、客戶傷害與營運風險。
- **實驗方案審議** — 彙整設計品質、風險與待核准事項後排入實驗。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 形成成長假設
2. 設定衡量指標
3. 估算樣本週期
4. 定義停止規則
5. 審查實驗風險
6. 核准實驗啟動

## 導入效益

- 商機轉換率：18% → **27%**
- 平均回應時間：26小時 → **6小時**
- 客戶資料完整率：62% → **94%**
- 報價逾期流失：9件/月 → **2件/月**
