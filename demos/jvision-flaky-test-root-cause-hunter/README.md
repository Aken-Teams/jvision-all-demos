# Flaky Test 根因獵人

> 分析執行時序、環境差異與共享狀態，定位不穩定測試的真正根因。         

分析執行時序、環境差異與共享狀態，定位不穩定測試的真正根因。         

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **不穩定測試榜** — 依失敗頻率、CI 浪費與產品風險排列 Flaky Test。
- **執行時序疊圖** — 對齊成功與失敗執行的步驟、日誌、資源及等待時間。
- **環境差異剖析** — 比較映像、依賴版本、節點負載與區域等執行條件。
- **共享狀態追蹤** — 找出測試間共用資料、快取、檔案與外部服務的污染。
- **根因假設實驗室** — 建立時序、環境及狀態假設並以重跑實驗驗證。
- **CI 降噪處方** — 產生修復、隔離或重構建議及預期噪音下降幅度。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 鎖定不穩定測試
2. 對齊執行時序
3. 比對環境條件
4. 追查共享狀態
5. 驗證根因假設
6. 核准降噪處方

## 導入效益

- 事件平均處理：120分鐘 → **30分鐘**
- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
- 資產盤點工時：20小時/月 → **4小時/月**
