# 末班車遺失物交接台

> 依班次、車號、座位與拾獲時間登錄末班車遺失物，管理司機、調度室、站務及客服間的封存交接、查詢比對與具證件的領回。

依班次、車號、座位與拾獲時間登錄末班車遺失物，管理司機、調度室、站務及客服間的封存交接、查詢比對與具證件的領回。

**產業別：**交通運輸　|　**系統類型：**service-desk

## 功能模組

- **拾獲登錄** — 記錄物品班次
- **封存保管** — 建立保管編號
- **跨站交接** — 簽認責任轉移
- **失主比對** — 搜尋特徵紀錄
- **領回核身** — 驗證申領身分
- **逾期處置** — 管理移交報廢

## 適合誰使用

- 駕駛員
- 站務人員
- 客服人員

## 運作流程

1. 登錄拾獲
2. 封存物品
3. 轉交站務
4. 比對失主
5. 核身領回
6. 逾期處置

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
