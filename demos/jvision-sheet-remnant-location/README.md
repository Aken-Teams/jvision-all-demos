# 板金餘板尋料套裁台

> 供板金廠管理餘板鋼種、厚度、尺寸、保護膜方向及實際架位，依切割排版需求推薦候選料，降低天車翻板與高價新板耗用。

供板金廠管理餘板鋼種、厚度、尺寸、保護膜方向及實際架位，依切割排版需求推薦候選料，降低天車翻板與高價新板耗用。

**產業別：**倉儲物流　|　**系統類型：**warehouse-wms

## 功能模組

- **餘板總覽** — 查看材質厚度尺寸
- **材證綁定** — 保留爐號與證明
- **堆位管理** — 記錄上下層位置
- **套裁搜尋** — 比對需求尺寸
- **排版預留** — 避免重複領用
- **切後結清** — 更新剩餘形狀

## 適合誰使用

- 排版工程師
- 鋼板庫管員

## 運作流程

1. 產生餘板
2. 材質確認
3. 入架定位
4. 套裁查料
5. 天車領料
6. 用料結清

## 導入效益

- 揀貨作業工時：7小時/日 → **2小時/日**
- 庫存準確率：88% → **99%**
- 出貨延遲率：9% → **2%**
- 盤點工時：16小時/月 → **3小時/月**
