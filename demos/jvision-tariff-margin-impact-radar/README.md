# 關稅變動毛利衝擊雷達

持續監測關稅變動並映射未交訂單，預警客戶毛利衝擊與調價時機。

**產業別：**採購供應鏈　|　**系統類型：**analytics-bi

## 功能模組

- **稅率變動雷達** — 監測商品、原產地與目的國相關的新增或調整稅率。
- **未交訂單映射** — 將稅率事件連結至受影響的未出貨訂單與排程。
- **毛利衝擊模擬** — 模擬不同生效日、稅率與匯率下的訂單毛利變化。
- **客戶曝險分群** — 按合約條件、訂單金額與轉嫁能力識別高曝險客戶。
- **調價方案規劃** — 比較全額轉嫁、分攤、延後或替代供應等定價策略。
- **調價行動中心** — 安排客戶通知、報價更新及訂單重議的優先任務。

## 適合誰使用

- 國貿主管
- 報關人員
- 業務

## 運作流程

1. 捕捉稅率變動
2. 定位受影響訂單
3. 模擬毛利衝擊
4. 劃分客戶曝險
5. 選擇調價方案
6. 啟動調價行動

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
