# 車輛清潔退場驗收台

> 依車型與下一班任務建立清潔標準，記錄座椅、地板、洗手間及異味檢查，對缺失退洗、複驗並發布可出車狀態，避免發車前臨時換車。

依車型與下一班任務建立清潔標準，記錄座椅、地板、洗手間及異味檢查，對缺失退洗、複驗並發布可出車狀態，避免發車前臨時換車。

**產業別：**交通運輸　|　**系統類型：**maintenance-cmms

## 功能模組

- **清潔任務** — 依班次排定
- **分區標準** — 逐項檢查車室
- **缺失採證** — 記錄髒污異味
- **退洗處理** — 分派返工項目
- **複驗確認** — 驗證改善完成
- **出車放行** — 發布可用狀態

## 適合誰使用

- 清潔領班
- 車隊調度員
- 出車驗收員

## 運作流程

1. 派發任務
2. 完成清潔
3. 執行驗收
4. 退回改善
5. 完成複驗
6. 核准出車

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
