# Prompt 在地化驗證器

> 驗證繁中、英文與日文 Prompt 的語意及行為一致性，支援多國部署。

驗證繁中、英文與日文 Prompt 的語意及行為一致性，支援多國部署。

**產業別：**資訊科技　|　**系統類型：**quality-qms

## 功能模組

- **多語 Prompt ** — 並排管理繁中、英文、日文版本及共用變數與地區差異。
- **跨語語意對齊** — 檢查目標、限制、語氣與輸出要求是否跨語保持一致。
- **在地表達檢查** — 辨識敬語、日期、幣別、法規用語與文化情境的不自然表達。
- **多語回應比對** — 以相同意圖執行各語版本，對照答案內容與行為差異。
- **語意偏移分級** — 依業務影響與因果線索排序漏譯、誤譯及規則偏移。
- **地區發布守門** — 為各語系設定通過門檻，控制 Prompt 版本的地區發布。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 選擇語系版本
2. 對照多語內容
3. 分析語意偏移
4. 驗證在地行為
5. 處理高風險差異
6. 核准地區發布
