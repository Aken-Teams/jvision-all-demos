# 施工日誌缺漏稽核台

> 自動呈現施工日誌在人數、機具、天候、進度、停工事件與照片上的缺漏或矛盾，建立退補與簽認軌跡，保全工期爭議所需同期紀錄。

自動呈現施工日誌在人數、機具、天候、進度、停工事件與照片上的缺漏或矛盾，建立退補與簽認軌跡，保全工期爭議所需同期紀錄。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **日誌總覽** — 查看每日填報狀態
- **缺漏偵測** — 標示未填與矛盾欄位
- **資料勾稽** — 比對人力進度與照片
- **退補作業** — 指派更正與補充說明
- **日誌封存** — 簽認不可任意改寫版本
- **缺漏分析** — 統計常見錯誤與單位

## 適合誰使用

- 現場工程師
- 工地主任
- 文件管理員

## 運作流程

1. 提交日誌
2. 系統檢核
3. 退回補正
4. 補充佐證
5. 主管簽認
6. 封存稽核

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
