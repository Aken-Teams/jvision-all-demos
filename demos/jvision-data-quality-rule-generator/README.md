# 資料品質規則生成器

> 根據資料契約、欄位分布與歷史事件生成可部署的品質規則，擴大監控覆蓋。

根據資料契約、欄位分布與歷史事件生成可部署的品質規則，擴大監控覆蓋。

**產業別：**數據分析　|　**系統類型：**quality-qms

## 功能模組

- **契約約束解析** — 從 Schema 與資料契約擷取必填、型別及值域要求。
- **欄位分布剖析** — 分析空值率、基數、分位數、模式與季節性。
- **品質事件回溯** — 從過往異常與修復紀錄辨識可重複監控的失效模式。
- **候選規則生成** — 建議完整性、有效性、一致性與新鮮度規則。
- **門檻模擬調校** — 以歷史資料回放規則，估算誤報、漏報及成本。
- **規則發布管理** — 核准規則版本並部署至管線或品質平台。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 解析資料契約
2. 分析歷史分布
3. 歸納失效模式
4. 審閱候選規則
5. 回放調整門檻
6. 核准部署規則

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
