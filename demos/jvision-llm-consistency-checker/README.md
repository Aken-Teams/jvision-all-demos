**產業別：**資訊科技　|　**系統類型：**quality-qms

## 功能模組

- **多輪推論矩陣** — 以相同或擾動提示執行多次推論並排列比較結果。
- **跨模型對照** — 比較不同模型、版本與參數組合對同一問題的回答。
- **主張差異比對** — 將回答拆成主張後標示一致、互斥、缺漏與數值偏差。
- **矛盾關係圖** — 以圖譜呈現模型、主張、來源與衝突關係。
- **穩定度評分** — 量化語意、事實、數值與結論在多次推論中的穩定性。
- **共識答案審閱** — 草擬有佐證的共識答案，保留分歧點供人工裁定。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 設定比對方案
2. 執行多路推論
3. 拆解回答主張
4. 定位矛盾關係
5. 評估答案穩定度
6. 裁定共識答案
