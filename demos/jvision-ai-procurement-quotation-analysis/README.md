# 智慧採購詢比價成本分析系統

> 管理採購需求、詢價案件、供應商報價與價格條件，以人工智慧協助標準化不同幣別、稅費、交期及付款條件，產生可比較的成本結構與議價重點，讓採購人員更快完成選商建議及簽核紀錄。

管理採購需求、詢價案件、供應商報價與價格條件，以人工智慧協助標準化不同幣別、稅費、交期及付款條件，產生可比較的成本結構與議價重點，讓採購人員更快完成選商建議及簽核紀錄。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **採購需求池** — 彙整待詢價需求、品項規格、數量、期望交期、預算與申請部門。
- **詢價案件管理** — 建立詢價批次、選擇邀請供應商、設定截止時間及必要報價欄位。
- **智慧比價工作台** — 將不同報價的幣別、稅費、交期、付款及最小訂購量轉為共同基準。
- **成本結構分析** — 拆解單價、運費、關稅、付款成本與持有成本，呈現總成本差異。
- **議價決策輔助** — 對照歷史價格與報價分布，顯示議價目標、談判重點及替代方案。
- **選商簽核中心** — 彙整推薦供應商、選擇理由、風險提示及各層級審核紀錄。

## 適合誰使用

- 採購專員
- 採購主管
- 需求部門主管
- 財務審核人員

## 運作流程

1. 確認採購需求
2. 建立詢價案件
3. 統一比較報價
4. 分析完整成本
5. 形成議價策略
6. 完成選商簽核

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
