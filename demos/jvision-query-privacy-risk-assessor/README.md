## 功能模組

- **查詢意圖解析** — 解析欄位、篩選、聚合與連接所形成的資料需求。
- **準識別子偵測** — 辨識可組合推回個人的欄位與外部連結可能性。
- **小群體暴露模擬** — 估算篩選與分組後可能出現的稀少族群。
- **重識別風險評分** — 計算不同攻擊情境下的重識別機率與信心區間。
- **隱私改寫工作台** — 比較抑制、泛化、遮罩與差分隱私的效用損失。
- **執行前隱私閘門** — 依風險門檻允許、阻擋或送交資料管理員核准。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 解析查詢
2. 辨識識別線索
3. 模擬群體暴露
4. 評估重識別
5. 調整隱私策略
6. 核准執行
