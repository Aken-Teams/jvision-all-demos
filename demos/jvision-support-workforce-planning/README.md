# 客服人力需求規劃台

> 依歷史案件量、渠道占比、處理時長與服務水準目標，建立客服需求情境及班別覆蓋建議，協助主管在活動、版本上線與旺季前完成人力配置及缺口溝通。

**產業別：**客服管理　|　**系統類型：**service-desk

## 功能模組

- **需求總覽** — 呈現渠道案件量、人力需求與缺口。
- **情境假設** — 設定活動、事件、成長率與到件分布。
- **工時模型** — 維護處理時長、縮減率及服務目標。
- **時段需求** — 計算每日各半小時所需客服人數。
- **班表比對** — 比較現有人力、技能與需求覆蓋。
- **補位方案** — 模擬加班、借調、委外與服務水準取捨。

## 適合誰使用

- 客服主管
- 排班專員
- 營運分析師

## 運作流程

1. 檢視需求
2. 設定情境
3. 校準工時
4. 產生需求
5. 比對班表
6. 核定補位

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
