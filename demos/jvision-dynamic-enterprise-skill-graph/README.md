# 動態技能圖譜

> 從職務、任務與成果推導技能關聯，建立可持續更新的企業技能語言。

從職務、任務與成果推導技能關聯，建立可持續更新的企業技能語言。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **技能本體工作台** — 統一技能名稱、層級、同義詞與相鄰能力定義。
- **職務技能映射** — 從職務內容與實際任務推導所需技能及熟練度。
- **成果技能取證** — 由專案、績效與工作產出辨識可驗證的技能證據。
- **技能關聯圖譜** — 探索技能、任務、職務、內容與人員之間的關聯。
- **技能供需差距** — 比較組織需求與現有人才技能的數量及程度缺口。
- **圖譜變更治理** — 審核新技能、關聯調整與模型信心不足的建議。

## 適合誰使用

- L&D 主管
- 部門主管
- 員工

## 運作流程

1. 定義技能語言
2. 映射職務任務
3. 驗證成果證據
4. 探索技能圖譜
5. 研判供需缺口
6. 核准圖譜更新

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
