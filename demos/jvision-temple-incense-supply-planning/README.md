# 宮廟香品供應管理台

> 協助宮廟依平日、節慶與進香團需求規劃香品、金紙、平安符袋等消耗物資，管理安全庫存、供應商交期、批次領用及活動結餘，避免大典缺料或過量囤積。

協助宮廟依平日、節慶與進香團需求規劃香品、金紙、平安符袋等消耗物資，管理安全庫存、供應商交期、批次領用及活動結餘，避免大典缺料或過量囤積。

**產業別：**宗教服務　|　**系統類型：**procurement-srm

## 功能模組

- **供應總覽** — 掌握節慶需求、庫存與到貨風險。
- **活動需求** — 依科儀及人流估算物資用量。
- **庫存盤點** — 管理現貨、批次與安全庫存。
- **採購補料** — 彙整缺口並建立採購需求。
- **到貨追蹤** — 追蹤供應商交期及驗收差異。
- **結餘分析** — 比較預估、領用及活動剩餘。

## 適合誰使用

- 宮廟總務
- 庫房管理員
- 採購人員

## 運作流程

1. 查看風險
2. 估算需求
3. 盤點現貨
4. 提出採購
5. 驗收到貨
6. 分析結餘

## 導入效益

- 活動籌備工時：20小時 → **5小時**
- 報名掌握率：65% → **94%**
- 物資盤點：6小時 → **1小時**
- 志工調度時效：3天 → **1天**
