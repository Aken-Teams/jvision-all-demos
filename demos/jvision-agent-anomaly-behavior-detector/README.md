偵測 Agent 呼叫暴增、流程偏離與異常資料存取，在失控前提出處置。

**產業別：**資訊科技　|　**系統類型：**security-soc

## 功能模組

- **行為基線監看** — 依 Agent、任務與時段建立正常工具呼叫基線。
- **呼叫暴增雷達** — 辨識請求量、重試率、併發與成本的突增。
- **流程偏離追蹤** — 比對實際任務軌跡與核准流程的異常分支。
- **資料存取警戒** — 偵測非常態資料集、敏感欄位與跨域存取。
- **失控風險預測** — 模擬異常持續時的成本、資料與營運衝擊。
- **抑制處置中心** — 執行限流、撤權、暫停或轉人工等核准措施。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 建立行為基線
2. 篩查呼叫異常
3. 比對流程偏離
4. 調查資料存取
5. 研判失控風險
6. 核准抑制措施
