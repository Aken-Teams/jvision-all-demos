# 測量控制點移交台

> 管理基地基準點、樓層控制點與沉陷觀測點的設置、複測、保護及工班移交，透過座標版本和偏差紀錄避免控制點遭破壞或引用錯誤造成放樣返工。

管理基地基準點、樓層控制點與沉陷觀測點的設置、複測、保護及工班移交，透過座標版本和偏差紀錄避免控制點遭破壞或引用錯誤造成放樣返工。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **點位地圖** — 按基地與樓層顯示控制點位置及有效性。
- **點位建置** — 登錄座標、高程、基準來源與保護方式。
- **複測紀錄** — 輸入觀測成果並自動標示容許偏差。
- **工班移交** — 記錄領用範圍、用途與交接雙方確認。
- **異常停用** — 處理碰損、遮蔽、位移及引用爭議。
- **版本履歷** — 追溯座標修訂、重設與歷次使用紀錄。

## 適合誰使用

- 測量工程師
- 施工工程師
- 分包領班

## 運作流程

1. 點位地圖
2. 點位建置
3. 複測紀錄
4. 工班移交
5. 異常停用
6. 版本履歷

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
