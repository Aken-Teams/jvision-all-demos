# 旅宿超賣搬房協調台

> 在超賣事件中統一管理受影響訂單、替代旅館、交通、升等與旅客通知，避免重複補償、承諾不一致或入住當日才臨時找房。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **超賣事件** — 彙整日期與受影響房型。
- **旅客排序** — 依到店與承諾條件排優先級。
- **替代房源** — 比較合作旅館與可用房。
- **安置方案** — 組合搬房、交通與升等。
- **旅客溝通** — 記錄通知、回覆與選擇。
- **補償結案** — 確認費用與責任歸屬。

## 適合誰使用

- 訂房主管
- 櫃檯經理
- 值班主管

## 運作流程

1. 建立事件
2. 排序旅客
3. 搜尋房源
4. 提出方案
5. 取得確認
6. 費用結案

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
