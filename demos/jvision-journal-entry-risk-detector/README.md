# 總帳分錄風險偵測器

> 針對總帳分錄的金額、時間、科目組合、摘要與建立者特徵進行風險分級，呈現可解釋的命中規則及相似案例，協助會計與稽核人員優先覆核高風險分錄並留下處理軌跡。

針對總帳分錄的金額、時間、科目組合、摘要與建立者特徵進行風險分級，呈現可解釋的命中規則及相似案例，協助會計與稽核人員優先覆核高風險分錄並留下處理軌跡。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **風險監控總覽** — 呈現風險分布、期間趨勢、公司別及待處理案件。
- **高風險分錄佇列** — 依分數、金額、日期與規則篩選待查分錄。
- **分錄脈絡檢視** — 查看借貸明細、建立資訊、附件及前後交易脈絡。
- **風險原因解析** — 說明異常時間、金額、科目或人員特徵的影響。
- **相似案例比對** — 並列歷史分錄與處理結果，輔助判斷本案風險。
- **查核處置追蹤** — 指派負責人、記錄結論並追蹤沖銷或更正進度。

## 適合誰使用

- 總帳會計
- 會計主管
- 內部稽核與財務長

## 運作流程

1. 掌握風險概況
2. 篩選待查分錄
3. 檢閱交易脈絡
4. 解讀風險原因
5. 比對歷史案例
6. 完成查核處置

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
