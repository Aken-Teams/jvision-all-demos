# 旅宿代收款交付對帳台

> 將旅館代收的接送、租車與票券款自房費拆分，追蹤服務取消、業者交付、佣金留存及未認領餘額，避免重付或長期掛帳。

將旅館代收的接送、租車與票券款自房費拆分，追蹤服務取消、業者交付、佣金留存及未認領餘額，避免重付或長期掛帳。

**產業別：**餐飲旅宿　|　**系統類型：**finance-ledger

## 功能模組

- **代收明細** — 查看住客與合作服務項目。
- **房費拆分** — 區分房費、代收款與佣金。
- **履約確認** — 核對服務完成或取消。
- **款項交付** — 記錄現金或轉帳給業者。
- **差異處理** — 追查重付、少付與未認領款。
- **月結清帳** — 結清負債與佣金收入。

## 適合誰使用

- 櫃檯人員
- 應付會計
- 財務主管

## 運作流程

1. 建立代收
2. 拆分交易
3. 確認履約
4. 執行交付
5. 處理差異
6. 完成清帳

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
