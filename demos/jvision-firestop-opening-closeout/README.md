**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **孔洞點位** — 依防火區劃、樓層及牆板編碼建立穿越點。
- **系統選型** — 比對管線材質、孔徑與核可封堵系統。
- **封堵派工** — 安排責任分包、期限與施作前置條件。
- **施工存證** — 保存清孔、填塞深度、密封材及完工照片。
- **標籤查驗** — 核對點位標籤、工法編號與現場狀態。
- **破壞重啟** — 記錄追加穿線並重新啟動封堵與複驗。

## 適合誰使用

- 機電工程師
- 消防專技人員
- 品管工程師

## 運作流程

1. 登錄貫穿點位
2. 核定封堵系統
3. 指派封堵施工
4. 提交施工存證
5. 辦理現場查驗
6. 維持竣工狀態

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
