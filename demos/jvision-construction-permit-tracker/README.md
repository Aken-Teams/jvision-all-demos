# 工程送審許可追蹤台

> 集中管理建照、消防、使用執照與各類施工送審文件，將主管機關意見、補正版本、承辦窗口及期限串成案件歷程，避免許可延誤阻塞工地里程碑。

集中管理建照、消防、使用執照與各類施工送審文件，將主管機關意見、補正版本、承辦窗口及期限串成案件歷程，避免許可延誤阻塞工地里程碑。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **許可總覽** — 彙整案件狀態、期限與里程碑影響。
- **送審清冊** — 依許可類型管理必要文件及簽證資料。
- **完整度檢核** — 標記缺件、過期附件與待用印項目。
- **送件紀錄** — 保存送件日期、文號、窗口及預計回覆日。
- **補正協作** — 拆解審查意見並分派設計與技師回覆。
- **時程衝擊** — 模擬延遲對開工、查驗及交屋節點的影響。

## 適合誰使用

- 工程專案經理
- 送審專員
- 設計顧問

## 運作流程

1. 檢視許可
2. 建立清冊
3. 完成檢核
4. 登錄送件
5. 處理補正
6. 調整時程

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
