# 供應商績效改善教練

> 整合模擬的交期、品質、成本、服務與改善紀錄，形成供應商績效卡及落差診斷，協助買賣雙方設定改善目標、拆解行動、準備檢討會議，並持續驗證改善成效。

整合模擬的交期、品質、成本、服務與改善紀錄，形成供應商績效卡及落差診斷，協助買賣雙方設定改善目標、拆解行動、準備檢討會議，並持續驗證改善成效。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **供應商績效卡** — 彙整交期、品質、成本、服務及配合度指標與趨勢。
- **績效落差診斷** — 將低分指標拆解至工廠、料號、訂單與問題類型。
- **改善目標設定** — 依落差建立量化目標、基準值、期限及驗證方式。
- **改善行動管理** — 拆解責任人、里程碑、所需證據與逾期提醒。
- **績效會議助手** — 整理議程、待決事項、趨勢圖與雙方會議紀錄。
- **成效驗證中心** — 比較改善前後結果並判定結案、觀察或追加措施。

## 適合誰使用

- 供應商管理人員
- 採購專員
- 供應商品質工程師

## 運作流程

1. 檢視績效結果
2. 診斷落差來源
3. 設定改善目標
4. 執行改善行動
5. 召開績效會議
6. 驗證改善成果

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
