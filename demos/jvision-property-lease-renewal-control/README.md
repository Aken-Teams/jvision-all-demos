# 商用租約續約管制台

> 供商辦與店面資產管理團隊集中追蹤租約期限、調租條款、押金、續約談判與核決版本，在通知期限前啟動作業，降低漏續約、空置及沿用錯誤條件的風險。

**產業別：**房地產與物業　|　**系統類型：**legal-case

## 功能模組

- **到期雷達** — 依通知期限排列待續租約。
- **條款摘要** — 整理租期、押金及調租約定。
- **方案試算** — 比較租金、免租期與裝修補助。
- **談判紀錄** — 保存房東與承租方往返方案。
- **續約核決** — 依金額與折讓送主管審核。
- **版本交接** — 確認定案條件與簽約文件。

## 適合誰使用

- 租賃專員
- 資產經理
- 法務人員

## 運作流程

1. 篩選到期租約
2. 檢查原始條款
3. 擬定續約方案
4. 記錄談判進度
5. 提交條件核決
6. 完成版本交接
