# 視覺資產合規檢查器

> 檢查視覺資產的 Logo、留白、色彩與版本誤用，降低品牌偏差。

檢查視覺資產的 Logo、留白、色彩與版本誤用，降低品牌偏差。

**產業別：**業務銷售　|　**系統類型：**quality-qms

## 功能模組

- **品牌資產巡檢** — 掃描 DAM、網站與廣告平台中的已發布視覺素材。
- **Logo 版本辨識** — 辨識舊版、變形、錯色及不適用情境的 Logo。
- **安全距離量測** — 量測 Logo 周圍留白、最小尺寸與遮擋情況。
- **品牌色彩校驗** — 比對色票、對比度、漸層與印刷或數位使用規範。
- **版型偏差模擬** — 預覽不同裝置與裁切情境下的品牌偏差風險。
- **資產修正派工** — 排序違規嚴重度，核准後指派替換或重製任務。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 建立巡檢範圍
2. 核驗 Logo 使用
3. 檢查安全距離
4. 校驗品牌色彩
5. 模擬多版型偏差
6. 核准修正派工
