# 射出成型參數最佳化系統

> 針對品質、週期、能耗與製程限制建立擬真最佳化任務，自動產生並排序候選成型參數，讓工程師比較每組方案的效益與風險，選定後透過試模紀錄及簽核流程形成可追溯的標準參數版本。

針對品質、週期、能耗與製程限制建立擬真最佳化任務，自動產生並排序候選成型參數，讓工程師比較每組方案的效益與風險，選定後透過試模紀錄及簽核流程形成可追溯的標準參數版本。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **最佳化任務總覽** — 查看任務進度、目標達成度、待審方案與近期發布版本。
- **品質目標設定** — 設定重量、尺寸、外觀、週期及能耗的目標與權重。
- **參數範圍管理** — 定義溫度、速度、壓力、保壓及冷卻時間的上下限與限制。
- **候選方案產生** — 以預先建置的擬真資料產生多組候選參數及預估結果。
- **效益風險評比** — 用排名與取捨圖比較品質、產能、能耗及穩健程度。
- **標準參數發布** — 完成試模確認、版本差異檢查、簽核與參數表發布。

## 適合誰使用

- 射出製程工程師
- 試模工程師
- 生產主管

## 運作流程

1. 建立任務
2. 設定目標
3. 限制參數
4. 產生方案
5. 評選方案
6. 核准發布
