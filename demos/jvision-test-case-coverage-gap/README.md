**產業別：**資訊科技　|　**系統類型：**quality-qms

## 功能模組

- **需求與風險總覽** — 彙整需求、功能區、變更程度與測試風險。
- **測試案例生成** — 依流程、角色及例外條件產生案例草稿。
- **案例審閱編輯** — 調整前置條件、步驟、資料與預期結果。
- **需求追溯矩陣** — 顯示每項需求對應的案例、狀態與覆蓋層級。
- **覆蓋缺口分析** — 找出功能、權限、例外與裝置情境缺口。
- **補測計畫管理** — 依風險排序缺口並指派補測責任與期限。

## 適合誰使用

- 測試工程師
- 測試主管
- 產品經理
- 軟體開發人員

## 運作流程

1. 盤點需求
2. 生成草稿
3. 審閱案例
4. 建立追溯
5. 辨識缺口
6. 安排補測
