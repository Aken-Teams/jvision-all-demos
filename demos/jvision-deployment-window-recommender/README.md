# 部署窗口推薦器

綜合流量、值班、變更風險與商務事件，推薦低衝擊部署窗口。文補正

**產業別：**資訊科技　|　**系統類型：**operations-console

## 功能模組

- **候選窗口日曆** — 整合發布計畫與可用時段，列出可比較的部署候選窗口。
- **流量低谷預測** — 預測各服務與區域在候選時段的請求量及尖峰風險。
- **值班覆蓋檢查** — 核對主責、備援與專家在部署及觀察期間的可用性。
- **商務衝突偵測** — 標示促銷、結算、活動及變更凍結等不可部署事件。
- **窗口風險比較** — 依流量、變更複雜度、人力與商務衝擊排序候選時段。
- **發布時段核准** — 彙整推薦依據、接受調整並送出部署窗口核准。

## 適合誰使用

- 工程主管
- 開發者

## 運作流程

1. 彙整時段
2. 預測流量
3. 核對值班
4. 排除衝突
5. 比較窗口
6. 核准排程
