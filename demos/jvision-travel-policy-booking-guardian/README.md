## 功能模組

- **差旅行程建案** — 彙整出差目的、地點、日期與旅客職級，建立預訂判斷基準。
- **艙等資格判定** — 依飛行時數、航線與職級即時判斷可預訂艙等。
- **住宿額度核對** — 比對城市住宿上限、房型、稅費與會議指定飯店規則。
- **政策衝突檢查** — 跨差旅規範、HR 資料與行程條件找出違規項目。
- **差旅例外核准** — 整理超額原因與替代方案，送交具權限主管修改或核准。
- **合規預訂執行** — 依核准結果鎖定合規選項並回寫訂單及差旅申請。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 建立差旅行程
2. 判斷可用艙等
3. 核對住宿方案
4. 檢視政策衝突
5. 處理例外申請
6. 完成合規預訂

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
