**產業別：**業務銷售　|　**系統類型：**analytics-bi

## 功能模組

- **素材疲勞總覽** — 依平台與活動呈現素材疲勞程度及預算風險。
- **曝光頻率警戒** — 追蹤受眾重複曝光與頻率跨越門檻的速度。
- **反應衰退曲線** — 比較點擊、互動與轉換率隨曝光累積的變化。
- **受眾疲勞切片** — 定位最早出現疲勞的客群、版位與投放情境。
- **創意替換模擬** — 評估候選素材接替後的觸及、轉換與成本影響。
- **換檔核准中心** — 審核停投、降頻或替換建議並安排執行時點。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 掃描疲勞風險
2. 確認頻率異常
3. 驗證成效衰退
4. 定位疲勞受眾
5. 比較替代創意
6. 核准素材換檔
