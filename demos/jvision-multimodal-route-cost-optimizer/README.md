# 多式聯運路線成本最佳化台

> 整合海運、空運、鐵路與公路等擬真運輸方案，依交期、費率、轉運風險及碳排限制比較可行路線，協助物流人員快速完成詢價試算、方案核准與運程追蹤。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **運輸任務總覽** — 集中呈現待規劃、待核准、運送中與異常的出貨任務。
- **路線方案產生** — 依起訖地、貨況與交期建立多種跨運具路線組合。
- **成本時效試算** — 拆解運費、附加費、轉運時間與延誤緩衝。
- **方案情境比較** — 並排比較成本、時效、風險與碳排的取捨。
- **路線核准作業** — 記錄推薦理由、主管意見與選定方案。
- **聯運節點追蹤** — 以時間軸檢視各運段、轉運節點與模擬異常。

## 適合誰使用

- 物流規劃專員
- 國貿人員
- 供應鏈主管

## 運作流程

1. 建立運輸任務
2. 產生聯運路線
3. 試算成本時效
4. 比較決策情境
5. 核准執行方案
6. 追蹤聯運進度

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
