# 技能模擬角色扮演器

> 模擬客戶、主管或事故情境並即時回饋，讓員工安全演練高風險任務。提升臨場反應與決策能力。

**產業別：**人力資源　|　**系統類型：**education-lms

## 功能模組

- **情境任務選擇** — 選擇客訴、主管溝通、事故應變等高風險演練主題。
- **角色與難度設定** — 配置虛擬角色性格、情境壓力、資訊限制與成功條件。
- **即時角色扮演** — 以文字或語音和虛擬客戶、主管或事故角色進行互動。
- **關鍵行為偵測** — 即時辨識遺漏步驟、不當措辭、升級時機與風險決策。
- **分支後果回放** — 呈現不同回應對客戶情緒、安全結果與任務成敗的影響。
- **能力回饋報告** — 依行為指標評分並產生下一輪可執行的改善建議。

## 適合誰使用

- L&D 主管
- 部門主管
- 員工

## 運作流程

1. 選定演練情境
2. 配置角色條件
3. 進行情境互動
4. 偵測關鍵行為
5. 回放分支後果
6. 檢討並指派複練
