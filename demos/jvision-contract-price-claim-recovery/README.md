# 採購合約價差索賠回收助手

> 比對模擬合約條款、議定價格、採購單、收貨與發票資料，找出超價計費、折扣未套用、短交或服務水準未達等可索賠項目，並協助整理證據、建立案件及追蹤回收結果。

## 功能模組

- **合約條款台帳** — 整理價格、折扣、返利、服務水準與索賠期限等條款。
- **價差比對中心** — 並列合約價、採購價與發票價，標示超價及未套用折扣。
- **索賠機會偵測** — 呈現短交、遲交、品質扣款與服務未達標等候選事件。
- **索賠證據包** — 彙整條款、訂單、收貨、發票與往來紀錄的模擬證據。
- **索賠通知編製** — 依案件事實產生可編輯的通知內容與金額計算明細。
- **回收案件追蹤** — 管理確認、爭議、折讓、退款及入帳等案件進度。

## 適合誰使用

- 採購合約管理人員
- 應付帳款人員
- 法務人員

## 運作流程

1. 檢視合約義務
2. 核對交易價差
3. 確認索賠事件
4. 組成證據資料
5. 發出索賠通知
6. 完成回收入帳
