# 薪轉帳戶變更驗證台

> 受理員工薪轉帳戶變更，核驗本人、銀行資料、生效薪期及重複帳號風險，透過雙人覆核後才納入薪資匯款檔，降低冒名竄改與錯匯追款。

受理員工薪轉帳戶變更，核驗本人、銀行資料、生效薪期及重複帳號風險，透過雙人覆核後才納入薪資匯款檔，降低冒名竄改與錯匯追款。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **變更申請** — 提交新帳戶與生效薪期
- **本人驗證** — 記錄獨立聯絡確認結果
- **帳戶核驗** — 檢查銀行格式與戶名
- **重複檢查** — 辨識多人共用及可疑帳號
- **雙人覆核** — 分權核准薪資主檔更新
- **首匯確認** — 追蹤退匯與實際生效

## 適合誰使用

- 員工
- 薪酬人員
- 人資主管

## 運作流程

1. 提出變更
2. 驗證本人
3. 核對帳戶
4. 掃描風險
5. 完成覆核
6. 確認首匯

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
