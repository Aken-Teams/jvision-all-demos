# Skill 依賴解析器

> 解析 Skill 的工具、知識、權限與子 Skill 依賴，提前避免安裝與執行失敗。

解析 Skill 的工具、知識、權限與子 Skill 依賴，提前避免安裝與執行失敗。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **依賴拓撲圖** — 展開 Skill、工具、知識庫與子 Skill 的多層依賴關係。
- **權限需求解析** — 比對各依賴所需角色、Scope、憑證與存取條件。
- **介面相容檢查** — 檢查 API、MCP 工具及資料 Schema 的版本相容性。
- **安裝方案模擬** — 模擬不同環境與版本組合的安裝結果及衝突。
- **缺件衝突清單** — 依阻斷程度列出缺少套件、循環依賴與版本衝突。
- **修復安裝計畫** — 產生可核准的補件、升降版與權限調整步驟。

1. 選取解析目標

4. 模擬安裝情境
5. 審查修復方案
6. 執行並驗證安裝
