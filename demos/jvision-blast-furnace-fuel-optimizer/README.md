# 高爐燃料最佳化顧問

> 整合班次爐況、裝料結構、風溫與燃料比等擬真資料，以趨勢診斷、異常解讀及情境試算協助高爐團隊穩定爐況，找出兼顧產量、品質與焦比成本的操作建議。

整合班次爐況、裝料結構、風溫與燃料比等擬真資料，以趨勢診斷、異常解讀及情境試算協助高爐團隊穩定爐況，找出兼顧產量、品質與焦比成本的操作建議。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **爐況總覽** — 以爐況評分、關鍵趨勢與班次事件掌握目前穩定度。
- **熱況剖面** — 查看爐身溫度、熱負荷與區域偏差的視覺化分布。
- **燃料診斷** — 拆解焦炭、噴煤與風溫對燃料比及產量的影響。
- **操作試算** — 模擬風量、富氧、噴煤及裝料參數調整後的結果。
- **調整建議** — 依風險與效益排序可執行的操作方案及注意事項。
- **班次復盤** — 比較各班操作、異常處置與成效，沉澱交班經驗。

## 適合誰使用

- 高爐值班工長
- 製程工程師
- 能源管理主管

## 運作流程

1. 掌握爐況
2. 定位熱況
3. 分析燃料
4. 模擬方案
5. 確認建議
6. 完成交班
