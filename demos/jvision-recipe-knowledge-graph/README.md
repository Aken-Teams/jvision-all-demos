# 配方知識圖譜

> 串聯原料、機理、參數、缺陷與結果，保存並復用配方隱性知識。実際

串聯原料、機理、參數、缺陷與結果，保存並復用配方隱性知識。実際

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **配方關聯圖譜** — 以互動網路呈現原料、設備參數、缺陷與品質結果。
- **原料機理地圖** — 整理原料特性、反應機理及其適用條件。
- **缺陷因果路徑** — 探索參數變動如何沿製程路徑形成特定缺陷。
- **相似配方探索** — 依材料、製程與品質目標尋找可復用的歷史配方。
- **隱性知識提煉** — 從工單與工程紀錄萃取尚未結構化的操作經驗。
- **知識驗證發布** — 審查關聯強度與適用邊界，發布可追溯知識版本。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 瀏覽知識全景
2. 定位機理節點
3. 追溯缺陷路徑
4. 搜尋相似經驗
5. 補充隱性知識
6. 驗證知識版本

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
