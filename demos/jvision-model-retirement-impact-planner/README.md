**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **退場模型公告板** — 登錄模型停用日期、版本限制、供應商通知與替代建議。
- **應用依賴拓樸** — 呈現模型與應用、提示、Agent、知識庫及閘道規則的依賴。
- **退場衝擊分級** — 依流量、業務關鍵性、替代難度與期限評估遷移風險。
- **替代模型配對** — 比較候選模型的能力、相容性、成本、區域及合規條件。
- **遷移波次規劃** — 按相依關係安排試點、分批切換、凍結期與回滾窗口。
- **切換就緒驗證** — 追蹤評測、提示調整、容量測試與應用負責人簽核狀態。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 登錄退場事件
2. 盤點依賴應用
3. 評估業務衝擊
4. 選擇替代模型
5. 編排遷移波次
6. 核准切換就緒

- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
