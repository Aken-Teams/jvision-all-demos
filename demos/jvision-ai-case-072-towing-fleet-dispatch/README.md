# 拖吊車隊任務站

> 派車、追蹤、簽收到成本油耗的車隊管理

追蹤道路救援接單、司機任務與扣車流程。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**物流運輸　|　**系統類型：**TMS 運輸調度

## 功能模組

- **路線調度** — 派車與路線規劃
- **任務派車** — 任務指派與追蹤
- **即時追蹤** — GPS 定位與到貨
- **簽收回單** — 電子簽收與回單
- **成本油耗** — 油耗與成本分析
- **冷鏈溫控** — 溫度監控與告警

## 適合誰使用

- 調度專員
- 車隊主管
- 營運經理

## 運作流程

1. 待調度
2. 配送中
3. 待簽收
4. 已完成

## 導入效益

- 派車規劃工時：3.9小時/日 → **1小時/日**
- 準時配送率：85% → **99%**
- 空車率：22% → **9.4%**
- 簽收回單時效：25小時 → **1.9小時**
