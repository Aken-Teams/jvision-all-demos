# 鋼構吊裝節序管制台

> 依結構穩定需求編排鋼柱、鋼梁與臨時支撐的吊裝節序，逐件確認到料、吊點、螺栓初鎖及測量條件，避免任意跳序造成待料或失穩風險。

依結構穩定需求編排鋼柱、鋼梁與臨時支撐的吊裝節序，逐件確認到料、吊點、螺栓初鎖及測量條件，避免任意跳序造成待料或失穩風險。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **節區總覽** — 以節區呈現構件順序與完成狀態。
- **相依編排** — 設定構件先後與臨時穩定條件。
- **到料配套** — 核對構件、螺栓與吊具備妥狀態。
- **吊裝執行** — 依序回報起吊、就位及摘鉤時間。
- **初鎖支撐** — 確認螺栓初鎖與臨時支撐完成。
- **測量放行** — 檢核垂直度及標高後開放下一節序。

## 適合誰使用

- 鋼構工程師
- 吊裝指揮手
- 工地主任

## 運作流程

1. 劃分節區
2. 設定節序
3. 確認備料
4. 執行吊裝
5. 完成穩定
6. 測量放行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
