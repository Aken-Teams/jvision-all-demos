# 告警風暴關聯器

> 聚合同源告警、預測事件影響並產出低噪音的處置優先序。60字內

聚合同源告警、預測事件影響並產出低噪音的處置優先序。60字內

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **告警風暴雷達** — 依服務、時間與拓撲關係即時辨識告警風暴。
- **同源關聯圖** — 將跨 APM、Kubernetes 與 CI/CD 告警歸併為事件群
- **根因候選樹** — 排序共同變更、依賴故障與資源異常等根因候選。
- **事件影響模擬** — 模擬事件擴散路徑、受影響服務與使用者範圍。
- **處置優先佇列** — 依影響、急迫性與模型信心排列可處理事件。
- **修復協同台** — 核准後建立 Jira 或 ITSM 任務並同步事件狀態。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 偵測風暴
2. 聚合同源
3. 研判根因
4. 模擬影響
5. 排定處置
6. 協同修復
