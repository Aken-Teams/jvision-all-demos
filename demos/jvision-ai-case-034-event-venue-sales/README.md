# 會展檔期報價所

> 從名單到成交的完整客戶生命週期管理

管理檔期、報價、合約、付款與籌備任務。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生活服務　|　**系統類型：**CRM 客戶關係管理

## 功能模組

- **客戶 360 視圖** — 整合互動、報價、合約與服務歷程
- **銷售管線** — 拖曳看板管理商機階段與轉化率
- **報價與合約** — 線上報價、審核與電子簽核
- **行銷活動** — 名單分群、活動追蹤與成效分析
- **AI 業務助理** — 下一步建議、風險提醒與成交預測
- **業績報表** — 銷售漏斗、預測與達成率儀表

## 適合誰使用

- 服務專員
- 服務主管
- 生活服務主管

## 運作流程

1. 待確認
2. 已排程
3. 服務中
4. 已完成

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：79% → **94%**
- 重工率：13% → **3.8%**
- 客訴關案：4.1天 → **1天**
