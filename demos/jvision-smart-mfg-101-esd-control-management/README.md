# ESD Control Management（靜電防護管理）

> 從異常到改善的品質閉環與追溯稽核

ESD Control Management（靜電防護管理）提供靜電防護點檢排程、腕帶/鞋跟阻值監測、異常即時警報。品保部依「防護設施建置→定期/即時監測→異常警報→處置追蹤→合規報告」推進作業，優先解決「人工點檢覆蓋率不足」，製程工程部則以ESD合規率與異常事件數確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 品保部
- 製程工程部
- 設備工程部

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉

## 導入效益

- 批號追溯時間：173分鐘 → **16分鐘**
- 客訴平均關案：22天 → **9天**
- 改善驗證率：63% → **92%**
- 重複不良率：6.4% → **2%**
