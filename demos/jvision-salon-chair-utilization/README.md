# 連鎖美業席位產能台

> 協助連鎖美髮與美容品牌依服務時長、員工技能、設備席位及尖峰需求配置可售產能，處理跨店支援與臨時空檔回補。

協助連鎖美髮與美容品牌依服務時長、員工技能、設備席位及尖峰需求配置可售產能，處理跨店支援與臨時空檔回補。

**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **席位資源** — 維護服務席位、空間與設備
- **技能班表** — 呈現員工技能及可服務時段
- **產能配置** — 組合人員、席位與服務時長
- **跨店支援** — 安排員工至缺口門店支援
- **空檔回補** — 重排取消預約釋出的產能
- **利用分析** — 比較門店尖離峰席位效能

## 適合誰使用

- 區域經理
- 門店店長
- 排班主管

## 運作流程

1. 設定門店資源
2. 匯入技能班表
3. 配置可售產能
4. 辨識門店缺口
5. 安排跨店支援
6. 檢討席位效能

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
