# AI 專利前案獵人

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **技術特徵拆解器** — 從發明揭露與產品規格抽取必要元件、關係及技術效果。
- **跨語言檢索式工坊** — 擴展中英日等語言的同義詞、分類號與技術概念查詢。
- **前案語意獵場** — 以特徵相似度搜尋全球專利與非專利技術文獻。
- **特徵對照矩陣** — 逐項比較發明特徵與候選前案的揭露位置及匹配程度。
- **時間與家族驗證** — 核對優先權日、公開日、法律狀態及同族專利關係。
- **前案檢索報告** — 產出含關鍵引文、缺口、排序理由與檢索範圍的審查報告。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 拆解發明特徵
2. 設計跨語言策略
3. 搜尋候選前案
4. 完成特徵比對
5. 驗證有效時間線
6. 審定檢索結論

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
