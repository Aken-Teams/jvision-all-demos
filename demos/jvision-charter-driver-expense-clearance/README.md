# 包車駕駛代墊結算台

> 依包車行程彙整駕駛代墊的停車、過路、洗車與臨時支出，核對客戶合約可轉嫁項目、憑證及核准，完成駕駛報銷與客戶加收。

依包車行程彙整駕駛代墊的停車、過路、洗車與臨時支出，核對客戶合約可轉嫁項目、憑證及核准，完成駕駛報銷與客戶加收。

**產業別：**交通運輸　|　**系統類型：**finance-case

## 功能模組

- **行程總覽** — 查看包車任務與預算
- **代墊申報** — 登錄支出用途與憑證
- **行程核對** — 確認地點時間與必要性
- **合約判定** — 區分公司吸收與客戶加收
- **駕駛核銷** — 核准報銷或退回補件
- **客戶請款** — 產出轉嫁費用明細

## 適合誰使用

- 包車駕駛
- 調度人員
- 費用會計

## 運作流程

1. 建立行程
2. 提交代墊
3. 核對事實
4. 判定歸屬
5. 完成報銷
6. 追加請款

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
