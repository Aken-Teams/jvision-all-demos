# 應用程式效能監控（APM）

> 服務工單、資產到即時監控的 IT 維運

應用程式效能監控（APM）提供交易響應時間追蹤、程式碼層級效能剖析(Profiling)、應用拓樸依賴關係圖。資訊部依「應用程式埋點/代理部署→即時效能資料收集→異常自動告警→根因分析定位→開發團隊修復→效能趨勢追蹤」推進作業，優先解決「系統緩慢無法定位根因」，應用系統開發團隊則以平均響應時間與系統可用率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**資訊科技　|　**系統類型：**IT 維運管理平台

## 功能模組

- **服務工單** — 事件/請求工單管理
- **資產管理** — IT 資產與軟體授權
- **即時監控** — 系統/網路健康監控
- **告警事件** — 告警彙整與分派
- **變更發布** — 變更與發布管理
- **服務報表** — SLA 與可用率報表

## 適合誰使用

- 資訊部
- 應用系統開發團隊
- 資訊安全部

## 運作流程

1. 已受理
2. 處理中
3. 使用者確認
4. 已關閉

## 導入效益

- 事件平均處理：113分鐘 → **28分鐘**
- 系統可用率：91% → **93%**
- SLA達成率：80% → **92%**
- 資產盤點工時：19小時/月 → **3.8小時/月**
