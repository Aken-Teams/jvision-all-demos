# 應用程式效能監控智慧站

監控MES、ERP、AOI等關鍵應用程式的效能瓶頸與異常，協助快速定位程式或架構問題。

- 原始系統：應用程式效能監控（APM）
- 產業分類：智慧製造｜IT管理
- 使用部門：資訊部、應用系統開發團隊、資訊安全部
- 工作流程：應用程式埋點/代理部署→即時效能資料收集→異常自動告警→根因分析定位→開發團隊修復→效能趨勢追蹤
- AI 應用：異常根因自動定位(AIOps)、效能趨勢預測與容量建議
- 主要 KPI：平均響應時間、系統可用率、錯誤率、根因定位平均時間
- 代表產品：Dynatrace、New Relic、AppDynamics、Datadog APM
