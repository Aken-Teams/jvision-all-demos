# 醫療轉介床位協調台

> 供醫療與照護機構管理轉介需求、候床條件、文件完整度及機構回覆，讓個管師快速媒合適合床位並追蹤實際入住結果。

供醫療與照護機構管理轉介需求、候床條件、文件完整度及機構回覆，讓個管師快速媒合適合床位並追蹤實際入住結果。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **需求總覽** — 查看個案轉介條件
- **床位名錄** — 管理機構條件與可收類型
- **文件檢核** — 確認轉介資料完整度
- **媒合工作台** — 比較機構與個案適配度
- **回覆追蹤** — 記錄機構評估與補件
- **入住結案** — 確認入住或轉介結果

## 適合誰使用

- 出院準備護理師
- 個案管理師
- 機構窗口

## 運作流程

1. 評估需求
2. 檢核文件
3. 篩選機構
4. 發送轉介
5. 協調床位
6. 確認入住

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
