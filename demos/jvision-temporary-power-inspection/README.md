# 工地臨時用電巡查台

> 依配電箱、樓層與迴路安排巡查，將破皮電線、漏電保護及隔離狀態以照片交班，確保危險缺失在復電前完成複驗。

依配電箱、樓層與迴路安排巡查，將破皮電線、漏電保護及隔離狀態以照片交班，確保危險缺失在復電前完成複驗。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **用電區域** — 查看配電箱與迴路。
- **巡查清單** — 執行安全檢查項目。
- **缺失舉證** — 記錄位置與危害照片。
- **隔離管制** — 標示斷電及禁用範圍。
- **班次交接** — 傳遞未改善風險。
- **複驗復電** — 核准解除隔離。

## 適合誰使用

- 職安人員
- 機電工程師
- 工地主任

## 運作流程

1. 安排巡查
2. 發現缺失
3. 執行隔離
4. 派工整改
5. 跨班交接
6. 複驗復電

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
