# 旅宿房務周轉協調台

> 整合退房、清掃、複查、維修與可售房釋出作業，協助房務主管依入住時限安排人力，避免房況資訊落差造成旅客久候或房間閒置。

整合退房、清掃、複查、維修與可售房釋出作業，協助房務主管依入住時限安排人力，避免房況資訊落差造成旅客久候或房間閒置。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **房況總覽** — 查看各樓層待清、清掃中及可售房數。
- **清掃派工** — 按入住期限與區域分派房務工作。
- **進度回報** — 登錄清掃開始、完成與用品缺補狀態。
- **缺失轉修** — 將設備或設施問題交由工程人員處理。
- **房況複查** — 由領班檢核清潔品質及備品完整度。
- **可售釋出** — 確認房間完成後同步標記可供入住。

## 適合誰使用

- 房務主管
- 櫃台領班
- 工程值班員

## 運作流程

1. 盤點退房房況
2. 安排清掃任務
3. 執行清掃回報
4. 處理房間缺失
5. 完成品質複查
6. 釋出入住房間

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
