**產業別：**業務銷售　|　**系統類型：**sales-crm

## 功能模組

- **案例素材庫** — 查看名稱標誌數字與引言
- **引用申請** — 登錄媒體用途與期間
- **權利檢查** — 核對合約及既有授權
- **內外核准** — 追蹤法務與客戶確認
- **可用版本** — 發布核准素材和限制
- **到期撤回** — 提醒續期並停止使用

## 適合誰使用

- 業務人員
- 行銷人員
- 法務人員

## 運作流程

1. 選擇素材
2. 提出用途
3. 核對權利
4. 取得授權
5. 發布版本
6. 管理到期
