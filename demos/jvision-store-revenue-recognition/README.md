# 禮券履約收入管理台

> 供連鎖企業管理禮券與儲值金的發行、銷售、兌用、跨店清算、逾期估計及履約收入認列，以批次資料模擬負債變動與會計分錄，降低大量票券人工核算風險。

供連鎖企業管理禮券與儲值金的發行、銷售、兌用、跨店清算、逾期估計及履約收入認列，以批次資料模擬負債變動與會計分錄，降低大量票券人工核算風險。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **票券發行** — 彙整面額、批次、效期與發行主體。
- **銷售收款** — 核對售出數量、折扣與收款方式。
- **兌用核對** — 比對各門市兌用及沖減負債資料。
- **跨店清算** — 計算發行方與兌用方往來款。
- **逾期估計** — 依歷史模式試算預期未兌用比例。
- **收入認列** — 產生負債沖轉與收入分錄草稿。

## 適合誰使用

- 總帳會計
- 收入會計
- 財務主管

## 運作流程

1. 彙整發行
2. 核對銷售
3. 核銷兌用
4. 辦理清算
5. 估計逾期
6. 認列收入

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
