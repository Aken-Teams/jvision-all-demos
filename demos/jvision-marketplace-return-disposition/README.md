# 電商退貨處置決策台

> 將退回商品依外觀、配件、包裝、序號與成本分級，決定重新上架、整新、轉售、退供應商或報廢，並追蹤每件商品的回收價值。

**產業別：**零售電商　|　**系統類型：**operations-console

## 功能模組

- **退件佇列** — 彙整已退款但尚待商品判定的退件。
- **品況檢驗** — 依品類檢查外觀、功能、配件與序號。
- **商品分級** — 區分全新、良品、整新品與不可售品。
- **處置建議** — 計算上架、整新、退供或報廢價值。
- **例外核准** — 審核高價商品與偏離標準的處置。
- **價值追蹤** — 比較原價、處置成本及最終回收金額。

## 適合誰使用

- 退貨營運主管
- 驗貨專員
- 商品經理

## 運作流程

1. 接收退件
2. 完成驗貨
3. 判定分級
4. 提出處置
5. 核准例外
6. 執行結案

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
