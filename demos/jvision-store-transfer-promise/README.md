# 門市調貨交接追蹤台

> 管理顧客調貨承諾、來源店保留、運送交接、目的店到貨與通知取件，使跨班店員清楚貨品去向、保留期限及顧客承諾，避免被誤售。

管理顧客調貨承諾、來源店保留、運送交接、目的店到貨與通知取件，使跨班店員清楚貨品去向、保留期限及顧客承諾，避免被誤售。

**產業別：**零售電商　|　**系統類型：**pos-frontdesk

## 功能模組

- **顧客需求** — 建立調貨承諾
- **貨源詢問** — 尋找來源門市
- **商品保留** — 避免期間誤售
- **轉運交接** — 追蹤店間移轉
- **到貨通知** — 記錄聯絡結果
- **取件結案** — 成交或釋放保留

## 適合誰使用

- 門市店員
- 調貨人員
- 店長

## 運作流程

1. 受理需求
2. 確認貨源
3. 鎖定保留
4. 完成交接
5. 通知取件
6. 完成結案

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
