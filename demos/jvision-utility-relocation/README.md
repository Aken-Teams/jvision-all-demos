# 地下管線遷改協調台

> 整合既有自來水、電力、瓦斯及電信管線的試挖成果、遷改方案、權管會勘與停供窗口，協調施工順序並追蹤遷改完成後的圖資回填。

整合既有自來水、電力、瓦斯及電信管線的試挖成果、遷改方案、權管會勘與停供窗口，協調施工順序並追蹤遷改完成後的圖資回填。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **管障地圖** — 呈現管線位置、衝突區段及處理狀態。
- **試挖紀錄** — 登錄試挖座標、深度、管種與現場照片。
- **權管會勘** — 安排會勘並記錄各單位處理結論。
- **遷改方案** — 管理改道設計、經費責任與核准版本。
- **停供施工** — 協調停水停電通知、窗口及施工排程。
- **竣工回填** — 驗收完成位置並更新實際管線圖資。

## 適合誰使用

- 管線工程師
- 工地主任
- 權管協調人員

## 運作流程

1. 管障地圖
2. 試挖紀錄
3. 權管會勘
4. 遷改方案
5. 停供施工
6. 竣工回填

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
