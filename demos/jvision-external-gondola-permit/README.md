# 外牆吊籠作業申請台

> 整合外牆吊籠立面時段、使用工班、操作資格、每日檢點、風速停用標準與交接紀錄，避免不同工班搶占設備或在條件不符時冒險作業。

整合外牆吊籠立面時段、使用工班、操作資格、每日檢點、風速停用標準與交接紀錄，避免不同工班搶占設備或在條件不符時冒險作業。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **立面排程** — 依棟別、向別、吊籠與時段呈現使用安排。
- **作業申請** — 填報工項、人數、樓層範圍與預計工時。
- **資格檢核** — 確認操作員證照、教育訓練與有效期限。
- **班前檢點** — 記錄鋼索、安全鎖、配重及通訊檢查。
- **天候管制** — 顯示風速門檻、停用決定與恢復條件。
- **收工交接** — 回報設備狀態、停放位置與待修問題。

## 適合誰使用

- 外牆工程師
- 吊籠操作員
- 職安人員

## 運作流程

1. 提出吊籠申請
2. 協調共用排程
3. 查核人員資格
4. 完成班前檢點
5. 核准開始作業
6. 收工回報交接

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
