# 客戶組合風險熱圖

按產業、方案、地區與 CSM 揭露客戶集中風險，支援資源重新配置。

**產業別：**客服管理　|　**系統類型：**analytics-bi

## 功能模組

- **組合風險熱圖** — 交叉呈現客戶數、收入、健康分數與續約風險的集中區塊。
- **產業曝險剖面** — 辨識特定產業的景氣、使用衰退與共同需求風險。
- **方案集中檢視** — 比較各方案的採用深度、工單壓力與合約到期曝險。
- **區域風險分布** — 揭露地區別的流失、服務能力與市場事件集中程度。
- **CSM 負載平衡** — 對照帳戶難度、風險收入與服務量，找出負載失衡。
- **資源調度模擬** — 模擬轉派 CSM 或投入專家後，組合風險與覆蓋率的變化。

## 適合誰使用

- 客戶成功主管
- CSM
- 客服主管

## 運作流程

1. 定位風險熱區
2. 拆解產業曝險
3. 檢視方案集中
4. 比較區域差異
5. 校準 CSM 負載
6. 核准資源調度

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
