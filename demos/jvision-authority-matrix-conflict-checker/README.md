# 授權矩陣衝突檢查器

> 比對章程、授權辦法與系統權限，找出決策授權衝突及越權風險。決策授權衝突及越權風險。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **章程權限解析** — 擷取董事會、委員會、經理人與股東會的法定決策權限。
- **授權辦法建模** — 將金額門檻、事項類型、簽核層級與代理規則轉為授權矩陣。
- **系統角色映射** — 把 ERP、採購與簽核系統角色對應至組織職務及法定身分。
- **授權差異比對** — 逐項比對文件規範、實際流程與系統可執行權限。
- **越權情境檢查** — 模擬超額核准、代理失效、職務分離破壞與權限殘留情境。
- **矯正方案草擬** — 產生章程修訂、權限回收及流程調整方案供治理核准。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 解析治理權源
2. 建立授權矩陣
3. 映射系統角色
4. 辨識授權衝突
5. 驗證越權風險
6. 核定矯正措施
