# 維修作業許可管理台

> 供工廠在高風險維修前管理動火、局限空間、高處與斷電等作業許可，整合危害辨識、隔離點、監火人、有效時段、現場確認及結案復歸，防止工單核准卻安全條件未到位。

供工廠在高風險維修前管理動火、局限空間、高處與斷電等作業許可，整合危害辨識、隔離點、監火人、有效時段、現場確認及結案復歸，防止工單核准卻安全條件未到位。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **許可申請** — 選擇作業類型、區域、人員與時段。
- **危害辨識** — 勾選風險與必要防護控制措施。
- **能源隔離** — 記錄斷電、洩壓、盲封與上鎖點。
- **現場會簽** — 由維修、職安及區域主管共同確認。
- **作業監控** — 追蹤許可有效時間、暫停與展延。
- **結案復歸** — 確認人員撤離、防護拆除與設備復歸。

## 適合誰使用

- 維修主管
- 職安人員
- 現場監工

## 運作流程

1. 提出許可
2. 辨識危害
3. 完成隔離
4. 現場會簽
5. 監控作業
6. 確認復歸

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
