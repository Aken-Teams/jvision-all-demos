# 補助成果指標預警器

> 預測補助案 KPI 未達風險，提出可執行的補救與契約變更方案以守住結案。

預測補助案 KPI 未達風險，提出可執行的補救與契約變更方案以守住結案。

**產業別：**專業服務　|　**系統類型：**finance-case

## 功能模組

- **指標達成預測** — 依里程碑、實績與剩餘期程預測各項 KPI 的期末達成率。
- **未達風險熱區** — 定位高風險指標、影響期間與可能導致核減的缺口。
- **缺口因果診斷** — 解析進度、成本、資格與交付證據間的未達因果鏈。
- **補救方案編排** — 組合追加活動、資源調度與證據補強措施並估算成效。
- **變更方案試算** — 比較 KPI、期程及預算變更選項對履約與核銷的影響。
- **結案守門清單** — 追蹤補救承諾、變更核准與結案必要成果的完成狀態。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 建立預測基線
2. 辨識未達熱區
3. 確認缺口成因
4. 編排補救行動
5. 評估契約變更
6. 守門追蹤結案

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
