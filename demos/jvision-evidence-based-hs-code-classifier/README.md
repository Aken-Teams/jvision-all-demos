# HS Code 證據型分類器

> 依商品材質、功能與組成提出 HS Code，並提供可覆核的分類依據。

依商品材質、功能與組成提出 HS Code，並提供可覆核的分類依據。

**產業別：**採購供應鏈　|　**系統類型：**erp

## 功能模組

- **待分類商品箱** — 管理新商品、變更規格與需要重判的分類案件。
- **商品特徵拆解** — 抽取材質、用途、組成、加工方式與成套狀態。
- **稅則章節導航** — 逐層比對部、章、節、目及相關分類註解。
- **候選代碼比較** — 並列候選 HS Code、適用理由、排除條件與信心。
- **分類理由書** — 組合規格、BOM 與稅則規則形成可覆核結論。
- **分類核定台** — 由報關人員修訂並核定代碼、有效地區與版本。

## 適合誰使用

- 國貿主管
- 報關人員
- 業務

## 運作流程

1. 建立分類案件
2. 確認商品特徵
3. 檢索適用稅則
4. 比較候選代碼
5. 完成分類理由
6. 核定分類結果

## 導入效益

- 採購前置時間：12天 → **5天**

- 缺料預警覆蓋：40% → **92%**
