原產地／目的地臺灣／日本
建議 HS Code8460.90

二、商品特徵與主要功能

本商品為額定功率 420 W 之桌上固定式雙砂輪研磨機，藉由電動馬達帶動左右砂輪旋轉，主要供金屬工件去毛邊、表面研磨與刃具修整。整機出貨時已包含馬達、主軸、砂輪、護罩、工件托架及鑄鐵機座，具備執行主要功能所需之全部構件。

三、適用分類規則

依一般解釋準則 GRI 1、第 XVI 部註 3 及稅則節 8460 之節文，本商品應按其金屬研磨之主要功能分類。其固定式結構不符合節 8467 手提式工具之範圍，亦不得僅按內含之電動馬達歸入節 8501。

四、分類結論

綜合商品客觀特徵、出貨狀態、BOM 組成及稅則規則，建議歸列 HS 8460.90「其他磨削或精加工金屬之工具機」。日本進口申報所需之國內細分碼，應由當地報關代理人依申報日有效稅則進一步確認。
