# 信用狀條款落差檢查器

## 功能模組

- **信用狀條款拆解** — 將信用狀本文、修改書與銀行條件拆成可核對要求。
- **單據逐項核對** — 比對發票、提單、裝箱單、產證與保險文件的欄位及用語。
- **不符點工作台** — 集中顯示缺漏、矛盾、逾期與格式不符並標示條款來源。
- **提示情境模擬** — 預估不同補正方案的接受機率、耗時與拒付風險。
- **補正方案排序** — 依截止日、成本與可執行性排列修改、換單或請求讓步方案。
- **銀行提示準備** — 彙整完成版單據、待確認事項與送件清單供提示前覆核。

## 適合誰使用

- 國貿主管
- 報關人員
- 業務

## 運作流程

1. 解析信用狀
2. 匯入待提示單據
3. 審查不符點
4. 模擬補正結果
5. 核准補正方案
6. 完成提示覆核
