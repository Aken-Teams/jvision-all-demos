# 診所疫苗批號管理台

> 管理自費與公費疫苗的批號、效期、適用族群、領用與接種紀錄，支援盤點及異常回溯，減少錯批、逾期與帳物不符。

管理自費與公費疫苗的批號、效期、適用族群、領用與接種紀錄，支援盤點及異常回溯，減少錯批、逾期與帳物不符。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **疫苗批次** — 管理來源、批號、效期與劑量
- **收貨驗收** — 登錄到貨數量及冷藏檢查結果
- **預約預留** — 依接種需求預留適用批號
- **接種扣帳** — 記錄領用、接種與未使用退回
- **盤點調整** — 核對實存並處理差異原因
- **批次回溯** — 查詢特定批號的使用流向

## 適合誰使用

- 護理師
- 藥品管理員
- 診所主管

## 運作流程

1. 批次驗收
2. 庫存上架
3. 預約預留
4. 接種領用
5. 庫存盤點
6. 批次稽核

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
