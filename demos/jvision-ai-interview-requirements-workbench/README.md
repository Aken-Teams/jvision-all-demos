# AI 訪談轉需求工作台

> 把訪談內容轉成目標、規則、例外及未決問題，加速形成可驗證的產品需求。

把訪談內容轉成目標、規則、例外及未決問題，加速形成可驗證的產品需求。

**產業別：**資訊科技　|　**系統類型：**collaboration-pm

## 功能模組

- **訪談逐字工作區** — 整理多場訪談逐字稿、講者、時間點與主題片段。
- **目標成果萃取** — 辨識利害關係人的目標、痛點、成功指標與優先序。
- **業務規則建模** — 將口語敘述整理成條件、動作、限制與決策規則。
- **例外情境盤點** — 找出邊界條件、失敗路徑、替代流程與特殊角色。
- **未決問題清單** — 標示矛盾、資訊缺口與待向受訪者確認的問題。
- **PRD 草案編排** — 組裝需求敘述、驗收條件、流程與訪談來源引用。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 整理訪談內容
2. 確認產品目標
3. 定義業務規則
4. 補齊例外情境
5. 釐清未決問題
6. 審定 PRD 草案

- 系統可用率：97% → **99%**
