# 圖說疑義答覆落地台

> 把圖說疑義、設計答覆、受影響圖號與施工位置串成可派發的現場指示，逐一追蹤樓層和工班是否閱讀、停用舊做法及完成調整，避免答覆只留在公文中，未真正傳達至重複施工區域。

把圖說疑義、設計答覆、受影響圖號與施工位置串成可派發的現場指示，逐一追蹤樓層和工班是否閱讀、停用舊做法及完成調整，避免答覆只留在公文中，未真正傳達至重複施工區域。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **疑義案件** — 管理提問、背景、急迫性與待答期限。
- **正式答覆** — 收錄設計結論、條件及生效日期。
- **影響判讀** — 標示受影響圖號、工項、樓層與區域。
- **現場指示** — 將答覆轉為班組可執行的圖文指令。
- **收悉確認** — 追蹤各責任工班的閱讀與交底狀態。
- **落地追蹤** — 盤點已施工範圍並追蹤調整或拆改。

## 適合誰使用

- 設計協調人員
- 現場工程師
- 分包領班

## 運作流程

1. 提出圖說疑義
2. 取得正式答覆
3. 判讀影響範圍
4. 發布現場指示
5. 完成班組交底
6. 追蹤調整完成

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
