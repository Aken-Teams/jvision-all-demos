# 到府搬運樓況勘查台

> 在報價與派車前記錄樓層、電梯、停車、搬運距離、大型家具與吊掛需求，將現勘結果轉成車輛人力配置及客戶確認的加價依據。

在報價與派車前記錄樓層、電梯、停車、搬運距離、大型家具與吊掛需求，將現勘結果轉成車輛人力配置及客戶確認的加價依據。

**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **地址樓況** — 記錄樓層電梯與動線
- **現勘照片** — 標示家具入口與障礙
- **停車條件** — 確認車格距離及時限
- **特殊搬運** — 辨識重物拆裝與吊掛
- **資源估算** — 試算人數車型與工時
- **現場交付** — 產出領班摘要與客戶簽認

## 適合誰使用

- 搬家業務
- 車隊調度
- 現場領班

## 運作流程

1. 建立搬運需求
2. 執行樓況現勘
3. 辨識特殊條件
4. 估算人車資源
5. 確認報價加項
6. 交付施工摘要

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
