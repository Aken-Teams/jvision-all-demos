# RFQ詢報價管理智慧站

管理客戶詢價單的接收、規格確認、成本試算到報價產出的完整流程，是製造業接單的第一關。

- 原始系統：RFQ（Request for Quotation）詢報價管理
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、業務工程(SE)、採購部、製造工程、品保部
- 工作流程：客戶詢價→需求登錄→跨部門會簽→成本試算→報價產出→追蹤結果
- AI 應用：自動擷取PDF/Email詢價內容轉結構化資料、相似歷史詢價智慧比對、報價時效風險提醒
- 主要 KPI：詢價回覆時效、詢價轉單率、平均會簽天數、報價正確率
- 代表產品：SAP Ariba、多為ERP客製模組（如鼎新、鼎捷）、自建Web表單+工作流系統
