# 長交期設備到貨倒排台

> 從現場需求日反推設備送審、核定、下單、製造、檢驗、運輸與進場節點，追蹤電梯、發電機或冰水主機等長交期設備的延誤與趕辦措施。

**產業別：**營建工程　|　**系統類型：**procurement-srm

## 功能模組

- **交期總覽** — 查看各設備需求日與風險燈號。
- **倒排節點** — 由現場需求日反推必要里程碑。
- **送審進度** — 追蹤規格文件、退補與核定日期。
- **製造追蹤** — 記錄備料、生產與廠驗完成度。
- **運輸進場** — 安排出貨、通關、卸貨及進場。
- **趕辦方案** — 評估逾期影響與加速措施。

## 適合誰使用

- 採購人員
- 機電工程師
- 專案經理

## 運作流程

1. 盤點交期風險
2. 建立倒排計畫
3. 追蹤送審核定
4. 更新製造實績
5. 安排運輸進場
6. 核定趕辦措施

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
