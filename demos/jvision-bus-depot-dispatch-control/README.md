# 客運班次異常調度台

> 供客運業者在車輛故障、駕駛缺勤或道路事件發生時，評估受影響班次、替補人車與旅客處置方案，留下調班核准、站務通知及恢復營運紀錄。

供客運業者在車輛故障、駕駛缺勤或道路事件發生時，評估受影響班次、替補人車與旅客處置方案，留下調班核准、站務通知及恢復營運紀錄。

**產業別：**交通運輸　|　**系統類型：**operations-console

## 功能模組

- **事件受理** — 登錄故障、缺勤、道路封閉與影響區間。
- **班次影響** — 展開受影響班次及後續車輛銜接關係。
- **替補方案** — 比較備援車輛、駕駛與併班調度選項。
- **調班核准** — 依營運限制審核取消、延駛或替補方案。
- **站務通知** — 產生站點、客服與旅客公告內容。
- **營運恢復** — 追蹤班次復原並記錄事件檢討事項。

## 適合誰使用

- 客運調度員
- 站務主管
- 營運經理

## 運作流程

1. 建立事件
2. 盤點影響
3. 擬定替補
4. 核准調班
5. 發布通知
6. 恢復結案

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
