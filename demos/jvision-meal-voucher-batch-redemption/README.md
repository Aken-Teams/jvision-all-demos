**產業別：**餐飲旅宿　|　**系統類型：**finance-ledger

## 功能模組

- **餐券收件** — 彙整紙本與電子券號
- **券號辨識** — 校正模糊與缺碼影像
- **履約勾稽** — 配對POS及發行清冊
- **重複檢查** — 辨識重用失效與跨店
- **門店補件** — 追蹤原券及交易證明
- **結算入帳** — 確認收入與通路應收

## 適合誰使用

- 門店主管
- 財務人員
- 通路營運

## 運作流程

1. 彙整餐券
2. 校正券號
3. 執行勾稽
4. 檢查重複
5. 完成補件
6. 結算入帳

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
