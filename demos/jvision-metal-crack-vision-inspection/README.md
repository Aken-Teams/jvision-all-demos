# 金屬材料裂紋視覺檢測系統

> 透過預先準備的金屬材料影像，模擬自動標示裂紋位置、長度、走向與嚴重度，讓檢驗員快速複核疑似缺陷、建立判定與處置紀錄，並分析不同材料、工序和批次的裂紋趨勢。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **檢測任務總覽** — 呈現待檢數、裂紋率、重大警示與各批次處理進度。
- **待檢影像佇列** — 依風險排序預載影像，並提供材料、工序及批次篩選。
- **裂紋標記檢視** — 放大影像並顯示裂紋區域、輪廓、信心分數與熱點。
- **裂紋量測分級** — 呈現長度、寬度、走向與嚴重度，供檢驗員修正判定。
- **缺陷處置單** — 模擬建立隔離、重工、追加檢查或報廢的處置紀錄。
- **裂紋趨勢分析** — 分析材料、工序、批次與位置的裂紋分布及變化。

## 適合誰使用

- 非破壞檢測人員
- 品管檢驗員與品質主管

## 運作流程

1. 掌握檢測進度
2. 選取待檢影像
3. 查看裂紋標記
4. 確認量測分級
5. 建立處置紀錄
6. 分析裂紋趨勢
