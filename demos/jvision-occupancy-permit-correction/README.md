# 使用執照補正管制台

> 集中登錄使用執照審查、公文與現勘提出的補正事項，拆解相互牽連的圖說、證明及現場改善工作，管理責任人、期限、送件版本與複審結果，避免漏改或重複退補。

集中登錄使用執照審查、公文與現勘提出的補正事項，拆解相互牽連的圖說、證明及現場改善工作，管理責任人、期限、送件版本與複審結果，避免漏改或重複退補。

**產業別：**營建工程　|　**系統類型：**legal-case

## 功能模組

- **補正總表** — 統整公文、現勘及口頭補充的補正事項。
- **關聯拆解** — 連結受影響圖說、文件、設備與現場工作。
- **責任派辦** — 設定設計、承商及顧問的負責範圍與期限。
- **版本修正** — 管理修正版圖說、證明與差異說明。
- **送件檢核** — 逐項確認簽章、份數、格式及相互一致性。
- **複審履歷** — 記錄送件批次、審查結果與再次補正原因。

## 適合誰使用

- 使照承辦人
- 建築師
- 工地主任

## 運作流程

1. 登錄補正意見
2. 拆解關聯工作
3. 指派改善責任
4. 提交修正成果
5. 執行送件檢核
6. 更新複審結果

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
