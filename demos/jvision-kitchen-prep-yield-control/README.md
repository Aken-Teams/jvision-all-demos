# 中央廚房備料耗損管制台

> 協助連鎖餐飲依門市需求彙整備料量、換算原料領用、記錄實際產出與耗損，並追蹤批次分裝及配送差異，降低中央廚房過量製作與門市缺料風險。

協助連鎖餐飲依門市需求彙整備料量、換算原料領用、記錄實際產出與耗損，並追蹤批次分裝及配送差異，降低中央廚房過量製作與門市缺料風險。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **需求彙整** — 依門市與供餐日彙整品項需求及臨時增減量。
- **配方換算** — 依標準配方反推原料領用量與預估產出。
- **備料排程** — 安排工作批次、負責班組及預計完成時間。
- **產出登錄** — 記錄實際領料、成品重量及可分裝份數。
- **耗損處理** — 檢視超標耗損並登錄原因與改善責任。
- **分裝配送** — 核對分裝批次、門市配量及配送交接狀態。

## 適合誰使用

- 中央廚房主管
- 生產領班
- 成本會計

## 運作流程

1. 彙整需求
2. 換算用料
3. 安排備料
4. 回報產出
5. 處理耗損
6. 確認配送

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
