# 擴產投資方案比較器

比較設備、班次、外包與良率改善組合，找出最佳擴產投資方案。／

**產業別：**生產製造　|　**系統類型：**erp

## 功能模組

- **產能缺口設定** — 依需求情境、交期與產品組合定義各期間的目標產能缺口。
- **設備投資方案** — 配置新設備數量、規格、建置期、折舊與預期產能。
- **班次擴充方案** — 模擬加班、增班、招募與技能限制對可用產能的影響。
- **外包配置方案** — 比較供應商容量、單價、交期、品質與供應風險。
- **良率改善方案** — 估算製程改善幅度、爬坡時間及其對有效產出的貢獻。
- **投資組合比較** — 比較各組合的資本支出、單位成本、達產時間與風險。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 定義擴產需求
2. 建立投資選項
3. 驗證方案假設
4. 模擬組合績效
5. 比較財務效益
6. 核准擴產組合

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
