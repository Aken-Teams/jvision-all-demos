# 毛利流失定價洩漏偵測器

> 從產品、客戶、業務、通路與訂單條件拆解毛利變化，辨識未授權折扣、價目偏離、成本轉嫁不足及小額附加費遺漏，協助企業找出定價執行落差並安排改善行動。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **毛利流失總覽** — 呈現毛利率趨勢、流失金額及主要產品客群。
- **價格瀑布分析** — 拆解牌價、折扣、回饋、運費與實際成交淨價。
- **定價洩漏警示** — 列出低於門檻、折扣越權與附加費遺漏的訂單。
- **訂單原因鑽取** — 查看客戶、產品、業務與交易條件的完整脈絡。
- **毛利驅動歸因** — 區分價格、銷量、組合及成本對毛利變化的影響。
- **改善行動追蹤** — 建立調價、折扣收回與合約修正任務並追蹤成效。

## 適合誰使用

- 財務分析師
- 定價主管
- 業務主管與產品經理

## 運作流程

1. 發現毛利流失
2. 拆解成交價格
3. 篩選洩漏訂單
4. 追查訂單原因
5. 判讀毛利動因
6. 執行改善追蹤
