# 工程許可附款追蹤台

> 管理建照、道路挖掘、消防及環保等工程許可的核准附款、履行期限與查驗證據，將每項條件指派到工務、設計或承包商，協助專案在開工及階段查驗前完成法定承諾。

管理建照、道路挖掘、消防及環保等工程許可的核准附款、履行期限與查驗證據，將每項條件指派到工務、設計或承包商，協助專案在開工及階段查驗前完成法定承諾。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **許可台帳** — 管理許可文件、機關、效期及版本。
- **附款拆解** — 將核准附款拆成可追蹤履行項目。
- **責任派工** — 指派內部單位及承包商完成條件。
- **證據收整** — 整理照片、報告、證明與函文。
- **內部覆核** — 檢查履行內容是否符合附款要求。
- **查驗資料包** — 依機關及查驗階段彙整送審資料。

## 適合誰使用

- 專案經理
- 工務主任
- 法規專員

## 運作流程

1. 登錄許可
2. 拆解附款
3. 分派執行
4. 回傳證據
5. 完成覆核
6. 準備查驗

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
