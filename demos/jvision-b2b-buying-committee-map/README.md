# 企業客戶關係人決策地圖

> 以視覺化地圖整理企業客戶中的使用者、影響者、決策者、採購與反對者，呈現彼此關係、立場、影響力及接觸狀態。業務可找出關係缺口、規劃溝通策略並協同推進複雜交易。

以視覺化地圖整理企業客戶中的使用者、影響者、決策者、採購與反對者，呈現彼此關係、立場、影響力及接觸狀態。業務可找出關係缺口、規劃溝通策略並協同推進複雜交易。

**產業別：**業務銷售　|　**系統類型：**sales-crm

## 功能模組

- **客戶組織圖** — 建立部門、職位、匯報線及跨部門影響關係的視覺圖。
- **關係人檔案** — 記錄角色、關注議題、立場、影響力與最近互動摘要。
- **採購委員會地圖** — 依使用、技術、財務、採購與決策角色檢查成員覆蓋。
- **支持阻力分析** — 顯示支持者、中立者、反對者及可能改變立場的因素。
- **溝通策略規劃** — 為不同關係人設定價值主張、訊息、管道與接觸順序。
- **關係推進看板** — 追蹤引薦、會議、文件分享與高層互訪等協作行動。

## 適合誰使用

- 企業業務代表
- 客戶經理
- 售前顧問

## 運作流程

1. 建立客戶組織
2. 補充關係人情報
3. 盤點決策角色
4. 分析支持與阻力
5. 制定溝通策略
6. 執行關係行動
