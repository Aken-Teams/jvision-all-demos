## 功能模組

- **專家訊號探索** — 彙整提交、查詢、值班、文件與修復紀錄。
- **領域能力画像** — 建立人員對資料域、平台與資產的實證能力分布。
- **問題意圖辨識** — 解析問題涉及的資料資產、技術層次與急迫程度。
- **專家候選排序** — 依相關性、近期經驗、可用性與利益衝突排序。
- **協作小組編排** — 為跨域問題組合資料擁有者與技術專家。
- **諮詢接洽管理** — 發送邀請、改派無法處理的請求並追蹤解答成效。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 提出資料問題
2. 解析所需能力
3. 建立專家画像
4. 排序推薦人選
5. 組成協作小組
6. 完成接洽回饋

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
