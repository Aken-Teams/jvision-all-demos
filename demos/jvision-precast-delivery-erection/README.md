# 預鑄構件到場安裝台

> 把預鑄梁柱、外牆板或樓板的出貨車趟、到場順序、吊裝位置與安裝條件放在同一作業台，避免車輛到場後因工作面未備妥、構件錯序或吊裝資源衝突而等待。

把預鑄梁柱、外牆板或樓板的出貨車趟、到場順序、吊裝位置與安裝條件放在同一作業台，避免車輛到場後因工作面未備妥、構件錯序或吊裝資源衝突而等待。

**產業別：**營建工程　|　**系統類型：**logistics-fleet

## 功能模組

- **構件安裝序列** — 依棟別、樓層及吊裝順序排列構件清單。
- **出貨車趟** — 配置構件、車號、司機、出廠與預計到場時間。
- **工作面條件** — 確認支承面、吊點、動線、吊車與人員均已備妥。
- **到場驗收** — 核對構件編號、外觀、尺寸及隨附證明。
- **吊裝定位** — 記錄起吊、就位、校正、臨時固定與完成時間。
- **異常協調** — 處理延遲、錯件、損傷、無法安裝與退運決策。

## 適合誰使用

- 吊裝工程師
- 預鑄廠調度員
- 現場工程師

## 運作流程

1. 排定安裝序列
2. 配置出貨車趟
3. 確認工作面條件
4. 辦理到場驗收
5. 執行吊裝定位
6. 結清車趟異常

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
