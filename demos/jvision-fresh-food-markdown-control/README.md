# 生鮮即期折價耗損控制台

> 依模擬的效期、庫存、銷速、毛利與報廢資料，協助生鮮部門分時制定折價策略，預估售罄與耗損風險，發布門市作業批次並分析折價後的毛利和報廢成果。

依模擬的效期、庫存、銷速、毛利與報廢資料，協助生鮮部門分時制定折價策略，預估售罄與耗損風險，發布門市作業批次並分析折價後的毛利和報廢成果。

**產業別：**零售電商　|　**系統類型：**operations-console

## 功能模組

- **效期庫存總覽** — 依剩餘效期、庫存量與門市顯示商品批次風險和處理優先序。
- **耗損風險清單** — 用銷速與效期模擬預測未售數量，標記可能報廢的高風險批次。
- **分時折價設計** — 設定各時段折扣級距、適用門市、數量上限與毛利底線。
- **售罄情境模擬** — 比較不同折價時點和幅度對售罄率、毛利及耗損的影響。
- **門市標價任務** — 產生模擬標價批次、商品清單與操作步驟，追蹤各店回報狀態。
- **折價耗損復盤** — 分析折價銷售、原價排擠、報廢與毛利結果，找出最佳規則。

## 適合誰使用

- 生鮮品類經理
- 門市店長
- 營運督導
- 損耗分析人員

## 運作流程

1. 盤點即期庫存
2. 辨識耗損風險
3. 制定分時折價
4. 比較售罄方案
5. 發布標價作業
6. 檢討耗損成果

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
