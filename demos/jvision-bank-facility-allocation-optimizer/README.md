**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **銀行額度盤點** — 呈現各銀行承諾額度、已用額度與剩餘可用量。
- **融資成本曲線** — 比較利率、承諾費、動用費及幣別成本。
- **到期梯度分析** — 檢視融資到期集中度與再融資壓力。
- **授信條件約束** — 納入財務承諾、用途限制、擔保與提款條件。
- **額度配置最佳化** — 在成本、期限、風險與銀行關係間求解配置。
- **提款執行計畫** — 形成提款、償還、展期及額度保留的行動清單。

## 適合誰使用

- 財務長
- Treasurer
- 資金人員

## 運作流程

1. 盤點可用額度
2. 計算完整成本
3. 檢視到期結構
4. 套用授信限制
5. 最佳化額度配置
6. 核准提款計畫

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
