# 品質異常統計分析系統

> 針對不符合報告（NCR）彙整廠區、產品、製程、缺陷類型、責任單位與處置結果，提供趨勢、柏拉圖、交叉分析及改善追蹤，協助品質主管找出重複異常與高成本問題。

針對不符合報告（NCR）彙整廠區、產品、製程、缺陷類型、責任單位與處置結果，提供趨勢、柏拉圖、交叉分析及改善追蹤，協助品質主管找出重複異常與高成本問題。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **異常統計總覽** — 呈現事件件數、嚴重度、結案速度及品質損失摘要。
- **多維條件分析** — 依期間、廠區、產品、製程及責任單位交叉篩選資料。
- **缺陷柏拉圖** — 排序主要缺陷類型、累積占比及影響件數以鎖定重點。
- **異常趨勢追蹤** — 比較週月趨勢、重複事件及改善前後的發生變化。
- **原因關聯分析** — 檢視缺陷、根因、製程與供應來源之間的關聯分布。
- **改善成效追蹤** — 彙整改善措施、負責人、目標日期及再發驗證結果。

## 適合誰使用

- 品質主管
- 品保工程師
- 製造主管
- 改善專案負責人

## 運作流程

1. 查看統計總覽
2. 設定分析條件
3. 辨識主要缺陷
4. 檢查發生趨勢
5. 探索原因關聯
6. 驗證改善成效

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
