# AI 治理例外管理器

> 管理 AI 治理例外的理由、補償控制、期限與覆核責任，避免永久化。

管理 AI 治理例外的理由、補償控制、期限與覆核責任，避免永久化。

**產業別：**資訊安全　|　**系統類型：**legal-case

## 功能模組

- **例外理由申請** — 記錄偏離政策的業務必要性與影響範圍。
- **政策偏離評估** — 比對適用條款並衡量風險與必要性。
- **補償控制設計** — 配置監控、限權、遮罩或人工複核措施。
- **例外期限管理** — 設定生效日、到期日與禁止自動續期規則。
- **覆核責任指派** — 指定風險承擔人、覆核人與逾時升級層級。
- **到期收斂處置** — 在到期時選擇撤銷、補正或重新審議。

## 適合誰使用

- CISO
- AI 治理主管
- 資安分析師

## 運作流程

1. 提出例外申請
2. 評估偏離風險
3. 配置補償控制
4. 設定失效期限
5. 完成責任覆核
6. 執行到期處置

## 導入效益

- 告警分流時間：45分鐘 → **8分鐘**
- 事件平均處理：12小時 → **3小時**
- 弱點修補率：68% → **96%**
- 合規稽核工時：30小時/月 → **6小時/月**
