# 餐飲小費分配覆核台

> 依門店、班次、職務、出勤與支援規則計算小費池分配，處理退刷、離職及人工調整，提供員工可理解的明細與主管覆核軌跡。

依門店、班次、職務、出勤與支援規則計算小費池分配，處理退刷、離職及人工調整，提供員工可理解的明細與主管覆核軌跡。

**產業別：**餐飲旅宿　|　**系統類型：**finance-case

## 功能模組

- **小費池** — 彙整各類小費
- **分配規則** — 設定職務權重
- **人員資格** — 核對出勤支援
- **分配試算** — 計算個人金額
- **例外調整** — 記錄退刷離職
- **發放覆核** — 鎖定薪資明細

## 適合誰使用

- 門店店長
- 薪酬人員
- 餐飲財務主管

## 運作流程

1. 建立小費池
2. 選定規則
3. 確認資格
4. 執行試算
5. 處理例外
6. 發布發放

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
