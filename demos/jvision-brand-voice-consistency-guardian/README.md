**產業別：**業務銷售　|　**系統類型：**operations-console

## 功能模組

- **品牌語氣基準** — 定義語調維度、品牌人格與各渠道允許的表達範圍。
- **文案一致性掃描** — 批次檢查文案與品牌語氣、用詞及格式規範的落差。
- **禁語風險雷達** — 標示禁用詞、敏感宣稱與不合規表述的風險。
- **跨渠道差異比對** — 比較網站、廣告、社群與郵件中的語氣偏移。
- **品牌化改寫室** — 依原意生成合規改寫並顯示修改理由與信心。
- **發布守門台** — 集中審核高風險文案，核准、退回或要求再次修改。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 設定語氣規範
2. 掃描待發文案
3. 處理禁語風險
4. 比對渠道語氣
5. 產生合規改寫
6. 核准內容發布
