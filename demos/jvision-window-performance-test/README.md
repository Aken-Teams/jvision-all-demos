# 門窗性能試驗追蹤台

> 管理門窗水密、氣密與抗風壓試驗的窗號選樣、前置檢查、測試參數、漏點定位、改善方式及複驗結果，確保抽測樣品可回溯至同型式現場安裝範圍。

管理門窗水密、氣密與抗風壓試驗的窗號選樣、前置檢查、測試參數、漏點定位、改善方式及複驗結果，確保抽測樣品可回溯至同型式現場安裝範圍。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **窗號分群** — 依型式、立面與施工批次建立母群。
- **抽測計畫** — 選定樣品、試驗項目與驗收標準。
- **前置確認** — 檢查封膠、養護及設備布置條件。
- **試驗紀錄** — 登錄壓力階段、時間與漏水位置。
- **漏點改善** — 追蹤膠條、排水孔與接縫修補。
- **複驗展開** — 核定複驗並管理同型式全面檢查。

## 適合誰使用

- 帷幕門窗工程師
- 品管工程師
- 試驗單位

## 運作流程

1. 建立母群
2. 選定窗號
3. 確認條件
4. 執行測試
5. 修補缺失
6. 複驗放行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
