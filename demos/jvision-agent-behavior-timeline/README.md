**產業別：**資訊科技　|　**系統類型：**security-soc

## 功能模組

- **行為事件時間線** — 依時間串接對話、決策、工具呼叫、資料存取與人工介入。
- **對話脈絡檢視器** — 還原使用者指令、Agent 回覆與各輪上下文變化。
- **決策摘要節點** — 呈現每個關鍵決策的理由摘要、信心與採用條件。
- **工具呼叫透視** — 檢視工具參數、回傳、耗時、錯誤與重試關係。
- **資料存取地圖** — 標示被讀寫的資料來源、敏感等級與權限判定。
- **事故還原工作區** — 鎖定異常起點、影響範圍與責任節點並建立處置案件。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 定位異常任務
2. 還原對話脈絡
3. 檢查決策節點
4. 追查工具呼叫
5. 核對資料存取
6. 完成事故還原
