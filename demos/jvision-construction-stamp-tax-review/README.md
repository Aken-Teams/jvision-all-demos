# 印花稅憑證檢核台

> 盤點各專案承攬契約、追加協議、訂購文件與收據的印花稅課徵基礎，判斷應稅類型、計算稅額並追蹤繳納憑證，避免追加文件漏報、金額變更少繳或重複貼用。

盤點各專案承攬契約、追加協議、訂購文件與收據的印花稅課徵基礎，判斷應稅類型、計算稅額並追蹤繳納憑證，避免追加文件漏報、金額變更少繳或重複貼用。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **文件盤點** — 彙整承攬契約、追加協議、訂單及收據。
- **課稅判定** — 依文件性質標示應稅類型、稅率與判定理由。
- **稅額試算** — 計算原始、追加、已繳與待補稅額。
- **憑證登錄** — 關聯繳款書、彙總繳納紀錄與證明。
- **漏繳預警** — 提示未送審、逾期、少繳及重複繳納風險。
- **稅務抽查** — 按專案、期間及文件類型產出檢核清冊。

## 適合誰使用

- 稅務會計
- 合約管理員
- 專案行政人員

## 運作流程

1. 登錄契約文件
2. 確認文件性質
3. 執行課稅判定
4. 核算應補稅額
5. 登錄繳納憑證
6. 完成定期抽查

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
