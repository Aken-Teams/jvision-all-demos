# 汽車總裝扭力防漏裝台

> 以擬真工站事件整合車型、車身序號、鎖附扭力與零件裝配確認，透過節拍看板、超規警示及補正流程，協助總裝線即時辨識扭力異常與漏裝風險，確保問題車輛在離站前完成處置。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **產線監控** — 呈現各工站節拍、在製車輛、異常燈號及待攔截數量。
- **扭力曲線** — 查看鎖附點目標範圍、實際曲線、超規原因與歷史比較。
- **裝配核對** — 依車型顯示必要零件、裝配狀態與疑似漏裝位置。
- **單車履歷** — 以車身序號查詢所有工站、鎖附點及零件確認紀錄。
- **異常處置** — 集中處理扭力超規、漏裝與重複鎖附事件並指派責任人。
- **返修放行** — 引導返修複核、電子簽核及離站條件確認。

## 適合誰使用

- 總裝線班長
- 製程工程師
- 品質工程師與返修人員

## 運作流程

1. 監看總裝節拍
2. 判讀扭力異常
3. 確認漏裝項目
4. 追溯單車紀錄
5. 執行異常處置
6. 複核車輛放行
