# 跨站製程異常溯因台

> 串接擬真的工序履歷，將末端品質異常沿產品批次逐站回溯，呈現各站點參數、設備、物料與等待事件的關聯證據，協助跨部門鎖定最可能的起始站點並追蹤改善驗證。

串接擬真的工序履歷，將末端品質異常沿產品批次逐站回溯，呈現各站點參數、設備、物料與等待事件的關聯證據，協助跨部門鎖定最可能的起始站點並追蹤改善驗證。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **製程路徑總覽** — 以站點流程圖呈現異常批次經過的完整加工路徑。
- **批次履歷回溯** — 查看各站進出時間、設備、物料、參數與檢驗紀錄。
- **可疑站點排序** — 依異常關聯度與偏差程度排列優先調查的站點。
- **跨站因果關聯** — 呈現上游事件與下游品質異常之間的關聯鏈。
- **聯合調查工作區** — 彙整各站證據、工程意見、根因假設與待辦事項。
- **改善批次驗證** — 比較改善前後批次的站點數據與品質結果。

## 適合誰使用

- 製程整合工程師
- 品保工程師
- 製造主管

## 運作流程

1. 展開製程路徑
2. 回溯批次履歷
3. 排序可疑站點
4. 建立因果鏈條
5. 進行聯合調查
6. 驗證改善批次

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
