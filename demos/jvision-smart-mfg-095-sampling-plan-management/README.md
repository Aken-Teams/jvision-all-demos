# Sampling Plan Management（抽樣計畫管理）

> 從異常到改善的品質閉環與追溯稽核

Sampling Plan Management（抽樣計畫管理）提供抽樣標準資料庫、AQL等級設定、抽樣數量自動計算。品保部依「產品風險分級→抽樣標準設定→檢驗執行→結果回饋→動態調整抽樣等級」推進作業，優先解決「抽樣標準查詢耗時」，IQC/OQC檢驗單位則以抽樣執行合規率與漏檢風險確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 品保部
- IQC
- OQC檢驗單位

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：20天 → **8.8天**
- 改善驗證率：68% → **92%**
- 重複不良率：6.1% → **2.1%**
