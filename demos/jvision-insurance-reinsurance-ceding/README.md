# 保險再保分出管理台

> 供保險公司依合約條件判定案件分保比例、計算再保費與攤回金額、編製分保清單並追蹤再保人確認，降低人工試算與漏分風險。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **合約條件** — 管理比例與超額再保條款
- **分保判定** — 媒合案件與適用合約
- **金額試算** — 計算保費責任及攤回
- **分保清單** — 彙整期間案件與調整
- **再保確認** — 追蹤對方回覆與爭議
- **期間結算** — 產生應收應付與差異

## 適合誰使用

- 再保人員
- 精算人員
- 財務會計

## 運作流程

1. 設定再保合約
2. 判定案件歸屬
3. 試算分保金額
4. 編製期間清單
5. 取得再保確認
6. 完成帳務結算

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
