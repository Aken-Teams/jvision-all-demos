**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **Context 批次** — 選取知識片段集合、目標模型視窗與本次最佳化範圍。
- **語意重複群組** — 依語意、實體、時間與來源關係聚類近似或包含型片段。
- **片段差異檢視** — 逐句比較重疊內容、獨有事實、衝突陳述與更新時間。
- **最佳證據選擇** — 依權威性、新鮮度、完整度與引用品質選定保留片段。
- **安全合併工作台** — 合併互補內容、保留來源定位並避免抹除關鍵限定條件。
- **視窗節省驗證** — 比較去重前後權杖量、召回品質、答案一致性與推論成本。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 建立最佳化批次
2. 產生重複群組
3. 審查片段差異
4. 選定主要證據
5. 執行安全合併
6. 驗證節省成效
