# 建照變更影響盤點台

> 管理建照變更項目的法規依據、圖說差異、施工影響、停等範圍及送審進度，協助設計、監造與營造團隊判斷哪些現場作業可續做、哪些必須暫停，避免未核准先行施工。

管理建照變更項目的法規依據、圖說差異、施工影響、停等範圍及送審進度，協助設計、監造與營造團隊判斷哪些現場作業可續做、哪些必須暫停，避免未核准先行施工。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **圖說差異** — 對照核准版與變更版的平面、立面及用途差異。
- **法規判定** — 記錄變更依據、申辦類型與必要文件。
- **工項影響** — 盤點受影響區域、工序、材料與分包契約。
- **停等邊界** — 標示可續作、限制施工及必須暫停範圍。
- **送審追蹤** — 管理補件、審查意見與預計核准日期。
- **核准換版** — 發布核准圖並回收現場舊版文件。

## 適合誰使用

- 建築師
- 監造主任
- 工地主任

## 運作流程

1. 提出變更
2. 判定法規
3. 盤點影響
4. 發布停等
5. 追蹤審查
6. 核准交底

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
