# 宮廟捐獻帳務管理台

> 管理香油錢、功德金、專案募款與指定用途捐獻的收款、收據、用途分類及公開報表，協助宮廟建立可追溯帳務。

管理香油錢、功德金、專案募款與指定用途捐獻的收款、收據、用途分類及公開報表，協助宮廟建立可追溯帳務。

**產業別：**宗教服務　|　**系統類型：**finance-ledger

## 功能模組

- **捐獻總覽** — 查看來源項目與金額
- **收款登錄** — 記錄現金匯款及活動收入
- **收據管理** — 處理開立補發與作廢
- **款項核對** — 確認收款與帳戶入帳
- **用途分類** — 管理指定用途及可用餘額
- **徵信報表** — 產生內部及公開名冊

## 適合誰使用

- 宮廟會計
- 財務委員
- 廟務主任

## 運作流程

1. 登錄捐獻
2. 開立收據
3. 核對款項
4. 分類用途
5. 財務覆核
6. 發布徵信

## 導入效益

- 活動籌備工時：20小時 → **5小時**
- 報名掌握率：65% → **94%**
- 物資盤點：6小時 → **1小時**
- 志工調度時效：3天 → **1天**
