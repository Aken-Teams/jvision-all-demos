# 鋼材厚度異常預測系統

> 利用擬真的歷史厚度、鋼種、速度與軋延參數，呈現鋼材厚度偏差的預測風險與可能原因，協助製程人員提早辨識超差批次、比較影響因子，並模擬調整策略與改善成效。

利用擬真的歷史厚度、鋼種、速度與軋延參數，呈現鋼材厚度偏差的預測風險與可能原因，協助製程人員提早辨識超差批次、比較影響因子，並模擬調整策略與改善成效。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **厚度風險總覽** — 呈現產線厚度偏差、風險分級與近期超差趨勢。
- **批次風險清單** — 依預測風險排列鋼材批次，提供鋼種、規格與生產條件篩選。
- **厚度曲線預測** — 對照目標值、模擬實測值與預測區間，標示可能超差區段。
- **影響因子解析** — 拆解速度、張力、輥縫與溫度等參數對預測結果的影響。
- **調整方案模擬** — 切換參數情境，預覽厚度偏差與風險等級的模擬變化。
- **改善成效追蹤** — 比較預警前後的超差率、處置結果與各產線改善幅度。

## 適合誰使用

- 軋延製程工程師
- 生產主管與品質工程師

## 運作流程

1. 檢視風險概況
2. 篩選高風險批次
3. 查看預測曲線
4. 解析異常原因
5. 模擬參數調整
6. 追蹤改善成果
