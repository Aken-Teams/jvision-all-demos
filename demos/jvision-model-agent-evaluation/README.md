# 模型與智慧代理評測平台

> 集中管理人工智慧模型與智慧代理的測試資料、評分標準、版本比較及發布門檻；智慧代理是能呼叫工具並完成多步任務的系統。平台可評估回答品質、安全性、成本與任務成功率，並留下核准及風險追蹤紀錄。

集中管理人工智慧模型與智慧代理的測試資料、評分標準、版本比較及發布門檻；智慧代理是能呼叫工具並完成多步任務的系統。平台可評估回答品質、安全性、成本與任務成功率，並留下核准及風險追蹤紀錄。

**產業別：**AI 工程平台　|　**系統類型：**operations-console

## 功能模組

- **評測治理總覽** — 彙整模型版本、評測狀態、發布風險與核心指標。
- **評測資料集** — 管理測試問題、任務情境、預期結果與敏感案例。
- **評分標準設計** — 設定正確性、安全性、語氣、成本與任務完成門檻。
- **批次評測實驗** — 選擇模型或智慧代理版本，模擬執行多組測試。
- **版本比較分析** — 比較指標、失敗案例、工具軌跡、延遲與成本差異。
- **發布治理關卡** — 依門檻提出核准、例外或退回，並追蹤風險事項。

## 適合誰使用

- 人工智慧產品經理
- 模型工程師
- 品質測試人員
- 風險治理主管

## 運作流程

1. 掌握評測狀態
2. 準備評測資料
3. 制定評分標準
4. 執行批次評測
5. 分析版本差異
6. 完成發布決策
