# 外匯曝險滾動預測器

連結訂單、採購與成交機率，滾動預測外匯曝險以提前避險。37                              

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **幣別曝險總覽** — 彙整各幣別淨曝險、方向、期間與風險金額。
- **訂單曝險推估** — 依銷售訂單金額、收款日與成交機率估算曝險。
- **採購曝險推估** — 依採購承諾、付款條件與履約機率估算外幣需求。
- **滾動曝險曲線** — 按週或月呈現淨曝險路徑及預測區間。
- **機率情境調整** — 測試訂單轉換、採購延遲與匯率波動情境。
- **提前避險建議** — 提出避險時點、金額與分批比例的優先建議。

## 適合誰使用

- 財務長
- Treasurer
- 資金人員

## 運作流程

1. 盤點幣別部位
2. 評估訂單流入
3. 評估採購流出
4. 檢視曝險曲線
5. 測試機率情境
6. 核准避險計畫

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
