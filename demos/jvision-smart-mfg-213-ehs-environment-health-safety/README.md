# 職業安全衛生管理預警塔

管理產線職安衛法規遵循、危害辨識、工安事故通報與健康檢查，降低製程作業風險。

- 原始系統：職業安全衛生管理系統（EHS, Environment, Health & Safety）
- 產業分類：智慧製造｜人資管理
- 使用部門：職安衛部門、產線主管、廠務工程部、人資部
- 工作流程：危害辨識 → 風險評估 → 防護措施執行 → 事故/異常通報 → 改善追蹤 → 稽核結案
- AI 應用：工安影像辨識（未戴PPE偵測）、事故熱點與高風險工序預測
- 主要 KPI：職災發生率、虛驚事件通報數、健檢異常改善率、PPE配戴合規率
- 代表產品：Intelex EHS、Cority、鼎新EHS模組、國內半導體大廠自建EHS平台
