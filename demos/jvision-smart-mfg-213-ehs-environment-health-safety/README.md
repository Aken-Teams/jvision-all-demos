# 職業安全衛生管理系統（EHS, Environment, Health & Safety）

> 從異常到改善的品質閉環與追溯稽核

職業安全衛生管理系統（EHS, Environment, Health & Safety）提供危害辨識與風險評估（HIRA）、工安事故/虛驚事件通報、個人防護具（PPE）發放紀錄。職安衛部門依「危害辨識 → 風險評估 → 防護措施執行 → 事故/異常通報 → 改善追蹤 → 稽核結案」推進作業，優先解決「工安事故通報延遲難即時處置」，產線主管則以職災發生率與虛驚事件通報數確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 職安衛部門
- 產線主管
- 廠務工程部

## 運作流程

1. 待確認
2. 照護中
3. 驗證確認
4. 已完成

## 導入效益

- 批號追溯時間：173分鐘 → **16分鐘**
- 客訴平均關案：22天 → **9天**
- 改善驗證率：63% → **92%**
- 重複不良率：6.4% → **2%**
