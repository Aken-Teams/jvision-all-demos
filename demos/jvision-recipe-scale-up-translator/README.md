# 配方放大量產轉譯器

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **實驗配方基線** — 彙整實驗配方、設備條件、操作步驟與關鍵品質屬性。
- **尺度效應預測** — 預測放大後混合、傳熱、傳質、剪切與反應動力的變化。
- **量產參數轉譯** — 將實驗室設定轉換為量產設備可執行的轉速、溫度及時間。
- **品質風險區間** — 呈現品質指標預測區間、敏感參數與超規機率。
- **爬坡批次規劃** — 安排中試、首批與量產批次的參數遞進、取樣及停損條件。
- **批次學習校正** — 依每批實績更新尺度模型並提出下一批參數修正建議。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 建立實驗基線
2. 映射量產設備
3. 預測尺度效應
4. 產生量產參數
5. 核准爬坡批次
6. 執行回饋校正
