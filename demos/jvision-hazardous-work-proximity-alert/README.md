# 危險作業鄰接預警台

> 把吊掛、動火、高處、開挖等作業依時段與施工區域疊合，於晨會前辨識上下層、動線及火源鄰接衝突，安排隔離、錯時或監視措施，避免不同工班各自施工形成複合風險。

把吊掛、動火、高處、開挖等作業依時段與施工區域疊合，於晨會前辨識上下層、動線及火源鄰接衝突，安排隔離、錯時或監視措施，避免不同工班各自施工形成複合風險。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **作業時空盤** — 以日期、時段與區域呈現危險作業分布。
- **作業申報** — 登錄工種、危害、範圍、動線及預定時間。
- **衝突偵測** — 列出上下層、相鄰區與共用動線的衝突。
- **聯防協調** — 安排錯時、隔離、監視與責任分工。
- **措施確認** — 逐項確認防護條件及現場照片紀錄。
- **開工放行** — 核定可施工時段並保留調整歷程。

## 適合誰使用

- 職安人員
- 工地工程師
- 分包領班

## 運作流程

1. 檢視作業分布
2. 申報作業需求
3. 辨識鄰接衝突
4. 協調聯防方案
5. 確認防護到位
6. 核准作業時段

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
