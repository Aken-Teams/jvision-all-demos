**產業別：**設備維護　|　**系統類型：**it-ops

## 功能模組

- **場域漂移脈搏** — 呈現各裝置群輸入特徵與推論結果的分布偏移。
- **基準分布對照** — 將現場窗口與訓練、驗證及前期穩定基準逐項比較。
- **漂移關聯圖譜** — 連結韌體、環境、設備與模型版本以追查共同變因。
- **漂移成因研判** — 區分季節變化、感測退化、資料管線異常與概念漂移。
- **回訓證據包** — 彙整代表樣本、影響範圍與回訓理由供人工修訂核准。
- **回訓觸發台** — 建立資料補採、標註、回訓及分批驗證任務。

## 適合誰使用

- IoT 架構師
- 設備工程師
- 場域主管

## 運作流程

1. 監測分布變化
2. 比對穩定基準
3. 追查關聯變因
4. 判定漂移類型
5. 審核回訓草案
6. 啟動回訓閉環
