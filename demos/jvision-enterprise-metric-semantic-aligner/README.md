# 企業指標語意對齊器

> 辨識企業指標的同名異義與異名同義，協助建立跨部門一致的衡量語言。

辨識企業指標的同名異義與異名同義，協助建立跨部門一致的衡量語言。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **指標語料掃描** — 從 BI、目錄、SQL 與文件擷取名稱、公式及使用脈絡。
- **同名異義偵測** — 找出名稱相同但公式、粒度或時間窗口不同的指標。
- **異名同義配對** — 辨識名稱不同但業務定義與計算邏輯相近的指標。
- **定義差異比對** — 並列公式、維度、來源、篩選條件與責任單位。
- **標準指標映射** — 將局部指標映射至候選企業標準與核准別名。
- **語意共識核定** — 協調定義爭議並發布具版本的企業指標語彙。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 蒐集指標語境
2. 審查同名衝突
3. 審查同義候選
4. 釐清定義差距
5. 建立標準映射
6. 核定企業語彙
