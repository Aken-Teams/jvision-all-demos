# 基樁打設深度交接台

> 供基樁現場按樁號記錄節長、貫入度、接樁與最終深度，讓施工班、測量及監造於移機前完成核對，避免樁位或深度紀錄失聯。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **樁位總圖** — 查看樁位與狀態
- **打設登錄** — 記錄節長及深度
- **貫入核算** — 比對設計停打值
- **接樁紀錄** — 留存接頭檢查
- **停打處置** — 追蹤障礙與復工
- **監造簽認** — 封存單樁履歷

## 適合誰使用

- 基樁班長
- 測量工程師

## 運作流程

1. 樁位放樣
2. 機台就位
3. 逐節打設
4. 接頭檢查
5. 停打判定
6. 移機交接

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
