# 重大訊息判斷助手

依事件事實、揭露門檻與法定時點形成重大訊息判斷及核准紀錄。<br>

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **重大事件立案** — 記錄交易、事故、財務變動或治理事件及最早知悉時間。
- **關鍵事實問卷** — 依事件類型引導蒐集金額、影響、確定性與涉及對象。
- **揭露門檻判定** — 比對量化門檻與質性標準，呈現符合、未符合及待確認依據。
- **揭露時點計算** — 依知悉、決議、簽約或發生日計算最晚申報時間。
- **判斷紀錄成文** — 產生含法源、事實、推論、異議與引用的可覆核判斷書。
- **申報決策簽核** — 完成揭露、暫緩或不揭露決策，並安排申報與持續監看。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 登錄潛在事件
2. 確認關鍵事實
3. 檢驗揭露門檻
4. 鎖定申報時限
5. 審閱判斷紀錄
6. 核准揭露決策

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
