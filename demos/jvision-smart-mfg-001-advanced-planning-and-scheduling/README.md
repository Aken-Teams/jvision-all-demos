# APS（Advanced Planning and Scheduling）

> 應收付、現金流到預算的財務即時掌握

APS（Advanced Planning and Scheduling）提供有限產能排程與模擬、多工廠/多產線排程整合、交期承諾（ATP/CTP）試算。生管依「訂單匯入 → 產能/物料檢核 → 排程演算 → 派工單產出 → 執行回饋 → 動態重排」推進作業，優先解決「人工排程耗時且無法即時調整」，PMC則以準時交貨率與產能利用率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生產製造　|　**系統類型：**財務會計系統

## 功能模組

- **應收帳款** — 開立、對帳與催收
- **應付帳款** — 請款、付款與對帳
- **現金流** — 資金調度與預測
- **預算管理** — 編列、控管與差異分析
- **固定資產** — 資產登錄與折舊
- **總帳傳票** — 傳票、拋轉與月結

## 適合誰使用

- 生管
- PMC
- 業務

## 運作流程

1. 待排程
2. 生產中
3. 待品檢
4. 已入庫

## 導入效益

- 排程作業工時：8.2小時/日 → **1.5小時/日**
- 準時交付率：85% → **99%**
- 缺料停線次數：12次/月 → **2.8次/月**
- 設備稼動率：74% → **86%**
