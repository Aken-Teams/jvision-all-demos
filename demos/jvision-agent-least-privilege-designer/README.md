# Agent 最小權限設計器

> 依 Agent 實際任務推導最小工具與資料權限，縮減不必要的越權暴露面。

依 Agent 實際任務推導最小工具與資料權限，縮減不必要的越權暴露面。

**產業別：**資訊科技　|　**系統類型：**security-soc

## 功能模組

- **任務能力拆解** — 把 Agent 目標拆成必要動作、工具、資料欄位與執行條件。
- **實際使用剖析** — 分析任務軌跡與工具呼叫，辨識已用、未用及偶發權限。
- **最小權限推導** — 產生精確到操作、資源、欄位與環境的權限建議。
- **權限影響模擬** — 模擬移除或限縮權限後的任務成功率、SLA 與風險變化。
- **政策差異修訂** — 比對現行 IAM 政策，提出撤銷、降級、限時或條件化調整。
- **權限方案部署** — 經核准同步 IAM，並以回歸任務驗證最小權限可用性。

## 適合誰使用

## 運作流程

1. 拆解任務能力
2. 分析權限使用
3. 推導最小集合
4. 模擬限縮影響
5. 審訂政策差異
6. 核准部署驗證
