# 評量命題閱卷分析平台

> 支援教師依課程目標與認知層次建立評量藍圖、編修題目及組卷，並以模擬作答進行輔助閱卷、爭議複核與配分校準，最後從題目品質及學生表現萃取可用的學習證據。

支援教師依課程目標與認知層次建立評量藍圖、編修題目及組卷，並以模擬作答進行輔助閱卷、爭議複核與配分校準，最後從題目品質及學生表現萃取可用的學習證據。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **評量藍圖設計** — 配置教學目標、認知層次、題型、配分與預期難度。
- **智慧命題工作室** — 建立並編修題幹、選項、評分規準與命題品質提示。
- **題庫組卷中心** — 依藍圖挑選題目、檢查重複性並預覽完整試卷結構。
- **輔助閱卷工作台** — 並列學生答案、評分規準、建議分數與可編輯評語。
- **爭議複核中心** — 集中處理低信心評分、教師歧見及配分調整影響。
- **學習證據分析** — 分析題目難度、鑑別度、概念缺口與班級表現分布。

## 適合誰使用

- 授課教師
- 命題教師
- 閱卷教師
- 教務與課程主管

## 運作流程

1. 建立評量藍圖
2. 編修評量題目
3. 完成題庫組卷
4. 執行輔助閱卷
5. 處理評分爭議
6. 解析學習證據

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
