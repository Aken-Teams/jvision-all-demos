# 臨時設施移交管制台

> 管理工地臨時電力、給排水、圍籬、通道及堆置區的設置、使用責任、遷移通知與拆除條件，讓工序轉換時可確認接管人及替代方案，避免誤拆後又重建。

管理工地臨時電力、給排水、圍籬、通道及堆置區的設置、使用責任、遷移通知與拆除條件，讓工序轉換時可確認接管人及替代方案，避免誤拆後又重建。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **臨設配置** — 依工區查看設施位置與狀態。
- **設施台帳** — 管理用途、容量、責任與使用期。
- **遷拆申請** — 提出遷移、拆除及生效日期。
- **影響會簽** — 確認受影響工班與替代方案。
- **現場移交** — 記錄新舊責任人和點交結果。
- **異動履歷** — 保留配置版本與重設成本。

## 適合誰使用

- 工務工程師
- 職安人員
- 分包領班

## 運作流程

1. 檢視配置
2. 確認台帳
3. 提出遷拆
4. 完成會簽
5. 現場點交
6. 更新履歷

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
