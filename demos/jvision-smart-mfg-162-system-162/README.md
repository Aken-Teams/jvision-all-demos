# 供應商稽核管理系統

> 供應商協同、詢比議價到交期風險控管

供應商稽核管理系統提供稽核排程與範本管理、現場稽核紀錄數位化、缺失發現與分級。採購部依「稽核排程 → 現場查核 → 缺失記錄 → 矯正措施追蹤 → 複核結案」推進作業，優先解決「稽核紀錄紙本化難以彙整」，品保部則以稽核覆蓋率與缺失改善完成率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**採購供應鏈　|　**系統類型：**SRM 採購供應商管理

## 功能模組

- **供應商管理** — 建檔、分級與績效評分
- **詢報價協作** — 線上詢價、比價與議價
- **採購訂單** — 請購、下單與交期追蹤
- **交期風險** — 缺料預警與到貨監控
- **供應商品質** — 進料檢驗與 SCAR 改善
- **綠色採購** — ESG 評分與永續採購

## 適合誰使用

- 採購部
- 品保部
- 供應商管理部

## 運作流程

1. 待詢價
2. 比價中
3. 待核准
4. 驗收完成

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：87% → **99%**
- 缺料預警覆蓋：38% → **86%**
- 議價作業工時：8小時/週 → **2小時/週**
