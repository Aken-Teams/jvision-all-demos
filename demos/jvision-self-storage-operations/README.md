# 迷你倉租務營運台

> 提供迷你倉業者管理倉位尺寸、租約期間、候補客戶、續租調價、逾期欠費與退租點交，以純 UI 呈現從詢價到倉位再次釋出的完整內部流程。

提供迷你倉業者管理倉位尺寸、租約期間、候補客戶、續租調價、逾期欠費與退租點交，以純 UI 呈現從詢價到倉位再次釋出的完整內部流程。

**產業別：**生活服務　|　**系統類型：**erp

## 功能模組

- **倉位圖** — 查看尺寸與出租狀態
- **詢價候補** — 管理客戶需求與候補
- **租約管理** — 建立租期和優惠條件
- **續租調價** — 處理到期與新租金
- **欠費處理** — 追蹤逾期租金案件
- **退租點交** — 記錄清空與損壞狀況

## 適合誰使用

- 門市人員
- 租務主管
- 財務人員

## 運作流程

1. 媒合倉位
2. 建立租約
3. 完成入住
4. 辦理續租
5. 處理欠費
6. 退租釋出

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
