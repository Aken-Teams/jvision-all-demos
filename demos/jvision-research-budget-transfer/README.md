# 研究經費移撥覆核台

> 管理研究計畫科目間預算移撥，檢查補助規定、已承諾採購、版本與核准文件，讓承辦在核銷前確認移撥後仍足以支應既有支出。

管理研究計畫科目間預算移撥，檢查補助規定、已承諾採購、版本與核准文件，讓承辦在核銷前確認移撥後仍足以支應既有支出。

**產業別：**教育　|　**系統類型：**finance-case

## 功能模組

- **計畫預算** — 呈現科目額度及使用
- **移撥申請** — 指定移出移入與理由
- **補助規則** — 檢查限制比例與禁轉
- **承諾支出** — 保留已下單未核銷金額
- **影響模擬** — 預覽移撥後可用餘額
- **覆核發布** — 核准並產生預算版本

## 適合誰使用

- 計畫主持人
- 研究行政
- 主計人員

## 運作流程

1. 提出經費移撥
2. 核對補助規則
3. 扣除承諾支出
4. 模擬預算影響
5. 完成主管覆核
6. 發布新版預算

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
