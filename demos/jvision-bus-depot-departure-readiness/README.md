# 客運班次出車整備台

> 供客運業者在發車前集中確認駕駛到勤、車輛指派、臨時故障、清潔加油與文件資格，對未符合條件的班次及早換車換人，降低脫班與延誤風險。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **出車總覽** — 顯示待整備、風險與已放行班次。
- **班次清單** — 檢視路線、時刻及車輛需求。
- **駕駛到勤** — 確認出勤、資格與工時限制。
- **車輛指派** — 配對可用車並顯示保修限制。
- **整備檢核** — 核對清潔、加油、文件及設備。
- **缺口調度** — 執行換人換車並完成放行。

## 適合誰使用

- 客運調度員
- 站務主管
- 車輛管理員

## 運作流程

1. 檢視風險
2. 盤點班次
3. 確認駕駛
4. 確認車輛
5. 完成整備
6. 替補放行

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
