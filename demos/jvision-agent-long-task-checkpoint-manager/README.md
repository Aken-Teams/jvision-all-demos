**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **長任務步驟圖** — 呈現任務階段、相依關係、外部副作用與可中斷位置。
- **檢查點策略** — 依時間、成本、風險或里程碑設定狀態保存時機。
- **狀態快照庫** — 保存上下文、工具結果、資料版本、權限與執行游標。
- **中斷根因診斷** — 辨識逾時、工具故障、權限變更與資料漂移造成的中斷。
- **恢復重試模擬** — 比較原點重跑、檢查點續跑、局部重試與人工接管方案。
- **受控續跑中心** — 核准恢復點與補償動作後續跑，並驗證最終狀態一致性。

## 適合誰使用

- AI 平台負責人
- 流程主管

## 運作流程

1. 解析長任務步驟
2. 設定保存策略
3. 建立狀態快照
4. 診斷中斷原因
5. 選擇恢復方案
6. 核准續跑驗證
