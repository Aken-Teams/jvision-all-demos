協助學校與補習班管理學生固定搭乘名單、臨時請假、上下車異常、家長聯繫及路線責任交接，使用人工回填的擬真狀態完成事件閉環，降低漏接與誤乘風險。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **路線名冊** — 管理學生、站點與固定班次。
- **乘車異動** — 登錄請假、改站與臨時搭乘。
- **點名看板** — 呈現各站上下車確認狀態。
- **異常事件** — 建立漏接、誤乘及未到案件。
- **家長聯繫** — 保存通知與確認結果。
- **責任交接** — 記錄行政、導師與車隊處置。

## 適合誰使用

- 校務行政
- 導師
- 接送主管

## 運作流程

1. 維護名冊
2. 彙整異動
3. 確認乘車
4. 建立異常
5. 聯繫家長
6. 完成交接

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
