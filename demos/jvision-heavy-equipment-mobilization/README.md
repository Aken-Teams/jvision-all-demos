# 大型機具進退場排程台

> 集中管理吊車、挖土機與高空作業車的進退場申請，預先檢核道路、地坪、作業半徑與停放空間，協調多工區時段並記錄改期及待機原因。

集中管理吊車、挖土機與高空作業車的進退場申請，預先檢核道路、地坪、作業半徑與停放空間，協調多工區時段並記錄改期及待機原因。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **機具排程總覽** — 查看各工區進場、使用及退場時段。
- **調度需求申請** — 填報機型、噸位、用途與作業範圍。
- **進場路線檢核** — 確認道路寬度、轉彎、淨高及管制時段。
- **場地承載確認** — 檢查地坪補強、支腿與停放條件。
- **衝突改派協調** — 處理撞期、換機、改期與跨區調度。
- **進退場點交** — 記錄里程、油量、附件、損傷與時間。

## 適合誰使用

- 機具調度員
- 工地主任
- 工區工程師

## 運作流程

1. 提出機具需求
2. 檢查場地條件
3. 協調調度時段
4. 辦理進場點交
5. 回報使用異常
6. 完成退場結算

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
