# 原料批次不良關聯分析台

> 串聯模擬的原料批號、供應商、入料檢驗、生產投料與成品不良資料，找出特定原料批次與缺陷類型的關聯，協助工廠界定受影響工單、評估供應商風險，並追蹤隔離與改善處置。

串聯模擬的原料批號、供應商、入料檢驗、生產投料與成品不良資料，找出特定原料批次與缺陷類型的關聯，協助工廠界定受影響工單、評估供應商風險，並追蹤隔離與改善處置。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **原料品質總覽** — 呈現批次不良趨勢、供應商排行與待處理品質警示。
- **批次關聯矩陣** — 交叉比較原料批次、產品、工單與缺陷類型的關聯程度。
- **供應商風險分析** — 檢視各供應商的批次品質、檢驗結果與異常發生頻率。
- **投料流向追溯** — 由原料批號追查領料、生產工單、成品批次與剩餘庫存。
- **檢驗明細中心** — 查看模擬的入料與成品檢驗項目、量測結果及判定紀錄。
- **批次處置管理** — 管理隔離、退料、特採與供應商改善要求及其處理進度。

## 適合誰使用

- 品質工程師
- 品保主管
- 採購人員
- 倉管人員
- 生產主管

## 運作流程

1. 發現品質異常
2. 比對批次關聯
3. 評估供應風險
4. 追查投料流向
5. 核對檢驗證據
6. 執行批次處置

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
