# 租賃押金餘額稽核台

> 逐約勾稽押金收取、換約轉列、抵扣欠款、退還與銀行流水，呈現帳面、實收及租戶認知差異，避免押金重退、漏退或無法追償。

逐約勾稽押金收取、換約轉列、抵扣欠款、退還與銀行流水，呈現帳面、實收及租戶認知差異，避免押金重退、漏退或無法追償。

**產業別：**房地產與物業　|　**系統類型：**finance-case

## 功能模組

- **押金台帳** — 呈現各約應收實收餘額
- **租約勾稽** — 核對押金條款與換約
- **銀行核對** — 匹配收退款流水
- **抵扣審查** — 查驗欠款及修繕依據
- **差異調查** — 追蹤帳實與租戶爭議
- **退還覆核** — 雙重確認退款與銷帳

## 適合誰使用

- 租賃會計
- 物業主管
- 稽核人員

## 運作流程

1. 建立押金基準
2. 匯入收退流水
3. 辨識餘額差異
4. 補齊差異證據
5. 核准調整退還
6. 完成餘額結清
