## 功能模組

- **三方比較** — 對照各期用藥
- **逐藥判定** — 標示續停替換
- **衝突處理** — 釐清重複劑量
- **處方確認** — 核准最終清單
- **衛教版本** — 產生變更說明
- **交付確認** — 記錄理解簽認

## 適合誰使用

- 臨床藥師
- 出院醫師
- 病房護理師

## 運作流程

1. 匯整用藥
2. 逐項判定
3. 處理衝突
4. 核准處方
5. 執行衛教
6. 確認交付
