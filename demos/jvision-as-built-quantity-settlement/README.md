按圖面區域與計價項目建立完工實測紀錄，統一長度、面積、體積及開口扣除規則，保留草圖、照片與覆核歷程，產出可供分包末期結算的雙方確認數量。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **實測工作包** — 依棟別、樓層、區域與計價項目安排丈量。
- **現場丈量** — 輸入尺寸、計量單位、草圖、照片與定位資訊。
- **計量規則** — 套用開口扣除、搭接、損耗及單位換算規則。
- **數量比對** — 比較契約、估驗累計與完工實測數量。
- **雙方覆核** — 記錄總包與分包的差異意見及確認結果。
- **結算明細** — 鎖定核定數量並產出末期結算附件。

## 適合誰使用

- 數量計算工程師
- 工務工程師
- 分包計價人員

## 運作流程

1. 建立工作包
2. 執行丈量
3. 計算數量
4. 比較差異
5. 共同覆核
6. 完成結算

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
