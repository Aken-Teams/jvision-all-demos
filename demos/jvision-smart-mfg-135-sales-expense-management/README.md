# 業務費用報支管理 Sales Expense Management追蹤台

管理業務出差、交際與客戶招待等費用的申報、審核與核銷，控管業務成本合理性。

- 原始系統：業務費用報支管理 Sales Expense Management
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、財務部、業務主管、會計部
- 工作流程：業務提交費用申報→發票拍照上傳→系統政策檢核→主管審核→財務核銷付款
- AI 應用：發票OCR自動辨識建檔、異常費用型態自動偵測
- 主要 KPI：核銷處理時效、費用合規率、異常費用件數、客戶服務成本占比
- 代表產品：SAP Concur、Zoho Expense、鼎捷ERP費用模組
