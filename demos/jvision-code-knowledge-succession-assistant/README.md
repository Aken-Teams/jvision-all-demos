**產業別：**資訊科技　|　**系統類型：**collaboration-pm

## 功能模組

- **程式領域地圖** — 依服務、模組與能力建立程式邊界及責任關係圖。
- **修改歷史脈絡** — 串聯提交、PR、需求與事件，解釋程式演進原因。
- **設計決策解讀** — 彙整架構文件與討論，呈現方案取捨及未採用選項。
- **專家知識網絡** — 辨識各模組熟悉者、貢獻領域與可替代的知識來源。
- **程式脈絡問答** — 針對維護情境回答程式位置、設計原因與修改風險。
- **接班學習計畫** — 生成閱讀順序、實作任務、專家訪談與能力驗收清單。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 選定領域
2. 追溯歷史
3. 理解設計
4. 盤點專家
5. 情境問答
6. 執行接班
