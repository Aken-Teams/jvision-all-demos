# 工區釋出條件確認台

> 依樓層與工區設定下一工種進場前必須完成的前置作業、查驗、清場、養護及安全條件，由責任班組逐項回報並附佐證，未達條件即標示阻礙，避免人員到場後才發現工作面尚不可施工。

依樓層與工區設定下一工種進場前必須完成的前置作業、查驗、清場、養護及安全條件，由責任班組逐項回報並附佐證，未達條件即標示阻礙，避免人員到場後才發現工作面尚不可施工。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **工區狀態圖** — 以樓層區域呈現待釋出與已接收狀態。
- **釋出條件** — 設定各工序交接前的必要條件。
- **阻礙事項** — 登錄未完成項目、責任人與期限。
- **完成佐證** — 整理清場、查驗與完工影像。
- **接收確認** — 由下一工班接受或退回工作面。
- **待工分析** — 追蹤延遲釋出造成的排程影響。

## 適合誰使用

- 現場工程師
- 工班領班
- 工地主任

## 運作流程

1. 建立待釋工區
2. 套用釋出條件
3. 回報前置完成
4. 排除未決阻礙
5. 辦理工作面接收
6. 檢討釋出延誤

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
