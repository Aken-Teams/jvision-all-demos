# IPQC（In-Process Quality Control，製程在線檢驗）

> 從異常到改善的品質閉環與追溯稽核

IPQC（In-Process Quality Control，製程在線檢驗）提供製程檢驗點設定、巡檢排程、檢驗結果登錄。品保部依「排程巡檢→現場量測登錄→異常判定→即時通報→處置追蹤」推進作業，優先解決「巡檢人力不足」，生產部則以製程不良率與巡檢達成率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 品保部
- 生產部
- 製程工程部

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉

## 導入效益

- 批號追溯時間：184分鐘 → **15分鐘**
- 客訴平均關案：22天 → **9.4天**
- 改善驗證率：61% → **92%**
- 重複不良率：6% → **2%**
