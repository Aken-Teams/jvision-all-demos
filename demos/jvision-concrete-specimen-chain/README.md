# 混凝土試體送驗台

> 供澆置現場按車次製作試體，管理編號、養護位置、齡期送驗與抗壓結果，發現漏送或低強度時立即圈出對應澆置區域。

供澆置現場按車次製作試體，管理編號、養護位置、齡期送驗與抗壓結果，發現漏送或低強度時立即圈出對應澆置區域。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **試體總覽** — 查看各齡期狀態
- **取樣編組** — 連結車次澆置區
- **養護點交** — 記錄位置與條件
- **齡期排程** — 提醒送驗日期
- **送驗簽收** — 核對試體數量
- **強度判讀** — 標記低強度區域

## 適合誰使用

- 品管工程師
- 試驗室人員

## 運作流程

1. 現場取樣
2. 拆模養護
3. 齡期提醒
4. 試體點交
5. 抗壓試驗
6. 異常處置

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
