# 飯店收益與房價決策台

> 整合擬真住房率、預訂進度、房型庫存、競品價格與節慶事件，協助收益經理預測住房需求、比較調價情境、設定房價與銷售限制，並追蹤決策後的營收及平均房價表現。

**產業別：**餐飲旅宿　|　**系統類型：**analytics-bi

## 功能模組

- **收益駕駛艙** — 總覽營收、住房率、平均房價與待處理警示。
- **需求預測日曆** — 以日曆查看各日期需求熱度、事件與預測住房率。
- **房價情境模擬** — 比較不同價格、折扣及入住限制對收益的影響。
- **房型庫存配置** — 調整房型與通路的擬真可售量及銷售限制。
- **調價審核中心** — 彙整價格建議、影響理由與主管核准紀錄。
- **策略成效分析** — 比較決策前後的營收、房價與預測誤差。

## 適合誰使用

- 飯店收益經理
- 營運主管
- 訂房部主管

## 運作流程

1. 掌握收益概況
2. 研判住房需求
3. 試算房價方案
4. 配置房型庫存
5. 核准調價策略
6. 追蹤策略成效

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
