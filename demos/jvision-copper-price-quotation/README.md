# 電纜銅價連動報價台

> 供電線電纜廠將指定銅價日、匯率、導體用量與客戶點價條件鎖入報價，模擬下單延遲的價差曝險，留下調價與例外承接依據。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **銅價匯率** — 建立指定日行情
- **導體用量** — 依線徑換算銅重
- **價格試算** — 加入加工與損耗
- **延遲模擬** — 估算點價曝險
- **例外授權** — 核准沿用舊價
- **調價依據** — 輸出價格條款

## 適合誰使用

- 銅材採購
- 報價業務

## 運作流程

1. 行情建檔
2. 規格換算
3. 建立報價
4. 曝險檢查
5. 價格簽核
6. 客戶點價

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
