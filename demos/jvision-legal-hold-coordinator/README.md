# 電子證據保全協調器

> 協調保管人、資料源與期間的法律保全通知及追蹤，降低電子證據滅失風險。

協調保管人、資料源與期間的法律保全通知及追蹤，降低電子證據滅失風險。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **保管人盤點** — 依案件人物、組織與事件關係辨識應納入保全的資料保管人。
- **資料源範圍** — 界定郵件、雲端硬碟、裝置、聊天與業務系統的保全範圍。
- **保全期間界定** — 根據爭議事件與資料生命週期設定起訖期間及保存條件。
- **Hold 通知中心** — 產生、送達並追蹤法律保全通知、提醒及收件確認。
- **遵循回覆追蹤** — 記錄保管人確認、資料位置申報、離職與保全困難等狀態。
- **滅失風險處置** — 偵測刪除政策、帳號停用與未回覆風險並啟動升級措施。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 盤點保管人
2. 圈定資料來源
3. 設定保全期間
4. 發送保全通知
5. 追蹤遵循狀態
6. 處置滅失風險

## 導入效益

- 案件文件工時：6小時 → **1.5小時**

- 計費遺漏：10% → **2%**
