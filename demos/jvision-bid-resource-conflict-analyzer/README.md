# 標案資源衝突分析器

> 交叉檢查投標與履約計畫中的關鍵人力、交付時程及保證額度衝突。

交叉檢查投標與履約計畫中的關鍵人力、交付時程及保證額度衝突。

**產業別：**專業服務　|　**系統類型：**collaboration-pm

## 功能模組

- **投標履約總曆** — 將各標案備標、決標與履約里程碑疊加到共同時間軸。
- **關鍵人撞期圖** — 辨識專案經理、技術專家與法定人員的重疊承諾。
- **交付衝突檢查** — 比對驗收、上線與重大交付日期的容量衝突。
- **保證額度占用** — 計算押標金、履約保證與銀行額度的期間性占用。
- **衝突影響鏈** — 追蹤單一資源短缺會影響的標案、工作與承諾。
- **資源解衝方案** — 比較調度、外包、改期與放棄案件的可行組合。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 匯集案件時程
2. 檢查關鍵人撞期
3. 檢查交付撞期
4. 核算保證占用
5. 評估連鎖影響
6. 核准解衝配置

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
