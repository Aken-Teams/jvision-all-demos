# 保固修繕期限管制台

> 集中受理交付後保固案件，判定保固範圍、責任分包與服務期限，安排進場、複修及住戶確認，並攔截非保固損壞的免費派工。

集中受理交付後保固案件，判定保固範圍、責任分包與服務期限，安排進場、複修及住戶確認，並攔截非保固損壞的免費派工。

**產業別：**營建工程　|　**系統類型：**service-desk

## 功能模組

- **案件受理** — 登錄住戶問題與時限
- **保固判定** — 核對責任期限與除外
- **修繕派工** — 安排工班和進場時間
- **期限追蹤** — 顯示回覆完修與逾期
- **住戶確認** — 記錄完工及複驗結果
- **保固分析** — 統計成本與高頻問題

## 適合誰使用

- 保固客服
- 修繕工程師
- 分包窗口

## 運作流程

1. 受理報修
2. 判定責任
3. 指派工班
4. 安排進場
5. 完成修繕
6. 住戶結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
