# 樣品屋做法封樣台

> 將樣品屋各空間的材料、收邊、尺寸、色澤與施工做法逐項核定，保留退件修改歷程並發布封樣標準，供後續樓層施工及驗收一致引用。

將樣品屋各空間的材料、收邊、尺寸、色澤與施工做法逐項核定，保留退件修改歷程並發布封樣標準，供後續樓層施工及驗收一致引用。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **封樣總覽** — 查看各空間與工種核定狀態。
- **做法清單** — 建立材料、尺寸與收邊檢查項。
- **現勘標註** — 在照片上記錄缺失與修改要求。
- **修改版次** — 比較各輪施工與意見差異。
- **多方核定** — 彙整業主、設計及監造確認。
- **標準發布** — 產出供各樓層引用的封樣手冊。

## 適合誰使用

- 品管工程師
- 設計監造
- 分包領班

## 運作流程

1. 盤點封樣進度
2. 建立檢查基準
3. 執行現勘標註
4. 追蹤修改版本
5. 完成共同核定
6. 發布封樣標準

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
