# 證照到期補件追蹤台

> 管理學生或教職員必備證照的效期、影本、報名收據、補件期限與查驗結果，在實習或稽核名單送出前完成資格清件並保留版本。

管理學生或教職員必備證照的效期、影本、報名收據、補件期限與查驗結果，在實習或稽核名單送出前完成資格清件並保留版本。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **證照台帳** — 記錄類別號碼與效期
- **文件收件** — 區分證照與報名證明
- **到期預警** — 依活動日期判斷有效性
- **補件通知** — 批次通知缺件人員
- **文件查驗** — 審核真實性與版本
- **資格名單** — 鎖定可實習或送審名單

## 適合誰使用

- 系所承辦
- 實習督導
- 證照審核人員

## 運作流程

1. 建立資格需求
2. 匯入持證名單
3. 辨識到期缺件
4. 發送補件通知
5. 查驗補交文件
6. 發布合格名單

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
