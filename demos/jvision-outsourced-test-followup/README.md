# 門診代檢通知回收台

> 管理轉介外部檢查的通知、病人預約、實際完成、報告頁數、收件與醫師閱覽，對逾期未檢或報告缺頁主動追件，避免異常結果失聯。

管理轉介外部檢查的通知、病人預約、實際完成、報告頁數、收件與醫師閱覽，對逾期未檢或報告缺頁主動追件，避免異常結果失聯。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **代檢案件** — 記錄項目院所與期限
- **病人通知** — 追蹤聯繫預約與回覆
- **檢查進度** — 確認預約到檢與未完成
- **報告收件** — 查驗病人頁數與附件
- **醫師閱覽** — 派送主治並記錄判讀
- **後續追蹤** — 安排回診補檢與異常處置

## 適合誰使用

- 門診護理師
- 病歷人員
- 主治醫師

## 運作流程

1. 建立代檢醫囑
2. 完成病人通知
3. 追蹤到檢狀態
4. 查驗報告收件
5. 派送醫師閱覽
6. 執行後續處置

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
