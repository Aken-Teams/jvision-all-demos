# 校園鐘點費核算作業台

> 匯整課表、實際授課、調補課、假日與超鐘點規則，逐堂產生可核對的教師鐘點費，支援系所補正、主管覆核及薪資交付。

匯整課表、實際授課、調補課、假日與超鐘點規則，逐堂產生可核對的教師鐘點費，支援系所補正、主管覆核及薪資交付。

**產業別：**教育　|　**系統類型：**finance-ledger

## 功能模組

- **授課基準** — 彙整課表與教師負荷
- **調補課異動** — 記錄停課補課與代課
- **鐘點試算** — 套用假日超鐘點規則
- **疑義清單** — 找出重複缺堂與超額
- **系所覆核** — 確認實際授課證據
- **薪資交付** — 產出核准支付批次

## 適合誰使用

- 系所承辦
- 人事薪資
- 教務人員

## 運作流程

1. 建立授課基準
2. 彙整授課異動
3. 計算鐘點金額
4. 處理計算疑義
5. 覆核支付清單
6. 送交薪資入帳

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
