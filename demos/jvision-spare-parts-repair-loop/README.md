# 維修備件翻修循環台

> 管理高價維修備件從拆下、送修、報價、核准、回廠檢驗到重新入庫的循環，追蹤可修率、周轉時間、保固與報廢決策。

管理高價維修備件從拆下、送修、報價、核准、回廠檢驗到重新入庫的循環，追蹤可修率、周轉時間、保固與報廢決策。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **循環總覽** — 查看待送修、在修與待驗收件。
- **拆件登錄** — 記錄來源設備、故障與序號。
- **外送批次** — 管理廠商、交接與預計回廠日。
- **報價核准** — 比較翻修、更換與報廢成本。
- **回廠驗收** — 記錄測試結果與保固資訊。
- **重新入庫** — 更新狀態、庫位與可用資格。

## 適合誰使用

- 維修工程師
- 備件管理員
- 維修主管

## 運作流程

1. 登錄拆下備件
2. 建立外送批次
3. 評估翻修報價
4. 追蹤廠商進度
5. 執行回廠驗收
6. 恢復可用庫存

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
