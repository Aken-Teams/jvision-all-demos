# 手術室周轉協調台

> 供中小型醫院協調每日手術排程、術前條件、房間清潔、器械準備與臨時延誤，透過六階段狀態板讓護理站、麻醉與供應室掌握下一台手術是否可安全銜接。

供中小型醫院協調每日手術排程、術前條件、房間清潔、器械準備與臨時延誤，透過六階段狀態板讓護理站、麻醉與供應室掌握下一台手術是否可安全銜接。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **手術序列** — 查看各房間當日台次與預估時段。
- **術前條件** — 確認禁食、同意書、檢驗與備血狀態。
- **器械準備** — 核對器械組、耗材及特殊設備需求。
- **房間周轉** — 追蹤退房、清消與重新布置進度。
- **延誤重排** — 評估延誤影響並調整後續台次。
- **周轉分析** — 分析科別、房間與原因別延誤。

## 適合誰使用

- 手術室護理長
- 排程專員
- 麻醉護理師

## 運作流程

1. 排列台次
2. 核對病人
3. 備妥器械
4. 完成周轉
5. 處理延誤
6. 檢討績效

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
