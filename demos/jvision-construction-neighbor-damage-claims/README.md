# 工地鄰損協調管理台

> 協助營造商記錄施工前鄰房現況、受理鄰損陳情、比對照片證據、安排會勘、擬定修復或和解方案，降低爭議升級與停工風險。

協助營造商記錄施工前鄰房現況、受理鄰損陳情、比對照片證據、安排會勘、擬定修復或和解方案，降低爭議升級與停工風險。

**產業別：**營建工程　|　**系統類型：**legal-case

## 功能模組

- **鄰房建檔** — 整理戶別與施工前現況
- **陳情受理** — 記錄損害位置及訴求
- **證據比對** — 並列施工前後照片與紀錄
- **會勘安排** — 協調住戶及專業人員時程
- **方案協議** — 管理修復、補償與簽核
- **履行結案** — 追蹤修復成果及文件

## 適合誰使用

- 工地主任
- 法務人員
- 業主代表

## 運作流程

1. 建立基準
2. 受理陳情
3. 安排會勘
4. 研判責任
5. 協商方案
6. 履行結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
