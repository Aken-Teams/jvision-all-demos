# 校園場地借用管理台

> 供學校統整教室、實驗室、禮堂與運動場的課務占用、社團申請、設備需求、資格限制、押金及使用後點交，減少場地撞期、違規使用與設備損壞爭議。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **場地目錄** — 呈現容量、設備、開放時段與限制。
- **占用日曆** — 整合課表、活動與維護封場資訊。
- **借用申請** — 填寫用途、人數、布置與設備需求。
- **資格審核** — 依優先權、申請資格與風險核定。
- **設備領用** — 安排鑰匙、器材及借還責任人。
- **使用點交** — 記錄場復、損壞、押金與違規結果。

## 適合誰使用

- 總務人員
- 社團指導老師
- 場地管理員

## 運作流程

1. 選擇場地
2. 提出申請
3. 檢查撞期
4. 核定借用
5. 領用使用
6. 完成點交

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
