# 熱處理硬度預測系統

> 依材料成分、零件尺寸與模擬的加熱、保溫、冷卻條件，預測熱處理後的硬度範圍與不合格風險，協助材料及製程工程師縮短試驗次數、比較不同熱處理配方，並保留預測與驗證紀錄。

**產業別：**研發管理　|　**系統類型：**analytics-bi

## 功能模組

- **預測專案總覽** — 呈現進行中專案、硬度達標率、風險分布與待驗證項目。
- **材料條件建檔** — 設定材料牌號、成分、零件尺寸及目標硬度範圍。
- **熱處理配方設定** — 編排加熱、保溫與冷卻階段的擬真溫度及時間條件。
- **硬度結果預測** — 呈現預測硬度、信賴區間、不合格機率及關鍵影響因素。
- **配方比較** — 並列多組熱處理配方的硬度結果、時間與模擬能耗。
- **驗證紀錄** — 登錄擬真實驗值、偏差原因與配方是否通過驗證。

## 適合誰使用

- 材料工程師
- 熱處理製程工程師與研發主管

## 運作流程

1. 掌握預測專案
2. 建立材料條件
3. 設定熱處理配方
4. 查看硬度預測
5. 比較候選配方
6. 完成模擬驗證
