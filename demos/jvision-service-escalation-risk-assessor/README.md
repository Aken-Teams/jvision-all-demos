# 服務升級風險判斷器

> 綜合客戶影響、合約承諾與關係強度，判定一致的服務升級層級。 

綜合客戶影響、合約承諾與關係強度，判定一致的服務升級層級。 

**產業別：**客服管理　|　**系統類型：**service-desk

## 功能模組

- **升級案件雷達** — 集中檢視待判斷案件、影響範圍與時效壓力。
- **合約承諾核對** — 比對 SLA、權益條款、賠償約定與例外承諾。
- **客戶關係圖譜** — 呈現決策者、贊助者、關鍵聯絡人與歷史互動。
- **業務影響評量** — 量化使用中斷、受影響用戶、營收與續約風險。
- **升級層級判定** — 依影響、合約及關係產生層級建議與判斷理由。
- **處置核准台** — 調整責任人、回應時限與處置方案後送交核准。

## 適合誰使用

- 客戶成功主管
- CSM
- 客服主管

## 運作流程

1. 發現高風險案件
2. 核對合約承諾
3. 檢視關係脈絡
4. 評估實際影響
5. 形成升級建議
6. 核准並啟動處置

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
