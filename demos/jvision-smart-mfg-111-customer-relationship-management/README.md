# CRM追蹤台

集中管理客戶基本資料、聯絡人、互動紀錄與商機的核心平台，是業務管理的資料主幹。

- 原始系統：CRM（Customer Relationship Management）
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、業務助理、行銷部、管理層、客服部
- 工作流程：建立客戶檔案→紀錄拜訪與互動→建立商機→追蹤進度→結案與歸檔
- AI 應用：自動摘要拜訪紀錄與郵件、客戶流失風險預警、智慧推薦下一步行動
- 主要 KPI：客戶資料完整率、商機轉換率、平均回應時間、客戶留存率
- 代表產品：Salesforce Sales Cloud、Microsoft Dynamics 365 Sales、HubSpot CRM、Zoho CRM
