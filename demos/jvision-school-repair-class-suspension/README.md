# 校園修繕停課協調台

> 將教室報修、施工封閉、換教室、停復課及師生家長通知放在同一時程，避免施工人員到場仍在上課，或修復後空間遲未恢復使用。

**產業別：**教育　|　**系統類型：**maintenance-cmms

## 功能模組

- **修繕案件** — 登錄教室故障與影響
- **封閉排程** — 協調施工與上課時段
- **換室安排** — 配置替代教室與設備
- **停課通知** — 管理對象管道與回執
- **施工進度** — 回報到場完工及延誤
- **復課放行** — 驗收後恢復空間使用

## 適合誰使用

- 總務承辦
- 教務排課員
- 校務通知人員

## 運作流程

1. 受理教室報修
2. 盤點課程衝突
3. 安排封閉換室
4. 發布停換課通知
5. 追蹤施工完工
6. 驗收恢復上課

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
