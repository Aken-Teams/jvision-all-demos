# Order Management 訂單追蹤台

管理客戶訂單自接單、確認、變更到出貨結案的全流程，是業務與供應鏈的銜接樞紐。

- 原始系統：Order Management 訂單管理
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、業務助理、PMC、物流部、財務部
- 工作流程：接收客戶PO→訂單建檔比對→交期確認→產線/物流連動→出貨→結案對帳
- AI 應用：PO文件OCR自動辨識建檔、交期延遲風險預測
- 主要 KPI：準時交貨率、訂單處理時效、訂單變更頻率、缺料延遲率
- 代表產品：SAP SD模組、Oracle NetSuite Order Management、鼎新/鼎捷ERP訂單模組
