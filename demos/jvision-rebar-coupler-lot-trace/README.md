# 鋼筋續接器批次追溯台

> 從續接器進料批號、證明文件、抽樣送驗到樓層安裝位置建立追溯鏈，並管理扭力檢查與不合格批次隔離，協助營造廠在查驗時快速證明材料與施工品質。

從續接器進料批號、證明文件、抽樣送驗到樓層安裝位置建立追溯鏈，並管理扭力檢查與不合格批次隔離，協助營造廠在查驗時快速證明材料與施工品質。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **進料批次** — 登錄廠牌、規格、爐號、數量與到場日期。
- **文件審查** — 核對出廠證明、型式認可與材料報告。
- **抽樣送驗** — 安排取樣、試驗項目及報告到期日。
- **安裝追溯** — 關聯批次與棟別、樓層、柱牆及接頭數量。
- **扭力抽查** — 記錄現場抽查位置、工具與判定結果。
- **隔離召回** — 鎖定不合格批次及受影響區位並追蹤更換。

## 適合誰使用

- 品管工程師
- 材料管理員
- 鋼筋分包領班

## 運作流程

1. 批次收料
2. 審查文件
3. 安排送驗
4. 登錄安裝
5. 現場抽查
6. 判定處置

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
