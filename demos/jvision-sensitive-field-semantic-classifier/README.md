## 功能模組

- **敏感欄位掃描** — 依值域、名稱與使用語境找出疑似敏感欄位。
- **敏感類別判定** — 區分個資、財務、健康、商業機密與受管制資料。
- **敏感傳播追蹤** — 沿資料血緣辨識衍生欄位、複本與外流路徑。
- **政策適配建議** — 依分類、地區與用途匹配遮罩、加密和存取政策。
- **分類衝突審核** — 處理模型、既有標籤與資料擁有者判斷的差異。
- **保護措施套用** — 核准分類並同步標籤、權限及資料保護規則。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 掃描疑似敏感欄位
2. 判定敏感類別
3. 追蹤下游傳播
4. 匹配保護政策
5. 解決分類衝突
6. 核准政策套用
