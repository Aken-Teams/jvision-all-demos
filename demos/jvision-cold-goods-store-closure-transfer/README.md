# 閉店冷藏品移轉台

> 在門市停電、故障或臨時閉店時，盤點冷藏商品的效期、溫層與箱數，協調接收店容量、移轉交接及可售判定，避免重複報廢或狀態不明上架。

在門市停電、故障或臨時閉店時，盤點冷藏商品的效期、溫層與箱數，協調接收店容量、移轉交接及可售判定，避免重複報廢或狀態不明上架。

**產業別：**零售電商　|　**系統類型：**pos-frontdesk

## 功能模組

- **閉店事件** — 啟動移轉範圍
- **冷品盤點** — 記錄溫層效期
- **容量媒合** — 尋找接收空間
- **移轉交接** — 追蹤箱件流向
- **到店點收** — 核對接收差異
- **可售判定** — 決定上架報廢

## 適合誰使用

- 門市店長
- 區域營運員
- 食品安全人員

## 運作流程

1. 啟動事件
2. 盤點冷品
3. 媒合容量
4. 裝運交接
5. 到店驗收
6. 判定可售

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
