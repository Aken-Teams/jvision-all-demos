# 可專利性論證助手

> 逐項比對專利請求項與前案特徵，形成可專利性論證並支援申請決策。

逐項比對專利請求項與前案特徵，形成可專利性論證並支援申請決策。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **請求項解析器** — 拆分獨立項與附屬項中的技術特徵及關係。
- **前案檢索策略** — 依技術概念、分類號、申請人與時間建立檢索式。
- **特徵逐項比對** — 將每項請求特徵對照前案段落、圖式與揭露程度。
- **新穎性論證** — 辨識單一前案未完整揭露的差異特徵。
- **進步性推演** — 分析組合動機、技術偏見與非顯而易見效果。
- **申請決策建議** — 比較保護範圍、核准機率與修改方案後提出建議。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 拆解請求項特徵
2. 建立前案集合
3. 完成逐項比對
4. 形成新穎性論證
5. 推演進步性攻防
6. 核定申請策略

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
