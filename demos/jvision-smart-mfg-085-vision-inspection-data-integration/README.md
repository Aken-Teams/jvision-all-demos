# AOI/AVI 設備數據整合平台（Vision Inspection Data Integration）

> 從異常到改善的品質閉環與追溯稽核

AOI/AVI 設備數據整合平台（Vision Inspection Data Integration）提供多機台數據匯入、離線複判站管理、缺陷影像資料庫。品保部依「多站數據匯入→統一格式轉換→離線複判→數據回饋→良率分析」推進作業，優先解決「不同廠牌AOI數據格式不一」，製程工程部則以複判效率與跨站數據整合完整度確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 品保部
- 製程工程部
- 設備工程部

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉

## 導入效益

- 批號追溯時間：184分鐘 → **15分鐘**
- 客訴平均關案：22天 → **9.4天**
- 改善驗證率：61% → **92%**
- 重複不良率：6% → **2%**
