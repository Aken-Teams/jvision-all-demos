# AOI/AVI 設備數據整合預警塔

整合多站別、多品牌AOI/AVI設備之檢測數據與影像，提供離線複判與統一管理平台。

- 原始系統：AOI/AVI 設備數據整合平台（Vision Inspection Data Integration）
- 產業分類：智慧製造｜品質管理
- 使用部門：品保部、製程工程部、設備工程部
- 工作流程：多站數據匯入→統一格式轉換→離線複判→數據回饋→良率分析
- AI 應用：跨機台缺陷分類統一化、複判優先序建議
- 主要 KPI：複判效率、跨站數據整合完整度、誤判率下降幅度
- 代表產品：Koh Young KSMART、CyberOptics、Mirtec
