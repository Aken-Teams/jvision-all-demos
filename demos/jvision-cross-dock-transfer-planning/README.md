# 越庫轉運波次規劃台

> 協助物流中心依到貨車次、出貨路線、月台容量與轉運時限規劃越庫波次，減少貨物落地等待、錯接路線及尖峰月台壅塞。

協助物流中心依到貨車次、出貨路線、月台容量與轉運時限規劃越庫波次，減少貨物落地等待、錯接路線及尖峰月台壅塞。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **到貨看板** — 掌握預計抵達車次與貨量
- **路線配對** — 將貨件匹配後段配送路線
- **波次規劃** — 建立卸貨、分流與裝車節奏
- **月台配置** — 分派進出車次作業月台
- **例外處理** — 處理延誤、錯線與滯留貨件
- **轉運績效** — 分析停留時間及銜接效率

## 適合誰使用

- 轉運主管
- 運務調度員
- 月台領班

## 運作流程

1. 彙整到貨
2. 配對路線
3. 編排波次
4. 配置月台
5. 排除例外
6. 檢討績效

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
