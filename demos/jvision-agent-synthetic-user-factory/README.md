## 功能模組

- **角色原型建模** — 定義職務、背景知識、權限與使用情境。
- **語氣變體設計** — 組合正式、急迫、含糊或對抗等表達風格。
- **行為策略生成** — 設定耐心、探索傾向、犯錯模式與決策偏好。
- **任務旅程編排** — 把業務目標拆成多輪互動、工具呼叫與轉折。
- **模擬群體運行** — 並行驅動多種合成使用者與待測 Agent 對話。
- **覆蓋缺口評估** — 比對驗收規則，找出未涵蓋角色與失敗行為。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 建立角色
2. 調整語氣
3. 設定行為
4. 編排旅程
5. 批次模擬
6. 確認覆蓋
