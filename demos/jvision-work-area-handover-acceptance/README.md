# 樓層工作面移交台

> 依樓層與區域建立前後工班的工作面移交標準，逐項確認乾燥度、清潔、管線收整、基面品質及成品狀態，以雙方照片和簽認形成責任界線，未合格區域不得排入接續施工。

依樓層與區域建立前後工班的工作面移交標準，逐項確認乾燥度、清潔、管線收整、基面品質及成品狀態，以雙方照片和簽認形成責任界線，未合格區域不得排入接續施工。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **工作面總覽** — 依棟別、樓層與區域查看移交狀態。
- **移交申請** — 選擇接續工種並產生條件清單。
- **前序自檢** — 提交清潔、基面與成品現況佐證。
- **聯合點收** — 由交接雙方逐項確認或登錄缺失。
- **缺失改善** — 追蹤修復責任、期限與複查結果。
- **工作面放行** — 雙方簽認後開放接續工班進場。

## 適合誰使用

- 工地工程師
- 前序工班領班
- 接續工班領班

## 運作流程

1. 選定移交區域
2. 提出移交申請
3. 完成前序自檢
4. 辦理聯合點收
5. 改善未合格項
6. 簽認工作面放行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
