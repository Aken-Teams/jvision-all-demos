# 公車場站發車管制台

> 供客運場站依班表、車輛可用狀態與駕駛報到情形安排發車，處理缺車、缺勤、誤點及臨時換車，保留班次異常與調度決策紀錄。

供客運場站依班表、車輛可用狀態與駕駛報到情形安排發車，處理缺車、缺勤、誤點及臨時換車，保留班次異常與調度決策紀錄。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **場站總覽** — 顯示待發班次、車輛、人員與異常。
- **班次序列** — 依時間排列路線班次及月台。
- **車輛配置** — 分派營運車、備援車與換車安排。
- **駕駛報到** — 確認報到、資格、工時與代班狀態。
- **異常調度** — 處理缺車、缺勤、誤點與回復方案。
- **準點分析** — 檢視路線、時段及異常原因分布。

## 適合誰使用

- 站務調度員
- 車隊主管
- 駕駛領班

## 運作流程

1. 載入班表
2. 確認車況
3. 核對人員
4. 完成配車
5. 處理異常
6. 檢討準點

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
