# 戶外堆場尋料調位台

> 供鋼構與板金廠以區、排、層管理大型構件和鋼板位置，記錄天車移位、壓料關係與出貨優先序，避免找料翻堆及拿錯構件。

供鋼構與板金廠以區、排、層管理大型構件和鋼板位置，記錄天車移位、壓料關係與出貨優先序，避免找料翻堆及拿錯構件。

**產業別：**倉儲物流　|　**系統類型：**warehouse-wms

## 功能模組

- **堆場地圖** — 查看區排層位置
- **入場定位** — 分配可放區位
- **移位回報** — 更新天車搬移
- **壓料關係** — 顯示上下堆疊
- **翻堆任務** — 安排吊運順序
- **出場點交** — 核對構件車次

## 適合誰使用

- 堆場管理員
- 天車操作員

## 運作流程

1. 材料入場
2. 指派區位
3. 天車移位
4. 出貨尋料
5. 翻堆備料
6. 裝車點交

## 導入效益

- 揀貨作業工時：7小時/日 → **2小時/日**
- 庫存準確率：88% → **99%**
- 出貨延遲率：9% → **2%**
- 盤點工時：16小時/月 → **3小時/月**
