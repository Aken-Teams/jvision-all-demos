# 工地緊急演練管理台

> 規劃火災、墜落、侷限空間等工地情境，分派通報、疏散與救援角色，記錄各節點耗時、觀察缺失及改善複驗，讓演練成果不再只剩簽到與照片。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **演練計畫** — 安排情境、日期、區域與目標。
- **應變腳本** — 設定事件節點與預期處置。
- **角色編組** — 分派指揮、通報、疏散及救援。
- **現場紀錄** — 登錄各節點時間與實際動作。
- **演練檢討** — 彙整觀察、落差及改善建議。
- **改善複驗** — 追蹤責任事項至驗證關閉。

## 適合誰使用

- 職安人員
- 工地主任
- 承攬商主管

## 運作流程

1. 建立計畫
2. 編排腳本
3. 配置角色
4. 執行紀錄
5. 召開檢討
6. 完成複驗

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
