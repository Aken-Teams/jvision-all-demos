# 採購申請與電子簽核系統

> 供應商協同、詢比議價到交期風險控管

採購申請與電子簽核系統提供線上請購單建立、依金額/類別動態簽核路徑、行動裝置簽核支援。採購部依「建立請購單 → 系統判定簽核路徑 → 逐層簽核 → 核准轉採購 → 軌跡歸檔」推進作業，優先解決「紙本簽核流程延誤採購時效」，各用料部門則以簽核平均時效與逾時簽核占比確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**採購供應鏈　|　**系統類型：**SRM 採購供應商管理

## 功能模組

- **供應商管理** — 建檔、分級與績效評分
- **詢報價協作** — 線上詢價、比價與議價
- **採購訂單** — 請購、下單與交期追蹤
- **交期風險** — 缺料預警與到貨監控
- **供應商品質** — 進料檢驗與 SCAR 改善
- **綠色採購** — ESG 評分與永續採購

## 適合誰使用

- 採購部
- 各用料部門
- 財務部

## 運作流程

1. 待詢價
2. 比價中
3. 待核准
4. 驗收完成

## 導入效益

- 採購前置時間：12天 → **5.3天**
- 準時到貨率：85% → **96%**
- 缺料預警覆蓋：39% → **86%**
- 議價作業工時：8.5小時/週 → **2小時/週**
