**產業別：**生產製造　|　**系統類型：**esg-energy

## 功能模組

- **電價碳強度時帶** — 整合動態電價與電網碳強度，標示未來高成本時段。
- **生產負載排程** — 呈現工單、設備、換線與各時段能源負載。
- **交期產能約束** — 設定訂單交期、設備能力、人力與不可移動製程限制。
- **低碳排程最佳化** — 產生兼顧成本、碳排、準交率與產能的候選排程。
- **排程情境比較** — 比較原排程與候選方案的費用、碳排及營運風險。
- **排程執行 Agent** — 監測電價變動，提出重排建議並在核准後同步製造系統。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 讀取價格與碳訊號
2. 檢視生產負載
3. 鎖定營運約束
4. 產生低碳排程
5. 評估排程風險
6. 核准並同步排程

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
