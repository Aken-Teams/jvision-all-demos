# 回頭車貨量媒合排程台

> 集中空返車的回程路線、可用時窗、車型載重與司機工時，將臨時貨源與可行車次配對，試算繞行成本及毛利後完成調度承諾，降低空駛率。

集中空返車的回程路線、可用時窗、車型載重與司機工時，將臨時貨源與可行車次配對，試算繞行成本及毛利後完成調度承諾，降低空駛率。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **空車看板** — 查看路線時窗與剩餘容量
- **貨源需求** — 登錄起訖貨量與限制
- **媒合推薦** — 篩選可行車貨組合
- **繞行試算** — 比較里程成本與報價
- **調度鎖定** — 確認司機時窗與裝卸點
- **空駛分析** — 追蹤利用率和實際毛利

## 適合誰使用

- 車隊調度
- 業務人員
- 運輸主管

## 運作流程

1. 發布空車
2. 建立貨源
3. 篩選媒合
4. 試算毛利
5. 鎖定車次
6. 檢討成效

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
