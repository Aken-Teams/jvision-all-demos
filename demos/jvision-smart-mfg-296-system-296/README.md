# 經營計畫管理系統

> 把分散數據變成可下鑽、可決策的經營洞察

經營計畫管理系統提供年度經營目標展開與分解、部門行動方案與時程規劃、計畫執行進度儀表板。總經理室依「目標訂定 → 計畫展開 → 部門任務分派 → 執行追蹤 → 定期檢討 → 計畫修正」推進作業，優先解決「經營計畫流於形式未落地追蹤」，經營企劃部則以經營目標達成率與行動方案準時完成率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**經營管理　|　**系統類型：**BI 商業智慧

## 功能模組

- **經營儀表板** — 關鍵指標即時總覽
- **趨勢分析** — 多維度趨勢與比較
- **指標下鑽** — 逐層鑽取到明細
- **平衡計分卡** — 策略目標與 KPI 對齊
- **AI 洞察** — 自動發現異常與機會
- **報表匯出** — 排程報表與分享

## 適合誰使用

- 總經理室
- 經營企劃部
- 各事業處

## 運作流程

1. 待釐清
2. 改善中
3. 核定確認
4. 已解除

## 導入效益

- 報表產出工時：17小時 → **1小時**
- 異常發現時效：2.9天 → **1天**
- 決策資料覆蓋：57% → **86%**
- 跨部門對齊：58% → **90%**
