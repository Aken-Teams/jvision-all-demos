# 防水層閉水試驗放行台

> 依浴廁、陽台、屋頂及水箱等區域管理防水施作批次、閉水條件、水位觀測、滲漏缺失、複驗與保護層放行，確保試驗通過前不被後續工序覆蓋而失去修補機會。

依浴廁、陽台、屋頂及水箱等區域管理防水施作批次、閉水條件、水位觀測、滲漏缺失、複驗與保護層放行，確保試驗通過前不被後續工序覆蓋而失去修補機會。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **施作批次** — 記錄區域、防水材料、施工日期與作業班組。
- **試驗前檢** — 確認收頭、落水頭封堵與蓄水深度條件。
- **水位觀測** — 登錄起訖時間、水位與期間巡查結果。
- **滲漏定位** — 標示漏水位置、影響樓層及可能原因。
- **修補複驗** — 追蹤修補工法與再次閉水結果。
- **覆蓋放行** — 合格後核准保護層、貼磚或回填施工。

## 適合誰使用

- 品管工程師
- 防水分包領班
- 監造工程師

## 運作流程

1. 申報批次
2. 試驗前檢
3. 執行閉水
4. 查驗滲漏
5. 修補複驗
6. 核准覆蓋

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
