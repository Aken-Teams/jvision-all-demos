# 工地棄料分類清運台

> 依工區與責任工班登錄營建棄料種類、估計量、堆置位置與清運期限，安排容器及合法清運批次，追蹤混料重分、場地占用與費用歸屬，避免堆滿才臨時叫車。

依工區與責任工班登錄營建棄料種類、估計量、堆置位置與清運期限，安排容器及合法清運批次，追蹤混料重分、場地占用與費用歸屬，避免堆滿才臨時叫車。

**產業別：**營建工程　|　**系統類型：**warehouse-wms

## 功能模組

- **棄料申報** — 記錄來源工班、種類、估計量與產生區域。
- **分類判定** — 依處理方式判定可回收、一般或特殊棄料。
- **堆置配置** — 查看各堆置區容量、容器及消防通道影響。
- **清運排程** — 合併需求並安排車次、容器與清運單位。
- **數量核對** — 登錄裝載量、磅重、趟次與差異原因。
- **責任核帳** — 依來源與混料事件分攤清運及重分費用。

## 適合誰使用

- 工地主任
- 環保工程師
- 清運調度員

## 運作流程

1. 申報棄料產生
2. 確認分類方式
3. 配置堆置空間
4. 安排清運車次
5. 核對清運數量
6. 結算責任費用

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
