# 契約工期事件歸責台

> 將停工指示、業主變更、天候、管線障礙等事件與契約條款、通知期限、日報證據及受影響排程活動連結，逐案研判責任與可展延天數，讓工期屆滿前即可形成送審主張及待補證清單。

**產業別：**營建工程　|　**系統類型：**legal-case

## 功能模組

- **事件登錄** — 記錄事件類型、期間、位置與影響描述。
- **條款檢核** — 連結契約依據、通知期限與舉證要求。
- **證據清單** — 彙整公文、日報、照片與會議紀錄。
- **排程影響** — 連結受影響活動並標示關鍵路徑關係。
- **責任研判** — 區分業主、承商、第三方與不可抗力責任。
- **展延送審** — 產出事件時序、天數主張與附件目錄。

## 適合誰使用

- 合約工程師
- 排程工程師
- 專案經理

## 運作流程

1. 即時登錄事件
2. 檢核通知義務
3. 蒐集同期證據
4. 分析排程影響
5. 研判責任天數
6. 編製展延文件

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
