# 現場圖說紅線整併台

> 集中收集各工區紙本或數位紅線註記，依圖號、位置與專業整併衝突內容，追蹤現場查證及設計確認，逐步形成可信竣工圖底稿。

集中收集各工區紙本或數位紅線註記，依圖號、位置與專業整併衝突內容，追蹤現場查證及設計確認，逐步形成可信竣工圖底稿。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **紅線收件** — 依圖號匯入現場註記
- **圖面套合** — 疊合各來源紅線內容
- **衝突辨識** — 標示同位置矛盾註記
- **現場查證** — 派員確認實際施作
- **整併核定** — 決定正式竣工內容
- **竣工底稿** — 輸出可繪製圖面資料

## 適合誰使用

- 現場工程師
- BIM工程師
- 竣工圖繪製員

## 運作流程

1. 提交紅線
2. 分類定位
3. 套合比對
4. 現場查證
5. 核定內容
6. 發布底稿

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
