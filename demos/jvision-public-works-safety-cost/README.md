# 公共工程職安費計價台

> 依公共工程契約項目管理安全衛生設施的數量、設置期間、現場照片、監造查驗與估驗金額，避免職安費用有施作卻因證據不足無法計價。

依公共工程契約項目管理安全衛生設施的數量、設置期間、現場照片、監造查驗與估驗金額，避免職安費用有施作卻因證據不足無法計價。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **契約項目** — 拆解職安費編碼、單位與計價規則
- **設施設置** — 記錄安全設施位置、數量與照片
- **使用期間** — 計算按月或按日計價的設置時間
- **監造查驗** — 追蹤查驗結果與補正要求
- **當期計量** — 依規則試算本期可申報數量
- **估驗附件** — 彙整明細、照片與簽認表單

## 適合誰使用

- 職安人員
- 工務人員
- 估驗計價人員

## 運作流程

1. 建立計價規則
2. 登錄現場設置
3. 蒐集履約證據
4. 申請監造查驗
5. 核算當期金額
6. 提交估驗附件

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
