# 沖壓件毛刺檢測系統

> 透過擬真輪廓影像與量測資料，辨識沖壓件邊緣毛刺的位置、高度及超規程度，協助檢驗員完成複判、分級與批次處置，並追蹤模具刃口、沖次及材料對毛刺的影響，及早安排修模並避免組裝刮傷。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **毛刺品質總覽** — 顯示產線超規率、毛刺高度分布、重點料號與待處理批次。
- **輪廓量測工作台** — 沿零件邊緣呈現毛刺位置、高度、規格線與局部放大影像。
- **缺陷分級判定** — 依料號規格將毛刺分為可接受、需去毛刺、重工或報廢。
- **批次處置管理** — 記錄抽驗結果、影響數量，以及隔離、重工、放行等處置狀態。
- **刃口修模建議** — 將毛刺位置映射至模具刃口，建立研磨或更換零件的建議清單。
- **毛刺趨勢分析** — 比較沖次、材料、穴位與修模前後的毛刺高度及超規率。

## 適合誰使用

- 品保檢驗員
- 模具工程師
- 製程工程師與品保主管

## 運作流程

1. 查看超規概況
2. 複核邊緣輪廓
3. 執行缺陷分級
4. 決定批次處置
5. 提出修模方案
6. 驗證改善趨勢

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
