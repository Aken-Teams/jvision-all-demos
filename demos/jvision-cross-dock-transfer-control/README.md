# 越庫轉運銜接管理台

> 依到車批次、卸貨月台、轉運路線與截單時間安排越庫貨物銜接，協助物流中心降低落地等待、錯接班次及轉運延誤。

依到車批次、卸貨月台、轉運路線與截單時間安排越庫貨物銜接，協助物流中心降低落地等待、錯接班次及轉運延誤。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **到車看板** — 呈現預計到車與延誤批次。
- **月台配置** — 安排卸貨月台及作業時窗。
- **貨件拆併** — 依目的線路建立轉運波次。
- **班次銜接** — 檢查截單與發車時間餘裕。
- **滯留處理** — 管理未接、錯接與破損貨件。
- **轉運績效** — 分析停留時間與路線銜接率。

## 適合誰使用

- 轉運調度員
- 月台主管
- 客服人員

## 運作流程

1. 接收到車預報
2. 配置卸貨月台
3. 建立轉運波次
4. 確認班次餘裕
5. 處理滯留件
6. 檢討轉運績效

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
