# 央廚備料損耗管制台

> 協助連鎖餐飲中央廚房依門市需求展開備料計畫，管理食材解凍、分切、醃製、出成率與報廢原因，並比較標準耗用及實際損耗，讓生產主管在出貨前掌握缺料與異常批次。

協助連鎖餐飲中央廚房依門市需求展開備料計畫，管理食材解凍、分切、醃製、出成率與報廢原因，並比較標準耗用及實際損耗，讓生產主管在出貨前掌握缺料與異常批次。

**產業別：**餐飲旅宿　|　**系統類型：**erp

## 功能模組

- **需求展開** — 彙整門市需求並換算原料與半成品數量。
- **批次排程** — 安排解凍、分切、醃製及包裝時段。
- **秤重回報** — 記錄投入量、良品量與工序損耗。
- **異常處理** — 追查低出成率、污染與規格偏差。
- **成品撥交** — 核對批號、效期及門市配送數量。
- **損耗分析** — 比較品項、班別與工序的耗損差異。

## 適合誰使用

- 央廚生產主管
- 備料領班
- 成本會計

## 運作流程

1. 展開需求
2. 建立批次
3. 回報工序
4. 處置異常
5. 確認撥交
6. 檢討成本

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
