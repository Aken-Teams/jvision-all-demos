# 網路監控系統（NMS）

> 服務工單、資產到即時監控的 IT 維運

網路監控系統（NMS）提供設備可用性與效能監控、頻寬流量分析、拓樸圖自動繪製。資訊部依「設備納管→持續輪詢監測→異常告警→通知網管→現場排除→事件歸檔」推進作業，優先解決「網路斷線影響產線停機」，網管人員則以網路可用率與平均故障排除時間確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**資訊科技　|　**系統類型：**IT 維運管理平台

## 功能模組

- **服務工單** — 事件/請求工單管理
- **資產管理** — IT 資產與軟體授權
- **即時監控** — 系統/網路健康監控
- **告警事件** — 告警彙整與分派
- **變更發布** — 變更與發布管理
- **服務報表** — SLA 與可用率報表

## 適合誰使用

- 資訊部
- 網管人員
- 產線設備維護部

## 運作流程

1. 已受理
2. 處理中
3. 使用者確認
4. 已關閉

- 系統可用率：99% → **95%**
- SLA達成率：85% → **92%**
- 資產盤點工時：20小時/月 → **4.2小時/月**
