# 工地吊裝排程協調台

> 協調塔吊、移動式吊車、吊掛區域、工班與材料到場時段，呈現吊裝衝突、重量限制、前置檢查及臨時改期，避免關鍵設備閒置與工序互卡。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **吊裝行事曆** — 查看設備與區域時段
- **需求申請** — 登錄吊物與作業需求
- **能力檢核** — 檢查載重及作業半徑
- **衝突處理** — 協調工班與區域重疊
- **前置確認** — 核對人員及文件狀態
- **執行紀錄** — 登錄完成與延誤原因

## 適合誰使用

- 工地主任
- 吊裝工程師
- 工班領班

## 運作流程

1. 提出需求
2. 檢核能力
3. 協調排程
4. 確認前置
5. 執行吊裝
6. 檢討延誤

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
