# 病理檢體外送交接台

> 將外送檢體、申請單、容器與運送箱逐件勾稽，記錄封箱、交運、實驗室簽收及報告回傳節點，讓漏裝、錯標或未回報告可快速定位。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **逐件勾稽** — 核對檢體申請單
- **封箱批次** — 建立箱件關係
- **承運交接** — 保存雙方簽認
- **到件驗收** — 記錄實驗室差異
- **報告追蹤** — 監看回傳時限
- **異常結案** — 調查漏件錯標

## 適合誰使用

- 檢體收件員
- 外送人員
- 委外檢驗窗口

## 運作流程

1. 建立清冊
2. 封箱覆核
3. 交付承運
4. 外院驗收
5. 追蹤報告
6. 異常結案

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
