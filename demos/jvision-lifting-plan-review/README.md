# 起重吊掛計畫審查台

> 集中編製與審查重大吊掛計畫，核對吊物重量、起重機載重表、站位半徑、吊具證明、指揮人員與現場條件，確保核定版本才能排入施工。

集中編製與審查重大吊掛計畫，核對吊物重量、起重機載重表、站位半徑、吊具證明、指揮人員與現場條件，確保核定版本才能排入施工。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **吊掛案件** — 查看各吊裝計畫與審查進度。
- **工況計算** — 登錄重量、半徑及設備能力。
- **證明附件** — 彙整載重表、吊具與人員證照。
- **站位配置** — 標示起重機站位、路徑與管制區。
- **聯合審查** — 逐項提出意見並追蹤補正。
- **核定發布** — 鎖定核准版本與施工限制。

## 適合誰使用

- 吊裝工程師
- 職安人員
- 工地主任

## 運作流程

1. 建立吊掛案件
2. 完成能力核算
3. 備齊審查附件
4. 確認現場配置
5. 處理審查意見
6. 核定施工版本

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
