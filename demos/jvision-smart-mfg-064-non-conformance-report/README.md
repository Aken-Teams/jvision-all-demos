# NCR（Non-Conformance Report）

> 從異常到改善的品質閉環與追溯稽核

NCR（Non-Conformance Report）提供不合格登錄、隔離區管理、判定會簽（讓步接受/報廢/重工）。品保部依「異常發現→隔離標示→判定會簽→處置執行→結案歸檔」推進作業，優先解決「不良品混料風險」，生產部則以NCR結案時效與重工率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 品保部
- 生產部
- 倉儲部

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉

## 導入效益

- 批號追溯時間：184分鐘 → **15分鐘**
- 客訴平均關案：22天 → **9.4天**
- 改善驗證率：61% → **92%**
- 重複不良率：6% → **2%**
