# 道路占用許可管制台

> 管理吊裝、灌漿及材料卸貨所需的道路占用申請，串接時段、範圍、交維配置與展延文件，避免許可尚未核准或已逾期仍安排進場作業。

管理吊裝、灌漿及材料卸貨所需的道路占用申請，串接時段、範圍、交維配置與展延文件，避免許可尚未核准或已逾期仍安排進場作業。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **占用行事曆** — 查看核准時段、路段及施工用途。
- **申請建檔** — 填報範圍、車道數與作業需求。
- **交維整備** — 核對交維圖、標誌、人力及附件。
- **許可追件** — 追蹤送件、補正、核准與有效期限。
- **當日放行** — 確認許可與現場條件後開放作業。
- **展延結案** — 處理改期、展延、撤場及成果存證。

## 適合誰使用

- 工務工程師
- 職安人員
- 運輸協調員

## 運作流程

1. 提出需求
2. 整備交維
3. 送件追蹤
4. 發布時窗
5. 現場放行
6. 撤場結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
