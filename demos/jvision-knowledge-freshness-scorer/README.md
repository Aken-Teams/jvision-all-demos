# 知識新鮮度評分器

> 依來源、擁有者、變更與回饋評估知識新鮮度，避免使用過期內容。

依來源、擁有者、變更與回饋評估知識新鮮度，避免使用過期內容。

**產業別：**企業協作　|　**系統類型：**analytics-bi

## 功能模組

- **新鮮度評分板** — 呈現文件分數、衰退速度與各項評分因子的影響。
- **來源可信度矩陣** — 比較正式制度庫、協作空間、郵件與工單等來源可靠度。
- **知識責任地圖** — 對應內容擁有者、覆核人與待確認的責任缺口。
- **內容變更雷達** — 偵測上游政策、系統與相關文件變更造成的內容落差。
- **使用回饋診斷** — 彙整搜尋點擊、負評、無效回覆與客服修正訊號。
- **更新處置中心** — 建立重審、改版、封存或降權任務並追蹤處置期限。

## 適合誰使用

- 知識工作者
- 主管
- 客服

## 運作流程

1. 檢視分數分布
2. 校準來源權重
3. 確認內容責任
4. 分析變更影響
5. 核對使用回饋
6. 執行更新處置

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
