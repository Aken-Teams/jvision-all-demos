# 動態促銷組合設計助手

> 運用擬真的交易、毛利與庫存資料，協助行銷人員設計滿額、加價購及商品組合活動，預覽客群反應與利潤風險，完成審核、排程和活動成效復盤。

運用擬真的交易、毛利與庫存資料，協助行銷人員設計滿額、加價購及商品組合活動，預覽客群反應與利潤風險，完成審核、排程和活動成效復盤。

**產業別：**零售電商　|　**系統類型：**sales-crm

## 功能模組

- **促銷機會雷達** — 依銷售趨勢、庫存壓力與節慶標籤列出適合促銷的商品機會。
- **組合活動設計** — 設定任選、滿額、加價購與搭贈規則，視覺化建立活動內容。
- **目標客群配置** — 選擇模擬客群、通路和門市範圍，預覽活動觸及規模。
- **毛利風險試算** — 試算折扣成本、預估銷量、毛利底線及可能的商品排擠效應。
- **活動審核排程** — 呈現跨部門審核節點、修改意見與各通路上線時程。
- **促銷成效復盤** — 比較活動前後指標、客群反應和商品組合表現，整理改善建議。

## 適合誰使用

- 行銷企劃
- 商品經理
- 財務審核人員
- 通路營運主管

## 運作流程

1. 辨識促銷機會
2. 建立活動組合
3. 圈選目標客群
4. 試算財務影響
5. 審核並安排上線
6. 檢討活動成效

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
