# 鄰房現況會勘存證台

> 供開工前依鄰房戶別建立牆面、地坪、門窗與既有裂縫紀錄，管理住戶會勘、拒絕入戶、照片定位及簽認文件，施工後發生損害爭議時可快速調閱比對。

供開工前依鄰房戶別建立牆面、地坪、門窗與既有裂縫紀錄，管理住戶會勘、拒絕入戶、照片定位及簽認文件，施工後發生損害爭議時可快速調閱比對。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **鄰房名冊** — 管理門牌、戶別、聯絡窗口與入戶狀態。
- **會勘排程** — 安排通知、改期、陪同人員與拒訪處理。
- **缺陷標註** — 依空間及構件記錄裂縫、滲水與變形。
- **定位影像** — 將照片連結至樓層、房間、牆面與方向。
- **住戶簽認** — 產出現況清冊並追蹤簽認或異議。
- **爭議比對** — 並列施工前紀錄與申訴現況供鑑定。

## 適合誰使用

- 工務工程師
- 第三方鑑定人
- 法務人員

## 運作流程

1. 建立鄰房名冊
2. 安排入戶會勘
3. 標註既有缺陷
4. 完成影像定位
5. 取得文件簽認
6. 建立爭議比對

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
