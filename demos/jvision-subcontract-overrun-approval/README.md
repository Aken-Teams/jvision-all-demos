# 分包超約預警核准台

> 整合分包原約、核准變更、累計估驗、未估應付與待議價金額，預測超約並攔截未授權請款或拆單，要求完成追加預算核准。

整合分包原約、核准變更、累計估驗、未估應付與待議價金額，預測超約並攔截未授權請款或拆單，要求完成追加預算核准。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **合約餘額** — 查看原約變更與已估
- **完工預測** — 估算未完工程總成本
- **超約預警** — 標示即將超額合約
- **拆單偵測** — 辨識規避授權的請款
- **超約核准** — 確認原因與預算來源
- **責任分析** — 比較工種與承辦超支

## 適合誰使用

- 成本工程師
- 合約管理員
- 專案經理

## 運作流程

1. 彙整承諾
2. 預測超約
3. 說明原因
4. 查核拆單
5. 主管核准
6. 更新額度

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
