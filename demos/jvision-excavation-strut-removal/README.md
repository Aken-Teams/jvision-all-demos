# 開挖支撐拆除放行台

> 管理地下工程各層支撐拆除前的樓板強度、回撐配置、防水完成面及監測判讀，將分區拆除順序、異常處置與技師核准集中呈現，避免條件未成熟即拆撐。

管理地下工程各層支撐拆除前的樓板強度、回撐配置、防水完成面及監測判讀，將分區拆除順序、異常處置與技師核准集中呈現，避免條件未成熟即拆撐。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **拆撐分區** — 以地下層及施工區標示支撐待拆、暫緩與完成狀態。
- **強度條件** — 登錄樓板試驗結果、養護天數與設計門檻。
- **回撐配置** — 核對回撐位置、數量、安裝照片及保留期限。
- **監測判讀** — 彙整人工匯入的位移數據與技師判讀結論。
- **異常處置** — 追蹤超限、滲水、裂縫及現場改善事項。
- **拆除放行** — 依分區記錄技師核准、限制條件與拆除順序。

## 適合誰使用

- 土木工程師
- 結構技師
- 工地主任

## 運作流程

1. 劃分拆撐區域
2. 登錄強度證明
3. 確認回撐完成
4. 提出監測判讀
5. 關閉拆前異常
6. 核准分區拆除

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
