# 保險理賠管理

> 受理、審核、風險到撥付的案件審查流程

從報案、文件、任務、準備金到付款的完整理賠管理展示把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**金融保險　|　**系統類型：**金融 / 保險案件系統

## 功能模組

- **案件受理** — 理賠/貸款案件建立
- **審核初核** — 文件審查與資格核對
- **風險評分** — 風險模型與評分
- **覆核核准** — 多層覆核與核決
- **撥付理算** — 理算與撥款作業
- **案件追溯** — 全程紀錄與稽核

## 適合誰使用

- 客戶服務專員
- 業務主管
- 法遵主管

## 運作流程

1. 建立保險理賠管理資料
2. 從報案、文件、任務、準備金到付款的完整理賠管理展示
3. 確認結果並完成留存

## 導入效益

- 案件平均處理：7.1天 → **3天**
- 風險檢出率：74% → **99%**
- 文件缺漏率：12% → **2.8%**
- 覆核作業工時：5小時/日 → **1小時/日**
