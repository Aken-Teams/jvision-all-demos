# 樓層材料限量叫料台

> 按棟別、樓層、工項與可堆置量控管材料叫料，合併重複需求並檢查現場餘料，避免超量配送、錯樓堆放及阻塞消防動線。

按棟別、樓層、工項與可堆置量控管材料叫料，合併重複需求並檢查現場餘料，避免超量配送、錯樓堆放及阻塞消防動線。

**產業別：**營建工程　|　**系統類型：**warehouse-wms

## 功能模組

- **樓層庫存** — 查看各區現有材料
- **叫料申請** — 提出工項用料需求
- **限量審核** — 檢查堆載與預算上限
- **需求合併** — 排除重複並整併配送
- **配送追蹤** — 記錄到樓與簽收
- **餘料退回** — 管理未用材料回收

## 適合誰使用

- 材料管理員
- 工務工程師
- 分包領班

## 運作流程

1. 盤點餘料
2. 提出叫料
3. 審核限量
4. 安排配送
5. 樓層簽收
6. 追蹤耗用

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
