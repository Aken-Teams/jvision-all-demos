# 客戶價值回顧產生器

> 將成果、節省與採用證據整理成可推動續約的客戶價值回顧。Turns outcomes, savings, and adoption evidence into renewal-ready customer value reviews.

將成果、節省與採用證據整理成可推動續約的客戶價值回顧。Turns outcomes, savings, and adoption evidence into renewal-ready customer value reviews.

**產業別：**客服管理　|　**系統類型：**analytics-bi

## 功能模組

- **回顧目標設定** — 選定 QBR 期間、受眾、商業目標與待證明的價值主張。
- **成果指標彙整** — 彙整效率、品質、營收與服務改善等成果指標。
- **價值量化工作台** — 將工時、成本避免與產能提升換算為可解釋價值。
- **採用進展敘事** — 把功能採用、團隊擴散與里程碑轉成清楚的成長故事。
- **QBR 故事編排** — 生成高層摘要、成果頁、風險頁與下一階段建議。
- **回顧行動承諾** — 確認會議結論、負責人與下季價值實現計畫。

## 適合誰使用

- 客戶成功主管
- CSM
- 客服主管

## 運作流程

1. 界定回顧主題
2. 確認成果數據
3. 量化客戶價值
4. 整理採用故事
5. 審閱 QBR 草稿
6. 確認後續承諾

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
