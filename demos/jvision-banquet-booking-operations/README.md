# 宴會訂席履約管理台

> 整合宴會廳檔期、桌數方案、菜單版本、訂金節點與跨部門交辦，協助業務、主廚及宴會主管同步掌握異動，降低撞期、漏收款與臨場執行錯誤。

整合宴會廳檔期、桌數方案、菜單版本、訂金節點與跨部門交辦，協助業務、主廚及宴會主管同步掌握異動，降低撞期、漏收款與臨場執行錯誤。

**產業別：**餐飲旅宿　|　**系統類型：**pos-frontdesk

## 功能模組

- **宴會檔期** — 檢視廳別占用與待確認訂席
- **方案報價** — 建立桌價、加購及折扣版本
- **菜單確認** — 管理菜色版本與特殊餐需求
- **訂金節點** — 追蹤訂金、尾款與逾期款項
- **跨部交辦** — 派發外場、廚房與工程任務
- **履約結案** — 核對實際桌數、耗用與毛利

## 適合誰使用

- 宴會業務
- 宴會主管
- 主廚

## 運作流程

1. 建立檔期
2. 製作報價
3. 確認菜單
4. 收取訂金
5. 執行交辦
6. 核算結案

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
