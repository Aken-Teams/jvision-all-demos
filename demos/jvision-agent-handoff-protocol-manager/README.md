**產業別：**資訊科技　|　**系統類型：**collaboration-pm

## 功能模組

- **交接鏈編排** — 設計上游、接收方與備援 Agent 的交接順序及相依關係。
- **交付物契約** — 定義每次交接必備欄位、格式、版本與資料敏感度。
- **驗收規則設計** — 設定完整性、一致性、品質門檻與接收逾時條件。
- **交接演練台** — 以測試任務模擬傳遞、拒收、補件與重送情境。
- **失敗回退策略** — 配置重試、回到前一 Agent、替代路徑或人工接管。
- **協定版本發布** — 完成差異審查與核准後發布具版本控制的交接協定。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 繪製交接鏈
2. 定義交付契約
3. 設定驗收條件
4. 執行交接演練
5. 配置失敗回退
6. 核准發布協定
