# 臨時設施責任交接台

> 管理施工便道、圍籬、洗車台、臨時排水與公共照明等設施的啟用、使用責任、維護區間及跨工班交接，清楚界定損壞、清潔和撤除由誰處理。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **設施台帳** — 登錄位置、用途、規格及服務範圍。
- **啟用檢查** — 確認安全、功能與現場照片。
- **責任配置** — 指定使用、巡查及修繕單位。
- **維護派工** — 追蹤損壞、清潔與改善事項。
- **現況交接** — 記錄移交前後狀態與責任切換。
- **撤除復原** — 確認拆除、清運及場地恢復。

## 適合誰使用

- 總務工程師
- 現場工程師
- 分包領班

## 運作流程

1. 設施建檔
2. 啟用查驗
3. 責任指派
4. 日常維護
5. 跨包交接
6. 撤除結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
