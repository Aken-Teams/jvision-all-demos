# 鋼構構件進場配對台

> 串聯鋼構構件編號、加工批次、裝車位置、運輸車次與吊裝區位，讓工地在卸車前核對當日吊裝順序及缺件，避免錯卸、翻找與構件堆置阻塞。

**產業別：**營建工程　|　**系統類型：**logistics-fleet

## 功能模組

- **構件清冊** — 管理構件編號、規格及吊裝區位。
- **裝車清單** — 記錄構件所在車次與裝載順序。
- **車次排程** — 安排出廠、到場窗口及卸貨位置。
- **到場配對** — 核對構件、車次與當日吊裝序。
- **異常處理** — 登錄錯車、缺件、損傷及改送。
- **吊裝銜接** — 確認卸車後的堆置或直接吊裝狀態。

## 適合誰使用

- 鋼構工程師
- 運輸調度員
- 吊裝領班

## 運作流程

1. 發布構件需求
2. 編製裝車清單
3. 安排運輸窗口
4. 執行到場配對
5. 處理缺錯構件
6. 銜接構件吊裝

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
