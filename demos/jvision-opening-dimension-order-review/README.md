**產業別：**營建工程　|　**系統類型：**procurement-srm

## 功能模組

- **逐樘門窗清冊** — 按棟別、樓層、戶別與編號管理每樘門窗。
- **圖面規格** — 顯示設計洞口、框料、開向、玻璃與五金需求。
- **現場丈量** — 輸入多點實測尺寸、垂直偏差與飾面預留。
- **差異檢核** — 自動標記尺寸、開向、數量及客變衝突。
- **異常確認** — 將超差項送設計、現場及廠商共同決定。
- **製作版下單** — 凍結核准數據並形成分批製作及交貨清單。

## 適合誰使用

- 現場工程師
- 門窗分包商
- 採購人員

## 運作流程

1. 建立逐樘清冊
2. 完成現場丈量
3. 執行差異檢核
4. 確認異常處置
5. 凍結製作版本
6. 發出正式訂單

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
