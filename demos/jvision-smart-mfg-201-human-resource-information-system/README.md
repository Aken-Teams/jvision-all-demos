# HRIS指揮台

企業人事主檔與組織資料的中央資料庫，作為所有人資子系統的資料來源與整合基礎。

- 原始系統：HRIS（Human Resource Information System）
- 產業分類：智慧製造｜人資管理
- 使用部門：人資部、行政部、各部門主管、稽核部、資訊部
- 工作流程：員工到職建檔 → 異動申請 → 主管簽核 → HR覆核 → 主檔更新 → 同步至薪資/考勤系統
- AI 應用：異常人事異動自動偵測、組織人力結構智慧分析建議
- 主要 KPI：資料正確率、異動處理時效、系統資料完整度、跨廠資料同步率
- 代表產品：SAP SuccessFactors、Workday HCM、鼎新 HR、104人資King、雲學堂旗下 HR 模組
