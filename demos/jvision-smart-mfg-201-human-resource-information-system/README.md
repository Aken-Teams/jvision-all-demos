# HRIS（Human Resource Information System）

> 出勤、薪資、招募到績效的人資全流程

HRIS（Human Resource Information System）提供員工基本資料與異動履歷管理、組織架構與職位對應、人事異動（調職、升遷、離職）簽核。人資部依「員工到職建檔 → 異動申請 → 主管簽核 → HR覆核 → 主檔更新 → 同步至薪資/考勤系統」推進作業，優先解決「各廠區人事資料分散、口徑不一」，行政部則以資料正確率與異動處理時效確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**HRIS 人力資源系統

## 功能模組

- **出勤差勤** — 打卡、請假與加班
- **薪資計算** — 薪資、勞健保與報稅
- **排班管理** — 智慧排班與工時控管
- **招募任用** — 職缺、面試與報到
- **教育訓練** — 課程、證照與紀錄
- **績效考核** — 目標設定與考核流程

## 適合誰使用

- 人資部
- 行政部
- 各部門主管

## 運作流程

1. 待處理
2. 主管確認
3. 人資執行
4. 歸檔完成

## 導入效益

- 薪資作業工時：42小時/月 → **7.8小時/月**
- 出勤異常處理：31分鐘 → **4.8分鐘**
- 招募到位天數：45天 → **26天**
- 表單簽核時效：2.9天 → **1.1天**
