# 工區進場條件檢核台

> 在工班與材料進場前，逐項確認前手完成、圖說核定、工作面淨空、臨水臨電及垂直運輸等條件，提早揭露阻礙並決定准予進場、改期或轉派其他區域。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **進場看板** — 顯示近期班組與工作面安排。
- **條件清單** — 依工種建立進場前檢核項目。
- **責任回報** — 由前手及支援單位提交完成證據。
- **障礙處置** — 指派未滿足條件的排除責任。
- **准入決策** — 決定進場、改期或轉派工作面。
- **待工分析** — 統計未備妥原因與影響工時。

## 適合誰使用

- 現場工程師
- 排程工程師
- 分包領班

## 運作流程

1. 排定進場
2. 發起檢核
3. 回報條件
4. 排除障礙
5. 核准進場
6. 檢討待工

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
