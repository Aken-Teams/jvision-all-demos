# 監造缺失複驗追蹤台

> 接收監造巡查或查驗提出的缺失，將照片、圖面位置、責任分包與改善標準綁在同一案件，安排現場複驗並保存退回原因，使營造端能掌握待銷項與逾期風險。

接收監造巡查或查驗提出的缺失，將照片、圖面位置、責任分包與改善標準綁在同一案件，安排現場複驗並保存退回原因，使營造端能掌握待銷項與逾期風險。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **監造缺失清單** — 彙整監造編號、分類、期限與目前處理狀態。
- **缺失定位** — 綁定棟樓層、軸線、空間、圖面標記與照片。
- **責任分派** — 指定責任分包、改善標準與預定完成日。
- **改善回報** — 提交改善說明、完工照片及無法處理原因。
- **複驗預約** — 整併可複驗案件並協調監造到場時段。
- **銷項紀錄** — 保存通過、退回、保留意見與正式簽認證據。

## 適合誰使用

- 監造工程師
- 品管工程師
- 分包工班領班

## 運作流程

1. 接收監造缺失
2. 補齊位置資訊
3. 派發改善責任
4. 提交改善成果
5. 辦理現場複驗
6. 完成正式銷項

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
