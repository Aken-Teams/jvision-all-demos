# 工地證照許可追蹤台

> 集中管理施工期間所需的申報、許可、證照與展延期限，依工程階段提示前置文件、送件進度及核准條件，降低停工風險。

集中管理施工期間所需的申報、許可、證照與展延期限，依工程階段提示前置文件、送件進度及核准條件，降低停工風險。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **許可清冊** — 列出工程所需申報與證照
- **工項關聯** — 設定許可與施工階段依賴
- **備件管理** — 彙整圖說、表單與證明文件
- **送件追蹤** — 記錄送件、收文及承辦窗口
- **補正處理** — 分派缺件並追蹤回覆期限
- **開工放行** — 確認核准條件與可施工範圍

## 適合誰使用

- 工務主任
- 專案工程師
- 專案經理

## 運作流程

1. 建立清冊
2. 關聯工項
3. 準備文件
4. 送件追蹤
5. 補正核准
6. 施工放行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
