# 駕駛疲勞風險排班器

> 依駕駛工時、路程與時段重排任務，降低疲勞駕駛事故風險。中文。

依駕駛工時、路程與時段重排任務，降低疲勞駕駛事故風險。中文。

**產業別：**企業協作　|　**系統類型：**logistics-fleet

## 功能模組

- **疲勞風險雷達** — 綜合連續工時、休息間隔、夜間任務與歷史風險評分。
- **路程負荷估算** — 估算里程、路況、駕駛時間及回程對疲勞的累積影響。
- **高風險時段檢查** — 標示深夜、清晨、尖峰及跨日任務的風險區間。
- **安全排班工作台** — 以休息規則與任務限制產生可執行的駕駛班表。
- **替班調度建議** — 在風險超標時推薦合適替班、任務交換或延後方案。
- **出車安全核准** — 針對高風險行程要求人工確認並發布最終派車安排。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 檢視風險分布
2. 評估路程負荷
3. 檢查危險時段
4. 產生安全班表
5. 協調替班方案
6. 核准發布班表

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
