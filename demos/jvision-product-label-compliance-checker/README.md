# 產品標示合規檢查器

> 比對包裝、說明書與數位頁面的法定標示要求，避免產品上市退件。

比對包裝、說明書與數位頁面的法定標示要求，避免產品上市退件。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **包裝版面檢查** — 辨識外盒、瓶身與標籤上的必備文字、符號及位置。
- **說明書條款核對** — 檢查警語、用途、成分、操作與責任資訊是否完整。
- **數位頁面掃描** — 比對官網、電商頁與電子標籤的公開資訊一致性。
- **市場語言矩陣** — 管理各銷售國家的語言、單位、圖示與在地化要求。
- **標示缺口比對** — 將法規義務映射至各載體，標出缺漏、衝突與過期內容。
- **上市放行清單** — 依市場與產品版本彙整整改項目及放行條件。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 選定產品與市場
2. 解析包裝標示
3. 核對說明書內容
4. 比對數位頁面
5. 補齊市場缺口
6. 核准上市放行

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
