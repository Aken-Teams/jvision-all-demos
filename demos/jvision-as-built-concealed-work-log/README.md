# 隱蔽工程封閉紀錄台

> 在天花、牆體、管道間與地下結構封閉前，依區域建立必拍點位、尺寸標註、查驗結果及定位參考，封閉後可由空間快速調閱內部現況，支援後續鑽孔、維修與責任查證。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **區域索引** — 依棟別、樓層、房間與牆面定位隱蔽範圍。
- **拍攝任務** — 列出全景、近照、尺寸及方向等必拍要求。
- **尺寸標註** — 在照片上標記基準線、深度及相對距離。
- **封閉查驗** — 核對施工品質、照片完整性與待改善事項。
- **封閉放行** — 完成簽認後鎖定區域紀錄並允許封板。
- **竣工調閱** — 由空間、系統或日期搜尋封閉前現況。

## 適合誰使用

- 機電工程師
- 品管工程師
- 維修接管人員

## 運作流程

1. 建立封閉區域
2. 設定拍攝要求
3. 完成現場紀錄
4. 執行封閉查驗
5. 核准區域封閉
6. 移交搜尋台帳

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
