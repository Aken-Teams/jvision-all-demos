# 染整布車在製尋料台

> 供染整廠追蹤每台布車的布批、重量、目前樓層、等待機台與移交時間，處理紙卡脫落及推錯區，降低找布和機台空等。

供染整廠追蹤每台布車的布批、重量、目前樓層、等待機台與移交時間，處理紙卡脫落及推錯區，降低找布和機台空等。

**產業別：**倉儲物流　|　**系統類型：**warehouse-wms

## 功能模組

- **布車看板** — 查看位置與工序
- **布批綁定** — 連結布車與批次
- **移動回報** — 更新樓層機台
- **在製尋料** — 查找急單布車
- **無主布車** — 處理標籤脫落
- **工序交接** — 確認收發重量

## 適合誰使用

- 染房領班
- 布車調度員

## 運作流程

1. 坯布上車
2. 派往機台
3. 布車移動
4. 機台接收
5. 異常尋料
6. 工序移交

## 導入效益

- 揀貨作業工時：7小時/日 → **2小時/日**
- 庫存準確率：88% → **99%**
- 出貨延遲率：9% → **2%**
- 盤點工時：16小時/月 → **3小時/月**
