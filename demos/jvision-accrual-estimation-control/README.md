# 費用預提估列管制台

> 彙整未到發票、未請款服務與跨期合約，讓會計依驗收進度建立預提估列、追蹤次月迴轉及實際發票差異，降低關帳漏列。

彙整未到發票、未請款服務與跨期合約，讓會計依驗收進度建立預提估列、追蹤次月迴轉及實際發票差異，降低關帳漏列。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **待估清單** — 彙整未到單據及跨期事項。
- **估列依據** — 保存合約、驗收與計算說明。
- **金額試算** — 依期間與進度計算預提金額。
- **分錄覆核** — 審查科目、部門及估列理由。
- **次月迴轉** — 安排自動迴轉與待沖狀態。
- **實際差異** — 比較發票金額並追蹤調整。

## 適合誰使用

- 總帳會計
- 部門經辦
- 財務主管

## 運作流程

1. 蒐集待估事項
2. 檢查估列依據
3. 試算預提金額
4. 覆核分錄
5. 執行次月迴轉
6. 核對實際帳單

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
