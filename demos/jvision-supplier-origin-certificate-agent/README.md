# 供應商產地證明追蹤 Agent

> 自動催收並驗證供應商產地證明，確保優惠申報所需證據持續完整有效。

自動催收並驗證供應商產地證明，確保優惠申報所需證據持續完整有效。

**產業別：**採購供應鏈　|　**系統類型：**legal-case

## 功能模組

- **待補證明清單** — 依訂單、料號與申報時程排列尚未取得的產地證明。
- **供應商催收中心** — 產生分級催收內容，追蹤供應商回覆與承諾交付日。
- **效期覆蓋檢查** — 比對證明有效期間、出貨日期與優惠申報適用區間。
- **證明內容驗證** — 核對出口商、品名、原產地、簽章與協定必要欄位。
- **異常聲明處理** — 識別補發、追溯、更正及供應商保留聲明的申報風險。
- **證據完整度台帳** — 彙整料號與訂單的有效證明覆蓋率及可申報狀態。

## 適合誰使用

- 國貿主管
- 報關人員
- 業務

## 運作流程

1. 盤點待補證明
2. 啟動分級催收
3. 核驗效期覆蓋
4. 審查證明內容
5. 處置異常聲明
6. 確認證據完整
