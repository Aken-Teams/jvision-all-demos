# 工地臨時設施管制台

> 管理施工期間圍籬、施工架、臨時用電、塔吊覆蓋區與工務所等臨時設施的配置申請、檢查紀錄、使用期限、改善事項及拆除回復。

管理施工期間圍籬、施工架、臨時用電、塔吊覆蓋區與工務所等臨時設施的配置申請、檢查紀錄、使用期限、改善事項及拆除回復。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **臨設配置** — 查看區域位置與狀態
- **設置申請** — 提報新設、移位或展延
- **安全檢查** — 執行分類檢點紀錄
- **改善追蹤** — 管理缺失與責任分包
- **期限管制** — 預警許可及使用到期
- **拆除回復** — 確認拆除與場地復原

## 適合誰使用

- 工地主任
- 職安人員
- 分包商工頭

## 運作流程

1. 盤點臨設配置
2. 提出設置申請
3. 執行安全檢查
4. 處理檢查缺失
5. 監控使用期限
6. 確認拆除回復

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
