# 隱藏專長發現器

> 從工作成果與跨系統貢獻辨識履歷未揭露的專長，活化內部人才。能。

從工作成果與跨系統貢獻辨識履歷未揭露的專長，活化內部人才。能。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **潛在技能雷達** — 從任務、作品與協作行為推測尚未登錄的能力。
- **貢獻證據探索** — 搜尋專案、知識庫、程式碼與業務成果中的技能線索。
- **職能圖譜對映** — 把非結構化貢獻映射至企業職能、熟練度與相鄰技能。
- **專長可信度評估** — 依成果品質、使用頻率、他人採用與時效計算可信度。
- **內部人才尋訪** — 依任務需求找出具備隱性專長且可投入的人選。
- **技能認證提案** — 邀請員工與主管確認證據，更新技能檔案與發展計畫。

## 適合誰使用

- L&D 主管
- 部門主管
- 員工

## 運作流程

1. 定義人才需求
2. 探索貢獻線索
3. 映射企業職能
4. 評估證據強度
5. 媒合內部人才
6. 確認技能檔案

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
