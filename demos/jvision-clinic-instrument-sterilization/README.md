**產業別：**醫療照護　|　**系統類型：**quality-qms

## 功能模組

- **器械組台帳** — 管理組別單件與數量
- **回收點交** — 記錄診間來源與污染狀態
- **接收清點** — 查核短少損壞與尖銳器
- **消毒批次** — 記錄清洗包裝與滅菌
- **效期隔離** — 攔截未完成或過期包
- **放行領用** — 核准回庫及診間取用

## 適合誰使用

- 診間助理
- 消毒室人員
- 護理主管

## 運作流程

1. 診間回收器械
2. 消毒室接收清點
3. 執行清洗包裝
4. 記錄滅菌結果
5. 覆核效期狀態
6. 放行回庫領用

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
