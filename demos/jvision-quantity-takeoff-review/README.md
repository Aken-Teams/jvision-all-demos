# 數量計算書覆核台

> 將數量計算式連結到圖號、樓層、構件與扣除規則，支援設計改版後差異重算及覆核註記，避免洞口漏扣、範圍重疊或重複計量。

將數量計算式連結到圖號、樓層、構件與扣除規則，支援設計改版後差異重算及覆核註記，避免洞口漏扣、範圍重疊或重複計量。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **計算書總覽** — 查看工項數量與狀態
- **圖面溯源** — 連結圖號範圍與構件
- **算式明細** — 呈現公式扣除與換算
- **版次比較** — 辨識改圖影響數量
- **覆核註記** — 記錄疑問與修正理由
- **數量簽認** — 發布採購報價基準

## 適合誰使用

- 數量估算師
- 成本工程師
- 設計工程師

## 運作流程

1. 建立範圍
2. 編製算式
3. 系統檢查
4. 圖面覆核
5. 修正數量
6. 正式簽認

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
