# 交屋鑰匙點交追蹤台

> 按戶別、門鎖與鑰匙用途管理套數、標籤、借還、保管及住戶點交，於交屋前查出短少或錯置，降低尋找、重配與換鎖風險。

按戶別、門鎖與鑰匙用途管理套數、標籤、借還、保管及住戶點交，於交屋前查出短少或錯置，降低尋找、重配與換鎖風險。

**產業別：**營建工程　|　**系統類型：**operations-console

## 功能模組

- **鑰匙總覽** — 查看戶別套數與狀態
- **編碼建檔** — 管理門鎖用途和標籤
- **借還登記** — 追蹤借用人及期限
- **交屋盤點** — 檢查每戶應交套數
- **遺失處理** — 記錄尋找重配與換鎖
- **住戶點交** — 簽認實交內容與時間

## 適合誰使用

- 交屋專員
- 修繕領班
- 鑰匙保管人

## 運作流程

1. 建立清冊
2. 施工借用
3. 歸還確認
4. 交屋預盤
5. 異常補正
6. 住戶簽收

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
