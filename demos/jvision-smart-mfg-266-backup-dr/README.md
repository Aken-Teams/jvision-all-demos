# 備份與災難復原管理艙

對MES、ERP、資料庫等關鍵系統進行定期備份與異地備援，確保災難發生時可快速復原營運。

- 原始系統：備份與災難復原系統（Backup & DR）
- 產業分類：智慧製造｜IT管理
- 使用部門：資訊部、資訊安全部、稽核室、各業務系統負責人
- 工作流程：制定備援策略→排程自動備份→備份完整性檢核→定期DR演練→事故發生時啟動復原→復原後驗證
- AI 應用：備份異常/勒索軟體行為偵測、復原時間預測與優化排程
- 主要 KPI：備份成功率、RTO/RPO達成率、演練通過率、備份儲存成長率
- 代表產品：Veeam Backup & Replication、Commvault、Veritas NetBackup、Zerto
