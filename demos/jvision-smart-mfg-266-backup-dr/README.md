# 備份與災難復原系統（Backup & DR）

> 告警分流、事件應變到弱點與合規治理

備份與災難復原系統（Backup & DR）提供排程備份與版本保留、異地/雲端備援複製、一鍵災難復原演練。資訊部依「制定備援策略→排程自動備份→備份完整性檢核→定期DR演練→事故發生時啟動復原→復原後驗證」推進作業，優先解決「系統當機無法即時復原」，資訊安全部則以備份成功率與RTO/RPO達成率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**資訊安全　|　**系統類型：**資安 SOC 平台

## 功能模組

- **告警分流** — 資安告警彙整分級
- **事件應變** — 事件調查與處置
- **弱點管理** — 弱點掃描與修補追蹤
- **身分權限** — 帳號與特權管理
- **合規治理** — 政策、稽核與合規
- **端點防護** — 端點偵測與應變

## 適合誰使用

- 資訊部
- 資訊安全部
- 稽核室

## 運作流程

1. 已偵測
2. 調查中
3. 研判確認
4. 已關閉

## 導入效益

- 告警分流時間：44分鐘 → **8.3分鐘**
- 事件平均處理：12小時 → **3.2小時**
- 弱點修補率：69% → **90%**
- 合規稽核工時：31小時/月 → **5.8小時/月**
