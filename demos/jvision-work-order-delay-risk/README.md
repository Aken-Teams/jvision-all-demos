# 工單延遲風險預測台

> 根據擬真的工單進度、站點排隊、物料到位與設備負荷資料，預測各工單無法如期完工的風險，說明主要延誤因素並提供插單、轉線或調整班次等排程情境比較。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **交期風險總覽** — 依產線、客戶與交期呈現工單延遲風險及預測完工時間。
- **風險工單清單** — 排序高風險工單，顯示落後進度、剩餘工序與交期差距。
- **關鍵路徑分析** — 呈現各站排隊、加工與等待時間對完工日期的影響。
- **延誤因素解析** — 拆解缺料、設備負荷、重工與人力不足等風險貢獻。
- **排程情境試算** — 比較插單、轉線、加班及調整優先序後的交期變化。
- **交期協調追蹤** — 記錄跨部門處置、承諾日期、負責人與客戶回覆狀態。

## 適合誰使用

- 生管人員
- 製造主管
- 業務跟單人員

## 運作流程

1. 掌握交期風險
2. 篩選風險工單
3. 檢視關鍵路徑
4. 解析延誤因素
5. 試算排程方案
6. 追蹤交期協調

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
