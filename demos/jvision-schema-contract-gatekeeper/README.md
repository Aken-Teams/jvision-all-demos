**產業別：**數據分析　|　**系統類型：**quality-qms

## 功能模組

- **Schema 版本差** — 比對基準與候選版本的欄位、型別、約束及預設值。
- **破壞性變更判定** — 辨識刪欄、改名、縮窄型別與必填化等不相容變更。
- **下游影響展開** — 沿血緣找出受影響管線、報表、模型與應用程式。
- **契約相容檢驗** — 依生產者與消費者契約執行向前及向後相容檢查。
- **遷移方案設計** — 建議雙寫、別名、分階段棄用與轉換步驟。
- **發布閘門裁決** — 依風險、豁免與下游確認結果允許或阻擋發布。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 提交 Schema 版本
2. 審查破壞項目
3. 確認下游影響
4. 執行契約測試
5. 核定遷移計畫
6. 裁決發布閘門

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
