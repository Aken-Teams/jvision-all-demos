# 出勤差勤管理

> 出勤、薪資、招募到績效的人資全流程

Jvision 雲端打卡、外勤回報、異常判斷、請假簽核、排班與工時計薪互動展示。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**HRIS 人力資源系統

## 功能模組

- **出勤差勤** — 打卡、請假與加班
- **薪資計算** — 薪資、勞健保與報稅
- **排班管理** — 智慧排班與工時控管
- **招募任用** — 職缺、面試與報到
- **教育訓練** — 課程、證照與紀錄
- **績效考核** — 目標設定與考核流程

## 適合誰使用

- 人資專員
- 人資經理
- 營運主管

## 運作流程

1. 建立出勤差勤管理資料
2. Jvision 雲端打卡、外勤回報、異常判斷、請假簽核、排班與工時計薪互動展示
3. 確認結果並完成留存

## 導入效益

- 薪資作業工時：40小時/月 → **8.2小時/月**
- 出勤異常處理：29分鐘 → **4.9分鐘**
- 招募到位天數：48天 → **26天**
- 表單簽核時效：3.1天 → **1天**
