**產業別：**資訊科技　|　**系統類型：**operations-console

## 功能模組

- **情境劇本工坊** — 編排正常、尖峰、例外與跨系統任務的測試情節。
- **合成資料生成器** — 產生兼顧邊界案例與隱私限制的角色、交易及事件資料。
- **尖峰負載模擬** — 模擬大量併發任務、工具延遲與服務限流狀態。
- **故障注入台** — 注入逾時、權限拒絕、資料缺漏與下游系統失效。
- **跨系統任務回放** — 逐步回放 Agent 在 ERP、CRM 與 MCP 工具間的任務路
- **流程缺口診斷** — 彙整失敗節點、復原能力與護欄缺口並形成修正建議。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 建立模擬劇本
2. 生成合成資料
3. 施加尖峰負載
4. 注入系統故障
5. 回放任務路徑
6. 修補流程缺口
