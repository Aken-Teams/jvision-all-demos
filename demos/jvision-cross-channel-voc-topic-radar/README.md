# 跨渠道 VOC 主題雷達

> 統整工單、訪談、社群與問卷語意，找出客戶聲音主題與風險訊號。

統整工單、訪談、社群與問卷語意，找出客戶聲音主題與風險訊號。

**產業別：**客服管理　|　**系統類型：**analytics-bi

## 功能模組

- **跨渠道聲音匯流** — 依客戶與旅程節點合併工單、訪談、社群及問卷內容。
- **VOC 主題聚類** — 自動辨識抱怨、需求、讚賞與流失徵兆等主題群。
- **主題關聯圖** — 呈現產品、功能、客群、情緒與問題實體之間的關聯。
- **異常聲量雷達** — 偵測主題聲量、負面情緒及高價值客戶影響的突升。
- **客戶原聲摘要** — 引用原始語句生成可追溯的主題摘要與影響說明。
- **VOC 行動案件** — 將達門檻的客戶風險轉成責任明確且持續追蹤的案件。

## 適合誰使用

- 客戶成功主管
- CSM
- 客服主管

## 運作流程

1. 匯聚客戶聲音
2. 辨識語意主題
3. 探索關聯脈絡
4. 判讀異常訊號
5. 核讀原聲證據
6. 啟動改善案件
