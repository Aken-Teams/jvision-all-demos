# 新店選址開店情境模擬器

**產業別：**房地產與物業　|　**系統類型：**analytics-bi

## 功能模組

- **商圈機會地圖** — 用模擬地圖呈現人口、消費、交通、競店與品牌空白區。
- **候選物件比較** — 並排比較租金、坪數、能見度、周邊機能與合約條件。
- **店型營運設計** — 選擇店型、營業時間、人力、品類及座位等營運假設。
- **開店財務試算** — 估算裝修、租金、人事、營收、現金流與損益兩平時間。
- **情境敏感度模擬** — 比較樂觀、基準和保守情境，測試租金、來客與客單變動影響。
- **決策開店藍圖** — 彙整選址評分、核准意見、風險對策與開店里程碑。

## 適合誰使用

- 展店開發人員
- 營運企劃
- 財務分析人員
- 品牌決策主管

## 運作流程

1. 界定展店需求
2. 篩選候選據點
3. 配置營運店型
4. 建立財務試算
5. 比較風險情境
6. 核定開店藍圖
