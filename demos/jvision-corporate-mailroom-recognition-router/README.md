# 企業收發室辨識分流器

> 辨識企業郵件與包裹的收件人及保密等級，自動分流通知以減少錯送。

辨識企業郵件與包裹的收件人及保密等級，自動分流通知以減少錯送。

**產業別：**企業協作　|　**系統類型：**operations-console

## 功能模組

- **郵件外觀辨識** — 從面單、信封與包裝擷取寄件方、條碼及類型。
- **收件人解析** — 比對姓名、部門、別名與座位找出正確收件人。
- **保密等級判定** — 識別機密、人資、法務、財務與一般件。
- **派送路徑分流** — 依樓層、保密要求與簽收方式安排流向。
- **到件通知中心** — 向收件人發送領取、派送或補充資訊通知。
- **錯送處置工作台** — 處理低信心辨識、拒收、逾期與退件案件。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 掃描到件
2. 解析收件人
3. 判定密級
4. 安排分流
5. 通知領取
6. 處理錯送

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
