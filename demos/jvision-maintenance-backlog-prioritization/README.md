# 維修積壓風險管理台

> 協助維修主管依安全、停機影響、故障頻率、料件狀態與工時評估積壓工單，建立可解釋的優先序、週排程承諾及延後理由，避免高風險工作被長期擱置。

協助維修主管依安全、停機影響、故障頻率、料件狀態與工時評估積壓工單，建立可解釋的優先序、週排程承諾及延後理由，避免高風險工作被長期擱置。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **積壓總覽** — 呈現工單老化、風險與資源缺口。
- **風險評分** — 依安全、產能及故障後果建立優先序。
- **料件就緒** — 核對所需備品、替代料與預計到料日。
- **工時能力** — 比較技能需求、可用人力及停機窗口。
- **週排程板** — 將可執行工作排入班次與設備時段。
- **延後審核** — 記錄延後原因、風險接受人與再評日期。

## 適合誰使用

- 維修主管
- 計畫保養員
- 廠務經理

## 運作流程

1. 盤點積壓
2. 評估風險
3. 確認備料
4. 配置能力
5. 承諾週排程
6. 審核延後

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
