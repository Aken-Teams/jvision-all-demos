# 庫存補貨指揮艙

> 收貨到出貨的倉內作業與庫存精準管理

用銷耗、交期與安全存量模型產生補貨建議。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**零售電商　|　**系統類型：**WMS 倉儲管理系統

## 功能模組

- **入庫上架** — 收貨、驗收與智慧上架
- **揀貨出貨** — 波次揀貨、覆核與出貨
- **儲位管理** — 儲位規劃與庫容視覺化
- **庫存盤點** — 即時庫存、盤點與調撥
- **拉動補料** — 安全庫存與自動補貨
- **條碼作業** — PDA 掃碼即時作業

## 適合誰使用

- 電商營運
- 商品經理
- 品牌負責人

## 運作流程

1. 待上架
2. 銷售中
3. 確認確認
4. 出貨完成

## 導入效益

- 補貨反應：23小時 → **4.2小時**
- 熱銷掌握率：62% → **92%**
- 缺貨率：12% → **3.8%**
- 結帳等待：6.4分鐘 → **1.5分鐘**
