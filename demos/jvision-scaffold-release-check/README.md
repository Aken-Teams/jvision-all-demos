# 施工架搭拆放行台

> 供施工架班完成底座、壁連座、斜撐、踏板及護欄檢點，缺失改善後由工安放行並管制拆架區域，避免未驗收施工架被使用。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **架區看板** — 呈現各立面狀態
- **搭設檢點** — 逐項確認構件
- **禁用掛牌** — 隔離重大缺失
- **改善追蹤** — 指派補強作業
- **複驗放行** — 工安確認可使用
- **拆架排程** — 管制拆除區域

## 適合誰使用

- 施工架班長
- 工安人員

## 運作流程

1. 劃定架區
2. 完成搭設
3. 安全檢點
4. 缺失改善
5. 複驗放行
6. 拆除銷項

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
