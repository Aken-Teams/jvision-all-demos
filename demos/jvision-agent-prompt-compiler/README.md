# Agent Prompt 編譯器

將自然語言 SOP 編譯成可版本管理、驗證與發布的系統提示及測試案例。

**產業別：**資訊科技　|　**系統類型：**operations-console

## 功能模組

- **SOP 編輯工作台** — 編寫或匯入作業程序，標記角色、條件、限制與預期產出。
- **指令結構拆解** — 將 SOP 拆成目標、步驟、工具、決策規則及交接契約。
- **系統提示編譯** — 把結構化規格轉譯為可執行的系統提示與工具使用約束。
- **矛盾與缺口檢查** — 找出規則互斥、順序衝突、責任不明與缺少終止條件之處。
- **測試案例生成** — 依正常、邊界、失敗及越權情境產生提示測試案例。
- **版本發布中心** — 比較提示差異、審核影響範圍並發布可回滾版本。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 建立 SOP 規格
2. 確認任務結構
3. 編譯系統提示
4. 修正規則衝突
5. 驗證測試案例
6. 核准版本發布
