# 家事服務鑰匙交接台

> 管理到府服務使用的住家鑰匙、磁扣、保管袋、領還與臨時換班轉交，以客戶代碼取代敏感標示，並在遺失時還原最後責任鏈。

管理到府服務使用的住家鑰匙、磁扣、保管袋、領還與臨時換班轉交，以客戶代碼取代敏感標示，並在遺失時還原最後責任鏈。

**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **保管物台帳** — 記錄鑰匙磁扣與密封袋
- **服務預約** — 連結案件與領用時段
- **領用查驗** — 確認人員與物品數量
- **換班轉交** — 保存交付雙方簽認
- **歸還點收** — 核對物品與功能狀態
- **遺失處置** — 停用追查與賠償紀錄

## 適合誰使用

- 客服調度
- 到府服務員
- 營運主管

## 運作流程

1. 建立保管台帳
2. 安排鑰匙領用
3. 辦理領用查驗
4. 完成換班轉交
5. 歸還功能點收
6. 處理遺失異常

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
