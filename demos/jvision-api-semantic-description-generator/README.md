# API 語意描述生成器

> 把 API 規格轉成含用途、限制、範例與復原策略的 Agent 可用語意描述。

把 API 規格轉成含用途、限制、範例與復原策略的 Agent 可用語意描述。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **用途語意補全** — 從規格與軌跡推導 API 適用任務及不適用情境。
- **限制條件生成** — 描述前置條件、速率限制、權限範圍與資料約束。
- **呼叫範例合成** — 產生符合 Schema 的正常、邊界與多步呼叫範例。
- **錯誤語意翻譯** — 將狀態碼與錯誤內容轉成 Agent 可理解的失敗原因。
- **復原策略編寫** — 為逾時、衝突、限流與部分成功生成安全恢復步驟。
- **工具選擇驗證** — 用情境題檢查語意描述能否引導 Agent 選對工具。

## 適合誰使用

- 平台架構師
- 整合工程師
- AI 應用開發者

## 運作流程

1. 選取 API 規格
2. 推導用途邊界
3. 生成限制範例
4. 編寫錯誤復原
5. 測試工具選擇
6. 發布語意描述
