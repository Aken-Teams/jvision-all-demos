# 客戶溝通節奏編排器

> 依客戶事件與聯絡偏好編排通知、會議及摘要，維持適當溝通節奏。

依客戶事件與聯絡偏好編排通知、會議及摘要，維持適當溝通節奏。

**產業別：**客服管理　|　**系統類型：**sales-crm

## 功能模組

- **客戶事件時間軸** — 彙整產品異常、工單、續約與關係變化事件。
- **聯絡偏好中心** — 管理聯絡人允許的管道、頻率、時段與議題偏好。
- **溝通壓力計** — 評估近期接觸密度、未回覆次數與疲勞風險。
- **節奏編排畫布** — 將通知、會議、追蹤與摘要配置到客戶旅程。
- **下一接觸建議** — 依事件急迫性與偏好排序最佳聯絡動作。
- **觸達執行中心** — 核准並發送訊息、建立會議及回寫執行結果。

## 適合誰使用

- 客戶成功主管
- CSM
- 客服主管

## 運作流程

1. 檢視觸發事件
2. 確認聯絡偏好
3. 評估接觸負荷
4. 設計溝通節奏
5. 審閱接觸建議
6. 核准並執行

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
