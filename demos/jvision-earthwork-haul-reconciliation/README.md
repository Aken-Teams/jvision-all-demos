**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **土方總覽** — 呈現核准量、累計運棄量及各去處餘額。
- **計畫建檔** — 設定土質分類、承運商與核准收容場所。
- **車次登錄** — 以批次方式建立車號、時間與載運數量。
- **聯單核對** — 比對出場、地磅、收容及回傳聯單資料。
- **異常處理** — 追蹤缺聯、超量、錯置及重複車次。
- **數量核銷** — 彙總合格車次並產出估驗與請款依據。

## 適合誰使用

- 土方工程師
- 工地會計
- 工地主任

## 運作流程

1. 土方總覽
2. 計畫建檔
3. 車次登錄
4. 聯單核對
5. 異常處理
6. 數量核銷

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
