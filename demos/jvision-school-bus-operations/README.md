# 校車路線乘車管理台

> 供幼兒園、補習班與私校管理校車路線、站點名單、乘車異動、缺席確認及家長通知，以模擬定位與簽到資料呈現每日接送狀態，不需連接真實車機。

供幼兒園、補習班與私校管理校車路線、站點名單、乘車異動、缺席確認及家長通知，以模擬定位與簽到資料呈現每日接送狀態，不需連接真實車機。

**產業別：**教育　|　**系統類型：**logistics-fleet

## 功能模組

- **路線站點** — 維護車次、站序及預定時間
- **乘車名單** — 查看學生與交接人資訊
- **請假異動** — 處理單日停搭及臨時換站
- **上下車點名** — 模擬每站學生上下車確認
- **異常處理** — 追蹤漏接、錯站與未交接
- **路線績效** — 分析車次準點與乘載情形

## 適合誰使用

- 校務行政
- 隨車老師
- 車隊主管

## 運作流程

1. 設定校車路線
2. 確認乘車名單
3. 處理乘車異動
4. 執行上下車點名
5. 回報接送異常
6. 檢討路線表現

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
