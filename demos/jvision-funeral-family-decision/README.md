# 治喪家屬決策確認台

> 供禮儀公司集中整理治喪流程中的家屬選項、報價差額、決議人、確認期限與變更紀錄，讓跨班服務人員掌握最新決定，避免口頭傳遞造成錯做與費用爭議。

供禮儀公司集中整理治喪流程中的家屬選項、報價差額、決議人、確認期限與變更紀錄，讓跨班服務人員掌握最新決定，避免口頭傳遞造成錯做與費用爭議。

**產業別：**生活服務　|　**系統類型：**service-desk

## 功能模組

- **決策清單** — 整理各階段待確認事項。
- **方案比較** — 並列選項、內容與費用差額。
- **決議權責** — 記錄主要聯絡人與同意關係。
- **確認期限** — 標示影響採購與排程的截止點。
- **變更軌跡** — 保留每次決定及原因。
- **執行發布** — 向內部團隊發布最新確認版本。

## 適合誰使用

- 禮儀師
- 客服人員
- 營運主管

## 運作流程

1. 建立事項
2. 整理方案
3. 指定決議人
4. 取得確認
5. 發布版本
6. 處理變更

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
