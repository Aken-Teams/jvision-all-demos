# 客戶合約收入辨認台

> 協助財會人員拆解客戶合約中的履約義務、交易價格、變動對價與收入認列時點，保留判斷、覆核及期末調整的完整底稿。

協助財會人員拆解客戶合約中的履約義務、交易價格、變動對價與收入認列時點，保留判斷、覆核及期末調整的完整底稿。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **合約收件** — 彙整條款、附件與後續變更版本。
- **義務拆解** — 識別商品、服務與可區分義務。
- **價格分攤** — 分配固定、變動及折扣對價。
- **認列排程** — 建立時點或隨時間認列計畫。
- **合約變更** — 評估追加、減項與累積追補。
- **期末覆核** — 保留判斷依據及調整分錄。

## 適合誰使用

- 收入會計
- 財務經理
- 會計師

## 運作流程

1. 登錄合約
2. 拆解義務
3. 分攤價格
4. 建立排程
5. 評估變更
6. 完成覆核

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
