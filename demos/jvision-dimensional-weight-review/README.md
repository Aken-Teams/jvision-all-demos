# 託運材積重覆核台

> 集中各站所申報的長寬高、實重、計費公式與影像證據，在帳單產生前找出材積重低報、公式版本不一及人工更改，支援補收與客戶申訴說明。

集中各站所申報的長寬高、實重、計費公式與影像證據，在帳單產生前找出材積重低報、公式版本不一及人工更改，支援補收與客戶申訴說明。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **尺寸清單** — 查看實重尺寸與來源
- **公式版本** — 維護客戶產品計算規則
- **量測證據** — 整理尺寸影像與時間
- **計費差異** — 比較原報與應計重量
- **覆核定案** — 核准補收或維持原價
- **申訴說明** — 產出計算明細與回覆

## 適合誰使用

- 站所人員
- 計費人員
- 客服人員

## 運作流程

1. 接收量測
2. 套用公式
3. 辨識差異
4. 查驗證據
5. 核定計費
6. 回覆申訴

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
