# 剩餘土石方去化額度台

> 管理工區土方分類、核准收容場所額度、每日運送配額、車次憑證與剩餘容量，協助承包商在開挖高峰前避開棄土場滿載或核准量不足。

管理工區土方分類、核准收容場所額度、每日運送配額、車次憑證與剩餘容量，協助承包商在開挖高峰前避開棄土場滿載或核准量不足。

**產業別：**營建工程　|　**系統類型：**logistics-fleet

## 功能模組

- **土方預估** — 依開挖區與土質建立出土量預測
- **收容場所** — 管理核准土質、容量與收受時段
- **額度配置** — 分配各場所及階段可使用數量
- **車次調度** — 安排每日車輛、批次與目的地
- **運送憑證** — 核對出場紀錄與收容場所回單
- **容量預警** — 預測額度耗盡與開挖停工風險

## 適合誰使用

- 土方工程師
- 運輸調度員
- 工地主任

## 運作流程

1. 預估階段出土量
2. 登錄核准場所
3. 配置去化額度
4. 排定每日車次
5. 核銷運送回單
6. 調整後續配額

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
