# 無障礙設施導航助手

> 依個人行動與感官需求安排無障礙路線、座位及會議空間，提升辦公可及性。

依個人行動與感官需求安排無障礙路線、座位及會議空間，提升辦公可及性。

**產業別：**企業協作　|　**系統類型：**operations-console

## 功能模組

- **可及需求設定** — 記錄輪椅、視覺、聽覺與陪同等個人需求。
- **無障礙路線規劃** — 依坡道、電梯、門寬與即時阻礙計算通行路線。
- **適配座位推薦** — 排序符合動線、桌高、照明與避難需求的座位。
- **會議空間適配** — 檢查會議室入口、設備、字幕與容納條件。
- **通行障礙應變** — 偵測電梯停用或封路並提出替代安排。
- **到訪行程引導** — 整合入館、通行、座位與離場的逐段指引。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 描述需求
2. 規劃路線
3. 選擇座位
4. 適配會議
5. 處理障礙
6. 啟動引導

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
