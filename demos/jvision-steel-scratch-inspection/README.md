**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **檢測影像佇列** — 依批次、產線及判定狀態瀏覽鋼板縮圖與刮傷標記。
- **刮傷複判工作台** — 放大影像、切換標記並量測刮傷長度、寬度及方向。
- **缺陷規格判定** — 依產品規格比較缺陷尺寸、位置與允收門檻。
- **批次處置決策** — 執行放行、降級、重工或隔離並填寫判定原因。
- **刮傷來源追溯** — 依缺陷方向與位置比對輥輪、導板及搬運環節。
- **品質趨勢報表** — 統計產線、班別、規格與來源別的刮傷率及改善趨勢。

## 適合誰使用

- 品管檢驗員
- 品質工程師
- 生產線主管

## 運作流程

1. 篩選待判影像
2. 複核刮傷標記
3. 套用允收規格
4. 決定批次處置
5. 追查刮傷來源
6. 檢討品質趨勢

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
