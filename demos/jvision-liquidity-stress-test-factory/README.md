# 流動性壓力測試工廠

> 組合延付、抽貸與市場衝擊情境，量化流動性缺口並準備應變措施。

組合延付、抽貸與市場衝擊情境，量化流動性缺口並準備應變措施。

**產業別：**財務會計　|　**系統類型：**finance-case

## 功能模組

- **衝擊情境編排** — 組合客戶延付、銀行抽貸、匯率與利率衝擊。
- **流動性基線建模** — 建立銀行餘額、收支預測、額度與融資到期基線。
- **連鎖效應模擬** — 推演衝擊對應收、付款、契約與融資條件的傳導。
- **缺口時點定位** — 找出各情境首次跌破現金緩衝的日期與金額。
- **應變措施配對** — 比較提款、延付、資產變現與避險措施的效果。
- **壓測方案核准** — 核准應變手冊、觸發門檻與責任人，供危機啟動。

## 適合誰使用

- 財務長
- Treasurer
- 資金人員

## 運作流程

1. 設定衝擊組合
2. 校準資金基線
3. 執行壓力模擬
4. 辨識流動性缺口
5. 設計應變組合
6. 核准應變手冊

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
