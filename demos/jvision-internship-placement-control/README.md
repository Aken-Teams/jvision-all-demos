# 校外實習媒合管理台

> 供技專校院管理實習職缺、學生資格、志願媒合、合約文件、訪視紀錄與異常轉換，降低跨系所及企業間的追蹤負擔。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **實習職缺** — 管理企業、名額、條件與工作內容。
- **學生資格** — 核對學分、證照及實習先修條件。
- **志願媒合** — 處理志願序、面談與錄取結果。
- **文件簽辦** — 追蹤合約、保險與家長文件。
- **實習訪視** — 安排教師訪視並記錄三方回饋。
- **異常轉換** — 處理中止、換點與改善追蹤。

## 適合誰使用

- 實習中心專員
- 系所教師
- 企業導師

## 運作流程

1. 審核職缺
2. 審核學生
3. 執行媒合
4. 完成簽辦
5. 進行訪視
6. 處理結案

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
