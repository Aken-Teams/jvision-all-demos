# 醫療檢驗碼對映治理台

> 治理HIS、LIS、健檢與委外實驗室間的檢驗代碼、檢體、單位及參考值對映，支援版本生效、測試案例、衝突審批與未知代碼補救。

治理HIS、LIS、健檢與委外實驗室間的檢驗代碼、檢體、單位及參考值對映，支援版本生效、測試案例、衝突審批與未知代碼補救。

**產業別：**醫療照護　|　**系統類型：**it-ops

## 功能模組

- **代碼比較** — 比對各端定義
- **對映編輯** — 建立欄位關係
- **檢體規則** — 核對檢體與單位
- **案例測試** — 驗證結果回寫
- **版本發布** — 控管生效範圍
- **未知碼處理** — 補救介接異常

## 適合誰使用

- 醫療資訊人員
- 醫檢師
- 介接工程師

## 運作流程

1. 提出異動
2. 比較定義
3. 建立對映
4. 測試案例
5. 核准發布
6. 處理例外

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
