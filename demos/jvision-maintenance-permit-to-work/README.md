# 設備作業許可管制台

> 管理設備檢修前的停機隔離、危害辨識、承攬商資格、作業許可與復機驗收，讓維修主管掌握高風險工作是否具備開工條件。

管理設備檢修前的停機隔離、危害辨識、承攬商資格、作業許可與復機驗收，讓維修主管掌握高風險工作是否具備開工條件。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **許可總覽** — 查看作業狀態與風險
- **危害辨識** — 選定風險及控制措施
- **能源隔離** — 記錄隔離點與確認人員
- **資格檢核** — 檢查承攬商證照與訓練
- **開工核准** — 完成現場會簽與許可
- **復機關閉** — 驗收設備並解除隔離

## 適合誰使用

- 維修主管
- 工安人員
- 設備工程師

## 運作流程

1. 申請作業
2. 辨識危害
3. 執行隔離
4. 檢查資格
5. 核准開工
6. 驗收復機

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
