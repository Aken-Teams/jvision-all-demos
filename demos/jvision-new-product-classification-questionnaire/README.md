# 新品分類問卷 Agent

> 主動向研發追問海關分類所需技術事實，加速新品出口與稅則判定。

主動向研發追問海關分類所需技術事實，加速新品出口與稅則判定。

**產業別：**採購供應鏈　|　**系統類型：**erp

## 功能模組

- **新品分類任務** — 從 PLM 或 ERP 建立待分類商品與出口情境。
- **技術問卷生成** — 依商品類型與候選稅則動態生成研發問題。
- **研發追問會話** — 針對模糊、缺漏或矛盾回答自動提出後續問題。
- **BOM 規格核對** — 將回答與材料、功能、製程及零組件規格交叉驗證。
- **稅則候選推理** — 依已確認事實排列候選 HS Code 與判定理由。
- **分類事實簽核** — 由研發與報關共同確認技術事實後送交分類。

## 適合誰使用

- 國貿主管
- 報關人員
- 業務

## 運作流程

1. 建立新品案件
2. 產生分類問卷
3. 回覆技術問題
4. 補問矛盾缺口
5. 審查候選稅則
6. 核准分類基礎

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
