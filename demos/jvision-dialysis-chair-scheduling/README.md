協助洗腎中心依患者固定療程、床位、護理人力、隔離需求及臨時請假安排每週班次，處理補做與換班候補，並在排程異動後產生交班及聯繫清單。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **固定療程** — 建立患者每週固定透析時段。
- **床位配置** — 依設備與隔離條件配置床位。
- **人力檢核** — 檢查各班護理人數及技能配置。
- **換班候補** — 處理請假、補做及候補遞補。
- **患者聯繫** — 產生異動確認與未到追蹤名單。
- **療程交班** — 彙整特殊需求與當班注意事項。

## 適合誰使用

- 透析護理長
- 排程櫃台
- 個案管理師

## 運作流程

1. 建立週表
2. 配置床位
3. 檢核人力
4. 處理異動
5. 確認患者
6. 發布交班

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
