# 快閃店開撤店協作台

> 管理快閃櫃位從合約確認、設計審核、商品鋪貨、人員訓練到開幕與撤場的跨部門任務，清楚掌握場地方限制、依賴關係和到期責任。

**產業別：**零售電商　|　**系統類型：**collaboration-pm

## 功能模組

- **進駐條件** — 記錄檔期、場租、抽成與場地限制。
- **設計送審** — 追蹤櫃位圖面、招牌及施工修正。
- **商品鋪貨** — 規劃首批貨量、陳列與補貨責任。
- **人員就緒** — 安排招募、排班、訓練及入場證。
- **開幕檢核** — 確認設備、收銀、商品及宣傳完成。
- **撤場點交** — 管理退貨、資產拆回與場地復原。

## 適合誰使用

- 通路開發專員
- 品牌專案經理
- 店務督導

## 運作流程

1. 確認進駐
2. 完成送審
3. 準備貨品
4. 完成人員
5. 開幕驗收
6. 撤場結案

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
