# 虛實偏差校準 Agent

> 持續比對現場與孿生模型偏差，自主校準參數並驗證模擬可信度。<

持續比對現場與孿生模型偏差，自主校準參數並驗證模擬可信度。<

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **孿生偏差總覽** — 依產線、設備與產品呈現模擬值和實測值的偏差熱區。
- **訊號異常診斷** — 辨識感測漂移、製程突變與資料缺口，避免錯誤校準。
- **偏差因果追蹤** — 串聯參數、配方、工單與影像，排序可能造成偏差的因果線索。
- **校準方案規劃** — 產生候選參數修正組合，估算對模型精度與製程穩定度的影響。
- **校準核准佇列** — 提交高風險參數變更供工程師核准，例外案件轉入人工處理。
- **回放驗證報告** — 用歷史工單與最新批次回放校準結果，確認孿生模型可信度。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 定位偏差熱區
2. 排除訊號異常
3. 解析偏差成因
4. 比較校準方案
5. 核准並執行校準
6. 驗證模型可信度

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
