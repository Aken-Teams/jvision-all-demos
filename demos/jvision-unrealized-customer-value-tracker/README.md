# 未實現價值追蹤器

> 找出客戶已購未用的能力與受阻原因，推動採用並降低 shelfware。

找出客戶已購未用的能力與受阻原因，推動採用並降低 shelfware。

**產業別：**客服管理　|　**系統類型：**sales-crm

## 功能模組

- **已購能力清單** — 解析合約與訂閱內容，列出客戶有權使用的產品能力。
- **未啟用能力雷達** — 對照產品事件與設定狀態，找出未開通或低使用功能。
- **採用阻礙診斷** — 從工單、互動與 VOC 判定技術、流程或認知阻礙。
- **價值缺口估算** — 估算未使用能力造成的效率、收入或成本改善缺口。
- **採用解鎖計畫** — 依阻礙安排啟用、整合、培訓與利害關係人任務。
- **價值實現驗證** — 追蹤能力採用與成果指標，確認 shelfware 已轉為實際價值。

## 適合誰使用

- 客戶成功主管
- CSM
- 客服主管

## 運作流程

1. 盤點已購能力
2. 偵測未用能力
3. 確認受阻原因
4. 估算價值缺口
5. 執行解鎖計畫
6. 驗證價值實現

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
