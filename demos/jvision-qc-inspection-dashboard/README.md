# 品質檢驗作業看板

> 以看板方式呈現進料、製程與出貨檢驗的待驗批次、抽樣進度、判定結果、異常警示及人員負荷，讓品管現場快速安排工作並掌握卡關項目；所有狀態均以擬真假資料互動展示。

以看板方式呈現進料、製程與出貨檢驗的待驗批次、抽樣進度、判定結果、異常警示及人員負荷，讓品管現場快速安排工作並掌握卡關項目；所有狀態均以擬真假資料互動展示。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **檢驗任務看板** — 依待驗、檢驗中、待判定及完成狀態排列所有批次。
- **待驗批次佇列** — 依到料時間、交期、風險及緊急程度排序待驗工作。
- **抽樣檢驗作業** — 顯示抽樣計畫、檢驗項目並輸入擬真假量測結果。
- **不合格警示台** — 集中呈現超規項目、批次影響、暫停狀態及處置建議。
- **人力負荷配置** — 比較檢驗員任務量、技能、進度並模擬重新指派。
- **交班績效摘要** — 整理本班完成量、未結批次、異常重點及下班注意事項。

## 適合誰使用

- 品管檢驗員
- 品質主管
- 倉管人員
- 生產線主管

## 運作流程

1. 掌握任務狀態
2. 安排待驗順序
3. 執行抽樣檢驗
4. 處理不合格警示
5. 平衡人員負荷
6. 完成班次交接

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
