# 產品碳排熱點導航器

> 沿製程與供應鏈定位產品碳排熱點，評估可追溯的低碳替代方案。​

沿製程與供應鏈定位產品碳排熱點，評估可追溯的低碳替代方案。​

**產業別：**生產製造　|　**系統類型：**esg-energy

## 功能模組

- **產品碳流地圖** — 串連原料、運輸、製程與能源，呈現單位產品碳流向。
- **碳排熱點排行** — 依生命週期階段與製程步驟找出高碳貢獻來源。
- **製程排放拆解** — 拆分設備能耗、配方、良率與工時造成的碳排差異。
- **供應替代探索** — 搜尋低碳材料、供應商、運輸路徑與製程替代選項。
- **減碳情境比較** — 比較替代方案的碳效益、成本、品質與交期影響。
- **減碳路線規劃** — 形成具來源引用、先後順序與責任人的改善路線。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 界定產品碳邊界
2. 定位碳排熱點
3. 拆解熱點成因
4. 蒐尋低碳替代
5. 評估替代情境
6. 發布減碳路線

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
