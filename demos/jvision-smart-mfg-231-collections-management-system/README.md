# 應收帳款催收管理系統（Collections Management System）

> 受理、審核、風險到撥付的案件審查流程

應收帳款催收管理系統（Collections Management System）提供逾期帳款自動分級(依天數/金額)、催收任務排程與分派、催收溝通紀錄管理(電話/email/信函)。會計專員、財務經理、負責人依「逾期帳款自動分級(依天數/金額)、催收任務排程與分派、催收溝通紀錄管理(電話/email/信函)」推進作業，優先解決「催收人員憑經驗判斷優先順序」，部門主管則以應收帳款催收管理追蹤台處理結果確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**財務會計　|　**系統類型：**金融 / 保險案件系統

## 功能模組

- **案件受理** — 理賠/貸款案件建立
- **審核初核** — 文件審查與資格核對
- **風險評分** — 風險模型與評分
- **覆核核准** — 多層覆核與核決
- **撥付理算** — 理算與撥款作業
- **案件追溯** — 全程紀錄與稽核

## 適合誰使用

- 會計專員
- 財務經理
- 負責人

## 運作流程

1. 待核對
2. 處理中
3. 待覆核
4. 已入帳

## 導入效益

- 月結作業天數：5.9天 → **2.1天**
- 對帳錯誤：8件/月 → **1.1件/月**
- 帳款逾期率：15% → **4.7%**
- 報表產出工時：17小時 → **1小時**
