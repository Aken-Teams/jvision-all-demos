# 實體合併仲裁台

> 仲裁知識圖譜中的同義實體與錯誤合併，避免搜尋與關聯結果被污染。

仲裁知識圖譜中的同義實體與錯誤合併，避免搜尋與關聯結果被污染。

**產業別：**企業協作　|　**系統類型：**operations-console

## 功能模組

- **候選合併佇列** — 排列疑似同人同物的名稱、代碼與跨來源實體配對。
- **身分特徵比對** — 比較別名、組織、聯絡資訊、時間與關聯特徵。
- **來源脈絡對照** — 並列文件、郵件、會議與工單中的實體使用脈絡。
- **衝突關係檢查** — 偵測互斥屬性、矛盾時間線與不可能共存的圖譜關係。
- **合併拆分仲裁** — 決定合併、維持分立、拆回或建立別名關係。
- **圖譜影響預覽** — 預覽裁決對搜尋、關聯、文件標註與下游節點的影響。

## 適合誰使用

- 知識工作者
- 主管
- 客服

## 運作流程

1. 受理疑似實體
2. 比對身分特徵
3. 查閱來源脈絡
4. 排除關係衝突
5. 作成仲裁決定
6. 驗證圖譜影響

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
