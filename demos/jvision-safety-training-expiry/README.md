# 職安教育資格到期台

> 集中管理作業人員的一般及特殊職安教育、證照影本、適用工種、複訓期限與各工地進場資格，在派工前辨識即將到期或資格不符者，並追蹤補訓、換證及停用處置。

集中管理作業人員的一般及特殊職安教育、證照影本、適用工種、複訓期限與各工地進場資格，在派工前辨識即將到期或資格不符者，並追蹤補訓、換證及停用處置。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **人員資格總覽** — 集中呈現人員、雇主、工種與資格狀態。
- **證照資料建檔** — 登錄證照類別、證號、影本及有效日期。
- **工種資格規則** — 設定各類作業必備教育與證照組合。
- **到期預警清單** — 依期限與工地風險排序待處理人員。
- **補訓換證追蹤** — 管理報名、完訓、補件及新證換發。
- **進場限制名單** — 產出可進場、限制作業與停用處置結果。

## 適合誰使用

- 職安人員
- 人資行政
- 工地門禁承辦

## 運作流程

1. 盤點人員資格
2. 建立證照資料
3. 套用工種規則
4. 檢視到期風險
5. 追蹤補訓換證
6. 發布進場限制

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
