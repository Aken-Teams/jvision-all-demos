以企業任務標籤整理模型能力、限制與適用情境，降低模型選型落差。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **任務能力分類** — 用摘要、推理、程式、客服等企業任務標籤建立能力分類。
- **模型能力卡** — 彙整模型版本、支援能力、上下文限制、部署方式與已知弱點。
- **任務適配比較** — 依指定任務並列模型品質、延遲、成本與合規適配度。
- **情境模擬選型** — 調整流量、預算與品質目標，模擬不同模型組合的結果。
- **候選模型排序** — 以多目標權重產生候選清單，並揭露分數與不確定範圍。
- **目錄發布同步** — 經核准後將選型結果與模型標籤同步至 Gateway 與應用團隊。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 瀏覽任務地圖
2. 檢視模型卡片
3. 建立比較清單
4. 模擬部署情境
5. 核定選型建議
6. 發布能力目錄
