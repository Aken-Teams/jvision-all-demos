# 光學缺陷風險分級台

> 依缺陷尺寸、位置、類型與產品檢驗規範，將自動光學檢測（AOI）結果分為提示、次要、主要與致命等級，提供人工調級、處置建議、批次放行及分級趨勢，讓品保判定更一致且可追溯。

依缺陷尺寸、位置、類型與產品檢驗規範，將自動光學檢測（AOI）結果分為提示、次要、主要與致命等級，提供人工調級、處置建議、批次放行及分級趨勢，讓品保判定更一致且可追溯。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **風險分級總覽** — 查看各嚴重度占比、高風險批次與待辦狀態。
- **分級規則庫** — 管理尺寸、位置、缺陷類型與產品規範的分級條件。
- **缺陷分級佇列** — 逐筆檢視缺陷影像、建議等級與判定依據。
- **人工調級工作台** — 調整特殊案例等級並記錄原因與佐證備註。
- **批次處置決策** — 依最高風險等級選擇放行、重工、隔離或報廢。
- **分級趨勢分析** — 比較產品、產線、班別與期間的嚴重度變化。

## 適合誰使用

- 品保工程師
- 品質主管
- 製程工程師

## 運作流程

1. 檢視風險概況
2. 維護分級規則
3. 確認建議等級
4. 處理調級例外
5. 決定批次處置
6. 追蹤分級趨勢

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
