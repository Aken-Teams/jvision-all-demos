# 宴會桌數變更結算台

> 以單一版本管理宴會保證桌、預備桌、實開桌、加菜與臨時撤桌，讓業務、廚房及現場同步簽認，結帳時依時間點與授權準確計價。

以單一版本管理宴會保證桌、預備桌、實開桌、加菜與臨時撤桌，讓業務、廚房及現場同步簽認，結帳時依時間點與授權準確計價。

**產業別：**餐飲旅宿　|　**系統類型：**pos-frontdesk

## 功能模組

- **桌數版本** — 管理保證預備桌
- **封盤管制** — 鎖定備料基準
- **廚房備料** — 確認供餐數量
- **現場變更** — 簽認開桌加菜
- **帳單核對** — 比較合約實際
- **宴會結算** — 確認最終金額

## 適合誰使用

- 宴會業務
- 宴會廚房
- 餐飲出納

## 運作流程

1. 建立宴會
2. 確認封盤
3. 發布廚房
4. 記錄變更
5. 核對帳單
6. 完成結算

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
