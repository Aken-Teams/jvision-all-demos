# 零售價格發布補償台

> 監看商品價格版本對POS、官網與平台的批次發布結果，定位失敗通路，預覽重送影響並執行補送或回復，避免舊價格覆蓋及錯價持續曝光。

監看商品價格版本對POS、官網與平台的批次發布結果，定位失敗通路，預覽重送影響並執行補送或回復，避免舊價格覆蓋及錯價持續曝光。

**產業別：**零售電商　|　**系統類型：**it-ops

## 功能模組

- **價格批次** — 查看發布版本
- **通路狀態** — 呈現各端結果
- **版本比較** — 辨識新舊價格
- **補送預覽** — 檢查影響範圍
- **補送回復** — 執行修復操作
- **售價驗證** — 抽查實際生效

## 適合誰使用

- 商品營運員
- 零售資訊人員
- 價格主管

## 運作流程

1. 建立批次
2. 監看發布
3. 比較版本
4. 預覽修復
5. 核准補送
6. 驗證生效

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
