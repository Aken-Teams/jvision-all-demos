# 企業政策智慧管理平台

> 集中管理公司政策、辦法與作業規範，呈現草擬、審查、發布、簽收及定期檢討流程，並以模擬智慧比對提示條文衝突、過期內容與適用範圍。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **政策資料庫** — 依主題、部門、效力狀態與適用對象查找現行政策。
- **條文編輯台** — 以章節結構草擬政策內容並標記負責人與依據。
- **衝突檢查** — 模擬提示政策間的重複、矛盾、過期引用與範圍缺口。
- **審查簽核** — 呈現法務、稽核及權責主管的依序審閱流程。
- **發布簽收** — 設定生效日與適用人員，追蹤公告閱讀及確認狀態。
- **定期檢討** — 管理檢討週期、到期提醒與歷次修訂紀錄。

## 適合誰使用

- 法務
- 稽核
- 人資
- 制度管理人員與各部門主管

## 運作流程

1. 盤點現行政策
2. 草擬政策條文
3. 檢查條文關聯
4. 完成跨部審查
5. 發布並追蹤簽收
6. 安排政策檢討

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
