# 計日工派工簽認台

> 將臨時計日工作從派工指示、到場人員、起訖時間到完成內容逐日留痕，由現場主管和承攬商當日簽認，月底自動彙整可請款工時及拒簽爭議。

將臨時計日工作從派工指示、到場人員、起訖時間到完成內容逐日留痕，由現場主管和承攬商當日簽認，月底自動彙整可請款工時及拒簽爭議。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **派工指示** — 建立工作範圍、地點、人力需求與核准上限。
- **人員到場** — 記錄班組、人員、工種及實際到離時間。
- **工時填報** — 計算正常、加班、待工與休息時數。
- **成果紀錄** — 保存施工前後照片及當日完成內容。
- **雙方簽認** — 由現場主管與承攬商確認或註記異議。
- **月結計價** — 彙整核准工時、單價及不可計價項目。

## 適合誰使用

- 工務工程師
- 現場領班
- 分包計價人員

## 運作流程

1. 發出派工
2. 確認到場
3. 填報工時
4. 回報成果
5. 當日簽認
6. 辦理月結

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
