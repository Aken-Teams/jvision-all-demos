# Sales Pipeline 業務機會管理

> 從名單到成交的完整客戶生命週期管理

Sales Pipeline 業務機會管理提供商機階段看板（Kanban）、成交機率與金額預估、階段停留天數分析。業務部依「建立商機→設定階段與機率→定期更新進度→階段推進或流失→成交/結案分析」推進作業，優先解決「業務各自為政商機不透明」，業務主管則以商機轉換率與平均銷售週期確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**業務銷售　|　**系統類型：**CRM 客戶關係管理

## 功能模組

- **商機階段看板** — Kanban 拖曳管理各階段商機與轉換
- **客戶與商機檔案** — 客戶聯絡人、需求與互動歷程整合
- **成交機率與金額預估** — 加權金額、成交機率與本月預估
- **階段停留天數分析** — 各階段平均停留與停滯商機警示
- **風險與待辦提醒** — 報價到期、無聯絡日期等自動排序
- **轉換率與銷售週期** — 漏斗轉換、平均銷售週期與達成率

## 適合誰使用

- 業務部
- 業務主管
- 總經理室

## 運作流程

1. 建立商機
2. 設定階段與機率
3. 定期更新進度
4. 階段推進或流失
5. 成交/結案分析

## 導入效益

- 商機轉換率：18% → **27%**
- 平均回應時間：28小時 → **6.2小時**
- 客戶資料完整率：60% → **88%**
- 報價逾期流失：9件/月 → **2件/月**
