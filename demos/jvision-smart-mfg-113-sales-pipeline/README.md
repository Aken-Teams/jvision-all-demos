# Sales Pipeline 業務機會指揮台

以商機階段（Stage）為主軸，視覺化管理從潛在客戶到成交的全過程，協助預測業績達成。

- 原始系統：Sales Pipeline 業務機會管理
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、業務主管、總經理室、行銷部
- 工作流程：建立商機→設定階段與機率→定期更新進度→階段推進或流失→成交/結案分析
- AI 應用：成交機率自動評分、停滯商機自動預警、業績達成率預測
- 主要 KPI：商機轉換率、平均銷售週期、Pipeline覆蓋率、贏單率
- 代表產品：Salesforce Sales Cloud、Pipedrive、HubSpot Sales Hub、Microsoft Dynamics 365
