# 光學跨機台模型校正台

> 比較同款產品在不同自動光學檢測（AOI）機台上的影像分布、判定差異與缺陷命中表現，提供基準機選擇、差異診斷、校正方案模擬、驗證及版本管理，降低模型移轉後因機台差異造成的品質波動。

比較同款產品在不同自動光學檢測（AOI）機台上的影像分布、判定差異與缺陷命中表現，提供基準機選擇、差異診斷、校正方案模擬、驗證及版本管理，降低模型移轉後因機台差異造成的品質波動。

**產業別：**AI 工程平台　|　**系統類型：**it-ops

## 功能模組

- **機台表現總覽** — 比較各模擬機台的一致率、誤報率與偏移警示。
- **基準機比對** — 選定參考機台並比較共通產品與樣本的判定結果。
- **偏移差異診斷** — 檢視亮度、色彩、尺度與特徵分布的差異摘要。
- **校正方案設定** — 組合正規化、閾值與特徵補償方案並預覽影響。
- **跨機驗證中心** — 以共同比對集檢查校正前後的一致性與風險。
- **校正版本管理** — 保存適用機台、驗證紀錄、核准狀態與回復點。

## 適合誰使用

- AI 模型工程師
- 設備工程師
- 品保工程師

## 運作流程

1. 盤點機台差異
2. 選定比對基準
3. 診斷偏移來源
4. 設計校正方案
5. 執行跨機驗證
6. 核准校正版本
