# 保險外勤文件收件台

> 追蹤業務攜回的要保正本、頁數、簽署欄位、公文袋及內勤簽收，將缺頁錯簽即時退補，降低承保延誤及不同客戶文件混袋風險。

追蹤業務攜回的要保正本、頁數、簽署欄位、公文袋及內勤簽收，將缺頁錯簽即時退補，降低承保延誤及不同客戶文件混袋風險。

**產業別：**金融保險　|　**系統類型：**operations-console

## 功能模組

- **案件文件表** — 列出應收正本及頁數
- **外勤裝袋** — 記錄袋號文件與業務
- **到件交接** — 保存送達時間與簽收人
- **拆袋查驗** — 核對頁數簽名與身分
- **缺件退補** — 指定錯欄缺頁與期限
- **核保歸檔** — 移交完整文件並封存

## 適合誰使用

- 保險業務
- 收件行政
- 案件覆核人員

## 運作流程

1. 建立應收清單
2. 外勤完成裝袋
3. 內勤簽收拆袋
4. 查驗簽署完整
5. 追蹤缺件補正
6. 移交核保歸檔

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
