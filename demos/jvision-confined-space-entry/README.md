# 缺氧空間進入管制台

> 針對地下室水槽、人孔與密閉設備空間，管理進入許可、作業名冊、氣體量測紀錄、通風救援配置及離場點名，確保每次進入都有完整管制。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **空間總覽** — 顯示各受限空間狀態與目前進入人數。
- **進入申請** — 建立作業內容、時段、班組與進入名冊。
- **環境量測** — 記錄氧氣及危害氣體數值與量測時間。
- **救援配置** — 確認通風、監視、通訊與救援人員器材。
- **進出點名** — 逐員記錄進入、暫離及最終離場時間。
- **異常撤離** — 停用許可並追蹤撤離清點與改善復驗。

## 適合誰使用

- 安全衛生人員
- 缺氧作業主管
- 施工領班

## 運作流程

1. 空間總覽
2. 進入申請
3. 環境量測
4. 救援配置
5. 進出點名
6. 異常撤離

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
