# 鋼筋加工料單協調台

> 管理鋼筋施工圖拆料、加工批次、需求日期、現場堆置區與綁紮順序，協助工地及加工廠提早發現料單重複、急件插單與到貨順序錯置，降低缺料等待及二次搬運。

管理鋼筋施工圖拆料、加工批次、需求日期、現場堆置區與綁紮順序，協助工地及加工廠提早發現料單重複、急件插單與到貨順序錯置，降低缺料等待及二次搬運。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **料單審核** — 檢查構件、號數、尺寸與需求數量。
- **加工排程** — 安排裁切彎折批次與預計完成日。
- **車趟編排** — 依工區需求與載重組合配送批次。
- **卸料配置** — 指定堆置區及可用容量。
- **缺料急件** — 管理缺料回報與插單優先順序。
- **耗用追蹤** — 比較到料、綁紮與剩餘數量。

## 適合誰使用

- 鋼筋工程師
- 加工廠排程員
- 鋼筋領班

## 運作流程

1. 提出料單
2. 完成審核
3. 安排加工
4. 組合配送
5. 卸料點收
6. 回報耗用

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
