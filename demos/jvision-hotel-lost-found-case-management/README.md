# 旅宿遺失物案件管理台

> 管理客房與公共區域拾獲物的登錄、影像佐證、保管位置、失主比對、領回或寄送及逾期處置，讓櫃台可快速查詢並保留完整責任軌跡。

管理客房與公共區域拾獲物的登錄、影像佐證、保管位置、失主比對、領回或寄送及逾期處置，讓櫃台可快速查詢並保留完整責任軌跡。

**產業別：**餐飲旅宿　|　**系統類型：**service-desk

## 功能模組

- **拾獲登錄** — 建立物品特徵、地點、時間與拾獲人。
- **保管定位** — 指派封存編號、櫃位及保管期限。
- **失主比對** — 依住宿資料與物品描述搜尋候選案件。
- **身分驗證** — 記錄失主特徵問答與核驗結果。
- **交付安排** — 管理現領、代理領取或付費寄送。
- **逾期處置** — 依規則執行銷毀、捐贈或移交。

## 適合誰使用

- 櫃台客服
- 房務領班
- 保全主管

## 運作流程

1. 建立案件
2. 封存入庫
3. 搜尋比對
4. 驗證失主
5. 完成交付
6. 逾期處理

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
