# 機會截止與前置期預警器

> 從投標截止日反推保證金、證明、詢答與內部簽核的最晚完成日。說明

從投標截止日反推保證金、證明、詢答與內部簽核的最晚完成日。說明

**產業別：**專業服務　|　**系統類型：**collaboration-pm

## 功能模組

- **機會期限總覽** — 集中顯示各標案截止日、剩餘工作天與逾期風險。
- **保證金時程** — 依申請、用印、匯款與銀行作業時間反推最晚啟動日。
- **資格證明前置期** — 盤點證照、實績與外部證明的取得時間及有效期限。
- **詢答窗口管理** — 辨識提問截止日，安排疑義彙整、內部確認與正式送問。
- **簽核路徑推演** — 依金額、風險與主管層級模擬簽核路徑及可能壅塞。
- **最晚日預警** — 整合各前置期產生紅線日期、責任人與升級提醒。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 解析機會截止
2. 反推保證金作業
3. 盤點資格證明
4. 安排詢答節點
5. 模擬內部簽核
6. 發布紅線期限

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
