# 食品拆包原料效期台

> 供食品加工線將大包原料拆成線邊桶後延續母批號，記錄開封時間、使用期限、剩量與存放區，優先領用即期桶並隔離逾期原料。

供食品加工線將大包原料拆成線邊桶後延續母批號，記錄開封時間、使用期限、剩量與存放區，優先領用即期桶並隔離逾期原料。

**產業別：**倉儲物流　|　**系統類型：**warehouse-wms

## 功能模組

- **拆包桶總覽** — 查看批號效期剩量
- **分裝建批** — 延續母批追溯
- **桶標列印** — 建立清楚子批標示
- **即期排序** — 顯示優先領用桶
- **領用扣量** — 更新線邊剩量
- **逾期隔離** — 禁止過期投料

## 適合誰使用

- 配料員
- 線邊庫管員

## 運作流程

1. 整包領出
2. 拆包分裝
3. 子批標示
4. 即期派料
5. 投料扣帳
6. 剩料處置

## 導入效益

- 揀貨作業工時：7小時/日 → **2小時/日**
- 庫存準確率：88% → **99%**
- 出貨延遲率：9% → **2%**
- 盤點工時：16小時/月 → **3小時/月**
