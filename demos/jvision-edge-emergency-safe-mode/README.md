# Edge 緊急安全模式

> 偵測雲端失聯或異常指令並切入保守控制，避免場域設備進入危險狀態。

偵測雲端失聯或異常指令並切入保守控制，避免場域設備進入危險狀態。

**產業別：**設備維護　|　**系統類型：**operations-console

## 功能模組

- **雲端失聯守望** — 監測心跳、延遲與認證狀態，辨識真實失聯而非短暫抖動。
- **異常指令攔截** — 檢查雲端指令是否違反物理限制、權限或操作序列。
- **安全模式劇本** — 按設備與風險情境配置保守控制值、停機順序及人工接管。
- **切換決策台** — 以異常證據、因果線索與風險排序決定是否切入安全模式。
- **本地保守控制** — 在斷線期間執行限速、限溫、隔離或受控停機。
- **復原與回切驗證** — 驗證雲端恢復、狀態同步及設備穩定後分階段回切。

## 適合誰使用

- IoT 架構師
- 設備工程師
- 場域主管

## 運作流程

1. 辨識失聯異常
2. 攔截危險指令
3. 選擇安全劇本
4. 核准緊急切換
5. 執行本地控制
6. 驗證恢復回切

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
