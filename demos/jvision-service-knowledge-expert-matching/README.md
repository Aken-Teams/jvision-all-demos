# 專業知識複用專家配對台

> 將顧問專案產出的範本、方法、案例與經驗教訓轉為可搜尋知識，依新案件的產業、議題、技能、語言及可投入時間，推薦適合素材與內部專家，縮短準備與解題時間。

將顧問專案產出的範本、方法、案例與經驗教訓轉為可搜尋知識，依新案件的產業、議題、技能、語言及可投入時間，推薦適合素材與內部專家，縮短準備與解題時間。

**產業別：**專業服務　|　**系統類型：**collaboration-pm

## 功能模組

- **知識收錄工作台** — 提交模擬範本、案例與經驗教訓，填寫來源、摘要及可使用範圍。
- **知識治理中心** — 審核分類、技能標籤、敏感性、版本、有效期限及內容負責人。
- **知識探索入口** — 依產業、問題與交付階段搜尋，預覽重點、適用條件及相似素材。
- **案件需求畫布** — 描述新案件背景、問題、所需技能、語言、地點與投入期間。
- **專家配對中心** — 比較專長證據、相關經驗、可用時段、負荷與推薦原因。
- **複用成效儀表板** — 追蹤素材採用、節省工時、配對速度、專家負荷與使用者回饋。

## 適合誰使用

- 顧問
- 專案經理
- 知識管理員
- 資源經理與領域專家

## 運作流程

1. 提交知識
2. 審核治理
3. 探索素材
4. 描述需求
5. 配對專家
6. 衡量複用
