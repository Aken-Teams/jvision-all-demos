# 宴會檔期產能協調台

> 協助宴會飯店統整廳房檔期、桌數版本、菜單需求、人力缺口與設備衝突，讓業務承諾、廚房備餐及宴會執行使用同一份作業基準。

協助宴會飯店統整廳房檔期、桌數版本、菜單需求、人力缺口與設備衝突，讓業務承諾、廚房備餐及宴會執行使用同一份作業基準。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **宴會日曆** — 依廳房與時段檢視預訂、保留及場復安排。
- **桌數版本** — 追蹤保證桌數、預估桌數與最終桌數變更。
- **菜單需求** — 彙整菜色、特殊飲食與出餐批次。
- **人力配置** — 試算外場、廚房與支援人員缺口。
- **設備調度** — 分配桌椅、布巾、音響及宴會器材。
- **執行確認** — 凍結作業版本並完成跨部門簽認。

## 適合誰使用

- 宴會業務
- 餐飲經理
- 主廚

## 運作流程

1. 建立檔期
2. 確認桌數
3. 拆解菜單
4. 配置人力
5. 調度設備
6. 發布版本

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
