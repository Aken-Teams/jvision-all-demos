# 永續資料與揭露智慧助理

> 協助中小企業收集環境、社會與治理資料，檢查單位、期間及佐證完整性，將擬真數據對應揭露主題並生成可編修的永續內容與審閱軌跡。

協助中小企業收集環境、社會與治理資料，檢查單位、期間及佐證完整性，將擬真數據對應揭露主題並生成可編修的永續內容與審閱軌跡。

**產業別：**ESG 永續　|　**系統類型：**esg-energy

## 功能模組

- **永續資料總覽** — 呈現各主題、部門與報導期間的資料收集進度。
- **指標資料收集** — 填報能源、排放、人力與治理等擬真指標數據。
- **資料品質檢查** — 標示缺值、單位錯誤、期間不一致與異常變動。
- **揭露主題對應** — 把企業指標對應至適用的永續議題與揭露欄位。
- **揭露內容草擬** — 依現有資料產生可編修的績效說明與管理方針草稿。
- **佐證審閱中心** — 連結擬真附件、處理審閱意見並保留修改紀錄。

## 適合誰使用

- 永續承辦人
- 財務人員
- 人資
- 廠務主管與管理階層

## 運作流程

1. 檢視收集進度
2. 填報永續指標
3. 修正品質問題
4. 對應揭露主題
5. 編修揭露草稿
6. 完成佐證審閱

## 導入效益

- 盤查作業工時：40小時 → **8小時**
- 數據完整率：60% → **95%**
- 減碳目標達成：50% → **88%**
- 用能異常反應：24小時 → **2小時**
