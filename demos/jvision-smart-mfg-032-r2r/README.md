# Run-to-Run製程控制智慧站

依前一批次製程結果動態調整下一批次製程參數，實現批次間自動製程優化，常見於半導體晶圓製程。

- 原始系統：Run-to-Run製程控制系統（R2R）
- 產業分類：智慧製造｜製造管理
- 使用部門：製程工程、設備工程
- 工作流程：批次量測結果輸入 → 模型運算調整量 → 參數自動修正 → 下批執行 → 效果驗證回饋
- AI 應用：AI優化製程模型精準度、機器學習預測最佳製程參數組合
- 主要 KPI：批次間變異縮減率、良率提升幅度、模型預測準確率
- 代表產品：多為半導體設備商內建控制模組，如Applied Materials、PDF Solutions相關解決方案
