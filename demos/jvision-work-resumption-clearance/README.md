# 工地停工復工確認台

> 將停工命令拆分至棟別、樓層與作業區域，逐項追蹤缺失改善、風險解除、文件核准及人員通知；復工前以區域化清單完成會簽，避免只憑口頭指示讓未解除區域恢復施工。

將停工命令拆分至棟別、樓層與作業區域，逐項追蹤缺失改善、風險解除、文件核准及人員通知；復工前以區域化清單完成會簽，避免只憑口頭指示讓未解除區域恢復施工。

**產業別：**營建工程　|　**系統類型：**operations-console

## 功能模組

- **停工區域** — 在樓層與工區圖上標示停工範圍及原因。
- **解除條件** — 拆解改善、文件、檢查及外部核准要求。
- **改善證據** — 依條件提交照片、報告與完成說明。
- **復工會簽** — 由職安、工務及監造逐區審查放行。
- **復工通知** — 發布可施工範圍、時間與殘餘限制。
- **停復工履歷** — 保留命令、改善、會簽及通知確認紀錄。

## 適合誰使用

- 工地主任
- 職安人員
- 監造工程師

## 運作流程

1. 劃定停工範圍
2. 拆解復工條件
3. 提交改善證據
4. 執行區域複查
5. 完成復工會簽
6. 發布復工通知

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
