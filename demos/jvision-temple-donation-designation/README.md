# 寺院捐款指定用途管理台

> 協助寺院與宗教法人管理一般捐款、指定用途款、專案勸募、收據開立、支用申請及餘額揭露，確保每筆善款依捐款人意願使用並保留內部稽核軌跡。

**產業別：**宗教服務　|　**系統類型：**finance-ledger

## 功能模組

- **捐款登錄** — 記錄捐款人、金額、方式與指定意願。
- **收據作業** — 管理編號、抬頭、補發與寄送狀態。
- **專款帳戶** — 呈現各指定用途的收入、支出與餘額。
- **支用申請** — 填報支出目的、預算及佐證資料。
- **用途審核** — 檢查申請是否符合捐款指定範圍。
- **揭露報表** — 彙整專案執行、餘額與捐款運用成果。

## 適合誰使用

- 寺院會計
- 執事人員
- 監事

## 運作流程

1. 受理捐款
2. 開立收據
3. 歸入專款
4. 提出支用
5. 審核用途
6. 彙整揭露

## 導入效益

- 活動籌備工時：20小時 → **5小時**
- 報名掌握率：65% → **94%**
- 物資盤點：6小時 → **1小時**
- 志工調度時效：3天 → **1天**
