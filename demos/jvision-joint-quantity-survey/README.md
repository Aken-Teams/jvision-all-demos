# 估驗聯合丈量作業台

> 供總包、分包與監造依契約項次共同建立丈量區段、記錄尺寸與計算式，現場逐筆確認爭議數量並鎖定簽認版本，降低重複申報、單位誤植及月底估驗雙方各持一份數量表的情況。

供總包、分包與監造依契約項次共同建立丈量區段、記錄尺寸與計算式，現場逐筆確認爭議數量並鎖定簽認版本，降低重複申報、單位誤植及月底估驗雙方各持一份數量表的情況。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **丈量批次** — 依估驗期別與施工區段安排聯合丈量清單。
- **契約項次** — 帶入計價單位、計算規則與前期累計數量。
- **現場量測** — 輸入尺寸、扣除項與定位照片並即時計算。
- **差異協議** — 並列雙方主張、爭議原因及修正數量。
- **共同簽認** — 鎖定丈量版本並記錄各方確認意見。
- **估驗彙出** — 彙整本期核定量、累計量及未決保留項。

## 適合誰使用

- 計價工程師
- 分包計價人員
- 監造工程師

## 運作流程

1. 建立批次
2. 核對規則
3. 現場丈量
4. 處理差異
5. 聯合簽認
6. 送入估驗

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
