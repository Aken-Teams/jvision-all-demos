# 職安缺失停復工台

> 針對重大職安缺失明確劃定停工區域、工項與班組，追蹤改善證據、複查及正式復工授權，防止交班後人員誤入或未核准先行復工。

**產業別：**營建工程　|　**系統類型：**security-soc

## 功能模組

- **停工看板** — 查看封鎖區域及工項
- **範圍劃定** — 標示人員設備和動線
- **改善派工** — 指定措施責任與期限
- **改善舉證** — 提交同位置修正資料
- **復工複查** — 確認風險已解除
- **狀態發布** — 通知班組正式復工

## 適合誰使用

- 職安人員
- 工地主任
- 分包領班

## 運作流程

1. 發現重大缺失
2. 發布停工
3. 執行改善
4. 提交證據
5. 現場複查
6. 核准復工

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
