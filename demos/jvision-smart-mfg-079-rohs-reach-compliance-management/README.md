# RoHS/REACH Compliance Management追蹤台

管理產品與材料是否符合RoHS、REACH等環保法規之限用物質要求，降低法規違規風險。

- 原始系統：RoHS/REACH Compliance Management（有害物質法規符合性管理）
- 產業分類：智慧製造｜品質管理
- 使用部門：法規事務部、品保部、採購部、研發部
- 工作流程：法規資料庫建立→供應商聲明蒐集→物質篩檢→合規判定→報告產出
- AI 應用：法規更新自動比對、高風險物質預警、文件缺漏自動提醒
- 主要 KPI：供應商聲明完成率、合規報告產出時效、違規事件數
- 代表產品：Assent Compliance、Actio、以客製化開發為主
