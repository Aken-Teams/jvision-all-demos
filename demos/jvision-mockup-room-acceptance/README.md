# 樣品屋工法定版驗收台

> 以樣品屋或標準層示範單元整合裝修工序、細部節點、材料搭配、檢查缺失與定版決議，將核准工法轉為量產樓層的查驗基準，避免各棟各戶施工標準不一致。

以樣品屋或標準層示範單元整合裝修工序、細部節點、材料搭配、檢查缺失與定版決議，將核准工法轉為量產樓層的查驗基準，避免各棟各戶施工標準不一致。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **樣品單元** — 建立房型、空間、示範範圍與預定完成日。
- **工序節點** — 列出施工順序、介面收邊與隱蔽檢查點。
- **聯合驗收** — 依空間及專業記錄判定與現場照片。
- **缺失改善** — 指派修正事項並追蹤複驗結果。
- **工法定版** — 保存設計、監造及業主的核定決議。
- **量產標準** — 發布定版圖卡、容許標準與查驗清單。

## 適合誰使用

- 裝修工程師
- 監造工程師
- 設計師

## 運作流程

1. 建立樣品
2. 完成施作
3. 聯合驗收
4. 改善複驗
5. 核定工法
6. 發布量產

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
