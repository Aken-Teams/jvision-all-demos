# 旅宿團房名單清件台

> 管理旅行團多版房名單的旅客、房型、同住關係、證件、餐食與特殊需求，標示版本差異及未清項目，讓前台在團體抵達前取得唯一可用版本。

管理旅行團多版房名單的旅客、房型、同住關係、證件、餐食與特殊需求，標示版本差異及未清項目，讓前台在團體抵達前取得唯一可用版本。

**產業別：**餐飲旅宿　|　**系統類型：**pos-frontdesk

## 功能模組

- **名單匯入** — 載入旅行社版本
- **版本比較** — 標示人房變更
- **團體配房** — 安排房型同住
- **缺件追蹤** — 補齊證件備註
- **名單封版** — 鎖定入住版本
- **單位發布** — 提供前台餐飲

## 適合誰使用

- 團體業務
- 訂房人員
- 前台主管

## 運作流程

1. 接收名單
2. 比較版本
3. 完成配房
4. 追蹤缺件
5. 核准封版
6. 發布接待

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
