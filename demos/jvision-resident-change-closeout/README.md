# 住戶客變收口追蹤台

> 以戶別及空間彙整客變核定內容，拆解土建、機電與裝修收口任務，控管現場使用版次、完成照片及跨工種確認，避免封板後才發現遺漏或不同版本混用。

以戶別及空間彙整客變核定內容，拆解土建、機電與裝修收口任務，控管現場使用版次、完成照片及跨工種確認，避免封板後才發現遺漏或不同版本混用。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **戶別總覽** — 呈現每戶客變狀態、期限與風險。
- **核定差異** — 比對原設計與客變核定內容及版次。
- **任務拆解** — 將變更拆給土建、機電及裝修工班。
- **施工回報** — 依空間登錄完成量、照片與現場問題。
- **收口複核** — 檢查跨工種銜接、修補與表面復原。
- **戶別結案** — 確認所有客變及收口項目完整關閉。

## 適合誰使用

- 客變專員
- 工務工程師
- 分包領班

## 運作流程

1. 載入核定客變
2. 確認現場版次
3. 拆派跨包任務
4. 回報施工成果
5. 執行收口複核
6. 完成戶別結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
