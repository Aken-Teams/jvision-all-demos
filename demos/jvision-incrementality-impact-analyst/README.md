**產業別：**業務銷售　|　**系統類型：**analytics-bi

## 功能模組

- **增量假設設計** — 設定處置組、對照組、觀察窗口與預期影響指標。
- **自然基線建模** — 依歷史趨勢、季節性與外部事件估算未投放時的結果。
- **跨渠道效果比對** — 對照內容、廣告、搜尋與網站變化，辨識真正增量。
- **因果線索圖譜** — 串聯活動、受眾、接觸點與轉換，檢查可能的混淆因素。
- **錯誤歸因診斷** — 標出自然需求、品牌慣性或渠道重疊造成的高估。
- **效果結論核准** — 彙整結論與證據包，供主管修訂並核准採用。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 建立判讀任務
2. 生成自然基線
3. 比對渠道變化
4. 審視因果線索
5. 修正歸因結論
6. 核准效果報告
