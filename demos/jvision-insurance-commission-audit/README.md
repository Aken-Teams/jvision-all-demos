# 保險通路佣金核算台

> 供保經代公司依商品、繳別、通路層級與契約狀態核算首年度及續年度佣金，處理解約追回、人工調整、覆核簽准與業務對帳，降低多版本獎酬規則造成的爭議。

**產業別：**金融保險　|　**系統類型：**finance-ledger

## 功能模組

- **結算批次** — 彙整當期新契約、續期與異動資料。
- **獎酬規則** — 維護商品、職級與期間適用條件。
- **佣金試算** — 計算首佣、續佣、獎金與分潤。
- **解約追回** — 追蹤撤件、停效及提前解約扣回。
- **差異申覆** — 處理業務提出的計算疑義。
- **佣金對帳** — 產出個人、組織與公司彙總明細。

## 適合誰使用

- 佣金專員
- 財務主管
- 通路主管

## 運作流程

1. 建立批次
2. 套用規則
3. 執行試算
4. 處理追回
5. 審理申覆
6. 發布對帳

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
