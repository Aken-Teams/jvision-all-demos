# 校園實驗室預約管制台

> 協助大專院校管理教學實驗室、專用儀器、課程預約、安全資格與耗材需求，讓教師提出整班使用申請，管理員檢查衝突及前置條件後發布場次並追蹤異常。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **資源目錄** — 管理實驗室、儀器與容納人數。
- **課程申請** — 提出班級、實驗項目及時段需求。
- **資格檢核** — 確認師生安全訓練與操作資格。
- **排程審核** — 處理時段、容量及設備衝突。
- **耗材準備** — 建立場次耗材與器具備置清單。
- **使用紀錄** — 登錄損壞、違規與場次異常。

## 適合誰使用

- 實驗室管理員
- 授課教師
- 系所行政

## 運作流程

1. 提出申請
2. 核對資格
3. 審查排程
4. 準備資源
5. 發布場次
6. 回報使用

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
