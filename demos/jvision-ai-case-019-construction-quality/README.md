# 營建缺失閉環台

> 從缺失登錄、平面圖定位到改善看板與複驗關閉的品質閉環

管理缺失開立、照片佐證、平面圖定位、改善期限與複驗結果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**營建工程　|　**系統類型：**營建工程管理

## 功能模組

- **缺失總覽** — 缺失、改善與複驗全局戰情
- **缺失登錄** — 缺失開立、照片佐證與分級
- **平面圖標記** — 樓層平面圖缺失定位釘標
- **改善看板** — 待改善／改善中／待複驗／已關閉
- **複驗關閉** — 改善前後照片比對與結案
- **品質統計** — 缺失類型分佈與改善時效

## 適合誰使用

- 品管工程師
- 工地主任
- 業主／監造

## 運作流程

1. 巡查發現缺失
2. 平面圖定位登錄
3. 指派改善
4. 改善執行
5. 複驗關閉

## 導入效益

- 缺失改善時效：7.4天 → **2.0天**
- 複驗關閉率：42% → **90%**
- 平均改善往返：多次 → **一次通過 88%**
