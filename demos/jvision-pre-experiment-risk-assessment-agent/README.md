# 實驗前風險評估 Agent

> 依實驗步驟、物質與設備自動建立危害清單及可執行的控制措施。說明

依實驗步驟、物質與設備自動建立危害清單及可執行的控制措施。說明

**產業別：**研發管理　|　**系統類型：**quality-qms

## 功能模組

- **風險評估案件** — 建立實驗前評估範圍，顯示未處理危害與開工阻擋項。
- **步驟危害拆解** — 逐步辨識加熱、加壓、轉移、混合與廢棄操作的危害。
- **物質相容性檢查** — 檢查化學、生物物質特性及混合、儲存與暴露風險。
- **設備防護核驗** — 確認設備額定值、連鎖、防護罩與緊急停止配置。
- **控制措施編排** — 依消除、替代、工程、管理與個人防護層級配置措施。
- **開工條件放行** — 彙整剩餘風險、責任人與完成期限，決定是否允許執行。

## 適合誰使用

- 實驗室主管
- 研究員
- 技術員

## 運作流程

1. 建立評估範圍
2. 拆解步驟危害
3. 核對物質風險
4. 確認設備防護
5. 配置控制措施
6. 核准實驗開工

## 導入效益

- 設計變更工時：8小時 → **2小時**
- 文件版本錯誤：6件/月 → **1件/月**
- 專案準時率：70% → **92%**
- 資料查找時間：30分鐘 → **5分鐘**
