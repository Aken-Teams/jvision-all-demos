# 殯儀設施檔期管制台

> 協助殯葬服務業者統籌禮廳、冰存空間、火化時段、接運車與誦經場地等稀缺資源，針對家屬日期偏好建立可行方案，避免跨場館預約衝突與服務斷點。

協助殯葬服務業者統籌禮廳、冰存空間、火化時段、接運車與誦經場地等稀缺資源，針對家屬日期偏好建立可行方案，避免跨場館預約衝突與服務斷點。

**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **案件需求** — 整理日期、宗教儀式與場地需求。
- **設施日曆** — 查看禮廳、冰存及火化空檔。
- **時序編排** — 串接接運、儀式及火化節點。
- **檔期暫留** — 設定保留期限避免重複占用。
- **預約確認** — 核對各場館回覆與必要文件。
- **異動重排** — 改期時重新搜尋可行組合。

## 適合誰使用

- 禮儀承辦人
- 場務調度員
- 服務主管

## 運作流程

1. 整理需求
2. 查詢空檔
3. 組合時序
4. 暫留資源
5. 完成預約
6. 處理異動

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
