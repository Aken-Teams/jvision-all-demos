# 客運駕駛交接調度台

> 供客運業者規劃長途班次的駕駛接替、交接地點、車次銜接與臨時缺勤備援，確保人員、車輛及法定休息安排一致。

供客運業者規劃長途班次的駕駛接替、交接地點、車次銜接與臨時缺勤備援，確保人員、車輛及法定休息安排一致。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **班次任務** — 呈現車次區段與行駛時刻
- **駕駛交接** — 安排接替人員與交接站點
- **工時檢核** — 檢查任務、休息與重疊衝突
- **缺勤備援** — 依資格及位置推薦替補人員
- **延誤重排** — 模擬延誤對後續任務的影響
- **交接確認** — 記錄抵達、接班與異常結果

## 適合誰使用

- 客運調度員
- 站務主管
- 駕駛領班

## 運作流程

1. 載入班次區段
2. 配置交接駕駛
3. 檢核工時休息
4. 處理臨時缺勤
5. 重排延誤銜接
6. 完成交接確認

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
