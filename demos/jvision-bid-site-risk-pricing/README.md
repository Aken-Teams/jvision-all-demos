# 標前現勘風險計價台

> 將公共工程標前現勘發現的交通、管線、施工空間與鄰房限制，轉成可追蹤的成本假設、詢價需求及投標風險加價，避免重要條件只留在個人照片中。

將公共工程標前現勘發現的交通、管線、施工空間與鄰房限制，轉成可追蹤的成本假設、詢價需求及投標風險加價，避免重要條件只留在個人照片中。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **現勘路線** — 依工區規劃勘查點及必要確認事項。
- **限制採集** — 定位記錄交通、空間、管線與鄰房條件。
- **工項關聯** — 將現勘發現連結受影響投標工項。
- **成本估算** — 建立數量、單價、工率與風險假設。
- **疑義詢答** — 彙整需向招標機關釐清的問題。
- **封標決策** — 決定納價、排除、保留或風險加價。

## 適合誰使用

- 估算工程師
- 投標經理
- 現勘工程師

## 運作流程

1. 規劃現勘
2. 採集條件
3. 映射工項
4. 取得成本
5. 提出疑義
6. 核定風險

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
