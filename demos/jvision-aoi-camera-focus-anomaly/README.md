# 光學相機失焦偵測台

> 利用預先建立的模擬檢測影像與清晰度指標，呈現自動光學檢測（AOI）相機可能失焦、焦距漂移或局部模糊的異常，提供影像比對、趨勢追蹤、原因判讀、維護派工及復機驗證畫面。

利用預先建立的模擬檢測影像與清晰度指標，呈現自動光學檢測（AOI）相機可能失焦、焦距漂移或局部模糊的異常，提供影像比對、趨勢追蹤、原因判讀、維護派工及復機驗證畫面。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **相機健康總覽** — 查看各模擬相機的清晰度、告警層級與維護狀態。
- **失焦告警中心** — 依相機、產品與嚴重度整理焦距異常事件。
- **基準影像比對** — 並排比較目前影像與正常基準的邊緣及局部細節。
- **清晰度趨勢** — 追蹤清晰度指標、異常時段與批次變化。
- **維護工單處理** — 建立調焦、鏡頭清潔或固定件檢查的模擬工單。
- **復機驗證紀錄** — 比較維護前後影像並記錄驗證結果與核准狀態。

## 適合誰使用

- 設備工程師
- 維修技術員
- 品保工程師

## 運作流程

1. 巡查相機健康
2. 受理失焦告警
3. 比對基準影像
4. 分析漂移趨勢
5. 執行維護處置
6. 完成復機驗證

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
