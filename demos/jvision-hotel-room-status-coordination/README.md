# 旅宿房況整備協調台

> 整合退房、清潔、查房、維修與可售狀態，讓房務主管依入住時限安排整房優先序，處理延遲與換房，避免櫃台售出尚未完成整備的客房。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **房況總覽** — 依樓層與狀態查看今日客房整備壓力。
- **優先排序** — 按入住時限、房型缺口與貴賓標記排序。
- **房務派工** — 分派清潔房間並平衡人員工作量。
- **查房驗收** — 記錄查房結果與退回重整項目。
- **維修協調** — 轉交設備缺失並評估是否暫停銷售。
- **放房確認** — 彙整完成證據並更新可售狀態。

## 適合誰使用

- 房務主管
- 櫃台值班經理
- 工程領班

## 運作流程

1. 檢視房況
2. 排定優先序
3. 分派整房
4. 完成查房
5. 排除異常
6. 確認放房

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
