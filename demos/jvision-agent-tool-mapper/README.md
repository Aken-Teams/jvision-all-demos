# Agent 工具映射器

> 把 Agent 工作步驟精準映射到 API、MCP 工具與必要人工節點。

把 Agent 工作步驟精準映射到 API、MCP 工具與必要人工節點。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **工作步驟建模** — 將目標流程整理為具輸入、產出與成功條件的可執行步驟。
- **工具能力搜尋** — 從 API 與 MCP 目錄搜尋可完成各步驟的候選工具。
- **語意契約比對** — 比對步驟意圖與工具參數、回傳 Schema、權限及副作用。
- **能力缺口診斷** — 標示無可用工具、契約不相容或權限不足的流程缺口。
- **人機節點配置** — 在判斷、核准及無法自動化的位置插入具責任人的人工節點。
- **可執行映射發布** — 驗證資料轉換與呼叫順序，發布 Agent 可直接採用的工具映射。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 匯入工作流程
2. 搜尋候選工具
3. 比對工具契約
4. 處理能力缺口
5. 配置人工節點
6. 測試並發布映射
