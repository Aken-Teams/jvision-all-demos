# 車票退款批次覆核台

> 勾稽售票、乘車驗票、班次取消與金流交易，攔截已使用、已退或超額退款票券，並管制手續費減免與批次修改後的出款版本。

**產業別：**交通運輸　|　**系統類型：**finance-case

## 功能模組

- **退票母體** — 彙整申請票券
- **乘車核對** — 確認是否使用
- **重退檢查** — 比對歷史退款
- **手續費覆核** — 管制減免授權
- **批次核准** — 鎖定退款版本
- **金流回寫** — 確認實際退款

## 適合誰使用

- 票務會計
- 客服人員
- 財務主管

## 運作流程

1. 建立批次
2. 核對乘車
3. 排除重退
4. 審核減免
5. 批准出款
6. 回寫結案

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
