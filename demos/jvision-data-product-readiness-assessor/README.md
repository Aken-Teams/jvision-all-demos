# 資料產品就緒度評估器

> 檢查資料產品的責任、SLA、文件、品質及使用條件，確保達到交付標準。

檢查資料產品的責任、SLA、文件、品質及使用條件，確保達到交付標準。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **產品責任檢查** — 確認業務擁有者、技術維護者與支援聯絡方式完整。
- **SLA 完備度** — 檢查新鮮度、可用率、回應時間與補救承諾。
- **文件覆蓋評量** — 評估欄位定義、來源、範例與操作手冊的完整度。
- **品質門檻檢驗** — 驗證準確性、完整性、唯一性與時效規則是否達標。
- **使用條件審查** — 確認允許用途、敏感分級、授權與保留限制。
- **就緒發布評分** — 彙總缺口、風險與阻擋項，產生發布建議。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 確認產品責任
2. 制定服務承諾
3. 審閱產品文件
4. 執行品質驗收
5. 核定使用條件
6. 決定發布就緒

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
