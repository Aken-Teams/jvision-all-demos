# 情境式微學習 Agent

> 在工作任務發生時推送精準微學習內容，讓員工即學即用並驗證成效。

在工作任務發生時推送精準微學習內容，讓員工即學即用並驗證成效。

**產業別：**人力資源　|　**系統類型：**education-lms

## 功能模組

- **工作情境感知** — 從專案、CRM、Git 或作業系統辨識當下任務情境。
- **學習需求判斷** — 結合任務難度、技能缺口與錯誤風險決定是否介入。
- **微內容編排** — 將知識重組為三至五分鐘、可立即操作的學習單元。
- **任務內推送** — 在員工使用的工作渠道選擇合適時機推送內容。
- **即學即用挑戰** — 用短題、模擬與實作提示驗證內容能否套用到任務。
- **學習轉化追蹤** — 衡量完成後的工作品質、速度與重複錯誤變化。

## 適合誰使用

- L&D 主管
- 部門主管
- 員工

## 運作流程

1. 偵測工作事件
2. 判斷介入時機
3. 生成微學習單元
4. 推送任務指引
5. 完成應用挑戰
6. 檢視轉化成效

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
