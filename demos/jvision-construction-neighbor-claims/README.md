# 工地鄰損陳情處理台

> 管理施工期間鄰房損害與居民陳情的受理、現況證據、責任研判、會勘協調、修繕承諾及結案文件，協助營造商降低爭議擴大與承諾逾期風險。

管理施工期間鄰房損害與居民陳情的受理、現況證據、責任研判、會勘協調、修繕承諾及結案文件，協助營造商降低爭議擴大與承諾逾期風險。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **陳情受理** — 登錄問題位置、類型、影響住戶及緊急程度。
- **現況證據** — 對照施工前後照片、測量資料與歷次紀錄。
- **責任研判** — 整理工序關聯、承商說明及初步責任意見。
- **聯合會勘** — 安排住戶、監造、承商與第三方的會勘事項。
- **改善承諾** — 追蹤修繕、補償及環境改善的負責人與期限。
- **簽認結案** — 彙整成果證據、住戶回覆與結案文件。

## 適合誰使用

- 工地主任
- 鄰房協調員
- 工務法務

## 運作流程

1. 受理居民陳情
2. 彙整現況證據
3. 研判施工責任
4. 召開聯合會勘
5. 執行改善承諾
6. 取得簽認結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
