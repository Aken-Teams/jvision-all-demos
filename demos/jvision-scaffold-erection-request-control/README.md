# 施工架搭拆申請管制台

> 讓各工種依立面、樓層與使用期間提出施工架搭設、修改或拆除需求，統一評估共用、衝突與安全條件，排定架工班作業並完成交付驗收，減少重複搭拆及未經核准自行變更。

讓各工種依立面、樓層與使用期間提出施工架搭設、修改或拆除需求，統一評估共用、衝突與安全條件，排定架工班作業並完成交付驗收，減少重複搭拆及未經核准自行變更。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **搭拆申請** — 登錄位置、用途、荷重、尺寸與使用期間。
- **立面配置** — 在棟別與立面視圖檢查重疊及共用需求。
- **架工排程** — 依優先級、材料與工作面安排搭修改拆作業。
- **條件審查** — 確認基礎、壁連座、防墜及周邊隔離條件。
- **交付驗收** — 記錄完工檢點、缺失改善與可使用狀態。
- **拆除管制** — 追蹤使用到期、續用確認及拆除後點交。

## 適合誰使用

- 施工架工程師
- 安衛人員
- 專業分包領班

## 運作流程

1. 提出需求
2. 整併配置
3. 條件審查
4. 排定施工
5. 驗收交付
6. 續用拆除

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
