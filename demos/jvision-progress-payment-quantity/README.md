# 估驗計價數量核對台

> 整合契約工項、樓層實作量、前期累計與本期估驗數量，讓工務、分包及成本人員逐項核對計量依據、扣回與保留款，降低試算表公式錯置及重複計價風險。

整合契約工項、樓層實作量、前期累計與本期估驗數量，讓工務、分包及成本人員逐項核對計量依據、扣回與保留款，降低試算表公式錯置及重複計價風險。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **契約工項** — 檢視單價、單位、契約量及計量規則。
- **數量申報** — 依棟別、樓層與區域填報本期完成量。
- **差異核對** — 標示申報量、實測量與核定量差異。
- **佐證附件** — 關聯照片、丈量紀錄及查驗文件。
- **累計試算** — 試算前期累計、扣回、保留款與本期金額。
- **估驗簽核** — 記錄退補件、核定意見與簽核歷程。

## 適合誰使用

- 工務工程師
- 成本工程師
- 分包計價人員

## 運作流程

1. 建立估驗期別
2. 申報完成數量
3. 補齊計量佐證
4. 核對數量差異
5. 試算估驗金額
6. 送審核定封存

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
