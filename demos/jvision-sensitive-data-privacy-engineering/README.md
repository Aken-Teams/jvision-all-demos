## 功能模組

- **敏感資料雷達** — 彙整敏感資料分布、風險等級、來源與待確認發現。
- **分類審查台** — 檢視欄位樣本、辨識理由並核准或修正敏感標籤。
- **資料流向地圖** — 呈現敏感資料從來源到報表及匯出的傳遞路徑。
- **隱私風險評估** — 依資料敏感度、用途、使用者與暴露面評估風險。
- **遮罩策略設計** — 配置遮蔽、代碼化、泛化與假名化的處理規則。
- **隱私驗證室** — 以模擬資料預覽處理前後差異及再識別風險。

## 適合誰使用

- 隱私管理人員
- 資安人員
- 資料工程師
- 系統負責人

## 運作流程

1. 查看敏感分布
2. 確認資料分類
3. 追查資料流向
4. 評估隱私風險
5. 設計保護策略
6. 驗證處理效果

## 導入效益

- 告警分流時間：45分鐘 → **8分鐘**
- 事件平均處理：12小時 → **3小時**
- 弱點修補率：68% → **96%**
- 合規稽核工時：30小時/月 → **6小時/月**
