# 施工日誌核對編製台

> 把各工班人數、施工位置、完成數量、機具工時、材料進場與天候照片整理成每日施工日誌，透過交叉核對找出矛盾與缺件，完成主管覆核後輸出正式留存版本。

把各工班人數、施工位置、完成數量、機具工時、材料進場與天候照片整理成每日施工日誌，透過交叉核對找出矛盾與缺件，完成主管覆核後輸出正式留存版本。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **當日回報總覽** — 彙整工班、人數、工區、工項及回報完成狀態。
- **人員機具核對** — 比對工班回報、點工資料及機具使用時數。
- **施工內容編製** — 依工區整理施作項目、完成數量與障礙。
- **材料天候紀錄** — 彙整材料進場、使用情況與天候影響。
- **日誌照片選編** — 挑選可證明當日工項且位置時間清楚的照片。
- **正式日誌簽核** — 呈現異動軌跡並輸出主管核准的留存版本。

## 適合誰使用

- 工地行政
- 現場工程師
- 工地主任

## 運作流程

1. 收集工班回報
2. 核對人員機具
3. 整理施工進度
4. 補齊材料天候
5. 編排證據照片
6. 覆核正式日誌

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
