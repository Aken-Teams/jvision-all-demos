# SMT餵料防呆管理協作所

驗證SMT產線餵料料號與貼片程式一致性，防止誤料上機之防呆系統。

- 原始系統：SMT餵料防呆管理系統（Feeder/Component Verification System）
- 產業分類：智慧製造｜製造管理
- 使用部門：SMT製造工程、生產、品保
- 工作流程：領料掃碼 → 餵料槽位比對 → 防呆確認上機 → 生產執行 → 用料履歷歸檔
- AI 應用：AI辨識異常換料模式並預警、智慧建議最佳餵料槽位配置
- 主要 KPI：誤料事件數、防呆攔截率、換料時間
- 代表產品：Cogiscan、Aegis FactoryLogix、ASM Siplace Feeder Management
