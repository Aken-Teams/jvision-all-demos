# 餐廳開閉店缺失交接台

> 將開店與閉店檢查依區域分派，讓各班次用照片記錄設備、冷藏、清潔及安全缺失，明確交接責任、期限與複驗結果。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **班次檢查** — 依區域執行開閉店清單。
- **缺失舉證** — 記錄設備與環境異常。
- **跨班交接** — 指定下一班責任人員。
- **處置追蹤** — 更新隔離、報修或清潔進度。
- **複驗放行** — 由店長確認改善完成。
- **門店稽核** — 比較各店缺失與逾時。

## 適合誰使用

- 值班店長
- 開閉店人員
- 區域督導

## 運作流程

1. 啟動檢查
2. 登錄缺失
3. 指定交接
4. 執行處置
5. 複驗放行
6. 督導改善

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
