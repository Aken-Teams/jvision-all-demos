# 外送平台訂單漏單稽核台

> 逐筆比對外送平台訂單、取消紀錄與 POS 入單結果，找出漏接、重複入機、取消後已製作及金額差異，讓門店當日補正並留下責任與損失紀錄。

**產業別：**餐飲旅宿　|　**系統類型：**pos-frontdesk

## 功能模組

- **訂單匯入** — 彙整平台與POS明細
- **自動比對** — 找出未配對與金額差異
- **異常佇列** — 分類漏接取消及重單
- **門店查核** — 補充製作與交付證據
- **補正處理** — 執行補帳退款或認損
- **損失分析** — 比較門店平台與時段

## 適合誰使用

- 門店主管
- 營運督導
- 財務人員

## 運作流程

1. 匯入訂單
2. 執行比對
3. 分派查核
4. 還原現場
5. 完成補正
6. 檢討改善

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
