# 內容支柱規劃 Agent

> 將品牌議題規劃為季度內容支柱與跨格式製作藍圖。​﻿​﻿​﻿​﻿​﻿​﻿

將品牌議題規劃為季度內容支柱與跨格式製作藍圖。​﻿​﻿​﻿​﻿​﻿​﻿

**產業別：**業務銷售　|　**系統類型：**collaboration-pm

## 功能模組

- **議題機會雷達** — 彙整搜尋、受眾與競品訊號，辨識值得長期投入的議題。
- **季度支柱畫布** — 把品牌命題拆成季度主軸、子題與溝通角度。
- **內容叢集地圖** — 規劃核心內容、延伸主題與彼此導流關係。
- **跨格式展開器** — 將主題轉為文章、影片、社群、電子報與銷售素材。
- **季度節奏排程** — 依活動、資源與渠道安排內容發布節奏。
- **支柱成效校準** — 比較覆蓋、互動與轉換，建議下季支柱調整。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 掃描議題機會
2. 選定季度支柱
3. 建立內容叢集
4. 展開跨格式素材
5. 編排季度節奏
6. 校準下一週期

## 導入效益

- 商機轉換率：18% → **27%**
- 平均回應時間：26小時 → **6小時**
- 客戶資料完整率：62% → **94%**
- 報價逾期流失：9件/月 → **2件/月**
