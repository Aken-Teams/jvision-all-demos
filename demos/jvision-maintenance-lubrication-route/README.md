# 設備潤滑路線管理台

> 供工廠規劃設備潤滑點、油品規格、巡迴路線與週期任務，記錄加注量、異常油況、漏油及補做結果，避免錯油、漏點與過度潤滑造成設備損傷。

供工廠規劃設備潤滑點、油品規格、巡迴路線與週期任務，記錄加注量、異常油況、漏油及補做結果，避免錯油、漏點與過度潤滑造成設備損傷。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **潤滑點台帳** — 管理設備點位、方法與安全提醒。
- **油品規格** — 維護油脂類型、用量及替代限制。
- **巡迴路線** — 依區域與工時編排執行順序。
- **週期任務** — 產生每日、每週與停機潤滑工單。
- **點位回報** — 記錄加注量、油況及現場照片。
- **異常改善** — 追蹤漏油、污染與補做結果。

## 適合誰使用

- 潤滑技師
- 維修主管
- 設備工程師

## 運作流程

1. 建立潤滑標準
2. 配置巡迴路線
3. 排定週期任務
4. 執行逐點潤滑
5. 登錄油況異常
6. 驗證改善結案

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
