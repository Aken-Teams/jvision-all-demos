# Digital Work Instruction/Quality SOP Management決策室

以數位化方式管理現場作業指導書與品質SOP，確保現場人員依最新標準作業並可追蹤閱讀紀錄。

- 原始系統：Digital Work Instruction/Quality SOP Management（數位作業指導書管理）
- 產業分類：智慧製造｜品質管理
- 使用部門：製程工程部、品保部、生產部、訓練單位
- 工作流程：SOP編寫審核→發行推播→現場掃碼查閱→閱讀簽核→定期複審更新
- AI 應用：圖文指導自動生成草稿、閱讀行為異常提醒
- 主要 KPI：SOP更新推播時效、現場閱讀簽核完成率、因SOP未依循造成異常次數
- 代表產品：以客製化開發為主，常整合SharePoint或MES電子作業指導模組
