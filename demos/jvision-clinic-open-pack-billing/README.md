# 診所耗材拆盒計價台

> 建立醫療耗材盒、支、片等包裝換算及拆盒紀錄，連結診間取用與療程計價，遇規格變更或臨時領用時即時呈現實物、帳面及未計費差異。

建立醫療耗材盒、支、片等包裝換算及拆盒紀錄，連結診間取用與療程計價，遇規格變更或臨時領用時即時呈現實物、帳面及未計費差異。

**產業別：**醫療照護　|　**系統類型：**warehouse-wms

## 功能模組

- **耗材規格** — 管理盒裝單件與換算
- **拆盒登記** — 建立單件批號與效期
- **診間領用** — 記錄取用人與用途
- **療程耗用** — 連結病人療程與數量
- **計價勾稽** — 找出已用未收與錯價
- **盤點調整** — 覆核帳實差異與原因

## 適合誰使用

- 診所庫管
- 護理長
- 櫃台計價員

## 運作流程

1. 建立包裝換算
2. 登記耗材拆盒
3. 執行診間領用
4. 連結療程耗用
5. 調查耗用差異
6. 覆核計價盤點

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
