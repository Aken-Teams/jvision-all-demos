# 外牆淋水測試分區台

> 依立面、樓層與窗框編碼規劃外牆淋水測試，管理測試條件、室內觀察、滲漏路徑研判、修繕及複測，形成交屋前外牆防水缺失的分區閉環紀錄。

依立面、樓層與窗框編碼規劃外牆淋水測試，管理測試條件、室內觀察、滲漏路徑研判、修繕及複測，形成交屋前外牆防水缺失的分區閉環紀錄。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **立面分區** — 依向別、樓層、軸線與窗框建立測試區。
- **測試腳本** — 設定水壓、噴淋時間、順序與觀察人員。
- **滲漏定位** — 在內外牆視圖標註入水與顯水位置。
- **原因研判** — 分類膠縫、排水、窗框接合或牆體缺陷。
- **修繕追蹤** — 記錄拆修範圍、材料、日期與責任廠商。
- **複測結案** — 保留相同條件下的複測結果與會簽。

## 適合誰使用

- 外牆工程師
- 品管人員
- 監造工程師

## 運作流程

1. 建立測試分區
2. 排定測試條件
3. 標註滲漏位置
4. 研判滲漏原因
5. 執行缺失修繕
6. 完成複測結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
