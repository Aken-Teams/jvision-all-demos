# 電芯配組壽命預測雲

> 彙整電芯分容測試、內阻、容量、電壓曲線與批次履歷，依一致性條件模擬配組並預估模組壽命，協助工程人員降低混配風險、提高成組利用率，提前辨識可能快速衰退的電芯。

彙整電芯分容測試、內阻、容量、電壓曲線與批次履歷，依一致性條件模擬配組並預估模組壽命，協助工程人員降低混配風險、提高成組利用率，提前辨識可能快速衰退的電芯。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **分容總覽** — 呈現各批次容量、內阻、良率、待配組數量與異常分布。
- **電芯履歷** — 查看單顆電芯的測試曲線、分級結果、批次來源及品質標記。
- **分級篩選** — 用容量、內阻、電壓及溫度等條件建立可視化分級規則。
- **智慧配組** — 模擬多組候選配置，呈現一致性分數、利用率與風險差異。
- **壽命預測** — 比較模組衰退曲線、剩餘循環數與影響壽命的主要因子。
- **待配庫池** — 管理各級電芯數量、庫齡、可配需求及滯留風險。

## 適合誰使用

- 電池製程工程師
- 測試工程師與生產計畫人員

## 運作流程

1. 檢視分容批次
2. 查核電芯履歷
3. 建立分級規則
4. 產生配組方案
5. 評估預估壽命
6. 安排庫池領料

- 準時交付率：80% → **95%**

- 設備稼動率：74% → **88%**
