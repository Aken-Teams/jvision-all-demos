以廠區地圖、搬運需求與虛擬車隊狀態模擬廠內物流調度，將無人搬運車任務依優先級、距離及壅塞情況自動排序，並提供人工改派與績效回顧介面。

**產業別：**倉儲物流　|　**系統類型：**warehouse-wms

## 功能模組

- **廠區物流地圖** — 呈現工站、倉位、路線與虛擬車輛位置。
- **搬運需求中心** — 彙整補料、轉運、回收與緊急搬運需求。
- **任務智慧編排** — 依優先級、距離、載具能力與時限安排任務。
- **交通衝突處理** — 顯示壅塞、交會與封路情境並提供改道方案。
- **車隊任務監控** — 追蹤虛擬車輛的任務階段、負載與等待狀態。
- **物流績效分析** — 分析準時率、空跑、熱點路段與任務週期。

## 適合誰使用

- 物流調度員
- 倉庫主管
- 生產線長
- 廠務工程師

## 運作流程

1. 掌握廠區態勢
2. 受理搬運需求
3. 編排車隊任務
4. 排除交通衝突
5. 監看任務進度
6. 回顧調度績效

## 導入效益

- 揀貨作業工時：7小時/日 → **2小時/日**
- 庫存準確率：88% → **99%**
- 出貨延遲率：9% → **2%**
- 盤點工時：16小時/月 → **3小時/月**
