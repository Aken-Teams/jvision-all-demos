# 紙卷殘卷秤重尋料台

> 供紙器與印刷廠管理拆封紙卷的紙種、克重、門幅、剩餘重量及包膜狀態，優先媒合小單與短單，避免帳上有殘卷卻持續領新卷。

供紙器與印刷廠管理拆封紙卷的紙種、克重、門幅、剩餘重量及包膜狀態，優先媒合小單與短單，避免帳上有殘卷卻持續領新卷。

**產業別：**倉儲物流　|　**系統類型：**warehouse-wms

## 功能模組

- **殘卷庫存** — 查看門幅剩重
- **回秤建檔** — 更新實際重量
- **批號重標** — 延續母卷追溯
- **工單媒合** — 依門幅克重找卷
- **用料預留** — 鎖定排程紙卷
- **用罄結清** — 關閉殘卷庫存

## 適合誰使用

- 紙卷庫管員
- 排程人員

## 運作流程

1. 紙卷拆用
2. 殘卷回秤
3. 重新包膜
4. 入架定位
5. 短單媒合
6. 領用結清

## 導入效益

- 揀貨作業工時：7小時/日 → **2小時/日**
- 庫存準確率：88% → **99%**
- 出貨延遲率：9% → **2%**
- 盤點工時：16小時/月 → **3小時/月**
