# IMDS預警塔

汽車與電子產業材料成分申報系統，管理供應鏈材料數據以符合國際法規要求。

- 原始系統：IMDS（International Material Data System）
- 產業分類：智慧製造｜品質管理
- 使用部門：品保部、研發部、採購部、法規事務部
- 工作流程：材料資料蒐集→供應商申報→系統審核→合規判定→客戶提交
- AI 應用：物質合規自動比對、缺件資料提醒、風險物質預警
- 主要 KPI：申報完成率、逾期供應商比例、法規符合率
- 代表產品：IMDS（Hersteller Initiative Qualität官方系統）、BOMcheck、Assent Compliance
