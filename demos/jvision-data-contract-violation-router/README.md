# 契約違反自動分流器

> 識別資料契約違反的責任方與受影響消費者，自動建立並派送處置事件。

識別資料契約違反的責任方與受影響消費者，自動建立並派送處置事件。

**產業別：**數據分析　|　**系統類型：**service-desk

## 功能模組

- **違約訊號偵測** — 偵測 Schema、品質、延遲與可用性契約的違反。
- **產消關係解析** — 從血緣辨識違約資料的生產者與所有下游消費者。
- **影響範圍評級** — 依報表、模型與決策用途計算事件嚴重度。
- **責任歸屬判定** — 比對資產所有權與值班表，找出主要處理團隊。
- **處置路由編排** — 依違約類型、嚴重度與時限選擇派送及升級路徑。
- **復原結果驗證** — 確認契約指標恢復且受影響消費端重新正常運作。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 接收違約訊號
2. 解析產消關係
3. 評估業務影響
4. 建立處置事件
5. 派送與升級
6. 驗證契約復原

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
