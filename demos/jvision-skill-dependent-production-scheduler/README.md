# 技能依賴排程器

> 依人員資格、實際熟練度與工序風險安排關鍵作業，降低排班風險。

依人員資格、實際熟練度與工序風險安排關鍵作業，降低排班風險。

**產業別：**生產製造　|　**系統類型：**hr-hris

## 功能模組

- **資格有效性矩陣** — 對照證照、授權範圍、有效期限與可執行工序。
- **熟練度能力圖** — 依近期績效、品質與操作經驗估算人員實際熟練度。
- **關鍵工序需求板** — 整理各工序所需技能、最低等級、班次與替補條件。
- **技能約束排班** — 在產能與勞動限制下產生符合資格的班次配置。
- **排班風險預警** — 偵測單點技能、證照到期、疲勞與新人集中等風險。
- **替班調度建議** — 在缺勤或插單時排序可解釋的換班、支援與培訓方案。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 彙整工序技能需求
2. 校準人員能力
3. 產生約束排班
4. 檢查排班風險
5. 核准人員配置
6. 監控班次履行

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
