## 功能模組

- **來源影響地圖** — 呈現每個知識來源對答案主張與結論的影響權重。
- **來源平衡分析** — 量化單一來源主導程度並比較來源分布健康度。
- **主導異常偵測** — 找出權重過高、互相引用或內容重複造成的偏置。
- **因果線索追蹤** — 追查提示、檢索排序與來源權重如何改變模型結論。
- **證據缺口清單** — 逐項標示缺少獨立佐證或觀點覆蓋不足的主張。
- **再平衡方案** — 排序降權、補檢索與人工查證建議並模擬改善幅度。

## 適合誰使用

## 運作流程

1. 定位高風險結論
2. 繪製來源影響
3. 檢測主導偏置
4. 追查形成原因
5. 補齊證據缺口
6. 核准再平衡
