# 客運駕駛交班管理台

> 將客運駕駛每日交班事項、車況摘要、路線異常與遺留任務集中留存，讓接班人確認風險及待辦，避免資訊只靠口頭傳遞。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **交班摘要** — 彙整班次、車輛及路線事項
- **車況留言** — 記錄駕駛觀察與待檢項目
- **路線異常** — 標示改道、停靠與施工資訊
- **遺留任務** — 分派下一班需完成的事項
- **接班確認** — 逐項閱讀並回覆處理方式
- **交班追溯** — 查詢班次交接與異常歷程

## 適合誰使用

- 值班駕駛
- 站務主管
- 調度員

## 運作流程

1. 彙整班次
2. 記錄異常
3. 建立待辦
4. 主管審閱
5. 接班簽認
6. 結案追蹤

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
