# 職涯路徑情境規劃器

> 比較多條職涯路徑的技能、時間與機會成本，支持員工自主發展。提升人才流動與職涯規劃的透明度。

比較多條職涯路徑的技能、時間與機會成本，支持員工自主發展。提升人才流動與職涯規劃的透明度。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **職涯起點盤點** — 整理現職經驗、已驗證技能、偏好與可投入發展時間。
- **路徑候選探索** — 探索專業深化、管理、跨職能與內部轉調等可能路徑。
- **技能階梯比較** — 比較各路徑所需技能、差距、先修條件與可轉移能力。
- **時間成本模擬** — 估算學習、輪調與累積實務經驗所需時間及工作負荷。
- **機會成本權衡** — 比較薪酬、職缺機率、發展彈性與放棄其他路徑的代價。
- **個人發展路線圖** — 將選定路徑轉為技能里程碑、實務任務與檢視節點。

## 適合誰使用

- L&D 主管
- 部門主管
- 員工

## 運作流程

1. 盤點個人起點
2. 探索候選路徑
3. 比較技能階梯
4. 模擬時間投入
5. 權衡機會成本
6. 確認發展路線

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
