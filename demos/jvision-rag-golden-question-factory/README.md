**產業別：**資訊科技　|　**系統類型：**analytics-bi

## 功能模組

- **真實問答候選池** — 從工單、對話與搜尋紀錄彙整候選問題。
- **問題意圖分群** — 依業務主題、意圖、語言與難度建立覆蓋分類。
- **黃金答案編修** — 建立標準答案、必要要點與不可接受敘述。
- **依據片段綁定** — 將答案連結至核准知識來源與有效版本。
- **評測集平衡** — 檢查主題分布、難度、重複度與邊界案例。
- **問題集維護排程** — 追蹤知識變更並安排重驗、汰換與補題。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 匯入候選問答
2. 分群覆蓋主題
3. 編修黃金答案
4. 綁定知識依據
5. 檢查評測平衡
6. 發布維護週期
