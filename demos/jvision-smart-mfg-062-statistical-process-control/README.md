# SPC（Statistical Process Control）

> 從異常到改善的品質閉環與追溯稽核

SPC（Statistical Process Control）提供即時管制圖繪製、製程能力分析（Cp/Cpk）、超出管制界線警報。製程工程部依「數據自動採集→管制圖繪製→異常判讀→警報通知→工程師處理」推進作業，優先解決「人工繪圖耗時」，品保部則以Cpk值與製程異常次數確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 製程工程部
- 品保部
- 生產部

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉

## 導入效益

- 批號追溯時間：169分鐘 → **14分鐘**
- 客訴平均關案：20天 → **8.5天**
- 改善驗證率：60% → **92%**
- 重複不良率：5.6% → **1.9%**
