# 光學少樣本缺陷學習台

> 讓工廠以少量已確認的自動光學檢測（AOI）缺陷影像建立學習任務，透過樣本挑選、增強預覽、訓練模擬、測試比較與版本發布畫面，快速評估新產品或罕見缺陷是否具備可用辨識能力。

讓工廠以少量已確認的自動光學檢測（AOI）缺陷影像建立學習任務，透過樣本挑選、增強預覽、訓練模擬、測試比較與版本發布畫面，快速評估新產品或罕見缺陷是否具備可用辨識能力。

**產業別：**AI 工程平台　|　**系統類型：**it-ops

## 功能模組

- **學習專案總覽** — 彙整產品、缺陷類別、樣本充足度與版本狀態。
- **代表樣本挑選** — 比較影像差異並選入少量正樣本與對照樣本。
- **樣本增強預覽** — 預覽旋轉、亮度、裁切等模擬變化及適用範圍。
- **學習任務設定** — 選擇基礎模型、樣本組合與模擬訓練參數。
- **測試比較實驗室** — 以保留案例比較候選模型的命中、誤判與混淆結果。
- **模型版本發布** — 整理審核紀錄並發布為離線展示用候選版本。

## 適合誰使用

- AI 模型工程師
- 品保工程師
- 製程工程師

## 運作流程

1. 建立學習專案
2. 挑選代表樣本
3. 設計增強方案
4. 設定學習任務
5. 驗證辨識效果
6. 審核候選版本
