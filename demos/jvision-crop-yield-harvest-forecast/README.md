# 農產量與採收預測平台

> 整合歷年產量、田區作業、作物生育與模擬氣象資料，預測各田區產量及適收日期，協助農場提早安排採收人力、包裝產能與出貨批次，並以情境比較降低延誤、過熟及供貨落差。

整合歷年產量、田區作業、作物生育與模擬氣象資料，預測各田區產量及適收日期，協助農場提早安排採收人力、包裝產能與出貨批次，並以情境比較降低延誤、過熟及供貨落差。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **農務總覽** — 以田區地圖、產量趨勢與風險卡片掌握整體採收態勢。
- **田區生育追蹤** — 查看各田區作物品種、生育階段、作業紀錄與成熟度。
- **產量預測** — 呈現各批次預估產量、信賴區間及影響因子。
- **採收窗口** — 用日曆比較適收日期、天候風險與品質衰退區間。
- **採收排程** — 依產量與窗口模擬班組、人力、包裝及出貨配置。
- **情境比較** — 比較提前、延後或分批採收對產量與交期的影響。

## 適合誰使用

- 農場場長
- 栽培管理員
- 採收班長與產銷規劃人員

## 運作流程

1. 掌握農務態勢
2. 確認田區狀態
3. 研判預估產量
4. 選定採收窗口
5. 配置採收資源
6. 核准執行方案

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
