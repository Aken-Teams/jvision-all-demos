# 馬達振動故障分類系統

> 透過擬真的馬達振動波形、頻譜與運轉條件，分類不平衡、不對心、軸承故障及機座鬆動等狀況，讓工程人員比較特徵、完成複核，並依故障嚴重度安排處置。

## 功能模組

- **故障分類總覽** — 呈現各類故障數量、嚴重度分布與高風險馬達排行。
- **振動波形分析** — 檢視三軸擬真波形、振幅、均方根值與異常時間區段。
- **振動頻譜分析** — 顯示轉頻、倍頻及特徵頻帶，支援圖表縮放與標記。
- **故障類型判讀** — 比較不平衡、不對心、軸承故障及鬆動的分類依據。
- **分類結果複核** — 讓工程師確認或修正分類、嚴重度與判讀備註。
- **處置案件管理** — 依故障類型建立校正、鎖固、檢修或追蹤量測案件。

## 適合誰使用

- 振動分析工程師
- 設備工程師
- 維修主管

## 運作流程

1. 掌握故障分布
2. 檢視振動波形
3. 分析頻譜特徵
4. 研判故障類型
5. 複核分類結果
6. 建立處置案件
