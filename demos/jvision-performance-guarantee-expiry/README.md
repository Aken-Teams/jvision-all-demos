# 履約保證到期控管台

> 集中管理履約保證金與銀行保證函的金額、正本位置、效期、展延條件及解除進度，避免保證失效違約或完工後持續占用授信。

集中管理履約保證金與銀行保證函的金額、正本位置、效期、展延條件及解除進度，避免保證失效違約或完工後持續占用授信。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **保證總覽** — 查看金額效期與型態
- **正本保管** — 追蹤文件位置與借還
- **到期預警** — 提示展延與通知期限
- **展延辦理** — 管理申請用印與換函
- **解除申請** — 確認完工後返還條件
- **授信分析** — 呈現占額與手續費

## 適合誰使用

- 財務融資人員
- 合約管理員
- 專案經理

## 運作流程

1. 建立保證
2. 正本入庫
3. 評估到期
4. 主管核准
5. 銀行辦理
6. 釋放授信

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
