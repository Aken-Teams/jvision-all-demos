# 不良品質成本機會雷達

> 將報廢、重工、退貨、客訴、停線與加急等不良品質成本集中換算，以產品、產線、缺失及客戶分析損失熱點，協助管理者辨識最值得優先改善且可量化回收的品質機會。

將報廢、重工、退貨、客訴、停線與加急等不良品質成本集中換算，以產品、產線、缺失及客戶分析損失熱點，協助管理者辨識最值得優先改善且可量化回收的品質機會。

**產業別：**財務會計　|　**系統類型：**analytics-bi

## 功能模組

- **品質損失總覽** — 呈現內外部失敗成本、趨勢及營收占比。
- **成本組成分析** — 拆解報廢、重工、退貨、客訴、停線與加急費用。
- **損失熱點雷達** — 依產品、產線、缺失、供應商及客戶定位熱點。
- **改善效益試算** — 模擬缺失降低幅度、投入成本與預期回收。
- **機會優先矩陣** — 按損失、可改善性、時程與信心排列專案。
- **效益實現追蹤** — 比較預估節省、實際節省與持續維持情況。

## 適合誰使用

- 品質經理
- 財務分析人員
- 廠長與改善專案負責人

## 運作流程

1. 彙整品質損失
2. 拆解成本來源
3. 定位損失熱點
4. 試算改善回收
5. 排定改善優先序
6. 確認實現效益

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
