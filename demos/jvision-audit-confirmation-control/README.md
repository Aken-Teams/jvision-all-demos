# 會計師函證寄回管制台

> 管理函證編號、地址驗證、獨立寄發、物流、直接回函、差異與替代程序，確保查核截止前取得符合獨立性要求的證據並完整封存。

管理函證編號、地址驗證、獨立寄發、物流、直接回函、差異與替代程序，確保查核截止前取得符合獨立性要求的證據並完整封存。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **函證清單** — 管理對象金額與編號
- **地址驗證** — 查驗獨立來源聯絡資料
- **寄件管制** — 記錄直接寄發與物流
- **回函收件** — 核對來源封緘與簽章
- **差異追蹤** — 處理未符與回覆差異
- **替代程序** — 記錄替代證據與覆核

## 適合誰使用

- 查核助理
- 審計經理
- 品質覆核人員

## 運作流程

1. 建立函證母體
2. 驗證寄送地址
3. 執行獨立寄發
4. 查驗直接回函
5. 處理未回差異
6. 品質覆核封存

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
