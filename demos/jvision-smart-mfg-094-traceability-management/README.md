# Traceability Management決策室

建立從原物料、製程參數到成品出貨之完整履歷鏈，支援快速品質問題溯源與批次回收。

- 原始系統：Traceability Management（產品追溯管理）
- 產業分類：智慧製造｜品質管理
- 使用部門：品保部、生產部、倉儲部、客服部
- 工作流程：原料入庫綁定→製程履歷記錄→成品序號生成→出貨對應登錄→追溯查詢
- AI 應用：異常批次影響範圍自動推算、追溯路徑自動視覺化
- 主要 KPI：追溯查詢時效、追溯完整度、批次回收準確率
- 代表產品：Critical Manufacturing MES、iTAC MES、以客製化開發為主
