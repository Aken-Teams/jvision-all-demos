# 橡膠混煉秤料覆核台

> 供橡膠混煉現場按配方順序核對主膠、炭黑、油料與小藥重量，對相似料和公斤公克進行雙人覆核，剩料回扣後才允許投入密煉機。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **配方秤單** — 查看投料順序
- **分站秤料** — 登錄各料實重
- **超差處理** — 攔截重量錯誤
- **雙人覆核** — 確認料名單位
- **密煉投料** — 完成鍋次交接
- **剩料退回** — 回扣批號重量

## 適合誰使用

- 秤料員
- 混煉班長

## 運作流程

1. 配方領取
2. 原料備妥
3. 逐項秤料
4. 雙人覆核
5. 投入密煉
6. 剩料結清
