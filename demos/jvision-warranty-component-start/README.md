# 設備保固起算確認台

> 釐清設備到貨、安裝、試運轉、驗收與正式使用等不同日期，依契約判定各設備保固起算點，追蹤爭議確認、延長承諾、保固證明及移交期限。

釐清設備到貨、安裝、試運轉、驗收與正式使用等不同日期，依契約判定各設備保固起算點，追蹤爭議確認、延長承諾、保固證明及移交期限。

**產業別：**營建工程　|　**系統類型：**maintenance-cmms

## 功能模組

- **設備清冊** — 依系統、標籤與供應商建立保固對象。
- **日期事件** — 彙整到貨、安裝、試運轉、驗收與啟用日。
- **條款判讀** — 標示契約起算規則、期限及例外約定。
- **廠商確認** — 發送日期證據並追蹤同意或異議。
- **展延處理** — 記錄延長承諾、停用期間與新到期日。
- **保固移交** — 產出設備保固證明及物業接管清冊。

## 適合誰使用

- 機電工程師
- 採購人員
- 物業移交人員

## 運作流程

1. 建立設備
2. 蒐集日期
3. 判讀條款
4. 廠商確認
5. 核定展延
6. 移交物業

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
