# 費用報銷合規審核助理

> 依企業費用政策檢查報銷單的金額上限、日期、類別、憑證與重複申請風險，清楚呈現命中條款並引導補件、退回或核准，協助主管與財會提升審核一致性。

依企業費用政策檢查報銷單的金額上限、日期、類別、憑證與重複申請風險，清楚呈現命中條款並引導補件、退回或核准，協助主管與財會提升審核一致性。

**產業別：**財務會計　|　**系統類型：**finance-case

## 功能模組

- **報銷單建立** — 填寫費用明細、專案、日期與付款資訊並附模擬憑證。
- **憑證檢視台** — 並列收據影像樣張、欄位內容與缺件提示。
- **合規檢查結果** — 依費用類別列出通過、警示與違規條款。
- **重複報銷比對** — 顯示金額、日期及商家相近的可疑歷史申請。
- **例外與補件處理** — 選擇退回、補充說明或提出政策例外申請。
- **分級審核簽核** — 依金額與風險呈現主管及財會的審核節點。

## 適合誰使用

- 報銷申請人
- 部門主管
- 費用會計與稽核人員

## 運作流程

1. 提交報銷申請
2. 確認憑證內容
3. 檢視合規結果
4. 排查重複申請
5. 處理例外補件
6. 完成分級簽核

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
