# 軋機板形厚度調校台

> 以軋延道次、輥縫、張力、彎輥及厚度剖面等擬真資料，協助操作員辨識板形與厚差來源，模擬調校參數並比較品質風險，縮短換規格後的穩定時間與不良長度。

以軋延道次、輥縫、張力、彎輥及厚度剖面等擬真資料，協助操作員辨識板形與厚差來源，模擬調校參數並比較品質風險，縮短換規格後的穩定時間與不良長度。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **軋線總覽** — 呈現機架狀態、規格進度與板形厚度品質摘要。
- **板形剖面** — 以橫向剖面及熱圖辨識浪形與不對稱區域。
- **厚度追蹤** — 查看長度方向厚差、公差帶與超差發生位置。
- **因子診斷** — 分析輥縫、張力、彎輥與速度對偏差的貢獻。
- **參數試調** — 模擬控制參數調整後的板形、厚度與設備負荷。
- **調校驗證** — 比較調整前後品質，建立規格別最佳參數卡。

## 適合誰使用

- 軋機操作員
- 軋延製程工程師
- 品質工程師

## 運作流程

1. 檢視軋線
2. 判讀板形
3. 追查厚差
4. 診斷因子
5. 模擬調校
6. 驗證定版
