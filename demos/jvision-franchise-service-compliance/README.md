# 加盟服務履約督導台

> 供連鎖清潔、家事或到府服務品牌管理加盟店的服務項目授權、案件抽查、客戶承諾、改善輔導與品牌費用扣補，維持跨區服務一致性。

**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **加盟店總覽** — 比較各店履約與風險
- **授權範圍** — 維護可承作服務與區域
- **案件抽查** — 抽核報價、紀錄與證據
- **承諾追蹤** — 掌握客戶承諾完成狀態
- **改善輔導** — 建立門店改善與複查計畫
- **獎懲核算** — 試算獎勵、扣款及申覆

## 適合誰使用

- 加盟營運督導
- 區域經理
- 品牌客服

## 運作流程

1. 檢視加盟表現
2. 確認授權範圍
3. 抽查履約案件
4. 追蹤客戶承諾
5. 執行改善輔導
6. 完成獎懲核算

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
