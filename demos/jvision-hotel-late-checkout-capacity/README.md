# 旅宿延遲退房協調台

> 依當日住房、房務清掃容量與下一組入住時間，受理延遲退房、試算加收費並協調房務順位，避免櫃台口頭承諾造成房間來不及交付。

**產業別：**餐飲旅宿　|　**系統類型：**pos-frontdesk

## 功能模組

- **退房看板** — 顯示續住房況與入住壓力
- **延退申請** — 登錄時段及旅客需求
- **房務影響** — 評估清掃容量與順位
- **費用試算** — 依房型會員規則計費
- **主管核定** — 核准時限或拒絕申請
- **執行追蹤** — 提醒退房與房務接手

## 適合誰使用

- 櫃台人員
- 房務主管
- 值班經理

## 運作流程

1. 檢視房況
2. 建立申請
3. 評估清掃
4. 試算費用
5. 核定承諾
6. 追蹤交房

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
