# 材料三單匹配審核台

> 將採購單、現場收料單與供應商發票按料號、工地、批次、數量及單價匹配，隔離短收、錯價、重複發票與跨案代送後再付款。

將採購單、現場收料單與供應商發票按料號、工地、批次、數量及單價匹配，隔離短收、錯價、重複發票與跨案代送後再付款。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **採購單** — 查看核准數量與價格
- **收料單** — 確認工地批次與實收
- **供應商發票** — 登錄請款明細與稅額
- **三單匹配** — 比對品項數量及單價
- **例外處理** — 處理短收錯價與重複
- **付款釋放** — 核准符合條件的款項

## 適合誰使用

- 應付會計
- 採購專員
- 材料管理員

## 運作流程

1. 匯入採購
2. 確認收料
3. 接收發票
4. 執行匹配
5. 異常確認
6. 釋放付款

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
