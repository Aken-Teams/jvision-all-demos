# 標案資格文件檢核台

> 把招標須知轉為資格、規格、用印、份數及電子檔規則，追蹤證明效期與最終封包版本，降低漏章、過期文件或命名錯誤造成廢標。

**產業別：**營建工程　|　**系統類型：**legal-case

## 功能模組

- **標案總覽** — 查看截止與文件狀態
- **資格矩陣** — 拆解招標須知要求
- **證明收件** — 管理文件效期與版本
- **用印追蹤** — 控制簽章份數與正本
- **封包覆核** — 核對紙本電子檔內容
- **送標簽認** — 雙人確認最終版本

## 適合誰使用

- 投標專員
- 法務人員
- 用印保管人

## 運作流程

1. 解析須知
2. 分派備件
3. 文件收件
4. 辦理用印
5. 封包覆核
6. 正式送標

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
