# 經銷商專案報備審核台

> 受理經銷商專案報備，正規化終端客戶、產品與預估金額，檢查重複報備及保護期，透過審核與續期機制建立可仲裁的通路優先權。

受理經銷商專案報備，正規化終端客戶、產品與預估金額，檢查重複報備及保護期，透過審核與續期機制建立可仲裁的通路優先權。

**產業別：**業務銷售　|　**系統類型：**sales-crm

## 功能模組

- **報備申請** — 登錄客戶產品與預估案值
- **客戶正規化** — 比對法人別名與關係戶
- **撞單檢查** — 找出重疊產品與期間
- **報備審核** — 核定優先權與保護條件
- **續期管理** — 追蹤進度及延長申請
- **爭議仲裁** — 依時間證據裁定權利

## 適合誰使用

- 經銷商窗口
- 通路經理
- 業務主管

## 運作流程

1. 提交報備
2. 正規化客戶
3. 檢查撞單
4. 核准保護
5. 追蹤續期
6. 處理爭議

## 導入效益

- 商機轉換率：18% → **27%**
- 平均回應時間：26小時 → **6小時**
- 客戶資料完整率：62% → **94%**
- 報價逾期流失：9件/月 → **2件/月**
