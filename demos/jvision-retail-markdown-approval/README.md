# 零售即期折價決策台

> 依門市商品效期、庫存量、銷速與毛利底線，產生分階段折價建議，經核准後派發到店執行並追蹤售罄、報廢及毛利結果。

依門市商品效期、庫存量、銷速與毛利底線，產生分階段折價建議，經核准後派發到店執行並追蹤售罄、報廢及毛利結果。

**產業別：**零售電商　|　**系統類型：**operations-console

## 功能模組

- **效期風險** — 彙整批次效期、庫存與剩餘銷售日。
- **折價模擬** — 比較折扣階梯、售罄率及毛利影響。
- **方案核准** — 依品類權限審核價格與適用門市。
- **標示派發** — 產生門市貼標、陳列與生效任務。
- **執行回報** — 記錄上架數、售出數與撤架數量。
- **成效檢討** — 分析折價收益、報廢及門市差異。

## 適合誰使用

- 品類經理
- 區域督導
- 門市店長

## 運作流程

1. 盤點風險
2. 模擬折扣
3. 核准方案
4. 派發任務
5. 執行折價
6. 檢討結果

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
