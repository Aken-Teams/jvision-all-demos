# 貨損短少索賠管理台

> 協助物流業者集中處理破損、遺失、短少與溫控異常的索賠案件，從責任判定、證據清單、賠償試算到承運商追償，保留完整時序與核准紀錄。

協助物流業者集中處理破損、遺失、短少與溫控異常的索賠案件，從責任判定、證據清單、賠償試算到承運商追償，保留完整時序與核准紀錄。

**產業別：**物流運輸　|　**系統類型：**finance-case

## 功能模組

- **異常受理** — 建立貨損、遺失與短少案件
- **證據清單** — 整理簽收、照片及聯繫紀錄
- **責任判定** — 依運送節點標記責任歸屬
- **賠償試算** — 套用限額與商品價值計算
- **追償管理** — 向承運商提出並追蹤求償
- **結案覆核** — 確認付款、追償與客戶回覆

## 適合誰使用

- 物流客服
- 理賠專員
- 營運主管

## 運作流程

1. 受理異常通報
2. 彙整案件證據
3. 判定責任歸屬
4. 試算賠償方案
5. 執行承運追償
6. 完成案件結案

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
