# SMT產線管理系統（SMT Line Management System）

> 訂單到入庫的製造現場全流程數位化

SMT產線管理系統（SMT Line Management System）提供印刷/貼片/回焊設備連線整合、貼片程式版本管理、SPI/AOI數據整合追溯。SMT製造工程依「程式下發 → 設備連線執行 → 製程/檢測數據採集 → 追溯資料綁定 → 產線績效分析」推進作業，優先解決「SMT多站設備資料分散難以整合」，生產則以SMT稼動率與首件合格率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生產製造　|　**系統類型：**MES 製造執行系統

## 功能模組

- **工單管理** — 訂單轉工單、拆併單與工單派發
- **排程排產** — 依產能、交期、負載自動排程
- **現場執行** — 派工、報工與進度即時回報
- **設備稼動 OEE** — 稼動、效率、良率即時監控
- **品質入庫** — 檢驗判定、不良處置與入庫
- **AI 改善建議** — 異常摘要與瓶頸改善建議

## 適合誰使用

- SMT製造工程
- 生產
- 品保

## 運作流程

1. 待排程
2. 生產中
3. 待品檢
4. 已入庫

## 導入效益

- 排程作業工時：8.2小時/日 → **1.5小時/日**
- 準時交付率：85% → **99%**
- 缺料停線次數：12次/月 → **2.8次/月**
- 設備稼動率：74% → **86%**
