# 結構化面試品質教練

> 依職缺職能建立一致的面試題組、追問提示與評分錨點，透過擬真面試紀錄分析提問覆蓋、評語證據及面試官評分差異，提升選才一致性並降低直覺偏誤。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **面試題組設計** — 依職能挑選行為題、情境題、追問及禁問題提示。
- **評分錨點設定** — 定義各職能不同分數的可觀察行為與證據標準。
- **面試引導模式** — 以流程卡呈現時間配置、題目、追問與即時筆記區。
- **紀錄品質檢查** — 檢查評語是否具體、有證據且與評分相互支持。
- **面試官校準** — 比較多位面試官的評分差距、理由與待討論項目。
- **品質教練回饋** — 呈現提問習慣、偏誤風險與可練習的改善建議。

## 適合誰使用

- 招募人員
- 面試官
- 用人主管

## 運作流程

1. 建立題組
2. 設定尺度
3. 執行面試
4. 檢查紀錄
5. 校準評分
6. 取得回饋
