# 會員權益介接補帳台

> 比對門店交易與會員權益異動，辨識少加、重複加值及斷線補送案件，讓客服依原始交易安全補帳並經覆核，避免直接手改餘額。

**產業別：**生活服務　|　**系統類型：**it-ops

## 功能模組

- **權益差異** — 列出少給多給與未回寫
- **交易證據** — 查閱收銀付款與原單
- **訊息鏈路** — 串起發送重送與回覆
- **補帳判定** — 建議補加沖回或不處理
- **覆核調整** — 雙人核准餘額異動
- **會員通知** — 回報結果並保存案件

## 適合誰使用

- 會員客服
- 系統營運人員
- 財務覆核

## 運作流程

1. 發現權益差異
2. 還原原始交易
3. 檢查重送鏈路
4. 核定補帳方式
5. 執行權益調整
6. 通知會員結案

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
