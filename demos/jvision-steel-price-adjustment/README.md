# 鋼材價格調整結算台

> 依契約公式、基期、指數月份與適用數量計算鋼材調整款，保留公式版本及雙向補貼勾稽，避免向業主請調又重複補貼分包商。

依契約公式、基期、指數月份與適用數量計算鋼材調整款，保留公式版本及雙向補貼勾稽，避免向業主請調又重複補貼分包商。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **指數資料** — 管理基期與月份指數
- **契約公式** — 設定門檻權重與除外
- **適用數量** — 連結估驗與鋼材用量
- **調價試算** — 計算增減與累計款
- **雙向勾稽** — 核對業主及分包補貼
- **結算簽核** — 發布可請領支付金額

## 適合誰使用

- 合約工程師
- 成本會計
- 估驗工程師

## 運作流程

1. 設定公式
2. 更新指數
3. 確認數量
4. 執行試算
5. 雙向覆核
6. 完成結算

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
