# 機台產品良率關聯分析

> 整合模擬的機台、生產工單、產品與品質檢驗資料，交叉分析不同機型、機台及製程參數對良率的影響，協助工廠快速辨識高風險設備、比較改善前後成果，並建立可追蹤的品質改善依據。

整合模擬的機台、生產工單、產品與品質檢驗資料，交叉分析不同機型、機台及製程參數對良率的影響，協助工廠快速辨識高風險設備、比較改善前後成果，並建立可追蹤的品質改善依據。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **良率監控總覽** — 以指標卡、趨勢圖及產線熱區呈現整體良率與異常機台。
- **機台效能比較** — 比較各機台的產量、良率、不良類型與參數分布差異。
- **產品交叉分析** — 以產品、機型與機台矩陣找出特定組合的品質落差。
- **關聯因子探索** — 呈現轉速、溫度、壓力等模擬參數與良率的統計關聯。
- **異常批次追溯** — 沿工單與生產批次查看機台紀錄、檢驗結果及不良明細。
- **改善成效追蹤** — 管理改善措施、負責人、期限及改善前後的良率變化。

## 適合誰使用

- 品質主管
- 製程工程師
- 生產主管
- 設備工程師

## 運作流程

1. 掌握良率概況
2. 比較機台表現
3. 確認產品組合
4. 探索影響因子
5. 追溯異常批次
6. 驗證改善成果
