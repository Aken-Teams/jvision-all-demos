# 職缺人才智慧配對平台

> 將職缺條件拆成技能、經驗、證照、地點與班別等可比較項目，對擬真假人才產生配對分數、依據與風險提示，協助中小企業更快建立候選名單且避免只憑關鍵字篩選。

將職缺條件拆成技能、經驗、證照、地點與班別等可比較項目，對擬真假人才產生配對分數、依據與風險提示，協助中小企業更快建立候選名單且避免只憑關鍵字篩選。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **職缺需求解析** — 將職務說明拆解為必要條件、加分項與可培養能力。
- **人才推薦池** — 以卡片呈現內外部擬真假人才、配對分數及推薦理由。
- **候選比較台** — 並列技能、經驗、期待條件、缺口與潛在風險。
- **配對條件調校** — 調整條件權重、必要門檻及替代能力後預覽排序變化。
- **招募短名單** — 將合適人才分組，記錄推薦狀態、負責人與下一步。
- **配對成效分析** — 呈現來源、推薦採用、階段轉換與條件偏誤概況。

## 適合誰使用

- 招募人員
- 用人主管
- 人資主管

## 運作流程

1. 解析職缺
2. 取得推薦
3. 比較人才
4. 調整條件
5. 建立短名單
6. 檢討成效

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
