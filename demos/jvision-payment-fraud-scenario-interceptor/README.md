# 付款詐欺情境攔截器

> 融合帳戶異動、付款行為與關係網絡，在放款前攔截高風險詐欺情境。

融合帳戶異動、付款行為與關係網絡，在放款前攔截高風險詐欺情境。

**產業別：**財務會計　|　**系統類型：**security-soc

## 功能模組

- **付款風險佇列** — 依金額、時效與模型風險集中排列待審付款指令。
- **收款帳戶異動檢查** — 核對帳戶變更時間、來源管道、雙重確認及歷史資料差異。
- **付款行為偏差** — 偵測異常金額、時段、頻率、幣別、裝置與操作人行為。
- **關係網絡辨識** — 分析供應商、帳戶、聯絡人與員工間的共用及隱藏關聯。
- **放款攔截控制** — 依風險門檻暫停、退回或升級付款，重大動作要求人工核准。
- **詐欺調查案件** — 整合聯絡驗證、關係線索與處置紀錄，追蹤案件至解除或通報。

## 適合誰使用

- 財務長
- Treasurer
- 資金人員

## 運作流程

1. 篩選高風險付款
2. 核驗帳戶變更
3. 檢查行為偏差
4. 追查關係網絡
5. 決定攔截措施
6. 完成調查處置

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
