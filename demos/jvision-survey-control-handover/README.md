# 放樣基準移交管制台

> 管理控制點、基準線與高程點的設置、複測、圖面定位、跨工種移交及毀損復原，讓承接工班確認使用同一基準，降低錯位施工與責任爭議。

管理控制點、基準線與高程點的設置、複測、圖面定位、跨工種移交及毀損復原，讓承接工班確認使用同一基準，降低錯位施工與責任爭議。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **基準點台帳** — 依棟別樓層管理座標、高程與點位狀態。
- **圖面定位** — 將控制點標註於平面圖並附現場照片。
- **複測紀錄** — 記錄儀器、閉合差、偏差與複測結果。
- **工種移交** — 指定接收工班、用途及有效施工範圍。
- **毀損通報** — 回報遮蔽、移位或破壞並暫停引用。
- **異動追溯** — 保存重設前後數值與簽認歷程。

## 適合誰使用

- 測量工程師
- 現場工程師
- 分包領班

## 運作流程

1. 建立點位
2. 現場標定
3. 聯合複測
4. 發起移交
5. 簽收使用
6. 維護復原

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
