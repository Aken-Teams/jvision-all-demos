# 工程發票期間歸屬台

> 把供應商發票與實際施工月份、估驗期間及暫估紀錄連結，管理跨期成本、迴轉與重複暫估例外，避免專案月毛利因入帳時點失真。

把供應商發票與實際施工月份、估驗期間及暫估紀錄連結，管理跨期成本、迴轉與重複暫估例外，避免專案月毛利因入帳時點失真。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **發票清冊** — 查看單據與歸屬狀態
- **施工期間** — 由工地確認實際月份
- **估驗連結** — 勾稽合約與完成工作
- **暫估建立** — 登錄已發生未到票成本
- **迴轉檢查** — 避免重複與錯期沖回
- **毛利影響** — 呈現調整前後專案毛利

## 適合誰使用

- 成本會計
- 工務工程師
- 財務主管

## 運作流程

1. 匯入發票
2. 確認施工期
3. 勾稽估驗
4. 建立暫估
5. 執行迴轉
6. 月結覆核

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
