# 印刷電路板孔位偏移檢測系統

> 以模擬鑽孔圖、板件影像與尺寸資料檢查通孔、導通孔及定位孔的中心偏移，呈現公差圓、偏移方向與超規程度，支援人工覆核、批次判定及鑽孔製程改善追蹤。

以模擬鑽孔圖、板件影像與尺寸資料檢查通孔、導通孔及定位孔的中心偏移，呈現公差圓、偏移方向與超規程度，支援人工覆核、批次判定及鑽孔製程改善追蹤。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **孔位品質看板** — 顯示超規孔數、偏移量、合格率與批次風險。
- **鑽孔圖紙瀏覽** — 查看模擬孔位分布、孔型、孔徑及設計座標。
- **孔位疊合檢測** — 疊合設計中心與實際孔影像，呈現偏移方向。
- **公差量測複核** — 逐孔查看偏移距離、孔環餘量及超規程度。
- **批次合格判定** — 依抽樣與公差規則模擬核准、重檢或退回批次。
- **偏移趨勢分析** — 分析機台代碼、孔型、區域與方向的偏移分布。

## 適合誰使用

- PCB 尺寸檢驗員
- 鑽孔製程工程師
- 品質主管

## 運作流程

1. 掌握品質
2. 核對圖紙
3. 執行疊合
4. 複核公差
5. 判定批次
6. 追蹤改善

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
