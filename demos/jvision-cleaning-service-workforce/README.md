# 清潔服務派班驗收台

> 管理商辦與社區清潔合約的定期班表、臨時代班、工作清單、現場照片紀錄及客戶驗收，降低缺勤與漏做造成的扣款。

**產業別：**生活服務　|　**系統類型：**service-desk

## 功能模組

- **案場合約** — 查看服務時段與工作範圍
- **人員派班** — 安排定期班表與技能需求
- **缺勤代班** — 媒合可支援的清潔人員
- **工作執行** — 勾選區域與清潔項目
- **客戶驗收** — 記錄評分及缺失內容
- **缺失改善** — 指派複查與完成期限

## 適合誰使用

- 清潔區域督導
- 派班專員
- 案場領班

## 運作流程

1. 設定合約
2. 建立班表
3. 處理代班
4. 回報工作
5. 執行驗收
6. 完成改善

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
