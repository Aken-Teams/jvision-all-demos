# 店內顧客動線熱區優化台

> 透過預先產生的匿名動線與區域停留資料，在店舖平面圖呈現熱區、冷區及路徑流失，協助營運團隊比較陳列調整情境、規劃實驗並評估改善成果。

透過預先產生的匿名動線與區域停留資料，在店舖平面圖呈現熱區、冷區及路徑流失，協助營運團隊比較陳列調整情境、規劃實驗並評估改善成果。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **店舖平面總覽** — 在可切換的門市平面圖上呈現區域、入口、結帳與展示位置。
- **停留熱區分析** — 以預載資料顯示各區停留密度、時段變化和冷熱區排行。
- **顧客路徑分析** — 查看匿名聚合路徑、常見順序、折返點與中途流失位置。
- **客群時段比較** — 比較不同模擬客群、日期與時段的動線和停留差異。
- **空間方案模擬** — 移動展示區與導引點，預覽方案對路徑覆蓋和熱區分布的影響。
- **優化實驗追蹤** — 建立前後測計畫，並排比較基準與調整後的模擬成效。

## 適合誰使用

- 門市營運主管
- 陳列設計人員
- 數據分析師
- 店長

## 運作流程

1. 選擇店舖範圍
2. 辨識冷熱區域
3. 分析主要路徑
4. 比較客群時段
5. 模擬空間調整
6. 追蹤優化實驗

- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
