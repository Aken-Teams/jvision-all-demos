# 病人主索引整併台

> 集中審查一人多號與疑似誤併案件，比對證件、姓名沿革、聯絡資料及跨系統病歷分布，經雙人核准後發布拆分或合併指令並追蹤同步結果。

集中審查一人多號與疑似誤併案件，比對證件、姓名沿革、聯絡資料及跨系統病歷分布，經雙人核准後發布拆分或合併指令並追蹤同步結果。

**產業別：**醫療照護　|　**系統類型：**it-ops

## 功能模組

- **疑似群組** — 列出重複病人
- **身分比對** — 核對識別證據
- **病歷分布** — 檢視跨系統資料
- **影響預覽** — 模擬合併拆分
- **雙人審核** — 控管高風險操作
- **同步追蹤** — 監看發布結果

## 適合誰使用

- 病歷管理師
- 醫療資訊人員
- 個資主管

## 運作流程

1. 發現疑案
2. 核實身分
3. 盤點病歷
4. 預覽影響
5. 雙人核准
6. 發布驗證

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
