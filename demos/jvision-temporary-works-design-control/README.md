# 臨時工程設計管制台

> 管理施工構台、支撐架、臨時開口防護與吊運平台等臨時工程的設計需求、計算書、圖說審查、現場施作及拆除條件，避免臨時設施未經核定即使用或逾期未拆。

管理施工構台、支撐架、臨時開口防護與吊運平台等臨時工程的設計需求、計算書、圖說審查、現場施作及拆除條件，避免臨時設施未經核定即使用或逾期未拆。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **設計需求** — 登錄用途、荷載、位置及使用期間。
- **計算圖說** — 管理計算書、設計圖與假設條件。
- **專業審查** — 追蹤技師意見、修訂及核定。
- **現場施作** — 依核定圖記錄施工與材料資訊。
- **使用放行** — 查驗現況後核准啟用。
- **拆除復原** — 確認停用條件、拆除及原貌恢復。

## 適合誰使用

- 臨時工程工程師
- 結構技師
- 職安人員

## 運作流程

1. 提出需求
2. 完成設計
3. 專業核定
4. 依圖施作
5. 查驗放行
6. 拆除結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
