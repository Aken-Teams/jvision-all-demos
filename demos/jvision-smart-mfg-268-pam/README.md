# 特權帳號管理系統（PAM）

> 告警分流、事件應變到弱點與合規治理

特權帳號管理系統（PAM）提供特權帳號密碼保險箱管理、工作階段錄影與側錄、臨時授權與到期自動收回。資訊部依「特權帳號納管→密碼保險箱化→申請臨時授權→審核通過開通→操作側錄→到期自動收回」推進作業，優先解決「設備商工程師擁有長期高權限」，資訊安全部則以特權帳號覆蓋率與密碼輪替合規率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**資訊安全　|　**系統類型：**資安 SOC 平台

## 功能模組

- **告警分流** — 資安告警彙整分級
- **事件應變** — 事件調查與處置
- **弱點管理** — 弱點掃描與修補追蹤
- **身分權限** — 帳號與特權管理
- **合規治理** — 政策、稽核與合規
- **端點防護** — 端點偵測與應變

## 適合誰使用

- 資訊部
- 資訊安全部
- 產線設備維護部

## 運作流程

1. 已偵測
2. 調查中
3. 研判確認
4. 已關閉

## 導入效益

- 告警分流時間：48分鐘 → **7.7分鐘**
- 事件平均處理：12小時 → **3.1小時**
- 弱點修補率：71% → **90%**
- 合規稽核工時：29小時/月 → **6小時/月**
