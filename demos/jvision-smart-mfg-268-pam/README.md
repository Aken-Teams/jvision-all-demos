# 特權帳號管理協作所

針對系統管理員、設備商工程師等高權限帳號進行集中控管、密碼保險箱化與工作階段側錄。

- 原始系統：特權帳號管理系統（PAM）
- 產業分類：智慧製造｜IT管理
- 使用部門：資訊部、資訊安全部、產線設備維護部、稽核室
- 工作流程：特權帳號納管→密碼保險箱化→申請臨時授權→審核通過開通→操作側錄→到期自動收回
- AI 應用：異常特權操作行為偵測、高風險帳號使用評分
- 主要 KPI：特權帳號覆蓋率、密碼輪替合規率、異常操作攔截數、第三方存取稽核完成率
- 代表產品：CyberArk PAM、BeyondTrust Password Safe、Delinea Secret Server
