# CMMS（Computerized Maintenance Management System）

> 保養、維修、預兆到備品的設備全生命週期

CMMS（Computerized Maintenance Management System）提供預防保養排程、維修工單管理、備品庫存管理。設備工程依「保養計畫制定 → 工單自動產生 → 維修執行紀錄 → 備品領用 → 履歷歸檔分析」推進作業，優先解決「保養計畫遺漏導致突發停機」，廠務則以平均故障間隔（MTBF）與平均修復時間（MTTR）確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**設備維護　|　**系統類型：**CMMS 設備維護

## 功能模組

- **保養排程** — 預防保養自動排程
- **維修工單** — 報修、派工與完工
- **預兆診斷** — 設備數據異常預警
- **備品管理** — 備品庫存與領用
- **OEE 稼動** — 稼動與故障分析
- **履歷追溯** — 設備維護履歷

## 適合誰使用

- 設備工程
- 廠務
- 品保

## 運作流程

1. 待派工
2. 維修中
3. 試車確認
4. 復機完成

## 導入效益

- 非計畫停機：24小時/月 → **6.1小時/月**
- 保養準時率：72% → **94%**
- 備品缺料：11次/月 → **1.9次/月**
- 故障排除時間：92分鐘 → **26分鐘**
