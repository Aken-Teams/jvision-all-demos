# 客服備品資格判定台

> 協助客服與售後團隊依產品保固、服務合約、故障症狀與客戶等級，判定是否可免費寄送替換備品，完成庫存預留、主管例外核准、寄送承諾與舊品回收追蹤。

**產業別：**客服管理　|　**系統類型：**service-desk

## 功能模組

- **權益查詢** — 彙整保固、合約與客戶服務等級。
- **症狀判定** — 依故障描述建議可用替換備品。
- **資格規則** — 判定免費、押金或付費寄送條件。
- **例外審批** — 處理超保、高價及特殊客戶申請。
- **寄送承諾** — 預留備品並記錄預計出貨日期。
- **舊品回收** — 追蹤故障品寄回與逾期催辦。

## 適合誰使用

- 客服專員
- 售後主管
- 備品管理員

## 運作流程

1. 確認權益
2. 辨識備品
3. 判定資格
4. 核准例外
5. 安排寄送
6. 追蹤回收

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
