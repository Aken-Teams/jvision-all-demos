# 鋼筋進場噸數核對台

> 彙整鋼筋送貨單、磅單、規格、爐號與使用棟別，現場完成進場點收後和採購合約及累計數量勾稽，攔截重量差異、錯料與超約請款。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **進場車次** — 查看供應商與預報重量
- **磅單核對** — 比對毛重皮重與淨重
- **規格批次** — 記錄鋼筋規格爐號棟別
- **差異處理** — 標記短重錯料及退貨
- **合約累計** — 比對訂購量與已收量
- **計價輸出** — 產出可付款的驗收明細

## 適合誰使用

- 工地材料員
- 採購人員
- 工程會計

## 運作流程

1. 接收預報
2. 核對磅重
3. 點收批次
4. 處理差異
5. 檢查合約
6. 送出計價

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
