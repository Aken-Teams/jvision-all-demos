# 塔吊升節附著整備台

> 供高樓營造團隊在塔吊升節前，集中核對附著框施工、焊道檢查、結構強度、技師文件與封鎖時段，依樓層形成可追溯的放行紀錄，降低缺件停工及未核准升節風險。

供高樓營造團隊在塔吊升節前，集中核對附著框施工、焊道檢查、結構強度、技師文件與封鎖時段，依樓層形成可追溯的放行紀錄，降低缺件停工及未核准升節風險。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **升節批次** — 依塔吊、樓層與預定日期建立升節工作批次。
- **附著配置** — 檢視附著框、拉桿與預埋件的位置及責任分工。
- **條件查核** — 核對強度、焊道、螺栓、通道與作業空間。
- **文件彙整** — 收整計算書、簽證、檢查表及操作人員資格。
- **窗口排程** — 協調停吊、封鎖、氣候備案與協力廠商到場。
- **升節放行** — 記錄會簽、限制條件及最終准駁結果。

## 適合誰使用

- 機具工程師
- 工地主任
- 職安人員

## 運作流程

1. 建立升節批次
2. 確認附著配置
3. 查核前置條件
4. 補齊技術文件
5. 協調作業窗口
6. 會簽准予升節

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
