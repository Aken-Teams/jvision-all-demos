# Prompt 可讀性重構器

**產業別：**資訊科技　|　**系統類型：**quality-qms

## 功能模組

- **指令結構解析** — 將角色、目標、限制、範例與輸出規則拆成可檢查的結構。
- **重複規則掃描** — 標示同義、近似與散落重複的指令及其維護負擔。
- **衝突指令偵測** — 找出優先序矛盾、互斥條件與跨段落規則衝突。
- **歧義語句診斷** — 辨識指涉不明、範圍模糊與可能造成多種解讀的語句。
- **重構草案工作台** — 依風險與可讀性產生合併、分層、改寫及命名建議。
- **行為等價驗證** — 比較原版與重構版輸出，確認可讀性提升且核心行為未偏移。

## 適合誰使用

1. 選取待整理 Prompt

4. 編修重構草案
5. 驗證行為等價
6. 核准替換版本
