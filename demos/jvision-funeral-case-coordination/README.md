# 禮儀服務案件協作台

> 管理殯葬禮儀公司從接案、方案確認、場地與人員排程到物品準備及結案請款的完整流程，降低家屬需求變更造成的執行疏漏。

管理殯葬禮儀公司從接案、方案確認、場地與人員排程到物品準備及結案請款的完整流程，降低家屬需求變更造成的執行疏漏。

**產業別：**生活服務　|　**系統類型：**service-desk

## 功能模組

- **案件總覽** — 查看場次時程、風險與待辦。
- **家屬需求** — 記錄儀式偏好與聯繫決議。
- **場次排程** — 安排場地、人員及協力廠商。
- **物品整備** — 檢核用品、花禮與文件。
- **需求變更** — 管理追加項目、版本及簽認。
- **結案請款** — 彙整實際服務與應收款項。

## 適合誰使用

- 禮儀師
- 案件助理
- 營運主管

## 運作流程

1. 建立服務案件
2. 確認家屬需求
3. 編排場次資源
4. 完成物品整備
5. 簽認需求變更
6. 覆核案件結算

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
