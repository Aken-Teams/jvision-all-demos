## 功能模組

- **語意快取總覽** — 呈現命中率、節省推論量、延遲改善與拒絕重用原因。
- **意圖相似比對** — 比較新請求與快取項目的語意意圖、條件及輸出需求。
- **資料版本血緣** — 追蹤答案使用的知識片段、索引版本與來源更新時間。
- **安全重用判定** — 綜合意圖、權限、時效與版本差異計算可重用風險。
- **失效範圍模擬** — 預覽資料或提示更新將使哪些快取答案失效。
- **快取策略審批** — 編輯並核准各情境的相似門檻、存活期與失效規則。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 觀察快取效益
2. 比對請求意圖
3. 核對資料版本
4. 評估重用風險
5. 模擬失效影響
6. 核准快取策略
