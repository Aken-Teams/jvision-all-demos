# 供應商入口網站（Supplier Portal）

> 供應商協同、詢比議價到交期風險控管

供應商入口網站（Supplier Portal）提供訂單/交期線上查詢、文件上傳(報價/認證/發票)、供應商公告與訊息推播。採購部依「供應商註冊 → 訂單/文件同步 → 自助查詢互動 → 問題協作處理 → 紀錄留存」推進作業，優先解決「供應商溝通仰賴email易遺漏」，供應商管理部則以供應商入口使用率與人工詢問工單減少率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**採購供應鏈　|　**系統類型：**SRM 採購供應商管理

## 功能模組

- **供應商管理** — 建檔、分級與績效評分
- **詢報價協作** — 線上詢價、比價與議價
- **採購訂單** — 請購、下單與交期追蹤
- **交期風險** — 缺料預警與到貨監控
- **供應商品質** — 進料檢驗與 SCAR 改善
- **綠色採購** — ESG 評分與永續採購

## 適合誰使用

- 採購部
- 供應商管理部
- 財務部

## 運作流程

1. 待詢價
2. 比價中
3. 待核准
4. 驗收完成

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：87% → **99%**
- 缺料預警覆蓋：38% → **86%**
- 議價作業工時：8小時/週 → **2小時/週**
