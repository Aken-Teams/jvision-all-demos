# 供應商入口網站

提供供應商自助查詢訂單、上傳文件與溝通的線上入口，降低雙方溝通成本。

- 原始系統：供應商入口網站（Supplier Portal）
- 產業分類：智慧製造｜採購管理
- 使用部門：採購部、供應商管理部、財務部
- 工作流程：供應商註冊 → 訂單/文件同步 → 自助查詢互動 → 問題協作處理 → 紀錄留存
- AI 應用：AI 客服機器人回覆常見供應商詢問、文件缺漏自動提醒
- 主要 KPI：供應商入口使用率、人工詢問工單減少率、文件齊備率
- 代表產品：SAP Ariba Network、Coupa Supplier Portal、Oracle Supplier Portal
