依核准土方計畫管理開挖來源、土質分類、運送車次、收容場所與剩餘額度，核對車牌、數量及收容證明，及早發現超量、誤送、憑證缺漏或計畫偏差。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **土方計畫** — 呈現核准來源區、土質、數量與收容配置。
- **出土批次** — 依開挖區和日期建立出土批次及預估量。
- **運送車次** — 登錄車號、司機、載運量與指定收容場所。
- **收容回證** — 核對收容時間、證明編號與實收數量。
- **額度平衡** — 比較核准量、出土量、運送量與收容量。
- **偏差處理** — 追蹤超量、誤送、土質變更與計畫修正。

## 適合誰使用

- 土方工程師
- 工地行政
- 專案經理

## 運作流程

1. 載入計畫
2. 建立批次
3. 登錄運送
4. 核對回證
5. 平衡數量
6. 處理偏差

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
