# 工期展延事證彙整台

> 依延誤事件串接日報、函文、照片、會議紀錄及排程要徑，建立同期通知、責任分析與申請天數試算，形成可提交的展延事證包。

依延誤事件串接日報、函文、照片、會議紀錄及排程要徑，建立同期通知、責任分析與申請天數試算，形成可提交的展延事證包。

**產業別：**營建工程　|　**系統類型：**legal-case

## 功能模組

- **延誤事件** — 管理事件日期與責任
- **同期證據** — 彙整日報函文及照片
- **要徑分析** — 連結受影響排程活動
- **天數試算** — 計算重疊與可申請日
- **通知期限** — 追蹤契約通知與送件
- **申請成冊** — 輸出展延說明及附件

## 適合誰使用

- 工務經理
- 排程工程師
- 合約法務

## 運作流程

1. 登錄事件
2. 發出通知
3. 彙整證據
4. 分析要徑
5. 審定天數
6. 提交申請

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
