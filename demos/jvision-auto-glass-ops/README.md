# 汽車玻璃服務管理

> 派車、追蹤、簽收到成本油耗的車隊管理

整合汽車玻璃預約、技師派工、玻璃訂購、客戶簽名、保險請款、收款與 AI 摘要的 Demo。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**交通運輸　|　**系統類型：**TMS 運輸調度

## 功能模組

- **路線調度** — 派車與路線規劃
- **任務派車** — 任務指派與追蹤
- **即時追蹤** — GPS 定位與到貨
- **簽收回單** — 電子簽收與回單
- **成本油耗** — 油耗與成本分析
- **冷鏈溫控** — 溫度監控與告警

## 適合誰使用

- 服務顧問
- 玻璃技師
- ADAS 校正人員
- 理賠專員

## 運作流程

1. 建立汽車玻璃服務管理資料
2. 整合汽車玻璃預約、技師派工、玻璃訂購、客戶簽名、保險請款、收款與 AI 摘要的 Demo
3. 確認結果並完成留存

## 導入效益

- 派車規劃工時：3.9小時/日 → **1小時/日**
- 準時配送率：85% → **99%**
- 空車率：22% → **9.4%**
- 油耗異常反應：25小時 → **2.9小時**
