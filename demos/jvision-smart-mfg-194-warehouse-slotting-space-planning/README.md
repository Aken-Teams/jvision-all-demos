# 倉儲空間規劃管理艙

依料件出入庫頻率、體積與關聯性，規劃最適儲位配置與倉庫佈局，提升空間利用率。

- 原始系統：倉儲空間規劃系統（Warehouse Slotting & Space Planning）
- 產業分類：智慧製造｜倉儲管理
- 使用部門：倉儲部、工程部、生管部
- 工作流程：出入庫數據分析→儲位分類→佈局模擬→儲位指派→執行調整→效益追蹤
- AI 應用：儲位配置最佳化模擬、儲位效益動態調整建議
- 主要 KPI：坪效、儲位利用率、揀貨行走距離、儲位調整週期
- 代表產品：Manhattan Associates Slotting、Blue Yonder、Flexsim模擬工具
