# 企業 Prompt 資產庫

治理可重用 Prompt 元件、參數、版本與擁有者，將提示轉為企業資產。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **提示元件目錄** — 管理角色、任務、格式與限制等可重用片段。
- **參數契約設計** — 定義輸入變數、型別、必填條件與預設值。
- **資產擁有權** — 指定擁有者、維護者、使用範圍與責任期限。
- **提示版本比較** — 比較文字、參數、模型設定與輸出格式差異。
- **提示試驗場** — 使用評測案例測試品質、風險、延遲與成本。
- **提示發布套件** — 核准、封裝並發布具版本鎖定的提示資產。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 建立提示元件
2. 定義參數契約
3. 指派資產責任
4. 建立候選版本
5. 執行品質試驗
6. 核准資產發布
