# 臨時工程查驗管理台

> 管理鷹架、支撐、施工架、臨時用電與防護設施的設計送審、搭設查驗、使用許可、定期複查及拆除，建立完整安全證據。

管理鷹架、支撐、施工架、臨時用電與防護設施的設計送審、搭設查驗、使用許可、定期複查及拆除，建立完整安全證據。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **設施清冊** — 依區域與工序建立臨時設施項目。
- **送審版本** — 管理設計圖、計算書及核准版本。
- **查驗排程** — 安排搭設、分段與定期查驗。
- **現場查驗** — 逐項記錄結果、照片與缺失。
- **使用許可** — 顯示可用、限用或停用狀態。
- **拆除結案** — 確認停用、拆除及場地復原。

## 適合誰使用

- 工地主任
- 職安人員
- 監造工程師

## 運作流程

1. 建立設施
2. 提交設計
3. 安排查驗
4. 執行查驗
5. 核發許可
6. 拆除結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
