# 儲能壽命收益最佳化器

> 以擬真電價、負載、電池健康與合約資料，同時評估充放電收益及電池劣化成本，讓營運人員比較不同排程策略、設定安全限制，並追蹤收益是否值得消耗可用壽命。

**產業別：**ESG 永續　|　**系統類型：**esg-energy

## 功能模組

- **儲能資產總覽** — 彙整容量、荷電狀態、健康度、當日收益及運轉限制。
- **壽命健康分析** — 查看容量衰退、循環深度、溫度情境與剩餘壽命推估。
- **收益機會雷達** — 呈現電價價差、尖峰削減、需量反應與備援價值的擬真機會。
- **充放電排程** — 以時段圖編排充放電功率，檢查容量、功率與備援限制。
- **策略情境比較** — 比較收益優先、壽命優先與平衡策略的報酬及劣化代價。
- **效益歸因報表** — 拆解各收益來源、能源成本、劣化成本與策略執行差異。

## 適合誰使用

- 儲能營運專員
- 能源分析師
- 資產主管

## 運作流程

1. 掌握資產狀態
2. 評估壽命風險
3. 辨識收益機會
4. 編排充放電計畫
5. 選擇平衡策略
6. 檢討效益歸因

## 導入效益

- 盤查作業工時：40小時 → **8小時**
- 數據完整率：60% → **95%**
- 減碳目標達成：50% → **88%**
- 用能異常反應：24小時 → **2小時**
