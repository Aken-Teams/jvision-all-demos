# 加盟權利金查核台

> 依加盟合約版本匯入門店營業額，排除免計項目並補入平台訂單，抽樣核對發票與金流，計算應收權利金及追補差額。

**產業別：**生活服務　|　**系統類型：**finance-case

## 功能模組

- **加盟門店** — 連結有效合約與費率
- **營收申報** — 收集門店分類營業額
- **來源比對** — 核對平台金流與發票
- **計費規則** — 套用免計項及階梯抽成
- **疑義查核** — 追查漏報錯列與異常
- **權利金結算** — 核定應收及追補款

## 適合誰使用

- 加盟管理員
- 財務人員
- 稽核主管

## 運作流程

1. 鎖定合約版本
2. 接收營收申報
3. 比對外部來源
4. 調查申報疑義
5. 計算權利金
6. 覆核追補結案

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
