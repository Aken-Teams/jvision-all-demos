# 採購需求智慧規格助手

> 協助請購人把口語需求轉成可詢價的完整規格，自動提示缺漏、矛盾與過度綁定品牌的條件，並提供歷史範本與驗收項目，降低反覆補件、錯買及供應商報價難以比較的情況。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **需求訪談引導** — 以情境問答整理用途、數量、預算、交期與使用環境。
- **規格完整檢查** — 顯示必要欄位、矛盾條件及尚待確認的需求缺口。
- **品牌中立檢核** — 標示指定品牌與排他條款，提出可量化的中性寫法。
- **歷史範本推薦** — 依品類展示可套用的規格範本與過往採購案例。
- **驗收條件設計** — 把功能需求轉成可勾選、可量測的交貨驗收項目。
- **詢價規格定稿** — 整合修訂紀錄並預覽供應商可讀的正式規格文件。

## 適合誰使用

- 請購人
- 採購專員
- 技術審查人員

## 運作流程

1. 描述採購情境
2. 補齊規格缺口
3. 排除限制條款
4. 套用參考範本
5. 確認驗收標準
6. 核准詢價版本

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
