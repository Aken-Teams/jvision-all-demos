# 貨損理賠追償管理台

> 協助物流業者處理貨損、短少與污染案件，串接簽收證據、責任節點、貨值認定、客戶賠付、承運商追償及保險文件，縮短案件結算週期。

協助物流業者處理貨損、短少與污染案件，串接簽收證據、責任節點、貨值認定、客戶賠付、承運商追償及保險文件，縮短案件結算週期。

**產業別：**物流運輸　|　**系統類型：**finance-case

## 功能模組

- **案件受理** — 建立貨損、短少、污染及延遲衍生損失案件。
- **責任節點** — 檢視模擬運送軌跡並標記可能發生異常的節點。
- **理賠證據** — 整理託運單、照片、簽收異議及貨值文件。
- **賠付試算** — 依契約責任上限、折舊及責任比例估算金額。
- **方案核決** — 呈核客戶賠付及對責任承運商的追償方案。
- **追償結算** — 追蹤賠付款、保險給付與承運商回收款。

## 適合誰使用

- 理賠專員
- 運務主管
- 物流財務

## 運作流程

1. 建立貨損案件
2. 鎖定責任節點
3. 完成證據審查
4. 提出賠付試算
5. 核定理賠方案
6. 完成追償結算

## 導入效益

- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
