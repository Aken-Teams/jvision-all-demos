## 功能模組

- **版本答案差異** — 逐題比較更新前後的內容、格式、引用與工具使用差異。
- **行為漂移圖譜** — 將拒答、推理路徑、語氣與指令遵循變化映射成關聯圖。
- **基準評測管理** — 依業務場景維護黃金答案、邊界案例與敏感測試集合。
- **品質變動警報** — 依差異幅度、任務重要度與影響範圍設定漂移警報。
- **漂移證據包** — 產生代表案例、差異摘要、可能成因與受影響應用清單。
- **升級放行評審** — 支援接受更新、延後切換或鎖定舊版的人工評審決策。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 查看漂移雷達
2. 比較版本答案
3. 追查漂移模式
4. 調整評測基準
5. 審閱證據包
6. 決定版本去向
