# 有限產能排程系統（Finite Capacity Scheduling, FCS）

> 從異常到改善的品質閉環與追溯稽核

有限產能排程系統（Finite Capacity Scheduling, FCS）提供設備級產能建模、排程甘特圖視覺化、換線時間納入排程考量。生管依「產能建檔 → 訂單優先序設定 → 排程演算 → 甘特圖確認 → 現場派工」推進作業，優先解決「排程與現場實際產能脫節」，製造工程則以設備稼動率與換線次數確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生產製造　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 生管
- 製造工程
- 現場班組長

## 運作流程

1. 待排程
2. 生產中
3. 待品檢
4. 已入庫

## 導入效益

- 排程作業工時：8.5小時/日 → **1.4小時/日**
- 準時交付率：78% → **97%**
- 缺料停線次數：12次/月 → **2.8次/月**
- 設備稼動率：71% → **88%**
