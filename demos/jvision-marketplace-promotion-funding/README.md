# 電商促銷分攤核算台

> 集中管理平台活動、品牌補貼、賣家折讓與店家自吸等促銷出資規則，逐筆試算訂單優惠歸屬、退貨沖回及對帳差異，支援財會完成月結請款。

集中管理平台活動、品牌補貼、賣家折讓與店家自吸等促銷出資規則，逐筆試算訂單優惠歸屬、退貨沖回及對帳差異，支援財會完成月結請款。

**產業別：**零售電商　|　**系統類型：**finance-ledger

## 功能模組

- **活動建檔** — 建立檔期、券別與參與商品範圍。
- **出資規則** — 設定平台、品牌與店家的分攤順位。
- **訂單試算** — 拆解訂單優惠及各出資方負擔額。
- **退貨沖回** — 依退款情境重算並產生沖回紀錄。
- **差異覆核** — 比對平台帳單與內部試算結果。
- **月結請款** — 彙整品牌請款及店家折讓明細。

## 適合誰使用

- 電商營運
- 平台財會
- 品牌經理

## 運作流程

1. 建立活動
2. 核定出資
3. 計算歸屬
4. 處理退款
5. 覆核差異
6. 完成請款

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
