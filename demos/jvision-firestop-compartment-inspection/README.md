# 防火封堵區劃查驗台

> 按防火區劃管理機電貫穿孔、核定封堵系統、材料批次、施工照片與隱蔽前查驗，確保天花封板後仍能追溯每一處防火填塞的合規證據。

按防火區劃管理機電貫穿孔、核定封堵系統、材料批次、施工照片與隱蔽前查驗，確保天花封板後仍能追溯每一處防火填塞的合規證據。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **區劃點位** — 依樓層與防火區劃建立貫穿孔清冊
- **系統選型** — 配對牆板、管材與核定封堵工法
- **材料批次** — 追蹤防火泥、套環及證明文件
- **施工登錄** — 記錄施作人員、日期與分層照片
- **隱蔽查驗** — 在封板前完成尺寸及外觀確認
- **破壞重驗** — 管理增設管線造成的重新封堵

## 適合誰使用

- 機電工程師
- 監造工程師
- 防火封堵廠商

## 運作流程

1. 建立貫穿點位
2. 配對封堵系統
3. 領用合格材料
4. 完成分層施工
5. 執行隱蔽查驗
6. 封存或啟動重驗

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
