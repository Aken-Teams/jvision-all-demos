# 校車路線異動管制台

> 協助校車與企業交通車業者管理站點增刪、乘員名單、路線版本、試跑檢核及家長或員工通知，在新學期或搬遷期間控制每次異動的核准、生效與舊版停用。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **異動申請** — 受理新增站點、換車及乘員異動。
- **路線試排** — 比較站序、里程、時間與容量影響。
- **乘員配置** — 調整乘員、班次、站點與座位名單。
- **異動審核** — 由調度及客戶單位確認生效方案。
- **通知發布** — 產生乘車通知並追蹤確認狀態。
- **版本管理** — 保存生效日、舊版及變更差異。

## 適合誰使用

- 路線規劃員
- 車隊調度
- 客服人員

## 運作流程

1. 受理需求
2. 模擬路線
3. 配置乘員
4. 核准版本
5. 發布通知
6. 正式切換

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
