# 連鑄裂紋漏鋼預警台

> 將鑄速、結晶器液位、冷卻、摩擦與溫度等擬真訊號轉為裂紋及漏鋼風險，呈現風險區段、可能原因與降速處置建議，協助連鑄人員提早介入並保留事件復盤紀錄。

將鑄速、結晶器液位、冷卻、摩擦與溫度等擬真訊號轉為裂紋及漏鋼風險，呈現風險區段、可能原因與降速處置建議，協助連鑄人員提早介入並保留事件復盤紀錄。

**產業別：**生產製造　|　**系統類型：**operations-console

## 功能模組

- **鑄流戰情** — 比較各鑄流狀態、風險等級與待處置預警。
- **風險預警** — 顯示裂紋與漏鋼機率、提前量及嚴重程度。
- **區段定位** — 沿鑄坯時間軸標示異常位置與關聯製程事件。
- **證據曲線** — 並列液位、溫度、摩擦、鑄速及冷卻變化。
- **處置指引** — 依風險原因提供降速、停流與現場檢查步驟。
- **事件復盤** — 重播預警前後狀態並整理原因、處置與損失。

## 適合誰使用

- 連鑄主控操作員
- 鑄機工程師
- 製程安全主管

## 運作流程

1. 巡看鑄流
2. 確認風險
3. 定位區段
4. 核對證據
5. 執行處置
6. 復盤事件
