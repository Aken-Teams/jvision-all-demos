# 貨櫃滯箱費管制台

> 追蹤進出口貨櫃的免費使用期限、提領、拆櫃、還空與責任歸屬，模擬不同船公司費率並產生逾期催辦清單，協助物流商降低滯箱與滯港費。

追蹤進出口貨櫃的免費使用期限、提領、拆櫃、還空與責任歸屬，模擬不同船公司費率並產生逾期催辦清單，協助物流商降低滯箱與滯港費。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **到港貨櫃** — 建立船次、櫃號與到港可提資訊。
- **免費期限** — 套用船公司及客戶約定的免費天數。
- **提還節點** — 記錄提櫃、拆櫃與還空進度。
- **費用試算** — 依逾期區間模擬累進費率。
- **到期催辦** — 依剩餘天數分級通知責任人員。
- **責任認定** — 彙整延誤證據與費用承擔建議。

## 適合誰使用

- 海運操作員
- 車隊調度
- 物流財務

## 運作流程

1. 建立櫃況
2. 確認期限
3. 安排提櫃
4. 追蹤拆還
5. 處理逾期
6. 核定費用

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
