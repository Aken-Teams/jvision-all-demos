# 簽收回單追補工作台

> 依運單追蹤紙本與電子簽收回單的回收、影像品質、缺章與補簽進度，讓缺件在請款日前被發現並明確指派司機或站所追補。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **回單佇列** — 查看運單與回收期限。
- **影像收件** — 上傳並檢查可讀性。
- **要件驗證** — 核對章、簽名與日期。
- **催補派工** — 指定司機或站所補件。
- **追補紀錄** — 保存聯繫與替代證明。
- **請款交付** — 將合格回單送往開票。

## 適合誰使用

- 回單文管
- 客服專員
- 站所主管

## 運作流程

1. 建立清單
2. 收取影像
3. 檢查要件
4. 派發補件
5. 完成追補
6. 交付請款

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
