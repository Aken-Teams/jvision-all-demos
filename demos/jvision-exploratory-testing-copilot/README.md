# 探索式測試 Copilot

> 結合產品風險與歷史缺陷，即時引導測試人員探索最有價值的路徑。

結合產品風險與歷史缺陷，即時引導測試人員探索最有價值的路徑。

**產業別：**資訊科技　|　**系統類型：**quality-qms

## 功能模組

- **風險探索雷達** — 依變更範圍、使用頻率與事故歷史標出本輪測試熱區。
- **探索路徑編排** — 將高風險情境組成可調整的探索式測試路線。
- **缺陷模式獵場** — 從相似歷史缺陷推導容易被忽略的操作與資料組合。
- **即時測試導航** — 依測試行為與觀察結果動態推薦下一個探索步驟。
- **假設驗證板** — 記錄測試假設、操作筆記、反證與待深入的異常訊號。
- **探索洞察交接** — 彙整覆蓋缺口、缺陷線索與 Agent 交接內容供團隊採取行動。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 圈定測試風險
2. 規劃探索路線
3. 套用缺陷模式
4. 執行動態探索
5. 驗證異常假設
6. 交付測試洞察

- 系統可用率：97% → **99%**
