# 焊接參數智慧最佳化系統

> 依材質、板厚、接頭型式與品質目標，模擬產生電流、電壓、速度及送線等參數候選方案，並比較品質、節拍與成本，讓工程師審核試產配方、記錄驗證結果及管理版本。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **最佳化任務中心** — 建立料號任務，設定品質、節拍、成本目標及完成期限。
- **條件限制設定** — 選擇材質與接頭，定義電流、電壓、速度等可調範圍。
- **候選方案比較** — 以模擬資料比較多組配方的品質分數、節拍與成本。
- **虛擬試焊評估** — 查看各方案的熔深、飛濺、變形與穩定度預估結果。
- **試產驗證管理** — 安排試產批次、檢驗項目與負責人，記錄模擬驗證結果。
- **配方版本中心** — 管理核准配方、版本差異、適用料號與變更原因。

## 適合誰使用

- 焊接製程工程師
- 研發工程師
- 生產主管

## 運作流程

1. 建立最佳化任務
2. 設定參數邊界
3. 比較候選配方
4. 評估試焊結果
5. 執行試產驗證
6. 核准配方版本
