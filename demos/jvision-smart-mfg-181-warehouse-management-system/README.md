# WMS預警塔

倉儲作業核心平台，管理收發貨、上架、儲位、揀補貨與庫存異動全流程。

- 原始系統：WMS（Warehouse Management System）
- 產業分類：智慧製造｜倉儲管理
- 使用部門：倉儲部、物流部、生管部、採購部、品保部
- 工作流程：收貨驗收→上架入庫→訂單分配→揀貨包裝→出貨交接→庫存更新
- AI 應用：儲位智慧推薦、需求預測輔助補貨、異常庫存自動預警
- 主要 KPI：庫存準確率、訂單出貨準時率、揀貨效率、坪效、盤點差異率
- 代表產品：SAP EWM、Oracle WMS Cloud、Manhattan Associates WMS、鼎捷數位 WMS
