# 錯誤處理完整性掃描器

> 掃描逾時、重試、補償與冪等設計缺口，提升跨服務交易韌性。             

掃描逾時、重試、補償與冪等設計缺口，提升跨服務交易韌性。             

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **失敗路徑地圖** — 呈現請求與事件鏈上每個可能失敗及中斷的位置。
- **逾時覆蓋掃描** — 檢查客戶端、服務端與下游呼叫是否具合理逾時界線。
- **重試策略檢查** — 辨識無退避、無上限及可能放大故障的重試設計。
- **補償流程驗證** — 檢查跨服務交易失敗後的回滾與補償動作是否完整。
- **冪等防線檢測** — 找出重送時可能造成重複扣款、寫入或事件發布的端點。
- **韌性修補方案** — 生成缺口修補草案、故障注入案例與驗證清單。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 展開失敗路徑
2. 校驗逾時界線
3. 審查重試行為
4. 驗證補償流程
5. 測試冪等防線
6. 核准韌性修補

## 導入效益

- 事件平均處理：120分鐘 → **30分鐘**
- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
- 資產盤點工時：20小時/月 → **4小時/月**
