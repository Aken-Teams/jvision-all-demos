# 合約連鎖義務映射器

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **客戶承諾抽取** — 擷取交付、品質、資安、賠償與時限等對客戶承諾。
- **義務傳導圖譜** — 呈現客戶承諾與供應商條款、部門活動間的傳導關係。
- **供應商承諾對照** — 檢查採購合約是否取得足以支撐客戶承諾的背對背保障。
- **內部履約映射** — 將義務連結至研發、採購、生產、交付與客服流程。
- **背對背缺口診斷** — 定位未轉嫁、標準較低、期限錯配或責任懸空的缺口。
- **義務補強方案** — 建立供應商修約、流程控制或風險承擔的補強方案。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 擷取客戶承諾
2. 建立傳導關係
3. 核對供應商保障
4. 確認內部履約
5. 判定連鎖缺口
6. 核准補強方案
