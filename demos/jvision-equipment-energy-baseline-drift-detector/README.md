# 設備能源基線漂移偵測器

**產業別：**生產製造　|　**系統類型：**esg-energy

## 功能模組

- **產量正規化基線** — 依產量、產品組合與班次建立設備合理能耗基線。
- **能耗漂移曲線** — 追蹤單位產出能耗相對基線的緩慢惡化。
- **工況影響校正** — 排除環境溫度、負載、換線及待機造成的假漂移。
- **劣化因子推理** — 關聯震動、溫度、壓力與維修史，排序可能劣化部件。
- **維護效益預估** — 估算不同維護時點可回收的電耗、成本與產能。
- **預防維護排程** — 建立維護工單，安排停機窗口並設定恢復驗證。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 建立設備基線
2. 辨識惡化趨勢
3. 校正工況干擾
4. 推理劣化因子
5. 評估維護效益
6. 核准維護排程
