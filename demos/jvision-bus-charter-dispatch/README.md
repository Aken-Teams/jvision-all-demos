# 遊覽車包車調度台

> 管理包車詢價、行程可行性、車輛與駕駛配置、靠行成本及出車文件，協助遊覽車業者避免撞單並提高車隊利用率。

管理包車詢價、行程可行性、車輛與駕駛配置、靠行成本及出車文件，協助遊覽車業者避免撞單並提高車隊利用率。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **需求看板** — 彙整待報價與已成交包車需求。
- **行程評估** — 檢查路線、停靠點與所需工時。
- **車駕配置** — 試排車輛及合格駕駛。
- **包車報價** — 試算里程、工時與靠行成本。
- **出車文件** — 整理派車單與旅客名冊狀態。
- **趟次損益** — 比較報價與實際成本差異。

## 適合誰使用

- 業務調度員
- 車隊主管
- 行政人員

## 運作流程

1. 受理詢價
2. 評估行程
3. 試排車駕
4. 提出報價
5. 核定出車
6. 檢討損益

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
