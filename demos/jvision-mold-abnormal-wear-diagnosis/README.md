# 模具異常磨耗診斷系統

> 透過模具部位、外觀症狀、尺寸變化、成品缺陷與維修履歷等擬真資料，協助辨識頂針、滑塊、導柱及模穴的異常磨耗型態，提供可能原因、檢查順序與處置建議，並追蹤維修前後的診斷結果。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **磨耗案件總覽** — 按嚴重度、模具、症狀及處理狀態彙整異常案件。
- **症狀標註建檔** — 在模具與成品示意圖標記刮痕、毛邊、間隙及尺寸漂移。
- **磨耗型態診斷** — 呈現可能磨耗部位、型態、信心程度與判斷依據。
- **原因關聯分析** — 串聯材料、潤滑、偏心、溫度及保養紀錄，分析可能成因。
- **拆檢處置指引** — 提供依優先順序排列的檢查項目、工具與建議處置方式。
- **維修復驗追蹤** — 記錄研磨、更換、間隙調整及復驗結果，追蹤是否再次發生。

## 適合誰使用

- 模具維修技師
- 品保工程師
- 模具主管

## 運作流程

1. 受理案件
2. 標註症狀
3. 執行診斷
4. 分析成因
5. 依序拆檢
6. 維修復驗

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
