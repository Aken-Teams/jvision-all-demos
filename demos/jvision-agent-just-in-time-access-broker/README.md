為高風險 Agent 任務核發附條件的短效權限，完成後自動驗證回收。

**產業別：**資訊科技　|　**系統類型：**security-soc

## 功能模組

- **特權需求評分** — 依任務目的、資料敏感度、操作破壞性與身分評估風險。
- **核發條件編排** — 設定核准層級、允許工具、資源範圍、時段與前置條件。
- **短效憑證簽發** — 產生綁定 Agent、任務與裝置情境的限時存取憑證。
- **特權使用監看** — 即時監測工具呼叫、資料範圍、偏離行為與剩餘有效時間。
- **到期回收控制** — 在完成、逾時、風險升高或任務取消時立即撤銷權限。
- **回收完整性驗證** — 確認憑證、工作階段與衍生權限均失效，並檢查殘留存取。

## 適合誰使用

## 運作流程

1. 評估特權需求
2. 設定核發條件
3. 核准簽發憑證
4. 監看特權使用
5. 觸發權限回收
6. 驗證回收結果
