# 請購舞弊與分拆偵測器

> 分析模擬請購資料中的金額門檻、時間、申請人、供應商與品項關聯，標示疑似拆單、重複請購、利益衝突及異常急件。稽核人員可查看證據脈絡、記錄判定並追蹤處置。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **異常案件佇列** — 依風險分數與金額排列疑似分拆、重複及規避案件。
- **分拆關聯視圖** — 以時間線串連相近日期、品項、申請人與供應商的請購。
- **偵測規則中心** — 展示門檻規避、重複金額、異常急件等規則與命中情形。
- **關係網路分析** — 呈現申請人、部門、核准者及供應商間的異常集中關係。
- **案件調查工作台** — 彙整請購明細、附件摘要、說明紀錄與調查判定。
- **處置追蹤看板** — 管理退回、更正、加強審核及升級稽核等後續處置。

## 適合誰使用

- 內部稽核人員
- 採購主管
- 財務審核人員

## 運作流程

1. 篩選高風險案件
2. 檢查分拆脈絡
3. 核對命中規則
4. 分析關係集中
5. 完成案件調查
6. 追蹤改善處置
