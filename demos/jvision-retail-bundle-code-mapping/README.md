# 商品組合碼對照工作台

> 治理各平台單品、組合包、贈品與倉庫料號的版本對照，讓組合改版後仍能正確扣庫存、產生揀貨內容並追查錯單來源。

治理各平台單品、組合包、贈品與倉庫料號的版本對照，讓組合改版後仍能正確扣庫存、產生揀貨內容並追查錯單來源。

**產業別：**零售電商　|　**系統類型：**erp

## 功能模組

- **商品主檔** — 查看標準單品與料號。
- **組合版本** — 設定套組、數量及贈品。
- **平台對映** — 連結各通路組合代碼。
- **拆單預覽** — 模擬庫存扣帳與揀貨項目。
- **衝突檢查** — 找出重碼與失效成分。
- **版本追溯** — 確認訂單使用的規則版本。

## 適合誰使用

- 商品管理員
- 電商營運
- 倉儲主管

## 運作流程

1. 建立單品
2. 編輯組合
3. 對映通路
4. 模擬拆單
5. 核准上線
6. 追查異常

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
