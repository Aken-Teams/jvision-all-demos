# 事故車維修協調台

> 供車隊集中管理事故通報、責任資料、估價版本、保險聯繫、維修排程與代步安排，讓營運人員掌握每輛事故車的停駛影響及預計復運日期。

**產業別：**交通運輸　|　**系統類型：**operations-console

## 功能模組

- **事故通報** — 記錄車輛、駕駛與事故經過
- **事故文件** — 整理報案、照片及責任資料
- **估價比較** — 比較修理廠項目與版本差異
- **保險協調** — 追蹤查勘、核價及自負額
- **維修進度** — 查看待料、施工與完工節點
- **復運審核** — 確認驗收結果與車輛復派

## 適合誰使用

- 車隊管理員
- 事故專員
- 營運主管

## 運作流程

1. 受理事故通報
2. 彙整責任文件
3. 審查維修估價
4. 協調保險核價
5. 監控維修進度
6. 核准車輛復運

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
