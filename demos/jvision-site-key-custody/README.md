# 交屋鑰匙借還管制台

> 以棟別、戶號、門位與鑰匙編碼建立實體鑰匙清冊，管理工班借用、代領、逾期催還、遺失換鎖及交屋封存，讓交屋前能迅速確認每一把鑰匙的持有人與可交付狀態。

以棟別、戶號、門位與鑰匙編碼建立實體鑰匙清冊，管理工班借用、代領、逾期催還、遺失換鎖及交屋封存，讓交屋前能迅速確認每一把鑰匙的持有人與可交付狀態。

**產業別：**營建工程　|　**系統類型：**operations-console

## 功能模組

- **鑰匙清冊** — 管理棟戶、門位、鑰匙碼、支數與目前狀態。
- **借用登記** — 記錄借用人、所屬工班、用途與預定歸還時間。
- **歸還核對** — 確認歸還支數、外觀、代還人與入櫃位置。
- **逾期催還** — 列出逾期持有人並記錄催辦與承諾時間。
- **遺失處置** — 管理停用、尋回、換鎖、費用與責任認定。
- **交屋封存** — 按戶盤點並建立密封鑰匙包與點交紀錄。

## 適合誰使用

- 交屋專員
- 工地行政
- 分包領班

## 運作流程

1. 建立鑰匙資料
2. 申請借用鑰匙
3. 完成領用確認
4. 辦理歸還入櫃
5. 處理逾期遺失
6. 盤點封存交付

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
