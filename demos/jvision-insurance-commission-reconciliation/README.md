# 保險佣金核對管理台

> 協助保經代公司依保單、險種、繳別與業務歸屬試算應收佣金，核對保險公司結算檔，處理停效追回、拆佣及短付差異。

協助保經代公司依保單、險種、繳別與業務歸屬試算應收佣金，核對保險公司結算檔，處理停效追回、拆佣及短付差異。

**產業別：**金融保險　|　**系統類型：**finance-ledger

## 功能模組

- **佣金總覽** — 查看應收、實收、追回與差異。
- **保單明細** — 檢視保單狀態及佣金基礎。
- **規則試算** — 套用險種、繳別與級距規則。
- **拆佣分配** — 管理多人及組織間佣金比例。
- **差異處理** — 核對短付、溢付與停效追回。
- **結算發布** — 覆核並發布業務佣金明細。

## 適合誰使用

- 佣金會計
- 通路營運主管
- 業務行政

## 運作流程

1. 彙整保單資料
2. 計算應收佣金
3. 設定拆佣歸屬
4. 核對公司結算
5. 處理追回差異
6. 發布佣金明細

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
