# 公共工程物調款試算台

> 依公共工程契約條款管理物價指數期別、可調整工項、估驗金額與調整款試算，協助承攬商準備計價依據、版本比較及送審附件，降低人工套表錯誤與漏計可請領金額。

依公共工程契約條款管理物價指數期別、可調整工項、估驗金額與調整款試算，協助承攬商準備計價依據、版本比較及送審附件，降低人工套表錯誤與漏計可請領金額。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **條款設定** — 建立門檻、基期、適用公式與排除規則。
- **指數期別** — 管理基期及估驗月份所採用的物價指數。
- **估驗工項** — 彙整本期工項金額與可調整分類。
- **調整試算** — 逐項呈現公式、係數與正負調整結果。
- **版本比較** — 比較不同指數或估驗版本造成的金額差異。
- **送審包件** — 整理計算表、依據文件及簽核紀錄。

## 適合誰使用

- 成本工程師
- 工務經理
- 主辦機關承辦

## 運作流程

1. 建立條款
2. 選定指數
3. 整理估驗
4. 執行試算
5. 覆核版本
6. 提交送審

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
