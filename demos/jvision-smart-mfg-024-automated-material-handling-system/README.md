# AMHS自動化物料搬運智慧站

以自動化天車、AGV、Stocker等設備實現廠內物料自動搬運與儲存之系統，常見於半導體/面板廠。

- 原始系統：AMHS自動化物料搬運系統（Automated Material Handling System）
- 產業分類：智慧製造｜製造管理
- 使用部門：物流工程、製造工程、設備工程
- 工作流程：搬運需求產生 → 派車調度 → 自動搬運執行 → 到站確認 → 異常回報處理
- AI 應用：AI優化搬運路徑與派車策略、智慧預測物流壅塞並提前疏導
- 主要 KPI：搬運及時率、平均搬運時間、系統稼動率
- 代表產品：Daifuku、Murata Machinery、TGW、KUKA
