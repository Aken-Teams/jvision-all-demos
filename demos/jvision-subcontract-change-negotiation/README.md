# 分包追加減議價台

> 集中登錄現場追加減指示、責任來源、分包報價與議價紀錄，串起施工前暫定授權到最終單價核定，避免工程先做後談卻缺少數量基準與承諾歷程。

集中登錄現場追加減指示、責任來源、分包報價與議價紀錄，串起施工前暫定授權到最終單價核定，避免工程先做後談卻缺少數量基準與承諾歷程。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **議價看板** — 掌握待報價、議價中與已核定案件。
- **追加建案** — 記錄指示來源、範圍及施工急迫性。
- **報價比對** — 比較分包版本、數量與單價差異。
- **議價紀錄** — 保存每輪條件、承諾與附件。
- **暫定授權** — 設定未定價施工的金額上限。
- **單價核定** — 完成簽核並發布結算依據。

## 適合誰使用

- 採購人員
- 成本工程師
- 工地主任

## 運作流程

1. 檢視案件
2. 建立追加
3. 審查報價
4. 進行議價
5. 授權施工
6. 核定價格

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
