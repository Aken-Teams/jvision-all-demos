# 員工關懷與離職預警決策室

運用出勤、績效、薪酬等資料以AI模型分析離職風險，提前介入關懷高流動風險族群，降低產線缺工衝擊。

- 原始系統：員工關懷與離職預警系統（AI Attrition Prediction）
- 產業分類：智慧製造｜人資管理
- 使用部門：人資部、各部門主管、產線廠長、經營高層
- 工作流程：資料蒐集 → AI風險評分 → 高風險名單產出 → 主管關懷面談 → 留才措施執行 → 成效追蹤
- AI 應用：機器學習離職風險預測模型、離職原因文字探勘分析
- 主要 KPI：預測準確率、流動率下降幅度、高風險名單關懷完成率、留任率
- 代表產品：Visier People Analytics、Workday People Analytics、104人資King流動分析模組
