# 員工留任與離職預警系統（AI Attrition Prediction）

> 出勤、薪資、招募到績效的人資全流程

員工留任與離職預警系統（AI Attrition Prediction）提供離職風險評分模型、高風險員工自動示警清單、員工一對一面談紀錄管理。人資部依「資料蒐集 → AI風險評分 → 高風險名單產出 → 主管一對一面談 → 留才措施執行 → 成效追蹤」推進作業，優先解決「產線作業員高流動率影響產能」，各部門主管則以預測準確率與流動率下降幅度確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**HRIS 人力資源系統

## 功能模組

- **出勤差勤** — 打卡、請假與加班
- **薪資計算** — 薪資、勞健保與報稅
- **排班管理** — 智慧排班與工時控管
- **招募任用** — 職缺、面試與報到
- **教育訓練** — 課程、證照與紀錄
- **績效考核** — 目標設定與考核流程

## 適合誰使用

- 人資部
- 各部門主管
- 產線廠長

## 運作流程

1. 待處理
2. 主管確認
3. 人資執行
4. 歸檔完成

## 導入效益

- 薪資作業工時：40小時/月 → **8.2小時/月**
- 出勤異常處理：29分鐘 → **4.9分鐘**
- 招募到位天數：48天 → **26天**
- 表單簽核時效：3.1天 → **1天**
