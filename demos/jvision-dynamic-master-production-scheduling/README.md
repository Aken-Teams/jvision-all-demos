# 智慧動態主生產排程台

> 整合訂單、產能、物料與交期限制，以視覺化情境模擬協助生管快速重排主生產計畫，辨識插單與缺料衝擊，並讓業務、採購及現場共同確認可執行版本。

整合訂單、產能、物料與交期限制，以視覺化情境模擬協助生管快速重排主生產計畫，辨識插單與缺料衝擊，並讓業務、採購及現場共同確認可執行版本。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **供需態勢總覽** — 彙整訂單交期、產能負荷、缺料與延遲風險。
- **主排程甘特圖** — 以產線與工單時間軸檢視可拖曳的生產安排。
- **急單插單模擬** — 比較插單前後的交期、產能與受影響訂單。
- **限制衝突中心** — 集中呈現設備、模具、人力及物料衝突。
- **跨部門協商室** — 記錄排程提案、部門意見與承諾交期。
- **版本發布追蹤** — 發布核定排程並比較版本差異與執行狀態。

## 適合誰使用

- 生管主管
- 排程人員
- 業務主管
- 採購人員
- 製造主管

## 運作流程

1. 掌握供需風險
2. 編排主生產計畫
3. 模擬急單影響
4. 排除限制衝突
5. 確認部門承諾
6. 發布執行版本

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
