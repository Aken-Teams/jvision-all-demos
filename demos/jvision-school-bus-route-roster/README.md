# 接駁路線乘員管理台

> 協助企業與機構管理接駁路線、站點時刻、乘員名冊、臨時搭乘申請、車次容量及異常通報，避免超額預約與漏接爭議。

協助企業與機構管理接駁路線、站點時刻、乘員名冊、臨時搭乘申請、車次容量及異常通報，避免超額預約與漏接爭議。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **路線站點** — 維護停靠順序與預定時刻
- **車次配置** — 安排車輛及可用座位
- **搭乘申請** — 處理固定與臨時乘車需求
- **乘員名冊** — 產生各站上下車清單
- **異動調度** — 處理候補、取消與換車
- **異常通報** — 記錄誤點、漏接與客訴

## 適合誰使用

- 交通行政
- 車隊調度員
- 值班主管

## 運作流程

1. 設定路線
2. 配置車次
3. 審核申請
4. 發布名冊
5. 調整異動
6. 檢討異常

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
