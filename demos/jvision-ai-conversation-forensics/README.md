# AI 對話鑑識工具

> 重建 AI 對話的提示、上下文、模型、工具與輸出鏈，支援事件根因分析。

重建 AI 對話的提示、上下文、模型、工具與輸出鏈，支援事件根因分析。

**產業別：**資訊安全　|　**系統類型：**security-soc

## 功能模組

- **事件對話搜尋** — 依使用者、時間、模型、資料標籤與事件編號定位對話。
- **提示鏈重建** — 還原系統提示、使用者提示、上下文與改寫順序。
- **模型路由剖析** — 呈現模型版本、路由決策、參數與信心不確定性。
- **工具呼叫回放** — 逐步檢視 Agent 呼叫工具的參數、權限與回傳內容。
- **輸出傳播追蹤** — 追查生成內容後續下載、分享、寫入與外傳路徑。
- **根因情境模擬** — 模擬移除特定提示、資料或工具後的可能結果差異。

## 適合誰使用

- CISO
- AI 治理主管
- 資安分析師

## 運作流程

1. 鎖定事件範圍
2. 重建提示脈絡
3. 確認模型路由
4. 回放工具行為
5. 追蹤輸出影響
6. 驗證根因結論

## 導入效益

- 告警分流時間：45分鐘 → **8分鐘**
- 事件平均處理：12小時 → **3小時**
- 弱點修補率：68% → **96%**
- 合規稽核工時：30小時/月 → **6小時/月**
