# 光學未知缺陷探索台

> 從自動光學檢測（AOI）的未分類異常影像中整理相似群集、離群案例與出現趨勢，讓品保人員檢視代表影像、合併或拆分群組、命名新缺陷並建立追蹤案件，提早掌握既有規則未涵蓋的品質風險。

從自動光學檢測（AOI）的未分類異常影像中整理相似群集、離群案例與出現趨勢，讓品保人員檢視代表影像、合併或拆分群組、命名新缺陷並建立追蹤案件，提早掌握既有規則未涵蓋的品質風險。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **未知異常雷達** — 呈現新出現群集、異常增幅與產品風險分布。
- **相似影像群集** — 以群組卡片比較代表影像、數量與相似程度。
- **離群案例檢視** — 集中查看不屬於既有類別或主要群集的特殊案例。
- **群組整理工作台** — 合併、拆分或排除群集，並記錄整理判斷。
- **新缺陷命名** — 建立名稱、特徵說明、風險假設與代表案例。
- **調查案件追蹤** — 指派負責人、追蹤原因假設及改善驗證狀態。

## 適合誰使用

- 品保工程師
- 製程工程師
- 品質主管

## 運作流程

1. 掃描未知異常
2. 瀏覽相似群集
3. 檢查離群案例
4. 整理異常群組
5. 定義新缺陷
6. 啟動原因調查

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
