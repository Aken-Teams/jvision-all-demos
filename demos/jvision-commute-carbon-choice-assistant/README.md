## 功能模組

- **通勤條件設定** — 設定起訖地、到達時間、同行人數與可接受轉乘條件。
- **多運具方案比較** — 並列大眾運輸、共乘、接駁、騎行與自行駕車方案。
- **旅程碳排試算** — 按距離、運具、載客率與能源別計算每趟碳排。
- **時間成本權衡** — 比較候車、轉乘、塞車風險及總通勤時間。
- **低碳選擇排序** — 依使用者偏好解釋時間、費用與減碳效益的推薦順序。
- **移動方案啟動** — 預約接駁或共乘、加入行事曆並驗證實際行程結果。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 設定本次通勤
2. 產生交通組合
3. 估算碳排影響
4. 比較時間與費用
5. 選定低碳方案
6. 安排並驗證行程

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
