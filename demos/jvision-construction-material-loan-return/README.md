# 工地借料歸還結算台

> 追蹤總包與分包之間臨時借用的材料、工具及剩料，記錄領用、轉交、歸還與不可歸還計價，避免完工後短少卻無法扣款。

追蹤總包與分包之間臨時借用的材料、工具及剩料，記錄領用、轉交、歸還與不可歸還計價，避免完工後短少卻無法扣款。

**產業別：**營建工程　|　**系統類型：**warehouse-wms

## 功能模組

- **可借物料** — 查看庫存與計價基準。
- **借出登錄** — 記錄工班、數量與用途。
- **轉交追蹤** — 保存跨工班持有人。
- **歸還點收** — 確認數量與狀態。
- **缺損認定** — 記錄耗用、遺失及照片。
- **結算扣款** — 計算不可歸還金額。

## 適合誰使用

- 材料管理員
- 工班領班
- 成本會計

## 運作流程

1. 提出借料
2. 核准領用
3. 材料出庫
4. 追蹤持有
5. 完成點收
6. 結算差額

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
