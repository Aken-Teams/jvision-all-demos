# 塔吊吊運協調排程台

> 管理多棟工區共用塔吊的吊運申請、荷重檢核、時段排程、衝突協調與完工回報，讓鋼筋、模板、機電等工班依施工優先序取得吊運資源，降低待工與臨時插單造成的現場混亂。

管理多棟工區共用塔吊的吊運申請、荷重檢核、時段排程、衝突協調與完工回報，讓鋼筋、模板、機電等工班依施工優先序取得吊運資源，降低待工與臨時插單造成的現場混亂。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **吊運申請** — 填報吊物、重量、起訖位置、需求時段與工序。
- **荷重檢核** — 依工作半徑及吊物重量確認是否符合能力限制。
- **時段排程** — 以塔吊與時段檢視每日吊運任務。
- **衝突協調** — 處理插單、撞期及跨工班優先序爭議。
- **日計畫發布** — 發布核定次序、指揮人員與現場注意事項。
- **吊運回報** — 記錄實際起訖時間、完成數量及異常原因。

## 適合誰使用

- 吊裝主管
- 施工工程師
- 分包領班

## 運作流程

1. 提出申請
2. 檢核能力
3. 安排時段
4. 協調衝突
5. 發布計畫
6. 完成回報

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
