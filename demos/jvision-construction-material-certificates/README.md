# 建材證明文件彙整台

> 按材料品項、廠牌、型號及進場批次收整出廠證明、試驗報告、綠建材文件與有效期限，讓品管能快速辨識缺件、過期或與核定型號不符的證明資料。

按材料品項、廠牌、型號及進場批次收整出廠證明、試驗報告、綠建材文件與有效期限，讓品管能快速辨識缺件、過期或與核定型號不符的證明資料。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **材料主檔** — 管理品項、廠牌、型號及文件要求。
- **進場批次** — 關聯批號、數量、日期及供應商。
- **證明收件** — 收整證書、報告及符合性聲明。
- **效期檢查** — 標示過期與即將失效文件。
- **型號比對** — 比對送審核定與實際進場資料。
- **查驗資料包** — 按批次輸出文件索引與附件。

## 適合誰使用

- 品管工程師
- 採購人員
- 材料管理員

## 運作流程

1. 設定文件要求
2. 建立進場批次
3. 催收供應文件
4. 檢查效期型號
5. 處理不符文件
6. 輸出查驗資料

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
