# 出勤打卡管理系統（Attendance Management）

> 出勤、薪資、招募到績效的人資全流程

出勤打卡管理系統（Attendance Management）提供多元刷卡方式（門禁卡、指紋、臉部辨識）、請假/加班線上申請、異常出勤（遲到早退曠職）自動標記。人資部依「員工刷卡/生物辨識 → 出勤資料上傳 → 異常比對 → 主管確認 → 資料鎖定 → 傳送薪資系統」推進作業，優先解決「大量作業員代打卡問題」，產線班長/組長則以出勤異常率與代打卡攔截數確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**HRIS 人力資源系統

## 功能模組

- **出勤差勤** — 打卡、請假與加班
- **薪資計算** — 薪資、勞健保與報稅
- **排班管理** — 智慧排班與工時控管
- **招募任用** — 職缺、面試與報到
- **教育訓練** — 課程、證照與紀錄
- **績效考核** — 目標設定與考核流程

## 適合誰使用

- 人資部
- 產線班長
- 組長
- 行政部

## 運作流程

1. 待處理
2. 主管確認
3. 人資執行
4. 歸檔完成

## 導入效益

- 薪資作業工時：39小時/月 → **8.3小時/月**
- 出勤異常處理：30分鐘 → **5.3分鐘**
- 招募到位天數：46天 → **26天**
- 表單簽核時效：3.1天 → **1天**
