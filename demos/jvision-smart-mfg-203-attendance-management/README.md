# 出勤打卡管理洞察站

記錄產線與辦公室員工出勤刷卡、請假、加班等時間資料，作為薪資核算之基礎依據。

- 原始系統：出勤打卡管理系統（Attendance Management）
- 產業分類：智慧製造｜人資管理
- 使用部門：人資部、產線班長/組長、行政部、警衛/門禁單位
- 工作流程：員工刷卡/生物辨識 → 出勤資料上傳 → 異常比對 → 主管確認 → 資料鎖定 → 傳送薪資系統
- AI 應用：臉部辨識防代打卡偵測、異常缺勤模式預測分析
- 主要 KPI：出勤異常率、代打卡攔截數、出勤資料正確率、請假簽核時效
- 代表產品：中控智慧考勤、緯創資通門禁考勤、鼎新HR考勤模組、Kronos（UKG）
