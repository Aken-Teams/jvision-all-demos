# AR 維修步驟驗證器

> 透過 AR 視覺逐步核對零件、作業順序與安全措施，降低維修錯誤。

透過 AR 視覺逐步核對零件、作業順序與安全措施，降低維修錯誤。

**產業別：**生產製造　|　**系統類型：**maintenance-cmms

## 功能模組

- **AR 維修作業窗** — 在設備實景疊加工單步驟、目標部位與操作提示。
- **零件視覺核對** — 辨識零件型號、方向與裝配位置是否符合工單要求。
- **工序順序驗證** — 確認拆卸、檢修、組裝與測試步驟依規定順序完成。
- **安全措施檢查** — 檢查斷能、洩壓、防護具及警戒區等安全條件。
- **偏差即時攔截** — 發現錯件、漏步或危險動作時暫停作業並給出修正。
- **復機品質確認** — 驗證扭矩、接線、護罩及試運轉結果後允許結案。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 載入維修任務
2. 確認零件工具
3. 完成安全隔離
4. 逐步執行維修
5. 處理作業偏差
6. 驗證復機結果

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
