**產業別：**採購供應鏈　|　**系統類型：**legal-case

## 功能模組

- **可疑交易雷達** — 依產品敏感度、客戶輪廓與交易變化標示訪談優先序。
- **動態問題編排** — 根據前一題答案即時產生用途、使用地與受益人追問。
- **客戶用途訪談** — 以可回溯問卷蒐集最終使用者、設備與應用場景資訊。
- **回答矛盾分析** — 跨 CRM、訂單與公開訊號找出說法不一致或資訊缺口。
- **用途風險評分** — 呈現軍民兩用、轉售與敏感產業風險及模型不確定性。
- **盡調結論核准** — 形成放行、補問、加強保證或拒絕交易的建議結論。

## 適合誰使用

- 國貿主管
- 報關人員
- 業務

## 運作流程

1. 篩選訪談案件
2. 設計動態問題
3. 執行用途訪談
4. 釐清回答矛盾
5. 評估用途風險
6. 核准盡調結論
