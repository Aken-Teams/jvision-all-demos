# 團膳餐數簽認結算台

> 管理團膳各駐點每日供餐、臨時加減餐、停餐原因與客戶簽認數，月底依合約彙總可請款餐數並快速處理雙方數量爭議。

管理團膳各駐點每日供餐、臨時加減餐、停餐原因與客戶簽認數，月底依合約彙總可請款餐數並快速處理雙方數量爭議。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **供餐日曆** — 查看各駐點預定與實供餐數。
- **餐數異動** — 記錄加餐、減餐與停餐。
- **客戶簽認** — 保存每日確認與備註。
- **差異協調** — 比對訂購、實供及簽認量。
- **合約計價** — 套用單價與最低供餐條件。
- **月結請款** — 產生可追溯的請款底稿。

## 適合誰使用

- 駐點主管
- 營運專員
- 請款會計

## 運作流程

1. 建立餐數
2. 回報異動
3. 完成簽認
4. 處理差異
5. 執行計價
6. 送出請款

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
