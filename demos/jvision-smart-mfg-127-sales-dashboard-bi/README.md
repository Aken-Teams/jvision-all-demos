# 業務儀表板 Sales Dashboard/BI追蹤台

整合各業務系統數據，以視覺化儀表板呈現業績、商機與客戶指標，支援快速決策。

- 原始系統：業務儀表板 Sales Dashboard/BI
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、業務主管、總經理室、財務部
- 工作流程：數據源整合→建立指標模型→儀表板視覺化呈現→主管檢視分析→異常追蹤處理
- AI 應用：異常業績自動根因分析、自然語言查詢報表生成
- 主要 KPI：報表產出時效、數據更新即時性、儀表板使用率、決策回應速度
- 代表產品：Microsoft Power BI、Tableau、Salesforce Tableau CRM
