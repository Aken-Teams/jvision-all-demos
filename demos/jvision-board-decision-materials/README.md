# 董事會決策材料智慧助理

> 協助彙整議案背景、財務數字、風險與附件，透過模擬智慧提示檢查內容缺漏及版本差異，產出結構一致的董事會材料並追蹤審閱意見。

協助彙整議案背景、財務數字、風險與附件，透過模擬智慧提示檢查內容缺漏及版本差異，產出結構一致的董事會材料並追蹤審閱意見。

**產業別：**經營管理　|　**系統類型：**collaboration-pm

## 功能模組

- **會議議程台** — 管理會議日期、議案順序、負責部門與材料完成狀態。
- **議案編寫器** — 依固定架構整理決策目的、背景、選項與建議方案。
- **材料完整檢查** — 標示模擬缺漏欄位、數字矛盾及尚未說明的重大風險。
- **版本差異檢視** — 並排呈現不同版本的段落、數字與附件異動。
- **審閱意見中心** — 彙整董事與主管的意見、回覆及待修改項目。
- **會議資料預覽** — 以董事閱讀視角預覽議程、議案摘要與附件索引。

## 適合誰使用

- 董事會秘書
- 總經理室
- 財務主管與議案負責人

## 運作流程

1. 建立會議議程
2. 撰寫議案內容
3. 檢查材料缺漏
4. 核對版本差異
5. 完成審閱回覆
6. 鎖定會議資料

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 決策資料覆蓋：55% → **92%**
- 跨部門對齊：60% → **90%**
