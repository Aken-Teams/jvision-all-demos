## 功能模組

- **會議處理佇列** — 列出待擷取決策的會議及錄音、逐字稿狀態。
- **決議擷取** — 從對話辨識決議內容、決策人與生效條件。
- **理由結構化** — 整理支持決議的目標、限制、證據與取捨。
- **反對意見保留** — 歸納異議者觀點、顧慮及未採納原因。
- **待驗假設管理** — 將不確定前提轉成有期限與負責人的驗證項。
- **決策知識入庫** — 預覽知識卡、處理人工修訂並發布至知識庫。

## 適合誰使用

- 知識工作者
- 主管
- 客服

## 運作流程

1. 選取待處理會議
2. 校對決議草案
3. 補全決策理由
4. 確認反對意見
5. 指派假設驗證
6. 核准知識入庫

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
