# 道路救援費用判責台

> 將道路救援、拖吊發票與故障原因、保固、事故及駕駛紀錄整合，判斷車隊、維修商、保險或駕駛應負擔比例，追蹤求償與最終核銷。

**產業別：**交通運輸　|　**系統類型：**finance-case

## 功能模組

- **救援案件** — 彙整拖吊地點與費用
- **故障還原** — 連結維修與保固紀錄
- **證據清單** — 整理照片單據與通話
- **責任分攤** — 核定各方負擔比例
- **求償追蹤** — 追保險維修商或駕駛
- **費用核銷** — 確認收款與公司吸收

## 適合誰使用

- 車管人員
- 保險專員
- 財務人員

## 運作流程

1. 接收費用
2. 還原故障
3. 補齊證據
4. 會簽判責
5. 執行求償
6. 完成核銷

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
