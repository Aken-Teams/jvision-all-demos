# 課後班接送異動台

> 整合家長臨時接送變更、代接者身分、校車異動、教師確認與學生放行，讓換班人員即時掌握尚未接走學生及每次授權依據。

**產業別：**教育　|　**系統類型：**operations-console

## 功能模組

- **異動受理** — 記錄日期方式與原因
- **家長驗證** — 確認授權來源和回電
- **代接資料** — 維護姓名關係與證件
- **接送清單** — 更新校車及自行接送
- **學生放行** — 查驗身分並記錄交付
- **未接處置** — 追蹤留班學生與通知

## 適合誰使用

- 課後班老師
- 櫃台人員
- 值班主管

## 運作流程

1. 接收接送異動
2. 驗證家長授權
3. 更新當日清單
4. 完成班級交班
5. 查驗身分放行
6. 處理逾時未接

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
