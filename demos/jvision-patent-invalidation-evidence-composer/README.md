# 專利無效證據組合器

> 搜尋並組合先前技術證據，支援專利新穎性與進步性爭議策略。​̲

搜尋並組合先前技術證據，支援專利新穎性與進步性爭議策略。​̲

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **爭議請求項拆解** — 將目標專利請求項拆成可比對的必要技術特徵。
- **先前技術搜尋** — 跨專利、論文與產品資料尋找公開日前證據。
- **特徵對應矩陣** — 逐項映射請求項特徵與各份先前技術揭露。
- **公開日驗證** — 核對優先權、公開日期與證據可用時點。
- **證據組合推演** — 測試單一文獻或多文獻組合的攻擊路徑。
- **無效策略卷宗** — 彙整引用、缺口、反方論點與建議主張。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 拆解請求項
2. 搜尋前案
3. 映射特徵
4. 驗證時點
5. 組合論證
6. 定稿策略

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
