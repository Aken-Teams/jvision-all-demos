# 原產地規則判定器

> 依 BOM、製程與貿易協定規則計算原產資格，支持正確申請優惠。

依 BOM、製程與貿易協定規則計算原產資格，支持正確申請優惠。

**產業別：**採購供應鏈　|　**系統類型：**erp

## 功能模組

- **協定情境選擇** — 設定出口國、進口國、適用協定與判定日期。
- **BOM 產地拆解** — 呈現各項投入物的產地、分類、價值與供應來源。
- **製程實質轉型圖** — 檢視生產步驟、加工地點與稅則變更效果。
- **原產資格試算** — 計算區域價值含量、稅則轉換及特定製程門檻。
- **資格缺口清單** — 找出非原產材料、證明不足與規則未滿足項目。
- **優惠資格核定** — 核准原產結論、協定優惠與證明文件適用期間。

## 適合誰使用

- 國貿主管
- 報關人員
- 業務

## 運作流程

1. 設定貿易協定
2. 核對 BOM 產地
3. 檢視製程轉型
4. 計算資格門檻
5. 補正資格缺口
6. 核准優惠使用

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
