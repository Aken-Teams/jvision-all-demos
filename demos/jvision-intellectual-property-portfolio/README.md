# 智慧財產組合決策平台

> 整合專利、商標、營業秘密與授權資產的擬真資料，從技術、產品、市場、成本及到期風險評估組合價值，協助企業決定申請、維護、布局、授權或放棄，並看清核心產品的保護缺口與年度預算配置。

**產業別：**研發管理　|　**系統類型：**legal-case

## 功能模組

- **智財組合總覽** — 呈現各類資產、國家地區、生命週期與策略價值分布。
- **技術產品關聯圖** — 連結專利、商標、營業秘密、技術主題與產品線。
- **保護缺口分析** — 找出核心市場、產品功能與競爭技術的保護空白。
- **資產價值評分** — 依商業、技術、法律與防禦價值建立決策評分。
- **預算情境模擬** — 比較申請、維護、海外布局及放棄方案的成本效益。
- **處置決策中心** — 管理申請、維護、授權、讓與或放棄的審議紀錄。

## 適合誰使用

- 智慧財產主管
- 研發主管
- 產品經理
- 企業法務

## 運作流程

1. 盤點智財組合
2. 連結技術產品
3. 辨識保護缺口
4. 評估資產價值
5. 模擬預算配置
6. 核定資產處置
