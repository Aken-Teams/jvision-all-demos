**產業別：**企業協作　|　**系統類型：**procurement-srm

## 功能模組

- **用品庫存盤點** — 彙整各據點現有量、已預留量、效期與可用安全庫存。
- **耗用趨勢分析** — 分析領用速度、季節變化與部門用量異常。
- **活動需求加成** — 依會議、招募、培訓與訪客活動換算額外用品需求。
- **人數情境預測** — 結合排班、門禁與遠距比例模擬不同到辦人數的耗用量。
- **補貨方案試算** — 比較補貨數量、下單時點、缺料風險與庫存持有成本。
- **採購補貨執行** — 產生建議採購單，核准後送交供應商並追蹤到貨。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 盤點可用庫存
2. 分析實際耗用
3. 載入活動需求
4. 模擬人數情境
5. 確認補貨建議
6. 下單並追蹤到貨

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
