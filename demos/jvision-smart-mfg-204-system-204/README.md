# 產線排班管理系統（三班制排班）

> 訂單到入庫的製造現場全流程數位化

產線排班管理系統（三班制排班）提供三班制/四班二輪排班規則引擎、產線人力配置與技能對應、換班/代班申請與審核。產線主管依「產能需求輸入 → 人力技能比對 → 自動排班 → 主管調整 → 員工確認 → 班表發佈」推進作業，優先解決「手工排班耗時且易疏漏技能配對」，生產排程部則以排班達成率與換班申請處理時效確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**MES 製造執行系統

## 功能模組

- **工單管理** — 訂單轉工單、拆併單與工單派發
- **排程排產** — 依產能、交期、負載自動排程
- **現場執行** — 派工、報工與進度即時回報
- **設備稼動 OEE** — 稼動、效率、良率即時監控
- **品質入庫** — 檢驗判定、不良處置與入庫
- **AI 改善建議** — 異常摘要與瓶頸改善建議

## 適合誰使用

- 產線主管
- 生產排程部
- 人資部

## 運作流程

1. 待處理
2. 主管確認
3. 人資執行
4. 歸檔完成

## 導入效益

- 薪資作業工時：41小時/月 → **8小時/月**
- 出勤異常處理：32分鐘 → **5.2分鐘**
- 招募到位天數：43天 → **26天**
- 表單簽核時效：3天 → **1天**
