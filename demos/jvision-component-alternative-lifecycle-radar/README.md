# 電子料件替代停產風險雷達

> 彙整電子料件清單、供應狀態、停產通知與替代品條件，以風險雷達標出可能斷料的產品。採購與研發可比較規格、驗證進度及成本影響，提前完成替代決策。

彙整電子料件清單、供應狀態、停產通知與替代品條件，以風險雷達標出可能斷料的產品。採購與研發可比較規格、驗證進度及成本影響，提前完成替代決策。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **風險雷達** — 依停產、交期、單一來源與庫存狀態分級料件。
- **影響展開** — 從料號追溯受影響的產品、版本與用料清單。
- **替代搜尋** — 依封裝、電性、認證及供應條件篩選候選料。
- **規格比對** — 並排呈現原料與替代料的關鍵規格及差異。
- **驗證追蹤** — 管理樣品、工程測試、品質認證與核准進度。
- **切換決策** — 比較成本、交期、庫存耗用與導入時程後定案。

## 適合誰使用

- 採購專員
- 電子工程師
- 產品經理
- 供應鏈主管

## 運作流程

1. 識別風險
2. 盤點影響
3. 尋找替代
4. 比較規格
5. 完成驗證
6. 決定切換

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
