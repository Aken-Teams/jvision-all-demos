# 關鍵零組件庫存協同智慧站

與供應商即時共享晶片、被動元件等關鍵料件庫存與產能資訊，強化供需協同備援。

- 原始系統：關鍵零組件庫存協同平台
- 產業分類：智慧製造｜採購管理
- 使用部門：採購部、供應鏈規劃部、生產計畫部
- 工作流程：需求預測共享 → 供應商產能回饋 → 庫存協同調整 → 缺料情境模擬 → 動態調度
- AI 應用：AI 預測關鍵料件供需缺口、智慧建議跨據點庫存調度方案
- 主要 KPI：關鍵料件庫存可視覆蓋率、協同預測準確度、跨點調度反應時間
- 代表產品：E2open、SAP Ariba Supply Chain Collaboration、Supplyframe
