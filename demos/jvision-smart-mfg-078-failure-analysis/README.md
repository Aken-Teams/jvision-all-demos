# FA（Failure Analysis，不良分析）

> 從異常到改善的品質閉環與追溯稽核

FA（Failure Analysis，不良分析）提供送測案件登錄、分析排程管理、分析設備（X-ray/SEM/切片）紀錄。FA實驗室依「送測登錄→初步檢查→儀器分析→失效機制判定→報告產出」推進作業，優先解決「分析週期長」，研發部則以平均分析週期與根因確認率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- FA實驗室
- 研發部
- 品保部

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉

## 導入效益

- 批號追溯時間：184分鐘 → **15分鐘**
- 客訴平均關案：22天 → **9.4天**
- 改善驗證率：61% → **92%**
- 重複不良率：6% → **2%**
