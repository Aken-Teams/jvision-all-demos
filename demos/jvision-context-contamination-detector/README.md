**產業別：**資訊科技　|　**系統類型：**security-soc

## 功能模組

- **Context 組裝** — 呈現系統指令、檢索片段、工具回傳與對話內容的實際組裝順序。
- **來源信任評分** — 依來源身分、簽章、權限、歷史可信度與內容異常計算風險。
- **注入語句掃描** — 辨識指令劫持、越權要求、資料外洩誘導與隱藏控制語句。
- **高權重污染定位** — 找出不可信片段如何進入高優先層級並影響模型決策。
- **污染影響模擬** — 模擬隔離、降權或移除片段後的回答、安全與任務完成差異。
- **Context 隔離** — 核准後封鎖來源、調降片段權重或更新檢索過濾規則。

## 適合誰使用

- AI 架構師
- 資料科學家

## 運作流程

1. 掌握污染風險
2. 還原組裝路徑
3. 判讀注入訊號
4. 模擬處置方案
5. 核准防護變更
6. 確認污染解除
