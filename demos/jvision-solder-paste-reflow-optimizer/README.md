**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **製程總覽** — 彙整線別品質、產品切換及主要缺陷趨勢。
- **錫膏分析** — 檢視錫膏高度、面積、體積與偏移分布。
- **溫度曲線** — 比較各溫區設定、升溫斜率與液相時間。
- **缺陷關聯** — 分析橋接、少錫、立碑等缺陷與參數關係。
- **配方建議** — 產生候選印刷與回焊設定並顯示限制條件。
- **試產驗證** — 建立模擬試產批次並比較配方前後品質結果。

## 適合誰使用
