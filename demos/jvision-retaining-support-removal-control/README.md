# 擋土支撐拆除管制台

> 依核定拆撐圖將各階段支撐拆除條件拆成樓板強度、回築完成度、監測值、臨時補強與作業順序檢核，串接聯合簽認、現場放行及拆後觀測，防止只憑會議口頭同意或誤用舊版順序施工。

依核定拆撐圖將各階段支撐拆除條件拆成樓板強度、回築完成度、監測值、臨時補強與作業順序檢核，串接聯合簽認、現場放行及拆後觀測，防止只憑會議口頭同意或誤用舊版順序施工。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **拆撐階段** — 依區域、支撐層次及順序建立作業批次。
- **核定圖版** — 綁定有效拆撐圖、計算書與變更註記。
- **條件矩陣** — 檢核樓板強度、回築、補強及周邊作業。
- **監測判讀** — 彙整壁體位移、軸力與地下水位是否合格。
- **聯合放行** — 由結構、監測與工地責任人依序簽認。
- **拆除紀錄** — 記錄實際順序、異常停點及拆後觀測。

## 適合誰使用

- 土木工程師
- 結構技師
- 工地主任

## 運作流程

1. 建立階段
2. 確認圖版
3. 蒐集條件
4. 判讀監測
5. 聯合放行
6. 拆後追蹤

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
