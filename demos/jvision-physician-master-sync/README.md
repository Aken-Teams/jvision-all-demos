# 醫師主檔同步管制台

> 管理醫師到離職、科別、院區、執照效期、簽章與申報代碼的跨系統發布，將失敗項目集中補送，避免診間無法開單或逾期資格持續使用。

管理醫師到離職、科別、院區、執照效期、簽章與申報代碼的跨系統發布，將失敗項目集中補送，避免診間無法開單或逾期資格持續使用。

**產業別：**醫療照護　|　**系統類型：**it-ops

## 功能模組

- **異動建檔** — 建立醫師事件
- **資格檢核** — 查核執照效期
- **系統範圍** — 選擇發布目標
- **生效排程** — 設定啟停時間
- **失敗補送** — 修復同步異常
- **發布稽核** — 確認各端一致

## 適合誰使用

- 人事承辦
- 醫療資訊人員
- 醫務管理師

## 運作流程

1. 建立異動
2. 檢查資格
3. 設定範圍
4. 核准發布
5. 處理失敗
6. 完成驗證

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
