**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **現金基準盤點** — 彙整銀行餘額、融資可用額與已知現金部位。
- **十三週預測曲線** — 按週呈現現金流入、流出、期末餘額與信賴區間。
- **驅動因子拆解** — 量化銷售、收款、採購及付款條件對預測的影響。
- **預測變動歸因** — 比較版本差異並指出現金預測上修或下修的原因。
- **因果情境模擬** — 調整營運假設，模擬各週流動性與資金缺口變化。
- **資金行動建議** — 依缺口風險排序催收、延付、融資與調撥方案。

## 適合誰使用

- 財務長
- Treasurer
- 資金人員

## 運作流程

1. 建立現金基準
2. 檢視十三週曲線
3. 追查營運驅動
4. 解釋版本變化
5. 模擬改善方案
6. 核准資金行動
