# 鑄造砂箱配對流轉台

> 供鑄造現場管理上下砂箱的配對、尺寸、所在造型線與維修狀態，模型拆裝及移位皆留交接，避免錯箱、尋箱或待修箱誤排澆注。

供鑄造現場管理上下砂箱的配對、尺寸、所在造型線與維修狀態，模型拆裝及移位皆留交接，避免錯箱、尋箱或待修箱誤排澆注。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **配對總覽** — 查看上下箱組合
- **造型領箱** — 綁定模型爐次
- **流轉位置** — 更新線別區位
- **退箱檢傷** — 記錄變形裂損
- **砂箱焊修** — 追蹤修復進度
- **復用放行** — 確認尺寸可用

## 適合誰使用

- 砂箱管理員
- 造型班長

## 運作流程

1. 建立配對
2. 造型領用
3. 線間移轉
4. 澆後退箱
5. 焊修校正
6. 檢驗復用

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
