# 宮廟科儀供品整備台

> 供宮廟依科儀場次管理供品、法器、疏文、桌案配置與志工分工，透過整備清單、覆核及回收盤點降低儀式缺漏與重複採買。

**產業別：**宗教服務　|　**系統類型：**operations-console

## 功能模組

- **科儀場次** — 建立日期、壇別與儀式需求
- **整備範本** — 套用各科儀供品法器清單
- **志工分工** — 指派桌案、文書與供品任務
- **物品領用** — 記錄法器及耗材領用數量
- **開壇覆核** — 逐項確認位置與整備狀態
- **回收盤點** — 結束後盤點法器及剩餘供品

## 適合誰使用

- 廟務主任
- 科儀執事
- 志工組長

## 運作流程

1. 建立科儀場次
2. 產生整備清單
3. 安排志工分工
4. 辦理物品領用
5. 執行開壇覆核
6. 完成回收盤點

## 導入效益

- 活動籌備工時：20小時 → **5小時**
- 報名掌握率：65% → **94%**
- 物資盤點：6小時 → **1小時**
- 志工調度時效：3天 → **1天**
