# 鄰房現況爭議比對台

> 將施工前鄰房鑑定照片、位置標記與住戶簽認資料，和施工期間新通報的裂縫、滲水或沉陷紀錄並列比對，整理時間軸、量測變化及處理結論，支援責任協調。

將施工前鄰房鑑定照片、位置標記與住戶簽認資料，和施工期間新通報的裂縫、滲水或沉陷紀錄並列比對，整理時間軸、量測變化及處理結論，支援責任協調。

**產業別：**營建工程　|　**系統類型：**legal-case

## 功能模組

- **鄰房案件圖** — 依門牌、樓層與空間查看通報和處理狀態。
- **基準影像庫** — 管理施工前照片、拍攝方向、位置及簽認。
- **損害通報** — 記錄裂縫、滲水、沉陷等現況與住戶主張。
- **前後比對** — 並列相同位置影像、尺寸與量測變化。
- **會勘紀錄** — 保存住戶、技師與施工方的現勘意見。
- **協議結案** — 追蹤責任結論、修繕承諾與簽認文件。

## 適合誰使用

- 鄰損協調人員
- 工地主任
- 法務人員

## 運作流程

1. 查看案件
2. 調取基準
3. 建立通報
4. 比對差異
5. 辦理會勘
6. 完成協議

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
