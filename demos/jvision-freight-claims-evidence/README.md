# 貨損索賠證據管理台

> 供物流商集中處理破損、短少、污染與延遲衍生的客戶索賠，串接模擬託運資料、照片、簽收註記、責任判定與賠付協商，建立可稽核的案件證據鏈及承運商追償進度。

供物流商集中處理破損、短少、污染與延遲衍生的客戶索賠，串接模擬託運資料、照片、簽收註記、責任判定與賠付協商，建立可稽核的案件證據鏈及承運商追償進度。

**產業別：**物流運輸　|　**系統類型：**finance-case

## 功能模組

- **案件受理** — 登錄託運單、損失類型與求償額。
- **證據彙整** — 整理照片、簽收單及往來紀錄。
- **責任判定** — 依契約條款分析責任歸屬。
- **賠付審批** — 試算賠償並執行層級核准。
- **承運追償** — 追蹤外包承運商回覆和付款。
- **損失分析** — 分析路線、客戶與貨類風險。

## 適合誰使用

- 理賠專員
- 物流客服
- 營運主管

## 運作流程

1. 受理索賠
2. 收集證據
3. 判定責任
4. 核准賠付
5. 執行追償
6. 結案分析

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
