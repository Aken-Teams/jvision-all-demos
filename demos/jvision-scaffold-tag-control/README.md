# 施工架掛牌巡檢台

> 以區域和架體編號管理施工架搭設申請、完工查驗、合格掛牌、每日巡檢與禁用狀態，讓現場人員明確辨識可使用範圍並追蹤缺失改善。

以區域和架體編號管理施工架搭設申請、完工查驗、合格掛牌、每日巡檢與禁用狀態，讓現場人員明確辨識可使用範圍並追蹤缺失改善。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **架體看板** — 依立面與區域顯示合格、待驗及禁用狀態。
- **搭設申請** — 建立架體範圍、用途、載重與搭設班組。
- **完工查驗** — 依類型檢查踏板、護欄、拉條及基座。
- **掛牌管理** — 核發合格牌並控制有效期限與使用條件。
- **巡檢缺失** — 登錄每日巡檢、天候複檢及缺失照片。
- **禁用復驗** — 隔離不合格區域並於改善後辦理復驗。

## 適合誰使用

- 安全衛生人員
- 鷹架作業主管
- 施工工程師

## 運作流程

1. 架體看板
2. 搭設申請
3. 完工查驗
4. 掛牌管理
5. 巡檢缺失
6. 禁用復驗

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
