# 車隊事故處置管理台

> 讓營業車隊在事故發生後統一記錄現場資訊、駕駛陳述、車損與第三方資料，協調報案、維修、保險及代班安排並追蹤復駛。

讓營業車隊在事故發生後統一記錄現場資訊、駕駛陳述、車損與第三方資料，協調報案、維修、保險及代班安排並追蹤復駛。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **事故通報** — 登錄時間、地點、人車及傷損概況。
- **現場資料** — 整理照片、陳述與第三方資訊。
- **營運應變** — 安排代班、轉乘及路線調整。
- **車損維修** — 追蹤估價、核准與完修進度。
- **保險協辦** — 管理報案資料與理賠文件。
- **復駛核准** — 確認檢查結果並解除停駛。

## 適合誰使用

- 車隊調度員
- 安全主管
- 保險經辦

## 運作流程

1. 受理事故通報
2. 檢核現場資料
3. 安排營運替代
4. 追蹤車損維修
5. 辦理保險案件
6. 審核車輛復駛

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
