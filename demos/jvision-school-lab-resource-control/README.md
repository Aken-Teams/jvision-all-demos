# 校園實驗室排用台

> 供大專校院統籌實驗室、專業教室、課程時段、使用資格與耗材需求，讓系所排課、教師申請及管理員審核可在同一流程避免資源衝突。

供大專校院統籌實驗室、專業教室、課程時段、使用資格與耗材需求，讓系所排課、教師申請及管理員審核可在同一流程避免資源衝突。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **資源總覽** — 查看空間負載與待審申請。
- **場域清冊** — 維護容量、設備及限制條件。
- **課程排用** — 編排固定課程與臨時借用。
- **資格檢核** — 確認教師及學生操作資格。
- **耗材準備** — 登錄課次需求與備妥狀態。
- **使用交接** — 記錄點交、異常與復原結果。

## 適合誰使用

- 實驗室管理員
- 系所排課人員
- 授課教師

## 運作流程

1. 檢視負載
2. 選擇場域
3. 安排時段
4. 檢核資格
5. 準備耗材
6. 完成點交

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
