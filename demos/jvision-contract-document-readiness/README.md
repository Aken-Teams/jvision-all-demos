# 承攬合約缺件催辦台

> 依分包合約與工種建立保險、證照、印鑑、保證及計畫書等必備文件清單，集中追蹤版本、效期、退補和進場前完成狀態。

依分包合約與工種建立保險、證照、印鑑、保證及計畫書等必備文件清單，集中追蹤版本、效期、退補和進場前完成狀態。

**產業別：**營建工程　|　**系統類型：**legal-case

## 功能模組

- **合約清冊** — 查看分包文件完整度
- **缺件規則** — 依工種設定必備項目
- **文件收件** — 管理版本效期與簽章
- **催辦中心** — 追蹤退補及逾期事項
- **進場閘門** — 檢查是否可核准進場
- **廠商分析** — 比較補件效率與風險

## 適合誰使用

- 合約管理員
- 工務工程師
- 分包窗口

## 運作流程

1. 建立清單
2. 通知收件
3. 文件提交
4. 內容審核
5. 退補催辦
6. 核准進場

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
