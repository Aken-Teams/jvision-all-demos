# 開挖監測異常應變台

> 彙整傾度、沉陷、地下水位等人工抄錄讀值，依警戒與行動值分級派辦複測、會勘及施工調整，保留每次判讀與解除管制的完整依據。

彙整傾度、沉陷、地下水位等人工抄錄讀值，依警戒與行動值分級派辦複測、會勘及施工調整，保留每次判讀與解除管制的完整依據。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **監測儀表板** — 呈現各類測點最新值與變化趨勢。
- **讀值登錄** — 匯入人工監測表並檢查缺值與單位。
- **門檻判讀** — 依警戒值、行動值與連續趨勢分級。
- **應變派辦** — 指派複測、補強、降載或施工調整。
- **會勘決策** — 記錄專業技師判讀與管制決議。
- **解除管制** — 核對改善及複測結果後恢復作業。

## 適合誰使用

- 監測工程師
- 工地主任
- 專任工程人員

## 運作流程

1. 收集讀值
2. 檢核異常
3. 評估影響
4. 下達措施
5. 執行複測
6. 解除列管

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
