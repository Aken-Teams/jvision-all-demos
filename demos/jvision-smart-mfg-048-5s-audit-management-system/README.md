# 5S稽核管理系統（5S Audit Management System）

> 從異常到改善的品質閉環與追溯稽核

5S稽核管理系統（5S Audit Management System）提供行動裝置稽核表填寫、稽核評分自動彙整、缺失改善追蹤。品保依「稽核排程 → 現場稽核填寫 → 評分彙整 → 缺失改善分派 → 複查結案」推進作業，優先解決「紙本稽核效率低且易遺失」，廠務則以5S稽核平均分數與缺失改善完成率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生產製造　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 品保
- 廠務
- 持續改善部門

## 運作流程

1. 待排程
2. 生產中
3. 待品檢
4. 已入庫

- 缺料停線次數：11次/月 → **2.8次/月**
- 設備稼動率：70% → **83%**
