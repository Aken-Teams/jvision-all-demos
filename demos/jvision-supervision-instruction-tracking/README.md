# 監造指示辦理追蹤台

> 將監造日誌、會議及現場口頭指示統一編號，明確記錄適用位置、要求內容、回覆期限與辦理證據，並處理指示衝突及澄清，避免完成後仍無正式回報。

將監造日誌、會議及現場口頭指示統一編號，明確記錄適用位置、要求內容、回覆期限與辦理證據，並處理指示衝突及澄清，避免完成後仍無正式回報。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **指示總覽** — 彙整來源、期限與辦理狀態。
- **指示登錄** — 記錄要求、位置、圖號與來源。
- **影響判讀** — 判斷成本、工期與施工範圍。
- **責任派辦** — 指定主責分包與回覆期限。
- **辦理回覆** — 提交說明、照片及相關文件。
- **確認關閉** — 由監造驗證成果或退回補正。

## 適合誰使用

- 監造工程師
- 工務工程師
- 專案經理

## 運作流程

1. 掌握指示
2. 正式登錄
3. 判讀影響
4. 指派辦理
5. 提交回覆
6. 驗證關閉

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
