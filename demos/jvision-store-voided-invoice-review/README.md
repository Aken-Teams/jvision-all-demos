# 門市發票作廢覆核台

> 集中收件門市作廢發票、原因、原票影像與重開資訊，依跨日、跨期及憑證缺漏分流覆核，讓總部財會在申報前完成追件、核准與稽核留痕。

集中收件門市作廢發票、原因、原票影像與重開資訊，依跨日、跨期及憑證缺漏分流覆核，讓總部財會在申報前完成追件、核准與稽核留痕。

**產業別：**零售電商　|　**系統類型：**finance-ledger

## 功能模組

- **作廢總覽** — 查看各店待辦與風險件
- **門市送件** — 登錄原票、原因與附件
- **憑證核驗** — 檢查票號與證據完整性
- **跨期判定** — 辨識跨日跨申報期案件
- **主管覆核** — 核准退回並留下意見
- **申報歸檔** — 彙整重開與申報證據

## 適合誰使用

- 門市主管
- 財會人員
- 稽核人員

## 運作流程

1. 監看總覽
2. 提交作廢
3. 核驗憑證
4. 判定期間
5. 完成覆核
6. 封存結案

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
