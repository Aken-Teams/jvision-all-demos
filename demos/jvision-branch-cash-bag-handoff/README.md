# 分行現鈔箱袋交接台

> 以箱袋編號管理現鈔金額、幣別、封條、點數差異與班次交接，要求交付及接收雙方確認，讓短溢款可回溯至特定箱袋與作業時段。

以箱袋編號管理現鈔金額、幣別、封條、點數差異與班次交接，要求交付及接收雙方確認，讓短溢款可回溯至特定箱袋與作業時段。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **箱袋台帳** — 管理編號幣別與預計額
- **封裝點數** — 記錄封條及交付金額
- **雙方交接** — 保存交收時間與責任人
- **接收複點** — 核對實收金額和封條
- **短溢調查** — 連結班次及現金交易
- **差異結清** — 覆核調整與責任結果

## 適合誰使用

- 分行櫃員
- 出納主管
- 內控人員

## 運作流程

1. 建立現鈔箱袋
2. 完成封裝點數
3. 執行雙人交接
4. 接收開封複點
5. 調查短溢差異
6. 核定差異結案

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
