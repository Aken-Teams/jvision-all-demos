# 施工樣板核准留樣台

> 管理實體施工樣板的材料批次、施工步驟、核准照片、附帶修正與保留位置，讓後續大量施工和驗收都能依同一品質基準判定。

管理實體施工樣板的材料批次、施工步驟、核准照片、附帶修正與保留位置，讓後續大量施工和驗收都能依同一品質基準判定。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **樣板清冊** — 查看類型位置與狀態
- **材料紀錄** — 連結品牌批次與色號
- **工法影像** — 保存步驟及細部照片
- **會勘意見** — 記錄各方修正條件
- **核准封樣** — 鎖定品質基準版本
- **標準發布** — 提供工班查閱比對

## 適合誰使用

- 品質工程師
- 監造工程師
- 分包領班

## 運作流程

1. 提出樣板
2. 完成施作
3. 聯合會勘
4. 修正複驗
5. 核准留樣
6. 量產比對

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
