# 技能缺口風險雷達

> 預測策略與技術變化造成的技能缺口，協助企業提前安排人才培育。提升人才供給與業務需求的匹配度。

預測策略與技術變化造成的技能缺口，協助企業提前安排人才培育。提升人才供給與業務需求的匹配度。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **能力風險雷達** — 依部門、職族與時間尺度呈現技能供需風險分布。
- **變化訊號掃描** — 追蹤策略、技術、專案與工作任務變化所帶來的新能力需求。
- **技能需求預測** — 預估各技能的需求人數、熟練度與缺口出現時間。
- **人才供給盤點** — 彙整員工技能證據、成長速度與可轉移能力。
- **培育情境模擬** — 比較訓練、招募、輪調與外包方案的成本及成效。
- **補缺行動組合** — 建立優先技能、目標人群、培育期限與追蹤指標。

## 適合誰使用

- L&D 主管
- 部門主管
- 員工

## 運作流程

1. 設定策略情境
2. 掃描需求訊號
3. 預測技能需求
4. 盤點人才供給
5. 比較補缺方案
6. 啟動提前培育

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
