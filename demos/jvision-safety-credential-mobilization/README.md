# 工地進場資格審驗台

> 依工地、工種與預定作業，自動組合人員進場應備的職安教育、專業證照、保險及體檢文件，集中處理送審、補件、到期與跨案移轉，讓現場在排班前攔下資格不符人員。

依工地、工種與預定作業，自動組合人員進場應備的職安教育、專業證照、保險及體檢文件，集中處理送審、補件、到期與跨案移轉，讓現場在排班前攔下資格不符人員。

**產業別：**營建工程　|　**系統類型：**operations-console

## 功能模組

- **進場名冊** — 彙整分包、人員、工種、雇主與預定進場日期。
- **資格矩陣** — 依作業類型列出教育、證照、保險及體檢要求。
- **文件送審** — 上傳證明文件並辨識有效期限與適用工地。
- **審驗補件** — 標記不符原因、退補紀錄與重新送審結果。
- **到期預警** — 依排班日提示即將失效或涵蓋期間不足的文件。
- **放行名冊** — 發布指定日期可進場人員及受限作業範圍。

## 適合誰使用

- 職安管理員
- 分包管理員
- 門禁承辦人

## 運作流程

1. 提報進場人員
2. 產生資格要求
3. 提交證明文件
4. 審驗並通知補件
5. 檢查排班有效性
6. 發布進場名冊

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
