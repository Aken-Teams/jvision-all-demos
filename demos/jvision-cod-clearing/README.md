# 物流代收貨款清算台

> 勾稽配送簽收、拒收、司機現金繳回、電子代收與商家撥款，計算手續費及應付淨額，攔截短繳、重撥與未完成配送仍撥款。

勾稽配送簽收、拒收、司機現金繳回、電子代收與商家撥款，計算手續費及應付淨額，攔截短繳、重撥與未完成配送仍撥款。

**產業別：**物流運輸　|　**系統類型：**finance-case

## 功能模組

- **配送母體** — 載入簽拒收狀態
- **繳回點收** — 核對現金電子款
- **代收勾稽** — 找出未平交易
- **費用清算** — 計算商家淨額
- **差異追收** — 處理短繳重撥
- **撥款核准** — 發布商家付款

## 適合誰使用

- 代收會計
- 場站出納
- 清算主管

## 運作流程

1. 載入配送
2. 點收繳回
3. 執行勾稽
4. 計算淨額
5. 調查差異
6. 核准撥款

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
