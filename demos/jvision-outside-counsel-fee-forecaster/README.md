# 外部律師費用預測器

> 依案件階段、律師工時與關鍵事件預測外部律師費用及預算缺口。<br>

依案件階段、律師工時與關鍵事件預測外部律師費用及預算缺口。<br>

**產業別：**專業服務　|　**系統類型：**finance-case

## 功能模組

- **案件階段建模** — 依調查、訴答、證據開示、審理與和解建立費用結構。
- **律師工時估算** — 按事務所、職級、費率與工作類型推估所需工時。
- **事件成本情境** — 模擬禁制令、追加請求、專家證人或延後審理的成本影響。
- **費用曲線預測** — 結合歷史案件與目前進度預測月度支出及完工估算。
- **預算超支預警** — 偵測費率、工時或範圍偏差，解釋可能超支的主要驅動因子。
- **律所預算協商** — 產出階段預算、替代費用方案與可供律所回覆的調整要求。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 建立案件基線
2. 估算工作工時
3. 模擬關鍵事件
4. 產生費用預測
5. 處理超支風險
6. 核定律所預算

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
