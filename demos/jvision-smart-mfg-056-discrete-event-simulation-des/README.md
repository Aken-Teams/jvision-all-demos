# 產線模擬智慧站

以離散事件模擬技術驗證產線佈局、產能與流程設計之虛擬驗證工具。

- 原始系統：產線模擬系統（Discrete Event Simulation, DES）
- 產業分類：智慧製造｜製造管理
- 使用部門：工業工程、製造工程、廠務規劃
- 工作流程：現況/設計數據建模 → 模擬情境設定 → 模擬運算執行 → 結果分析比較 → 方案決策採納
- AI 應用：AI自動搜尋最佳產線配置方案、智慧加速大量情境模擬運算
- 主要 KPI：模擬預測準確率、產能規劃週期縮短率、投資決策採用率
- 代表產品：Siemens Plant Simulation（Tecnomatix）、FlexSim、AnyLogic
