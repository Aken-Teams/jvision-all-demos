# 套管預留預埋管制台

> 在結構澆置前整合給排水、消防、空調與電氣套管需求，管理定位、尺寸、補強核准及封模前查驗，減少漏埋後洗孔與結構損傷。

在結構澆置前整合給排水、消防、空調與電氣套管需求，管理定位、尺寸、補強核准及封模前查驗，減少漏埋後洗孔與結構損傷。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **套管整合圖** — 合併各機電系統的預留預埋需求
- **點位清冊** — 管理尺寸、標高、方向與責任分包
- **結構檢核** — 辨識梁柱干涉及補強需求
- **版次凍結** — 鎖定各澆置區使用的施工版次
- **封模查驗** — 逐點確認固定、封口及定位成果
- **漏埋處置** — 審批洗孔、改道或結構補強方案

## 適合誰使用

- 機電整合工程師
- 結構工程師
- 現場工程師

## 運作流程

1. 彙整套管需求
2. 完成結構套核
3. 凍結澆置版次
4. 現場定位安裝
5. 執行封模查驗
6. 處理漏埋偏位

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
