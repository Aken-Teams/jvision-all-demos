# 租賃車違規歸責作業台

> 供租車與長租業者將違規通知對應租約、駕駛與用車時段，管理申訴、代繳、行政處理費及客戶追償，保留通知與送達證據以降低逾期罰款。

**產業別：**交通運輸　|　**系統類型：**finance-case

## 功能模組

- **通知收件** — 登錄違規機關、日期、車號與期限。
- **租約比對** — 依用車時段找出承租人與駕駛。
- **責任判定** — 判斷駕駛負擔、公司負擔或申訴。
- **代繳處理** — 記錄罰款、行政費與付款狀態。
- **客戶追償** — 產生通知並追蹤收款及異議。
- **案件結案** — 彙整繳款、申訴與送達證據。

## 適合誰使用

- 租賃營運專員
- 客服人員
- 財務出納

## 運作流程

1. 登錄通知
2. 配對租約
3. 判定處置
4. 通知客戶
5. 完成款務
6. 歸檔結案

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
