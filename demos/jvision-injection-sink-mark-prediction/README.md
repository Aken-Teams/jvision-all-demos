# 射出成型縮痕預測系統

> 彙整產品肉厚、模具區域、保壓壓力、保壓時間與冷卻條件等擬真資料，預測各批次縮痕風險與可能位置，協助試模及品保人員在量產前比較參數方案、確認改善效果並留下判定紀錄。

彙整產品肉厚、模具區域、保壓壓力、保壓時間與冷卻條件等擬真資料，預測各批次縮痕風險與可能位置，協助試模及品保人員在量產前比較參數方案、確認改善效果並留下判定紀錄。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **縮痕風險總覽** — 以批次、機台與產品彙整縮痕風險、待處理案件及近期變化。
- **產品肉厚建模** — 設定產品區域、肉厚、肋位與柱位，建立縮痕分析所需的擬真假資料。
- **成型條件輸入** — 編輯料溫、模溫、保壓、冷卻及澆口等條件，形成預測情境。
- **缺陷熱區預測** — 用產品示意圖呈現縮痕位置、風險等級與主要影響因子。
- **參數方案比較** — 並列多組調機方案，查看風險、週期與品質指標的差異。
- **改善驗證紀錄** — 記錄採用方案、抽檢結果、審核意見與結案狀態。

## 適合誰使用

- 試模工程師
- 射出製程工程師
- 品保工程師

## 運作流程

1. 檢視風險
2. 建立模型
3. 輸入條件
4. 判讀熱區
5. 比較方案
6. 驗證結案

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
