# 標案數字一致性稽核員

> 跨標書、報價、時程與人力表核對數字，及早消除投標文件矛盾。提升投標文件一致性與審核效率。

**產業別：**專業服務　|　**系統類型：**finance-case

## 功能模組

- **稽核案件台** — 選擇標案版本與待核對文件，界定本次數字稽核範圍。
- **數字關聯圖** — 建立總價、工期、工時、人數與工作項目間的引用及計算關係。
- **跨表矛盾檢查** — 逐項比對標書、報價單、甘特圖與人力配置表的數值。
- **差異根因追查** — 沿版本、公式與來源欄位追查數字不一致的可能原因。
- **修正方案排序** — 依影響範圍、可信來源與截止時間排列修正建議。
- **一致性驗證** — 重算修正版文件並產出可提交的一致性檢查結論。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 建立稽核案件
2. 映射數字關係
3. 標記矛盾項目
4. 確認差異根因
5. 核准修正方案
6. 驗證並結案
