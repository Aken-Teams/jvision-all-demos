**產業別：**企業協作　|　**系統類型：**collaboration-pm

## 功能模組

- **教訓語意搜尋** — 以事件、症狀、根因與改善措施搜尋相似失敗經驗。
- **敏感層級判定** — 辨識個資、客戶機密、法律特權與可能究責的內容層級。
- **安全摘要生成** — 保留可學習的因果與處置內容，同時遮蔽姓名及敏感細節。
- **教訓來源核證** — 連結事故報告、工單、會議決議與修復紀錄以驗證結論。
- **受控經驗分享** — 依職務與用途產生不同揭露程度的分享版本。
- **改善措施複用** — 將已驗證的預防措施轉成檢核表、作業指引或團隊任務。

## 適合誰使用

- 知識工作者
- 主管
- 客服

## 運作流程

1. 描述待解問題
2. 篩選可見內容
3. 產生安全結果
4. 核證教訓
5. 核准分享
6. 採用改善
