# SPC統計製程管制系統（Statistical Process Control）

> 從異常到改善的品質閉環與追溯稽核

SPC統計製程管制系統（Statistical Process Control）提供管制圖即時繪製、製程能力分析（Cp/Cpk）、超規則自動預警。品保依「製程數據採集 → 管制圖繪製 → 超規則判定 → 異常預警 → 對策執行與驗證」推進作業，優先解決「製程異常無法及時發現」，製程工程則以製程能力指數（Cpk）與超規則觸發次數確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生產製造　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 品保
- 製程工程
- 製造工程

## 運作流程

1. 待排程
2. 生產中
3. 待品檢
4. 已入庫
