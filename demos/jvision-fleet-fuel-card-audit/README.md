# 車隊油卡異常核對台

> 比對油卡交易、車輛出勤、里程與核准油品，標記休假日刷卡、短時重複、錯車及超量加油，由車管人員調查並完成核銷、追回或停卡。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **交易總覽** — 查看車卡油品與金額
- **行程比對** — 核對出勤地點與里程
- **異常規則** — 標記重刷錯車及超量
- **駕駛說明** — 收集原因與加油憑證
- **處置核定** — 決定核銷追回或停卡
- **油耗分析** — 比較車輛司機與站點

## 適合誰使用

- 車管人員
- 駕駛主管
- 財務人員

## 運作流程

1. 匯入交易
2. 比對行程
3. 產生異常
4. 取得說明
5. 核定處置
6. 檢討油耗

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
