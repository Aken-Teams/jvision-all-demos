# 禁運與制裁關聯篩查器

> 穿透客戶、受益人與交易關係進行制裁篩查，阻止高風險交易放行。

穿透客戶、受益人與交易關係進行制裁篩查，阻止高風險交易放行。

**產業別：**專業服務　|　**系統類型：**security-soc

## 功能模組

- **交易對手建檔** — 彙整客戶、供應商、銀行、船舶及交易參與者的識別資料。
- **受益所有權穿透** — 沿股權與控制鏈解析最終受益人、代理人及關聯企業。
- **制裁名單匹配** — 以名稱、別名、證件、地址與國籍比對多國制裁名單。
- **交易關係圖譜** — 呈現付款、物流、轉售與中介關係中的間接曝險路徑。
- **命中風險研判** — 結合相似度、控制比例、司法管轄與交易行為解釋風險。
- **交易放行閘門** — 依研判結果執行放行、補件、暫停或拒絕交易決策。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 識別交易參與者
2. 穿透受益關係
3. 執行名單篩查
4. 追蹤間接曝險
5. 研判命中結果
6. 決定交易處置

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
