# 製程訊號異常預警雲

> 將故障偵測與分類所用的設備製程訊號轉成趨勢、事件與健康分數，提前辨識漂移、突波及多變量異常。使用者可查看關聯批次、判讀風險並建立調查與抑制規則。

將故障偵測與分類所用的設備製程訊號轉成趨勢、事件與健康分數，提前辨識漂移、突波及多變量異常。使用者可查看關聯批次、判讀風險並建立調查與抑制規則。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **健康監看** — 呈現設備群組健康分數、異常數與風險分布。
- **訊號趨勢** — 以多軸曲線查看漂移、突波及基準區間。
- **預警中心** — 集中列出異常事件、嚴重度與可能影響範圍。
- **關聯分析** — 連結訊號、腔體、配方、產品與批次的關聯。
- **規則工作室** — 以表單設定門檻、持續時間及預警抑制條件。
- **事件處置** — 記錄調查結論、責任人、措施與恢復確認。

## 適合誰使用

- 設備工程師
- 製程工程師
- 品質值班人員

## 運作流程

1. 巡查健康
2. 檢視訊號
3. 研判預警
4. 追查關聯
5. 調整規則
6. 完成處置

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
