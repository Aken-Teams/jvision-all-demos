## 功能模組

- **待傳技術資料包** — 盤點圖紙、原始碼、模型、規格與接收者可取得的技術內容。
- **技術特徵辨識** — 解析性能、用途與關鍵參數，對應可能適用的管制分類。
- **接收者與用途審查** — 核查接收組織、人員國籍、最終用途及受限關係。
- **跨境路徑判定** — 評估目的地、雲端區域、存取方式與視同出口情境。
- **許可義務判斷** — 引用管制規則與例外條款，判定許可、限制或禁止要求。
- **放行條件控制** — 產生可分享、需降敏、待許可或禁止傳輸的處置決定。

## 適合誰使用

- 國貿主管
- 報關人員
- 業務

## 運作流程

1. 提交技術資料包
2. 辨識受控技術
3. 審查接收者用途
4. 判定跨境情境
5. 核定管制義務
6. 執行條件式放行
