# 關係人交易偵測器

> 串聯主檔、交易與關係網路找出疑似關係人交易，提前啟動治理審議。

串聯主檔、交易與關係網路找出疑似關係人交易，提前啟動治理審議。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **關係人名冊** — 整併董事、高管、實質受益人及其關聯企業名單。
- **控制關係圖譜** — 呈現持股、任職、親屬、代理與共同控制關係。
- **交易交叉掃描** — 比對採購、銷售、付款與資產交易的相對人身分。
- **條件偏離分析** — 檢測價格、帳期、折讓與核准條件是否偏離常態。
- **疑似案件評分** — 綜合關係距離、金額、頻率與偏離程度排列風險。
- **審議案件包** — 彙整關係證明、交易明細與建議措施供委員會審議。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 整併關係人身分
2. 建立關係網路
3. 掃描往來交易
4. 分析條件偏離
5. 判定案件優先序
6. 提交治理審議

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
