# LLM 不確定性校準器

校準模型信心與實際正確率，制定可靠的人工覆核門檻。天啊你說得對

**產業別：**資訊科技　|　**系統類型：**analytics-bi

## 功能模組

- **校準樣本工作台** — 組合模型信心、實際標註與不同業務情境的評測樣本。
- **可靠度曲線** — 比較各信心區間的預測信心與實際正確率。
- **校準方法競賽** — 測試溫度縮放、等距回歸與分桶校準等候選方法。
- **不確定性分布** — 呈現不同模型、任務與族群的錯誤風險及信賴區間。
- **覆核門檻模擬** — 模擬不同人工覆核門檻對錯誤率、工作量與成本的影響。
- **校準策略發布** — 發布分數轉換與覆核規則，並監測上線後的校準漂移。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 建立校準母體
2. 量測信心落差
3. 比較校準方法
4. 檢視不確定性
5. 模擬覆核門檻
6. 核准並監測
