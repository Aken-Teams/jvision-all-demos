# 臨時設施拆除放行台

> 針對施工架、防護棚、臨時支撐與圍籬等臨時設施，管理拆除申請、前置條件、安全檢點、影響會簽及分區放行，避免設施過早移除而破壞後續工序、防墜措施或公共安全。

針對施工架、防護棚、臨時支撐與圍籬等臨時設施，管理拆除申請、前置條件、安全檢點、影響會簽及分區放行，避免設施過早移除而破壞後續工序、防墜措施或公共安全。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **拆除申請** — 選擇設施、區域、預定日期與拆除原因。
- **條件核對** — 確認依賴工序完成及替代防護已備妥。
- **影響會簽** — 由受影響的土建、機電與外牆工種表示意見。
- **安全檢點** — 記錄現勘結果、拆除方法與管制範圍。
- **分區放行** — 依樓層或立面區段核准可拆範圍。
- **拆後確認** — 上傳完工影像並追蹤殘留物及防護缺失。

## 適合誰使用

- 工地主任
- 職安人員
- 分包領班

## 運作流程

1. 申請拆除
2. 核對條件
3. 工種會簽
4. 安全現勘
5. 核准放行
6. 拆後結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
