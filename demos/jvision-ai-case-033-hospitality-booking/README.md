# 旅宿房況營收台

> 前台結帳、會員到進銷存的門市一體化

整合房況、訂房平台、加購與結算。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**餐飲旅宿　|　**系統類型：**POS 門市管理

## 功能模組

- **前台結帳** — 點餐、開單與快速結帳
- **桌位 / 訂位** — 桌況與訂位管理
- **訂單管理** — 內用、外帶、外送整合
- **庫存進銷** — 即時庫存與自動叫貨
- **會員行銷** — 會員、點數與優惠
- **日結報表** — 營收與熱銷分析

## 適合誰使用

- 櫃檯專員
- 櫃檯主管
- 餐飲旅宿主管

## 運作流程

1. 待確認
2. 準備中
3. 服務中
4. 已完成

## 導入效益

- 結帳等待：7.7分鐘 → **2.1分鐘**
- 翻桌率：73% → **90%**
- 備料浪費：15% → **5.6%**
- 訂位掌握率：69% → **96%**
