# 人資薪假招募艙

> 出勤、薪資、招募到績效的人資全流程

管理招募、員工、薪資、請假與績效摘要。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**HRIS 人力資源系統

## 功能模組

- **出勤差勤** — 打卡、請假與加班
- **薪資計算** — 薪資、勞健保與報稅
- **排班管理** — 智慧排班與工時控管
- **招募任用** — 職缺、面試與報到
- **教育訓練** — 課程、證照與紀錄
- **績效考核** — 目標設定與考核流程

## 適合誰使用

- 人資專員
- 人資經理
- 營運主管

## 運作流程

1. 待處理
2. 主管確認
3. 人資執行
4. 歸檔完成

## 導入效益

- 薪資作業工時：41小時/月 → **8小時/月**
- 出勤異常處理：32分鐘 → **5.2分鐘**
- 招募到位天數：43天 → **26天**
- 表單簽核時效：3天 → **1天**
