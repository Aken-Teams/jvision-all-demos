# 工項編碼主檔治理台

> 統一估價、排程、採購、日報與成本系統使用的工項代碼，管理新增、合併、停用和對照關係，避免同工異碼造成成本及進度報表失真。

統一估價、排程、採購、日報與成本系統使用的工項代碼，管理新增、合併、停用和對照關係，避免同工異碼造成成本及進度報表失真。

**產業別：**營建工程　|　**系統類型：**erp

## 功能模組

- **工項樹** — 查看標準層級與代碼
- **新增申請** — 提出名稱定義和用途
- **重複比對** — 辨識同義及近似工項
- **系統映射** — 管理各系統代碼關係
- **治理簽核** — 核准新增合併與停用
- **使用稽核** — 追蹤錯掛和未映射資料

## 適合誰使用

- 成本控制員
- 排程工程師
- 主檔管理員

## 運作流程

1. 提出需求
2. 相似檢查
3. 定義層級
4. 跨域覆核
5. 主管核准
6. 發布監控

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
