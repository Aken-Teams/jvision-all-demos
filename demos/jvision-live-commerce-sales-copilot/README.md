# 直播電商即時導購助手

> 用預設直播腳本、商品卡、模擬聊天室與庫存資料，協助主持人掌握觀眾提問、快速取得商品賣點與比較話術，安排優惠節奏並標記需客服接手的問題；所有即時效果均以介面內情境播放呈現。

用預設直播腳本、商品卡、模擬聊天室與庫存資料，協助主持人掌握觀眾提問、快速取得商品賣點與比較話術，安排優惠節奏並標記需客服接手的問題；所有即時效果均以介面內情境播放呈現。

**產業別：**業務銷售　|　**系統類型：**sales-crm

## 功能模組

- **直播流程腳本** — 依時段編排開場、商品介紹、互動、優惠與收尾橋段。
- **商品導購卡庫** — 快速查看商品賣點、規格比較、適用情境與常見疑問。
- **模擬留言監看** — 播放擬真聊天室訊息，依問題、情緒與購買意圖自動分組。
- **主持提示面板** — 根據當前橋段顯示回答建議、話題提醒與下一個行動提示。
- **優惠節奏控制** — 安排限時價、組合購與倒數卡片，模擬觀眾畫面效果。
- **客服接手機制** — 將尺寸、訂單或敏感客訴標記成案件並指派後續處理。

## 適合誰使用

- 直播主持人
- 直播場控人員
- 電商客服人員

## 運作流程

1. 編排直播流程
2. 準備導購資料
3. 監看觀眾留言
4. 提示主持回應
5. 推出限時優惠
6. 轉交後續服務

- 平均回應時間：26小時 → **6小時**
- 客戶資料完整率：62% → **94%**
