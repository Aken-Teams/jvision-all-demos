# 鄰房現況鑑定追蹤台

> 按門牌、樓層與構件管理施工前鄰房會勘，追蹤聯絡、入戶、照片定位、住戶簽認及拒訪紀錄，發生龜裂求償時快速比對基準證據。

按門牌、樓層與構件管理施工前鄰房會勘，追蹤聯絡、入戶、照片定位、住戶簽認及拒訪紀錄，發生龜裂求償時快速比對基準證據。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **鄰房名冊** — 管理門牌住戶及聯絡
- **會勘排程** — 安排入戶時段與人員
- **構件拍攝** — 按空間與牆面留存影像
- **住戶簽認** — 記錄同意拒訪與備註
- **損況比對** — 比較施工前後變化
- **證據匯出** — 產出爭議所需資料

## 適合誰使用

- 鄰損工程師
- 鑑定技師
- 客服人員

## 運作流程

1. 建立名冊
2. 預約會勘
3. 現況拍攝
4. 完成簽認
5. 品質覆核
6. 爭議比對

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
