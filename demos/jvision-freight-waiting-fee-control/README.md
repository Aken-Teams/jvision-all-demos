# 物流滯留費核算管理台

> 管理車輛在倉庫、碼頭與客戶端等待裝卸所產生的滯留費，彙整到離時間、等待原因、合約免計時數、責任歸屬及請款證據，提升費用回收率。

管理車輛在倉庫、碼頭與客戶端等待裝卸所產生的滯留費，彙整到離時間、等待原因、合約免計時數、責任歸屬及請款證據，提升費用回收率。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **等待事件** — 記錄場站、到離時間與運務單。
- **原因佐證** — 整理排隊原因、照片與聯繫紀錄。
- **合約規則** — 設定免計時間、費率與適用條件。
- **費用試算** — 依事件與規則計算可請金額。
- **責任協商** — 判定客戶、場站或承運方責任。
- **請款追蹤** — 管理送件、折讓與收款結果。

## 適合誰使用

- 運輸調度員
- 運費結算員
- 客戶經理

## 運作流程

1. 建立等待事件
2. 補齊等待佐證
3. 套用計費規則
4. 試算滯留費用
5. 處理責任爭議
6. 送出費用請款

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
