# 實驗筆記完整度教練

> 逐項檢查實驗筆記的重現要素，指出缺漏並引導研究人員補齊紀錄。

**產業別：**研發管理　|　**系統類型：**quality-qms

## 功能模組

- **待檢筆記工作台** — 依實驗風險與缺漏程度排列待檢查的實驗筆記。
- **材料身分核對** — 核對樣品、試劑批號、濃度、用量與保存條件是否完整。
- **方法步驟檢查** — 找出操作順序、參數、時間與判定條件中的缺漏或歧義。
- **環境儀器核驗** — 確認溫濕度、儀器型號、校正狀態及軟體版本已記錄。
- **觀察與原始數據** — 比對觀察敘述、附件與原始數據，標示無法追溯的結論。
- **重現性補正清單** — 依影響程度排序補寫建議，完成後重新驗證筆記完整度。

## 適合誰使用

- 實驗室主管
- 研究員
- 技術員

## 運作流程

1. 選取待檢筆記
2. 核對材料資訊
3. 審查方法步驟
4. 確認環境與儀器
5. 連結觀察與數據
6. 驗證可重現性

## 導入效益

- 設計變更工時：8小時 → **2小時**
- 文件版本錯誤：6件/月 → **1件/月**
- 專案準時率：70% → **92%**
- 資料查找時間：30分鐘 → **5分鐘**
