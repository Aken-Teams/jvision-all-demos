# 輸送帶馬達異常監測系統

> 以擬真的馬達電流、溫度、振動、轉速及輸送負載建立運轉監測畫面，辨識過載、偏載、卡料與傳動異常，協助產線快速定位受影響區段、派工處置並分析停線原因。

以擬真的馬達電流、溫度、振動、轉速及輸送負載建立運轉監測畫面，辨識過載、偏載、卡料與傳動異常，協助產線快速定位受影響區段、派工處置並分析停線原因。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **輸送線態勢圖** — 以分段流程圖顯示馬達、輸送方向、運轉及停線狀態。
- **馬達負載監看** — 呈現電流、溫度、振動、轉速與輸送負載的擬真趨勢。
- **異常事件佇列** — 集中管理過載、過熱、卡料、滑差及振動異常事件。
- **區段原因分析** — 串聯上下游狀態，判斷偏載、卡料或傳動部件異常。
- **停線處置派工** — 建立停線處置卡、指派機修並記錄安全確認與復線結果。
- **停機損失分析** — 依產線、區段與原因彙整停機時數及影響產量。

## 適合誰使用

- 產線領班
- 設備維護工程師
- 現場機修人員

## 運作流程

1. 掌握全線狀態
2. 檢查馬達負載
3. 確認異常事件
4. 定位問題原因
5. 執行停線處置
6. 檢討停機損失

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
