# Customer Scorecard Management（客戶評分卡管理）

> 應收付、現金流到預算的財務即時掌握

Customer Scorecard Management（客戶評分卡管理）提供客戶評分數據匯入、多維度評分彙總、趨勢圖表分析。業務部依「客戶評分數據取得→標準化彙整→趨勢分析→改善措施擬定→追蹤成效」推進作業，優先解決「各客戶評分格式不一」，品保部則以平均客戶評分與低分項目改善完成率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**財務會計系統

## 功能模組

- **應收帳款** — 開立、對帳與催收
- **應付帳款** — 請款、付款與對帳
- **現金流** — 資金調度與預測
- **預算管理** — 編列、控管與差異分析
- **固定資產** — 資產登錄與折舊
- **總帳傳票** — 傳票、拋轉與月結

## 適合誰使用

- 業務部
- 品保部
- 高階主管

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉

## 導入效益

- 批號追溯時間：184分鐘 → **15分鐘**
- 客訴平均關案：22天 → **9.4天**
- 改善驗證率：61% → **92%**
- 重複不良率：6% → **2%**
