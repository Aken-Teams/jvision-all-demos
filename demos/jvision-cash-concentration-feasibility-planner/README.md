# 現金集中可行性規劃器

> 比較資金池與自動歸集方案及法規限制，規劃可落地的現金集中架構。

比較資金池與自動歸集方案及法規限制，規劃可落地的現金集中架構。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **帳戶流動性地圖** — 彙整各公司、銀行與幣別餘額及資金缺口。
- **資金池架構設計** — 設計實體或名義 pooling 的參與主體與主帳戶關係。
- **歸集規則模擬** — 模擬定額、門檻、零餘額與週期 sweeping 規則。
- **跨境法規檢核** — 檢查外匯、稅務、薄資本與跨境資金移轉限制。
- **集中方案比較** — 比較利息節省、手續費、風險與可動用資金改善幅度。
- **導入決策包** — 產出銀行配置、核准事項、例外條件與分階段上線計畫。

## 適合誰使用

- 財務長
- Treasurer
- 資金人員

## 運作流程

1. 盤點資金版圖
2. 設計 Pooling
3. 模擬 Sweeping
4. 檢核法規限制
5. 比較可行方案
6. 核准導入藍圖

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
