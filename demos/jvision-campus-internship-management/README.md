# 校外實習營運管理台

> 供大專院校管理實習職缺審查、學生媒合、合約文件、訪視紀錄、工時回報與異常輔導，讓系所、企業及學生的責任與里程碑可追蹤並符合校務規範。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **實習總覽** — 彙整職缺、學生、文件及風險狀態。
- **職缺審查** — 檢核企業資格、工作內容與安全條件。
- **學生媒合** — 管理志願、面試、錄取與分發結果。
- **文件管理** — 追蹤合約、保險、家長同意及缺件。
- **訪視輔導** — 安排教師訪視並記錄學生適應情形。
- **異常處理** — 管理工時爭議、職務不符與轉換單位。

## 適合誰使用

- 實習承辦人
- 系所教師
- 職涯中心主管

## 運作流程

1. 審查職缺
2. 媒合學生
3. 確認錄取
4. 完成文件
5. 執行訪視
6. 處理異常

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
