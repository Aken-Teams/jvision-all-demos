# 禮儀服務場次協調台

> 供禮儀公司整合治喪期間的家屬需求、流程時程、場地物品、協力廠商、車輛人員與費用異動，讓禮儀師在高時效且不可出錯的服務中完成逐日確認與交接。

供禮儀公司整合治喪期間的家屬需求、流程時程、場地物品、協力廠商、車輛人員與費用異動，讓禮儀師在高時效且不可出錯的服務中完成逐日確認與交接。

**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **治喪日程** — 排列入殮、奠禮、火化與安葬節點。
- **家屬確認** — 記錄決策人、偏好及待確認事項。
- **用品配置** — 管理會場、花藝、祭品與文書需求。
- **人車調度** — 安排禮儀人員、接體車及接駁車。
- **協力交辦** — 追蹤宗教師、花店與會館任務。
- **異動結算** — 確認加減項、簽認與尾款資料。

## 適合誰使用

- 禮儀師
- 場務主管
- 行政人員

## 運作流程

1. 建立日程
2. 確認需求
3. 配置用品
4. 安排人車
5. 交辦廠商
6. 完成結算

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
