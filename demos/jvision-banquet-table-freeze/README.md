在宴會前依採購、備料與排桌截止點管制桌數版本，記錄各單位確認及封盤後變更授權，讓廚房、場務與服務人力都使用同一執行基準。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **桌數預估** — 維護變更版本
- **單位確認** — 收集備料排桌回覆
- **封盤決策** — 鎖定執行基準
- **變更申請** — 處理封盤後異動
- **影響評估** — 估算食材人力
- **版本發布** — 通知所有單位

## 適合誰使用

- 宴會業務
- 廚房主管
- 宴會經理

## 運作流程

1. 更新預估
2. 單位確認
3. 執行封盤
4. 提出變更
5. 評估核准
6. 重新發布

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
