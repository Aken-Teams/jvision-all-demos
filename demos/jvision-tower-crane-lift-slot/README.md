# 塔吊吊運時段協調台

> 供鋼筋、模板、機電與材料班組申請塔吊時段，列明吊物重量、落點與吊具需求，處理插單、超重退件及臨時停吊，減少工班排隊。

供鋼筋、模板、機電與材料班組申請塔吊時段，列明吊物重量、落點與吊具需求，處理插單、超重退件及臨時停吊，減少工班排隊。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **吊運日曆** — 查看工班時段
- **吊次申請** — 填報重量與落點
- **負載審核** — 檢查吊具及限制
- **插單調序** — 處理急件衝突
- **執行看板** — 回報備妥與完成
- **待時分析** — 統計取消等待

## 適合誰使用

- 塔吊指揮員
- 現場工程師

## 運作流程

1. 提出申請
2. 安全審核
3. 排定時段
4. 備料確認
5. 吊運執行
6. 待時結算

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
