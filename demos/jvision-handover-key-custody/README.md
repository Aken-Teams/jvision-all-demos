# 交屋鑰匙資產管制台

> 以鑰匙編號管理各戶大門、信箱、設備間及公設鑰匙的成套、借用、歸還、封袋與交付，保留持有人和盤點差異，確保交屋前缺件能及時追討或補製。

以鑰匙編號管理各戶大門、信箱、設備間及公設鑰匙的成套、借用、歸還、封袋與交付，保留持有人和盤點差異，確保交屋前缺件能及時追討或補製。

**產業別：**營建工程　|　**系統類型：**operations-console

## 功能模組

- **鑰匙資產簿** — 依戶別、門位、用途與編號管理鑰匙。
- **入庫成套** — 清點原鑰、備份數量、標籤及鑰匙圈組合。
- **借用歸還** — 記錄借用人、用途、期限與歸還狀況。
- **逾期追查** — 追蹤未還、遺失、損壞及補製責任。
- **交屋盤點** — 按戶核對應交與實有鑰匙數量。
- **封袋交付** — 完成封袋、編碼、交付及住戶簽收。

## 適合誰使用

- 交屋行政
- 鑰匙管理員
- 工務工程師

## 運作流程

1. 查看資產
2. 辦理入庫
3. 登記借還
4. 追查異常
5. 交屋盤點
6. 封袋簽收

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
