# 現場派工系統（Real-Time Dispatching, RTD）

> 訂單到入庫的製造現場全流程數位化

現場派工系統（Real-Time Dispatching, RTD）提供即時工單分派、優先序動態調整、人機配置建議。現場班組長依「排程下達 → 現場狀態擷取 → 動態派工 → 執行回報 → 異常重派」推進作業，優先解決「排程無法反映現場即時變化」，生管則以派工達成率與平均等待時間確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生產製造　|　**系統類型：**MES 製造執行系統

## 功能模組

- **工單管理** — 訂單轉工單、拆併單與工單派發
- **排程排產** — 依產能、交期、負載自動排程
- **現場執行** — 派工、報工與進度即時回報
- **設備稼動 OEE** — 稼動、效率、良率即時監控
- **品質入庫** — 檢驗判定、不良處置與入庫
- **AI 改善建議** — 異常摘要與瓶頸改善建議

## 適合誰使用

- 現場班組長
- 生管
- 製造工程

## 運作流程

1. 待調度
2. 配送中
3. 品檢確認
4. 入庫完成

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：77% → **93%**
- 缺料停線次數：13次/月 → **2.8次/月**
- 設備稼動率：75% → **92%**
