## 功能模組

- **生成式查詢庫** — 管理品牌、品類、競品與購買意圖相關的測試問題。
- **回答採樣器** — 定期擷取不同生成式搜尋引擎的回答與引用。
- **品牌露出分析** — 衡量提及率、回答位置、語氣及競品占有情形。
- **引用來源圖譜** — 追溯被引用網域、頁面與品牌內容的關聯。
- **競品可見度對照** — 比較各主題下品牌與競品的引用及推薦差距。
- **曝光提升計畫** — 依可見度缺口排序內容更新與權威來源拓展建議。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 建立監測問題
2. 採樣生成回答
3. 計算品牌可見度
4. 追溯引用來源
5. 比較競品差距
6. 核准提升計畫
