**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **借款申請** — 建立保單、申請金額、撥款帳戶與聯絡資訊。
- **額度試算** — 依模擬保價金、既有借款及利息計算可借額。
- **權利審查** — 檢查要保人身分、質押、限制及文件有效性。
- **條件確認** — 呈現利率、計息方式及借款對契約的影響。
- **撥款核准** — 依金額與風險等級執行分層簽核。
- **餘額追蹤** — 監控本金、利息及接近保價金的警戒案件。

## 適合誰使用

- 保戶服務專員
- 核保審查員
- 保險財務

## 運作流程

1. 受理借款申請
2. 試算可借額度
3. 審查契約權利
4. 確認借款條件
5. 完成撥款核准
6. 監控借款餘額

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
