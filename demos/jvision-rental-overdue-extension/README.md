# 租賃車逾期續租結算台

> 追蹤租賃車預定歸還、逾期聯絡、續租天數、費率及保險延長，處理跨日跨店還車與授權，確保續租費正確收取且責任期間不中斷。

追蹤租賃車預定歸還、逾期聯絡、續租天數、費率及保險延長，處理跨日跨店還車與授權，確保續租費正確收取且責任期間不中斷。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **到期看板** — 查看將還與已逾期車輛
- **續租確認** — 記錄顧客聯絡與承諾
- **費用試算** — 計算跨日費率與里程
- **保險延長** — 確認保障期間及限制
- **跨店還車** — 協調目的門市與交接
- **收款結清** — 完成授權收費與歸還

## 適合誰使用

- 租車櫃台
- 車隊主管
- 財務人員

## 運作流程

1. 監看到期
2. 聯絡確認
3. 試算費用
4. 延長保障
5. 協調還車
6. 完成結清

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
