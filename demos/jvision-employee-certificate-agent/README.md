# 員工證明文件 Agent

> 自動核對員工資格並完成證明文件產生、簽核與安全交付，減少重複行政。

自動核對員工資格並完成證明文件產生、簽核與安全交付，減少重複行政。

**產業別：**企業協作　|　**系統類型：**hr-hris

## 功能模組

- **證明申請精靈** — 依用途引導選擇在職、薪資、年資等證明。
- **任職資格核對** — 確認雇用狀態、職稱、年資與可揭露欄位。
- **證明文件編製** — 套用核准範本並生成符合用途的文件內容。
- **簽核路徑安排** — 依文件類型、語言與敏感程度指派簽核人。
- **用印與簽署** — 完成電子簽章、公司用印與文件防偽標記。
- **安全交付中心** — 透過下載、加密郵件或指定收件方交付證明。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 提出申請
2. 核對資格
3. 編製文件
4. 完成簽核
5. 簽署用印
6. 安全交付

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
