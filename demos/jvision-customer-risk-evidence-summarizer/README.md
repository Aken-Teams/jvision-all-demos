# 客戶風險證據摘要器

> 把分散的使用、工單與合約訊號整理成可行動的客戶風險故事。​＂管理

把分散的使用、工單與合約訊號整理成可行動的客戶風險故事。​＂管理

**產業別：**客服管理　|　**系統類型：**sales-crm

## 功能模組

- **帳戶風險拼圖** — 聚合單一帳戶的使用、工單、互動與合約訊號。
- **風險事件時間軸** — 依時間排列風險升高前後的關鍵事件。
- **訊號關聯圖** — 連結產品障礙、服務問題、關係變化與商業風險。
- **風險故事草稿** — 生成包含起因、演變、影響與未知項的摘要。
- **行動缺口檢查** — 指出尚缺的訪談、資料與可執行的下一步。
- **CSM 摘要核准** — 協作修訂並核准寫回帳戶計畫的風險故事。

## 適合誰使用

- 客戶成功主管
- CSM
- 客服主管

## 運作流程

1. 選定風險帳戶
2. 檢閱事件脈絡
3. 核對訊號關聯
4. 編修風險故事
5. 補齊行動缺口
6. 核准帳戶摘要

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
