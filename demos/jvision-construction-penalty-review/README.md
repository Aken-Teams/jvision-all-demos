# 工程罰扣認列審議台

> 集中管理業主罰扣通知、契約依據、申訴期限、責任分析與預估損失，及早向責任分包商保留轉扣並完成財務認列或沖回。

集中管理業主罰扣通知、契約依據、申訴期限、責任分析與預估損失，及早向責任分包商保留轉扣並完成財務認列或沖回。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **罰扣案件** — 查看金額期限與狀態
- **契約依據** — 連結條款通知和事證
- **申訴評估** — 分析可抗辯理由與期限
- **責任分攤** — 確認公司及分包責任
- **損失認列** — 估算負債與轉扣金額
- **審議決議** — 簽認申訴和會計處理

## 適合誰使用

- 合約法務
- 專案財務
- 專案經理

## 運作流程

1. 接收通知
2. 查核契約
3. 彙整事證
4. 評估金額
5. 主管審議
6. 追蹤結果

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
