# 到府師傅材料結算台

> 按到府案件管理師傅領料、現場追加、客戶報價、實收、退料與現金繳回，讓內勤逐案核對材料毛利及未授權加價，避免漏計與少繳。

**產業別：**生活服務　|　**系統類型：**service-desk

## 功能模組

- **案件工單** — 查看服務範圍
- **領料交接** — 記錄攜出材料
- **追加報價** — 取得客戶確認
- **現場收款** — 登錄支付方式
- **退料點收** — 核對剩餘材料
- **案件結算** — 分析收入毛利

## 適合誰使用

- 到府師傅
- 服務調度員
- 營運會計

## 運作流程

1. 建立工單
2. 領料出發
3. 申請追加
4. 完工收款
5. 返站退料
6. 覆核結算

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
