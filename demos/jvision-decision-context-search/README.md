## 功能模組

- **決策語意搜尋** — 以問題、專案或結果尋找相關歷史決策。
- **決策時間線** — 還原提案、討論、核准、變更與落地順序。
- **選項比較器** — 並列曾評估方案、取捨條件及淘汰理由。
- **假設追蹤** — 標示決策所依賴假設及其後續驗證狀態。
- **理由與反對意見** — 連結支持證據、異議內容與相關參與者。
- **後果回溯** — 比較預期效益、實際結果與衍生影響。

## 適合誰使用

- 知識工作者
- 主管
- 客服

## 運作流程

1. 提出決策問題
2. 定位歷史脈絡
3. 比較當時選項
4. 驗證關鍵假設
5. 重建完整論證
6. 採用回溯結論
