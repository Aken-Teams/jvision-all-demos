# 連鎖餐飲備料協同台

> 整合各門市銷售預估、中央廚房備料需求、批次分配與缺料替代，協助營運團隊在每日截單前完成彙總、調整及配送確認，降低過量製作、臨時追料與門市缺貨。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **需求預估** — 依門市、品項與營業日彙整建議備料量。
- **門市提報** — 管理各店需求申報、截單狀態與異常增減。
- **原料可用量** — 呈現可用庫存、在途數量與預估缺口。
- **產能配置** — 依產線時段安排批次與製作優先序。
- **缺料替代** — 評估替代品、減配方案及受影響門市。
- **配料確認** — 產生門市分配清單並追蹤配送交接。

## 適合誰使用

- 中央廚房主管
- 門市營運督導
- 採購人員

## 運作流程

1. 建立預估
2. 彙整提報
3. 核對庫存
4. 配置產能
5. 處理缺口
6. 確認配送

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
