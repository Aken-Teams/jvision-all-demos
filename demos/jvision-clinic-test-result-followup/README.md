# 診所檢驗結果追蹤台

> 將檢驗結果依異常程度分流，追蹤醫師覆核、病人通知、複診安排與未聯繫升級，確保重要結果不因紙本報告、跨班交接或聯絡失敗而遺漏。

將檢驗結果依異常程度分流，追蹤醫師覆核、病人通知、複診安排與未聯繫升級，確保重要結果不因紙本報告、跨班交接或聯絡失敗而遺漏。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **結果收件** — 彙整待覆核報告與檢驗完成時間。
- **醫師判讀** — 標記嚴重度、處置建議與時限。
- **病人通知** — 記錄電話、簡訊與通知內容。
- **複診安排** — 預約回診、追加檢查或轉介。
- **失聯升級** — 依風險和聯繫次數啟動升級。
- **閉環確認** — 確認病人已知悉且後續已落實。

## 適合誰使用

- 診所醫師
- 護理師
- 櫃台人員

## 運作流程

1. 接收報告
2. 完成判讀
3. 聯繫病人
4. 安排後續
5. 升級失聯
6. 確認閉環

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
