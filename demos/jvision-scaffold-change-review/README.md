# 施工架變更驗算送審台

> 管理施工架拆拉桿、增設懸臂及壁連座調整等變更，串聯現場申請、結構驗算、圖說審查、施工放行與復原查驗，避免先改後補文件或工班依錯誤版本搭設。

管理施工架拆拉桿、增設懸臂及壁連座調整等變更，串聯現場申請、結構驗算、圖說審查、施工放行與復原查驗，避免先改後補文件或工班依錯誤版本搭設。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **變更申請** — 標示變更位置、原因與預定作業期間。
- **驗算資料** — 彙整荷重、構件及支撐條件供技師驗算。
- **圖說送審** — 管制送審版次、意見與核准文件。
- **搭設派工** — 依核准範圍安排架工施工與交底。
- **完工查驗** — 記錄搭設結果、照片及缺失改善。
- **復原追蹤** — 到期提醒拆除臨設並恢復原架體。

## 適合誰使用

- 工地主任
- 施工架技師
- 職安人員

## 運作流程

1. 提出變更
2. 準備驗算
3. 審定圖說
4. 執行搭設
5. 現場查驗
6. 到期復原

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
