# 客戶預收款履約核銷台

> 協助企業管理儲值、訂金、預付方案及尚未履約的客戶款項，連結履約節點進行收入轉列、退款、長期未動用檢視與期末負債核對。

協助企業管理儲值、訂金、預付方案及尚未履約的客戶款項，連結履約節點進行收入轉列、退款、長期未動用檢視與期末負債核對。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **預收台帳** — 查看來源、餘額與帳齡
- **履約條件** — 設定轉列與退款規則
- **履約核對** — 確認服務或商品已交付
- **收入轉列** — 產生分期或一次轉列批次
- **退款處理** — 管理取消及退款責任
- **期末核對** — 比對明細與總帳餘額

## 適合誰使用

- 應收會計
- 營運財務
- 財務主管

## 運作流程

1. 彙整預收交易
2. 設定履約條件
3. 核對履約證據
4. 執行收入轉列
5. 處理取消退款
6. 完成期末核對

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
