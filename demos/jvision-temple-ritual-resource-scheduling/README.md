# 宮廟科儀資源排程台

> 協助宮廟安排法會、祭典與個別科儀所需的法師、執事、空間、器具及前置物，檢查時段與資源衝突，並將準備清單交接給各服務人員。

協助宮廟安排法會、祭典與個別科儀所需的法師、執事、空間、器具及前置物，檢查時段與資源衝突，並將準備清單交接給各服務人員。

**產業別：**宗教服務　|　**系統類型：**operations-console

## 功能模組

- **科儀日曆** — 查看法會與個別儀式時段。
- **儀式範本** — 維護人員及物品標準需求。
- **執事配置** — 安排法師與服務人員。
- **空間安排** — 配置殿堂及集合區域。
- **器具領用** — 管理法器與用品準備歸還。
- **衝突處理** — 辨識撞期並調整配置方案。

## 適合誰使用

- 宮廟行政
- 科儀執事
- 總務人員

## 運作流程

1. 建立科儀場次
2. 套用儀式範本
3. 配置執事空間
4. 排除資源衝突
5. 完成器具領用
6. 確認儀式收尾

## 導入效益

- 活動籌備工時：20小時 → **5小時**
- 報名掌握率：65% → **94%**
- 物資盤點：6小時 → **1小時**
- 志工調度時效：3天 → **1天**
