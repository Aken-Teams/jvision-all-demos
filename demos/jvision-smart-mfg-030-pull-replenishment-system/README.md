# 拉動式補料系統（Pull Replenishment System）

> 收貨到出貨的倉內作業與庫存精準管理

拉動式補料系統（Pull Replenishment System）提供消耗訊號觸發補料、補料規則動態調整、補料執行追蹤。物流工程依「消耗訊號產生 → 補料規則比對 → 補料任務下達 → 執行補料 → 庫存更新確認」推進作業，優先解決「推式補料造成庫存過剩」，生產則以補料及時率與庫存周轉率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**倉儲物流　|　**系統類型：**WMS 倉儲管理系統

## 功能模組

- **入庫上架** — 收貨、驗收與智慧上架
- **揀貨出貨** — 波次揀貨、覆核與出貨
- **儲位管理** — 儲位規劃與庫容視覺化
- **庫存盤點** — 即時庫存、盤點與調撥
- **拉動補料** — 安全庫存與自動補貨
- **條碼作業** — PDA 掃碼即時作業

## 適合誰使用

- 物流工程
- 生產
- 倉儲

## 運作流程

1. 待盤點
2. 待補貨
3. 移庫中
4. 出庫完成

## 導入效益

- 揀貨作業工時：7.4小時/日 → **1.9小時/日**
- 庫存準確率：86% → **99%**
- 出貨延遲率：9.4% → **1.9%**
- 盤點工時：15小時/月 → **3小時/月**
