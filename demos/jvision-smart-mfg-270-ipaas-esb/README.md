# 系統整合平台（iPaaS/ESB）

> 服務工單、資產到即時監控的 IT 維運

系統整合平台（iPaaS/ESB）提供API/訊息佇列整合管理、資料格式轉換與對應、整合流程視覺化編排。資訊部依「定義介接需求→建立整合流程與對應規則→測試驗證→上線監控→異常重送處理→變更版本管理」推進作業，優先解決「點對點介接難以維護」，系統整合團隊則以介接成功率與平均整合上線時間確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**資訊科技　|　**系統類型：**IT 維運管理平台

## 功能模組

- **服務工單** — 事件/請求工單管理
- **資產管理** — IT 資產與軟體授權
- **即時監控** — 系統/網路健康監控
- **告警事件** — 告警彙整與分派
- **變更發布** — 變更與發布管理
- **服務報表** — SLA 與可用率報表

## 適合誰使用

- 資訊部
- 系統整合團隊
- 各業務系統負責人

## 運作流程

1. 已受理
2. 處理中
3. 使用者確認
4. 已關閉

## 導入效益

- 事件平均處理：120分鐘 → **31分鐘**
- 系統可用率：93% → **97%**
- SLA達成率：90% → **92%**
- 資產盤點工時：20小時/月 → **4.2小時/月**
