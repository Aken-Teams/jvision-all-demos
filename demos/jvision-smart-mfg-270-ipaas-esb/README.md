# 系統整合決策室

作為ERP、MES、WMS、SCADA等系統間資料交換的中介層，統一管理介接、轉換與流程編排。

- 原始系統：系統整合平台（iPaaS/ESB）
- 產業分類：智慧製造｜IT管理
- 使用部門：資訊部、系統整合團隊、各業務系統負責人
- 工作流程：定義介接需求→建立整合流程與對應規則→測試驗證→上線監控→異常重送處理→變更版本管理
- AI 應用：介接異常自動診斷建議、資料對應規則智慧推薦
- 主要 KPI：介接成功率、平均整合上線時間、交易錯誤率、API可用率
- 代表產品：MuleSoft Anypoint Platform、Boomi、TIBCO、Apache Kafka
