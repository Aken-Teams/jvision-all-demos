# 門市零用金憑證稽核台

> 管理各門市零用金請支、發票影像、核准門檻與寄回進度，辨識重複單據、拆單及遲交，讓關帳前完成補件與不合規剔除。

管理各門市零用金請支、發票影像、核准門檻與寄回進度，辨識重複單據、拆單及遲交，讓關帳前完成補件與不合規剔除。

**產業別：**零售電商　|　**系統類型：**finance-case

## 功能模組

- **零用金支出** — 查看門市請支與餘額。
- **憑證收件** — 核對影像及正本狀態。
- **門檻檢查** — 辨識超額與拆單行為。
- **重複偵測** — 比對發票號碼與金額。
- **補件追蹤** — 催收缺漏或遲交單據。
- **稽核結案** — 記錄剔除及改善結果。

## 適合誰使用

- 門市店長
- 費用會計
- 內稽人員

## 運作流程

1. 登錄支出
2. 檢查憑證
3. 套用規則
4. 要求補件
5. 判定核銷
6. 追蹤改善

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
