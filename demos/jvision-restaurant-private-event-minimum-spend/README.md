# 餐飲包場低消結算台

> 整合包場報價、低消折抵、超時、臨時加購與現場簽認，讓門店在結帳前核清所有口頭變更，避免漏收場租及追加服務。

整合包場報價、低消折抵、超時、臨時加購與現場簽認，讓門店在結帳前核清所有口頭變更，避免漏收場租及追加服務。

**產業別：**餐飲旅宿　|　**系統類型：**finance-case

## 功能模組

- **包場條件** — 整理日期、低消與折抵規則。
- **消費累計** — 彙總餐飲及可折抵品項。
- **現場加購** — 記錄設備、酒水與服務追加。
- **超時計價** — 計算超出場地時段費用。
- **客戶簽認** — 確認異動與最終消費。
- **結帳覆核** — 計算低消差額與應收。

## 適合誰使用

- 宴會業務
- 值班經理
- 收銀會計

## 運作流程

1. 建立合約
2. 累計消費
3. 登錄追加
4. 核算超時
5. 完成簽認
6. 結清帳款

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
