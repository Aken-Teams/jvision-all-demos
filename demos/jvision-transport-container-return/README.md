# 運輸空籃回收對帳台

> 按配送趟次記錄周轉空籃交付、客戶返還、司機收回與場站入庫，處理客戶與司機數量爭議，追蹤長期滯留、短少責任及補購需求。

按配送趟次記錄周轉空籃交付、客戶返還、司機收回與場站入庫，處理客戶與司機數量爭議，追蹤長期滯留、短少責任及補購需求。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **容器台帳** — 查看客戶持有量
- **趟次交付** — 記錄隨貨空籃
- **回收簽認** — 確認司機收回
- **回站點收** — 核對場站入庫
- **差異調查** — 判定短少責任
- **滯留催還** — 追蹤逾期容器

## 適合誰使用

- 配送司機
- 容器管理員
- 客戶對帳員

## 運作流程

1. 建立交付
2. 客戶返還
3. 司機收回
4. 回站點收
5. 調查差異
6. 催還結案

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
