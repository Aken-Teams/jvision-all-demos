**產業別：**研發管理　|　**系統類型：**collaboration-pm

## 功能模組

- **需求收納總覽** — 彙整需求來源、版本、狀態與負責團隊。
- **需求結構化** — 拆解目標、角色、情境、限制及驗收條件。
- **規格追溯矩陣** — 建立需求與系統、介面及資料規格的對應。
- **一致性掃描** — 標示遺漏、矛盾、模糊與術語不一致疑點。
- **疑點協作審查** — 集中呈現證據、討論、責任人與澄清結論。
- **規格基線放行** — 確認覆蓋門檻、變更摘要與版本核准狀態。

## 適合誰使用

- 產品經理
- 系統分析師
- 研發主管
- 測試工程師

## 運作流程

1. 彙整需求
2. 拆解條件
3. 連結規格
4. 掃描差異
5. 協作澄清
6. 核定基線
