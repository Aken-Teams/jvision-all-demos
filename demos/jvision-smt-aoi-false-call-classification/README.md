# 表面黏著光學誤判分類系統

> 針對表面黏著自動光學檢查的模擬告警，將誤報依反光、陰影、元件外觀、程式門檻等原因分類，提供複核佇列、規則建議與改善統計，降低檢驗員重複判讀負擔。

針對表面黏著自動光學檢查的模擬告警，將誤報依反光、陰影、元件外觀、程式門檻等原因分類，提供複核佇列、規則建議與改善統計，降低檢驗員重複判讀負擔。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **誤判營運總覽** — 統整告警量、誤報率、待處理數與主要誤判原因。
- **告警分類佇列** — 依信心分數與急迫度排列待判讀的模擬 AOI 告警。
- **影像比對複核** — 並列標準樣本、告警影像及檢測框供人工確認。
- **誤判原因群組** — 以反光、陰影、外觀差異等標籤整理相似案例。
- **檢測規則建議** — 展示門檻調整與檢測區域修正的模擬建議。
- **誤報改善分析** — 比較機種、程式版本與時段的誤報變化。

## 適合誰使用

- AOI 檢驗員
- AOI 程式工程師
- 品質主管

## 運作流程

1. 檢視概況
2. 領取告警
3. 完成判讀
4. 歸類原因
5. 評估建議
6. 確認改善

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
