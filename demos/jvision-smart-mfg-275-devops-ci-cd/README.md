# DevOps/CI-CD洞察站

支援內部系統(如MES客製模組、報表、AOI演算法)開發團隊的版本控管、自動化建置測試與部署。

- 原始系統：DevOps/CI-CD 平台
- 產業分類：智慧製造｜IT管理
- 使用部門：資訊部應用開發團隊、資訊安全部、QA測試團隊
- 工作流程：開發提交程式碼→自動建置測試→程式碼安全掃描→部署至測試環境驗證→審核通過後正式上線→異常自動回滾
- AI 應用：程式碼缺陷自動偵測建議、部署風險評估與異常預警
- 主要 KPI：部署頻率、變更失敗率、平均修復時間、建置成功率
- 代表產品：GitLab CI/CD、Jenkins、GitHub Actions、Azure DevOps
