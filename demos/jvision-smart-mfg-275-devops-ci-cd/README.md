# DevOps/CI-CD 平台

> 服務工單、資產到即時監控的 IT 維運

DevOps/CI-CD 平台提供原始碼版本控管、自動化建置與單元測試、持續整合/持續部署(CI/CD)管線。資訊部應用開發團隊依「開發提交程式碼→自動建置測試→程式碼安全掃描→部署至測試環境驗證→審核通過後正式上線→異常自動回滾」推進作業，優先解決「人工部署錯誤頻繁」，資訊安全部則以部署頻率與變更失敗率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**資訊科技　|　**系統類型：**IT 維運管理平台

## 功能模組

- **服務工單** — 事件/請求工單管理
- **資產管理** — IT 資產與軟體授權
- **即時監控** — 系統/網路健康監控
- **告警事件** — 告警彙整與分派
- **變更發布** — 變更與發布管理
- **服務報表** — SLA 與可用率報表

## 適合誰使用

- 資訊部應用開發團隊
- 資訊安全部
- QA測試團隊

## 運作流程

1. 已受理
2. 處理中
3. 使用者確認
4. 已關閉

## 導入效益

- 事件平均處理：127分鐘 → **29分鐘**
- 系統可用率：95% → **99%**
- SLA達成率：88% → **92%**
- 資產盤點工時：19小時/月 → **4小時/月**
