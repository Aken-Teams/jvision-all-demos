# BI（Business Intelligence Dashboard）

> 把分散數據變成可下鑽、可決策的經營洞察

BI（Business Intelligence Dashboard）提供跨系統資料整合（ERP/MES/CRM/財務）、自訂儀表板與角色權限視覺化、多維度鑽取（廠區/產品線/客戶）。總經理室依「資料源接取 → ETL整合 → 建立資料模型 → 儀表板呈現 → 異常示警 → 決策會議引用」推進作業，優先解決「各部門報表分散、格式不一致」，財務部則以報表更新即時率與儀表板使用率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**經營管理　|　**系統類型：**BI 商業智慧

## 功能模組

- **經營儀表板** — 關鍵指標即時總覽
- **趨勢分析** — 多維度趨勢與比較
- **指標下鑽** — 逐層鑽取到明細
- **平衡計分卡** — 策略目標與 KPI 對齊
- **AI 洞察** — 自動發現異常與機會
- **報表匯出** — 排程報表與分享

## 適合誰使用

- 總經理室
- 財務部
- 業務部
