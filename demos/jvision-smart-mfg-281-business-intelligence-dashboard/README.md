# BI指揮台

整合跨部門資料源，提供高階主管即時經營儀表板與多維度鑽取分析。

- 原始系統：BI（Business Intelligence Dashboard）
- 產業分類：智慧製造｜經營管理
- 使用部門：總經理室、財務部、業務部、生產部、經營企劃部
- 工作流程：資料源接取 → ETL整合 → 建立資料模型 → 儀表板呈現 → 異常示警 → 決策會議引用
- AI 應用：自然語言問答查詢報表、異常趨勢自動偵測與根因提示
- 主要 KPI：報表更新即時率、儀表板使用率、決策回應時間、異常示警準確率
- 代表產品：Microsoft Power BI、Tableau、Qlik Sense、SAP Analytics Cloud
