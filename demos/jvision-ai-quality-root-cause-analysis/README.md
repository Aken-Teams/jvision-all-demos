# 智慧品質異常根因分析系統

> 整合檢驗結果、製程條件、缺陷分布與異常處置紀錄，以人工智慧協助歸納問題模式、排序可能根因並提出驗證方向，讓品保與製造團隊更快完成圍堵、改善及成效追蹤，縮短品質異常處理時間。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **品質戰情總覽** — 呈現良率、不良率、重大異常、待辦案件與產品線品質趨勢。
- **檢驗數據中心** — 依產品、批次、站點及檢驗項目查閱量測結果與超規明細。
- **缺陷模式分析** — 以柏拉圖、熱區圖及趨勢圖辨識主要缺陷類型與集中區域。
- **根因關聯分析** — 展示人員、機台、材料、方法及環境因素與異常的關聯程度。
- **異常處置中心** — 建立品質事件，管理隔離批次、影響範圍、責任部門與處置狀態。
- **改善成效驗證** — 追蹤矯正預防措施、驗證數據、改善前後差異及結案審核。

## 適合誰使用

- 品保主管
- 品質工程師
- 製程工程師
- 產線主管

## 運作流程

1. 監看品質風險
2. 確認超規批次
3. 辨識缺陷模式
4. 研判可能根因
5. 執行圍堵改善
6. 驗證改善結案

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
