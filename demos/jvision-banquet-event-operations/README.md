# 宴會場次營運協調台

> 供宴會廳統籌婚宴、尾牙與會議餐敘，集中管理場次需求、桌型配置、菜單版本、跨部門任務、臨場異動及結案檢討，降低口頭交接造成的漏項與出餐錯誤。

**產業別：**餐飲旅宿　|　**系統類型：**pos-frontdesk

## 功能模組

- **場次總覽** — 依日期與宴會廳查看所有活動及準備狀態。
- **桌型席次** — 配置桌型、席數、主桌與特殊座位需求。
- **菜單版本** — 管理菜色、素食、過敏與出餐順序版本。
- **部門任務** — 拆分外場、廚房、工程及清潔待辦。
- **臨場事件** — 登錄延席、加桌、設備與服務異常。
- **場次復盤** — 彙整成本、客訴、異動及執行落差。

## 適合誰使用

- 宴會業務
- 宴會經理
- 廚房主管

## 運作流程

1. 檢視場次
2. 確認桌席
3. 核定菜單
4. 派發任務
5. 處理現場
6. 完成復盤

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
