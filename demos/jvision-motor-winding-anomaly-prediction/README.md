# 馬達繞組異常預測系統

> 運用擬真的三相電流、溫度、絕緣與負載歷史資料，預測馬達繞組過熱、相位不平衡及絕緣劣化風險，協助設備人員排定檢測優先序、模擬維修方案並追蹤改善。

運用擬真的三相電流、溫度、絕緣與負載歷史資料，預測馬達繞組過熱、相位不平衡及絕緣劣化風險，協助設備人員排定檢測優先序、模擬維修方案並追蹤改善。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **繞組風險總覽** — 顯示高風險馬達、預估異常時間與主要電氣風險分布。
- **三相數據分析** — 比較三相電流、電壓、溫度及不平衡程度的擬真資料。
- **絕緣劣化趨勢** — 呈現絕緣指標、溫升與負載變化的長期關聯。
- **異常原因研判** — 列出過熱、缺相、不平衡與絕緣劣化的模擬風險依據。
- **檢修方案模擬** — 比較降載、清潔、烘乾或重繞等方案的預估改善幅度。
- **預防工單追蹤** — 建立電氣檢測與預防維修工單，追蹤負責人和完成狀態。

## 適合誰使用

- 電機工程師
- 設備工程師
- 維修主管

## 運作流程

1. 盤點繞組風險
2. 檢查三相數據
3. 追蹤絕緣劣化
4. 研判異常原因
5. 模擬檢修方案
6. 安排預防工作

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
