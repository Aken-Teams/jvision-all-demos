# 供應商協同管理平台（Supplier Collaboration Portal）

> 供應商協同、詢比議價到交期風險控管

供應商協同管理平台（Supplier Collaboration Portal）提供訂單/交期線上確認、VMI供應商管理庫存、品質異常協同處理。採購依「需求發布 → 供應商確認交期 → 出貨/到貨追蹤 → 品質協同處理 → 績效評估」推進作業，優先解決「交期資訊傳遞延遲」，生管則以交期達成率與供應商品質合格率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**採購供應鏈　|　**系統類型：**SRM 採購供應商管理

## 功能模組

- **供應商管理** — 建檔、分級與績效評分
- **詢報價協作** — 線上詢價、比價與議價
- **採購訂單** — 請購、下單與交期追蹤
- **交期風險** — 缺料預警與到貨監控
- **供應商品質** — 進料檢驗與 SCAR 改善
- **綠色採購** — ESG 評分與永續採購

## 適合誰使用

- 採購
- 生管
- 品保

## 運作流程

1. 待詢價
2. 比價中
3. 待核准
4. 驗收完成

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：87% → **99%**
- 缺料預警覆蓋：38% → **86%**
- 議價作業工時：8小時/週 → **2小時/週**
