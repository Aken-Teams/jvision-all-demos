# 施工電梯叫料排程台

> 依施工電梯載重、樓層與尖離峰時段受理各分包叫料，核對材料到場、接料人與搬運條件，透過候補及爽約釋位降低排隊堵塞、空趟與工班待工。

依施工電梯載重、樓層與尖離峰時段受理各分包叫料，核對材料到場、接料人與搬運條件，透過候補及爽約釋位降低排隊堵塞、空趟與工班待工。

**產業別：**營建工程　|　**系統類型：**logistics-fleet

## 功能模組

- **運能班表** — 呈現各施工電梯的載重、樓層與可用時段。
- **叫料申請** — 填報材料、尺寸、重量、樓層與接料人。
- **條件檢核** — 檢查載重、尺寸、禁運時段及搬運需求。
- **時段調度** — 排序核准、候補與緊急插單。
- **現場報到** — 確認材料及人員到齊後啟動運送。
- **爽約處理** — 釋放逾時時段並通知候補工班遞補。

## 適合誰使用

- 物流調度員
- 分包領班
- 電梯操作員

## 運作流程

1. 公布電梯運能
2. 提交叫料需求
3. 檢查搬運條件
4. 核定運送時段
5. 現場到料報到
6. 完成運送結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
