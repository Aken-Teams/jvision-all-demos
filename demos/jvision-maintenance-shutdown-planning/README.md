# 歲修停機協調管理台

> 協助工廠規劃年度歲修的停機範圍、工作包、承攬人力、隔離條件、物料與復機驗收，以虛擬甘特圖呈現跨單位衝突，降低延後開機及遺漏作業風險。

協助工廠規劃年度歲修的停機範圍、工作包、承攬人力、隔離條件、物料與復機驗收，以虛擬甘特圖呈現跨單位衝突，降低延後開機及遺漏作業風險。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **停機範圍** — 設定設備邊界與歲修窗口
- **工作包排程** — 安排工序、工期與相依關係
- **人力協調** — 檢查班組與承攬資源衝突
- **物料就緒** — 確認備品、工具與待料風險
- **隔離確認** — 模擬能源隔離與作業許可
- **復機驗收** — 管理測試、缺失與開機核准

## 適合誰使用

- 維修主管
- 歲修計畫員
- 工安人員

## 運作流程

1. 界定停機範圍
2. 編排歲修工作包
3. 平衡人力物料
4. 確認安全隔離
5. 追蹤歲修執行
6. 完成復機驗收

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
