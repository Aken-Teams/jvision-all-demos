# 貨損短少求償管理台

> 從簽收異常建立貨損、短少與遺失案件，彙整照片、託運資料、責任區段及貨值證明，管理承運商協商、賠付核准與客戶回覆。

**產業別：**物流運輸　|　**系統類型：**finance-case

## 功能模組

- **異常收件** — 建立貨損、短少與遺失案件。
- **貨件還原** — 檢視託運、轉運及簽收節點。
- **證據清單** — 管理照片、單據與貨值證明。
- **責任判定** — 標示異常發生區段及責任方。
- **求償協商** — 試算金額並記錄協商往來。
- **賠付結案** — 覆核入款及客戶補償結果。

## 適合誰使用

- 物流客服
- 理賠專員
- 運輸主管

## 運作流程

1. 受理貨件異常
2. 還原運輸軌跡
3. 補齊求償證據
4. 判定責任區段
5. 提出賠付方案
6. 確認賠付結案

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
