# 印章用印風險判讀器

> 依文件內容、金額、交易對象與授權範圍評估用印風險。面向總務主管與行政團隊，把高頻工作集中在可執行工作台中。

依文件內容、金額、交易對象與授權範圍評估用印風險。面向總務主管與行政團隊，把高頻工作集中在可執行工作台中。

**產業別：**企業協作　|　**系統類型：**legal-case

## 功能模組

- **用印文件解析** — 辨識文件類型、關鍵條款、日期、責任與簽署主體。
- **金額曝險評估** — 彙總交易金額、付款條件、賠償上限與潛在承諾。
- **交易對象檢視** — 核對相對人身分、關係企業、黑名單與歷史往來風險。
- **授權層級核對** — 依印章種類、金額與文件性質確認申請人授權。
- **用印風險分級** — 產生風險分數、信心區間與可追溯的判讀理由。
- **高風險複核台** — 集中呈現高風險案件，供主管補件、退回或核准用印。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 提交用印案件
2. 解析關鍵內容
3. 核對交易對象
4. 驗證授權範圍
5. 執行風險複核
6. 核准用印
