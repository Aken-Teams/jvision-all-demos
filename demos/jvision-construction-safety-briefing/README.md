# 工地危害告知管理台

> 管理承攬商與工班每日進場前的危害告知、作業區域、應備防護及簽認狀態，協助工地主任快速辨識未完成教育或條件不符的人員。

管理承攬商與工班每日進場前的危害告知、作業區域、應備防護及簽認狀態，協助工地主任快速辨識未完成教育或條件不符的人員。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **今日工班** — 檢視進場工班、人數及作業區域。
- **危害清單** — 建立工項對應風險與防護要求。
- **資格核對** — 確認人員教育與證照狀態。
- **班前簽認** — 記錄告知內容與人員確認結果。
- **異常管制** — 追蹤缺件、資格不符及禁止進場。
- **職安統計** — 分析承攬商完成率與常見缺失。

## 適合誰使用

- 工地主任
- 職安人員
- 承攬商領班

## 運作流程

1. 申報工項
2. 設定危害
3. 檢查資格
4. 執行告知
5. 完成簽認
6. 追蹤異常

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
