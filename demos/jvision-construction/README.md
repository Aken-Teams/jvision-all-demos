# 營建專案管理

> 進度、日報、品安到估價成本的工程管理

Jvision 建築工程專案、工地日報、品質安衛、材料成本與審批流程一站式 demo。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**營建工程　|　**系統類型：**營建工程管理

## 功能模組

- **工程進度** — WBS 排程與進度追蹤
- **工地日報** — 日報、人機料回報
- **品質安衛** — 巡檢與缺失改善
- **估價發包** — 估價、發包與計價
- **成本控管** — 預算、實支與請款
- **現場紀錄** — 照片與文件留存

## 適合誰使用

- 工務工程師
- 專案經理
- 工程處長

## 運作流程

1. 建立營建專案管理資料
2. Jvision 建築工程專案、工地日報、品質安衛、材料成本與審批流程一站式 demo
3. 確認結果並完成留存

## 導入效益

- 日報彙整工時：3.1小時/日 → **0.5小時/日**
- 進度落後預警：42% → **94%**
- 估驗計價天數：9.6天 → **3.8天**
- 缺失改善時效：7天 → **2天**
