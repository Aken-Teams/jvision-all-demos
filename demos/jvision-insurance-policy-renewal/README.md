# 企業保單續保管理台

> 協助保經與企業風險單位盤點財產、責任及團體保險的到期保單，整理曝險變動、詢價條件、報價比較與續保決策，避免保障中斷或重複投保。

協助保經與企業風險單位盤點財產、責任及團體保險的到期保單，整理曝險變動、詢價條件、報價比較與續保決策，避免保障中斷或重複投保。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **保單台帳** — 查看保障、保額與到期資訊
- **曝險盤點** — 更新資產、人數及營運變化
- **詢價管理** — 建立承保條件與詢價進度
- **報價比較** — 對照保費、限額與除外條款
- **方案決策** — 送審續保組合及差異理由
- **續保確認** — 核對承保文件與保障銜接

## 適合誰使用

- 保險經紀人
- 企業風險專員
- 財務主管

## 運作流程

1. 盤點到期保單
2. 更新企業曝險
3. 發出市場詢價
4. 比較承保報價
5. 核定續保方案
6. 確認保障生效

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
