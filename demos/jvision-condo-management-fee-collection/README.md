# 社區管理費催收台

> 管理社區各戶管理費計算、繳款入帳、欠費分級與催收紀錄，讓物業公司及管委會掌握帳齡、承諾付款與法律移送進度。

管理社區各戶管理費計算、繳款入帳、欠費分級與催收紀錄，讓物業公司及管委會掌握帳齡、承諾付款與法律移送進度。

**產業別：**房地產與物業　|　**系統類型：**finance-case

## 功能模組

- **社區總覽** — 查看棟別收繳與欠費狀況
- **費用計算** — 產生各戶應繳費用
- **繳款核對** — 認列轉帳與臨櫃收款
- **欠費帳齡** — 依逾期期間分類案件
- **催收作業** — 記錄通知及付款承諾
- **移送管理** — 管理存證及法律程序

## 適合誰使用

- 社區總幹事
- 物業財務
- 管委會財委

## 運作流程

1. 產生帳單
2. 核對收款
3. 篩選欠費
4. 執行催收
5. 追蹤承諾
6. 核准移送

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
