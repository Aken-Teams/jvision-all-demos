**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **作業聯繫板** — 以工區與時段呈現各類高風險作業。
- **作業申請** — 登錄範圍、人員、設備、危害與預定時間。
- **衝突辨識** — 找出上下層、動線、火源及能源隔離衝突。
- **聯合會勘** — 記錄相關工班協調結果與現場條件。
- **開工放行** — 檢查管制措施、證照及監視人員後放行。
- **完工解除** — 確認復原、清場、火源監視及區域交還。

## 適合誰使用

- 職安人員
- 工地主任
- 分包領班

## 運作流程

1. 檢視聯繫板
2. 提出申請
3. 辨識衝突
4. 聯合會勘
5. 核准開工
6. 解除管制

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
