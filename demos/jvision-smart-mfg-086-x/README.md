# AXI（自動X光檢測管理）

> 從異常到改善的品質閉環與追溯稽核

AXI（自動X光檢測管理）提供X光檢測程式管理、缺陷影像判讀、機台校驗追蹤。品保部依「焊點X光掃描→影像判讀→缺陷分類→異常通報→處置追蹤」推進作業，優先解決「隱藏焊點缺陷難目視發現」，製程工程部則以焊點缺陷檢出率與誤判率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 品保部
- 製程工程部
- 設備工程部

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉

## 導入效益

- 批號追溯時間：191分鐘 → **14分鐘**
- 客訴平均關案：21天 → **9.2天**
- 改善驗證率：67% → **92%**
- 重複不良率：5.8% → **2%**
