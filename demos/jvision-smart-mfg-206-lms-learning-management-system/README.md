# 教育訓練管理系統（LMS, Learning Management System）

> 應收付、現金流到預算的財務即時掌握

教育訓練管理系統（LMS, Learning Management System）提供課程規劃與線上教材管理、新人訓練/OJT進度追蹤、產線技能認證與考核。人資訓練組依「訓練需求規劃 → 課程排定 → 員工報名/指派 → 上課簽到 → 測驗考核 → 證書/紀錄歸檔」推進作業，優先解決「大量新進員工訓練進度難掌握」，產線班組長則以訓練完成率與技能認證通過率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**教育　|　**系統類型：**財務會計系統

## 功能模組

- **應收帳款** — 開立、對帳與催收
- **應付帳款** — 請款、付款與對帳
- **現金流** — 資金調度與預測
- **預算管理** — 編列、控管與差異分析
- **固定資產** — 資產登錄與折舊
- **總帳傳票** — 傳票、拋轉與月結

## 適合誰使用

- 人資訓練組
- 產線班組長
- 職安衛部門

## 運作流程

1. 待安排
2. 進行中
3. 待確認
4. 已完成

## 導入效益

- 排課作業工時：5.8小時/週 → **1.6小時/週**
- 作業批改時效：5.2天 → **1天**
- 出席掌握率：69% → **89%**
- 學習進度可視：48% → **92%**
