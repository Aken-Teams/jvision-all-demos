# 教育訓練管理決策室

規劃並追蹤新人訓練、產線技能訓練、法規訓練與線上課程，建立員工能力發展紀錄。

- 原始系統：教育訓練管理系統（LMS, Learning Management System）
- 產業分類：智慧製造｜人資管理
- 使用部門：人資訓練組、產線班組長、職安衛部門、品保部
- 工作流程：訓練需求規劃 → 課程排定 → 員工報名/指派 → 上課簽到 → 測驗考核 → 證書/紀錄歸檔
- AI 應用：AI課程推薦與個人化學習路徑、技能落差自動分析
- 主要 KPI：訓練完成率、技能認證通過率、法規逾期率、訓練投資報酬
- 代表產品：雲學堂 LMS、TibaMe企業版、Moodle、SAP SuccessFactors Learning
