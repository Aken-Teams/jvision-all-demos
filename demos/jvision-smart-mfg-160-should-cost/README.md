# Should-cost 成本分析系統

> 供應商協同、詢比議價到交期風險控管

Should-cost 成本分析系統提供成本結構模型建置、材料/工時/製程成本拆解、報價合理性比對分析。採購部依「建立成本模型 → 輸入製程參數 → 系統推算合理成本 → 對比供應商報價 → 議價談判」推進作業，優先解決「供應商報價黑箱難以驗證」，成本工程部則以成本模型準確度與議價節省金額確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**採購供應鏈　|　**系統類型：**SRM 採購供應商管理

## 功能模組

- **供應商管理** — 建檔、分級與績效評分
- **詢報價協作** — 線上詢價、比價與議價
- **採購訂單** — 請購、下單與交期追蹤
- **交期風險** — 缺料預警與到貨監控
- **供應商品質** — 進料檢驗與 SCAR 改善
- **綠色採購** — ESG 評分與永續採購

## 適合誰使用

- 採購部
- 成本工程部
- 研發部

## 運作流程

1. 待詢價
2. 比價中
3. 待核准
4. 驗收完成

## 導入效益

- 採購前置時間：11天 → **4.7天**
- 準時到貨率：77% → **90%**
- 缺料預警覆蓋：38% → **86%**
- 議價作業工時：7.5小時/週 → **1.9小時/週**
