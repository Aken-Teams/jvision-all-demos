# 貨損遺失異常交接偵測台

> 串接預先建立的託運單、照片、數量、封條與交接紀錄，在純介面中模擬辨識貨損、短少、遺失及責任斷點，協助物流團隊快速建立事件、釐清證據並追蹤改善。

**產業別：**物流運輸　|　**系統類型：**operations-console

## 功能模組

- **異常事件總覽** — 集中呈現貨損、短少、遺失及高風險交接。
- **貨物交接鏈** — 以時間軸還原各節點的交付與簽收狀態。
- **影像證據檢視** — 並排查看預載貨況照片、標記與單據。
- **異常偵測分析** — 比對數量、重量、封條與交接差異。
- **責任節點判定** — 呈現可能責任環節及支持證據。
- **理賠改善追蹤** — 建立模擬理賠案件與防止再發任務。

## 適合誰使用

- 物流客服
- 理賠人員
- 倉儲主管
- 承運管理員

## 運作流程

1. 受理異常事件
2. 還原交接流程
3. 蒐整影像證據
4. 分析異常差異
5. 判定責任節點
6. 追蹤理賠改善
