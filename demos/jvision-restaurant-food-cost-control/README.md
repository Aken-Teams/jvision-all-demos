# 餐飲食材成本管制台

> 整合菜單配方、食材採購價、理論用量與盤點差異，協助連鎖餐飲找出毛利下滑來源，模擬調價、換料及份量調整後的成本影響。

整合菜單配方、食材採購價、理論用量與盤點差異，協助連鎖餐飲找出毛利下滑來源，模擬調價、換料及份量調整後的成本影響。

**產業別：**餐飲旅宿　|　**系統類型：**erp

## 功能模組

- **成本總覽** — 查看各店成本率、毛利與異常排行。
- **配方成本** — 維護菜品配方、份量及替代食材。
- **採購價格** — 比較供應商報價與食材價格波動。
- **耗損差異** — 對照理論用量、實際領料及盤點結果。
- **情境試算** — 模擬調價、換料與份量變動。
- **版本發布** — 審核並發布生效中的成本版本。

## 適合誰使用

- 餐飲營運主管
- 中央廚房管理員
- 財務人員

## 運作流程

1. 辨識成本異常
2. 檢查配方用量
3. 核對價格波動
4. 分析耗損來源
5. 模擬改善方案
6. 核准成本版本

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
