# 設備預兆管家

> 保養、維修、預兆到備品的設備全生命週期

整合設備履歷、巡檢與保養紀錄，提前提示維修風險。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**設備維護　|　**系統類型：**CMMS 設備維護

## 功能模組

- **保養排程** — 預防保養自動排程
- **維修工單** — 報修、派工與完工
- **預兆診斷** — 設備數據異常預警
- **備品管理** — 備品庫存與領用
- **OEE 稼動** — 稼動與故障分析
- **履歷追溯** — 設備維護履歷

## 適合誰使用

- 設備工程師
- 維修課長
- 廠長

## 運作流程

1. 待派工
2. 維修中
3. 試車確認
4. 復機完成

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：80% → **99%**
- 備品缺料：9.6次/月 → **1.9次/月**
- 故障排除時間：90分鐘 → **25分鐘**
