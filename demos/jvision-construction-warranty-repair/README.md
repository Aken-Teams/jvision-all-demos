# 建案保固修繕管制台

> 協助建商在交屋後受理住戶保固報修，判定責任工種、安排承包商進場、記錄修繕前後證據及追蹤住戶驗收，並彙整重複缺失與廠商履約表現。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **報修受理** — 登錄戶別、缺失與住戶時段
- **保固判定** — 核對期限、範圍及責任工種
- **廠商派修** — 指派承包商與預定進場日
- **施工證據** — 整理修繕前後照片及說明
- **住戶驗收** — 記錄複驗結果與簽認狀態
- **缺失分析** — 分析重複問題及廠商績效

## 適合誰使用

- 保固客服
- 工務主管
- 承包商窗口

## 運作流程

1. 受理報修
2. 判定責任
3. 安排進場
4. 執行修繕
5. 住戶複驗
6. 回饋分析

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
