# 現場餘料轉用調度台

> 盤點散落各樓層與工區的可用餘料，記錄規格、數量、保管責任及可轉用條件，讓缺料工區先提出調撥需求並完成交接，減少重複採購及結案廢料。

**產業別：**營建工程　|　**系統類型：**warehouse-wms

## 功能模組

- **餘料盤點** — 登錄位置、規格、數量及材料狀態。
- **現況佐證** — 保存包裝、尺寸與堆放位置照片。
- **可用查詢** — 依工項與規格搜尋可轉用餘料。
- **調撥申請** — 提出需求數量、用途及接收工區。
- **移交點收** — 記錄交出與接收雙方確認數量。
- **效益統計** — 換算節省採購與減少報廢金額。

## 適合誰使用

- 材料管理員
- 工務工程師
- 分包領班

## 運作流程

1. 回報施工餘料
2. 確認可用狀態
3. 發布可調庫存
4. 提出轉用申請
5. 完成實物點交
6. 核算轉用效益

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
