# 維修備品送修周轉台

> 管理可修復備品從故障拆下、替換領用、送外維修、報價核准、返廠驗收至重新入庫的完整周轉，協助維護單位掌握可用量、維修成本與長期滯外風險。

管理可修復備品從故障拆下、替換領用、送外維修、報價核准、返廠驗收至重新入庫的完整周轉，協助維護單位掌握可用量、維修成本與長期滯外風險。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **故障拆換** — 記錄設備位置、故障症狀與替換備品。
- **送修批次** — 彙整待修品、廠商及交寄資料。
- **報價審核** — 比較修復方案、費用與新品替代成本。
- **在修追蹤** — 呈現檢測、待料、維修及返運狀態。
- **返廠驗收** — 記錄外觀、功能測試與保固結果。
- **周轉分析** — 分析可用、在修、報廢與滯外備品。

## 適合誰使用

- 維修主管
- 備品管理員
- 採購人員

## 運作流程

1. 登錄故障
2. 建立送修
3. 審核報價
4. 追蹤進度
5. 執行驗收
6. 恢復庫存

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
