# 跨系統交易補償協調器

> 追蹤跨系統多步交易，在部分寫入失敗時協調核准且可驗證的補償作業。

追蹤跨系統多步交易，在部分寫入失敗時協調核准且可驗證的補償作業。

**產業別：**資訊科技　|　**系統類型：**operations-console

## 功能模組

- **交易鏈編排** — 以步驟圖定義 ERP、MES、CRM 等系統的寫入順序與相依條件。
- **失敗斷點監測** — 即時定位逾時、拒絕、重複寫入及部分成功的交易斷點。
- **狀態差異判讀** — 比對各系統最終狀態，辨識不一致實體、影響範圍與風險。
- **補償方案生成** — 依交易語意產生反向操作、替代修正及安全執行順序。
- **高風險補償核准** — 針對退款、庫存回沖等敏感補償建立人工核准決策。
- **一致性驗證** — 重查所有參與系統，驗證補償結果並關閉交易案件。

## 適合誰使用

- 平台架構師
- 整合工程師
- AI 應用開發者

## 運作流程

1. 建立交易鏈
2. 定位失敗斷點
3. 評估不一致
4. 擬定補償計畫
5. 核准敏感操作
6. 執行並結案
