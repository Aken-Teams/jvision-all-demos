# 施工區域斷電掛牌台

> 管理施工臨時斷電、迴路隔離、掛牌人員與復電會簽，讓跨班交接時清楚掌握仍在作業者，並防止掛牌遭誤拆或尚未撤離便提前送電。

管理施工臨時斷電、迴路隔離、掛牌人員與復電會簽，讓跨班交接時清楚掌握仍在作業者，並防止掛牌遭誤拆或尚未撤離便提前送電。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **斷電申請** — 登錄區域、迴路、作業內容與期間。
- **迴路隔離圖** — 顯示電源、盤體、開關及影響設備。
- **掛牌上鎖紀錄** — 記錄鎖具編號、掛牌人與執行時間。
- **作業人員名冊** — 追蹤各工班簽入、換班及撤離狀態。
- **復電前會簽** — 確認人員、工具及臨時接線均已清除。
- **復電結果回報** — 記錄送電時間、測試結果及異常。

## 適合誰使用

- 機電工程師
- 職安人員
- 作業領班

## 運作流程

1. 提出斷電申請
2. 確認影響範圍
3. 執行隔離掛牌
4. 登錄作業人員
5. 完成復電會簽
6. 送電測試結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
