# 工地許可證照期限管制台

> 集中管理建照、道路占用、動火、高架作業與環保申報等工地許可文件，依施工項目檢查適用性、有效期限、展延責任及缺件狀態，避免無證施工與停工損失。

集中管理建照、道路占用、動火、高架作業與環保申報等工地許可文件，依施工項目檢查適用性、有效期限、展延責任及缺件狀態，避免無證施工與停工損失。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **證照台帳** — 登錄許可類型、範圍與有效期間。
- **工項對照** — 連結施工項目與必要許可。
- **期限看板** — 顯示到期、展延與申辦節點。
- **補件任務** — 分派文件缺口與責任人。
- **核准版本** — 保存許可文件及適用條件。
- **施工攔截** — 列出不得開工的風險項目。

## 適合誰使用

- 工地主任
- 工務人員
- 職安人員

## 運作流程

1. 建立清冊
2. 對照工項
3. 準備送件
4. 覆核條件
5. 發布核准
6. 展延關閉

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
