## 功能模組

- **負載情境編排** — 建立流量曲線、請求組合與提示長度分布。
- **併發壓力控制** — 逐級提高虛擬使用者與每秒請求量。
- **限流策略試驗** — 測試配額、排隊、退避與優先級規則。
- **供應商中斷注入** — 模擬逾時、錯誤率升高及模型端點失效。
- **降級切換驗證** — 檢查備援模型、快取回覆與安全回滾。
- **韌性結果分析** — 比較延遲、吞吐、錯誤率、成本與恢復時間。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 建立負載模型
2. 執行併發爬升
3. 施加限流
4. 注入供應商故障
5. 驗證降級復原
6. 核定容量基線
