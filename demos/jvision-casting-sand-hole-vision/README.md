# 鑄件表面砂眼視覺檢測系統

> 以鑄件表面影像呈現砂眼、孔洞與麻點的視覺判讀結果，讓檢驗人員依區域及嚴重度完成複核，並串聯產品面別、模具穴號、批次處置與缺陷圖譜，提升外觀檢驗一致性。

以鑄件表面影像呈現砂眼、孔洞與麻點的視覺判讀結果，讓檢驗人員依區域及嚴重度完成複核，並串聯產品面別、模具穴號、批次處置與缺陷圖譜，提升外觀檢驗一致性。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **外觀檢驗總覽** — 呈現班次檢測進度、砂眼分級、異常穴號與複檢待辦。
- **表面影像檢測** — 放大鑄件各面影像，查看砂眼框選、直徑及嚴重程度。
- **產品面別檢視** — 依正面、背面與側面切換缺陷位置，掌握外觀分布。
- **檢驗標準管理** — 展示不同料號與區域的允收門檻、缺陷級距及判定範例。
- **砂眼缺陷圖譜** — 依形態、尺寸與成因整理代表案例，供檢驗人員比對。
- **模具趨勢分析** — 比較模具、穴號、班次及批次的砂眼發生率與變化。

## 適合誰使用

- 外觀檢驗員
- 品質工程師
- 鑄造製程主管

## 運作流程

1. 確認檢驗進度
2. 判讀表面砂眼
3. 核對產品面別
4. 套用允收標準
5. 查閱缺陷案例
6. 追蹤模具趨勢

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
