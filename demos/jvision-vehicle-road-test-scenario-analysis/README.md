# 車輛路試情境異常分析台

> 將擬真道路測試任務、路線情境、駕駛標記與車輛訊號整理為可回放的分析介面，協助測試團隊比對不同車型及版本表現、定位異常發生條件，並將問題轉成可重現的驗證案例。

將擬真道路測試任務、路線情境、駕駛標記與車輛訊號整理為可回放的分析介面，協助測試團隊比對不同車型及版本表現、定位異常發生條件，並將問題轉成可重現的驗證案例。

**產業別：**研發管理　|　**系統類型：**analytics-bi

## 功能模組

- **測試任務** — 管理車輛、版本、路線、測試目標與任務完成狀態。
- **情境地圖** — 以地圖呈現坡道、彎道、壅塞、坑洞及天候等測試情境。
- **行程回放** — 同步展示路線位置、事件時間軸、駕駛標記與車輛狀態。
- **訊號分析** — 疊合速度、轉速、溫度、煞車等擬真曲線並圈選異常區段。
- **版本比較** — 比較不同車型、零件或軟體版本在相同情境下的表現。
- **異常案例** — 將片段整理為含情境、證據、嚴重度及重現步驟的問題案例。

## 適合誰使用

- 整車測試工程師
- 系統驗證工程師與研發專案主管

## 運作流程

1. 建立路試任務
2. 確認情境覆蓋
3. 回放異常行程
4. 分析訊號關聯
5. 比較版本差異
6. 建立重現案例
