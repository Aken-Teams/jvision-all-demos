# 施工界面衝突協調台

> 集中管理土建、機電與裝修之間的施工界面衝突，將圖面位置、現場條件、責任分工、解法決議與完成證據串成單一案件，避免同一衝突在會議、群組與不同版本圖說中反覆討論。

集中管理土建、機電與裝修之間的施工界面衝突，將圖面位置、現場條件、責任分工、解法決議與完成證據串成單一案件，避免同一衝突在會議、群組與不同版本圖說中反覆討論。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **衝突總覽** — 依棟別、樓層、專業與急迫度呈現待協調案件。
- **衝突提報** — 在圖面位置建立衝突並附上照片與影響工序。
- **界面拆解** — 列出牽涉工種、施工順序與各方責任邊界。
- **協調決議** — 記錄方案比較、會議結論及應辦單位與期限。
- **改善驗證** — 核對圖說修改、現場處置及前後照片證據。
- **界面分析** — 分析高頻衝突區域、責任工種及延誤影響。

## 適合誰使用

- 界面工程師
- 工地主任
- 專業分包主管

## 運作流程

1. 盤點衝突
2. 定位提報
3. 拆解責任
4. 協調定案
5. 執行驗證
6. 結案復盤

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
