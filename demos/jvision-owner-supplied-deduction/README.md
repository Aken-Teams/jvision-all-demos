# 代工代料扣款核算台

> 記錄總包代分包提供的人力、材料、機具與臨時支援，於發生當下取得數量、單價、照片及現場簽認，月底按合約扣款規則彙整，處理異議後形成計價扣款明細。

記錄總包代分包提供的人力、材料、機具與臨時支援，於發生當下取得數量、單價、照片及現場簽認，月底按合約扣款規則彙整，處理異議後形成計價扣款明細。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **扣款總覽** — 呈現各分包本期事件、金額與簽認狀態。
- **現場建單** — 登錄支援內容、日期、區域、數量與照片。
- **即時簽認** — 記錄分包現場代表的確認或拒簽理由。
- **單價核算** — 依合約、議定價或成本加成計算扣款。
- **異議處理** — 逐項比較雙方主張並保存協調決議。
- **扣款結算** — 產出本期可帶入估驗的扣款明細。

## 適合誰使用

- 工務工程師
- 成本工程師
- 分包計價人員

## 運作流程

1. 查看待辦
2. 建立事件
3. 取得簽認
4. 計算金額
5. 協調異議
6. 帶入計價

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
