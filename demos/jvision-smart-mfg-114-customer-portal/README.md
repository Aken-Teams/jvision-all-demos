# Customer Portal 客戶入口網站

提供客戶自助查詢訂單、出貨、文件與報價狀態的線上入口，減少業務往返溝通。

- 原始系統：Customer Portal 客戶入口網站
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、客服部、資訊部、品保部、物流部
- 工作流程：客戶登入入口網站→查詢訂單/文件→提交需求或問題→系統通知內部處理→結果回饋客戶
- AI 應用：智慧客服機器人回覆常見問題、異常訂單自動主動通知
- 主要 KPI：客戶自助使用率、客服來電下降率、文件下載時效、客戶滿意度
- 代表產品：SAP Customer Portal、Salesforce Experience Cloud、客製化Web Portal（多見於PCB/SMT大廠自建）
