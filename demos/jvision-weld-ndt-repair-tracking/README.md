**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **焊口圖冊** — 依區域與構件建立焊口位置及唯一編號。
- **施焊紀錄** — 登錄焊工、工法、日期、材料與外觀檢查。
- **抽驗排程** — 依規範比例、風險與批次選取檢測焊口。
- **檢測委託** — 管理方法、檢測公司、排程及現場準備。
- **報告判讀** — 對回焊口並記錄缺陷種類、位置與結果。
- **返修複驗** — 追蹤挖除、重焊、再次檢測與最終放行。

## 適合誰使用

- 品管工程師
- 檢測公司承辦
- 焊接領班

## 運作流程

1. 建立焊口
2. 登錄施焊
3. 選取抽驗
4. 執行檢測
5. 判定返修
6. 複驗放行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
