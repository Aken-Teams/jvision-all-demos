# 焊接氣孔缺陷檢測系統

> 集中呈現焊接影像或檢測圖中的氣孔位置、直徑、密度與群聚情形，支援分區判定、人工複核、批次追溯及成因分析，協助品管人員快速識別超標工件並管理隔離與重檢。

集中呈現焊接影像或檢測圖中的氣孔位置、直徑、密度與群聚情形，支援分區判定、人工複核、批次追溯及成因分析，協助品管人員快速識別超標工件並管理隔離與重檢。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **氣孔風險總覽** — 查看各批次氣孔率、群聚警示、超標工件與複核待辦。
- **氣孔影像判讀** — 顯示氣孔位置、直徑、數量、信心分數及群聚範圍。
- **焊區分區評估** — 依起弧區、中段與收弧區統計密度並套用不同允收門檻。
- **人工複核中心** — 逐項確認氣孔標記，排除雜訊並完成工件合格判定。
- **批次成因追溯** — 關聯材料批號、保護氣體、焊材、班次及配方的模擬紀錄。
- **隔離重檢管理** — 管理超標工件隔離、補焊、重檢結果與解除狀態。

## 適合誰使用

- 非破壞檢測人員
- 品質工程師
- 焊接製程主管

## 運作流程

1. 辨識高風險批次
2. 判讀氣孔分布
3. 評估焊區門檻
4. 完成缺陷複核
5. 追查可能成因
6. 執行隔離重檢

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
