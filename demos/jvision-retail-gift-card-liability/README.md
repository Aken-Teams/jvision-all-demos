# 零售禮券負債核銷台

> 統一紙本與電子禮券的發行、贈券、兌換、作廢及負債異動，逐券號勾稽門市交易，攔截重複兌付與遞延收入錯列。

**產業別：**零售電商　|　**系統類型：**finance-ledger

## 功能模組

- **券號台帳** — 查看發行與持有狀態。
- **發售分類** — 區分銷售、贈送與補發。
- **兌換勾稽** — 連結門市消費交易。
- **異常券號** — 攔截重複及失效兌換。
- **負債調節** — 計算發行與核銷餘額。
- **月結覆核** — 保存調整及授權證據。

## 適合誰使用

- 財務會計
- 禮券管理員
- 門市稽核

## 運作流程

1. 彙整發行
2. 分類負債
3. 勾稽兌換
4. 調查異常
5. 調節餘額
6. 核准月結

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
