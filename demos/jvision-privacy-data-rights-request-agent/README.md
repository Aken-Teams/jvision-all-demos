# 個資權利請求處理助手

> 協助企業受理個人資料查詢、閱覽、更正、刪除與停止利用等權利請求，透過身分驗證、資料範圍盤點、跨部門作業及期限控管形成標準流程，並保留回覆與核准紀錄，降低漏答、誤揭露及逾期風險。

協助企業受理個人資料查詢、閱覽、更正、刪除與停止利用等權利請求，透過身分驗證、資料範圍盤點、跨部門作業及期限控管形成標準流程，並保留回覆與核准紀錄，降低漏答、誤揭露及逾期風險。

**產業別：**資訊安全　|　**系統類型：**service-desk

## 功能模組

- **隱私請求收件匣** — 集中呈現請求類型、來源、法定期限與處理狀態。
- **身分驗證工作台** — 以擬真驗證資料確認申請人身分及代理權限。
- **資料範圍盤點** — 依目的、系統與部門標記應搜尋及排除的資料範圍。
- **跨部門處理看板** — 分派資料查找、修正、刪除及停止利用等作業。
- **例外法規判定** — 檢查保留義務、第三人權益與拒絕或限制回覆理由。
- **安全回覆中心** — 預覽揭露內容、遮蔽敏感欄位並完成核准與回覆。

## 適合誰使用

- 隱私專員
- 客服人員
- 企業法務
- 資訊管理員

## 運作流程

1. 受理權利請求
2. 完成身分驗證
3. 界定資料範圍
4. 執行跨部門作業
5. 審核法規例外
6. 核准安全回覆
