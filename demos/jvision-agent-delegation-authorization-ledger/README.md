# Agent 委任授權簿

> 記錄授權人、期間、範圍與 Agent 代表行為，建立可追責的委任鏈。

記錄授權人、期間、範圍與 Agent 代表行為，建立可追責的委任鏈。

**產業別：**資訊科技　|　**系統類型：**legal-case

## 功能模組

- **委任人身分確認** — 驗證授權人身分、職權與代表組織授權的資格。
- **委任條款編製** — 定義 Agent 可代表執行的行為、資源、金額、期間與限制。
- **轉委任關係圖** — 呈現人、Agent、子 Agent 與工具間的授權來源及傳遞關係。
- **代表行為對帳** — 把實際工具呼叫逐筆對應至當時有效的委任條款。
- **越界責任判定** — 識別無授權、逾期、超額及不當轉委任並指定處置責任。
- **委任存證封存** — 核准後封存條款、變更、撤銷與代表行為的可驗證紀錄。

## 運作流程

1. 驗證委任資格
2. 擬定委任條款
3. 檢查轉委任鏈
4. 對帳代表行為
5. 處理授權越界
6. 核准存證封存
