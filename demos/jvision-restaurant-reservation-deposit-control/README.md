# 餐廳訂位訂金管制台

> 協助連鎖餐廳統一管理訂位訂金、付款期限、改期抵用、取消扣款與每日對帳，讓櫃台快速辨識高風險訂位，降低熱門時段臨時未到造成的桌位與營收損失。

協助連鎖餐廳統一管理訂位訂金、付款期限、改期抵用、取消扣款與每日對帳，讓櫃台快速辨識高風險訂位，降低熱門時段臨時未到造成的桌位與營收損失。

**產業別：**餐飲旅宿　|　**系統類型：**pos-frontdesk

## 功能模組

- **訂位總覽** — 依日期、餐期與門店查看訂位及訂金狀態。
- **收款追蹤** — 追蹤付款期限、金額、通路與逾期案件。
- **異動處理** — 辦理改期、取消、訂金移轉及補差額。
- **規則設定** — 設定餐期別的訂金、退款與保留規則。
- **對帳作業** — 彙整平台、刷卡及轉帳紀錄進行核對。
- **未到分析** — 分析未到店、取消與訂金沒收趨勢。

## 適合誰使用

- 訂位專員
- 餐廳店長
- 財務人員

## 運作流程

1. 檢視訂位
2. 追蹤付款
3. 處理異動
4. 套用規則
5. 完成對帳
6. 檢討成效

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
