# 鋼筋料單版次核對台

> 串聯結構圖版次、鋼筋料單、加工批次與工區需求，讓加工前、出貨前及收料時均可核對有效版本；圖說變更時立即圈出受影響料件，避免舊料單持續加工造成退料與重製。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **料單總覽** — 依樓層與構件查看料單版本及使用狀態。
- **版次比對** — 比較新舊料單的尺寸、數量與料號差異。
- **圖料關聯** — 建立結構圖號、修訂版與料單的對應關係。
- **加工回報** — 掌握待加工、加工中與完成的料件數量。
- **出貨核對** — 出車前確認批次採用的有效料單版本。
- **收料處置** — 記錄到場核驗、隔離、退料與改用決定。

## 適合誰使用

- 鋼筋工程師
- 加工廠窗口
- 工地收料員

## 運作流程

1. 建立圖料關聯
2. 發布有效料單
3. 比對改版差異
4. 確認加工影響
5. 執行出貨核對
6. 完成現場收料

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
