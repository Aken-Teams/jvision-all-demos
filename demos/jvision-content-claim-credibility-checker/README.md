# 內容證據可信度檢查器

> 檢查內容中的無來源、過期數據與誇大主張，降低品牌及法遵風險。

檢查內容中的無來源、過期數據與誇大主張，降低品牌及法遵風險。

**產業別：**業務銷售　|　**系統類型：**analytics-bi

## 功能模組

- **主張句擷取** — 從文案、文章與廣告中辨識數字、比較與效果主張。
- **來源引用核驗** — 確認每項主張是否連結可存取且足以支持內容的來源。
- **數據時效檢查** — 判斷統計期間、發布日期與更新頻率是否已失效。
- **誇大語氣檢測** — 標記絕對化、無條件保證與超出證據範圍的說法。
- **跨渠道矛盾比對** — 比對網站、廣告、社群與銷售素材中的主張差異。
- **可信改寫工作台** — 根據可靠來源產生保守改寫與合規引用建議。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 匯入待審內容
2. 擷取關鍵主張
3. 核驗引用來源
4. 檢查時效與誇大
5. 協作修正文案
6. 核准渠道發布
