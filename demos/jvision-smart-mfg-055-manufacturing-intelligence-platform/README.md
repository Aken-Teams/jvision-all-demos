# 製造大數據分析平台（Manufacturing Intelligence Platform）

> 訂單到入庫的製造現場全流程數位化

製造大數據分析平台（Manufacturing Intelligence Platform）提供跨系統數據彙整整合、時序數據歷史查詢、自助式分析儀表板。製造工程依「多源數據擷取 → 資料整合清洗 → 分析模型建立 → 視覺化呈現 → 決策應用回饋」推進作業，優先解決「數據散落多系統難以整合分析」，資訊部門則以數據整合覆蓋率與分析報告產出時效確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生產製造　|　**系統類型：**MES 製造執行系統

## 功能模組

- **工單管理** — 訂單轉工單、拆併單與工單派發
- **排程排產** — 依產能、交期、負載自動排程
- **現場執行** — 派工、報工與進度即時回報
- **設備稼動 OEE** — 稼動、效率、良率即時監控
- **品質入庫** — 檢驗判定、不良處置與入庫
- **AI 改善建議** — 異常摘要與瓶頸改善建議

## 適合誰使用

- 製造工程
- 資訊部門
- 高階管理層

## 運作流程

1. 待排程
2. 生產中
3. 待品檢
4. 已入庫

## 導入效益

- 排程作業工時：7.5小時/日 → **1.4小時/日**
- 準時交付率：75% → **89%**
- 缺料停線次數：11次/月 → **2.8次/月**
- 設備稼動率：70% → **83%**
