# 區域業務配額規劃台

> 依擬真的市場潛力、既有客戶、商機量、產業分布與業務產能，模擬區域邊界及個人配額配置，協助主管比較方案、檢查公平性並完成可追溯的配額發布。

**產業別：**業務銷售　|　**系統類型：**sales-crm

## 功能模組

- **市場潛力地圖** — 用模擬地圖與產業資料呈現區域客群、商機價值及成長潛力。
- **區域設計工作台** — 調整區域歸屬與客戶分派，檢查重疊、空白市場和跨區衝突。
- **配額模擬器** — 依公司目標、潛力與歷史表現產生個人配額並調整權重。
- **負荷公平檢查** — 比較客戶數、商機量、差旅負擔、達成難度與團隊公平性。
- **方案審議中心** — 並列多個規劃版本、主管意見、調整理由與核准狀態。
- **配額發布中心** — 預覽個人配額通知、版本差異、生效日期與確認回覆狀態。

## 適合誰使用

- 業務營運主管
- 區域業務主管
- 財務規劃人員與業務副總

## 運作流程

1. 盤點潛力
2. 設計區域
3. 模擬配額
4. 檢查公平
5. 審議方案
6. 發布配額
