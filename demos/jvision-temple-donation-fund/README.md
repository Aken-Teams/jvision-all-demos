# 宮廟香油金專款管理台

> 協助宮廟區分香油金、建醮、修繕與急難救助等捐款用途，完成收據編號、專款收支、動支審核、芳名揭示偏好及定期徵信報表，提升帳務透明度。

協助宮廟區分香油金、建醮、修繕與急難救助等捐款用途，完成收據編號、專款收支、動支審核、芳名揭示偏好及定期徵信報表，提升帳務透明度。

**產業別：**宗教服務　|　**系統類型：**finance-ledger

## 功能模組

- **捐款登錄** — 記錄信眾、金額與指定用途
- **收據管理** — 控管編號、補發及作廢紀錄
- **專款帳冊** — 分列各募款專案收支餘額
- **動支審核** — 檢核用途、憑證與核准層級
- **芳名徵信** — 管理公開、匿名及稱謂偏好
- **徵信報表** — 產出專款收支與用途說明

## 適合誰使用

- 宮廟會計
- 總務主任
- 管理委員

## 運作流程

1. 建立專款
2. 受理捐款
3. 開立收據
4. 申請動支
5. 審核付款
6. 發布徵信

## 導入效益

- 活動籌備工時：20小時 → **5小時**
- 報名掌握率：65% → **94%**
- 物資盤點：6小時 → **1小時**
- 志工調度時效：3天 → **1天**
