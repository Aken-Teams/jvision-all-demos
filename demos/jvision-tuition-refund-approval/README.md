# 學費退費試算審核台

> 依課程開課日、已上堂數、教材領用、優惠方案與退費規章試算金額，協助教務及財務一致處理轉班、停課與退費申請。

依課程開課日、已上堂數、教材領用、優惠方案與退費規章試算金額，協助教務及財務一致處理轉班、停課與退費申請。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **申請收件** — 管理退費、轉班與停課申請。
- **修課核對** — 確認堂數、出席及課程進度。
- **教材扣款** — 檢查教材領用與可退狀態。
- **退費試算** — 依規章與優惠計算應退金額。
- **例外簽核** — 處理特殊減免與爭議案件。
- **付款交接** — 產生退款明細與財務清單。

## 適合誰使用

- 教務專員
- 財務人員
- 校務主管

## 運作流程

1. 受理申請
2. 確認修課
3. 核對教材
4. 試算金額
5. 核准例外
6. 交付退款

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
