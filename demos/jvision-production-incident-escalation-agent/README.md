# 生產異常戰情升級協作助手

> 集中管理停機、缺料、品質與人力等生產異常，以擬真事件自動摘要影響、建議負責角色與升級時限，透過戰情時間軸協調處置、決策與交接，避免問題失聯。

集中管理停機、缺料、品質與人力等生產異常，以擬真事件自動摘要影響、建議負責角色與升級時限，透過戰情時間軸協調處置、決策與交接，避免問題失聯。

**產業別：**企業協作　|　**系統類型：**operations-console

## 功能模組

- **異常戰情總覽** — 依嚴重度呈現未結事件、影響產線與處置時限。
- **事件摘要判級** — 彙整擬真訊息並建議事件等級與影響範圍。
- **責任派案協作** — 指派主責、會辦角色與各自待辦事項。
- **逾時升級中心** — 依回應及恢復時限提示升級路徑與對象。
- **戰情時間軸** — 集中記錄處置進度、證據、決策與班次交接。
- **結案復盤報告** — 整理根因、處置、損失與預防再發行動。

## 適合誰使用

- 值班主管
- 線長
- 設備工程師
- 品質工程師
- 生管人員

## 運作流程

1. 掌握異常戰情
2. 摘要並判定等級
3. 派案召集處置
4. 執行逾時升級
5. 同步戰情進度
6. 完成結案復盤

- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
