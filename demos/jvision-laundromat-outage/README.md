# 自助洗衣故障停機台

> 將顧客報障轉成門店機台停用案件，集中錯誤描述、退款、所需零件、師傅到場與復機驗證，避免故障機持續吞幣及維修空跑。

**產業別：**生活服務　|　**系統類型：**maintenance-cmms

## 功能模組

- **機台地圖** — 查看門店設備與狀態
- **報障受理** — 合併顧客描述與照片
- **停用公告** — 記錄停機及現場標示
- **備料派工** — 初判零件與指派師傅
- **退款處理** — 追蹤吞幣退款及證據
- **復機驗證** — 測試功能並解除停用

## 適合誰使用

- 客服人員
- 維修調度
- 門店巡檢員

## 運作流程

1. 受理顧客報障
2. 確認停機狀態
3. 判斷維修需求
4. 安排師傅到場
5. 完成維修測試
6. 復機退款結案

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
