# 低品質流量偵測器

> 辨識機器人、誤點與無效流量來源，協助行銷團隊減少廣告預算浪費。

辨識機器人、誤點與無效流量來源，協助行銷團隊減少廣告預算浪費。

**產業別：**業務銷售　|　**系統類型：**analytics-bi

## 功能模組

- **機器人流量辨識** — 依裝置、行為節奏與網路特徵找出自動化造訪。
- **誤點模式分析** — 偵測瞬間離站、重複點擊與版位誘導造成的非意圖互動。
- **無效來源追蹤** — 定位低品質網站、聯播網、關鍵字與推薦來源。
- **虛假轉換檢查** — 辨識無效表單、重複名單與無後續價值的轉換事件。
- **浪費預算估算** — 依渠道與活動估算低品質流量造成的支出及機會損失。
- **投放阻擋建議** — 產生排除來源、受眾調整與出價下修的可執行方案。

## 運作流程

1. 選定監測活動
2. 辨識機器人造訪
3. 判讀誤點行為
4. 追查無效來源
5. 估算預算浪費
6. 核准投放調整
