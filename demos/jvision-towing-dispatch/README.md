# 道路救援調度

> 派車、追蹤、簽收到成本油耗的車隊管理

整合拖吊接單、道路救援派遣、司機任務、車隊狀態、扣車管理、帳務收款與 AI 摘要的 Demo。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**物流運輸　|　**系統類型：**TMS 運輸調度

## 功能模組

- **救援接單** — 報案受理與案件建立
- **智慧派遣** — 就近派車與拖吊指派
- **司機任務** — 現場任務與拖回進度
- **車隊即時看板** — 拖吊車狀態與定位
- **扣車管理** — 車輛入場放行與停置費
- **帳務收款** — 計費對帳與收款結案

## 適合誰使用

- 調度專員
- 車隊主管
- 營運經理

## 運作流程

1. 受理報案建案
2. 就近派遣拖吊車
3. 司機現場救援回報
4. 車輛入場與扣車控管
5. 計費對帳收款結案

## 導入效益

- 派車規劃工時：3.8小時/日 → **0.9小時/日**
- 準時配送率：80% → **91%**
- 空車率：21% → **9.4%**
- 簽收回單時效：23小時 → **1.9小時**
