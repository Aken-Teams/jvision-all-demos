# 道路救援調度

> 派車、追蹤、簽收到成本油耗的車隊管理

整合拖吊接單、道路救援派遣、司機任務、車隊狀態、扣車管理、帳務收款與 AI 摘要的 Demo。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**物流運輸　|　**系統類型：**TMS 運輸調度

## 功能模組

- **路線調度** — 派車與路線規劃
- **任務派車** — 任務指派與追蹤
- **即時追蹤** — GPS 定位與到貨
- **簽收回單** — 電子簽收與回單
- **成本油耗** — 油耗與成本分析
- **冷鏈溫控** — 溫度監控與告警

## 適合誰使用

- 調度專員
- 車隊主管
- 營運經理

## 運作流程

1. 建立道路救援調度資料
2. 整合拖吊接單、道路救援派遣、司機任務、車隊狀態、扣車管理、帳務收款與 AI 摘要的 Demo
3. 確認結果並完成留存

## 導入效益

- 派車規劃工時：3.8小時/日 → **0.9小時/日**
- 準時配送率：80% → **91%**
- 空車率：21% → **9.4%**
- 簽收回單時效：23小時 → **1.9小時**
