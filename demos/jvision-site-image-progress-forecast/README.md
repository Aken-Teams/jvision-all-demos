# 工地影像進度預測台

> 利用預先準備的工地影像與模擬辨識結果，將樓層、區域及工項完成度對照排程基準，呈現實績差異與完工趨勢，協助專案團隊快速確認落後熱區、查閱影像證據並安排趕工措施。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **進度總覽** — 呈現計畫與實績曲線、落後天數、關鍵工項及區域熱圖。
- **工地影像牆** — 依日期、樓層、區域與工項瀏覽定位完成的擬真現場影像。
- **實績辨識** — 顯示影像中的工項、完成度與辨識信心，支援人工確認。
- **排程對照** — 將核定實績映射至排程活動，呈現提前、正常及落後狀態。
- **完工預測** — 模擬目前速度延續後的里程碑日期與可能延誤區間。
- **追趕計畫** — 建立增派人力、調整工序等措施並比較預期改善幅度。

## 適合誰使用

- 專案經理
- 工地主任
- 進度工程師與監造人員

## 運作流程

1. 掌握專案差異
2. 查閱現場影像
3. 確認辨識實績
4. 更新排程進度
5. 評估完工日期
6. 制定追趕措施

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
