# 轉運貨籠封存放行台

> 針對跨站轉運貨籠建立封存清單、件數覆核、異常補件與放行責任，讓下一段承運前確認貨物及標籤完整，避免整籠誤轉、漏裝或責任斷點。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **貨籠清單** — 查看路由件數與狀態
- **封存覆核** — 核對貨件標籤和數量
- **封條登錄** — 記錄封存人與封條號
- **重開異動** — 管理抽換及重新點交
- **裝車放行** — 確認異常已處理完成
- **交接追溯** — 查閱跨站責任軌跡

## 適合誰使用

- 轉運理貨員
- 班組長
- 幹線調度

## 運作流程

1. 建立貨籠
2. 核對內容
3. 完成封存
4. 處理重開
5. 核准裝車
6. 到站交接

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
