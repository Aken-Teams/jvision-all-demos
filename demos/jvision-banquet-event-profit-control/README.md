# 宴會檔期毛利管制台

> 協助飯店宴會與大型餐廳管理廳別檔期、桌價方案、加購項目、預估成本、訂金節點及結案毛利，降低業務超賣場地與低毛利接單風險。

協助飯店宴會與大型餐廳管理廳別檔期、桌價方案、加購項目、預估成本、訂金節點及結案毛利，降低業務超賣場地與低毛利接單風險。

**產業別：**餐飲旅宿　|　**系統類型：**pos-frontdesk

## 功能模組

- **廳別檔期** — 查看各宴會廳占用與保留狀態
- **方案估價** — 組合桌價、設備與加購服務
- **訂金追蹤** — 管理收款節點與逾期提醒
- **菜單成本** — 估算菜色與酒水成本
- **執行核對** — 確認桌數、設備及服務需求
- **毛利結案** — 比較預估與實際損益

## 適合誰使用

- 宴會業務
- 餐飲經理
- 財務人員

## 運作流程

1. 登記檔期
2. 配置方案
3. 確認訂金
4. 覆核成本
5. 執行宴會
6. 結算毛利

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
