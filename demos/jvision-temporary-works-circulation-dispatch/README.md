# 假設工程週轉調度台

> 管理模板、支撐架、安全護欄與施工平台等週轉料，在各棟、樓層及工區間的需求、拆除、整備與再派用，讓現場掌握可用數量、堆置位置及損壞責任。

管理模板、支撐架、安全護欄與施工平台等週轉料，在各棟、樓層及工區間的需求、拆除、整備與再派用，讓現場掌握可用數量、堆置位置及損壞責任。

**產業別：**營建工程　|　**系統類型：**warehouse-wms

## 功能模組

- **週轉料總覽** — 彙整各類週轉料的在用、待拆、整備與可用數量。
- **工區需求排程** — 按工作面與施工日期登錄需求規格及數量。
- **拆料回收預報** — 預估拆除時間、回收數量及下一個可用日期。
- **整備判定** — 記錄清理、修復、報廢與待檢查狀態。
- **跨區調度** — 比對供需缺口並建立棟別或工地間調撥單。
- **週轉效益** — 分析週轉次數、閒置天數、損耗與租購需求。

## 適合誰使用

- 工地主任
- 材料管理員
- 假設工程領班

## 運作流程

1. 提報工作面需求
2. 盤點可供來源
3. 安排拆料回收
4. 檢查整備狀態
5. 核准調度派用
6. 結算回收差異

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
