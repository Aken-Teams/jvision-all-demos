# 集團內部費用分攤台

> 供集團財會依服務量、營收、人數或固定比例，將共享中心與總部費用分攤至各公司及成本中心，管理規則版本、例外調整、覆核與傳票摘要。

供集團財會依服務量、營收、人數或固定比例，將共享中心與總部費用分攤至各公司及成本中心，管理規則版本、例外調整、覆核與傳票摘要。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **分攤架構** — 管理公司、成本中心與層級。
- **規則版本** — 設定動因、比例及有效期間。
- **基礎數據** — 檢查人數、營收與服務量。
- **分攤試算** — 逐層計算費用承擔結果。
- **異議覆核** — 處理例外調整與回覆意見。
- **入帳發布** — 產生公司別傳票與摘要。

## 適合誰使用

- 管理會計
- 集團財會主管
- 子公司會計

## 運作流程

1. 選擇期間
2. 設定規則
3. 檢核數據
4. 執行試算
5. 處理異議
6. 發布入帳

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
