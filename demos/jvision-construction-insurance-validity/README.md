# 工程保險效期稽核台

> 集中管理營造綜合險、雇主責任險等保單的承保期間、工程金額、工區與被保險人，遇工期展延、金額增加或分包異動時產生批改檢核，避免事故發生才發現保障缺口。

集中管理營造綜合險、雇主責任險等保單的承保期間、工程金額、工區與被保險人，遇工期展延、金額增加或分包異動時產生批改檢核，避免事故發生才發現保障缺口。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **保單總覽** — 檢視各工程險種、期間、金額與承保範圍。
- **效期監控** — 比對工程期程與保單起訖日期並提示缺口。
- **金額檢核** — 比較契約變更後工程總額與投保金額。
- **名單核對** — 確認業主、承包商及分包商是否納入承保。
- **批改追蹤** — 管理批改需求、報價、核准及批單回收。
- **保障稽核** — 彙整缺口、除外責任與未完成改善事項。

## 適合誰使用

- 風險管理人員
- 專案經理
- 財務人員

## 運作流程

1. 建立保單資料
2. 接收工程異動
3. 辨識保障缺口
4. 提出批改申請
5. 核對批單內容
6. 完成效期稽核

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
