# 網購漏配補寄處理台

> 串接客服申訴、裝箱證據、庫存判定、補寄批准與運費歸責，讓客服與倉庫在同一案件內快速決定補寄、退款或拒絕。

**產業別：**零售電商　|　**系統類型：**service-desk

## 功能模組

- **申訴受理** — 記錄缺少品項與客戶證據。
- **裝箱查驗** — 核對揀貨與封箱紀錄。
- **責任判定** — 判斷漏配、遺失或誤解。
- **補救核准** — 選擇補寄、退款或折抵。
- **補寄安排** — 建立新包裹及追蹤碼。
- **案件結案** — 確認送達與成本歸責。

## 適合誰使用

- 客服專員
- 倉儲主管
- 財務審核

## 運作流程

1. 建立申訴
2. 查驗裝箱
3. 判定責任
4. 核准補救
5. 執行補寄
6. 確認結案

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
