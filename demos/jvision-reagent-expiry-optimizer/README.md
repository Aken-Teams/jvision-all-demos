# 試劑庫存效期最佳化器

> 依實驗排程、庫存效期與預估用量調整採購及領用，降低試劑報廢。

依實驗排程、庫存效期與預估用量調整採購及領用，降低試劑報廢。

**產業別：**研發管理　|　**系統類型：**warehouse-wms

## 功能模組

- **試劑效期總覽** — 按批號呈現剩餘效期、可用量與儲存條件風險。
- **實驗需求推演** — 將實驗計畫轉換為各時段的試劑需求與安全餘量。
- **批號領用排序** — 依效期、相容性與實驗限制推薦最佳領用批次。
- **採購時點最佳化** — 計算建議採購量、到貨日與避免過量的延後方案。
- **報廢風險處置** — 找出即將閒置或過期的試劑並提出調撥、替代或加速使用方案。
- **減廢成效模擬** — 比較調整前後的過期數量、採購成本與缺料機率。

## 適合誰使用

- 實驗室主管
- 研究員
- 技術員

## 運作流程

1. 盤點效期風險
2. 展開實驗需求
3. 重排領用批次
4. 調整採購節奏
5. 核准減廢方案
6. 追蹤報廢改善

## 導入效益

- 設計變更工時：8小時 → **2小時**
- 文件版本錯誤：6件/月 → **1件/月**
- 專案準時率：70% → **92%**
- 資料查找時間：30分鐘 → **5分鐘**
