# 設備拆件救援管制台

> 供維修團隊在關鍵備品缺料時，管理從停用或低優先設備拆取零件的風險評估、審批、拆裝紀錄、受影響設備狀態及後續補回計畫。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **救援需求** — 記錄故障與缺料急迫度
- **供體評估** — 比較可拆設備與營運風險
- **拆件審批** — 確認授權及回復計畫
- **拆裝紀錄** — 記錄零件來源與安裝結果
- **設備關聯** — 查看受體與供體狀態
- **補回追蹤** — 管理到料、復原及驗收

## 適合誰使用

- 維修主管
- 設備工程師
- 備品管理員

## 運作流程

1. 提出缺料救援
2. 評估供體設備
3. 核准拆件方案
4. 完成拆裝作業
5. 更新設備狀態
6. 追蹤零件補回

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
