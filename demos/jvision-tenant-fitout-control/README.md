# 租戶裝修進場管制台

> 供商辦與商場物業審核租戶裝修圖說、承包商資格、施工時段、押金與違規改善，降低公共區域損壞、工安事件及開幕延誤。

供商辦與商場物業審核租戶裝修圖說、承包商資格、施工時段、押金與違規改善，降低公共區域損壞、工安事件及開幕延誤。

**產業別：**房地產與物業　|　**系統類型：**construction-pm

## 功能模組

- **裝修申請** — 彙整圖說、工期及施工作業項目。
- **資格審查** — 核對承包商保險與人員名冊。
- **進場排程** — 控管施工時段、貨梯及卸貨區。
- **現場巡查** — 記錄工安、噪音與公設保護狀況。
- **違規改善** — 開立缺失、期限及押金扣抵建議。
- **完工退場** — 辦理驗收、復原與押金返還。

## 適合誰使用

- 物業經理
- 機電主管
- 租戶服務專員

## 運作流程

1. 提出申請
2. 審查資格
3. 核排進場
4. 巡查施工
5. 完成改善
6. 驗收退場

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
