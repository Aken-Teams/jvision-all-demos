# 宮廟信眾與服務管理

> 把日常作業收斂成可操作、可追蹤的營運中樞

信徒名冊、點燈登記、法會活動與捐獻收據的互動式廟務管理 Demo把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**宗教服務　|　**系統類型：**營運管理主控台

## 功能模組

- **營運總覽** — 今日狀態與待辦
- **作業看板** — 作業流程看板
- **例外處理** — 異常與例外管理
- **資料建立** — 快速建立與流轉
- **營運洞察** — 數據彙整與洞察
- **操作紀錄** — 稽核與追溯

## 適合誰使用

- 行政人員
- 活動總幹事
- 管理委員

## 運作流程

1. 建立宮廟信眾與服務管理資料
2. 信徒名冊、點燈登記、法會活動與捐獻收據的互動式廟務管理 Demo
3. 確認結果並完成留存

## 導入效益

- 活動籌備工時：19小時 → **4.7小時**
- 報名掌握率：61% → **88%**
- 物資盤點：5.6小時 → **0.9小時**
- 志工調度時效：2.8天 → **0.9天**
