# Gauge/Calibration Management（量具校驗管理）

> 從異常到改善的品質閉環與追溯稽核

Gauge/Calibration Management（量具校驗管理）提供量具建檔與編號、校驗週期排程、外校/內校紀錄管理。計量室依「量具建檔→校驗排程→送校/內校執行→結果登錄→合格標示發放」推進作業，優先解決「量具逾期未校驗」，品保部則以校驗準時率與量具逾期比例確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 計量室
- 品保部
- 生產部

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉

## 導入效益

- 批號追溯時間：173分鐘 → **16分鐘**
- 客訴平均關案：22天 → **9天**
- 改善驗證率：63% → **92%**
- 重複不良率：6.4% → **2%**
