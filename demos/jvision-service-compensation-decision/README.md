# 服務補償額度決策助手

> 依模擬案件的責任歸屬、顧客影響、服務中斷、客戶價值與歷史補償，建議退款、折抵或贈品方案，並以權限護欄、理由紀錄及分級審批維持公平與成本控制。

**產業別：**客服管理　|　**系統類型：**service-desk

## 功能模組

- **案件情境建檔** — 選擇模擬服務事件，整理顧客訴求、損失、責任與既有處理紀錄。
- **影響責任評估** — 以嚴重度、持續時間、可歸責性及客戶價值形成一致評估結果。
- **補償方案比較** — 並列退款、點數、折抵與贈品方案，呈現成本、適用性及顧客效益。
- **額度護欄檢查** — 檢查角色權限、頻率、累計額度、重複補償與必要證明等規則。
- **例外審批中心** — 針對超額或特殊案件顯示理由、風險與審批層級，支援模擬決策。
- **補償成效分析** — 分析補償成本、案件類型、顧客回饋、重複申請及政策落差。

## 適合誰使用

- 第一線客服人員
- 客服班長
- 營運主管與財務稽核人員

## 運作流程

1. 建立案件
2. 評估影響
3. 比較方案
4. 檢查額度
5. 審批例外
6. 追蹤結果

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
