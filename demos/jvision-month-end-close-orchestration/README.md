# 月結關帳任務指揮台

> 將月結所需傳票、攤提、對帳、估列、報表檢核與主管簽核編排成有相依關係的任務，集中追蹤卡點、重開原因及關帳版本，縮短結帳週期。

將月結所需傳票、攤提、對帳、估列、報表檢核與主管簽核編排成有相依關係的任務，集中追蹤卡點、重開原因及關帳版本，縮短結帳週期。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **關帳範本** — 設定週期任務、期限與前後依賴。
- **任務分派** — 配置負責人、覆核人與備援人員。
- **完成證據** — 附加傳票、對帳表及檢核結果。
- **阻塞管理** — 揭示被前置任務卡住的工作。
- **關帳簽核** — 依層級確認模組與總帳關帳。
- **版本重開** — 記錄重開原因、影響及重新核准。

## 適合誰使用

- 總帳會計
- 財會主管
- 各模組會計

## 運作流程

1. 啟動週期
2. 分派任務
3. 執行作業
4. 排除阻塞
5. 覆核關帳
6. 管理重開

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
