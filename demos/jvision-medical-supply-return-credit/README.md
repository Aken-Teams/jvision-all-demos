## 功能模組

- **科室退庫** — 記錄品項批號數量原因
- **倉庫驗收** — 確認實收及可退狀態
- **廠商退貨** — 追蹤交運與簽收結果
- **折讓證明** — 登錄金額稅額與期別
- **成本沖回** — 核對庫存應付與科別
- **差異結案** — 處理跨月缺件及調整

## 適合誰使用

- 醫材庫管
- 醫療會計
- 採購人員

## 運作流程

1. 提出耗材退庫
2. 完成倉庫驗收
3. 辦理供應商退貨
4. 追蹤折讓文件
5. 核對成本帳務
6. 覆核差異結案
