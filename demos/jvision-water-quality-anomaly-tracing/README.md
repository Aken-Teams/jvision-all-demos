# 水質異常預警溯源平台

> 整合取水、製程與供水節點的擬真水質檢測資料，自動標示偏離正常型態的指標，協助人員研判污染路徑、比對可能來源、模擬隔離措施，並留下通報與採樣追蹤紀錄。

整合取水、製程與供水節點的擬真水質檢測資料，自動標示偏離正常型態的指標，協助人員研判污染路徑、比對可能來源、模擬隔離措施，並留下通報與採樣追蹤紀錄。

**產業別：**品質管理　|　**系統類型：**operations-console

## 功能模組

- **水質監控總覽** — 彙整各節點水質狀態、異常指標、事件等級與待辦事項。
- **異常預警中心** — 列出超限與型態異常事件，呈現趨勢、可信度及判讀依據。
- **污染路徑溯源** — 以節點關聯圖推演上游來源、傳播路徑與可能受影響區域。
- **污染來源比對** — 比較擬真污染特徵、周邊作業與歷史案例，形成來源候選清單。
- **採樣隔離規劃** — 安排複驗採樣點、優先順序及閥門隔離情境，估算影響範圍。
- **事件通報處置** — 管理事件時間軸、責任人、通報對象、處置紀錄與解除條件。

## 適合誰使用

- 水質分析師
- 供水值班主管
- 環安人員

## 運作流程

1. 監看水質狀態
2. 判讀異常預警
3. 推演污染路徑
4. 比對來源候選
5. 規劃採樣隔離
6. 完成通報處置

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
