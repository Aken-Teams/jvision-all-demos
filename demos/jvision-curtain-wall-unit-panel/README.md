# 帷幕牆板塊履歷追蹤台

> 以單元板塊編號串聯深化圖、材料批次、工廠組裝、品質檢查、運輸架次、樓層吊裝與破片補製，確保大量客製板塊依最新版設計安裝至正確軸線位置。

以單元板塊編號串聯深化圖、材料批次、工廠組裝、品質檢查、運輸架次、樓層吊裝與破片補製，確保大量客製板塊依最新版設計安裝至正確軸線位置。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **板塊主檔** — 管理板塊編號、樓層軸線與圖面版次。
- **生產進度** — 追蹤備料、組框、玻璃及組裝狀態。
- **工廠品檢** — 記錄尺寸、密封與外觀檢查。
- **運輸架次** — 編排裝架、車趟與卸貨順序。
- **吊裝定位** — 指派板塊至立面位置並回報安裝。
- **破片補製** — 追蹤損壞隔離、補製及替換履歷。

## 適合誰使用

- 帷幕牆工程師
- 工廠品管
- 吊裝領班

## 運作流程

1. 發布板塊
2. 工廠組裝
3. 品質放行
4. 裝架運輸
5. 現場吊裝
6. 補製替換

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
