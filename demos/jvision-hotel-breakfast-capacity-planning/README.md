# 旅宿早餐產能規劃台

> 依住房人數、團客出發時間、餐券方案與歷史取餐曲線，規劃分時段用餐量、餐檯補餐及人力配置，降低尖峰排隊、缺餐與過量備餐。

依住房人數、團客出發時間、餐券方案與歷史取餐曲線，規劃分時段用餐量、餐檯補餐及人力配置，降低尖峰排隊、缺餐與過量備餐。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **住房需求** — 彙整散客、團客與早餐方案人數。
- **時段預測** — 推估各時段到場量與座位壓力。
- **席位配置** — 規劃分區開放及團客保留座位。
- **備餐批次** — 設定熱食、冷盤與飲品補餐節奏。
- **人力配置** — 安排廚房、補餐、帶位及收桌人力。
- **差異復盤** — 比較預估、實到、缺餐及剩食結果。

## 適合誰使用

- 餐飲經理
- 早餐廚房領班
- 餐廳帶位主管

## 運作流程

1. 彙整需求
2. 預測尖峰
3. 配置席位
4. 規劃備餐
5. 安排人力
6. 檢討差異

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
