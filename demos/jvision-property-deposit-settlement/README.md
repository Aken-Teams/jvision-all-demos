# 租賃押金退還結算台

> 供物業公司在租戶退租時整合點交缺失、欠繳費用、修繕估價與押金抵扣，保留逐項核准及租戶確認紀錄，降低押金爭議並縮短退還作業時間。

供物業公司在租戶退租時整合點交缺失、欠繳費用、修繕估價與押金抵扣，保留逐項核准及租戶確認紀錄，降低押金爭議並縮短退還作業時間。

**產業別：**房地產與物業　|　**系統類型：**finance-case

## 功能模組

- **退租總覽** — 顯示點交、估價、核准及退款進度。
- **退租建案** — 建立租戶、租約及押金基礎資料。
- **點交缺失** — 記錄空間損傷與責任判定。
- **抵扣試算** — 整合欠費、修繕與清潔費用。
- **結算核准** — 執行分級審核並產生結算明細。
- **退款追蹤** — 登錄租戶確認、退款與爭議結果。

## 適合誰使用

- 物業管理員
- 修繕主管
- 財務人員

## 運作流程

1. 盤點退租
2. 建立結算
3. 完成點交
4. 試算抵扣
5. 核准明細
6. 辦理退款

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
