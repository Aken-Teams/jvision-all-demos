# 代管租金匯付覆核台

> 將租客入帳依物件、屋主與租期拆分，計入代管費、修繕代墊、空置及跨月調整，再由不同角色覆核匯付，降低錯匯與少付爭議。

將租客入帳依物件、屋主與租期拆分，計入代管費、修繕代墊、空置及跨月調整，再由不同角色覆核匯付，降低錯匯與少付爭議。

**產業別：**房地產與物業　|　**系統類型：**finance-case

## 功能模組

- **租金入帳** — 匹配租客與租期
- **物件歸屬** — 對應屋主與代管合約
- **淨額試算** — 計入費用代墊與調整
- **扣項憑證** — 保存修繕及欠款證據
- **匯付覆核** — 檢查帳戶與應付淨額
- **付款結案** — 記錄匯款及屋主明細

## 適合誰使用

- 代管會計
- 物業專員
- 財務主管

## 運作流程

1. 匯入租金流水
2. 確認物件歸屬
3. 計算屋主淨額
4. 補齊扣項證據
5. 覆核匯付清單
6. 完成付款通知

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
