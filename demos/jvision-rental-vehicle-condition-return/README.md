# 租賃車況交還判定台

> 以取車基準照片與車況圖對照返車影像，逐項判定新舊損傷、油量、里程及配件短少，管理客戶確認、估價、減免授權與爭議證據。

以取車基準照片與車況圖對照返車影像，逐項判定新舊損傷、油量、里程及配件短少，管理客戶確認、估價、減免授權與爭議證據。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **取車基準** — 保存原始車況
- **返車採證** — 建立返還影像
- **損傷比對** — 判定新舊刮痕
- **配件油量** — 核對附屬項目
- **費用估算** — 計算修復補收
- **議決結案** — 處理減免爭議

## 適合誰使用

- 租車門市人員
- 車況鑑定員
- 門市主管

## 運作流程

1. 建立基準
2. 返車採證
3. 比對損傷
4. 估算費用
5. 核准收費
6. 客戶確認

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
