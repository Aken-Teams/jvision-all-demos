## 功能模組

- **完工案總覽** — 查看未結成本與帳齡
- **未到票追蹤** — 催收發票及驗收資料
- **暫估清理** — 比對實際發票與迴轉
- **尾款核對** — 確認應付保留及扣款
- **責任催辦** — 指定清理人與期限
- **專案封帳** — 簽認最終成本和毛利

## 適合誰使用

- 成本會計
- 專案財務
- 工程主管

## 運作流程

1. 篩選完工案
2. 分類未結
3. 工程確認
4. 取得憑證
5. 會計調整
6. 核准封帳

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
