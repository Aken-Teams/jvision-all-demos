# Agent 稽核證據包產生器

依查核案件彙整 Agent 版本、授權、操作證據與核准紀錄，快速產出可交付證據包。

**產業別：**資訊科技　|　**系統類型：**security-soc

## 功能模組

- **查核案件建檔** — 設定查核範圍、期間、Agent 與適用控制項。
- **版本快照鎖定** — 鎖定案件期間內的模型、提示詞、工具與設定版本。
- **授權鏈核對** — 比對 IAM 角色、工具權限、臨時授權與實際使用紀錄。
- **任務證據編排** — 將任務軌跡、工具呼叫、成本與來源整理成控制項證據。
- **證據包覆核** — 標記缺口、退回補件並完成案件責任人的核准。
- **查核包封存** — 匯出具雜湊、索引與版本資訊的查核交付包。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 建立查核案件
2. 鎖定版本範圍
3. 核對授權使用
4. 編排控制證據
5. 覆核與補件
6. 匯出並封存
