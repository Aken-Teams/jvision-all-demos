> 彙整擬真的錫膏檢測資料，針對厚度、體積與面積超限焊墊進行分布分析、缺陷分群及原因追查，協助品質人員快速判斷鋼板堵孔、刮刀設定或錫膏狀態等問題。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **檢測異常總覽** — 彙整線別、產品及工單的厚度超限率與異常嚴重度。
- **板面厚度熱圖** — 以電路板座標呈現過厚、過薄及集中異常的焊墊區域。
- **厚度趨勢分析** — 比較板序、站位與時間區段的厚度分布及製程漂移。
- **異常型態分群** — 將局部過厚、連片過薄與週期性偏差等現象分類比較。
- **根因關聯追查** — 關聯鋼板開孔、刮刀設定、錫膏批次及清潔紀錄。
- **改善驗證管理** — 建立模擬處置措施並比較調整前後的厚度分布與超限率。

## 適合誰使用

- 品質工程師
- 製程工程師
- 線長

## 運作流程

1. 鎖定異常批次
2. 定位板面熱區
3. 判讀漂移趨勢
4. 辨識異常型態
5. 追查可能根因
6. 驗證改善結果
