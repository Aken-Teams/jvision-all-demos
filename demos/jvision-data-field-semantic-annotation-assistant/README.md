## 功能模組

- **待註解欄位池** — 依使用熱度與定義缺漏整理優先處理欄位。
- **值域特徵剖析** — 分析樣本值、格式、分布與欄位間關係。
- **查詢語境解析** — 從 SQL、報表與使用方式辨識欄位的商業語境。
- **定義候選生成** — 綜合值域與文件產生名稱、定義及範例建議。
- **術語一致性校準** — 比對企業詞彙表並提示同義、衝突與命名偏差。
- **目錄註解發布** — 核准定義並回寫資料目錄與相關 Schema。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 選取缺註欄位
2. 檢視值域特徵
3. 還原使用語境
4. 產生定義候選
5. 校準企業術語
6. 核准發布註解
