# 表面黏著橋接短路檢測系統

> 以模擬表面黏著檢測影像呈現相鄰接腳錫料橋接與短路疑點，自動標示位置、信心分數及嚴重度，讓檢驗人員快速複核、建立返修單並統計高發元件與站點。

以模擬表面黏著檢測影像呈現相鄰接腳錫料橋接與短路疑點，自動標示位置、信心分數及嚴重度，讓檢驗人員快速複核、建立返修單並統計高發元件與站點。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **短路檢測看板** — 呈現今日疑點、確認缺陷、待返修及各線別分布。
- **影像檢測工作區** — 在模擬板件影像上標示橋接區域與接腳位置。
- **疑點複核中心** — 逐筆比較原圖、標記圖與信心分數並完成判定。
- **元件風險分析** — 依封裝、接腳間距與料號統計橋接高發元件。
- **返修處置單** — 建立返修項目、責任站點及模擬處理紀錄。
- **缺陷趨勢報表** — 分析橋接數量、確認率與產線改善走勢。

## 適合誰使用

- AOI 檢驗員
- 品保工程師
- 返修技術員

## 運作流程

1. 查看告警
2. 檢視影像
3. 複核疑點
4. 分析元件
5. 安排返修
6. 追蹤趨勢

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
