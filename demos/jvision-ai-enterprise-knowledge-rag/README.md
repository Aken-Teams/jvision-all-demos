# 企業知識檢索與問答平台

> 整合企業規章、作業手冊、產品資料與常見問題，透過模擬的檢索增強生成技術，讓員工以自然語言取得附引用依據的答案。系統同時呈現知識分類、版本、權限範圍與內容缺口管理。

**產業別：**AI 工程平台　|　**系統類型：**it-ops

## 功能模組

- **知識入口首頁** — 依部門與情境呈現熱門知識、公告及快速入口。
- **跨庫智慧搜尋** — 跨分類搜尋文件、段落、問答與專有名詞。
- **企業知識問答** — 以自然語言提問並顯示整合後的模擬答案。
- **引用依據檢視** — 核對答案引用段落、文件版本與適用範圍。
- **知識分類治理** — 管理主題樹、標籤、負責人及內容生命週期。
- **知識缺口管理** — 彙整未解問題並安排補充、審核與發布。

## 適合誰使用

- 全體員工
- 知識管理員
- 部門主管與資訊人員

## 運作流程

1. 進入知識入口
2. 搜尋相關內容
3. 提出企業問題
4. 核對引用來源
5. 維護知識分類
6. 補足知識缺口

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 決策資料覆蓋：55% → **92%**
- 跨部門對齊：60% → **90%**
