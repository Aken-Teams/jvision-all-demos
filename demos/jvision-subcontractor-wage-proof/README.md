# 分包工資查核管制台

> 彙整分包商進場人員、出勤、工資清冊與匯款證明，抽查實領金額及欠薪申訴，在估驗付款前完成勞務履約查核，降低公共工程欠薪與連帶處理風險。

彙整分包商進場人員、出勤、工資清冊與匯款證明，抽查實領金額及欠薪申訴，在估驗付款前完成勞務履約查核，降低公共工程欠薪與連帶處理風險。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **人員總覽** — 依分包商呈現進場人數與工資查核狀態。
- **名冊比對** — 比對勞工身分、工種、進退場及承攬層級。
- **出勤核對** — 將工地出勤與分包申報工作日交叉檢查。
- **工資證明** — 登錄薪資清冊、匯款憑證及實領金額。
- **抽查申訴** — 記錄勞工抽訪、差異說明與欠薪案件。
- **付款放行** — 依查核結果決定估驗款放行或暫扣。

## 適合誰使用

- 工地行政
- 分包管理人員
- 工務經理

## 運作流程

1. 人員總覽
2. 名冊比對
3. 出勤核對
4. 工資證明
5. 抽查申訴
6. 付款放行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
