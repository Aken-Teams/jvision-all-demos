# 放款撥付前提管制台

> 依核准書區分撥款前與撥款後條件，阻擋未完成擔保設定、自備款或契約簽署的案件；任何解除均須記錄理由、額度與具權限的核准人。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **前提分類** — 區分前後條件
- **撥付阻擋** — 顯示未成就項目
- **證據檢視** — 驗證擔保文件
- **額度核對** — 確認可撥金額
- **例外解除** — 分層核准放行
- **放行憑證** — 產生一次性授權

## 適合誰使用

- 放款作業員
- 授信經辦
- 風控主管

## 運作流程

1. 載入案件
2. 分類前提
3. 驗證證據
4. 檢查額度
5. 核准例外
6. 授權撥付

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
