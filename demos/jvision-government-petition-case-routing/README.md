# 政府陳情分流協辦平台

> 將模擬電話、網路與書面陳情統一收件，協助辨識主旨、權責機關、急迫性及重複案件，完成自動分流、跨單位協辦、期限追蹤與回覆草擬，提升政府案件處理一致性並降低逾期風險。

將模擬電話、網路與書面陳情統一收件，協助辨識主旨、權責機關、急迫性及重複案件，完成自動分流、跨單位協辦、期限追蹤與回覆草擬，提升政府案件處理一致性並降低逾期風險。

**產業別：**客服管理　|　**系統類型：**service-desk

## 功能模組

- **陳情收件** — 統一呈現多管道案件、附件、個資遮罩與收件狀態。
- **智能分流** — 建議案件類別、權責單位、急迫性與分派理由。
- **重複辨識** — 比對相似陳情、既有案件及可合併處理的議題。
- **協辦工作台** — 管理主辦、協辦分工、意見交換與待補資料。
- **期限管控** — 追蹤法定期限、內部節點、催辦紀錄及逾期風險。
- **回覆審核** — 彙整辦理結果、產生回覆草稿並執行逐級核稿。

## 適合誰使用

- 陳情收件人員
- 分案主管
- 機關承辦人與跨單位協辦人員

## 運作流程

1. 建立陳情案件
2. 確認權責分流
3. 合併重複案件
4. 啟動跨單位協辦
5. 追蹤辦理期限
6. 核定案件回覆

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
