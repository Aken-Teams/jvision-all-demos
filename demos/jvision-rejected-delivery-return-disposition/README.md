# 配送拒收回站處置台

> 管理拒收貨件回站後的位置、原因、重送、退回貨主與費用決策，透過跨班點交避免無主貨、錯分及未經確認的重複配送。

管理拒收貨件回站後的位置、原因、重送、退回貨主與費用決策，透過跨班點交避免無主貨、錯分及未經確認的重複配送。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **拒收佇列** — 查看回站貨件與原因。
- **站內定位** — 記錄暫存區與移動軌跡。
- **客戶確認** — 釐清重送或退回意願。
- **處置決策** — 選擇重送、退貨或待指示。
- **車趟安排** — 建立下一步運輸任務。
- **班次交接** — 確認貨件與責任人。

## 適合誰使用

- 站所理貨員
- 客服專員
- 調度主管

## 運作流程

1. 掃描回站
2. 確認原因
3. 取得指示
4. 核准處置
5. 安排運輸
6. 交接結案

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
