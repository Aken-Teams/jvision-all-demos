# 零售效期折價管制台

> 依門市批次效期建立巡檢、折價、下架與報廢任務，協助生鮮及食品零售降低過期風險，同時管控折價權限與毛利損失。

依門市批次效期建立巡檢、折價、下架與報廢任務，協助生鮮及食品零售降低過期風險，同時管控折價權限與毛利損失。

**產業別：**零售電商　|　**系統類型：**warehouse-wms

## 功能模組

- **效期雷達** — 依剩餘天數列出門市高風險批次。
- **折價規則** — 設定品類與效期對應折扣級距。
- **巡架任務** — 派發指定貨架與批次檢查工作。
- **下架處置** — 記錄折價、移倉、退供或報廢結果。
- **例外核准** — 審核超額折價與延後處置理由。
- **損失分析** — 比較門市報廢、折價及售罄績效。

## 適合誰使用

- 門市店長
- 商品管理
- 區域督導

## 運作流程

1. 辨識即期批次
2. 套用折價規則
3. 派發門市巡架
4. 執行商品處置
5. 審核處置例外
6. 檢討效期損失

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
