# 外籍移工管理管理艙

專為電子製造業大量聘僱外籍移工設計，管理入境、居留、體檢、契約與仲介費用等專屬事務。

- 原始系統：外籍移工管理系統（Foreign Worker Management）
- 產業分類：智慧製造｜人資管理
- 使用部門：人資部、勞務仲介窗口、廠務行政、法務合規部
- 工作流程：招募媒合 → 入境安排 → 聘僱許可申請 → 到職建檔 → 居留/體檢期限追蹤 → 期滿續聘或離境
- AI 應用：證件到期自動預警提醒、多語言智慧翻譯溝通輔助
- 主要 KPI：證件逾期件數、聘僱合規率、移工留任率、仲介成本占比
- 代表產品：一零四移工管理平台、鼎新外勞管理模組、各縣市人力仲介自建系統
