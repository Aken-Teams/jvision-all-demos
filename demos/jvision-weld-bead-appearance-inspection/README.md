# 焊道外觀智慧檢測系統

> 以焊道外觀影像模擬辨識咬邊、焊瘤、裂紋、偏移與成形不均，提供缺陷標記、尺寸量測、人工複判及工件追溯，協助產線建立一致的外觀驗收標準與返修流程。

以焊道外觀影像模擬辨識咬邊、焊瘤、裂紋、偏移與成形不均，提供缺陷標記、尺寸量測、人工複判及工件追溯，協助產線建立一致的外觀驗收標準與返修流程。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **焊道品質總覽** — 呈現檢測量、外觀合格率、主要缺陷與返修待辦。
- **焊道影像檢測** — 逐段查看焊道影像、缺陷框選、信心分數與位置座標。
- **外觀尺寸量測** — 展示焊道寬度、高度、偏移量與咬邊深度的模擬量測。
- **缺陷複判工作台** — 確認或修正缺陷類型、嚴重度、允收結果與判定說明。
- **返修派工管理** — 建立打磨、補焊及重檢任務，追蹤人員、期限與狀態。
- **班次品質分析** — 比較班次、焊工、工位及料號的缺陷率與返修表現。

## 適合誰使用

- 焊道檢驗員
- 品質工程師
- 產線領班

## 運作流程

1. 掌握外觀品質
2. 檢查焊道影像
3. 核對外觀尺寸
4. 完成缺陷複判
5. 指派返修作業
6. 檢討班次表現

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
