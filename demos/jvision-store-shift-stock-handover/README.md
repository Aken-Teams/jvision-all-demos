# 門市交班庫存點交台

> 針對精品、手機等高價商品，在班次交接時分開盤點可售、展示、預留、送修與借出狀態，鎖定差異時段、經手人與調查證據。

**產業別：**零售電商　|　**系統類型：**pos-frontdesk

## 功能模組

- **班次清冊** — 分類商品狀態
- **交班點數** — 記錄交班數量
- **接班覆點** — 雙方確認責任
- **差異證據** — 保存現場照片
- **時段調查** — 追查經手紀錄
- **差異結案** — 核准調整歸責

## 適合誰使用

- 門市店員
- 值班店長
- 區域稽核員

## 運作流程

1. 產生清冊
2. 執行點數
3. 接班覆點
4. 回報差異
5. 調查時段
6. 核准結案

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
