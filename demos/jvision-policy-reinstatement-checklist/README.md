# 保險復效條件清件台

> 彙整停效保單的欠費、利息、健康告知、體檢、核保決定與文件效期，依申請基準日鎖定版本，避免補件過期仍被誤認可復效。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **復效案件** — 呈現停效原因與申請日
- **保費試算** — 計算欠費利息及有效期
- **健康文件** — 追蹤告知體檢與補件
- **效期檢查** — 依基準日判定文件有效
- **核保決定** — 記錄標準加費或拒絕
- **復效生效** — 覆核條件後更新保單

## 適合誰使用

- 保全行政
- 核保人員
- 法遵覆核

## 運作流程

1. 受理復效申請
2. 試算欠費金額
3. 收集健康文件
4. 檢查文件效期
5. 核定復效條件
6. 執行保單復效

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
