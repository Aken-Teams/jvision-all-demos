# 軌道乘務交接管制台

> 管理列車乘務班次、報到資格、勤務包與交接事項，於缺員或運轉調整時建立替補方案，並留存延誤說明與交班確認，降低資訊斷點及違反工時規則風險。

管理列車乘務班次、報到資格、勤務包與交接事項，於缺員或運轉調整時建立替補方案，並留存延誤說明與交班確認，降低資訊斷點及違反工時規則風險。

**產業別：**交通運輸　|　**系統類型：**operations-console

## 功能模組

- **勤務班次** — 呈現車次與乘務勤務鏈
- **報到資格** — 核對人員證照與休息條件
- **勤務資料** — 發布路線提示與臨時命令
- **缺員替補** — 模擬可用人員與替補影響
- **乘務交接** — 記錄車況及未結交辦事項
- **異常稽核** — 檢視延誤、超時與交接紀錄

## 適合誰使用

- 乘務派班員
- 值班站長
- 乘務主管

## 運作流程

1. 建立勤務
2. 資格核對
3. 發布資料
4. 處理缺員
5. 完成交接
6. 稽核結班

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
