# 平衡計分卡管理系統（BSC）

> 把分散數據變成可下鑽、可決策的經營洞察

平衡計分卡管理系統（BSC）提供策略地圖建立與展示、KPI 指標樹狀展開與權責指派、部門/個人目標對齊追蹤。總經理室依「願景訂定 → 策略地圖展開 → 四構面指標設定 → 部門對齊 → 定期追蹤 → 考核回饋」推進作業，優先解決「策略與執行脫節」，人資部則以策略目標達成率與指標對齊覆蓋率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**經營管理　|　**系統類型：**BI 商業智慧

## 功能模組

- **經營儀表板** — 關鍵指標即時總覽
- **趨勢分析** — 多維度趨勢與比較
- **指標下鑽** — 逐層鑽取到明細
- **平衡計分卡** — 策略目標與 KPI 對齊
- **AI 洞察** — 自動發現異常與機會
- **報表匯出** — 排程報表與分享

## 適合誰使用

- 總經理室
- 人資部
- 財務部

## 運作流程

1. 待釐清
2. 改善中
3. 核定確認
4. 已解除

## 導入效益

- 報表產出工時：17小時 → **1小時**
- 異常發現時效：2.9天 → **1天**
- 決策資料覆蓋：57% → **86%**
- 跨部門對齊：58% → **90%**
