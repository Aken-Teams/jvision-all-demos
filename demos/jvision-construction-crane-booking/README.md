# 工地吊裝資源協調台

> 協助工地主任統整塔吊、吊車、操作人員、吊裝區域與工項需求，處理時段衝突、前置條件及臨時變更，降低工班等待與大型吊裝延誤。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **吊裝總覽** — 顯示當日任務、設備負荷與衝突警示。
- **需求申請** — 登錄吊物、重量、樓層、區域及所需時段。
- **條件檢核** — 確認場地、構件、人員與文件準備狀況。
- **資源排程** — 配置設備、操作人員與吊裝時間窗口。
- **現場調度** — 處理延誤、插單、取消及替代安排。
- **效率分析** — 統計等待、衝突、利用率與延遲原因。

## 適合誰使用

- 工地主任
- 吊裝協調員
- 工班領班

## 運作流程

1. 提出申請
2. 檢查條件
3. 協調衝突
4. 發布排程
5. 執行回報
6. 分析改善

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
