# 技能證據驗證器

> 以作品、實務任務與同儕評核驗證技能，避免僅用完課紀錄判定能力。提升能力認證的可信度與實用性。

以作品、實務任務與同儕評核驗證技能，避免僅用完課紀錄判定能力。提升能力認證的可信度與實用性。

**產業別：**人力資源　|　**系統類型：**education-lms

## 功能模組

- **能力驗證申請** — 選定待驗證技能、熟練等級與適用職務標準。
- **作品證據集** — 彙整專案成果、程式提交、文件與工作產出作為能力證明。
- **任務表現比對** — 將實際任務成果對照技能指標、品質門檻與完成條件。
- **同儕評核室** — 邀請具資格評核者依量表提供評分、意見與反證。
- **證據關聯判讀** — 交叉檢查作品歸屬、任務脈絡、評核一致性與證據缺口。
- **技能認證決議** — 形成通過、補證或暫緩結論並更新員工技能檔案。

## 適合誰使用

- L&D 主管
- 部門主管
- 員工

## 運作流程

1. 提出驗證申請
2. 組建作品證據
3. 比對任務表現
4. 完成同儕評核
5. 審查證據缺口
6. 發布認證結果

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
