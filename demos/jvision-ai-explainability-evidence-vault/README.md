# AI 可解釋性證據庫

> 保存 AI 決策的特徵、規則、來源與版本，快速組成可驗證的個案說明。

保存 AI 決策的特徵、規則、來源與版本，快速組成可驗證的個案說明。

**產業別：**資訊安全　|　**系統類型：**security-soc

## 功能模組

- **決策特徵快照** — 凍結個案採用的特徵值、權重、缺失值與轉換方式。
- **規則版本庫** — 保存命中規則、門檻、例外條件及當時生效版本。
- **來源血緣圖** — 連結原始文件、資料欄位、擷取片段與來源系統。
- **決策版本比較** — 比較模型、提示、規則或資料版本造成的結果差異。
- **解釋關聯圖譜** — 串聯特徵、規則、來源、輸出與人工覆核關係。
- **個案說明包** — 產生可編修的決策說明、引用清單與版本證明。

## 適合誰使用

- CISO
- AI 治理主管
- 資安分析師

## 運作流程

1. 選定待解釋個案
2. 凍結特徵快照
3. 核對規則版本
4. 追溯資料來源
5. 比較決策差異
6. 核准說明證據包

## 導入效益

- 告警分流時間：45分鐘 → **8分鐘**
- 事件平均處理：12小時 → **3小時**
- 弱點修補率：68% → **96%**
- 合規稽核工時：30小時/月 → **6小時/月**
