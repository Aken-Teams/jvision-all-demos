> 管理工地廢棄物分類、裝載、清運車次、過磅數量與最終處理證明，逐車核對清運商回傳文件及計費，標示聯單缺漏、重量異常或去向不明的風險車次。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **清運總覽** — 依廢棄物類別與工區顯示待運、運送中及已結案量。
- **車次派運** — 登錄清運商、車號、載運類別與預定去向。
- **磅單核對** — 輸入進出場重量並比對預估裝載量。
- **聯單追蹤** — 檢查聯單編號、簽章、日期及車次對應。
- **去向證明** — 保存處理場收受證明與最終處理方式。
- **請款稽核** — 按車次與重量核對計費及異常扣款。

## 適合誰使用

- 環安人員
- 工地行政
- 成本會計

## 運作流程

1. 盤點待運
2. 安排車次
3. 核對重量
4. 收齊聯單
5. 確認去向
6. 審核請款

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
