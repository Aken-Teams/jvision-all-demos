# 貨櫃物流資產周轉最佳化台

> 以擬真貨櫃、棧板、籠車與拖架資料呈現所在地、可用狀態及滯留天數，預測區域供需落差並建議調撥、回收與維修排序，協助降低閒置及額外租用成本。

以擬真貨櫃、棧板、籠車與拖架資料呈現所在地、可用狀態及滯留天數，預測區域供需落差並建議調撥、回收與維修排序，協助降低閒置及額外租用成本。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **資產營運總覽** — 呈現利用率、短缺據點、滯留與維修概況。
- **物流資產清冊** — 管理貨櫃、棧板、籠車及拖架的模擬資料。
- **資產分布地圖** — 查看各據點數量、狀態與供需熱區。
- **周轉供需預測** — 模擬未來各區可用量及短缺風險。
- **調撥回收規劃** — 建立跨據點調撥、回收與替代方案。
- **滯留維修處置** — 排序逾期占用、損壞檢修及報廢任務。

## 適合誰使用

- 資產調度員
- 貨櫃管理員
- 物流營運主管

## 運作流程

1. 掌握資產績效
2. 核對資產清冊
3. 檢視區域分布
4. 預測供需缺口
5. 安排調撥回收
6. 處理滯留維修

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
