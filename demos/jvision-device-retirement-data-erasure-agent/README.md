# 裝置退役資料清除 Agent

> 協調金鑰撤銷、資料抹除與資產關閉，產出可驗證的安全退役證明。＂ 服務估值風險

**產業別：**設備維護　|　**系統類型：**security-soc

## 功能模組

- **退役裝置盤點** — 核對裝置身分、場域位置、韌體與關聯資產。
- **金鑰撤銷作業** — 撤銷裝置憑證、API 金鑰與機器身分授權。
- **資料抹除編排** — 依媒體類型執行安全清除、重置或實體銷毀程序。
- **平台關聯解除** — 移除 IoT、SCADA、SIEM 與雲端服務中的裝置關聯。
- **資產關閉核銷** — 同步 EAM 資產狀態、庫存去向與退役責任人。
- **退役證明封裝** — 彙整撤銷回執、抹除結果與資產關閉證明。

## 適合誰使用

- IoT 架構師
- 設備工程師
- 場域主管

## 運作流程

1. 確認退役清單
2. 查核裝置關聯
3. 撤銷存取權限
4. 執行資料抹除
5. 關閉平台資產
6. 簽發退役證明

- 非計畫停機：24小時/月 → **6小時/月**
