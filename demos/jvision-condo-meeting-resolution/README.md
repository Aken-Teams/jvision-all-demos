# 社區議決執行管理台

> 供社區物業與管委會管理議案提報、會議資料、表決門檻、決議內容、責任分工及後續執行證據，讓住戶大會與管委會決議不再散落於紙本紀錄，並可清楚追蹤逾期事項。

**產業別：**房地產與物業　|　**系統類型：**collaboration-pm

## 功能模組

- **議案提報** — 收集提案理由、附件與預算需求。
- **會議排程** — 準備議程、出席名冊與會議資料。
- **表決紀錄** — 記錄門檻、票數及決議原文。
- **決議派工** — 指定責任人、期限與交付成果。
- **成果驗收** — 上傳執行證據並完成覆核。
- **住戶公告** — 產生公告版本與發布紀錄。

## 適合誰使用

- 社區經理
- 管委會主委
- 行政秘書

## 運作流程

1. 提出議案
2. 排定審議
3. 記錄表決
4. 分派執行
5. 驗收成果
6. 發布公告
