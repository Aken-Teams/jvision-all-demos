# 材料到場卸貨預約台

> 整合材料車到場時段、入口、卸貨區、吊車或堆高機需求及樓棟目的地，預先化解車輛撞期、機具不足與卸錯位置問題。

**產業別：**營建工程　|　**系統類型：**logistics-fleet

## 功能模組

- **卸貨排程** — 查看時段入口與月台
- **到貨預約** — 申報車型材料與需求
- **機具配置** — 安排吊車堆高機人力
- **車輛報到** — 記錄到場排隊與放行
- **卸貨簽收** — 確認品項位置及完成
- **待時分析** — 統計壅塞與空等原因

## 適合誰使用

- 物流調度員
- 材料管理員
- 供應商司機

## 運作流程

1. 提出預約
2. 檢查容量
3. 配置資源
4. 車輛報到
5. 完成卸貨
6. 結算待時

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
