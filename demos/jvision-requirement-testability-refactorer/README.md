# 需求可測試性重構器

將模糊需求重構為可驗證的 Given-When-Then 情境，提高驗收與測試清晰度。

**產業別：**資訊科技　|　**系統類型：**collaboration-pm

## 功能模組

- **模糊需求診斷** — 標記主觀形容詞、缺少條件、未定義名詞與不可量測敘述。
- **領域詞彙對齊** — 對照需求、架構與程式碼，統一角色、事件及業務名詞。
- **行為條件拆解** — 把需求拆為前置狀態、觸發事件、規則分支與可觀察結果。
- **GWT 情境生成** — 產生正常、邊界、錯誤及權限情境的 Given-When-Then 草
- **驗收覆蓋檢查** — 檢查每條業務規則、例外與非功能限制是否有對應情境。
- **測試任務發布** — 將核准情境同步至需求票、測試案例與 CI 自動化待辦。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 診斷需求歧義
2. 校準領域詞彙
3. 拆解可驗證行為
4. 生成 GWT 情境
5. 審查規則覆蓋
6. 核准並發布測試
