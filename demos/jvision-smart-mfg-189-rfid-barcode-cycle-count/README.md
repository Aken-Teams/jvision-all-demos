# RFID/條碼盤點預警塔

透過RFID或條碼掃描進行倉儲盤點作業，取代傳統人工紙本盤點以提升準確度與速度。

- 原始系統：RFID/條碼盤點管理系統（RFID/Barcode Cycle Count）
- 產業分類：智慧製造｜倉儲管理
- 使用部門：倉儲部、財務部、稽核部
- 工作流程：盤點排程→儲位分組→掃描/RFID讀取→系統比對差異→覆核→帳務調整
- AI 應用：差異異常型態分析、高風險儲位優先排程建議
- 主要 KPI：盤點準確率、盤點耗時、差異調整金額、循環盤點覆蓋率
- 代表產品：Zebra Technologies、Honeywell、SATO、Impinj RFID方案
