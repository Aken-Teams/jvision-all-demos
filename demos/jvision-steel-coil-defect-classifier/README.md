# 鋼捲表面缺陷分類系統

> 彙整鋼捲表面影像與模擬產線資料，自動呈現刮傷、壓痕、鏽蝕、孔洞等缺陷分類結果，協助品管人員快速複核、判定處置方式，並追蹤各鋼種、機台與班別的缺陷趨勢。

彙整鋼捲表面影像與模擬產線資料，自動呈現刮傷、壓痕、鏽蝕、孔洞等缺陷分類結果，協助品管人員快速複核、判定處置方式，並追蹤各鋼種、機台與班別的缺陷趨勢。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **品質總覽** — 以批次、不良率、缺陷分布及待複核數量呈現當日品質狀態。
- **影像待判台** — 集中展示模擬鋼捲影像、缺陷框選位置與模型分類信心分數。
- **缺陷複核** — 讓檢驗員確認缺陷類別、嚴重度、尺寸與是否影響出貨。
- **批次處置** — 依複核結果模擬放行、降級、重工或報廢的處置流程。
- **缺陷分析** — 比較鋼種、產線、班別與日期的缺陷率及主要缺陷型態。
- **判定規範** — 管理缺陷範例、分級條件與檢驗作業說明，供人員查閱。

## 適合誰使用

- 鋼鐵廠品管檢驗員
- 品質主管與製程工程師

## 運作流程

1. 掌握品質概況
2. 瀏覽待判影像
3. 確認缺陷結果
4. 決定批次處置
5. 分析缺陷來源
6. 維護判定標準

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
