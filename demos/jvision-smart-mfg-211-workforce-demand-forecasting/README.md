# 產線人力需求預測洞察站

依生產排程與訂單預測未來各產線人力缺口，提前規劃招募、調度與外包人力，避免產能瓶頸。

- 原始系統：產線人力需求預測系統（Workforce Demand Forecasting）
- 產業分類：智慧製造｜人資管理
- 使用部門：生產規劃部、人資部、產線主管、供應鏈管理部
- 工作流程：訂單預測輸入 → 產能人力換算 → 缺口分析 → 招募/調度建議產出 → 主管審核 → 執行追蹤
- AI 應用：機器學習需求預測模型、人力缺口智慧模擬與建議
- 主要 KPI：人力預測準確率、缺工天數、加班工時占比、外包人力使用率
- 代表產品：鼎新智慧人力預測、SAP IBP人力模組、各集團自建AI人力預測平台
