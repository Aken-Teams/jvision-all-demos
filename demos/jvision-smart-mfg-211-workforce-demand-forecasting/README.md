# 產線人力需求預測系統（Workforce Demand Forecasting）

> 訂單到入庫的製造現場全流程數位化

產線人力需求預測系統（Workforce Demand Forecasting）提供訂單/產能與人力需求連動試算、各產線技能別缺口分析、淡旺季人力彈性配置建議。生產規劃部依「訂單預測輸入 → 產能人力換算 → 缺口分析 → 招募/調度建議產出 → 主管審核 → 執行追蹤」推進作業，優先解決「訂單暴增時人力補充來不及」，人資部則以人力預測準確率與缺工天數確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**MES 製造執行系統

## 功能模組

- **工單管理** — 訂單轉工單、拆併單與工單派發
- **排程排產** — 依產能、交期、負載自動排程
- **現場執行** — 派工、報工與進度即時回報
- **設備稼動 OEE** — 稼動、效率、良率即時監控
- **品質入庫** — 檢驗判定、不良處置與入庫
- **AI 改善建議** — 異常摘要與瓶頸改善建議

## 適合誰使用

- 生產規劃部
- 人資部
- 產線主管

## 運作流程

1. 待處理
2. 主管確認
3. 人資執行
4. 歸檔完成

## 導入效益

- 薪資作業工時：41小時/月 → **8小時/月**
- 出勤異常處理：32分鐘 → **5.2分鐘**
- 招募到位天數：43天 → **26天**
- 表單簽核時效：3天 → **1天**
