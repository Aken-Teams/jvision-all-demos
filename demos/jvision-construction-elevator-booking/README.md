# 施工電梯樓層預約台

> 讓各工班預約施工電梯的人員或材料運送趟次，登錄上料點、目的樓層、尺寸重量與所需時間，由管理員合併同向需求並管制尖峰優先權，降低梯口排隊、人料混載及大型材料臨時占梯。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **梯次看板** — 按電梯與時段顯示上下行安排。
- **運送預約** — 登錄人員、材料、樓層及時間需求。
- **同向併單** — 合併相近樓層與相容載物需求。
- **載運檢核** — 檢查載重、尺寸與人料分流規則。
- **現場叫號** — 依班表管理報到、放行與過號。
- **候梯分析** — 分析尖峰、延誤與占梯時間。

## 適合誰使用

- 電梯管理員
- 工地主任
- 工班領班

## 運作流程

1. 登錄運送需求
2. 檢核載運條件
3. 合併相近梯次
4. 發布梯次班表
5. 執行叫號放行
6. 檢討候梯瓶頸

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
