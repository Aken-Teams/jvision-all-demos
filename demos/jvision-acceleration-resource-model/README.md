# 趕工資源投入試算台

> 針對落後工項建立增班、加班、平行施工與機具增援方案，統一工率、可追回天數、直接成本及現場限制假設，讓主管在下達趕工前比較成本與工期效益。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **落後工項** — 篩選落後天數及影響里程碑的工項。
- **基準假設** — 設定工率、班次、空間及資源上限。
- **人力方案** — 模擬增班、加班與平行作業配置。
- **機具方案** — 配置吊運、施工設備與臨時設施。
- **成本工期** — 計算追回天數與各項增量成本。
- **方案決策** — 比較效益、風險及核准結果。

## 適合誰使用

- 專案經理
- 排程工程師
- 成本工程師

## 運作流程

1. 選定落後工項
2. 建立工率假設
3. 配置增援資源
4. 試算成本天數
5. 比較趕工方案
6. 核定追蹤成效

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
