# 生產工單管理

> 訂單轉工單、排產派工、現場回報到品檢入庫，一條龍把生產現場數位化。

生產工單管理把訂單、工單、派工、報工與品檢入庫整合到同一畫面，並用 AI 摘要現場狀況，讓生管專注處理例外。

**產業別：**生產製造　|　**系統類型：**MES 製造執行系統

## 功能模組

- **工單管理** — 訂單轉工單、拆併單與派發
- **排產派工** — 依產能與交期派工到產線
- **現場回報** — 報工、進度與異常即時回報
- **品檢入庫** — 檢驗判定、不良處置與入庫

## 適合誰使用

- 生管專員
- 製造課長
- 廠長

## 運作流程

1. 訂單轉工單
2. 排產派工
3. 領料開工
4. 報工回報
5. 品檢判定
6. 允收入庫

## 導入效益

- 工單建立工時：6小時/日 → **1.5小時/日**
- 準時交付率：80% → **94%**
- 現場進度延遲：40分鐘 → **10分鐘**
- 缺料停線次數：10次/月 → **3次/月**
