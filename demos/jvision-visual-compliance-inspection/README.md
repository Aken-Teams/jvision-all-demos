**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **巡檢批次中心** — 以門市、日期和巡檢類型管理預載照片批次及處理進度。
- **影像缺失複核** — 在照片上呈現模擬標記框、規則依據與信心值，供人工確認。
- **合規清單判定** — 逐項核對陳列、清潔、安全及品牌標準，記錄通過或缺失。
- **改善工單建立** — 把確認缺失轉成含期限、責任人及參考範例的改善任務。
- **改善前後複驗** — 並排比較預載的改善前後照片，完成複驗或要求再次處理。
- **門市風險分析** — 彙整門市、區域和缺失類型的合規趨勢及重複發生排行。

## 適合誰使用

- 稽核人員
- 區域督導
- 門市店長
- 品牌管理人員

## 運作流程

1. 建立巡檢批次
2. 複核影像標記
3. 完成合規判定
4. 指派改善任務
5. 比較照片複驗
6. 分析區域風險

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
