# 冷鏈溫控警示站

> 派車、追蹤、簽收到成本油耗的車隊管理

追蹤溫度、路線、簽收與異常告警。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**交通運輸　|　**系統類型：**TMS 運輸調度

## 功能模組

- **路線調度** — 派車與路線規劃
- **任務派車** — 任務指派與追蹤
- **即時追蹤** — GPS 定位與到貨
- **簽收回單** — 電子簽收與回單
- **成本油耗** — 油耗與成本分析
- **冷鏈溫控** — 溫度監控與告警

## 適合誰使用

- 冷鏈調度員
- 駕駛
- 品質人員
- 物流主管

## 運作流程

1. 待確認
2. 已派車
3. 行駛中
4. 到站完成

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：82% → **95%**
- 空車率：23% → **9.4%**
- 油耗異常反應：24小時 → **3.1小時**
