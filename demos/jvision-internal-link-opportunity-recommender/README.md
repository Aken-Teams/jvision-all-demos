**產業別：**業務銷售　|　**系統類型：**analytics-bi

## 功能模組

- **主題叢集地圖** — 將網站內容依實體、意圖與語意關聯組成主題叢集。
- **頁面權重分析** — 評估流量、外鏈、排名與既有內鏈形成的頁面權重。
- **連結機會推薦** — 找出來源頁、目標頁與適合插入連結的內容段落。
- **錨文字建議** — 生成自然且避免關鍵字過度重複的錨文字選項。
- **結構缺口診斷** — 辨識孤兒頁、過深頁面、權重斷點與主題競食。
- **CMS 發布批次** — 預覽修改、處理衝突並將核准連結送往 CMS。
