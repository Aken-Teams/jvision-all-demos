# 宮廟指定捐款履約台

> 協助宮廟管理信眾指定用於修繕、獎助學金、急難救助或特定法會的捐款，追蹤用途限制、核准支出、執行進度與公開徵信內容。

**產業別：**宗教服務　|　**系統類型：**finance-ledger

## 功能模組

- **募款專案** — 設定用途、期間與目標
- **指定入款** — 登錄捐款與用途限制
- **支出申請** — 提出用途與預算項目
- **核准憑證** — 檢查權限及佐證文件
- **專款餘額** — 查看承諾、支用與結餘
- **徵信摘要** — 整理可公開的收支成果

## 適合誰使用

- 宮廟財務
- 主任委員
- 監事

## 運作流程

1. 建立募款專案
2. 登錄指定捐款
3. 提出專款支出
4. 覆核用途憑證
5. 更新專款餘額
6. 發布徵信摘要

## 導入效益

- 活動籌備工時：20小時 → **5小時**
- 報名掌握率：65% → **94%**
- 物資盤點：6小時 → **1小時**
- 志工調度時效：3天 → **1天**
