# 寵物寄宿健康交接台

> 集中每隻寄宿寵物的飲食、用藥、排泄、行為與健康異常，依班次產生待辦與未完成警示，並保存通知飼主及送醫決策的完整時間軸。

集中每隻寄宿寵物的飲食、用藥、排泄、行為與健康異常，依班次產生待辦與未完成警示，並保存通知飼主及送醫決策的完整時間軸。

**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **寄宿檔案** — 記錄寵物辨識與禁忌
- **飲食計畫** — 安排餐次份量與特殊餐
- **用藥任務** — 管理藥名劑量與時間
- **健康觀察** — 記錄排泄行為及症狀
- **班次交接** — 移交待辦與關注事項
- **飼主通報** — 保存通知回覆與送醫決策

## 適合誰使用

- 寵物照護員
- 值班主管
- 門店客服

## 運作流程

1. 建立照護檔案
2. 排定照護任務
3. 執行日常照護
4. 回報健康異常
5. 完成班次交接
6. 通知飼主結案

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
