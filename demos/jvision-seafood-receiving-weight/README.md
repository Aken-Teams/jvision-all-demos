# 水產驗收扣冰磅差台

> 供水產加工廠把供應商箱數、地磅毛重、筐重、冰水扣重與分級淨重放在同一驗收批，當場確認計價重量並保留爭議依據。

供水產加工廠把供應商箱數、地磅毛重、筐重、冰水扣重與分級淨重放在同一驗收批，當場確認計價重量並保留爭議依據。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **到貨批次** — 查看魚種來源
- **雙磅登錄** — 記錄毛重空重
- **扣冰計算** — 套用筐冰扣除
- **分級回報** — 記錄尺寸淨重
- **差異判讀** — 比較票載實收
- **計價核准** — 鎖定付款重量

## 適合誰使用

- 原料驗收員
- 採購人員

## 運作流程

1. 車輛報到
2. 卸前過磅
3. 原料分級
4. 退筐複磅
5. 扣重核對
6. 付款放行

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
