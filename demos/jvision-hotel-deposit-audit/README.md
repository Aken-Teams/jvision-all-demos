**產業別：**餐飲旅宿　|　**系統類型：**finance-case

## 功能模組

- **押金台帳** — 彙整收款來源
- **住宿配對** — 連結房間訂單
- **扣款證據** — 附上損害消費
- **原路退回** — 核對退款工具
- **異常稽核** — 檢查重退漏退
- **押金結清** — 完成跨班交接

## 適合誰使用

- 前台出納
- 夜間稽核員
- 財務主管

## 運作流程

1. 收取押金
2. 配對住宿
3. 確認扣款
4. 試算應退
5. 覆核退款
6. 完成結清

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
