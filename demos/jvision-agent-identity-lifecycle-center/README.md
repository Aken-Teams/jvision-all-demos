# Agent 身分生命週期中心

> 治理 Agent 身分與服務憑證的建立、輪替及停用，消除共用帳號風險。

治理 Agent 身分與服務憑證的建立、輪替及停用，消除共用帳號風險。

**產業別：**資訊科技　|　**系統類型：**security-soc

## 功能模組

- **Agent 身分註冊** — 為每個 Agent 建立唯一主體、用途、擁有者與環境歸屬。
- **服務憑證簽發** — 依任務與工具範圍簽發短效金鑰、權杖或服務憑證。
- **憑證輪替排程** — 依效期、風險與使用狀態安排自動或人工輪替。
- **Agent 權限綁定** — 將 Agent 身分綁定最小權限角色、MCP 工具與資料範圍。
- **身分停用處置** — 在離役、異常或擁有者變更時撤銷身分與所有憑證。
- **共用帳號偵測** — 找出多 Agent 共用憑證、身分漂移與無主帳號風險。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 申請 Agent 身分
2. 審核權限邊界
3. 簽發專屬憑證
4. 監測身分使用
5. 核准憑證輪替
6. 停用 Agent 身分
