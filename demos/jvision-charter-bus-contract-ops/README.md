# 遊覽車包車履約台

> 供遊覽車業者管理企業與旅行社包車詢價、行程限制、車輛駕駛配置、出車文件及完班追加費，讓業務、調度與財務共用同一案件版本。

供遊覽車業者管理企業與旅行社包車詢價、行程限制、車輛駕駛配置、出車文件及完班追加費，讓業務、調度與財務共用同一案件版本。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **包車詢價** — 整理日期、人數與用車需求。
- **行程編排** — 管理停靠點、時程及版本。
- **車駕配置** — 指派合適車輛與駕駛。
- **出車檢核** — 確認名冊、文件與聯絡資訊。
- **異動控管** — 記錄行程變更及影響費用。
- **完班結算** — 核算超時、停車與追加項目。

## 適合誰使用

- 包車業務
- 車隊調度員
- 營運會計

## 運作流程

1. 受理需求
2. 建立行程
3. 配置車駕
4. 出車覆核
5. 登錄異動
6. 完成結算

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
