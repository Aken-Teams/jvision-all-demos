# 共同費用分攤審核台

> 管理總部、工務所與共用機具費用的分攤池、受益專案、動因及比例，提供試算、例外說明與核准歷程，避免沿用過時比例造成工程毛利失真。

管理總部、工務所與共用機具費用的分攤池、受益專案、動因及比例，提供試算、例外說明與核准歷程，避免沿用過時比例造成工程毛利失真。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **費用池管理** — 按費用性質建立總部、工地與機具池。
- **受益專案設定** — 維護納入或排除的工程及有效期間。
- **分攤動因試算** — 依工時、營收、面積或用量模擬結果。
- **毛利影響分析** — 比較分攤前後各專案成本與毛利。
- **例外調整說明** — 記錄比例覆寫、排除及一次性調整理由。
- **分攤批次審核** — 核准計算版本並鎖定入帳批次。

## 適合誰使用

- 成本會計
- 財務主管
- 專案經理

## 運作流程

1. 建立待分費用池
2. 確認受益專案
3. 選定分攤動因
4. 檢視毛利影響
5. 審核例外調整
6. 鎖定分攤入帳

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
