# 標案承諾履約追蹤器

> 把得標承諾轉為可執行里程碑、交付證據與驗收條件，避免履約漏項。

把得標承諾轉為可執行里程碑、交付證據與驗收條件，避免履約漏項。

**產業別：**專業服務　|　**系統類型：**construction-pm

## 功能模組

- **得標承諾拆解** — 從契約、服務建議書與議價紀錄擷取履約承諾。
- **履約里程碑編排** — 將承諾配置到時程、前置條件、負責人與交付日。
- **驗收條件矩陣** — 逐項對照交付物、品質標準、查驗方式與驗收人。
- **交付證據包** — 彙集成果文件、照片、簽核與系統紀錄供驗收使用。
- **漏項與逾期預警** — 偵測未指派承諾、缺少證據及可能延誤的里程碑。
- **履約變更核准** — 管理承諾變更、展延與替代交付方案的人工核准。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 解析得標承諾
2. 建立履約計畫
3. 定義驗收標準
4. 蒐集交付證明
5. 處置漏項風險
6. 核准履約結案

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
