# 標案資格硬門檻檢查器

> 逐條核驗標案硬性資格，及早排除證照、實績、財務或區域不合案件。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **資格條款拆解** — 從公告與附件辨識必要、排除及補正資格條款。
- **證照有效性檢查** — 核對證照類型、持有人、適用範圍與到期日期。
- **實績門檻驗證** — 驗證案型、金額、期間與驗收文件是否符合要求。
- **財務條件核算** — 檢查資本額、營收、納稅與信用等硬性財務門檻。
- **地區資格驗證** — 比對登記地、營業據點及在地服務等區域限制。
- **Go／No-Go 判** — 彙整逐條結果、缺口與信心，提交是否投標的核准。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 匯入資格文件
2. 拆解硬性條款
3. 核驗證照實績
4. 核算財務地區
5. 處理資格缺口
6. 核准投標判定
