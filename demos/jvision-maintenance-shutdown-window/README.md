協助工廠在年度歲修前整合設備停機範圍、工項依存、承商人力、隔離條件、備料狀態與復機驗收，降低窗口超時及未完成工項影響生產的風險。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **停機範圍** — 定義設備邊界、窗口時間及受影響的生產區域。
- **工項依存** — 排列拆卸、檢修、測試與復機的前後關係。
- **準備度檢核** — 檢查備件、工具、承商與技術文件是否到位。
- **隔離計畫** — 規劃能源隔離、作業許可及安全確認點。
- **窗口戰情** — 依關鍵路徑更新工項進度、延誤與替代方案。
- **復機驗收** — 管理試運轉、品質確認、交機及遺留事項。

## 適合誰使用

- 維修計畫員
- 設備主管
- 工安人員

## 運作流程

1. 界定停機範圍
2. 編排工項依存
3. 確認施工準備
4. 核定安全隔離
5. 管制窗口進度
6. 完成復機驗收

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
