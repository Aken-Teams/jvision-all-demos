# 瀝青鋪築工作面管制台

> 供道路工程依鋪築工作面整合刨除範圍、黏層準備、料車批次、攤鋪碾壓及接縫處理紀錄，連結當日數量與異常區段，讓監造可快速判定工作面是否完成。

供道路工程依鋪築工作面整合刨除範圍、黏層準備、料車批次、攤鋪碾壓及接縫處理紀錄，連結當日數量與異常區段，讓監造可快速判定工作面是否完成。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **工作面配置** — 依樁號、車道、層別與預定數量切分區段。
- **鋪前整備** — 確認刨除、清掃、黏層及人孔調整狀態。
- **料車批次** — 記錄出廠、到場、卸料時間與載運數量。
- **攤鋪碾壓** — 登錄攤鋪機、壓路機與各階段作業時間。
- **異常區段** — 標註離析、接縫、厚度或平整度疑義位置。
- **數量簽認** — 彙整鋪築面積、重量、退料及監造認列。

## 適合誰使用

- 道路工程師
- 鋪面工地主任
- 監造工程師

## 運作流程

1. 劃定鋪築工作面
2. 完成鋪前整備
3. 登錄料車批次
4. 記錄鋪築節拍
5. 處理異常區段
6. 簽認完成數量

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
