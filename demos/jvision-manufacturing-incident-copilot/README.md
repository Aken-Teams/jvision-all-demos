# 製造異常智慧協作助手

> 提供製造現場異常通報、知識查詢、處置建議與跨部門協作的一站式智慧助手，以擬真假資料模擬對話式問答及案件處理，協助人員快速理解狀況、引用標準程序、分派任務並完成交班與結案。

**產業別：**生產製造　|　**系統類型：**service-desk

## 功能模組

- **現場異常通報** — 以引導式表單登錄異常現象、位置、影響與擬真附件。
- **智慧處置助手** — 透過對話介面摘要問題並提供分步處置與安全提醒。
- **知識案例搜尋** — 搜尋標準作業程序、故障知識及歷史相似異常案例。
- **協作指揮中心** — 顯示處理時間軸、參與部門、任務分工及最新進度。
- **處置任務看板** — 管理負責人、優先級、期限、檢查項目與任務完成狀態。
- **交班結案摘要** — 自動整理事件經過、處置結果、未完成事項與交班重點。

## 適合誰使用

- 現場作業員
- 班組長
- 製程工程師
- 設備工程師
- 生產主管

## 運作流程

1. 通報現場異常
2. 取得處置建議
3. 查找處理依據
4. 啟動跨部門協作
5. 執行處置任務
6. 完成交班結案

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
