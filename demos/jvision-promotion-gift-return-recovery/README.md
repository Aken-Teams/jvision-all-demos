# 促銷贈品退貨追收台

> 處理主商品退貨時贈品應退、折價扣回與缺件追收，依活動版本還原顧客取得資格，提供客服試算、倉庫收件及財務退款一致的處置依據。

處理主商品退貨時贈品應退、折價扣回與缺件追收，依活動版本還原顧客取得資格，提供客服試算、倉庫收件及財務退款一致的處置依據。

**產業別：**零售電商　|　**系統類型：**operations-console

## 功能模組

- **贈品關聯** — 查看主商品與贈品組合
- **活動還原** — 讀取下單時規則版本
- **退款試算** — 計算退贈或扣回金額
- **收件確認** — 核對贈品品項與狀態
- **顧客追收** — 記錄通知及補寄安排
- **退款結案** — 放行退款並封存依據

## 適合誰使用

- 客服人員
- 退貨倉管
- 財務人員

## 運作流程

1. 辨識關聯
2. 還原規則
3. 提出方案
4. 確認收回
5. 處理缺件
6. 完成退款

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
