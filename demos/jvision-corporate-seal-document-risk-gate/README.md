# 印鑑法律文件風險閘門

> 將用印申請、法律文件審查、授權層級、印鑑保管與取用紀錄整合為一道風險閘門，依文件類型、金額、交易對象及異常條件決定審核路徑，避免未授權用印、錯版文件及高風險承諾直接生效。

將用印申請、法律文件審查、授權層級、印鑑保管與取用紀錄整合為一道風險閘門，依文件類型、金額、交易對象及異常條件決定審核路徑，避免未授權用印、錯版文件及高風險承諾直接生效。

**產業別：**企業協作　|　**系統類型：**legal-case

## 功能模組

- **用印申請中心** — 建立文件類型、交易背景、金額、份數與用印需求。
- **文件版本檢查** — 確認附件完整性、定稿版本、頁數與關鍵欄位差異。
- **風險規則閘門** — 依金額、對象、條款及異常訊號決定風險和流程。
- **授權簽核路徑** — 顯示各風險層級所需的法務、財務與主管核准。
- **印鑑取用作業** — 核對印鑑種類、保管人、核准條件及模擬取用紀錄。
- **法律文件稽核簿** — 查詢申請、版本、意見、核准、用印及歸檔歷程。

## 適合誰使用

- 用印申請人
- 企業法務
- 部門主管
- 印鑑保管人

## 運作流程

1. 提出用印申請
2. 核對文件版本
3. 執行風險判定
4. 完成授權簽核
5. 執行印鑑取用
6. 歸檔稽核紀錄

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
