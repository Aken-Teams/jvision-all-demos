# 資料複製與擴散雷達

偵測敏感資料流入沙箱、個人空間與試算表的非預期複製，控制影子資料。

**產業別：**數據分析　|　**系統類型：**security-soc

## 功能模組

- **敏感資料指紋** — 建立個資、財務與機密欄位的內容及結構指紋。
- **副本擴散掃描** — 掃描沙箱、檔案區、試算表與臨時資料庫中的相似副本。
- **複製路徑還原** — 重建資料從受管來源流向非受管位置的傳播路徑。
- **持有人與用途辨識** — 關聯帳號、團隊、查詢活動與副本的宣稱用途。
- **外流風險分級** — 依敏感度、暴露面、保存期與存取權限排序風險。
- **副本控管處置** — 提出遮罩、收權、隔離、到期或安全刪除方案。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 建立敏感指紋
2. 掃描潛在副本
3. 還原擴散路徑
4. 評估暴露風險
5. 核准控管措施
6. 確認副本收斂

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
