# 平台通路結算核對台

> 協助品牌電商逐期核對各平台訂單、退貨、抽成、廣告費、物流費與實際撥款，將差異分派給營運或財務查核，避免漏收貨款及人工試算造成月結延誤。

協助品牌電商逐期核對各平台訂單、退貨、抽成、廣告費、物流費與實際撥款，將差異分派給營運或財務查核，避免漏收貨款及人工試算造成月結延誤。

**產業別：**零售電商　|　**系統類型：**finance-ledger

## 功能模組

- **結算總覽** — 查看各平台待收與已撥款。
- **訂單配對** — 比對訂單、退貨及撥款明細。
- **費率規則** — 維護抽成與活動分攤條件。
- **差異調查** — 分類短撥、溢撥與未知扣款。
- **覆核工作** — 分派差異並追蹤處理證據。
- **入帳摘要** — 產生通路結算與會計摘要。

## 適合誰使用

- 電商財務
- 通路營運
- 會計主管

## 運作流程

1. 彙整結算批次
2. 配對訂單撥款
3. 套用費率規則
4. 調查結算差異
5. 完成主管覆核
6. 產生入帳摘要

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
