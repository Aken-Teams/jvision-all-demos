# 校務排課資源最佳化器

> 將模擬班級課程、教師專長、可授時段、教室容量與設備需求轉為可檢查的排課條件，自動產生多套候選課表，協助校務人員比較衝突、資源利用與公平性並處理臨時調課。

**產業別：**教育　|　**系統類型：**operations-console

## 功能模組

- **排課條件中心** — 管理班級、師資、時段、連堂與不可排等模擬限制。
- **空間資源盤點** — 呈現教室容量、設備、可用時段與維護停用狀態。
- **師資負荷配置** — 比較教師專長、授課時數、偏好與跨校區移動負荷。
- **候選課表生成** — 展示多套模擬課表及其衝突、利用率與公平性分數。
- **衝突調整工作台** — 以拖放與交換情境處理班級、教師及教室衝突。
- **臨時異動中心** — 模擬教師請假或教室停用，產生代課與換室建議。

## 適合誰使用

- 教務排課人員
- 系所助理
- 教務主任
- 教師

## 運作流程

1. 設定排課條件
2. 確認空間供給
3. 平衡師資負荷
4. 比較候選課表
5. 解決排課衝突
6. 處理臨時異動

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
