# EAP（Equipment Automation Program，設備自動化整合平台）

> 保養、維修、預兆到備品的設備全生命週期

EAP（Equipment Automation Program，設備自動化整合平台）提供設備自動化指令下達、製程資料自動回傳、配方自動下載。設備工程依「MES指令下達 → EAP轉譯 → 設備執行 → 製程數據回傳 → MES記錄比對」推進作業，優先解決「設備與MES資料需人工輸入」，製造工程則以自動化涵蓋率與配方錯誤率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**設備維護　|　**系統類型：**CMMS 設備維護

## 功能模組

- **保養排程** — 預防保養自動排程
- **維修工單** — 報修、派工與完工
- **預兆診斷** — 設備數據異常預警
- **備品管理** — 備品庫存與領用
- **OEE 稼動** — 稼動與故障分析
- **履歷追溯** — 設備維護履歷

## 適合誰使用

- 設備工程
- 製造工程
- 資訊部門

## 運作流程

1. 待派工
2. 維修中
3. 試車確認
4. 復機完成

## 導入效益

- 非計畫停機：24小時/月 → **6.2小時/月**
- 保養準時率：75% → **99%**
- 備品缺料：10次/月 → **1.9次/月**
- 故障排除時間：94分鐘 → **24分鐘**
