# 營運車停車罰單申覆台

> 將營運車停車罰單與派車任務、裝卸證明、臨停許可及駕駛說明配對，判斷公司或駕駛責任，控管申覆期限並完成繳款、扣回或撤銷。

將營運車停車罰單與派車任務、裝卸證明、臨停許可及駕駛說明配對，判斷公司或駕駛責任，控管申覆期限並完成繳款、扣回或撤銷。

**產業別：**交通運輸　|　**系統類型：**legal-case

## 功能模組

- **罰單收件** — 登錄車號違規與期限
- **任務配對** — 連結當時班次與裝卸點
- **證據蒐集** — 整理許可照片與客戶證明
- **責任判定** — 裁定營運需要或駕駛責任
- **申覆送件** — 產出理由與附件清單
- **結果結算** — 處理撤銷繳款與扣回

## 適合誰使用

- 車管人員
- 駕駛主管
- 法務人員

## 運作流程

1. 登錄罰單
2. 配對任務
3. 蒐集證據
4. 判定責任
5. 提出申覆
6. 完成結算

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
