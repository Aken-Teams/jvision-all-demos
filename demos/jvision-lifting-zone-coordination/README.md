# 塔吊吊運衝突協調台

> 彙整各工班塔吊申請的吊物、重量、吊點、路徑與時段，檢查雙機作業、吊運禁區及樓層卸料面衝突，排定每日吊運序列並處理臨時插單。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **吊運看板** — 按塔吊與時段呈現排程、負荷及禁區。
- **需求申請** — 登錄吊物重量、尺寸、吊點及目標樓層。
- **路徑檢核** — 檢查吊重能力、迴轉交集和地面管制區。
- **序列排程** — 依工序優先級與吊次時間安排作業。
- **衝突重排** — 處理雙機衝突、延誤、插單及天候停吊。
- **績效回顧** — 分析等待、空吊、取消與各工班使用量。

## 適合誰使用

- 塔吊調度員
- 吊掛作業主管
- 施工工程師

## 運作流程

1. 吊運看板
2. 需求申請
3. 路徑檢核
4. 序列排程
5. 衝突重排
6. 績效回顧

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
