# 深開挖支撐軸力研判台

> 整合深開挖各階段的支撐配置、軸力觀測紀錄、警戒值判讀與異常處置，協助工地主任及監造掌握開挖面變化、追蹤補強決議，並留下可供會議與查驗使用的完整歷程。

整合深開挖各階段的支撐配置、軸力觀測紀錄、警戒值判讀與異常處置，協助工地主任及監造掌握開挖面變化、追蹤補強決議，並留下可供會議與查驗使用的完整歷程。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **開挖階段圖** — 依樓層與開挖深度呈現支撐架設及拆除順序。
- **軸力讀值簿** — 登錄測點數值、量測時間、位置與資料來源。
- **趨勢研判** — 比較基準值、警戒值、行動值及近期變化斜率。
- **超限處置** — 建立停挖、加撐、卸載或加密觀測等處置。
- **技師覆核** — 彙整判讀依據與附件供專業技師確認。
- **續挖放行** — 確認處置完成後核發下一階段施工許可。

## 適合誰使用

- 工地主任
- 監造工程師
- 大地技師

## 運作流程

1. 配置階段
2. 登錄讀值
3. 判讀趨勢
4. 指派處置
5. 覆核結果
6. 核准續挖

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
