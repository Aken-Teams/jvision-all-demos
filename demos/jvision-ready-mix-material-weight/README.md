# 預拌原料磅差驗收台

> 供預拌廠逐車核對砂石、水泥與飛灰的供應商票重、廠內雙磅、含水率及卸料倉，當班處理短交、濕砂虛重與卸錯倉爭議。

供預拌廠逐車核對砂石、水泥與飛灰的供應商票重、廠內雙磅、含水率及卸料倉，當班處理短交、濕砂虛重與卸錯倉爭議。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **進料車次** — 查看物料供應商
- **進出雙磅** — 計算實卸重量
- **含水扣重** — 換算乾料重量
- **料倉確認** — 防止卸錯料倉
- **磅差處理** — 建立短交爭議
- **驗收結算** — 鎖定應付數量

## 適合誰使用

- 地磅人員
- 原料採購

## 運作流程

1. 進廠過磅
2. 取樣檢驗
3. 指定料倉
4. 卸後複磅
5. 乾重核算
6. 付款核准

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
