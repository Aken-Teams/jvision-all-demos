# 分區完工移交驗收台

> 針對大型工地分棟、分樓層或分系統辦理階段性完工移交，整合契約範圍、測試紀錄、缺失清單、備品文件與保管責任，讓已完成區域可正式交給業主或營運單位。

針對大型工地分棟、分樓層或分系統辦理階段性完工移交，整合契約範圍、測試紀錄、缺失清單、備品文件與保管責任，讓已完成區域可正式交給業主或營運單位。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **移交區域** — 定義分區邊界與契約範圍。
- **條件盤點** — 列出測試、缺失、清潔與文件要求。
- **資料備件** — 彙整操作文件、圖說及測試紀錄。
- **聯合會勘** — 記錄現況、缺失及保留事項。
- **責任移交** — 簽認保管、維護及進出管制責任。
- **保留結案** — 追蹤移交後尚待完成的事項。

## 適合誰使用

- 驗收工程師
- 業主代表
- 營運接管人員

## 運作流程

1. 劃定區域
2. 盤點條件
3. 彙整文件
4. 聯合會勘
5. 簽認移交
6. 關閉保留

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
