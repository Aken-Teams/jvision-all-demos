# 建案銷售追客艙

> 進度、日報、品安到估價成本的工程管理

房地產 CRM 集中管理潛在客戶、買方與屋主需求，從帶看回饋、方案報價一路追蹤到成交交接，避免重要承諾散落在通訊軟體。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**營建工程　|　**系統類型：**營建工程管理

## 功能模組

- **工程進度** — WBS 排程與進度追蹤
- **工地日報** — 日報、人機料回報
- **品質安衛** — 巡檢與缺失改善
- **估價發包** — 估價、發包與計價
- **成本控管** — 預算、實支與請款
- **現場紀錄** — 照片與文件留存

## 適合誰使用

- 房仲業務

## 運作流程

1. 待釐清
2. 現場處理
3. 待查驗
4. 計價完成

## 導入效益

- 日報彙整工時：3.1小時/日 → **0.5小時/日**
- 進度落後預警：42% → **94%**
- 估驗計價天數：9.6天 → **3.8天**
- 缺失改善時效：7天 → **2天**
