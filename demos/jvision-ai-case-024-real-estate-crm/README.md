# 建案銷售追客艙

> 從來客登記、戶別銷控到議價成交與交屋的建案銷售管理

建案銷售追客艙集中管理接待中心的來客登記、客戶需求與戶別銷控，從帶看跟進、議價成交一路追蹤到簽約與交屋，避免重要承諾散落在通訊軟體。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**營建工程　|　**系統類型：**建案銷售管理

## 功能模組

- **銷售總覽** — 銷售KPI、去化率與業績戰報
- **戶別銷控** — 樓層戶別銷控表與價格牌
- **來客追蹤** — 來客登記、需求配對與客戶分級
- **帶看跟進** — 帶看排程、跟進提醒與熱度追蹤
- **成交簽約** — 議價、訂簽開與合約進度
- **業績目標** — 個人與案場業績目標達成

## 適合誰使用

- 銷售代表
- 案場主管
- 貸款交屋專員

## 運作流程

1. 來客登記
2. 需求配對推案
3. 帶看跟進
4. 議價成交
5. 簽約與交屋

## 導入效益

- 來客回追工時：2.8小時/日 → **0.4小時/日**
- 銷控更新即時率：46% → **96%**
- 帶看轉成交天數：21天 → **12天**
- 逾期跟進件數：18件 → **4件**
