**產業別：**企業協作　|　**系統類型：**analytics-bi

## 功能模組

- **圖譜建模畫布** — 定義人、事件、資產、規則等節點類型與關係結構。
- **實體辨識工坊** — 從文件、郵件、會議與工單辨識候選企業實體。
- **關係推導器** — 推導任職、參與、依據、影響與隸屬等語意關係。
- **實體消歧中心** — 合併同名異寫實體，拆分同名不同人或不同物件。
- **圖譜探索器** — 以互動網路探索節點鄰居、關係路徑與影響範圍。
- **關係發布審核** — 審查低信心與敏感關係後發布為可推理的正式圖譜。

## 適合誰使用

- 知識工作者
- 主管
- 客服

## 運作流程

1. 設計圖譜模型
2. 抽取候選實體
3. 建立候選關係
4. 消歧合併實體
5. 驗證推理路徑
6. 審核發布圖譜
