# 集團關係企業管理系統

> 把分散數據變成可下鑽、可決策的經營洞察

集團關係企業管理系統提供集團組織架構與持股比例圖、關係人交易登錄與檢核、轉投資效益分析。財務部依「組織架構更新 → 關係人交易登錄 → 交易合理性檢核 → 轉投資效益分析 → 法定文件產出 → 申報揭露」推進作業，優先解決「集團架構複雜、持股關係不易掌握」，法務部則以關係人交易揭露完整率與法定申報準時率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**經營管理　|　**系統類型：**BI 商業智慧

## 功能模組

- **經營儀表板** — 關鍵指標即時總覽
- **趨勢分析** — 多維度趨勢與比較
- **指標下鑽** — 逐層鑽取到明細
- **平衡計分卡** — 策略目標與 KPI 對齊
- **AI 洞察** — 自動發現異常與機會
- **報表匯出** — 排程報表與分享

## 適合誰使用

- 財務部
- 法務部
- 稽核室

## 運作流程

1. 待釐清
2. 改善中
3. 核定確認
4. 已解除
