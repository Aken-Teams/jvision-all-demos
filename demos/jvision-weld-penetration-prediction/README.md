# 焊接熔深品質預測系統

> 運用既有焊接參數與抽檢資料模擬預測熔深、熔寬及未熔合風險，提供條件試算、批次比較與預測依據說明，協助工程師在投產前評估品質窗口並降低破壞性抽驗成本。

運用既有焊接參數與抽檢資料模擬預測熔深、熔寬及未熔合風險，提供條件試算、批次比較與預測依據說明，協助工程師在投產前評估品質窗口並降低破壞性抽驗成本。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **熔深風險總覽** — 查看料號、產線與配方的預測分布、超限風險及待評估案件。
- **焊接條件試算** — 調整電流、電壓、速度與板厚，模擬熔深及熔寬結果。
- **品質窗口分析** — 以圖表呈現可接受參數區間及偏離窗口的風險程度。
- **相似案例比對** — 搜尋相近材質、接頭與參數的歷史抽檢結果供決策參考。
- **抽驗計畫管理** — 依預測風險安排截面試驗樣本、檢驗項目與負責人。
- **預測報告中心** — 彙整輸入條件、預測結果、影響因子與工程審核意見。

## 適合誰使用

- 焊接製程工程師
- 研發工程師
- 品質主管

## 運作流程

1. 盤點熔深風險
2. 試算焊接條件
3. 確認品質窗口
4. 比對歷史案例
5. 安排風險抽驗
6. 審核預測報告

## 導入效益

- 報表產出工時：16小時 → **1小時**
