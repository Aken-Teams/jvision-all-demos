**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **陳情總覽** — 呈現新案、逾期及重複陳情分布。
- **案件受理** — 登錄來電人、門牌、時段與問題描述。
- **工項查證** — 對照陳情時段、位置與當時施工活動。
- **責任派處** — 指派工班、改善措施及完成期限。
- **聯絡歷程** — 記錄說明、承諾與住戶回應。
- **改善結案** — 覆核改善證據並完成正式回覆。

## 適合誰使用

- 工地主任
- 敦親睦鄰人員
- 現場工程師

## 運作流程

1. 掌握陳情態勢
2. 建立陳情案件
3. 比對施工來源
4. 派發改善任務
5. 回覆處理進度
6. 覆核改善結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
