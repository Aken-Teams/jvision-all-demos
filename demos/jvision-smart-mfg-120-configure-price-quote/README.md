# CPQ智慧站

針對客製化程度高的電子產品，整合規格配置、定價規則與報價產出，確保複雜產品報價快速且正確。

- 原始系統：CPQ（Configure-Price-Quote）
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、業務工程(SE)、產品部、財務部
- 工作流程：選擇產品類型→配置規格選項→系統自動定價與相容性檢查→產出報價→核准發送
- AI 應用：智慧推薦最適配置組合、異常配置/報價自動偵測
- 主要 KPI：報價產出時效、配置錯誤率、報價轉單率、平均客製化週期
- 代表產品：Salesforce CPQ、Oracle CPQ、SAP CPQ、PROS Smart CPQ
