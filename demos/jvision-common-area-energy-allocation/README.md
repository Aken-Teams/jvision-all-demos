# 公設能耗費用分攤台

> 依空調、電梯、照明等公設設備的使用時段與租戶面積分攤能耗費，處理延長空調、空置及進退場，提供透明計算底稿。

依空調、電梯、照明等公設設備的使用時段與租戶面積分攤能耗費，處理延長空調、空置及進退場，提供透明計算底稿。

**產業別：**房地產與物業　|　**系統類型：**esg-energy

## 功能模組

- **能耗費用池** — 彙整各公設設備成本。
- **租戶基礎** — 管理面積、樓層與佔用期。
- **延時使用** — 記錄加開空調與特殊時段。
- **分攤模型** — 設定面積、時數與固定比例。
- **例外覆核** — 審查空置與特殊減免。
- **租戶明細** — 發布設備別計算底稿。

## 適合誰使用

- 物業會計
- 機電主管
- 租戶服務

## 運作流程

1. 彙整成本
2. 確認租戶
3. 登錄延時
4. 執行分攤
5. 覆核例外
6. 發布明細

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
