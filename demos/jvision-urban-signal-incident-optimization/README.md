# 城市號誌事件協同平台

> 以模擬路況、號誌週期與道路事件資料建立城市交通指揮介面，協助交控人員辨識壅塞成因、比較號誌調整方案、協調事件處置，並以情境回放檢視旅行時間與路網恢復成效。

以模擬路況、號誌週期與道路事件資料建立城市交通指揮介面，協助交控人員辨識壅塞成因、比較號誌調整方案、協調事件處置，並以情境回放檢視旅行時間與路網恢復成效。

**產業別：**交通運輸　|　**系統類型：**operations-console

## 功能模組

- **路網態勢地圖** — 呈現模擬壅塞熱區、路口服務水準與主要幹道流向。
- **號誌策略工作台** — 比較週期、時相與綠燈帶方案對路網指標的預估影響。
- **交通事件中心** — 集中顯示事故、施工、積水與活動等模擬事件及影響範圍。
- **協同調度看板** — 分派交控、警政與工程處置任務，追蹤回報與相依事項。
- **情境模擬比較** — 並列基準與多套應變方案，評估延滯、排隊及外溢風險。
- **事件回放分析** — 依時間軸重現號誌調整與處置節點，檢討恢復成效。

## 適合誰使用

- 交通控制員
- 號誌工程師
- 事件調度員
- 交控中心主管

## 運作流程

1. 掌握路網態勢
2. 設計號誌策略
3. 確認事件影響
4. 協調處置任務
5. 比較應變方案
6. 回放檢討績效

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
