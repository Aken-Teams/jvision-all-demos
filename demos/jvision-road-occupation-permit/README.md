# 道路占用施工許可台

> 管理吊裝、灌漿、管線接駁等需占用道路的申請範圍、交維配置、許可期限、通知事項與復舊查驗，避免工程車到場後才發現許可未核准或管制條件不符。

管理吊裝、灌漿、管線接駁等需占用道路的申請範圍、交維配置、許可期限、通知事項與復舊查驗，避免工程車到場後才發現許可未核准或管制條件不符。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **占用需求** — 登錄路段、面積、工法與施工日期。
- **交維配置** — 呈現圍設、改道及行人動線。
- **申請文件** — 彙整計畫、圖說與相關證明。
- **審查追蹤** — 管理送件、補正與核准條件。
- **施工窗口** — 同步許可期限與現場排程。
- **撤場復舊** — 記錄設施撤除及路面查驗。

## 適合誰使用

- 工地總務
- 交維承辦人
- 施工主管

## 運作流程

1. 提出需求
2. 配置交維
3. 彙整送件
4. 追蹤核准
5. 執行管制
6. 完成復舊

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
