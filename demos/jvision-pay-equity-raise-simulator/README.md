# 薪酬公平調薪模擬台

> 分析職級、職務、年資、績效與薪資分布，找出同工不同酬、薪資倒掛及留才風險，並以可解釋的情境模擬不同調薪預算與分配規則，協助企業在成本、績效和公平性之間做出一致且可追溯的決策。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **薪酬公平總覽** — 呈現各職級、部門與族群的薪資分布及公平指標。
- **同職薪資分析** — 比較相近職務與條件員工的薪資差距和離群點。
- **薪資異常清單** — 列出薪資倒掛、低於區間及疑似不合理差距個案。
- **調薪規則設計** — 設定預算、績效權重、最低增幅與薪資區間限制。
- **情境模擬比較** — 並列多套調薪方案的成本、公平與留才影響。
- **校準核定中心** — 提供主管調整、理由註記、審核狀態及核定摘要。

## 適合誰使用

- 薪酬人資
- 部門主管
- 人資長
- 財務主管

## 運作流程

1. 檢視薪酬結構
2. 辨識公平異常
3. 建立調薪規則
4. 模擬多套方案
5. 進行主管校準
6. 完成調薪核定

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
