# 殯儀設施檔期管理台

> 供殯葬服務業者統籌禮廳、冰存位、火化時段、接體車與工作人員檔期，依案件儀式需求檢查資源衝突並管理預留、候補及異動通知。

供殯葬服務業者統籌禮廳、冰存位、火化時段、接體車與工作人員檔期，依案件儀式需求檢查資源衝突並管理預留、候補及異動通知。

**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **設施日曆** — 查看禮廳與冰存空檔
- **車輛排程** — 安排接體及送行車輛
- **人員班表** — 配置禮儀與場務人員
- **案件預留** — 保留時段與需求資源
- **異動候補** — 處理換期及候補順位
- **就緒確認** — 檢查儀式前資源狀態

## 適合誰使用

- 禮儀主管
- 場務人員
- 案件承辦

## 運作流程

1. 查詢檔期
2. 預留設施
3. 配置車輛
4. 安排人力
5. 處理異動
6. 確認就緒

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
