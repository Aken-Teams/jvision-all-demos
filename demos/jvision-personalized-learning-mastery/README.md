# 個人學習精熟診斷平台

> 依模擬作答、課程進度與能力標籤建立個人知識圖譜，診斷概念精熟度與先備缺口，為每位學習者安排可調整的內容、練習及複習路徑，並讓教師檢視介入前後的學習變化。

依模擬作答、課程進度與能力標籤建立個人知識圖譜，診斷概念精熟度與先備缺口，為每位學習者安排可調整的內容、練習及複習路徑，並讓教師檢視介入前後的學習變化。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **能力圖譜總覽** — 以概念節點呈現個人精熟程度、先備關係與待補缺口。
- **精熟診斷報告** — 依模擬作答證據分析穩定掌握、猜測、遺忘與迷思概念。
- **學習路徑規劃** — 排列教材、練習與複習任務，說明推薦原因及預期目標。
- **今日學習任務** — 提供學生可執行的單日學習清單、時間估計與完成回饋。
- **教師調整中心** — 讓教師替換內容、鎖定必修節點並設定補救或進階條件。
- **成長證據分析** — 比較診斷前後的精熟曲線、錯誤類型與介入成效。

## 適合誰使用

- 學生
- 授課教師
- 教學設計師
- 課程主管

## 運作流程

1. 檢視能力圖譜
2. 閱讀診斷證據
3. 建立個人路徑
4. 完成今日任務
5. 調整學習安排
6. 檢討學習成長

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
