# 技能供需情境模擬器

> 模擬招募、培訓、外包與自動化組合，量化技能缺口與人才投資回報。

模擬招募、培訓、外包與自動化組合，量化技能缺口與人才投資回報。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **技能供需基線** — 對照策略工作量、現有人才與技能熟練度建立缺口基線。
- **招募補位模擬** — 試算職缺數、到職時間、薪資與招募成功率。
- **培訓轉能模擬** — 估算學習路徑、轉能週期、完訓率與生產力爬坡。
- **外包產能模擬** — 評估供應商產能、交付風險、知識留存與採購成本。
- **自動化替代模擬** — 判斷可自動化任務、釋放工時及所需的人機協作技能。
- **人才組合最佳化** — 依成本、速度與風險排序混合策略並建立投資組合。

## 適合誰使用

- L&D 主管
- 部門主管
- 員工

## 運作流程

1. 設定技能需求
2. 模擬招募補位
3. 模擬內部轉能
4. 模擬外包產能
5. 模擬自動化替代
6. 決定人才投資

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
