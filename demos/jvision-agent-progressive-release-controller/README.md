**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **候選版本登錄** — 登錄模型、提示詞、工具、權限與設定的版本差異。
- **發布分群設計** — 按部門、角色、任務風險與資料敏感度建立發布群組。
- **流量階梯編排** — 設定各階段流量比例、觀察時間與晉級條件。
- **護欄指標監測** — 追蹤成功率、人工接管、成本、延遲與政策違規。
- **自動暫停回退** — 觸發門檻時停止擴量並切回穩定版本。
- **全量發布裁定** — 彙整各群組結果，核准擴量、延長觀察或終止發布。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 登錄候選版本
2. 劃分發布群組
3. 設定流量階梯
4. 監測護欄指標
5. 處理暫停回退
6. 裁定全面發布
