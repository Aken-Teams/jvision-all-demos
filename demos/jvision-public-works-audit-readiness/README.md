# 公共工程查核備戰台

> 依公共工程施工查核構面整理品質文件、進度數據、現場狀況與簡報證據，透過模擬查核列出不一致及待改善事項，分派期限並保留複查結果，降低正式查核失分。

依公共工程施工查核構面整理品質文件、進度數據、現場狀況與簡報證據，透過模擬查核列出不一致及待改善事項，分派期限並保留複查結果，降低正式查核失分。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **查核構面總覽** — 按品質、進度、職安、環境及文件呈現整備度。
- **備查證據庫** — 連結計畫書、紀錄、照片、試驗與核定文件。
- **一致性檢核** — 比對簡報數字、表單版本與現場實際狀況。
- **模擬查核** — 依查核路線記錄抽問、抽件及現場發現。
- **改善戰情板** — 分派文件補正、現場整理及制度改善事項。
- **簡報備查包** — 凍結簡報、佐證索引、陪檢分工與應答提示。

## 適合誰使用

- 品管主管
- 工地主任
- 公共工程承辦人

## 運作流程

1. 界定查核範圍
2. 盤點備查證據
3. 檢查資料一致
4. 執行模擬查核
5. 完成缺口改善
6. 凍結備查版本

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
