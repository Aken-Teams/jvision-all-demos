# LLM 延遲剖析台

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **請求瀑布剖析** — 以時間軸拆解一次請求的完整處理階段。
- **排隊時間診斷** — 分析併發、限流、區域與供應商造成的等待。
- **檢索延遲分析** — 拆解嵌入、查詢、重排與文件讀取時間。
- **首 Token 監測** — 比較模型、提示長度與負載下的首 Token 時間。
- **工具呼叫耗時** — 追蹤各工具執行、重試、網路與序列化延遲。
- **瓶頸改善案件** — 依門檻建立優化案件並驗證改善前後差異。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 選取慢速請求
2. 檢視請求瀑布
3. 診斷排隊檢索
4. 比較首 Token
5. 追查工具耗時
6. 驗證改善結案

- 系統可用率：97% → **99%**
