# 光學誤報自動過濾台

> 針對自動光學檢測（AOI）產生但實際非缺陷的 False Call 誤報，提供規則與模型建議、批次過濾、人工覆核及效果比較，協助品保人員降低無效判讀量，同時避免真正缺陷被錯誤排除。

針對自動光學檢測（AOI）產生但實際非缺陷的 False Call 誤報，提供規則與模型建議、批次過濾、人工覆核及效果比較，協助品保人員降低無效判讀量，同時避免真正缺陷被錯誤排除。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **誤報營運總覽** — 掌握誤報量、過濾率、人工覆判量與風險提醒。
- **誤報候選佇列** — 依產品、站點與信心值檢視待處理候選項目。
- **過濾策略設定** — 組合閾值、缺陷類型與區域條件，預覽策略影響。
- **批次過濾作業** — 模擬套用策略並比較保留、排除與待確認結果。
- **高風險覆核** — 集中檢查可能誤刪真缺陷的低信心排除項目。
- **過濾成效分析** — 比較策略版本的減量效果、風險與班別差異。

## 適合誰使用

- AOI 覆判員
- 品保工程師
- 製程工程師

## 運作流程

1. 盤點誤報現況
2. 篩選候選項目
3. 建立過濾策略
4. 執行批次過濾
5. 複核高風險項目
6. 評估策略成效

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
