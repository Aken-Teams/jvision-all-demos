# 關係企業往來對帳台

> 協助集團財會逐期核對關係企業間的銷貨、採購、代墊、借款與利息餘額，辨識幣別、期間及文件差異，指派對方公司確認並形成結帳沖銷依據。

協助集團財會逐期核對關係企業間的銷貨、採購、代墊、借款與利息餘額，辨識幣別、期間及文件差異，指派對方公司確認並形成結帳沖銷依據。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **公司關係** — 設定交易雙方與對帳窗口
- **交易配對** — 比對發票、代墊與資金往來
- **差異分類** — 辨識匯率、期間及科目差異
- **雙邊確認** — 指派差異並記錄對方回覆
- **調整建議** — 建立重分類與補入帳方案
- **期末鎖定** — 確認餘額並輸出沖銷依據

## 適合誰使用

- 集團會計
- 子公司會計
- 財務主管

## 運作流程

1. 建立對帳批次
2. 執行交易配對
3. 分類未合差異
4. 完成雙邊確認
5. 提出帳務調整
6. 鎖定期末餘額

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
