## 功能模組

- **缺口雷達** — 以需求量、失敗率與業務影響定位知識缺口。
- **失敗搜尋分析** — 聚合零結果、反覆改寫及快速離站的查詢。
- **重複提問叢集** — 將客服與內部頻繁問題歸併為需求主題。
- **缺口成因圖** — 連結缺少內容、用詞落差及權限阻斷等原因。
- **建設優先序** — 解釋每項內容建議的需求、成本與預期效益。
- **內容任務規劃** — 建立文章題綱、指派專家並設定驗收指標。

## 適合誰使用

- 知識工作者
- 主管
- 客服

## 運作流程

1. 掃描知識缺口
2. 檢視失敗查詢
3. 彙整真實問題
4. 判定缺口成因
5. 選定建設項目
6. 啟動內容建設

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
