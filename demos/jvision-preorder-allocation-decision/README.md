# 預購訂單配貨決策台

> 依下單時間、付款狀態、會員承諾及到貨批次建立預購配貨順序，處理取消、插單與合併出貨，確保有限到貨量可公平且可追溯分配。

依下單時間、付款狀態、會員承諾及到貨批次建立預購配貨順序，處理取消、插單與合併出貨，確保有限到貨量可公平且可追溯分配。

**產業別：**零售電商　|　**系統類型：**warehouse-wms

## 功能模組

- **預購佇列** — 查看訂單順序與承諾日。
- **到貨批次** — 登錄可分配數量與日期。
- **配貨規則** — 設定付款、會員與通路順位。
- **分配模擬** — 預覽各批訂單配貨結果。
- **例外審核** — 處理插單與客訴保留。
- **履約通知** — 發布配貨或延期訊息。

## 適合誰使用

- 電商營運
- 配貨專員
- 客服主管

## 運作流程

1. 載入訂單
2. 登錄到貨
3. 套用規則
4. 模擬配貨
5. 核准例外
6. 發布結果

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
