# Agent 幻覺舉證器

**產業別：**資訊科技　|　**系統類型：**quality-qms

## 功能模組

- **回覆句子拆解** — 將 Agent 回覆拆成可獨立驗證的事實、推論與建議句。
- **來源候選搜尋** — 跨 ERP、CRM、MCP 與文件庫尋找每句話的候選依據。
- **主張證據對位** — 建立句子、資料欄位、文件段落與圖譜節點的對應關係。
- **支持度判定** — 依來源權威性、時效與一致性評定支持、矛盾或證據不足。
- **幻覺缺口修訂** — 標出無證據內容並產生刪除、降調或補充來源的修訂方案。
- **可查證輸出核准** — 讓負責人逐句覆核證據包後發布具引用標記的答案。

## 適合誰使用

## 運作流程

1. 拆解待驗回覆
2. 搜尋企業來源
3. 建立證據對位
4. 判定幻覺風險
5. 修訂證據缺口
6. 核准可查證版本
