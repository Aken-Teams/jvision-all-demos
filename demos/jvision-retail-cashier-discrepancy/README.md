# 門市收銀差異調查台

> 集中處理門市每日現金、刷卡、電子支付、禮券與退貨的收銀差異，保留班別調查、證據、覆核及帳務調整紀錄。

集中處理門市每日現金、刷卡、電子支付、禮券與退貨的收銀差異，保留班別調查、證據、覆核及帳務調整紀錄。

**產業別：**零售電商　|　**系統類型：**finance-case

## 功能模組

- **日結差異** — 彙整各店、班別及支付方式差額。
- **交易追查** — 查閱收銀、退款、取消與交班紀錄。
- **證據彙整** — 收集點交表、簽單及說明文件。
- **原因判定** — 分類操作錯誤、支付落差或舞弊疑點。
- **責任覆核** — 核准吸收、追繳或進一步調查。
- **帳務調整** — 建立調整摘要並追蹤入帳完成。

## 適合誰使用

- 門市店長
- 零售財務
- 稽核人員

## 運作流程

1. 接收收銀差異
2. 分派門市查核
3. 蒐集交易證據
4. 判定差異原因
5. 核准處理方式
6. 完成帳務結案

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
