協助保經代公司依保單生效、續期、停效與解約狀態計算業務佣金，管理跨期補發及追扣，提供個人明細、覆核軌跡與爭議案件，降低結算錯誤。

**產業別：**金融保險　|　**系統類型：**finance-ledger

## 功能模組

- **規則版本** — 管理商品、年度與通路適用的佣金級距。
- **保單事件** — 彙整生效、續期、停效、復效及解約資料。
- **佣金試算** — 計算首期、續期、獎金與跨期調整。
- **追扣管理** — 依解約條件建立追扣與分期回收項目。
- **結算爭議** — 受理業務對計算基礎或歸屬的異議。
- **批次核定** — 完成雙層覆核並產出個人結算明細。

## 適合誰使用

- 佣金會計
- 通路營運
- 業務主管

## 運作流程

1. 發布規則
2. 彙整事件
3. 執行試算
4. 建立追扣
5. 處理異議
6. 核定結算

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
