# 開挖監測超限應變台

> 整合深開挖期間的監測讀值、警戒門檻、現場巡查與處置紀錄，協助工地主任在接獲異常後完成分級判定、停工通報、改善派工及復工簽認，保留完整決策證據。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **監測總覽** — 按測點與區域呈現最新讀值及警戒狀態。
- **超限判讀** — 比對行動值、警戒值與歷次變化趨勢。
- **現場查證** — 登錄異常位置、巡查照片與周邊施工狀況。
- **應變派工** — 指派支撐補強、降載或停工等處置。
- **複測確認** — 記錄複測結果及改善前後差異。
- **復工簽認** — 彙整證據並完成監造與工地主任放行。

## 適合誰使用

- 工地主任
- 監測顧問
- 監造工程師

## 運作流程

1. 掌握讀值
2. 判定等級
3. 現勘查證
4. 執行處置
5. 安排複測
6. 核准復工

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
