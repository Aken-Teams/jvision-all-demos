# 餐飲進貨驗收差異台

> 把食材到貨重量、缺貨、替代品、品質照片與扣款原因集中成驗收案件，協助門店、採購及財務在付款前完成差異確認與供應商追扣。

把食材到貨重量、缺貨、替代品、品質照片與扣款原因集中成驗收案件，協助門店、採購及財務在付款前完成差異確認與供應商追扣。

**產業別：**餐飲旅宿　|　**系統類型：**procurement-srm

## 功能模組

- **到貨批次** — 查看今日供應商與預定品項。
- **實收驗證** — 記錄重量、數量及品質結果。
- **差異舉證** — 整理短磅、破損與替代品照片。
- **供應商確認** — 追蹤差異回覆與責任認定。
- **扣款結算** — 產生折讓及應付扣抵清單。
- **供應商分析** — 比較差異率與改善趨勢。

## 適合誰使用

- 驗收人員
- 採購專員
- 應付會計

## 運作流程

1. 載入到貨
2. 記錄實收
3. 提出差異
4. 確認責任
5. 執行扣款
6. 評估供應商

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
