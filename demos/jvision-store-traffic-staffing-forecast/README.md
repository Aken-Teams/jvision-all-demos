# 門市來客排班聯動預測台

> 結合模擬的歷史來客、天候、節慶、活動與班表資料，預測各時段服務需求，將人力缺口轉成排班建議，並協助店長處理工時限制、調班及預測落差。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **來客預測總覽** — 以日曆與時段曲線呈現各店未來來客量、信心區間及影響事件。
- **需求條件設定** — 設定服務水準、崗位技能、作業工時與活動加成等預測條件。
- **智慧班表草案** — 將時段需求轉換為視覺化班表，顯示每位員工的班次與崗位。
- **工時衝突檢查** — 標示超時、休息不足、技能缺口及可用性衝突，提供調整選項。
- **調班缺口協作** — 管理請假、換班和代班候選名單，預覽異動後的人力覆蓋。
- **預測排班復盤** — 比較預測與模擬實績，分析服務水準、工時成本和誤差來源。

## 適合誰使用

- 門市店長
- 區域主管
- 排班專員
- 人力資源人員

## 運作流程

1. 檢視來客預測
2. 設定服務需求
3. 產生班表草案
4. 排除班表衝突
5. 協調臨時異動
6. 檢討預測落差

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
