# 保固到期巡檢排程台

> 從分包契約整理各設備與工項保固期限，在到期前依區域排定預防巡檢、彙整缺失並通知原承包商改善，讓尾款或保固責任解除前完成最後一輪驗證。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **到期總覽** — 呈現近期保固與巡檢風險。
- **保固台帳** — 維護工項、廠商、期限與保留款。
- **巡檢排程** — 按區域與專業建立檢查批次。
- **現場巡檢** — 記錄狀況、照片及缺失等級。
- **回場改善** — 通知原分包並追蹤修繕期限。
- **到期結案** — 複驗後建議解除責任或續管。

## 適合誰使用

- 保固專員
- 物業人員
- 成本工程師

## 運作流程

1. 檢視到期
2. 核對契約
3. 安排巡檢
4. 執行檢查
5. 催辦改善
6. 核准結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
