# 技術債利息估算器

> 將技術債造成的維護工時、事故損失與交付延遲換算成可排序成本。

將技術債造成的維護工時、事故損失與交付延遲換算成可排序成本。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **債務成本總帳** — 彙總各技術債的維護、事故與延遲成本及估算區間。
- **維護耗損估算** — 計算重工、除錯與知識轉移持續消耗的工程工時。
- **事故利息模型** — 連結事件頻率、復原時間與營運衝擊估算事故成本。
- **交付延遲歸因** — 辨識技術債對週期時間、阻塞與延期的實際貢獻。
- **利息情境預測** — 預測延後償還時的成本成長、風險與不確定範圍。
- **償債投資排序** — 依投入、節省金額與風險下降排列優先償還項目。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 盤點債務成本
2. 校準維護耗損
3. 連結事故損失
4. 驗證交付影響
5. 模擬償還時機
6. 核准償債順序

## 導入效益

- 事件平均處理：120分鐘 → **30分鐘**
- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
- 資產盤點工時：20小時/月 → **4小時/月**
