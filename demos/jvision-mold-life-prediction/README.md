# 模具壽命預測系統

> 彙整模具基本資料、累積模次、材料負荷、保養與維修等擬真紀錄，估算各模具及關鍵部件的剩餘可用壽命，協助保養排程、備件準備與汰換評估，避免只按固定週期維護或故障後才停機處理。

彙整模具基本資料、累積模次、材料負荷、保養與維修等擬真紀錄，估算各模具及關鍵部件的剩餘可用壽命，協助保養排程、備件準備與汰換評估，避免只按固定週期維護或故障後才停機處理。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **模具資產總覽** — 彙整模具狀態、累積模次、剩餘壽命與近期保養需求。
- **模次履歷管理** — 檢視生產批次、每日模次、材料負荷及異常停機歷程。
- **健康指標評估** — 以磨耗、故障、保養及負荷資料呈現模具健康分數。
- **剩餘壽命預測** — 顯示模具與關鍵部件的剩餘模次、到期區間及可信程度。
- **保養排程規劃** — 依壽命、訂單與產線空檔安排保養日期、工項及負責人。
- **備件汰換評估** — 檢查所需備件、預估成本，並比較修復、翻新與汰換方案。

## 適合誰使用

- 模具保養工程師
- 設備主管
- 生產排程人員

## 運作流程

1. 盤點資產
2. 更新履歷
3. 評估健康
4. 確認壽命
5. 安排保養
6. 決定汰換

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
