# Agent 紅隊挑戰器

自動生成越權、提示注入與社交工程攻擊，量化 Agent 的安全弱點。

**產業別：**資訊科技　|　**系統類型：**security-soc

## 功能模組

- **攻擊情境工坊** — 依 Agent 角色、資料與工具權限生成具目標的對抗測試情境。
- **越權行為挑戰** — 測試橫向存取、角色冒用、敏感工具呼叫與核准繞過。
- **提示注入攻防** — 投放直接、間接及跨工具注入，觀察指令優先序是否遭竄改。
- **誘導社交工程** — 模擬權威施壓、緊急請求與資訊套取等多輪誘導策略。
- **弱點利用鏈** — 串接多個低風險缺陷，驗證其能否形成可重現的攻擊路徑。
- **防護修補驗證** — 重播攻擊以確認提示、政策、權限或工具護欄已阻斷弱點。

## 運作流程

1. 建立攻擊範圍

3. 執行注入攻擊
4. 展開誘導對話
5. 組合利用路徑
6. 驗證修補效果
