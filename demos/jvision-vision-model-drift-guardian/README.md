監測光線、相機、產品及缺陷分布漂移，維持視覺檢測品質。実際 至少 6 characters...

**產業別：**生產製造　|　**系統類型：**quality-qms

## 功能模組

- **光照穩定監測** — 追蹤亮度、色溫、反光與陰影分布的長期偏移。
- **相機健康診斷** — 監測焦距、曝光、雜訊、震動與鏡頭污染。
- **產品分布漂移** — 辨識料號、外觀版本與產品組合相對訓練集的變化。
- **缺陷分布漂移** — 分析缺陷類別、尺寸、位置及信心分數的偏移。
- **模型品質守門** — 彙整誤判、漏判與漂移訊號，判定模型服務風險。
- **校正回訓決策** — 建議清潔、重校、調閾值或建立新模型版本。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 檢查光照偏移
2. 診斷相機狀態
3. 辨識產品變化
4. 分析缺陷分布
5. 評估檢測風險
6. 執行校正回訓

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
