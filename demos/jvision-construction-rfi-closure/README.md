**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **疑義提報** — 記錄問題、圖面位置與現場需求日期。
- **專業會簽** — 分派建築、結構、機電及業主確認。
- **正式答覆** — 管理澄清內容、附件及答覆版本。
- **影響評估** — 記錄成本、工期與施工介面影響。
- **版本發布** — 指定現場應採用的答覆與修訂圖。
- **施工確認** — 由現場確認已理解並完成處置。

## 適合誰使用

- 工地主任
- 監造工程師
- 設計專案經理

## 運作流程

1. 提出疑義
2. 監造分流
3. 完成會簽
4. 評估影響
5. 發布版本
6. 確認關閉

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
