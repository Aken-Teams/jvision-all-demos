**產業別：**企業協作　|　**系統類型：**collaboration-pm

## 功能模組

- **賓客接待檔案** — 管理賓客偏好、禮賓等級、飲食禁忌與陪同需求。
- **行程編排板** — 整合會議、參訪與休息時段，找出衝突及緩衝不足。
- **交通接駁規劃** — 安排班機銜接、車輛、司機、路線與候車備案。
- **餐飲接待安排** — 依人數、禁忌、地點與時程配置餐廳及茶點。
- **接待人力配置** — 指派迎賓、陪同、口譯與場控人員並確認交接。
- **行程異動指揮** — 偵測延誤與資源衝突，排序可解釋的改排方案。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 建立賓客任務
2. 彙整完整行程
3. 模擬衝突
4. 確認資源
5. 執行即時協調
6. 驗證接待完成

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
