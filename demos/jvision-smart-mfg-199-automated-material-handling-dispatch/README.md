# AGV/AMR智慧搬運調度追蹤台

調度無人搬運車(AGV)與自主移動機器人(AMR)執行倉內物料搬運，減少人工搬運需求。

- 原始系統：AGV/AMR智慧搬運調度系統（Automated Material Handling Dispatch）
- 產業分類：智慧製造｜倉儲管理
- 使用部門：倉儲部、設備工程部、生管部
- 工作流程：搬運任務產生→車隊調度指派→路徑規劃執行→物料交接→任務完成回報→效率統計
- AI 應用：多車隊路徑動態最佳化、搬運需求預測與預先調度
- 主要 KPI：搬運任務完成率、車輛稼動率、搬運時效、人力搬運替代率
- 代表產品：Geek+、快倉（Quicktron）、KUKA、盟立自動化（Mirle）
