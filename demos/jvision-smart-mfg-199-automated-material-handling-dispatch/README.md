# AGV/AMR智慧搬運調度系統（Automated Material Handling Dispatch）

> 收貨到出貨的倉內作業與庫存精準管理

AGV/AMR智慧搬運調度系統（Automated Material Handling Dispatch）提供搬運任務自動派發、多車隊路徑規劃與避障、與WMS/WCS任務對接。倉儲部依「搬運任務產生→車隊調度指派→路徑規劃執行→物料交接→任務完成回報→效率統計」推進作業，優先解決「人工搬運效率低且有職災風險」，設備工程部則以搬運任務完成率與車輛稼動率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**倉儲物流　|　**系統類型：**WMS 倉儲管理系統

## 功能模組

- **入庫上架** — 收貨、驗收與智慧上架
- **揀貨出貨** — 波次揀貨、覆核與出貨
- **儲位管理** — 儲位規劃與庫容視覺化
- **庫存盤點** — 即時庫存、盤點與調撥
- **拉動補料** — 安全庫存與自動補貨
- **條碼作業** — PDA 掃碼即時作業

## 適合誰使用

- 倉儲部
- 設備工程部
- 生管部

## 運作流程

1. 待調度
2. 配送中
3. 複核確認
4. 出庫完成

## 導入效益

- 揀貨作業工時：6.7小時/日 → **2.1小時/日**
- 庫存準確率：92% → **99%**
- 出貨延遲率：8.8% → **1.9%**
- 盤點工時：17小時/月 → **3.1小時/月**
