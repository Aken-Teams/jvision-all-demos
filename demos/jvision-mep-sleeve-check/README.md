# 機電套管封模覆核台

> 供機電與土建在牆梁封模前逐點確認套管、預留孔及預埋盒的尺寸和座標，處理碰撞與漏設，避免拆模後鑽孔補救傷及結構。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **點位總圖** — 查看樓層預留點
- **套管核對** — 檢查口徑標高
- **碰撞會勘** — 記錄移位決議
- **缺失修正** — 指派補設調整
- **封模停點** — 未完成禁止封模
- **聯合簽認** — 土建機電共同放行

## 適合誰使用

- 機電工程師
- 模板班長

## 運作流程

1. 載入點位
2. 現場放樣
3. 逐點覆核
4. 衝突修正
5. 封模檢查
6. 共同放行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
