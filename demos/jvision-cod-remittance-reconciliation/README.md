# 貨到付款匯款核對台

> 統一物流商代收明細、銀行入帳、拒收跨期與手續費調整，按訂單逐筆勾稽應收與實收，找出短匯、未匯及不合理沖銷。

統一物流商代收明細、銀行入帳、拒收跨期與手續費調整，按訂單逐筆勾稽應收與實收，找出短匯、未匯及不合理沖銷。

**產業別：**零售電商　|　**系統類型：**finance-ledger

## 功能模組

- **代收明細** — 彙整物流商訂單收款。
- **銀行入帳** — 查看批次匯款與日期。
- **訂單勾稽** — 自動配對應收與實收。
- **費用驗算** — 核對手續費及調整。
- **差異案件** — 調查拒收、短匯與跨期。
- **回款核銷** — 確認入帳並關閉應收。

## 適合誰使用

- 應收會計
- 電商財務
- 物流專員

## 運作流程

1. 匯入代收
2. 取得入帳
3. 執行配對
4. 驗算費用
5. 處理差異
6. 完成核銷

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
