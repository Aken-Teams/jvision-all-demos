# 工程變更管理系統（ECN/ECR）

> 訂單到入庫的製造現場全流程數位化

工程變更管理系統（ECN/ECR）提供變更申請（ECR）與變更通知（ECN）流程、影響範圍分析（BOM/庫存/客戶）、多部門審查簽核路徑設定。研發專員、研發主管、研發管理主管依「變更申請（ECR）與變更通知（ECN）流程、影響範圍分析（BOM/庫存/客戶）、多部門審查簽核路徑設定」推進作業，優先解決「變更未同步導致新舊料混用」，部門主管則以工程變更管理預警塔處理結果確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**研發管理　|　**系統類型：**MES 製造執行系統

## 功能模組

- **工單管理** — 訂單轉工單、拆併單與工單派發
- **排程排產** — 依產能、交期、負載自動排程
- **現場執行** — 派工、報工與進度即時回報
- **設備稼動 OEE** — 稼動、效率、良率即時監控
- **品質入庫** — 檢驗判定、不良處置與入庫
- **AI 改善建議** — 異常摘要與瓶頸改善建議

## 適合誰使用

- 研發專員
- 研發主管
- 研發管理主管

## 運作流程

1. 待排程
2. 生產中
3. 審核確認
4. 發布完成

## 導入效益

- 設計變更工時：7.8小時 → **2.1小時**
- 文件版本錯誤：6件/月 → **1.1件/月**
- 專案準時率：71% → **86%**
- 資料查找時間：31分鐘 → **4.8分鐘**
