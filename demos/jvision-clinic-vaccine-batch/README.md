# 診所疫苗批次施打管理台

> 供診所規劃自費及公費疫苗批次、預約名額、適用條件、施打紀錄與後續劑次，透過擬真名冊完成資格覆核與批號留存，降低錯劑、漏約及追溯困難。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **疫苗方案** — 設定品項、劑次與適用條件。
- **施打梯次** — 配置日期、名額及執行人員。
- **資格覆核** — 檢查年齡、間隔與方案資格。
- **批號登錄** — 保存施打品項、批號與效期。
- **後續劑次** — 安排下一劑並追蹤未完成名單。
- **批次報表** — 彙整使用量、異常與完成情況。

## 適合誰使用

- 護理師
- 櫃檯人員
- 診所主管

## 運作流程

1. 建立方案
2. 開放梯次
3. 覆核資格
4. 登錄施打
5. 安排續劑
6. 完成結報

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
