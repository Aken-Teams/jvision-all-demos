# 配方變更法規衝擊檢查器

> 檢查配方成分變更對各市場准入與標示義務的影響，避免合規退件。

檢查配方成分變更對各市場准入與標示義務的影響，避免合規退件。

**產業別：**生產製造　|　**系統類型：**quality-qms

## 功能模組

- **配方版本差異** — 逐項比較新舊配方的成分、濃度、用途與供應來源變化。
- **市場義務矩陣** — 對照銷售市場，標示禁限用物質、門檻與申報義務。
- **成分合規判定** — 結合法規條文與企業規則，判斷每項變更的准入風險。
- **標示衝擊預覽** — 顯示成分表、警語、宣稱與包裝文字需要調整的位置。
- **矛盾與缺口檢查** — 找出配方、規格、標示與法規來源之間的衝突或缺件。
- **上市修正清單** — 依市場產生需補測、改標、申報或暫緩上市的執行清單。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 比對配方變更
2. 界定目標市場
3. 執行合規判定
4. 檢視標示影響
5. 處理矛盾缺口
6. 核定上市措施

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
