# 供應商評鑑計分卡協作所

以品質、交期、成本、服務等構面量化評分供應商表現，作為續用與汰換決策依據。

- 原始系統：供應商評鑑計分卡系統（Supplier Scorecard）
- 產業分類：智慧製造｜採購管理
- 使用部門：採購部、品保部、供應商管理部、研發部
- 工作流程：設定評鑑構面 → 定期蒐集數據 → 系統評分 → 結果通報 → 改善追蹤
- AI 應用：AI 自動彙整品質/交期數據生成評分、供應商表現異常預警
- 主要 KPI：合格供應商比率、平均評鑑分數、供應商淘汰率、改善完成率
- 代表產品：SAP Ariba Supplier Management、Coupa Supplier Performance、JAGGAER
