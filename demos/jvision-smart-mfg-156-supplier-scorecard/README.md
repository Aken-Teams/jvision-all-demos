# 供應商評鑑計分卡系統（Supplier Scorecard）

> 供應商協同、詢比議價到交期風險控管

供應商評鑑計分卡系統（Supplier Scorecard）提供多構面評分卡設定、定期自動評鑑排程、評鑑結果趨勢分析。採購部依「設定評鑑構面 → 定期蒐集數據 → 系統評分 → 結果通報 → 改善追蹤」推進作業，優先解決「評鑑標準不一致主觀性高」，品保部則以合格供應商比率與平均評鑑分數確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**採購供應鏈　|　**系統類型：**SRM 採購供應商管理

## 功能模組

- **供應商管理** — 建檔、分級與績效評分
- **詢報價協作** — 線上詢價、比價與議價
- **採購訂單** — 請購、下單與交期追蹤
- **交期風險** — 缺料預警與到貨監控
- **供應商品質** — 進料檢驗與 SCAR 改善
- **綠色採購** — ESG 評分與永續採購

## 適合誰使用

- 採購部
- 品保部
- 供應商管理部

## 運作流程

1. 待詢價
2. 比價中
3. 待核准
4. 驗收完成

## 導入效益

- 採購前置時間：13天 → **4.8天**
- 準時到貨率：80% → **98%**
- 缺料預警覆蓋：42% → **86%**
- 議價作業工時：7.7小時/週 → **2小時/週**
