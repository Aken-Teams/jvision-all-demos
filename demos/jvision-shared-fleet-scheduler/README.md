# 公務車共享排程器

> 依地點、乘員、路線與優先級合併派車，提高公務車使用率。面向總務主管與行政團隊，把高頻工作集中在可執行工作台中。

依地點、乘員、路線與優先級合併派車，提高公務車使用率。面向總務主管與行政團隊，把高頻工作集中在可執行工作台中。

**產業別：**企業協作　|　**系統類型：**logistics-fleet

## 功能模組

- **用車需求池** — 彙整出發地、目的地、時段、乘員與任務優先級。
- **共乘媒合** — 辨識方向與時間相近需求，提出可接受繞行的合併組合。
- **路線時程模擬** — 估算交通、停靠、等待與回程對後續任務的影響。
- **車輛適配** — 依座位、車型、續航、設備與維護狀態選擇車輛。
- **司機任務板** — 安排司機班次、取車時間、乘客名單與上下車順序。
- **派車調整台** — 監控延誤與臨時需求，重排車輛、共乘組合及優先順序。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 提交用車需求
2. 產生共乘組合
3. 模擬路線時程
4. 確認車輛司機
5. 執行接送
6. 處理異動結案

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
