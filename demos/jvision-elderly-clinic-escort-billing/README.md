# 長照陪診費用核對台

> 依陪診起訖、跨日延長、交通、停車與憑證，同時計算對家屬收費及對服務員計薪，標示兩者差異與缺件，降低毛利漏失及申訴。

**產業別：**生活服務　|　**系統類型：**finance-case

## 功能模組

- **陪診案件** — 記錄服務對象與醫院
- **時間核對** — 確認起訖延長及跨日
- **交通費用** — 登錄車資停車與里程
- **憑證補件** — 追蹤收據與核准證據
- **雙邊試算** — 計算客收與人員計薪
- **結算覆核** — 核定帳單及薪資批次

## 適合誰使用

- 長照客服
- 服務督導
- 薪務人員

## 運作流程

1. 建立陪診案件
2. 回報實際服務
3. 查驗費用憑證
4. 處理計費差異
5. 試算收費計薪
6. 完成結算覆核

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
