# 工業能耗碳排最佳化平台

> 彙整工廠產線、設備、班次與能源帳單的擬真資料，建立單位產量能耗及碳排基準，找出異常與改善機會，模擬生產排程、設備設定或能源組合調整後的成本與減碳效益。

**產業別：**ESG 永續　|　**系統類型：**esg-energy

## 功能模組

- **廠區能碳總覽** — 呈現廠區與產線的能源、成本、碳排及目標達成狀況。
- **能耗流向分析** — 以能源種類、設備與製程拆解耗用結構及尖峰時段。
- **產品碳排核算** — 用擬真排放係數分攤產品與製程碳排，呈現核算邏輯。
- **異常根因診斷** — 比較基準與實績，找出待機、效率下降或排程造成的異常。
- **改善情境模擬** — 模擬製程參數、班次、設備汰換或能源組合的能碳效益。
- **節能專案追蹤** — 建立改善措施、責任人、預期效益、里程碑與驗證結果。

## 適合誰使用

- 能源管理員
- 永續專員
- 生產主管

## 運作流程

1. 檢視能碳績效
2. 拆解耗用來源
3. 核算產品碳排
4. 診斷異常根因
5. 模擬改善方案
6. 追蹤節能專案

## 導入效益

- 盤查作業工時：40小時 → **8小時**
- 數據完整率：60% → **95%**
- 減碳目標達成：50% → **88%**
- 用能異常反應：24小時 → **2小時**
