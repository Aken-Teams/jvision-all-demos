# 印刷電路板鑽孔品質檢測

> 彙整印刷電路板鑽孔影像、孔徑量測與製程批次資料，以人工智慧標示偏孔、毛刺、孔壁破損等疑似缺陷，協助品管人員快速複判、追蹤批次風險並產出品質報告。

彙整印刷電路板鑽孔影像、孔徑量測與製程批次資料，以人工智慧標示偏孔、毛刺、孔壁破損等疑似缺陷，協助品管人員快速複判、追蹤批次風險並產出品質報告。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **品質監控總覽** — 呈現待檢批次、缺陷分布、合格率與高風險工單。
- **批次資料匯入** — 模擬上傳鑽孔影像、孔徑量測及工單製程資料。
- **孔位智慧檢測** — 以孔位圖卡展示偏孔、毛刺與孔壁破損的辨識結果。
- **缺陷複判工作台** — 逐筆比對原圖、標記區域及判定依據並完成人工複核。
- **異常處置追蹤** — 建立隔離、重工或放行決策，追蹤負責人與處理進度。
- **品質趨勢報告** — 分析機台、料號、班別及缺陷類型的歷史變化。

## 適合誰使用

- 印刷電路板品管工程師
- 製程工程師與品質主管

## 運作流程

1. 掌握待檢批次
2. 建立檢測批次
3. 檢視智慧判定
4. 完成人工複判
5. 指派異常處置
6. 回顧品質趨勢

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
