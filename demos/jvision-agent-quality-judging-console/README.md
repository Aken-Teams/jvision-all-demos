## 功能模組

- **裁判規準設計** — 定義事實正確性、任務完成度、格式、安全與引用等評分尺度。
- **確定性規則裁判** — 以 Schema、關鍵值、計算式與政策條件執行可重現的硬性檢查。
- **模型語意裁判** — 評估開放式答案的相關性、完整性、推理品質與證據一致性。
- **裁判分歧仲裁** — 比較規則、不同模型及既有標註的衝突，估計判定可信度。
- **人工盲審工作台** — 將低信心或高影響案例匿名派給領域專家複核與評註。
- **品質基準發布** — 彙整裁定結果，建立可比較的 Agent、版本與任務類型基準。

## 適合誰使用

## 運作流程

1. 建立評分規準
2. 執行規則檢查
3. 進行模型評判
4. 分析裁判分歧
5. 完成專家盲審
6. 發布品質基準
