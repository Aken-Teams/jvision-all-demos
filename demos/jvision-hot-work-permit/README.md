# 動火作業許可管制台

> 管理焊接、切割與加熱作業的區域申請、危害評估、防火措施、監火人配置及完工後巡查，避免多工班同時施工造成火災與許可失效風險。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **許可總覽** — 按樓層與時段顯示動火申請及有效狀態。
- **作業申請** — 填報工法、區域、人員、時段與火花範圍。
- **危害評估** — 確認可燃物、孔洞、鄰近工序與風險等級。
- **措施確認** — 檢點隔離、滅火器材及監火人配置。
- **作業監看** — 記錄開工、暫停、展延與現場抽查結果。
- **餘火關閉** — 完成收工及分時巡查後關閉許可。

## 適合誰使用

- 安全衛生人員
- 施工領班
- 監火人員

## 運作流程

1. 許可總覽
2. 作業申請
3. 危害評估
4. 措施確認
5. 作業監看
6. 餘火關閉

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
