# 自動光學檢測標準樣本台

> 協助品保與製程人員從歷史良品影像中篩選代表樣本，自動產生自動光學檢測用的標準樣本候選集，並以版本審核、覆蓋率與模擬驗證流程，降低人工挑樣偏差及換線建模時間。

協助品保與製程人員從歷史良品影像中篩選代表樣本，自動產生自動光學檢測用的標準樣本候選集，並以版本審核、覆蓋率與模擬驗證流程，降低人工挑樣偏差及換線建模時間。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **樣本來源盤點** — 依產品、料號、線別與批次整理歷史良品影像及其品質標記。
- **候選樣本篩選** — 以清晰度、重複度與異常標記條件排除不適合的樣本。
- **代表樣本生成** — 將候選影像分群並推薦可涵蓋主要外觀差異的標準樣本組。
- **樣本差異比對** — 並排查看推薦樣本的區域特徵、相似度與被選入原因。
- **版本審核發布** — 建立標準樣本版本，記錄增刪意見並完成簽核發布。
- **離線模擬驗證** — 以擬真測試資料呈現誤判、漏判與特徵覆蓋的驗證結果。

## 適合誰使用

- 品保工程師
- AOI 工程師
- 製程工程師

## 運作流程

1. 盤點樣本來源
2. 清理候選資料
3. 建立標準樣本
4. 比對樣本差異
5. 審核版本發布
6. 驗證檢測表現

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
