# 工廠OT資安管理追蹤台

針對PLC、SCADA、MES等產線OT環境提供資產可視化、威脅偵測與網段隔離，因應IT/OT融合資安風險。

- 原始系統：工廠OT資安管理系統
- 產業分類：智慧製造｜IT管理
- 使用部門：資訊安全部、設備工程部、資訊部、產線工程部
- 工作流程：OT資產盤點建檔→網段區隔設計→流量持續監控→異常事件告警→應變處置→定期弱點掃描與修補
- AI 應用：OT異常流量行為偵測、設備韌體弱點風險評分
- 主要 KPI：OT資產可視化覆蓋率、異常事件偵測數、網段隔離合規率、產線資安停機時數
- 代表產品：Claroty、Nozomi Networks、Dragos、Fortinet FortiGate(OT版)
