# 工程押標金追蹤台

> 按標案管理押標金形式、繳付、有效期間、開標結果、可退日期與實際退款，辨識逾期未退及已入帳未沖銷款項，降低資金閒置。

按標案管理押標金形式、繳付、有效期間、開標結果、可退日期與實際退款，辨識逾期未退及已入帳未沖銷款項，降低資金閒置。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **押標金總覽** — 查看標案金額與狀態
- **繳付登錄** — 記錄現金支票或保證
- **退還條件** — 設定開標與可退日期
- **催退追蹤** — 管理逾期聯絡及回覆
- **退款配對** — 核對銀行入帳款項
- **帳務沖銷** — 關閉押標金資產餘額

## 適合誰使用

- 投標專員
- 出納人員
- 財務主管

## 運作流程

1. 提出申請
2. 核准繳付
3. 完成付款
4. 更新結果
5. 追蹤退款
6. 完成沖銷

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
