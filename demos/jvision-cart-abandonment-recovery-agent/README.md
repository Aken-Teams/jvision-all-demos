# 購物車放棄挽回旅程助手

> 根據擬真購物車、顧客互動與優惠資料，辨識放棄風險及可能阻礙，協助行銷人員設計分眾挽回旅程、訊息內容與優惠界線，並在純介面中模擬觸達節奏、人工核准及成效歸因。

根據擬真購物車、顧客互動與優惠資料，辨識放棄風險及可能阻礙，協助行銷人員設計分眾挽回旅程、訊息內容與優惠界線，並在純介面中模擬觸達節奏、人工核准及成效歸因。

**產業別：**零售電商　|　**系統類型：**sales-crm

## 功能模組

- **放棄案件佇列** — 依購物車金額、放棄時間與挽回機會排列待處理顧客。
- **放棄原因診斷** — 呈現運費、價格、付款疑慮與比較購物等模擬原因及佐證。
- **挽回旅程設計** — 以節點編排等待、分流、訊息、優惠與人工覆核步驟。
- **訊息內容工作室** — 依顧客情境產生並編修電子郵件、簡訊與站內提醒文案。
- **優惠界線控管** — 設定折扣上限、適用品項、最低消費與毛利警示條件。
- **挽回成效歸因** — 以模擬資料比較自然回購、訊息帶回與優惠帶回的成效。

## 適合誰使用

- 會員行銷人員
- 電商營運人員
- 客服主管

## 運作流程

1. 篩選挽回案件
2. 確認放棄原因
3. 編排挽回旅程
4. 完成訊息內容
5. 核准優惠方案
6. 檢視挽回歸因

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
