# 金屬零件智慧尺寸量測系統

> 利用預載零件影像與擬真校正資料，模擬辨識孔徑、長寬、間距及角度等尺寸，自動對照圖面公差並標示超差項目，協助檢驗員完成複核、產出檢驗報告與追蹤量測一致性。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **量測作業總覽** — 呈現待量測工件、合格率、超差項目與檢驗進度。
- **工件規格選擇** — 選擇零件料號、版本與檢驗模板並查看目標尺寸。
- **影像校正** — 以預載基準尺與定位點模擬比例、角度及透視校正。
- **尺寸量測工作台** — 在零件影像上呈現孔徑、距離、長寬與角度標記。
- **公差複核** — 逐項對照上下限、標示超差並供檢驗員確認結果。
- **檢驗報告中心** — 預覽單件或批次尺寸報告、判定摘要與簽核欄位。

## 適合誰使用

- 品管檢驗員
- 品質工程師與品保主管

## 運作流程

1. 檢視量測任務
2. 選擇工件規格
3. 完成影像校正
4. 執行尺寸量測
5. 複核公差結果
6. 產出檢驗報告
