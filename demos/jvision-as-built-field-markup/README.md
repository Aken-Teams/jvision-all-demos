# 竣工圖現況回填台

> 在隱蔽工程封閉前，按區域收集現場偏移、管線改道、設備改號與尺寸實測標註，經工程師覆核後形成待繪清單，持續比對繪圖完成度，避免竣工階段只靠紙圖與聊天照片回憶現況。

在隱蔽工程封閉前，按區域收集現場偏移、管線改道、設備改號與尺寸實測標註，經工程師覆核後形成待繪清單，持續比對繪圖完成度，避免竣工階段只靠紙圖與聊天照片回憶現況。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **位置清冊** — 按樓層、空間與系統管理待回填位置。
- **現況標註** — 記錄偏移、改道、增刪與尺寸實測。
- **封閉影像** — 保存封板或澆置前的定位照片。
- **專業覆核** — 確認標註內容足以支持竣工繪製。
- **待繪派工** — 將確認項目派送至CAD或BIM繪圖人員。
- **圖面回連** — 比對更新成果並連結竣工圖版本。

## 適合誰使用

- 現場工程師
- BIM工程師
- 竣工圖繪圖員

## 運作流程

1. 建立待回填位置
2. 標記現場變更
3. 拍攝封閉前證據
4. 覆核回填內容
5. 更新竣工圖面
6. 比對關閉項目

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
