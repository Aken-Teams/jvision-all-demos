# ITSM預警塔

統一受理與追蹤全公司IT服務請求、事件、變更與問題，是IT部門對內服務的單一窗口。

- 原始系統：ITSM（IT Service Management）
- 產業分類：智慧製造｜IT管理
- 使用部門：資訊部、全公司使用者、稽核室、採購部
- 工作流程：使用者提出請求→服務台分類分派→工程師處理→變更審核（如需）→結案回饋→SLA報表統計
- AI 應用：工單自動分類與派工建議、聊天機器人自助排除常見問題、事件趨勢異常預警
- 主要 KPI：平均解決時間(MTTR)、首次解決率、SLA達成率、工單重開率、使用者滿意度
- 代表產品：ServiceNow、BMC Helix ITSM、Ivanti Neurons、Freshservice、ManageEngine ServiceDesk Plus
