# ITSM（IT Service Management）

> 服務工單、資產到即時監控的 IT 維運

ITSM（IT Service Management）提供服務台/工單受理與分派、事件管理（Incident）、變更管理（Change Management）。資訊部依「使用者提出請求→服務台分類分派→工程師處理→變更審核（如需）→結案回饋→SLA報表統計」推進作業，優先解決「報修管道分散、無追蹤紀錄」，全公司使用者則以平均解決時間(MTTR)與首次解決率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**資訊科技　|　**系統類型：**IT 維運管理平台

## 功能模組

- **服務工單** — 事件/請求工單管理
- **資產管理** — IT 資產與軟體授權
- **即時監控** — 系統/網路健康監控
- **告警事件** — 告警彙整與分派
- **變更發布** — 變更與發布管理
- **服務報表** — SLA 與可用率報表

## 適合誰使用

- 資訊部
- 全公司使用者
- 稽核室

## 運作流程

1. 已受理
2. 處理中
3. 使用者確認
4. 已關閉

## 導入效益

- 事件平均處理：127分鐘 → **29分鐘**
- 系統可用率：95% → **99%**
- SLA達成率：88% → **92%**
- 資產盤點工時：19小時/月 → **4小時/月**
