# 扣件熱處理往返台

> 供扣件廠以桶號、工單、重量及材質點交委外熱處理，將加工廠拆併桶、爐號、回貨與硬度報告重新對應，攔截短少、混批及重複請款。

供扣件廠以桶號、工單、重量及材質點交委外熱處理，將加工廠拆併桶、爐號、回貨與硬度報告重新對應，攔截短少、混批及重複請款。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **送出批次** — 記錄桶號重量
- **廠商簽收** — 確認交付狀態
- **爐次回報** — 連結加工廠爐號
- **回貨點收** — 處理拆併桶
- **報告核對** — 配對硬度資料
- **加工結算** — 依合格回貨計價

## 適合誰使用

- 外發管理員
- 扣件品保

## 運作流程

1. 外發備料
2. 司機點交
3. 廠商入爐
4. 分批返廠
5. 品質驗收
6. 費用核准

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
