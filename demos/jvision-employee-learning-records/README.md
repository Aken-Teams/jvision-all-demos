# 員工學習歷程管理系統

> 集中管理員工受訓計畫、課程報名、學習進度、測驗成果、證照效期與能力成長紀錄，協助人資及主管掌握培訓完成情況，找出能力缺口，並以擬真資料呈現個人與部門學習成果。

集中管理員工受訓計畫、課程報名、學習進度、測驗成果、證照效期與能力成長紀錄，協助人資及主管掌握培訓完成情況，找出能力缺口，並以擬真資料呈現個人與部門學習成果。

**產業別：**人力資源　|　**系統類型：**education-lms

## 功能模組

- **學習首頁** — 呈現個人必修進度、推薦課程與近期學習任務。
- **課程目錄** — 依職能、部門與難度瀏覽可報名的模擬課程。
- **學習與測驗** — 展示教材章節、完成進度與互動式測驗結果。
- **證照資格管理** — 管理證照、取得日期、效期與續證提醒。
- **能力成長圖譜** — 比較職務需求、個人能力與學習後的成長幅度。
- **培訓成效報表** — 分析部門完成率、課程評價與能力缺口。

## 適合誰使用

- 人資專員
- 部門主管
- 培訓講師與一般員工

## 運作流程

1. 查看學習任務
2. 選擇培訓課程
3. 完成學習測驗
4. 維護證照資格
5. 檢視能力成長
6. 評估培訓成效

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
