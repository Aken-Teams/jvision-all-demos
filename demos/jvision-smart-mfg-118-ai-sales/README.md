# AI Sales 智慧業務助理決策室

運用生成式AI輔助業務人員撰寫郵件、摘要商機、產出提案，提升業務生產力與回應速度。

- 原始系統：AI Sales 智慧業務助理
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、業務主管、行銷部、產品經理
- 工作流程：業務輸入需求或錄音→AI生成草稿/摘要→業務人員審核修改→發送客戶→回饋優化模型
- AI 應用：生成式AI提案/郵件撰寫、語音轉文字與情緒分析、銷售話術智慧推薦
- 主要 KPI：文書作業時間節省率、AI採納率、業務回應時效、新人上手時間
- 代表產品：Salesforce Einstein Copilot、Microsoft Copilot for Sales、Gong.io
