# 越獄攻擊偵測器

> 辨識角色扮演、編碼及多輪規避攻擊，降低 LLM 安全規則被繞過的風險。

辨識角色扮演、編碼及多輪規避攻擊，降低 LLM 安全規則被繞過的風險。

**產業別：**資訊安全　|　**系統類型：**security-soc

## 功能模組

- **多輪對話重建** — 還原跨回合提示、回應與上下文的完整攻擊鏈。
- **角色扮演辨識** — 偵測利用虛構角色或情境要求模型忽略限制的手法。
- **編碼內容解析** — 解碼 Base64、字元替換與混淆文本中的惡意意圖。
- **規避路徑分析** — 辨識逐步試探、語意拆分及跨回合組合攻擊。
- **攻擊風險判定** — 評估成功機率、潛在損害與模型不確定性。
- **防護規則強化** — 將確認的攻擊模式轉為閘道規則與測試案例。

## 適合誰使用

- CISO
- AI 治理主管
- 資安分析師

## 運作流程

1. 重建對話
2. 辨識手法
3. 推演風險
4. 確認事件
5. 核准防護
6. 驗證強化
