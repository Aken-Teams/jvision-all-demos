## 功能模組

- **技術主題探索** — 以關鍵概念、技術分類與時間範圍建立分析題目。
- **專利地景圖** — 呈現技術聚落、申請人布局與年度趨勢。
- **權利項拆解** — 將獨立權利項分解為元件、關係及限制條件。
- **概念風險比對** — 對照設計概念與權利項特徵並顯示接近程度。
- **繞道方案導航** — 探索替換元件、改變關係或製程的候選路徑。
- **評估報告工作區** — 彙整證據、註記、方案比較與顧問審查意見。

## 適合誰使用

- 研發主管
- 產品工程師
- 智財專員
- 專利顧問

## 運作流程

1. 定義主題
2. 閱讀地景
3. 拆解權利項
4. 比對概念
5. 探索替代
6. 審查決策
