# 鋼構焊口批次追蹤台

> 以焊口編號串接施工位置、焊工資格、焊材批次、外觀檢查與非破壞檢測，讓不合格結果能精準圈選返修範圍並完成再次檢測與放行。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **焊口地圖** — 依構件與樓層定位所有焊口狀態。
- **焊工资格** — 核對焊法、位置與資格有效期限。
- **施焊紀錄** — 登錄焊材批次、參數與施工人員。
- **檢測排程** — 安排外觀及非破壞檢測批次。
- **返修管制** — 標記缺陷、修補方式與再次送檢。
- **批次放行** — 彙整合格報告並完成區域放行。

## 適合誰使用

- 品管工程師
- 焊接工程師
- 檢測協調員

## 運作流程

1. 建立焊口
2. 資格核對
3. 登錄施焊
4. 安排檢測
5. 處理返修
6. 簽認放行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
