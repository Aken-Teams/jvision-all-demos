# 貨損索賠案件管理台

> 協助物流業者集中管理破損、短少、汙損與遺失案件，串連責任初判、證據清單、賠償試算及承運商追償，避免索賠逾期或資料不足。

協助物流業者集中管理破損、短少、汙損與遺失案件，串連責任初判、證據清單、賠償試算及承運商追償，避免索賠逾期或資料不足。

**產業別：**物流運輸　|　**系統類型：**finance-case

## 功能模組

- **案件受理** — 登記運單、損失類型與客戶主張。
- **證據清單** — 整理照片、簽收與包裝佐證狀態。
- **責任判定** — 依運送節點及條款進行責任初判。
- **賠償試算** — 計算貨值上限、自負額及建議金額。
- **追償協商** — 追蹤協力承運商回覆與分攤方案。
- **結案覆核** — 確認付款、折讓及改善事項完成。

## 適合誰使用

- 理賠專員
- 客服主管
- 運務主管

## 運作流程

1. 受理通報
2. 蒐集證據
3. 釐清責任
4. 提出方案
5. 執行追償
6. 完成結案
