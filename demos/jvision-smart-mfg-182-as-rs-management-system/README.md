# 自動化立體倉庫管理系統（AS/RS Management System）

> 收貨到出貨的倉內作業與庫存精準管理

自動化立體倉庫管理系統（AS/RS Management System）提供出入庫指令排程、料箱/棧板位置管理、設備狀態監控。倉儲部依「入庫申請→堆垛機調度→料箱存放→出庫指令→堆垛機取料→交付產線」推進作業，優先解決「廠房空間有限難擴充平面倉」，設備工程部則以出入庫效率與設備稼動率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**倉儲物流　|　**系統類型：**WMS 倉儲管理系統

## 功能模組

- **入庫上架** — 收貨、驗收與智慧上架
- **揀貨出貨** — 波次揀貨、覆核與出貨
- **儲位管理** — 儲位規劃與庫容視覺化
- **庫存盤點** — 即時庫存、盤點與調撥
- **拉動補料** — 安全庫存與自動補貨
- **條碼作業** — PDA 掃碼即時作業

## 適合誰使用

- 倉儲部
- 設備工程部
- 生管部

## 運作流程

1. 待盤點
2. 待補貨
3. 移庫中
4. 出庫完成

## 導入效益

- 揀貨作業工時：6.9小時/日 → **2.1小時/日**
- 庫存準確率：88% → **99%**
- 出貨延遲率：9.2% → **1.9%**
- 盤點工時：17小時/月 → **2.9小時/月**
