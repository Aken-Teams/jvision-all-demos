# 自動化立體倉庫管理決策室

控制堆高機、料箱式立體倉庫的存取設備，實現高密度自動化儲存與存取。

- 原始系統：自動化立體倉庫管理系統（AS/RS Management System）
- 產業分類：智慧製造｜倉儲管理
- 使用部門：倉儲部、設備工程部、生管部、資訊部
- 工作流程：入庫申請→堆垛機調度→料箱存放→出庫指令→堆垛機取料→交付產線
- AI 應用：存取路徑最佳化、熱門料號動態前移儲位、設備故障預測維護
- 主要 KPI：出入庫效率、設備稼動率、存取準確率、單位坪效產出
- 代表產品：Daifuku（大福）、Murata Machinery（村田自動化）、SSI Schäfer、Dematic
