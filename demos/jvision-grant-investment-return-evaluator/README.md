# 補助投入產出評估器

> 量化自籌資金、核銷負擔、技術價值與成功率，篩選值得申請的補助案。

量化自籌資金、核銷負擔、技術價值與成功率，篩選值得申請的補助案。

**產業別：**專業服務　|　**系統類型：**finance-case

## 功能模組

- **自籌資金試算** — 估算現金、設備與人力投入及各期資金壓力。
- **核銷負擔估算** — 評估憑證、工時、採購程序與查核準備成本。
- **技術價值評分** — 衡量研發成果、智財、產品化與能力累積效益。
- **核准機率校準** — 依資格、主題契合與歷史結果估算成功率區間。
- **風險調整報酬** — 將補助額、投入成本、成功率與延伸價值換算為預期報酬。
- **申請組合排序** — 在資金與人力限制下排列最值得投入的補助組合。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 估算自籌投入
2. 盤點核銷工時
3. 評估技術收益
4. 校準成功機率
5. 比較風險報酬
6. 核定申請組合

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
