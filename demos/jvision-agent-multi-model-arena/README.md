**產業別：**資訊科技　|　**系統類型：**analytics-bi

## 功能模組

- **競技任務設計** — 設定共同比較任務、輸入資料、工具權限與成功條件。
- **候選模型陣容** — 配置參賽模型、推論參數、路由策略與備援組合。
- **平行對戰執行** — 以相同任務批次驅動模型及專業 Agent 完成對戰。
- **品質裁判台** — 依正確性、引用完整度、規則遵循及人工偏好評分。
- **效能成本剖析** — 比較首字延遲、總耗時、權杖成本與工具呼叫開銷。
- **模型組合決選** — 依情境權重選出主模型、備援模型與建議路由規則。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 定義競技題目
2. 編排參賽模型
3. 啟動平行競技
4. 審閱品質評分
5. 分析效能成本
6. 核定模型組合
