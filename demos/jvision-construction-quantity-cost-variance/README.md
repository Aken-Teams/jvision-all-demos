# 工程估量成本偏差預警雲

> 整合圖說版本、工程項目、模擬數量計算、單價與預算資料，提供估算核對、版本差異及成本預測，協助估算與專案團隊提早發現漏項、數量變動和單價偏差，控制追加成本及預算風險。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **估算總覽** — 呈現工程費、數量變動、預算差異與高風險項目摘要。
- **數量明細** — 依工種、樓層、區域與構件查看模擬計算數量及來源。
- **版本差異** — 比較不同圖說或估算版本的新增、刪除及數量變動。
- **單價資料庫** — 管理材料、人工與機具的模擬單價、日期及採用依據。
- **偏差預警** — 依數量、單價與預算門檻列出異常項目和影響金額。
- **成本預測** — 模擬變更、物價與執行進度情境，預測完工成本區間。

## 適合誰使用

- 工程估算師
- 成本控制工程師
- 專案經理與採購人員

## 運作流程

1. 檢視估算概況
2. 核對工程數量
3. 確認版本變動
4. 更新計價基礎
5. 處理成本預警
6. 核定完工預測

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
