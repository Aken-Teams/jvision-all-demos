# 沖壓模具沖次保養台

> 供沖壓廠按模號累計各機台沖次，交班記錄崩刃、毛邊與導柱狀態，達保養門檻自動轉待修並鎖住領用，避免超壽命繼續生產。

供沖壓廠按模號累計各機台沖次，交班記錄崩刃、毛邊與導柱狀態，達保養門檻自動轉待修並鎖住領用，避免超壽命繼續生產。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **模具健康** — 查看沖次與狀態
- **上機綁定** — 連結工單與沖床
- **沖次回報** — 累計班次產量
- **退模檢傷** — 記錄崩刃毛邊
- **保養工單** — 依門檻安排維護
- **修後放行** — 確認可再次上機

## 適合誰使用

- 模具保養員
- 沖壓班長

## 運作流程

1. 領模上機
2. 班次生產
3. 退模檢傷
4. 壽命判定
5. 拆修保養
6. 復模驗收

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
