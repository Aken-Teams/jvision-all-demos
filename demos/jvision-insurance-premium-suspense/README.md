# 保費入帳懸帳清理台

> 集中無法辨識的銀行入款，依付款人、金額、日期、保單與繳費週期提出候選配對，經覆核後完成入帳、退款或拆分，避免錯誤催繳及停效。

集中無法辨識的銀行入款，依付款人、金額、日期、保單與繳費週期提出候選配對，經覆核後完成入帳、退款或拆分，避免錯誤催繳及停效。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **入款池** — 彙整未明款項
- **候選搜尋** — 比對可能保單
- **拆款處理** — 分配多張保單
- **認領協作** — 向通路補資料
- **配對覆核** — 避免錯誤入帳
- **清帳結案** — 完成入帳退款

## 適合誰使用

- 保費會計
- 保單服務人員
- 收款主管

## 運作流程

1. 接收入款
2. 搜尋候選
3. 補充證據
4. 處理拆款
5. 覆核配對
6. 完成清帳

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
