# 混凝土澆置管制台

> 供工地在每次混凝土澆置前整合申請、數量估算、泵車與工班安排、試體抽驗、車次紀錄及異常處置，確保連續澆置條件與品質文件完整，降低待料、冷縫及超量損耗。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **澆置申請** — 登錄部位、強度、方數與預定時段。
- **前置查核** — 確認模板、鋼筋、機具與人員條件。
- **車次看板** — 排列預拌車到場與卸料模擬紀錄。
- **現場抽驗** — 記錄坍度、溫度與試體編號。
- **異常處置** — 處理退料、塞管、待料及超時事件。
- **方數結算** — 比較估算、出貨、實收與剩料數量。

## 適合誰使用

- 工地主任
- 品管工程師
- 現場工程師

## 運作流程

1. 提出申請
2. 完成查核
3. 安排車次
4. 執行抽驗
5. 處理異常
6. 完成結算

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
