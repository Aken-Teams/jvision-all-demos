# 顧問工時範圍消耗台

> 把顧問每日投入連結到合約工作包、客戶要求與變更事項，即時顯示額度燃盡及範圍蔓延，協助專案經理在服務交付前調整投入或提出加價。

**產業別：**專業服務　|　**系統類型：**collaboration-pm

## 功能模組

- **合約工作包** — 拆分範圍額度與成果
- **投入登錄** — 將工時連結具體需求
- **客戶要求** — 辨識新增或範圍內事項
- **燃盡預警** — 預測額度用完日期
- **變更提案** — 整理加價減項與證據
- **資源調整** — 核准人力與交付優先序

## 適合誰使用

- 顧問
- 專案經理
- 客戶合夥人

## 運作流程

1. 建立合約工作包
2. 連結每日投入
3. 辨識範圍蔓延
4. 預測額度燃盡
5. 提出商務變更
6. 核定投入調整

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
