# 貨運標案配額履約台

> 協助貨主將年度運輸標案的得標路線、承諾量與費率轉成每週配額，追蹤各承運商接單、拒單、準點與最低量履約情況，並為旺季轉單及下一輪議價保留量化依據。

協助貨主將年度運輸標案的得標路線、承諾量與費率轉成每週配額，追蹤各承運商接單、拒單、準點與最低量履約情況，並為旺季轉單及下一輪議價保留量化依據。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **標案合約** — 登錄路線、費率、承諾量及有效期間。
- **週配額規劃** — 依預估貨量分配各承運商運能。
- **接單監控** — 追蹤接受、拒單及未回覆運次。
- **轉單調整** — 處理容量缺口及備援承運分配。
- **履約評分** — 計算準點、拒單與量價承諾表現。
- **議價分析** — 比較標案費率與實際使用成果。

## 適合誰使用

- 運輸採購
- 物流調度
- 供應鏈主管

## 運作流程

1. 建立合約
2. 規劃配額
3. 發布需求
4. 處理缺口
5. 評核履約
6. 準備議價

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
