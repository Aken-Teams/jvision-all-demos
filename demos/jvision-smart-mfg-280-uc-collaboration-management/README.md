# 統一通訊與協作平台管理

管理公司內部視訊會議、即時通訊、電子郵件等協作平台的帳號、授權與使用政策，支援跨廠區跨國協作。

- 原始系統：統一通訊與協作平台管理（UC & Collaboration Management）
- 產業分類：智慧製造｜IT管理
- 使用部門：資訊部、行政部、人資部、各事業處
- 工作流程：帳號開通與授權指派→使用政策設定(DLP整合)→平台可用性監控→異常使用告警→授權使用量檢視→定期成本優化
- AI 應用：會議逐字稿與重點摘要、異常訊息外流行為偵測
- 主要 KPI：平台可用率、授權使用率、資料外洩事件數、使用者滿意度
- 代表產品：Microsoft Teams、Zoom、Cisco Webex、Slack
