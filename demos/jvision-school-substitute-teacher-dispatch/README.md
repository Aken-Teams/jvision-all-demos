# 校園代課調度管理台

> 協助學校在教師請假後快速盤點課表衝突、代課資格、授課節數與鐘點費，完成邀請、確認、課務交接及費用核算，降低臨時空堂與行政反覆聯繫。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **缺課總覽** — 呈現待媒合節次與急迫缺口。
- **請假拆課** — 依課表拆解日期、班級及科目。
- **人選篩選** — 比對資格、空堂及節數限制。
- **代課邀請** — 管理邀請順位與回覆期限。
- **課務交接** — 整理教材、進度及班級提醒。
- **授課核薪** — 確認實授節數與鐘點費資料。

## 適合誰使用

- 教務組員
- 年級主任
- 出納人員

## 運作流程

1. 檢視缺口
2. 拆解課表
3. 篩選人選
4. 發出邀請
5. 完成交接
6. 核算費用

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
