**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **準則校準室** — 整理團隊編碼、架構與測試準則，處理規則間的衝突。
- **可維護性熱區** — 依複雜度、變更頻率與事故紀錄定位高風險程式區塊。
- **程式脈絡檢視** — 串聯需求、架構決策、測試與事件，解釋程式碼形成原因。
- **重構方案工坊** — 產生符合團隊準則的可比較重構方案與預期品質收益。
- **變更驗證沙盒** — 模擬重構影響並執行測試、相依性與回歸風險檢查。
- **改善交付中心** — 拆分可執行任務、追蹤 Agent 交接並在失敗時安全回滾。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 校準工程準則
2. 鎖定維護熱區
3. 還原設計脈絡
4. 比較重構方案
5. 驗證品質影響
6. 交付持續改善

- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
- 資產盤點工時：20小時/月 → **4小時/月**
