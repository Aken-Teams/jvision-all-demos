# 鋼板鏽蝕缺陷智慧檢測系統

> 以擬真的鋼板表面影像辨識鏽斑、點蝕與片狀鏽蝕，量化面積、密度及嚴重等級，協助品管人員複判、隔離批次，並結合庫位與存放時間追查受潮風險及改善防鏽管理。

以擬真的鋼板表面影像辨識鏽斑、點蝕與片狀鏽蝕，量化面積、密度及嚴重等級，協助品管人員複判、隔離批次，並結合庫位與存放時間追查受潮風險及改善防鏽管理。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **鏽蝕影像佇列** — 依批次、庫位、鋼種及判定狀態呈現待檢影像。
- **鏽蝕複判工作台** — 放大影像、調整標記並確認鏽斑、點蝕或片狀鏽蝕。
- **缺陷量化分級** — 計算鏽蝕面積、密度、分布及嚴重等級。
- **批次隔離處置** — 執行放行、除鏽、降級或隔離並建立處置紀錄。
- **儲運風險追溯** — 比對庫位濕度、存放天數、包裝與運輸條件的擬真資料。
- **防鏽改善分析** — 統計受潮來源、重複發生區域及防鏽措施前後成效。

## 適合誰使用

- 品管檢驗員
- 倉儲主管
- 品質工程師

## 運作流程

1. 篩選鏽蝕影像
2. 複核缺陷類型
3. 量化鏽蝕等級
4. 執行批次處置
5. 追溯儲運風險
6. 驗證防鏽改善

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
