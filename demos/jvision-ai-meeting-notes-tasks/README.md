# 智慧會議紀錄與任務追蹤

> 以擬真會議內容模擬逐字紀錄、重點摘要、決議辨識與待辦抽取，將討論結果轉成可指派、可追蹤的工作項目。團隊可校正紀錄、確認責任人、管理期限並檢視跨會議執行狀態。

以擬真會議內容模擬逐字紀錄、重點摘要、決議辨識與待辦抽取，將討論結果轉成可指派、可追蹤的工作項目。團隊可校正紀錄、確認責任人、管理期限並檢視跨會議執行狀態。

**產業別：**企業協作　|　**系統類型：**collaboration-pm

## 功能模組

- **會議排程總覽** — 瀏覽近期會議、與會者、議程及準備狀態。
- **逐字紀錄檢視** — 以模擬逐字稿呈現講者、時間與討論段落。
- **智慧摘要編修** — 檢視並調整議題重點、風險與討論結論。
- **決議確認中心** — 逐項確認會議決議、依據與相關負責人。
- **任務指派看板** — 將待辦指派給成員並設定期限與優先級。
- **跨會議追蹤** — 彙整不同會議的任務進度、逾期與阻礙。

## 適合誰使用

- 會議主持人
- 專案經理
- 部門主管與一般與會者

## 運作流程

1. 建立會議議程
2. 檢視逐字紀錄
3. 編修會議摘要
4. 確認正式決議
5. 指派追蹤任務
6. 檢討執行進度

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
