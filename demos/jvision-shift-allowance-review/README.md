# 輪班津貼異常覆核台

> 比對班表、打卡、換班紀錄與津貼代碼，找出跨夜、臨時換班、請假及重複計給異常，由主管確認實際班別後產出薪資可用的核定明細。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **班表匯入** — 彙整排班與換班版本
- **打卡比對** — 核對實際上下班時段
- **津貼規則** — 維護跨夜職務與假日條件
- **異常清單** — 分類漏發重發及衝突
- **主管覆核** — 確認實際工作班別
- **薪資輸出** — 產出核定津貼明細

## 適合誰使用

- 薪酬人員
- 部門主管
- 人資主管

## 運作流程

1. 載入資料
2. 執行比對
3. 套用規則
4. 說明差異
5. 核准津貼
6. 送入薪資

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
