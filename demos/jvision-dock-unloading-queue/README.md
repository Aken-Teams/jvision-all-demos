# 物流到站待卸排隊台

> 管理車輛到站報到、文件完整度、月台需求與急件順位，讓調度依到達時間和作業條件安排待卸隊列，並記錄等待、插隊與換班交接。

管理車輛到站報到、文件完整度、月台需求與急件順位，讓調度依到達時間和作業條件安排待卸隊列，並記錄等待、插隊與換班交接。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **到站隊列** — 查看報到時間與順位
- **文件預檢** — 確認單據封條與預報
- **月台需求** — 標記設備溫層及卸法
- **優先排序** — 安排急件預約與一般車
- **進台作業** — 記錄進出時間與月台
- **等待分析** — 追蹤延誤原因與費用

## 適合誰使用

- 場站調度
- 月台主管
- 司機窗口

## 運作流程

1. 車輛報到
2. 預檢文件
3. 確認需求
4. 安排順位
5. 完成卸貨
6. 檢討等待

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
