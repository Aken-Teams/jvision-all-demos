# 校園能耗安全維運平台

> 以模擬電表、空調、消防、門禁與設備巡檢資料建立校園維運總覽，辨識能耗異常及安全風險，協助人員建立工單、安排巡檢、比較節能方案，並追蹤缺失改善與設備生命週期。

以模擬電表、空調、消防、門禁與設備巡檢資料建立校園維運總覽，辨識能耗異常及安全風險，協助人員建立工單、安排巡檢、比較節能方案，並追蹤缺失改善與設備生命週期。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **校園能耗總覽** — 比較建物、時段與設備類別的模擬用電及基準差異。
- **異常安全中心** — 集中呈現能耗突升、設備故障與消防門禁等模擬風險。
- **維修工單管理** — 建立故障處置、責任人、所需零件、期限與完工紀錄。
- **巡檢任務中心** — 安排例行巡檢路線，填寫檢查結果、照片占位與缺失。
- **節能情境評估** — 比較空調時程、照明策略與設備更新的預估節能效果。
- **設備生命週期** — 檢視維修履歷、故障頻率、保養週期與汰換優先序。

## 適合誰使用

- 校園總務人員
- 設備維護技師
- 能源管理員
- 安全主管

## 運作流程

1. 掌握能耗表現
2. 判讀安全異常
3. 派送維修工單
4. 執行設備巡檢
5. 比較節能方案
6. 規劃設備汰換

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
