# 業主估驗收款核對台

> 將承商申報、監造核定、發票、保留款、罰扣及銀行入帳逐期勾稽，拆解短收原因並追蹤待收差額，避免漏開票和應收帳齡失真。

將承商申報、監造核定、發票、保留款、罰扣及銀行入帳逐期勾稽，拆解短收原因並追蹤待收差額，避免漏開票和應收帳齡失真。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **期別總覽** — 查看申報核定與收款
- **核定差異** — 分析刪減及保留款
- **發票勾稽** — 核對開票金額與期間
- **入帳配對** — 媒合銀行款項與期別
- **短收追查** — 分類扣款與待收差額
- **帳齡分析** — 追蹤逾期和現金流

## 適合誰使用

- 應收會計
- 估驗工程師
- 專案財務

## 運作流程

1. 接收核定
2. 拆解差額
3. 開立發票
4. 配對入帳
5. 追查短收
6. 關閉期別

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
