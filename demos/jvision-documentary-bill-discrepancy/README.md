> 逐條登錄信用狀與押匯單據差異，管理出口商補件、接受瑕疵、提示期限及版本比較，確保每項舊缺失均已關閉並留下對外通知證據。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **單據清冊** — 整理押匯文件
- **瑕疵圈選** — 對照信用狀條款
- **補件往返** — 追蹤客戶回覆
- **版本比較** — 確認缺失修正
- **提示期限** — 監控法定時限
- **處置結案** — 記錄補正接受

## 適合誰使用

- 押匯經辦
- 貿易融資主管
- 法遵人員

## 運作流程

1. 收件建案
2. 檢查瑕疵
3. 通知客戶
4. 覆核新版
5. 決定提示
6. 完成結案

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
