# 法令遵循管理系統（Compliance）

> 把分散數據變成可下鑽、可決策的經營洞察

法令遵循管理系統（Compliance）提供法規資料庫與異動追蹤、合規檢核清單與自評、出口管制/貿易合規篩查。法務部依「法規盤點 → 合規檢核設計 → 定期自評 → 違規通報 → 矯正措施 → 稽核複查」推進作業，優先解決「跨國法規更新掌握不及時」，稽核室則以合規檢核完成率與違規事件數確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**經營管理　|　**系統類型：**BI 商業智慧

## 功能模組

- **經營儀表板** — 關鍵指標即時總覽
- **趨勢分析** — 多維度趨勢與比較
- **指標下鑽** — 逐層鑽取到明細
- **平衡計分卡** — 策略目標與 KPI 對齊
- **AI 洞察** — 自動發現異常與機會
- **報表匯出** — 排程報表與分享

## 適合誰使用

- 法務部
- 稽核室
- 人資部

## 運作流程

1. 待釐清
2. 改善中
3. 核定確認
4. 已解除
