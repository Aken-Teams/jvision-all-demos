# Agent 邊界條件驗證器

> 以空值、矛盾、逾時與部分失敗情境，驗證 Agent 的例外韌性。

以空值、矛盾、逾時與部分失敗情境，驗證 Agent 的例外韌性。

**產業別：**資訊科技　|　**系統類型：**quality-qms

## 功能模組

- **空值缺欄測試** — 注入缺少必填值、空白內容與未知欄位，檢查判斷及追問行為。
- **矛盾資料測試** — 建立跨來源衝突、時間倒置及互斥事實，驗證取捨與說明能力。
- **工具逾時測試** — 模擬延遲、無回應與超時重試，檢查截止時間與替代路徑。
- **部分失敗測試** — 讓多工具流程僅部分成功，驗證狀態保存、回復與人工接管。
- **重試冪等驗證** — 重播相同請求及延遲回應，偵測重複寫入與不一致副作用。
- **韌性門檻判定** — 彙整恢復率、誤動作與處理時間，判定是否符合上線門檻。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 設定邊界矩陣
2. 驗證空值處理
3. 驗證矛盾判讀
4. 驗證逾時恢復
5. 驗證部分失敗
6. 裁定韌性結果
