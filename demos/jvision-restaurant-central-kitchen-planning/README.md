# 餐飲中央廚房備料台

> 協助連鎖餐飲依門市銷售預估彙整中央廚房備料、半成品分裝、批次效期與配送需求，降低臨時追加、備料過量及門市缺料造成的營運損失。

協助連鎖餐飲依門市銷售預估彙整中央廚房備料、半成品分裝、批次效期與配送需求，降低臨時追加、備料過量及門市缺料造成的營運損失。

**產業別：**餐飲旅宿　|　**系統類型：**erp

## 功能模組

- **需求預估** — 彙整各門市品項需求與活動修正量。
- **原料盤點** — 檢視原料、半成品與可用效期批次。
- **備料排程** — 安排製程順序、人力與預計完成時間。
- **分裝作業** — 管理門市別分裝數量與標籤狀態。
- **配送彙整** — 建立配送梯次及門市交付清單。
- **耗損分析** — 比較需求、實作、退回及報廢差異。

## 適合誰使用

- 中央廚房主管
- 採購人員
- 門市店長

## 運作流程

1. 彙整需求
2. 核對存量
3. 建立排程
4. 完成分裝
5. 安排配送
6. 檢討差異

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
