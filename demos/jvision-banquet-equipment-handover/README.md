**產業別：**餐飲旅宿　|　**系統類型：**warehouse-wms

## 功能模組

- **活動需求** — 彙整器材清單
- **器材預留** — 鎖定可用設備
- **出庫交接** — 記錄領用責任
- **跨廳轉借** — 更新即時保管
- **收場點收** — 核對歸還狀態
- **損壞結案** — 判定維修賠償

## 適合誰使用

- 宴會領班
- 器材管理員
- 值班經理

## 運作流程

1. 提出需求
2. 確認預留
3. 領用交接
4. 轉借更新
5. 收場點收
6. 異常結案

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
