# 經銷返利級距預警台

> 依經銷合約級距、有效銷售、退貨與指定品類，試算期間返利及距下一級門檻，提示異常衝量和可能跨級成本，協助業務在承諾前掌握毛利影響。

**產業別：**業務銷售　|　**系統類型：**sales-crm

## 功能模組

- **合約級距** — 維護門檻比率與適用品
- **達成看板** — 查看經銷累計與差距
- **退貨調整** — 排除退貨取消與不適用
- **情境試算** — 模擬新增訂單及跨級成本
- **衝量預警** — 標記異常集中與低毛利
- **預估發布** — 輸出業務與財務共用版

## 適合誰使用

- 通路業務
- 財務分析
- 業務主管

## 運作流程

1. 設定級距
2. 彙整銷售
3. 調整退貨
4. 模擬情境
5. 檢查風險
6. 發布預估
