# 校外實習媒合督導台

> 供技專校院管理學生校外實習的職缺審查、志願媒合、合約文件、到職追蹤、教師訪視與異常退場，確保學習目標、勞動條件及校方督導責任落實。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **實習職缺** — 管理企業、工作內容與勞動條件。
- **志願媒合** — 比對學生志願、資格與職缺名額。
- **文件簽核** — 追蹤合約、保險與家長文件。
- **到職確認** — 記錄報到、企業導師與實習期間。
- **訪視督導** — 安排教師訪視及改善追蹤。
- **異常退場** — 處理申訴、轉換單位與提前終止。

## 適合誰使用

- 實習承辦人
- 系所教師
- 企業導師

## 運作流程

1. 審查實習職缺
2. 完成志願媒合
3. 備妥實習文件
4. 確認學生到職
5. 執行教師訪視
6. 處理異常退場

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
