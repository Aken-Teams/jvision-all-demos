# 工程詢疑與設變分析台

> 集中管理工程詢疑單、圖說回覆與設計變更，透過擬真關聯分析呈現受影響的工項、成本、工期及責任界面，協助專案團隊在核准前完成衝擊評估、協調與追蹤。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **詢疑總覽** — 依專案、急迫度與逾期狀態彙整待辦及風險。
- **詢疑建單** — 建立問題、圖面標記、責任單位與要求回覆日期。
- **圖說版次比對** — 並排呈現新舊圖說與模擬差異標註。
- **影響關聯分析** — 展開設變涉及的工項、界面、材料與文件關聯。
- **成本工期試算** — 模擬不同處置方案的追加成本與工期衝擊。
- **協調放行追蹤** — 呈現會簽意見、核准條件與現場落實進度。

## 適合誰使用

- 專案經理
- 工地主任
- 設計顧問
- 成本工程師

## 運作流程

1. 掌握待辦
2. 提出詢疑
3. 確認差異
4. 盤點衝擊
5. 評估方案
6. 核准執行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
