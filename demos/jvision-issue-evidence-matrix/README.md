# 爭點證據矩陣

將案件主張、法律要件、證據與反證連結成矩陣，找出訴訟缺口與攻防優先序。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **主張樹建模** — 拆解原告與被告主張，建立爭點、子爭點及依存關係。
- **要件拆解** — 把請求權基礎與抗辯轉為可逐項驗證的法律要件。
- **證據掛接** — 將卷證、證詞與鑑定資料連結至支持或否定的要件。
- **反證攻防** — 並列相反證據、可信度爭議與可能的對方攻擊路徑。
- **缺口矩陣** — 以矩陣標示未證明、證據衝突及證明力不足的區域。
- **策略模擬** — 模擬補證、撤回主張或調整攻防後的勝算與資源影響。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 建立主張樹
2. 確認法律要件
3. 配置卷內證據
4. 檢視反證攻防
5. 處理證據缺口
6. 核定訴訟策略

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
