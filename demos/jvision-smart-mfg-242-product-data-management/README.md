# PDM（Product Data Management，產品資料管理）

> 保養、維修、預兆到備品的設備全生命週期

PDM（Product Data Management，產品資料管理）提供CAD檔案版本控制、零件庫與標準件管理、設計簽核與存取權限控制。研發專案管理師、研發經理、技術長依「CAD檔案版本控制、零件庫與標準件管理、設計簽核與存取權限控制」推進作業，優先解決「CAD檔案版本覆蓋、遺失」，部門主管則以PDM管理艙處理結果確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**研發管理　|　**系統類型：**CMMS 設備維護

## 功能模組

- **保養排程** — 預防保養自動排程
- **維修工單** — 報修、派工與完工
- **預兆診斷** — 設備數據異常預警
- **備品管理** — 備品庫存與領用
- **OEE 稼動** — 稼動與故障分析
- **履歷追溯** — 設備維護履歷

## 適合誰使用

- 研發專案管理師
- 研發經理
- 技術長

## 運作流程

1. 規劃中
2. 執行中
3. 驗證中
4. 發布完成

## 導入效益

- 設計變更工時：8小時 → **2小時**
- 文件版本錯誤：5.8件/月 → **1件/月**
- 專案準時率：74% → **86%**
- 資料查找時間：31分鐘 → **5.2分鐘**
