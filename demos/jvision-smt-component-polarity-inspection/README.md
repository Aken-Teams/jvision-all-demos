# 表面黏著元件極性檢測

> 利用擬真的板件影像、元件方向標記與設計基準，檢測二極體、電解電容及積體電路等有極性元件的裝配方向，協助檢驗員複核疑似反向位置並避免通電失效。

利用擬真的板件影像、元件方向標記與設計基準，檢測二極體、電解電容及積體電路等有極性元件的裝配方向，協助檢驗員複核疑似反向位置並避免通電失效。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **極性風險總覽** — 彙整產品、工單及元件類型的極性錯誤與待複核數量。
- **板件方向地圖** — 在擬真板圖上標示所有有極性元件及疑似反向熱區。
- **極性影像判讀** — 放大元件圓點、缺口、色帶與正負符號等方向特徵。
- **設計基準比對** — 並排比較實際方向、設計圖示、封裝規則與預期角度。
- **疑似錯誤複核** — 依信心分數逐筆模擬確認、駁回或標記需要返修。
- **方向修正驗證** — 追蹤模擬返修狀態並比較修正前後影像與複檢結論。

## 適合誰使用

- 自動光學檢測操作員
- 品質工程師
- 返修技術員

## 運作流程

1. 盤點極性風險
2. 定位疑似位置
3. 辨識方向特徵
4. 核對設計基準
5. 完成人工複核
6. 驗證方向修正

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
