# 餐廳備料耗損管制台

> 供連鎖餐廳依訂位、歷史銷量與菜單需求規劃每日備料，記錄領料、製成率、報廢及跨店調撥，協助店長降低缺料停賣與食材過量耗損。

供連鎖餐廳依訂位、歷史銷量與菜單需求規劃每日備料，記錄領料、製成率、報廢及跨店調撥，協助店長降低缺料停賣與食材過量耗損。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **備料總覽** — 彙整各店需求、缺口與異常。
- **菜單展算** — 將銷量換算為原料需求量。
- **備料工單** — 安排品項、批次及負責站別。
- **跨店調撥** — 媒合餘料門市與缺料門市。
- **耗損登錄** — 記錄報廢數量、原因與責任區。
- **差異分析** — 比較理論耗用與實際耗用。

## 適合誰使用

- 餐廳店長
- 廚房主管
- 成本會計

## 運作流程

1. 檢視需求
2. 展算原料
3. 發布備料
4. 處理缺口
5. 登錄耗損
6. 覆核差異

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
