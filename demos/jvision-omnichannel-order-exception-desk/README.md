# 全通路訂單例外處理台

> 集中處理官網、門市與平台訂單的缺貨、拆單、改址、付款卡單及逾時出貨，依服務時限分派責任單位並提供可選補救方案。

集中處理官網、門市與平台訂單的缺貨、拆單、改址、付款卡單及逾時出貨，依服務時限分派責任單位並提供可選補救方案。

**產業別：**零售電商　|　**系統類型：**operations-console

## 功能模組

- **例外佇列** — 集中顯示跨通路卡關訂單與時限。
- **原因判定** — 分類缺貨、付款、地址及配送問題。
- **處理分流** — 依原因派給客服、倉庫或門市。
- **補救方案** — 比較調貨、拆單、替代品與退款選項。
- **時限追蹤** — 監看承諾回覆與出貨恢復期限。
- **結案覆盤** — 確認訂單結果並統計重複根因。

## 適合誰使用

- 電商營運專員
- 訂單客服
- 倉配協調員

## 運作流程

1. 接收例外
2. 判定原因
3. 分派處理
4. 選擇補救
5. 恢復履約
6. 確認結案

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
