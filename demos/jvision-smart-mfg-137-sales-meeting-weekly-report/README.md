# 業務會議週報管理 Sales Meeting & Weekly Report指揮台

標準化業務週報與會議紀錄的填報、彙整與追蹤，讓主管掌握團隊動態並落實行動追蹤。

- 原始系統：業務會議週報管理 Sales Meeting & Weekly Report
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、業務主管、總經理室
- 工作流程：業務填寫週報→主管審閱回饋→彙總團隊週報→會議討論重點案件→追蹤行動項目結案
- AI 應用：週報內容自動摘要與重點萃取、行動項目逾期自動提醒
- 主要 KPI：週報準時提交率、行動項目結案率、重點問題上報時效、會議跟進完成率
- 代表產品：Microsoft Teams+Power Automate、Notion、自建CRM週報模組
