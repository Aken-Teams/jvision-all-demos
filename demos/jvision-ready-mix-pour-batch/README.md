# 預拌車澆置批次台

> 依澆置區與混凝土配比建立叫料批次，登錄每車出廠、到場、卸料、退料及方數，勾稽送貨單與供應商請款並辨識等候過久。

依澆置區與混凝土配比建立叫料批次，登錄每車出廠、到場、卸料、退料及方數，勾稽送貨單與供應商請款並辨識等候過久。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **澆置批次** — 建立區域與配比批次
- **車次追蹤** — 記錄每車關鍵時間
- **方數核對** — 核對叫料實收與退料
- **等待監控** — 標示逾時到場與卸料
- **送單勾稽** — 連結送貨單及異常
- **請款覆核** — 彙總供料計價數量

## 適合誰使用

- 混凝土工程師
- 現場監工
- 材料會計

## 運作流程

1. 建立批次
2. 安排叫料
3. 車次到場
4. 卸料驗收
5. 批次結算
6. 請款核認

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
