# 商辦停車位配額管理台

> 管理租戶固定、臨停與訪客車位配額，處理增減申請、候補排序、車號名冊、費用起訖及違規占用，提升有限車位使用效率。

管理租戶固定、臨停與訪客車位配額，處理增減申請、候補排序、車號名冊、費用起訖及違規占用，提升有限車位使用效率。

**產業別：**房地產與物業　|　**系統類型：**operations-console

## 功能模組

- **車位總覽** — 查看固定、臨停及保留車位狀態。
- **租戶配額** — 維護各租戶合約配額與使用數。
- **增減申請** — 處理車位新增、退租與期間變更。
- **候補排序** — 依規則安排需求租戶遞補。
- **車號名冊** — 管理授權車輛及替換紀錄。
- **費用結算** — 計算月費、臨停與起訖調整。

## 適合誰使用

- 物業行政
- 租戶窗口
- 停車管理員

## 運作流程

1. 盤點可用車位
2. 受理租戶申請
3. 審核配額資格
4. 安排候補遞補
5. 啟用車號權限
6. 完成費用結算

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
