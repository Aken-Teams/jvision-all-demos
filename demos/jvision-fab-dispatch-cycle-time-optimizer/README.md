**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **產線戰情** — 總覽在製量、交期風險、瓶頸站點與班別負荷。
- **派工排序** — 依交期、等待時間及設備資格產生批次優先序。
- **批次路徑** — 查看批次目前站點、後續流程與預估等待時間。
- **瓶頸分析** — 呈現站點排隊、設備負載與未來壅塞熱區。
- **策略模擬** — 比較急單、最短流程及瓶頸優先等派工情境。
- **班別發布** — 確認派工清單、例外理由與交接事項的展示紀錄。

## 適合誰使用

- 生產管制員
- 值班主管
- 工業工程師

## 運作流程

1. 掌握產況
2. 建立排序
3. 檢查路徑
4. 分析瓶頸
5. 模擬策略
6. 發布交班

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
