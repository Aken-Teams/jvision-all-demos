# 再出口規則計算器

> 計算原產技術與受控含量，判斷跨境交易路徑涉及的再出口義務。防範域外管制風險。

計算原產技術與受控含量，判斷跨境交易路徑涉及的再出口義務。防範域外管制風險。

**產業別：**採購供應鏈　|　**系統類型：**legal-case

## 功能模組

- **技術來源圖譜** — 追溯產品、軟體、設備及製程中受管制技術的來源。
- **受控含量計算** — 依市場價值與規則口徑計算受控項目的含量比例。
- **直接產品規則測試** — 判斷境外產品是否因技術或設備關係落入直接產品規則。
- **交易路徑義務圖** — 映射出口、再出口、境內移轉各節點的管制義務。
- **管轄判定工作台** — 整合分類、目的地、交易方與例外條件形成適用結論。
- **再出口判定書** — 產出計算明細、規則依據、缺口及許可需求草案。

## 適合誰使用

- 國貿主管
- 報關人員
- 業務

## 運作流程

1. 追溯技術來源
2. 計算受控含量
3. 測試直接產品規則
4. 映射交易義務
5. 審定管轄結論
6. 核准判定文件
