# 空壓機漏氣智慧偵測系統

> 透過擬真的聲學巡檢、管線位置與耗能資料，標示壓縮空氣疑似洩漏點，估算漏氣量、電費與碳排損失，協助工廠依效益安排修繕、複驗成果，建立可追蹤的節能改善紀錄。

透過擬真的聲學巡檢、管線位置與耗能資料，標示壓縮空氣疑似洩漏點，估算漏氣量、電費與碳排損失，協助工廠依效益安排修繕、複驗成果，建立可追蹤的節能改善紀錄。

**產業別：**ESG 永續　|　**系統類型：**esg-energy

## 功能模組

- **漏氣熱點地圖** — 在廠區平面圖呈現疑似漏氣點、嚴重度與修繕狀態。
- **聲學特徵檢視** — 展示擬真頻譜、音量特徵及疑似洩漏判定依據。
- **能源損失估算** — 依壓力、孔徑與運轉時間估算風量、電費及碳排損失。
- **修繕優先排序** — 依損失金額、安全影響與施工難度排列案件。
- **修繕案件管理** — 指派負責人、記錄處置方式、材料與完工日期。
- **複驗節能成果** — 比較修繕前後特徵與損失，確認節能量及案件結案。

## 適合誰使用

- 能源管理員
- 廠務工程師
- 管線維修人員

## 運作流程

1. 定位漏氣熱點
2. 確認聲學特徵
3. 估算能源損失
4. 排定修繕順序
5. 執行管線修繕
6. 複驗節能成果

## 導入效益

- 盤查作業工時：40小時 → **8小時**
- 數據完整率：60% → **95%**
- 減碳目標達成：50% → **88%**
- 用能異常反應：24小時 → **2小時**
