# 投標風險挑戰 Agent

> 以評審與法務視角挑戰投標假設、資格與成本缺口，提升 Go／No-Go 決策品質。

以評審與法務視角挑戰投標假設、資格與成本缺口，提升 Go／No-Go 決策品質。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **標案挑戰台** — 彙整公告重點、評選方法與待驗證投標假設。
- **資格攻防檢查** — 逐條比對資格門檻、證照效期與公司實績。
- **法務條款質疑** — 辨識責任失衡、違約風險與模糊履約義務。
- **成本壓力測試** — 模擬低價得標、成本上升與付款延遲情境。
- **模擬評審會** — 由技術、商務與法務角色交叉追問提案弱點。
- **Go／No-Go 裁** — 依缺口嚴重度、勝率及補救成本產出決策建議。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 建立挑戰題
2. 攻防資格
3. 質疑條款
4. 壓測成本
5. 模擬評選
6. 裁定進退

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
