# 教師備課與課堂助理

> 協助教師以模擬課綱資料完成單元備課、教材內容對標與教學活動設計，人工智慧可摘要素材、提示目標缺口、產生課堂提問及差異化活動，並在課後彙整觀察紀錄與待調整事項。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **單元備課工作室** — 依教學目標組合課程流程、時間配置、素材與教師備註。
- **教材課綱對標** — 呈現教材段落與學習表現、內容指標及缺口的對照關係。
- **提問活動設計** — 建立引導問題、分組任務、差異化活動及預期學生回應。
- **教學素材中心** — 整理模擬文章、圖卡、學習單與可重用的單元素材。
- **課堂助理模式** — 以教學時間軸顯示下一步、提問提示與臨時調整選項。
- **課後反思紀錄** — 彙整課堂觀察、學生反應、未完成內容與下次修訂建議。

## 適合誰使用

- 中小學教師
- 教學組長
- 教材編輯
- 代課教師

## 運作流程

1. 規劃單元教案
2. 完成教材對標
3. 設計提問活動
4. 整理教學素材
5. 執行課堂流程
6. 完成課後反思

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
