# 窯車耐火材點檢台

> 供陶瓷與玻璃廠逐台記錄窯車耐火磚、立柱、墊板與密封裙狀態，出窯後分級缺損並安排冷修，防止碎落污染或窯內倒塌。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **窯車總覽** — 查看可用待修狀態
- **部位檢點** — 記錄磚柱墊板
- **禁用鎖車** — 隔離重大缺損
- **冷修工單** — 安排拆補更換
- **平整校正** — 驗證修後尺寸
- **復用放行** — 交還裝窯班

## 適合誰使用

- 窯爐技師
- 裝窯班長

## 運作流程

1. 出窯清車
2. 部位點檢
3. 缺損分級
4. 窯車冷修
5. 尺寸校正
6. 裝窯復用

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
