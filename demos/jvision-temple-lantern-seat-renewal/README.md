> 協助宮廟管理光明燈、太歲燈與文昌燈等燈種的年度燈位、信眾資料、續登優先期、收款與安奉名冊，避免重複占位、姓名錯植及跨年度資料遺漏。

協助宮廟管理光明燈、太歲燈與文昌燈等燈種的年度燈位、信眾資料、續登優先期、收款與安奉名冊，避免重複占位、姓名錯植及跨年度資料遺漏。

**產業別：**宗教服務　|　**系統類型：**operations-console

## 功能模組

- **燈位配置** — 依燈種、區域與編號建立年度可用燈位。
- **舊戶續登** — 管理原燈位保留期限與續登狀態。
- **新戶候補** — 依申請時間及偏好排列候補順位。
- **資料校對** — 核對姓名、生辰、地址與祈福文字。
- **收款核銷** — 記錄現金、匯款及收據開立情形。
- **安奉名冊** — 產出燈位名冊並追蹤更正及完成狀態。

## 適合誰使用

- 宮廟櫃台
- 燈務承辦
- 財務志工

## 運作流程

1. 設定燈位
2. 辦理續登
3. 安排候補
4. 校對資料
5. 完成收款
6. 發布名冊

## 導入效益

- 活動籌備工時：20小時 → **5小時**
- 報名掌握率：65% → **94%**
- 物資盤點：6小時 → **1小時**
- 志工調度時效：3天 → **1天**
