# 住戶驗屋複驗排程台

> 將住戶驗屋缺失按工種拆派，依完修狀態、住戶可約時間與工班到場能力安排複驗，避免漏項、空跑及多次無效約驗。

將住戶驗屋缺失按工種拆派，依完修狀態、住戶可約時間與工班到場能力安排複驗，避免漏項、空跑及多次無效約驗。

**產業別：**營建工程　|　**系統類型：**service-desk

## 功能模組

- **戶別總覽** — 查看缺失與可約狀態
- **完修確認** — 核對工班回報與照片
- **複驗排程** — 媒合住戶與陪驗人員
- **到場通知** — 同步時間及注意事項
- **現場複驗** — 逐項記錄接受或退修
- **複驗分析** — 統計重約與高頻缺失

## 適合誰使用

- 交屋客服
- 修繕工程師
- 住戶服務專員

## 運作流程

1. 拆分缺失
2. 完成修繕
3. 確認可驗
4. 協調時段
5. 執行複驗
6. 住戶簽認

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
