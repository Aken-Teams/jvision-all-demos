# 雲端資源管理平台（Cloud Management Platform, CMP）

> 服務工單、資產到即時監控的 IT 維運

雲端資源管理平台（Cloud Management Platform, CMP）提供多雲資源盤點與可視化、成本分析與預算控管(FinOps)、資源自動擴縮與排程。資訊部依「雲端資源上架→標籤與權限設定→用量與成本監控→異常/超支告警→優化建議執行→月度報表」推進作業，優先解決「雲端費用失控超支」，財務部則以雲端成本節省率與資源使用率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**資訊科技　|　**系統類型：**IT 維運管理平台

## 功能模組

- **多雲資源盤點** — 跨 AWS/Azure/GCP 資源清冊與拓撲可視化
- **成本分析 FinOps** — 花費歸屬、標籤分攤與預算控管
- **用量監控** — 運算/儲存/網路即時用量與健康度
- **超支告警** — 預算門檻與異常花費即時告警分派
- **優化建議** — 閒置資源、規格調整與保留方案建議
- **月度報表** — 成本節省率、資源使用率與稽核報表

## 適合誰使用

- 資訊部
- 財務部
- 雲端維運團隊

## 運作流程

1. 資源盤點上架
2. 標籤與成本歸屬
3. 用量與成本監控
4. 超支告警分派
5. 優化執行與報表

## 導入效益

- 事件平均處理：113分鐘 → **28分鐘**
- 系統可用率：91% → **93%**
- SLA達成率：80% → **92%**
- 資產盤點工時：19小時/月 → **3.8小時/月**
