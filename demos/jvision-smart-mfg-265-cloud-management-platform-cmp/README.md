# 雲端資源管理指揮台

統一管理跨公有雲、私有雲與混合雲資源，控管成本、效能與治理政策。

- 原始系統：雲端資源管理平台（Cloud Management Platform, CMP）
- 產業分類：智慧製造｜IT管理
- 使用部門：資訊部、財務部、雲端維運團隊、資安部
- 工作流程：雲端資源上架→標籤與權限設定→用量與成本監控→異常/超支告警→優化建議執行→月度報表
- AI 應用：用量預測與成本優化建議、閒置資源自動偵測、異常花費告警
- 主要 KPI：雲端成本節省率、資源使用率、預算達成率、安全合規率
- 代表產品：VMware Aria (原vRealize)、Flexera CloudHealth、Morpheus Data、Microsoft Azure Cost Management
