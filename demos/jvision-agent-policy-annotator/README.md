**產業別：**資訊科技　|　**系統類型：**security-soc

## 功能模組

- **Agent 流程畫布** — 展開任務節點、分支、工具呼叫與資料流向。
- **節點政策註解** — 將權限、法遵、資料與成本規則綁定至指定節點。
- **工具權限邊界** — 限制各節點可用工具、操作範圍與授權層級。
- **資料使用約束** — 設定敏感欄位遮罩、留存、跨境與用途限制。
- **政策路徑模擬** — 模擬正常、越權與例外路徑的政策判定結果。
- **治理套件發布** — 版本化發布政策並驗證執行環境已正確套用。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 展開 Agent 流程
2. 標註治理規則
3. 界定工具權限
4. 限制資料使用
5. 模擬政策判定
6. 核准並發布
