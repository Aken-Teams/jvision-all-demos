# 設計選品採購板

> 供應商協同、詢比議價到交期風險控管

管理選品板、採購、到貨、安裝與客戶確認。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**營建工程　|　**系統類型：**SRM 採購供應商管理

## 功能模組

- **供應商管理** — 建檔、分級與績效評分
- **詢報價協作** — 線上詢價、比價與議價
- **採購訂單** — 請購、下單與交期追蹤
- **交期風險** — 缺料預警與到貨監控
- **供應商品質** — 進料檢驗與 SCAR 改善
- **綠色採購** — ESG 評分與永續採購

## 適合誰使用

- 工班專員
- 工班主管
- 營建工程主管

## 運作流程

1. 待釐清
2. 現場處理
3. 待查驗
4. 計價完成

## 導入效益

- 日報彙整工時：3.2小時/日 → **0.5小時/日**
- 進度落後預警：39% → **92%**
- 估驗計價天數：10天 → **3.8天**
- 缺失改善時效：6.7天 → **2天**
