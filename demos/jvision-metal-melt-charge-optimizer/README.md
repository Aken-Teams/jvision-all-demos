# 金屬熔煉配料最佳化器

> 依目標合金成分、原料庫存、回爐料、元素收得率與價格等擬真資料，自動組合多套配料方案，比較成本、成分命中及供料風險，協助熔煉與採購共同決定可執行爐料。

依目標合金成分、原料庫存、回爐料、元素收得率與價格等擬真資料，自動組合多套配料方案，比較成本、成分命中及供料風險，協助熔煉與採購共同決定可執行爐料。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **熔煉任務** — 建立合金牌號、爐量、目標成分與交期條件。
- **原料池** — 檢視新料、合金料、回爐料的庫存、價格與限制。
- **配料條件** — 設定元素上下限、收得率、最低用量及禁用規則。
- **方案求解** — 產生多套符合限制的配料組合與成分預估。
- **成本比較** — 比較候選方案的成本、命中餘裕與供料風險。
- **領料定案** — 確認選定配方並輸出擬真秤料與領料明細。

## 適合誰使用

- 熔煉配料員
- 冶金工程師
- 原料採購人員

## 運作流程

1. 建立任務
2. 盤點原料
3. 設定限制
4. 產生配方
5. 比較方案
6. 核定領料
