# 射出成型翹曲預測系統

> 以產品幾何區域、材料收縮、模溫、冷卻配置與成型參數等擬真資料，預測脫模後的翹曲方向及尺寸偏差，讓試模與品質團隊在量產前比較改善方案，降低反覆修模、調機與尺寸超差風險。

以產品幾何區域、材料收縮、模溫、冷卻配置與成型參數等擬真資料，預測脫模後的翹曲方向及尺寸偏差，讓試模與品質團隊在量產前比較改善方案，降低反覆修模、調機與尺寸超差風險。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **翹曲風險總覽** — 彙整產品最大變形量、超差點位、案件狀態與改善趨勢。
- **尺寸基準設定** — 建立產品基準面、量測點、公差與變形判定規則。
- **冷卻條件配置** — 設定模溫分區、冷卻水路、冷卻時間與材料收縮特性。
- **變形結果預測** — 以三維示意及位移箭頭呈現翹曲方向、程度與熱區。
- **改善方案模擬** — 比較保壓、模溫、冷卻及結構調整對尺寸偏差的影響。
- **尺寸驗證報告** — 整理預測值、擬真量測值、判定結果與簽核紀錄。

## 適合誰使用

- 模具工程師
- 試模工程師
- 尺寸品保人員

## 運作流程

1. 鎖定案件
2. 定義公差
3. 配置冷卻
4. 判讀變形
5. 模擬改善
6. 簽核報告

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
