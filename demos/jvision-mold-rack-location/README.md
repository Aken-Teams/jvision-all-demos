# 模具架位借還盤點台

> 供沖壓與射出工廠管理模具架位、吊重限制、借出機台及待修隔離位置，透過出入架點交避免夜班找模、錯架與損傷模再領用。

供沖壓與射出工廠管理模具架位、吊重限制、借出機台及待修隔離位置，透過出入架點交避免夜班找模、錯架與損傷模再領用。

**產業別：**倉儲物流　|　**系統類型：**warehouse-wms

## 功能模組

- **架位總覽** — 查看承重與占用
- **模具尋位** — 依模號料號查找
- **領模點交** — 綁定機台工單
- **退模檢傷** — 記錄狀態與附件
- **待修隔離** — 禁止異常模領用
- **循環盤點** — 核對實物位置

## 適合誰使用

- 模具庫管員
- 換模技師

## 運作流程

1. 工單叫模
2. 架位尋模
3. 吊運出庫
4. 機台歸還
5. 檢傷入架
6. 庫位盤點

## 導入效益

- 揀貨作業工時：7小時/日 → **2小時/日**
- 庫存準確率：88% → **99%**
- 出貨延遲率：9% → **2%**
- 盤點工時：16小時/月 → **3小時/月**
