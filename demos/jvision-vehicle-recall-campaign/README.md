# 車輛召回活動執行台

> 供汽車經銷與維修體系管理召回或服務活動的適用車輛、車主聯繫、零件配額、預約進廠、施作證明及未完成車輛追蹤。

供汽車經銷與維修體系管理召回或服務活動的適用車輛、車主聯繫、零件配額、預約進廠、施作證明及未完成車輛追蹤。

**產業別：**交通運輸　|　**系統類型：**maintenance-cmms

## 功能模組

- **活動總覽** — 掌握範圍、期限與完成率
- **適用車輛** — 篩選車輛及風險等級
- **車主聯繫** — 安排分批通知與回覆
- **零件配額** — 配置據點零件與保留量
- **進廠施作** — 追蹤預約、施工及證明
- **未完成追蹤** — 管理失聯與逾期車輛

## 適合誰使用

- 服務活動專員
- 維修廠主管
- 客服人員

## 運作流程

1. 建立召回活動
2. 確認車輛名單
3. 執行車主通知
4. 配置零件工位
5. 完成進廠施作
6. 追蹤未完成車輛

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
