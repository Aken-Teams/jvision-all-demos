# 樣品管理系統 Sample Management管理艙

管理客戶樣品申請、製作、寄送與追蹤，並記錄樣品驗證結果，支援新產品導入業務。

- 原始系統：樣品管理系統 Sample Management
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、業務工程(SE)、研發部、品保部、物流部
- 工作流程：客戶提出樣品需求→內部審核與製作→寄送客戶→客戶驗證回饋→追蹤轉量產訂單
- AI 應用：樣品需求與量產轉換率預測、樣品驗證延遲風險提醒
- 主要 KPI：樣品交付時效、樣品轉量產轉換率、樣品成本比率、驗證回饋及時率
- 代表產品：多為ERP/CRM客製模組（電子製造業常見自建樣品管理子系統）
