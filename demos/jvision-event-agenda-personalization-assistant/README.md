# 活動議程個人化助手

**產業別：**業務銷售　|　**系統類型：**collaboration-pm

## 功能模組

- **參與目標探索** — 整理參與者角色、興趣、學習目標與商務期待。
- **議程價值配對** — 將場次主題、難度與講者專長配對個人目標。
- **會談對象推薦** — 推薦具互補需求、共同議題或合作潛力的交流對象。
- **行程路線最佳化** — 處理時段衝突、場地距離、休息與容量限制。
- **參與方案模擬** — 比較學習、拓展人脈與商機等多目標行程方案。
- **個人議程同步** — 核准後預約場次與會談，並同步變更至個人行事曆。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 釐清參與目標
2. 檢視場次配對
3. 挑選會談對象
4. 最佳化每日路線
5. 比較參與方案
6. 確認並同步議程

## 導入效益

- 商機轉換率：18% → **27%**
- 平均回應時間：26小時 → **6小時**
- 客戶資料完整率：62% → **94%**
- 報價逾期流失：9件/月 → **2件/月**
