# 公共工程投標合規台

> 針對公共工程招標文件，拆解資格、押標金、實績、專任人員與電子領投標要求，分派備標責任並在截止前完成文件版本、簽章及封裝檢核。

針對公共工程招標文件，拆解資格、押標金、實績、專任人員與電子領投標要求，分派備標責任並在截止前完成文件版本、簽章及封裝檢核。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **標案總覽** — 依截止日與風險顯示各投標案進度。
- **資格拆解** — 整理廠商、人員、實績與財務資格條件。
- **備標分工** — 將文件責任、期限與覆核人分派到單位。
- **更正追蹤** — 比對招標公告變更及受影響的備標文件。
- **合規檢核** — 確認效期、簽章、押標金及格式要求。
- **封裝送標** — 模擬紙本或電子投標封裝並完成點交。

## 適合誰使用

- 標案經理
- 估算工程師
- 法務行政人員

## 運作流程

1. 標案總覽
2. 資格拆解
3. 備標分工
4. 更正追蹤
5. 合規檢核
6. 封裝送標

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
