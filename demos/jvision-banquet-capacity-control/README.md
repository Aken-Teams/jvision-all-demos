# 宴會產能接單管制台

> 整合宴會廳檔期、桌數配置、菜單版本、廚房產能與服務人力，讓宴會業務在報價前確認可承接量，避免同日多場活動造成備餐、翻場及人力安排衝突。

整合宴會廳檔期、桌數配置、菜單版本、廚房產能與服務人力，讓宴會業務在報價前確認可承接量，避免同日多場活動造成備餐、翻場及人力安排衝突。

**產業別：**餐飲旅宿　|　**系統類型：**pos-frontdesk

## 功能模組

- **宴會檔期總覽** — 查看各廳別、時段與暫留案件。
- **桌席配置試算** — 模擬桌數、動線及舞台占用。
- **菜單產能評估** — 估算菜色工序與廚房負荷。
- **服務人力規劃** — 配置外場、場務與支援人員。
- **報價版本管理** — 比較方案成本、售價與毛利。
- **接單審核中心** — 彙整衝突並完成承接決策。

## 適合誰使用

- 宴會業務
- 餐飲經理
- 宴會主廚

## 運作流程

1. 受理詢價
2. 配置場地
3. 評估餐飲
4. 安排人力
5. 產出報價
6. 核准接單

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
