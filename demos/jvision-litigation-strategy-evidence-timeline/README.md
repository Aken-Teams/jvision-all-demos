# 訴訟策略證據時間線

> 集中管理訴訟爭點、當事人主張、程序期限與證據資料，將事件和文件組成可視化時間線，協助律師檢查證據缺口、比較攻防策略及準備庭期。以擬真案件呈現團隊如何形成一致且可追溯的訴訟作戰計畫。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **案件戰情總覽** — 呈現案件階段、下次庭期、重大爭點與待辦風險。
- **事證時間線** — 依日期排列事件、文件、證詞及程序節點並建立連結。
- **爭點主張矩陣** — 對照雙方主張、法律要件、支持證據與反駁內容。
- **證據資料庫** — 分類管理證物、來源、可信度、保管資訊及引用位置。
- **攻防策略模擬** — 比較不同主張路徑、證據組合與可能風險。
- **庭期準備中心** — 彙整期限、書狀、證人、庭前問題與任務分工。

## 適合誰使用

- 訴訟律師
- 企業法務
- 法務助理
- 案件主管

## 運作流程

1. 掌握案件狀態
2. 重建事證時間線
3. 整理訴訟爭點
4. 檢查證據缺口
5. 比較攻防策略
6. 完成庭期準備

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
