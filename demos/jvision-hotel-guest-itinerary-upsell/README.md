**產業別：**餐飲旅宿　|　**系統類型：**pos-frontdesk

## 功能模組

- **賓客需求摘要** — 集中查看住宿資料、同行者、偏好與特殊需求。
- **行程時間軸** — 以拖放式時間軸安排抵達、用餐、活動與離店。
- **體驗推薦庫** — 依客群與空檔篩選擬真館內及在地體驗。
- **加購服務清單** — 選擇接送、餐飲、設施與活動並試算金額。
- **確認對話預覽** — 模擬多語訊息往返及旅客接受或調整結果。
- **服務交接單** — 產生各部門執行清單、時程與注意事項。

## 適合誰使用

- 禮賓人員
- 前台人員
- 訂房專員

## 運作流程

1. 彙整賓客需求
2. 建立住宿行程
3. 挑選合適體驗
4. 組合加購方案
5. 確認旅客選擇
6. 派送交接事項

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
