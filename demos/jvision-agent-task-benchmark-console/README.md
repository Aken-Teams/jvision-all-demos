# Agent 任務基準管理台

> 管理可跨版本比較的 Agent 任務、資料集與評分規則，建立產品級基線。

管理可跨版本比較的 Agent 任務、資料集與評分規則，建立產品級基線。

**產業別：**資訊科技　|　**系統類型：**analytics-bi

## 功能模組

- **基準任務庫** — 維護具版本的代表性任務、難度標籤與完成條件。
- **評測資料集** — 組合標準案例、對抗案例與保留測試集並控管版本。
- **評分規則設計器** — 設定正確性、完成度、安全、成本與延遲的評分方式。
- **版本對跑中心** — 以相同任務與環境批次執行不同 Agent 版本。
- **基準比較榜** — 比較版本總分、能力切面、成本與統計顯著性。
- **發布門檻管理** — 依基線退化與風險指標決定版本是否可晉級發布。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 定義基準任務
2. 組建評測資料集
3. 制定評分規則
4. 執行版本對跑
5. 分析能力差異
6. 核准版本晉級
