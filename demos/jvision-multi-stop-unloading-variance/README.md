# 多站卸貨差異結案台

> 依整車裝載及各卸貨站簽收逐站還原品項數量，集中處理多收、少收、拒收與回車貨，鎖定差異發生站點並完成客戶、司機及倉庫歸責。

依整車裝載及各卸貨站簽收逐站還原品項數量，集中處理多收、少收、拒收與回車貨，鎖定差異發生站點並完成客戶、司機及倉庫歸責。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **裝車基準** — 建立出發數量
- **逐站軌跡** — 呈現卸貨順序
- **簽收核對** — 比對站點數量
- **餘量重算** — 還原車上結餘
- **差異調查** — 追補簽單證據
- **歸責結案** — 確認賠付調整

## 適合誰使用

- 運輸調度員
- 配送司機
- 差異理賠員

## 運作流程

1. 建立基準
2. 記錄卸貨
3. 計算差異
4. 追補證據
5. 判定責任
6. 完成結案

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
