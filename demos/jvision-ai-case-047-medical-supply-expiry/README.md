# 醫材效期庫存艙

> 以 FEFO 先到期先出，管好醫材效期、批號、儲位與安全存量

管理醫材庫存、批號、效期與安全存量。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台，把近效期與過期風險擋在事故發生之前。

**產業別：**醫療照護　|　**系統類型：**醫材效期庫存管理系統

## 功能模組

- **效期總覽** — 全院醫材效期分佈與 FEFO 儀表
- **近效期預警** — 到期天數分級預警與待處理清單
- **批號儲位** — 批號追溯、儲位定位與 FEFO 上架
- **領用消耗** — 科別領用扣帳與批號消耗軌跡
- **庫存盤點** — 循環盤點、帳實差異與效期核對
- **補貨管理** — 安全存量、效期汰換與自動補貨

## 適合誰使用

- 櫃檯人員
- 護理長
- 採購管理員

## 運作流程

1. 效期總覽
2. 近效期預警
3. 批號儲位定位
4. 領用消耗扣帳
5. 盤點與補貨

## 導入效益

- 候診等待：34分鐘 → **13分鐘**
- 回診完成率：73% → **92%**
- 申報退件率：7.8% → **1.9%**
- 紀錄作業工時：4.2小時/日 → **1小時/日**
