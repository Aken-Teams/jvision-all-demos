# 醫材效期庫存艙

> 收貨到出貨的倉內作業與庫存精準管理

管理醫材庫存、批號、效期與安全存量。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**醫療照護　|　**系統類型：**WMS 倉儲管理系統

## 功能模組

- **入庫上架** — 收貨、驗收與智慧上架
- **揀貨出貨** — 波次揀貨、覆核與出貨
- **儲位管理** — 儲位規劃與庫容視覺化
- **庫存盤點** — 即時庫存、盤點與調撥
- **拉動補料** — 安全庫存與自動補貨
- **條碼作業** — PDA 掃碼即時作業

## 適合誰使用

- 櫃檯人員
- 護理長
- 院所負責人

## 運作流程

1. 待確認
2. 照護中
3. 待回覆
4. 批價完成

## 導入效益

- 候診等待：34分鐘 → **13分鐘**
- 回診完成率：73% → **92%**
- 申報退件率：7.8% → **1.9%**
- 紀錄作業工時：4.2小時/日 → **1小時/日**
