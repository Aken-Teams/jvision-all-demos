# AI Factory Copilot管理艙

以生成式AI提供自然語言查詢、異常摘要與決策建議之智慧製造助理系統。

- 原始系統：AI Factory Copilot（AI工廠智慧助理）
- 產業分類：智慧製造｜製造管理
- 使用部門：生產、製造工程、廠務主管、品保
- 工作流程：使用者自然語言提問 → AI檢索跨系統數據 → 分析摘要生成 → 建議產出 → 人員決策採納
- AI 應用：生成式AI自動產出異常分析報告、AI輔助新進人員快速查詢作業知識、智慧建議下一步行動方案
- 主要 KPI：查詢回應時效、報告產出效率提升率、使用採用率
- 代表產品：Microsoft Copilot for Manufacturing、Siemens Industrial Copilot、SAP Joule（此類產品多屬近年新興功能，成熟度仍在快速發展中）
