# AI Factory Copilot（AI工廠智慧助理）

> 訂單到入庫的製造現場全流程數位化

AI Factory Copilot（AI工廠智慧助理）提供自然語言查詢生產數據、異常事件自動摘要、跨系統知識問答。生產依「使用者自然語言提問 → AI檢索跨系統數據 → 分析摘要生成 → 建議產出 → 人員決策採納」推進作業，優先解決「跨系統數據查詢需具備專業技能」，製造工程則以查詢回應時效與報告產出效率提升率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生產製造　|　**系統類型：**MES 製造執行系統

## 功能模組

- **工單管理** — 訂單轉工單、拆併單與工單派發
- **排程排產** — 依產能、交期、負載自動排程
- **現場執行** — 派工、報工與進度即時回報
- **設備稼動 OEE** — 稼動、效率、良率即時監控
- **品質入庫** — 檢驗判定、不良處置與入庫
- **AI 改善建議** — 異常摘要與瓶頸改善建議

## 適合誰使用

- 生產
- 製造工程
- 廠務主管

## 運作流程

1. 待排程
2. 生產中
3. 待品檢
4. 已入庫

## 導入效益

- 排程作業工時：8.5小時/日 → **1.4小時/日**
- 準時交付率：78% → **97%**
- 缺料停線次數：12次/月 → **2.8次/月**
- 設備稼動率：71% → **88%**
