# 資料外洩內部威脅偵測台

> 分析模擬的檔案存取、下載、分享與外寄行為，辨識大量搬移敏感資料、異常查閱及離職前可疑活動，協助企業兼顧資安調查、員工隱私與處置程序。

分析模擬的檔案存取、下載、分享與外寄行為，辨識大量搬移敏感資料、異常查閱及離職前可疑活動，協助企業兼顧資安調查、員工隱私與處置程序。

**產業別：**資訊安全　|　**系統類型：**security-soc

## 功能模組

- **外洩風險總覽** — 依資料類型、管道、部門及風險程度呈現疑似外洩事件。
- **行為偏差分析** — 比較使用者近期與平常的存取量、時段、位置及分享對象。
- **敏感資料脈絡** — 查看檔案分類、擁有者、存取人員、流向及業務用途。
- **事件調查工作室** — 以時間軸串接下載、壓縮、外寄與公開分享等模擬證據。
- **人資法務協作** — 依案件敏感度限制資料可見性並記錄會簽與處置意見。
- **改善措施追蹤** — 管理權限調整、教育訓練、政策修訂及到期複核事項。

## 適合誰使用

- 資訊安全人員
- 人力資源主管
- 法務人員
- 資料擁有者

## 運作流程

1. 發現外洩
2. 評估偏差
3. 確認資料
4. 調查事件
5. 協調處置
6. 追蹤改善

- 弱點修補率：68% → **96%**
- 合規稽核工時：30小時/月 → **6小時/月**
