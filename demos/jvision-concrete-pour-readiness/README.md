# 混凝土澆置整備台

> 以澆置批次統整查驗、預埋、模板、泵車、車次與人力條件，建立未完成事項、放行責任及改期通知，讓預拌車出發前即可確認工作面是否具備澆置條件。

以澆置批次統整查驗、預埋、模板、泵車、車次與人力條件，建立未完成事項、放行責任及改期通知，讓預拌車出發前即可確認工作面是否具備澆置條件。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **澆置排程** — 顯示批次、區域、方數與供料時段。
- **條件清單** — 追蹤模板、鋼筋、預埋及查驗狀態。
- **車次協調** — 編排預拌車、泵車與到場節奏。
- **人力配置** — 確認澆置、試體及收面班組。
- **異常改期** — 處理缺件、塞車及天候造成的異動。
- **澆置放行** — 彙整各責任人確認並發布放行。

## 適合誰使用

- 工務工程師
- 品管工程師
- 工地主任

## 運作流程

1. 排定批次
2. 查核條件
3. 協調車次
4. 配置班組
5. 處理異常
6. 核准放行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
