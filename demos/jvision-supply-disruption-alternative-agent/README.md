> 針對供應商停工、物流受阻、原料短缺與交期驟變等事件，快速盤點受影響料件、訂單及客戶，提出替代供應、替代料、調撥與排程方案，支援跨部門評估和決策留痕。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **中斷事件中心** — 建立事件類型、供應商、預估期間與可信程度。
- **供應影響圖譜** — 展開受影響料件、產品、工單、訂單與客戶。
- **替代方案產生器** — 提出替代供應商、替代料、調撥及改期選項。
- **方案權衡工作台** — 比較成本、交期、品質、認證與客戶影響。
- **跨部門協同室** — 彙整採購、研發、生產、品質與業務意見。
- **應變行動追蹤** — 管理核定方案、責任人、期限及殘餘風險。

## 適合誰使用

- 採購人員
- 供應鏈經理
- 生產規劃師
- 研發工程師與業務主管

## 運作流程

1. 通報中斷事件
2. 展開供應影響
3. 建立替代選項
4. 評估方案取捨
5. 協同核定方案
6. 追蹤風險解除
