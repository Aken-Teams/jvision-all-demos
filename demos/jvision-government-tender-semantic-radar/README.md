# 政府標案語意雷達

依企業能力、實績與區域持續篩選真正值得投入的政府標案。知。監控。

**產業別：**專業服務　|　**系統類型：**sales-crm

## 功能模組

- **標案語意搜尋** — 用能力與商業語意搜尋公告，不受限於標題或關鍵字。
- **能力適配雷達** — 比對公司服務能力、證照與歷史實績的適配程度。
- **區域可履約分析** — 評估服務區域、據點覆蓋與跨區履約限制。
- **相似實績對照** — 找出可支撐投標資格與評選優勢的既有案例。
- **機會價值排序** — 綜合適配、預算、期限、競爭與成本排列標案。
- **標案監測清單** — 持續追蹤新公告、異動與截止期限並建立研判任務。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 定義尋標輪廓
2. 探索語意標案
3. 檢視能力適配
4. 比對區域實績
5. 排列投入價值
6. 建立追蹤機會

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
