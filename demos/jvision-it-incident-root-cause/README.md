# 資訊事件根因自癒協作台

> 彙整應用、主機、網路與變更紀錄的模擬訊號，以人工智慧建立事件脈絡、推測根因並推薦可審核的自癒方案，協助資訊團隊縮短服務中斷時間。

彙整應用、主機、網路與變更紀錄的模擬訊號，以人工智慧建立事件脈絡、推測根因並推薦可審核的自癒方案，協助資訊團隊縮短服務中斷時間。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **服務健康總覽** — 以服務與使用者影響呈現異常狀態、趨勢及重大事件。
- **事件脈絡拓撲** — 串接服務依賴、異常指標、告警與近期變更的關聯。
- **根因假設工作台** — 列出候選根因、支持證據、反證與建議驗證步驟。
- **自癒方案模擬** — 預覽重啟、切換、回復設定等方案的步驟、風險及影響。
- **復原協作戰情室** — 管理處理角色、任務、進度、公告與服務恢復確認。
- **事後檢討中心** — 整理事件時間線、根因、修復成果與預防再發行動。

## 適合誰使用

- 資訊維運人員
- 服務台人員
- 應用系統負責人
- 資訊主管

## 運作流程

1. 發現異常
2. 建立脈絡
3. 驗證根因
4. 核准自癒
5. 協作復原
6. 預防再發

## 導入效益

- 事件平均處理：120分鐘 → **30分鐘**
- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
- 資產盤點工時：20小時/月 → **4小時/月**
