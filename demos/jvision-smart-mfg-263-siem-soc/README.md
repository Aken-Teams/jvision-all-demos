# 資訊安全事件管理追蹤台

集中彙整全公司日誌，透過關聯分析偵測資安威脅並支援事件應變。

- 原始系統：資訊安全事件管理平台（SIEM/SOC）
- 產業分類：智慧製造｜IT管理
- 使用部門：資訊安全部、資訊部、稽核室、法遵部
- 工作流程：日誌收集→正規化與關聯分析→告警產生→SOC分級研判→事件應變處置→事後複盤報告
- AI 應用：UEBA使用者行為異常偵測、告警自動分級降噪、威脅獵捕(Threat Hunting)輔助
- 主要 KPI：平均偵測時間(MTTD)、平均應變時間(MTTR)、誤報率、事件覆蓋率
- 代表產品：Splunk Enterprise Security、IBM QRadar、Microsoft Sentinel、LogRhythm
