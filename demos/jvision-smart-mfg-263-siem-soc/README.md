# 資訊安全事件管理平台（SIEM/SOC）

> 告警分流、事件應變到弱點與合規治理

資訊安全事件管理平台（SIEM/SOC）提供日誌集中收集與正規化、威脅關聯規則與異常偵測、資安事件告警與分級。資訊安全部依「日誌收集→正規化與關聯分析→告警產生→SOC分級研判→事件應變處置→事後複盤報告」推進作業，優先解決「日誌分散難以追查攻擊路徑」，資訊部則以平均偵測時間(MTTD)與平均應變時間(MTTR)確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**資訊安全　|　**系統類型：**資安 SOC 平台

## 功能模組

- **監控總覽** — 日誌流量與告警即時態勢
- **告警分流** — 告警彙整、關聯與分級研判
- **事件應變** — 事件調查、遏制與處置追蹤
- **威脅獵捕** — 攻擊路徑與 MITRE ATT&CK 關聯
- **弱點管理** — 弱點掃描與修補進度追蹤
- **合規治理** — 稽核紀錄、報表與 MTTD/MTTR

## 適合誰使用

- 資訊安全部
- 資訊部
- 稽核室

## 運作流程

1. 日誌收集與正規化
2. 關聯分析與告警
3. SOC 研判與威脅獵捕
4. 事件應變與遏制
5. 複盤報告與合規稽核

## 導入效益

- 告警分流時間：45分鐘 → **8.2分鐘**
- 事件平均處理：12小時 → **2.9小時**
- 弱點修補率：72% → **90%**
- 合規稽核工時：31小時/月 → **6.2小時/月**
