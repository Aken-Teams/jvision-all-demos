# 資訊安全事件管理平台（SIEM/SOC）

> 告警分流、事件應變到弱點與合規治理

資訊安全事件管理平台（SIEM/SOC）提供日誌集中收集與正規化、威脅關聯規則與異常偵測、資安事件告警與分級。資訊安全部依「日誌收集→正規化與關聯分析→告警產生→SOC分級研判→事件應變處置→事後複盤報告」推進作業，優先解決「日誌分散難以追查攻擊路徑」，資訊部則以平均偵測時間(MTTD)與平均應變時間(MTTR)確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**資訊安全　|　**系統類型：**資安 SOC 平台

## 功能模組

- **告警分流** — 資安告警彙整分級
- **事件應變** — 事件調查與處置
- **弱點管理** — 弱點掃描與修補追蹤
- **身分權限** — 帳號與特權管理
- **合規治理** — 政策、稽核與合規
- **端點防護** — 端點偵測與應變

## 適合誰使用

- 資訊安全部
- 資訊部
- 稽核室

## 運作流程

1. 已偵測
2. 調查中
3. 研判確認
4. 已關閉

## 導入效益

- 告警分流時間：45分鐘 → **8.2分鐘**
- 事件平均處理：12小時 → **2.9小時**
- 弱點修補率：72% → **90%**
- 合規稽核工時：31小時/月 → **6.2小時/月**
