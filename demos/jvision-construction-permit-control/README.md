# 工程許可證照管制台

> 管理建照、道路申挖、消防與施工許可等證照的申請條件、送件版本、補正紀錄及有效期限，讓工務團隊看見許可對工序的阻擋關係並提前安排承辦追蹤。

管理建照、道路申挖、消防與施工許可等證照的申請條件、送件版本、補正紀錄及有效期限，讓工務團隊看見許可對工序的阻擋關係並提前安排承辦追蹤。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **許可清冊** — 列出專案所需證照與狀態
- **送件備查** — 核對文件、圖說與用印項目
- **機關進度** — 記錄送件窗口與審查階段
- **補正管理** — 追蹤補件內容及回覆期限
- **工序影響** — 呈現許可與施工活動依賴
- **效期展延** — 管理到期提醒與展延申請

## 適合誰使用

- 工務工程師
- 專案經理
- 行政專員

## 運作流程

1. 建立許可清冊
2. 核對送件資料
3. 登錄機關送件
4. 處理審查補正
5. 確認工序解鎖
6. 追蹤效期展延

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
