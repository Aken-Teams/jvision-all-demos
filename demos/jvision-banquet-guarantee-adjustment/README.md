# 宴會保證桌數調整台

> 管理宴會保證桌數的提出、截止、追加減與餐飲備料影響，將業務承諾、廚房可承作量及最終計費基準留在同一版本，避免口頭改桌造成爭議。

管理宴會保證桌數的提出、截止、追加減與餐飲備料影響，將業務承諾、廚房可承作量及最終計費基準留在同一版本，避免口頭改桌造成爭議。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **宴會總覽** — 查看日期桌數與截止日
- **桌數申請** — 登錄客戶追加減需求
- **備料影響** — 試算食材人力與桌型
- **計費試算** — 計算保證桌數與加開
- **例外核准** — 處理截止後變更要求
- **版本封存** — 鎖定最終執行與計價版

## 適合誰使用

- 宴會業務
- 宴會經理
- 廚房主管

## 運作流程

1. 建立宴會
2. 提出調整
3. 評估備料
4. 試算計費
5. 核准例外
6. 封存執行

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
