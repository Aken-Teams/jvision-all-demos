# 合約履約義務預警中心

> 將已簽合約中的交付、付款、驗收、續約、通知與保密義務整理成可追蹤任務，依期限及相依條件顯示責任歸屬和風險，主動提出待辦與升級提醒，避免企業因漏做通知、延遲履約或自動續約而蒙受損失。

將已簽合約中的交付、付款、驗收、續約、通知與保密義務整理成可追蹤任務，依期限及相依條件顯示責任歸屬和風險，主動提出待辦與升級提醒，避免企業因漏做通知、延遲履約或自動續約而蒙受損失。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **履約風險儀表板** — 呈現近期到期、逾期、高風險及各部門義務分布。
- **義務關聯地圖** — 連結合約條款、責任人、前置條件與後續義務。
- **履約任務中心** — 管理交付、付款、驗收與通知任務的狀態及證明。
- **期限預警佇列** — 依剩餘天數、金額與法律後果排列預警優先順序。
- **續約終止管理** — 追蹤自動續約、終止窗口及必要通知程序。
- **例外升級中心** — 彙整逾期、爭議與責任不明案件並啟動升級處理。

## 適合誰使用

- 合約管理員
- 企業法務
- 專案經理
- 財務人員

## 運作流程

1. 檢視履約全貌
2. 解析義務關係
3. 指派履約任務
4. 處理期限預警
5. 決定續約終止
6. 升級履約例外
