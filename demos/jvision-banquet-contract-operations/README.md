# 宴會合約履約管制台

> 供飯店宴會與婚宴團隊集中管理場地合約、桌數異動、菜單版本、訂金節點、跨部門交辦及尾款結算，降低業務承諾未落地與臨時變更造成的營運損失。

供飯店宴會與婚宴團隊集中管理場地合約、桌數異動、菜單版本、訂金節點、跨部門交辦及尾款結算，降低業務承諾未落地與臨時變更造成的營運損失。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **宴會總覽** — 掌握場次、金額與風險
- **合約版本** — 比對條款與承諾異動
- **菜單桌數** — 維護菜單及保證桌數
- **部門交辦** — 派送場務與餐飲任務
- **款項節點** — 追蹤訂金及尾款
- **場次結算** — 分析實收與活動毛利

## 適合誰使用

- 宴會業務
- 餐飲經理
- 財務專員

## 運作流程

1. 檢視宴會總覽
2. 確認合約版本
3. 核定菜單桌數
4. 派送部門交辦
5. 追蹤款項節點
6. 完成場次結算

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
