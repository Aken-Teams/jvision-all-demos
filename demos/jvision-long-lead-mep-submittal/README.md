# 機電長交期設備送審台

> 倒排變壓器、發電機、冰水主機與消防泵等設備的送審、澄清、製造及到貨節點，將監造核定與工地需求日連動，預警長交期設備延誤。

倒排變壓器、發電機、冰水主機與消防泵等設備的送審、澄清、製造及到貨節點，將監造核定與工地需求日連動，預警長交期設備延誤。

**產業別：**營建工程　|　**系統類型：**procurement-srm

## 功能模組

- **設備總表** — 管理規格、需求日與供應商資料
- **倒排節點** — 由安裝日回推核定、製造與運輸期限
- **送審文件** — 組合型錄、規範對照與計算資料
- **審查澄清** — 追蹤監造意見、回覆及改版輪次
- **製造廠驗** — 更新生產里程碑與廠驗缺失
- **到貨整備** — 確認運輸、吊裝與機房接收條件

## 適合誰使用

- 機電經理
- 採購人員
- 設備供應商

## 運作流程

1. 確認設備需求日
2. 完成規格詢比
3. 提交設備送審
4. 關閉審查意見
5. 追蹤製造廠驗
6. 辦理工地到貨

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
