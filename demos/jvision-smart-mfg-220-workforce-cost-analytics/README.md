# 人力成本分析與人事報表協作所

彙整薪資、加班、福利、招募等各項人力成本數據，提供經營層人力投資報酬與成本結構分析。

- 原始系統：人力成本分析與人事報表系統（Workforce Cost Analytics）
- 產業分類：智慧製造｜人資管理
- 使用部門：人資部、財務部、經營高層、各廠區廠長
- 工作流程：各系統成本資料匯入 → 成本歸屬分攤 → 報表產出 → 主管檢視分析 → 預算調整建議 → 追蹤成效
- AI 應用：人力成本異常波動自動預警、成本結構最佳化模擬建議
- 主要 KPI：人事費用率、人均產值、加班費占比、預算達成率
- 代表產品：SAP SuccessFactors Workforce Analytics、Visier、鼎新人力成本分析模組
