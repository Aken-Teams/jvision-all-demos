# 火化場次協調管理台

> 協調禮儀公司申請、火化爐別、場次容量、文件資格及臨時異動，讓殯葬設施營運單位降低撞期、等待與文件缺漏。

協調禮儀公司申請、火化爐別、場次容量、文件資格及臨時異動，讓殯葬設施營運單位降低撞期、等待與文件缺漏。

**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **場次日曆** — 查看爐別、時段及剩餘容量。
- **申請受理** — 登錄禮儀公司與服務需求。
- **文件查驗** — 核對許可證明與身分資料。
- **爐次配置** — 依條件安排爐別及先後順序。
- **異動協調** — 管理改期、取消及緊急插單。
- **服務核銷** — 記錄完成時間與費用狀態。

## 適合誰使用

- 場次調度員
- 設施主管
- 櫃台人員

## 運作流程

1. 檢視容量
2. 受理申請
3. 查驗文件
4. 安排爐次
5. 處理異動
6. 完成核銷

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
