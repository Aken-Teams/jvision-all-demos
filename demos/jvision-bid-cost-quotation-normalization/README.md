# 投標詢價範圍比對台

> 把公共工程投標工項拆成可詢價工作包，統一各分包商報價的包含、排除、數量基準、稅費與工期條件，再以同口徑比較缺漏及風險加價，避免只看總價而誤把不同施工範圍當成可比報價。

把公共工程投標工項拆成可詢價工作包，統一各分包商報價的包含、排除、數量基準、稅費與工期條件，再以同口徑比較缺漏及風險加價，避免只看總價而誤把不同施工範圍當成可比報價。

**產業別：**營建工程　|　**系統類型：**procurement-srm

## 功能模組

- **詢價工作包** — 依標單與施工界面定義發包範圍及數量。
- **廠商邀價** — 管理邀價名單、回覆期限與澄清往返。
- **報價收錄** — 登錄各版單價、總價、效期與付款條件。
- **口徑正規化** — 統一稅費、數量、工期、運費及排除項。
- **缺漏澄清** — 圈選異常低價、漏項與不同界面責任。
- **採用價核定** — 記錄選價理由、風險加價及備援廠商。

## 適合誰使用

- 估算工程師
- 採購人員
- 投標經理

## 運作流程

1. 拆分工作包
2. 發送邀價
3. 收錄報價
4. 統一口徑
5. 澄清缺漏
6. 核定採用價

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
