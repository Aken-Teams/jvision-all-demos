# 政府補助審查績效平台

> 集中管理模擬補助申請、資格文件、評分意見與核定條件，利用人工智慧摘要申請內容、提示資格或預算疑點，支援委員審查、決議留痕及補助後里程碑與成果指標追蹤。

集中管理模擬補助申請、資格文件、評分意見與核定條件，利用人工智慧摘要申請內容、提示資格或預算疑點，支援委員審查、決議留痕及補助後里程碑與成果指標追蹤。

**產業別：**專業服務　|　**系統類型：**finance-case

## 功能模組

- **申請收件中心** — 彙整申請摘要、附件狀態、補件期限與案件處理進度。
- **資格預算檢核** — 以模擬規則提示資格不符、文件缺漏及預算配置疑點。
- **委員審查工作台** — 提供內容摘要、評分量表、利益迴避提示與個別意見填寫。
- **決議核定管理** — 彙整評分差異、會議決議、核定金額與附帶條件。
- **里程碑追蹤** — 管理各計畫期程、交付成果、查核點與逾期改善事項。
- **補助績效分析** — 比較經費執行、成果達成、產業別與年度計畫績效。

## 適合誰使用

- 補助承辦人
- 審查委員
- 計畫主持人
- 機關主管

## 運作流程

1. 完成案件收件
2. 檢核資格預算
3. 執行專業審查
4. 形成核定決議
5. 追蹤計畫執行
6. 評估補助成效

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
