**產業別：**醫療照護　|　**系統類型：**logistics-fleet

## 功能模組

- **透析班表** — 連結病人班別與日期
- **臨時異動** — 管理換班住院與停接
- **乘車需求** — 記錄輪椅陪同與設備
- **車次配置** — 安排去回程與座位
- **雙向確認** — 確認患者司機與護理站
- **異常處置** — 處理漏接遲到及空趟

## 適合誰使用

- 透析行政
- 車隊調度
- 護理站人員

## 運作流程

1. 同步透析班表
2. 受理臨時異動
3. 確認乘車條件
4. 完成車次配置
5. 執行雙向確認
6. 處理接送結果

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
