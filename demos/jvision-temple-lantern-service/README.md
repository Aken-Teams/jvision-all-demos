# 宮廟點燈名冊管理台

> 供宮廟受理光明燈、太歲燈與文昌燈等服務，管理燈種席位、信眾資料校對、標籤列印、安座批次及到期續燈通知。

供宮廟受理光明燈、太歲燈與文昌燈等服務，管理燈種席位、信眾資料校對、標籤列印、安座批次及到期續燈通知。

**產業別：**宗教服務　|　**系統類型：**operations-console

## 功能模組

- **燈種席位** — 管理燈別容量與燈位
- **點燈受理** — 登錄信眾及祈福資料
- **資料校對** — 檢查姓名生辰與重複
- **標籤收據** — 批次產生燈牌與憑證
- **安座批次** — 追蹤燈牌製作與安置
- **續燈通知** — 整理到期名冊及聯繫狀態

## 適合誰使用

- 服務台人員
- 廟務幹事
- 會計人員

## 運作流程

1. 設定燈種席位
2. 受理信眾點燈
3. 校對名冊內容
4. 製作燈牌收據
5. 完成燈牌安座
6. 辦理到期續燈

## 導入效益

- 活動籌備工時：20小時 → **5小時**
- 報名掌握率：65% → **94%**
- 物資盤點：6小時 → **1小時**
- 志工調度時效：3天 → **1天**
