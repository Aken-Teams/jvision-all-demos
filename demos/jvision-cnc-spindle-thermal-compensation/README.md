> 以擬真的主軸溫度、運轉時間與位移量建立視覺化熱變位模型，呈現不同暖機及加工情境下的補償建議，讓製程人員試算補正效果、管理版本並降低長時間加工的尺寸誤差。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **熱狀態總覽** — 呈現各機台主軸溫度、暖機階段、預估位移及補償狀態。
- **溫升位移分析** — 對照運轉時間、溫度與各軸位移曲線，檢視熱變化關係。
- **熱變位模型** — 切換不同機型及加工情境的模擬模型，查看誤差與適用範圍。
- **補償曲線試算** — 調整補償節點與係數，預覽各溫度區間的補正結果。
- **效果驗證比較** — 比較補償前後的尺寸分布、殘餘誤差與過度補正風險。
- **補償版本管理** — 管理草稿、待審與核准版本，保留係數差異及適用機台紀錄。

5. 驗證補償效果
6. 發布補償版本
