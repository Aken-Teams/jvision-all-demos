# 採購支出分析儀表板協作所

彙整全公司採購支出資料並依品類、供應商、部門多維度分析，支撐策略採購決策。

- 原始系統：採購支出分析儀表板（Spend Analysis）
- 產業分類：智慧製造｜採購管理
- 使用部門：採購部、財務部、經營管理層、策略採購部
- 工作流程：支出資料彙整 → 分類清理 → 多維度分析 → 降本機會辨識 → 策略採購決策
- AI 應用：AI 自動分類採購品項與異常支出、智慧辨識供應商整併降本機會
- 主要 KPI：採購支出可視覆蓋率、降本機會轉化率、供應商集中度
- 代表產品：SAP Ariba Spend Analysis、Coupa Spend Analysis、Sievo、Zycus
