# 標單數量單價覆核台

> 針對大量標單項次檢查單位、數量、公式、詢價來源與異常單價，建立雙人覆核及修正紀錄，避免漏估主要材料或錯列高風險單價。

針對大量標單項次檢查單位、數量、公式、詢價來源與異常單價，建立雙人覆核及修正紀錄，避免漏估主要材料或錯列高風險單價。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **標單總覽** — 查看項次與覆核進度
- **公式檢查** — 辨識漏算及引用錯誤
- **單位核對** — 檢查數量與換算關係
- **詢價比對** — 連結廠商報價來源
- **異常單價** — 標示偏離行情的標項
- **報價鎖定** — 雙人簽認最終標單

## 適合誰使用

- 估算工程師
- 採購詢價員
- 投標主管

## 運作流程

1. 匯入標單
2. 執行檢查
3. 補齊詢價
4. 逐項覆核
5. 調整風險
6. 鎖定送標

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
