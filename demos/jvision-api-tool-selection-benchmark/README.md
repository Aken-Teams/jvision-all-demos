**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **真實任務題庫** — 將企業工作轉為含目標、限制與標準答案的測試題。
- **候選工具目錄** — 管理可選 API、MCP Tool、版本、權限與適用範圍。
- **Agent 選擇競測** — 讓不同 Agent 策略在相同任務下自主選擇工具。
- **參數品質評分** — 評估端點、欄位、型別、必填值與呼叫順序正確性。
- **策略基準排行** — 比較任務成功率、成本、延遲與錯誤恢復能力。
- **工具策略調校** — 依失敗模式調整描述、路由規則與少樣本範例。

## 適合誰使用

- 平台架構師
- 整合工程師
- AI 應用開發者

## 運作流程

1. 定義基準任務
2. 配置候選工具
3. 執行選擇競測
4. 評閱呼叫參數
5. 比較策略表現
6. 發布調校方案

## 導入效益

- 事件平均處理：120分鐘 → **30分鐘**
- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
- 資產盤點工時：20小時/月 → **4小時/月**
