# 預購到貨承諾拆單台

> 依預購商品到貨進度、同單現貨、贈品與免運條件，產生可執行的拆寄方案並留存顧客承諾變更，協助客服與倉庫降低壓單、錯寄和重複運費。

依預購商品到貨進度、同單現貨、贈品與免運條件，產生可執行的拆寄方案並留存顧客承諾變更，協助客服與倉庫降低壓單、錯寄和重複運費。

**產業別：**零售電商　|　**系統類型：**operations-console

## 功能模組

- **到貨看板** — 追蹤預購品預計到貨
- **訂單解析** — 拆解現貨預購與贈品
- **拆寄試算** — 比較等待與分批方案
- **承諾確認** — 記錄顧客選擇與通知
- **批次放行** — 產生分批出貨指示
- **履約追蹤** — 監看逾期與額外成本

## 適合誰使用

- 電商營運
- 客服人員
- 出貨主管

## 運作流程

1. 監看到貨
2. 解析訂單
3. 規劃拆寄
4. 確認承諾
5. 放行出貨
6. 追蹤履約

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
