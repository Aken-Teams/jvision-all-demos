# 轉運場到車預約台

> 協助物流轉運場管理幹線車與支線車到場預約、月台指派、交叉轉運銜接、等待異常及離場確認，減少尖峰壅塞與錯失班次。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **到車預約** — 登錄車次、時窗與預估貨量。
- **月台配置** — 依車型、路線與容量指派月台。
- **轉運銜接** — 配對卸貨來源與下一段班次。
- **到場異常** — 處理遲到、溢量及臨時換車。
- **候場監控** — 掌握報到、進場與作業等待時間。
- **離場確認** — 核對裝載完成與實際發車時間。

## 適合誰使用

- 場站調度員
- 運輸主管
- 月台領班

## 運作流程

1. 建立預約
2. 配置月台
3. 規劃銜接
4. 車輛報到
5. 執行轉運
6. 確認離場

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
