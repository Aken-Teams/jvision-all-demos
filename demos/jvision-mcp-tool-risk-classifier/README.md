# MCP 工具風險分級器

依資料敏感度、寫入影響、金額與可逆性分級 MCP 工具風險。

**產業別：**資訊科技　|　**系統類型：**security-soc

## 功能模組

- **資料敏感度判定** — 辨識工具會讀取或輸出的個資、財務、機密與受管制資料。
- **寫入影響分析** — 判斷工具是否建立、修改、刪除資料或觸發外部業務動作。
- **金額曝險估算** — 計算單次及累計可操作金額、限額與潛在財務損失。
- **可逆性評估** — 檢查動作能否撤銷、補償、人工攔截及恢復原狀。
- **工具風險定級** — 結合資料、權限、金額與可逆性產生風險等級及理由。
- **核准政策配置** — 依等級套用自動放行、單人覆核、雙人核准或禁止呼叫。

## 運作流程

1. 盤點資料範圍
2. 分析寫入效果
3. 估算金額風險
4. 驗證可逆性
5. 審定風險級別
6. 發布核准政策
