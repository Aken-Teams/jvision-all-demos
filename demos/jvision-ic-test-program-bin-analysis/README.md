# 積體電路測試分箱異常分析台

> 分析積體電路測試程式版本、測項結果與分箱分布，找出特定機台、批次或程式變更後的異常偏移。工程師可比較版本、下鑽失敗測項並建立複測與修正建議。

分析積體電路測試程式版本、測項結果與分箱分布，找出特定機台、批次或程式變更後的異常偏移。工程師可比較版本、下鑽失敗測項並建立複測與修正建議。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **測試總覽** — 呈現產品良率、分箱結構與版本風險趨勢。
- **分箱分析** — 依批次、晶圓、機台及時段拆解各分箱比例。
- **版本比較** — 比較測試程式版本、參數變動與上線時間。
- **測項下鑽** — 從異常分箱追到失敗測項、上下限與數值分布。
- **關聯切片** — 交叉分析測試機、探針卡、介面板與產品批次。
- **複測決策** — 建立複測條件、程式修正建議與結果追蹤紀錄。

## 適合誰使用

- 測試工程師
- 產品工程師
- 品質工程師

## 運作流程

1. 發現偏移
2. 拆解分箱
3. 比較版本
4. 定位測項
5. 交叉驗證
6. 決定複測
