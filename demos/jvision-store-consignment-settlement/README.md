# 門市寄售商品結算台

> 整合各寄售櫃點的銷售、退貨、盤差、抽成與請款資料，統一月份歸屬及責任認定，降低通路退件與寄售貨款漏收。

整合各寄售櫃點的銷售、退貨、盤差、抽成與請款資料，統一月份歸屬及責任認定，降低通路退件與寄售貨款漏收。

**產業別：**零售電商　|　**系統類型：**finance-ledger

## 功能模組

- **櫃點總覽** — 查看各寄售點結算進度。
- **銷退明細** — 彙整銷售與退貨月份。
- **庫存對帳** — 核對期初、進退貨與結存。
- **抽成計算** — 套用通路分潤及費用。
- **盤差歸責** — 處理短少與責任確認。
- **請款管理** — 產生帳單並追蹤退件。

## 適合誰使用

- 通路專員
- 應收會計
- 商品主管

## 運作流程

1. 收集報表
2. 核對庫存
3. 判定月份
4. 計算抽成
5. 確認盤差
6. 送出請款

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
