# 保險理賠給付覆核台

> 將核賠結果與銀行出款清冊逐筆勾稽，檢查受款帳戶、核定上限、重複給付、扣抵與批次異動，經雙人覆核後鎖定付款版本。

將核賠結果與銀行出款清冊逐筆勾稽，檢查受款帳戶、核定上限、重複給付、扣抵與批次異動，經雙人覆核後鎖定付款版本。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **核賠勾稽** — 比對核定出款
- **帳戶驗證** — 確認受款資料
- **重複檢查** — 攔截再次給付
- **批次差異** — 檢視版本修改
- **雙人覆核** — 確認付款清冊
- **付款回寫** — 記錄銀行結果

## 適合誰使用

- 理賠會計
- 出納人員
- 財務主管

## 運作流程

1. 載入核賠
2. 比對出款
3. 驗證帳戶
4. 排除重付
5. 核准批次
6. 回寫結案

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
