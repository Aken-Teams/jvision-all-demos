# 再保險分出案件管理台

> 供產險公司針對超過自留額或符合合約條件的承保案件，整理風險摘要、分出條件、再保人詢價、承接比例與文件回覆，控管生效前的再保配置完整性。

供產險公司針對超過自留額或符合合約條件的承保案件，整理風險摘要、分出條件、再保人詢價、承接比例與文件回覆，控管生效前的再保配置完整性。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **曝險總覽** — 呈現待分出案件、自留額與未配置風險。
- **風險資料包** — 整理標的、保額、損失紀錄及核保條件。
- **再保詢價** — 管理詢價對象、期限與問題回覆。
- **條件比較** — 比較費率、承接比例與除外條款。
- **分出配置** — 組合自留及各再保人的承接份額。
- **承保核准** — 確認再保證據完整後送交承保決策。

## 適合誰使用

- 再保專員
- 核保人員
- 風險主管

## 運作流程

1. 辨識分出案
2. 備妥資料包
3. 發送詢價
4. 比較條件
5. 完成配置
6. 核准生效

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
