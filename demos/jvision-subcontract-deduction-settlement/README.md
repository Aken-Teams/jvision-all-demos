# 分包代扣款結算台

> 彙整總包代分包支付的材料、機具、清潔、水電與罰款等代扣項目，逐筆附上責任依據與憑證，於每期估驗前完成分包確認，避免漏扣、重扣或結算爭議。

彙整總包代分包支付的材料、機具、清潔、水電與罰款等代扣項目，逐筆附上責任依據與憑證，於每期估驗前完成分包確認，避免漏扣、重扣或結算爭議。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **代扣登錄** — 建立費用類別、金額與責任分包。
- **憑證歸集** — 附上發票、照片、通知與計算依據。
- **重複檢核** — 比對事件、日期及單據避免重扣。
- **依據覆核** — 確認契約條款與責任歸屬。
- **分包對帳** — 處理認列、申覆與協議調整。
- **估驗結轉** — 鎖定本期代扣並帶入估驗。

## 適合誰使用

- 分包管理員
- 工地會計
- 分包計價人員

## 運作流程

1. 提出代扣
2. 補齊憑證
3. 查重覆核
4. 通知分包
5. 爭議協議
6. 估驗結算

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
