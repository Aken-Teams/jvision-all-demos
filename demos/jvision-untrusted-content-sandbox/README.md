# 不可信內容沙箱

隔離郵件、網頁與文件中的不可信指令，抑制間接提示攻擊。​̲໮

**產業別：**資訊安全　|　**系統類型：**security-soc

## 功能模組

- **郵件威脅拆解** — 分離寄件內容、附件文字、連結與隱藏指令。
- **網頁內容降權** — 標記外部頁面來源並限制其對模型指令的優先度。
- **文件指令隔離** — 從文件事實中辨識並隔離企圖操控 Agent 的語句。
- **指令效果限制** — 禁止不可信內容改寫目標、權限或工具參數。
- **安全重播沙箱** — 在無外部副作用環境重播內容與 Agent 反應。
- **間接攻擊判讀** — 解釋攻擊鏈、受影響工具與建議阻斷措施。

## 適合誰使用

- CISO
- AI 治理主管
- 資安分析師

## 運作流程

1. 收取內容
2. 標記信任
3. 隔離指令
4. 限制效果
5. 沙箱重播
6. 核准處置

## 導入效益

- 告警分流時間：45分鐘 → **8分鐘**
- 事件平均處理：12小時 → **3小時**
- 弱點修補率：68% → **96%**
- 合規稽核工時：30小時/月 → **6小時/月**
