# 專利地圖空白區分析器

> 從技術、申請人與時間維度辨識專利布局空白，支援研發選題與申請策略。

從技術、申請人與時間維度辨識專利布局空白，支援研發選題與申請策略。

**產業別：**專業服務　|　**系統類型：**analytics-bi

## 功能模組

- **技術主題分類** — 將專利依技術特徵、應用場景與成熟度聚類。
- **申請人競合圖譜** — 呈現主要申請人、合作關係與相近技術群。
- **技術演進時間軸** — 追蹤各主題的申請趨勢、轉折點與生命週期。
- **布局密度矩陣** — 交叉比較技術主題、申請人與年份的專利密度。
- **空白機會辨識** — 找出低密度但需求、能力或成長訊號較強的區域。
- **研發選題評分** — 依差異化、可行性、擁擠度與策略價值排序題目。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 定義分析疆界
2. 建立技術分類
3. 分析競合格局
4. 檢視演進趨勢
5. 驗證布局空白
6. 核定研發選題
