> 依船期與各項截關節點列出訂艙、補料、報關及提單文件，集中版本、缺件與送件責任，在截止前完成雙重確認，避免漏船、改船及倉租損失。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **船期總覽** — 查看航次與各截關時間
- **文件清單** — 依航線產生必備文件
- **版本控管** — 標記最新版與修改差異
- **缺件追補** — 指派客戶及內部待辦
- **送件確認** — 保存報關船公司回執
- **逾期處置** — 評估改船與成本影響

## 適合誰使用

- 海運文件人員
- 報關窗口
- 業務人員

## 運作流程

1. 建立航次
2. 產生清單
3. 追補資料
4. 鎖定版本
5. 完成送件
6. 處理風險
