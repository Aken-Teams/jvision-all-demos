# 自動光學檢測缺陷溯因台

> 整合自動光學檢測的缺陷紀錄與擬真製程、設備及物料資料，透過時間、站點和批次關聯找出可疑根因，讓品保人員從缺陷分布一路追查影響因子並建立改善追蹤案件。

整合自動光學檢測的缺陷紀錄與擬真製程、設備及物料資料，透過時間、站點和批次關聯找出可疑根因，讓品保人員從缺陷分布一路追查影響因子並建立改善追蹤案件。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **缺陷態勢總覽** — 呈現缺陷率、類型排行、影響批次與線別風險分布。
- **缺陷熱區分析** — 以產品區域熱圖查看刮傷、異物、偏移等缺陷集中位置。
- **因子關聯探索** — 展開缺陷與設備、參數、物料及班別之間的關聯網絡。
- **批次時序追查** — 沿生產時間軸比對缺陷發生前後的重要製程事件。
- **根因假設驗證** — 比較異常組與正常組數據，呈現候選根因的支持證據。
- **改善案件追蹤** — 建立改善措施、負責人、期限與複驗結果的追蹤紀錄。

## 適合誰使用

- 品保工程師
- 製程工程師
- 品質主管

## 運作流程

1. 掌握缺陷態勢
2. 定位缺陷熱區
3. 探索關聯因子
4. 回溯批次時序
5. 驗證根因假設
6. 追蹤改善成效

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
