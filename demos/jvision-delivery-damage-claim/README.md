# 材料到貨缺損索賠台

> 在材料卸貨驗收時按採購單、批號與包裝記錄短少、破損或錯規，管理保留簽收、供應商回覆、補貨、折讓與求償期限。

**產業別：**營建工程　|　**系統類型：**procurement-srm

## 功能模組

- **到貨驗收** — 核對品項數量與批號
- **缺損建單** — 記錄破損短少及照片
- **保留簽收** — 產生帶保留條件紀錄
- **供應商協議** — 追蹤責任與處理方案
- **補貨折讓** — 管理重送退貨及折價
- **索賠核銷** — 確認回收金額與結案

## 適合誰使用

- 收料員
- 採購專員
- 材料工程師

## 運作流程

1. 到貨點收
2. 記錄缺損
3. 保留簽收
4. 提出索賠
5. 完成補償
6. 財務結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
