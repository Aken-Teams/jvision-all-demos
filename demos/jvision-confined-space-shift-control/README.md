# 侷限空間作業輪值台

> 以侷限空間作業許可為核心，管理氣體檢測時點、進出人員、監視者輪值、通風與救援準備，讓換班後仍能確認空間內人員及許可有效性。

以侷限空間作業許可為核心，管理氣體檢測時點、進出人員、監視者輪值、通風與救援準備，讓換班後仍能確認空間內人員及許可有效性。

**產業別：**營建工程　|　**系統類型：**operations-console

## 功能模組

- **作業監控** — 顯示各空間許可與在場人數。
- **許可建檔** — 登錄作業範圍、危害與有效期間。
- **氣體檢測** — 記錄開工前及定時檢測結果。
- **人員進出** — 維護進場、離場與在場名冊。
- **監視輪值** — 完成監視者換班與責任交接。
- **收工清點** — 確認全員離場並關閉許可。

## 適合誰使用

- 職安人員
- 作業主管
- 現場監視者

## 運作流程

1. 檢視作業狀態
2. 申請作業許可
3. 確認環境合格
4. 登錄人員進出
5. 完成輪值交接
6. 清點關閉作業

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
