# 論文口試資格清件台

> 在口試排程前核對學分、研究倫理、論文相似度、指導教授同意及外聘委員資格，將缺件與效期集中追蹤，避免排定後取消或違規授位。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **學業門檻** — 檢查學分成績與修業期
- **倫理資格** — 核對研究倫理及效期
- **論文檢核** — 登錄相似度與版本
- **委員資格** — 查驗內外聘委員條件
- **缺件追蹤** — 通知學生與指導教授
- **口試放行** — 核准進入排程及發聘

## 適合誰使用

- 系所承辦
- 研究生
- 系所主管

## 運作流程

1. 提出口試申請
2. 檢核學業門檻
3. 查驗研究文件
4. 審查委員資格
5. 完成缺件補正
6. 核准口試排程

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
