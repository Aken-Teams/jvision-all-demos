# 餐飲折讓授權稽核台

> 逐筆串起收銀折讓、原因碼、當班主管核准與補償證據，找出事後補理由、高頻小額折讓及超權操作，守住門店毛利。

**產業別：**餐飲旅宿　|　**系統類型：**finance-case

## 功能模組

- **折讓明細** — 彙整門店折扣與招待交易。
- **權限規則** — 設定原因與金額核准層級。
- **異常偵測** — 標示拆單及高頻小額模式。
- **證據補件** — 收集客訴與主管同意紀錄。
- **案件調查** — 查看人員、班次及品項關聯。
- **改善追蹤** — 記錄處置與複查結果。

## 適合誰使用

- 店長
- 營運稽核
- 財務主管

## 運作流程

1. 彙入折讓
2. 套用規則
3. 建立案件
4. 門店說明
5. 判定處置
6. 追蹤複查

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
