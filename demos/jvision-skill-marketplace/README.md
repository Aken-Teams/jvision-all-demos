# Skill Marketplace

> 讓企業搜尋、評估、授權、安裝及計價可供 Agent 重用的 Skills。＂ 服務估值風險

讓企業搜尋、評估、授權、安裝及計價可供 Agent 重用的 Skills。＂ 服務估值風險

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **Skill 能力探索** — 依任務、產業、系統與相容性搜尋可用 Skill。
- **規格相容比較** — 比較輸入輸出 Schema、MCP 支援、版本與相依套件。
- **授權政策審查** — 檢查資料權限、憑證範圍、地域限制與使用條款。
- **沙盒試用驗證** — 以測試資料執行 Skill，檢視結果品質與呼叫行為。
- **Skill 安裝中心** — 選擇環境、版本與 Agent，完成部署及失敗回滾。
- **用量計價管理** — 管理方案、單次呼叫成本、預算上限與費用歸屬。

## 適合誰使用

- 平台架構師
- 整合工程師
- AI 應用開發者

## 運作流程

1. 搜尋所需能力
2. 比較候選規格
3. 審查存取授權
4. 執行沙盒試用
5. 安裝至 Agent
6. 啟用計價監控

## 導入效益

- 事件平均處理：120分鐘 → **30分鐘**
- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
- 資產盤點工時：20小時/月 → **4小時/月**
