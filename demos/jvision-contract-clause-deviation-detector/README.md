# 合約條款偏離偵測器

> 比對合約與標準條款庫，定位非標準偏離並聚焦高風險法務審查。合約紅線審查／標準條款偏離偵測／談判風險聚焦。

## 功能模組

- **待審合約工作區** — 呈現合約結構、版本差異、交易背景與目前談判狀態。
- **標準條款選配** — 依交易類型、地區與風險政策選用適當的標準條款集。
- **逐條偏離比對** — 標出刪除、新增、改寫及語意偏移的非標準內容。
- **偏離風險評分** — 依責任、賠償、付款、終止等面向評估嚴重度與信心。
- **替代文字建議** — 提供回復標準、折衷版本與談判理由等可解釋建議。
- **談判立場核定** — 確認可接受偏離、底線與需升級決策的條款。

## 適合誰使用

- 法務主管
- 專利工程師

## 運作流程

1. 建立審查案件
2. 套用標準條款
3. 檢視條款偏離
4. 判定偏離風險
5. 擬定替代文字
6. 核定談判立場
