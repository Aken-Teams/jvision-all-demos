# 全通路客服自助解決助手

> 提供網站、通訊軟體與應用程式一致的模擬自助客服體驗，理解顧客問題後引導查詢、排錯與申請流程；無法解決時則整理對話、驗證結果及需求後轉交人工。

提供網站、通訊軟體與應用程式一致的模擬自助客服體驗，理解顧客問題後引導查詢、排錯與申請流程；無法解決時則整理對話、驗證結果及需求後轉交人工。

**產業別：**客服管理　|　**系統類型：**service-desk

## 功能模組

- **全通路對話入口** — 切換網站、通訊軟體與應用程式情境，展示一致的對話與服務狀態。
- **問題理解中心** — 呈現意圖、關鍵資訊、信心程度及需要向顧客補問的欄位。
- **引導解決流程** — 依問題類型逐步展示查詢、排錯、退換貨或服務申請的互動步驟。
- **結果確認頁** — 請顧客確認是否解決，顯示處理摘要、後續提醒與滿意度回饋。
- **人工轉接中心** — 整理對話摘要、已嘗試步驟、顧客資料與轉接原因，模擬排隊狀態。
- **自助成效分析** — 分析熱門意圖、解決率、卡點、轉接原因及各通路體驗差異。

## 適合誰使用

- 消費者
- 客服營運主管
- 知識管理員與第一線客服人員

## 運作流程

1. 接收提問
2. 理解問題
3. 引導處理
4. 確認結果
5. 轉接人工
6. 改善服務

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
