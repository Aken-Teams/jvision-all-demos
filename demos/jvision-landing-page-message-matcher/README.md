# 落地頁訊息匹配器

比對廣告意圖與落地頁訊息，找出斷裂點並提出降低跳出的修改方案。​

**產業別：**業務銷售　|　**系統類型：**analytics-bi

## 功能模組

- **廣告意圖解析** — 解析廣告承諾、關鍵字、受眾需求與行動暗示。
- **頁面訊息解構** — 拆解首屏標題、賣點、證明與行動呼籲。
- **意圖訊息比對** — 逐項比對廣告承諾與頁面回應的一致程度。
- **訊息斷裂定位** — 標出缺漏、矛盾、語氣偏差與資訊延遲位置。
- **跳出因果診斷** — 結合流量與行為資料排序可能的跳出原因。
- **頁面修正提案** — 產生標題、賣點、內容順序與 CTA 的修改版本。

## 運作流程

1. 選擇廣告組合
2. 確認意圖摘要
3. 檢視頁面結構
4. 定位匹配缺口
5. 驗證跳出線索
6. 核准修改版本
