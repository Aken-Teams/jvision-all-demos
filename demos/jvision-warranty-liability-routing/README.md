# 保固責任派工判定台

> 將交屋後報修依戶別、設備、施工區位與保固條款歸併，串接施工及驗收紀錄判定責任分包，處理退件與改派，避免同案重複派工或責任爭議長期懸置。

**產業別：**營建工程　|　**系統類型：**service-desk

## 功能模組

- **報修受理** — 記錄戶別、位置、現象與住戶佐證。
- **案件歸併** — 辨識同源或重複問題並合併處理。
- **依據查詢** — 調閱契約保固、施工及驗收紀錄。
- **責任判定** — 指定責任分包並記錄判定理由。
- **維修派工** — 安排到場、追蹤退件與必要改派。
- **完修驗收** — 確認修復成果並保留責任績效。

## 適合誰使用

- 保固客服
- 工務工程師
- 分包維修窗口

## 運作流程

1. 受理住戶報修
2. 辨識重複案件
3. 查核保固依據
4. 判定責任分包
5. 執行維修派工
6. 驗收關閉案件

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
