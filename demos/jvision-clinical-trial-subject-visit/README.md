**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **受試篩選** — 依納入與排除條件檢查資格。
- **同意管理** — 記錄同意版本及簽署狀態。
- **訪視排程** — 計算允許窗口與預約日期。
- **項目執行** — 核對問診、檢查與檢體工作。
- **偏差處理** — 登錄漏項、逾窗與矯正措施。
- **醫師覆核** — 集中確認訪視紀錄及異常。

## 適合誰使用

- 研究護理師
- 試驗主持醫師
- 研究行政

## 運作流程

1. 篩選候選者
2. 完成同意
3. 安排訪視
4. 執行項目
5. 處理偏差
6. 完成覆核

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
