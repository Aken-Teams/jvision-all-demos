# 競品專利動向哨兵

持續追蹤競品專利新案、家族、審查與權利狀態，提早辨識技術威脅。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **競品新案雷達** — 監測指定競品、發明人與技術分類的新公開案件。
- **專利家族展開** — 彙整同族申請、優先權、國別布局與延伸案件。
- **審查進度監看** — 追蹤核駁、答辯、分割、續案與核准等程序事件。
- **權利狀態警報** — 辨識有效、失效、異議、訴訟與權利範圍變化。
- **技術主張比對** — 將競品請求項與自家產品規格及研發主題進行比對。
- **威脅處置清單** — 依產品影響、地域與時程排序監控或迴避建議。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 設定競品監測範圍
2. 捕捉新案與異動
3. 展開家族布局
4. 研判權利走向
5. 比對產品影響
6. 啟動威脅應對

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
