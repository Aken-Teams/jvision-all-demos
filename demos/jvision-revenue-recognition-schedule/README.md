# 合約收入認列管理台

> 彙整客戶合約的履約義務、交易價格、變更與驗收條件，建立收入分攤及認列時程，協助會計完成月結調整與佐證覆核。

彙整客戶合約的履約義務、交易價格、變更與驗收條件，建立收入分攤及認列時程，協助會計完成月結調整與佐證覆核。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **收入總覽** — 查看認列、遞延與待處理金額。
- **合約檢視** — 整理價款、期間與變更條款。
- **義務拆分** — 識別履約義務與單獨售價。
- **認列排程** — 建立時點或期間認列計畫。
- **月結分錄** — 產生調整分錄與差異說明。
- **覆核證據** — 彙整驗收與主管覆核紀錄。

## 適合誰使用

- 收入會計
- 財務主管
- 合約管理員

## 運作流程

1. 匯入客戶合約
2. 辨識履約義務
3. 分攤交易價格
4. 建立認列排程
5. 產生月結分錄
6. 完成收入覆核

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
