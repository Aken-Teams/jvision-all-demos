# 健康分數漂移監測器

> 監測客戶健康分數的資料與模型漂移，持續維持流失預警品質。能。

監測客戶健康分數的資料與模型漂移，持續維持流失預警品質。能。

**產業別：**客服管理　|　**系統類型：**analytics-bi

## 功能模組

- **健康分數脈動** — 追蹤分數分布、風險層級與預警命中率的變化。
- **客群漂移偵測** — 辨識方案、產業、區域與生命週期結構的偏移。
- **產品訊號變動** — 檢查功能改版或埋點變更是否改寫使用指標含義。
- **預警品質驗證** — 以續約、降級與流失結果回測模型準確性。
- **失準原因排序** — 依影響程度與可解釋線索排列可能根因。
- **校準方案工作台** — 模擬重設門檻、重加權或重訓後的預警表現。

## 適合誰使用

- 客戶成功主管
- CSM
- 客服主管

## 運作流程

1. 選定監測範圍
2. 掃描漂移訊號
3. 定位變動來源
4. 驗證預警失準
5. 評估校準方案
6. 核准模型處置

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
