# 資料品質例外裁決台

**產業別：**數據分析　|　**系統類型：**quality-qms

## 功能模組

- **品質豁免申請** — 針對特定資料集與規則提出具範圍、理由及期限的豁免。
- **例外裁決席** — 依業務必要性、資料風險與歷史案例建議核准或駁回。
- **期限與續期盤** — 管理生效、到期、續期門檻與逾時升級，避免永久豁免。
- **補償控制設計** — 配置替代檢查、隔離、標記或人工覆核以降低例外風險。
- **告警降噪策略** — 只抑制已核准範圍的重複告警，保留風險升高與越界訊號。
- **例外退場中心** — 追蹤根因修復、驗證品質恢復並撤銷不再必要的豁免。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 提交品質豁免
2. 評估例外風險
3. 核定期限條件
4. 落實補償控制
5. 監控告警邊界
6. 修復並撤銷例外

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
