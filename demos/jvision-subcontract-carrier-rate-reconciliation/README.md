# 外包車行運價核對台

> 依派車紀錄、車型、路線、合約價與臨時議價逐趟核對外包車行帳單，找出重複趟次、錯套車型及缺乏核准的加價。

依派車紀錄、車型、路線、合約價與臨時議價逐趟核對外包車行帳單，找出重複趟次、錯套車型及缺乏核准的加價。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **派車紀錄** — 查看外包趟次與路線。
- **帳單匯入** — 整理各車行請款格式。
- **趟次配對** — 依日期車號與客戶勾稽。
- **運價驗算** — 套用車型與路線合約。
- **加價覆核** — 檢查臨時議價證據。
- **付款結案** — 核准正確應付金額。

## 適合誰使用

- 調度主管
- 應付會計
- 運價管理員

## 運作流程

1. 匯入派車
2. 匯入帳單
3. 執行配對
4. 驗算價格
5. 確認加價
6. 核准付款

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
