# 製程良率即時預測台

> 利用目前工單進度與擬真製程數據，持續推估各產品、線別及批次的完工良率，提早標示可能低於目標的生產批次，並提供影響因素與情境試算，協助現場安排調整與抽驗。

利用目前工單進度與擬真製程數據，持續推估各產品、線別及批次的完工良率，提早標示可能低於目標的生產批次，並提供影響因素與情境試算，協助現場安排調整與抽驗。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **良率預測總覽** — 彙整各線別、產品與工單的預測良率及目標差距。
- **批次趨勢追蹤** — 呈現批次由投產至完工的預測曲線與風險變化。
- **低良率風險清單** — 依風險程度排序可能無法達標的在製批次。
- **影響因素解析** — 說明參數、設備狀態、物料與班別對預測結果的影響。
- **改善情境試算** — 調整模擬參數與抽驗策略，比較預測良率的可能變化。
- **現場處置追蹤** — 記錄調機、加驗、暫停或轉線等處置及後續成效。

## 適合誰使用

- 製造主管
- 製程工程師
- 生管人員

## 運作流程

1. 查看良率預測
2. 追蹤批次走勢
3. 篩選高風險批次
4. 解析影響因素
5. 試算改善方案
6. 執行處置追蹤

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
