# 招募管理預警塔

管理職缺公告、履歷篩選、面試安排至錄取全流程，因應製造業大量產線作業員快速招募需求。

- 原始系統：招募管理系統（ATS, Applicant Tracking System）
- 產業分類：智慧製造｜人資管理
- 使用部門：人資招募組、用人部門主管、廠務行政
- 工作流程：職缺申請 → 刊登發佈 → 履歷篩選 → 面試安排 → 錄取核薪 → 轉入職管理
- AI 應用：AI履歷自動評分與職缺媒合、到職率/流失風險預測
- 主要 KPI：職缺補齊天數、履歷轉面試率、錄取到職率、招募成本
- 代表產品：104人資King ATS、CakeResume for Business、Workable、SmartRecruiters
