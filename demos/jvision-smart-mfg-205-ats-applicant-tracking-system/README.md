# 招募管理系統（ATS, Applicant Tracking System）

> 出勤、薪資、招募到績效的人資全流程

招募管理系統（ATS, Applicant Tracking System）提供多平台職缺同步刊登、履歷自動篩選與關鍵字比對、面試排程與線上通知。人資招募組依「職缺申請 → 刊登發佈 → 履歷篩選 → 面試安排 → 錄取核薪 → 轉入職管理」推進作業，優先解決「產線缺工需大量快速招募」，用人部門主管則以職缺補齊天數與履歷轉面試率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**HRIS 人力資源系統

## 功能模組

- **出勤差勤** — 打卡、請假與加班
- **薪資計算** — 薪資、勞健保與報稅
- **排班管理** — 智慧排班與工時控管
- **招募任用** — 職缺、面試與報到
- **教育訓練** — 課程、證照與紀錄
- **績效考核** — 目標設定與考核流程

## 適合誰使用

- 人資招募組
- 用人部門主管
- 廠務行政

## 運作流程

1. 待處理
2. 主管確認
3. 人資執行
4. 歸檔完成

## 導入效益

- 薪資作業工時：42小時/月 → **7.7小時/月**
- 出勤異常處理：29分鐘 → **5.1分鐘**
- 招募到位天數：47天 → **26天**
- 表單簽核時效：2.9天 → **1天**
