# 溫室氣體盤查艙

> 碳盤查、能源監控到減碳目標的永續管理

整合活動數據、排放係數與 Scope 1/2/3 計算。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**ESG 永續　|　**系統類型：**ESG 永續 / 能源管理

## 功能模組

- **碳盤查** — 範疇一、二、三排放盤查
- **能源監控** — 用電/用能即時監控
- **減碳目標** — 目標設定與進度追蹤
- **排放源管理** — 排放源清冊與係數庫
- **永續報告** — GRI/ISO 報告產出
- **需量告警** — 用電尖峰即時預警

## 適合誰使用

- 永續專員
- 永續主管
- ESG 永續主管

## 運作流程

1. 待上架
2. 銷售中
3. 查證確認
4. 已結案

## 導入效益

- 盤查作業工時：42小時 → **7.7小時**
- 數據完整率：59% → **97%**
- 減碳目標達成：52% → **83%**
- 用能異常反應：23小時 → **2小時**
