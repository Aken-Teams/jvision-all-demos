# 跨站視覺追蹤器

追蹤產品跨站外觀變化，定位缺陷首次生成與持續惡化的站點。実際

**產業別：**生產製造　|　**系統類型：**quality-qms

## 功能模組

- **產品影像串鏈** — 依產品序號串接各製程站的影像與檢測紀錄。
- **跨站外觀時間軸** — 逐站並排呈現同一產品的外觀演變。
- **站間差異檢視** — 疊合相鄰站影像，突出新增、擴大或位移的異常。
- **缺陷生成站定位** — 推定缺陷首次出現的站點與可信區間。
- **站點條件關聯** — 關聯生成站的設備、材料、參數與同批產品。
- **改善任務編排** — 針對責任站產生調查、調機與複驗任務。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 串接產品旅程
2. 檢視外觀演變
3. 比對相鄰站點
4. 判定生成站點
5. 追查站點條件
6. 派發改善任務

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
