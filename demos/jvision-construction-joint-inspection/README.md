# 施工縫留設查驗台

> 依澆置分區管理施工縫、伸縮縫與後澆帶的核定位置、界面處理、止水材料及續澆前查驗，將設計詳圖、現場照片和量測結果連結，避免任意停澆、接縫污染或止水配置錯誤。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **留縫配置** — 在結構圖標示施工縫、後澆帶與伸縮縫位置。
- **異動核定** — 記錄臨時停澆原因及設計監造核定結果。
- **成形紀錄** — 保存停澆面、鋼筋、止水及模板現況照片。
- **界面處理** — 追蹤鑿毛、清潔、濕潤與止水材料施工。
- **續澆查驗** — 依縫型檢查界面、鋼筋及雜物清除狀況。
- **續澆放行** — 彙整缺失及簽核後發布可續澆區域。

## 適合誰使用

- 結構工程師
- 品管工程師
- 混凝土工班領班

## 運作流程

1. 規劃留縫位置
2. 核定現場異動
3. 記錄停澆成形
4. 完成界面處理
5. 執行續澆查驗
6. 核准續澆作業

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
