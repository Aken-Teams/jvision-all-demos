# 沖壓成型品質預測系統

> 整合擬真的材料批次、模具、壓力、速度與成型參數，在排產或試模階段預測裂紋、起皺及尺寸超差風險，協助製程工程師比較參數方案、設定品質管制窗口，並追蹤實際判定與預測差異，減少反覆試作與報廢。

整合擬真的材料批次、模具、壓力、速度與成型參數，在排產或試模階段預測裂紋、起皺及尺寸超差風險，協助製程工程師比較參數方案、設定品質管制窗口，並追蹤實際判定與預測差異，減少反覆試作與報廢。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **品質風險總覽** — 彙整待生產工單的裂紋、起皺、尺寸風險與優先處理順序。
- **條件設定工作台** — 選擇材料批次、模具與成型參數，建立可重複比較的製程情境。
- **品質預測結果** — 呈現各缺陷機率、關鍵影響因子、風險區域與預測可信度。
- **參數方案比較** — 並列多組壓力、速度及間隙方案，評估品質、產能與容許範圍。
- **製程窗口核准** — 設定參數上下限、品質檢查點與核准狀態，形成生產設定版本。
- **預測驗證分析** — 以擬真檢驗結果比較預測與實際判定，追蹤偏差和改善成效。

## 適合誰使用

- 製程工程師
- 試模工程師
- 品保主管與生產課長

## 運作流程

1. 篩選高風險工單
2. 建立成型情境
3. 檢視品質預測
4. 比較調參方案
5. 核准製程窗口
6. 回顧預測表現

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
