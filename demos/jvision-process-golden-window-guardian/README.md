# 製程參數黃金窗口守門員

> 管理產品與製程的最佳參數範圍，以擬真批次曲線監看偏移、預警越界風險，並串聯品質結果、變更審核與處置紀錄，降低參數漂移造成的不良與重工。

管理產品與製程的最佳參數範圍，以擬真批次曲線監看偏移、預警越界風險，並串聯品質結果、變更審核與處置紀錄，降低參數漂移造成的不良與重工。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **黃金窗口管理** — 維護各產品與站點的參數上下限及目標值。
- **批次曲線監看** — 以趨勢圖比較實際參數、目標線與管制界限。
- **偏移預警中心** — 依接近界限、越界時間及影響程度排列警示。
- **品質關聯分析** — 比對參數偏移與缺陷、良率及批次結果。
- **調參情境模擬** — 比較候選參數組合及預估品質風險。
- **變更審核紀錄** — 呈現參數調整申請、審核與版本追溯。

## 適合誰使用

- 製程工程師
- 品質工程師
- 線長
- 生產主管

## 運作流程

1. 定義最佳窗口
2. 巡查批次曲線
3. 處理偏移預警
4. 驗證品質關聯
5. 模擬調參方案
6. 核准參數變更

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
