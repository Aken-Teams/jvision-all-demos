## 功能模組

- **退費申請** — 登錄原因與項目
- **金額試算** — 扣除已履約額
- **原款配對** — 確認支付工具
- **重複檢查** — 攔截重退風險
- **分層覆核** — 落實職務分離
- **退款結案** — 核對實際出款

## 適合誰使用

- 診所櫃檯
- 醫務會計
- 財務主管

## 運作流程

1. 受理申請
2. 核算履約
3. 配對原款
4. 執行檢核
5. 核准退費
6. 確認出款
