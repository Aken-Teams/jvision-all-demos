# 殯儀場館檔期管理台

> 協助殯葬服務業者管理禮廳、冷藏位、火化時段與接駁車等有限資源，處理預留、確認、衝突及臨時改期，讓案件承辦與場館調度維持一致安排。

協助殯葬服務業者管理禮廳、冷藏位、火化時段與接駁車等有限資源，處理預留、確認、衝突及臨時改期，讓案件承辦與場館調度維持一致安排。

**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **資源日曆** — 查看禮廳、冷藏位與車輛占用
- **檔期預留** — 依案件暫留所需資源
- **衝突協調** — 比較替代時段與調整方案
- **場館確認** — 記錄內外部資源確認結果
- **改期處理** — 同步異動影響與通知對象
- **使用分析** — 分析尖峰需求及資源缺口

## 適合誰使用

- 禮儀承辦
- 場館調度
- 營運主管

## 運作流程

1. 查詢資源
2. 建立預留
3. 處理衝突
4. 取得確認
5. 同步改期
6. 檢討使用

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
