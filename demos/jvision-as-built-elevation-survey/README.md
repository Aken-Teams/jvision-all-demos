# 竣工高程實測成果台

> 彙整道路、排水、基地與建築完成面的竣工高程實測點，對照核准設計值及容許差，管理異常點複測、設計釋疑與修整成果，形成竣工圖可採用的測量紀錄。

彙整道路、排水、基地與建築完成面的竣工高程實測點，對照核准設計值及容許差，管理異常點複測、設計釋疑與修整成果，形成竣工圖可採用的測量紀錄。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **測點配置** — 依區域、斷面與設施建立測點及設計高程。
- **實測匯入** — 登錄測次、儀器、基準點及實測數值。
- **高程比對** — 計算設計差值、坡度與容許差判定。
- **超差處置** — 指定複測、修整或設計釋疑的責任與期限。
- **複測驗證** — 保存修整後數值並比較歷次測量結果。
- **成果核定** — 凍結可供竣工圖引用的測量成果版。

## 適合誰使用

- 測量工程師
- 土建工程師
- 監造工程師

## 運作流程

1. 建立竣工測點
2. 提交現場實測
3. 判讀高程差異
4. 執行異常處置
5. 完成複測驗證
6. 核定竣工成果

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
