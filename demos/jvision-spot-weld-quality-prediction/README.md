# 點焊品質預測系統

> 彙整點焊電流、通電時間、加壓力與電極狀態等擬真製程資料，預測焊點品質與不良風險，協助品保提前安排抽驗、追查高風險批次，並比較參數調整前後的改善成效。

彙整點焊電流、通電時間、加壓力與電極狀態等擬真製程資料，預測焊點品質與不良風險，協助品保提前安排抽驗、追查高風險批次，並比較參數調整前後的改善成效。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **品質風險總覽** — 以良率、風險分布與產線排行呈現當日點焊品質概況。
- **工單批次監控** — 依工單、機台與班別檢視各批次的預測品質和異常數量。
- **焊點風險解析** — 呈現單一焊點的參數、風險分數與主要影響因子。
- **抽驗任務管理** — 將高風險批次排入破壞或非破壞檢驗並記錄模擬結果。
- **參數改善模擬** — 比較不同電流、時間及壓力設定下的預估品質變化。
- **品質成效報告** — 彙整不良趨勢、預測命中與改善前後差異供主管檢討。

## 適合誰使用

- 品保工程師
- 製程工程師
- 產線主管

## 運作流程

1. 掌握品質風險
2. 鎖定高風險批次
3. 解析焊點原因
4. 安排品質抽驗
5. 模擬參數改善
6. 回顧改善成效

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
