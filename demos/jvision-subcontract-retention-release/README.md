# 分包保留款到期釋放台

> 依分包契約管理各期估驗保留款、保固起算日、缺失扣留、文件條件與分段釋放，讓工務與財務在付款前核對履約狀態，避免逾期未付或尚有責任即提前釋款。

依分包契約管理各期估驗保留款、保固起算日、缺失扣留、文件條件與分段釋放，讓工務與財務在付款前核對履約狀態，避免逾期未付或尚有責任即提前釋款。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **契約條件** — 設定保留比例、釋放節點及保固期間。
- **保留款台帳** — 按估驗期累計應保留、已釋放與餘額。
- **到期清單** — 顯示近期符合完工或保固節點的案件。
- **條件會簽** — 核對驗收、缺失、結算及保固文件。
- **扣留覆核** — 計算爭議款、未改善缺失與應付淨額。
- **釋款批次** — 建立核准付款清冊及分包通知紀錄。

## 適合誰使用

- 計價工程師
- 財務人員
- 工務經理

## 運作流程

1. 設定條件
2. 累計台帳
3. 產生到期
4. 工務會簽
5. 覆核金額
6. 核准付款

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
