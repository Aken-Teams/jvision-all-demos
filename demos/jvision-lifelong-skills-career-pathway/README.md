# 終身學習職涯銜接平台

> 將模擬課程、證照、工作經驗與職務需求映射為可閱讀的技能圖譜，協助學習者盤點既有能力、辨識職涯目標缺口、規劃跨機構學習路徑，並以作品與評量證據追蹤技能成長。

將模擬課程、證照、工作經驗與職務需求映射為可閱讀的技能圖譜，協助學習者盤點既有能力、辨識職涯目標缺口、規劃跨機構學習路徑，並以作品與評量證據追蹤技能成長。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **個人技能圖譜** — 整合模擬課程、證照、經歷與作品，呈現技能節點及關聯。
- **職務能力探索** — 瀏覽目標職務的核心技能、熟練要求與相近轉職方向。
- **技能缺口診斷** — 比較個人現況與目標職務，列出優先補強能力及證據不足。
- **學習路徑規劃** — 組合課程、專題與證照，形成可調整的階段學習計畫。
- **能力證據錢包** — 整理評量、作品、證書與經驗紀錄，標示證據可信程度。
- **職涯進展追蹤** — 追蹤技能成長、路徑完成度與目標職務準備程度。

## 適合誰使用

- 在職學習者
- 待轉職者
- 職涯顧問
- 培訓機構課程規劃者

## 運作流程

1. 建立技能圖譜
2. 探索目標職務
3. 診斷能力缺口
4. 規劃學習路徑
5. 累積能力證據
6. 檢視職涯進展

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
