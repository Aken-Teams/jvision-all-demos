# 保險客戶主檔整併台

> 辨識不同通路建立的重複客戶，審查姓名、證號、地址、法人關係與服務紀錄，預覽整併對保單、理賠、制裁篩檢及行銷同意的影響。

辨識不同通路建立的重複客戶，審查姓名、證號、地址、法人關係與服務紀錄，預覽整併對保單、理賠、制裁篩檢及行銷同意的影響。

**產業別：**金融保險　|　**系統類型：**it-ops

## 功能模組

- **重複候選** — 產生疑似群組
- **身分證據** — 比對關鍵欄位
- **關係檢視** — 呈現法人家庭
- **影響模擬** — 預覽保單移轉
- **整併審核** — 雙人管制決策
- **同步驗證** — 確認各端一致

## 適合誰使用

- 客戶資料管理員
- 法遵人員
- 資訊人員

## 運作流程

1. 建立候選
2. 核實身分
3. 盤點關係
4. 預覽整併
5. 雙人核准
6. 同步驗證

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
