# 訂閱報表智慧問答台

> 彙整網站訂閱來源、營運報表與歷史資料，透過自然語言提問快速找出指標變化、異常原因及重點摘要，並以模擬引用來源呈現答案，降低人工查表與跨系統整理資訊的時間。

彙整網站訂閱來源、營運報表與歷史資料，透過自然語言提問快速找出指標變化、異常原因及重點摘要，並以模擬引用來源呈現答案，降低人工查表與跨系統整理資訊的時間。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **訂閱來源總覽** — 檢視各類網站訂閱來源、更新狀態與最新文章。
- **報表摘要中心** — 依日期與主題瀏覽營運報表及自動整理重點。
- **自然語言問答** — 用日常語句詢問指標、事件與內容關聯。
- **趨勢比較分析** — 以圖表比較期間、來源或部門的資料差異。
- **答案來源查核** — 展開引用段落、資料日期與模擬可信度標示。
- **洞察匯出分享** — 將問答結果整理成簡報摘要或分享卡片。

## 適合誰使用

- 企業主管
- 營運分析師
- 行銷企劃與研究人員

## 運作流程

1. 設定訂閱來源
2. 瀏覽報表摘要
3. 提出資料問題
4. 比較期間趨勢
5. 核對引用依據
6. 分享決策摘要

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
