# 智慧定價折扣控管台

> 整合商品成本、客戶層級、競爭情境與歷史成交資料，提供建議價格及可接受折扣區間；當報價低於毛利或權限門檻時，引導業務補充理由並進入分級審批。

**產業別：**業務銷售　|　**系統類型：**sales-crm

## 功能模組

- **報價工作台** — 選擇客戶與品項，模擬數量、合約期、牌價、折扣及預估毛利。
- **建議價格中心** — 以擬真成交紀錄與客戶特徵呈現建議價、合理區間及影響因素。
- **折扣護欄檢查** — 即時標示權限、最低毛利、促銷互斥與客戶分級等規則結果。
- **情境比較器** — 並列不同價格、數量與付款條件對營收、毛利及成交機率的影響。
- **例外審批中心** — 呈現申請理由、風險摘要與分級簽核路徑，支援模擬核准或退回。
- **定價績效儀表板** — 分析折扣分布、護欄命中、成交結果與業務或產品別的價格紀律。

## 適合誰使用

- 業務代表
- 業務主管
- 財務主管與產品定價經理

## 運作流程

1. 建立報價
2. 取得建議
3. 檢查護欄
4. 比較方案
5. 審批例外
6. 追蹤成效
