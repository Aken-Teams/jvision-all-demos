# 交屋文件備妥追蹤台

> 依戶別建立交屋文件包清單，追蹤保固書、設備說明、檢測紀錄、圖卡與簽章文件的收件、審核、補件及裝袋，並以戶號覆核避免交屋當日缺件或錯裝。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **戶別清單** — 建立各戶應備文件與適用設備項目。
- **廠商收件** — 追蹤分包上傳、紙本送達與承諾日期。
- **文件審查** — 檢查型號、日期、簽章及有效版本。
- **缺件催補** — 派發缺漏、錯版與逾期文件補正。
- **文件組包** — 依戶號產生目錄並記錄裝袋結果。
- **交付覆核** — 掃描戶號並確認文件包與房屋一致。

## 適合誰使用

- 交屋專員
- 工務行政
- 分包文件窗口

## 運作流程

1. 建立應備清單
2. 收取廠商文件
3. 審查文件效力
4. 追蹤缺漏補正
5. 完成戶別組包
6. 交屋前最終覆核

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
