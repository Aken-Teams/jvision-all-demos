# 門市報廢稅證核驗台

> 集中門市報廢清冊、品號數量、銷毀照片與核准紀錄，讓財會在認列損失前核驗證據及異常比例，並產出稅務查核所需的完整報廢證明包。

集中門市報廢清冊、品號數量、銷毀照片與核准紀錄，讓財會在認列損失前核驗證據及異常比例，並產出稅務查核所需的完整報廢證明包。

**產業別：**零售電商　|　**系統類型：**finance-case

## 功能模組

- **報廢批次** — 彙整各店待核驗清冊
- **銷毀證據** — 整理照片日期與品項
- **帳實核對** — 比對品號數量與庫存
- **異常分析** — 標記高額高頻報廢
- **財會核驗** — 核准認列或退回補件
- **稅證封存** — 產出查核證據包

## 適合誰使用

- 門市主管
- 存貨會計
- 稽核人員

## 運作流程

1. 建立批次
2. 上傳證據
3. 核對庫存
4. 檢視異常
5. 核准認列
6. 封存稅證

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
