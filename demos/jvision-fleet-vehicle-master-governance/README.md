# 車隊車輛主檔治理台

> 整合車號、車身號、內部編號及換牌沿革，治理車型、保險、維修與排班系統間的車輛身分，防止重複建檔或未投保車輛被派班。

整合車號、車身號、內部編號及換牌沿革，治理車型、保險、維修與排班系統間的車輛身分，防止重複建檔或未投保車輛被派班。

**產業別：**交通運輸　|　**系統類型：**it-ops

## 功能模組

- **車輛候選** — 找出重複主檔
- **車籍比對** — 核對車身車號
- **換牌沿革** — 串連歷史編號
- **系統關聯** — 檢視成本維修
- **整併審核** — 確認保留資料
- **發布驗證** — 同步排班資產

## 適合誰使用

- 車籍管理員
- 車隊資訊人員
- 資產會計

## 運作流程

1. 發現重複
2. 核對車籍
3. 串連沿革
4. 預覽影響
5. 核准整併
6. 同步驗證

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
