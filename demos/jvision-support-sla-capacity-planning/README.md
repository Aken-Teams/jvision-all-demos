# 客服人力容量規劃台

> 依歷史案件量、活動檔期、渠道與服務等級，模擬客服各時段所需人力，協助主管安排班次、外包席次及跨組支援方案。

依歷史案件量、活動檔期、渠道與服務等級，模擬客服各時段所需人力，協助主管安排班次、外包席次及跨組支援方案。

**產業別：**客服管理　|　**系統類型：**service-desk

## 功能模組

- **容量總覽** — 查看需求與人力缺口
- **需求預測** — 分析渠道時段與事件量
- **人力供給** — 盤點班次技能及可用席次
- **情境模擬** — 比較加班外包與跨組支援
- **方案發布** — 形成時段容量配置方案
- **偏差檢討** — 比較預估與實際服務結果

## 適合誰使用

- 客服營運主管
- 排班專員
- 外包管理員

## 運作流程

1. 彙整需求
2. 建立預測
3. 盤點供給
4. 模擬方案
5. 發布容量
6. 檢討偏差

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
