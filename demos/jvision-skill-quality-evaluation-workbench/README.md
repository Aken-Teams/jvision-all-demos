# Skill 品質評測台

> 以企業任務集比較 Skill 的完成率、成本與安全性，建立可執行的上架門檻。

以企業任務集比較 Skill 的完成率、成本與安全性，建立可執行的上架門檻。

**產業別：**資訊科技　|　**系統類型：**quality-qms

## 功能模組

- **任務集設計器** — 建立涵蓋正常、邊界與攻擊情境的代表性任務集。
- **版本對照試驗** — 以相同輸入並行評測多個 Skill 或版本。
- **完成品質評分** — 判定任務完成率、答案正確性與工具選擇品質。
- **成本效能比較** — 比較 Token、API 費用、延遲與重試成本。
- **安全壓力測試** — 測試越權、資料外洩、危險呼叫與提示攻擊風險。
- **上架門檻裁定** — 依加權指標產生通過、限用或退回改善結論。

## 適合誰使用

- 平台架構師
- 整合工程師
- AI 應用開發者

## 運作流程

1. 定義評測任務
2. 配置候選 Skill
3. 執行對照試驗
4. 分析品質成本
5. 審查安全缺口
6. 核定上架資格

- 系統可用率：97% → **99%**
