# 未到發票費用估列台

> 供會計在月結時依驗收、合約、服務期間與歷史請款辨識未到發票，建立費用估列、覆核依據及次月迴轉追蹤，避免費用跨期、重複入帳與結帳後補調。

供會計在月結時依驗收、合約、服務期間與歷史請款辨識未到發票，建立費用估列、覆核依據及次月迴轉追蹤，避免費用跨期、重複入帳與結帳後補調。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **估列總覽** — 呈現候選、待確認、已過帳與差異項目。
- **候選辨識** — 依驗收與未請款狀態整理估列清單。
- **金額試算** — 按期間、數量或比例計算應列費用。
- **依據彙整** — 保存合約、驗收與部門確認證據。
- **覆核過帳** — 依門檻審核科目、成本中心與金額。
- **迴轉比對** — 將估列與實際發票配對並分析差異。

## 適合誰使用

- 總帳會計
- 部門預算管理員
- 財務主管

## 運作流程

1. 辨識候選
2. 確認期間
3. 試算金額
4. 補齊依據
5. 覆核過帳
6. 比對迴轉

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
