# 瓶頸移轉模擬器

> 模擬工站改善後的產能流動與新瓶頸位置，避免製程局部最佳化。／

模擬工站改善後的產能流動與新瓶頸位置，避免製程局部最佳化。／

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **產線流動建模** — 建立工站、緩衝區、設備、換線與重工路徑的製程圖譜。
- **現況瓶頸診斷** — 依週期、等待、稼動率與在製品判定目前限制產出的工站。
- **改善方案設定** — 模擬增速、加機、降故障、縮換線或調整批量等改善措施。
- **瓶頸移轉預測** — 預測改善生效後新瓶頸的位置、發生時間與形成原因。
- **連鎖影響分析** — 顯示在製品堆積、缺料、品質與下游等待的跨站變化。
- **全線改善草案** — 產生兼顧前後站能力、投資需求與執行順序的改善組合。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 建立產線圖譜
2. 診斷目前瓶頸
3. 設定單站改善
4. 模擬瓶頸移轉
5. 修訂全線方案
6. 核准改善計畫

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
