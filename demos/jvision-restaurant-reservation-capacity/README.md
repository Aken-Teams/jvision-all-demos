# 餐廳訂位容量調度台

> 整合訂位、候位、桌型與用餐時段，協助餐廳預估尖峰容量、安排併桌拆桌並追蹤未到店紀錄，降低空桌與現場塞車。

整合訂位、候位、桌型與用餐時段，協助餐廳預估尖峰容量、安排併桌拆桌並追蹤未到店紀錄，降低空桌與現場塞車。

**產業別：**餐飲旅宿　|　**系統類型：**pos-frontdesk

## 功能模組

- **訂位日曆** — 檢視各時段訂位與剩餘容量
- **桌位配置** — 安排桌型、併桌與保留桌
- **到店報到** — 記錄報到、遲到與同行人數
- **候位佇列** — 排序候位並估算入座時間
- **換桌調度** — 處理換桌及臨時桌位調整
- **容量分析** — 分析拒客、爽約與桌位利用率

## 適合誰使用

- 櫃檯領班
- 值班經理
- 店長

## 運作流程

1. 建立訂位
2. 配置桌位
3. 確認提醒
4. 報到候位
5. 入座調度
6. 營運複盤

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
