# 製程控制限自適應引擎

**產業別：**生產製造　|　**系統類型：**quality-qms

## 功能模組

- **控制限健康度** — 呈現各製程特性的誤報率、漏報風險與控制限適配程度。
- **產品組合分群** — 依料號、配方、設備與批量建立具可比性的製程情境群組。
- **環境效應建模** — 量化溫濕度、季節與班次對製程分布和波動的影響。
- **候選界限模擬** — 模擬不同上下限對誤報、漏報、良率與停線時間的影響。
- **界限版本審核** — 並列現行與建議控制限，呈現不確定區間及變更理由。
- **控制限發布監測** — 將核准界限同步至來源系統，持續觀察變更後的告警品質。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 檢視界限失配
2. 建立產品情境
3. 估算環境效應
4. 模擬候選界限
5. 核准界限版本
6. 發布並觀察成效

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
