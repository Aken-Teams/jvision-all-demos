# 電子實驗記錄本（ELN，實驗數據管理）

> 訂單到入庫的製造現場全流程數位化

電子實驗記錄本（ELN，實驗數據管理）提供實驗計畫與記錄結構化輸入、數據自動匯入（設備介接）、實驗結果版本追溯與簽署。研發專案管理師、研發經理、技術長依「實驗計畫與記錄結構化輸入、數據自動匯入（設備介接）、實驗結果版本追溯與簽署」推進作業，優先解決「紙本記錄易遺失且難以搜尋」，部門主管則以電子實驗記錄本智慧站處理結果確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**研發管理　|　**系統類型：**MES 製造執行系統

## 功能模組

- **工單管理** — 訂單轉工單、拆併單與工單派發
- **排程排產** — 依產能、交期、負載自動排程
- **現場執行** — 派工、報工與進度即時回報
- **設備稼動 OEE** — 稼動、效率、良率即時監控
- **品質入庫** — 檢驗判定、不良處置與入庫
- **AI 改善建議** — 異常摘要與瓶頸改善建議

## 適合誰使用

- 研發專案管理師
- 研發經理
- 技術長

1. 規劃中
2. 執行中

4. 發布完成
