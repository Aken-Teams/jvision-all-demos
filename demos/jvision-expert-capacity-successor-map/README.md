## 功能模組

- **知識集中地圖** — 顯示主題、專家與團隊間的知識集中關係。
- **單點風險榜** — 找出僅由少數人掌握且需求持續升高的知識。
- **專家負載排程** — 整合案件量、會議與可支援時段預估容量。
- **替代者推薦** — 按相似經驗、協作紀錄與學習距離排列候選人。
- **接班情境模擬** — 模擬離職、休假或需求暴增時的覆蓋缺口。
- **知識移轉計畫** — 建立影子學習、文件補強與共同承接任務。

## 適合誰使用

- 知識工作者
- 主管
- 客服

## 運作流程

1. 盤點知識集中
2. 鎖定單點瓶頸
3. 確認專家容量
4. 評估候補人選
5. 模擬人力情境
6. 核准移轉計畫

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
