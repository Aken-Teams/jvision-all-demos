# ITAM（IT資產管理）

> 服務工單、資產到即時監控的 IT 維運

ITAM（IT資產管理）提供硬體資產盤點與序號追蹤、軟體授權管理與合規稽核、資產採購、報廢生命週期。資訊部依「資產採購入帳→標籤建檔→派發使用→定期盤點→報廢/汰換→稽核報表」推進作業，優先解決「資產帳實不符」，財務部則以資產盤點準確率與軟體合規率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**資訊科技　|　**系統類型：**IT 維運管理平台

## 功能模組

- **服務工單** — 事件/請求工單管理
- **資產管理** — IT 資產與軟體授權
- **即時監控** — 系統/網路健康監控
- **告警事件** — 告警彙整與分派
- **變更發布** — 變更與發布管理
- **服務報表** — SLA 與可用率報表

## 適合誰使用

- 資訊部
- 財務部
- 採購部

## 運作流程

1. 已受理
2. 處理中
3. 使用者確認
4. 已關閉

- 事件平均處理：115分鐘 → **32分鐘**
- 系統可用率：99% → **99%**
- SLA達成率：83% → **92%**
- 資產盤點工時：21小時/月 → **4.1小時/月**
