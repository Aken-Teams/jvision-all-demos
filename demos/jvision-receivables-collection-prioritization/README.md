# 應收帳款催收排序平台

> 整合客戶欠款金額、逾期天數、付款紀錄、爭議狀態與業務關係，產生可解釋的催收優先順序及建議行動，協助財會團隊把時間投入最可能回收且影響最大的帳款。

整合客戶欠款金額、逾期天數、付款紀錄、爭議狀態與業務關係，產生可解釋的催收優先順序及建議行動，協助財會團隊把時間投入最可能回收且影響最大的帳款。

**產業別：**財務會計　|　**系統類型：**finance-case

## 功能模組

- **催收優先佇列** — 依回收影響、逾期風險與成功機率排列客戶。
- **客戶欠款全貌** — 呈現發票帳齡、付款歷史、信用與往來資訊。
- **發票爭議中心** — 集中查看短付、退貨、價格或文件爭議及處理人。
- **建議行動助手** — 依客戶狀況提供電話、郵件或業務協調建議。
- **付款承諾追蹤** — 記錄承諾金額、日期、可信度與是否如期履行。
- **回收績效分析** — 比較人員、客群與帳齡區間的催收成果。

## 適合誰使用

- 應收帳款會計
- 財務主管
- 業務人員與催收專員

## 運作流程

1. 排定催收順序
2. 檢視客戶帳況
3. 釐清發票爭議
4. 選擇催收行動
5. 登錄付款承諾
6. 檢討回收成果

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
