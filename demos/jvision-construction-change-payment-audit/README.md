# 工程變更款授權稽核台

> 把現場指示、原合約範圍、變更單、報價與核准權限串成案件，辨識先做後簽、超權、重複計價及原約工作另列追加。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **原約範圍** — 查看合約工項與責任。
- **變更案件** — 彙整指示、報價與附件。
- **重複檢查** — 比對原約及其他變更。
- **權限驗證** — 確認金額核准層級。
- **稽核缺失** — 標示先做後簽與超權。
- **改善結案** — 追蹤補簽、扣款與制度改善。

## 適合誰使用

- 專案經理
- 成本主管
- 內稽人員

## 運作流程

1. 選取變更
2. 比對原約
3. 檢查重複
4. 驗證權限
5. 提出缺失
6. 追蹤改善

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
