# 運費附加費覆核台

> 逐票審查承運商申報的偏遠、等待、搬運及二次配送費，核對區域、合約與作業證據，攔截同票重複加收及無證明請款。

逐票審查承運商申報的偏遠、等待、搬運及二次配送費，核對區域、合約與作業證據，攔截同票重複加收及無證明請款。

**產業別：**物流運輸　|　**系統類型：**finance-case

## 功能模組

- **請款匯入** — 整理承運商附加費。
- **費率規則** — 核對區域與計價條件。
- **證據檢查** — 查看候時與簽認資料。
- **重複偵測** — 比對同票同費目。
- **爭議處理** — 追蹤扣款與承運商回覆。
- **付款覆核** — 核准合規附加費。

## 適合誰使用

- 應付會計
- 物流營運
- 稽核人員

## 運作流程

1. 匯入帳單
2. 套用規則
3. 檢查證據
4. 偵測重複
5. 提出爭議
6. 核准付款

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
