# 製程配方參數推薦台

> 依產品規格、設備能力及擬真歷史批次表現，推薦可供工程師評估的製程配方參數組合；透過限制條件、方案比較、風險說明與模擬驗證，加速新品試產及既有配方優化。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **推薦需求設定** — 選擇產品、設備、品質目標與希望優化的生產指標。
- **參數限制管理** — 設定溫度、壓力、速度等參數的容許範圍與相依規則。
- **配方方案推薦** — 提供多組候選參數及預估品質、節拍與風險結果。
- **方案權衡比較** — 並排比較推薦方案在良率、產能、能耗及穩定度的差異。
- **模擬批次驗證** — 以擬真批次資料呈現各方案可能產生的結果分布。
- **配方審核定版** — 記錄工程意見、版本差異與核准後的試產配方。

## 適合誰使用

- 製程工程師
- 研發工程師
- 製造主管

## 運作流程

1. 建立推薦需求
2. 設定參數限制
3. 取得配方推薦
4. 比較方案權衡
5. 驗證模擬批次
6. 審核配方版本

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
