# 租賃空置單元整備台

> 在租戶退租後，協調清點、修繕、清潔、估價資料與帶看條件，依預定招租日追蹤空置單元恢復可出租狀態，降低跨部門等待造成的空租天數。

在租戶退租後，協調清點、修繕、清潔、估價資料與帶看條件，依預定招租日追蹤空置單元恢復可出租狀態，降低跨部門等待造成的空租天數。

**產業別：**房地產與物業　|　**系統類型：**operations-console

## 功能模組

- **空置清單** — 查看退租日、目標招租日與目前狀態。
- **退租檢查** — 記錄現況、遺留物及應修復項目。
- **費用責任** — 區分押金扣抵、房東負擔及升級投資。
- **修繕排程** — 安排工項依賴、承商與完成日期。
- **招租素材** — 追蹤清潔、拍攝、平面圖及定價資料。
- **可租驗收** — 確認鑰匙、設備與帶看條件已就緒。

## 適合誰使用

- 租賃經理
- 物業主任
- 修繕協調員

## 運作流程

1. 建立空置案
2. 盤點缺失
3. 核定責任
4. 完成整備
5. 準備招租
6. 開放帶看

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
