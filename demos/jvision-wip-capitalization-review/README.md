# 在建工程轉列檢核台

> 按工程標的確認實際完工、驗收、可使用日期與剩餘重大義務，彙整成本後執行在建工程轉列，避免資產長期掛帳或過早開始折舊。

按工程標的確認實際完工、驗收、可使用日期與剩餘重大義務，彙整成本後執行在建工程轉列，避免資產長期掛帳或過早開始折舊。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **在建清冊** — 查看標的成本與進度
- **完工判定** — 核對驗收與可使用狀態
- **成本彙整** — 確認應資本化交易
- **剩餘義務** — 評估未完工程影響
- **資產轉列** — 設定日期類別與金額
- **查核底稿** — 保存證據和核准軌跡

## 適合誰使用

- 資產會計
- 專案財務
- 工程主管

## 運作流程

1. 篩選標的
2. 確認完工
3. 清查義務
4. 彙總成本
5. 核准轉列
6. 建立資產

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
