# 技能差距課程推薦引擎

> 把職務技能標準、員工自評、主管評估與模擬工作成果整合為差距地圖，依優先度、可用時間及學習方式推薦內外部課程，並用後續任務與再評估確認能力提升。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **職務技能地圖** — 呈現職務所需技能、目標等級與能力之間的關聯。
- **個人差距診斷** — 比較目標與目前能力，說明證據來源及待確認項目。
- **課程推薦清單** — 依差距、時間、難度與學習偏好排序擬真課程。
- **個人學習計畫** — 安排課程、微學習、實作任務、期限與預估投入時間。
- **能力驗證中心** — 以測驗、作品或主管觀察記錄學習後的能力證據。
- **組織技能分析** — 分析部門缺口、課程覆蓋、學習進度及投資重點。

## 適合誰使用

- 員工
- 直屬主管
- 培訓發展人員

## 運作流程

1. 確認技能標準
2. 診斷差距
3. 挑選課程
4. 建立計畫
5. 驗證能力
6. 檢討投資

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
