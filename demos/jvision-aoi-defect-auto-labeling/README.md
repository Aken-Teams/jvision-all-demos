# 光學缺陷自動標註台

> 將自動光學檢測（AOI）影像中的刮傷、髒污、缺角與異物候選區轉成可檢核標註，協助品保人員批次修正、複核與匯出訓練資料，減少人工逐張框選時間並維持標註規則一致。

將自動光學檢測（AOI）影像中的刮傷、髒污、缺角與異物候選區轉成可檢核標註，協助品保人員批次修正、複核與匯出訓練資料，減少人工逐張框選時間並維持標註規則一致。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **標註任務總覽** — 查看批次進度、待辦數量與各缺陷類別分布。
- **影像批次管理** — 依產品、工單與日期整理模擬 AOI 影像批次。
- **缺陷自動框選** — 呈現系統建議的缺陷位置、範圍與類別信心值。
- **人工修正工作台** — 調整框線、增刪標記並更正缺陷分類。
- **標註品質複核** — 抽樣比較標註結果並記錄退回原因與修正意見。
- **資料集匯出中心** — 設定版本與篩選條件，預覽可下載的標註資料摘要。

## 適合誰使用

- 品保工程師
- 影像標註員
- AI 模型工程師

## 運作流程

1. 建立標註任務
2. 整理影像批次
3. 產生建議標註
4. 修正缺陷標記
5. 執行抽樣複核
6. 封存資料版本

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
