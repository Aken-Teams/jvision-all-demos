# 施工圖介面整合台

> 針對建築、結構、機電與設備施工圖進行套圖衝突、介面責任、修訂與核定追蹤，確保工班取得同一基準版本後才進場施工。

針對建築、結構、機電與設備施工圖進行套圖衝突、介面責任、修訂與核定追蹤，確保工班取得同一基準版本後才進場施工。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **套圖批次** — 彙整同區域各專業圖面與基準版。
- **衝突清單** — 標示空間碰撞、尺寸及施工順序問題。
- **責任協調** — 指定主責專業、配合單位與決議期限。
- **修訂提交** — 管理各分包新版圖面及修正說明。
- **整合核定** — 確認衝突關閉與圖面會簽狀態。
- **現場發放** — 發布可施工版本並回收舊版。

## 適合誰使用

- 施工圖整合工程師
- 機電經理
- 分包商繪圖員

## 運作流程

1. 建立套圖
2. 標記衝突
3. 協調責任
4. 提交修訂
5. 完成核定
6. 發布現場

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
