# 預鑄構件進場組裝台

> 以構件編號串聯工廠出貨、車趟排序、現場堆置、吊裝圖與接頭查驗，讓預鑄梁柱或牆板依當日組裝順序到場，並處理錯件、缺件、破損及補製替換。

以構件編號串聯工廠出貨、車趟排序、現場堆置、吊裝圖與接頭查驗，讓預鑄梁柱或牆板依當日組裝順序到場，並處理錯件、缺件、破損及補製替換。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **構件清單** — 管理編號、版次、尺寸與目標位置。
- **車趟排序** — 依吊裝順序安排出貨與到場時段。
- **到貨核對** — 核對構件標籤、數量與外觀狀態。
- **吊裝派工** — 顯示吊點、順序及當日安裝位置。
- **接頭查驗** — 記錄灌漿、焊接與臨時支撐結果。
- **異常補製** — 追蹤錯件、破損及替換構件進度。

## 適合誰使用

- 預鑄工程師
- 吊裝指揮
- 品管工程師

## 運作流程

1. 選定構件
2. 安排車趟
3. 到貨驗件
4. 定位吊裝
5. 接頭查驗
6. 異常結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
