# 沖床異常振動診斷系統

> 運用預先產生的振動波形、頻譜與沖程趨勢，模擬辨識沖床軸承鬆動、飛輪不平衡、離合器衝擊及模具偏載等異常，協助維修人員分級告警、比對診斷證據、安排檢修並追蹤修復成效，減少停機與誤判。

運用預先產生的振動波形、頻譜與沖程趨勢，模擬辨識沖床軸承鬆動、飛輪不平衡、離合器衝擊及模具偏載等異常，協助維修人員分級告警、比對診斷證據、安排檢修並追蹤修復成效，減少停機與誤判。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **振動監控總覽** — 以機台卡片、趨勢與廠區平面呈現異常程度及告警狀態。
- **波形頻譜分析** — 切換時域波形、頻譜與沖程同步視圖，查看異常特徵標記。
- **故障診斷中心** — 列出可能故障模式、判斷依據、可信度與建議檢查部位。
- **告警事件管理** — 依嚴重度受理、指派、備註與關閉振動事件，保留處理軌跡。
- **檢修工單排程** — 建立檢修項目，安排停機窗口、維修技師、工具及備品。
- **修復成效驗證** — 比較維修前後振動指標與頻譜特徵，判定恢復、觀察或再修。

## 適合誰使用

- 設備工程師
- 維修技師
- 生產課長與廠務主管

## 運作流程

1. 發現異常機台
2. 檢視振動證據
3. 研判故障模式
4. 受理告警事件
5. 安排停機檢修
6. 確認修復結果

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
