# 營建廢棄物清運台

> 管理拆除廢料、包材與混合廢棄物的分類、清運申請、車次憑證及處理場回單，核對重量與費用，避免混裝、去向不明或重複請款。

管理拆除廢料、包材與混合廢棄物的分類、清運申請、車次憑證及處理場回單，核對重量與費用，避免混裝、去向不明或重複請款。

**產業別：**營建工程　|　**系統類型：**logistics-fleet

## 功能模組

- **廢棄物看板** — 依類別、堆置區與待運狀態查看批次。
- **分類申報** — 登錄來源工班、種類、估量及照片。
- **清運排車** — 核對承運資格並安排車輛時段。
- **出場紀錄** — 記錄車號、重量、聯單及出場照片。
- **回單核銷** — 核對處理場證明與實收重量。
- **費用對帳** — 依批次、車次與責任工班分攤成本。

## 適合誰使用

- 環安人員
- 工地倉管
- 成本工程師

## 運作流程

1. 申報廢料
2. 確認分類
3. 安排清運
4. 核對出場
5. 收取回單
6. 完成對帳

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
