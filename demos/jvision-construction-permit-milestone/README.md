# 建照使照文件管制台

> 協助建設公司與營造團隊依建照、變更設計及使用執照申辦節點整理圖說、審查意見、補件版本與責任窗口，以視覺化方式掌握文件成熟度及可能影響開工或交屋的延誤。

協助建設公司與營造團隊依建照、變更設計及使用執照申辦節點整理圖說、審查意見、補件版本與責任窗口，以視覺化方式掌握文件成熟度及可能影響開工或交屋的延誤。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **申辦路徑** — 建立建照、變更與使照節點。
- **文件清單** — 管理圖說、簽證與證明版本。
- **審查意見** — 拆解主管機關意見與補正要求。
- **補件分工** — 指定設計及工程窗口和期限。
- **期限預警** — 呈現阻塞及里程碑衝擊。
- **申辦總覽** — 彙整案件成熟度與核准狀態。

## 適合誰使用

- 開發專案經理
- 建築師窗口
- 工務行政

## 運作流程

1. 規劃路徑
2. 備齊文件
3. 登錄送審
4. 處理補正
5. 監控期限
6. 確認核准

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
