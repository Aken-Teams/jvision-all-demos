# 集團往來淨額結算台

> 協助企業集團彙整各法人間的應收應付往來，進行幣別、到期日與交易爭議核對，建立多邊淨額結算方案，取得子公司確認後產生付款指示及清帳明細。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **餘額匯入** — 彙整各法人應收應付明細。
- **雙邊核對** — 配對交易、幣別與到期日差異。
- **爭議處理** — 分派缺件、金額與歸屬問題。
- **淨額試算** — 計算多邊結算後的付款部位。
- **法人確認** — 取得子公司對結算結果的回覆。
- **付款清帳** — 產生付款指示與沖帳明細。

## 適合誰使用

- 集團資金人員
- 子公司會計
- 財務主管

## 運作流程

1. 蒐集餘額
2. 核對交易
3. 排除爭議
4. 計算淨額
5. 取得確認
6. 執行結算

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
