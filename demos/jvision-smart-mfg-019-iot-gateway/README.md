# IoT Gateway洞察站

連接現場設備、感測器與上層系統之通訊閘道，實現數據標準化擷取與傳輸。

- 原始系統：IoT Gateway（工業物聯網閘道）
- 產業分類：智慧製造｜製造管理
- 使用部門：資訊部門、設備工程、製造工程
- 工作流程：設備訊號擷取 → 邊緣運算前處理 → 協定轉換標準化 → 資料上傳雲端/平台 → 上層系統應用
- AI 應用：AI於邊緣端即時異常偵測、智慧數據壓縮與傳輸優化
- 主要 KPI：設備連網覆蓋率、數據傳輸延遲、連線穩定率
- 代表產品：PTC Kepware、Advantech WISE-PaaS、Siemens MindSphere、Ignition Edge
