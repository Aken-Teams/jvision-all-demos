# 門市價牌換檔覆核台

> 把促銷換檔清單依門市、貨架與商品派工，透過前後照片及掃碼覆核架上價、生效時間和收銀價，降低漏換與錯價客訴。

把促銷換檔清單依門市、貨架與商品派工，透過前後照片及掃碼覆核架上價、生效時間和收銀價，降低漏換與錯價客訴。

**產業別：**零售電商　|　**系統類型：**pos-frontdesk

## 功能模組

- **換檔批次** — 查看促銷生效與門市範圍。
- **貨架任務** — 按區域派發價牌清單。
- **商品核對** — 確認條碼與陳列位置。
- **換牌舉證** — 上傳前後照片與時間。
- **價差檢查** — 比對架上價與收銀價。
- **主管抽查** — 覆核高風險與未完成項目。

## 適合誰使用

- 門市人員
- 店長
- 營運督導

## 運作流程

1. 建立換檔
2. 分派貨架
3. 核對商品
4. 完成換牌
5. 檢查價差
6. 抽查結案

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
