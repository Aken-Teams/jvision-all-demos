# Context 預算配置器

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **視窗預算配置** — 分配系統指令、歷史、知識與工具結果的額度。
- **內容優先級規則** — 依任務、風險與資料新鮮度設定保留順位。
- **歷史壓縮策略** — 設定摘要、合併與捨棄對話歷史的條件。
- **知識片段配額** — 控制檢索片段數量、長度與最低相關度。
- **工具結果裁切** — 保留工具回傳中的必要欄位與關鍵證據。
- **截斷風險模擬** — 預覽不同模型視窗下的內容取捨與缺漏。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 選定請求樣本
2. 分配視窗預算
3. 設定保留順位
4. 配置壓縮裁切
5. 模擬截斷結果
6. 核准配置上線
