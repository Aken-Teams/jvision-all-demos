# 模型檔案完整性驗證器

> 驗證模型檔案的雜湊、數位簽章與來源鏈，防止權重遭竄改。海量的AI模型檔案完整性與來源鏈驗證。

**產業別：**資訊安全　|　**系統類型：**security-soc

## 功能模組

- **模型檔案清冊** — 列出權重、設定、分詞器與序列化檔案的核准版本。
- **雜湊一致性驗證** — 比對建置、儲存與部署節點上的檔案雜湊。
- **數位簽章檢查** — 驗證簽署者身分、憑證效期與簽章完整性。
- **來源鏈追溯** — 追蹤模型從供應商、微調、封裝到部署的傳遞鏈。
- **竄改風險模擬** — 評估異常檔案進入環境後的影響與阻斷方案。
- **可信版本復原** — 隔離可疑檔案並切換至最近通過驗證的模型版本。

## 適合誰使用

- CISO
- AI 治理主管
- 資安分析師

## 運作流程

1. 盤點模型檔案
2. 核對檔案雜湊
3. 驗證簽署身分
4. 審查來源鏈
5. 評估竄改影響
6. 復原可信版本
