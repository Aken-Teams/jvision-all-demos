# 外發電鍍逐籃對料台

> 供金屬加工廠逐籃記錄外發電鍍的料號、件數、重量、表處規格與交付狀態，分批回廠時逐籃核銷，迅速定位短少、錯鍍與待返工批。

供金屬加工廠逐籃記錄外發電鍍的料號、件數、重量、表處規格與交付狀態，分批回廠時逐籃核銷，迅速定位短少、錯鍍與待返工批。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **籃次總覽** — 查看送回狀態
- **出廠點交** — 記錄件重規格
- **加工追蹤** — 更新協力廠進度
- **返廠點收** — 逐籃核銷數量
- **錯鍍短少** — 建立爭議證據
- **返工追蹤** — 管理重鍍往返

## 適合誰使用

- 外發管理員
- 收料品管

## 運作流程

1. 裝籃建批
2. 司機交運
3. 廠商加工
4. 返廠點收
5. 品質驗收
6. 往返結清

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
