# MCP 相容性回歸測試器

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **版本差異偵測** — 比對 Server、Client、工具清單與 Schema 的版本變
- **契約案例編排** — 依能力發現、參數、授權與回應建立回歸案例。
- **雙端回歸執行** — 跨 Server 與 Client 組合重播真實呼叫及邊界案例。
- **Schema 相容判** — 辨識欄位刪除、型別改變、必填提升與回應漂移。
- **破壞變更定位** — 將失敗對應至版本提交、工具定義與呼叫軌跡。
- **發布閘門裁決** — 依風險阻擋發布、核准例外或回滾相容版本。

## 適合誰使用

- 平台架構師
- 整合工程師
- AI 應用開發者

## 運作流程

1. 選定版本組合
2. 建立契約套件
3. 執行回歸測試
4. 判讀相容性
5. 確認破壞來源
6. 裁決發布
