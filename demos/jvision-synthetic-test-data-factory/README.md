# 合成測試資料工廠

> 產生保留資料關聯與邊界案例的去識別測試資料，加速安全測試。            

產生保留資料關聯與邊界案例的去識別測試資料，加速安全測試。            

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **資料關聯藍圖** — 解析資料表、事件與欄位間的主外鍵及業務依賴。
- **去識別策略設計** — 為姓名、帳號與敏感屬性配置泛化、擾動或合成策略。
- **合成資料生成器** — 依目標規模與分布產生跨實體一致的測試資料集。
- **邊界案例編排** — 建立極值、空值、罕見組合與錯誤格式等測試情境。
- **隱私洩漏檢驗** — 評估重識別、近鄰複製與敏感屬性推斷風險。
- **測試資料包發布** — 封裝具版本、品質指標與適用測試範圍的資料包。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 繪製資料關聯
2. 設定去識別規則
3. 生成合成資料
4. 補齊邊界案例
5. 驗證隱私效用
6. 核准資料包
