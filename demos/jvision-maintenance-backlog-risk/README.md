# 維修積壓風險整頓台

> 供維護主管整理長期未結工單，依設備關鍵度、停機風險、備件狀態與工時需求分群，決定立即執行、合併停機、委外或正式取消。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **積壓總覽** — 呈現逾期結構與風險分布。
- **風險評分** — 依關鍵度和故障後果排序。
- **資源檢查** — 核對人力、備件與停機窗口。
- **整頓批次** — 組合可共同執行的維修任務。
- **延後決策** — 記錄延期、委外或取消依據。
- **消化追蹤** — 分析完成速度與風險下降。

## 適合誰使用

- 維護主管
- 維修規劃員
- 廠務經理

## 運作流程

1. 盤點積壓
2. 評估風險
3. 確認資源
4. 建立批次
5. 核准決策
6. 追蹤消化

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
