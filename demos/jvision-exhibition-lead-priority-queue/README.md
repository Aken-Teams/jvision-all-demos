# 展會商機優先隊列

> 即時評估展會名單價值，協助業務優先跟進最可能成交的商機。中文

**產業別：**業務銷售　|　**系統類型：**sales-crm

## 功能模組

- **商機優先隊列** — 依互動強度、職務影響力、需求與採購時程動態排序名單。
- **展會互動熱度** — 彙整攤位拜訪、議程參與、內容下載與會後回訪訊號。
- **決策角色辨識** — 辨識決策者、影響者、使用者及其在採購流程中的權重。
- **需求意圖解析** — 從對談與行為中抽取需求主題、產品興趣及待解問題。
- **採購時程研判** — 推估採購窗口、急迫性與適合啟動業務接觸的時間。
- **跟進派案中心** — 達門檻時建立案件、推薦負責業務並追蹤首次回應。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 檢視優先名單
2. 確認互動熱度
3. 校正角色權重
4. 審閱需求意圖
5. 判定跟進時機
6. 核准並指派

## 導入效益

- 商機轉換率：18% → **27%**
- 平均回應時間：26小時 → **6小時**
- 客戶資料完整率：62% → **94%**
- 報價逾期流失：9件/月 → **2件/月**
