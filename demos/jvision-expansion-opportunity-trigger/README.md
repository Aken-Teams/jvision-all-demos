# 擴張機會觸發器

> 從容量、使用深度與新團隊訊號辨識升級機會，提升淨留存。Detects upgrade opportunities from capacity, usage depth, and new-team signals to improve net

**產業別：**客服管理　|　**系統類型：**sales-crm

## 功能模組

- **擴張訊號雷達** — 持續掃描容量逼近、使用深化與新團隊加入等訊號。
- **新團隊滲透圖** — 呈現新部門、地區與角色的自然採用及擴散路徑。
- **容量臨界預測** — 預測席次、用量或方案限制何時會達到升級臨界點。
- **升級潛力評分** — 綜合營收、需求強度、健康度與成交不確定性排序機會。
- **擴張情境試算** — 比較加席、升版與跨團隊方案的收益及風險。
- **商機觸發中心** — 經核准後建立跟進任務並把商機同步至 CRM。

## 適合誰使用

- 客戶成功主管
- CSM
- 客服主管

## 運作流程

1. 掃描擴張訊號
2. 確認新團隊需求
3. 預測容量臨界
4. 排序升級機會
5. 比較擴張方案
6. 核准並觸發跟進
