# 團體住房房卡發放台

> 依團體房名單、入住條件與押款狀態準備房卡包，管理領隊領取、臨時換房、補卡及未發卡片，降低尖峰報到時錯發房號與個資外露。

依團體房名單、入住條件與押款狀態準備房卡包，管理領隊領取、臨時換房、補卡及未發卡片，降低尖峰報到時錯發房號與個資外露。

**產業別：**餐飲旅宿　|　**系統類型：**pos-frontdesk

## 功能模組

- **團體總覽** — 查看梯次房數與到店時間
- **分房核對** — 確認房號住客與特殊需求
- **發卡條件** — 檢查清潔押款與證件
- **卡包製作** — 建立房卡與領取標籤
- **換房補卡** — 停用舊卡並記錄原因
- **領取簽認** — 保存領隊與個別領取紀錄

## 適合誰使用

- 團體櫃台
- 訂房人員
- 值班主管

## 運作流程

1. 匯入團名
2. 核對房況
3. 檢查條件
4. 準備卡包
5. 處理變更
6. 完成發放

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
