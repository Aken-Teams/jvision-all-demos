# 工程送審文件管制台

> 供承攬商管理材料送審、施工計畫、樣品及圖說文件的版次、審查意見與核准狀態，確保工項開工前取得有效核准文件並避免誤用舊版。

供承攬商管理材料送審、施工計畫、樣品及圖說文件的版次、審查意見與核准狀態，確保工項開工前取得有效核准文件並避免誤用舊版。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **送審看板** — 顯示待送、審查中與逾期件。
- **文件清冊** — 管理類型、工項及必要文件。
- **送審編組** — 組成文件包並執行送審檢核。
- **意見回覆** — 逐項處理審查意見及佐證。
- **版次管制** — 比較修訂內容與有效版本。
- **現場發布** — 發布核准版及簽收紀錄。

## 適合誰使用

- 文件管制員
- 工地主任
- 監造工程師

## 運作流程

1. 盤點需求
2. 建立清冊
3. 組成送審包
4. 審查回覆
5. 修訂定版
6. 發布簽收

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
