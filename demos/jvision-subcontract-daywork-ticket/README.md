# 分包點工簽認核價台

> 管理契約外臨時點工需求，從現場派工、班別工時、機具與材料耗用到每日簽認及單價核定，形成請款可引用的依據，減少月底補單、工時灌水與責任爭議。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **點工需求** — 記錄派工原因、地點、工種與預估人力。
- **出工回報** — 填報人員、班別、起訖時間與工作內容。
- **耗用紀錄** — 登錄配合機具、零星材料及等待時間。
- **每日簽認** — 由雙方現場代表確認實作數量與異議。
- **契約判定** — 辨識原契約內、追加、代工或責任扣款。
- **核價彙整** — 套用核定單價並形成請款附件。

## 適合誰使用

- 現場工程師
- 分包工頭
- 成本工程師

## 運作流程

1. 提出點工需求
2. 回報實際出工
3. 登錄額外耗用
4. 完成當日簽認
5. 判定契約歸屬
6. 核定請款金額

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
