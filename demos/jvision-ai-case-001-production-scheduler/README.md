# 產線智排中心

> 訂單到入庫的製造現場全流程數位化，讓插單、缺料與交期一眼看清、當天可決。

產線智排中心把訂單、產能、料況、治具與現場報工整合到同一畫面，依交期與規則自動排出優先序，讓生管把時間花在處理例外、而不是重算排程。

**產業別：**生產製造　|　**系統類型：**MES 製造執行系統

## 功能模組

- **工單管理** — 訂單轉工單、拆併單與派發
- **智慧排程** — 依產能、交期、負載與治具自動排程
- **缺料與插單** — 料況比對、缺料預警與插單重排
- **現場報工** — 派工、報工與進度即時回報
- **設備稼動 OEE** — 稼動、效率、良率即時監控
- **AI 排程建議** — 瓶頸摘要與替代產線建議

## 適合誰使用

- 生管專員
- 製造課長
- 廠長

## 運作流程

1. 訂單轉工單
2. 排產派工
3. 領料開工
4. 報工回報
5. 品檢判定
6. 允收入庫

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：82% → **96%**
- 插單重排時間：45分鐘 → **8分鐘**
- 缺料停線次數：12次/月 → **3次/月**
