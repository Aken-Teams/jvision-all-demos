# 事故時間線與復盤器

自動重建事故事件、決策與系統證據，協助團隊完成高品質復盤。文補正

**產業別：**資訊科技　|　**系統類型：**operations-console

## 功能模組

- **事故範圍建立** — 界定受影響服務、時間區間、嚴重度與關聯事件。
- **事件時間線重建** — 合併告警、部署、訊息與操作紀錄，形成一致事件順序。
- **因果線索圖** — 串聯變更、症狀、決策與恢復動作，標示因果可信度。
- **決策脈絡還原** — 對齊討論內容與當時監控證據，說明每項決策的依據。
- **復盤草稿編輯** — 生成影響、根因、有效應對與改善機會的結構化復盤。
- **改善行動追蹤** — 把復盤結論轉成有負責人、期限與驗證方式的改善任務。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 界定事故
2. 重建時間線
3. 分析因果
4. 還原決策
5. 審閱復盤
6. 落實改善

- 事件平均處理：120分鐘 → **30分鐘**
- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
- 資產盤點工時：20小時/月 → **4小時/月**
