# 受託款項專戶核對台

> 逐案件核對受託專戶入款、付款人、用途、可動用條件、撥款指示與餘額，要求書面授權及雙人覆核，防止誤用其他客戶資金。

**產業別：**專業服務　|　**系統類型：**finance-case

## 功能模組

- **專戶流水** — 匯入收支與銀行餘額
- **案件歸屬** — 配對客戶案件及用途
- **動用條件** — 檢查委任與保管限制
- **撥款申請** — 記錄收款方金額與依據
- **雙人覆核** — 分離承辦製單與放行
- **餘額報告** — 逐案核對並交付客戶

## 適合誰使用

- 信託會計
- 案件承辦
- 財務主管

## 運作流程

1. 匯入專戶流水
2. 辨識款項歸屬
3. 核對動用條件
4. 提出撥款申請
5. 執行雙人覆核
6. 完成撥款對帳

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
