# 醫療轉診追蹤管理台

> 管理診所轉出與轉入個案的摘要準備、院所聯繫、預約結果及回覆報告，以擬真病例狀態呈現待追蹤清單，避免高風險患者在跨院照護過程中失聯。

管理診所轉出與轉入個案的摘要準備、院所聯繫、預約結果及回覆報告，以擬真病例狀態呈現待追蹤清單，避免高風險患者在跨院照護過程中失聯。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **轉診建案** — 登錄原因、急迫度與目標院所
- **摘要準備** — 核對轉診摘要與必要附件
- **院所媒合** — 記錄科別、窗口及預約資訊
- **就醫追蹤** — 更新聯繫與實際就醫結果
- **報告回收** — 管理回覆報告與待補資料
- **照護銜接** — 安排回診、用藥及後續處置

## 適合誰使用

- 護理師
- 轉診個管師
- 診所醫師

## 運作流程

1. 建立轉診需求
2. 準備轉診摘要
3. 聯繫接收院所
4. 追蹤患者就醫
5. 收錄回覆報告
6. 安排後續照護

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
