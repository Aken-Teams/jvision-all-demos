**產業別：**房地產與物業　|　**系統類型：**finance-case

## 功能模組

- **代墊案件** — 記錄支出與代墊對象。
- **責任依據** — 連結條款及簽認。
- **驗收證據** — 保存工項與完成結果。
- **追償開單** — 產生租戶應付明細。
- **拒付處理** — 管理疑義與補充證據。
- **收款核銷** — 配對入帳及剩餘餘額。

## 適合誰使用

- 物業會計
- 案場主任
- 租戶服務

## 運作流程

1. 登錄代墊
2. 補齊歸責
3. 確認驗收
4. 產生帳單
5. 處理拒付
6. 完成核銷

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
