# 案件時間線重建器

> 從郵件、文件與事件重建可引用的案件時間線，縮短法律事實整理。

從郵件、文件與事件重建可引用的案件時間線，縮短法律事實整理。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **案件範圍設定** — 界定爭點、當事人、日期區間與待證事實。
- **事件抽取桌** — 從郵件、文件及系統紀錄辨識日期、行動與參與者。
- **事件關聯圖** — 串連人物、文件、義務與前後因果關係。
- **衝突與缺口檢查** — 標示時間矛盾、版本差異及缺少佐證的區段。
- **可引用時間線** — 依爭點編排事件並附上原文定位與引用來源。
- **案件敘事產生器** — 把核實事件轉成法律摘要、陳述稿與附件索引。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 界定案件問題
2. 辨識關鍵事件
3. 建立事件關聯
4. 查核矛盾缺口
5. 審定引用時間線
6. 輸出案件敘事

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
