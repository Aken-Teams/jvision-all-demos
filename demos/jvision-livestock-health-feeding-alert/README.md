# 畜牧健康與疫病預警平台

> 彙整模擬畜群健康、採食飲水、舍區事件與防疫紀錄，辨識個體或群體異常趨勢，提供分級告警、病例研判、隔離處置及追蹤工作台，協助牧場提早發現風險並建立完整防疫處理軌跡。

彙整模擬畜群健康、採食飲水、舍區事件與防疫紀錄，辨識個體或群體異常趨勢，提供分級告警、病例研判、隔離處置及追蹤工作台，協助牧場提早發現風險並建立完整防疫處理軌跡。

**產業別：**醫療照護　|　**系統類型：**operations-console

## 功能模組

- **畜群總覽** — 呈現各舍區健康分數、異常數量與待處置告警。
- **採食分析** — 比較畜群採食飲水趨勢、基準區間與異常時段。
- **健康檔案** — 查看個體或批次的症狀、體況、用藥及免疫紀錄。
- **疫病預警** — 以風險層級整理疑似群聚、傳播範圍與關聯線索。
- **處置工作台** — 建立巡檢、採樣、隔離、診療與消毒任務。
- **恢復追蹤** — 追蹤處置後採食、症狀及群體健康指標變化。

## 適合誰使用

- 牧場場長
- 飼養管理員
- 駐場獸醫與防疫專員

## 運作流程

1. 檢視畜群風險
2. 分析採食變化
3. 調閱健康紀錄
4. 研判疫病風險
5. 指派防疫處置
6. 確認恢復狀態
