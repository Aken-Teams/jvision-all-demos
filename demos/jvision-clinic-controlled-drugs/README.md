# 診所管制藥品簿冊台

> 供診所管理管制藥品的驗收入庫、領用調劑、逐筆結存、盤點差異及報廢申報，以電子簿冊模擬降低人工抄錄錯誤與稽查風險。

供診所管理管制藥品的驗收入庫、領用調劑、逐筆結存、盤點差異及報廢申報，以電子簿冊模擬降低人工抄錄錯誤與稽查風險。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **批號庫存** — 管理批號效期與結存
- **驗收入庫** — 登錄來源憑證與數量
- **領用調劑** — 連結處方及使用紀錄
- **電子簿冊** — 呈現逐筆收支結存
- **盤點差異** — 比對實物與帳面數量
- **報廢申報** — 整理原因見證與文件

## 適合誰使用

- 藥師
- 護理長
- 診所負責醫師

## 運作流程

1. 驗收管制藥品
2. 建立批號結存
3. 記錄處方領用
4. 覆核收支簿冊
5. 執行定期盤點
6. 處理報廢申報

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
