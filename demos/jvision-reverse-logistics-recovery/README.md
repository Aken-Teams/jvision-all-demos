# 逆物流回收處理台

> 協調門店、客戶端與物流商的退貨取件、回收路線、到倉點收及後續處置，提升回收成功率並縮短可再售商品回庫時間。

協調門店、客戶端與物流商的退貨取件、回收路線、到倉點收及後續處置，提升回收成功率並縮短可再售商品回庫時間。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **回收案件** — 建立退貨與回收需求
- **取件規劃** — 安排承運商及回收路線
- **任務追蹤** — 掌握取件與轉運節點
- **異常處理** — 處理失聯拒收與品項不符
- **到倉點收** — 核對數量外觀及附件
- **處置決策** — 決定回庫整新報廢或退供

## 適合誰使用

- 逆物流調度員
- 退貨倉主管
- 客服專員

## 運作流程

1. 建立案件
2. 規劃取件
3. 執行回收
4. 排除異常
5. 完成點收
6. 決定處置

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
