# 減速機齒輪磨耗診斷系統

> 彙整擬真的減速機振動、油液顆粒、溫度與運轉時數資料，診斷齒面磨耗、點蝕及偏磨風險，協助維護人員比對齒輪特徵、評估剩餘壽命並安排換油或拆檢。

彙整擬真的減速機振動、油液顆粒、溫度與運轉時數資料，診斷齒面磨耗、點蝕及偏磨風險，協助維護人員比對齒輪特徵、評估剩餘壽命並安排換油或拆檢。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **減速機健康總覽** — 呈現健康分數、磨耗風險、負載狀態與設備排行。
- **齒輪特徵分析** — 顯示齒輪嚙合頻率、邊帶及擬真振動特徵的異常區段。
- **油液狀態分析** — 比較金屬顆粒、黏度與換油紀錄，觀察潤滑劣化趨勢。
- **磨耗型態診斷** — 呈現均勻磨耗、點蝕、偏磨等模擬診斷結果與依據。
- **壽命風險評估** — 依磨耗與負載趨勢估算剩餘壽命及建議處置期限。
- **保養處置規劃** — 建立換油、校正、內視檢查或拆解檢修的工作計畫。

## 適合誰使用

- 設備工程師
- 潤滑管理員
- 維修主管

## 運作流程

1. 盤點設備健康
2. 分析齒輪特徵
3. 檢查油液狀態
4. 確認磨耗型態
5. 評估剩餘壽命
6. 安排保養處置

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
