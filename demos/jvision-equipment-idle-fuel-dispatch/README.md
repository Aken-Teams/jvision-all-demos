# 工程機具節能調度台

> 以擬真工時、任務、油耗與保養資料呈現工程機具的使用效率，找出長時間待機、空跑與不當配置，並模擬跨工區調度方案，降低租賃支出及燃料浪費。

以擬真工時、任務、油耗與保養資料呈現工程機具的使用效率，找出長時間待機、空跑與不當配置，並模擬跨工區調度方案，降低租賃支出及燃料浪費。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **機具營運總覽** — 彙整各工區稼動、閒置、油耗及保養狀態。
- **閒置時段分析** — 以時間軸辨識待機、空跑與排程空檔。
- **燃料效率診斷** — 比較同型機具油耗並標示高耗用情境。
- **工區需求配置** — 整理任務所需機型、能力、時段與優先級。
- **調度方案模擬** — 比較移機、續租與共用方案的成本及衝突。
- **班次派工發布** — 形成每日機具配置、駕駛任務與交接清單。

## 適合誰使用

- 機具調度員
- 工地主任
- 設備主管
- 成本管理人員

## 運作流程

1. 檢視營運
2. 找出閒置
3. 分析油耗
4. 彙整需求
5. 比較調度
6. 發布派工

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
