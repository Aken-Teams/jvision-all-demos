# COQ（Cost of Quality，品質成本管理）

> 從異常到改善的品質閉環與追溯稽核

COQ（Cost of Quality，品質成本管理）提供品質成本分類建置、跨部門成本數據彙整、成本趨勢分析。財務部依「成本數據蒐集→分類歸屬→彙整分析→報表產出→管理審查」推進作業，優先解決「品質成本數據分散各系統」，品保部則以品質成本占營收比例與內外部失敗成本比確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 財務部
- 品保部
- 高階主管

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉

## 導入效益

- 批號追溯時間：176分鐘 → **16分鐘**
- 客訴平均關案：21天 → **9.5天**
- 改善驗證率：65% → **92%**
- 重複不良率：6.2% → **1.9%**
