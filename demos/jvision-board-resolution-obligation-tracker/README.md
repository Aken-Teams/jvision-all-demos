# 董事會決議義務追蹤器

> 把董事會決議轉成責任、期限及佐證要求，持續追蹤直到決策落地。

把董事會決議轉成責任、期限及佐證要求，持續追蹤直到決策落地。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **決議文件解析** — 解析議事錄、決議案號、表決結果與附帶條件。
- **決議行動拆解** — 將複合決議拆成具體行動、里程碑與完成標準。
- **責任歸屬確認** — 對應主責高階主管、執行單位與跨部門協作者。
- **期限依賴排程** — 管理承諾日期、前後依賴、定期回報與展延申請。
- **決議佐證包** — 彙整核准文件、執行成果與董事會要求的完成證明。
- **落實狀態核驗** — 檢查未完成責任、逾期風險並提交治理層核准結案。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 匯入董事會決議
2. 確認執行事項
3. 指派決議責任
4. 核定執行時程
5. 提交完成佐證
6. 核驗決議落地

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
