# 貨損理賠案件管理台

> 供第三方物流與承運商集中處理破損、短少、污染及遺失案件，串接模擬託運資料、責任判定、證據補件、賠付試算與求償進度，縮短跨公司往返並控制理賠損失。

供第三方物流與承運商集中處理破損、短少、污染及遺失案件，串接模擬託運資料、責任判定、證據補件、賠付試算與求償進度，縮短跨公司往返並控制理賠損失。

**產業別：**物流運輸　|　**系統類型：**finance-case

## 功能模組

- **案件受理** — 建立貨損類型與託運基本資料。
- **證據補件** — 整理簽收、包裝、照片與往來文件。
- **責任判定** — 依交接節點與條款分配責任。
- **賠付試算** — 計算貨值、折舊、上限與自負額。
- **核賠作業** — 管理審批、和解與付款狀態。
- **代位求償** — 追蹤向分包商或保險方追回款項。

## 適合誰使用

- 理賠專員
- 站所主管
- 客服人員

## 運作流程

1. 受理案件
2. 蒐集證據
3. 判定責任
4. 試算賠付
5. 完成核賠
6. 辦理求償

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
