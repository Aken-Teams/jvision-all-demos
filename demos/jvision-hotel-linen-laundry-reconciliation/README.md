# 旅宿布巾送洗對帳台

> 逐批連結客房布巾交洗、洗衣廠收件、回洗、重洗、污損與計價重量，找出短少及不合理費用，讓飯店在月結前完成數量與帳單覆核。

逐批連結客房布巾交洗、洗衣廠收件、回洗、重洗、污損與計價重量，找出短少及不合理費用，讓飯店在月結前完成數量與帳單覆核。

**產業別：**餐飲旅宿　|　**系統類型：**warehouse-wms

## 功能模組

- **交洗批次** — 登錄品項數量
- **磅單核對** — 比較重量件數
- **回洗點收** — 連結返還批次
- **重洗污損** — 記錄責任原因
- **短少調查** — 追查批次落差
- **月結帳單** — 覆核洗滌請款

## 適合誰使用

- 房務庫管
- 洗滌廠窗口
- 成本會計

## 運作流程

1. 建立交洗
2. 廠商簽收
3. 回洗點收
4. 處理重洗
5. 調查短少
6. 核准月結

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
