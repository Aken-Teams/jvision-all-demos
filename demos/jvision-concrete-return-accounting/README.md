# 混凝土退料異常台

> 逐車記錄混凝土退料方數、時間、原因、責任歸屬與處置方式，串接原叫料批次及澆置區域，供工務與成本人員核對預拌廠月結，辨識過量叫料、塞車或品質退料。

逐車記錄混凝土退料方數、時間、原因、責任歸屬與處置方式，串接原叫料批次及澆置區域，供工務與成本人員核對預拌廠月結，辨識過量叫料、塞車或品質退料。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **退料看板** — 呈現各澆置批次的退料量、原因與待處理事件。
- **事件登錄** — 記錄車號、配比、退料方數、時間與現場說明。
- **叫料追溯** — 對應原叫料單、澆置區與實際收料紀錄。
- **原因認定** — 分類品質、過量、塞車、停工等退料原因。
- **責任判定** — 確認工地、分包或預拌廠的責任與費用負擔。
- **月結核對** — 彙整可計費、應扣款及仍有爭議的退料明細。

## 適合誰使用

- 混凝土工程師
- 工地主任
- 成本會計

## 運作流程

1. 查看異常
2. 登錄退料
3. 核對叫料
4. 確認原因
5. 認定責任
6. 辦理結算

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
