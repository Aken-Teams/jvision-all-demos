# 實驗互相干擾偵測器

> 找出受眾同時進入的衝突實驗，避免污染結果並維持決策可信度。​

找出受眾同時進入的衝突實驗，避免污染結果並維持決策可信度。​

**產業別：**業務銷售　|　**系統類型：**analytics-bi

## 功能模組

- **實驗版圖** — 呈現進行中實驗的受眾、渠道、指標與時程。
- **受眾重疊掃描** — 計算實驗間同一使用者或客群的重疊程度。
- **干擾衝突偵測** — 辨識處置、訊息、渠道或指標互相影響的組合。
- **因果污染圖** — 顯示實驗曝光如何交叉影響結果與歸因。
- **可信度模擬** — 模擬排除、延期或重分流後的統計可信度。
- **實驗協調排程** — 產生調整優先序並同步核准後的實驗安排。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 盤點進行中實驗
2. 檢查受眾重疊
3. 判定干擾類型
4. 追查因果路徑
5. 比較修正方案
6. 核准協調排程
