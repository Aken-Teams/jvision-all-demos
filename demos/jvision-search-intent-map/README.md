**產業別：**業務銷售　|　**系統類型：**analytics-bi

## 功能模組

- **搜尋主題全景** — 彙整關鍵字、搜尋量與排名，形成可探索的主題版圖。
- **意圖聚類樹** — 依問題、比較、採購與支援意圖建立語意群集。
- **漏斗對齊矩陣** — 把意圖群映射至認知、考慮、決策與留存階段。
- **內容缺口清單** — 找出高需求但缺少頁面、素材或答案覆蓋的主題。
- **意圖判讀審核** — 檢視分類信心、代表字詞與來源證據並修正標籤。
- **內容行動佇列** — 將優先缺口轉成內容任務並追蹤負責人與進度。

## 適合誰使用

- 行銷主管
- 內容團隊

## 運作流程

1. 盤點搜尋版圖
2. 檢視意圖群集
3. 映射內容漏斗
4. 辨識內容缺口
5. 審核模型判讀
6. 派發內容任務
