# 物流棧板循環對帳台

> 管理物流商與貨主、承運商及收貨點之間的棧板借出、交換、欠板與折價賠償，依運次還原流向並產生對帳差異，降低載具流失及月底人工追帳成本。

管理物流商與貨主、承運商及收貨點之間的棧板借出、交換、欠板與折價賠償，依運次還原流向並產生對帳差異，降低載具流失及月底人工追帳成本。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **載具總覽** — 掌握棧板分布、欠板及異常。
- **運次交付** — 登錄各運次的帶出與交換數量。
- **回收交換** — 記錄返還、跨點交換及轉移。
- **欠板追蹤** — 依持有人與帳齡管理催回任務。
- **夥伴對帳** — 比對雙方明細並處理爭議。
- **賠償結算** — 計算遺失、破損及折價費用。

## 適合誰使用

- 物流調度員
- 載具管理員
- 結算人員

## 運作流程

1. 檢視分布
2. 登錄交付
3. 確認回收
4. 催收欠板
5. 核對明細
6. 完成結算

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
