**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **判讀佇列** — 依產品、缺陷風險及等待時間排列待判案件。
- **多源檢視** — 並列外觀影像、剖面示意、量測值與檢驗文字。
- **特徵標註** — 框選缺陷區域並記錄尺寸、位置與形貌特徵。
- **案例比對** — 展示相似缺陷案例、分類結果與差異摘要。
- **分類決策** — 選擇缺陷類別、風險等級並填寫判讀依據。
- **處置派送** — 將案件送往複核、製程改善或失效分析流程。

## 適合誰使用

- 品質工程師
- 封裝製程工程師
- 實驗室分析員

## 運作流程

1. 領取案件
2. 彙看證據
3. 標註特徵
4. 比對案例
5. 確認分類
6. 派送處置

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
