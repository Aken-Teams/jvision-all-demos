# 建築樣品核定封樣台

> 串聯裝修與外牆材料的送樣、設計比選、監造審查、業主核定及實體封樣，並把核定樣品連結至採購批次與現場查驗，避免顏色、紋理或收邊規格因版次混淆而誤用。

串聯裝修與外牆材料的送樣、設計比選、監造審查、業主核定及實體封樣，並把核定樣品連結至採購批次與現場查驗，避免顏色、紋理或收邊規格因版次混淆而誤用。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **送樣清單** — 管理材料品名、供應商、規格及送樣輪次。
- **並排比選** — 比較候選樣品的色澤、紋理、尺寸與價格。
- **設計批註** — 記錄設計修正要求與再次送樣條件。
- **業主核定** — 保存選定結果、限制條件及核定日期。
- **封樣編碼** — 產生實體封樣標籤與保管位置。
- **進料比對** — 將採購及到貨批次與核定封樣進行核對。

## 適合誰使用

- 設計師
- 監造工程師
- 採購工程師

## 運作流程

1. 提交樣品
2. 規格初審
3. 設計比選
4. 完成核定
5. 編碼封樣
6. 到貨查驗

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
