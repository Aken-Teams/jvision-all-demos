# 員工餐排班成本管制台

> 供連鎖餐飲依各店班表、預估出勤與供餐標準安排員工餐，追蹤備餐數、臨時加餐、剩食與分店成本，減少餐點浪費及月底人工彙整。

供連鎖餐飲依各店班表、預估出勤與供餐標準安排員工餐，追蹤備餐數、臨時加餐、剩食與分店成本，減少餐點浪費及月底人工彙整。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **供餐日曆** — 依分店與班別查看每日預估供餐人數。
- **人數確認** — 彙整排班、支援與請假造成的人數異動。
- **備餐派工** — 建立菜單、份數與廚務負責人安排。
- **實績登記** — 記錄實際供餐、加餐、取消及剩食數量。
- **差異處理** — 檢視超量與短缺事件並標記原因。
- **成本分析** — 比較分店、班別及菜單的單人成本。

## 適合誰使用

- 區域營運主管
- 店長
- 廚務主管

## 運作流程

1. 查看供餐需求
2. 確認人數異動
3. 安排員工餐
4. 回報供餐實績
5. 處理供餐差異
6. 檢討分店成本

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
