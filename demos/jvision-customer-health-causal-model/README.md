# 客戶健康因果模型

> 融合使用、服務、關係與商務訊號，解釋客戶健康變化並及早介入。觸發後建立案件

融合使用、服務、關係與商務訊號，解釋客戶健康變化並及早介入。觸發後建立案件

**產業別：**客服管理　|　**系統類型：**sales-crm

## 功能模組

- **客戶健康脈搏** — 呈現帳戶健康分數、變化速度與高風險客戶排行。
- **健康因果圖譜** — 連結使用、服務、關係及商務訊號與健康結果。
- **變化貢獻分解** — 量化各訊號對近期健康升降的正負貢獻。
- **根因證據檢視** — 下鑽事件、工單、互動與合約資料以驗證可能根因。
- **介入效果推演** — 預估培訓、服務升級或高層溝通對健康的改善幅度。
- **健康介入中心** — 建立風險案件並協調 CSM、客服與商務團隊追蹤。

## 適合誰使用

- 客戶成功主管
- CSM
- 客服主管

## 運作流程

1. 辨識健康異動
2. 探索因果關係
3. 分解變化來源
4. 驗證根因證據
5. 推演介入方案
6. 啟動客戶介入

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
