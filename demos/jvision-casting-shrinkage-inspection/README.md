# 鑄件縮孔智慧檢測系統

> 彙整鑄件影像、批次與缺陷標註，以智慧判讀呈現縮孔位置、尺寸及風險等級，協助品管人員完成複判、批次追溯、異常處置與品質趨勢分析，降低漏檢及報廢成本。

彙整鑄件影像、批次與缺陷標註，以智慧判讀呈現縮孔位置、尺寸及風險等級，協助品管人員完成複判、批次追溯、異常處置與品質趨勢分析，降低漏檢及報廢成本。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **品質監控總覽** — 查看今日檢測量、缺陷分布、高風險批次與待處理警示。
- **縮孔影像判讀** — 對照原始影像與缺陷熱區，檢視尺寸、位置及信心分數。
- **人工複判工作台** — 逐件確認判讀結果，填寫缺陷等級、處置意見與複判原因。
- **批次追溯中心** — 依爐次、材質、模具及工單追查檢測紀錄與缺陷明細。
- **異常處置管理** — 建立隔離、重工、報廢及原因調查任務，追蹤負責人與期限。
- **品質趨勢分析** — 比較期間、產線與模具的縮孔率，呈現改善前後成效。

## 適合誰使用

- 鑄造品管工程師
- 製程工程師
- 品保主管

## 運作流程

1. 掌握品質風險
2. 檢視縮孔判讀
3. 完成結果複判
4. 追查生產批次
5. 執行異常處置
6. 檢討改善成效

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
