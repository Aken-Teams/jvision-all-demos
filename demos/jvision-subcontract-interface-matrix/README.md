# 施工界面責任釐清台

> 把契約未明確描述的孔洞、基座、收邊、修補、臨設及材料交界拆成界面事項，記錄各分包的供料、施工、保護與驗收責任，並保存協調結論及追加依據。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **界面矩陣** — 依工種交界列出供料與施工事項。
- **契約依據** — 關聯標單、規範及責任條款。
- **責任協調** — 收集各分包主張與會議結論。
- **責任判定** — 指定主責、配合及費用歸屬。
- **決議發布** — 通知相關班組及生效日期。
- **履行情形** — 追蹤完成、異議及追加申請。

## 適合誰使用

- 工務經理
- 合約工程師
- 分包專案經理

## 運作流程

1. 盤點界面事項
2. 查找契約依據
3. 收集分包主張
4. 召開責任協調
5. 發布界面決議
6. 追蹤責任履行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
