# LLM 事實核對流水線

拆解模型關鍵主張並查證企業與外部來源，降低錯誤資訊。天啊你說得對

**產業別：**資訊科技　|　**系統類型：**operations-console

## 功能模組

- **關鍵主張拆分** — 從回答中抽取可查證事實、數字、事件與關係主張。
- **查證優先排序** — 依影響、可疑度、時效性與傳播風險排序主張。
- **企業來源查證** — 比對資料湖、BI 與知識庫中的權威企業紀錄。
- **外部來源查證** — 針對需外部確認的主張搜尋並交叉比對可信來源。
- **事實裁決台** — 將主張判定為支持、反駁、資訊不足或已過時。
- **更正回寫佇列** — 產生答案修正建議並在核准後同步至模型應用。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 接收高風險回答
2. 拆解並排序主張
3. 查核企業紀錄
4. 交叉查核外部來源
5. 裁定事實狀態
6. 核准更正回寫

- 事件平均處理：120分鐘 → **30分鐘**
- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
