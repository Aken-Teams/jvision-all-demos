# 工區移交條件查核台

> 以工作面為單位定義前後工種的移交條件，查核尺寸、清潔、積水、臨設、材料及前項缺失，並由交出與接收班組共同簽認，避免接手後才發現無法施工。

以工作面為單位定義前後工種的移交條件，查核尺寸、清潔、積水、臨設、材料及前項缺失，並由交出與接收班組共同簽認，避免接手後才發現無法施工。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **工區清單** — 依樓層、區域與工序管理工作面。
- **移交條件** — 設定各工種必須完成的交付標準。
- **交方自檢** — 由前序班組提交完成狀態與照片。
- **接方查核** — 讓後序班組現勘並記錄異議。
- **缺失改善** — 追蹤未收尾、偏差及清理工作。
- **雙方簽認** — 鎖定移交時間與責任分界。

## 適合誰使用

- 工務工程師
- 前序分包領班
- 後序分包領班

## 運作流程

1. 建立移交工區
2. 確認交付條件
3. 完成交方自檢
4. 執行接方現勘
5. 改善未通過項
6. 雙方完成簽認

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
