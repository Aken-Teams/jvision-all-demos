# 價值流程圖工具（Value Stream Mapping, VSM）

> 應收付、現金流到預算的財務即時掌握

價值流程圖工具（Value Stream Mapping, VSM）提供現況價值流程繪製、未來狀態流程設計、浪費環節標註分析。工業工程依「現況流程調查 → VSM繪製 → 浪費點辨識 → 未來狀態設計 → 改善計畫執行追蹤」推進作業，優先解決「流程浪費環節不易被系統性辨識」，製造工程則以流程週期時間縮短率與增值比率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生產製造　|　**系統類型：**財務會計系統

## 功能模組

- **應收帳款** — 開立、對帳與催收
- **應付帳款** — 請款、付款與對帳
- **現金流** — 資金調度與預測
- **預算管理** — 編列、控管與差異分析
- **固定資產** — 資產登錄與折舊
- **總帳傳票** — 傳票、拋轉與月結

## 適合誰使用

- 工業工程
- 製造工程
- 持續改善部門

## 運作流程

1. 待排程
2. 生產中
3. 待品檢
4. 已入庫

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：77% → **93%**
- 缺料停線次數：13次/月 → **2.8次/月**
- 設備稼動率：75% → **92%**
