# 混凝土試體齡期管制台

> 將澆置區域、試體組別、養護方式與七天、二十八天送壓日期集中管理，遇假日自動標示調整日，並追蹤送驗、報告回收、強度判定及異常複驗，避免漏送與報告對錯樓層。

將澆置區域、試體組別、養護方式與七天、二十八天送壓日期集中管理，遇假日自動標示調整日，並追蹤送驗、報告回收、強度判定及異常複驗，避免漏送與報告對錯樓層。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **齡期總覽** — 依日期呈現待送壓、送驗中與逾期試體。
- **試體建檔** — 綁定澆置區域、車次、配比與試體編號。
- **送壓日曆** — 計算各齡期日期並標示假日調整。
- **送驗交接** — 記錄取件、交付、收件與試體狀況。
- **報告判讀** — 登錄強度結果並比對設計要求。
- **異常處置** — 追蹤複驗、影響區域與施工限制。

## 適合誰使用

- 品管工程師
- 工地主任
- 試驗室窗口

## 運作流程

1. 查看到期批次
2. 建立試體資料
3. 確認送壓日期
4. 辦理送驗交接
5. 登錄判讀報告
6. 追蹤異常處置

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
