**產業別：**業務銷售　|　**系統類型：**sales-crm

## 功能模組

- **銷售工作總覽** — 集中顯示待辦、重點客戶、業績與近期活動。
- **企業客戶管理** — 瀏覽客戶公司資料、分級、產業與往來概況。
- **聯絡人管理** — 管理關鍵聯絡人、職務、偏好及互動關係。
- **商機流程管理** — 以銷售階段看板追蹤金額、機率與預計結案日。
- **互動活動紀錄** — 記錄電話、會議、郵件與下一步跟進安排。
- **業績預測分析** — 檢視銷售漏斗、團隊達成率與營收預測。

## 適合誰使用

- 業務代表
- 業務主管
- 行銷人員與客戶成功經理

## 運作流程

1. 檢視業務總覽
2. 建立企業客戶
3. 維護關鍵聯絡人
4. 推進銷售商機
5. 登錄互動活動
6. 提交業績預測

- 商機轉換率：18% → **27%**
