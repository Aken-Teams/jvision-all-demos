# 代課師資媒合排班台

> 供學校或教育機構登錄教師請假、課務需求與合格師資名冊，依科目資格及可用時段媒合代課人員，完成邀請、課程交接、出勤確認與鐘點費核算。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **缺課需求** — 登錄請假節次與科目需求
- **師資名冊** — 管理資格、專長及可用時段
- **媒合排序** — 依資格與衝堂情況推薦人選
- **代課邀請** — 追蹤邀請、回覆與備選順位
- **課程交接** — 交付進度、教材及班級提醒
- **出勤核薪** — 確認節次並核算鐘點費

## 適合誰使用

- 教務組長
- 課務人員
- 代課教師

## 運作流程

1. 登錄缺課
2. 篩選師資
3. 發送邀請
4. 完成交接
5. 確認出勤
6. 核算鐘點

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
