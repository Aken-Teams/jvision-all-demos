# 工程案號同步稽核台

> 比對投標、合約、採購、工時與財務系統中的工程案號、名稱、階段及關閉狀態，攔截掛錯案交易並管理跨系統同步修復。

比對投標、合約、採購、工時與財務系統中的工程案號、名稱、階段及關閉狀態，攔截掛錯案交易並管理跨系統同步修復。

**產業別：**營建工程　|　**系統類型：**erp

## 功能模組

- **專案主檔** — 查看各系統案號狀態
- **同步比對** — 辨識名稱階段和狀態差異
- **錯掛交易** — 列出採購工時費用異常
- **修正判定** — 選定權威值與處理方式
- **同步補送** — 追蹤各系統修復結果
- **稽核報表** — 統計錯誤來源與影響

## 適合誰使用

- 專案財務
- 系統管理員
- 主檔管理員

## 運作流程

1. 擷取主檔
2. 產生差異
3. 確認權威值
4. 評估交易
5. 執行修復
6. 稽核關閉

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
