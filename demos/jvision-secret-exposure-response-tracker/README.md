**產業別：**資訊科技　|　**系統類型：**security-soc

## 功能模組

- **外洩警報台** — 辨識提交、建置產物與日誌中的金鑰暴露並判定嚴重度。
- **秘密傳播時間線** — 重建金鑰從首次提交到複製、部署與使用的完整路徑。
- **曝險範圍圖** — 標出受影響儲存庫、管線、叢集、服務與雲端資源。
- **濫用跡象獵捕** — 搜尋異常 API 呼叫、登入與資源操作，判斷是否已遭利用。
- **金鑰輪替編排** — 依相依順序協調撤銷、重發、部署與服務驗證。
- **修復回復指揮** — 監控 Agent 交接與逾時，在輪替失敗時回復至安全狀態。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 確認外洩警報
2. 重建傳播路徑
3. 界定曝險範圍
4. 獵捕濫用行為
5. 執行撤銷輪替
6. 確認安全回復
