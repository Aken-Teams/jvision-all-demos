**產業別：**生產製造　|　**系統類型：**esg-energy

## 功能模組

- **訂單需求建模** — 設定數量、規格、交期、目的地與報價幣別。
- **材料碳情境** — 比較不同材料、供應商與再生料比例的碳排影響。
- **產線碳情境** — 模擬各廠區、產線、班次與能源結構的製造排放。
- **物流碳情境** — 估算運輸模式、距離與裝載率造成的碳排及成本。
- **碳成本最佳化** — 在毛利、交期、產能與排放間產生帕累托方案。
- **接單報價決策** — 呈現碳成本區間、風險與建議報價條件。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 建立訂單情境
2. 比較材料選項
3. 配置生產路徑
4. 模擬物流方案
5. 最佳化碳成本
6. 核定接單報價

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
