# 馬達軸承異常聲紋診斷系統

> 以預先建立的馬達聲音樣本、聲紋頻譜及模擬診斷結果，辨識軸承磨損、潤滑不足與鬆動等異常，協助維護人員複核聲紋、比較歷史變化並建立檢修任務。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **聲紋監控總覽** — 顯示馬達異常數、診斷類型分布與高風險設備排行。
- **聲音樣本檢視** — 播放預置音訊並同步呈現波形、轉速及採樣情境資訊。
- **頻譜特徵分析** — 展示頻率能量、特徵峰值與正常聲紋的差異區段。
- **異常類型診斷** — 呈現磨損、潤滑不足或鬆動的模擬機率與判讀依據。
- **歷史聲紋比較** — 比較同一馬達不同日期的頻譜變化與風險走勢。
- **檢修任務追蹤** — 建立複檢、潤滑或更換軸承任務並記錄處理結果。

## 適合誰使用

- 設備巡檢員
- 維護工程師
- 維修主管

## 運作流程

1. 發現異常馬達
2. 聽取聲音樣本
3. 檢查頻譜特徵
4. 確認診斷類型
5. 比較歷史變化
6. 派送檢修任務

- 非計畫停機：24小時/月 → **6小時/月**
