# 臨時加班餐次確認台

> 依核准加班名單彙整餐次、飲食需求、領取地點與臨時取消，在訂餐截止前鎖定版本並核對供應商帳單，降低多訂、漏餐及無法歸屬費用。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **餐次總覽** — 查看各時段需求與截止
- **名單確認** — 依核准加班選擇餐點
- **飲食需求** — 登錄素食過敏與備註
- **訂單封存** — 鎖定供應商下單版本
- **領取點交** — 記錄實領與未領餐點
- **帳單核對** — 比對訂購供餐與請款

## 適合誰使用

- 加班員工
- 部門主管
- 總務人員

## 運作流程

1. 建立餐次
2. 確認需求
3. 主管核名
4. 鎖定訂單
5. 完成發餐
6. 核對帳單

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
