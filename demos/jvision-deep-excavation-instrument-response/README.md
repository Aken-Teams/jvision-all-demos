# 深開挖監測應變管制台

> 整合傾度、沉陷與支撐軸力等人工填報數據，依警戒值分級呈現異常，管理複測、停工研判、應變措施、監造確認與解除列管，留下深開挖安全決策軌跡。

整合傾度、沉陷與支撐軸力等人工填報數據，依警戒值分級呈現異常，管理複測、停工研判、應變措施、監造確認與解除列管，留下深開挖安全決策軌跡。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **監測點配置** — 依開挖區與樓層管理監測點、儀器類型及警戒門檻。
- **數值登錄** — 輸入各期人工量測值並附上報告與現場照片。
- **警戒判讀** — 呈現超限、變化速率異常及待確認項目。
- **應變派工** — 建立複測、補強、降載或局部停工等處置任務。
- **技師審認** — 記錄專業判讀、監造意見及復工限制條件。
- **趨勢總覽** — 比較各監測點趨勢、事件時效與解除列管狀態。

## 適合誰使用

- 工地主任
- 監造工程師
- 大地技師

## 運作流程

1. 配置監測點
2. 回報量測值
3. 辨識警戒事件
4. 執行應變措施
5. 完成專業審認
6. 解除追蹤列管

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
