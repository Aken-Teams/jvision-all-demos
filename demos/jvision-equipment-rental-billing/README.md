# 機具租賃計費核對台

> 依機具進退場、啟停租、故障、待機與加班紀錄重建可計費期間，逐項核對出租商帳單及合約費率，讓工地在月底前完成爭議標記與費用確認。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **租賃清冊** — 查看各機具合約及現場狀態。
- **計費事件** — 記錄進退場、停租、故障與加班。
- **應付試算** — 依日租、月租及附加費率計算。
- **帳單匯入** — 登錄出租商請款期間與明細。
- **差異核對** — 找出天數、費率及附加費不符。
- **爭議結算** — 記錄協議金額並鎖定付款結果。

## 適合誰使用

- 機具管理員
- 工地會計
- 採購人員

## 運作流程

1. 建立租約
2. 每日紀錄
3. 期間結算
4. 匯入帳單
5. 差異協議
6. 核定付款

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
