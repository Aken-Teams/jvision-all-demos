# 分包估驗計價管理台

> 依分包契約項目管理當期申報數量、現場丈量、品質扣款、保留款與核定金額，讓工務、品管及成本人員完成一致的估驗流程。

依分包契約項目管理當期申報數量、現場丈量、品質扣款、保留款與核定金額，讓工務、品管及成本人員完成一致的估驗流程。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **契約清單** — 維護計價項目、單價及契約上限。
- **當期申報** — 由分包商填報完成數量與證據。
- **現場覆量** — 記錄丈量結果及可計價數量。
- **扣款計算** — 套用品質、代墊及保留款規則。
- **估驗簽核** — 逐層覆核當期與累計核定額。
- **計價結案** — 產出估驗明細及付款依據。

## 適合誰使用

- 工務工程師
- 成本工程師
- 分包商窗口

## 運作流程

1. 開啟估驗期間
2. 提交完成數量
3. 執行現場覆量
4. 核對品質扣款
5. 完成估驗簽核
6. 產出計價憑單

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
