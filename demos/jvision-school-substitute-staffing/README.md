# 校園代課媒合管理台

> 協助學校與教育機構管理教師請假產生的代課需求、資格條件、候選名單、課務衝突、到課確認及鐘點費資料，縮短臨時缺課處理時間。

協助學校與教育機構管理教師請假產生的代課需求、資格條件、候選名單、課務衝突、到課確認及鐘點費資料，縮短臨時缺課處理時間。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **缺課需求** — 彙整日期、班級及科目
- **師資名冊** — 維護資格與可授科目
- **候選媒合** — 依條件產生代課順位
- **課表檢核** — 檢查衝突與授課上限
- **到課確認** — 記錄接受及實際授課
- **鐘點彙整** — 產生核發與異常清單

## 適合誰使用

- 教務組員
- 年級主任
- 人事會計

## 運作流程

1. 建立缺課需求
2. 篩選合格師資
3. 確認媒合順位
4. 完成課表檢核
5. 記錄實際到課
6. 彙整鐘點資料

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
