# 員工制服領換結算台

> 管理員工制服尺寸、配發標準、領用換貨、跨店移轉及離職歸還，串起總務庫存與人資結清，避免重複領用、尺寸誤購和未經確認的薪資扣款。

管理員工制服尺寸、配發標準、領用換貨、跨店移轉及離職歸還，串起總務庫存與人資結清，避免重複領用、尺寸誤購和未經確認的薪資扣款。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **制服總覽** — 查看員工配額與持有量
- **尺寸建檔** — 維護尺寸試穿與偏好
- **領用簽收** — 配發品項並保存簽認
- **換貨調撥** — 處理尺寸更換與跨店
- **離職歸還** — 追蹤應還與實還品項
- **結算確認** — 處理遺失賠償及同意

## 適合誰使用

- 總務人員
- 店主管
- 人資人員

## 運作流程

1. 確認配額
2. 登錄尺寸
3. 配發簽收
4. 處理領換
5. 離職點交
6. 完成結算

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
