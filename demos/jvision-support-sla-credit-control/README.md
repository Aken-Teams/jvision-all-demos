# 客服服務抵用額核算台

> 供企業客服依服務合約、事故影響範圍與可用性紀錄試算服務抵用額，完成內部覆核、客戶通知及帳務交接，降低補償標準不一致的爭議。

供企業客服依服務合約、事故影響範圍與可用性紀錄試算服務抵用額，完成內部覆核、客戶通知及帳務交接，降低補償標準不一致的爭議。

**產業別：**客服管理　|　**系統類型：**service-desk

## 功能模組

- **事故總覽** — 查看事故期間與影響客群。
- **合約規則** — 維護門檻、級距及排除條款。
- **客戶圈選** — 確認受影響帳戶與服務方案。
- **抵用試算** — 產生各帳戶建議抵用金額。
- **覆核簽准** — 處理例外調整及核准紀錄。
- **通知入帳** — 發送說明並交接帳務處理。

## 適合誰使用

- 客服主管
- 客戶成功經理
- 帳務人員

## 運作流程

1. 確認事故
2. 讀取條款
3. 圈選客戶
4. 試算抵用
5. 核准例外
6. 通知入帳

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
