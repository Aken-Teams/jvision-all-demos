# AI經營決策助手指揮台

運用生成式AI彙整跨系統經營數據，提供高階主管自然語言問答與決策建議摘要。

- 原始系統：AI經營決策助手
- 產業分類：智慧製造｜經營管理
- 使用部門：總經理室、經營企劃部、財務部、各事業處主管
- 工作流程：問題提出 → 資料自動檢索 → AI分析彙整 → 決策建議產出 → 主管確認 → 決策執行追蹤
- AI 應用：生成式AI自然語言經營問答、異常財務/營運指標根因自動分析、決策情境模擬與建議生成
- 主要 KPI：決策回應時間縮短率、AI建議採納率、報表閱讀效率提升、異常偵測準確率
- 代表產品：Microsoft Copilot for Power BI、SAP Joule、Salesforce Einstein Copilot
