# 測量控制點交接台

> 集中管理基準點引測、複測成果、保護狀態與工班交接，讓放樣前能確認採用座標、高程及儀器紀錄，避免控制點遭破壞或引用錯誤造成整層偏位。

集中管理基準點引測、複測成果、保護狀態與工班交接，讓放樣前能確認採用座標、高程及儀器紀錄，避免控制點遭破壞或引用錯誤造成整層偏位。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **點位總覽** — 依棟別、樓層與狀態查看控制點分布。
- **引測建檔** — 登錄座標、高程、來源點及測量成果。
- **複測覆核** — 比較前後測值並判定是否超出容許差。
- **點位交接** — 記錄領用工班、用途與現場確認結果。
- **異常隔離** — 停用位移或受損點並圈選影響範圍。
- **成果履歷** — 追溯點位版本、簽認與歷次測量紀錄。

## 適合誰使用

- 測量工程師
- 工地主任
- 施工工程師

## 運作流程

1. 盤點點位
2. 建立成果
3. 執行複測
4. 申請領用
5. 現場交接
6. 封存追溯

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
