# 多銀行即時現金可視器

> 統一多銀行餘額、在途款與受限資金口徑，即時呈現真正可動用現金。

統一多銀行餘額、在途款與受限資金口徑，即時呈現真正可動用現金。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **多銀行帳戶總覽** — 以法人、銀行、幣別與帳戶整合各地即時帳面餘額。
- **幣別標準化** — 按指定匯率來源將多幣資金換算為集團報表幣別。
- **在途資金追蹤** — 追蹤收付款、清算、調撥與價值日造成的在途現金。
- **受限資金辨識** — 標示質押、監管、最低留存及用途受限的不可動用款項。
- **可用現金計算** — 依帳面、在途與限制條件計算各時點可自由動用資金。
- **流動性缺口預覽** — 結合應收應付與融資到期，預覽短期現金餘缺及調撥需求。

## 適合誰使用

- 財務長
- Treasurer
- 資金人員

## 運作流程

1. 彙整銀行頭寸
2. 統一幣別口徑
3. 核對在途款項
4. 排除受限資金
5. 確認可用現金
6. 安排資金調度

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
