# Jvision 活動會展與婚禮場地管理平台

可互動展示的活動籌備 Demo，整合詢價、檔期、報價合約、訂金付款、賓客桌次、籌備任務與 AI 活動摘要。

## 線上 Demo

https://jvision-event-wedding.vercel.app

## 專案海報

[![Jvision 活動會展與婚禮場地管理平台海報](docs/marketing/jvision-event-wedding-poster.png)](docs/marketing/jvision-event-wedding-poster.png)

## Demo 功能

- 新增活動詢價與報價資料
- 推進案件階段並同步更新提醒
- 產生活動報價與訂金建議
- 切換籌備任務狀態
- 檢視案件總覽、營收、人數與 AI 摘要

## 指令

```bash
npm install
npm run build
npm run assets
npm run verify
```
