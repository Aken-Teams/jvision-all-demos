# 門市盤盈虧核准台

> 將門市盤點差異依商品、原因、金額及歷史頻率分級，要求照片與盤點底稿，落實保管人、調整人及核准人分離，攔截反覆短少與異常調帳。

將門市盤點差異依商品、原因、金額及歷史頻率分級，要求照片與盤點底稿，落實保管人、調整人及核准人分離，攔截反覆短少與異常調帳。

**產業別：**零售電商　|　**系統類型：**finance-case

## 功能模組

- **盤差佇列** — 彙整盈虧項目
- **佐證補件** — 附上底稿照片
- **歷史模式** — 查看反覆差異
- **風險分級** — 依金額頻率排序
- **分層核准** — 執行職務分離
- **調帳發布** — 更新核准庫存

## 適合誰使用

- 門市店長
- 存貨會計
- 零售稽核員

## 運作流程

1. 匯入盤差
2. 補充原因
3. 分析歷史
4. 決定重盤
5. 核准調整
6. 發布調帳

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
