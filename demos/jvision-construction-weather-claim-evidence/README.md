# 工期天候展延證據台

> 協助承包商逐日整理降雨、停工通知、受影響工項、人機待命及現場佐證，建立天候事件與要徑工期的關聯，供專案團隊編製展延申請及回覆業主審查。

協助承包商逐日整理降雨、停工通知、受影響工項、人機待命及現場佐證，建立天候事件與要徑工期的關聯，供專案團隊編製展延申請及回覆業主審查。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **事件總覽** — 呈現天候事件、缺件與展延狀態。
- **天候紀錄** — 建立降雨、警報及停工時段。
- **工項影響** — 連結事件、施工要徑與替代工作。
- **證據彙整** — 整理日報、照片、通知及人機紀錄。
- **天數試算** — 依合約規則推算可申請展延日數。
- **送審資料** — 組裝申請文件並追蹤審查意見。

## 適合誰使用

- 工地主任
- 工務人員
- 合約工程師

## 運作流程

1. 檢視事件
2. 登錄天候
3. 判定影響
4. 補齊證據
5. 試算天數
6. 提出申請

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
