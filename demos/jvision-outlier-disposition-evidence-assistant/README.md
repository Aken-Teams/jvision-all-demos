**產業別：**研發管理　|　**系統類型：**quality-qms

## 功能模組

- **異常值案件辨識** — 依預設規則標出極端值、漂移、批次偏移與儀器異常訊號。
- **異常原因調查** — 串聯樣品、儀器、試劑、操作紀錄與方法偏差尋找可能原因。
- **替代分析比較** — 並列保留、排除、轉換與穩健統計方法對結論的影響。
- **處置理由草擬** — 根據調查事實生成可編修的科學判斷與方法依據。
- **異常值處置審議** — 由研究與品質角色審查證據、分析敏感度及處置選項。
- **核准結果固化** — 鎖定最終決定、報告呈現方式與後續矯正要求。

## 適合誰使用

- 實驗室主管
- 研究員
- 技術員

## 運作流程

1. 建立異常值案件
2. 調查可能原因
3. 執行替代分析
4. 撰寫處置理由
5. 審議科學依據
6. 核准並固化結果
