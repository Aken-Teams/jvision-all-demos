**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **訪視清單** — 彙整預定個案
- **備料建議** — 依計畫產生清單
- **庫存替代** — 處理缺料替換
- **出車交接** — 確認攜出物品
- **耗用登錄** — 記錄個案使用
- **退料結案** — 清點未用耗材

## 適合誰使用

- 居家護理師
- 護理站庫管
- 護理主管

## 運作流程

1. 排定訪視
2. 產生清單
3. 完成揀料
4. 出車交接
5. 登錄耗用
6. 退料覆核

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
