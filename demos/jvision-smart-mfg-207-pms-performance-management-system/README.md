# 績效考核管理系統（PMS, Performance Management System）

> 出勤、薪資、招募到績效的人資全流程

績效考核管理系統（PMS, Performance Management System）提供KPI/OKR目標設定與追蹤、主管/員工雙向考核表單、360度回饋評核。人資部依「目標設定 → 期中檢核 → 自評 → 主管評核 → 校準會議 → 結果發佈與獎酬連結」推進作業，優先解決「紙本考核表流程冗長」，各部門主管則以考核完成率與考核結果分佈合理度確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**HRIS 人力資源系統

## 功能模組

- **出勤差勤** — 打卡、請假與加班
- **薪資計算** — 薪資、勞健保與報稅
- **排班管理** — 智慧排班與工時控管
- **招募任用** — 職缺、面試與報到
- **教育訓練** — 課程、證照與紀錄
- **績效考核** — 目標設定與考核流程

## 適合誰使用

- 人資部
- 各部門主管
- 高階經營層

## 運作流程

1. 待處理
2. 主管確認
3. 人資執行
4. 歸檔完成

## 導入效益

- 薪資作業工時：40小時/月 → **8.2小時/月**
- 出勤異常處理：29分鐘 → **4.9分鐘**
- 招募到位天數：48天 → **26天**
- 表單簽核時效：3.1天 → **1天**
