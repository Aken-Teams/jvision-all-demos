# 績效考核管理追蹤台

辦公室與幹部人員的目標設定、期中檢核、年度考核與評等管理，支援KPI/OKR多元制度。

- 原始系統：績效考核管理系統（PMS, Performance Management System）
- 產業分類：智慧製造｜人資管理
- 使用部門：人資部、各部門主管、高階經營層
- 工作流程：目標設定 → 期中檢核 → 自評 → 主管評核 → 校準會議 → 結果發佈與獎酬連結
- AI 應用：考核評語一致性與偏誤偵測、高潛力人才自動標記
- 主要 KPI：考核完成率、考核結果分佈合理度、目標達成率、申訴案件數
- 代表產品：SAP SuccessFactors Performance、鼎新PMS、Lattice、104人資King績效模組
