# 員工宿舍管理系統（Dormitory Management）

> 入住申請、床位分配、住宿費代扣到退宿點交的宿舍全流程

員工宿舍管理系統（Dormitory Management）提供床位/房間分配與異動管理、住宿費用計算與代扣、宿舍門禁與訪客登記。人資部依「入住申請 → 床位分配 → 住宿費登記 → 門禁/訪客管理 → 違規/報修處理 → 退宿點交」推進作業，優先解決「大量入退宿床位調度混亂」，廠務行政則以床位使用率與住宿費對帳正確率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**HRIS 人力資源系統

## 功能模組

- **宿舍總覽** — 床位使用率與入住即時看板
- **床位分配** — 房間/床位分配與入退宿異動
- **住宿費代扣** — 住宿費計算與薪資代扣對帳
- **門禁訪客** — 門禁刷卡紀錄與訪客登記
- **報修違規** — 設施報修派工與違規登記處理
- **退宿點交** — 退宿申請、財物點交與稽核

## 適合誰使用

- 人資部
- 廠務行政
- 宿舍管理員

## 運作流程

1. 入住申請
2. 床位分配
3. 住宿費登記
4. 門禁與報修
5. 退宿點交

## 導入效益

- 薪資作業工時：42小時/月 → **7.8小時/月**
- 出勤異常處理：31分鐘 → **4.8分鐘**
- 招募到位天數：45天 → **26天**
- 表單簽核時效：2.9天 → **1.1天**
