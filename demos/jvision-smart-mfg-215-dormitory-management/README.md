# 員工宿舍管理追蹤台

管理工廠員工宿舍床位分配、住宿費用、門禁與生活公約，適用大量產線員工與外籍移工集中住宿場景。

- 原始系統：員工宿舍管理系統（Dormitory Management）
- 產業分類：智慧製造｜人資管理
- 使用部門：人資部、廠務行政、宿舍管理員、保全單位
- 工作流程：入住申請 → 床位分配 → 住宿費登記 → 門禁/訪客管理 → 違規/報修處理 → 退宿點交
- AI 應用：床位智慧分配最佳化、異常進出/群聚行為偵測預警
- 主要 KPI：床位使用率、住宿費對帳正確率、違規事件處理時效、消防演練完成率
- 代表產品：各人力仲介自建宿舍管理平台、鼎新宿舍模組、電子廠自建移工宿舍系統
