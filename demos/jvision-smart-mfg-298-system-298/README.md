# 稽核管理系統

> 從異常到改善的品質閉環與追溯稽核

稽核管理系統提供年度稽核計畫與風險導向排程、電子工作底稿與查核程序管理、缺失記錄與改善追蹤(CAPA)。稽核室依「風險評估排程 → 稽核計畫制定 → 現場查核 → 缺失開立 → 改善追蹤 → 董事會報告」推進作業，優先解決「紙本工作底稿版本管理困難」，董事會則以稽核計畫執行率與缺失改善及時率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**經營管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 稽核室
- 董事會
- 各受查部門主管

## 運作流程

1. 待釐清
2. 改善中
3. 核定確認
4. 已解除

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：2.9天 → **1天**
- 決策資料覆蓋：58% → **86%**
- 跨部門對齊：61% → **94%**
