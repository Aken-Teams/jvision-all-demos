# 沉默客戶風險雷達

> 主動辨識互動下降但未開案的客戶，及早找回無聲流失風險。​＂管理

主動辨識互動下降但未開案的客戶，及早找回無聲流失風險。​＂管理

**產業別：**客服管理　|　**系統類型：**sales-crm

## 功能模組

- **沉默訊號雷達** — 監測登入、功能使用、回覆與會議頻率的下降。
- **失聯角色偵測** — 找出關鍵聯絡人淡出及贊助者影響力變化。
- **續約曝險視窗** — 結合合約時點、使用衰退與互動中斷評估曝險。
- **風險演變時間線** — 重建客戶從正常互動走向沉默的關鍵事件。
- **挽回情境模擬** — 預估不同接觸時機與介入方式的挽回機率。
- **主動關懷編排** — 安排 CSM 任務、接觸對象、訊息與後續追蹤。

## 適合誰使用

- 客戶成功主管
- CSM
- 客服主管

## 運作流程

1. 檢視沉默警報
2. 確認失聯角色
3. 評估續約曝險
4. 還原風險歷程
5. 比較挽回策略
6. 核准主動關懷

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
