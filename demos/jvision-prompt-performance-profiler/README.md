## 功能模組

- **提示區段切片** — 將系統指令、範例、知識片段與問題分段標記。
- **Token 成本分解** — 計算各區段輸入、輸出及快取 Token 用量。
- **延遲瀑布分析** — 呈現檢索、組裝、推論與工具呼叫耗時。
- **區段消融實驗** — 移除或縮短指定片段並比較品質與速度。
- **指令貢獻評分** — 估計各段對正確性、格式與安全結果的影響。
- **上下文縮減方案** — 排序可刪除、摘要或快取的提示內容。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 切分提示
2. 盤點用量
3. 定位延遲
4. 執行消融
5. 評估貢獻
6. 套用縮減
