# 工地盤點差異簽核台

> 依材料與小型機具執行工地實盤，將帳面、調撥、退料及耗用差異分類為正常耗損、登錄錯誤或遺失，未經調查核准不得直接改帳。

**產業別：**營建工程　|　**系統類型：**warehouse-wms

## 功能模組

- **盤點批次** — 設定區域品項與截止
- **實盤輸入** — 記錄數量狀態與照片
- **差異清單** — 比較帳面和實際數量
- **原因調查** — 勾稽領退調撥與耗用
- **調整簽核** — 核准損耗或更正
- **盤差分析** — 追蹤高風險品項區域

## 適合誰使用

- 材料管理員
- 成本會計
- 工地主任

## 運作流程

1. 建立盤點
2. 現場實盤
3. 產生差異
4. 調查原因
5. 主管核准
6. 更新帳務

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
