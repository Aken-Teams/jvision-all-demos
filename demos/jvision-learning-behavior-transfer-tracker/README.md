# 學習後行為轉移追蹤器

> 比對訓練前後的真實工作行為，衡量技能是否成功轉移到職場。雬雬

比對訓練前後的真實工作行為，衡量技能是否成功轉移到職場。雬雬

**產業別：**人力資源　|　**系統類型：**education-lms

## 功能模組

- **轉移目標設定** — 把課程成果轉成可觀察、可比較的工作行為。
- **訓前行為基線** — 建立受訓前的任務頻率、品質與協作基準。
- **學習歷程剖面** — 呈現課程完成、練習表現與知識掌握程度。
- **在職行為觀測** — 從 Git、CRM、MES 等工作事件辨識行為改變。
- **轉移效果歸因** — 比較前後差異並排除職務、流程與季節因素。
- **強化介入方案** — 為未轉移技能安排主管回饋、任務或微學習。

## 適合誰使用

- L&D 主管
- 部門主管
- 員工

## 運作流程

1. 定義行為
2. 建立基線
3. 核對學習
4. 觀察工作
5. 判讀轉移
6. 安排強化

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
