# 餐飲品項代碼整併台

> 建立餐點、套餐、加料與外送平台品名的標準代碼，處理重複品號、稅別及套餐拆解版本，讓營收、耗料與成本資料可一致彙總。

建立餐點、套餐、加料與外送平台品名的標準代碼，處理重複品號、稅別及套餐拆解版本，讓營收、耗料與成本資料可一致彙總。

**產業別：**餐飲旅宿　|　**系統類型：**erp

## 功能模組

- **標準品項** — 維護餐點與銷售屬性。
- **重複偵測** — 找出疑似同品異碼。
- **通路對映** — 連結POS與外送品名。
- **套餐拆解** — 管理組成與生效版本。
- **稅別覆核** — 確認品項稅務與收入歸屬。
- **影響驗證** — 檢查營收與耗料彙總。

## 適合誰使用

- 商品管理員
- 財務分析
- 餐飲營運

## 運作流程

1. 彙入品項
2. 辨識重複
3. 裁定標準
4. 設定拆解
5. 覆核稅別
6. 驗證報表

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
