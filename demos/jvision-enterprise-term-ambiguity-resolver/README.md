## 功能模組

- **歧義詞搜尋** — 偵測查詢中的縮寫、同名詞與可能對應的多個企業概念。
- **部門語境判讀** — 依使用者部門、職務與業務流程調整候選詞義排序。
- **上下文線索比對** — 從文件段落、郵件主旨、工單與程式碼擷取消歧線索。
- **詞義關聯圖** — 呈現術語、系統、產品、團隊與同義詞之間的關聯。
- **候選詞義裁決** — 比較候選定義、支持來源、矛盾訊號與判定信心。
- **企業詞典修訂** — 將確認結果新增為部門限定詞義、別名或使用規則。

## 適合誰使用

- 知識工作者
- 主管
- 客服

## 運作流程

1. 輸入疑義詞
2. 套用部門語境
3. 擷取上下文
4. 探索關聯
5. 確認詞義
6. 發布定義

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
