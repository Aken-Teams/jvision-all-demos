# 重大客戶事件室

> 整合重大客戶事件的跨部門資訊與行動，確保對客說法一致。中文。

整合重大客戶事件的跨部門資訊與行動，確保對客說法一致。中文。

**產業別：**客服管理　|　**系統類型：**service-desk

## 功能模組

- **重大事件總覽** — 集中呈現客戶影響、事件等級、進度及當前責任人。
- **跨系統事件脈絡** — 串聯工單、產品異常、工程問題、商機及主管決策。
- **客戶承諾檢核** — 比對合約 SLA、服務承諾、補償條件與續約風險。
- **聯合作戰分工** — 協調客服、工程、業務與 CSM 的任務、依賴及期限。
- **對客訊息中心** — 產生具事實依據且跨團隊一致的客戶更新內容。
- **復原與結案** — 驗證服務復原、客戶確認、後續改善及結案條件。

## 適合誰使用

- 客戶成功主管
- CSM
- 客服主管

## 運作流程

1. 建立事件室
2. 重建完整脈絡
3. 確認承諾風險
4. 協調處置任務
5. 核准對客溝通
6. 驗證復原結案

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
