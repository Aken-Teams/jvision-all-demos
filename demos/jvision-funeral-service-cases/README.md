# 禮儀服務案件管理台

> 協助禮儀公司管理接案訪談、治喪流程、場地與人員安排、用品確認及家屬請款，降低多案件並行時的遺漏與溝通風險。

協助禮儀公司管理接案訪談、治喪流程、場地與人員安排、用品確認及家屬請款，降低多案件並行時的遺漏與溝通風險。

**產業別：**生活服務　|　**系統類型：**service-desk

## 功能模組

- **案件總覽** — 查看治喪階段與待辦
- **家屬需求** — 記錄偏好與聯絡窗口
- **流程排程** — 安排儀式及申辦事項
- **資源派工** — 配置人員場地與車輛
- **用品確認** — 核對品項數量與交付
- **費用收款** — 管理估價異動及收款

## 適合誰使用

- 禮儀師
- 行政人員
- 營運主管

## 運作流程

1. 受理接案
2. 訪談需求
3. 排定流程
4. 配置資源
5. 執行確認
6. 結案收款

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
