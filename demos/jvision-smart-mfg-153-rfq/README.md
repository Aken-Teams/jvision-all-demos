# 詢比議價管理系統（RFQ）

> 從名單到成交的完整客戶生命週期管理

詢比議價管理系統（RFQ）提供線上發布詢價單(RFQ/RFP/RFI)、供應商報價回覆入口、多維度比價分析表。採購部依「建立詢價單 → 供應商報價 → 系統比價 → 議價協商 → 決標下單」推進作業，優先解決「人工彙整報價費時易出錯」，成本工程部則以平均議價節省率與詢價回覆率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**採購供應鏈　|　**系統類型：**CRM 客戶關係管理

## 功能模組

- **客戶 360 視圖** — 整合互動、報價、合約與服務歷程
- **銷售管線** — 拖曳看板管理商機階段與轉化率
- **報價與合約** — 線上報價、審核與電子簽核
- **行銷活動** — 名單分群、活動追蹤與成效分析
- **AI 業務助理** — 下一步建議、風險提醒與成交預測
- **業績報表** — 銷售漏斗、預測與達成率儀表

## 適合誰使用

- 採購部
- 成本工程部
- 研發部

## 運作流程

1. 待詢價
2. 比價中
3. 待核准
4. 驗收完成

## 導入效益

- 採購前置時間：11天 → **4.7天**
- 準時到貨率：77% → **90%**
- 缺料預警覆蓋：38% → **86%**
- 議價作業工時：7.5小時/週 → **1.9小時/週**
