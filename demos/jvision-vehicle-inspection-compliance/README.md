# 營業車定檢合規台

> 協助客運、計程車與租賃車隊管理車輛定期檢驗、牌照文件、保險證明及缺失複驗時程，提前安排停駛窗口與代班車，避免逾期受罰或影響營運。

協助客運、計程車與租賃車隊管理車輛定期檢驗、牌照文件、保險證明及缺失複驗時程，提前安排停駛窗口與代班車，避免逾期受罰或影響營運。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **合規總覽** — 呈現車輛期限、風險與近期停駛需求。
- **證件台帳** — 管理行照、保險及營業相關文件期限。
- **定檢排程** — 安排檢驗站、日期與代班車輛。
- **缺失清單** — 記錄不合格項目與改善責任。
- **複驗追蹤** — 追蹤修復完成、複驗預約及結果。
- **合規報表** — 彙整到期、合格及逾期原因供主管查核。

## 適合誰使用

- 車隊管理員
- 維修協調員
- 營運主管

## 運作流程

1. 辨識到期車
2. 核對文件
3. 安排定檢
4. 登錄缺失
5. 完成複驗
6. 封存證明

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
