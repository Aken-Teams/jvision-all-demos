# 材料跨案調撥計價台

> 管理鋼材、磁磚與設備在不同工地間的調撥申請、出入數量、運費、損耗及成本轉移，避免材料已移動但兩案帳務仍重複或漏列。

管理鋼材、磁磚與設備在不同工地間的調撥申請、出入數量、運費、損耗及成本轉移，避免材料已移動但兩案帳務仍重複或漏列。

**產業別：**營建工程　|　**系統類型：**warehouse-wms

## 功能模組

- **調撥申請** — 登錄來源目的及數量
- **可調庫存** — 確認批次與保留狀態
- **運送安排** — 管理車次運費與交接
- **到案簽收** — 核對實收損耗及照片
- **成本移轉** — 計算材料運費與損耗
- **雙案勾稽** — 確認出入帳同步

## 適合誰使用

- 材料管理員
- 物流調度員
- 成本會計

## 運作流程

1. 提出調撥
2. 來源核准
3. 安排運送
4. 目的簽收
5. 成本計算
6. 雙案過帳

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
