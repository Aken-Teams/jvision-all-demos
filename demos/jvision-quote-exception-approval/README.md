# 報價例外條件簽核台

> 集中折扣、付款條件、最低量、保固及特殊承諾的例外申請，顯示毛利與風險影響，鎖定核准版本並確保正式報價只引用有效授權。

集中折扣、付款條件、最低量、保固及特殊承諾的例外申請，顯示毛利與風險影響，鎖定核准版本並確保正式報價只引用有效授權。

**產業別：**業務銷售　|　**系統類型：**sales-crm

## 功能模組

- **例外申請** — 選擇折扣帳期及特殊條件
- **影響試算** — 顯示毛利現金與風險
- **授權路由** — 依金額條件決定簽核人
- **會簽協作** — 集中補充與修改意見
- **版本核准** — 鎖定有效條件與期限
- **報價發布** — 產出引用核准碼的版本

## 適合誰使用

- 業務人員
- 財務主管
- 業務主管

## 運作流程

1. 建立例外
2. 試算影響
3. 決定路由
4. 完成會簽
5. 核准版本
6. 發布報價
