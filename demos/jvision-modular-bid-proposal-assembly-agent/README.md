**產業別：**專業服務　|　**系統類型：**collaboration-pm

## 功能模組

- **核准素材庫** — 管理可重用的技術說明、實績、證照與商務條款。
- **標書章節藍圖** — 依招標文件建立章節結構、頁數限制與責任分工。
- **內容模組配對** — 將核准素材匹配到需求條款與指定章節。
- **章節組裝工作台** — 生成技術、商務與實績章節並保留素材來源。
- **招標規格校對** — 檢查必答項、格式、字數、附件與前後敘述一致性。
- **定稿核准中心** — 管理章節審閱、修改意見、核准狀態與輸出版本。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 選取核准素材
2. 建立章節藍圖
3. 配對內容模組
4. 組裝標書初稿
5. 校對規格一致性
6. 核准並輸出定稿

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
