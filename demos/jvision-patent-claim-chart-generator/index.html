EdgeVision X4 — Adaptive Inference Architecture
Technical Specification · EVX4-TS-048 · Rev. 4.8

4.3 Adaptive Partition Controller

The controller continuously obtains system telemetry from the Telemetry Agent, including network round-trip latency, available upstream bandwidth, NPU utilization, and thermal headroom.

1 Based on the received telemetry, the controller selects one of the locally stored model partition profiles and may offload the remaining graph to the configured cloud node.

The selected profile is applied without restarting the inference pipeline. Intermediate tensors are serialized by the SplitGraph transport service.
