# 塗料原料調價報價台

> 供塗料廠將樹脂、溶劑、顏料的供應商漲價通知對應產品配方耗用，批次重算訂單成本與生效日曝險，避免舊價持續接單。

供塗料廠將樹脂、溶劑、顏料的供應商漲價通知對應產品配方耗用，批次重算訂單成本與生效日曝險，避免舊價持續接單。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **漲價通知** — 整理料號生效日
- **配方映射** — 找出受影響產品
- **成本重算** — 依配方耗用更新
- **訂單曝險** — 顯示未出貨風險
- **調價清單** — 產生客戶新價格
- **例外簽核** — 核准緩漲條件

## 適合誰使用

- 原料採購
- 產品業務

## 運作流程

1. 收到通知
2. 確認料號
3. 展開配方
4. 重算毛利
5. 提出調價
6. 例外核准

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
