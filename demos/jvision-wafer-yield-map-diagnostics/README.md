整合晶圓測試結果、缺陷座標與製程批次，以良率地圖呈現空間分布，辨識環狀、邊緣、群聚等異常型態，協助品質與製程人員追查可能站點、比較批次差異並建立改善紀錄。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **良率總覽** — 以產品、批次及站點彙整良率趨勢與待診斷警示。
- **晶圓地圖** — 呈現晶粒測試結果、缺陷位置與可互動的區域篩選。
- **圖樣診斷** — 標示環狀、邊緣及群聚圖樣並列出可能成因。
- **批次比對** — 並排比較多片晶圓與歷史正常基準的空間差異。
- **製程追溯** — 串接模擬製程履歷，定位可疑設備、腔體與站點。
- **改善追蹤** — 記錄判定、處置、責任人及改善前後的驗證結果。

## 適合誰使用

- 良率工程師
- 製程整合工程師
- 品質主管

## 運作流程

1. 掌握良率
2. 檢視地圖
3. 判讀圖樣
4. 比較批次
5. 追查製程
6. 結案驗證

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
