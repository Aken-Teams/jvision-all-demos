# 合約義務擷取器

> 從合約精準抽取各類義務，建立含責任、期限與來源條款的追蹤台帳。

從合約精準抽取各類義務，建立含責任、期限與來源條款的追蹤台帳。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **合約條款解析** — 解析合約正文、附件、補充協議與條款層級結構。
- **義務類型擷取** — 辨識交付、付款、通知、稽核、續約與終止義務。
- **期限條件計算** — 換算固定日期、相對期限、觸發條件與循環週期。
- **義務責任配對** — 將義務主體、內部負責人與協作部門建立對應。
- **條款義務台帳** — 以來源條款、履行情況與風險維護可追蹤清冊。
- **履約提醒處置** — 對將到期、逾期及條件觸發義務發出提醒並追蹤完成。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 選定待析合約
2. 審閱義務候選
3. 校準期限條件
4. 指定履約責任
5. 發布義務台帳
6. 追蹤履約完成
