**產業別：**宗教服務　|　**系統類型：**operations-console

## 功能模組

- **燈位總覽** — 查看各燈種區域的可用與占用狀態。
- **點燈登記** — 建立信眾、祈福對象及燈種資料。
- **資料校對** — 檢查姓名、生辰、地址與重複登記。
- **燈位配置** — 分配區域、排號並處理同行需求。
- **安奉確認** — 批次記錄名牌製作與現場安奉完成。
- **異常補正** — 處理誤植、錯位、換燈與查詢案件。

## 適合誰使用

- 宮廟櫃台
- 廟務行政
- 值年主管

## 運作流程

1. 檢視燈位
2. 受理登記
3. 校對資料
4. 配置區位
5. 完成安奉
6. 處理補正
