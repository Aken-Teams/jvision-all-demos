# 公用事業天候韌性指揮台

> 整合颱風、豪雨、熱浪等擬真情境與電力、供水設施資料，推演可能受損範圍、服務中斷及資源缺口，協助指揮人員建立整備方案、分派事件任務、安排復原順序並進行事後檢討。

整合颱風、豪雨、熱浪等擬真情境與電力、供水設施資料，推演可能受損範圍、服務中斷及資源缺口，協助指揮人員建立整備方案、分派事件任務、安排復原順序並進行事後檢討。

**產業別：**經營管理　|　**系統類型：**operations-console

## 功能模組

- **天候事件戰情** — 彙整事件階段、影響區域、高風險設施、服務中斷與待辦任務。
- **衝擊情境推演** — 選擇颱風、豪雨或熱浪強度，查看設施受損與需求變化推估。
- **韌性缺口盤點** — 檢視備援容量、關鍵備品、人力、通訊與替代供應的不足項目。
- **應變任務協作** — 依事件建立跨部門任務、責任角色、時限、依賴關係與回報狀態。
- **搶修資源調度** — 配置隊伍、車輛、備品和臨時供應點，模擬不同調度方案。
- **服務復原排序** — 依民生關鍵性、影響戶數、修復時間與資源需求安排復原順序。

## 適合誰使用

- 應變指揮官
- 設施營運主管
- 搶修調度員

## 運作流程

1. 建立事件態勢
2. 推演可能衝擊
3. 盤點韌性缺口
4. 展開協作任務
5. 配置搶修資源
6. 決定復原順序

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 決策資料覆蓋：55% → **92%**
- 跨部門對齊：60% → **90%**
