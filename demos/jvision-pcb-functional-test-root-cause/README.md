# 印刷電路板功能測試根因分析

> 整合印刷電路板功能測試步驟、失敗症狀、韌體版本、物料批次與製程履歷，以關聯圖與候選原因排序協助工程師縮小問題範圍，建立驗證計畫並累積可查詢的根因案例。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **失敗案件總覽** — 彙整失敗症狀、影響批次、分析狀態與案件優先級。
- **案件資料建檔** — 建立測試步驟、症狀、韌體及跨站製程履歷。
- **關聯證據圖譜** — 以關聯圖呈現症狀、元件、物料與製程條件連結。
- **根因候選排序** — 依證據一致性列出可能原因、支持項目及反證。
- **驗證計畫管理** — 建立替換、重測與條件對照等模擬驗證任務。
- **根因案例知識庫** — 保存已確認根因、處置方式與相似案件查詢結果。

## 適合誰使用

- 產品工程師
- 測試工程師
- 製程工程師與品質主管

## 運作流程

1. 盤點失敗案件
2. 建立分析案件
3. 探索關聯證據
4. 評估根因候選
5. 執行驗證計畫
6. 沉澱根因案例
