> 依保單指定、法定順位、死亡狀態、未成年身分與比例條款建立受益人樹，逐人追蹤證明文件、給付資格與帳戶，防止漏付、錯付及比例誤算。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **受益人樹** — 呈現順位關係
- **比例試算** — 計算應得份額
- **逐人補件** — 追蹤資格文件
- **特殊判定** — 處理未成年死亡
- **資格覆核** — 雙人確認給付
- **給付清冊** — 產生出款名單

## 適合誰使用

- 理賠經辦
- 法務人員
- 理賠主管

## 運作流程

1. 建立關係
2. 判定順位
3. 試算比例
4. 完成補件
5. 覆核資格
6. 發布給付

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
