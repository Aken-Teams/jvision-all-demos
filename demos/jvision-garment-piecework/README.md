# 成衣計件返修核薪台

> 供成衣廠按員工、工序、紮號與合格件數計算計件薪資，返修品必須完成複驗才計薪，並保留借調工序及臨時單價的核准軌跡。

供成衣廠按員工、工序、紮號與合格件數計算計件薪資，返修品必須完成複驗才計薪，並保留借調工序及臨時單價的核准軌跡。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **工序單價** — 維護有效版本
- **完工回報** — 按紮號記件數
- **返修流轉** — 暫停不良件計薪
- **複驗轉正** — 確認合格產量
- **異常核對** — 找出重複漏報
- **計件結薪** — 產生個人明細

## 適合誰使用

- 車縫組長
- 薪資人員

## 運作流程

1. 發布單價
2. 工序派工
3. 完工登錄
4. 品質判定
5. 異常覆核
6. 月薪結算

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
