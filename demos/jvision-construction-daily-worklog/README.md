# 施工日報工項彙整台

> 彙整各工區每日出工人數、施工位置、完成數量、天候與停待原因，依標準工項及位置編碼檢核異常，讓工務快速完成日報覆核、修正與提交。

彙整各工區每日出工人數、施工位置、完成數量、天候與停待原因，依標準工項及位置編碼檢核異常，讓工務快速完成日報覆核、修正與提交。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **日報總覽** — 查看各工區提交狀態、異常與待覆核日報。
- **現場填報** — 登錄工項、位置、人數、數量及天候資料。
- **欄位檢核** — 檢查位置編碼、計量單位及重複回報。
- **出工彙整** — 按分包商與工種統計每日投入人力。
- **停待紀錄** — 記錄停工、待料與工作面受阻原因。
- **日報輸出** — 產出核定版日報與附件清冊。

## 適合誰使用

- 現場工程師
- 工務主管
- 內業工程師

## 運作流程

1. 檢視提交狀態
2. 登錄施工實績
3. 處理資料異常
4. 核對出工人力
5. 確認停待原因
6. 核定施工日報

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
