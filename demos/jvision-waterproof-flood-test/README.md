**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **試水區圖** — 查看各區測試狀態
- **注水計時** — 記錄起訖與液位
- **滲漏標記** — 定位樓下水跡
- **修補工單** — 指派缺失修補
- **複測核驗** — 重新計時判定
- **覆蓋放行** — 交接後續工班

## 適合誰使用

- 防水班長
- 品管工程師

## 運作流程

1. 區段封堵
2. 開始注水
3. 定時巡查
4. 缺失修補
5. 重新試水
6. 覆蓋交接

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
