# Stop-Ship / Quality Alert Management追蹤台

於重大品質異常發生時，快速發布停止出貨或品質警示通知，防止不良品擴大流出。

- 原始系統：Stop-Ship / Quality Alert Management（停止出貨/品質警示管理）
- 產業分類：智慧製造｜品質管理
- 使用部門：品保部、生產部、出貨倉儲部、業務部
- 工作流程：異常確認→警示發布→受影響批次鎖定→跨部門通知→改善驗證後解除
- AI 應用：受影響批次自動範圍推算、警示優先等級建議
- 主要 KPI：警示發布時效、受影響批次攔截率、解除平均時間
- 代表產品：以客製化QMS警示模組為主
