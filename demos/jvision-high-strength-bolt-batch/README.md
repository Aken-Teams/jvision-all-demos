> 管理鋼構高強螺栓從進料材證、批次抽驗、箱號領用到安裝區位與扭力紀錄的完整鏈結，發生試驗不合格時可立即圈定受影響樓層、接頭及待換範圍。

管理鋼構高強螺栓從進料材證、批次抽驗、箱號領用到安裝區位與扭力紀錄的完整鏈結，發生試驗不合格時可立即圈定受影響樓層、接頭及待換範圍。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **進料批次** — 登錄箱號、爐號、規格與材證。
- **批次抽驗** — 管理取樣、送驗與報告判定。
- **領用發料** — 記錄各箱螺栓領用班組與區域。
- **接頭定位** — 對應樓層、軸線與鋼構接頭編號。
- **扭力查驗** — 登錄初鎖、終鎖及抽查結果。
- **異常隔離** — 圈定不合格批次與換料進度。

## 適合誰使用

- 鋼構工程師
- 品管工程師
- 鋼構領班

## 運作流程

1. 批次收料
2. 抽樣送驗
3. 核准發料
4. 安裝定位
5. 扭力驗收
6. 異常追溯

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
