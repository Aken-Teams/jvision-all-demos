# 集團合併報表管理追蹤台

自動彙整多家子公司財務數據，執行合併沖銷、外幣換算並產出集團合併財務報表。

- 原始系統：集團合併報表管理系統
- 產業分類：智慧製造｜經營管理
- 使用部門：財務部、會計部、稽核室、集團管理部
- 工作流程：子公司數據匯入 → 幣別換算 → 內部交易沖銷 → 合併調整 → 報表產出 → 審計覆核
- AI 應用：異常內部交易自動偵測、合併分錄建議與錯誤預警
- 主要 KPI：合併結帳天數、沖銷正確率、報表產出準時率、審計調整項數
- 代表產品：SAP Group Reporting、Oracle Hyperion Financial Management、鼎新合併報表系統
