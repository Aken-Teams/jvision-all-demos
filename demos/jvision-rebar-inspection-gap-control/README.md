# 鋼筋查驗缺口管制台

> 將鋼筋查驗依樓層、構件與查驗批次拆解，集中記錄主筋、箍筋、搭接、保護層及續接位置的缺口，管制改善、複驗與封模放行，避免缺失被後續工序遮蔽。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **構件查驗地圖** — 依棟別、樓層與構件查看待驗、缺失及可封模狀態。
- **鋼筋檢查表** — 記錄筋徑、間距、搭接、保護層與續接位置結果。
- **缺口舉證** — 將缺失照片、圖面標記與構件位置綁定。
- **改善派工** — 指定鋼筋班修正內容、期限與施工優先序。
- **複驗放行** — 比對改善前後證據並決定通過、退回或保留。
- **缺失分析** — 統計高頻缺失、責任班組與封模延誤趨勢。

## 適合誰使用

- 現場工程師
- 品管工程師
- 鋼筋工班領班

## 運作流程

1. 建立查驗批次
2. 執行鋼筋查驗
3. 標記查驗缺口
4. 完成缺口改善
5. 複驗核准封模
6. 檢討缺失趨勢

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
