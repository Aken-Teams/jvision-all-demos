# 製造技能矩陣彈性派工助手

> 建立人員、工站、證照與熟練度的視覺化技能矩陣，依擬真訂單負荷、出勤與資格限制推薦派工組合，辨識關鍵技能缺口，並規劃輪調、訓練及認證。

建立人員、工站、證照與熟練度的視覺化技能矩陣，依擬真訂單負荷、出勤與資格限制推薦派工組合，辨識關鍵技能缺口，並規劃輪調、訓練及認證。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **技能矩陣總覽** — 交叉呈現人員、工站、熟練度與資格狀態。
- **人員技能檔案** — 查看個人經驗、認證、到期日與可操作工站。
- **班次需求配置** — 設定各班工站需求、人數及必要技能條件。
- **彈性派工建議** — 依出勤、資格、熟練度與輪調需求產生組合。
- **技能缺口雷達** — 找出單點依賴、資格到期與無替補工站。
- **輪調訓練規劃** — 建立培訓路徑、實作任務與認證進度。

## 適合誰使用

- 生產線長
- 製造主管
- 人力資源專員
- 訓練管理員

## 運作流程

1. 盤點技能覆蓋
2. 確認人員資格
3. 建立班次需求
4. 產生彈性派工
5. 辨識技能缺口
6. 安排輪調訓練

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
