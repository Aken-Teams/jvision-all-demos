# 假設工程審查管制台

> 集中管理鷹架、支撐架、擋土與施工構台的計算書、圖說、技師簽證及現場查驗，讓營造廠在啟用、變更與拆除前完成分級審查並保留完整履歷。

集中管理鷹架、支撐架、擋土與施工構台的計算書、圖說、技師簽證及現場查驗，讓營造廠在啟用、變更與拆除前完成分級審查並保留完整履歷。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **工程總覽** — 依棟別、區域與風險呈現申請及啟用狀態。
- **設計送審** — 建立工項並彙整圖說、計算書與簽證文件。
- **分級審查** — 記錄承辦、技師及監造的意見與核定結果。
- **搭設查驗** — 依核定圖說執行現場檢點及缺失拍照。
- **變更追蹤** — 管制載重、構型或施工條件變更後的重審。
- **啟用履歷** — 保存啟用、停用、巡查與拆除的完整紀錄。

## 適合誰使用

- 工地主任
- 土木技師
- 安全衛生人員

## 運作流程

1. 工程總覽
2. 設計送審
3. 分級審查
4. 搭設查驗
5. 變更追蹤
6. 啟用履歷

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
