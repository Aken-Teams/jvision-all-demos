# 翻譯稿件版本交付台

> 集中原稿版本、術語庫、譯稿、審校意見及客戶確認，鎖定每次交付的來源與目標檔，避免漏套新術語、誤寄未審版及無償超輪修改。

**產業別：**專業服務　|　**系統類型：**collaboration-pm

## 功能模組

- **原稿版本** — 追蹤來源檔及變更範圍
- **翻譯任務** — 分派語言段落與期限
- **術語規範** — 鎖定專名和禁用譯法
- **審校差異** — 逐項處理語意格式問題
- **客戶意見** — 記錄確認與修改輪次
- **交付封存** — 輸出核准版及交付證據

## 適合誰使用

- 專案經理
- 翻譯人員
- 審校人員

## 運作流程

1. 建立原稿基準
2. 分派翻譯工作
3. 套用核准術語
4. 執行雙語審校
5. 收斂客戶意見
6. 交付正式版本

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
