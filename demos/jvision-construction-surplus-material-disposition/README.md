# 工地餘料退場處置台

> 在工項結束時盤點未用材料，依可退供應商、轉場、留作備品或報廢分類，完成數量確認與價值歸屬，避免餘料閒置或被帶離。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **餘料盤點** — 登錄位置、數量與狀態。
- **現況證據** — 保存包裝及標示照片。
- **處置決策** — 選擇退貨、轉場或備品。
- **價值評估** — 計算可回收與損失。
- **退場核准** — 確認所有權及承運安排。
- **移交結案** — 記錄收受方與點交量。

## 適合誰使用

- 材料管理員
- 工務工程師
- 成本主管

## 運作流程

1. 發起盤點
2. 登錄餘料
3. 判定所有權
4. 選擇處置
5. 核准退場
6. 完成移交

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
