## 功能模組

- **AI 事件戰情牆** — 依嚴重度呈現資料外洩、錯誤決策與失控 Agent 事件。
- **三維分級矩陣** — 按資料敏感度、決策後果與自主行為範圍計算事件級別。
- **影響路徑分析** — 追蹤模型、應用、資料、使用者與下游動作的受影響範圍。
- **處置劇本指揮器** — 依事件類型啟動隔離模型、撤銷權限或停止 Agent 等劇本。
- **高風險核准佇列** — 集中審批停用服務、封鎖帳號與回滾決策等重大動作。
- **復原與復盤室** — 追蹤服務恢復、補救措施、事件時間線與改進項目。

## 適合誰使用

- CISO
- AI 治理主管
- 資安分析師

## 運作流程

1. 受理 AI 事件
2. 判定事件級別
3. 界定影響範圍
4. 啟動處置劇本
5. 核准高風險動作
6. 復原並完成復盤

## 導入效益

- 告警分流時間：45分鐘 → **8分鐘**
- 事件平均處理：12小時 → **3小時**
- 弱點修補率：68% → **96%**
- 合規稽核工時：30小時/月 → **6小時/月**
