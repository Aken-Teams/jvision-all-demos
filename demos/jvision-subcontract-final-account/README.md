# 分包結算封帳檢核台

> 在分包最終結算前彙整原約、追加減、累計估驗、代付款、罰扣、保留款與未完責任，執行封帳清單後才允許結清付款。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **結算總覽** — 查看合約與累計金額
- **追加減核對** — 確認所有變更已納入
- **扣款清理** — 彙整代付罰扣與索賠
- **保留款確認** — 核對扣留和釋放餘額
- **封帳檢核** — 取得跨部門結清確認
- **結算鎖定** — 發布最終付款版本

## 適合誰使用

- 合約管理員
- 成本會計
- 工地主任

## 運作流程

1. 提出結算
2. 工程清查
3. 採購清查
4. 財務勾稽
5. 雙方議定
6. 封帳付款

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
