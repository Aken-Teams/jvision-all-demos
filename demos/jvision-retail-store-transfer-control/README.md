# 連鎖門市調撥協調台

> 依各店庫存、銷速、活動需求與運送批次提出跨店調撥，管理供應店確認、揀貨交接、在途及收貨差異，減少熱門店缺貨與滯銷店積壓。

依各店庫存、銷速、活動需求與運送批次提出跨店調撥，管理供應店確認、揀貨交接、在途及收貨差異，減少熱門店缺貨與滯銷店積壓。

**產業別：**零售電商　|　**系統類型：**warehouse-wms

## 功能模組

- **門市缺口** — 比較各店可售天數與活動需求。
- **調撥建議** — 配對供應店、需求店及建議數量。
- **門市確認** — 由供應店確認實際可撥數量。
- **揀貨交接** — 建立裝箱明細與物流交接紀錄。
- **在途追蹤** — 查看批次狀態與預計抵店日。
- **收貨驗差** — 登錄實收、短少、破損與後續處理。

## 適合誰使用

- 商品調度專員
- 區域督導
- 門市店長

## 運作流程

1. 辨識缺口
2. 建立建議
3. 確認可撥
4. 完成出店
5. 追蹤在途
6. 驗收入店

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
