**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **跨庫變更拓撲** — 將多個PR、提交、套件與服務依相依關係串成變更圖。
- **共用契約比對** — 偵測API、事件結構、Schema與共享型別的破壞性變更。
- **下游影響追蹤** — 找出受契約變更影響的消費服務、用戶端與部署環境。
- **跨庫審查建議** — 依程式脈絡產生具檔案與行號證據的跨服務審查意見。
- **相容遷移規劃** — 安排版本策略、雙寫雙讀、淘汰期限與跨團隊升級順序。
- **合併風險閘門** — 彙總測試與相容性結果，對高風險合併要求人工核准。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 建立跨庫變更集
2. 掃描契約差異
3. 確認下游影響
4. 處理審查發現
5. 協調相容遷移
6. 核准跨庫合併
