# 設備綜合效率損失導航器

> 將設備綜合效率拆解為稼動率、性能與良率，透過擬真停機、降速及不良資料形成損失樹，協助主管從異常指標一路追查班別、產品、設備與事件根因。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **效率戰情總覽** — 呈現全廠與產線效率及三大構成指標。
- **損失結構樹** — 將停機、降速與不良損失逐層量化展開。
- **多維下鑽分析** — 依班別、機台、產品與時段交叉篩選。
- **根因線索導航** — 串聯異常事件與可能原因，標示影響程度。
- **改善行動看板** — 把分析結果轉成負責人、期限與改善任務。
- **效益驗證中心** — 比較改善前後效率與已回收的產能效益。

## 適合誰使用

- 廠長
- 製造主管
- 製程工程師
- 改善專員

## 運作流程

1. 鎖定效率缺口
2. 拆解主要損失
3. 下鑽異常條件
4. 確認根因線索
5. 指派改善行動
6. 驗證改善收益

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
