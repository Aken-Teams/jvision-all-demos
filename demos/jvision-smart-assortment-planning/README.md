# 智慧商品組合陳列規劃台

> 整合模擬的銷售、毛利、庫存與門市空間資料，協助零售團隊比較商品汰換、品類配置及貨架陳列方案，在提案前預估營收影響並產出可執行的門市配置計畫。

整合模擬的銷售、毛利、庫存與門市空間資料，協助零售團隊比較商品汰換、品類配置及貨架陳列方案，在提案前預估營收影響並產出可執行的門市配置計畫。

**產業別：**零售電商　|　**系統類型：**analytics-bi

## 功能模組

- **品類績效總覽** — 以銷售、毛利、庫存與坪效卡片辨識需調整的品類與門市。
- **商品組合編輯** — 新增、保留或淘汰商品，並檢查價格帶、品牌及規格覆蓋情形。
- **貨架配置畫布** — 以拖拉式平面圖安排層架、端架與商品排面，呈現空間占用結果。
- **情境效益模擬** — 比較不同商品與排面方案的預估營收、毛利、庫存和坪效。
- **門市分群套版** — 依店型、商圈及空間條件建立配置範本，預覽各店套用差異。
- **陳列發布追蹤** — 產出圖文陳列指引、設定期限，並以模擬回報追蹤門市完成狀態。

## 適合誰使用

## 運作流程

1. 發現調整機會
2. 編修商品組合
3. 設計貨架陳列
4. 比較方案效益
5. 套用門市版本
6. 發布執行任務
