# 客運事故值勤應變台

> 協助客運業者在擦撞、車輛故障或乘客受傷時，依事件等級協調備援車、駕駛通報、乘客安置、保險文件與主管覆核，保留完整應變時間軸。

協助客運業者在擦撞、車輛故障或乘客受傷時，依事件等級協調備援車、駕駛通報、乘客安置、保險文件與主管覆核，保留完整應變時間軸。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **事件警報** — 建立事故及嚴重分級
- **應變時間軸** — 呈現通報與處置進度
- **備援調度** — 安排車輛與接駁任務
- **乘客安置** — 記錄名單及協助措施
- **證據文件** — 整理照片與保險資料
- **檢討結案** — 覆核原因及改善事項

## 適合誰使用

- 行控調度員
- 站務主管
- 安全管理員

## 運作流程

1. 接獲通報
2. 啟動分級
3. 調派備援
4. 安置乘客
5. 彙整證據
6. 檢討結案

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
