# 社區管理費催收管制台

> 供社區物業按戶別計算管理費、停車費與公共基金，追蹤欠費帳齡、催繳接觸及分期承諾，並產出管委會決議與法務移交所需的完整案件紀錄。

供社區物業按戶別計算管理費、停車費與公共基金，追蹤欠費帳齡、催繳接觸及分期承諾，並產出管委會決議與法務移交所需的完整案件紀錄。

**產業別：**房地產與物業　|　**系統類型：**finance-case

## 功能模組

- **戶別帳冊** — 管理戶別、權狀比例與固定收費設定。
- **應繳計算** — 產生管理費、停車費及臨時分攤款。
- **欠費帳齡** — 依逾期區間與金額排列催收優先序。
- **催繳紀錄** — 記錄通知管道、接觸結果與下次行動。
- **付款協議** — 建立分期或展延承諾並追蹤履約情形。
- **案件移交** — 整理管委會審議及法務移交資料包。

## 適合誰使用

- 物業經理
- 社區會計
- 管委會財委

## 運作流程

1. 維護戶別
2. 產生應繳
3. 篩選欠費
4. 執行催繳
5. 追蹤協議
6. 決議移交

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
