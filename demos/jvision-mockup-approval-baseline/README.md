# 樣品屋標準定版管制台

> 管理住宅或旅館工程樣品屋的材料組合、施工節點、設計變更、缺失修正與定版簽認，將核准成果轉為各樓層施工標準，並追蹤後續現場偏離與例外核准。

管理住宅或旅館工程樣品屋的材料組合、施工節點、設計變更、缺失修正與定版簽認，將核准成果轉為各樓層施工標準，並追蹤後續現場偏離與例外核准。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **樣品區配置** — 依房型與空間建立牆面、天花、設備等查驗區。
- **材料組合** — 整理色號、型號、替代品及核准樣品。
- **節點決議** — 記錄收頭作法、尺寸與設計現勘結論。
- **缺失修正** — 指派樣品屋缺失並比較修正前後成果。
- **標準定版** — 凍結核准材料、節點、照片與適用房型。
- **量產例外** — 審查樓層條件造成的偏離與替代方案。

## 適合誰使用

- 裝修工程師
- 設計監造
- 分包領班

## 運作流程

1. 建立樣品範圍
2. 確認材料組合
3. 辦理聯合查驗
4. 完成缺失修正
5. 簽認標準定版
6. 管制量產偏離

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
