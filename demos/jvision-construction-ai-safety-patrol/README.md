## 功能模組

- **安全戰情** — 呈現即時模擬事件、風險分布、逾期改善與現場安全指標。
- **影像巡查** — 以預錄影像卡片展示護具、禁區、開口及動線等辨識標記。
- **事件研判** — 查看事件片段、位置、規則與信心值，確認真實性及風險等級。
- **改善派工** — 指定承攬商、改善要求與期限，追蹤回報及逾期升級。
- **複查關閉** — 比較改善前後影像與佐證，由安全人員核准或退回。
- **風險熱區** — 分析區域、時段、工種與違規類型的群聚及重複發生趨勢。

## 適合誰使用

- 職業安全衛生管理員
- 工地主任與承攬商領班

## 運作流程

1. 監看安全態勢
2. 巡覽辨識事件
3. 完成風險研判
4. 指派現場改善
5. 複查改善結果
6. 調整巡查重點

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
