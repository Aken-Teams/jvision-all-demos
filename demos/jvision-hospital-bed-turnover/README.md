**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **床位總覽** — 依病房、科別、性別與隔離條件呈現可用狀態。
- **候床佇列** — 排列急診、預約住院及轉床病人的優先順序。
- **預計出院** — 追蹤醫囑、藥物、衛教及結帳等出院障礙。
- **清床進度** — 管理退床、清消、設備檢查及可用確認。
- **床位配對** — 依照護條件與優先級提出配置及衝突提示。
- **入床交接** — 確認病人、病房與運送人員的交接任務。

## 適合誰使用

- 住院中心專員
- 護理站長
- 床位協調員

## 運作流程

1. 彙整候床需求
2. 盤點預計出院
3. 推進退床清消
4. 確認床位可用
5. 執行需求配對
6. 完成入床交接

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
