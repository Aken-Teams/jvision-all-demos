# 平台銷售款清分台

> 逐訂單拆解平台貨款、退貨、補貼、運費、佣金、廣告費與罰款，勾稽應收和實際撥款，讓跨期差異可被分類、追款或轉列正確科目。

逐訂單拆解平台貨款、退貨、補貼、運費、佣金、廣告費與罰款，勾稽應收和實際撥款，讓跨期差異可被分類、追款或轉列正確科目。

**產業別：**零售電商　|　**系統類型：**finance-case

## 功能模組

- **結算匯入** — 載入平台明細
- **訂單配對** — 連結銷退資料
- **款項拆分** — 拆解費用補貼
- **差額分類** — 辨識跨期少撥
- **追款申訴** — 追蹤平台回覆
- **撥款核銷** — 結清應收帳款

## 適合誰使用

- 電商會計
- 平台營運員
- 應收主管

## 運作流程

1. 載入結算
2. 配對訂單
3. 拆分款項
4. 調查差額
5. 提出申訴
6. 完成核銷

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
