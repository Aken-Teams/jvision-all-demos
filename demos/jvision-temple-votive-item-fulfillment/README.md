# 宮廟還願品履約管理台

> 協助宮廟管理信眾登記的還願供品、戲台、花籃與公益捐贈等承諾，安排可接受日期、規格審核、供應商進場及完成證明，避免大型節日前重複排程或不符場地規範。

**產業別：**宗教服務　|　**系統類型：**operations-console

## 功能模組

- **還願登記** — 記錄信眾、神明、品項及期望日期。
- **規格審查** — 檢查尺寸、數量、禁忌及場地限制。
- **日期安排** — 配置節慶、法會與一般日可用時段。
- **進場協調** — 管理供應商、車輛及交付方式。
- **完成驗收** — 記錄擺設、演出或捐贈完成證明。
- **收據結案** — 整理費用、捐贈及致謝文件。

## 適合誰使用

- 廟務人員
- 總務主管
- 會計人員

## 運作流程

1. 受理登記
2. 審查規格
3. 安排日期
4. 協調進場
5. 完成驗收
6. 文件結案
