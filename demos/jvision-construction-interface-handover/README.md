# 工種介面交接管制台

> 管理土建、機電、裝修等工種在同一作業面進退場前的條件確認、缺失整改、保護責任與正式交接，降低互相等待及成品破壞。

管理土建、機電、裝修等工種在同一作業面進退場前的條件確認、缺失整改、保護責任與正式交接，降低互相等待及成品破壞。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **作業面總覽** — 查看區域、工種與預定交接日期。
- **前置條件** — 檢核尺寸、清潔、測試與文件。
- **交接缺失** — 記錄阻礙接續施工的問題。
- **交面簽認** — 由交付與承接工種共同確認。
- **成品保護** — 指定保護措施及損壞責任。
- **介面追蹤** — 監控逾期交面與後續工序影響。

## 適合誰使用

- 工地主任
- 工務工程師
- 分包領班

## 運作流程

1. 規劃交接區域
2. 檢查前置條件
3. 提出交接缺失
4. 完成缺失整改
5. 共同簽認交面
6. 追蹤成品保護

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
