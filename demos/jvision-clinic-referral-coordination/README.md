# 醫療轉診協調管理台

> 協助診所管理轉出與轉入個案的摘要、預約、文件、回覆及追蹤期限，讓護理與行政人員掌握每位病人的轉診閉環，降低漏約、缺件與結果未回傳情形。

協助診所管理轉出與轉入個案的摘要、預約、文件、回覆及追蹤期限，讓護理與行政人員掌握每位病人的轉診閉環，降低漏約、缺件與結果未回傳情形。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **轉診總覽** — 掌握待安排、已預約、待回覆及逾期個案。
- **案件建檔** — 記錄轉診原因、急迫度與目標專科。
- **資料準備** — 整理摘要、檢查報告及轉診附件清單。
- **預約協調** — 記錄院所時段、病人確認與交通需求。
- **結果回收** — 追蹤就診結果、回覆文件及缺漏項目。
- **後續照護** — 建立回診、用藥或衛教等追蹤任務。

## 適合誰使用

- 護理師
- 診所行政
- 醫師

## 運作流程

1. 盤點案件
2. 建立轉診
3. 備妥資料
4. 協調預約
5. 收回結果
6. 安排追蹤

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
