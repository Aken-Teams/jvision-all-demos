比較保稅倉、加工區與退稅方案，找出兼顧節稅及現金占用的落地模式。

**產業別：**採購供應鏈　|　**系統類型：**finance-case

## 功能模組

- **保稅倉情境設計** — 模擬進口貨物延後繳稅、分批提領與轉口的資金效果。
- **加工區情境設計** — 評估區內加工、內銷與復出口配置的稅負及作業要求。
- **退稅方案試算** — 估算已繳稅款可退金額、申請時點與實際回收期間。
- **現金占用比較** — 比較各方案的稅款遞延、保證金、庫存與營運資金需求。
- **適用資格檢查** — 核對貨物、流程、帳冊及所在地是否符合方案門檻。
- **保稅選型建議** — 按淨效益、導入成本與合規難度推薦最適方案。

## 適合誰使用

- 國貿主管
- 報關人員
- 業務

## 運作流程

1. 建立保稅情境
2. 試算倉儲方案
3. 試算加工區方案
4. 試算退稅方案
5. 比較資格與資金
6. 核定保稅模式

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
