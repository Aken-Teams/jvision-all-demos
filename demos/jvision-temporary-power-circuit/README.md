# 臨時用電迴路管制台

> 建立臨時配電箱與下游迴路關係，管理負載估算、接用申請、保護裝置檢點、移箱改線、停送電範圍及現場標示，降低誤接、過載與交班資訊落差。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **迴路拓樸** — 呈現總盤、分盤、箱體與下游接用關係。
- **接用申請** — 登錄設備功率、期間、位置及插接方式。
- **負載試算** — 比較額定容量、同時用電與預留餘裕。
- **保護檢點** — 記錄漏電、接地、箱門與線路防護結果。
- **移箱改線** — 管制切換步驟、停電範圍與新版標示。
- **停送電公告** — 通知受影響工班並保存復電確認。

## 適合誰使用

- 臨時電工
- 安衛工程師
- 分包領班

## 運作流程

1. 建立拓樸
2. 申請接用
3. 容量審查
4. 現場接線
5. 安全檢點
6. 異動交班

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
