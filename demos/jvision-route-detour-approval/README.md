# 營運路線臨時改道台

> 針對道路施工、活動或突發封閉，建立改道路線、停靠站影響、班次時刻與駕駛指示，經安全及營運確認後發布版本並追蹤恢復原線。

針對道路施工、活動或突發封閉，建立改道路線、停靠站影響、班次時刻與駕駛指示，經安全及營運確認後發布版本並追蹤恢復原線。

**產業別：**交通運輸　|　**系統類型：**operations-console

## 功能模組

- **事件總覽** — 查看封路原因與期間
- **改道規劃** — 建立替代路線和限制
- **站點影響** — 標記停駛與臨時站
- **班次調整** — 估算時間與駕駛工時
- **版本發布** — 同步駕駛站務及客服
- **復原追蹤** — 確認道路開放與回復原線

## 適合誰使用

- 營運調度
- 路線主管
- 站務人員

## 運作流程

1. 建立事件
2. 規劃改道
3. 評估站點
4. 調整班次
5. 發布指示
6. 恢復原線

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
