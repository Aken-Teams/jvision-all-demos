# 供應商交期達成率管理決策室

追蹤供應商實際交貨與承諾交期的達成情形，量化交期表現並驅動改善行動。

- 原始系統：供應商交期達成率管理系統（OTD）
- 產業分類：智慧製造｜採購管理
- 使用部門：採購部、供應商管理部、生產計畫部
- 工作流程：訂單交期設定 → 到貨數據蒐集 → 達成率統計 → 延遲原因分析 → 供應商溝通改善
- AI 應用：AI 預測訂單延遲風險並提前示警、延遲原因自動分類歸納
- 主要 KPI：整體OTD達成率、平均延遲天數、延遲訂單占比
- 代表產品：SAP Ariba Supplier Performance、Coupa、Power BI/Tableau客製看板
