# 旅宿迷你吧耗用管制台

> 管理客房迷你吧的房內配置、補貨盤點、住客耗用與退房計價，協助房務和櫃台在結帳時限內釐清短少及免計爭議。

管理客房迷你吧的房內配置、補貨盤點、住客耗用與退房計價，協助房務和櫃台在結帳時限內釐清短少及免計爭議。

**產業別：**餐飲旅宿　|　**系統類型：**warehouse-wms

## 功能模組

- **標準配置** — 設定房型應備品項、數量及售價。
- **退房盤點** — 依退房清單記錄房內實際數量。
- **耗用計價** — 將確認耗用品項送入待結帳清單。
- **爭議覆核** — 處理誤報、贈送及住客否認案件。
- **樓層補貨** — 彙整缺品並建立補貨任務。
- **損耗分析** — 分析房型、品項與班別差異。

## 適合誰使用

- 房務領班
- 櫃台人員
- 餐飲倉管

## 運作流程

1. 設定房內配置
2. 執行退房盤點
3. 確認住客計價
4. 覆核收費爭議
5. 完成樓層補貨
6. 檢討盤點差異

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
