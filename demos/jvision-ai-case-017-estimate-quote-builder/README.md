# 工程報價生成所

> 從詢價到核定報價的一站式估價工作台

把工項估價、單價分析、BOQ 明細與報價單生成整合成一個可操作、可追蹤、可稽核的單一平台，讓報價又快又準。

**產業別：**營建工程　|　**系統類型：**工程估價與報價生成系統

## 功能模組

- **報價總覽** — 工程總價、毛利、料工費占比與待核報價戰情
- **工項估價** — 依施工分項拆解工項、數量與單價來源
- **單價分析** — 料工費組成拆解，帶出每一工項的單價明細
- **BOQ 明細表** — 工項/單位/數量/單價/複價的成本彙總表
- **報價單生成** — 含加成、稅金、付款條件的正式報價文件
- **版本比較** — 報價版本差異追溯與核定歷程

## 適合誰使用

- 估價工程師
- 工程預算主管
- 營建工程主管

## 運作流程

1. 建立詢價
2. 工項估價
3. 單價分析
4. 彙整 BOQ
5. 版本核定

## 導入效益

- 報價彙整工時：6.4小時/案 → **1.2小時/案**
- 單價分析涵蓋率：48% → **96%**
- 報價產出天數：5.5天 → **1.5天**
- 估價誤差率：9% → **3%**
