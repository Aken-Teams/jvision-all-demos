# 工程報價生成所

> 從名單到成交的完整客戶生命週期管理

快速建立估價明細、報價版本與毛利試算。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**營建工程　|　**系統類型：**CRM 客戶關係管理

## 功能模組

- **客戶 360 視圖** — 整合互動、報價、合約與服務歷程
- **銷售管線** — 拖曳看板管理商機階段與轉化率
- **報價與合約** — 線上報價、審核與電子簽核
- **行銷活動** — 名單分群、活動追蹤與成效分析
- **AI 業務助理** — 下一步建議、風險提醒與成交預測
- **業績報表** — 銷售漏斗、預測與達成率儀表

## 適合誰使用

- 工班專員
- 工班主管
- 營建工程主管

## 運作流程

1. 待釐清
2. 現場處理
3. 待查驗
4. 計價完成

## 導入效益

- 日報彙整工時：3.1小時/日 → **0.5小時/日**
- 進度落後預警：42% → **94%**
- 估驗計價天數：9.6天 → **3.8天**
- 缺失改善時效：7天 → **2天**
