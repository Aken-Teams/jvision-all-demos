# 電子料件濕敏度管理協作所

依IPC/JEDEC J-STD-033標準管理濕敏元件(MSL)的開封、暴露時間與烘烤紀錄，避免爆米花效應。

- 原始系統：電子料件濕敏度管理系統（MSL Management System）
- 產業分類：智慧製造｜倉儲管理
- 使用部門：倉儲部、SMT製程部、品保部、工程部
- 工作流程：開封登記計時→暴露時間監控→超時預警→烘烤處理→再密封標示→上線核可
- AI 應用：暴露時間風險預測與優先領用建議、異常濕敏事件根因分析
- 主要 KPI：MSL超時事件數、烘烤達成率、濕敏相關不良率、追溯完整率
- 代表產品：多整合於MES客製模組（如Siemens Opcenter、Critical Manufacturing MES），另有廠內自建濕敏管理系統
