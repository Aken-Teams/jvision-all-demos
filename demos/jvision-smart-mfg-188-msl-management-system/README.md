# 電子料件濕敏度管理系統（MSL Management System）

> 收貨到出貨的倉內作業與庫存精準管理

電子料件濕敏度管理系統（MSL Management System）提供MSL等級建檔與到期倒數、開封暴露時間累計計時、超時自動預警與烘烤建議。倉儲部依「開封登記計時→暴露時間監控→超時預警→烘烤處理→再密封標示→上線核可」推進作業，優先解決「暴露時間人工計算易超時」，SMT製程部則以MSL超時事件數與烘烤達成率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**倉儲物流　|　**系統類型：**WMS 倉儲管理系統

## 功能模組

- **入庫上架** — 收貨、驗收與智慧上架
- **揀貨出貨** — 波次揀貨、覆核與出貨
- **儲位管理** — 儲位規劃與庫容視覺化
- **庫存盤點** — 即時庫存、盤點與調撥
- **拉動補料** — 安全庫存與自動補貨
- **條碼作業** — PDA 掃碼即時作業

## 適合誰使用

- 倉儲部
- SMT製程部
- 品保部

## 運作流程

1. 待盤點
2. 待補貨
3. 移庫中
4. 出庫完成

## 導入效益

- 揀貨作業工時：6.6小時/日 → **1.9小時/日**
- 庫存準確率：83% → **93%**
- 出貨延遲率：8.5% → **1.9%**
- 盤點工時：15小時/月 → **2.8小時/月**
