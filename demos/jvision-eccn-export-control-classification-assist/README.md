**產業別：**採購供應鏈　|　**系統類型：**legal-case

## 功能模組

- **技術參數剖析** — 抽取效能、精度、頻率、加密與軍民用途參數。
- **管制清單比對** — 逐項比對 CCL 類別、產品群與技術門檻。
- **候選 ECCN 比較** — 比較候選碼的適用條文、控制理由與信心。
- **例外條件檢查** — 檢驗 EAR99、許可例外及其附帶限制。
- **出口情境驗證** — 結合目的地、最終用途與交易方判斷許可需求。
- **管制分類核定** — 核准 ECCN、控制理由、例外資格與重審條件。

## 適合誰使用

- 國貿主管
- 報關人員
- 業務

## 運作流程

1. 建立產品案件
2. 確認技術參數
3. 比對管制條目
4. 檢查許可例外
5. 驗證出口情境
6. 核定管制分類
