# 混凝土冷縫處置管制台

> 針對澆置中斷、供料延遲或設備故障造成的疑似冷縫，記錄發生時序與位置，完成技師研判、處置工法核准、修補施工、檢測及結案追蹤。

針對澆置中斷、供料延遲或設備故障造成的疑似冷縫，記錄發生時序與位置，完成技師研判、處置工法核准、修補施工、檢測及結案追蹤。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **中斷通報** — 記錄停澆起訖、原因、天候與供料狀態。
- **界面定位** — 在結構圖標示澆置前緣及影響範圍。
- **證據彙整** — 串接車次、坍度、配比與現場照片。
- **技師研判** — 提出結構影響、檢測需求與處置原則。
- **修補施工** — 管制打除、界面處理、植筋或補強步驟。
- **檢測結案** — 記錄檢測結果、複驗與核准結論。

## 適合誰使用

- 土建工程師
- 品管工程師
- 結構技師

## 運作流程

1. 即時通報
2. 定位取證
3. 初步評估
4. 技師核定
5. 執行修補
6. 複驗結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
