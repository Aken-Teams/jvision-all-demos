# 客運遺失物協尋管理台

> 供客運與捷運營運單位處理乘客遺失物通報，依班次、車號、座位與物品特徵媒合拾獲紀錄，管理保管位置、身分核驗、領回預約及逾期處置，降低站點間查找成本。

供客運與捷運營運單位處理乘客遺失物通報，依班次、車號、座位與物品特徵媒合拾獲紀錄，管理保管位置、身分核驗、領回預約及逾期處置，降低站點間查找成本。

**產業別：**交通運輸　|　**系統類型：**service-desk

## 功能模組

- **遺失通報** — 登錄行程線索與物品描述。
- **拾獲登錄** — 建立拾獲地點、時間與保管標籤。
- **特徵媒合** — 依班次及特徵比對可能物件。
- **站點移交** — 追蹤物件跨站運送與簽收。
- **領回核驗** — 以描述問題與證件確認領取人。
- **逾期處置** — 管理公告、移送與銷毀期限。

## 適合誰使用

- 客服人員
- 站務人員
- 保管中心主管

## 運作流程

1. 受理通報
2. 登錄拾獲
3. 執行媒合
4. 安排移交
5. 核驗領回
6. 處理逾期

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
