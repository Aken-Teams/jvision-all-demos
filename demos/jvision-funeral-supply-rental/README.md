# 禮儀用品租賃周轉台

> 供禮儀公司管理靈堂布置用品的預留、出庫、案件交接、回收檢點、清潔維修與再次可租日期，避免跨案件重複承諾或遺失。

供禮儀公司管理靈堂布置用品的預留、出庫、案件交接、回收檢點、清潔維修與再次可租日期，避免跨案件重複承諾或遺失。

**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **用品總覽** — 查看庫存、預留與維修狀態。
- **案件預留** — 依日期和套件配置用品。
- **出庫交接** — 建立裝車與現場交接清單。
- **回收檢點** — 核對數量、外觀及缺件。
- **整備維修** — 安排清潔、修復及可租日期。
- **周轉分析** — 檢視利用率與缺損成本。

## 適合誰使用

- 禮儀用品管理員
- 案件協調員
- 營運主管

## 運作流程

1. 查看用品
2. 配置案件
3. 完成出庫
4. 執行檢點
5. 安排整備
6. 分析周轉

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
