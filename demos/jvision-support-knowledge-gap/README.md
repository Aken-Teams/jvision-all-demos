從未解決案件、重複轉派與客服搜尋失敗紀錄辨識知識缺口，建立補文任務、安排審核發布並追蹤文章是否真正降低處理時間。

**產業別：**客服管理　|　**系統類型：**service-desk

## 功能模組

- **缺口雷達** — 彙整搜尋失敗與未解案件
- **主題歸併** — 合併相似問題及需求量
- **補文任務** — 指定作者期限與素材
- **內容審核** — 驗證答案正確與可操作性
- **發布管理** — 安排版本上線及適用範圍
- **成效驗證** — 衡量文章對解決率的影響

## 適合誰使用

- 知識管理員
- 客服組長
- 產品專家

## 運作流程

1. 蒐集缺口訊號
2. 歸併問題主題
3. 指派內容補寫
4. 審核答案內容
5. 發布知識版本
6. 驗證解決成效

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
