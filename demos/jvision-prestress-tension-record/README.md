# 預力鋼腱張拉紀錄台

> 供橋梁與預力構造現場逐束登錄張拉端、油壓值、伸長量與回縮量，完成雙人覆核、異常停工及紀錄交付，避免紙表算錯後仍封錨。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **張拉總覽** — 掌握各區張拉進度
- **批次建檔** — 建立構件與鋼束資料
- **伸長核算** — 比對理論與實測值
- **異常停點** — 管制超差鋼束
- **雙人覆核** — 完成班長與品管簽認
- **紀錄交付** — 彙整張拉成果表

## 適合誰使用

- 張拉班長
- 品管工程師

## 運作流程

1. 排定張拉
2. 建立批次
3. 登錄讀值
4. 判讀超差
5. 複測簽認
6. 封存交付

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
