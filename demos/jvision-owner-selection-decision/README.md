# 業主選配決策追蹤台

> 依戶別與空間管理設備、材質及配色選項，記錄業主選擇、價格影響、決策期限與簽認版本，並將核定結果同步成採購及施工清單，攔截逾期或反覆變更。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **戶別總覽** — 查看各戶選配進度與決策期限。
- **選項目錄** — 維護設備、材質、色號及價差。
- **決策登錄** — 記錄業主選擇與洽談內容。
- **價差試算** — 計算加減價及付款狀態。
- **版本簽認** — 產生選配版本供業主確認。
- **採購交付** — 發布凍結清單給採購與工地。

## 適合誰使用

- 客變專員
- 採購人員
- 工務工程師

## 運作流程

1. 檢視戶況
2. 設定選項
3. 記錄決策
4. 確認價差
5. 完成簽認
6. 交付執行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
