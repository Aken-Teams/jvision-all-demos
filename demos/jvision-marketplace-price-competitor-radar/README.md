# 市集價格競品動態雷達

> 以預先建立的擬真市集快照，追蹤自有與競品商品的價格、促銷、排名及內容變化，協助通路人員比對同款商品、設定監控條件、判讀價格異常，並規劃調價或促銷回應及追蹤成效。

以預先建立的擬真市集快照，追蹤自有與競品商品的價格、促銷、排名及內容變化，協助通路人員比對同款商品、設定監控條件、判讀價格異常，並規劃調價或促銷回應及追蹤成效。

**產業別：**零售電商　|　**系統類型：**analytics-bi

## 功能模組

- **市場動態總覽** — 彙整各市集價格帶、促銷密度、排名變化與今日重要事件。
- **商品配對工作台** — 並排比對名稱、規格、容量與圖片標記，確認是否為可比商品。
- **價格歷程分析** — 查看自有與競品價格快照、折扣區間及價差變化時間軸。
- **競品活動情報** — 整理滿額、折價券、組合價、贈品與內容改版等擬真事件。
- **監控警示規則** — 設定價差、排名、促銷與新品等條件，預覽觸發的警示。
- **市場回應沙盤** — 模擬調價、加贈或維持策略對毛利與競爭力的可能影響。

## 適合誰使用

- 電商通路營運人員
- 商品經理
- 定價主管

## 運作流程

1. 掃描市場變化
2. 確認競品配對
3. 分析價格歷程
4. 解讀競品活動
5. 設定持續監控
6. 規劃市場回應

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
