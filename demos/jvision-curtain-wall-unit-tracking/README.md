# 帷幕牆板塊供裝追蹤台

> 以單元板塊編號串起深化核准、生產版次、品管狀態、裝箱車次、現場暫存、吊裝樓層與破片補製，讓每片板塊都能確認規格與去向，避免圖說變更後舊板出貨或補製品無法對回安裝位置。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **板塊清冊** — 依立面、樓層、軸線與型式建立唯一編號。
- **深化定版** — 綁定核准圖版、材料規格與生產放行狀態。
- **生產品檢** — 追蹤製程、檢驗結果及可出貨日期。
- **裝箱運輸** — 管理框架號、裝箱順序、車次與到場時窗。
- **吊裝定位** — 核對暫存位置、吊裝順序及實際安裝點。
- **破片補製** — 處理破損、錯版、退回與替代板塊關係。

## 適合誰使用

- 帷幕牆工程師
- 工廠生管
- 吊裝領班

## 運作流程

1. 建立清冊
2. 核准生產
3. 製作品檢
4. 裝箱到場
5. 核對吊裝
6. 異常補製

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
