# Agent 人機協作佇列

> 將高風險或低信心的 Agent 步驟交由人工決策，再安全續跑。

將高風險或低信心的 Agent 步驟交由人工決策，再安全續跑。

**產業別：**資訊科技　|　**系統類型：**operations-console

## 功能模組

- **待決策工作籃** — 集中顯示因風險、信心或政策門檻暫停的執行項目。
- **風險優先排序** — 依金額、敏感資料、剩餘時限與影響範圍排列案件。
- **決策上下文檢視** — 並列呈現 Agent 推論、引用來源、工具結果及待決問題。
- **人工裁決台** — 提供核准、修改、拒絕、轉派及要求補充資訊的操作。
- **續跑與回滾控制** — 從核准節點恢復任務，或將失敗流程安全回復至檢查點。
- **逾時升級規則** — 設定決策時限、代理審核人與逐級升級處置。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 檢視待決策佇列
2. 排序處理優先級
3. 核對決策上下文
4. 作成人工裁決
5. 監控恢復執行
6. 設定升級機制
