# 空屋水電復歸派工台

> 以房屋地址為核心整合水電表況、欠費、復歸需求、派工照片與驗收結果，避免空屋尚未通水通電便安排帶看，並保留費用歸責證據。

**產業別：**房地產與物業　|　**系統類型：**maintenance-cmms

## 功能模組

- **空屋清單** — 顯示水電準備狀態
- **表況核對** — 記錄表號度數與欠費
- **復歸工單** — 建立項目及費用歸屬
- **派工調度** — 指派師傅與到場時段
- **完工驗收** — 比對前後照片和讀數
- **帶看放行** — 確認空屋可安全使用

## 適合誰使用

- 代管專員
- 維修調度
- 驗收人員

## 運作流程

1. 盤點待整備空屋
2. 核對水電表況
3. 建立復歸工單
4. 安排到場施工
5. 驗收水電狀態
6. 釋出帶看資格

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
