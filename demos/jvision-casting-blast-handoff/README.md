# 鑄件噴砂外發點收台

> 供鑄造廠在委外噴砂前按棧板記錄爐批、件數與既有外觀缺陷，返廠後比對短少、混爐及新增撞傷，保留加工責任與扣款依據。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **棧板批次** — 連結鑄件與爐批
- **外觀點交** — 記錄既有缺陷
- **送廠簽收** — 確認件數重量
- **返廠點收** — 核對棧板批次
- **損傷比對** — 辨識新增缺陷
- **爭議扣款** — 保留責任證據

## 適合誰使用

- 鑄件倉管員
- 採購人員

## 運作流程

1. 鑄件備料
2. 外觀點交
3. 外發簽收
4. 噴砂回貨
5. 返廠驗收
6. 費用結清

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
