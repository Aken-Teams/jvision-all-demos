# 工地請購拆單稽查台

> 依工地、申請人、供應商、品類與短期時間窗群組分析請購，辨識刻意拆低金額以規避比價或授權的案件，要求合併、說明或升級核准。

依工地、申請人、供應商、品類與短期時間窗群組分析請購，辨識刻意拆低金額以規避比價或授權的案件，要求合併、說明或升級核准。

**產業別：**營建工程　|　**系統類型：**procurement-srm

## 功能模組

- **請購總覽** — 查看工地需求與金額
- **關聯群組** — 聚合同期同類同廠商
- **拆單預警** — 標示規避門檻風險
- **證據調閱** — 查看申請理由與規格
- **合併處理** — 整併比價或重新簽核
- **例外核准** — 記錄急件放行依據

## 適合誰使用

- 採購主管
- 內控人員
- 工地主任

## 運作流程

1. 接收請購
2. 關聯分析
3. 調閱依據
4. 責任說明
5. 合併或升級
6. 稽核結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
