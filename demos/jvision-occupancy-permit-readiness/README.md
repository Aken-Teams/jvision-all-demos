# 使用執照勘驗整備台

> 依使用執照申請範圍拆解消防、昇降、無障礙、停車與竣工文件條件，管理現場預檢、缺失改善及主管機關會勘，協助工地按目標日期完成取照。

依使用執照申請範圍拆解消防、昇降、無障礙、停車與竣工文件條件，管理現場預檢、缺失改善及主管機關會勘，協助工地按目標日期完成取照。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **取照總覽** — 呈現目標日期、關鍵條件及整體成熟度。
- **文件清單** — 管理竣工圖、證明書與各專業合格文件。
- **現場預檢** — 依建管、消防與無障礙條件執行自查。
- **勘驗排程** — 安排建築師、專業單位及機關會勘。
- **缺失改善** — 分派會勘缺失並追蹤完成與複驗證據。
- **取照歸檔** — 記錄補件、核准及使用執照交付資訊。

## 適合誰使用

- 工務經理
- 建管專員
- 監造建築師

## 運作流程

1. 取照總覽
2. 文件清單
3. 現場預檢
4. 勘驗排程
5. 缺失改善
6. 取照歸檔

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
