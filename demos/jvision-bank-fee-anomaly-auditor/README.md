# 銀行費用異常稽核員

> 逐筆比對銀行合約費率與實際扣費，找出錯收項目並協助追回款項。

逐筆比對銀行合約費率與實際扣費，找出錯收項目並協助追回款項。

**產業別：**財務會計　|　**系統類型：**finance-case

## 功能模組

- **費率條款解析** — 從銀行合約、價目表與補充協議擷取適用費率及門檻。
- **扣費逐筆配對** — 將銀行扣費依帳戶、服務、日期與交易量對應合約條款。
- **錯收差額檢測** — 計算超收、重複扣費、未套優惠與不明費目的差額。
- **優惠資格驗證** — 檢查交易量、餘額與綁約條件是否符合議定優惠。
- **追款證據包** — 彙整條款頁、扣款紀錄、計算式與爭議理由形成追款草案。
- **追回成效台帳** — 追蹤銀行回覆、退款、折讓與未來費率修正成果。

## 適合誰使用

- 財務長
- Treasurer
- 資金人員

## 運作流程

1. 解析條款
2. 配對扣費
3. 檢查差額
4. 驗證資格
5. 提出追款
6. 確認追回

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
