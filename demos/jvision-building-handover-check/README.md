# 建築竣工智慧移交檢核台

> 依建築空間、設備與合約清單整理竣工圖、操作手冊、保固及測試文件，以擬真規則自動顯示缺件、版次衝突和待改善項目，讓營造與物業團隊順利完成移交。

依建築空間、設備與合約清單整理竣工圖、操作手冊、保固及測試文件，以擬真規則自動顯示缺件、版次衝突和待改善項目，讓營造與物業團隊順利完成移交。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **竣工資料總覽** — 依棟別、樓層、系統顯示文件完整度與待辦。
- **空間設備建檔** — 建立空間、設備、文件及保固資料的對應關係。
- **文件收件整理** — 模擬上傳竣工圖、手冊、證明與測試報告。
- **智慧完整檢核** — 依合約清單檢查缺件、欄位、格式及簽章。
- **版次衝突處理** — 比較文件版本並指派補件或修正責任。
- **移交包與簽收** — 預覽分冊成果、接管清單與簽收狀態。

## 適合誰使用

- 竣工文件管理員
- 專案經理
- 監造工程師
- 物業接管人員

## 運作流程

1. 盤點進度
2. 建立對應
3. 收集文件
4. 執行檢核
5. 完成補正
6. 移交簽收

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
