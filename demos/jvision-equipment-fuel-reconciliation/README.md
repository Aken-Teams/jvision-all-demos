# 機具油料領用核算台

> 依工地油槽、領料單、機具與操作班次記錄柴油收發，將每次加油量對應機具工時及施工工項，計算合理耗用區間並追查異常；月底可按自有、租賃或分包設備彙整應計成本與扣款。

依工地油槽、領料單、機具與操作班次記錄柴油收發，將每次加油量對應機具工時及施工工項，計算合理耗用區間並追查異常；月底可按自有、租賃或分包設備彙整應計成本與扣款。

**產業別：**營建工程　|　**系統類型：**erp

## 功能模組

- **油料庫存** — 查看油槽收發存與盤點差異。
- **加油登錄** — 記錄機具、數量、時間與領用人。
- **工時匯入** — 整理機具班次及實際運轉工時。
- **耗用核算** — 比較油耗基準與每工時用量。
- **異常追查** — 標示突增、重複與未明領用。
- **成本扣款** — 分攤工項成本及分包代墊款。

## 適合誰使用

- 物料管理員
- 機具主管
- 成本會計

## 運作流程

1. 確認期初庫存
2. 記錄機具加油
3. 彙整運轉工時
4. 計算合理油耗
5. 釐清耗用異常
6. 完成成本結算

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
