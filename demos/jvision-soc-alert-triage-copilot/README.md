# 資安告警分流調查副駕

> 將資安監控中心收到的大量告警自動去重、關聯與分級，以人工智慧摘要攻擊脈絡、推薦調查步驟及回應方案，降低小型資安團隊的誤報負擔與查案時間。

將資安監控中心收到的大量告警自動去重、關聯與分級，以人工智慧摘要攻擊脈絡、推薦調查步驟及回應方案，降低小型資安團隊的誤報負擔與查案時間。

**產業別：**資訊安全　|　**系統類型：**security-soc

## 功能模組

- **告警分流佇列** — 依可信度、衝擊與時效排列告警，支援批次合併及指派。
- **事件關聯圖譜** — 把帳號、主機、網域、檔案及告警串成可探索的攻擊脈絡。
- **引導式調查室** — 依事件類型列出待驗證假設、查證步驟與模擬查詢結果。
- **證據摘要工作台** — 彙整時間軸、可疑行為、關鍵證據及尚未確認的資訊缺口。
- **回應任務協作** — 將封鎖、隔離、通知及復原動作分派給不同處理角色。
- **值班成效分析** — 比較告警量、誤報、處理時間與分析人員工作負荷。

## 適合誰使用

- 資安監控中心分析人員
- 資訊主管
- 事件應變人員

## 運作流程

1. 接收分流
2. 建立關聯
3. 引導調查
4. 彙整證據
5. 協調回應
6. 檢討值班

## 導入效益

- 告警分流時間：45分鐘 → **8分鐘**
- 事件平均處理：12小時 → **3小時**
- 弱點修補率：68% → **96%**
- 合規稽核工時：30小時/月 → **6小時/月**
