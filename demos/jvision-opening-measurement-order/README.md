# 門窗洞口複測下單台

> 依棟別、戶號與門窗編號管理洞口實測、修整複測、開向及下單版本，將尺寸差異轉成待處理清單，只有符合製作條件的樘位才能併批下單，避免抄反尺寸或過早投產。

依棟別、戶號與門窗編號管理洞口實測、修整複測、開向及下單版本，將尺寸差異轉成待處理清單，只有符合製作條件的樘位才能併批下單，避免抄反尺寸或過早投產。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **門窗清冊** — 管理戶號、樘號、型式、開向與設計尺寸。
- **現場量測** — 輸入洞口寬高、對角、垂直度及照片。
- **尺寸比對** — 自動呈現設計值、實測值與允差判定。
- **修整複測** — 派發洞口修整並保留每次複測歷程。
- **下單批次** — 將合格樘位依型式、交期與樓層合併送製。
- **廠商回認** — 由製造端確認尺寸版次、數量與預計交貨日。

## 適合誰使用

- 門窗工程師
- 現場工程師
- 門窗廠業務

## 運作流程

1. 匯入門窗清冊
2. 執行洞口量測
3. 判定尺寸允差
4. 完成修整複測
5. 核准合併下單
6. 回認製造資料

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
