# 寵物美容產能排程台

> 依美容師技能、犬貓體型、服務工時與籠位限制安排每日工單，處理遲到、加項及超時插單，提升門店可承接量與準時率。

依美容師技能、犬貓體型、服務工時與籠位限制安排每日工單，處理遲到、加項及超時插單，提升門店可承接量與準時率。

**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **服務工單** — 建立寵物資料與美容項目
- **技能矩陣** — 維護美容師可承接技能與限制
- **產能排程** — 配置工時、人員及籠位
- **加項評估** — 試算臨時加項的工時影響
- **延誤調度** — 處理遲到、超時與插單
- **產能分析** — 分析利用率與延誤原因

## 適合誰使用

- 門市櫃檯
- 美容師
- 店長

## 運作流程

1. 建立需求
2. 估算工時
3. 配置資源
4. 到店檢查
5. 進度調度
6. 工單結案

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
