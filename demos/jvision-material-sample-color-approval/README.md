# 材料送樣選色追蹤台

> 管理材料樣品從送樣、實體收件、業主選色、監造意見到核定封樣的完整歷程，以唯一編號連結色號、照片及採購規格，避免舊樣或未核定選項被下單。

管理材料樣品從送樣、實體收件、業主選色、監造意見到核定封樣的完整歷程，以唯一編號連結色號、照片及採購規格，避免舊樣或未核定選項被下單。

**產業別：**營建工程　|　**系統類型：**procurement-srm

## 功能模組

- **樣品收件** — 登錄實體樣品與存放位置。
- **色樣比較** — 並列色號、材質與表面處理。
- **審查意見** — 彙整業主及設計回覆內容。
- **版次歷程** — 保留重送、退選與換色紀錄。
- **核定封樣** — 產生唯一封樣編號與標籤。
- **採購核對** — 比對訂單與最終核定規格。

## 適合誰使用

- 材料工程師
- 設計監造人員
- 採購人員

## 運作流程

1. 樣品送達
2. 規格初審
3. 比較選色
4. 補樣修正
5. 核定封樣
6. 下單核對

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
