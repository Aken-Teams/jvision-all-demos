# 公安申報缺件整備台

> 依建築物公共安全申報項目建立文件包，追蹤現場、設備商與專業檢查人提供的證明、照片、簽章及有效期限，檢查缺件依存關係並形成可送件版本。

依建築物公共安全申報項目建立文件包，追蹤現場、設備商與專業檢查人提供的證明、照片、簽章及有效期限，檢查缺件依存關係並形成可送件版本。

**產業別：**營建工程　|　**系統類型：**legal-case

## 功能模組

- **申報項目清單** — 依用途與規模展開應備檢查項目及文件。
- **缺件依存關係** — 顯示文件的前置證明、簽章與現場照片需求。
- **文件收件箱** — 集中接收各單位上傳的報告、證明與附件。
- **期限簽章檢核** — 標記過期、將到期、漏章及版本不符文件。
- **退補件處理** — 拆解審查意見並指派補正責任與期限。
- **正式送件包** — 依申報順序編排文件並鎖定送件版本。

## 適合誰使用

- 法規承辦人
- 機電工程師
- 專業檢查人

## 運作流程

1. 建立應備清單
2. 分派文件責任
3. 收集申報附件
4. 檢查期限簽章
5. 處理缺件補正
6. 核定正式送件

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
