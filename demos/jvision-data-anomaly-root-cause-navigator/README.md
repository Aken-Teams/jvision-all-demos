**產業別：**數據分析　|　**系統類型：**operations-console

## 功能模組

- **異常事件總覽** — 依影響範圍、嚴重度與持續時間排序品質異常。
- **血緣衝擊導航** — 呈現異常欄位的上下游資產、管線與報表路徑。
- **變更關聯分析** — 比對程式、Schema、規則與排程變更的時間關係。
- **根因候選推演** — 產生可能源頭、傳播機制與信心區間。
- **修復情境模擬** — 預估重跑、回滾或規則調整的效果與副作用。
- **修復導航計畫** — 編排處置順序、責任人與下游驗證範圍。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 選定異常事件
2. 追溯資料血緣
3. 對照近期變更
4. 評估根因候選
5. 模擬修復方案
6. 執行修復導航

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
