# 法規影響與政策模擬台

> 協助政策單位整理法規草案、利害關係人、適用對象與成本效益假設，建立多方案模擬、風險矩陣、公眾意見及審議紀錄，讓法規影響評估從資料蒐集到決策建議皆可追溯與比較。

協助政策單位整理法規草案、利害關係人、適用對象與成本效益假設，建立多方案模擬、風險矩陣、公眾意見及審議紀錄，讓法規影響評估從資料蒐集到決策建議皆可追溯與比較。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **評估案件庫** — 管理法規草案、評估狀態、承辦分工與版本。
- **影響關係圖** — 盤點適用對象、利害關係人及影響傳導路徑。
- **方案與假設** — 設定政策選項、基準情境、參數與資料依據。
- **政策模擬** — 比較各方案對成本、效益、族群及產業的結果。
- **風險評估** — 整理法律、執行、公平及非預期效果的風險矩陣。
- **審議報告** — 彙整模擬、意見、爭點與建議並形成決策摘要。

## 適合誰使用

- 政策分析師
- 法制人員
- 業務機關代表與審議主管

## 運作流程

1. 建立評估案件
2. 盤點影響對象
3. 設定政策方案
4. 執行政策模擬
5. 審查法規風險
6. 形成審議建議

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
