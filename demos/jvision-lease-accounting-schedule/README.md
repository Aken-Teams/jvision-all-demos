# 租賃會計攤銷管理台

> 協助企業彙整辦公室、車輛與設備租約，判定租賃會計處理，建立使用權資產及負債攤銷表，管理利率、租期或租金變更造成的重衡量與傳票覆核。

協助企業彙整辦公室、車輛與設備租約，判定租賃會計處理，建立使用權資產及負債攤銷表，管理利率、租期或租金變更造成的重衡量與傳票覆核。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **租約台帳** — 集中標的、租期、付款條件與選擇權。
- **會計判定** — 記錄適用範圍、豁免理由及判定結果。
- **折現參數** — 設定付款期程、折現率與起租日。
- **攤銷試算** — 產生負債利息與使用權資產攤銷表。
- **租約重衡量** — 模擬租金、期限及終止條件變更影響。
- **傳票覆核** — 產生每期分錄並記錄覆核與過帳狀態。

## 適合誰使用

- 總帳會計
- 財務主管
- 租約承辦人

## 運作流程

1. 登錄租約
2. 完成判定
3. 設定參數
4. 建立攤銷
5. 處理變更
6. 核准傳票

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
