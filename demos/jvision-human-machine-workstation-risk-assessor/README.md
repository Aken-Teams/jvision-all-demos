# 人機工位風險評估器

> 分析人員姿勢、作業節拍與機器動線，找出碰撞風險並改善工位設計。

分析人員姿勢、作業節拍與機器動線，找出碰撞風險並改善工位設計。

**產業別：**生產製造　|　**系統類型：**security-soc

## 功能模組

- **工位動作重建** — 由影像與感測資料重建人員姿勢、站位及移動路徑。
- **機器動線建模** — 描繪機械手臂、治具與搬運設備的運動範圍及時序。
- **人機節拍對齊** — 將人員動作與機器週期對齊，辨識同時進入區域的時刻。
- **碰撞風險熱區** — 依距離、速度與暴露時間標示高風險交會位置。
- **工位改造沙盤** — 模擬護欄、站位、路徑與節拍調整對安全及產能的影響。
- **安全設計評審** — 產出風險差距、改善草案與可供核准的設計證據包。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 建立工位場景
2. 重建人機動線
3. 辨識危險交會
4. 設計改善方案
5. 評審安全產能
6. 核准工位改造

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
