**產業別：**企業協作　|　**系統類型：**collaboration-pm

## 功能模組

- **活動規模規劃** — 定義日期、流程、參加人數、預算與各時段容量需求。
- **場地配置協調** — 比對場地容量、動線、門禁、無障礙與備援空間。
- **餐飲供應安排** — 依人數、飲食限制、供餐節點與保存條件配置餐飲。
- **設備資源調度** — 安排影音、網路、舞台、電力與備用設備的進撤場。
- **賓客名單協同** — 整合報名、貴賓、工作人員與訪客門禁名單。
- **活動應變指揮** — 模擬天候、設備、人流與供應商異常並建立處置方案。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 建立活動藍圖
2. 鎖定場地配置
3. 確認餐飲供應
4. 完成設備調度
5. 整合人員名單
6. 演練應變方案

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
