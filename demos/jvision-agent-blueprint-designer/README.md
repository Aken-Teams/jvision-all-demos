**產業別：**資訊科技　|　**系統類型：**operations-console

## 功能模組

- **目標拆解畫布** — 將業務成果拆成任務範圍、觸發條件與完成定義。
- **Agent 角色設計** — 定義主 Agent、專業子角色及其職責與協作邊界。
- **工具能力配置** — 配置可呼叫工具、必要參數、失敗處理與使用限制。
- **知識範圍編排** — 指定 Agent 可引用的知識域、來源與檢索規則。
- **權限護欄設計** — 設定資料權限、人工核准點與禁止執行的高風險動作。
- **成功條件契約** — 建立品質、時效、成本與安全性等可驗收指標。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 定義業務目標
2. 配置 Agent 角色
3. 選配執行工具
4. 圈定知識範圍
5. 設置權限護欄
6. 簽核成功契約
