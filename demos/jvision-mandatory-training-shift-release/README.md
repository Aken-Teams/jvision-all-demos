# 法定訓練排班放行台

> 依職務與證照規定建立必修訓練，協調主管釋放班次、安排補課與完訓證據，並在資格到期前限制不合格人員上線，兼顧營運人力與合規。

**產業別：**人力資源　|　**系統類型：**education-lms

## 功能模組

- **必修總覽** — 查看人員課程與到期日
- **梯次安排** — 媒合班表與訓練場次
- **代班協調** — 處理釋放人力與補位
- **出席完訓** — 記錄結果與證明文件
- **資格限制** — 標記不得上線的逾期者
- **恢復放行** — 補課後恢復排班資格

## 適合誰使用

- 訓練人員
- 排班主管
- 員工

## 運作流程

1. 辨識到期
2. 安排梯次
3. 協調釋班
4. 確認完訓
5. 限制上線
6. 恢復資格

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
