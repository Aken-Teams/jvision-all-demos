# 能源管理系統（Energy Management System, EMS）

> 碳盤查、能源監控到減碳目標的永續管理

能源管理系統（Energy Management System, EMS）提供能耗即時監控、分區/分設備能耗分析、節能異常告警。廠務依「能耗數據採集 → 分項統計分析 → 異常耗能告警 → 節能對策執行 → 效益驗證追蹤」推進作業，優先解決「能源浪費難以定位」，設備工程則以單位產品能耗與節能達成率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**ESG 永續　|　**系統類型：**ESG 永續 / 能源管理

## 功能模組

- **碳盤查** — 範疇一、二、三排放盤查
- **能源監控** — 用電/用能即時監控
- **減碳目標** — 目標設定與進度追蹤
- **排放源管理** — 排放源清冊與係數庫
- **永續報告** — GRI/ISO 報告產出
- **需量告警** — 用電尖峰即時預警

## 適合誰使用

- 廠務
- 設備工程
- 永續發展部門

## 運作流程

1. 待蒐集
2. 核對中
3. 查證確認
4. 揭露完成

## 導入效益

- 盤查作業工時：41小時 → **8小時**
- 數據完整率：64% → **99%**
- 減碳目標達成：48% → **83%**
- 用能異常反應：24小時 → **2小時**
