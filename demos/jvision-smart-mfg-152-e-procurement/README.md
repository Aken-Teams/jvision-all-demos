# 電子採購平台（e-Procurement）

> 供應商協同、詢比議價到交期風險控管

電子採購平台（e-Procurement）提供線上型錄與商品搜尋、電子請購單與預算檢核、多層級電子簽核。採購部依「線上請購 → 主管簽核 → 比價下單 → 供應商確認 → 驗收入庫」推進作業，優先解決「紙本簽核流程冗長」，資材部則以採購週期天數與電子化採購占比確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**採購供應鏈　|　**系統類型：**SRM 採購供應商管理

## 功能模組

- **供應商管理** — 建檔、分級與績效評分
- **詢報價協作** — 線上詢價、比價與議價
- **採購訂單** — 請購、下單與交期追蹤
- **交期風險** — 缺料預警與到貨監控
- **供應商品質** — 進料檢驗與 SCAR 改善
- **綠色採購** — ESG 評分與永續採購

## 適合誰使用

- 採購部
- 資材部
- 財務部

## 運作流程

1. 待詢價
2. 比價中
3. 待核准
4. 驗收完成

## 導入效益

- 採購前置時間：12天 → **4.9天**
- 準時到貨率：84% → **92%**
- 缺料預警覆蓋：40% → **86%**
- 議價作業工時：7.8小時/週 → **2.1小時/週**
