# 清潔合約履約管理台

> 管理商辦、社區與門市清潔合約的服務範圍、班次、臨時加派、現場驗收及扣款爭議，協助清潔公司統一掌握各案場履約品質、人力缺口與續約風險。

管理商辦、社區與門市清潔合約的服務範圍、班次、臨時加派、現場驗收及扣款爭議，協助清潔公司統一掌握各案場履約品質、人力缺口與續約風險。

**產業別：**生活服務　|　**系統類型：**service-desk

## 功能模組

- **合約範圍** — 維護案場、頻率與服務標準
- **班次配置** — 安排人員與每日清潔區域
- **臨時加派** — 估價並追蹤額外服務需求
- **現場驗收** — 記錄完成結果與客戶評語
- **缺失改善** — 指派重作與確認改善期限
- **履約分析** — 比較品質、成本與續約風險

## 適合誰使用

- 區域督導
- 案場領班
- 業務主管

## 運作流程

1. 確認合約任務
2. 配置服務班次
3. 處理臨時加派
4. 提交現場驗收
5. 追蹤缺失改善
6. 檢討履約績效

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
