# 模具外修報價驗收台

> 供模具送修時逐項列出損傷、零件與尺寸要求，保留原報價、追加核准、返廠量測及試模結果，未通過驗收不得付款並追蹤返修保固。

供模具送修時逐項列出損傷、零件與尺寸要求，保留原報價、追加核准、返廠量測及試模結果，未通過驗收不得付款並追蹤返修保固。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **送修項目** — 記錄損傷與要求
- **報價比對** — 比較工項零件費
- **追加簽核** — 管制新增費用
- **返廠量測** — 逐項檢查尺寸
- **試模驗收** — 確認修復效果
- **付款保固** — 合格後核銷追保

## 適合誰使用

- 模具工程師
- 採購人員

## 運作流程

1. 故障判定
2. 廠商報價
3. 核准送修
4. 返廠檢查
5. 上機試模
6. 驗收付款

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
