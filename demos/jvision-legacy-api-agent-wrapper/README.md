# Legacy API 自動包裝器

> 從舊 API 文件與實際流量，自動產生可發現、可授權及可測試的 Agent 工具介面。

從舊 API 文件與實際流量，自動產生可發現、可授權及可測試的 Agent 工具介面。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **舊 API 文件解析** — 解析 OpenAPI、WSDL、PDF 與維運手冊，辨識端點、參數及
- **呼叫流量反推** — 從實際呼叫軌跡推斷未記載的操作模式、欄位關係與前置條件。
- **工具語意定義** — 將技術端點整理為 Agent 可理解的工具名稱、用途與輸入輸出描述。
- **Schema 正規化** — 統一舊系統的欄位型別、列舉值、錯誤格式與資料結構。
- **授權護欄配置** — 為讀取、寫入及敏感操作設定 IAM 權限、憑證範圍與核准門檻。
- **MCP 包裝發布** — 執行契約測試後產生 MCP／Skill 定義，發布至 Agent 能

## 適合誰使用

## 運作流程

1. 匯入舊制來源
2. 還原端點行為
3. 編排工具介面
4. 校正資料契約
5. 核定存取邊界
6. 驗證並發布
