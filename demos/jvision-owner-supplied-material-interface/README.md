# 業主供料界面協調台

> 管理業主供應設備與材料的選型凍結、採購交期、到場保管及承商安裝界面，清楚標示供料延誤對施工面的影響與待決事項，避免責任邊界模糊造成待工索賠。

管理業主供應設備與材料的選型凍結、採購交期、到場保管及承商安裝界面，清楚標示供料延誤對施工面的影響與待決事項，避免責任邊界模糊造成待工索賠。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **供料清冊** — 管理品項、供應責任、數量與安裝區位。
- **選型凍結** — 追蹤型號、尺寸、色樣與最晚核定日。
- **交期里程碑** — 管理下單、生產、出貨及預定到場日期。
- **安裝界面** — 確認預留孔、電力、給排水與固定條件。
- **到貨保管** — 登錄點收、缺損、保管位置及移交狀態。
- **延誤影響** — 呈現受影響工序、待工天數與責任通知。

## 適合誰使用

- 業主專案代表
- 機電工程師
- 工地主任

## 運作流程

1. 建立供料清冊
2. 完成選型凍結
3. 追蹤採購交期
4. 檢核安裝界面
5. 辦理到貨移交
6. 處理延誤影響

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
