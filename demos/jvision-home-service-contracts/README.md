**產業別：**生活服務　|　**系統類型：**service-desk

## 功能模組

- **合約台帳** — 管理服務範圍與頻率
- **週期任務** — 產生據點服務排程
- **資格派員** — 依技能與限制配置人員
- **改期補班** — 追蹤取消與補作安排
- **追加服務** — 登錄合約外需求費用
- **月度驗收** — 彙整履約證據及簽核

## 適合誰使用

- 營運調度員
- 現場督導
- 合約專員

## 運作流程

1. 建立合約
2. 產生任務
3. 配置人員
4. 處理異動
5. 確認追加
6. 完成驗收

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
