# 檢驗委外費用核對台

> 逐檢體比對送驗、取消、重送、報告與委外廠商帳單，依生效合約價檢查重複及錯價，提供科室確認與財務付款的完整證據。

逐檢體比對送驗、取消、重送、報告與委外廠商帳單，依生效合約價檢查重複及錯價，提供科室確認與財務付款的完整證據。

**產業別：**醫療照護　|　**系統類型：**finance-case

## 功能模組

- **送驗明細** — 整理檢體項目與狀態
- **廠商帳單** — 匯入逐項費用資料
- **合約價格** — 管理項目費率與效期
- **逐筆勾稽** — 找出取消重複與漏單
- **帳務疑義** — 與科室廠商往返確認
- **付款覆核** — 核定可付及扣款金額

## 適合誰使用

- 檢驗科承辦
- 醫療會計
- 採購合約管理員

## 運作流程

1. 彙整送驗紀錄
2. 匯入廠商帳單
3. 套用有效合約
4. 執行逐檢體比對
5. 處理帳務疑義
6. 核定付款結案

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
