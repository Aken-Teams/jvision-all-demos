# 烤爐燃燒器保養台

> 供食品烘焙廠依烤爐區段記錄點火、火焰、爐溫偏差與燃燒器清潔校正，安排避開生產的保養窗口，修後以空爐測溫確認。

供食品烘焙廠依烤爐區段記錄點火、火焰、爐溫偏差與燃燒器清潔校正，安排避開生產的保養窗口，修後以空爐測溫確認。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **烤爐總覽** — 查看區段健康
- **火焰巡查** — 登錄點火燃燒
- **溫差紀錄** — 比較各區爐溫
- **保養窗口** — 避開生產排程
- **燃燒器保養** — 記錄清潔校正
- **空爐驗收** — 確認溫度均勻

## 適合誰使用

- 烤爐操作員
- 設備技師

## 運作流程

1. 班前巡查
2. 異常建單
3. 安排停爐
4. 清潔校正
5. 空爐測溫
6. 量產放行

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
