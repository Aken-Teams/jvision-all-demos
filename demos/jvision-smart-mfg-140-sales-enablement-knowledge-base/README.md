# 業務知識庫與教育訓練 Sales Enablement/Knowledge Base協作所

集中管理產品規格、應用案例、話術範本與競品資訊，並提供業務新人教育訓練資源。

- 原始系統：業務知識庫與教育訓練 Sales Enablement/Knowledge Base
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、產品部、人資部、業務主管
- 工作流程：內容彙整建檔→分類上架知識庫→業務查詢或訓練學習→定期更新內容→成效追蹤評估
- AI 應用：智慧問答檢索（Chatbot）、個人化學習內容推薦
- 主要 KPI：新人上手時間、知識庫使用率、話術一致性評分、訓練完成率
- 代表產品：Highspot、Seismic、SharePoint知識庫
