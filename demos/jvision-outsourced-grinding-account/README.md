# 機加工外發研磨對帳台

> 供CNC工廠按料框與工序記錄外發研磨前尺寸、件數、交期及加工單價，處理分批回貨、不良重磨與短少，僅以驗收合格數核付費用。

供CNC工廠按料框與工序記錄外發研磨前尺寸、件數、交期及加工單價，處理分批回貨、不良重磨與短少，僅以驗收合格數核付費用。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **研磨送出** — 記錄尺寸件數
- **在外進度** — 追蹤承諾交期
- **分批回貨** — 逐框核銷數量
- **尺寸驗收** — 判定加工結果
- **重磨往返** — 追蹤不良再加工
- **合格結算** — 依驗收數付款

## 適合誰使用

- 外發管理員
- 製程品管

## 運作流程

1. 外發備料
2. 廠商點交
3. 加工追蹤
4. 分批收料
5. 尺寸驗收
6. 費用核銷

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
