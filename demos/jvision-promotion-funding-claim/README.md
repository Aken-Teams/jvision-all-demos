# 促銷檔期費用請款台

> 將供應商促銷贊助條件轉成可計算規則，匯整活動銷售、門檻、上限與分攤比例，產出請款底稿並追蹤憑證及到期日，避免漏請、重請與少收。

**產業別：**零售電商　|　**系統類型：**finance-case

## 功能模組

- **檔期建檔** — 登錄活動與供應商條件
- **條件規則** — 設定門檻上限分攤方式
- **實績彙整** — 檢視銷售與達標結果
- **費用試算** — 計算各方應負擔金額
- **請款底稿** — 產出明細與佐證清單
- **收款追蹤** — 追蹤開票、折讓與入帳

## 適合誰使用

- 採購人員
- 行銷人員
- 應收會計

## 運作流程

1. 建立檔期
2. 確認條件
3. 匯整實績
4. 試算費用
5. 提出請款
6. 核銷收款

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
