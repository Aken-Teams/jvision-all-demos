# 員工系統權限控管台

> 以身分與存取管理概念集中呈現員工帳號、角色、應用系統權限、申請簽核及定期覆核，協助企業落實最小權限與離職停權，清楚追蹤誰在何時因何原因取得哪些系統操作資格。

以身分與存取管理概念集中呈現員工帳號、角色、應用系統權限、申請簽核及定期覆核，協助企業落實最小權限與離職停權，清楚追蹤誰在何時因何原因取得哪些系統操作資格。

**產業別：**資訊安全　|　**系統類型：**security-soc

## 功能模組

- **身分帳號總覽** — 查看員工帳號、任職部門、啟用狀態與登入風險標記。
- **角色權限設計** — 建立職務角色並配置各應用系統的功能與資料範圍。
- **存取申請中心** — 提出新增、變更或移除權限申請並呈現簽核路徑。
- **應用權限矩陣** — 交叉檢視人員、角色、系統及權限層級的授權關係。
- **定期權限覆核** — 依部門或系統批次確認權限保留、調整及收回決定。
- **異動稽核軌跡** — 查詢帳號與權限的申請、核准、執行及覆核歷程。

## 適合誰使用

- 資訊管理員
- 資安人員
- 部門主管
- 人力資源人員

## 運作流程

1. 檢視員工身分
2. 建立職務角色
3. 提出權限申請
4. 審查授權關係
5. 執行定期覆核
6. 查驗異動軌跡
