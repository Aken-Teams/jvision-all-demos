> 協助手術室將排程個案、備用耗材、實際使用與退回品項逐案核對，標記自費同意、健保申報及批號紀錄缺口，降低漏計價、錯計價與術後補登負擔。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **手術清單** — 依日期、術式與主治醫師整理待處理個案。
- **耗材備套** — 建立標準備套及個案追加耗材清單。
- **使用登錄** — 區分已使用、已拆未用、植入及退回。
- **同意核對** — 確認自費品項與同意文件是否一致。
- **申報檢查** — 檢查計價類別、數量與必要紀錄缺口。
- **個案結算** — 彙總應計價項目並提交帳務確認。

## 適合誰使用

- 手術室護理師
- 醫材管理員
- 醫務帳務員

## 運作流程

1. 選取個案
2. 建立備套
3. 登錄使用
4. 核對同意
5. 檢查申報
6. 完成計價

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
