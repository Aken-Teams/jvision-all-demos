# 鋼筋續接器抽驗台

> 依續接器進場批號與施工位置建立抽驗計畫，串接取樣、試體封籤、送驗、報告判讀及不合格批次處置，避免報告未回或批號不明時誤放行後續施工。

依續接器進場批號與施工位置建立抽驗計畫，串接取樣、試體封籤、送驗、報告判讀及不合格批次處置，避免報告未回或批號不明時誤放行後續施工。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **抽驗看板** — 查看各批次抽驗與放行狀態。
- **批號建檔** — 登錄材料批號、數量與使用位置。
- **取樣封籤** — 編列試體並記錄見證取樣資訊。
- **送驗追蹤** — 管理實驗室送件及預計回報日。
- **報告判讀** — 登錄強度結果與合格判定。
- **批次處置** — 管制不合格範圍、複驗與解禁。

## 適合誰使用

- 品管工程師
- 現場工程師
- 監造人員

## 運作流程

1. 盤點待驗批次
2. 建立材料履歷
3. 執行見證取樣
4. 追蹤試驗進度
5. 判讀試驗結果
6. 完成處置放行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
