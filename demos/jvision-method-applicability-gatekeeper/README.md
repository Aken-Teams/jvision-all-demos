# 方法適用性守門員

> 在實驗執行前核驗基質、量測範圍與偵測極限，防止分析方法誤用。

在實驗執行前核驗基質、量測範圍與偵測極限，防止分析方法誤用。

**產業別：**研發管理　|　**系統類型：**quality-qms

## 功能模組

- **待審方法佇列** — 集中顯示即將使用的方法、樣品類型與適用性風險。
- **樣品基質比對** — 比對方法驗證基質與實際樣品成分，找出干擾與缺口。
- **量測範圍核驗** — 檢查預期濃度是否落在校正範圍及已驗證區間內。
- **偵測極限檢查** — 核對 LOD、LOQ 與報告門檻是否符合實驗目的。
- **適用性缺口包** — 彙整文件與系統間的矛盾、缺證及引用來源。
- **方法放行決策** — 產生可用、限用或禁用建議，並列出必要前置條件。

## 適合誰使用

- 實驗室主管
- 研究員
- 技術員

## 運作流程

1. 提出方法使用案
2. 比對基質條件
3. 核驗量測範圍
4. 檢查偵測能力
5. 審閱缺口證據
6. 核准方法用途

## 導入效益

- 設計變更工時：8小時 → **2小時**
- 文件版本錯誤：6件/月 → **1件/月**
- 專案準時率：70% → **92%**
- 資料查找時間：30分鐘 → **5分鐘**
