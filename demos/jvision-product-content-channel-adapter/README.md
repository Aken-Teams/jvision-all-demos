# 商品內容產製與通路適配台

> 集中管理商品賣點、規格、圖片文案與品牌語氣，將同一份擬真商品資料轉成官網、市集及社群所需格式，協助內容團隊檢查欄位完整度、禁用詞與字數限制，完成多人審稿及版本交付。

集中管理商品賣點、規格、圖片文案與品牌語氣，將同一份擬真商品資料轉成官網、市集及社群所需格式，協助內容團隊檢查欄位完整度、禁用詞與字數限制，完成多人審稿及版本交付。

**產業別：**零售電商　|　**系統類型：**collaboration-pm

## 功能模組

- **商品素材主檔** — 集中檢視商品規格、賣點、受眾、圖片標記與來源版本。
- **內容產製工作室** — 依商品素材產生標題、短文案、長描述與特色條列草稿。
- **通路格式適配** — 切換官網與不同市集範本，對照必要欄位及字數規範。
- **內容品質檢查** — 標示規格矛盾、敏感用語、禁用詞、超字與缺漏欄位。
- **多人審稿中心** — 以批註、修訂差異與簽核狀態完成品牌及通路審閱。
- **上架內容交付** — 彙整核准版本、素材清單與欄位對照，產生模擬交付包。

## 適合誰使用

- 商品企劃
- 內容編輯
- 電商通路營運人員

## 運作流程

1. 建立商品素材
2. 產出內容草稿
3. 轉換通路格式
4. 執行品質檢查
5. 完成多人審稿
6. 交付上架內容
