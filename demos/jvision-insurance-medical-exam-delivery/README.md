## 功能模組

- **體檢需求** — 列出要保件與檢查項目
- **院所派送** — 配置合作院所及窗口
- **預約追蹤** — 管理客戶預約與改期
- **項目查驗** — 核對實做及缺漏項目
- **報告收件** — 追蹤寄送對象與頁數
- **核保交付** — 送交完整體檢證據包

## 適合誰使用

- 保險業務
- 體檢行政
- 核保助理

## 運作流程

1. 建立體檢需求
2. 安排合作院所
3. 完成客戶預約
4. 查驗實做項目
5. 收齊體檢報告
6. 交付核保清件

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
