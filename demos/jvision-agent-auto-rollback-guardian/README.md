# Agent 自動回滾守門員

> 監控 Agent 品質與成本門檻，越界時安全回滾至已驗證的穩定版本。

監控 Agent 品質與成本門檻，越界時安全回滾至已驗證的穩定版本。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **版本健康監控** — 即時追蹤各 Agent 版本的成功率、延遲、品質與成本指標。
- **回滾門檻設定** — 依流程風險設定品質下降、成本暴增與連續失敗的觸發條件。
- **越界因果診斷** — 比對任務軌跡與工具呼叫，排序最可能造成異常的版本變更。
- **穩定版本切換** — 產生回滾計畫並透過核准工具將流量切回指定穩定版本。
- **回滾結果驗證** — 以探針任務確認品質、成本與權限行為均已恢復正常。
- **故障處置中心** — 集中呈現回滾事件、人工接管項目與縮短故障時間的成效。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 監看版本健康
2. 定義守門條件
3. 診斷越界原因
4. 核准回滾方案
5. 驗證恢復狀態
6. 結案與回報

## 導入效益

- 事件平均處理：120分鐘 → **30分鐘**
- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
- 資產盤點工時：20小時/月 → **4小時/月**
