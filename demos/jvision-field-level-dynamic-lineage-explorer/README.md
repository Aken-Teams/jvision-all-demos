# 欄位級動態血緣探索器

> 從查詢與資料管線重建欄位流向，精準追溯來源、轉換與下游影響。

從查詢與資料管線重建欄位流向，精準追溯來源、轉換與下游影響。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **欄位血緣地圖** — 逐欄呈現來源、轉換節點與下游消費關係。
- **查詢解析工作台** — 解析 SQL、檢視表與運算式中的欄位映射。
- **管線轉換追蹤** — 辨識 ETL 步驟中的重新命名、合併、拆分與計算。
- **血緣缺口偵測** — 標示無法解析、來源衝突或映射中斷的路徑。
- **欄位影響分析** — 模擬 Schema 或邏輯變更對報表、模型及介面的影響。
- **血緣校正佇列** — 審核低信心映射並發布經確認的欄位關係。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 選定目標欄位
2. 解析相關查詢
3. 重建管線流向
4. 處理血緣缺口
5. 評估下游影響
6. 校正並發布
