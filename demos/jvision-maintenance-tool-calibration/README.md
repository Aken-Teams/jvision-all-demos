# 維修量具校驗到期管制台

> 供維修部門管理扭力扳手、電表、壓力計等作業量具的領用、校驗週期、送校、結果判定與失準影響範圍，避免使用逾期量具並快速找出可能受影響的維修工單。

供維修部門管理扭力扳手、電表、壓力計等作業量具的領用、校驗週期、送校、結果判定與失準影響範圍，避免使用逾期量具並快速找出可能受影響的維修工單。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **量具台帳** — 管理規格、編號、位置與責任人。
- **校驗排程** — 依週期產生到期與預警清單。
- **送校批次** — 整理外校、內校與暫停使用狀態。
- **結果登錄** — 保存數值、證書及合否判定。
- **影響追溯** — 找出失準期間使用過的工單。
- **使用管制** — 封鎖逾期或不合格量具。

## 適合誰使用

- 維修工程師
- 量具管理員
- 維護主管

## 運作流程

1. 建立量具
2. 產生到期
3. 停止領用
4. 執行送校
5. 判定結果
6. 追溯影響

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
