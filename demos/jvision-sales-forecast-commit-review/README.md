# 業務預估承諾校準台

> 在週會前要求業務以客戶事件、決策人、預算與下一步證據更新成交預估，由主管挑戰承諾日期及金額，保存調整原因並比較預估偏差。

**產業別：**業務銷售　|　**系統類型：**sales-crm

## 功能模組

- **預估總覽** — 查看承諾最佳及漏斗
- **證據更新** — 填寫客戶事件與下一步
- **承諾提交** — 申報金額及預計成交日
- **主管挑戰** — 記錄風險問題與調整
- **週版鎖定** — 封存會議核定預估
- **偏差回顧** — 比較承諾與實際結果

## 適合誰使用

- 業務人員
- 業務主管
- 營運主管

## 運作流程

1. 更新證據
2. 提交承諾
3. 檢查風險
4. 校準預估
5. 鎖定週版
6. 回顧偏差

- 商機轉換率：18% → **27%**
- 平均回應時間：26小時 → **6小時**
- 客戶資料完整率：62% → **94%**
