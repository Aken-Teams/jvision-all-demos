# 勒索攻擊預警隔離協調台

> 從模擬的檔案異動、帳號行為與端點訊號辨識勒索攻擊前兆，呈現擴散範圍並協調隔離、通報、備份確認及復原決策，讓工廠在停線前完成應變。

## 功能模組

- **勒索前兆雷達** — 呈現大量改檔、可疑工具、權限提升與備份停用等早期訊號。
- **擴散路徑沙盤** — 以資產關聯圖模擬攻擊可能橫向移動及影響的系統。
- **隔離方案模擬** — 比較隔離帳號、端點、網段或共享資料夾的營運影響。
- **應變協調室** — 依事件等級建立資訊、廠務、法務與主管的處置任務。
- **備份復原盤點** — 檢視模擬備份版本、完整性、復原順序與預估復原時間。
- **事件時間線報告** — 整理前兆、決策、任務與復原里程碑，形成檢討報告。

## 適合誰使用

- 資訊主管
- 資安人員
- 廠務主管
- 營運持續管理人員

## 運作流程

1. 辨識前兆
2. 推演擴散
3. 選擇隔離
4. 啟動協調
5. 安排復原
6. 完成檢討

## 導入效益

- 告警分流時間：45分鐘 → **8分鐘**
- 事件平均處理：12小時 → **3小時**
- 弱點修補率：68% → **96%**
- 合規稽核工時：30小時/月 → **6小時/月**
