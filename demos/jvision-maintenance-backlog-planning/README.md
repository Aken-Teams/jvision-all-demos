# 維修積壓治理工作台

> 協助維修主管清理長期未結工單，依安全、產能、料件、人力與停機窗口重新排序，辨識殭屍工單、合併重複需求並建立可執行的週排程承諾。

協助維修主管清理長期未結工單，依安全、產能、料件、人力與停機窗口重新排序，辨識殭屍工單、合併重複需求並建立可執行的週排程承諾。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **積壓剖面** — 依廠區設備與齡期分析
- **工單清理** — 合併重複並關閉失效需求
- **風險排序** — 評估安全、產能與惡化程度
- **準備度檢核** — 確認料件、工具與技術文件
- **週排程板** — 依人力窗口建立執行承諾
- **落差檢討** — 分析跳票原因及積壓變化

## 適合誰使用

- 維修主管
- 計畫工程師
- 設備工程師

## 運作流程

1. 盤點積壓
2. 清理工單
3. 風險評分
4. 確認準備
5. 承諾排程
6. 檢討落差

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
