**產業別：**資訊科技　|　**系統類型：**analytics-bi

## 功能模組

- **交付旅程圖** — 還原需求到部署各階段的實際流動路徑。
- **等待時間剖析** — 定位審查、測試、環境與核准造成的排隊時間。
- **重跑成本分析** — 統計建置與測試重跑原因及耗用工時。
- **工具切換熱區** — 辨識跨 Git、Jira、CI 與通訊工具的頻繁切換。
- **摩擦因果圖** — 連結流程摩擦、團隊負荷與交付延遲的因果線索。
- **改善實驗台** — 建立改善草案、預估效益並追蹤核准後成果。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 還原旅程
2. 量測等待
3. 拆解重跑
4. 盤點切換
5. 判讀摩擦
6. 執行實驗

## 導入效益

- 事件平均處理：120分鐘 → **30分鐘**
- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
- 資產盤點工時：20小時/月 → **4小時/月**
