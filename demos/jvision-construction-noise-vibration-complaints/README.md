# 工地噪振陳情處理台

> 集中受理住戶、里長與主管機關轉入的噪音振動陳情，將時間、門牌、施工工項及回應承諾串接，協助現場交班、辨識重複案件並追蹤改善與回覆期限。

集中受理住戶、里長與主管機關轉入的噪音振動陳情，將時間、門牌、施工工項及回應承諾串接，協助現場交班、辨識重複案件並追蹤改善與回覆期限。

**產業別：**營建工程　|　**系統類型：**service-desk

## 功能模組

- **陳情受理** — 登錄來源、聯絡方式、時間、門牌與反映內容。
- **熱點分布** — 依工地周界與鄰近門牌呈現陳情集中位置。
- **施工比對** — 核對陳情時段的工項、機具與責任班組。
- **改善派辦** — 指派降噪、調整工法、巡查或住戶溝通任務。
- **回覆承諾** — 保存回覆內容、承諾日期與聯繫結果。
- **陳情趨勢** — 分析時段、工項、區域及重複陳情原因。

## 適合誰使用

- 工地行政
- 環安人員
- 工地主任

## 運作流程

1. 受理陳情案件
2. 比對施工活動
3. 執行現場查核
4. 派辦改善措施
5. 回覆陳情結果
6. 檢討重複熱點

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
