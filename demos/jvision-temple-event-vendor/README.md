> 協助宮廟管理遶境與慶典期間的攤商申請、品項審查、區位配置、費用收取、進撤場及違規紀錄，在有限場地內兼顧動線、安全與公平分配。

**產業別：**宗教服務　|　**系統類型：**operations-console

## 功能模組

- **攤商申請** — 登錄資格與販售品項
- **品項審查** — 檢查禁限售及文件
- **攤位配置** — 安排區位與通行動線
- **費用收取** — 追蹤租金與保證金
- **進撤場管理** — 安排時段及車輛順序
- **現場稽查** — 記錄占位與安全違規

## 適合誰使用

- 廟務行政
- 活動總務
- 現場管理員

## 運作流程

1. 受理申請
2. 審核資格
3. 配置攤位
4. 完成收費
5. 安排進場
6. 執行稽查
