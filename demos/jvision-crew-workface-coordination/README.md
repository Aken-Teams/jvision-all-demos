# 工班出工界面協調台

> 依樓層、區域與工序協調各工班出工，先確認圖料、人力、機具及工作面條件，並處理撞期與臨時變動，降低到場待工和工序干擾。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **出工看板** — 檢視各區工班安排
- **人力申報** — 登錄班組與預計人數
- **條件確認** — 核對工作面前置事項
- **衝突協調** — 處理同區同時段撞期
- **變更通知** — 同步延期與改派資訊
- **待工分析** — 統計無效出工原因

## 適合誰使用

- 工地主任
- 工務工程師
- 分包領班

## 運作流程

1. 申報出工
2. 檢查工作面
3. 辨識衝突
4. 協調排程
5. 到場確認
6. 檢討待工

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
