# 公共工程送審排程台

> 依公共工程契約、品質計畫與預定進度，建立施工計畫、材料設備、樣品及試驗文件的應送審節點，反推編製、內審與監造審查時間，揭露退件對採購及開工面的影響，避免送審晚於施工需求。

依公共工程契約、品質計畫與預定進度，建立施工計畫、材料設備、樣品及試驗文件的應送審節點，反推編製、內審與監造審查時間，揭露退件對採購及開工面的影響，避免送審晚於施工需求。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **送審架構** — 依契約、章節、工項與文件類型建立送審清單。
- **反推排程** — 從核定需求日回推編製、內審與監造審查期限。
- **送審包編製** — 彙整主文、附件、版次與關聯規範。
- **審查輪次** — 追蹤送出、退件、修正與核定歷程。
- **工期影響** — 呈現未核定文件所阻擋的採購與施工節點。
- **瓶頸分析** — 分析退件來源、審查天數與承辦負荷。

## 適合誰使用

- 文件管制工程師
- 施工計畫工程師
- 進度工程師

## 運作流程

1. 建立應送審項目
2. 反推核定期限
3. 編製送審文件
4. 完成內部審核
5. 處理審查意見
6. 更新影響排程

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
