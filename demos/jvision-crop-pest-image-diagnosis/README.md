# 作物病蟲害影像診斷防治助手

> 透過預載的作物葉片、果實與害蟲影像，模擬辨識可能病蟲害、嚴重程度及相似症狀，提供田間複查重點與分級防治建議，協助農場建立一致的巡田判斷紀錄。

透過預載的作物葉片、果實與害蟲影像，模擬辨識可能病蟲害、嚴重程度及相似症狀，提供田間複查重點與分級防治建議，協助農場建立一致的巡田判斷紀錄。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **病蟲害風險總覽** — 呈現田區風險、待複查案件與近期發生趨勢。
- **巡田影像案件** — 從預載影像建立作物、田區與症狀案件。
- **影像診斷結果** — 顯示候選病蟲害、標記區域及模擬信心程度。
- **相似症狀比對** — 並排比較易混淆症狀與關鍵辨識特徵。
- **田間複查紀錄** — 記錄實地觀察、影響範圍與人工確認結論。
- **防治追蹤計畫** — 提供分級處置建議並追蹤後續改善情形。

## 適合誰使用

- 農場管理者
- 植保人員
- 巡田技術員

## 運作流程

1. 掌握病蟲風險
2. 建立影像案件
3. 檢視診斷結果
4. 比對相似症狀
5. 完成田間複查
6. 安排防治追蹤

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
