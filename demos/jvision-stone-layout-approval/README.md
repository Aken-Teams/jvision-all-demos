# 石材排版核准追蹤台

> 集中管理石材批次照片、紋理排版圖、區域編號與核准意見，清楚區分送審、退修及定版內容；工廠加工與現場鋪貼前皆能核對核准排版，降低紋理錯置與整批重排成本。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **排版案件** — 依立面、空間與石材批次建立排版任務。
- **板材影像** — 整理單片照片、紋理方向、尺寸與瑕疵標記。
- **編排工作區** — 模擬板片順序並對應區域及安裝編號。
- **圈註審查** — 集中記錄設計意見、退修原因與回覆。
- **定版發布** — 鎖定核准版本並產生加工用排版清單。
- **現場核對** — 依安裝編號確認到料與實際鋪貼位置。

## 適合誰使用

- 建築設計師
- 石材工程師
- 加工廠窗口

## 運作流程

1. 建立排版範圍
2. 上傳板材影像
3. 編製排版方案
4. 執行設計審查
5. 發布核准版本
6. 核對現場鋪貼

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
