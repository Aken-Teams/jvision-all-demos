# 站點滯留貨清理台

> 盤點問題貨籠內逾時未轉運貨件，依標籤、外觀、末次掃描及路由線索建立認領與處置任務，防止跨班遺忘、誤裝車和長期占用異常區。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **滯留盤點** — 查看問題區貨件與天數
- **身分辨識** — 整理標籤外觀與掃描線索
- **路由追查** — 還原來源目的與末次事件
- **認領分派** — 交由相關站點或客戶確認
- **處置決策** — 選擇轉運退回理賠報失
- **清區結案** — 確認實物離區與系統更新

## 適合誰使用

- 站所理貨員
- 異常件專員
- 站所主管

## 運作流程

1. 盤點貨件
2. 辨識身分
3. 追查路由
4. 發出認領
5. 核定處置
6. 移出結案

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
