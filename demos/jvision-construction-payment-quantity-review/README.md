# 工程估驗計價協作台

> 依合約項目、現場完成數量、查驗證據與保留款規則，協作分包商申報、工地初審、監造複核及爭議調整，形成每期可計價明細。

依合約項目、現場完成數量、查驗證據與保留款規則，協作分包商申報、工地初審、監造複核及爭議調整，形成每期可計價明細。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **本期申報** — 按合約項目登錄數量與申報金額。
- **完成證據** — 關聯查驗、照片、測量及進度資料。
- **數量核對** — 比較申報量、核定量與累計上限。
- **金額試算** — 套用單價、保留款、代扣及加減帳。
- **爭議協調** — 逐項記錄差異理由與協議數量。
- **估驗核定** — 產出本期核定明細與簽核紀錄。

## 適合誰使用

- 工務工程師
- 成本控制人員
- 分包商計價員

## 運作流程

1. 提交申報
2. 核對現場
3. 審查數量
4. 試算金額
5. 處理爭議
6. 核定送付

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
