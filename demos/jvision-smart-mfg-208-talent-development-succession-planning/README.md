# 人才發展與繼任計畫智慧站

針對關鍵技術職位與幹部職缺，規劃人才梯隊與接班培育計畫，降低關鍵人力斷層風險。

- 原始系統：人才發展與繼任計畫系統（Talent Development & Succession Planning）
- 產業分類：智慧製造｜人資管理
- 使用部門：人資部、高階經營層、各廠區處長級主管
- 工作流程：關鍵職位盤點 → 候選人評估 → 九宮格定位 → 發展計畫擬定 → 導師輔導 → 繼任準備度追蹤
- AI 應用：高潛力人才預測模型、繼任準備度自動評分
- 主要 KPI：關鍵職位繼任覆蓋率、高潛人才留任率、發展計畫完成率
- 代表產品：SAP SuccessFactors Succession、Cornerstone OnDemand、104人資King人才發展模組
