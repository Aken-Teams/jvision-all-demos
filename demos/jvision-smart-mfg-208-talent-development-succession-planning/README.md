# 人才發展與繼任計畫系統（Talent Development & Succession Planning）

> 出勤、薪資、招募到績效的人資全流程

人才發展與繼任計畫系統（Talent Development & Succession Planning）提供關鍵職位盤點與風險評估、高潛力人才九宮格分析、個人發展計畫（IDP）追蹤。人資部依「關鍵職位盤點 → 候選人評估 → 九宮格定位 → 發展計畫擬定 → 導師輔導 → 繼任準備度追蹤」推進作業，優先解決「資深技術幹部退休斷層風險」，高階經營層則以關鍵職位繼任覆蓋率與高潛人才留任率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**HRIS 人力資源系統

## 功能模組

- **出勤差勤** — 打卡、請假與加班
- **薪資計算** — 薪資、勞健保與報稅
- **排班管理** — 智慧排班與工時控管
- **招募任用** — 職缺、面試與報到
- **教育訓練** — 課程、證照與紀錄
- **績效考核** — 目標設定與考核流程

## 適合誰使用

- 人資部
- 高階經營層
- 各廠區處長級主管

## 運作流程

1. 待處理
2. 主管確認
3. 人資執行
4. 歸檔完成

## 導入效益

- 薪資作業工時：42小時/月 → **7.8小時/月**
- 出勤異常處理：31分鐘 → **4.8分鐘**
- 招募到位天數：45天 → **26天**
- 表單簽核時效：2.9天 → **1.1天**
