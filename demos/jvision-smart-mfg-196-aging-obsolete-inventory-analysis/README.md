# 庫齡呆滯料分析系統（Aging & Obsolete Inventory Analysis）

> 收貨到出貨的倉內作業與庫存精準管理

庫齡呆滯料分析系統（Aging & Obsolete Inventory Analysis）提供庫齡區間自動分類、呆滯料預警與清單產出、呆滯料處置建議(調撥/促銷/報廢)。倉儲部依「庫齡自動計算→呆滯門檻判定→預警通報→處置方案評估→執行處置→效益追蹤」推進作業，優先解決「呆滯料長期積壓占用資金」，財務部則以呆滯料金額占比與庫齡結構分布確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**倉儲物流　|　**系統類型：**WMS 倉儲管理系統

## 功能模組

- **入庫上架** — 收貨、驗收與智慧上架
- **揀貨出貨** — 波次揀貨、覆核與出貨
- **儲位管理** — 儲位規劃與庫容視覺化
- **庫存盤點** — 即時庫存、盤點與調撥
- **拉動補料** — 安全庫存與自動補貨
- **條碼作業** — PDA 掃碼即時作業

## 適合誰使用

- 倉儲部
- 財務部
- 採購部

## 運作流程

1. 待上架
2. 銷售中
3. 複核確認
4. 出庫完成

## 導入效益

- 揀貨作業工時：6.9小時/日 → **2.1小時/日**
- 庫存準確率：88% → **99%**
- 出貨延遲率：9.2% → **1.9%**
- 盤點工時：17小時/月 → **2.9小時/月**
