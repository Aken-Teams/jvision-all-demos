# Agent 商業 KPI 歸因器

把 Agent 行為連結至節時、轉換與損失避免成果，量化實際投資回報。

**產業別：**資訊科技　|　**系統類型：**analytics-bi

## 功能模組

- **成果指標建模** — 定義節省工時、轉換提升、損失避免與成本等衡量口徑。
- **行為成果鏈** — 串連 Agent 步驟、工具呼叫、人工介入與最終業務事件。
- **基準組比較** — 以人工流程、歷史期間或未啟用群組建立可比較基準。
- **增量效果估算** — 排除季節性與共同因素，估算 Agent 對 KPI 的增量貢獻。
- **效益成本核算** — 合併模型、工具、人工覆核成本並計算淨效益與回收期。
- **歸因結論簽核** — 呈現可信區間與限制，供業務及財務共同確認 ROI。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 設定成果口徑
2. 串接行為成果
3. 建立比較基準
4. 估算增量貢獻
5. 核算投資回報
6. 簽核歸因結論
