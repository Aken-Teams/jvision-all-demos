# 新進員工個人化上手助理

> 依職務、廠區、班別與既有經驗，為新進員工安排個人化報到任務、學習內容、關係人與階段檢核；主管可從模擬進度及卡關訊號提早介入，縮短獨立作業時間。

依職務、廠區、班別與既有經驗，為新進員工安排個人化報到任務、學習內容、關係人與階段檢核；主管可從模擬進度及卡關訊號提早介入，縮短獨立作業時間。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **新人今日首頁** — 集中顯示今日任務、重要提醒、推薦內容與求助入口。
- **個人上手路徑** — 依角色與經驗呈現首日、首週及前三十日計畫。
- **報到任務中心** — 管理文件、制度、帳號申請及部門交接等模擬任務。
- **職務知識導航** — 以情境分類提供流程、術語、常見問題與學習卡。
- **關係人地圖** — 說明主管、帶教夥伴及協作窗口的職責與聯繫情境。
- **階段檢核與介入** — 呈現能力檢核、卡關訊號、主管回饋與介入建議。

## 適合誰使用

- 新進員工
- 直屬主管
- 人資專員
- 帶教人員

## 運作流程

1. 開始今日任務
2. 確認上手路徑
3. 完成報到事項
4. 學習職務知識
5. 連結協作夥伴
6. 檢核並介入

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
