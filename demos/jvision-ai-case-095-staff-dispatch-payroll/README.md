# 派遣工時計薪台

> 出勤、薪資、招募到績效的人資全流程

追蹤派工、出勤、工時、薪資與請款。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**HRIS 人力資源系統

## 功能模組

- **出勤差勤** — 打卡、請假與加班
- **薪資計算** — 薪資、勞健保與報稅
- **排班管理** — 智慧排班與工時控管
- **招募任用** — 職缺、面試與報到
- **教育訓練** — 課程、證照與紀錄
- **績效考核** — 目標設定與考核流程

## 適合誰使用

- 調度專員
- 車隊主管
- 營運經理

## 運作流程

1. 待調度
2. 配送中
3. 主管確認
4. 歸檔完成

## 導入效益

- 薪資作業工時：42小時/月 → **7.7小時/月**
- 出勤異常處理：29分鐘 → **5.1分鐘**
- 招募到位天數：47天 → **26天**
- 表單簽核時效：2.9天 → **1天**
