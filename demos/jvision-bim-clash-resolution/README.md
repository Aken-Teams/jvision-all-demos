# 模型碰撞責任協調台

> 將 BIM 碰撞依樓層、系統與嚴重度分類，指派設計或施工責任單位，管理替代方案、模型修訂與現場截止點，避免未解碰撞流入套圖及施工。

將 BIM 碰撞依樓層、系統與嚴重度分類，指派設計或施工責任單位，管理替代方案、模型修訂與現場截止點，避免未解碰撞流入套圖及施工。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **碰撞總覽** — 依專業系統、樓層與嚴重度彙整案件。
- **案件篩選** — 合併重複碰撞並排除可接受或誤判項目。
- **責任協調** — 指定主責單位、受影響工種與截止日期。
- **方案比選** — 比較改管、降板、開孔等解決方案。
- **修模覆核** — 連結新版模型並驗證碰撞是否消除。
- **施工鎖定** — 依現場時程凍結方案並追蹤例外變更。

## 適合誰使用

- BIM 經理
- 機電整合工程師
- 設計監造人員

## 運作流程

1. 碰撞總覽
2. 案件篩選
3. 責任協調
4. 方案比選
5. 修模覆核
6. 施工鎖定

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
