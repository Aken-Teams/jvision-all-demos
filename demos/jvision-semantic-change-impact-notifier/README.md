# 語意變更影響通知器

> 追蹤指標與定義變更，精準通知受影響的使用者及報表擁有者。​̲

追蹤指標與定義變更，精準通知受影響的使用者及報表擁有者。​̲

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **語意版本比對** — 比較指標公式、維度、口徑與業務定義差異。
- **指標血緣展開** — 追溯語意變更影響的模型、查詢、報表與管線。
- **報表衝擊定位** — 標記受影響圖表、篩選器及計算欄位。
- **使用者關係解析** — 依查詢紀錄與擁有權找出實際使用者和負責人。
- **分眾變更通知** — 按角色、使用頻率與衝擊程度產生通知內容。
- **認知同步確認** — 追蹤已讀、接受、異議與報表修正狀態。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 偵測變更
2. 展開血緣
3. 評估衝擊
4. 辨識對象
5. 發送通知
6. 同步認知

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
