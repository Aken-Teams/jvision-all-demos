# 旅宿布草周轉管理台

> 管理客房布草從樓層回收、髒污分類、外洗交接、驗收至重新配發的完整周轉，協助旅宿掌握安全庫存、洗滌損耗、供應商缺件與每日房務需求。

管理客房布草從樓層回收、髒污分類、外洗交接、驗收至重新配發的完整周轉，協助旅宿掌握安全庫存、洗滌損耗、供應商缺件與每日房務需求。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **需求預估** — 按住房率與房型推估每日布草需求。
- **樓層回收** — 登錄各樓層髒布草回收與差異。
- **外洗交接** — 建立送洗批次及雙方點交紀錄。
- **回洗驗收** — 核對回洗數量、品質與缺件狀況。
- **庫存配發** — 查看可用量並安排樓層領用。
- **損耗求償** — 彙整污損報廢與供應商責任。

## 適合誰使用

- 房務主管
- 布草房人員
- 採購專員

## 運作流程

1. 預估需求
2. 回收清點
3. 送洗點交
4. 品質驗收
5. 樓層配發
6. 損耗結案

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
