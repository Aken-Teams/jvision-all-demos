# 精準灌溉田區水分決策台

> 運用預先建立的田區、作物、生育期、土壤水分與天氣情境資料，模擬各區缺水風險及灌溉需求，協助農場管理者安排灌溉順序、水量與時段，降低用水浪費。

**產業別：**生產製造　|　**系統類型：**operations-console

## 功能模組

- **農場水情總覽** — 呈現各田區含水狀態、缺水風險與用水概況。
- **田區水分地圖** — 用色階比較預載田區的水分與土壤差異。
- **作物需水評估** — 依作物與生育期呈現目標水分區間。
- **天氣情境模擬** — 比較降雨、高溫及乾旱情境對需水的影響。
- **灌溉建議中心** — 建議田區灌溉優先序、時段與水量。
- **輪灌排程追蹤** — 編排模擬灌溉任務並記錄完成結果。

## 適合誰使用

- 農場管理者
- 田間技術員
- 灌溉操作員

## 運作流程

1. 掌握農場水情
2. 檢查田區差異
3. 評估作物需水
4. 模擬天氣影響
5. 確認灌溉建議
6. 執行輪灌排程
