# 資料管線自癒 Agent

> 自動判讀資料管線故障並執行重試、切換、補數與品質驗證，降低人工值班負擔。

自動判讀資料管線故障並執行重試、切換、補數與品質驗證，降低人工值班負擔。

**產業別：**數據分析　|　**系統類型：**it-ops

## 功能模組

- **管線健康監測** — 持續監測批次與串流管線的延遲、失敗、Schema 漂移及品質異常。
- **失敗根因分類** — 依錯誤訊息、執行紀錄與上下游血緣判定故障類型及影響範圍。
- **復原策略編排** — 針對暫時性錯誤、來源中斷或資源不足，產生重試與切換方案。
- **缺口補數作業** — 定位缺失分區與時間窗，規劃可重入且避免重複寫入的補數任務。
- **復原品質驗證** — 以筆數、完整性、唯一性與業務規則確認補數及切換結果。
- **值班案件中心** — 彙整影響、證據、處置進度與人工核准事項，追蹤至正式結案。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 偵測管線異常
2. 判讀失敗類型
3. 選定復原策略
4. 執行缺口補數
5. 驗證資料完整
6. 結案與改善

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
