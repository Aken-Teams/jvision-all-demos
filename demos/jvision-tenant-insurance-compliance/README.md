# 租戶保險履約追蹤台

> 依租約追蹤租戶公共意外、火險與裝修期間保單的保障範圍、額度、受益人及效期，集中補件與到期催續，降低無保曝險。

**產業別：**房地產與物業　|　**系統類型：**legal-case

## 功能模組

- **租約義務** — 設定險種、額度與條款。
- **保單台帳** — 查看承保期間與保險人。
- **保障審查** — 核對範圍、額度及受益人。
- **缺件補正** — 追蹤批單與證明文件。
- **續保日曆** — 管理到期及催辦節點。
- **曝險總覽** — 呈現未合規租戶與面積。

## 適合誰使用

- 租務專員
- 物業風控
- 租戶窗口

## 運作流程

1. 建立義務
2. 收取保單
3. 審查保障
4. 要求補正
5. 追蹤續保
6. 主管覆核
