# 員工代墊逾期清算台

> 彙整員工借支、公司預付款、報銷與繳回紀錄，依補件期限追蹤未沖項，並在調職或離職前啟動清算與授權確認，避免預支款成為呆帳。

彙整員工借支、公司預付款、報銷與繳回紀錄，依補件期限追蹤未沖項，並在調職或離職前啟動清算與授權確認，避免預支款成為呆帳。

**產業別：**人力資源　|　**系統類型：**finance-case

## 功能模組

- **借支總覽** — 查看員工餘額與到期日
- **報銷勾稽** — 配對憑證與借支用途
- **補件追蹤** — 催收缺漏發票與說明
- **繳回確認** — 記錄退款與銀行入帳
- **離職攔截** — 檢查未清款與授權
- **清算結案** — 核准沖銷或轉追償

## 適合誰使用

- 員工
- 費用會計
- 人資人員

## 運作流程

1. 彙整借支
2. 配對用途
3. 追蹤補件
4. 確認繳回
5. 離職檢查
6. 完成清算

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
