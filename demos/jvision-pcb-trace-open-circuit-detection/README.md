# 印刷電路板線路斷路檢測系統

> 以模擬印刷電路板線路圖與檢測影像呈現斷線、缺口及蝕刻不足疑點，提供參考圖比對、缺陷座標定位、人工複核與批次隔離流程，協助裸板檢驗快速追蹤開路風險。

以模擬印刷電路板線路圖與檢測影像呈現斷線、缺口及蝕刻不足疑點，提供參考圖比對、缺陷座標定位、人工複核與批次隔離流程，協助裸板檢驗快速追蹤開路風險。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **開路風險看板** — 呈現批次開路疑點、確認數、隔離數與熱點分布。
- **板層線路瀏覽** — 切換模擬板層並查看線路、焊墊與網路分布。
- **參考圖差異比對** — 將檢測圖與標準圖疊合，突出線路缺口與中斷。
- **斷路定位複核** — 依座標逐筆確認斷線範圍、信心及嚴重度。
- **批次隔離處置** — 模擬建立隔離單並選擇重工、報廢或放行。
- **開路原因分析** — 依板層、區域與製程站點統計斷路發生模式。

## 適合誰使用

- PCB 檢驗員
- 製程工程師
- 品質主管

## 運作流程

1. 辨識風險
2. 選取板層
3. 比對差異
4. 確認位置
5. 隔離批次
6. 追查原因

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
