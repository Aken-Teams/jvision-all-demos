# 印刷電路板電路測試診斷

> 彙整印刷電路板線上電路測試紀錄，針對開路、短路、元件值偏差及接觸不良等失敗項目進行分類與關聯分析，協助測試工程師判斷治具、測點或電路異常並安排複測。

彙整印刷電路板線上電路測試紀錄，針對開路、短路、元件值偏差及接觸不良等失敗項目進行分類與關聯分析，協助測試工程師判斷治具、測點或電路異常並安排複測。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **測試異常總覽** — 呈現一次通過率、主要失敗類型及待診斷板件。
- **測試批次匯入** — 模擬載入測試程式、板號、測點數值及失敗碼。
- **異常群組分析** — 依失敗碼、測點及元件位置將相似異常自動分群。
- **診斷證據工作台** — 整合電路位置、量測差異與可能原因供工程師確認。
- **複測任務管理** — 安排清潔治具、重測或轉人工檢查並追蹤結果。
- **測試效能報表** — 分析程式版本、治具、料號與班別的通過率趨勢。

## 適合誰使用

- 電路測試工程師
- 品質工程師與測試線領班

## 運作流程

1. 掌握測試異常
2. 載入測試批次
3. 檢視異常分群
4. 確認診斷原因
5. 安排處置複測
6. 分析測試表現

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
