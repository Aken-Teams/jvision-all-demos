# 門市開閉店任務執行助手

> 將門市開店與閉店標準流程轉為分時任務，由智慧執行助手依模擬情境提示優先順序、檢查遺漏、協助通報例外，讓店長掌握交接與多店完成狀態。

**產業別：**經營管理　|　**系統類型：**operations-console

## 功能模組

- **班次任務啟動** — 依門市與班次載入開店或閉店流程，呈現期限與當班人員。
- **引導任務清單** — 用分步指引執行現金、設備、清潔、安全及環境檢查。
- **情境處理助手** — 根據模擬回報提供下一步建議、補充檢查與標準話術。
- **例外通報中心** — 記錄設備故障、短溢款或安全問題，依類型顯示通報路徑。
- **班次交接紀錄** — 整理未結事項、重要提醒與責任歸屬，供下一班確認接手。
- **多店執行監控** — 以地圖與清單呈現各店任務進度、逾時項目及例外狀態。

## 適合誰使用

- 門市店長
- 值班主管
- 門市員工
- 區域營運主管

## 運作流程

1. 啟動當班流程
2. 執行標準任務
3. 取得情境建議
4. 通報門市例外
5. 完成班次交接
6. 監控多店進度

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 決策資料覆蓋：55% → **92%**
- 跨部門對齊：60% → **90%**
