# 供應鏈融資適配器

辨識適合應收、應付或存貨融資的交易，優先釋放營運現金。37                              

**產業別：**財務會計　|　**系統類型：**finance-case

## 功能模組

- **應收融資候選** — 依債務人品質、帳齡與付款紀錄篩選可融資發票。
- **應付融資候選** — 依供應商需求、付款條件與採購關係篩選交易。
- **存貨融資候選** — 依存貨價值、週轉、保值性與可控性評估標的。
- **方案適配評分** — 比較交易資格、資金成本、期限與執行難度。
- **現金釋放排序** — 依可釋放金額、速度、成本與風險排列優先序。
- **融資申請編排** — 組成申請批次並安排銀行、內部核准與執行節點。

## 適合誰使用

- 財務長
- Treasurer
- 資金人員

## 運作流程

1. 篩選應收交易
2. 篩選應付交易
3. 評估存貨標的
4. 計算適配評分
5. 排序現金機會
6. 核准融資申請

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
