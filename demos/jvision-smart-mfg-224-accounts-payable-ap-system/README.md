# 應付帳款管理系統（Accounts Payable, AP System）

> 應收付、現金流到預算的財務即時掌握

應付帳款管理系統（Accounts Payable, AP System）提供供應商發票登錄與比對(三方核對)、付款排程管理、預付款與押金追蹤。會計專員、財務經理、負責人依「供應商發票登錄與比對(三方核對)、付款排程管理、預付款與押金追蹤」推進作業，優先解決「發票與採購單/驗收單三方核對耗時」，部門主管則以應付帳款管理智慧站處理結果確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**財務會計　|　**系統類型：**財務會計系統

## 功能模組

- **應收帳款** — 開立、對帳與催收
- **應付帳款** — 請款、付款與對帳
- **現金流** — 資金調度與預測
- **預算管理** — 編列、控管與差異分析
- **固定資產** — 資產登錄與折舊
- **總帳傳票** — 傳票、拋轉與月結

## 適合誰使用

- 會計專員
- 財務經理
- 負責人

## 運作流程

1. 待核對
2. 處理中
3. 待覆核
4. 已入帳

## 導入效益

- 月結作業天數：5.9天 → **2.1天**
- 對帳錯誤：8件/月 → **1.1件/月**
- 帳款逾期率：15% → **4.7%**
- 報表產出工時：17小時 → **1小時**
