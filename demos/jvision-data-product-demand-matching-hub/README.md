把業務資料需求媒合至既有資產與能力缺口，避免重複建置。?  

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **需求意圖解析** — 將自然語言需求拆成指標、粒度、時效與使用情境。
- **既有資產搜尋** — 從目錄、Schema 與查詢紀錄找出可重用資料產品。
- **語意適配評分** — 比較需求與候選資產的定義、範圍及品質契合度。
- **重用方案組裝** — 組合多個資料集與既有管線形成可交付方案。
- **供給缺口診斷** — 指出缺少的欄位、品質規則、授權或更新頻率。
- **建置決策台** — 核准重用、擴充或新建路徑並建立交付任務。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 提交資料需求
2. 搜尋可用資產
3. 評估語意契合
4. 組裝重用方案
5. 確認能力缺口
6. 核准交付路徑

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
