# 進度落後趕工承諾台

> 把工務會議中的增員、加班、材料到位與工序調整承諾轉成逐日可核對事項，追蹤實績、未兌現原因及對要徑追回天數的影響。

把工務會議中的增員、加班、材料到位與工序調整承諾轉成逐日可核對事項，追蹤實績、未兌現原因及對要徑追回天數的影響。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **落後總覽** — 查看關鍵工項差距
- **趕工承諾** — 登錄增員加班與到料
- **人力核對** — 比較承諾與實到人數
- **資源到位** — 追蹤材料機具前置
- **追回試算** — 評估承諾對要徑影響
- **升級追蹤** — 處理連續未達承諾

## 適合誰使用

- 排程工程師
- 工地主任
- 分包專案經理

## 運作流程

1. 確認落後
2. 提出方案
3. 主管核定
4. 逐日核對
5. 分析追回
6. 升級處置

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
