# 設備保固求償管理台

> 協助工廠判斷故障設備與零組件是否仍在供應商保固範圍，彙整故障證據、維修紀錄與費用，追蹤退料、換新品、折讓及拒賠原因，避免可求償成本被一般維修費吸收。

協助工廠判斷故障設備與零組件是否仍在供應商保固範圍，彙整故障證據、維修紀錄與費用，追蹤退料、換新品、折讓及拒賠原因，避免可求償成本被一般維修費吸收。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **保固資產** — 關聯設備、零件、供應商及保固期限。
- **故障篩選** — 從維修紀錄辨識可能保固案件。
- **求償證據** — 彙整照片、診斷、工時與採購文件。
- **送件追蹤** — 管理通知期限、退料及補件要求。
- **判定協商** — 記錄核准、拒賠與責任比例。
- **補償核對** — 核對換料、折讓與費用返還。

## 適合誰使用

- 維修工程師
- 設備主管
- 採購人員

## 運作流程

1. 辨識保固
2. 建立案件
3. 整理證據
4. 提交求償
5. 處理判定
6. 核對補償

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
