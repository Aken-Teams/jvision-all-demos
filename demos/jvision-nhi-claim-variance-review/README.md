# 健保申報差額覆核台

> 比對醫令、批價、身分碼與健保申報資料，將可能核刪、重複申報或碼別不一致案件集中覆核，保存補正前後版本、原因與核准軌跡。

**產業別：**醫療照護　|　**系統類型：**finance-case

## 功能模組

- **批次匯入** — 載入申報資料
- **差額掃描** — 比對醫令批價
- **碼別檢核** — 檢查身分規則
- **補證管理** — 蒐集病歷依據
- **版本覆核** — 查看修正差異
- **送件核准** — 鎖定申報批次

## 適合誰使用

- 健保申報人員
- 醫務管理師
- 財務主管

## 運作流程

1. 載入批次
2. 掃描差異
3. 判讀碼別
4. 追補證據
5. 覆核修正
6. 核准送件

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
