# 表單簽核流程艙

> 建立表單、簽核、通知與流程追蹤的單一平台

把散落的辦公室簽核作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**企業協作　|　**系統類型：**協作 / 專案平台

## 功能模組

- **簽核總覽** — 待辦、逾期與各類表單即時概況
- **待簽清單** — 我的待簽表單、金額與到期倒數
- **流程設計** — 多關卡簽核路徑與條件分流設定
- **簽核軌跡** — 單據時間軸、意見與稽核紀錄
- **表單範本** — 請購、請假、費用等表單模板庫
- **效率分析** — 各關卡耗時、退件率與部門負載

## 適合誰使用

- 申請人（專案專員）
- 部門主管 / 財務長
- 稽核人員 / 營運長

## 運作流程

1. 填單送出（申請人）
2. 路徑分流（流程引擎）
3. 逐關簽核（部門主管）
4. 軌跡稽核（稽核人員）
5. 效率覆盤（營運長）

## 導入效益

- 跨部門協調工時：8.3小時/週 → **2小時/週**
- 任務準時率：69% → **88%**
- 資訊落差：30% → **7.5%**
- 文件查找時間：20分鐘 → **3.2分鐘**
