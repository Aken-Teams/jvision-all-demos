# 餐飲菜單同步例外台

> 比較POS、官網與外送平台的品項、規格、加料、售價及停售狀態，集中處理發布失敗、結構不相容與舊版殘留，避免門店收到無法履約訂單。

比較POS、官網與外送平台的品項、規格、加料、售價及停售狀態，集中處理發布失敗、結構不相容與舊版殘留，避免門店收到無法履約訂單。

**產業別：**餐飲旅宿　|　**系統類型：**it-ops

## 功能模組

- **菜單版本** — 管理品項規格
- **通路轉換** — 對映加料結構
- **發布批次** — 同步各平台
- **落差清單** — 找出售價停售差異
- **例外修正** — 調整不相容資料
- **通路驗證** — 確認實際上架

## 適合誰使用

- 菜單營運員
- 餐飲資訊人員
- 門店主管

## 運作流程

1. 建立版本
2. 轉換結構
3. 核准發布
4. 掃描落差
5. 修正補送
6. 驗證上架

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
