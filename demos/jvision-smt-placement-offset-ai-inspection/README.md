# 表面黏著貼片偏移檢測

> 以擬真的電路板影像、元件座標與檢測框呈現人工智慧貼片偏移判定，量化水平、垂直及旋轉偏差，協助檢驗人員快速複核高風險元件並追蹤機種與站位趨勢。

以擬真的電路板影像、元件座標與檢測框呈現人工智慧貼片偏移判定，量化水平、垂直及旋轉偏差，協助檢驗人員快速複核高風險元件並追蹤機種與站位趨勢。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **偏移檢測總覽** — 彙整板件狀態、偏移不良率、高風險料號及待複核數量。
- **板件影像檢測** — 在擬真板件影像上標示元件外框、標準位置與偏移方向。
- **偏移量測明細** — 呈現水平、垂直、旋轉偏差及容許值的逐件比較。
- **人工複核工作台** — 讓檢驗員切換影像視角並模擬確認誤報或真實缺陷。
- **站位趨勢分析** — 依貼片站位、吸嘴、料號及時間比較偏移分布與變化。
- **調機驗證追蹤** — 記錄模擬校正建議，對照調整前後的偏移量與複檢狀態。

## 適合誰使用

- 自動光學檢測操作員
- 品質工程師
- 製程工程師

## 運作流程

1. 掌握待檢風險
2. 檢視標記影像
3. 核對偏移數值
4. 完成人工複核
5. 分析站位趨勢
6. 確認校正成效

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
