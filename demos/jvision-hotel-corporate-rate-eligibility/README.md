# 企業住房合約價驗證台

> 管理企業客戶的適用房型、議定價、黑名日期、訂房資格與產量承諾，讓訂房人員在接單時快速判斷可否使用合約價並留下例外核准。

管理企業客戶的適用房型、議定價、黑名日期、訂房資格與產量承諾，讓訂房人員在接單時快速判斷可否使用合約價並留下例外核准。

**產業別：**餐飲旅宿　|　**系統類型：**sales-crm

## 功能模組

- **企業合約** — 管理客戶與議定條件。
- **適用日曆** — 查看旺日封鎖與價期。
- **住客驗證** — 確認公司身分與訂房資格。
- **房價判定** — 計算適用房型及價格。
- **例外核准** — 處理超量或封鎖日申請。
- **產量追蹤** — 檢視房晚承諾與使用情形。

## 適合誰使用

- 企業業務
- 訂房專員
- 收益經理

## 運作流程

1. 建立合約
2. 設定價期
3. 驗證住客
4. 判定房價
5. 核准例外
6. 檢討產量

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
