**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **替代運能** — 確認永久電梯啟用、保護及載重限制。
- **末次運輸** — 彙整各樓層大型材料與廢料最後搬運需求。
- **分段拆機** — 規劃轎廂、標準節與附牆的拆除順序。
- **洞口封閉** — 追蹤樓層門洞、欄杆及永久牆體復原。
- **立面修補** — 管理附牆點、防水、飾面及色差修補。
- **設備退場** — 完成檢點、運離、場地清理與租期結算。

## 適合誰使用

- 工地主任
- 機具工程師
- 收尾工程師

## 運作流程

1. 確認替代運能
2. 彙整末次運輸
3. 排定分段拆機
4. 完成洞口封閉
5. 驗收立面修補
6. 辦理設備退場

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
