# AI 敏感資料外送攔截器

> 在 AI 請求送出前攔截敏感資料，依政策阻擋、遮罩或送交核准。

在 AI 請求送出前攔截敏感資料，依政策阻擋、遮罩或送交核准。

**產業別：**資訊安全　|　**系統類型：**security-soc

## 功能模組

- **外送流量總覽** — 監看各模型、部門與通道的敏感資料外送風險。
- **攔截政策編排** — 設定資料標籤、目的模型與處置動作的判斷規則。
- **敏感內容遮罩** — 預覽並套用個資、機密欄位與程式片段的遮罩方式。
- **外送核准佇列** — 審核因業務需要而申請放行的高風險 AI 請求。
- **政策情境模擬** — 模擬新政策對阻擋率、誤判率與業務延遲的影響。
- **攔截事件處置** — 調查遭阻擋的外送事件並同步 SIEM、DLP 與 GRC。

## 適合誰使用

- CISO
- AI 治理主管
- 資安分析師

## 運作流程

1. 辨識外送風險
2. 制定攔截條件
3. 確認遮罩結果
4. 裁決放行申請
5. 模擬政策成效
6. 完成事件處置

## 導入效益

- 告警分流時間：45分鐘 → **8分鐘**
- 事件平均處理：12小時 → **3小時**
- 弱點修補率：68% → **96%**
- 合規稽核工時：30小時/月 → **6小時/月**
