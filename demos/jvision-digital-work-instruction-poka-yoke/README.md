# 數位作業指導防呆助手

> 把圖文、影片替代縮圖與逐步作業標準轉為可互動工站指引，依產品版本提示工具與檢查點，利用畫面規則模擬防呆驗證，並記錄異常回報及完成履歷。

把圖文、影片替代縮圖與逐步作業標準轉為可互動工站指引，依產品版本提示工具與檢查點，利用畫面規則模擬防呆驗證，並記錄異常回報及完成履歷。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **工單任務入口** — 顯示今日工單、產品版本與作業準備事項。
- **逐步作業指引** — 以圖文卡片、計時與注意事項引導每個步驟。
- **關卡防呆驗證** — 模擬料號、工具、順序與數值輸入檢查。
- **自主品質檢查** — 依工序填寫檢查結果並呈現判定標準。
- **現場異常回報** — 選擇問題類型、標記步驟並提出支援需求。
- **版本履歷管理** — 查閱指導書版本、變更內容與作業完成紀錄。

## 適合誰使用

- 產線作業員
- 線長
- 製程工程師
- 品質人員

## 運作流程

1. 領取工單任務
2. 依指引執行
3. 通過防呆關卡
4. 完成自主檢查
5. 回報現場異常
6. 追溯版本履歷

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
