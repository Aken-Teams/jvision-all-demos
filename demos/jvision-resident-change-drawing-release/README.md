# 客變圖面收斂發行台

> 將住戶客變需求、現勘註記、報價確認與各專業圖面收斂成單一施工版，依戶別管制簽認、凍結與現場發行，避免報價內容和施工圖不同或工班誤用其他戶別版本。

將住戶客變需求、現勘註記、報價確認與各專業圖面收斂成單一施工版，依戶別管制簽認、凍結與現場發行，避免報價內容和施工圖不同或工班誤用其他戶別版本。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **戶別需求總覽** — 依戶別彙整變更項目、選配、附件與處理狀態。
- **圖價一致檢核** — 比對報價項目、數量與圖面實際變更內容。
- **跨專業收斂** — 協調建築、機電、消防與設備圖面的連動修改。
- **住戶簽認** — 保存簽認版本、例外條款與最後確認日期。
- **施工版凍結** — 鎖定戶別施工內容並記錄凍結後異動。
- **圖面發行回收** — 發送正確戶別版本並追蹤現場收訖與舊版回收。

## 適合誰使用

- 客變專員
- 設計工程師
- 現場工程師

## 運作流程

1. 彙整客變需求
2. 核對報價內容
3. 收斂專業圖面
4. 取得住戶簽認
5. 凍結戶別施工版
6. 發行現場施工

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
