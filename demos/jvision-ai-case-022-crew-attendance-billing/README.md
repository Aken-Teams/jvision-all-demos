# 工班請款結算台

> 進度、日報、品安到估價成本的工程管理

整合工班出勤、工時計算與請款明細。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**營建工程　|　**系統類型：**營建工程管理

## 功能模組

- **結算總覽** — 本期出工、計價與請款結算儀表
- **工班考勤** — 各工班每月出工/請假/加班考勤日曆
- **工時計價** — 工時彙整、單價套用與估驗計價
- **請款單** — 計價明細產生請款單與稅額試算
- **保留款管理** — 各期保留款提列、累計與釋回
- **付款進度** — 請款審核、撥款排程與付款進度追蹤

## 適合誰使用

- 工班專員
- 工班主管
- 營建工程主管

## 運作流程

1. 出工登記
2. 工時統計
3. 產生請款單
4. 保留款提列
5. 審核付款

## 導入效益

- 日報彙整工時：2.8小時/日 → **0.5小時/日**
- 進度落後預警：38% → **85%**
- 估驗計價天數：9.4天 → **3.8天**
- 缺失改善時效：6.6天 → **1.9天**
