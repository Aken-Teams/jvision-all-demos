# 臨時工資憑證覆核台

> 彙整臨時點工人員身分、工地、日期、工種、工時、單價及領款證明，辨識跨工地重複出勤、灌水、代簽與錯用工資標準。

**產業別：**營建工程　|　**系統類型：**hr-hris

## 功能模組

- **點工名冊** — 查看人員與工地出勤
- **工時登錄** — 記錄日期班別與工種
- **單價檢查** — 核對核准工資標準
- **重複偵測** — 辨識跨案重複人員
- **領款憑證** — 保存簽領與付款證明
- **工資核付** — 核准可支付明細

## 適合誰使用

- 工地行政
- 薪資會計
- 稽核人員

## 運作流程

1. 建立名冊
2. 填報出勤
3. 主管簽認
4. 異常檢查
5. 憑證覆核
6. 執行付款

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
