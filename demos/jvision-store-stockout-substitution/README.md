# 門市缺貨替代回報台

> 將空架品項的後倉查找、替代陳列、調撥請求與補貨責任集中交接，避免多人重複找貨或整個班次無人處理熱門缺貨。

將空架品項的後倉查找、替代陳列、調撥請求與補貨責任集中交接，避免多人重複找貨或整個班次無人處理熱門缺貨。

**產業別：**零售電商　|　**系統類型：**pos-frontdesk

## 功能模組

- **空架佇列** — 依銷售影響排序缺貨。
- **後倉查找** — 記錄已查庫位與結果。
- **替代建議** — 選擇可陳列替代商品。
- **調撥補貨** — 向他店或倉庫提出需求。
- **班次交接** — 指定責任人與下一步。
- **上架確認** — 回報恢復時間與照片。

## 適合誰使用

- 門市人員
- 值班店長
- 補貨主管

## 運作流程

1. 通報空架
2. 查找後倉
3. 判定替代
4. 提出調撥
5. 跨班交接
6. 恢復上架

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
