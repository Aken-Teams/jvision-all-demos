# 餐飲食材出成率管制台

> 供連鎖餐飲比對標準配方、領料、銷售與盤點資料，追查門店及品項的食材耗損、份量偏差與異常成本，協助店長每日完成原因註記及改善追蹤。

供連鎖餐飲比對標準配方、領料、銷售與盤點資料，追查門店及品項的食材耗損、份量偏差與異常成本，協助店長每日完成原因註記及改善追蹤。

**產業別：**餐飲旅宿　|　**系統類型：**erp

## 功能模組

- **耗用總覽** — 彙整門店食材成本與出成率異常。
- **配方基準** — 維護菜品標準份量與理論耗用。
- **差異分析** — 比對銷售、領料、報廢及盤點差異。
- **異常案件** — 依門店與食材建立調查清單。
- **原因改善** — 記錄偏差原因、責任與改善措施。
- **成效追蹤** — 觀察改善前後耗損與成本趨勢。

## 適合誰使用

- 餐飲營運主管
- 門店店長
- 成本會計

## 運作流程

1. 檢視耗用
2. 確認基準
3. 拆解差異
4. 建立案件
5. 回報改善
6. 驗證成效

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
