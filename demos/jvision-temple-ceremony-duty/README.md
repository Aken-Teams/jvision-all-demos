# 宮廟科儀執事管理台

> 供宮廟安排醮典、遶境與例行法會的科儀節次、執事人員、法器供品、服裝站位及行前演練，將傳統口傳分工轉成可查核任務板，避免大型儀式漏序或人員錯位。

**產業別：**宗教服務　|　**系統類型：**operations-console

## 功能模組

- **科儀節次** — 編排儀式順序、時間與銜接提示。
- **執事配置** — 安排主祭、陪祭、司儀與志工位置。
- **法器供品** — 盤點各節次所需法器及供品。
- **服裝站位** — 確認服制、隊形與進退場位置。
- **行前演練** — 記錄演練問題與改善責任。
- **儀式紀錄** — 保存版本、臨場差異與傳承備註。

## 適合誰使用

- 廟務主任
- 科儀總務
- 志工隊長

## 運作流程

1. 編排節次
2. 配置執事
3. 備妥用品
4. 確認站位
5. 辦理演練
6. 保存紀錄

## 導入效益

- 活動籌備工時：20小時 → **5小時**
- 報名掌握率：65% → **94%**
- 物資盤點：6小時 → **1小時**
- 志工調度時效：3天 → **1天**
