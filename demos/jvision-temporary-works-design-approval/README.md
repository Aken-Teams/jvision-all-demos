# 假設工程設計審查台

> 管理施工便橋、支撐平台、臨時構台等假設工程的計算書、施工圖、載重限制與核准條件，確保現場搭設版本及使用方式符合專業審查結果。

管理施工便橋、支撐平台、臨時構台等假設工程的計算書、施工圖、載重限制與核准條件，確保現場搭設版本及使用方式符合專業審查結果。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **項目總覽** — 依工區查看假設工程與審查狀態。
- **計算書管理** — 管理設計荷重、假設與技師簽證版次。
- **施工圖審查** — 套合圖說並彙整逐條審查意見。
- **核准版發行** — 發布可施工版本及附帶限制條件。
- **搭設查驗** — 依核准圖核對構件、尺寸與連結。
- **使用管制** — 揭示載重、期限及禁止變更事項。

## 適合誰使用

- 專任工程人員
- 結構技師
- 施工工程師

## 運作流程

1. 建立項目
2. 提交設計
3. 專業審查
4. 核准發行
5. 搭設查驗
6. 使用列管

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
