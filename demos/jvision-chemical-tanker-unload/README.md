# 化工槽車卸料槽位台

> 供化工與塗料廠在槽車卸料前依料名、品管狀態、接頭與儲槽可用容量完成雙人核對，記錄卸前後液位，防止錯槽及溢槽。

**產業別：**倉儲物流　|　**系統類型：**warehouse-wms

## 功能模組

- **到車看板** — 查看待卸槽車
- **物料放行** — 核對品名檢驗狀態
- **槽位檢查** — 確認容量與相容性
- **雙人覆核** — 比對管線及接頭
- **卸料紀錄** — 登錄起訖液位
- **差異處理** — 追查短交殘液

## 適合誰使用

- 槽區操作員
- 品管人員

## 運作流程

1. 槽車報到
2. 取樣放行
3. 指定槽位
4. 接管覆核
5. 執行卸料
6. 差異簽收

## 導入效益

- 揀貨作業工時：7小時/日 → **2小時/日**
- 庫存準確率：88% → **99%**
- 出貨延遲率：9% → **2%**
- 盤點工時：16小時/月 → **3小時/月**
