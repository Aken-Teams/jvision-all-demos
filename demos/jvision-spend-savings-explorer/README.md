# 採購支出與節省機會探勘

> 將模擬的採購交易依品類、供應商、部門與據點重新分類，找出支出分散、價格差異、合約外採購及需求整併機會。管理者可逐層追查明細、估算節省潛力並建立改善專案。

將模擬的採購交易依品類、供應商、部門與據點重新分類，找出支出分散、價格差異、合約外採購及需求整併機會。管理者可逐層追查明細、估算節省潛力並建立改善專案。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **支出分類工作台** — 檢視交易分類、信心程度及需要人工修正的品項。
- **支出全景分析** — 依品類、供應商、部門與據點呈現支出結構及趨勢。
- **價格差異探勘** — 找出相同或近似品項在不同供應商間的價格落差。
- **支出分散分析** — 辨識供應商過多、小額頻繁與跨部門重複採購情況。
- **合約外採購檢視** — 比對合約覆蓋與交易紀錄，顯示未使用議定條件的支出。
- **節省機會清單** — 估算整併、轉單與重新議價的潛力並建立改善專案。

## 適合誰使用

- 採購分析師
- 品類經理
- 財務主管

## 運作流程

1. 校正交易分類
2. 掌握支出結構
3. 辨識價格落差
4. 發現分散需求
5. 檢查合約外支出
6. 建立節省專案
