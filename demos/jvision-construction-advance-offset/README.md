# 工程預付款沖抵管制台

> 管理材料與分包預付款的支付條件、保證、應沖比例及每期實際沖抵，辨識漏沖、少沖與合約終止後未追回餘額，降低資金曝險。

管理材料與分包預付款的支付條件、保證、應沖比例及每期實際沖抵，辨識漏沖、少沖與合約終止後未追回餘額，降低資金曝險。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **預付總覽** — 查看餘額與風險狀態
- **沖抵規則** — 設定比例起點與條件
- **請款勾稽** — 計算本期應沖金額
- **漏沖預警** — 標示未依約沖抵案件
- **餘款追回** — 處理解約停業與返還
- **帳務核對** — 比對明細帳與總帳

## 適合誰使用

- 應付會計
- 合約管理員
- 專案財務

## 運作流程

1. 核准預付
2. 支付入帳
3. 接收請款
4. 計算沖抵
5. 差異覆核
6. 結清追回

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
