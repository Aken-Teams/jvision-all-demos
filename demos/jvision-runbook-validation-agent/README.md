# Runbook 自動驗證器

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **Runbook 健康** — 依更新時間、服務變更與歷次結果排列待驗證 Runbook。
- **步驟依賴解析** — 解析每個操作步驟所需服務、工具、憑證與前置條件。
- **權限可用檢查** — 在最小權限原則下驗證角色、憑證與命令授權是否有效。
- **沙箱演練場** — 於隔離環境逐步執行指令並捕捉輸出、逾時與副作用。
- **失效差異診斷** — 比對文件預期與實際結果，定位過期參數、路徑及權限。
- **修訂發布中心** — 產生修訂草案與重驗計畫，核准後更新 Runbook 與任務。

## 適合誰使用

- 工程主管
- 開發者

## 運作流程

1. 選定手冊
2. 解析步驟
3. 檢查權限
4. 沙箱演練
5. 診斷落差
6. 核准修訂
