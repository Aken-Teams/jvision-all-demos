# 會員身分合併審核台

> 比對官網、APP、POS與客服會員資料，呈現姓名、手機、登入方式、消費與點數證據，經人工審核後安全合併或排除同名誤判。

比對官網、APP、POS與客服會員資料，呈現姓名、手機、登入方式、消費與點數證據，經人工審核後安全合併或排除同名誤判。

**產業別：**零售電商　|　**系統類型：**security-soc

## 功能模組

- **候選佇列** — 排序疑似重複會員。
- **身分比對** — 比較聯絡與登入資料。
- **交易證據** — 查看消費、退貨與地址。
- **權益模擬** — 預覽點數券與等級移轉。
- **合併審核** — 執行雙人覆核或駁回。
- **稽核紀錄** — 保存欄位來源與決策。

## 適合誰使用

- 會員營運
- 客服主管
- 個資管理員

## 運作流程

1. 產生候選
2. 比對身分
3. 查看交易
4. 模擬權益
5. 核准合併
6. 封存結果

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
