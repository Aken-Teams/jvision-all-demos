# 鋼捲缺陷追溯分級助手

> 以鋼捲表面影像縮圖、缺陷座標、製程履歷與訂單規範等擬真資料，完成缺陷複判、等級判定、來源追溯及處置建議，協助品質人員一致化判級並加速客訴查證。

以鋼捲表面影像縮圖、缺陷座標、製程履歷與訂單規範等擬真資料，完成缺陷複判、等級判定、來源追溯及處置建議，協助品質人員一致化判級並加速客訴查證。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **待判鋼捲** — 依風險、客戶與交期排列待複判的鋼捲工作清單。
- **缺陷檢視** — 查看缺陷影像、類型信心度、尺寸與表面座標。
- **捲面分布** — 以展開圖呈現缺陷密度、聚集區及長度位置。
- **品質分級** — 依客戶規範試算放行、降級、分切或報廢結果。
- **來源追溯** — 串接擬真爐次、鑄坯、軋製與精整履歷找出來源。
- **判級報告** — 產出含證據、判定理由與處置建議的品質摘要。

## 適合誰使用

- 表面檢查員
- 品質工程師
- 客訴處理人員

## 運作流程

1. 挑選鋼捲
2. 複判缺陷
3. 檢查分布
4. 試算等級
5. 追溯來源
6. 核發報告

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
