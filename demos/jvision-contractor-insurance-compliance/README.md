依分包契約條款追蹤工程險、雇主責任險等應備保單、批單與承保範圍，遇人員增加或工期展延時主動重算有效期間，未完成補保者限制進場或請款。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **契約保險條件** — 設定各分包應投保種類與額度。
- **保單收件** — 收集保單、批單及繳費證明。
- **內容審查** — 核對期間、被保險人與除外條款。
- **展延續保** — 因工期或範圍變動產生補保任務。
- **管制名單** — 列出不得進場或暫緩請款廠商。
- **風險總覽** — 呈現各案承保缺口與到期趨勢。

## 適合誰使用

- 合約管理員
- 職安人員
- 分包窗口

## 運作流程

1. 建立條件
2. 提交保單
3. 審查承保
4. 通知補正
5. 執行管制
6. 啟動續保

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
