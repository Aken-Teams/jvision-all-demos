# 客戶案件主檔歸戶台

> 以統編、法人、品牌與集團關係比對專業服務客戶及案件，裁決重複主檔並保護已開票資料，使工時、合約額度與利益衝突檢查完整歸戶。

以統編、法人、品牌與集團關係比對專業服務客戶及案件，裁決重複主檔並保護已開票資料，使工時、合約額度與利益衝突檢查完整歸戶。

**產業別：**專業服務　|　**系統類型：**it-ops

## 功能模組

- **客戶主檔** — 彙整法人品牌與統編
- **重複候選** — 找出別名與集團關係
- **案件關聯** — 檢視合約工時與發票
- **衝突檢查** — 評估歸戶後利益關係
- **歸戶裁決** — 決定合併別名或分拆
- **對映發布** — 同步主檔並保護歷史

## 適合誰使用

- 案件管理員
- 財務主檔人員
- 風險主管

## 運作流程

1. 彙整客戶來源
2. 產生重複候選
3. 盤點案件關聯
4. 執行衝突評估
5. 核定歸戶結果
6. 發布跨系統對映

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
