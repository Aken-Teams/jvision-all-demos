# 合約負債收入認列台

> 協助訂閱制與預收款企業按合約履約義務拆分交易價格、建立認列排程、處理合約變更及期末調整，產出合約負債明細與會計分錄。

協助訂閱制與預收款企業按合約履約義務拆分交易價格、建立認列排程、處理合約變更及期末調整，產出合約負債明細與會計分錄。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **合約建檔** — 登錄期間、金額及收款條件
- **義務拆分** — 拆分服務項目與交易價格
- **認列排程** — 建立各期收入認列計畫
- **合約變更** — 處理升級、解約與期間異動
- **期末調整** — 試算補提、沖回與估計變更
- **分錄報表** — 產生分錄及合約負債明細

## 適合誰使用

- 收入會計
- 財務主管
- 內部稽核

## 運作流程

1. 建立收入合約
2. 拆分履約義務
3. 產生認列排程
4. 處理合約變更
5. 執行期末調整
6. 核准分錄報表

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
