# AI 決策申訴入口

> 讓 AI 決策受影響者取得理由、補交資料並正式申請人工覆核。

讓 AI 決策受影響者取得理由、補交資料並正式申請人工覆核。

**產業別：**資訊安全　|　**系統類型：**legal-case

## 功能模組

- **決策案件查詢** — 以案件編號與身分驗證取得受影響決策。
- **決策理由說明** — 用可理解文字呈現主要因素、限制與不確定性。
- **補充資料提交** — 上傳更正資料、證明文件與個人陳述。
- **申訴理由建構** — 引導選擇爭點並組成完整申訴內容。
- **人工覆核申請** — 選擇覆核範圍、聯絡方式與合理調整需求。
- **救濟進度追蹤** — 查看受理、補件、覆核、決定與後續救濟狀態。

## 適合誰使用

- CISO
- AI 治理主管
- 資安分析師

## 運作流程

1. 驗證並取得決策
2. 閱讀決策理由
3. 補交更正資料
4. 提出申訴爭點
5. 進行人工覆核
6. 送達救濟結果

## 導入效益

- 告警分流時間：45分鐘 → **8分鐘**
- 事件平均處理：12小時 → **3小時**
- 弱點修補率：68% → **96%**
- 合規稽核工時：30小時/月 → **6小時/月**
