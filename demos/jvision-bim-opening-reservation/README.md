# 機電預留套管定版台

> 在結構澆置前整合機電套管、樓板開口與牆體預留需求，依模型或圖說版次檢查碰撞、尺寸及標高，管理逾期變更與現場定版簽認，降低後鑽孔及結構修補。

在結構澆置前整合機電套管、樓板開口與牆體預留需求，依模型或圖說版次檢查碰撞、尺寸及標高，管理逾期變更與現場定版簽認，降低後鑽孔及結構修補。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **預留清單** — 依澆置區整理套管、開口、埋件及責任系統。
- **版次疊合** — 比對結構底圖與各機電專業的提交版本。
- **碰撞檢查** — 標記鋼筋、梁柱、設備及不同系統間衝突。
- **尺寸覆核** — 確認座標、標高、口徑與防火需求。
- **定版會簽** — 由結構、機電及現場共同鎖定施工版。
- **逾期變更** — 評估定版後新增需求的工期、結構與費用影響。

## 適合誰使用

- BIM 工程師
- 機電工程師
- 結構工程師

## 運作流程

1. 彙整預留需求
2. 疊合專業版本
3. 處理模型碰撞
4. 覆核尺寸標高
5. 簽認澆置定版
6. 審批逾期變更

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
