# IT治理、風險與法規遵循追蹤台

整合IT資安政策、風險評估與法規遵循(如ISO 27001、個資法)管理，支援稽核與董事會報告。

- 原始系統：IT治理、風險與法規遵循平台（GRC）
- 產業分類：智慧製造｜IT管理
- 使用部門：資訊安全部、稽核室、法遵部、資訊部、董事會/管理層
- 工作流程：制定資安政策與控制項→定期風險評估→稽核排程執行→發現事項開立改善單→追蹤改善完成→管理層報告
- AI 應用：風險評分自動計算與趨勢分析、法規異動自動比對政策缺口
- 主要 KPI：稽核發現改善完成率、風險降低率、合規達成率、政策覆蓋率
- 代表產品：ServiceNow GRC、RSA Archer、MetricStream
