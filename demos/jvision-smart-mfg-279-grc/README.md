# IT治理、風險與法規遵循平台（GRC）

> 告警分流、事件應變到弱點與合規治理

IT治理、風險與法規遵循平台（GRC）提供資安政策與制度文件管理、風險評估與風險登記冊、合規基準檢核清單。資訊安全部依「制定資安政策與控制項→定期風險評估→稽核排程執行→發現事項開立改善單→追蹤改善完成→管理層報告」推進作業，優先解決「資安制度文件版本混亂」，稽核室則以稽核發現改善完成率與風險降低率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**資訊安全　|　**系統類型：**資安 SOC 平台

## 功能模組

- **告警分流** — 資安告警彙整分級
- **事件應變** — 事件調查與處置
- **弱點管理** — 弱點掃描與修補追蹤
- **身分權限** — 帳號與特權管理
- **合規治理** — 政策、稽核與合規
- **端點防護** — 端點偵測與應變

## 適合誰使用

- 資訊安全部
- 稽核室
- 法遵部

## 運作流程

1. 已偵測
2. 調查中
3. 研判確認
4. 已關閉

## 導入效益

- 告警分流時間：42分鐘 → **7.5分鐘**
- 事件平均處理：11小時 → **2.8小時**
- 弱點修補率：64% → **90%**
- 合規稽核工時：28小時/月 → **5.6小時/月**
