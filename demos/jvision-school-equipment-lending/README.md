# 校園設備借用管理台

> 管理學校攝影器材、實驗設備與教具的申請、資格審核、領用點交、逾期催還及損壞責任，提升共享設備周轉效率。

管理學校攝影器材、實驗設備與教具的申請、資格審核、領用點交、逾期催還及損壞責任，提升共享設備周轉效率。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **設備目錄** — 查看設備狀態與條件
- **借用申請** — 建立時段及課程用途
- **資格審核** — 確認權限與教師同意
- **領用點交** — 記錄配件及領用狀況
- **歸還驗收** — 檢查設備與實際歸期
- **異常處理** — 追蹤逾期損壞與責任

## 適合誰使用

- 設備管理員
- 授課教師
- 系所主管

## 運作流程

1. 查找設備
2. 提出申請
3. 審核資格
4. 領用點交
5. 歸還驗收
6. 處理異常

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
