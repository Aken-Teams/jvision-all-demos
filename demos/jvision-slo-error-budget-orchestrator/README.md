# SLO 錯誤預算調度器

依 SLO 錯誤預算消耗動態管制發布，並調度可靠性改善工作。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **預算燃燒儀表** — 呈現各服務錯誤預算餘額、燃燒率與預測耗盡時間。
- **SLO 健康診斷** — 辨識造成可用性、延遲或正確性目標偏離的服務訊號。
- **發布風險閘門** — 依消耗速度與變更風險建議放行、降速或凍結發布。
- **速度穩定排程** — 在產品交付與可靠性改善間配置團隊容量。
- **可靠性任務編隊** — 把主要燃燒來源拆成可執行的修復、測試與韌性任務。
- **耗盡應變中心** — 協調逾時升級、發布停止與安全回滾，保留 Agent 交接證據。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 監看預算燃燒
2. 診斷偏離來源
3. 裁定發布節奏
4. 重排團隊容量
5. 執行可靠性修復
6. 啟動耗盡應變

## 導入效益

- 事件平均處理：120分鐘 → **30分鐘**
- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
- 資產盤點工時：20小時/月 → **4小時/月**
