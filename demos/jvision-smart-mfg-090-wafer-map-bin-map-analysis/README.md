# Wafer Map / Bin Map Analysis管理艙

分析晶圓測試Bin Map空間分布，找出製程異常造成的圖形化缺陷模式，支援根因定位。

- 原始系統：Wafer Map / Bin Map Analysis（晶圓圖分析）
- 產業分類：智慧製造｜品質管理
- 使用部門：製程工程部、品保部、良率工程部
- 工作流程：測試數據匯入→Bin Map產出→圖形模式辨識→異常關聯分析→根因鎖定
- AI 應用：空間缺陷圖形深度學習辨識、異常模式自動分類與根因建議
- 主要 KPI：圖形異常檢出率、根因定位時效、良率提升幅度
- 代表產品：exensio（PDF Solutions）、KLA、以客製化開發為主
