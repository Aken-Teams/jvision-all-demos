# Wafer Map / Bin Map Analysis（晶圓圖分析）

> 把分散數據變成可下鑽、可決策的經營洞察

Wafer Map / Bin Map Analysis（晶圓圖分析）提供Bin Map視覺化、空間圖形辨識、多批次疊圖比對。製程工程部依「測試數據匯入→Bin Map產出→圖形模式辨識→異常關聯分析→根因鎖定」推進作業，優先解決「圖形化缺陷肉眼判讀耗時」，品保部則以圖形異常檢出率與根因定位時效確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**BI 商業智慧

## 功能模組

- **經營儀表板** — 關鍵指標即時總覽
- **趨勢分析** — 多維度趨勢與比較
- **指標下鑽** — 逐層鑽取到明細
- **平衡計分卡** — 策略目標與 KPI 對齊
- **AI 洞察** — 自動發現異常與機會
- **報表匯出** — 排程報表與分享

## 適合誰使用

- 製程工程部
- 品保部
- 良率工程部

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉
