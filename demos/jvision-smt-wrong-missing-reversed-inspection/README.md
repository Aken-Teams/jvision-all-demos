# 貼片錯漏反件檢測系統

> 透過擬真的板件影像、物料表與標準裝配圖，檢查表面黏著製程中的錯料、漏裝及元件翻面，集中呈現疑似缺陷與比對依據，協助檢驗員快速複核並建立返修紀錄。

透過擬真的板件影像、物料表與標準裝配圖，檢查表面黏著製程中的錯料、漏裝及元件翻面，集中呈現疑似缺陷與比對依據，協助檢驗員快速複核並建立返修紀錄。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **裝件檢測總覽** — 呈現工單檢測進度、三類缺陷數量與高風險板件。
- **標準裝配比對** — 並排顯示標準裝配圖、物料資料與擬真待檢板件影像。
- **缺陷辨識清單** — 依錯件、漏件及反件分類列出位置、信心分數與影像縮圖。
- **檢驗複核工作台** — 提供局部放大與比對資訊，模擬接受、駁回及改判操作。
- **返修任務管理** — 將確認缺陷轉成返修項目，指派模擬人員並記錄處置方式。
- **複檢放行紀錄** — 核對返修前後影像、複檢結論及板件放行狀態。

## 適合誰使用

- 自動光學檢測操作員
- 品質工程師
- 返修技術員

## 運作流程

1. 檢視裝件概況
2. 比對標準裝配
3. 篩選疑似缺陷
4. 完成人工判定
5. 安排返修處置
6. 複檢確認放行

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
