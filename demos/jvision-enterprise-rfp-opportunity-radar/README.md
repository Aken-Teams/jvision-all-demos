**產業別：**專業服務　|　**系統類型：**sales-crm

## 功能模組

- **標案來源雷達** — 彙整公開採購、補助平台與受邀投標的最新機會。
- **需求主題分類** — 依產業、採購項目、技術主題與交付型態自動歸類。
- **資格初篩** — 快速比對投標資格、證照、實績與地域限制。
- **機會優先榜** — 綜合契合度、規模、期限與競爭訊號排列追蹤順序。
- **關鍵變更監看** — 追蹤公告更正、截止日異動、問答與邀標狀態。
- **商機接手機制** — 經核准後建立 CRM 商機並同步研判與追蹤任務。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 掃描機會來源
2. 辨識需求類型
3. 完成資格初篩
4. 排列追蹤優先序
5. 監看公告變更
6. 核准轉入商機

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
