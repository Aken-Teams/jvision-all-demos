# 併購標的掃描協同估值平台

> 集中管理併購候選公司，依策略適配、財務品質、產業風險與協同潛力進行篩選，並以多種估值方法模擬交易價格、整合成本及綜效，支援管理團隊形成可追溯的投資評估。

集中管理併購候選公司，依策略適配、財務品質、產業風險與協同潛力進行篩選，並以多種估值方法模擬交易價格、整合成本及綜效，支援管理團隊形成可追溯的投資評估。

**產業別：**財務會計　|　**系統類型：**finance-case

## 功能模組

- **標的市場掃描** — 依產業、規模、地區與成長條件瀏覽及篩選候選公司。
- **策略適配評分** — 從產品、市場、能力與客群面向評估併購契合度。
- **財務品質檢視** — 整理營收、獲利、負債與現金流並標記異常趨勢。
- **獨立價值估算** — 以現金流折現及市場倍數建立估值區間。
- **協同效益建模** — 拆解營收綜效、成本節省、整合成本與實現時程。
- **投資評議室** — 彙整排名、估值與風險，記錄委員意見及決議。

## 適合誰使用

- 策略發展主管
- 財務主管
- 投資分析師與事業群主管

## 運作流程

1. 建立候選清單
2. 評估策略契合
3. 檢視財務品質
4. 推估獨立價值
5. 共編協同模型
6. 形成投資決議
