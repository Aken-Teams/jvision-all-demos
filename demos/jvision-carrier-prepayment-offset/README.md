# 承攬運費預付款沖銷台

> 將車行預付款逐筆連結實際趟次、簽收、應付運費與扣款，追蹤未出車、重複請款及長期餘額，讓調度和財務共同確認後完成沖銷或追償。

將車行預付款逐筆連結實際趟次、簽收、應付運費與扣款，追蹤未出車、重複請款及長期餘額，讓調度和財務共同確認後完成沖銷或追償。

**產業別：**物流運輸　|　**系統類型：**finance-ledger

## 功能模組

- **預付款總覽** — 查看車行餘額與帳齡
- **趟次配對** — 連結派車簽收與應付
- **履約核驗** — 確認出車及交付證據
- **差異查核** — 辨識重付未出車與扣款
- **沖銷試算** — 計算可沖與待追回金額
- **結案核准** — 完成沖帳或轉追償

## 適合誰使用

- 運費會計
- 車隊調度
- 財務主管

## 運作流程

1. 載入預付
2. 配對趟次
3. 核驗履約
4. 查明差異
5. 提出沖銷
6. 核准結案

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
