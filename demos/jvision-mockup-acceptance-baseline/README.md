# 實體樣板驗收基準台

> 管理樣品屋、外牆樣板及標準層樣板的施作範圍、查驗項目與核准結論，將可接受工法、收邊及觀感照片轉成後續大量施工的驗收基準。

管理樣品屋、外牆樣板及標準層樣板的施作範圍、查驗項目與核准結論，將可接受工法、收邊及觀感照片轉成後續大量施工的驗收基準。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **樣板總覽** — 管理樣板類型、位置與核定狀態。
- **查驗基準** — 建立工法、尺寸、收邊與觀感項目。
- **現勘紀錄** — 依細部位置記錄照片與各方意見。
- **意見收斂** — 合併衝突意見並追蹤修正回覆。
- **基準發行** — 發布核准照片、做法與不得偏離事項。
- **量產比對** — 將首件成果與核准樣板逐項比較。

## 適合誰使用

- 設計監造
- 品管工程師
- 施工領班

## 運作流程

1. 定義樣板
2. 完成施作
3. 聯合查驗
4. 修正收斂
5. 核准發行
6. 首件比對

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
