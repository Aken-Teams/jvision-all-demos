# 射出成型毛邊缺陷預測

> 依射出壓力、鎖模力、模具狀態、材料黏度與產品結構等歷史條件，預估分模線及頂針周邊的毛邊風險，協助製程人員比較參數方案、規劃試模檢查並追蹤調機改善成果。

依射出壓力、鎖模力、模具狀態、材料黏度與產品結構等歷史條件，預估分模線及頂針周邊的毛邊風險，協助製程人員比較參數方案、規劃試模檢查並追蹤調機改善成果。

**產業別：**生產製造　|　**系統類型：**quality-qms

## 功能模組

- **毛邊風險總覽** — 呈現高風險工單、毛邊不良率及可能異常模具。
- **成型條件建檔** — 編輯壓力、鎖模力、溫度、材料與模具狀態資料。
- **毛邊區域預測** — 在產品輪廓圖標示分模線、頂針及高風險位置。
- **改善方案比較** — 比較降壓、增強鎖模或檢修模具等方案影響。
- **試模檢查任務** — 安排調機、模具檢查與試產抽驗的模擬工作。
- **毛邊趨勢分析** — 分析模具、材料、穴位與參數對毛邊不良的影響。

## 適合誰使用

- 射出成型製程工程師
- 模具工程師
- 調機技術員與品質主管

## 運作流程

1. 掌握毛邊風險
2. 建立成型條件
3. 判讀風險區域
4. 選擇改善方案
5. 執行試模檢查
6. 檢討改善成果
