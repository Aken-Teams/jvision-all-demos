# 採購預算控管系統

> 供應商協同、詢比議價到交期風險控管

採購預算控管系統提供預算科目與額度設定、請購即時預算檢核、預算執行率儀表板。採購部依「預算設定 → 請購檢核 → 額度扣減 → 執行監控 → 期末結算檢討」推進作業，優先解決「採購超支事後才發現」，財務部則以預算執行率與超支事件數確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**採購供應鏈　|　**系統類型：**SRM 採購供應商管理

## 功能模組

- **供應商管理** — 建檔、分級與績效評分
- **詢報價協作** — 線上詢價、比價與議價
- **採購訂單** — 請購、下單與交期追蹤
- **交期風險** — 缺料預警與到貨監控
- **供應商品質** — 進料檢驗與 SCAR 改善
- **綠色採購** — ESG 評分與永續採購

## 適合誰使用

- 採購部
- 財務部
- 各用料部門

## 運作流程

1. 待詢價
2. 比價中
3. 待核准
4. 驗收完成

## 導入效益

- 採購前置時間：12天 → **4.9天**
- 準時到貨率：84% → **92%**
- 缺料預警覆蓋：40% → **86%**
- 議價作業工時：7.8小時/週 → **2.1小時/週**
