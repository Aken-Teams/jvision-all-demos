# 焊接電流異常分析系統

> 以擬真的焊接電流波形、設定值與工單紀錄，找出尖峰、驟降、漂移及週期不穩等異常，協助工程人員比對機台、材料與班別差異，快速完成事件判讀與改善追蹤。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **異常監控總覽** — 顯示事件數、嚴重度、機台排行與近期異常趨勢。
- **電流波形分析** — 放大檢視擬真電流曲線、設定上下限與異常區段。
- **基準曲線比對** — 將異常波形與正常樣本疊圖，標示尖峰、驟降及漂移差異。
- **條件交叉分析** — 依機台、材料、工單、班別及焊接程序切分異常分布。
- **異常事件處置** — 記錄事件判讀、責任分派、處理狀態與模擬改善結果。
- **異常趨勢報告** — 彙整重複異常、偏差程度與各產線改善成效。

## 適合誰使用

- 製程工程師
- 設備工程師
- 品保工程師

## 運作流程

1. 瀏覽異常概況
2. 檢查電流波形
3. 比對正常基準
4. 分析關聯條件
5. 建立處置紀錄
6. 追蹤異常趨勢
