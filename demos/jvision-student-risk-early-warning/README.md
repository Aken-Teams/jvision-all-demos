# 學習風險預警輔導平台

> 彙整模擬出缺席、作業、評量與互動紀錄，辨識學習投入下降、連續缺交及成績滑落等風險，提供可解釋的預警依據、分級處置建議與跨導師、任課教師及輔導人員的協作追蹤。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **學習風險總覽** — 依班級、年級與風險層級呈現學生分布、趨勢及待辦。
- **預警案件清單** — 列出新增、升級、待確認與持續觀察的學生風險案件。
- **風險證據解析** — 整合缺席、缺交、成績及互動變化，說明預警形成原因。
- **介入計畫中心** — 建立關懷訪談、補救教學、家長聯繫與追蹤期限。
- **輔導協作紀錄** — 以角色權限展示跨教師訊息、會談摘要與任務交接。
- **風險改善追蹤** — 比較介入前後指標與風險等級，辨識有效措施。

## 適合誰使用

- 班級導師
- 任課教師
- 輔導教師
- 教務主管

## 運作流程

1. 掌握風險分布
2. 確認預警案件
3. 核對風險證據
4. 制定介入計畫
5. 執行協作輔導
6. 評估風險改善

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
