# 企業策略管理洞察站

協助集團規劃中長期經營策略、追蹤策略專案執行進度並支援決策沙盤推演。

- 原始系統：企業策略管理系統
- 產業分類：智慧製造｜經營管理
- 使用部門：總經理室、經營企劃部、事業處、財務部
- 工作流程：市場情勢分析 → 策略選項評估 → 策略專案立案 → 資源配置 → 執行追蹤 → 成效檢討
- AI 應用：市場情境自動模擬與敏感度分析、策略風險與機會自動辨識
- 主要 KPI：策略專案準時完成率、策略投資報酬率、市場反應時效、策略達成率
- 代表產品：Oracle Strategic Planning、Anaplan、SAP Analytics Cloud策略模組
