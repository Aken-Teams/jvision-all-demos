# OEE 稼動洞察站

> 保養、維修、預兆到備品的設備全生命週期

把稼動率、性能、品質與停機事件轉成改善洞察。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生產製造　|　**系統類型：**CMMS 設備維護

## 功能模組

- **保養排程** — 預防保養自動排程
- **維修工單** — 報修、派工與完工
- **預兆診斷** — 設備數據異常預警
- **備品管理** — 備品庫存與領用
- **OEE 稼動** — 稼動與故障分析
- **履歷追溯** — 設備維護履歷

## 適合誰使用

- 生管專員
- 製造課長
- 廠長

## 運作流程

1. 待排程
2. 生產中
3. 待品檢
4. 已入庫

## 導入效益

- 排程作業工時：7.8小時/日 → **1.6小時/日**
- 準時交付率：80% → **99%**
- 缺料停線次數：12次/月 → **2.8次/月**
- 設備稼動率：77% → **84%**
