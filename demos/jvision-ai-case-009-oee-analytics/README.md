# OEE 稼動洞察站

> 稼動、性能、品質到六大損失的稼動洞察全景

把稼動率、性能、品質與停機事件轉成改善洞察。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生產製造　|　**系統類型：**OEE 稼動分析

## 功能模組

- **稼動總覽** — 全廠 OEE 戰情與即時稼動
- **OEE 分析** — 稼動×性能×良率三率拆解
- **六大損失** — 六大損失 Pareto 歸因分析
- **產線比較** — 產線與班別稼動對比
- **停機分析** — 停機事件與趨勢追蹤
- **改善追蹤** — 改善行動與成效追蹤

## 適合誰使用

- 生管專員
- 製造課長
- 廠長

## 運作流程

1. 採集稼動數據
2. 計算三率 OEE
3. 歸因六大損失
4. 比較產線班別
5. 追蹤改善成效

## 導入效益

- 排程作業工時：7.8小時/日 → **1.6小時/日**
- 準時交付率：80% → **99%**
- 缺料停線次數：12次/月 → **2.8次/月**
- 設備稼動率：77% → **84%**
