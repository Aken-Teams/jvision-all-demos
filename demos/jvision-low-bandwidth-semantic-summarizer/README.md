# 低頻寬語意摘要器

在邊緣端提煉事件、特徵與代表片段，只傳必要資訊以節省網路頻寬。

**產業別：**設備維護　|　**系統類型：**operations-console

## 功能模組

- **邊緣事件篩選** — 從連續感測與影像流辨識值得回傳的事件。
- **語意特徵提煉** — 將原始訊號壓縮成可搜尋的物件、狀態與特徵。
- **代表片段擷取** — 挑選最能說明事件前因後果的影像或波形片段。
- **現場摘要生成** — 產生含時間、設備、嚴重度與可信度的事件摘要。
- **頻寬配額編排** — 依連線品質與事件優先級配置上傳資源。
- **摘要傳輸驗證** — 確認雲端收到完整摘要、特徵與必要代表片段。

## 適合誰使用

- IoT 架構師
- 設備工程師
- 場域主管

## 運作流程

1. 設定篩選
2. 提煉特徵
3. 選取片段
4. 生成摘要
5. 配置頻寬
6. 驗證送達

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
