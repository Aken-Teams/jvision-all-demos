# 投資專案組合最佳化器

> 集中評估設備、數位化與市場拓展等投資提案，以預算、資源、風險及策略貢獻建立擬真比較，模擬不同專案組合並協助排定核准與遞延順序。

**產業別：**財務會計　|　**系統類型：**finance-case

## 功能模組

- **投資提案池** — 彙整待評估提案、申請金額、負責單位與審查狀態。
- **專案價值評分** — 比較財務效益、策略契合、急迫性與風險分數。
- **資源限制盤點** — 檢視年度預算、人力、設備停機及執行容量限制。
- **組合模擬器** — 勾選不同專案組合並即時比較整體價值與資源使用。
- **壓力測試** — 調整成本、效益與時程假設，觀察組合穩健程度。
- **投資決策台** — 整理核准、候補與遞延建議及其決策理由。

## 適合誰使用

- 企業主
- 財務主管
- 投資審查委員與專案管理人員

## 運作流程

1. 盤點投資提案
2. 評估專案價值
3. 確認資源限制
4. 建立候選組合
5. 執行壓力測試
6. 形成投資決策
