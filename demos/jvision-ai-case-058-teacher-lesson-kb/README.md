# 教師備課知識庫

> 任務、專案、知識到流程自動化的團隊協作

彙整教材、教案、學習單與 AI 備課建議。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**教育　|　**系統類型：**協作 / 專案平台

## 功能模組

- **任務看板** — 任務指派與進度
- **專案協作** — 專案與里程碑
- **知識文件** — 文件與知識庫
- **流程自動化** — 表單簽核自動化
- **團隊溝通** — 討論與通知
- **工作報表** — 產能與進度報表

## 適合誰使用

- 教務專員
- 教務主任
- 機構負責人

## 運作流程

1. 待安排
2. 進行中
3. 待確認
4. 已完成

## 導入效益

- 排課作業工時：5.9小時/週 → **1.6小時/週**
- 作業批改時效：5天 → **1.1天**
- 出席掌握率：71% → **89%**
- 學習進度可視：47% → **86%**
