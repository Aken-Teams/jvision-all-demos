# 軋延製程參數最佳化系統

> 整合擬真的鋼種、規格、設備限制與歷史生產結果，產生軋延速度、輥縫、張力及冷卻量的參數建議，讓工程師比較多種方案對品質、產能與能耗的影響，再形成可追蹤的製程配方。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **製程績效總覽** — 統整品質、產能、能耗與待審參數方案等關鍵指標。
- **生產條件設定** — 選擇鋼種、厚度、寬度、目標產量及設備限制。
- **參數方案產生** — 以擬真資料產生速度、輥縫、張力和冷卻量的候選組合。
- **方案效益比較** — 並列比較品質風險、產量、能耗與限制符合程度。
- **方案審核** — 呈現調整差異、風險提示與主管核准或退回紀錄。
- **製程配方庫** — 保存核准方案並依鋼種、規格與版本查找模擬配方。

## 適合誰使用

- 軋延製程工程師
- 生產主管與廠長

## 運作流程

1. 檢視製程績效
2. 建立生產條件
3. 產生候選參數
4. 比較方案效益
5. 審核建議方案
6. 建立配方版本

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
