# 電纜盤具回收周轉台

> 供電纜廠逐只管理木盤與鐵盤的規格、出貨客戶、押金、預計回收日及破損狀態，安排催回與整修，避免缺盤影響成品裝載。

供電纜廠逐只管理木盤與鐵盤的規格、出貨客戶、押金、預計回收日及破損狀態，安排催回與整修，避免缺盤影響成品裝載。

**產業別：**倉儲物流　|　**系統類型：**warehouse-wms

## 功能模組

- **盤具總覽** — 查看規格與狀態
- **出貨綁定** — 連結客戶與押金
- **在外追蹤** — 顯示逾期盤具
- **催回清單** — 安排客戶聯繫
- **回收驗傷** — 記錄缺件破損
- **整修周轉** — 追蹤可用日期

## 適合誰使用

- 盤具管理員
- 出貨人員

## 運作流程

1. 盤具配發
2. 成品裝盤
3. 隨貨出場
4. 到期催回
5. 返廠驗傷
6. 押金結清

## 導入效益

- 揀貨作業工時：7小時/日 → **2小時/日**
- 庫存準確率：88% → **99%**
- 出貨延遲率：9% → **2%**
- 盤點工時：16小時/月 → **3小時/月**
