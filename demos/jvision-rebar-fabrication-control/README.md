# 鋼筋加工配料管制台

> 依結構圖與施工區拆解鋼筋料單，管理續接器、定尺加工、損耗估算、加工場批次及樓層到料，讓現場能追蹤缺料、餘料與圖說變更造成的重製。

依結構圖與施工區拆解鋼筋料單，管理續接器、定尺加工、損耗估算、加工場批次及樓層到料，讓現場能追蹤缺料、餘料與圖說變更造成的重製。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **需求總覽** — 按樓層與構件呈現鋼筋需求及供料狀態。
- **配料拆解** — 建立筋號、尺寸、數量、續接及定尺需求。
- **料單審核** — 比對圖說版本並完成工地與分包確認。
- **加工排程** — 安排加工批次、機台負荷與預定出貨。
- **到料點收** — 依批次核對標籤、重量與卸料區域。
- **餘料變更** — 管理停製、重製、餘料轉用與損耗原因。

## 適合誰使用

- 鋼筋工程師
- 加工場排程員
- 材料管理員

## 運作流程

1. 需求總覽
2. 配料拆解
3. 料單審核
4. 加工排程
5. 到料點收
6. 餘料變更

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
