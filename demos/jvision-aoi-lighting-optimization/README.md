# 光學檢測光源最佳化台

> 依產品材質、缺陷類型與模擬影像評分，比較自動光學檢測（AOI）的亮度、角度、色溫及通道組合，提供參數搜尋、候選方案比較、影像預覽與配方核准，協助工程師縮短換線時的光源調校時間。

依產品材質、缺陷類型與模擬影像評分，比較自動光學檢測（AOI）的亮度、角度、色溫及通道組合，提供參數搜尋、候選方案比較、影像預覽與配方核准，協助工程師縮短換線時的光源調校時間。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **光源任務總覽** — 查看換線任務、最佳化進度、候選配方與待核准項目。
- **光源條件設定** — 選擇產品、材質、目標缺陷及模擬檢測場景。
- **參數搜尋空間** — 設定亮度、角度、色溫與通道的可選範圍。
- **候選方案排行** — 依對比、均勻度與反光抑制分數排列候選配方。
- **影像效果比較** — 並排檢視不同參數下的模擬影像與缺陷可見度。
- **標準配方核准** — 記錄驗證結果並建立產品適用的光源配方版本。

## 適合誰使用

- 設備工程師
- 製程工程師
- 品保工程師

## 運作流程

1. 建立調校任務
2. 定義光源條件
3. 設定搜尋範圍
4. 比較候選配方
5. 驗證影像效果
6. 核准標準配方

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**

- 設備稼動率：74% → **88%**
