# 合約風險標記台

> 案件、庭期、合約到工時計費的法務管理

以 AI 標記合約風險條款與待確認事項。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**專業服務　|　**系統類型：**法務案件管理

## 功能模組

- **案件管理** — 案件建檔與進度
- **庭期管理** — 開庭與期限提醒
- **合約管理** — 合約審閱與風險
- **工時計費** — 工時記錄與計費
- **文件管理** — 文件版本與檢索
- **案件追溯** — 全程紀錄與稽核

## 適合誰使用

- 案件管理專員
- 專案合夥人
- 事務所負責人

## 運作流程

1. 待受理
2. 執行中
3. 客戶確認
4. 已結案

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：69% → **94%**
- 計費遺漏：11% → **1.9%**
- 進度查找時間：20分鐘 → **3.1分鐘**
