# 訂單與庫存管理

> 收貨到出貨的倉內作業與庫存精準管理

把網路訂單、門市庫存、保留量與出貨狀態放在同一畫面，避免商品已售出但庫存尚未扣帳。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**零售電商　|　**系統類型：**WMS 倉儲管理系統

## 功能模組

- **入庫上架** — 收貨、驗收與智慧上架
- **揀貨出貨** — 波次揀貨、覆核與出貨
- **儲位管理** — 儲位規劃與庫容視覺化
- **庫存盤點** — 即時庫存、盤點與調撥
- **拉動補料** — 安全庫存與自動補貨
- **條碼作業** — PDA 掃碼即時作業

## 適合誰使用

- 電商營運專員

## 運作流程

1. 接收並檢查新訂單
2. 保留可用庫存並建立揀貨單
3. 完成出貨並回寫庫存

## 導入效益

- 補貨反應：25小時 → **3.8小時**
- 熱銷掌握率：59% → **94%**
- 缺貨率：12% → **3.8%**
- 結帳等待：5.8分鐘 → **1.5分鐘**
