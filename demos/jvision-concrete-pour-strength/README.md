# 混凝土澆置強度預測助手

> 整合擬真的配比、澆置條件、坍度、試體與養護紀錄，以視覺化模型預估混凝土強度發展及異常風險，協助品管人員提早安排複驗、拆模判斷與改善措施。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **澆置排程看板** — 呈現區域、構件、供料批次與品質準備狀態。
- **澆置前檢核** — 核對配比、材料證明、天候與人員準備項目。
- **現場抽驗紀錄** — 輸入坍度、溫度、取樣與試體編號等擬真資料。
- **強度曲線預測** — 呈現各齡期預測值、信賴區間與達標日期。
- **批次異常診斷** — 比較批次表現並列出可能風險因子與證據。
- **處置與放行** — 管理複驗、養護改善、拆模建議及簽核結果。

## 適合誰使用

- 工地品管人員
- 監造工程師
- 試驗室人員
- 工地主任

## 運作流程

1. 安排澆置
2. 檢查條件
3. 登錄抽驗
4. 預測強度
5. 診斷異常
6. 決定處置

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
