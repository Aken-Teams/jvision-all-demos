# 追加減帳議價追蹤台

> 彙整追加減工作的指示依據、施工前照片、數量計算、廠商報價與議價紀錄，追蹤暫定價、核定價及尚未談定的成本曝險。

彙整追加減工作的指示依據、施工前照片、數量計算、廠商報價與議價紀錄，追蹤暫定價、核定價及尚未談定的成本曝險。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **追加清冊** — 查看金額與核價狀態
- **依據彙整** — 連結指示圖說及照片
- **數量估價** — 編列數量成本與報價
- **議價紀錄** — 保存每輪條件與金額
- **核價簽認** — 確認正式增減價款
- **曝險分析** — 追蹤已做未定價金額

## 適合誰使用

- 合約工程師
- 成本工程師
- 專案經理

## 運作流程

1. 建立案件
2. 整理依據
3. 編列報價
4. 進行議價
5. 完成簽認
6. 更新合約

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
