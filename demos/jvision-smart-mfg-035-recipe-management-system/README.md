# 配方管理系統（Recipe Management System）

> 訂單到入庫的製造現場全流程數位化

配方管理系統（Recipe Management System）提供配方版本控管、配方自動下載至設備、配方使用權限管理。製程工程依「配方建立審核 → 版本發布 → 設備自動下載 → 執行紀錄比對 → 異常配方攔截」推進作業，優先解決「配方版本混淆造成製程異常」，設備工程則以配方錯誤事件數與配方版本一致率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生產製造　|　**系統類型：**MES 製造執行系統

## 功能模組

- **工單管理** — 訂單轉工單、拆併單與工單派發
- **排程排產** — 依產能、交期、負載自動排程
- **現場執行** — 派工、報工與進度即時回報
- **設備稼動 OEE** — 稼動、效率、良率即時監控
- **品質入庫** — 檢驗判定、不良處置與入庫
- **AI 改善建議** — 異常摘要與瓶頸改善建議

## 適合誰使用

- 製程工程
- 設備工程
- 品保

## 運作流程

1. 待排程
2. 生產中
3. 待品檢
4. 已入庫

## 導入效益

- 排程作業工時：7.8小時/日 → **1.6小時/日**
- 準時交付率：80% → **99%**
- 缺料停線次數：12次/月 → **2.8次/月**
- 設備稼動率：77% → **84%**
