# FTO 特徵比對台

> 把產品 BOM 與規格逐項對照有效專利請求項，支援上市前 FTO 判斷。

把產品 BOM 與規格逐項對照有效專利請求項，支援上市前 FTO 判斷。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **產品特徵清單** — 從 BOM、圖面與規格整理產品元件、功能及技術關係。
- **有效請求項池** — 彙整目標市場內有效、待審及即將到期的相關請求項。
- **請求項拆解器** — 將獨立與附屬請求項拆成可逐項判讀的技術限制。
- **產品請求項對照表** — 以 claim chart 標示產品特徵對各項限制的符合、疑似或不符
- **FTO 風險評分器** — 綜合覆蓋程度、法律狀態、地域與產品暴露計算風險。
- **上市決策方案室** — 比較設計迴避、授權、無效挑戰與市場限制等處置方案。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 整理產品特徵
2. 篩選有效專利
3. 拆解請求項限制
4. 完成逐項比對
5. 評估 FTO 風險
6. 審定上市方案

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
