# 得標機率情境評估器

> 綜合競爭、客戶關係、方案差異與資源條件，模擬標案得標機率。 profiles.

綜合競爭、客戶關係、方案差異與資源條件，模擬標案得標機率。 profiles.

**產業別：**專業服務　|　**系統類型：**analytics-bi

## 功能模組

- **基準勝率模型** — 以歷史投標結果與案件特徵估算初始得標區間。
- **競爭態勢盤** — 比較可能競爭者的實績、價格傾向與優勢領域。
- **關係覆蓋評估** — 呈現決策角色、互動深度與需求理解的覆蓋程度。
- **差異化強度表** — 評估技術、服務、實績與商務條件的可辨識優勢。
- **情境模擬器** — 調整價格、夥伴、團隊與方案策略以觀察勝率變化。
- **Go／No-Go 決** — 整合勝率、成本與信心範圍，形成投標決策建議。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 建立基準預測
2. 研判競爭態勢
3. 校準關係覆蓋
4. 量化方案差異
5. 比較策略情境
6. 作成投標決策

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
