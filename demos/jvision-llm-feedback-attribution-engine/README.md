# LLM 使用者回饋歸因器

> 將負評精準歸因至模型、提示、檢索與資料版本，建立可追責的改善閉環。

將負評精準歸因至模型、提示、檢索與資料版本，建立可追責的改善閉環。

**產業別：**資訊科技　|　**系統類型：**analytics-bi

## 功能模組

- **負評語意收件匣** — 依錯誤類型、影響範圍與使用情境聚合低評分回饋。
- **回應版本血緣圖** — 還原單次回應使用的模型、提示、檢索器與知識版本。
- **版本差異比對** — 比較正常與異常請求的提示、參數、知識片段及輸出差異。
- **根因歸因工作台** — 計算各候選責任點的歸因信心、風險與支持證據。
- **改善責任案件** — 把確認的根因轉為具負責人、期限與驗收條件的改善案件。
- **修正成效驗證** — 用評測集與線上回饋驗證修正版本是否降低同類負評。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 彙整負評
2. 還原血緣
3. 比對差異
4. 確認根因
5. 指派改善
6. 驗證結案
