# 配送空趟原因認定台

> 彙整司機到場、聯絡、定位照片與客戶預約紀錄，依證據判定無人收貨、地址錯誤、車輛遲到或現場拒收，決定二次配送、空趟費及責任歸屬。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **空趟案件** — 彙整未交付車次
- **到場證據** — 整理時間照片與聯絡紀錄
- **預約核對** — 比對時窗地址與承諾
- **原因判定** — 裁定客戶司機或內部責任
- **重派安排** — 建立二次配送與新時窗
- **費用結算** — 核定空趟費及內部吸收

## 適合誰使用

- 配送調度
- 客服人員
- 運費結算員

## 運作流程

1. 建立案件
2. 補齊證據
3. 核對預約
4. 認定原因
5. 安排重派
6. 完成結算

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
