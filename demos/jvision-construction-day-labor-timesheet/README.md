# 工地點工工時核對台

> 逐日核對點工人員、工區、工種、正常與加班時數，串連現場簽認及包商月結表，攔截重複出勤、未核准加班與冒名計價。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **人員名冊** — 管理工種、包商與資格。
- **每日工時** — 記錄工區及正常加班。
- **現場簽認** — 由監工確認實際出勤。
- **月結比對** — 比較日單與包商申報。
- **異常調查** — 標示重複及超時紀錄。
- **工資結算** — 核准可計價工時。

## 適合誰使用

- 工地主任
- 點工管理員
- 成本會計

## 運作流程

1. 建立名冊
2. 登錄工時
3. 現場簽認
4. 匯入月結
5. 處理差異
6. 核准結算

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
