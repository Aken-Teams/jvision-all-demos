# 壓鑄氣孔缺陷預測系統

> 整合擬真的合金批次、射出曲線、模溫、真空及冷卻條件，預測壓鑄件內部氣孔的發生機率、位置與嚴重度，協助工程師在生產前比較參數方案、管制高風險批次，並追蹤抽驗結果，降低加工後才發現的報廢損失。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **氣孔風險總覽** — 依工單、機台與料號呈現氣孔風險、待確認方案和批次狀態。
- **缺陷位置模擬** — 以工件剖面與區域熱圖呈現預測氣孔位置、大小及嚴重度。
- **成因診斷分析** — 分析射出速度、真空、模溫及合金條件對氣孔風險的影響。
- **參數情境試算** — 比較不同射出曲線、增壓點與真空設定下的預測結果。
- **生產方案核准** — 保存建議參數、風險說明、抽驗計畫與主管核准紀錄。
- **抽驗驗證追蹤** — 以擬真切片或氣密結果回填批次，追蹤預測差異與改善成效。

## 適合誰使用

- 壓鑄製程工程師
- 品質工程師
- 生產課長與模具工程師

## 運作流程

1. 辨識高風險批次
2. 確認氣孔位置
3. 診斷關鍵成因
4. 試算改善參數
5. 核准生產方案
6. 驗證批次結果

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
