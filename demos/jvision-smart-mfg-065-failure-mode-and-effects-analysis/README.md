# FMEA指揮台

系統化評估設計或製程潛在失效模式，量化風險並優先排序改善，屬預防性品質工具。

- 原始系統：FMEA（Failure Mode and Effects Analysis）
- 產業分類：智慧製造｜品質管理
- 使用部門：研發部、製程工程部、品保部、生產部
- 工作流程：建立團隊→列舉失效模式→評分計算RPN→擬定改善措施→追蹤更新
- AI 應用：歷史失效知識庫比對、RPN異常評分提示、改善建議生成
- 主要 KPI：高風險項目改善完成率、RPN下降幅度、設計變更觸發FMEA更新率
- 代表產品：APIS IQ-FMEA、PTC Windchill FMEA、Minitab、以客製化開發為主
