# 旅宿通路房價維護台

> 集中管理各訂房通路的房型、房價、日期區間與取消條件，讓收益人員逐站覆核發布結果，及早攔截漏改、錯價與房型代碼誤配。

集中管理各訂房通路的房型、房價、日期區間與取消條件，讓收益人員逐站覆核發布結果，及早攔截漏改、錯價與房型代碼誤配。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **調價總覽** — 查看日期、房型與通路的維護進度。
- **價期設定** — 建立房價、庫存方案與適用區間。
- **房型對照** — 核對內部房型與通路方案代碼。
- **差異檢查** — 比對價格、餐別及取消條件。
- **發布覆核** — 由主管確認高風險異動。
- **版本紀錄** — 追蹤每次修改與發布證據。

## 適合誰使用

- 收益經理
- 訂房主管
- 通路專員

## 運作流程

1. 建立批次
2. 設定價期
3. 核對映射
4. 檢查差異
5. 核准發布
6. 完成存證

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
