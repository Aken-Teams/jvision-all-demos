# GraphRAG 路徑解釋器

> 視覺化 GraphRAG 答案所經實體、關係與文件路徑，協助使用者理解推理依據。

視覺化 GraphRAG 答案所經實體、關係與文件路徑，協助使用者理解推理依據。

**產業別：**企業協作　|　**系統類型：**analytics-bi

## 功能模組

- **答案與主張拆解** — 將生成答案拆為可驗證主張，標示信心與仍有不確定性的部分。
- **實體路徑圖** — 展示人員、組織、產品、事件及概念間的推理連接路徑。
- **文件節點檢視** — 開啟路徑引用的文件段落、時間、版本與來源系統。
- **關係依據解析** — 說明實體關係由哪些敘述、資料欄位或推斷規則建立。
- **替代路徑比較** — 比較支持同一主張的不同路徑、長度、來源品質與一致性。
- **路徑可信度評估** — 綜合節點權威性、關係強度、時效與衝突計算可理解的可信度。

## 適合誰使用

- 知識工作者
- 主管
- 客服

## 運作流程

1. 選取答案主張
2. 展開實體路徑
3. 查閱文件節點
4. 解讀關係依據
5. 比較替代路徑
6. 確認答案可信度
