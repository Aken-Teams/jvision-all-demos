**產業別：**房地產與物業　|　**系統類型：**service-desk

## 功能模組

- **客訴受理** — 記錄租戶、區域與體感。
- **區域聚合** — 合併同樓層相關案件。
- **技師派工** — 安排人員與優先序。
- **處置紀錄** — 保存量測與修復結果。
- **復發追蹤** — 關聯再次通報與根因。
- **租戶回覆** — 同步進度及完成確認。

## 適合誰使用

- 租戶服務
- 機電技師
- 物業主任

## 運作流程

1. 受理通報
2. 合併事件
3. 安排派工
4. 執行處置
5. 觀察復發
6. 租戶確認

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
