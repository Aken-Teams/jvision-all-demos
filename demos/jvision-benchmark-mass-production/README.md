# 實品樣板量產核定台

> 管理外牆、客房、衛浴與公共區域等實品樣板，彙整材料、工法、色澤及業主意見，將核定條件轉成量產基準並控管後續變更，避免各樓層施作品質走樣。

管理外牆、客房、衛浴與公共區域等實品樣板，彙整材料、工法、色澤及業主意見，將核定條件轉成量產基準並控管後續變更，避免各樓層施作品質走樣。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **樣板案件** — 建立樣板位置、適用工項、廠商與審查節點。
- **材料工法** — 彙整材料型號、色號、施工層次與細部做法。
- **會勘意見** — 依構件記錄業主、設計與監造的意見。
- **修正複核** — 呈現修改前後差異與各項覆核結果。
- **量產基準** — 發布核定照片、允收標準及適用樓層。
- **變更沿革** — 追蹤量產後材料替代或設計調整的核准歷程。

## 適合誰使用

- 裝修工程師
- 設計監造
- 業主代表

## 運作流程

1. 提報實品樣板
2. 登錄材料工法
3. 執行聯合會勘
4. 完成樣板修正
5. 核定量產基準
6. 管制後續變更

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
