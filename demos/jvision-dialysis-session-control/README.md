# 透析療程作業管理台

> 供透析院所安排固定療程、床位班次、處方參數確認、檢驗待辦、異常事件與返家交班，降低重複療程中的漏項與資訊斷點。

供透析院所安排固定療程、床位班次、處方參數確認、檢驗待辦、異常事件與返家交班，降低重複療程中的漏項與資訊斷點。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **療程班表** — 依患者頻率安排日期、床位與班次。
- **治療前核對** — 確認處方、體重、檢驗與注意事項。
- **療程紀錄** — 呈現分段生命徵象及作業紀錄。
- **檢驗追蹤** — 管理定期檢驗與異常複查待辦。
- **異常事件** — 記錄處置、醫師指示及後續觀察。
- **返家交班** — 整理衛教、用藥與下次療程提醒。

## 適合誰使用

- 透析護理師
- 腎臟科醫師
- 護理長

## 運作流程

1. 安排班次
2. 療前核對
3. 開始療程
4. 追蹤檢驗
5. 處理異常
6. 完成交班

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
