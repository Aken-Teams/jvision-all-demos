# 設計迴避方案探索器

> 針對專利高風險技術元素探索替代路徑，協助研發降低侵權風險。研發設計迴避／FTO 高風險元素拆解／替代技術決策。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **高風險元素清單** — 列出可能落入權利項的產品元件、功能與技術特徵。
- **權利項要素拆解** — 把獨立與附屬權利項拆成可供工程判讀的必要要素。
- **替代原理探索** — 為高風險要素產生不同原理、結構或流程的技術路徑。
- **迴避候選比較** — 比較候選方案的侵權距離、效能、成本與開發難度。
- **工程可行性驗證** — 記錄模擬、樣機與測試結果，驗證替代方案是否可落地。
- **方案決策核准** — 選定設計迴避方案並核准研發變更與後續驗證工作。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 鎖定風險元素
2. 解析權利邊界
3. 生成替代路徑
4. 排序迴避候選
5. 驗證工程可行性
6. 核准設計變更
