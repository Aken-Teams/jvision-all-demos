## 功能模組

- **答案主張拆解** — 將回答拆成可獨立驗證的事實、數字與推論主張。
- **主張引用配對** — 建立每項主張與引用片段、原始文件之間的對應。
- **引用支持度檢查** — 判斷來源是否直接、部分或完全未支持答案主張。
- **來源可開啟驗證** — 測試文件權限、網址有效性、版本與錨點定位。
- **跨來源佐證圖** — 顯示多份文件對主張的支持、衝突與引用傳遞關係。
- **完整性審核包** — 彙整缺引、錯引與失效引用，產生可修改的審核結論。

## 適合誰使用

## 運作流程

1. 選取待審答案
2. 拆分可驗主張
3. 配對引用來源
4. 驗證支持與存取
5. 審閱缺引與衝突
6. 簽核完整性結果
