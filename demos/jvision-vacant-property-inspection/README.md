# 空屋代管巡檢交付台

> 依代管合約建立每戶巡檢週期、必拍位置與異常處置，將有時間地點脈絡的照片整理成屋主交付報告，證明漏水、門窗及設備已按期查驗。

**產業別：**房地產與物業　|　**系統類型：**maintenance-cmms

## 功能模組

- **巡檢排程** — 安排戶別週期與路線
- **巡檢表單** — 逐項確認門窗水電設備
- **定位照片** — 綁定戶別位置與時間
- **異常通報** — 建立漏水損壞等案件
- **改善追蹤** — 連結派工與複查結果
- **屋主報告** — 產出履約與異常摘要

## 適合誰使用

- 代管巡檢員
- 物業主管
- 客服專員

## 運作流程

1. 排定巡檢任務
2. 執行逐戶查驗
3. 上傳位置照片
4. 建立異常案件
5. 覆核改善結果
6. 交付巡檢報告

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
