# 沖壓廢料秤重交售台

> 供沖壓廠按鋼種、銅料與料斗記錄產線交廢、內磅、扣桶重、裝車及回收商磅單，核對牌價與磅差，降低混料、短重和私運風險。

供沖壓廠按鋼種、銅料與料斗記錄產線交廢、內磅、扣桶重、裝車及回收商磅單，核對牌價與磅差，降低混料、短重和私運風險。

**產業別：**倉儲物流　|　**系統類型：**warehouse-wms

## 功能模組

- **料斗總覽** — 查看材質與重量
- **內部過磅** — 扣除桶重建批
- **材質覆核** — 防止高低價混料
- **裝車交運** — 記錄封條與車號
- **磅差比對** — 核對回收商磅單
- **牌價結算** — 確認單價與收入

## 適合誰使用

- 廢料庫管員
- 財務人員

## 運作流程

1. 產線交廢
2. 料斗過磅
3. 材質封存
4. 裝車點交
5. 外磅回證
6. 價款核准

## 導入效益

- 揀貨作業工時：7小時/日 → **2小時/日**
- 庫存準確率：88% → **99%**
- 出貨延遲率：9% → **2%**
- 盤點工時：16小時/月 → **3小時/月**
