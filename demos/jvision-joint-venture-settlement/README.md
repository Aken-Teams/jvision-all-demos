# 聯合承攬分帳結算台

> 依聯合承攬協議管理成員出資、代墊、共同成本、專屬成本、業主收款及分配比例，透過逐筆認列與對帳完成各期分帳及完工結算。

依聯合承攬協議管理成員出資、代墊、共同成本、專屬成本、業主收款及分配比例，透過逐筆認列與對帳完成各期分帳及完工結算。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **聯營總覽** — 呈現各成員權益與未結餘額。
- **協議參數** — 維護出資及成本分配規則。
- **收支歸集** — 匯入業主收款與專案支出。
- **成本分攤** — 判定共同、專屬及代墊成本。
- **成員對帳** — 產出應收應付與差異明細。
- **結算確認** — 管理異議、調整與正式結算。

## 適合誰使用

- 專案會計
- 財務主管
- 聯營管理員

## 運作流程

1. 檢視聯營權益
2. 設定分帳規則
3. 彙集專案收支
4. 執行成本分攤
5. 發送成員對帳
6. 核定分帳結算

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
