# 電子料件缺料預警系統

> 供應商協同、詢比議價到交期風險控管

電子料件缺料預警系統提供關鍵料件交期監控、市場缺料資訊彙整、安全庫存水位預警。採購部依「料件監控 → 缺料訊號偵測 → 影響訂單模擬 → 應變對策擬定 → 跨部門通報」推進作業，優先解決「晶片/被動元件缺料資訊掌握滯後」，生產計畫部則以缺料預警提前天數與缺料導致停線次數確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**採購供應鏈　|　**系統類型：**SRM 採購供應商管理

## 功能模組

- **供應商管理** — 建檔、分級與績效評分
- **詢報價協作** — 線上詢價、比價與議價
- **採購訂單** — 請購、下單與交期追蹤
- **交期風險** — 缺料預警與到貨監控
- **供應商品質** — 進料檢驗與 SCAR 改善
- **綠色採購** — ESG 評分與永續採購

## 適合誰使用

- 採購部
- 生產計畫部
- 業務部

## 運作流程

1. 待詢價
2. 比價中
3. 待核准
4. 驗收完成

## 導入效益

- 採購前置時間：12天 → **5.3天**
- 準時到貨率：85% → **96%**
- 缺料預警覆蓋：39% → **86%**
- 議價作業工時：8.5小時/週 → **2小時/週**
