# 會議決策承諾追蹤助理

> 將擬真會議紀錄整理成決策、承諾事項與待確認問題，讓團隊指派負責人、期限及驗收條件，並透過逾期提醒與決策回顧維持執行閉環。

**產業別：**企業協作　|　**系統類型：**collaboration-pm

## 功能模組

- **會議工作區** — 查看會議清單、參與者、目的與近期需處理事項。
- **紀錄整理** — 從預載會議內容整理重點、問題與待確認語句。
- **決策登錄簿** — 記錄決策內容、採用理由、影響範圍與決定人。
- **承諾事項板** — 管理負責人、期限、驗收條件與目前執行狀態。
- **逾期阻礙中心** — 集中顯示逾期承諾、卡關原因與需要協助的事項。
- **成果驗收** — 檢視交付證據、確認完成品質並保留回顧紀錄。

## 適合誰使用

- 專案經理
- 部門主管
- 會議主持人與行政幕僚

## 運作流程

1. 建立會議工作區
2. 整理會議重點
3. 確認正式決策
4. 分派承諾事項
5. 排除逾期阻礙
6. 驗收並完成回顧
