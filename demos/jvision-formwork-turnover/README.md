# 系統模板周轉盤點台

> 供鋁模與系統模板工班按樓層點交牆板、梁板、支撐及銷片，記錄損壞、缺件與修整去向，避免轉層後才發現關鍵板件短少。

供鋁模與系統模板工班按樓層點交牆板、梁板、支撐及銷片，記錄損壞、缺件與修整去向，避免轉層後才發現關鍵板件短少。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **套組總覽** — 查看樓層齊套度
- **拆模點收** — 逐件確認數量
- **損傷分級** — 記錄修整需求
- **轉層配套** — 配置下一樓層
- **補件追蹤** — 追蹤借調與採購
- **期末盤點** — 結清遺失損壞

## 適合誰使用

- 模板班長
- 材料管理員

## 運作流程

1. 建立套組
2. 拆模點收
3. 損傷判定
4. 樓層配套
5. 吊運交接
6. 組模結清

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
