# 應收帳款催收管理 AR/Collections Management智慧站

追蹤客戶應收帳款狀態並協同業務進行逾期催收，降低壞帳風險並改善現金流。

- 原始系統：應收帳款催收管理 AR/Collections Management
- 產業分類：智慧製造｜業務管理
- 使用部門：財務部、業務部、信用管理部、管理層
- 工作流程：帳款到期監控→逾期分級→指派業務/財務催收→跟進催收結果→呆帳風險評估上報
- AI 應用：客戶付款行為模式分析、催收優先順序智慧排序
- 主要 KPI：帳款周轉天數(DSO)、逾期回收率、呆帳率、催收任務完成率
- 代表產品：SAP Collections Management、HighRadius、鼎新ERP應收帳款模組
