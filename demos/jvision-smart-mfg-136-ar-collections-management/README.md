# 應收帳款催收管理 AR/Collections Management

> 受理、審核、風險到撥付的案件審查流程

應收帳款催收管理 AR/Collections Management提供應收帳款到期監控、逾期分級與催收排程、業務/財務協同催收任務。財務部依「帳款到期監控→逾期分級→指派業務/財務催收→跟進催收結果→呆帳風險評估上報」推進作業，優先解決「業務只顧接單忽略收款」，業務部則以帳款周轉天數(DSO)與逾期回收率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**業務銷售　|　**系統類型：**金融 / 保險案件系統

## 功能模組

- **案件受理** — 理賠/貸款案件建立
- **審核初核** — 文件審查與資格核對
- **風險評分** — 風險模型與評分
- **覆核核准** — 多層覆核與核決
- **撥付理算** — 理算與撥款作業
- **案件追溯** — 全程紀錄與稽核

## 適合誰使用

- 財務部
- 業務部
- 信用管理部

## 運作流程

1. 需求確認
2. 方案評估
3. 報價議合
4. 已成交

## 導入效益

- 商機轉換率：17% → **29%**
- 平均回應時間：27小時 → **6小時**
- 客戶資料完整率：61% → **88%**
- 報價逾期流失：9.5件/月 → **2件/月**
