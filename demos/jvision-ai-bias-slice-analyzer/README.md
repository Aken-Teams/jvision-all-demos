# AI 偏誤切片分析器

> 按族群、地區、產品與情境切片比較錯誤率，揭露平均值掩蓋的不公平。

按族群、地區、產品與情境切片比較錯誤率，揭露平均值掩蓋的不公平。

**產業別：**資訊安全　|　**系統類型：**analytics-bi

## 功能模組

- **評測母體設計器** — 定義基準資料、預測結果、真值與受保護屬性。
- **偏誤切片建構器** — 組合族群、地區、產品及情境條件建立交叉分析切片。
- **錯誤率比較矩陣** — 並列各切片的誤判率、漏判率、校準度與樣本量。
- **公平落差偵測** — 找出顯著偏離整體或參照群體的高風險切片。
- **偏誤原因實驗室** — 檢驗資料代表性、標註、特徵與決策閾值造成的落差。
- **緩解方案驗證** — 模擬重採樣、閾值調整或模型修正對公平與效能的影響。

## 適合誰使用

- CISO
- AI 治理主管
- 資安分析師

## 運作流程

1. 建立評測母體
2. 定義比較切片
3. 比較錯誤指標
4. 確認公平落差
5. 分析偏誤來源
6. 核准緩解方案
