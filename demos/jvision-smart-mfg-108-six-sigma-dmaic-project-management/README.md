# Six Sigma/DMAIC Project Management協作所

管理六標準差DMAIC改善專案之進度、統計工具應用與成效驗證，驅動系統化品質持續改善。

- 原始系統：Six Sigma/DMAIC Project Management（六標準差改善專案管理）
- 產業分類：智慧製造｜品質管理
- 使用部門：品保部、製程工程部、研發部、持續改善小組
- 工作流程：定義（Define）→衡量（Measure）→分析（Analyze）→改善（Improve）→控制（Control）
- AI 應用：統計工具自動推薦、專案效益預測、相似專案案例比對
- 主要 KPI：專案準時完成率、年度效益金額、專案投資報酬率
- 代表產品：Minitab、iSixSigma工具集、Sigma XL
