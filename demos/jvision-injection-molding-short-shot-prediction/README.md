# 射出成型短射缺陷預測

> 利用射出壓力、保壓時間、料溫、模溫與產品規格等歷史條件，預估短射發生風險並標示可能填充不足區域，協助製程人員在排產前比較參數方案、建立調機建議及追蹤改善成效。

利用射出壓力、保壓時間、料溫、模溫與產品規格等歷史條件，預估短射發生風險並標示可能填充不足區域，協助製程人員在排產前比較參數方案、建立調機建議及追蹤改善成效。

**產業別：**生產製造　|　**系統類型：**quality-qms

## 功能模組

- **短射風險總覽** — 呈現高風險工單、近期不良率及主要影響因子。
- **成型條件設定** — 編輯模擬壓力、速度、料溫、模溫及保壓參數。
- **填充風險預測** — 以產品區域圖顯示填充不足位置與短射機率。
- **參數方案比較** — 並列不同參數組合的風險、週期及品質預估。
- **調機任務追蹤** — 將建議參數轉成調機待辦並記錄確認結果。
- **改善成效分析** — 比較模具、材料、產品及參數調整前後的不良趨勢。

## 適合誰使用

- 射出成型製程工程師
- 調機技術員
- 品管人員與生產主管

## 運作流程

1. 盤點短射風險
2. 建立成型條件
3. 檢視填充預測
4. 比較參數方案
5. 執行調機確認
6. 追蹤改善成效

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
