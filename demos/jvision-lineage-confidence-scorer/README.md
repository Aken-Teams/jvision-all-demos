# 血緣可信度評分器

> 量化資料血緣的觀測、文件與驗證可信度，避免將推測關係當成事實。

量化資料血緣的觀測、文件與驗證可信度，避免將推測關係當成事實。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **血緣關係地圖** — 呈現資料表、欄位、管線與報表間的已知及推測連結。
- **執行觀測評分** — 依實際查詢、作業日誌與欄位流動頻率計算觀測強度。
- **文件佐證評分** — 衡量目錄說明、映射文件與擁有者聲明的完整性及時效。
- **驗證覆蓋評分** — 檢視自動測試、人工確認與抽樣追蹤所覆蓋的血緣節點。
- **矛盾血緣偵測** — 找出觀測結果、文件描述及人工驗證彼此不一致的連結。
- **可信度補強佇列** — 依影響程度排序待補文件、待驗證與待重新觀測的關係。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 選定血緣範圍
2. 彙整關係主張
3. 計算三維分數
4. 審查矛盾連結
5. 安排補強工作
6. 發布可信標示

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
