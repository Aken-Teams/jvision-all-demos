# 電商促銷費用結算台

> 集中管理品牌參與各電商平台檔期時的折價分攤、廣告補貼、贈品成本、活動門檻與結案請款，讓營運及財務辨識促銷實際毛利與待補款項。

集中管理品牌參與各電商平台檔期時的折價分攤、廣告補貼、贈品成本、活動門檻與結案請款，讓營運及財務辨識促銷實際毛利與待補款項。

**產業別：**零售電商　|　**系統類型：**finance-ledger

## 功能模組

- **活動立案** — 建立平台檔期、商品範圍、目標及責任窗口。
- **折扣分攤** — 設定平台、品牌與供應商各自負擔的優惠比例。
- **費用預算** — 編列廣告、贈品、折價與物流補助預算。
- **執行追蹤** — 比較活動銷售、折扣使用及預算消耗進度。
- **補貼請款** — 整理平台補貼條件、憑證、申請金額與回覆。
- **活動損益** — 計算商品毛利、行銷費用與待回收補貼。

## 適合誰使用

- 電商營運
- 品牌財務
- 通路業務

## 運作流程

1. 建立促銷活動
2. 設定費用分攤
3. 核定活動預算
4. 追蹤活動執行
5. 彙整補貼請款
6. 完成損益結案

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
