# 印刷電路板線路短路檢測系統

> 透過模擬印刷電路板線路影像與網路資料，標示殘銅、毛刺及相鄰線路黏連造成的短路疑點，支援網路對照、位置複核、批次管制與成因統計，降低不良裸板流入組裝。

透過模擬印刷電路板線路影像與網路資料，標示殘銅、毛刺及相鄰線路黏連造成的短路疑點，支援網路對照、位置複核、批次管制與成因統計，降低不良裸板流入組裝。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **短路風險總覽** — 彙整疑點、確認短路、受影響網路及批次狀態。
- **線路網路檢視** — 顯示模擬網路拓撲、相鄰線路與設計間距。
- **短路影像檢測** — 在板層影像上框選殘銅、毛刺與線路黏連區域。
- **跨網路複核** — 比對疑點兩側網路編號並確認是否異常連接。
- **批次管制中心** — 建立模擬攔截紀錄並設定重檢、重工或報廢。
- **短路成因統計** — 分析板層、線距、區域及製程站點的缺陷趨勢。

## 適合誰使用

- PCB 檢驗員
- CAM 工程師
- 品質主管

## 運作流程

1. 查看異常
2. 檢視網路
3. 定位疑點
4. 確認短路
5. 管制批次
6. 改善製程

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
