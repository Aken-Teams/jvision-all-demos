**產業別：**專業服務　|　**系統類型：**quality-qms

## 功能模組

- **送審檔案工作台** — 管理評選文件版本並顯示各檔案的格式合規狀態。
- **匿名資訊掃描** — 偵測公司、人名、標誌、文件屬性及可回推身分的線索。
- **頁數與章節檢查** — 核對頁數上限、必備章節、順序及封面是否計頁。
- **字體版式檢查** — 檢查字型、字級、行距、邊界與圖表標示是否合規。
- **檔案規格檢查** — 驗證格式、大小、命名、加密、附件拆分及輸出設定。
- **退件風險修正單** — 依淘汰風險排列違規項，定位頁面並追蹤修正結果。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 建立格式基準
2. 掃描匿名揭露
3. 核對頁數章節
4. 修正版式問題
5. 驗證檔案規格
6. 核准最終送件

- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
