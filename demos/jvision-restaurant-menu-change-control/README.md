# 連鎖餐飲菜單換版台

> 管理新品上市、停售、價格與配方異動的跨店換版工作，逐項確認菜單物、收銀資料、食材、教育及門市生效狀態，避免各通路版本不一致。

管理新品上市、停售、價格與配方異動的跨店換版工作，逐項確認菜單物、收銀資料、食材、教育及門市生效狀態，避免各通路版本不一致。

**產業別：**餐飲旅宿　|　**系統類型：**collaboration-pm

## 功能模組

- **版本批次** — 建立菜單版本、生效範圍與凍結日期。
- **品項差異** — 檢視新增、停售、改價及配方變動。
- **物料清單** — 追蹤菜單板、立牌與外送圖稿換發。
- **門市訓練** — 安排新品製作及銷售話術確認。
- **逐店上線** — 蒐集門市換版勾稽與現場證據。
- **例外處理** — 管理缺料、延後生效與錯版修正。

## 適合誰使用

- 品牌營運企劃
- 商品經理
- 區督導

## 運作流程

1. 建立版本
2. 核對差異
3. 準備物料
4. 完成訓練
5. 逐店生效
6. 關閉例外

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
