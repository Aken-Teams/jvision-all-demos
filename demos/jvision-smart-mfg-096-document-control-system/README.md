# Document Control System（文件管制系統）

> 從異常到改善的品質閉環與追溯稽核

Document Control System（文件管制系統）提供文件版本控管、簽核流程、文件分發追蹤。品保部依「文件建立→審核簽核→發行分發→現場使用→定期複審更新」推進作業，優先解決「現場使用舊版文件」，各生產與職能部門則以文件複審準時率與現場文件版本正確率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 品保部
- 各生產與職能部門
- 稽核單位

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉

## 導入效益

- 批號追溯時間：187分鐘 → **15分鐘**
- 客訴平均關案：21天 → **8.6天**
- 改善驗證率：64% → **92%**
- 重複不良率：5.9% → **2.1%**
