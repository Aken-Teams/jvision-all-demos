# Document Control System智慧站

集中管理品質相關文件之版本、簽核與發行，確保現場使用文件為最新有效版本。

- 原始系統：Document Control System（文件管制系統）
- 產業分類：智慧製造｜品質管理
- 使用部門：品保部、各生產與職能部門、稽核單位
- 工作流程：文件建立→審核簽核→發行分發→現場使用→定期複審更新
- AI 應用：文件到期自動提醒、跨文件關聯變更影響分析
- 主要 KPI：文件複審準時率、現場文件版本正確率、簽核時效
- 代表產品：MasterControl Documents、Veeva QualityDocs、SharePoint整合客製化
