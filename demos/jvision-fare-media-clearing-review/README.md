**產業別：**交通運輸　|　**系統類型：**finance-case

## 功能模組

- **票證交易** — 載入搭乘資料
- **日期橋接** — 對齊三種日期
- **補貼拆分** — 辨識優惠款項
- **清分差額** — 分類時間差漏款
- **外部追查** — 管理票證商回覆
- **帳務核銷** — 結清暫記項目

## 適合誰使用

- 票證會計
- 營收管理員
- 清分主管

## 運作流程

1. 載入交易
2. 橋接日期
3. 拆分補貼
4. 判定差額
5. 追查漏款
6. 完成核銷

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
