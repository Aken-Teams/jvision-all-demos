# 公共標案數量疑義澄清台

> 協助公共工程投標團隊比對招標圖、規範與詳細價目表，集中管理工程數量差異、計價單位疑義、風險金額與正式釋疑回覆，讓估價版本及投標決策採用一致依據。

協助公共工程投標團隊比對招標圖、規範與詳細價目表，集中管理工程數量差異、計價單位疑義、風險金額與正式釋疑回覆，讓估價版本及投標決策採用一致依據。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **招標文件庫** — 整理圖說、規範、價目表及補充公告版次。
- **數量比對** — 記錄自算數量、招標數量與差異比例。
- **疑義清單** — 分類單位、範圍、漏項及文件矛盾問題。
- **風險估算** — 評估不同解讀對直接成本與報價的影響。
- **正式釋疑** — 彙整提問文字、送出日期及機關回覆。
- **估價更新** — 將核定解讀同步至工項單價與投標版本。

## 適合誰使用

- 估價工程師
- 採購主管
- 投標經理

## 運作流程

1. 匯整文件
2. 比對數量
3. 建立疑義
4. 評估風險
5. 提出釋疑
6. 更新投標

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
