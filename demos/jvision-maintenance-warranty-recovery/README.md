# 設備保固追償管理台

> 供工廠設備與維修部門辨識保固期內故障，集中管理報修證據、供應商責任、零件與工資索賠、回覆承諾及抵扣結果，避免自行吸收原可向原廠追償的維修成本。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **保固總覽** — 呈現有效保固設備與追償案件狀態。
- **故障建案** — 連結設備、工單、故障現象與停機損失。
- **證據彙整** — 整理照片、檢測、零件與維修紀錄。
- **責任判定** — 比對保固條款與人為排除條件。
- **供應商協商** — 追蹤回覆、到場、換件與費用承諾。
- **回收結案** — 確認折讓、退款、免費換件與實際回收。

## 適合誰使用

- 設備工程師
- 維修主管
- 採購承辦

## 運作流程

1. 篩選故障
2. 建立案件
3. 備齊證據
4. 確認責任
5. 執行協商
6. 確認回收

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
