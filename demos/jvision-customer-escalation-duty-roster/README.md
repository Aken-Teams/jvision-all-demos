# 重大客服值班交接台

> 供客服中心管理夜間與假日重大事件值班，清楚呈現當班聯絡鏈、事件門檻、待續案件、承諾回覆與交接確認，避免跨班資訊遺失或高風險客訴無人接手。

**產業別：**客服管理　|　**系統類型：**service-desk

## 功能模組

- **值班名冊** — 查看班次與各層級聯絡人。
- **重大事件** — 集中顯示高風險客服案件。
- **升級門檻** — 查閱事件分級與通知規則。
- **交接包** — 彙整背景、進度與待辦事項。
- **接班確認** — 由接班人逐項認領責任。
- **承諾追蹤** — 監控下次回覆及補償期限。

## 適合誰使用

- 客服值班主管
- 一線客服
- 事件協調員

## 運作流程

1. 確認當班人員
2. 辨識重大案件
3. 建立事件交接包
4. 覆核升級狀態
5. 完成接班認領
6. 追蹤後續承諾

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
