# 司機隨車文件交接台

> 以文件袋與運單追蹤提貨單、報關文件、回單及證明的領取、轉交與歸還，讓跨車、跨班移動都有責任人和缺件預警。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **文件套組** — 按運單整理應帶文件。
- **領用登錄** — 記錄司機與領取時間。
- **轉交追蹤** — 保存跨車跨班移交。
- **回收點驗** — 核對頁數、章與附件。
- **缺件預警** — 催辦逾期及關鍵文件。
- **流向稽核** — 還原每次持有人。

## 適合誰使用

- 調度員
- 司機
- 文件管理員

## 運作流程

1. 建立套組
2. 點交領用
3. 隨車使用
4. 跨班轉交
5. 回站點驗
6. 缺件追查

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
