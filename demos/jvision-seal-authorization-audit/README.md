# 印鑑用印授權稽核台

> 管理營建契約、標單、保證與公文的用印申請，鎖定核准文件版本、金額權限、印章種類、份數及正本流向，防止先蓋後補或抽換頁面。

管理營建契約、標單、保證與公文的用印申請，鎖定核准文件版本、金額權限、印章種類、份數及正本流向，防止先蓋後補或抽換頁面。

**產業別：**營建工程　|　**系統類型：**legal-case

## 功能模組

- **用印申請** — 登錄文件金額及份數
- **版本鎖定** — 保存核准文件指紋
- **授權簽核** — 依金額類型決定層級
- **印章領用** — 記錄保管人及用印時間
- **正本追蹤** — 管理領回寄送與作廢
- **稽核查詢** — 還原版本及完整軌跡

## 適合誰使用

- 法務人員
- 印鑑保管人
- 授權主管

## 運作流程

1. 提出申請
2. 法務審查
3. 權限核准
4. 執行用印
5. 正本交付
6. 事後稽核

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
