# 物流碳排核算低碳承運選擇台

> 依模擬出貨重量、里程、運具、燃料與承運商資料計算物流碳排，清楚揭示排放係數與核算邊界，並比較成本、時效及減碳表現，支援低碳承運採購決策。

依模擬出貨重量、里程、運具、燃料與承運商資料計算物流碳排，清楚揭示排放係數與核算邊界，並比較成本、時效及減碳表現，支援低碳承運採購決策。

**產業別：**ESG 永續　|　**系統類型：**esg-energy

## 功能模組

- **物流碳排總覽** — 呈現排放趨勢、來源結構與減碳目標差距。
- **運輸活動資料** — 整理重量、里程、運具、燃料與承運商資料。
- **碳排核算工作台** — 依預設係數與邊界計算各運輸活動排放。
- **係數證據管理** — 檢視排放係數版本、來源與適用條件。
- **承運方案比較** — 並排比較碳排、成本、時效與服務品質。
- **減碳報告中心** — 產生依路線、承運商及運具分類的模擬報表。

## 適合誰使用

- 永續專員
- 物流採購
- 供應鏈主管

## 運作流程

1. 檢視排放概況
2. 整理活動資料
3. 執行碳排核算
4. 覆核係數證據
5. 選擇低碳承運
6. 產出減碳報告

## 導入效益

- 盤查作業工時：40小時 → **8小時**
- 數據完整率：60% → **95%**
- 減碳目標達成：50% → **88%**
- 用能異常反應：24小時 → **2小時**
