# 企業碳費減碳投資模擬器

> 整合企業排放基準、碳費費率與減碳方案，模擬不同產量及投資情境下的碳費支出、減量效益、回收年限與資金需求，協助管理層比較設備汰換、綠電及節能專案的財務影響。

整合企業排放基準、碳費費率與減碳方案，模擬不同產量及投資情境下的碳費支出、減量效益、回收年限與資金需求，協助管理層比較設備汰換、綠電及節能專案的財務影響。

**產業別：**ESG 永續　|　**系統類型：**esg-energy

## 功能模組

- **排放基準盤點** — 依廠區與排放來源檢視年度基準、產量及排放強度。
- **碳費情境設定** — 調整費率、免徵門檻、成長率與優惠條件並保存版本。
- **減碳方案庫** — 比較設備汰換、節能、綠電及製程改善方案的成本效益。
- **投資組合模擬** — 組合多項方案，試算逐年減量、資本支出與營運節省。
- **財務效益分析** — 呈現淨現值、回收期、碳費節省與資金缺口。
- **決策摘要報告** — 產生適合管理會議使用的情境比較與建議摘要。

## 適合誰使用

- 永續經理
- 財務主管
- 廠務主管與總經理

## 運作流程

1. 確認排放基準
2. 建立碳費假設
3. 篩選減碳方案
4. 配置投資組合
5. 審查財務效益
6. 核定減碳路徑

## 導入效益

- 盤查作業工時：40小時 → **8小時**
- 數據完整率：60% → **95%**
- 減碳目標達成：50% → **88%**
- 用能異常反應：24小時 → **2小時**
