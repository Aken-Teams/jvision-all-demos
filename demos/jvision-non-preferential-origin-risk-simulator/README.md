# 非優惠產地風險模擬器

> 模擬交易與製程路徑，辨識轉運、實質轉型及產地標示的規避風險。

模擬交易與製程路徑，辨識轉運、實質轉型及產地標示的規避風險。

**產業別：**採購供應鏈　|　**系統類型：**legal-case

## 功能模組

- **貨物流向重建** — 還原原料、加工、轉運與最終進口國的完整路徑。
- **實質轉型測試** — 依稅則變更、附加價值及關鍵製程判斷產地形成。
- **轉運風險掃描** — 找出低加工、高繞道或文件產地跳變等可疑節點。
- **產地標示檢核** — 比對商品、包裝、發票與報關資料上的產地標示。
- **規避情境模擬** — 調整製程與路徑，模擬主管機關可能採取的認定。
- **風險處置方案** — 依可解釋風險排序提出補強製程、改標或暫停出貨建議。

## 適合誰使用

- 國貿主管
- 報關人員
- 業務

## 運作流程

1. 重建交易路徑
2. 判定實質轉型
3. 掃描轉運疑點
4. 核對產地標示
5. 推演查核情境
6. 核定風險處置

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
