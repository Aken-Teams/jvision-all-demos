> 協助顧問團隊把合約承諾轉為工作範疇、交付物、假設與驗收條件，持續比對需求變更、工時與里程碑，提早標示範疇膨脹、資源不足及交付延誤風險。

**產業別：**專業服務　|　**系統類型：**collaboration-pm

## 功能模組

- **範疇基準中心** — 整理專案目標、包含與排除事項、假設、限制及合約承諾。
- **交付結構規劃** — 將範疇拆為工作包、交付物、負責人、里程碑與驗收條件。
- **變更需求管理** — 記錄新增需求及影響，區分範疇內外並模擬核准或議價流程。
- **交付風險雷達** — 依進度、工時、依賴與決策延遲呈現風險分數及預警原因。
- **風險處置中心** — 建立避免、降低或升級方案，指定責任人、期限與觸發條件。
- **里程碑審查室** — 檢查交付物、驗收證據、未決事項、客戶確認與下一階段條件。

## 適合誰使用

- 專案經理
- 顧問主管
- 交付顧問
- 客戶窗口與商務負責人

## 運作流程

1. 建立範疇
2. 規劃交付
3. 控制變更
4. 掃描風險
5. 執行處置
6. 審查里程碑
