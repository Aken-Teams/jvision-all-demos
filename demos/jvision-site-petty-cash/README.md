# 工地零用金核銷台

> 讓工地逐筆登錄零星採買、收據、用途、成本工項與核准人，管理預支、補款及現金盤點差異，防止月底集中補單和私人支出混入。

讓工地逐筆登錄零星採買、收據、用途、成本工項與核准人，管理預支、補款及現金盤點差異，防止月底集中補單和私人支出混入。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **零用金總覽** — 查看額度餘額與待辦
- **支出登錄** — 填寫用途工項及金額
- **憑證查核** — 檢查收據抬頭與內容
- **費用簽核** — 依金額層級核准
- **補款作業** — 彙整核銷與撥補
- **現金盤點** — 記錄帳實差異及調查

## 適合誰使用

- 工地行政
- 零用金保管人
- 成本會計

## 運作流程

1. 發生支出
2. 用途確認
3. 憑證審核
4. 主管核准
5. 財務核銷
6. 定期盤點

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
