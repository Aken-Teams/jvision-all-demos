**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **分區總覽** — 以樓層與空間查看試水狀態。
- **試水排程** — 設定放水、觀察及排水時間。
- **水位紀錄** — 登錄起訖水位與現場照片。
- **滲漏定位** — 標記樓下滲漏點及可能路徑。
- **修補複驗** — 管理修補內容與每輪複測結果。
- **工序放行** — 通過後解除保護層或貼磚限制。

## 適合誰使用

- 防水工程師
- 監造人員
- 泥作領班

## 運作流程

1. 選定試水分區
2. 安排試水時程
3. 記錄水位變化
4. 巡查樓下滲漏
5. 修補並重新測試
6. 放行後續工序

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
