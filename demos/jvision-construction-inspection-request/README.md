# 工程報驗排程管理台

> 依施工進度建立隱蔽工程與工序報驗，檢查前置文件、安排監造時段、記錄查驗結果及複驗，避免未驗先封板或等待查驗拖延後續工班。

依施工進度建立隱蔽工程與工序報驗，檢查前置文件、安排監造時段、記錄查驗結果及複驗，避免未驗先封板或等待查驗拖延後續工班。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **待驗預告** — 建立工區、工序與期望查驗時間。
- **前置檢核** — 確認自主檢查、圖說及試驗文件。
- **監造排程** — 協調查驗人員與現場可用時段。
- **查驗紀錄** — 登錄量測值、照片及合格判定。
- **缺失複驗** — 追蹤改善責任與再次查驗結果。
- **工序釋放** — 核准封閉或下一工項進場。

## 適合誰使用

- 施工工程師
- 品管工程師
- 監造工程師

## 運作流程

1. 預告報驗
2. 檢查文件
3. 安排查驗
4. 執行查驗
5. 完成複驗
6. 釋放工序

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
