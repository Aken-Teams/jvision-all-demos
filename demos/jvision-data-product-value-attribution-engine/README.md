## 功能模組

- **資料產品組合** — 整理資料集、指標、模型與其服務的業務情境。
- **決策影響鏈** — 連結資料產品到使用者決策、營運流程與成果指標。
- **成果貢獻估算** — 估算各資料產品對營收、效率與風險改善的貢獻。
- **情境歸因模擬** — 模擬停用、改善或擴大採用後的成果差異。
- **價值可信區間** — 呈現歸因假設、不確定性與可能的重複計算。
- **投資優先排序** — 依價值、成本與信心產生資料產品投資次序。

## 運作流程

1. 選定資料產品
2. 連結決策流程
3. 計算成果貢獻
4. 模擬投資情境
5. 審閱可信程度
6. 發布投資排序
