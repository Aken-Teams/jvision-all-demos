依任務意圖、資料敏感度與 SLA 動態選派 Agent，降低錯派及延遲。

**產業別：**資訊科技　|　**系統類型：**operations-console

## 功能模組

- **任務意圖辨識** — 解析請求目的、領域、語言及預期交付物，形成路由標籤。
- **敏感度分級** — 依資料內容、使用者身分與政策判定可用 Agent 範圍。
- **SLA 可行性預測** — 估算候選 Agent 的排隊、執行與人工核准時間。
- **候選路徑最佳化** — 在品質、成本、風險與時限間比較單一或多 Agent 路徑。
- **即時派送控制** — 套用核准規則後派送任務，並在情境變化時重新路由。
- **路由成效校準** — 追蹤錯派、逾時與轉派結果，持續調整選派策略。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 辨識任務意圖
2. 評定資料敏感度
3. 預測 SLA 表現
4. 比較路由方案
5. 派送並動態轉向
6. 校準選派策略

- 事件平均處理：120分鐘 → **30分鐘**
- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
- 資產盤點工時：20小時/月 → **4小時/月**
