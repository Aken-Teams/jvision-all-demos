# 保單契約變更管制台

> 集中處理保單受益人、地址、繳別、保額及附約變更申請，透過文件檢核、風險覆核與補件追蹤，降低契約保全作業錯誤。

集中處理保單受益人、地址、繳別、保額及附約變更申請，透過文件檢核、風險覆核與補件追蹤，降低契約保全作業錯誤。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **申請佇列** — 彙整契約變更案件
- **變更內容** — 比對變更前後資料
- **文件檢核** — 確認簽章與附件完整
- **規則覆核** — 判斷核保及風險條件
- **補件追蹤** — 管理通知與回收期限
- **生效結案** — 確認批改與客戶通知

## 適合誰使用

- 保全專員
- 核保人員
- 客服主管

## 運作流程

1. 受理申請
2. 檢核文件
3. 執行覆核
4. 通知補件
5. 核准批改
6. 通知生效

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
