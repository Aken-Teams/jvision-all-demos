# 圖說送審版次控管台

> 以圖號為核心管理送審版本、審查意見、修訂回覆、核定狀態與現場發放範圍，避免同張圖因檔名不同被重複送審，或核定新版尚未發布、舊版仍留在工班手上繼續施工。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **圖號版次總表** — 以唯一圖號呈現各版次、狀態與最新核定版。
- **送審包編製** — 組合圖檔、送審表、附件與送出紀錄。
- **審查意見拆解** — 逐條指派意見、回覆責任與完成期限。
- **修訂差異檢視** — 標示前後版本變更範圍及回覆依據。
- **核定版發行** — 指定發放工區、工班與生效日期。
- **舊版回收稽核** — 追蹤收訖、撤圖、作廢及未回收名單。

## 適合誰使用

- 設計工程師
- 文件管制員
- 現場工程師

## 運作流程

1. 盤點圖號版次
2. 編製圖說送審包
3. 拆解審查意見
4. 完成修訂比對
5. 發行核定施工版
6. 確認舊版撤回

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
