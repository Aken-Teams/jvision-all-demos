## 功能模組

- **待領物品盤點** — 依收件時間、保存期限與存放位置彙整尚未領取物品。
- **逾期風險預測** — 預測逾期機率、占用天數與可能產生的退件成本。
- **分級領件提醒** — 按物品急迫性與收件人偏好安排多輪通知。
- **逾期升級處置** — 將高風險或多次未回應案件升級至主管與據點窗口。
- **授權代領安排** — 核對代領人身分、授權範圍與可領取時段。
- **退件作業排程** — 協調承運商、包裝與交接時間並更新物品去向。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 掃描待領清單
2. 評估逾期風險
3. 發送分級提醒
4. 升級未回應案件
5. 確認代領方案
6. 執行退件或結案

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
