# 農機維護與共享調度平台

> 集中管理農機台帳、模擬工時、保養週期、故障工單與跨農場預約需求，預測維護風險並協助安排保養、租借及運送時段，使有限農機在農忙期間兼顧妥善率、使用公平與調度效率。

集中管理農機台帳、模擬工時、保養週期、故障工單與跨農場預約需求，預測維護風險並協助安排保養、租借及運送時段，使有限農機在農忙期間兼顧妥善率、使用公平與調度效率。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **機隊總覽** — 彙整可用、保養、故障與外借農機及近期需求。
- **農機台帳** — 管理機型、能力、模擬工時、所屬單位與使用履歷。
- **預防維護** — 呈現保養預測、到期項目、零件需求與維護計畫。
- **維修工單** — 處理報修、診斷、派工、維修進度與驗收紀錄。
- **共享排程** — 以時間軸安排跨農場借用並辨識重複預約。
- **交付調度** — 規劃農機運送、交接、歸還與機況檢查流程。

## 適合誰使用

- 農機管理員
- 維修技師
- 合作社調度員與農場申請人

## 運作流程

1. 掌握機隊狀態
2. 核對設備能力
3. 安排預防保養
4. 處理故障工單
5. 協調共享時段
6. 完成交付歸還

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
