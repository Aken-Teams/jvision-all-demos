**產業別：**業務銷售　|　**系統類型：**sales-crm

## 功能模組

- **競情變動雷達** — 偵測競品定價、功能、案例與市場說法的變化。
- **主張證據驗證** — 核對新競爭主張的來源、時效與可信程度。
- **銷售情境配對** — 將證據映射至產業、角色、交易階段與異議情境。
- **話術改寫台** — 依情境更新開場、差異化說法與追問句。
- **異議反駁編排** — 產生有證據支持的回應、禁語與升級條件。
- **戰卡發布中心** — 比較版本並發布核准內容至前線使用介面。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 檢視競情變動
2. 驗證最新證據
3. 指定銷售情境
4. 編修建議話術
5. 演練異議回應
6. 核准發布戰卡
