掃描 AI 回應中的金鑰、個資與內部片段，在送達使用者前阻止洩漏。

**產業別：**資訊安全　|　**系統類型：**security-soc

## 功能模組

- **回應掃描台** — 即時檢查待輸出的 AI 回應及其洩漏風險。
- **金鑰憑證偵測** — 辨識 API 金鑰、權杖、密碼與憑證材料。
- **個資片段比對** — 跨資料來源比對身分資訊與受保護個人資料。
- **內部內容溯源** — 找出回應片段與內部文件、程式碼或知識庫的相似來源。
- **輸出處置規則** — 設定刪除、改寫、隔離或停止傳送的處置門檻。
- **洩漏調查包** — 彙整命中片段、來源關聯與建議處置供人工覆核。

## 適合誰使用

- CISO
- AI 治理主管
- 資安分析師

## 運作流程

1. 攔下待送回應
2. 檢查祕密材料
3. 核對個資範圍
4. 追查內部來源
5. 決定輸出處置
6. 核准調查結論
