# OEE系統（Overall Equipment Effectiveness）

> 保養、維修、預兆到備品的設備全生命週期

OEE系統（Overall Equipment Effectiveness）提供稼動率/效能/良率自動計算、停機原因分類統計、損失時間帕累托分析。製造工程依「設備數據採集 → 停機原因標記 → OEE指標運算 → 損失分析 → 改善行動追蹤」推進作業，優先解決「設備真實效益難以量化」，生產則以OEE綜合指標與稼動率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**設備維護　|　**系統類型：**CMMS 設備維護

## 功能模組

- **保養排程** — 預防保養自動排程
- **維修工單** — 報修、派工與完工
- **預兆診斷** — 設備數據異常預警
- **備品管理** — 備品庫存與領用
- **OEE 稼動** — 稼動與故障分析
- **履歷追溯** — 設備維護履歷

## 適合誰使用

- 製造工程
- 生產
- 設備工程

## 運作流程

1. 待派工
2. 維修中
3. 試車確認
4. 復機完成

## 導入效益

- 非計畫停機：23小時/月 → **5.6小時/月**
- 保養準時率：71% → **90%**
- 備品缺料：9.4次/月 → **1.9次/月**
- 故障排除時間：85分鐘 → **24分鐘**
