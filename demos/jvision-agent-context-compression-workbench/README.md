# Agent 情境壓縮器

> 將冗長 Agent 任務歷程壓縮成可追溯、可驗證且適合後續推理的關鍵情境。

將冗長 Agent 任務歷程壓縮成可追溯、可驗證且適合後續推理的關鍵情境。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **長任務脈絡展開** — 依時間呈現訊息、工具結果、決策轉折與狀態變化。
- **關鍵事實萃取** — 挑出目標、限制、已驗證事實、未決事項與重要決策。
- **情境壓縮編輯器** — 以分層摘要重組歷程，控制 Token 目標與保留粒度。
- **摘要來源錨點** — 讓每項壓縮事實連回原訊息、文件或工具結果。
- **壓縮失真檢測** — 比對原始歷程與摘要，找出遺漏、矛盾與語意漂移。
- **壓縮版本發布** — 核准壓縮情境並供後續任務載入或回復舊版。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 選取長任務歷程
2. 萃取關鍵事實
3. 編排分層摘要
4. 核對來源錨點
5. 檢測壓縮失真
6. 發布情境版本
