# 事件初判指揮 Agent

> 關聯告警、變更與服務拓撲，提出可驗證的故障假設與處置行動以縮短 MTTR。

關聯告警、變更與服務拓撲，提出可驗證的故障假設與處置行動以縮短 MTTR。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **事件訊號匯流** — 將 APM、Kubernetes、CI/CD 與雲端告警聚合為單一待
- **變更拓撲關聯** — 對照部署紀錄、程式變更與服務依賴，定位可能受影響路徑。
- **故障假設排序** — 依時間、症狀與依賴關係產生根因假設及信心分數。
- **假設證據驗證** — 為各項假設蒐集日誌、指標、追蹤與測試結果。
- **處置核准台** — 呈現風險、回復方式與影響範圍，供人工核准高風險動作。
- **復原追蹤室** — 監測處置成效、指派後續工作並確認事件結案條件。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 建立事件態勢
2. 還原變更路徑
3. 審查根因假設
4. 補強驗證證據
5. 核准處置行動
6. 確認復原結案

## 導入效益

- 事件平均處理：120分鐘 → **30分鐘**
- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
- 資產盤點工時：20小時/月 → **4小時/月**
