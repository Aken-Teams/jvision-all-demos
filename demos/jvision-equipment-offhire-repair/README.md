> 記錄租賃機具故障時間、症狀、停用證據及租賃商收件時間，追蹤維修到場、替代機與復機，明確認定停租區間和租金責任。

**產業別：**營建工程　|　**系統類型：**maintenance-cmms

## 功能模組

- **故障通報** — 記錄症狀時間與照片
- **停租申請** — 提出停止計費依據
- **廠商受理** — 記錄回覆及到場承諾
- **替代機安排** — 追蹤調機與恢復施工
- **復機驗收** — 確認修復及重新起租
- **租金核定** — 計算停租與責任區間

## 適合誰使用

- 機具管理員
- 操作人員
- 租賃商維修員

## 運作流程

1. 發現故障
2. 通知停租
3. 廠商受理
4. 執行維修
5. 測試復機
6. 核定租金

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
