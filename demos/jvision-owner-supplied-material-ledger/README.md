# 業主供料收發核帳台

> 管理業主供應材料的到貨、驗收、分區領用、退料、損耗與期末盤點，將每筆收發連到施工位置及責任工班，支援結算時核對短少與超耗扣款。

管理業主供應材料的到貨、驗收、分區領用、退料、損耗與期末盤點，將每筆收發連到施工位置及責任工班，支援結算時核對短少與超耗扣款。

**產業別：**營建工程　|　**系統類型：**warehouse-wms

## 功能模組

- **供料總覽** — 查看到貨、庫存、領用及差異。
- **到貨驗收** — 登錄業主供料批次與實收數量。
- **分區發料** — 依施工位置及工班辦理領用。
- **退料損耗** — 記錄餘料退回及合理耗損原因。
- **現場盤點** — 核對各倉區帳面與實際庫存。
- **結算核帳** — 計算短少、超耗與應扣金額。

## 適合誰使用

- 材料管理員
- 成本工程師
- 分包領班

## 運作流程

1. 掌握供料存量
2. 辦理到貨驗收
3. 登錄工班領用
4. 處理退料損耗
5. 執行期末盤點
6. 完成結算核帳

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
