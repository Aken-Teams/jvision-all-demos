# 配送附加費認列台

> 將司機回報的等待、搬運、上樓、偏遠與二次配送事件轉成可收客戶及應付司機的費用，檢查證據與合約後避免付了卻漏收。

將司機回報的等待、搬運、上樓、偏遠與二次配送事件轉成可收客戶及應付司機的費用，檢查證據與合約後避免付了卻漏收。

**產業別：**物流運輸　|　**系統類型：**finance-ledger

## 功能模組

- **事件佇列** — 查看候時搬運與重送。
- **作業證據** — 保存時間、照片及簽名。
- **合約規則** — 核對可收與應付條件。
- **雙向計價** — 計算客戶應收及司機應付。
- **客戶確認** — 取得附加作業簽認。
- **毛利追蹤** — 找出已付未收案件。

## 適合誰使用

- 客服專員
- 運價管理員
- 應收會計

## 運作流程

1. 回報事件
2. 檢查證據
3. 套用合約
4. 完成計價
5. 取得確認
6. 追蹤毛利

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
