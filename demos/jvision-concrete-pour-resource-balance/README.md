# 混凝土澆置資源平衡台

> 依各澆置區方量、泵浦產能、預拌車供應、試驗人力與交通時段進行跨區資源試排，協調同日多個澆置面的優先序，降低塞車待料、泵浦空轉及澆置中斷風險。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **澆置申請** — 登錄區域、方量、強度與時間窗。
- **車次配置** — 安排預拌車頻率與進場順序。
- **泵浦排程** — 配置泵浦、管路及轉場時間。
- **支援人力** — 安排試驗、指揮與收面班組。
- **資源平衡** — 處理多區衝突與供應能力限制。
- **澆置實績** — 比較計畫節奏、到車與完成量。

## 適合誰使用

- 混凝土工程師
- 施工主任
- 預拌廠窗口

## 運作流程

1. 提報需求
2. 配置泵浦
3. 確認供料
4. 平衡資源
5. 發布計畫
6. 回報實績

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
