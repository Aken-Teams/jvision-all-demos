# 電路板光學假點複判助手

> 協助檢驗人員複判電路板自動光學檢查產生的疑似缺陷，以元件局部影像、標準樣板、偏移量與歷史判例快速區分真缺陷和假點，並回饋檢查規則。

協助檢驗人員複判電路板自動光學檢查產生的疑似缺陷，以元件局部影像、標準樣板、偏移量與歷史判例快速區分真缺陷和假點，並回饋檢查規則。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **待判佇列** — 依線別、板號、缺陷類型及信心排序檢查點。
- **影像複判** — 放大檢視局部影像、檢測框與標準樣板。
- **偏差量測** — 顯示元件位移、角度、焊點及標記差異。
- **判例參考** — 提供相似元件與歷史真假缺陷判例。
- **判定工作台** — 完成放行、真缺陷或升級複核並填寫理由。
- **規則回饋** — 彙整高頻假點並提出門檻或檢查區域調整建議。

## 適合誰使用

- 目檢員
- 品質工程師
- 產線主管

## 運作流程

1. 選取點位
2. 檢視影像
3. 核對偏差
4. 參考判例
5. 完成判定
6. 改善規則

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
