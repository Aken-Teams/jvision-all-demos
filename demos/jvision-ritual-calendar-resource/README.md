# 法會壇場資源排程台

> 協助宮廟與寺院規劃法會日期、壇場配置、法師班次、供品物資、信眾名冊與儀程版本，避免多場儀式同時進行造成資源衝突。

**產業別：**宗教服務　|　**系統類型：**operations-console

## 功能模組

- **法會日曆** — 管理法會、壇場與前後場復時段。
- **壇場配置** — 安排壇位、動線及容量需求。
- **執事班次** — 配置法師、司儀與服務人員。
- **供品物資** — 拆解供品、法器與耗材需求。
- **信眾名冊** — 管理參與類別、牌位與校對狀態。
- **儀程發布** — 維護流程版本及各組執行提示。

## 適合誰使用

- 法會執事
- 宗務人員
- 物資組長

## 運作流程

1. 建立法會
2. 配置壇場
3. 安排班次
4. 備妥物資
5. 校對名冊
6. 發布儀程

## 導入效益

- 活動籌備工時：20小時 → **5小時**
- 報名掌握率：65% → **94%**
- 物資盤點：6小時 → **1小時**
- 志工調度時效：3天 → **1天**
