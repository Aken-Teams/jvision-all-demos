# 再生能源發電承諾管理

> 整合風力與太陽能的擬真氣象、歷史發電及售電合約資料，預測各時段可交付電量，協助能源業者安排申報承諾、辨識缺口並模擬調整方案，降低偏差罰款與臨時購電風險。

整合風力與太陽能的擬真氣象、歷史發電及售電合約資料，預測各時段可交付電量，協助能源業者安排申報承諾、辨識缺口並模擬調整方案，降低偏差罰款與臨時購電風險。

**產業別：**ESG 永續　|　**系統類型：**esg-energy

## 功能模組

- **發電營運總覽** — 以電站、能源類型及時段呈現預測發電、承諾量、實績與風險摘要。
- **發電預測中心** — 比較氣象情境與模型版本，查看未來發電曲線、信賴區間及影響因子。
- **供電承諾編排** — 依合約與時段建立申報承諾，檢查數量限制、截止時間及交付餘裕。
- **偏差風險監看** — 列出可能低於或高於承諾的時段，呈現風險等級與預估費用。
- **調整方案模擬** — 模擬儲能移轉、跨站調度或外購電量對承諾缺口與成本的影響。
- **履約結算分析** — 回顧承諾與實績差異、偏差原因、費用明細及各電站履約表現。

## 適合誰使用

- 能源管理專員
- 電力交易主管
- 廠務主管

## 運作流程

1. 掌握營運態勢
2. 審閱發電預測
3. 建立供電承諾
4. 追蹤履約偏差
5. 比較調整方案
6. 完成結算複盤

## 導入效益

- 盤查作業工時：40小時 → **8小時**
- 數據完整率：60% → **95%**
- 減碳目標達成：50% → **88%**
- 用能異常反應：24小時 → **2小時**
