# 電網負載尖峰調度平台

> 以廠區或區域配電的擬真用電資料預測短期負載與契約容量風險，讓調度人員辨識尖峰來源、規劃可移轉負載、模擬需量反應方案，並追蹤執行成效與節省的超約費用。

以廠區或區域配電的擬真用電資料預測短期負載與契約容量風險，讓調度人員辨識尖峰來源、規劃可移轉負載、模擬需量反應方案，並追蹤執行成效與節省的超約費用。

**產業別：**ESG 永續　|　**系統類型：**operations-console

## 功能模組

- **電網負載戰情** — 呈現各區域即時擬真負載、預測尖峰、容量餘裕及待處置告警。
- **短期負載預測** — 查看未來時段負載曲線、信賴區間、尖峰機率及主要用電來源。
- **可調資源盤點** — 依產線與設備列出可降載量、允許時段、恢復時間及營運限制。
- **削峰方案模擬** — 組合移轉、降載與儲能策略，比較尖峰降低量、成本及生產影響。
- **調度任務執行** — 將核准方案拆成負責人、時間與設備任務，以狀態流程模擬執行回報。
- **需量成效分析** — 比較基準線與執行曲線，分析削峰達成率、異常與費用效益。

## 適合誰使用

- 電力調度員
- 廠務工程師
- 能源主管

## 運作流程

1. 監看負載態勢
2. 研判尖峰時段
3. 盤點可調資源
4. 擬定削峰方案
5. 派發調度任務
6. 檢討執行成效

## 導入效益

- 盤查作業工時：40小時 → **8小時**
- 數據完整率：60% → **95%**
- 減碳目標達成：50% → **88%**
- 用能異常反應：24小時 → **2小時**
