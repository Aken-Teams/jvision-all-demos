# 門市到店取貨差異台

> 核對電商調撥至門市的到店取貨箱件、訂單與實收商品，處理短少、錯店、破損及顧客到店前缺件，串接補寄、轉店或取消方案與責任記錄。

核對電商調撥至門市的到店取貨箱件、訂單與實收商品，處理短少、錯店、破損及顧客到店前缺件，串接補寄、轉店或取消方案與責任記錄。

**產業別：**零售電商　|　**系統類型：**pos-frontdesk

## 功能模組

- **到店清單** — 查看預計抵店訂單箱件
- **門市點收** — 核對商品數量與狀態
- **差異建案** — 登錄短少錯店及破損
- **來源追查** — 釐清倉庫幹線門市責任
- **補貨協調** — 安排補寄轉店或取消
- **取件通知** — 更新顧客可取件狀態

## 適合誰使用

- 門市人員
- 電商物流
- 客服人員

## 運作流程

1. 接收預報
2. 完成點收
3. 提出差異
4. 追查來源
5. 安排補救
6. 通知取件

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
