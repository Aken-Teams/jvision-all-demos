# 再保分保帳務管理台

> 協助保險公司依再保合約條件計算保費分出、賠款攤回、佣金與準備金，管理結算期次、差異調整及再保人往來帳，降低人工試算風險。

**產業別：**金融保險　|　**系統類型：**finance-ledger

## 功能模組

- **再保總覽** — 查看合約額度、結算期次與待辦差異。
- **合約條件** — 管理比例、層級、限額、佣金與期間。
- **分保試算** — 計算保費分出、賠款攤回及準備金。
- **差異調整** — 追蹤來源資料與前期結算調整。
- **結算核准** — 完成會辦、覆核及結算版本鎖定。
- **往來帳務** — 彙整再保人應收、應付與付款狀態。

## 適合誰使用

- 再保專員
- 保險財務
- 精算主管

## 運作流程

1. 維護合約
2. 彙整資料
3. 執行試算
4. 調查差異
5. 覆核結算
6. 管理收付

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
