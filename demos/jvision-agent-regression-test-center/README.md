## 功能模組

- **黃金任務庫** — 維護標準輸入、預期成果、容許範圍與關鍵行為檢查點。
- **版本變更集** — 集中比較模型、提示、工具、權限及設定的版本差異。
- **批次重跑控制** — 選擇環境與任務分群，並行重播完整 Agent 執行軌跡。
- **多目標評分** — 依正確性、完成率、成本、延遲及安全性計算回歸結果。
- **退化根因分析** — 定位分數下降與模型回應、提示內容或工具行為變更的關聯。
- **版本放行閘門** — 依退化門檻、風險與人工複核結果決定放行或阻擋。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 維護黃金任務
2. 選定待測版本
3. 執行回歸批次
4. 比較基準分數
5. 診斷能力退化
6. 裁定版本放行
