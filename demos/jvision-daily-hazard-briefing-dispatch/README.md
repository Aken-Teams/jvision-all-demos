# 每日危害告知派工台

> 依當日工項、區域、天候與交叉作業，自動組成各班組真正適用的危害告知與管制措施，完成帶班宣導、人員確認及臨時變更補告知，避免每天照抄制式內容卻與現場作業脫節。

依當日工項、區域、天候與交叉作業，自動組成各班組真正適用的危害告知與管制措施，完成帶班宣導、人員確認及臨時變更補告知，避免每天照抄制式內容卻與現場作業脫節。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **今日工項** — 彙整各區班組、人員、機具與預定作業。
- **危害配對** — 依工項與交叉作業帶出適用危害及措施。
- **告知編排** — 調整班前說明順序、圖示與現場重點。
- **班前宣導** — 記錄領班講解、人員確認及未到名單。
- **變更補告知** — 工區或工法異動時圈選受影響人員重告知。
- **執行稽核** — 分析缺漏、逾時與高風險班組的告知品質。

## 適合誰使用

- 安衛人員
- 工班領班
- 現場工程師

## 運作流程

1. 彙整派工
2. 辨識危害
3. 編製內容
4. 班前宣導
5. 變更重告
6. 抽查改善

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
