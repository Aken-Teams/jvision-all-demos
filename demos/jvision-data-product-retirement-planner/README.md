# 資料產品退場規劃器

> 盤點資料產品依賴、替代方案與利害關係人，規劃不中斷的安全退場。

盤點資料產品依賴、替代方案與利害關係人，規劃不中斷的安全退場。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **退場候選評估** — 依使用量、維護成本、品質與重複性評估資料產品退場價值。
- **相依血緣探勘** — 找出上游來源、下游管線、報表、模型與自助查詢依賴。
- **替代產品配對** — 比較替代資料集的 Schema、語意、品質與更新頻率相容度。
- **影響對象辨識** — 從查詢、權限與擁有權定位需要遷移或接收通知的人員。
- **遷移波次規劃** — 依依賴風險安排切換、雙軌驗證、通知與停止供應時程。
- **安全下線控制** — 檢查阻斷條件、監控切換結果並在失敗時恢復供應。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 評估退場候選
2. 盤點完整依賴
3. 選定替代產品
4. 確認影響對象
5. 安排遷移波次
6. 執行安全下線

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
