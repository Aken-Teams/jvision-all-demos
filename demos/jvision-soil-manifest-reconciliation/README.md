# 土方運棄聯單核銷台

> 按土方計畫與運棄日期彙整車次、車號、載運方數、收容場所及聯單影像，自動標示缺號、重號與數量差異，協助工地逐日完成聯單回收及月度核銷。

按土方計畫與運棄日期彙整車次、車號、載運方數、收容場所及聯單影像，自動標示缺號、重號與數量差異，協助工地逐日完成聯單回收及月度核銷。

**產業別：**營建工程　|　**系統類型：**logistics-fleet

## 功能模組

- **運棄計畫** — 依日期與去化場所安排車次。
- **車次登錄** — 記錄車號、司機、出場時間與方數。
- **聯單回收** — 上傳聯單正反面及收容章戳。
- **序號檢核** — 辨識缺號、重號與資料矛盾。
- **數量核對** — 比較計畫、過磅、聯單及申報量。
- **運費核銷** — 依有效車次確認可付款金額。

## 適合誰使用

- 土方管理員
- 現場工程師
- 工地會計

## 運作流程

1. 安排車次
2. 出場登錄
3. 回收聯單
4. 異常檢核
5. 方數確認
6. 費用核銷

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
