# 餐飲過敏原供餐管制台

> 集中管理菜單過敏原、顧客特殊需求、廚房防交叉接觸措施與出餐覆核，讓前場、廚房及主管留下完整供餐責任紀錄。

集中管理菜單過敏原、顧客特殊需求、廚房防交叉接觸措施與出餐覆核，讓前場、廚房及主管留下完整供餐責任紀錄。

**產業別：**餐飲旅宿　|　**系統類型：**quality-qms

## 功能模組

- **菜品檔案** — 維護原料、過敏原及可替代方案。
- **需求登錄** — 記錄桌次、顧客與過敏嚴重程度。
- **特餐工單** — 產生清楚標示的製作與出餐指示。
- **防護確認** — 勾選器具、工作區與換手套措施。
- **出餐覆核** — 由廚房與前場確認餐點及桌號。
- **事件檢討** — 記錄誤送、退餐及矯正措施。

## 適合誰使用

- 餐廳領班
- 廚房主管
- 食品安全專員

## 運作流程

1. 維護過敏資料
2. 登錄顧客需求
3. 建立特餐工單
4. 確認防護措施
5. 執行雙人覆核
6. 封存事件紀錄

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
