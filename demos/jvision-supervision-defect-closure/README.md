# 監造抽查缺失閉環台

> 管理監造抽查所開缺失的圖面位置、規範依據、責任工班、改善期限及複查結果，避免照片無法對位、重複開單或已改善卻未正式關閉。

管理監造抽查所開缺失的圖面位置、規範依據、責任工班、改善期限及複查結果，避免照片無法對位、重複開單或已改善卻未正式關閉。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **抽查看板** — 查看缺失與複查狀態
- **缺失開立** — 定位圖面並附規範照片
- **責任派工** — 指定工班和期限
- **改善回報** — 提交修正過程與成果
- **監造複查** — 核准結案或再次退回
- **品質分析** — 辨識重複缺失與工班

## 適合誰使用

- 監造工程師
- 品質工程師
- 分包領班

## 運作流程

1. 現場抽查
2. 開立缺失
3. 分派改善
4. 提交成果
5. 執行複查
6. 正式關閉

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
