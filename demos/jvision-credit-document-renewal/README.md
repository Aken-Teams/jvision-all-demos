# 企業授信文件展期台

> 追蹤企業授信額度所依賴的財報、保險、擔保、董事會文件與承諾效期，在動用前完成催補、審查與展期，避免失效文件支撐放款。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **授信額度** — 連結客戶額度與條件
- **文件清單** — 管理擔保保險與財報
- **到期預警** — 依動用日計算有效性
- **客戶催補** — 追蹤通知承諾與回件
- **文件審查** — 確認版本簽章與效力
- **額度限制** — 核准展期或暫停動用

## 適合誰使用

- 授信管理員
- 企業金融業務
- 風險主管

## 運作流程

1. 建立文件條件
2. 辨識到期風險
3. 發送客戶催補
4. 查驗展期文件
5. 評估額度影響
6. 核定文件展期

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
