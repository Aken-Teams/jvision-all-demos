# 專利地域效力檢查器

> 依銷售、製造與進口地核對專利效力，避免產品布局的地域誤判。涉外專利法務／產品 FTO 判斷／上市前地域風險控管。

依銷售、製造與進口地核對專利效力，避免產品布局的地域誤判。涉外專利法務／產品 FTO 判斷／上市前地域風險控管。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **營運地域盤點** — 彙整產品的銷售國、製造地、進口地與預定上市市場。
- **專利家族展開** — 展開目標專利的家族成員、各國申請案與權利關係。
- **權利狀態核驗** — 核對各司法管轄區的授權、年費、屆期與失效狀態。
- **地域行為配對** — 將製造、販售、要約與進口行為配對到可能適用的權利。
- **效力缺口分析** — 標示無權利覆蓋、狀態不明或可能誤判的國家與行為。
- **地域結論核准** — 編修地域效力結論與依據，送交法務主管核准發布。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 界定營運足跡
2. 建立專利家族
3. 核驗在地效力
4. 比對受控行為
5. 審查地域缺口
6. 核准效力結論
