# 工程保險理賠對帳台

> 把事故支出、維修發票、保險申報、核賠、自負額與實際收款逐案勾稽，追蹤未補憑證及未收理賠，確保損失和應收款正確。

把事故支出、維修發票、保險申報、核賠、自負額與實際收款逐案勾稽，追蹤未補憑證及未收理賠，確保損失和應收款正確。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **理賠案件** — 查看事故與保單狀態
- **損失支出** — 彙整修復醫療等費用
- **理賠憑證** — 追蹤照片報價和證明
- **核賠差異** — 比較申請與核准金額
- **收款配對** — 核對保險匯款與案件
- **會計結案** — 認列自負額和最終損失

## 適合誰使用

- 保險承辦
- 專案財務
- 成本會計

## 運作流程

1. 建立理賠案
2. 彙整支出
3. 補齊憑證
4. 確認核賠
5. 配對收款
6. 認列結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
