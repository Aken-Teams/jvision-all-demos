# 錯誤驅動學習教練

> 從真實工作錯誤生成個人化練習與即時回饋，降低相同錯誤再次發生。提升工作表現與技能成長。

從真實工作錯誤生成個人化練習與即時回饋，降低相同錯誤再次發生。提升工作表現與技能成長。

**產業別：**人力資源　|　**系統類型：**education-lms

## 功能模組

- **工作錯誤收件匣** — 彙整退件、客訴、缺陷與重工紀錄並隱去敏感內容。
- **錯誤模式診斷** — 辨識知識誤解、流程遺漏、判斷偏差與操作失誤模式。
- **重犯風險預測** — 估算不同任務與情境下再次犯錯的機率及影響。
- **個人練習生成** — 依錯誤原因建立微練習、案例題與情境化補強任務。
- **練習回饋教室** — 針對作答步驟提供即時提示、解析與可改進行為。
- **重犯改善追蹤** — 比較練習前後的工作表現並調整後續練習強度。

## 適合誰使用

- L&D 主管
- 部門主管
- 員工

## 運作流程

1. 匯入工作錯誤
2. 診斷錯誤模式
3. 預測重犯風險
4. 配置個人練習
5. 練習並接收回饋
6. 驗證改善成效

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
