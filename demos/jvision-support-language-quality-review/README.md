# 客服話術品質校準台

> 協助客服中心抽樣文字與通話案件，依同理、正確性、合規及解決能力評分，進行複評校準、教練回饋與改善追蹤。

協助客服中心抽樣文字與通話案件，依同理、正確性、合規及解決能力評分，進行複評校準、教練回饋與改善追蹤。

**產業別：**客服管理　|　**系統類型：**service-desk

## 功能模組

- **案件抽樣** — 依渠道、議題及人員建立樣本
- **品質評分** — 按構面記錄分數與證據
- **複評校準** — 比較評審結果及尺度差異
- **教練回饋** — 整理優點與改善建議
- **改善任務** — 指派練習及複訓內容
- **品質趨勢** — 觀察團隊分數與錯誤類型

## 適合誰使用

- 客服品保
- 客服主管
- 教育訓練人員

## 運作流程

1. 建立抽樣
2. 執行評分
3. 進行複評
4. 校準尺度
5. 派送改善
6. 追蹤成效

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
