# 施工架壁連座拆補台

> 管控外牆施工期間壁連座因開口、吊料或飾面作業而申請暫拆、替代補強、限時復裝與查驗，避免不同工班任意拆除造成施工架失穩。

管控外牆施工期間壁連座因開口、吊料或飾面作業而申請暫拆、替代補強、限時復裝與查驗，避免不同工班任意拆除造成施工架失穩。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **架面配置** — 依立面網格呈現壁連座位置與狀態
- **暫拆申請** — 登錄拆除原因、範圍及預計時段
- **補強審核** — 確認斜撐或替代拉結配置
- **期限監控** — 追蹤每一拆除點的復裝倒數
- **復裝查驗** — 比對拆前拆後照片與固定方式
- **異常通報** — 通知逾時、超量拆除與巡查缺失

## 適合誰使用

- 職安人員
- 鷹架領班
- 外牆工程師

## 運作流程

1. 提出暫拆需求
2. 定位影響範圍
3. 核定替代補強
4. 執行受控拆除
5. 完成壁連復裝
6. 查驗關閉申請

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
