# 開挖支撐巡查交班台

> 依支撐構件與開挖區記錄滲水、異音、變形及雨後巡查，將未結異常、封鎖範圍和處置進度完整交接給下一班。

依支撐構件與開挖區記錄滲水、異音、變形及雨後巡查，將未結異常、封鎖範圍和處置進度完整交接給下一班。

**產業別：**營建工程　|　**系統類型：**operations-console

## 功能模組

- **支撐總覽** — 查看區域與構件狀態
- **班次巡查** — 依路線記錄檢查結果
- **異常通報** — 標示位置程度與照片
- **封鎖處置** — 管理停工範圍與措施
- **交班清單** — 移交未結風險及責任
- **趨勢紀錄** — 比較連續班次變化

## 適合誰使用

- 開挖工程師
- 夜班監工
- 職安人員

## 運作流程

1. 班前接手
2. 現場巡查
3. 通報異常
4. 執行處置
5. 複查狀態
6. 班末交接

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
