**產業別：**資訊科技　|　**系統類型：**operations-console

## 功能模組

- **Agent 套件封裝** — 彙整版本、模型、工具、提示與相依元件。
- **使用授權配置** — 設定租戶、席次、期限、地域與再散布權限。
- **方案定價設計** — 建立免費、訂閱、按次或企業議價方案。
- **發布合規檢查** — 核對權限、資料使用、成本與安全政策。
- **市集審核工作台** — 協調產品、資安與法務完成上架簽核。
- **安裝清單產生器** — 產出環境需求、權限範圍與部署步驟。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 封裝版本
2. 配置授權
3. 制定價格
4. 執行檢查
5. 完成審核
6. 發布安裝
