# 考場封卷交接管制台

> 追蹤試卷印製後的封袋、領卷、考場點交、回收、缺卷與開封異常，讓每一袋試卷都有數量、時間及責任人，降低外流與遺失風險。

追蹤試卷印製後的封袋、領卷、考場點交、回收、缺卷與開封異常，讓每一袋試卷都有數量、時間及責任人，降低外流與遺失風險。

**產業別：**教育　|　**系統類型：**operations-console

## 功能模組

- **封卷台帳** — 記錄科目袋號與份數
- **領卷派發** — 指定考場與領用人
- **考前點交** — 核對封條科目和數量
- **交接簽認** — 保存各節點責任人
- **回收清點** — 核對作答空白與備用卷
- **異常封存** — 調查缺卷誤領與破封

## 適合誰使用

- 試務承辦
- 監考人員
- 閱卷主管

## 運作流程

1. 建立封卷批次
2. 派發領卷任務
3. 執行考前點交
4. 記錄考場啟封
5. 完成回收清點
6. 移交閱卷封存

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
