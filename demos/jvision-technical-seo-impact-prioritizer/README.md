## 功能模組

- **網站資產盤點** — 依網域、模板、頁型與市場整理可搜尋頁面資產。
- **技術問題掃描** — 辨識索引、效能、結構化資料與內部連結問題。
- **問題影響圖** — 呈現技術缺陷涉及的模板、頁面、查詢與轉換路徑。
- **商業影響評分** — 綜合流量損失、排名機會、營收價值與修復成本。
- **修復優先佇列** — 依邊際效益排序問題並合併可共同處理的項目。
- **修復成效驗證** — 比較上線前後的收錄、排名、流量與轉換變化。

## 適合誰使用

## 運作流程

1. 界定網站資產
2. 發現技術問題
3. 建立影響關聯
4. 估算商業影響
5. 核定修復順序
6. 驗證修復效益
