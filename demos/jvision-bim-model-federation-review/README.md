# BIM模型整合發布台

> 管控建築、結構與機電模型版本的收件、座標檢核、聯邦整合、碰撞議題指派及核准發布，明確區分工作版與施工可用版，避免現場引用未審模型。

管控建築、結構與機電模型版本的收件、座標檢核、聯邦整合、碰撞議題指派及核准發布，明確區分工作版與施工可用版，避免現場引用未審模型。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **模型收件** — 管理專業別、區域、版次、交付日與檔案狀態。
- **座標檢核** — 檢查基準點、樓層、單位與命名規則。
- **聯邦整合** — 組合各專業模型並記錄整合批次。
- **碰撞議題** — 依位置與工種分類碰撞並指定責任人。
- **修正覆核** — 比較回覆版本並確認議題是否真正排除。
- **核准發布** — 凍結施工可用版並通知現場更新。

## 適合誰使用

- BIM經理
- 專業建模員
- 施工工程師

## 運作流程

1. 提交專業模型
2. 檢核模型規則
3. 建立整合批次
4. 分派碰撞議題
5. 覆核修正成果
6. 發布施工版本

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
