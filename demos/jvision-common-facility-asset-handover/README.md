# 公設點交資產盤點台

> 按公設空間與設備位號盤點主機、備品、鑰匙、工具及操作文件，記錄實點數量、缺件責任和補交期限，支援建商向物業正式移交。

**產業別：**營建工程　|　**系統類型：**warehouse-wms

## 功能模組

- **公設清冊** — 依空間查看待交資產
- **現場盤點** — 核對設備備品及數量
- **鑰匙工具** — 管理套數與保管人
- **文件查核** — 確認手冊圖說與保固
- **缺件追蹤** — 指派補交責任和期限
- **點交簽認** — 產生正式移交紀錄

## 適合誰使用

- 移交工程師
- 物業代表
- 設備廠商

## 運作流程

1. 建立清冊
2. 執行預盤
3. 物業複點
4. 開立缺件
5. 完成補交
6. 正式簽認

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
