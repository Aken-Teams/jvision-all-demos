# 工地日報工數彙整台

> 將各工班每日人數、工種、工作區域、完成量與待工原因統一彙整，交叉核對進場紀錄及分包回報，減少行政重抄與月底補日報，並形成可追溯的工數基準。

將各工班每日人數、工種、工作區域、完成量與待工原因統一彙整，交叉核對進場紀錄及分包回報，減少行政重抄與月底補日報，並形成可追溯的工數基準。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **日報填報** — 依日期與工區登錄班組作業。
- **工數彙整** — 統一工種、班組及出勤口徑。
- **進場核對** — 比對填報人數與進場名冊。
- **完成量登錄** — 連結工數與當日施工成果。
- **待工異常** — 記錄停等原因與責任歸屬。
- **效率分析** — 檢視工數趨勢與生產效率。

## 適合誰使用

- 現場工程師
- 工地行政
- 工務主管

## 運作流程

1. 班組回報
2. 現場登錄
3. 名冊核對
4. 異常說明
5. 日報核定
6. 月度彙整

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
