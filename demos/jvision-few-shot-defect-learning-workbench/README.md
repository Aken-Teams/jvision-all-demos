以少量真實樣本和合成缺陷快速建立新產品視覺檢測模型。模型 F1 分數已達 0.94。

**產業別：**生產製造　|　**系統類型：**quality-qms

## 功能模組

- **缺陷樣本盤點** — 依產品、站點與缺陷類型整理有限的正負影像樣本。
- **少樣本標註台** — 用框選、遮罩與相似樣本建議加速缺陷區域標註。
- **合成缺陷工坊** — 生成具位置、尺寸、材質與光照變化的缺陷影像。
- **快速模型訓練** — 以遷移學習和少樣本策略建立候選檢測模型。
- **誤判壓力測試** — 檢查漏檢、誤報、產線漂移與未見條件下的穩健性。
- **產線檢測發布** — 設定信心門檻、人工複判規則並部署至指定站點。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 盤點缺陷樣本
2. 標註關鍵特徵
3. 生成合成缺陷
4. 訓練候選模型
5. 驗證誤判風險
6. 核准產線部署

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
