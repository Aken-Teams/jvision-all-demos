# 鷹架拆除條件確認台

> 按棟別、立面與樓層盤點外牆工項、查驗缺失、吊掛需求及安全設施，透過各工種會簽確認拆架條件，避免拆除後才發現漏作而重新搭架。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **立面總覽** — 以棟別與區段呈現拆架準備度。
- **條件清單** — 列出各立面拆除前必要工項。
- **工種會簽** — 收集各責任工種完成確認。
- **證據覆核** — 檢視完工照片與查驗紀錄。
- **安全檢核** — 確認拆架動線、隔離與防墜措施。
- **拆除放行** — 核准區段並排定拆除日期。

## 適合誰使用

- 工地主任
- 外牆工程師
- 職安人員

## 運作流程

1. 檢視立面準備度
2. 建立拆架條件
3. 取得工種會簽
4. 覆核完成證據
5. 確認拆除安全
6. 核准拆架排程

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
