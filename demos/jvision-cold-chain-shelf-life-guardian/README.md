# 冷鏈品質與剩餘效期守門台

> 以預先建立的溫度歷程、品項規格與批次資料模擬冷鏈品質變化，估算剩餘貨架期並標示高風險批次，協助品保決定放行、優先出貨、降級使用或隔離。

以預先建立的溫度歷程、品項規格與批次資料模擬冷鏈品質變化，估算剩餘貨架期並標示高風險批次，協助品保決定放行、優先出貨、降級使用或隔離。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **冷鏈品質總覽** — 彙整批次風險、超溫暴露及剩餘效期分布。
- **批次效期清冊** — 查詢品項、批號、標示效期與目前狀態。
- **溫度歷程檢視** — 呈現預先建立的運輸與儲存溫度曲線。
- **剩餘效期估算** — 模擬不同溫度暴露對可用天數的影響。
- **品質放行判定** — 依風險證據記錄放行、降級或隔離決策。
- **優先出貨處置** — 依剩餘效期建議批次排序與去化方式。

## 適合誰使用

- 品質保證人員
- 冷鏈倉管
- 供應鏈主管

## 運作流程

1. 檢視品質風險
2. 選取查核批次
3. 檢查溫度歷程
4. 評估剩餘效期
5. 完成品質判定
6. 安排批次處置

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
