# 表面黏著首件檢查輔助系統

> 整合模擬工單、元件清單、首件影像與檢查規範，逐站引導核對料號、方向、極性、焊點及製程條件，標示疑點並形成電子檢查紀錄，協助主管一致且快速地完成首件放行。

整合模擬工單、元件清單、首件影像與檢查規範，逐站引導核對料號、方向、極性、焊點及製程條件，標示疑點並形成電子檢查紀錄，協助主管一致且快速地完成首件放行。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **首件任務看板** — 顯示待檢、檢查中、待簽核與已放行的首件任務。
- **工單資料核對** — 比對模擬工單、板號、程式版本與用料清單。
- **元件逐項檢查** — 依位置核對料號、數量、方向、極性與外觀。
- **焊點影像輔助** — 在模擬影像中標記可能漏件、偏移或焊接異常。
- **疑點處理中心** — 彙整不符合項目並記錄重檢、修正及責任角色。
- **首件簽核放行** — 呈現檢查軌跡並完成模擬核准、退回或附條件放行。

## 適合誰使用

- 首件檢驗員
- 製程工程師
- 線長
- 品質主管

## 運作流程

1. 建立任務
2. 核對工單
3. 檢查元件
4. 檢視焊點
5. 排除疑點
6. 簽核放行
