# 貨損求償案件管理台

> 協助物流商將破損、短少、汙損及延誤案件串接運單、責任區段、貨值證明、承運契約與賠付進度，縮短跨站點調查及向協力商追償的時間。

協助物流商將破損、短少、汙損及延誤案件串接運單、責任區段、貨值證明、承運契約與賠付進度，縮短跨站點調查及向協力商追償的時間。

**產業別：**物流運輸　|　**系統類型：**legal-case

## 功能模組

- **案件受理** — 關聯運單與損害類型
- **證據清單** — 核對照片及貨值文件
- **責任區段** — 分析站點與承運交接
- **賠付試算** — 依契約計算責任上限
- **追償作業** — 追蹤協力商應負款項
- **案件結案** — 完成核准及收付款紀錄

## 適合誰使用

- 理賠專員
- 運務主管
- 財務專員

## 運作流程

1. 建立案件
2. 蒐集證據
3. 判定責任
4. 核算賠付
5. 執行追償
6. 完成結案

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
