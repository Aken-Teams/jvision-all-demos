# 扣件線材價差報價台

> 供扣件廠將盤元行情、材質附價、成材率、熱處理與表處費帶入客戶報價，設定有效期及漲價門檻，避免沿用舊成本承接負毛利訂單。

供扣件廠將盤元行情、材質附價、成材率、熱處理與表處費帶入客戶報價，設定有效期及漲價門檻，避免沿用舊成本承接負毛利訂單。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **線材行情** — 維護盤元與附價
- **成本試算** — 換算成材與加工
- **報價草案** — 建立數量級距
- **漲價模擬** — 評估成本敏感度
- **例外簽核** — 管制低毛利價格
- **效期追蹤** — 提醒成本重估

## 適合誰使用

- 採購人員
- 報價業務

## 運作流程

1. 更新行情
2. 建立成本
3. 試算報價
4. 毛利檢查
5. 例外核准
6. 報價追蹤

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
