# 國際運費發票拆分台

> 將承攬商單張發票拆至各票貨、幣別、費用項與成本中心，核對報價、匯率及稅別，標記未議定附加費並產出可入帳和可轉嫁客戶的明細。

將承攬商單張發票拆至各票貨、幣別、費用項與成本中心，核對報價、匯率及稅別，標記未議定附加費並產出可入帳和可轉嫁客戶的明細。

**產業別：**物流運輸　|　**系統類型：**finance-ledger

## 功能模組

- **發票匯入** — 載入多票多費用明細
- **票貨拆分** — 分配至提單與客戶案件
- **匯率稅別** — 套用日期幣別與稅務規則
- **報價驗算** — 比較約定與實際收費
- **附加費爭議** — 追查未議定費用項
- **入帳輸出** — 產出成本與轉嫁明細

## 適合誰使用

- 物流成本會計
- 承攬商窗口
- 業務人員

## 運作流程

1. 接收發票
2. 拆分票貨
3. 核定匯稅
4. 比對報價
5. 處理爭議
6. 完成入帳

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
