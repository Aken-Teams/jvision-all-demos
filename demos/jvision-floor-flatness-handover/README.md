# 地坪平整度交接台

> 在地坪移交裝修前，依空間與測點記錄標高、平整度、坡度及積水結果，將超差區域派修並複測，避免後續地材施工後才發現高低差或排水不良。

在地坪移交裝修前，依空間與測點記錄標高、平整度、坡度及積水結果，將超差區域派修並複測，避免後續地材施工後才發現高低差或排水不良。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **空間測點圖** — 呈現房間測點與品質狀態。
- **標高量測** — 登錄設計值、實測值及高低差。
- **坡度檢核** — 判讀洩水方向、坡度與積水測試。
- **超差清單** — 圈選修補區域並指派責任班組。
- **修補複測** — 比較修補前後數值與照片。
- **地坪交接** — 由後續工班確認品質後接收工作面。

## 適合誰使用

- 土建工程師
- 測量工程師
- 裝修領班

## 運作流程

1. 布設測點
2. 執行量測
3. 判定超差
4. 派工修補
5. 完成複測
6. 簽認交接

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
