# 資料目錄與語意搜尋助理

> 建立企業資料表、欄位、指標、報表與負責人的可搜尋目錄，使用者可用日常語句描述需求，由人工智慧理解語意、推薦適合資料、解釋欄位關係並提出存取申請，減少找資料與反覆詢問資訊部門的時間。

建立企業資料表、欄位、指標、報表與負責人的可搜尋目錄，使用者可用日常語句描述需求，由人工智慧理解語意、推薦適合資料、解釋欄位關係並提出存取申請，減少找資料與反覆詢問資訊部門的時間。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **語意搜尋首頁** — 以日常語句搜尋資料表、欄位、指標、報表與主題。
- **資料資產目錄** — 依領域瀏覽資產摘要、更新頻率、品質與使用熱度。
- **欄位血緣檢視** — 呈現欄位定義、上下游關係、轉換邏輯與影響範圍。
- **商業詞彙庫** — 管理共用名詞、指標公式、同義詞與負責部門。
- **資料問答助理** — 解讀使用需求、比較候選資料並說明推薦理由。
- **存取申請中心** — 提交資料用途、權限期間並追蹤審核與到期狀態。

## 適合誰使用

- 資料分析師
- 部門主管
- 資料管理員
- 一般業務使用者

## 運作流程

1. 描述資料需求
2. 瀏覽候選資產
3. 確認欄位血緣
4. 核對名詞定義
5. 取得智慧建議
6. 申請資料存取

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
