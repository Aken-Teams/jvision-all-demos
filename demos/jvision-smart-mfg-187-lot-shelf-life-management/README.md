# 批號效期管理系統（Lot & Shelf-Life Management）

> 收貨到出貨的倉內作業與庫存精準管理

批號效期管理系統（Lot & Shelf-Life Management）提供批號自動綁定與追溯、效期到期預警、先進先出(FIFO)/先到期先出(FEFO)出庫規則。倉儲部依「入庫登記批號效期→系統排定出庫順序→到期預警→隔離處置→出庫批號記錄」推進作業，優先解決「過期料件誤用導致品質異常」，品保部則以效期報廢率與批號追溯完整率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**倉儲物流　|　**系統類型：**WMS 倉儲管理系統

## 功能模組

- **入庫上架** — 收貨、驗收與智慧上架
- **揀貨出貨** — 波次揀貨、覆核與出貨
- **儲位管理** — 儲位規劃與庫容視覺化
- **庫存盤點** — 即時庫存、盤點與調撥
- **拉動補料** — 安全庫存與自動補貨
- **條碼作業** — PDA 掃碼即時作業

## 適合誰使用

- 倉儲部
- 品保部
- 生管部

## 運作流程

1. 待盤點
2. 待補貨
3. 移庫中
4. 出庫完成

## 導入效益

- 揀貨作業工時：7.3小時/日 → **2小時/日**
- 庫存準確率：90% → **95%**
- 出貨延遲率：9% → **1.9%**
- 盤點工時：16小時/月 → **3.2小時/月**
