# 批號效期管理洞察站

追蹤電子料件與化學輔料的批號、效期與先進先出規則，避免過期料件流入產線。

- 原始系統：批號效期管理系統（Lot & Shelf-Life Management）
- 產業分類：智慧製造｜倉儲管理
- 使用部門：倉儲部、品保部、生管部、製造部
- 工作流程：入庫登記批號效期→系統排定出庫順序→到期預警→隔離處置→出庫批號記錄
- AI 應用：效期風險預測與優先耗用建議、異常批號使用型態偵測
- 主要 KPI：效期報廢率、批號追溯完整率、FEFO執行率、異常攔截次數
- 代表產品：SAP Batch Management、Oracle SCM、鼎捷Digiwin批號管理模組
