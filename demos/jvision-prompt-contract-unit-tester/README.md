# Prompt 單元測試器

> 以輸入輸出契約自動測試 Prompt 行為，提升修改與發布安全性。

以輸入輸出契約自動測試 Prompt 行為，提升修改與發布安全性。

**產業別：**資訊科技　|　**系統類型：**quality-qms

## 功能模組

- **輸出契約編輯器** — 定義必要欄位、格式、語意規則、拒答條件與允許誤差。
- **測試輸入工廠** — 建立正常、邊界、惡意及多輪情境的參數化測試案例。
- **Prompt 測試執** — 對指定 Prompt 與模型矩陣批次執行可重現的單元測試。
- **契約斷言檢查** — 逐項判定結構、內容、安全與工具呼叫是否符合契約。
- **修改影響模擬** — 預測候選修改對通過率、成本、延遲與失敗類型的影響。
- **發布品質閘門** — 依測試結果與風險規則決定是否允許 Prompt 版本發布。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 選擇測試標的
2. 編寫輸出契約
3. 建立測試案例
4. 執行模型矩陣
5. 分析失敗影響
6. 核准安全發布
