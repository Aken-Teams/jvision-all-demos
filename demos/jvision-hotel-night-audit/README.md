# 旅宿夜間營收稽核台

> 協助飯店夜間班核對房費、餐飲掛帳、折讓、押金與付款批次，逐項處理跨日異常並產出可交接的日結營收報告。

協助飯店夜間班核對房費、餐飲掛帳、折讓、押金與付款批次，逐項處理跨日異常並產出可交接的日結營收報告。

**產業別：**餐飲旅宿　|　**系統類型：**finance-ledger

## 功能模組

- **日結批次** — 建立營業日關閉清單與責任人。
- **房費核對** — 比對房況、房價及實際過帳。
- **掛帳核對** — 檢查餐飲與其他營業點轉房帳。
- **收款平衡** — 核對現金、刷卡、押金及退款。
- **異常調整** — 處理漏過帳、折讓與付款差異。
- **日結簽核** — 產出營收摘要並完成跨班交接。

## 適合誰使用

- 夜間稽核員
- 櫃台主管
- 收入會計

## 運作流程

1. 啟動營業日結
2. 核對客房收入
3. 核對跨點掛帳
4. 平衡各式收款
5. 覆核異常調整
6. 關閉營業日

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
