# 醫療險核保評估台

> 集中檢視投保告知、病史摘要、檢查報告、核保規則與加費除外建議，協助核保人員留下可追溯的一致決策紀錄。

集中檢視投保告知、病史摘要、檢查報告、核保規則與加費除外建議，協助核保人員留下可追溯的一致決策紀錄。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **案件分流** — 依保額與健康告知分派案件。
- **病史摘要** — 整理疾病、用藥與檢查紀錄。
- **補件管理** — 追蹤體檢與醫療文件缺項。
- **規則評估** — 比對核保規則與風險因子。
- **條件建議** — 擬定標準、加費或除外方案。
- **決策覆核** — 記錄核定理由與主管意見。

## 適合誰使用

- 核保人員
- 核保醫師
- 核保主管

## 運作流程

1. 案件分流
2. 閱讀病史
3. 追蹤補件
4. 醫療評估
5. 擬定條件
6. 核定決策

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
