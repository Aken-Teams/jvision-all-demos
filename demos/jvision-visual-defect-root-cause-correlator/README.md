關聯缺陷影像、設備、材料與參數，找出可執行的改善根因。実際 至少 6 characters...

**產業別：**生產製造　|　**系統類型：**quality-qms

## 功能模組

- **缺陷影像聚類** — 依紋理、形狀與位置將新舊缺陷影像自動分群。
- **設備狀態對位** — 把影像拍攝時點對齊機台、模具與維護狀態。
- **材料批次關聯** — 比對材料供應批次、檢驗特徵與缺陷發生率。
- **參數偏移分析** — 找出缺陷前後溫度、壓力、速度等參數異動。
- **根因候選排序** — 以可解釋分數排序設備、材料與參數的根因組合。
- **改善方案模擬** — 預測調整方案對缺陷率、產能與誤判風險的影響。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 辨識缺陷族群
2. 對齊設備狀態
3. 核查材料批次
4. 分析參數偏移
5. 評估根因候選
6. 核准改善試驗

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
