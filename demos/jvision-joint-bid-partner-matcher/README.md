# 聯合投標夥伴媒合器

> 依標案資格缺口、合作實績與利益衝突，媒合可共同投標的夥伴。能。

依標案資格缺口、合作實績與利益衝突，媒合可共同投標的夥伴。能。

**產業別：**專業服務　|　**系統類型：**procurement-srm

## 功能模組

- **標案條件拆解** — 解析資格、證照、實績、在地要求與評選條件。
- **資格缺口矩陣** — 對照自身能力，標示必須由合作夥伴補足的條件。
- **夥伴候選媒合** — 依能力互補、共同實績與可用產能推薦候選公司。
- **利益衝突檢查** — 檢查競業關係、排他條款、關係人與投標限制。
- **聯盟成本試算** — 比較分工、報價、毛利、保證責任與履約成本。
- **投標團隊組裝** — 形成主承包商、分包商、顧問與實績引用配置。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 匯入標案需求
2. 盤點資格缺口
3. 搜尋互補夥伴
4. 排除合作風險
5. 協商分工成本
6. 核准聯合團隊

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
