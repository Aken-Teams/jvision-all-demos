# 大體積混凝土澆置管制台

> 針對筏基、厚牆等大體積混凝土建立分區澆置順序、供料節拍、冷縫時限、分層厚度、試體與溫控紀錄，讓停車、泵送異常及配比切換都有一致處置依據。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **澆置分區** — 設定順序、方量、分層及施工縫位置。
- **供料車序** — 安排車號、配比與預定到場節拍。
- **澆置節拍** — 追蹤出廠、到場、卸料與區段間隔。
- **現場試驗** — 登錄坍度、氯離子及試體組別。
- **溫控紀錄** — 管理測溫點、養護與溫差狀態。
- **中斷應變** — 處理塞管、停車、退料與冷縫措施。

## 適合誰使用

- 土建工程師
- 預拌廠調度
- 品管工程師

## 運作流程

1. 劃分澆區
2. 排定供料
3. 到場檢驗
4. 連續澆置
5. 溫控養護
6. 異常結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
