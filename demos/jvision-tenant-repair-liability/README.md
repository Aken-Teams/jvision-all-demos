# 租戶修繕歸責判定台

> 集中報修事實、租約條款、現勘照片、報價與租戶確認，依設備範圍判定房東、物業或租戶責任，避免工程完成後才爭議付款。

集中報修事實、租約條款、現勘照片、報價與租戶確認，依設備範圍判定房東、物業或租戶責任，避免工程完成後才爭議付款。

**產業別：**房地產與物業　|　**系統類型：**legal-case

## 功能模組

- **報修案件** — 記錄位置、症狀與申報人。
- **條款比對** — 查看租約維修責任。
- **現勘證據** — 保存原因及設備狀況。
- **報價評估** — 比較工項與責任金額。
- **責任確認** — 取得租戶或房東簽認。
- **費用結案** — 追蹤付款、代墊及押金。

## 適合誰使用

- 物業主任
- 租務專員
- 工程主管

## 運作流程

1. 受理報修
2. 查閱條款
3. 完成現勘
4. 提出報價
5. 確認責任
6. 完成結算

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
