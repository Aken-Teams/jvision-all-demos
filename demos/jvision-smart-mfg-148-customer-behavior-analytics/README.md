# 客戶行為分析 Customer Behavior Analytics協作所

分析客戶下單頻率、產品偏好與互動軌跡，挖掘交叉銷售與增購機會，強化客戶經營策略。

- 原始系統：客戶行為分析 Customer Behavior Analytics
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、行銷部、產品部、管理層
- 工作流程：整合多來源客戶數據→建立行為分析模型→產出洞察與建議→業務執行經營策略→成效追蹤回饋
- AI 應用：交叉銷售/增購機會智慧推薦、客戶流失風險預測模型
- 主要 KPI：交叉銷售成功率、客戶流失預警準確率、客單價成長率、既有客戶營收占比
- 代表產品：Microsoft Dynamics 365 Customer Insights、Salesforce Customer 360、Tableau CRM Analytics
