# 城市路燈節能維運平台

> 以路燈資產、照明時段、用電與報修紀錄的擬真資料，找出異常耗電及疑似故障燈具，協助管理單位規劃分區調光策略、安排維修路線、管理備料並驗證節能成效。

以路燈資產、照明時段、用電與報修紀錄的擬真資料，找出異常耗電及疑似故障燈具，協助管理單位規劃分區調光策略、安排維修路線、管理備料並驗證節能成效。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **照明營運總覽** — 呈現各行政區亮燈率、用電、故障、工單與節能目標。
- **路燈資產地圖** — 在示意地圖查看燈具位置、型號、狀態、維修歷史與周邊重要性。
- **調光節能策略** — 依道路類型與時段模擬亮度排程、節電量及安全限制。
- **故障診斷中心** — 分類不亮、閃爍、日間亮燈與耗電異常，顯示可能原因。
- **維修派工路線** — 依故障急迫性、區域、技能與備料組合維修批次及行駛順序。
- **維運績效分析** — 分析妥善率、修復時間、重複故障、節電成果與區域差異。

## 適合誰使用

- 路燈維運專員
- 派工主管
- 節能管理員

## 運作流程

1. 掌握照明營運
2. 定位問題資產
3. 規劃調光策略
4. 研判故障原因
5. 安排維修路線
6. 檢討維運績效

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
