# 建照規費繳納核銷台

> 集中管理建照、使照與各項審查規費通知，追蹤繳費期限、專案歸屬、代墊、收據正本及帳務核銷，防止逾期或重複繳納。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **規費清冊** — 查看機關項目與期限
- **通知收件** — 登錄公文金額及依據
- **付款申請** — 完成專案和科目簽核
- **繳費追蹤** — 記錄付款方式與時間
- **收據管理** — 保存正本位置及影像
- **核銷勾稽** — 配對代墊與會計入帳

## 適合誰使用

- 法規承辦
- 出納人員
- 成本會計

## 運作流程

1. 收到通知
2. 確認歸屬
3. 主管核准
4. 執行繳納
5. 收據歸檔
6. 財務核銷

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
