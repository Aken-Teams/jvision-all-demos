# 資料權限使用率清理器

> 依實際使用與業務需求清除閒置及過度資料權限，縮小資料暴露面。

依實際使用與業務需求清除閒置及過度資料權限，縮小資料暴露面。

**產業別：**數據分析　|　**系統類型：**security-soc

## 功能模組

- **授權暴露盤點** — 彙整人員、群組、服務帳號對資料資產的有效存取範圍。
- **權限使用分析** — 依查詢與存取紀錄判斷權限的使用頻率、末次使用及用途。
- **長期閒置權限** — 找出超過政策期限未使用且無必要相依性的授權。
- **過度授權偵測** — 比較職務、資料敏感度與實際行為，標示超出需求的權限。
- **最小權限方案** — 提出撤銷、降級、限時化或拆分群組的具體清理建議。
- **撤權復原監控** — 追蹤撤權後失敗事件，必要時依核准條件暫時恢復存取。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 界定清理範圍
2. 比對授權與使用
3. 判定暴露風險
4. 產生縮權方案
5. 核准清理批次
6. 執行並監控撤權

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
