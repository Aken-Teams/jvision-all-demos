**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **事故範圍判讀** — 辨識停線設備、受影響製程、工單與連鎖風險。
- **在製品損失盤點** — 估算各批在製品的報廢、逾時與可挽救價值。
- **客戶承諾排序** — 依交期、合約罰則與客戶等級計算訂單急迫度。
- **復機資源配對** — 核對人員、設備、模具、物料與維修能力是否到位。
- **復機序列推演** — 比較候選復機順序對產能、交期與損失的影響。
- **復原指令協同** — 發布核准序列、追蹤交接，異常時升級或回滾。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 界定事故
2. 盤點在製品
3. 衡量承諾
4. 核實資源
5. 核准序列
6. 執行復原

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
