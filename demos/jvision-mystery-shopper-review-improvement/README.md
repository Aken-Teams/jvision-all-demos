# 神秘客評論門市改善助手

> 整合擬真的神秘客稽核、顧客評論與門市回覆資料，歸納服務、環境及商品問題，協助門市找出根因、建立改善計畫、演練回覆並追蹤改善成效。

整合擬真的神秘客稽核、顧客評論與門市回覆資料，歸納服務、環境及商品問題，協助門市找出根因、建立改善計畫、演練回覆並追蹤改善成效。

**產業別：**客服管理　|　**系統類型：**service-desk

## 功能模組

- **回饋收件總覽** — 集中呈現神秘客報告與模擬評論，依門市、來源和嚴重度篩選。
- **問題主題洞察** — 將回饋歸納為服務、環境、商品與流程主題，顯示情緒和趨勢。
- **門市體驗診斷** — 整合門市評分、重複問題及同區比較，找出優先改善項目。
- **問題根因分析** — 用引導式魚骨圖與追問卡整理現象、原因、證據及可控因素。
- **回覆改善共編** — 草擬顧客回覆與內部改善計畫，設定責任人、期限和驗證指標。
- **改善成效追蹤** — 比較改善前後評分、負評主題與任務完成情況，判定是否結案。

## 適合誰使用

- 顧客體驗主管
- 區域督導
- 門市店長
- 客服人員

## 運作流程

1. 彙整顧客回饋
2. 歸納問題主題
3. 診斷門市表現
4. 釐清問題根因
5. 擬定回覆改善
6. 驗證改善成效

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
