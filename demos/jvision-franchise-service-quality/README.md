# 加盟服務品質稽訪台

> 管理總部對加盟門市的服務抽查、神秘客紀錄、改善承諾與複查證據，協助客服及營運團隊追蹤跨店服務標準落差。

管理總部對加盟門市的服務抽查、神秘客紀錄、改善承諾與複查證據，協助客服及營運團隊追蹤跨店服務標準落差。

**產業別：**客服管理　|　**系統類型：**service-desk

## 功能模組

- **門市分群** — 依區域與風險建立稽訪名單。
- **服務量表** — 維護接待與問題處理標準。
- **稽訪紀錄** — 記錄觀察結果與情境證據。
- **改善承諾** — 指派負責人及完成期限。
- **複查驗證** — 審核改善證據與再次訪查。
- **跨店比較** — 比較分數、缺失及改善速度。

## 適合誰使用

- 客服主管
- 區域督導
- 加盟店長

## 運作流程

1. 規劃稽訪
2. 執行觀察
3. 確認缺失
4. 承諾改善
5. 完成複查
6. 檢討趨勢

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
