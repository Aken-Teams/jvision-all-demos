# 承攬商動火銷項台

> 供工廠機修動火作業管理人員資格、隔離、氣瓶與監火條件，收工後完成餘火複查、工具清點及設備復歸，未銷項許可持續警示。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **動火看板** — 查看進行中區域
- **資格核對** — 確認人員證照
- **隔離檢點** — 記錄斷能防護
- **監火巡查** — 回報現場狀態
- **收工複查** — 清點餘火氣瓶
- **許可銷項** — 恢復設備與區域

## 適合誰使用

- 維修監工
- 工安人員

## 運作流程

1. 提出申請
2. 資格審核
3. 現場開工
4. 監火巡查
5. 收工複查
6. 許可銷項

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
