# 合約審閱風險分級助手

> 協助法務逐條檢視採購、銷售與合作合約，將關鍵條款、缺漏內容及偏離公司範本之處分類標示，提供風險理由、修訂建議與協商重點，讓非法律背景主管也能快速理解合約風險並完成審核。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **合約案件建立** — 選擇合約類型、交易背景並載入擬真文件內容。
- **條款辨識檢視** — 依章節呈現條款摘要、關係人、金額與重要日期。
- **風險分級面板** — 將責任、賠償、保密及終止等風險分級並說明理由。
- **範本差異比對** — 並列公司標準條款與對方版本，醒目標示增刪修改。
- **修訂建議工作台** — 產生替代文字、談判底線及可接受的折衷方案。
- **審閱簽核摘要** — 彙整未決風險、承辦回覆、審核意見與簽署建議。

## 適合誰使用

- 企業法務
- 業務主管
- 採購主管
- 合約承辦人

## 運作流程

1. 建立審閱案件
2. 確認條款辨識
3. 評估條款風險
4. 比對標準範本
5. 擬定修訂策略
6. 完成審閱決策
