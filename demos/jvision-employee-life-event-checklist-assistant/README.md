## 功能模組

- **生命事件申報** — 引導員工選擇結婚、生育、搬遷或家庭變動並填寫生效日。
- **個人化事項組合** — 依事件、身分、地區與到職條件產生專屬辦理清單。
- **福利資格核對** — 比對福利辦法與員工資料，確認補助、假別及申請期限。
- **必備文件檢查** — 列出證明文件、表單與簽章要求，指出缺件或資料不一致。
- **跨部門辦理協調** — 安排 HR、薪酬、門禁、保險與總務事項的先後關係。
- **員工事項辦結** — 經員工確認後送出申請，追蹤各事項完成狀態與權益生效。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 申報生命事件
2. 產生應辦清單
3. 核對福利權益
4. 補齊申請文件
5. 協調部門辦理
6. 確認權益生效

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
