# IoT 裝置身分健康雷達

> 持續評估 IoT 裝置的憑證、韌體、硬體與行為可信度，及早發現冒用。

持續評估 IoT 裝置的憑證、韌體、硬體與行為可信度，及早發現冒用。

**產業別：**設備維護　|　**系統類型：**security-soc

## 功能模組

- **裝置身分總覽** — 整合裝置 ID、憑證、硬體指紋與註冊歸屬。
- **憑證壽命監測** — 追蹤到期、撤銷、輪替失敗與異常簽發狀況。
- **硬體指紋偏移** — 偵測安全晶片、序號與硬體組態是否遭替換。
- **韌體可信驗證** — 比對簽章、版本、開機證明與已知弱點狀態。
- **裝置行為基線** — 辨識連線、遙測與命令模式偏離可信基線的跡象。
- **冒用處置控制** — 彙整身分風險並執行隔離、重驗或憑證撤銷核准。

## 適合誰使用

- IoT 架構師
- 設備工程師
- 場域主管

## 運作流程

1. 建立身分基線
2. 檢查憑證健康
3. 驗證硬體一致
4. 驗證韌體可信
5. 研判行為異常
6. 核准隔離處置

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
