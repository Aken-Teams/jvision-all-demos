# 飯店迷你吧耗用結算台

> 讓房務逐房回報迷你吧耗用、補充與招待，櫃台在退房前完成核對及入帳；逾時回報則進入補帳與聯絡流程，避免漏收、錯房及重複扣款。

**產業別：**餐飲旅宿　|　**系統類型：**pos-frontdesk

## 功能模組

- **房況總覽** — 查看待查與將退房房間
- **耗用回報** — 登錄品項數量與招待
- **房帳核對** — 比對前次補充與現存
- **退房入帳** — 確認費用加入房帳
- **離館補帳** — 處理逾時追收與授權
- **盤差分析** — 分析漏收與異常耗用

## 適合誰使用

- 房務人員
- 櫃台人員
- 夜審人員

## 運作流程

1. 排定巡房
2. 回報耗用
3. 核對房帳
4. 完成結帳
5. 處理補帳
6. 檢討盤差

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
