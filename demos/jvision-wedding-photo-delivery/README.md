## 功能模組

- **素材清單** — 管理原檔選片與缺件
- **後製版本** — 比較照片影片修訂版
- **客戶意見** — 彙整逐項回覆與輪次
- **相本製作** — 追蹤排版校稿與送印
- **交件驗收** — 核對數量格式與成品
- **尾款條件** — 依驗收結果通知收款

## 適合誰使用

- 婚攝專案經理
- 後製人員
- 門店會計

## 運作流程

1. 建立交付項目
2. 收集新人選片
3. 執行後製修訂
4. 彙整客戶驗收
5. 完成成品製作
6. 交付收取尾款
