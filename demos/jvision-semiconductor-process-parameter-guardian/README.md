# 半導體製程參數守門員

> 針對先進製程控制提出的參數調整建議，提供影響預覽、規格邊界檢查、風險分級與簽核流程。系統以擬真歷史資料模擬自動製程控制情境，避免不合理設定直接進入生產。

針對先進製程控制提出的參數調整建議，提供影響預覽、規格邊界檢查、風險分級與簽核流程。系統以擬真歷史資料模擬自動製程控制情境，避免不合理設定直接進入生產。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **建議佇列** — 集中呈現各站點待審建議、風險等級與處理時限。
- **參數詳情** — 比較現值、建議值、調整幅度及建議依據。
- **邊界檢查** — 依工程上下限、互鎖條件與產品規則檢查衝突。
- **影響模擬** — 用擬真資料預覽參數變更對品質指標的可能影響。
- **變更簽核** — 支援核准、退回、加註條件及限批試行決策。
- **成效回顧** — 追蹤已核准建議的模擬結果、偏差與規則命中紀錄。

## 適合誰使用

- 製程工程師
- 設備工程師
- 值班主管

## 運作流程

1. 接收建議
2. 確認內容
3. 檢查邊界
4. 預覽影響
5. 簽核變更
6. 回顧成效

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
