## 功能模組

- **行權窗口總覽** — 集中顯示即將開啟、可行使、將到期與已錯失的權利窗口。
- **價格調整權** — 追蹤調價條件、指數基準、通知期與生效日。
- **終止解除權** — 監控便利終止、違約終止、補正期間與通知要求。
- **索賠請求權** — 計算索賠通知、資料提交與時效中斷等關鍵期限。
- **稽核檢查權** — 管理稽核頻率、提前通知、資料範圍與現場查核窗口。
- **行權通知執行** — 產生通知草案、確認送達方式並追蹤對方回應與結果。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 盤點權利窗口
2. 評估價格調整
3. 審視終止條件
4. 準備索賠主張
5. 安排稽核行權
6. 核准並送達通知
