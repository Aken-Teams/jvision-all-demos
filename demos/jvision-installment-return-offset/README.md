# 分期商戶退貨沖款台

> 將商戶退貨單連結原分期交易、已出帳期數、剩餘本金與已撥商戶款，支援部分退貨的消費者退款、商戶追款及利息調整。

將商戶退貨單連結原分期交易、已出帳期數、剩餘本金與已撥商戶款，支援部分退貨的消費者退款、商戶追款及利息調整。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **退貨受理** — 登錄商戶單據與金額
- **原交易匹配** — 連結分期與撥款資料
- **沖款試算** — 計算本金期數與利息
- **商戶追款** — 判定已撥款返還責任
- **帳單調整** — 停止扣款或建立退款
- **差異覆核** — 核對雙邊餘額後結案

## 適合誰使用

- 分期帳務
- 商戶服務
- 財務覆核

## 運作流程

1. 接收商戶退貨
2. 匹配原分期交易
3. 試算退貨沖款
4. 確認商戶責任
5. 調整消費者帳單
6. 完成雙邊覆核

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
