# 遺失物智慧媒合台

> 以影像、地點和時間媒合失物與失主，提升物品安全歸還率。中文。

以影像、地點和時間媒合失物與失主，提升物品安全歸還率。中文。

**產業別：**企業協作　|　**系統類型：**operations-console

## 功能模組

- **失物影像建檔** — 從照片辨識品類、顏色、品牌、材質與可區辨特徵。
- **失主線索登錄** — 將遺失描述、可能地點、時間及持有人資訊轉為搜尋條件。
- **時空軌跡比對** — 比對拾獲位置、門禁動線、訪客紀錄與遺失時間窗。
- **智慧媒合候選** — 融合影像、文字與時空特徵，排序可能相符的失物案件。
- **所有權驗證** — 以未公開特徵及補充問題驗證申領者對物品的了解。
- **安全領回交付** — 安排領取、代理授權或寄送，並記錄最終交付結果。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 建立失物特徵
2. 建立遺失描述
3. 縮小時空範圍
4. 審閱媒合結果
5. 驗證申領身分
6. 完成安全交付

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
