# Agent 決策可解釋台

> 還原 Agent 決策依據、替代方案與不確定性，協助主管審查自動決策。

還原 Agent 決策依據、替代方案與不確定性，協助主管審查自動決策。

**產業別：**資訊科技　|　**系統類型：**analytics-bi

## 功能模組

- **決策路徑還原** — 重建目標、規劃步驟、工具呼叫與最終決策的因果順序。
- **依據來源檢視** — 呈現每項主張引用的企業資料、規則與即時訊號。
- **替代方案比較** — 並列候選方案、淘汰原因、預期效益與限制條件。
- **不確定性剖面** — 拆解信心區間、資料缺口、敏感因子與模型分歧。
- **主管反事實測試** — 調整關鍵條件，觀察決策排序與結果如何改變。
- **決策審查裁定** — 接受、退回或轉人工，並記錄主管裁定理由。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 選定待審決策
2. 還原決策路徑
3. 查驗決策依據
4. 比較替代方案
5. 測試不確定性
6. 完成審查裁定
