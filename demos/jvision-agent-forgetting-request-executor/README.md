## 功能模組

- **遺忘範圍辨識** — 以資料主體識別碼解析需刪除的帳戶、事件與關聯內容。
- **資料足跡追蹤** — 跨向量庫、日誌、快取、記憶與備援索引建立資料分布圖。
- **保留義務判定** — 區分可刪除資料、法定保留項目及需去識別化的紀錄。
- **分層刪除編排** — 依相依順序調度各儲存層刪除、失效與索引重建作業。
- **殘留資料複查** — 以原識別碼、別名與語意近似查詢驗證是否仍可取回資料。
- **完成證明簽發** — 彙整刪除範圍、保留例外、執行結果與責任人證明。

## 適合誰使用

## 運作流程

1. 受理遺忘請求
2. 建立足跡地圖
3. 裁定保留界線
4. 執行分層刪除
5. 驗證不可取回
6. 核發完成證明
