# 工程材料樣品核定台

> 管理建材樣品從規格比對、送樣、設計審查、業主選色、封樣到進場核對，確保採購及施工使用的是已核定版本。

管理建材樣品從規格比對、送樣、設計審查、業主選色、封樣到進場核對，確保採購及施工使用的是已核定版本。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **送樣清單** — 列出材料、區域及需求日期。
- **規格比對** — 核對契約規範與廠商提案。
- **樣式選擇** — 呈現色號、紋理與替代方案。
- **審查意見** — 彙整設計、監造與業主意見。
- **核定封樣** — 鎖定核准型號及樣品版本。
- **進場核對** — 比對到場材料與封樣資料。

## 適合誰使用

- 材料工程師
- 設計監造
- 採購工程師

## 運作流程

1. 建立材料送樣
2. 完成規格比對
3. 提出樣式選項
4. 彙整審查意見
5. 核定封樣版本
6. 查驗進場材料

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
