# 遊覽車包車營運台

> 管理包車詢價、行程里程、車輛適配、司機指派、住宿膳雜與出車文件，將報價到結案串成完整流程，協助遊覽車業者避免車班衝突並掌握案件毛利。

管理包車詢價、行程里程、車輛適配、司機指派、住宿膳雜與出車文件，將報價到結案串成完整流程，協助遊覽車業者避免車班衝突並掌握案件毛利。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **詢價案件** — 管理客戶需求、人數、日期與行程版本。
- **行程編排** — 拆解景點、里程、停留及過夜安排。
- **報價試算** — 計算車資、空駛、膳雜與住宿成本。
- **車班配置** — 檢查車型容量、保養狀態與檔期衝突。
- **司機任務** — 安排司機並核對工時及必要文件。
- **案件結算** — 彙整加時、停車與實際成本及毛利。

## 適合誰使用

- 包車業務
- 調度人員
- 車隊主管

## 運作流程

1. 受理詢價
2. 編排行程
3. 提出報價
4. 配置車輛
5. 指派司機
6. 完成結算

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
