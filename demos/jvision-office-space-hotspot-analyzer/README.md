# 辦公空間熱點分析器

> 融合人流與預約資料辨識擁擠及閒置區，支援辦公空間重配。＂ 服務估值風險

融合人流與預約資料辨識擁擠及閒置區，支援辦公空間重配。＂ 服務估值風險

**產業別：**企業協作　|　**系統類型：**analytics-bi

## 功能模組

- **人流密度觀測** — 呈現門禁、感測器與區域人數的時段變化。
- **預約使用比對** — 比對預約、實際進場與空間占用，找出落差。
- **樓層熱點地圖** — 以熱區呈現擁擠、閒置、停留時間與動線瓶頸。
- **尖離峰模式分析** — 辨識週間、時段與團隊活動造成的空間使用模式。
- **空間重配模擬** — 模擬座位、會議室與共享區調整後的容量效果。
- **重配方案提案** — 彙整熱點發現、預期效益與施工影響供核准。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 選定分析範圍
2. 比對人流與預約
3. 定位擁擠閒置區
4. 解析使用模式
5. 模擬空間重配
6. 提交重配提案

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
