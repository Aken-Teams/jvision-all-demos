# 社區公基金工程台

> 協助社區管委會管理公共基金修繕提案、住戶決議、廠商估價、分期付款與驗收保固，讓重大公共工程的資金用途及進度可被追溯。

協助社區管委會管理公共基金修繕提案、住戶決議、廠商估價、分期付款與驗收保固，讓重大公共工程的資金用途及進度可被追溯。

**產業別：**房地產與物業　|　**系統類型：**construction-pm

## 功能模組

- **基金總覽** — 掌握可用、保留與已支出金額
- **修繕提案** — 建立範圍、原因及預算需求
- **決議紀錄** — 保存會議表決與授權結果
- **估價比較** — 並列廠商報價及條件
- **驗收付款** — 依里程碑核對付款資格
- **保固追蹤** — 管理缺失改善及保固期限

## 適合誰使用

- 物業經理
- 管委會委員
- 社區財務

## 運作流程

1. 提出修繕
2. 編列預算
3. 完成決議
4. 評選廠商
5. 驗收付款
6. 管理保固

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
