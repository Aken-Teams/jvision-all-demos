# 企業搜尋意圖理解器

> 辨識查人、查事、查政策與查證據意圖，提升企業搜尋結果相關性。

辨識查人、查事、查政策與查證據意圖，提升企業搜尋結果相關性。

**產業別：**企業協作　|　**系統類型：**operations-console

## 功能模組

- **搜尋語句解析** — 拆解自然語句中的目標、範圍、時間與條件。
- **意圖路由圖** — 將查人、查事、查政策與查證據意圖分流至適合的搜尋策略。
- **企業實體抽取** — 辨識人員、專案、制度、案件、系統與日期等企業實體。
- **相關性策略台** — 依意圖調整來源權重、排序特徵與搜尋範圍。
- **查證答案工作區** — 整合多來源結果，產生附出處且可核對的答案。
- **意圖品質監測** — 追蹤誤判、零結果、改寫率與使用者回饋並建立改善案件。

## 適合誰使用

- 知識工作者
- 主管
- 客服

## 運作流程

1. 輸入搜尋需求
2. 判定搜尋意圖
3. 確認關鍵實體
4. 套用排序策略
5. 核對答案出處
6. 改善低品質查詢

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
