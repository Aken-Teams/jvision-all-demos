# 新進員工報到管理系統（Onboarding Management）

> 應收付、現金流到預算的財務即時掌握

新進員工報到管理系統（Onboarding Management）提供報到前文件與體檢預約、到職手續電子化簽署、新人訓練排程自動指派。人資部依「錄取通知 → 報到文件準備 → 到職手續辦理 → 新人訓練指派 → 試用期追蹤 → 轉正評核」推進作業，優先解決「大量新人同時到職手續紙本作業慢」，產線用人主管則以報到手續完成時效與試用期留任率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**財務會計系統

## 功能模組

- **應收帳款** — 開立、對帳與催收
- **應付帳款** — 請款、付款與對帳
- **現金流** — 資金調度與預測
- **預算管理** — 編列、控管與差異分析
- **固定資產** — 資產登錄與折舊
- **總帳傳票** — 傳票、拋轉與月結

## 適合誰使用

- 人資部
- 產線用人主管
- 教育訓練組

## 運作流程

1. 待處理
2. 主管確認
3. 人資執行
4. 歸檔完成

## 導入效益

- 薪資作業工時：41小時/月 → **8小時/月**
- 出勤異常處理：32分鐘 → **5.2分鐘**
- 招募到位天數：43天 → **26天**
- 表單簽核時效：3天 → **1天**
