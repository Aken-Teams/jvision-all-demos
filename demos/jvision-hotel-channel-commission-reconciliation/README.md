# 旅宿佣金請款核對台

> 按訂單、入住與退款事件比對各訂房平台佣金帳單，辨識改期、取消、部分退款及費率套用錯誤，協助旅館在付款前提出爭議。

按訂單、入住與退款事件比對各訂房平台佣金帳單，辨識改期、取消、部分退款及費率套用錯誤，協助旅館在付款前提出爭議。

**產業別：**餐飲旅宿　|　**系統類型：**finance-ledger

## 功能模組

- **帳單匯入** — 整理各通路佣金明細。
- **訂單配對** — 連結入住、改期及退款紀錄。
- **費率驗算** — 依合約檢查佣金比例。
- **差異案件** — 分類多收、漏折與重複計費。
- **爭議追蹤** — 記錄通路回覆與折讓。
- **付款覆核** — 核准無爭議應付金額。

## 適合誰使用

- 應付會計
- 訂房專員
- 財務主管

## 運作流程

1. 匯入帳單
2. 配對訂單
3. 驗算費率
4. 建立爭議
5. 確認折讓
6. 核准付款

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
