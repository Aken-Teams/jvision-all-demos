# 健檢報告提醒台

> 預約、病歷、診療到申報回診的照護流程

追蹤健檢項目、報告、異常與複檢提醒。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**醫療照護　|　**系統類型：**診所 / 照護系統

## 功能模組

- **預約掛號** — 線上預約與報到
- **病患病歷** — 病歷與就診紀錄
- **診療處置** — 醫囑、處方與處置
- **申報請款** — 健保申報與請款
- **回診追蹤** — 主動回診與提醒
- **藥材庫存** — 藥品/耗材管理

## 適合誰使用

- 櫃檯人員
- 護理長
- 院所負責人

## 運作流程

1. 待確認
2. 照護中
3. 待回覆
4. 批價完成

## 導入效益

- 候診等待：37分鐘 → **12分鐘**
- 回診完成率：69% → **94%**
- 申報退件率：8.3% → **1.9%**
- 紀錄作業工時：3.8小時/日 → **1小時/日**
