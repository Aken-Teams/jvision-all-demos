# 材料替代評估協調台

> 針對缺貨、停產或交期風險提出替代材料，集中比較規格、認證、色樣、介面、價格與工期影響，依序取得設計、監造及業主核定，並將結果交付採購與現場。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **替代需求** — 登錄原規格、替代原因、需求日期與候選材料。
- **規格比對** — 比較性能、尺寸、認證、色樣及施工介面。
- **商務影響** — 評估價差、交期、最低訂量與既有訂單處置。
- **專業會審** — 彙整設計、監造、工務及業主的審查意見。
- **核定版本** — 保存核准品項、條件、樣品編號與生效日期。
- **採購交底** — 將核定結果同步採購與現場並撤銷舊資料。

## 適合誰使用

- 採購工程師
- 設計監造人員
- 工務工程師

## 運作流程

1. 提出需求
2. 比較規格
3. 評估商務
4. 辦理會審
5. 完成核定
6. 執行交底

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
