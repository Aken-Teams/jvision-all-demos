# 防火牆與網路資安管理決策室

集中管理廠區與辦公室多台防火牆、入侵防禦設備的政策設定與威脅防禦，統一資安邊界控管。

- 原始系統：防火牆與網路資安管理平台（NGFW/Firewall Management）
- 產業分類：智慧製造｜IT管理
- 使用部門：資訊安全部、資訊部、網管人員
- 工作流程：防火牆設備納管→政策集中設定→變更申請審核→政策部署與生效→流量與威脅監控→定期政策稽核
- AI 應用：異常流量與攻擊型態偵測、政策衝突與冗餘規則偵測
- 主要 KPI：政策合規率、入侵攔截數、政策變更平均審核時間、規則冗餘比例
- 代表產品：Palo Alto Networks Panorama、Fortinet FortiManager、Cisco Firepower Management Center、Check Point Security Management
