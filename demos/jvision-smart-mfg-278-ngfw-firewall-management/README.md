# 防火牆與網路資安管理平台（NGFW/Firewall Management）

> 告警分流、事件應變到弱點與合規治理

防火牆與網路資安管理平台（NGFW/Firewall Management）提供多台防火牆集中政策管理、入侵偵測/防禦(IDS/IPS)、VPN與遠端存取控管。資訊安全部依「防火牆設備納管→政策集中設定→變更申請審核→政策部署與生效→流量與威脅監控→定期政策稽核」推進作業，優先解決「多廠區防火牆政策不一致」，資訊部則以政策合規率與入侵攔截數確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**資訊安全　|　**系統類型：**資安 SOC 平台

## 功能模組

- **告警分流** — 資安告警彙整分級
- **事件應變** — 事件調查與處置
- **弱點管理** — 弱點掃描與修補追蹤
- **身分權限** — 帳號與特權管理
- **合規治理** — 政策、稽核與合規
- **端點防護** — 端點偵測與應變

## 適合誰使用

- 資訊安全部
- 資訊部
- 網管人員

## 運作流程

1. 已偵測

## 導入效益

- 告警分流時間：47分鐘 → **7.8分鐘**
- 事件平均處理：12小時 → **2.9小時**
- 弱點修補率：68% → **90%**
- 合規稽核工時：29小時/月 → **6.4小時/月**
