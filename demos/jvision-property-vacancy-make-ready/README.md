# 租賃空置整備管理台

> 在租戶退租後統籌點收、清運、修繕、清潔、驗收與招租交付，讓資產管理團隊縮短空置單元恢復可出租狀態的時間。

在租戶退租後統籌點收、清運、修繕、清潔、驗收與招租交付，讓資產管理團隊縮短空置單元恢復可出租狀態的時間。

**產業別：**房地產與物業　|　**系統類型：**maintenance-cmms

## 功能模組

- **空置清單** — 顯示退租日、預計可租日及狀態。
- **退租點收** — 記錄遺留物、損壞與復原責任。
- **整備工項** — 拆分清運、修繕、油漆與清潔任務。
- **施工排程** — 協調工種順序及完工期限。
- **成本控管** — 追蹤估價、核准與租戶扣款。
- **可租驗收** — 確認完成品質並釋出帶看狀態。

## 適合誰使用

- 資產管理員
- 物業主管
- 修繕廠商

## 運作流程

1. 建立退租案件
2. 完成現況點收
3. 編排整備工項
4. 執行施工追蹤
5. 覆核整備成本
6. 驗收釋出招租

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
