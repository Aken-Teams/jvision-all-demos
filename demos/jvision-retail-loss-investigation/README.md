# 零售防損異常調查工作台

> 匯整模擬的交易、退貨、折扣、盤點與權限紀錄，將可疑行為形成異常案件，協助防損人員檢視事件時間軸、關聯證據、調查筆記與處置結果。

匯整模擬的交易、退貨、折扣、盤點與權限紀錄，將可疑行為形成異常案件，協助防損人員檢視事件時間軸、關聯證據、調查筆記與處置結果。

**產業別：**零售電商　|　**系統類型：**finance-case

## 功能模組

- **異常警示佇列** — 集中呈現可疑退款、折扣、盤差與權限操作，依風險排序待查事件。
- **調查案件管理** — 建立案件、設定範圍與負責人，管理狀態、期限和保密標籤。
- **事件時間軸** — 按時間重建模擬交易、班次、庫存異動與人員操作紀錄。
- **證據關聯圖** — 視覺化連結人員、商品、交易、門市和相似事件，標記關鍵證據。
- **訪談處置紀錄** — 使用結構化表單記錄訪談摘要、調查結論與處置建議。
- **損失改善追蹤** — 彙整根因、損失金額與控制措施，追蹤改善期限和復發狀況。

## 適合誰使用

- 防損專員
- 內部稽核人員
- 區域主管
- 門市主管

## 運作流程

1. 受理異常警示
2. 建立調查案件
3. 還原事件經過
4. 整理關聯證據
5. 記錄訪談處置
6. 追蹤控制改善

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
