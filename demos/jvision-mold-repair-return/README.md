# 模具外修送返驗收台

> 供沖壓與射出現場將模具故障點、拆出零件及送修範圍逐項點交，返廠後完成尺寸、動作與試模驗收，不合格直接轉保固返修。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **故障範圍** — 標記模具異常
- **拆件送修** — 逐項點交零件
- **在外追蹤** — 查看承諾返廠日
- **返廠量測** — 核對尺寸與更換
- **上機試模** — 驗證動作成品
- **保固返修** — 追蹤未修復項

## 適合誰使用

- 模具技師
- 設備工程師

## 運作流程

1. 故障診斷
2. 拆件點交
3. 在外維修
4. 返廠驗收
5. 上機試模
6. 返修結案

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
