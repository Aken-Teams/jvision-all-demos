# 薪資管理系統（Payroll）

> 出勤、薪資、招募到績效的人資全流程

薪資管理系統（Payroll）提供底薪/加班費/夜班津貼自動核算、三班制加班費規則引擎、勞健保、勞退提撥計算。人資部依「考勤資料匯入 → 薪資計算 → 主管覆核 → 扣繳計算 → 轉帳檔產出 → 薪資單發放」推進作業，優先解決「三班輪班加班費計算規則複雜易錯」，財務部則以薪資核算正確率與發放準時率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**HRIS 人力資源系統

## 功能模組

- **薪資總覽** — 本期薪資關鍵指標與作業進度
- **考勤匯入** — 三班考勤匯入與工時異常核對
- **加班費規則** — 三班制加班費與夜班津貼規則引擎
- **薪資試算** — 底薪、加班、勞健保與勞退核算
- **主管覆核** — 薪資明細覆核與差異調整簽核
- **轉帳發放** — 扣繳計算、轉帳檔產出與薪資單

## 適合誰使用

- 人資部
- 財務部
- 稽核部

## 運作流程

1. 考勤資料匯入
2. 加班費規則套用
3. 薪資自動核算
4. 主管覆核調整
5. 轉帳與薪資單發放

## 導入效益

- 薪資作業工時：38小時/月 → **7.5小時/月**
- 出勤異常處理：28分鐘 → **4.7分鐘**
- 招募到位天數：42天 → **26天**
- 表單簽核時效：2.8天 → **0.9天**
