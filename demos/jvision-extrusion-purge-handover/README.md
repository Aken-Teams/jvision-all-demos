# 押出換料清線交接台

> 供塑膠押出線於材質或顏色切換時逐項確認料斗、螺桿、濾網與牽引端清線，記錄過渡料重量及首批判定，避免殘料混色或重複清機。

供塑膠押出線於材質或顏色切換時逐項確認料斗、螺桿、濾網與牽引端清線，記錄過渡料重量及首批判定，避免殘料混色或重複清機。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **換料看板** — 查看新舊材質
- **分段清線** — 確認料斗螺桿
- **過渡料秤重** — 記錄排料損耗
- **濾網處置** — 確認更換或續用
- **首批判定** — 檢查顏色材質
- **班次交接** — 傳遞未完項目

## 適合誰使用

- 押出領班
- 機台操作員

## 運作流程

1. 換料排定
2. 停止供料
3. 分段清線
4. 過渡排料
5. 首批確認
6. 恢復量產

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
