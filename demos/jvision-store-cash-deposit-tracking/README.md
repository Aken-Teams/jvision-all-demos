**產業別：**零售電商　|　**系統類型：**finance-ledger

## 功能模組

- **應繳總覽** — 彙整門市當日現金。
- **封包登錄** — 記錄袋號、金額及封存人。
- **交接追蹤** — 保存每段持有人與時間。
- **入帳配對** — 核對銀行實際存入。
- **短溢調查** — 定位責任段與證據。
- **逾期預警** — 追蹤未繳與高風險門市。

## 適合誰使用

- 門市店長
- 出納人員
- 財務主管

## 運作流程

1. 確認應繳
2. 建立封包
3. 完成交接
4. 配對入帳
5. 調查差異
6. 主管結案

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
