# 工廠能源需量碳排最佳化台

> 整合擬真電力需量、設備用能、生產計畫與排放係數，預測尖峰契約容量風險，模擬移峰、卸載與排程調整方案，同時呈現成本、產能及碳排影響。

**產業別：**ESG 永續　|　**系統類型：**esg-energy

## 功能模組

- **能源碳排總覽** — 彙整用電、費用、碳排與目標達成狀態。
- **尖峰需量預測** — 以擬真曲線預估需量高峰與超約風險。
- **設備用能剖析** — 比較產線、設備、班別與產品的能源占比。
- **移峰卸載模擬** — 模擬設備延後、降載或錯峰的影響。
- **產能碳成本權衡** — 比較各方案對交期、產量、電費與排放的差異。
- **節能行動追蹤** — 管理方案責任、執行進度與實際節能效益。

## 適合誰使用

- 能源管理員
- 廠務主管
- 生管主管
- 永續專員

## 運作流程

1. 盤點能源碳況
2. 預判需量尖峰
3. 定位高耗能設備
4. 模擬移峰卸載
5. 評估營運權衡
6. 追蹤節能成效

## 導入效益

- 盤查作業工時：40小時 → **8小時**
- 數據完整率：60% → **95%**
- 減碳目標達成：50% → **88%**
- 用能異常反應：24小時 → **2小時**
