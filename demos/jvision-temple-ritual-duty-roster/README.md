# 宮廟科儀執事排班台

> 供宮廟依法會科儀、壇場、執事資格與輪值規則安排人員，管理請假代班、服裝器物準備及當日點名，降低大型活動臨時缺席與職務錯置。

**產業別：**宗教服務　|　**系統類型：**operations-console

## 功能模組

- **科儀總覽** — 查看場次、人力缺口與異常。
- **場次編排** — 建立壇場、流程及時間需求。
- **執事資格** — 維護可擔任職務與服務紀錄。
- **輪值配置** — 安排職務、班次與休息時段。
- **請假代班** — 媒合合格替補並留下確認。
- **報到交班** — 點名並確認器物與注意事項。

## 適合誰使用

- 廟務主任
- 科儀總務
- 執事組長

## 運作流程

1. 建立場次
2. 設定職務
3. 篩選資格
4. 發布輪值
5. 處理代班
6. 報到交班

## 導入效益

- 活動籌備工時：20小時 → **5小時**
- 報名掌握率：65% → **94%**
- 物資盤點：6小時 → **1小時**
- 志工調度時效：3天 → **1天**
