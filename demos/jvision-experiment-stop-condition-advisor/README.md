# 實驗停止條件判斷器

> 綜合統計功效、追加成本與實驗風險，建議繼續、調整或停止實驗。

綜合統計功效、追加成本與實驗風險，建議繼續、調整或停止實驗。

**產業別：**研發管理　|　**系統類型：**quality-qms

## 功能模組

- **停止條件設定** — 定義主要終點、最小效應、功效門檻、成本與安全界線。
- **中期結果評估** — 顯示累積樣本、效應估計、變異與資料品質狀況。
- **統計功效預測** — 預測追加樣本後達成研究目標的機率與不確定區間。
- **續做成本推演** — 估算不同追加批次所需儀器、試劑、人力與等待成本。
- **實驗風險權衡** — 評估樣品耗損、安全風險、偏差累積與研究價值。
- **續停決策審議** — 並列繼續、調整或停止方案的理由與預期後果供核准。

## 適合誰使用

- 實驗室主管
- 研究員
- 技術員

## 運作流程

1. 定義決策界線
2. 審閱中期數據
3. 預測追加價值
4. 核算續做成本
5. 比較風險情境
6. 核准續做或停止

## 導入效益

- 設計變更工時：8小時 → **2小時**
- 文件版本錯誤：6件/月 → **1件/月**
- 專案準時率：70% → **92%**
- 資料查找時間：30分鐘 → **5分鐘**
