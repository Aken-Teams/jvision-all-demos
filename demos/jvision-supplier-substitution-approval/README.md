# 供應商缺貨替代審批台

> 在供應商缺貨時比較替代商品的規格、成本、標示與通路影響，集中取得採購、商品及電商核准，避免未授權替換造成退貨。

在供應商缺貨時比較替代商品的規格、成本、標示與通路影響，集中取得採購、商品及電商核准，避免未授權替換造成退貨。

**產業別：**零售電商　|　**系統類型：**procurement-srm

## 功能模組

- **缺貨案件** — 查看供應中斷與影響量。
- **規格比對** — 比較成分、容量與包裝。
- **成本評估** — 核對進價及售價影響。
- **標示檢查** — 確認頁面與門市標示需求。
- **跨部審批** — 收集採購商品及通路意見。
- **替代發布** — 設定門市、通路與效期。

## 適合誰使用

- 採購專員
- 商品經理
- 電商營運

## 運作流程

1. 通報缺貨
2. 提出替代
3. 比較價規
4. 檢查標示
5. 完成審批
6. 發布追蹤

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
