# 法遵落差任務產生器

> 把新法規義務轉成控制、文件與系統修改任務，建立法遵執行閉環。法規義務落地／控制與文件缺口整改／合規任務閉環。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **新義務拆解** — 將條文拆成適用對象、觸發條件、期限與可驗證要求。
- **現行控制對照** — 逐項比對既有政策、程序、控制與系統規則的覆蓋程度。
- **法遵落差清單** — 標示缺失、部分符合、證明不足與責任不明的義務。
- **整改任務編排** — 把落差轉成控制新增、文件修訂與系統改造工作。
- **跨部門會簽** — 由法務、流程、資訊與業務共同調整任務範圍及期限。
- **落地驗收關閉** — 驗證整改成果與義務覆蓋情形，關閉或退回未達標任務。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 拆解法定義務
2. 對照現行控制
3. 確認法遵落差
4. 產生整改任務
5. 完成跨部門會簽
6. 驗收義務落地

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
