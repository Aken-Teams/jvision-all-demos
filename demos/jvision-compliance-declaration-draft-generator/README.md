# 合規聲明草稿產生器

> 依產品證據與目標市場要求產生具來源引用、可審核的合規聲明草稿。<br>

依產品證據與目標市場要求產生具來源引用、可審核的合規聲明草稿。<br>

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **市場要求選擇** — 依銷售國家、產品類別與用途建立適用法規及聲明清單。
- **產品證據盤點** — 對應規格、測試報告、認證、物料與供應商聲明的有效版本。
- **聲明要件核對** — 逐項檢查法定措辭、識別資訊、簽署者及必要附件。
- **合規聲明起草** — 依市場格式自動生成含產品範圍、標準與責任主體的草稿。
- **主張一致性審查** — 比對草稿、測試證據與產品規格，標示過度或互相矛盾的主張。
- **聲明核准發行** — 完成法務與工程簽核，輸出帶版本及有效期的正式聲明。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 界定市場要求
2. 彙整產品證據
3. 核對聲明要件
4. 產生聲明草稿
5. 審查內容一致性
6. 核准正式發行
