# 競品客戶聲音礦工

彙整競品評論、論壇與案例，挖掘優缺點及可切入的差異化機會。​

**產業別：**業務銷售　|　**系統類型：**analytics-bi

## 功能模組

- **競品聲量探索** — 依品牌、產品與市場主題探索外部客戶討論。
- **評論觀點聚類** — 將大量評論歸納為功能、服務、價格等觀點群。
- **論壇痛點挖掘** — 辨識論壇討論中的反覆抱怨、需求與使用情境。
- **優缺點對照** — 跨來源比較各競品被肯定與批評的具體面向。
- **客戶聲音圖譜** — 連結品牌、功能、客群、情境與情緒間的關係。
- **差異機會工坊** — 產生可驗證的定位缺口、內容角度與市場機會。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 設定競品範圍
2. 探索市場聲音
3. 校正觀點分類
4. 比較優勢弱點
5. 審閱關聯圖譜
6. 核准差異機會
