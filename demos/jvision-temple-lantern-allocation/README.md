**產業別：**宗教服務　|　**系統類型：**operations-console

## 功能模組

- **燈位總覽** — 依燈區呈現可用與保留位置。
- **點燈登記** — 建立信眾、燈種及祈福資料。
- **續點保留** — 處理原燈位續用與到期釋出。
- **名條校對** — 批次檢查姓名和祈福內容。
- **安奉進度** — 追蹤製作、上架與完成狀態。
- **異動處理** — 管理換位、更名與退費例外。

## 適合誰使用

- 服務台人員
- 點燈作業員
- 宮廟行政主管

## 運作流程

1. 盤點燈位
2. 受理登記
3. 確認續點
4. 校對名條
5. 完成安奉
6. 處理異動

## 導入效益

- 活動籌備工時：20小時 → **5小時**
- 報名掌握率：65% → **94%**
- 物資盤點：6小時 → **1小時**
- 志工調度時效：3天 → **1天**
