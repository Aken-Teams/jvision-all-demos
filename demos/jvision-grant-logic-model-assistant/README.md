# 補助計畫邏輯模型助手

> 串連計畫問題、活動、產出、成果與衡量指標，提升補助申請內容一致性。

串連計畫問題、活動、產出、成果與衡量指標，提升補助申請內容一致性。

**產業別：**專業服務　|　**系統類型：**collaboration-pm

## 功能模組

- **問題樹編輯器** — 拆解目標族群、核心問題、成因與可驗證基準線。
- **介入策略設計** — 將問題成因映射到具體策略、假設與外部條件。
- **活動工作鏈** — 安排活動、負責人、時程與活動間的先後依賴。
- **產出定義表** — 定義每項活動直接交付的數量、品質與完成標準。
- **成果因果鏈** — 連結短中長期成果並檢查因果跳躍與邏輯缺口。
- **指標驗證計畫** — 為成果設定指標、基準值、目標值、資料源與頻率。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 界定核心問題
2. 設計介入策略
3. 編排執行活動
4. 定義直接產出
5. 驗證成果鏈條
6. 核准衡量架構

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
