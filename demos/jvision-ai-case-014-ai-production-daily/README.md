# AI 報工日報助理

> 進度、日報、品安到估價成本的工程管理

自動彙整報工、異常、產量與明日重點。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生產製造　|　**系統類型：**營建工程管理

## 功能模組

- **工程進度** — WBS 排程與進度追蹤
- **工地日報** — 日報、人機料回報
- **品質安衛** — 巡檢與缺失改善
- **估價發包** — 估價、發包與計價
- **成本控管** — 預算、實支與請款
- **現場紀錄** — 照片與文件留存

## 適合誰使用

- 生管專員
- 製造課長
- 廠長

## 運作流程

1. 待排程
2. 生產中
3. 待品檢
4. 已入庫

## 導入效益

- 排程作業工時：8.3小時/日 → **1.5小時/日**
- 準時交付率：82% → **91%**
- 缺料停線次數：12次/月 → **2.8次/月**
- 設備稼動率：73% → **93%**
