# 機器人焊接軌跡異常偵測系統

> 利用預先建立的模擬軌跡資料，比對機器人焊接路徑、姿態、速度與偏移趨勢，重播異常區段並呈現事件原因、工件關聯及校正任務，協助工程師降低偏焊、漏焊與碰撞風險。

利用預先建立的模擬軌跡資料，比對機器人焊接路徑、姿態、速度與偏移趨勢，重播異常區段並呈現事件原因、工件關聯及校正任務，協助工程師降低偏焊、漏焊與碰撞風險。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **軌跡監控總覽** — 呈現工作站狀態、異常事件、偏移分布與待校正任務。
- **三維軌跡重播** — 以模擬視圖重播焊接路徑、姿態、速度及異常時間點。
- **基準路徑比對** — 疊合標準與實際模擬軌跡，顯示各路段的位置偏差。
- **異常事件中心** — 依偏焊、停頓、速度突變與姿態異常整理事件詳情。
- **校正任務管理** — 建立治具確認、原點校正與程式修正任務並追蹤結果。
- **影響工件追溯** — 依工作站、程式版本與時段列出可能受影響的工件。

## 適合誰使用

- 自動化工程師
- 焊接製程工程師
- 設備主管

## 運作流程

1. 掌握軌跡警示
2. 重播異常路段
3. 比對基準偏差
4. 判定事件原因
5. 安排校正作業
6. 追查影響工件
