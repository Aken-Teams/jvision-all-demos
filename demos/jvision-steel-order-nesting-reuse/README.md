# 鋼材排材餘料再用最佳化台

> 將鋼材訂單尺寸、材質、切割限制、庫存母材與可用餘料轉為視覺化排材方案，比較材料利用率、換料次數與交期影響，並建立餘料標籤及後續訂單配對建議。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **訂單池** — 依材質、厚度、交期與尺寸整理待排材需求。
- **母材餘料庫** — 搜尋母材與餘料的規格、尺寸、位置及可用狀態。
- **智慧排材** — 產生多套板面配置並呈現切割路徑與剩餘區域。
- **方案比較** — 比較利用率、切割長度、換料次數與交期風險。
- **切割批次** — 編排切割順序並輸出純展示用的批次作業卡。
- **餘料再配** — 登錄新餘料並推薦可使用其尺寸的後續訂單。

## 適合誰使用

- 生產排程員
- 切割工程師
- 鋼材倉管人員

## 運作流程

1. 整理訂單
2. 選取材料
3. 產生排材
4. 評選方案
5. 編成批次
6. 登錄餘料

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
