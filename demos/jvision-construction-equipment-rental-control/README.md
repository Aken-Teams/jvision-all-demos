# 工地機具租賃管制台

> 管理各工地租賃機具的需求申請、比價核准、進退場、計租停租與損壞責任，避免閒置續租、重複叫機及租金爭議。

管理各工地租賃機具的需求申請、比價核准、進退場、計租停租與損壞責任，避免閒置續租、重複叫機及租金爭議。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **機具總覽** — 查看各工地租用與閒置狀態
- **需求申請** — 提出機型時段與用途需求
- **比價核准** — 比較廠商條件並完成簽核
- **進場驗收** — 記錄時數外觀及附件
- **停退租作業** — 確認停租與實際離場時間
- **租金核對** — 比對計租期間及爭議費用

## 適合誰使用

- 工地主任
- 機料主管
- 工務會計

## 運作流程

1. 提出需求
2. 完成比價
3. 核准叫機
4. 辦理進場
5. 確認退租
6. 核對請款

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
