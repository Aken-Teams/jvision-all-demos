# Yield Analysis協作所

彙整製程各站別良率數據，進行多維度分析找出低良率根因，支援製程改善決策。

- 原始系統：Yield Analysis（良率分析）
- 產業分類：智慧製造｜品質管理
- 使用部門：製程工程部、品保部、生產部、設備工程部
- 工作流程：數據自動採集→良率計算→多維度分析→根因鎖定→改善追蹤
- AI 應用：低良率根因自動推薦、異常機台/批次關聯分析、良率趨勢預測
- 主要 KPI：直通率（FPY）、綜合良率、異常反應時效
- 代表產品：exensio（原PDF Solutions）、Camstar/Critical Manufacturing、以客製化開發為主
