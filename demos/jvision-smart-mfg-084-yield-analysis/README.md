# Yield Analysis（良率分析）

> 從異常到改善的品質閉環與追溯稽核

Yield Analysis（良率分析）提供良率即時看板、多站良率追蹤、不良模式排行（柏拉圖）。製程工程部依「數據自動採集→良率計算→多維度分析→根因鎖定→改善追蹤」推進作業，優先解決「良率數據分散各系統」，品保部則以直通率（FPY）與綜合良率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 製程工程部
- 品保部
- 生產部

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉

## 導入效益

- 批號追溯時間：176分鐘 → **16分鐘**
- 客訴平均關案：21天 → **9.5天**
- 改善驗證率：65% → **92%**
- 重複不良率：6.2% → **1.9%**
