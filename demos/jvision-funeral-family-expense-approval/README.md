# 殯葬家屬費用確認台

> 協助禮儀公司將治喪過程中的臨時增項、代墊款、供應商報價與家屬確認集中管理，保留每次方案變更及同意紀錄，避免結案請款時因品項認知不同產生爭議。

協助禮儀公司將治喪過程中的臨時增項、代墊款、供應商報價與家屬確認集中管理，保留每次方案變更及同意紀錄，避免結案請款時因品項認知不同產生爭議。

**產業別：**生活服務　|　**系統類型：**finance-case

## 功能模組

- **治喪案件** — 管理家屬窗口、服務方案與預算。
- **臨時增項** — 登錄新增品項、原因與預估金額。
- **方案比較** — 呈現替代方案及價格差異。
- **家屬確認** — 保留同意、拒絕與變更時間紀錄。
- **代墊核銷** — 整理供應商單據及代付款項。
- **結案帳單** — 彙整原約、增減項與已收款項。

## 適合誰使用

- 禮儀師
- 服務主管
- 會計人員

## 運作流程

1. 建立案件
2. 提出增項
3. 比較方案
4. 取得確認
5. 整理憑證
6. 完成結算

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
