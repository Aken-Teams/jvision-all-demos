# 貨運稅費墊款核銷台

> 管理關稅、倉租、查驗及其他貨運代墊費用，將憑證連結運單、客戶與授權條件，追蹤可請款、免收、折讓及回收狀態，避免漏收與錯戶。

**產業別：**物流運輸　|　**系統類型：**finance-case

## 功能模組

- **代墊登錄** — 建立費用憑證
- **運單配對** — 連結客戶貨件
- **可收判定** — 檢查合約條件
- **免收折讓** — 保存授權理由
- **帳單併入** — 產生請款項目
- **回收追蹤** — 監看逾期款項

## 適合誰使用

- 貨運會計
- 報關作業員
- 客戶帳務員

## 運作流程

1. 登錄費用
2. 配對貨件
3. 判定可收
4. 審批例外
5. 產生請款
6. 追蹤回收

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
