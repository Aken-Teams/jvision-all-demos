# 診所爽約召回管理台

> 依療程重要性與爽約風險整理未到診名單，協助診所進行聯繫、改約、候補遞補及多次未回個案升級，維持照護連續性。

依療程重要性與爽約風險整理未到診名單，協助診所進行聯繫、改約、候補遞補及多次未回個案升級，維持照護連續性。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **未到診清單** — 彙整爽約患者與原預約資訊。
- **風險分級** — 依病況、療程及爽約次數排序。
- **聯繫紀錄** — 記錄電話、簡訊及聯絡結果。
- **改約安排** — 提供合適時段並確認新預約。
- **候補遞補** — 將釋出時段媒合候補患者。
- **個案升級** — 轉交護理師處理高風險未回案件。

## 適合誰使用

- 診所櫃台
- 個案管理師
- 門診護理師

## 運作流程

1. 產生爽約名單
2. 評定召回優先
3. 執行患者聯繫
4. 完成重新預約
5. 遞補釋出時段
6. 升級未回個案

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
