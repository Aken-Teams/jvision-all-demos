## 功能模組

- **存取風險雷達** — 依使用者、時段、資料域與查詢行為辨識異常存取模式。
- **非典型時段偵測** — 比對個人與同職務基線，找出深夜、假日及突發高頻查詢。
- **查詢範圍偏移** — 辨識資料量、資料表數與跨域關聯突然擴大的查詢。
- **敏感欄位監測** — 追蹤個資、財務及機密欄位的讀取、匯出與組合使用。
- **因果線索分析** — 串聯身分、SQL、管線與下游工具，排列可能的異常成因。
- **告警處置中心** — 依風險排序告警，執行限流、撤權或送交人工審查。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 檢視風險雷達
2. 確認時段異常
3. 分析查詢範圍
4. 核對敏感欄位
5. 追查因果線索
6. 核准告警處置

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
