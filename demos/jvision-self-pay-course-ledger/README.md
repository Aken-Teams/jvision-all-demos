# 自費療程收款核銷台

> 管理自費療程的購買方案、付款、贈送堂數、跨店使用、退費與餘額，讓櫃檯逐次核銷並保留更正軌跡，避免漏扣、重扣與退款金額爭議。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **療程總覽** — 查看餘額與異常
- **方案建檔** — 設定堂數及贈送
- **收款配對** — 核對支付紀錄
- **到診核銷** — 扣除使用堂數
- **異動退費** — 試算轉店與退款
- **帳本稽核** — 追蹤每筆變動

## 適合誰使用

- 診所櫃檯
- 療程顧問
- 財務人員

## 運作流程

1. 查詢方案
2. 建立契約
3. 確認收款
4. 執行核銷
5. 處理異動
6. 覆核結案

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
