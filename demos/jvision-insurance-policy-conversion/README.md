# 團險加退保異動台

> 供保險公司與經代通路批次處理企業團體保險的員工加保、退保、身分變更及保費追溯，透過資格檢核與差異覆核降低生效錯誤。

供保險公司與經代通路批次處理企業團體保險的員工加保、退保、身分變更及保費追溯，透過資格檢核與差異覆核降低生效錯誤。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **企業保單** — 查看方案、資格與有效期間。
- **異動收件** — 匯入加退保及身分變更名冊。
- **資格檢核** — 檢查年齡、身分與必要欄位。
- **生效核定** — 確認承保結果與生效日期。
- **保費差額** — 計算追溯加退費與期間差異。
- **批次結案** — 輸出結果及企業回覆清單。

## 適合誰使用

- 團險作業員
- 核保人員
- 保費會計

## 運作流程

1. 選取保單
2. 匯入名冊
3. 檢核資格
4. 核定生效
5. 重算保費
6. 回覆結案

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
