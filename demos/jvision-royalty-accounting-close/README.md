# 授權金結算會計台

> 協助品牌授權方依合約費率、最低保證額、銷售申報與可扣抵項目計算授權金，處理差異覆核、應收認列及結算單出具。

協助品牌授權方依合約費率、最低保證額、銷售申報與可扣抵項目計算授權金，處理差異覆核、應收認列及結算單出具。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **合約條款** — 維護費率、期間及最低保證額。
- **銷售申報** — 匯入被授權商的銷售明細。
- **金額試算** — 依合約口徑計算授權金。
- **差異覆核** — 檢查扣抵、退貨與異常波動。
- **會計認列** — 建立應收及期間調整資料。
- **結算出具** — 產生結算單與計算附件。

## 適合誰使用

- 授權會計
- 合約管理員
- 財務主管

## 運作流程

1. 確認條款
2. 接收申報
3. 執行試算
4. 覆核差異
5. 完成認列
6. 出具結算

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
