# 組織圖與職位管理指揮台

視覺化呈現企業組織架構、職位編制與職缺配額，支援多廠區、多事業部的組織管理需求。

- 原始系統：組織圖與職位管理系統（Org Chart & Position Management）
- 產業分類：智慧製造｜人資管理
- 使用部門：人資部、經營高層、各部門主管、財務部（人力成本）
- 工作流程：組織調整申請 → 編制審核 → 組織圖更新 → 職位說明書同步 → 公告發佈 → 歷史版本歸檔
- AI 應用：組織效能與管理幅度智慧分析、職位重疊/冗餘自動偵測
- 主要 KPI：編制達成率、組織圖更新時效、職位空缺天數、管理幅度合理性
- 代表產品：SAP SuccessFactors Org Chart、Pingboard、鼎新HR組織模組
