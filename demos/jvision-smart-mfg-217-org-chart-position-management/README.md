# 組織圖與職位管理系統（Org Chart & Position Management）

> 前台結帳、會員到進銷存的門市一體化

組織圖與職位管理系統（Org Chart & Position Management）提供動態組織圖視覺化、職位編制與員額管控、職位說明書（JD）管理。人資部依「組織調整申請 → 編制審核 → 組織圖更新 → 職位說明書同步 → 公告發佈 → 歷史版本歸檔」推進作業，優先解決「組織異動頻繁導致圖表未即時更新」，經營高層則以編制達成率與組織圖更新時效確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**POS 門市管理

## 功能模組

- **前台結帳** — 點餐、開單與快速結帳
- **桌位 / 訂位** — 桌況與訂位管理
- **訂單管理** — 內用、外帶、外送整合
- **庫存進銷** — 即時庫存與自動叫貨
- **會員行銷** — 會員、點數與優惠
- **日結報表** — 營收與熱銷分析

## 適合誰使用

- 人資部
- 經營高層
- 各部門主管

## 運作流程

1. 待上架
2. 銷售中
3. 主管確認
4. 已結案
