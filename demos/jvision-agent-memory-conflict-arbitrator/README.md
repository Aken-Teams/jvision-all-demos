# Agent 記憶衝突仲裁器

偵測 Agent 新舊記憶中的事實衝突，追查來源並引導人工完成可信裁決。

**產業別：**資訊科技　|　**系統類型：**operations-console

## 功能模組

- **記憶矛盾偵測** — 比對新舊事實、時間條件與實體關係，標出衝突敘述。
- **事實關聯圖譜** — 呈現衝突事實、來源文件、任務與受影響記憶的關係。
- **時效與沿革判讀** — 區分資料更新、條件變更、過期事實與真正矛盾。
- **來源可信評分** — 依權威性、時效、佐證數量與擷取方式排列來源。
- **衝突裁決工作台** — 支援採納、合併、暫緩或要求補充來源的人工裁決。
- **記憶修訂同步** — 將裁定結果寫回長期記憶並標記受影響的 Agent。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 發現記憶衝突
2. 展開關聯脈絡
3. 判讀時間條件
4. 評估來源可信度
5. 作成仲裁決定
6. 同步可信記憶
