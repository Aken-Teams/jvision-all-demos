# 受限物質法規比對器

**產業別：**專業服務　|　**系統類型：**quality-qms

## 功能模組

- **BOM 材料展開** — 穿透零件、子組件與均質材料，建立物質層級產品結構。
- **多國法規庫** — 管理各市場限用清單、豁免、門檻、生效日與產品範圍。
- **物質識別正規化** — 統一 CAS 編號、物質別名、材料宣告與供應商命名。
- **限值適用判定** — 依市場、品類、用途及豁免條件判斷每項物質的適用限值。
- **材料風險熱區** — 定位超標、資料缺漏、即將到期豁免及高不確定性材料。
- **替代材料情境** — 比較材料替換對合規、成本、性能與供應可得性的影響。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 展開產品 BOM
2. 選定目標市場
3. 正規化物質資料
4. 執行限值判定
5. 審查材料風險
6. 核定替代方案

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
