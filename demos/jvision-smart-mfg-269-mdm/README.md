# 資料治理與主資料管理預警塔

統一定義並管理料號、供應商、客戶、BOM等主資料，確保跨系統資料一致性與品質。

- 原始系統：資料治理與主資料管理平台（MDM）
- 產業分類：智慧製造｜IT管理
- 使用部門：資訊部、資料治理委員會、生管部、採購部、財務部
- 工作流程：定義主資料標準→來源系統資料匯入→比對去重與品質檢核→主資料審核發佈→同步至下游系統→持續監控異動
- AI 應用：相似資料自動比對合併建議、資料品質異常自動偵測
- 主要 KPI：主資料重複率、資料品質合格率、跨系統一致性比率、資料治理覆蓋範圍
- 代表產品：Informatica MDM、SAP Master Data Governance、Talend Data Fabric、Collibra
