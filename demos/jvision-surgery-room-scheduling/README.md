# 手術室排程協調台

> 協調手術房、醫師、護理人力、器械與術前檢查的排程條件，呈現衝突及候補案例，協助醫療機構降低延誤與臨時取消。

協調手術房、醫師、護理人力、器械與術前檢查的排程條件，呈現衝突及候補案例，協助醫療機構降低延誤與臨時取消。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **手術日曆** — 查看房間時段與案例配置。
- **排程申請** — 登錄術式、時長及資源需求。
- **術前條件** — 核對檢查、同意書與禁食狀態。
- **資源配置** — 安排人員、器械與特殊設備。
- **衝突處理** — 調整重疊資源與候補案例。
- **日程發布** — 發布核定班表及異動通知。

## 適合誰使用

- 手術排程員
- 護理長
- 外科醫師

## 運作流程

1. 查看容量
2. 受理申請
3. 核對條件
4. 配置資源
5. 排除衝突
6. 發布日程

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
