# 混凝土澆置票核對台

> 將預約方量、車次送貨票、樓層澆置紀錄、退料與等候費逐票勾稽，攔截重複票號及錯誤工區，並保留材料批次追溯證據。

將預約方量、車次送貨票、樓層澆置紀錄、退料與等候費逐票勾稽，攔截重複票號及錯誤工區，並保留材料批次追溯證據。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **澆置計畫** — 查看日期、部位與預定方量。
- **車次送達** — 記錄票號、批次與到場時間。
- **澆置確認** — 核對實際樓層及使用量。
- **退料等候** — 登錄退料與候時原因。
- **票據勾稽** — 找出重複及方量落差。
- **月結覆核** — 確認供應商可付款金額。

## 適合誰使用

- 現場工程師
- 材料管理員
- 成本會計

## 運作流程

1. 建立計畫
2. 登錄車次
3. 確認澆置
4. 處理退料
5. 勾稽差異
6. 核准月結

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
