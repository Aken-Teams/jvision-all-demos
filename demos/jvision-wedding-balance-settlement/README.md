# 婚宴檔期尾款清算台

> 彙整婚宴合約、追加項目、供應商履約、客戶確認與已收款，逐項判定應收應付及暫扣原因，讓企劃與會計在活動後快速結清毛利。

**產業別：**生活服務　|　**系統類型：**finance-case

## 功能模組

- **婚宴案件** — 呈現合約檔期與預算
- **追加項目** — 記錄變更版本與確認
- **供應履約** — 核對交付數量及異常
- **尾款試算** — 計算客戶應收與廠商應付
- **暫扣爭議** — 管理待確認與責任項目
- **清算結案** — 覆核收付與最終毛利

## 適合誰使用

- 婚宴企劃
- 活動主管
- 會計人員

## 運作流程

1. 鎖定最終合約
2. 彙整追加項目
3. 核對供應履約
4. 試算雙邊尾款
5. 處理暫扣爭議
6. 完成收付結案

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
