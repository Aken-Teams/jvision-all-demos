**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **配方目標設定** — 設定品質、成本、能耗目標及各項指標的優先權重。
- **材料限制編輯** — 管理材料上下限、替代料、相容性與供應限制。
- **可行解空間** — 探索符合製程與材料限制的候選參數和配方組合。
- **多目標權衡** — 以 Pareto 前緣比較品質、成本、能耗與穩健性。
- **候選配方驗證** — 模擬製程波動並對照歷史批次，評估量產成功機率。
- **試產配方發布** — 建立試產批次、核准參數範圍並同步至製造系統。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 定義最佳化目標
2. 建立材料限制
3. 探索可行配方
4. 比較多目標權衡
5. 驗證候選配方
6. 核准試產發布
