# 學校教材選用審議台

> 協助學校管理各科教材提案、版本樣書、教師評分、利益迴避聲明、會議決議及採購數量，讓每學期的教材選用具備一致標準、完整紀錄與可追溯的核准依據。

協助學校管理各科教材提案、版本樣書、教師評分、利益迴避聲明、會議決議及採購數量，讓每學期的教材選用具備一致標準、完整紀錄與可追溯的核准依據。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **教材提案** — 登錄科目、出版社、版本與樣書資料。
- **評選量表** — 設定內容、難度、價格等評分標準。
- **教師審議** — 彙整評分、意見及利益迴避聲明。
- **會議決議** — 記錄表決結果、附帶條件與異議。
- **核准版本** — 確認各年級與科目的正式教材。
- **採購交接** — 產出版本、數量與交付班級清冊。

## 適合誰使用

- 教務主任
- 科別召集人
- 採購人員

## 運作流程

1. 徵集提案
2. 設定標準
3. 教師評選
4. 召開審議
5. 核准選用
6. 交付採購

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
