# 水電異常偵測儀

> 自動偵測水電異常、尖峰與節能機會的單一平台

自動偵測水電異常、尖峰與節能機會。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**ESG 永續　|　**系統類型：**ESG 永續 / 能源管理

## 功能模組

- **即時計量監控** — 水電表分路即時讀值與負載監看
- **異常偵測引擎** — AI 分析基線偏移、突波與漏耗
- **告警與派工** — 異常自動分級告警並指派處理
- **漏水漏電診斷** — 夜間基載比對定位管線與迴路
- **需量與尖峰管理** — 契約容量與尖峰負載預警
- **節能機會分析** — 用能標竿比對與節費建議

## 適合誰使用

- 永續管理師
- ESG 主管
- 總經理

## 運作流程

1. 計量採集
2. 異常判定
3. 告警派工
4. 現場診斷
5. 節能複盤

## 導入效益

- 盤查作業工時：41小時 → **8小時**
- 數據完整率：64% → **99%**
- 減碳目標達成：48% → **83%**
- 用能異常反應：24小時 → **2小時**
