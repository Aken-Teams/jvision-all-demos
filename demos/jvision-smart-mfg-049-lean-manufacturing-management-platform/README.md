# 精實生產管理指揮台

整合現場數據採集、任務指派與績效追蹤，支援精實生產推行之綜合管理平台。

- 原始系統：精實生產管理平台（Lean Manufacturing Management Platform）
- 產業分類：智慧製造｜製造管理
- 使用部門：製造工程、持續改善部門、生產
- 工作流程：現場任務數位化 → 執行數據採集 → 精實指標運算 → 異常改善追蹤 → 標準化推廣
- AI 應用：AI整合多項精實指標提出改善建議、智慧識別跨產線可複製之最佳實踐
- 主要 KPI：整體浪費比率、標準化覆蓋率、精實指標達成率
- 代表產品：Parsec TrakSYS、Tulip Interfaces
