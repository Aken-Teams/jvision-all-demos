# 軌道乘務資格派班台

> 依列車班次、路線熟悉資格、車型認證、輪班規則與休息限制配置駕駛及乘務人員，提前標示缺員和資格即將到期風險，支援調班與備勤替補決策。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **列車班次需求** — 顯示各班次職務與資格需求。
- **乘務資格矩陣** — 查閱路線、車型及職務認證。
- **乘務排班盤** — 配置正班、備勤與休息日。
- **工時規則檢查** — 檢核連勤及最低休息時間。
- **請假替補媒合** — 篩選可合法執勤的替補人員。
- **資格到期預警** — 追蹤認證效期與排班影響。

## 適合誰使用

- 乘務排班員
- 運務主管
- 訓練管理員

## 運作流程

1. 匯入班次
2. 核對資格
3. 配置人員
4. 檢查工時
5. 處理替補
6. 發布班表

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
