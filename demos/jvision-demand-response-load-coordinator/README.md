**產業別：**生產製造　|　**系統類型：**esg-energy

## 功能模組

- **削峰事件指揮台** — 彙整需量反應事件、目標功率、執行時段與預估收益。
- **非關鍵負載盤點** — 辨識空壓、空調、充電與輔機等可調節負載及限制。
- **生產安全護欄** — 依工單、配方與設備狀態排除不可降載的生產環節。
- **降載組合規劃** — 排序可執行策略並模擬功率缺口、成本與製程影響。
- **負載調節執行** — 經核准後向 SCADA 或 PLC 下達分段降載與復載指令。
- **削峰成效驗證** — 比對基線與實際需量，確認履約、收益及生產穩定性。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 接收削峰事件
2. 盤點可調負載
3. 設定安全邊界
4. 核准降載方案
5. 執行動態調節
6. 驗證履約收益

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
