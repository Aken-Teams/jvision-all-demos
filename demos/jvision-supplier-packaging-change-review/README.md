# 商品包裝改版切換台

> 管理供應商商品換包裝、條碼沿用或變更、舊包材庫存與通路上架日期，協調採購、倉庫、門市及電商完成新舊版並行和切換，避免誤判錯品。

管理供應商商品換包裝、條碼沿用或變更、舊包材庫存與通路上架日期，協調採購、倉庫、門市及電商完成新舊版並行和切換，避免誤判錯品。

**產業別：**零售電商　|　**系統類型：**operations-console

## 功能模組

- **改版案件** — 登錄新舊包裝與生效日
- **條碼判定** — 確認沿用變更及對映
- **庫存盤點** — 查看新舊版各點存量
- **通路切換** — 安排門市電商上架日期
- **辨識指引** — 發布圖片與客服說明
- **切換驗收** — 確認各通路完成更新

## 適合誰使用

- 商品經理
- 採購人員
- 通路營運

## 運作流程

1. 建立改版
2. 核定條碼
3. 盤點舊貨
4. 安排切換
5. 發布指引
6. 完成驗收

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
