# 感測器可信度融合器

> 融合多感測器與物理規則辨識故障讀值，避免錯誤訊號驅動設備決策。

融合多感測器與物理規則辨識故障讀值，避免錯誤訊號驅動設備決策。

**產業別：**設備維護　|　**系統類型：**operations-console

## 功能模組

- **多感測器對照** — 同步比較同區域或同物理量的感測讀值與時間偏差。
- **物理規則驗算** — 以能量守恆、變化率與設備邊界檢查讀值合理性。
- **可信度評分** — 融合校準紀錄、漂移、噪聲與交叉一致性產生信任分數。
- **故障來源定位** — 區分單點失效、共同環境干擾、通訊錯碼與設備真異常。
- **替代讀值合成** — 以可信感測器與模型估值產生帶不確定性的暫代訊號。
- **控制防錯策略** — 設定降權、隔離、人工確認與復用原始讀值的條件。

## 適合誰使用

- IoT 架構師
- 設備工程師
- 場域主管

## 運作流程

1. 建立感測對照組
2. 套用物理約束
3. 計算讀值可信度
4. 研判故障來源
5. 核准替代訊號
6. 防止錯誤控制

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
