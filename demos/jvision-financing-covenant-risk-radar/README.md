以財務預測持續推演融資條款，提前識別接近違約的 Covenant 並啟動協商。

**產業別：**財務會計　|　**系統類型：**finance-case

## 功能模組

- **融資條款庫** — 管理各貸款的財務比率、門檻、測試日、補救期與例外約定。
- **Covenant 指** — 依合約定義計算槓桿、利息保障、淨值及流動性指標。
- **預測情境推演** — 將預算、滾動預測與壓力情境投射至未來條款測試日。
- **違約距離雷達** — 衡量各條款距門檻的緩衝、惡化速度與預估觸發時間。
- **協商策略工作台** — 比較提前還款、增資、豁免與條款重議對資金成本的影響。
- **貸方溝通案件** — 管理銀行聯絡、資料包、協商里程碑、承諾事項及截止日。

## 適合誰使用

- 財務長
- Treasurer
- 資金人員

## 運作流程

1. 整理融資條款
2. 更新指標計算
3. 推演未來情境
4. 辨識高風險條款
5. 擬定協商方案
6. 追蹤貸方協商

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
