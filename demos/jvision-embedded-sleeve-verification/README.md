# 預埋套管定位覆核台

> 將套管編號、系統、尺寸、標高及軸線位置轉成樓層查核清單，於封模與澆置前逐點覆核照片和偏差，讓漏埋、錯徑或移位能在混凝土施工前被攔截。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **套管清冊** — 管理編號、用途、尺寸與所屬系統。
- **平面定位** — 依軸線、樓層及標高標記位置。
- **現場取證** — 上傳尺規入鏡的定位照片。
- **偏差判定** — 比對容許值並標示缺漏或錯徑。
- **改正追蹤** — 分派移位、更換及補設工作。
- **澆置放行** — 彙整查核結果並完成簽認。

## 適合誰使用

- 機電工程師
- 土建工程師
- 監造工程師

## 運作流程

1. 建立套管清冊
2. 配置圖面位置
3. 完成現場定位
4. 執行偏差覆核
5. 追蹤缺失改正
6. 簽認澆置放行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
