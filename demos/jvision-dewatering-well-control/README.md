# 深開挖降水井管制台

> 管理深開挖各階段降水井配置、啟停計畫、巡查讀值、備援設備、異常水位與停井封井條件，讓工程團隊以人工填報資料判斷降水措施是否符合開挖進度及核准方案。

管理深開挖各階段降水井配置、啟停計畫、巡查讀值、備援設備、異常水位與停井封井條件，讓工程團隊以人工填報資料判斷降水措施是否符合開挖進度及核准方案。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **井群配置** — 管理井號、位置、深度與服務區域。
- **啟停計畫** — 依開挖階段安排運轉與備援井。
- **巡查讀值** — 人工填報水位、流量與設備狀態。
- **異常派修** — 追蹤停電、堵塞及泵浦故障。
- **備援檢核** — 確認發電機、備用泵與切換程序。
- **停井封井** — 審查停抽條件、試停結果與封填。

## 適合誰使用

- 地下工程師
- 監測工程師
- 機電人員

## 運作流程

1. 建立井群
2. 排定啟停
3. 巡查填報
4. 異常處理
5. 備援確認
6. 停井封填

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
