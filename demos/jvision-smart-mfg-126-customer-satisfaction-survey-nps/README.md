# 客戶滿意度調查 Customer Satisfaction Survey/NPS決策室

定期蒐集客戶對產品、服務與交期的滿意度回饋，量化客戶關係健康度並驅動改善行動。

- 原始系統：客戶滿意度調查 Customer Satisfaction Survey/NPS
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、品保部、客服部、管理層
- 工作流程：設計問卷→發送客戶→回收彙整→計算滿意度指標→低分案件跟進改善
- AI 應用：開放式回饋文字情感分析、低分風險客戶自動預警
- 主要 KPI：NPS分數、問卷回收率、低分案件改善率、客戶留存率關聯性
- 代表產品：Qualtrics、SurveyMonkey、Medallia
