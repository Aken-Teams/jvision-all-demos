# 員工自助服務指揮台

提供員工線上查詢薪資、請假、打卡異常申訴等自助功能，減少人資窗口重複性作業。

- 原始系統：員工自助服務系統（ESS, Employee Self-Service）
- 產業分類：智慧製造｜人資管理
- 使用部門：全體員工、人資部、產線行政人員
- 工作流程：員工登入APP/Kiosk → 選擇服務項目 → 線上申請 → 主管/HR簽核 → 結果通知
- AI 應用：智慧客服機器人回覆常見問題、個人化訊息與提醒推播
- 主要 KPI：自助服務使用率、HR人工詢問件數下降率、申請處理時效、員工滿意度
- 代表產品：SAP SuccessFactors ESS、鼎新ESS、104人資King ESS、Workday ESS
