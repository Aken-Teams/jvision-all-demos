# 員工自助服務系統（ESS, Employee Self-Service）

> 出勤、薪資、招募到績效的人資全流程

員工自助服務系統（ESS, Employee Self-Service）提供電子薪資單查詢、請假/加班線上申請、個人資料異動申請。全體員工依「員工登入APP/Kiosk → 選擇服務項目 → 線上申請 → 主管/HR簽核 → 結果通知」推進作業，優先解決「人資窗口大量重複性詢問」，人資部則以自助服務使用率與HR人工詢問件數下降率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**HRIS 人力資源系統

## 功能模組

- **出勤差勤** — 打卡、請假與加班
- **薪資計算** — 薪資、勞健保與報稅
- **排班管理** — 智慧排班與工時控管
- **招募任用** — 職缺、面試與報到
- **教育訓練** — 課程、證照與紀錄
- **績效考核** — 目標設定與考核流程

## 適合誰使用

- 全體員工
- 人資部
- 產線行政人員

## 運作流程

1. 待處理
2. 主管確認
3. 人資執行
4. 歸檔完成

## 導入效益

- 薪資作業工時：38小時/月 → **7.5小時/月**
- 出勤異常處理：28分鐘 → **4.7分鐘**
- 招募到位天數：42天 → **26天**
- 表單簽核時效：2.8天 → **0.9天**
