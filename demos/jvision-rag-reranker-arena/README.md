以企業查詢比較多種 RAG 重排序器的精準度、延遲與成本。健壮

**產業別：**資訊科技　|　**系統類型：**analytics-bi

## 功能模組

- **企業查詢題庫** — 管理真實查詢、標準相關文件、困難負例與評測切分。
- **候選重排序器** — 配置 reranker 模型、取樣深度、分數門檻與推論參數。
- **重排序對戰場** — 對相同初始召回結果平行執行多個 reranker。
- **前段證據評測** — 比較 Precision@K、NDCG、MRR 與關鍵證據進入前列的
- **延遲成本剖析** — 分析各 reranker 的批次延遲、權杖或請求成本及吞吐量。
- **部署策略決選** — 依查詢類型選擇最佳 reranker、深度、門檻與降級方案。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 建立查詢基準
2. 配置競技選手
3. 執行平行重排
4. 評估前段證據
5. 比較延遲成本
6. 核定部署策略
