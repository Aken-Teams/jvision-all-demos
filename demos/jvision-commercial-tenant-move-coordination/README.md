# 商辦租戶搬遷協調台

> 協調商辦租戶進駐或遷出的貨梯時段、搬運商、人員名單、保護工程、門禁與現場點交，避免多戶衝突並確保公共區域損壞可追責。

**產業別：**房地產與物業　|　**系統類型：**collaboration-pm

## 功能模組

- **搬遷申請** — 登錄日期、貨量、車輛及搬運商。
- **貨梯排程** — 配置卸貨區、貨梯及分段使用時間。
- **名單文件** — 檢查保險、人員與車輛資料。
- **保護要求** — 列出地板、牆面和轉角防護標準。
- **現場點交** — 保存搬遷前後公共區域影像。
- **損壞追蹤** — 管理修復責任、報價與結案。

## 適合誰使用

- 物業主任
- 租戶行政窗口
- 保全主管

## 運作流程

1. 提出計畫
2. 配置時段
3. 審核文件
4. 完成防護
5. 執行點交
6. 關閉損壞

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
