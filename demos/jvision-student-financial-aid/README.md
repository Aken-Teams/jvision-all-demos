**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **方案設定** — 管理補助資格、名額、金額、期間與排除條件。
- **申請受理** — 彙整學生申請資料及各項證明文件。
- **資格檢核** — 依成績、身分、所得及既有補助進行初篩。
- **評分審議** — 分派委員評分並處理利益衝突與差異意見。
- **名單核定** — 依排名、名額及預算產生建議獲獎名單。
- **撥款追蹤** — 確認公告、申訴、帳戶資料與入帳結果。

## 適合誰使用

- 學務承辦人
- 審查委員
- 出納人員

## 運作流程

1. 建立獎助方案
2. 受理學生申請
3. 執行資格初篩
4. 進行委員審議
5. 核定獲獎名單
6. 完成補助撥款

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
