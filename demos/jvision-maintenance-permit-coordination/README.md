# 維修作業許可管制台

> 管理高風險維修的動火、受限空間、斷電與高處作業許可，串接危害檢核、隔離點確認、會簽及復歸，避免未授權施工。

管理高風險維修的動火、受限空間、斷電與高處作業許可，串接危害檢核、隔離點確認、會簽及復歸，避免未授權施工。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **許可總覽** — 查看各類許可與效期
- **危害檢核** — 辨識作業風險與措施
- **能源隔離** — 記錄隔離點及驗證
- **會簽放行** — 取得維修與工安核准
- **施工監控** — 記錄人員時段與異常
- **復歸結案** — 確認撤場與設備復歸

## 適合誰使用

- 維修主管
- 工安人員
- 現場工程師

## 運作流程

1. 提出申請
2. 檢核危害
3. 執行隔離
4. 會簽放行
5. 監督施工
6. 復歸結案

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
