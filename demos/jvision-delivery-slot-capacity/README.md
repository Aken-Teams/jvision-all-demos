# 配送時段容量預約管制台

> 讓配送中心依區域、車型與日期配置可承接的到貨時段，受理門市或企業客戶預約、候補及改期，並在超量前調整容量，降低集中到貨造成的等待與失約。

讓配送中心依區域、車型與日期配置可承接的到貨時段，受理門市或企業客戶預約、候補及改期，並在超量前調整容量，降低集中到貨造成的等待與失約。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **容量規則** — 設定區域、車型與時段上限。
- **時段日曆** — 查看每日預約與剩餘容量。
- **預約受理** — 建立配送需求與到貨限制。
- **候補佇列** — 依優先條件安排釋出名額。
- **改期協調** — 比較替代時段並保存同意紀錄。
- **容量分析** — 分析尖峰、失約與運能浪費。

## 適合誰使用

- 配送調度員
- 客服人員
- 營運主管

## 運作流程

1. 設定容量
2. 提出預約
3. 檢查承載
4. 安排候補
5. 協調改期
6. 檢討容量

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
