**產業別：**資訊科技　|　**系統類型：**operations-console

## 功能模組

- **發布健康監控** — 即時呈現新版本錯誤率、延遲、資源與核心業務指標。
- **護欄違規偵測** — 偵測技術 SLO 與轉換、付款等業務護欄是否遭突破。
- **版本因果比對** — 比較基準版與新版本，估算異常由本次發布造成的可能性。
- **回滾情境模擬** — 推演繼續觀察、限制流量與立即回滾的預期結果。
- **回滾決策台** — 呈現建議、信心區間與觸發條件，供負責人核准。
- **回滾執行驗證** — 執行回滾後確認版本、指標與業務服務均已恢復。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 監看發布
2. 確認違規
3. 定位因果
4. 模擬選項
5. 核准決策
6. 驗證恢復
