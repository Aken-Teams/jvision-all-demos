# Agent 能力分解器

> 將複雜任務拆成可重用的 Agent 能力、責任邊界與人機協作節點。

將複雜任務拆成可重用的 Agent 能力、責任邊界與人機協作節點。

**產業別：**資訊科技　|　**系統類型：**collaboration-pm

## 功能模組

- **任務目標建模** — 整理成果、限制、成功條件與不可由 Agent 自主決定的事項。
- **能力原子拆解** — 將端到端任務拆成可重用、可測試且單一職責的能力單元。
- **能力依賴圖** — 呈現能力間的資料、工具、順序與前置決策相依關係。
- **責任邊界配置** — 為每項能力指定 Agent、人工負責人及最終問責角色。
- **失控風險模擬** — 模擬能力合併、權限擴張與失敗傳播造成的單體風險。
- **能力藍圖發布** — 封裝核准的能力定義、介面與責任矩陣供後續 Agent 重用。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 定義任務目標
2. 產生能力草案
3. 校正依賴關係
4. 劃定責任邊界
5. 模擬失控情境
6. 核准能力藍圖
