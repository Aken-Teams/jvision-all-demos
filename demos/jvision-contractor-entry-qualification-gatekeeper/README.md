# 承攬商入場資格守門員

> 跨系統核驗承攬商保險、訓練與許可，阻止不合格人員入場。面向總務主管與行政團隊，把高頻工作集中在可執行工作台中。

## 功能模組

- **承攬商名冊** — 彙整公司、人員、工種與預定施工區域，建立待審清單。
- **保險效期核驗** — 辨識保單被保人、保障範圍、額度與有效期間。
- **訓練資格核對** — 比對必修安衛課程、測驗結果與複訓期限。
- **證照適任檢查** — 依工種核對專業證照、發證機關與限制條件。
- **工作許可審查** — 確認施工內容、時段、區域與核准層級是否一致。
- **入場放行台** — 整合資格缺口與補件狀態，核准或封鎖門禁權限。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 建立入場批次
2. 核驗保險
3. 比對訓練證照
4. 審查工作許可
5. 決定放行
6. 同步門禁

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
