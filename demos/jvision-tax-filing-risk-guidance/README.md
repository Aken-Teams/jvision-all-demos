# 稅務申報異常輔導平台

> 整合模擬申報資料、歷史案件與產業基準，以人工智慧標示稅額、營收及扣抵異常，協助稅務人員分級選案、檢視風險理由、安排輔導並追蹤改善結果，降低人工篩選負擔。

**產業別：**財務會計　|　**系統類型：**finance-case

## 功能模組

- **申報風險總覽** — 以風險層級、產業及轄區呈現申報案件分布與待辦量。
- **異常規則中心** — 展示稅額、營收、扣抵與跨期波動等偵測規則及命中條件。
- **案件選案工作台** — 依風險分數排序案件，支援篩選、比較與加入查核清單。
- **風險理由解析** — 拆解異常指標、同業差距及歷期變化，提供可讀的判斷依據。
- **輔導任務管理** — 安排聯繫、補件與更正期限，記錄每次輔導內容及進度。
- **改善績效追蹤** — 比較輔導前後風險、申報修正與案件處理成效。

## 適合誰使用

- 稅務審查人員
- 輔導專員
- 科室主管
- 企業財會人員

## 運作流程

1. 掌握風險態勢
2. 設定異常條件
3. 建立選案清單
4. 解析選案理由
5. 執行案件輔導
6. 檢討改善成效

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
