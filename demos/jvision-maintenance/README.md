# 設備維護管理

> 保養、維修、預兆到備品的設備全生命週期

管理工廠設備的報修、故障判斷、維修派工與復機確認，讓停機影響與備品用量可追溯。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**設備維護　|　**系統類型：**CMMS 設備維護

## 功能模組

- **保養排程** — 預防保養自動排程
- **維修工單** — 報修、派工與完工
- **預兆診斷** — 設備數據異常預警
- **備品管理** — 備品庫存與領用
- **OEE 稼動** — 稼動與故障分析
- **履歷追溯** — 設備維護履歷

## 適合誰使用

- 設備維修工程師

## 運作流程

1. 受理故障並判定停機風險
2. 派工維修與登錄備品用量
3. 試車確認並恢復生產

## 導入效益

- 非計畫停機：23小時/月 → **5.6小時/月**
- 保養準時率：71% → **90%**
- 備品缺料：9.4次/月 → **1.9次/月**
- 故障排除時間：85分鐘 → **24分鐘**
