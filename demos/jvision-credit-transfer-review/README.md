# 轉學生學分抵免審查台

> 集中轉學生原校成績、課綱、逐科抵免意見與畢業要求影響，重用已核定的等同性判例，避免重複審查、錯抵必修及結果未回寫。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **申請收件** — 整理成績課綱與證明
- **課程比對** — 比較學分內容與成績
- **抵免判例** — 查找歷年等同性決議
- **教師審查** — 記錄認抵補件或駁回
- **畢業模擬** — 檢查必修與學分影響
- **結果核定** — 發布抵免並保留依據

## 適合誰使用

- 註冊組承辦
- 授課教師
- 系所主管

## 運作流程

1. 受理抵免申請
2. 建立課程比對
3. 派送專業審查
4. 完成逐科決議
5. 檢查畢業影響
6. 核定回寫結果

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
