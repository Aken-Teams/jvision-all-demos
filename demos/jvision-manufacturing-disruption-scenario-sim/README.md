**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **中斷情境建構** — 設定事件時間、持續期、影響範圍與恢復假設。
- **材料短缺模擬** — 測試缺料、替代料與供應延遲對工單的連鎖影響。
- **設備停擺模擬** — 模擬關鍵設備故障、降速與備援產線切換。
- **電力受限模擬** — 評估停電、限電與復電順序對產能及品質的衝擊。
- **物流阻斷模擬** — 測試進料與出貨延誤、路線中斷及替代運輸方案。
- **韌性應變劇本** — 比較備料、轉產、改班與替代運輸的恢復時間和成本。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 建立中斷事件
2. 推演材料短缺
3. 推演設備停擺
4. 推演電力限制
5. 推演物流阻斷
6. 核准應變劇本

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
