## 功能模組

- **熱平衡監控總覽** — 呈現各模具溫差、熱點數量、循環穩定度與待改善優先級。
- **模溫分區熱圖** — 以模具表面分區呈現熱點、冷點、升溫趨勢及目標溫度帶。
- **冷卻迴路分析** — 查看各迴路流量、進出水溫差、影響區域與可能阻塞提示。
- **噴塗節拍設定** — 調整噴塗區域、時間、用量及循環節拍，建立模擬情境。
- **平衡方案最佳化** — 比較冷卻、噴塗與節拍組合對溫差、產能及缺陷風險的影響。
- **熱製程配方管理** — 保存核准配方與版本，呈現套用前後溫差、週期及品質成效。

## 適合誰使用

- 壓鑄製程工程師
- 模具工程師
- 生產課長與設備技師

## 運作流程

1. 辨識失衡模具
2. 定位熱點冷點
3. 檢查冷卻迴路
4. 設定噴塗節拍
5. 選擇平衡方案
6. 發布熱製程配方
