# 鋼筋加工單版次管制台

> 將鋼筋施工圖、撿料表、加工單與現場需求依樓層及澆置區串接，標示版次差異、已加工數量和追加損失，避免設計變更後仍依舊版下料或重複叫料。

將鋼筋施工圖、撿料表、加工單與現場需求依樓層及澆置區串接，標示版次差異、已加工數量和追加損失，避免設計變更後仍依舊版下料或重複叫料。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **澆置區需求** — 依樓層、區段與澆置日建立鋼筋需求包。
- **版次比對** — 呈現施工圖與撿料表前後版的料號數量差異。
- **加工單管理** — 建立下料、彎製、停製與補製指示。
- **在製盤點** — 區分未製、在製、完成及已出貨數量。
- **變更損失** — 估算呆料、重工、急件運費及責任歸屬。
- **到料確認** — 追蹤批次送達、點收結果及澆置區領用。

## 適合誰使用

- 鋼筋工程師
- 採購人員
- 加工廠窗口

## 運作流程

1. 建立區段需求
2. 比對圖說版次
3. 簽發加工指示
4. 盤查在製數量
5. 核算變更影響
6. 確認批次到料

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
