# LLM 回答風格治理器

> 檢查並修正 LLM 回答的品牌語氣、格式及專業用語，統一企業輸出。

檢查並修正 LLM 回答的品牌語氣、格式及專業用語，統一企業輸出。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **品牌語氣規範** — 定義正式度、語調、禁用表述與品牌個性標準。
- **回答格式規則** — 設定標題、段落、條列、日期與數字的輸出格式。
- **企業術語詞庫** — 管理核准術語、產品名稱、縮寫與替代用詞。
- **風格一致檢測** — 逐項標示語氣、格式及用語偏差並解釋原因。
- **合規改寫工作台** — 產生保留原意且符合規範的回答修訂版本。
- **版本發布驗證** — 以評測集驗證風格分數，通過門檻後發布規則。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 建立標準
2. 選取樣本
3. 檢測偏差
4. 審閱改寫
5. 核准規則
6. 發布驗證
