# Jvision 工作與專案管理平台

整合專案排程、任務看板、目標追蹤、工時負荷與 AI 摘要的互動 Demo，讓跨部門協作更清楚。

## Demo 功能

- 新增任務與專案資訊
- 推進任務看板狀態
- 平衡成員工作負荷
- 更新目標進度
- 產生 AI 工作摘要
