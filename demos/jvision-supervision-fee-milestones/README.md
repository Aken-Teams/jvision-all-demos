# 監造服務費里程核驗台

> 依監造契約建立設計審查、施工查驗、估驗及驗收等請款里程碑，連結成果交付與業主核准證據，提示可開票、退件補正及逾期未收款案件。

依監造契約建立設計審查、施工查驗、估驗及驗收等請款里程碑，連結成果交付與業主核准證據，提示可開票、退件補正及逾期未收款案件。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **里程碑總覽** — 查看契約階段、達成條件與可請金額。
- **成果交付登錄** — 連結報告、圖說、會議及查驗成果。
- **核准證據核驗** — 確認業主簽認、公文與退件狀態。
- **請款資料組裝** — 依里程碑產生明細及附件清單。
- **開票認列審核** — 核對金額、稅額與收入認列時點。
- **收款追蹤** — 追蹤送件、退補、開票及實收結果。

## 適合誰使用

- 監造專案經理
- 專案會計
- 請款承辦人

## 運作流程

1. 建立契約里程碑
2. 登錄成果交付
3. 確認業主核准
4. 組裝請款文件
5. 審核開票認列
6. 追蹤收款結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
