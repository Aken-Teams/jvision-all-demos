# 旅宿刷卡請款追補台

> 比對櫃台刷卡授權、夜審批次與銀行入帳，找出已授權未請款、批次漏送及即將逾期交易，分派追補並保存補送或無法收回的責任紀錄。

**產業別：**餐飲旅宿　|　**系統類型：**finance-case

## 功能模組

- **授權清單** — 彙整櫃台刷卡授權
- **批次勾稽** — 比對夜審與收單請款
- **漏送預警** — 標記未請款及將逾期
- **追補處理** — 記錄補送與銀行回覆
- **入帳確認** — 核對收款與手續費
- **責任結案** — 認損並保留調查紀錄

## 適合誰使用

- 櫃台主管
- 夜審人員
- 應收會計

## 運作流程

1. 匯入授權
2. 核對批次
3. 排序風險
4. 執行追補
5. 確認收款
6. 核准結案

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
