# 電商活動庫存鎖定台

> 供品牌電商在大促前配置各平台活動額度、安全庫存與超賣規則，模擬訂單湧入後的可售量變化，並集中處理缺貨替代、額度釋回及活動復盤。

供品牌電商在大促前配置各平台活動額度、安全庫存與超賣規則，模擬訂單湧入後的可售量變化，並集中處理缺貨替代、額度釋回及活動復盤。

**產業別：**零售電商　|　**系統類型：**warehouse-wms

## 功能模組

- **活動建檔** — 建立平台檔期與參加商品
- **額度配置** — 切分通路可售量與安全庫存
- **超賣規則** — 設定停賣、替代及預購條件
- **消耗監看** — 追蹤活動額度與銷售速度
- **缺貨處置** — 分派替代品或取消補償方案
- **活動復盤** — 比較配置、銷售及損失結果

## 適合誰使用

- 電商營運
- 庫存管理員
- 商品經理

## 運作流程

1. 建立活動
2. 圈選商品
3. 鎖定額度
4. 監看消耗
5. 處理缺貨
6. 釋回復盤

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
