# 系統提示洩漏探針

主動探測 AI 應用是否洩漏系統提示與內部機密，協助在上線前修補。

**產業別：**資訊安全　|　**系統類型：**security-soc

## 功能模組

- **探測目標設定** — 設定待測應用、模型端點、身分情境與允許範圍。
- **洩漏探針設計** — 產生直接索取、間接推導與上下文套取的測試提示。
- **自動攻擊執行** — 依測試計畫執行單輪、多輪及變形探針。
- **機密片段比對** — 將回答與系統提示、政策及敏感知識指紋交叉比對。
- **洩漏缺口診斷** — 定位可重現的洩漏路徑、觸發條件與修補缺口。
- **修補複測門檻** — 以原始及變形探針複測，判定是否符合上線條件。

## 適合誰使用

- CISO
- AI 治理主管
- 資安分析師

## 運作流程

1. 界定目標
2. 編製探針
3. 審核測試
4. 執行探測
5. 診斷缺口
6. 複測准入

## 導入效益

- 告警分流時間：45分鐘 → **8分鐘**
- 事件平均處理：12小時 → **3小時**
- 弱點修補率：68% → **96%**
- 合規稽核工時：30小時/月 → **6小時/月**
