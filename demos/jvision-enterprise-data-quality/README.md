# 企業資料品質監理中心

> 持續檢視企業客戶、訂單、庫存與財務資料的完整性、正確性、一致性及時效性，由人工智慧發現異常規則與影響範圍，協助資料負責人分派修正、驗證改善並建立跨部門品質責任。

## 功能模組

- **品質監理總覽** — 呈現各資料域品質分數、異常趨勢與高風險排行。
- **品質規則庫** — 管理完整性、格式、唯一性、一致性與時效檢核規則。
- **異常資料探查** — 檢視異常樣本、欄位分布、可能原因與影響範圍。
- **影響鏈分析** — 追蹤問題資料對報表、流程與下游資料集的影響。
- **修正工作台** — 分派問題給資料負責人，追蹤原因、處置與期限。
- **改善驗證** — 比較修正前後品質指標並確認問題是否可正式結案。

## 適合誰使用

- 資料治理主管
- 資料分析師
- 資料負責人
- 資訊人員

## 運作流程

1. 監看品質概況
2. 設定檢核標準
3. 調查異常資料
4. 評估業務影響
5. 執行資料修正
6. 驗證改善成效

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
