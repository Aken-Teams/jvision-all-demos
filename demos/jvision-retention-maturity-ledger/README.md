# 工程保留款到期清冊

> 逐合約彙整各期扣留、調整、釋放及未沖餘額，連結驗收與保固條件，提前提示到期應付或仍須保留案件，避免早付、漏付與重付。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **保留款總覽** — 查看合約餘額與到期
- **扣留明細** — 追溯各期計價來源
- **到期清冊** — 列出近期可釋放案件
- **條件查核** — 核對驗收保固與扣款
- **釋放付款** — 辦理核准與支付
- **帳務沖銷** — 核對總帳及未沖餘額

## 適合誰使用

- 應付會計
- 合約管理員
- 財務主管

## 運作流程

1. 累積扣留
2. 確認條件
3. 產生清冊
4. 工程覆核
5. 付款核准
6. 總帳沖銷

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
