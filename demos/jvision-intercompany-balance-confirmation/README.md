# 關係企業往來確認台

> 按關係企業與幣別彙整應收、應付、代墊及資金融通餘額，管理雙方差異確認、佐證交換、調整分錄與簽回，縮短月結前往來對帳時間。

按關係企業與幣別彙整應收、應付、代墊及資金融通餘額，管理雙方差異確認、佐證交換、調整分錄與簽回，縮短月結前往來對帳時間。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **往來彙總** — 按公司、科目和幣別呈現餘額。
- **雙邊匹配** — 比對雙方明細及期末餘額。
- **差異分類** — 區分在途、匯率和入帳錯誤。
- **佐證交換** — 集中保存發票、付款及合約資料。
- **調整分錄** — 建立責任公司與更正建議。
- **餘額簽回** — 完成雙方確認並鎖定批次。

## 適合誰使用

- 總帳會計
- 關係企業會計
- 財務主管

## 運作流程

1. 產生批次
2. 執行匹配
3. 分類差異
4. 交換佐證
5. 完成調整
6. 雙方簽回

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
