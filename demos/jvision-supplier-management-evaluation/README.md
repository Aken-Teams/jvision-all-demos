# 供應商管理評鑑系統

> 集中維護供應商基本資料、證照文件、供貨品項、交期品質表現與合作風險，透過一致的評鑑表及分級規則完成定期考核、改善追蹤與准入審核，協助採購建立透明且可比較的供應商管理制度。

集中維護供應商基本資料、證照文件、供貨品項、交期品質表現與合作風險，透過一致的評鑑表及分級規則完成定期考核、改善追蹤與准入審核，協助採購建立透明且可比較的供應商管理制度。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **供應商總覽** — 彙整供應商分級、待評鑑、文件到期、重大風險與績效分布。
- **供應商資料庫** — 管理公司資訊、聯絡窗口、供貨品項、工廠據點及合作狀態。
- **資格文件管理** — 檢視證照、稽核報告、保密協議與有效期限，呈現補件提醒。
- **績效評分卡** — 比較交期、品質、價格與服務指標，查看各期得分及同類排名。
- **定期評鑑作業** — 由採購、品保及使用部門填寫評鑑表，完成加權計分與分級。
- **改善准入管理** — 追蹤改善要求、回覆證據、複評結果，以及新增或續約審核流程。

## 適合誰使用

- 採購主管
- 採購專員
- 品保人員
- 供應商管理委員

## 運作流程

1. 掌握供應商組合
2. 維護合作資料
3. 確認資格文件
4. 檢視供貨績效
5. 完成跨部門評鑑
6. 審核改善與准入

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
