# 汽車供應商品質風險雷達

> 整合供應商先期品質文件、樣件驗證、製程能力、變更紀錄與歷史缺失，以風險雷達及里程碑看板呈現量產前缺口，協助採購與品質團隊提早介入高風險料件，追蹤改善並做出放行決策。

整合供應商先期品質文件、樣件驗證、製程能力、變更紀錄與歷史缺失，以風險雷達及里程碑看板呈現量產前缺口，協助採購與品質團隊提早介入高風險料件，追蹤改善並做出放行決策。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **風險雷達** — 依供應商、料件與專案呈現品質風險分數、變化與熱區。
- **料件專案樹** — 瀏覽車型、系統、零件與供應商關係及各節點狀態。
- **文件查核** — 管理先期品質文件清單、版本、審查結果與缺漏項目。
- **樣件驗證** — 呈現尺寸、材料、功能與可靠度驗證結果及未通過項目。
- **製程能力** — 比較關鍵特性的製程能力指標、趨勢與量產穩定風險。
- **放行評審** — 彙整未結事項、例外條件與跨部門意見，模擬量產放行決策。

## 適合誰使用

- 供應商品質工程師
- 採購人員與新產品專案經理

## 運作流程

1. 掃描供應風險
2. 界定影響範圍
3. 查核品質文件
4. 審視樣件結果
5. 評估製程成熟度
6. 完成量產評審
