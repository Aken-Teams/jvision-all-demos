# 現場變更指示計價台

> 把會議、口頭或通訊訊息中的現場變更先轉成編號指示，界定施工範圍、即時採證人材機投入，並在工作完成後形成可追認的數量與計價依據，降低月底追加爭議。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **變更指示登錄** — 記錄指示人、時間、原始訊息、原因與緊急程度。
- **施工範圍確認** — 以圖面、位置及工項界定新增、刪減或重作範圍。
- **權利保留通知** — 建立工期與價款影響通知及送達紀錄。
- **人材機採證** — 逐日登錄人工、材料、機具、數量與現場照片。
- **數量計價** — 彙整丈量結果、單價來源、管理費及扣減項。
- **追認協商** — 追蹤送審、議價、核定與未認列差額。

## 適合誰使用

- 現場工程師
- 成本工程師
- 專案經理

## 運作流程

1. 登錄現場指示
2. 確認施工範圍
3. 發出保留通知
4. 蒐集投入證據
5. 編製追加計價
6. 完成價款追認

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
