# 每日施工條件交班台

> 依工區整理當班未完成工項、材料狀態、封閉前查驗、臨時防護、積水與禁入範圍，透過位置化照片和接班確認形成每日交接基準，避免重要限制沉在群組訊息或只靠口頭轉述。

依工區整理當班未完成工項、材料狀態、封閉前查驗、臨時防護、積水與禁入範圍，透過位置化照片和接班確認形成每日交接基準，避免重要限制沉在群組訊息或只靠口頭轉述。

**產業別：**營建工程　|　**系統類型：**operations-console

## 功能模組

- **工區總覽** — 按樓層與區域顯示當班施工狀態。
- **未結工項** — 記錄進度、剩餘工作與下一步條件。
- **風險限制** — 標示開口、帶電、積水及禁止進入區。
- **定位影像** — 保存交班當下的全景與問題細節。
- **交接確認** — 由接班者逐項接受或提出異議。
- **跨班追蹤** — 追蹤未解除事項的責任與處置時限。

## 適合誰使用

- 值班工程師
- 工區主任
- 職安人員

## 運作流程

1. 盤點當班現況
2. 標示安全限制
3. 補齊定位照片
4. 提交交班清單
5. 接班確認異議
6. 追蹤跨班事項

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
