# 出院帶藥缺件協調台

> 以病人出院批次追蹤處方審核、調劑、缺藥替代、衛教與領藥交付，讓病房和藥局共享卡點及預計完成時間，避免漏藥並縮短床位釋出等待。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **出院看板** — 掌握待藥病人
- **處方核對** — 檢查用藥清單
- **缺藥協調** — 處理短缺替代
- **完成預估** — 回報調劑時程
- **衛教確認** — 記錄用藥說明
- **領藥交付** — 核對病人藥袋

## 適合誰使用

- 病房護理師
- 藥師
- 出院協調員

## 運作流程

1. 建立清單
2. 審核處方
3. 處理缺藥
4. 回報進度
5. 執行衛教
6. 完成交付
