> 供染整廠依缸容、布重、深淺色順序與洗缸需求安排染批，業務插單時同步配料室與胚布倉，避免染料已配但缸未空或深色污染淺色。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **染缸排程** — 查看缸別時段
- **待染批次** — 整理布重色系
- **換色序列** — 判斷深淺與洗缸
- **插單模擬** — 評估受影響批次
- **配料同步** — 確認染料準備
- **換班交接** — 發布唯一排程版

## 適合誰使用

- 染房生管
- 配料室領班

## 運作流程

1. 彙整染批
2. 缸容配對
3. 換色排序
4. 插單重排
5. 配料備布
6. 交班執行
