# 工程環境故障排除 Agent

診斷本機、憑證、依賴與權限故障，提供可執行修復步驟以縮短開發阻塞。

**產業別：**資訊科技　|　**系統類型：**service-desk

## 功能模組

- **環境症狀採集** — 收集作業系統、工具鏈、錯誤訊息與重現指令。
- **憑證鏈診斷** — 檢查憑證有效期、信任鏈、代理與登入權杖狀態。
- **依賴衝突解析** — 比對套件鎖檔、版本需求與私有套件來源的衝突。
- **權限阻塞定位** — 辨識倉庫、雲端、叢集及開發資源的缺失權限。
- **修復方案沙盒** — 產生低風險修復指令並預估對現有環境的影響。
- **開發復工驗證** — 重跑建置、測試與存取檢查，確認阻塞已解除。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 描述阻塞症狀
2. 檢查憑證連線
3. 分析依賴差異
4. 確認權限缺口
5. 核准執行修復
6. 驗證恢復開發

## 導入效益

- 事件平均處理：120分鐘 → **30分鐘**
- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
- 資產盤點工時：20小時/月 → **4小時/月**
