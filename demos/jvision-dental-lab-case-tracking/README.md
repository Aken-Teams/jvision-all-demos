# 牙科假牙製程追件台

> 將牙科印模、設計、技工所製作、色號確認、試戴、重製與回件日期串成病例製程，於病人到診前確認成品與配件完整，避免診間空轉。

將牙科印模、設計、技工所製作、色號確認、試戴、重製與回件日期串成病例製程，於病人到診前確認成品與配件完整，避免診間空轉。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **技工病例** — 記錄牙位材質與色號
- **送件交接** — 追蹤印模附件與收件
- **製程進度** — 更新設計製作與預計完成
- **回件點收** — 核對成品模型及配件
- **試戴安排** — 確認病人預約與可用性
- **重製處理** — 記錄原因責任與新期限

## 適合誰使用

- 牙科助理
- 技工所聯絡人
- 牙醫師

## 運作流程

1. 建立技工訂單
2. 完成送件交接
3. 追蹤製作進度
4. 執行回件點收
5. 安排病人試戴
6. 驗收或啟動重製

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
