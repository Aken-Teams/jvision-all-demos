# Agent 個人化邊界控制台

> 區分個人偏好、企業事實與敏感記憶，防止 Agent 產生不當個人化。

區分個人偏好、企業事實與敏感記憶，防止 Agent 產生不當個人化。

**產業別：**資訊科技　|　**系統類型：**security-soc

## 功能模組

- **記憶分類盤點** — 將 Agent 記憶辨識為偏好、企業事實或敏感資訊。
- **偏好適用範圍** — 限制個人偏好可影響的任務、角色與有效期間。
- **企業事實錨定** — 將共享事實連結至權威來源與版本。
- **敏感記憶防線** — 阻擋憑證、健康、財務與機密資訊進入長期記憶。
- **邊界衝突檢查** — 偵測個人偏好覆蓋企業規則或跨使用者洩漏。
- **記憶修正控制** — 核准更正、縮限、到期或刪除不當記憶。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 盤點現有記憶
2. 界定偏好用途
3. 驗證企業事實
4. 隔離敏感資訊
5. 審查邊界衝突
6. 核准記憶修正
