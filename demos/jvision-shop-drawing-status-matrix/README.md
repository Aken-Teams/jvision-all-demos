# 施工圖送審版次矩陣台

> 依棟別、樓層、工項與施工區建立施工圖送審矩陣，控管預計送審日、審查碼、修訂版次、適用區域及現場作廢回收，避免工班使用錯版圖說施工。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **送審矩陣** — 按區域與工項呈現圖說需求、送審及核准狀態。
- **版次送審** — 登錄圖號、版次、修訂摘要與送審文件。
- **審查意見** — 拆解設計與監造意見並追蹤逐項回覆。
- **版差比較** — 標示前後版變更位置及受影響施工區。
- **核准發布** — 發布可施工版本並通知相關工班簽收。
- **舊版回收** — 追蹤現場圖櫃、工班紙本及作廢章紀錄。

## 適合誰使用

- 圖管工程師
- 施工工程師
- 監造工程師

## 運作流程

1. 建立圖說矩陣
2. 提交設計版次
3. 辦理圖說審查
4. 完成修訂覆核
5. 發布施工核准版
6. 回收作廢舊版

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
