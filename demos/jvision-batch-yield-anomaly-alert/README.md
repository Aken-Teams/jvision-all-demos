# 批次良率異常預警台

> 依擬真批次檢驗與生產紀錄監看良率變化，辨識相對於同產品、線別及近期基準的異常下降，在超出品質門檻前提供分級預警、影響範圍及建議處置，降低連續不良批次。

依擬真批次檢驗與生產紀錄監看良率變化，辨識相對於同產品、線別及近期基準的異常下降，在超出品質門檻前提供分級預警、影響範圍及建議處置，降低連續不良批次。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **批次預警總覽** — 呈現產品、線別與班別的良率預警數量及風險分布。
- **異常批次佇列** — 依偏離幅度、連續性與影響數量排序待確認批次。
- **基準差異分析** — 比較批次與同產品、同設備及近期生產基準的差異。
- **不良結構檢視** — 拆解不良類型、數量、站點與產品區域的組成變化。
- **預警處置中心** — 指派加驗、隔離、調機或暫停等處置及完成期限。
- **後續批次觀察** — 追蹤處置後數個批次的良率回穩與預警解除狀態。

## 適合誰使用

- 品保工程師
- 品質主管
- 現場領班

## 運作流程

1. 掌握預警分布
2. 確認異常批次
3. 比較歷史基準
4. 拆解不良結構
5. 指派預警處置
6. 觀察後續批次

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
