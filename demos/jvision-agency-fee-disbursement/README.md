# 校務代收款解繳核對台

> 將各處室代收名冊、收據、銀行入帳、現金繳交及會計科目逐筆勾稽，處理同名學生與跨項目付款，釐清短溢及延遲解繳責任。

**產業別：**教育　|　**系統類型：**finance-ledger

## 功能模組

- **代收名冊** — 建立學生與收費項目
- **收據管理** — 登錄號碼與作廢狀態
- **收款勾稽** — 配對網銀與現金款項
- **差異處理** — 追查同名跨項及短溢
- **解繳簽收** — 記錄處室交款責任
- **會計入帳** — 核定科目並完成銷帳

## 適合誰使用

- 校務出納
- 處室承辦
- 會計人員

## 運作流程

1. 建立代收批次
2. 登錄收據收款
3. 執行逐筆勾稽
4. 調查未合差異
5. 完成款項解繳
6. 核定科目入帳

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
