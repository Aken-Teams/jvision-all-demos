# 圖說疑義釋疑管制台

管理施工圖、規範與現場條件不一致所產生的釋疑案件，連結圖面標註、責任設計單位、回覆期限及影響工項，避免口頭答覆未納入正式施工依據。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **疑義總覽** — 依專業、區域與施工急迫度顯示案件。
- **問題提報** — 圈選圖面並描述衝突、假設及所需決策。
- **資料補充** — 彙整照片、尺寸、規範及相關版次。
- **設計回覆** — 記錄澄清意見、替代方案與正式性狀態。
- **核定發布** — 由監造確認結論並建立施工依據。
- **影響通知** — 通知相關工班並追蹤圖說或工法更新。

## 適合誰使用

- 施工工程師
- 設計監造人員
- 圖管人員

## 運作流程

1. 疑義總覽
2. 問題提報
3. 資料補充
4. 設計回覆
5. 核定發布
6. 影響通知

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
