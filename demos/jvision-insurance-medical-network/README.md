# 保險特約醫療網管理台

> 供保險公司管理健檢、醫療諮詢與理賠協力院所的簽約服務、區域覆蓋、轉介案件、帳單覆核、服務品質及合約續評。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **院所網絡** — 查看據點、科別與覆蓋
- **合約服務** — 維護價格、資格及期限
- **案件轉介** — 分派服務與追蹤完成
- **帳單覆核** — 核對服務項目及合約價
- **品質事件** — 管理申訴與改善要求
- **續約評估** — 評估量能、品質與續約條件

## 適合誰使用

- 醫療網管理專員
- 保險營運主管
- 帳務審核員

## 運作流程

1. 盤點醫療網絡
2. 建立合作合約
3. 追蹤轉介案件
4. 覆核服務帳單
5. 處理品質事件
6. 完成續約評估

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
