# 電腦數控刀具崩刃偵測

> 透過擬真的主軸負載、振動與聲音特徵，呈現電腦數控加工中刀具崩刃的異常判定、事件回放與受影響工件追溯，協助現場快速停查、隔離批次並降低連續不良品風險。

透過擬真的主軸負載、振動與聲音特徵，呈現電腦數控加工中刀具崩刃的異常判定、事件回放與受影響工件追溯，協助現場快速停查、隔離批次並降低連續不良品風險。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **崩刃告警中心** — 集中顯示事件等級、機台刀號、發生時間與待處理狀態。
- **異常訊號回放** — 以時間軸重現事件前後的負載、振動及聲學特徵變化。
- **判定依據解析** — 拆解各項特徵對崩刃判定的影響，呈現模擬信心分數。
- **影響批次追溯** — 列出事件前後加工的工件、工單與目前流向，供品保圈選隔離。
- **檢查處置作業** — 建立停機檢查、換刀、首件確認及批次放行的操作清單。
- **異常案例報告** — 彙整事件證據、原因分類、損失估算與後續改善追蹤。

## 適合誰使用

- 機台操作員
- 品保工程師
- 製程工程師

## 運作流程

1. 接收崩刃告警
2. 回放異常訊號
3. 確認判定證據
4. 圈選影響批次
5. 執行檢查處置
6. 完成案例結案

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
