# 搜尋結果證據排序器

> 依權威性、新鮮度、情境與可追溯性重排搜尋結果，讓使用者先看到可信答案。

依權威性、新鮮度、情境與可追溯性重排搜尋結果，讓使用者先看到可信答案。

**產業別：**企業協作　|　**系統類型：**service-desk

## 功能模組

- **查詢情境解析** — 辨識使用者角色、任務目的與查詢限制。
- **來源權威評級** — 按作者、擁有者、核准狀態與系統來源評定權威性。
- **知識時效檢查** — 偵測過期、互相矛盾或已被新版取代的內容。
- **引用鏈追溯** — 呈現答案所依據的文件、工單、郵件與程式來源。
- **可信結果重排** — 綜合權威、時效、情境與可追溯性產生排序。
- **排序品質校準** — 以點擊、採用與客服解決結果調整排序權重。

## 適合誰使用

- 知識工作者
- 主管
- 客服

## 運作流程

1. 解析搜尋意圖
2. 核驗來源權威
3. 排除失效知識
4. 檢視答案出處
5. 採用可信答案
6. 回饋排序成效

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
