# 企業風險管理系統（ERM）

> 把分散數據變成可下鑽、可決策的經營洞察

企業風險管理系統（ERM）提供風險登錄簿與風險矩陣評估、供應鏈/財務/營運/資安風險分類管理、風險預警指標(KRI)監控。風控部依「風險辨識 → 風險評估分級 → 應對措施制定 → 監控指標追蹤 → 定期報告 → 董事會審視」推進作業，優先解決「風險分散於各部門未整合」，稽核室則以重大風險覆蓋率與風險應變時效確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**經營管理　|　**系統類型：**BI 商業智慧

## 功能模組

- **經營儀表板** — 關鍵指標即時總覽
- **趨勢分析** — 多維度趨勢與比較
- **指標下鑽** — 逐層鑽取到明細
- **平衡計分卡** — 策略目標與 KPI 對齊
- **AI 洞察** — 自動發現異常與機會
- **報表匯出** — 排程報表與分享

## 適合誰使用

- 風控部
- 稽核室
- 財務部

## 運作流程

1. 待釐清
2. 改善中
3. 核定確認
4. 已解除
