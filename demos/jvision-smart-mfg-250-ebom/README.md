# 研發BOM管理系統（EBOM）

> 訂單到入庫的製造現場全流程數位化

研發BOM管理系統（EBOM）提供EBOM結構建立與版本控制、EBOM轉MBOM對應規則管理、替代料與多來源料號設定。研發專員、研發主管、研發管理主管依「EBOM結構建立與版本控制、EBOM轉MBOM對應規則管理、替代料與多來源料號設定」推進作業，優先解決「EBOM與MBOM不一致導致生產錯誤」，部門主管則以研發BOM管理管理艙處理結果確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**研發管理　|　**系統類型：**MES 製造執行系統

## 功能模組

- **工單管理** — 訂單轉工單、拆併單與工單派發
- **排程排產** — 依產能、交期、負載自動排程
- **現場執行** — 派工、報工與進度即時回報
- **設備稼動 OEE** — 稼動、效率、良率即時監控
- **品質入庫** — 檢驗判定、不良處置與入庫
- **AI 改善建議** — 異常摘要與瓶頸改善建議

## 適合誰使用

- 研發專員
- 研發主管
- 研發管理主管

## 運作流程

1. 待排程
2. 生產中
3. 審核確認
4. 發布完成

## 導入效益

- 設計變更工時：8.3小時 → **2小時**
- 文件版本錯誤：6.1件/月 → **1件/月**
- 專案準時率：70% → **86%**
- 資料查找時間：29分鐘 → **5.3分鐘**
