# 旅宿賓客主檔整併台

> 辨識OTA隱藏信箱、英文姓名、同行人與會員資料造成的重複賓客，審查身分證據、偏好及同意紀錄，避免同名誤併與跨館個資誤寄。

辨識OTA隱藏信箱、英文姓名、同行人與會員資料造成的重複賓客，審查身分證據、偏好及同意紀錄，避免同名誤併與跨館個資誤寄。

**產業別：**餐飲旅宿　|　**系統類型：**it-ops

## 功能模組

- **重複候選** — 彙整疑似賓客
- **身分比對** — 核對姓名聯絡
- **住史檢視** — 比較跨館紀錄
- **偏好整合** — 選擇保留資料
- **整併覆核** — 控管個資風險
- **跨館同步** — 驗證發布結果

## 適合誰使用

- 賓客資料管理員
- 前台主管
- 個資人員

## 運作流程

1. 建立候選
2. 核實賓客
3. 比較資料
4. 選定主檔
5. 核准整併
6. 同步驗證

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
