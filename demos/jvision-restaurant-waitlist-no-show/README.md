# 餐廳候位過號處置台

> 管理候位登記、叫號、保留期限、過號恢復與桌位釋放，讓交班人員清楚每組顧客承諾和等待歷程，降低跳號爭議及尖峰空桌時間。

**產業別：**餐飲旅宿　|　**系統類型：**pos-frontdesk

## 功能模組

- **候位名單** — 查看排序、人數與需求
- **桌況配置** — 配對可用桌型與區域
- **叫號紀錄** — 記錄通知時間與結果
- **過號判定** — 依保留規則處理逾時
- **例外授權** — 核准恢復順位或延長
- **翻桌分析** — 檢視等待與空桌損失

## 適合誰使用

- 帶位人員
- 值班主管
- 外場經理

## 運作流程

1. 建立候位
2. 配置桌型
3. 執行叫號
4. 判定過號
5. 處理例外
6. 檢討桌效

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
