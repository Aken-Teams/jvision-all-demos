# 帷幕牆單元板塊追蹤台

> 以板塊編號串接深化核准版、生產狀態、品質檢查、裝架車趟、樓層卸貨、吊裝位置及破片補製，避免舊版板塊出貨、錯層安裝或補片失聯。

**產業別：**營建工程　|　**系統類型：**logistics-fleet

## 功能模組

- **板塊台帳** — 依棟別、立面、樓層與編號管理單元板。
- **深化版次** — 綁定每片板塊適用的核准圖與變更。
- **生產品檢** — 追蹤加工、組裝、玻璃與出廠檢查。
- **裝架配車** — 安排架號、裝載順序、車趟與到場時間。
- **吊裝定位** — 核對卸貨、待吊、已裝與安裝位置。
- **破片補製** — 建立損壞原因、替代版次及急件排程。

## 適合誰使用

- 帷幕牆工程師
- 工廠窗口
- 吊裝領班

## 運作流程

1. 核准深化
2. 安排生產
3. 完成品檢
4. 裝架出貨
5. 吊裝定位
6. 補製結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
