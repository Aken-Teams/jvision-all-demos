**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **API 情境探索** — 依業務目標、來源服務與資料需求推薦合適的內部 API。
- **情境範例產生器** — 使用指定語言與框架生成符合團隊慣例的呼叫範例。
- **契約相容檢查** — 驗證欄位、型別、版本與錯誤回應是否符合 API 契約。
- **權限範圍教練** — 說明所需身分、授權範圍與最小權限申請方式。
- **請求試跑台** — 在安全環境送出範例請求並檢查回應、限流與錯誤處理。
- **整合計畫輸出** — 彙整可用程式碼、必要設定、測試案例與待辦事項。

## 適合誰使用

1. 描述情境

5. 安全試跑
6. 採用整合
