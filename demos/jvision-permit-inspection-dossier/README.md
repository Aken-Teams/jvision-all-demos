# 建照查驗文件備查台

> 依建照施工查驗節點彙整圖說、簽章、技師證明、試驗報告與現場照片，執行版次和效期預檢，減少主管機關查驗退補。

依建照施工查驗節點彙整圖說、簽章、技師證明、試驗報告與現場照片，執行版次和效期預檢，減少主管機關查驗退補。

**產業別：**營建工程　|　**系統類型：**legal-case

## 功能模組

- **查驗節點** — 查看申報日期與狀態
- **文件矩陣** — 依節點列出必備資料
- **收件中心** — 管理簽章效期與版本
- **版次核對** — 比較建照與施工圖說
- **送件預檢** — 找出缺頁與矛盾內容
- **備查送件** — 記錄送件補正及核准

## 適合誰使用

- 法規承辦
- 監造建築師
- 文件管理員

## 運作流程

1. 建立節點
2. 分派備件
3. 文件收集
4. 版本覆核
5. 完成預檢
6. 申報備查

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
