# 租戶水電分攤結算台

> 管理各單元期初期末讀數、租戶進退場、空置與壞表估算，依租約費率產生可追溯帳單，降低分攤少收與重開單爭議。

管理各單元期初期末讀數、租戶進退場、空置與壞表估算，依租約費率產生可追溯帳單，降低分攤少收與重開單爭議。

**產業別：**房地產與物業　|　**系統類型：**finance-ledger

## 功能模組

- **抄表批次** — 查看各表計與讀數狀態。
- **讀數舉證** — 保存照片及抄表人。
- **佔用期間** — 管理租戶與空置生效日。
- **費用分攤** — 套用費率與公共比例。
- **異常處理** — 處理壞表、跳表及爭議。
- **帳單發布** — 產生明細與計算軌跡。

## 適合誰使用

- 物業會計
- 案場主任
- 租戶服務

## 運作流程

1. 建立抄表
2. 登錄讀數
3. 確認佔用
4. 執行分攤
5. 覆核異常
6. 發布帳單

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
