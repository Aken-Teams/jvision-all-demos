# 學籍身分跨校併檔台

> 比對招生、學籍及學習平台中的重複學生身分，檢視成績、繳費、選課與獎懲關聯後進行合併或分拆裁決，防止同名誤併。

比對招生、學籍及學習平台中的重複學生身分，檢視成績、繳費、選課與獎懲關聯後進行合併或分拆裁決，防止同名誤併。

**產業別：**教育　|　**系統類型：**it-ops

## 功能模組

- **重複候選** — 找出姓名證號相似身分
- **身分證據** — 比對生日來源與歷程
- **關聯資料** — 檢視成績選課與繳費
- **併分模擬** — 預覽合併或拆分結果
- **裁決工作台** — 核定主身分與保留規則
- **跨校發布** — 同步修正並留下稽核

## 適合誰使用

- 學籍管理員
- 資訊人員
- 資料治理主管

## 運作流程

1. 偵測重複身分
2. 查核身分證據
3. 盤點關聯資料
4. 模擬併分結果
5. 核定身分裁決
6. 發布跨系統修正

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
