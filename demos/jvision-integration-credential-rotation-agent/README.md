# 整合憑證輪替 Agent

> 協調整合金鑰的建立、切換驗證與舊憑證撤銷，降低輪替期間服務中斷。

協調整合金鑰的建立、切換驗證與舊憑證撤銷，降低輪替期間服務中斷。

**產業別：**資訊科技　|　**系統類型：**security-soc

## 功能模組

- **憑證資產盤點** — 辨識金鑰、Token、憑證的擁有者、期限與使用位置。
- **使用關聯圖** — 對應憑證所連接的 API、MCP Server、Skill 與環境。
- **輪替波次規劃** — 依相依順序、維護窗口與風險安排分批切換。
- **新舊金鑰雙軌** — 管理新憑證發放、並行有效期與消費端更新狀態。
- **連線驗證測試** — 以實際權限和代表性呼叫確認新憑證可正常工作。
- **舊憑證撤銷** — 在確認無殘留流量後撤銷舊憑證並關閉回復窗口。

## 適合誰使用

- 平台架構師
- 整合工程師
- AI 應用開發者

## 運作流程

1. 盤點待輪替憑證
2. 解析使用關聯
3. 擬定輪替波次
4. 核准並啟動切換
5. 驗證新憑證流量
6. 撤銷舊憑證
