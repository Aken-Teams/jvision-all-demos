**產業別：**業務銷售　|　**系統類型：**analytics-bi

## 功能模組

- **投放組合盤點** — 彙整各平台、活動、受眾與市場的預算及成果。
- **增量效果估計** — 運用實驗與因果線索估算廣告真正帶來的額外成果。
- **邊際回報曲線** — 呈現各渠道加減預算後的預期增量回報與飽和點。
- **配置情境模擬** — 比較成長、獲利、品牌與風險限制下的預算方案。
- **預算調整提案** — 提出跨平台增減額度、移轉順序與預期效益。
- **投放同步與驗證** — 核准後更新平台預算並追蹤實際增量結果。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 盤點投放組合
2. 估算增量效果
3. 建立邊際曲線
4. 模擬配置情境
5. 核准預算移轉
6. 同步並驗證成果
