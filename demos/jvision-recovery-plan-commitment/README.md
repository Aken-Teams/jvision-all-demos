# 落後進度趕工承諾台

> 針對落後工項建立可執行的趕工方案，拆解增班、增員、工作面及材料承諾，逐日比對承諾量與實績，讓無效措施及連帶影響能及早升級處理。

針對落後工項建立可執行的趕工方案，拆解增班、增員、工作面及材料承諾，逐日比對承諾量與實績，讓無效措施及連帶影響能及早升級處理。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **落後清單** — 依浮時與里程碑影響排序落後工項。
- **趕工提案** — 填報班次、人力、工法與預計產量。
- **每日承諾** — 拆分每日工作面及完成量目標。
- **資源到位** — 核對人員、材料與機具實際進場。
- **實績追蹤** — 比較承諾量、完成量與追回幅度。
- **偏差升級** — 針對連續未達案件啟動主管協調。

## 適合誰使用

- 工地主任
- 排程工程師
- 分包領班

## 運作流程

1. 辨識落後
2. 提出方案
3. 確認條件
4. 執行趕工
5. 核對實績
6. 升級處置

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
