> 以房號追蹤房務發現、工程處理中、待料及複驗狀態，讓櫃檯在售房前看見未完成故障，避免問題房被錯誤放售。

**產業別：**餐飲旅宿　|　**系統類型：**maintenance-cmms

## 功能模組

- **房況看板** — 顯示故障房與可售風險。
- **房務通報** — 記錄位置、症狀及照片。
- **維修處置** — 更新檢查、修復與待料狀態。
- **工程交班** — 傳遞未完工項與注意事項。
- **房務複驗** — 確認功能及清潔恢復。
- **售房放行** — 解除停售並留下核准。

## 適合誰使用

- 房務主管
- 工程人員
- 櫃檯主管

## 運作流程

1. 發現故障
2. 判定停售
3. 執行維修
4. 跨班交接
5. 完成複驗
6. 恢復銷售

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
