# Customer Audit Portal（客戶稽核入口/線上稽核系統）

> 從異常到改善的品質閉環與追溯稽核

Customer Audit Portal（客戶稽核入口/線上稽核系統）提供客戶帳號權限管理、品質文件線上查閱、線上稽核排程與紀錄。業務部依「客戶申請稽核→線上資料準備→稽核執行（現場或遠端）→缺失回覆→結案留存」推進作業，優先解決「客戶稽核來訪成本高」，品保部則以稽核準備時間與客戶稽核滿意度確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 業務部
- 品保部
- 資訊部

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：20天 → **8.8天**
- 改善驗證率：68% → **92%**
- 重複不良率：6.1% → **2.1%**
