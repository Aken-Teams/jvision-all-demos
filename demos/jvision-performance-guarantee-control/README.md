# 履約保證文件控管台

> 集中管理押標金、履約保證金與保函正本、效期、金額及解除條件，在工程展延或契約增額時提示展延補足，並追蹤到期返還與帳務沖銷。

集中管理押標金、履約保證金與保函正本、效期、金額及解除條件，在工程展延或契約增額時提示展延補足，並追蹤到期返還與帳務沖銷。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **保證案件總覽** — 查看類型、金額、效期與目前狀態。
- **保函正本登錄** — 記錄銀行、編號、保管人與正本位置。
- **展延補足預警** — 比對工期及契約額提示續期或增額。
- **解除條件追蹤** — 追蹤驗收、保固及缺失改善里程碑。
- **返還申請** — 準備函文、核准及正本返還程序。
- **帳務沖銷** — 核對退還款項、手續費與會計結清。

## 適合誰使用

- 合約管理員
- 財務人員
- 專案經理

## 運作流程

1. 建立保證要求
2. 完成繳付登錄
3. 監控工程異動
4. 辦理展延補足
5. 申請解除返還
6. 核對收回結清

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
