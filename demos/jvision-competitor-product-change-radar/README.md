# 競品產品變更雷達

**產業別：**業務銷售　|　**系統類型：**analytics-bi

## 功能模組

- **競品變更雷達** — 集中顯示各競品近期變更、影響程度與偵測時間。
- **功能版本時間線** — 追蹤新功能、版本發布、下線項目與產品節奏。
- **定價方案監視器** — 比對價格、方案層級、限制與促銷條款變化。
- **文件差異檢視器** — 逐段呈現官網、說明文件與條款的新增及刪除內容。
- **競爭影響研判** — 分析變更對客群、定位、銷售話術與產品路線的影響。
- **策略回應作戰室** — 建立競爭回應案件，指派產品、行銷與銷售行動。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 查看變更警報
2. 還原版本脈絡
3. 評估定價變化
4. 核對文件差異
5. 研判競爭衝擊
6. 啟動策略回應
