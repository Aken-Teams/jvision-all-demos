# 遊覽車趟次執行台

> 供遊覽車業者從包車確認後管理車輛、駕駛、集合點、行程版本、休息時段與臨時異動，確保每一趟次具備可執行的派遣資料。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **包車任務** — 彙整客戶、日期、人數與服務規格。
- **行程版本** — 管理集合點、停靠點及時間變更。
- **車輛配置** — 依座位、設備與檢驗狀態選車。
- **駕駛指派** — 核對資格、工時及住宿安排。
- **任務發布** — 發布駕駛可執行的最終任務單。
- **途中異動** — 記錄延誤、改點與替代處置。

## 適合誰使用

- 車隊調度員
- 包車業務
- 駕駛主管

## 運作流程

1. 接收任務
2. 確認行程
3. 配置車輛
4. 指派駕駛
5. 發布任務
6. 回報結案

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
