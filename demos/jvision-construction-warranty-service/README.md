# 建案保固修繕管理台

> 協助建商在交屋後集中受理住戶保固申請，判定責任與保固範圍，安排原承包商會勘修繕，管理複驗、扣款及結案證據，避免案件久懸與責任爭議。

協助建商在交屋後集中受理住戶保固申請，判定責任與保固範圍，安排原承包商會勘修繕，管理複驗、扣款及結案證據，避免案件久懸與責任爭議。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **保固受理** — 登錄戶別、問題位置、照片與可配合時段。
- **責任判定** — 比對保固條款並確認建商或住戶責任。
- **會勘派工** — 安排工務與承包商到場確認修繕方案。
- **修繕追蹤** — 管理施工日期、材料需求及完成回報。
- **住戶複驗** — 記錄複驗結果、未改善項目與再派工。
- **扣款結案** — 彙整責任扣款、簽認文件及結案證據。

## 適合誰使用

- 建商客服
- 保固工務
- 發包管理員

## 運作流程

1. 受理報修
2. 判定責任
3. 安排會勘
4. 執行修繕
5. 完成複驗
6. 核算結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
