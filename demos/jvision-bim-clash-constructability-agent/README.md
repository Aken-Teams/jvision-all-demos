# 建築資訊模型施工審查助手

> 以建築資訊模型概念呈現建築、結構與機電圖說的衝突清單，透過三維視角示意、規則審查與議題協作，協助工程團隊在施工前確認空間干涉、維修淨空與工序風險；展示資料皆為預先建立。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **模型總覽** — 以預設三維模型視角呈現樓層、專業系統及衝突熱區。
- **衝突檢查** — 列出構件碰撞、間距不足與重疊問題，支援條件篩選。
- **施工性審查** — 依維修淨空、吊裝路徑與施工順序等規則顯示風險。
- **議題協作** — 為圖說問題指定責任專業、期限、回覆與處理狀態。
- **版本比對** — 比較修正前後構件與問題狀態，確認新增、消除或位移項目。
- **審查報告** — 彙整重大衝突、責任分布、逾期議題及會議決議。

## 適合誰使用

- 建築資訊模型協調員
- 機電工程師
- 工地主任與設計顧問

## 運作流程

1. 瀏覽整合模型
2. 篩選重大衝突
3. 檢核可施工性
4. 分派圖說議題
5. 驗證修正版本
6. 完成協調結論

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
