# 績效目標品質校準副手

> 協助主管與員工檢查績效目標是否具體、可衡量、可控且對齊組織方向，並在期末以證據摘要、評分分布及跨團隊差異支援校準會議，提升績效管理的一致性。

協助主管與員工檢查績效目標是否具體、可衡量、可控且對齊組織方向，並在期末以證據摘要、評分分布及跨團隊差異支援校準會議，提升績效管理的一致性。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **目標草擬工作台** — 建立目標、衡量方式、權重、期限與預期成果。
- **目標品質檢查** — 檢查明確性、可衡量性、可控性、挑戰度及重複項目。
- **組織目標對齊** — 呈現個人、團隊與公司目標的連結及覆蓋缺口。
- **成果證據整理** — 彙整模擬里程碑、數字成果、回饋與異常背景。
- **評分校準會議** — 比較團隊分布、相似職級案例、評分理由與待議項目。
- **回饋定稿中心** — 整合校準結論、優勢、改善方向與下期行動草稿。

## 適合誰使用

- 員工
- 直屬主管
- 人資績效管理人員

## 運作流程

1. 草擬目標
2. 改善品質
3. 確認對齊
4. 整理證據
5. 進行校準
6. 完成回饋

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
