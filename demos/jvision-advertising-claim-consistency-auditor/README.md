**產業別：**業務銷售　|　**系統類型：**quality-qms

## 功能模組

- **廣告素材盤點** — 彙整各渠道投放中的標題、文案、圖片與行動呼籲。
- **落地頁主張擷取** — 辨識落地頁中的效能、價格、優惠與保證性陳述。
- **產品事實核對** — 逐項比對規格、方案、適用條件與已核准產品事實。
- **承諾關聯圖** — 呈現素材、頁面、產品版本與佐證來源之間的關係。
- **誤導風險修訂** — 標示矛盾、遺漏限定語與過期承諾並產生修訂草案。
- **發布核准台** — 協作審閱修訂內容，核准後更新發布狀態與責任人。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 盤點待稽核素材
2. 擷取頁面承諾
3. 核對產品事實
4. 檢視承諾關聯
5. 協作修訂風險
6. 核准安全發布
