# 客運駕駛資格管制台

> 供客運業者集中管理駕駛執照、職業資格、定期體檢、違規紀錄、教育訓練與可派車狀態，在排班前攔截證照逾期或資格受限的人員。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **駕駛名冊** — 查看人員資格與可派狀態。
- **證照管理** — 維護執照、證書及有效期限。
- **體檢追蹤** — 記錄定期檢查與限制條件。
- **違規審查** — 評估違規事件對派遣的影響。
- **補訓任務** — 安排複訓與資格補正。
- **派遣檢核** — 模擬排班前資格攔截。

## 適合誰使用

- 客運調度員
- 駕駛管理員
- 營運主管

## 運作流程

1. 建立駕駛檔案
2. 檢查到期風險
3. 審查違規影響
4. 安排補件補訓
5. 驗證恢復資格
6. 執行排班檢核

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
