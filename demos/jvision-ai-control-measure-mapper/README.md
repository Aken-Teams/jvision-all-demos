# AI 控制措施映射器

> 把 AI 風險映射至政策、測試、監控與人工監督，找出控制缺口。

把 AI 風險映射至政策、測試、監控與人工監督，找出控制缺口。

**產業別：**資訊安全　|　**系統類型：**security-soc

## 功能模組

- **AI 風險清冊** — 依模型、用途與影響記錄具體 AI 風險情境。
- **風險控制關聯圖** — 將每項風險連結至政策、技術控制與責任單位。
- **控制測試設計** — 定義控制有效性的測試案例、門檻與執行頻率。
- **持續監控配置** — 為關鍵控制設定指標、告警條件與觀測來源。
- **人工監督配置** — 指定需人工審查的節點、權限與升級條件。
- **控制缺口熱圖** — 以風險覆蓋率與控制成熟度排序待改善缺口。

## 適合誰使用

- CISO
- AI 治理主管
- 資安分析師

## 運作流程

1. 界定 AI 風險
2. 映射既有控制
3. 設計有效性測試
4. 配置持續監控
5. 確認人工監督
6. 核准缺口改善

## 導入效益

- 告警分流時間：45分鐘 → **8分鐘**
- 事件平均處理：12小時 → **3小時**
- 弱點修補率：68% → **96%**
- 合規稽核工時：30小時/月 → **6小時/月**
