# 政府補助適配器

> 比對公司條件、補助資格、徵案主題與可列支成本，找出高適配申請案。

比對公司條件、補助資格、徵案主題與可列支成本，找出高適配申請案。

**產業別：**專業服務　|　**系統類型：**finance-case

## 功能模組

- **補助方案清單** — 整理申請期間、補助比例、主題與申請單位限制。
- **企業條件剖面** — 彙整公司規模、產業、證照、實績與研發能力。
- **資格適配矩陣** — 逐條對照申請資格並標示符合、待確認與不符合。
- **主題契合圖譜** — 連結公司技術、計畫構想與政策徵案重點。
- **支出可列支檢查** — 比對預估成本與補助科目，找出不可列支或超限項目。
- **申請缺口清單** — 產生待補證照、佐證文件、合作條件與改善建議。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 選定補助方案
2. 建立企業條件
3. 逐條比對資格
4. 評估主題契合
5. 檢查支出適格性
6. 確認缺口與申請

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
