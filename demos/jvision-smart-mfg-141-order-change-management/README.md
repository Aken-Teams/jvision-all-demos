# 訂單變更管理 Order Change Management預警塔

管理客戶訂單數量、交期或規格異動的申請、影響評估與跨部門同步，降低變更造成的損失。

- 原始系統：訂單變更管理 Order Change Management
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、PMC、採購部、製造工程、財務部
- 工作流程：客戶提出變更需求→影響評估→跨部門會簽→確認變更條件→同步更新訂單→通知相關單位
- AI 應用：變更影響自動模擬評估、高風險變更自動預警
- 主要 KPI：變更處理時效、變更造成損失金額、變更同步及時率、緊急變更比例
- 代表產品：多為ERP客製模組（SAP SD變更管理、鼎新/鼎捷ERP訂單異動模組）
