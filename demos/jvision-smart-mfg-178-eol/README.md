# 料件停產與生命週期管理艙

監控電子料件停產(EOL)公告與生命週期階段，提前規劃備料或轉換替代料，避免斷料衝擊。

- 原始系統：料件停產與生命週期管理系統（EOL）
- 產業分類：智慧製造｜採購管理
- 使用部門：採購部、研發部、品保部、產品管理部
- 工作流程：EOL/PCN公告監控 → 影響BOM分析 → 因應對策擬定 → 末次下單/轉料執行 → 追蹤結案
- AI 應用：AI 自動彙整全球料件停產公告、預測料件剩餘生命週期
- 主要 KPI：EOL預警提前天數、受影響料件轉換完成率、因停產造成停線次數
- 代表產品：SiliconExpert、Z2Data、Total Parts Plus、IHS Markit(S&P Global)
