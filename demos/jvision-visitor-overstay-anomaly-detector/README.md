# 訪客滯留異常偵測器

> 即時辨識訪客逾時、偏離授權區域與未簽退風險，協助行政團隊提升場域安全。

即時辨識訪客逾時、偏離授權區域與未簽退風險，協助行政團隊提升場域安全。

**產業別：**企業協作　|　**系統類型：**security-soc

## 功能模組

- **訪客態勢總覽** — 彙整在場訪客、預定離場時間、所在區域與即時風險等級。
- **逾時訪客偵測** — 比對預約時段、門禁動態與行程變更，找出異常滯留訪客。
- **授權區域偏離** — 偵測訪客進入非授權樓層、敏感空間或偏離核准動線的情形。
- **未簽退追查** — 交叉檢查離場紀錄、門禁事件與接待資訊，鎖定疑似未簽退個案。
- **異常研判工作台** — 以規則與模型混合評分，檢查矛盾資訊並引用企業資料佐證判斷。
- **場域安全處置** — 協調接待、門禁與總務人員執行聯繫、尋訪、升級及安全回滾。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 掌握在場態勢
2. 確認逾時異常
3. 調查區域偏離
4. 追查未簽退者
5. 完成風險研判
6. 協同安全處置

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
