彙整表面黏著製程的錫膏、元件、爐溫與歷史檢驗假資料，呈現虛焊風險評分、可疑板件排序及影響因子，協助品保在抽檢前鎖定高風險批次並追蹤改善結果。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **製程風險總覽** — 以批次、產線與機種呈現虛焊風險分布及今日異常摘要。
- **批次資料建檔** — 建立模擬生產批次並檢視錫膏、爐溫及元件相關欄位。
- **虛焊風險分析** — 顯示板件風險評分、預測結果與主要影響因子。
- **高風險板件排行** — 依風險高低篩選可疑板件，展開位置與缺陷線索。
- **複檢任務管理** — 將可疑板件指派給檢驗人員並模擬填寫確認結果。
- **改善成效追蹤** — 比較改善前後的風險、命中率與缺陷趨勢。

## 適合誰使用

- SMT 製程工程師
- 品保工程師
- 產線主管

## 運作流程

1. 掌握風險
2. 建立批次
3. 執行分析
4. 鎖定板件
5. 完成複檢
6. 驗證改善

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
