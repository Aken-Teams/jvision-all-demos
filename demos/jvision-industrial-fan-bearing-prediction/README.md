# 工業風機軸承故障預測系統

> 運用擬真的振動頻譜、軸承溫度、轉速與負載資料，呈現內外環、滾動體及潤滑異常的風險，預估可用時間並協助維護人員安排潤滑、換件與停機檢修，避免風機突發故障。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **軸承健康總覽** — 呈現風機與各軸承測點的健康分數、風險及運轉狀態。
- **振動頻譜分析** — 展示擬真時域、頻域與特徵頻率，標示異常峰值。
- **故障模式判讀** — 區分內環、外環、滾動體、鬆動及潤滑不良等風險。
- **剩餘壽命預估** — 顯示劣化曲線、預估可用天數與預測信賴區間。
- **維護決策中心** — 比較潤滑、持續觀察與停機換件方案的風險及成本。
- **檢修紀錄追蹤** — 管理任務、換件紀錄、試車結果與後續觀察期限。

## 適合誰使用

- 設備診斷工程師
- 維護主管
- 機修技師

## 運作流程

1. 篩選高風險軸承
2. 分析振動頻譜
3. 判讀故障模式
4. 評估可用時間
5. 選擇維護方案
6. 完成檢修追蹤

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
