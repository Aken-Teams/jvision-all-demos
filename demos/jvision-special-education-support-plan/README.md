# 特教支持計畫協作台

> 協助學校統整特殊教育學生的支持目標、課堂調整、專業服務、會議決議與執行證據，讓導師、特教教師及輔導人員依週期更新進度並準備檢討會議。

協助學校統整特殊教育學生的支持目標、課堂調整、專業服務、會議決議與執行證據，讓導師、特教教師及輔導人員依週期更新進度並準備檢討會議。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **學生總覽** — 呈現支持週期、近期會議與待辦事項。
- **支持目標** — 設定可追蹤目標、指標與檢討日期。
- **課堂調整** — 管理教學、評量及環境支持措施。
- **服務協作** — 安排特教、輔導與專業服務責任。
- **執行紀錄** — 記錄觀察證據及措施完成狀況。
- **檢討會議** — 產生進度摘要並追蹤會議決議。

## 適合誰使用

- 特教教師
- 班級導師
- 輔導主任

## 運作流程

1. 盤點需求
2. 設定目標
3. 配置措施
4. 執行觀察
5. 共同檢討
6. 追蹤決議

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
