# 兼職排班可用時段台

> 集中兼職人員每週可排時段、課表、請假與跨店支援意願，提供版本截止及缺班提醒，讓主管在正式排班前取得可信的可用人力，不再反覆抄群組。

集中兼職人員每週可排時段、課表、請假與跨店支援意願，提供版本截止及缺班提醒，讓主管在正式排班前取得可信的可用人力，不再反覆抄群組。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **週期總覽** — 查看各店回覆與截止日
- **時段填報** — 提交可排不可排及偏好
- **課表請假** — 維護固定與臨時限制
- **衝突檢查** — 辨識重疊超時與跨店
- **缺班媒合** — 尋找可支援人員
- **版本發布** — 封存排班輸入基準

## 適合誰使用

- 兼職員工
- 店主管
- 區域人資

## 運作流程

1. 開放填報
2. 提交時段
3. 補充異動
4. 檢查衝突
5. 補足缺口
6. 發布基準

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
