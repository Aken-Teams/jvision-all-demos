# 材料進場檢驗批次台

> 依到貨批次串接送貨單、材質證明、抽樣要求、檢驗狀態、隔離位置與允收放行，防止文件未齊或尚未檢驗的材料被誤領投入施工。

依到貨批次串接送貨單、材質證明、抽樣要求、檢驗狀態、隔離位置與允收放行，防止文件未齊或尚未檢驗的材料被誤領投入施工。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **到貨建批** — 依送貨單、供應商與批號建立檢驗批。
- **文件核驗** — 檢查材證、型錄、核准文件及有效期限。
- **抽驗安排** — 依規範設定取樣數與送驗要求。
- **待驗隔離** — 標示存放區、禁用原因及保管責任。
- **結果判定** — 彙整外觀、尺寸與試驗結果決定處置。
- **批次放行** — 發布允收、限用、退貨及適用工區。

## 適合誰使用

- 品管工程師
- 倉管人員
- 現場工程師

## 運作流程

1. 建立批次
2. 查驗文件
3. 執行抽樣
4. 隔離保管
5. 判定處置
6. 通知領用

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
