# 壓鑄冷隔缺陷預測系統

> 利用擬真的金屬液溫度、充填時間、澆口速度、模溫及流動路徑，預測壓鑄件冷隔出現的位置與嚴重度，協助製程人員辨識金屬液匯流不良區、比較改善方案並建立首件檢查計畫，降低外觀缺陷與強度不足。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **冷隔風險總覽** — 彙整工單風險、重點料號、待試模方案與近期缺陷趨勢。
- **充填溫度熱圖** — 以工件表面熱圖呈現金屬液前緣溫度、匯流區與冷隔位置。
- **流動路徑分析** — 查看充填順序、流向、末端區及匯流角度，辨識流動異常。
- **冷隔成因診斷** — 排列模溫、液溫、澆口速度與充填時間等關鍵影響因子。
- **改善方案模擬** — 試算調整溫度、速度或澆口條件後的冷隔風險與製程限制。
- **首件檢查計畫** — 建立高風險區檢查點、判定標準、抽樣數量與簽核紀錄。

## 適合誰使用

- 壓鑄製程工程師
- 模具工程師
- 品質工程師與試模主管

## 運作流程

1. 掌握冷隔風險
2. 定位低溫匯流區
3. 檢查充填路徑
4. 研判關鍵成因
5. 模擬改善方案
6. 發布首件檢查

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
