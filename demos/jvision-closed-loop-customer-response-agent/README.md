# 閉環回覆追蹤 Agent

> 改善完成後主動通知受影響客戶並驗證效果，確保每則 VOC 真正閉環。

改善完成後主動通知受影響客戶並驗證效果，確保每則 VOC 真正閉環。

**產業別：**客服管理　|　**系統類型：**service-desk

## 功能模組

- **改善完成偵測** — 從產品發布與工單狀態辨識可對客戶回覆的改善項目。
- **受影響客戶定位** — 依回報、使用路徑與合約資料找出應通知的客戶群。
- **個人化回覆編排** — 引用原始回饋與改善內容，產生符合客戶情境的通知。
- **多渠道通知佇列** — 依偏好與重要性安排郵件、客服訊息及 CSM 親訪。
- **效果確認追問** — 在適當時間詢問問題是否改善，並收集客戶驗證結果。
- **VOC 閉環驗收** — 依回覆、使用數據與未解疑慮判定閉環或重新開案。

## 適合誰使用

- 客戶成功主管
- CSM
- 客服主管

## 運作流程

1. 確認改善完成
2. 圈選受影響客戶
3. 審閱個人化回覆
4. 執行分級通知
5. 追問改善效果
6. 驗收 VOC 閉環

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
