# 機具租賃工時計費台

> 彙整租賃機具每日開工、待機、加班、故障與停租工時，依合約費率產生可核對計費明細，處理現場簽單與廠商月結表差異。

彙整租賃機具每日開工、待機、加班、故障與停租工時，依合約費率產生可核對計費明細，處理現場簽單與廠商月結表差異。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **機具台帳** — 查看設備與租約狀態
- **工時登錄** — 記錄作業待機與加班
- **計費規則** — 設定日租時租及扣款
- **簽單比對** — 比對現場與廠商紀錄
- **租金試算** — 計算應付及爭議金額
- **月結核認** — 簽認可付款明細

## 適合誰使用

- 機具管理員
- 工務工程師
- 應付會計

## 運作流程

1. 建立租約
2. 每日填報
3. 現場簽認
4. 匯入月表
5. 差異核對
6. 付款核准

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
