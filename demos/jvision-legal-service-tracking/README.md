# 法律文件送達追件台

> 依案件期限管理法律文件寄送、受送達人、郵件追蹤、退件原因、補正與再次送達，確保承辦能在法定期限前完成有效送達或替代程序。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **送達文件** — 連結案件文件與期限
- **受送達資料** — 管理地址身分及來源
- **寄送追蹤** — 記錄方式單號與節點
- **簽退收件** — 辨識簽收及退件原因
- **補正重送** — 安排更址與替代方式
- **期限結案** — 確認法律效果並封存

## 適合誰使用

- 法務助理
- 承辦律師
- 案件主管

## 運作流程

1. 建立送達任務
2. 查驗地址身分
3. 完成寄件登錄
4. 監看簽收退件
5. 核定補正措施
6. 覆核有效送達

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
