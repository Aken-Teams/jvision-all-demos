# 車隊臨時換車交接台

> 在故障或臨時調度換車時，將班次、駕駛、票機、隨車設備、乘客特殊需求及遺留物逐項轉移，讓相關站點確認並避免新車缺少必要配置。

在故障或臨時調度換車時，將班次、駕駛、票機、隨車設備、乘客特殊需求及遺留物逐項轉移，讓相關站點確認並避免新車缺少必要配置。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **換車事件** — 記錄原因時限
- **替代車媒合** — 比較車型資格
- **轉移清單** — 列出票機設備
- **乘客需求** — 確認特殊服務
- **交接簽認** — 分工完成移轉
- **班次發布** — 通知站點乘客

## 適合誰使用

- 車隊調度員
- 駕駛員
- 站務主管

## 運作流程

1. 啟動換車
2. 選定替代車
3. 產生清單
4. 執行轉移
5. 交接覆核
6. 發布班次

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
