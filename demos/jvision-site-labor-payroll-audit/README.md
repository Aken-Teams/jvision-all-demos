# 工地人員日報核薪台

> 將領班日報的人員、工種、工區與工數同門禁、停工及分包契約勾稽，辨識重複報工、停工計工及加班差異，經現場簽認後產出核薪依據。

將領班日報的人員、工種、工區與工數同門禁、停工及分包契約勾稽，辨識重複報工、停工計工及加班差異，經現場簽認後產出核薪依據。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **人員日報** — 查看工班人員與工數
- **工區工項** — 指定實作區域及工作內容
- **出勤勾稽** — 比對門禁停工與班表
- **異常工數** — 標記重複雨停及超時
- **現場簽認** — 由工務確認實際投入
- **核薪彙總** — 套用費率並輸出應付

## 適合誰使用

- 工地領班
- 工務人員
- 工程會計

## 運作流程

1. 提交日報
2. 核對工項
3. 勾稽出勤
4. 查明異常
5. 完成簽認
6. 彙總核薪

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
