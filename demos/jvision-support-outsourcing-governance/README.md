# 客服委外履約管理台

> 供企業管理委外客服團隊的服務範圍、人力承諾、品質抽查、SLA 違約、改善計畫與月度驗收，建立供應商履約及費用扣抵依據。

供企業管理委外客服團隊的服務範圍、人力承諾、品質抽查、SLA 違約、改善計畫與月度驗收，建立供應商履約及費用扣抵依據。

**產業別：**客服管理　|　**系統類型：**service-desk

## 功能模組

- **服務契約** — 維護服務範圍、指標與扣款條款。
- **人力承諾** — 比對排班承諾與實際投入。
- **品質抽查** — 建立抽樣、評分與覆核結果。
- **SLA 違約** — 彙整逾時事件與排除條件。
- **改善計畫** — 追蹤根因、行動與複驗期限。
- **月度驗收** — 確認績效、扣抵與應付金額。

## 適合誰使用

- 客服營運主管
- 品保專員
- 採購窗口

## 運作流程

1. 設定契約
2. 核對人力
3. 執行抽查
4. 認定違約
5. 追蹤改善
6. 完成驗收

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
