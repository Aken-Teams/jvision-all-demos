**產業別：**資訊科技　|　**系統類型：**security-soc

## 功能模組

- **參數契約檢查** — 依 MCP 與 Skill Schema 驗證欄位、型別及允許值。
- **呼叫配額控制** — 按工具、Agent、租戶與時段配置速率及用量上限。
- **敏感欄位遮罩** — 辨識憑證與個資，於送出前遮蔽或代換。
- **工具風險審批** — 依操作風險與資料範圍決定自動核准或人工簽核。
- **異常呼叫解析** — 偵測偏離基線的參數與頻率並推斷可能成因。
- **安全開放測試** — 以模擬請求驗證政策效果後發布可用工具。

## 適合誰使用

- 平台架構師
- 整合工程師
- AI 應用開發者

## 運作流程

1. 載入契約
2. 設定配額
3. 配置遮罩
4. 編排審批
5. 模擬攔截
6. 發布閘道
