# 工程模擬與設計空間探索平台

> 以純介面模擬電腦輔助工程分析流程，讓工程師設定參數、建立批次案例、查看代理模型預測與設計空間分布，快速比較性能、成本及限制條件下的候選方案。

以純介面模擬電腦輔助工程分析流程，讓工程師設定參數、建立批次案例、查看代理模型預測與設計空間分布，快速比較性能、成本及限制條件下的候選方案。

**產業別：**AI 工程平台　|　**系統類型：**analytics-bi

## 功能模組

- **模擬專案總覽** — 管理分析目標、模型版本、案例進度與品質摘要。
- **參數空間設定** — 定義幾何、材料、負載參數及上下限與限制。
- **虛擬實驗設計** — 以擬真方式產生具代表性的參數案例組合。
- **代理模型分析** — 呈現訓練樣本、預測誤差與特徵影響程度。
- **設計空間探索** — 互動篩選性能、成本及約束下的可行區域。
- **候選方案決選** — 並排比較方案指標、敏感度與選擇理由。

## 適合誰使用

- 模擬工程師
- 機構工程師
- 研發主管
- 產品設計師

## 運作流程

1. 建立專案
2. 定義參數
3. 規劃案例
4. 檢視模型
5. 探索空間
6. 選定方案
