# 多語接待 Agent

> 以多語自助報到、即時通知與智慧導覽，減少櫃台接待負擔。面向總務主管與行政團隊，把高頻工作集中在可執行工作台中。

**產業別：**企業協作　|　**系統類型：**operations-console

## 功能模組

- **多語迎賓台** — 依訪客語言與來訪目的提供個人化問候及操作指引。
- **訪客報到站** — 核對預約、身分與同意事項，完成報到及識別證發放。
- **受訪者通知** — 透過企業通訊與電話通知受訪者，追蹤回應及到場時間。
- **室內導覽** — 依會議室、門禁與無障礙需求產生多語路線指引。
- **接待問答** — 回答停車、網路、設施與訪客規範等現場常見問題。
- **接待監控台** — 呈現等候、失聯及導覽異常，建議行政人員優先介入。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 選擇語言
2. 核驗預約
3. 完成報到
4. 通知接待人
5. 引導赴會
6. 確認交接

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
