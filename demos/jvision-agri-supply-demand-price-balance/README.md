# 農產供需與產銷預警系統

> 整合模擬生產預估、批發行情、訂單需求、庫存及通路促銷資料，分析農產品供需缺口與價格波動，提供滯銷、缺貨及產銷失衡預警，協助產銷組織提早調整採收、集貨與通路配置。

## 功能模組

- **產銷總覽** — 呈現品項供需、價格、庫存及風險燈號。
- **供給預估** — 按產區與週期查看預估產量、可售庫存及上市節奏。
- **需求分析** — 分析訂單、通路需求、促銷計畫與需求缺口。
- **價格行情** — 比較模擬市場行情、歷史區間與價格驅動因素。
- **失衡預警** — 辨識滯銷、缺貨、價格急變及集中上市風險。
- **調節模擬** — 試算轉單、促銷、調貨與採收調整的平衡效果。

## 適合誰使用

- 產銷班經理
- 合作社供銷人員
- 通路採購與市場分析員

## 運作流程

1. 檢視產銷態勢
2. 確認供給節奏
3. 分析通路需求
4. 研判價格趨勢
5. 處理失衡預警
6. 發布調節方案
