**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **療程權益** — 記錄購買次數效期與店別
- **療程預約** — 預留次數與治療時段
- **到診確認** — 核對病人與可用權益
- **治療核銷** — 由治療師確認實際服務
- **補課跨店** — 處理請假補回與轉用
- **差異調查** — 核對紙卡系統及退款

## 適合誰使用

- 復健櫃台
- 治療師
- 營運主管

## 運作流程

1. 建立療程權益
2. 預留療程額度
3. 完成病人到診
4. 確認治療執行
5. 處理權益異動
6. 覆核餘額結清

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
