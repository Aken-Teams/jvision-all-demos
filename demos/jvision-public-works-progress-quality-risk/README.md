# 公共工程品質風險監理台

> 集中呈現公共工程契約里程碑、模擬施工進度、查驗紀錄、缺失改善與風險事件，協助監造及主辦機關比對計畫與實績、追蹤品質缺失、研判延誤影響並形成督導與履約管理紀錄。

集中呈現公共工程契約里程碑、模擬施工進度、查驗紀錄、缺失改善與風險事件，協助監造及主辦機關比對計畫與實績、追蹤品質缺失、研判延誤影響並形成督導與履約管理紀錄。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **工程總覽** — 彙整進度、品質、契約、風險及近期督導事項。
- **進度監控** — 以甘特圖比較預定與實際工項及關鍵路徑。
- **品質查驗** — 管理查驗批次、檢驗結果、照片樣本與判定。
- **缺失改善** — 追蹤缺失分級、責任單位、改善期限及複驗。
- **風險監理** — 評估工期、成本、品質與履約事件的機率及衝擊。
- **督導報告** — 彙整現況、重大差異、改善要求與會議決議。

## 適合誰使用

- 機關工程承辦人
- 監造工程師
- 專案經理與品質管理人員

## 運作流程

1. 掌握工程狀態
2. 分析進度落差
3. 執行品質查驗
4. 追蹤缺失改善
5. 研判履約風險
6. 發布督導結論

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
