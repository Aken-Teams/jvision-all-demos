# 透析療程排班紀錄台

> 供透析院所安排固定療程、床位與照護人力，記錄治療前評估、療程參數、異常事件及耗材使用，並追蹤未到與補作安排，形成完整班次作業紀錄。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **療程班表** — 安排固定班次與臨時補作
- **床位配置** — 配置床位、時段與照護人力
- **療前核對** — 確認體重、醫囑及風險事項
- **療程紀錄** — 記錄參數、觀察與處置內容
- **異常事件** — 通報低血壓等療程異常
- **耗材核算** — 彙整班次耗材與差異用量

## 適合誰使用

- 透析護理師
- 護理長
- 腎臟科醫師

## 運作流程

1. 安排療程
2. 配置床位
3. 療前核對
4. 記錄療程
5. 處理異常
6. 班次結算

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
