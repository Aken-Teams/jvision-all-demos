# 預力施拉灌漿管制台

> 管理後拉法預力工程的鋼絞線批次、混凝土強度放行、千斤頂校驗、逐束施拉讀值、伸長量判定、切索封錨及孔道灌漿，形成每一束可追溯的施工履歷。

管理後拉法預力工程的鋼絞線批次、混凝土強度放行、千斤頂校驗、逐束施拉讀值、伸長量判定、切索封錨及孔道灌漿，形成每一束可追溯的施工履歷。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **預力束台帳** — 管理束號、鋼絞線批次與設計值。
- **施拉放行** — 檢核混凝土強度及施工前條件。
- **設備校驗** — 維護千斤頂與壓力表配對曲線。
- **施拉紀錄** — 登錄分級油壓、伸長量與回縮值。
- **偏差判定** — 比對理論值並追蹤異常束處置。
- **封錨灌漿** — 記錄切索、封錨及孔道灌漿成果。

## 適合誰使用

- 預力工程師
- 品管工程師
- 預力班組

## 運作流程

1. 建立束號
2. 確認放行
3. 配對設備
4. 分級施拉
5. 判定偏差
6. 封錨灌漿

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
