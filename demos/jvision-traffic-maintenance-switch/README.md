# 交維階段切換管制台

> 供道路與地下工程管理各階段交通維持切換，整合核准交維圖、封路許可、管線單位回覆、告示通知、設施布設與夜間復原查驗，降低切換當晚臨時停工風險。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **階段圖台** — 管理各期交維範圍、動線與核准圖。
- **許可清單** — 追蹤封路、挖掘與夜間施工效期。
- **通知管理** — 記錄住戶、警政及管線單位通知。
- **設施布設** — 派工標誌、護欄、號誌與照明配置。
- **切換查驗** — 逐點核對布設成果與缺失。
- **道路開放** — 記錄復原、核准與實際開放時間。

## 適合誰使用

- 交維工程師
- 工地主任
- 監造工程師

## 運作流程

1. 規劃階段
2. 確認許可
3. 完成通知
4. 現場布設
5. 聯合查驗
6. 核准開放

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
