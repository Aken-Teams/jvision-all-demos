# 土方車次棄土聯單台

> 供開挖工地逐車配發土方聯單，核對車牌、土質、估方、出場與合法收容場回證，攔截未回單、異常繞行及重複計價車次。

供開挖工地逐車配發土方聯單，核對車牌、土質、估方、出場與合法收容場回證，攔截未回單、異常繞行及重複計價車次。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **車次看板** — 追蹤出入場狀態
- **聯單配發** — 建立車牌土質資料
- **估方核對** — 比較車斗與磅重
- **回證驗收** — 核對收容場簽章
- **異常車次** — 處理逾時與錯場
- **運費結算** — 排除缺單重複車

## 適合誰使用

- 土方工程師
- 警衛人員

## 運作流程

1. 開立聯單
2. 裝車確認
3. 門禁放行
4. 收容簽收
5. 回單核驗
6. 車次結算

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
