## 功能模組

- **重複文件叢集** — 依語意與結構相似度聚合跨系統近似文件。
- **段落差異比對** — 逐段標出共通內容、衝突說法與獨有資訊。
- **權威版本判定** — 依來源、核准狀態、更新時間與引用量推薦主版本。
- **整併草稿編輯** — 選擇保留段落並解決術語、規則與附件衝突。
- **版本關係建模** — 設定取代、衍生、適用範圍與歷史版本關係。
- **整併發布控制** — 核准主版本並更新連結、搜尋結果與舊文件提示。

## 適合誰使用

- 知識工作者
- 主管
- 客服

## 運作流程

1. 選取重複叢集
2. 檢查內容差異
3. 指定權威版本
4. 完成整併草稿
5. 確認版本關係
6. 核准整併發布

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
