# 存貨成本與呆滯料提列系統（Inventory Costing & Obsolescence Provision System）

> 應收付、現金流到預算的財務即時掌握

存貨成本與呆滯料提列系統（Inventory Costing & Obsolescence Provision System）提供存貨計價法設定(移動平均/先進先出)、呆滯料齡分析(Aging by SKU)、呆滯/跌價損失提列計算。會計專員、會計主管、財務會計主管依「存貨計價法設定(移動平均/先進先出)、呆滯料齡分析(Aging by SKU)、呆滯/跌價損失提列計算」推進作業，優先解決「料號眾多呆滯風險難以即時掌握」，部門主管則以存貨成本與呆滯料提列協作所處理結果確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**財務會計　|　**系統類型：**財務會計系統

## 功能模組

- **應收帳款** — 開立、對帳與催收
- **應付帳款** — 請款、付款與對帳
- **現金流** — 資金調度與預測
- **預算管理** — 編列、控管與差異分析
- **固定資產** — 資產登錄與折舊
- **總帳傳票** — 傳票、拋轉與月結

## 適合誰使用

- 會計專員
- 會計主管
- 財務會計主管

## 運作流程

1. 待上架
2. 銷售中
3. 覆核確認
4. 已結案

## 導入效益

- 月結作業天數：6.2天 → **2天**
- 對帳錯誤：8.2件/月 → **1件/月**
- 帳款逾期率：15% → **4.7%**
- 報表產出工時：16小時 → **1.1小時**
