# 工地罰款責任認定台

> 集中登錄交通、環保、職安及契約罰款，追蹤通知日期、申覆期限、事證與責任對象，經會簽後決定公司吸收、分包扣款或個人負擔。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **罰款案件總覽** — 依類型、工地、金額與期限查看案件。
- **裁罰文件登錄** — 保存通知、法條、照片與送達資訊。
- **申覆期限管理** — 計算期限並提示待備文件。
- **責任事證調查** — 彙整人車、工班、指示與現場紀錄。
- **歸責會簽** — 決定申覆、吸收、扣款或個人負擔。
- **付款扣款追蹤** — 追蹤繳款、分包扣回及結案差額。

## 適合誰使用

- 工地主任
- 法務人員
- 財務人員

## 運作流程

1. 登錄裁罰案件
2. 盤點申覆期限
3. 蒐集責任資料
4. 評估申覆方案
5. 完成責任會簽
6. 執行財務結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
