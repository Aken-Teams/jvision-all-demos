# 工地抽排水放流管制台

> 管理地下開挖與施工積水的抽排水申請、沉澱處理、放流路徑及水質檢查，連結雨前整備、異常濁水處置與承包商責任，讓現場在排放前完成條件確認並保留環保稽查佐證。

管理地下開挖與施工積水的抽排水申請、沉澱處理、放流路徑及水質檢查，連結雨前整備、異常濁水處置與承包商責任，讓現場在排放前完成條件確認並保留環保稽查佐證。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **水情總覽** — 呈現積水區、沉澱設施、排水路徑與申請狀態。
- **抽排申請** — 登錄來源、預估水量、設備、時段及責任工班。
- **放流路徑** — 標示沉澱流程、排放口與周邊敏感位置。
- **排放檢核** — 記錄外觀、水質、沉澱容量與設備條件。
- **排放巡查** — 保存起訖時間、現場照片與排水狀況。
- **異常停排** — 處理濁水、溢流、堵塞與民眾通報事件。

## 適合誰使用

- 職安環保人員
- 土方工程師
- 抽排水工班領班

## 運作流程

1. 提出抽排需求
2. 確認處理路徑
3. 執行放流檢核
4. 核准啟動排放
5. 巡查排放過程
6. 處理異常結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
