# 契約工項超量預警台

> 將現場完成量、歷期估驗量、契約數量與已核准變更額度並列，提前辨識即將超量或已無可計價額度的工項，促使工務在繼續施作前啟動變更、留證或成本控管。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **契約額度** — 查看原契約、變更與各工項可用數量。
- **完成量回報** — 彙整現場完成、估驗認列與待確認數量。
- **超量預警** — 依剩餘比例及施工趨勢分級提示風險。
- **指示佐證** — 連結業主指示、圖說與現場照片。
- **處置決策** — 選擇停做、變更、吸收或爭議保留方案。
- **曝險分析** — 追蹤各專案未核准超量數量與金額。

## 適合誰使用

- 成本工程師
- 工地主任
- 合約管理員

## 運作流程

1. 載入契約額度
2. 彙整實際完成量
3. 產生超量預警
4. 補充施工依據
5. 核定處置方案
6. 追蹤額度轉正

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
