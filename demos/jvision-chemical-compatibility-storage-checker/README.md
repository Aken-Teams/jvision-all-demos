# 化學相容性存放檢查器

> 依 SDS 與實際庫位辨識化學品不相容共置，協助實驗室降低事故風險。

依 SDS 與實際庫位辨識化學品不相容共置，協助實驗室降低事故風險。

**產業別：**研發管理　|　**系統類型：**quality-qms

## 功能模組

- **化學品庫位圖** — 以儲櫃、層架與相鄰距離呈現試劑實際存放位置。
- **SDS 危害解析** — 抽取 SDS 中的危害分類、禁忌物與建議儲存條件。
- **共置衝突掃描** — 比對庫位鄰近關係並找出可能反應或污染的組合。
- **相容性判定台** — 顯示衝突規則、化學實體、風險分數與模型信心。
- **移置方案規劃** — 模擬替代庫位並產生兼顧分區與容量的調整方案。
- **安全案件追蹤** — 建立高風險整改案件，指派責任人並追蹤複核結案。

## 適合誰使用

- 實驗室主管
- 研究員
- 技術員

## 運作流程

1. 盤點存放現況
2. 解析危害資訊
3. 掃描不相容共置
4. 審查風險依據
5. 核准移置方案
6. 執行並複核結案
