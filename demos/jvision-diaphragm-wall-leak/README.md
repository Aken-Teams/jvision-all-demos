# 連續壁接頭滲漏處置台

> 以連續壁單元與接頭編號定位地下室滲漏，記錄水量、壓力、灌注材料、鑽孔配置與每次處置成效，避免不同班組重複施工，並以觀察期確認止水是否穩定。

以連續壁單元與接頭編號定位地下室滲漏，記錄水量、壓力、灌注材料、鑽孔配置與每次處置成效，避免不同班組重複施工，並以觀察期確認止水是否穩定。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **壁體漏點圖** — 依單元、接頭與高程定位滲漏。
- **水勢分級** — 記錄滴水、湧水及環境狀態。
- **處置方案** — 規劃鑽孔、材料、壓力與施工順序。
- **灌注紀錄** — 填報每孔時間、壓力及實際用量。
- **觀察追蹤** — 按日記錄乾燥狀態與復發情形。
- **成效分析** — 比較工法、材料與漏點改善成果。

## 適合誰使用

- 地下工程師
- 防水領班
- 監造工程師

## 運作流程

1. 定位漏點
2. 判定水勢
3. 核定方案
4. 執行灌注
5. 持續觀察
6. 驗收結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
