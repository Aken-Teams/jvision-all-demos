將虛構的電話、文字、影像描述與單位回報整合為災情事件，協助去重、定位、分級及建立受影響範圍，再依模擬救援隊伍、車輛、物資與道路狀況提出調度方案，支援指揮、回報與解除追蹤。

**產業別：**交通運輸　|　**系統類型：**operations-console

## 功能模組

- **災情收件** — 集中顯示虛構電話、文字、影像描述與單位回報。
- **通報融合** — 比對位置、時間與內容，合併重複或關聯事件。
- **災情態勢圖** — 呈現事件位置、影響範圍、道路限制與風險熱區。
- **事件分級** — 依人命、規模與擴大可能性設定救援優先序。
- **資源調度** — 配對隊伍、車輛、物資、集結點與替代路線。
- **任務追蹤** — 管理派遣、到場、處置、增援、回報及解除狀態。

## 適合誰使用

- 災害應變中心值勤員
- 災情研判員
- 救援調度員與現場指揮官

## 運作流程

1. 接收災情通報
2. 融合關聯事件
3. 建立災情態勢
4. 判定救援優先序
5. 派遣救援資源
6. 追蹤任務解除
