# 工程技能路徑推薦器

> 依實際程式碼與任務能力缺口，推薦可在工作中完成的工程學習路徑。

依實際程式碼與任務能力缺口，推薦可在工作中完成的工程學習路徑。

**產業別：**資訊科技　|　**系統類型：**education-lms

## 功能模組

- **程式能力剖面** — 從提交、審查與測試成果分析已展現的工程技能。
- **任務缺口診斷** — 比對即將承接的任務，找出需要補強的實作能力。
- **成長路徑設計** — 依職涯目標與工作需求排列循序漸進的技能節點。
- **實作挑戰配對** — 把真實待辦、技術債與測試任務轉成可控的學習挑戰。
- **導師協作站** — 安排審查者、配對夥伴與 Agent 輔導，設定升級條件。
- **能力驗證檔案** — 以合併成果、測試品質與回饋證明技能已能在工作中運用。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 建立能力剖面
2. 找出任務缺口
3. 編排成長路徑
4. 承接實作挑戰
5. 接受導師協作
6. 驗證能力成長
