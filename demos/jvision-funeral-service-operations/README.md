# 禮儀服務履約管理台

> 供禮儀公司管理治喪案件、家屬需求版本、場次時程、用品服務、禮儀人員分工與追加費用，讓短時間且不可延誤的多方協作具備清楚交接與核對依據。

供禮儀公司管理治喪案件、家屬需求版本、場次時程、用品服務、禮儀人員分工與追加費用，讓短時間且不可延誤的多方協作具備清楚交接與核對依據。

**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **治喪案件** — 集中家屬聯絡與服務需求
- **日程編排** — 安排治喪期間各項場次
- **用品清單** — 核對花禮文書及儀式用品
- **人員分工** — 配置禮儀師司儀與場務
- **現場檢核** — 依時間點確認服務就緒
- **費用結案** — 核對方案、追加與代墊項目

## 適合誰使用

- 禮儀顧問
- 場務主管
- 行政人員

## 運作流程

1. 建立案件
2. 確認方案
3. 排定日程
4. 備妥資源
5. 執行檢核
6. 完成結案

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
