# 餐飲外送帳款核對台

> 彙整各外送平台訂單、取消、折扣、廣告費與撥款明細，讓連鎖餐飲逐店核對應收差異、提出申覆並完成會計認列。

**產業別：**餐飲旅宿　|　**系統類型：**finance-ledger

## 功能模組

- **結算匯入** — 整理平台訂單與撥款批次。
- **訂單配對** — 比對門市銷售與平台結算資料。
- **折扣拆分** — 辨識品牌、平台及門市負擔金額。
- **差異處理** — 分類漏單、退款、費率及廣告費異常。
- **申覆追蹤** — 彙整證據並追蹤平台回覆結果。
- **帳款認列** — 確認實收並產出會計結轉摘要。

## 適合誰使用

- 餐飲財務
- 通路營運
- 門市督導

## 運作流程

1. 匯入平台結算
2. 配對門市訂單
3. 拆分活動負擔
4. 調查結算差異
5. 提出平台申覆
6. 完成帳款認列

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
