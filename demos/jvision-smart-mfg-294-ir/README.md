# 投資人關係管理系統（IR）

> 把分散數據變成可下鑽、可決策的經營洞察

投資人關係管理系統（IR）提供法人會議與財報發布排程管理、投資人問答資料庫、股價/市場輿情監控。投資人關係部依「財報彙整 → 法說會準備 → 法人溝通 → 輿情監控 → 重大訊息公告 → 效益檢討」推進作業，優先解決「法人溝通紀錄分散難追蹤」，財務部則以法人溝通滿意度與重大訊息即時揭露率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**經營管理　|　**系統類型：**BI 商業智慧

## 功能模組

- **經營儀表板** — 關鍵指標即時總覽
- **趨勢分析** — 多維度趨勢與比較
- **指標下鑽** — 逐層鑽取到明細
- **平衡計分卡** — 策略目標與 KPI 對齊
- **AI 洞察** — 自動發現異常與機會
- **報表匯出** — 排程報表與分享

## 適合誰使用

- 投資人關係部
- 財務部
- 發言人室
