**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **優化任務設定** — 選擇工件、材料與機台，設定效率、品質及成本的優化目標。
- **參數限制管理** — 設定轉速、進給、切深、負載與表面品質的可接受範圍。
- **候選方案生成** — 以擬真演算法產生多組參數建議並標示預估效益與風險。
- **多目標方案比較** — 用圖表比較加工週期、刀具壽命、能耗、負載及品質分數。
- **試切結果模擬** — 模擬不同方案的加工曲線、品質結果及可能異常情境。
- **參數版本審核** — 保存參數版本、變更差異與審核狀態，供現場依核准版執行。

## 適合誰使用

## 運作流程

1. 建立優化任務
2. 定義安全限制
3. 產生候選參數
4. 比較方案效益
5. 模擬試切結果
6. 核准參數版本
