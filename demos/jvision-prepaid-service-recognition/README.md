# 預收服務履約核銷台

> 依預收方案、贈送堂數、展延、跨店使用與實際服務逐次核銷履約義務，區分收款與收入認列，提供退款時可追溯的剩餘權益基礎。

依預收方案、贈送堂數、展延、跨店使用與實際服務逐次核銷履約義務，區分收款與收入認列，提供退款時可追溯的剩餘權益基礎。

**產業別：**生活服務　|　**系統類型：**finance-ledger

## 功能模組

- **方案台帳** — 記錄收款堂數與效期
- **權益組成** — 區分購買贈送與展延
- **服務核銷** — 逐次匹配實際履約
- **跨店差異** — 核對門店回報與歸屬
- **退款試算** — 計算剩餘可退基礎
- **收入認列** — 依履約產生會計批次

## 適合誰使用

- 門店營運
- 財務會計
- 方案管理員

## 運作流程

1. 建立預收方案
2. 匯入收款權益
3. 彙整服務紀錄
4. 處理權益異動
5. 執行履約核銷
6. 認列收入結案

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
