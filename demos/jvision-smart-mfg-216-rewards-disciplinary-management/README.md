# 獎懲考核管理智慧站

記錄員工獎懲事件、簽核流程與累積紀錄，作為考核、續聘與升遷之客觀依據。

- 原始系統：獎懲考核管理系統（Rewards & Disciplinary Management）
- 產業分類：智慧製造｜人資管理
- 使用部門：人資部、產線主管、稽核部、勞資關係窗口
- 工作流程：事件通報 → 主管簽核 → 人資審核 → 獎懲紀錄建檔 → 員工確認/申訴 → 定期統計分析
- AI 應用：違規事件模式分析與熱點部門標記、獎懲公平性偏誤偵測
- 主要 KPI：獎懲案件處理時效、申訴成立率、重複違規率、獎懲紀錄完整度
- 代表產品：鼎新HR獎懲模組、104人資King獎懲管理、企業自建電子簽核系統整合
