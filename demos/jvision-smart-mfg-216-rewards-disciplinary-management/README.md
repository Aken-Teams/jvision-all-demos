# 獎懲考核管理系統（Rewards & Disciplinary Management）

> 應收付、現金流到預算的財務即時掌握

獎懲考核管理系統（Rewards & Disciplinary Management）提供獎懲事件申請與簽核流程、獎懲點數累積與抵免規則、違規案件調查紀錄。人資部依「事件通報 → 主管簽核 → 人資審核 → 獎懲紀錄建檔 → 員工確認/申訴 → 定期統計分析」推進作業，優先解決「紙本獎懲紀錄易遺失或竄改」，產線主管則以獎懲案件處理時效與申訴成立率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**財務會計系統

## 功能模組

- **應收帳款** — 開立、對帳與催收
- **應付帳款** — 請款、付款與對帳
- **現金流** — 資金調度與預測
- **預算管理** — 編列、控管與差異分析
- **固定資產** — 資產登錄與折舊
- **總帳傳票** — 傳票、拋轉與月結

## 適合誰使用

- 人資部
- 產線主管
- 稽核部

## 運作流程

1. 待處理
2. 主管確認
3. 人資執行
4. 歸檔完成

## 導入效益

- 薪資作業工時：38小時/月 → **7.5小時/月**
- 出勤異常處理：28分鐘 → **4.7分鐘**
- 招募到位天數：42天 → **26天**
- 表單簽核時效：2.8天 → **0.9天**
