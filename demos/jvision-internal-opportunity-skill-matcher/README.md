# 內部機會技能媒合器

> 以可轉移技能媒合專案、輪調與職缺，提升人才被看見及內部流動機會。

以可轉移技能媒合專案、輪調與職缺，提升人才被看見及內部流動機會。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **可轉移技能剖析** — 從成果與任務辨識員工可跨職務運用的技能組合。
- **內部機會池** — 集中呈現專案支援、短期任務、輪調與正式職缺。
- **人機會適配器** — 計算技能鄰近度、發展意願、可用時間與地點適配。
- **職涯轉移路徑** — 顯示從現職到目標機會的可行路徑與待補技能。
- **人才短名單** — 讓主管比較候選人的匹配理由、證據與團隊互補性。
- **流動協議中心** — 協調原部門、用人部門與員工的投入比例及轉任條件。

## 適合誰使用

- L&D 主管
- 部門主管
- 員工

## 運作流程

1. 建立技能輪廓
2. 發布內部機會
3. 產生適配推薦
4. 探索轉移路徑
5. 審選媒合人選
6. 確認流動安排

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
