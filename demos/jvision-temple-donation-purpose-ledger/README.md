# 宮廟指定捐款管理台

> 協助宮廟區分建廟、慈善、香油與特定法務等捐款用途，管理收據、專款餘額、支用申請及信眾查詢紀錄，確保指定款項不被混用。

協助宮廟區分建廟、慈善、香油與特定法務等捐款用途，管理收據、專款餘額、支用申請及信眾查詢紀錄，確保指定款項不被混用。

**產業別：**宗教服務　|　**系統類型：**finance-ledger

## 功能模組

- **捐款登記** — 記錄信眾、金額與指定用途。
- **收據管理** — 處理編號、補發與作廢紀錄。
- **專款帳冊** — 顯示用途別收入、支出及餘額。
- **支用申請** — 檢查支出是否符合指定目的。
- **信眾查詢** — 依收據或聯絡資料查找紀錄。
- **監事報表** — 產生用途別收支及異常摘要。

## 適合誰使用

- 廟務行政
- 出納人員
- 監事

## 運作流程

1. 接受捐款
2. 開立收據
3. 歸入專款
4. 提出支用
5. 審核支用
6. 揭露報表

## 導入效益

- 活動籌備工時：20小時 → **5小時**
- 報名掌握率：65% → **94%**
- 物資盤點：6小時 → **1小時**
- 志工調度時效：3天 → **1天**
