# 餐飲原料退貨折讓台

> 串起門店原料拒收或退貨、供應商簽收、補貨及折讓單，核對數量、發票與帳款是否一致，協助採購在月結前追齊未折帳款並處理爭議。

串起門店原料拒收或退貨、供應商簽收、補貨及折讓單，核對數量、發票與帳款是否一致，協助採購在月結前追齊未折帳款並處理爭議。

**產業別：**餐飲旅宿　|　**系統類型：**procurement-srm

## 功能模組

- **退貨建案** — 登錄原料批次與原因
- **簽收證據** — 保存照片與供應商簽認
- **補貨追蹤** — 查看替換品到貨結果
- **折讓勾稽** — 配對發票與折讓文件
- **爭議協調** — 處理數量品質及價格差異
- **帳款結清** — 確認扣款與月結狀態

## 適合誰使用

- 驗收人員
- 採購人員
- 應付會計

## 運作流程

1. 提出退貨
2. 完成交接
3. 確認補貨
4. 追收折讓
5. 處理爭議
6. 完成結清

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
