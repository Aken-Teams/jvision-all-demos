**產業別：**採購供應鏈　|　**系統類型：**logistics-fleet

## 功能模組

- **路徑目標設定** — 設定到貨期限、成本上限、風險容忍度與碳排權重。
- **候選路徑生成** — 依產地、商品與訂單條件建立可行的港口、航段及報關組合。
- **落地成本試算** — 拆解運費、關稅、保險、資金占用與轉運費用。
- **路徑風險推演** — 模擬延誤、制裁、港口壅塞與交易方異常對交付的影響。
- **多目標路徑排序** — 以可解釋分數比較時間、成本、風險及碳排取捨。
- **改道核准驗證** — 送審選定路徑、同步運輸安排並驗證預期改善成果。

## 適合誰使用

- 國貿主管
- 報關人員
- 業務

## 運作流程

1. 定義選路目標
2. 建立可行路徑
3. 核算落地成本
4. 推演中斷情境
5. 選定建議路徑
6. 核准改道並驗證

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
