# 工地停工區復工放行台

> 管理局部停工範圍、原因、改善項目、複驗證據及相關工班，只有責任角色逐項簽認後才發布復工版本，避免工班空等或未改善便自行進場。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **停工區域** — 標示範圍原因與工班
- **改善清單** — 分派缺失與完成期限
- **改善證據** — 上傳施工前後與測試結果
- **復工複驗** — 逐項檢查解除條件
- **放行核准** — 發布有效復工版本
- **工班通知** — 確認各班組收悉與進場

## 適合誰使用

- 工地主任
- 安衛人員
- 分包領班

## 運作流程

1. 劃定停工
2. 分派改善
3. 提交證據
4. 執行複驗
5. 核准復工
6. 通知進場

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
