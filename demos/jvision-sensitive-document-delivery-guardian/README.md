## 功能模組

- **寄送文件建案** — 建立寄件目的、文件清單、預定收件人與交付期限。
- **敏感內容辨識** — 辨識個資、合約、財務與機密標示，判定文件敏感等級。
- **收件資格核驗** — 比對通訊錄、合約關係與授權名單，確認收件方身分。
- **加密方式配置** — 依敏感等級建議檔案加密、密碼分送與存取期限。
- **安全寄送選擇** — 選擇掛號、專人遞送或安全連結，設定簽收與追蹤條件。
- **寄送放行作業** — 彙整檢查結果供核准，放行後產生追蹤編號與交付紀錄。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 建立寄送案件
2. 辨識敏感內容
3. 核驗收件資格
4. 設定加密保護
5. 確認寄送方式
6. 核准並放行

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
