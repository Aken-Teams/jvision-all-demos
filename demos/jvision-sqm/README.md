# 供應商品質管理 SQM

> 供應商協同、詢比議價到交期風險控管

Jvision SQM 供應商品質管理平台，展示採購收料、IQC 檢驗、供應商文件、綠色產品資料與評鑑稽核流程。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**SRM 採購供應商管理

## 功能模組

- **供應商管理** — 建檔、分級與績效評分
- **詢報價協作** — 線上詢價、比價與議價
- **採購訂單** — 請購、下單與交期追蹤
- **交期風險** — 缺料預警與到貨監控
- **供應商品質** — 進料檢驗與 SCAR 改善
- **綠色採購** — ESG 評分與永續採購

## 適合誰使用

- 品保工程師
- 品質經理
- 廠長

## 運作流程

1. 建立供應商品質管理 SQM資料
2. Jvision SQM 供應商品質管理平台，展示採購收料、IQC 檢驗、供應商文件、綠色產品資料與評鑑稽核流程
3. 確認結果並完成留存

## 導入效益

- 批號追溯時間：187分鐘 → **15分鐘**
- 客訴平均關案：21天 → **8.6天**
- 改善驗證率：64% → **92%**
