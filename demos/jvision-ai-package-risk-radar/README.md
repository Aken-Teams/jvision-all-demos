# AI 套件風險雷達

持續監測推論框架、插件與 Agent 工具弱點，協助團隊優先完成修補。

**產業別：**資訊安全　|　**系統類型：**security-soc

## 功能模組

- **AI 套件資產圖** — 盤點推論框架、插件、Agent 工具及其部署位置。
- **相依關係圖譜** — 呈現模型服務與套件、版本、工具權限之間的關係。
- **弱點曝險雷達** — 彙整已知漏洞、惡意套件與供應鏈風險訊號。
- **可利用性研判** — 結合執行路徑與權限判斷弱點能否在環境中被利用。
- **修補方案工作台** — 比較升級、移除、隔離與補償控制對服務的影響。
- **修補驗證中心** — 重新掃描套件並確認弱點、相依衝突與功能回歸已排除。

## 適合誰使用

- CISO
- AI 治理主管
- 資安分析師

## 運作流程

1. 建立套件資產圖
2. 解析相依關係
3. 比對弱點訊號
4. 確認可利用風險
5. 核准修補方案
6. 驗證修補成果

## 導入效益

- 告警分流時間：45分鐘 → **8分鐘**
- 事件平均處理：12小時 → **3小時**
- 弱點修補率：68% → **96%**
- 合規稽核工時：30小時/月 → **6小時/月**
