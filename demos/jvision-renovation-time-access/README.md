# 社區裝修時段放行台

> 集中管理住戶裝修申請、工班名冊、施工禁限時段、證件押領與材料進場，讓警衛換班後仍可依核准版本正確放行並記錄違規。

集中管理住戶裝修申請、工班名冊、施工禁限時段、證件押領與材料進場，讓警衛換班後仍可依核准版本正確放行並記錄違規。

**產業別：**房地產與物業　|　**系統類型：**operations-console

## 功能模組

- **裝修申請** — 登錄戶別工項與期間
- **工班名冊** — 維護人員車輛及證件
- **時段管制** — 檢查禁限時與衝突
- **門崗放行** — 顯示當班可放行清單
- **證件押領** — 追蹤證件與門禁卡
- **違規處置** — 記錄超時損壞及通知

## 適合誰使用

- 物業管理員
- 警衛人員
- 裝修承辦

## 運作流程

1. 提出裝修申請
2. 審核施工條件
3. 核定工班名冊
4. 門崗查驗放行
5. 登記退場結果
6. 處理違規結案

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
