# 電梯井道逐層移交台

> 逐樓層檢核電梯井道淨尺寸、門洞、底坑、防水、吊鉤、電源及施工防護，將土建缺失與電梯廠進場條件集中處理，避免只簽總表後才逐層發現無法安裝。

逐樓層檢核電梯井道淨尺寸、門洞、底坑、防水、吊鉤、電源及施工防護，將土建缺失與電梯廠進場條件集中處理，避免只簽總表後才逐層發現無法安裝。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **梯井總覽** — 依梯號呈現各樓層移交狀態。
- **尺寸實測** — 記錄井道、門洞與底坑實測值。
- **條件檢核** — 檢查吊鉤、電源、防水及防護。
- **缺失派工** — 將偏差與未完成項目指派責任工種。
- **改善複驗** — 比對改善前後證據及量測結果。
- **正式移交** — 由土建與電梯廠共同簽認工作面。

## 適合誰使用

- 機電工程師
- 土建工程師
- 電梯廠商

## 運作流程

1. 建立梯井
2. 逐層實測
3. 條件會勘
4. 派發改善
5. 完成複驗
6. 簽認移交

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
