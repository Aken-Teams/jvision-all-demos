# 商品主檔衝突仲裁台

> 集中採購、電商與門市對商品條碼、容量、品牌及分類的衝突提案，透過欄位級裁定和同步驗證，避免錯誤資料批次污染各通路。

集中採購、電商與門市對商品條碼、容量、品牌及分類的衝突提案，透過欄位級裁定和同步驗證，避免錯誤資料批次污染各通路。

**產業別：**零售電商　|　**系統類型：**erp

## 功能模組

- **商品總覽** — 查看標準商品與來源。
- **欄位衝突** — 比對條碼、規格與分類。
- **來源證據** — 保存包裝及供應商資料。
- **欄位裁定** — 指定黃金值及理由。
- **同步派送** — 追蹤各系統更新狀態。
- **結果驗證** — 確認頁面與門市正確。

## 適合誰使用

- 商品管理員
- 採購主管
- 電商營運

## 運作流程

1. 彙入主檔
2. 偵測衝突
3. 補充證據
4. 執行裁定
5. 發布同步
6. 驗證結果

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
