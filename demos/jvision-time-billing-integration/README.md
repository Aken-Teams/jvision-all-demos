# 工時開票介接補漏台

> 比對核准工時與開票系統匯入結果，定位顧問代碼、費率或客戶鍵值失敗，防止人工補單後原批次重送造成漏開或重複開票。

比對核准工時與開票系統匯入結果，定位顧問代碼、費率或客戶鍵值失敗，防止人工補單後原批次重送造成漏開或重複開票。

**產業別：**專業服務　|　**系統類型：**it-ops

## 功能模組

- **批次異常** — 顯示匯入失敗與部分成功
- **逐筆勾稽** — 比較核准工時與開票項
- **代碼對映** — 修正顧問客戶與費率鍵
- **補單鏈路** — 串起原批次與人工單
- **安全重送** — 模擬防重後執行補送
- **開票覆核** — 確認草稿總額與明細

## 適合誰使用

- 計費專員
- 系統營運人員
- 財務主管

## 運作流程

1. 接收工時批次
2. 比對缺漏明細
3. 修正主檔對映
4. 還原補單鏈路
5. 執行安全補送
6. 覆核發票結果

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
