# AI 使用目的登錄站

> 督促各部門登錄 AI 用途、資料範圍、責任人與期限，補足治理責任。

督促各部門登錄 AI 用途、資料範圍、責任人與期限，補足治理責任。

**產業別：**資訊安全　|　**系統類型：**security-soc

## 功能模組

- **用途申報台** — 建立 AI 使用目的、業務情境與預期成果申報。
- **資料範圍盤點** — 標記輸入資料、敏感等級、保存位置與使用限制。
- **責任人指派** — 確認業務、技術、資料與風險責任人的承擔關係。
- **期限承諾表** — 設定試用、複審、停用與資料刪除期限。
- **未登錄用途偵測** — 比對 AI 流量與申報紀錄，找出影子 AI 使用。
- **治理補件佇列** — 依風險排序缺漏項目並送交部門補件或主管核准。

## 適合誰使用

- CISO
- AI 治理主管
- 資安分析師

## 運作流程

1. 發現未申報使用
2. 建立用途申報
3. 盤點使用資料
4. 指定治理責任
5. 設定有效期限
6. 驗證登錄閉環

## 導入效益

- 告警分流時間：45分鐘 → **8分鐘**
- 事件平均處理：12小時 → **3小時**
- 弱點修補率：68% → **96%**
- 合規稽核工時：30小時/月 → **6小時/月**
