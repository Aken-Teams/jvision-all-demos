# 客運代車調度應變台

> 供客運業者在車輛臨時故障、定檢延長或事故停駛時，依路線班次、車型座位、駕駛資格與回廠位置挑選代車，評估受影響班次並發布替代配置方案。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **停駛事件** — 登錄故障車、位置與預估停駛時間。
- **可用車池** — 篩選座位、車型與所在場站。
- **替換模擬** — 試排代車及後續班次連鎖影響。
- **資格檢核** — 確認駕駛可駕車型與工時限制。
- **場站通知** — 發布換車、月台及旅客應對資訊。
- **復駛追蹤** — 追蹤維修完成及車輛歸隊安排。

## 適合誰使用

- 車輛調度員
- 站務主管
- 維修協調員

## 運作流程

1. 通報停駛
2. 盤點代車
3. 模擬替換
4. 確認人車
5. 發布異動
6. 恢復配置

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
