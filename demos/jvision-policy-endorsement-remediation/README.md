## 功能模組

- **清件清單** — 列出必要文件
- **缺漏圈選** — 標示頁次簽章
- **補正通知** — 產生客戶要求
- **版本比較** — 辨識新舊內容
- **生效時限** — 監控預定日期
- **清件核准** — 確認可辦批改

## 運作流程

1. 建立批改
2. 檢查文件
3. 通知補正
4. 驗證版本
5. 核對生效
6. 核准送辦

- 案件平均處理：7天 → **3天**
