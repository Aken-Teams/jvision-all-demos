# 視覺回歸語意裁判

> 以版面語意與互動影響裁決視覺差異，區分可接受變更與功能缺陷。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **視覺差異收件匣** — 依頁面、元件與風險彙整基準圖及候選圖差異。
- **版面語意分解器** — 辨識元件角色、內容層級與響應式重排的語意結構。
- **關鍵內容遮擋檢查** — 檢測按鈕、表單、提示與主要內容是否被裁切或覆蓋。
- **互動可用性驗證** — 判斷差異是否影響點擊目標、焦點順序與操作流程。
- **語意差異裁決台** — 將差異判為預期變更、可接受偏移或真實功能缺陷。
- **基準圖治理中心** — 核准更新基準、建立缺陷或調整視覺測試容忍規則。

## 適合誰使用

## 運作流程

1. 分流視覺差異
2. 解析版面語意
3. 檢查內容遮擋
4. 驗證互動影響
5. 裁決差異性質
6. 核准後續處置
