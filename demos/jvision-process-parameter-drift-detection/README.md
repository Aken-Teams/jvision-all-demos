# 製程參數漂移監測台

> 監測擬真製程參數相對於基準區間的緩慢偏移，區分短暫波動與持續漂移，並從產品、設備和配方版本切分比較，協助工程人員在品質超規前完成確認、調整及復歸追蹤。

監測擬真製程參數相對於基準區間的緩慢偏移，區分短暫波動與持續漂移，並從產品、設備和配方版本切分比較，協助工程人員在品質超規前完成確認、調整及復歸追蹤。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **漂移監測總覽** — 顯示各線別參數的穩定度、漂移數量與風險分級。
- **參數趨勢分析** — 以控制界線及基準帶呈現參數緩慢偏移的歷程。
- **基準群組比較** — 比較設備、產品、班別與配方版本之間的參數分布。
- **漂移事件中心** — 集中管理新發生、持續中、已確認與已復歸的漂移事件。
- **影響範圍評估** — 列出可能受影響的工單、批次、品質指標及下游站點。
- **復歸措施追蹤** — 記錄調整內容、責任人與參數回穩後的觀察結果。

## 適合誰使用

- 製程工程師
- 設備工程師
- 製造主管

## 運作流程

1. 監看參數穩定度
2. 判讀漂移趨勢
3. 比較基準群組
4. 確認漂移事件
5. 評估影響範圍
6. 執行復歸追蹤

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
