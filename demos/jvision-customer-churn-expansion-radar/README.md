# 客戶流失擴張預警台

> 彙整擬真的交易、互動、客服與產品使用訊號，辨識可能流失的客戶及加購、續約或升級機會，並用可解釋的風險因子與建議任務協助客戶團隊安排優先行動。

**產業別：**數據分析　|　**系統類型：**analytics-bi

## 功能模組

- **客群雷達總覽** — 以風險和擴張潛力矩陣呈現客群分布、重要變化及待處理帳戶。
- **流失預警清單** — 依風險分數、合約價值與到期日排序，顯示主要警訊及建議優先級。
- **客戶訊號時間軸** — 整合擬真交易、登入、客服與拜訪事件，解釋風險升降原因。
- **擴張機會探索** — 辨識加購、升級、跨部門導入與續約延伸機會，估算潛在價值。
- **行動任務中心** — 建立挽留或擴張計畫，指派負責人、期限、話術與下一步。
- **成效回顧分析** — 比較預警命中、任務完成、續約與擴張結果，檢視策略成效。

## 適合誰使用

- 客戶成功經理
- 業務主管
- 續約專員與營運分析師

## 運作流程

1. 觀察客群
2. 篩選預警
3. 診斷訊號
4. 評估機會
5. 執行行動
6. 回顧成效
