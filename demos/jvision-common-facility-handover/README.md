# 公共設施點交管制台

> 依公共空間與設備系統整合實體查驗、測試紀錄、鑰匙備品、操作文件及缺失改善，支援營造廠向業主或管委會分區點交，清楚呈現每一區尚缺什麼才能正式移交。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **公設區域總覽** — 依空間與系統顯示待查驗、待補件及已移交狀態。
- **聯合點交清單** — 整合建築、機電、消防與景觀的查驗項目。
- **設備測試紀錄** — 彙整試運轉結果、見證人與測試附件。
- **鑰匙備品文件** — 清點鑰匙、遙控器、耗材、手冊及保固資料。
- **缺失改善** — 指派責任廠商並追蹤修繕及複驗結果。
- **正式移交** — 產生點交紀錄、保留事項與雙方簽認清冊。

## 適合誰使用

- 交屋主管
- 機電工程師
- 管委會點交代表

## 運作流程

1. 建立點交範圍
2. 整備測試文件
3. 執行聯合查驗
4. 派發點交缺失
5. 辦理缺失複驗
6. 完成分區移交

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
