# 學籍異動跨處室簽辦台

> 將休退學、復學、轉系等學籍異動串連教務、財務、宿舍、圖書與兵役會辦，追蹤欠款、退費及生效學期，避免紙本漏章與後續資料錯誤。

將休退學、復學、轉系等學籍異動串連教務、財務、宿舍、圖書與兵役會辦，追蹤欠款、退費及生效學期，避免紙本漏章與後續資料錯誤。

**產業別：**教育　|　**系統類型：**collaboration-pm

## 功能模組

- **異動申請** — 受理類型與生效學期
- **會辦路徑** — 依異動類型派送處室
- **資格清件** — 檢查欠款資產與資格
- **費用處理** — 試算學費宿舍退補款
- **學籍核定** — 確認生效日與異動結果
- **結果發布** — 通知學生及相關系統

## 適合誰使用

- 註冊組承辦
- 處室會辦人員
- 學生事務主管

## 運作流程

1. 受理異動申請
2. 啟動跨處室會辦
3. 完成欠項清件
4. 核算退補費用
5. 核定學籍異動
6. 發布異動結果

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
