# 實習媒合履約管理台

> 供技專院校管理企業實習名額、學生志願、資格審查、面談媒合與實習期間文件，並追蹤訪視、異常通報及學分完成條件。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **企業名額** — 管理職缺條件、期間與企業窗口。
- **學生申請** — 檢核資格、志願與申請文件。
- **媒合面談** — 安排推薦、面談與錄取結果。
- **履約文件** — 追蹤合約、保險及家長文件。
- **訪視輔導** — 記錄教師訪視與學生回饋。
- **成果認定** — 檢核時數、評量與學分條件。

## 適合誰使用

- 實習承辦人
- 系所教師
- 職涯中心主管

## 運作流程

1. 建立企業名額
2. 審核學生申請
3. 安排媒合面談
4. 完成履約文件
5. 執行訪視輔導
6. 認定實習成果

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
