**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **案件總覽** — 掌握治喪節點、缺口與風險。
- **接案建檔** — 記錄家屬需求及服務方案。
- **治喪時程** — 安排儀式、場地與重要期限。
- **用品配置** — 確認用品規格、數量及交付。
- **協力調度** — 管理宗教師與供應商承諾。
- **結案核算** — 彙整變更、成本與家屬確認。

## 適合誰使用

- 禮儀師
- 案件助理
- 營運主管

## 運作流程

1. 查看案件
2. 建立方案
3. 排定時程
4. 配置用品
5. 確認協力
6. 完成結案

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
