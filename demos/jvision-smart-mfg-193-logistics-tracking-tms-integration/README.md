# 物流追蹤與TMS整合指揮台

串接承運商與貨況追蹤資訊，提供出貨後在途可視性與運輸成本管理。

- 原始系統：物流追蹤與TMS整合系統（Logistics Tracking / TMS Integration）
- 產業分類：智慧製造｜倉儲管理
- 使用部門：物流部、業務部、財務部、客服部
- 工作流程：出貨叫車→承運商取貨→在途追蹤→到貨確認→運費核對→客戶通知
- AI 應用：到貨時間預測、運輸異常風險預警
- 主要 KPI：準時到貨率、運輸成本占比、貨況查詢回應時效、運輸異常率
- 代表產品：Oracle Transportation Management、SAP TM、project44、FourKites
