# 帷幕牆錨栓查驗台

> 依立面分區管理帷幕牆預埋件與後置錨栓的位置、埋深、拉拔試驗及偏差處置，確保封板或安裝骨架前完成抽驗並留下可追溯紀錄。

依立面分區管理帷幕牆預埋件與後置錨栓的位置、埋深、拉拔試驗及偏差處置，確保封板或安裝骨架前完成抽驗並留下可追溯紀錄。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **立面分區** — 依軸線與格位呈現錨栓查驗狀態。
- **安裝登錄** — 記錄錨栓型式、位置、埋深與照片。
- **尺寸覆核** — 比對設計座標及現場安裝偏差。
- **拉拔試驗** — 建立抽驗批次並登錄荷重結果。
- **偏差處置** — 送審補強或替代固定方案。
- **立面放行** — 核對合格紀錄後開放骨架安裝。

## 適合誰使用

- 帷幕牆工程師
- 品管工程師
- 監造工程師

## 運作流程

1. 建立格位
2. 登錄安裝
3. 覆核偏差
4. 執行抽驗
5. 處理異常
6. 分區放行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
