## 功能模組

- **套件授權盤點** — 彙整產品版本中的開源套件、授權版本與相依關係。
- **分發模式建模** — 定義雲端服務、內部部署、裝置韌體等實際交付方式。
- **授權義務圖譜** — 將授權條款、相依路徑與分發行為映射為義務關係。
- **義務缺口比對** — 找出原始碼揭露、聲明附帶與再授權等未滿足事項。
- **合規方案審核** — 比較替換套件、調整分發或補齊文件等處置方案。
- **發布合規閘門** — 核准義務清單並將限制同步至 CI/CD 發布流程。
