# 設備能耗監控預警塔

針對個別生產設備進行能耗即時監控與分析之細粒度能源管理系統。

- 原始系統：設備能耗監控系統（Equipment Energy Monitoring System）
- 產業分類：智慧製造｜製造管理
- 使用部門：設備工程、廠務、永續發展部門
- 工作流程：設備能耗數據採集 → 能效分析比較 → 異常/待機浪費辨識 → 節能對策執行 → 效益追蹤
- AI 應用：AI辨識高耗能異常設備、智慧建議設備排程降低尖峰負載
- 主要 KPI：設備單位能耗、待機能耗占比、節能效益金額
- 代表產品：Schneider Electric PME（Power Monitoring Expert），多為EMS模組延伸功能
