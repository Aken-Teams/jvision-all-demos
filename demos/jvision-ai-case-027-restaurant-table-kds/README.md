# 餐飲桌位出單站 KDS

> 桌位地圖、點餐開單到廚房 KDS 出單的內外場一體化

串接桌位、點餐、廚房出單與營收分析。把外場、廚房與收銀散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**餐飲旅宿　|　**系統類型：**桌位出單站 KDS

## 功能模組

- **桌位管理** — 桌況地圖：空桌 / 用餐中 / 待清理 / 已訂位
- **點餐開單** — 帶位開桌、選菜加註並送單至廚房
- **廚房出單站 KDS** — 待製作 / 製作中 / 待出餐三欄工單看板
- **訂位候位** — 線上訂位與現場候位叫號管理
- **結帳翻桌** — 分帳、折扣、收款與桌位釋出
- **營運報表** — 營收、翻桌率與熱銷分析

## 適合誰使用

- 外場服務員
- 廚房線上人員
- 外場主管

## 運作流程

1. 帶位開桌
2. 點餐送廚
3. 廚房製作出餐
4. 送餐服務
5. 結帳翻桌

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：67% → **88%**
- 備料浪費：16% → **5.6%**
- 訂位掌握率：66% → **98%**

## 畫面

1. 營運總覽 — KPI、桌位地圖、廚房出單摘要與逾時關注
2. 桌位管理 — 分區桌位地圖（A / B / C / VIP），依狀態著色與座位數
3. 點餐開單 — 菜單分類、品項選擇與開單工單（特殊需求加註）
4. 廚房出單 KDS — 待製作 / 製作中 / 待出餐三欄看板，逾時工單以紅色標示（計時為靜態示範文字）
5. 訂位候位 — 今日訂位清單與現場候位叫號
6. 營運報表 — 各時段營收、用餐型態佔比、熱銷排行與結帳明細
