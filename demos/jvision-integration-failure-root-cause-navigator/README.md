# 整合故障根因導航器

> 串聯 Agent、Gateway、API 與後端事件，快速定位整合故障的真正斷點。

串聯 Agent、Gateway、API 與後端事件，快速定位整合故障的真正斷點。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **跨層事件拓撲** — 重建 Agent 到後端系統的完整呼叫與依賴路徑。
- **故障時間線對齊** — 將提示、工具呼叫、Gateway 與後端日誌依時間校準。
- **身分授權診斷** — 檢查憑證、Token、Scope、角色與租戶邊界。
- **請求傳遞追蹤** — 追查參數轉換、Schema 映射、重試與回應變形。
- **根因候選推理** — 依事件因果與既知模式排序最可能的故障來源。
- **修復驗證導航** — 執行安全重播驗證修復，失敗時升級或回滾。

## 適合誰使用

- 平台架構師
- 整合工程師
- AI 應用開發者

## 運作流程

1. 選取故障案例
2. 對齊事件時間線
3. 排查授權鏈
4. 追蹤請求傳遞
5. 鎖定根因
6. 驗證修復

## 導入效益

- 事件平均處理：120分鐘 → **30分鐘**
- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
- 資產盤點工時：20小時/月 → **4小時/月**
