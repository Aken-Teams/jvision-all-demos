# 員工服務案件分流助理

> 將請假、薪資、福利、證明、門禁及資訊需求等員工問題分類，判斷急迫度、責任單位與所需資料，先提供可核對的自助指引，再把複雜案件送往正確窗口並追蹤時限。

將請假、薪資、福利、證明、門禁及資訊需求等員工問題分類，判斷急迫度、責任單位與所需資料，先提供可核對的自助指引，再把複雜案件送往正確窗口並追蹤時限。

**產業別：**人力資源　|　**系統類型：**service-desk

## 功能模組

- **員工服務入口** — 以生活化分類引導員工描述問題並查看熱門服務。
- **問題理解與補問** — 摘要員工需求，提示缺少的日期、身分或附件等資料。
- **智慧分類分流** — 建議服務類別、急迫度、責任單位與處理時限。
- **自助解決指引** — 提供政策摘要、操作步驟、表單清單與適用條件。
- **承辦案件工作台** — 呈現待接案、處理中、待員工回覆與即將逾期案件。
- **服務品質分析** — 分析案件量、轉派、解決時間、熱門問題與知識缺口。

## 適合誰使用

- 一般員工
- 人資服務人員
- 總務與資訊窗口

## 運作流程

1. 提出需求
2. 補齊資訊
3. 確認分流
4. 嘗試自助
5. 承辦處理
6. 改善服務

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
