# 殯儀設施檔期協調台

> 供禮儀公司集中安排禮廳、冰存、火化與接運等設施時段，檢查治喪流程的前後銜接及文件條件，協助承辦人處理檔期衝突、候補方案與家屬確認。

供禮儀公司集中安排禮廳、冰存、火化與接運等設施時段，檢查治喪流程的前後銜接及文件條件，協助承辦人處理檔期衝突、候補方案與家屬確認。

**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **設施檔期總覽** — 查看禮廳、冰存與火化時段。
- **治喪節點編排** — 安排接運至火化的先後關係。
- **衝突方案比較** — 比較改期對其他節點的影響。
- **候補檔期追蹤** — 管理候補順位及確認期限。
- **文件條件清單** — 核對申請各設施所需文件。
- **家屬確認紀錄** — 保存方案確認與變更同意。

## 適合誰使用

- 禮儀承辦
- 設施聯絡員
- 營運主管

## 運作流程

1. 建立案件
2. 編排節點
3. 查詢檔期
4. 比較方案
5. 備妥文件
6. 確認檔期

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
