## 功能模組

- **過期候選佇列** — 依久未更新、規則變更與失效引用排列內容。
- **時效依據檢查** — 比對生效日、產品版本及相關政策的最新狀態。
- **複核通知中心** — 向內容擁有者發送含期限與建議處置的通知。
- **內容複核工作台** — 選擇續用、修訂、封存或需專家判定。
- **替代內容配對** — 推薦可接替舊內容的權威文件並檢查覆蓋差異。
- **封存與導向發布** — 核准封存、建立重新導向並更新所有引用關係。

## 適合誰使用

- 知識工作者
- 主管
- 客服

## 運作流程

1. 鎖定過期候選
2. 驗證失效依據
3. 通知內容負責人
4. 決定處置方式
5. 確認替代內容
6. 核准封存導向

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
