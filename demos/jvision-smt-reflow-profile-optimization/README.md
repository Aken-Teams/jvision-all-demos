## 功能模組

- **回焊製程總覽** — 呈現產品配方、曲線達標率、異常區段及待最佳化任務。
- **溫度曲線分析** — 疊加目標窗口與擬真量測曲線，檢視各測點溫度變化。
- **製程窗口檢核** — 檢查升溫斜率、恆溫時間、液相時間及峰值溫度限制。
- **曲線偏差診斷** — 定位過熱、升溫不足與測點差異，整理可能影響條件。
- **爐溫方案試算** — 模擬各溫區設定與輸送速度對曲線、品質及能耗的影響。
- **配方版本管理** — 比較模擬配方版本，記錄核准狀態、適用產品與預期成效。
