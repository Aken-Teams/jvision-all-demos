# 工程試體送驗鏈管台

> 以試體編號串起取樣位置、製作人員、養護條件、交接運送、試驗排程、報告回收與不合格處置，避免標籤抄錯、漏送或報告無法對應施工區段。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **試體編碼** — 建立取樣區段、材料批次與試驗齡期編號。
- **製作養護** — 記錄製作時間、人員及養護條件。
- **交接送驗** — 保存送件箱號、交付時間與雙方簽收。
- **試驗排程** — 依齡期安排試驗並預警假日或逾期。
- **報告回收** — 核對報告編號、數值及試體關聯。
- **異常處置** — 對低強度、破損或遺失啟動複驗調查。

## 適合誰使用

- 品管工程師
- 試驗人員
- 實驗室窗口

## 運作流程

1. 建立編號
2. 製作養護
3. 封箱交接
4. 實驗室收件
5. 回傳報告
6. 判讀結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
