# 工程測量儀器校驗台

> 集中管理全站儀、水準儀、雷射儀等測量設備的校驗效期、工地領用、日常自檢、異常停用及送校履歷，避免使用逾期或碰撞失準儀器產生整批放樣誤差。

集中管理全站儀、水準儀、雷射儀等測量設備的校驗效期、工地領用、日常自檢、異常停用及送校履歷，避免使用逾期或碰撞失準儀器產生整批放樣誤差。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **儀器台帳** — 管理設備編號、型式與目前所在工地。
- **校驗證書** — 保存校驗日期、效期與合格文件。
- **領用調撥** — 記錄領用人、工區與跨案移轉。
- **日常自檢** — 填報基準點檢測與容許差結果。
- **異常停用** — 處理碰撞、摔落與讀值漂移事件。
- **成果回溯** — 圈定異常期間需重新檢核的測量點。

## 適合誰使用

- 測量主管
- 測量工程師
- 工務所管理員

## 運作流程

1. 建置台帳
2. 申請領用
3. 執行自檢
4. 通報異常
5. 停用送校
6. 回溯成果

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
