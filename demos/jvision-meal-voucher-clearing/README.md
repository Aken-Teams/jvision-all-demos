# 餐券核銷清算作業台

> 整合門店餐券核銷、券號驗證、發行商送件與退件追蹤，逐日勾稽收銀資料及應收款，避免重複核銷、券種誤選或逾期未請款。

**產業別：**餐飲旅宿　|　**系統類型：**finance-ledger

## 功能模組

- **核銷登錄** — 彙整門店券號與消費資料。
- **券號驗證** — 檢查重複、效期及券種。
- **收銀勾稽** — 比對券面額與收銀折抵。
- **清算送件** — 依發行商建立請款批次。
- **退件補正** — 處理缺件與錯誤券號。
- **回款核對** — 確認入帳與未收差額。

## 適合誰使用

- 門店收銀
- 財務專員
- 營運主管

## 運作流程

1. 彙入核銷
2. 驗證券號
3. 勾稽營收
4. 建立送件
5. 補正退件
6. 核銷回款

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
