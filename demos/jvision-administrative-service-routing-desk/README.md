**產業別：**企業協作　|　**系統類型：**service-desk

## 功能模組

- **多管道需求受理** — 集中接收郵件、表單與對話中的行政服務請求。
- **行政需求辨識** — 判斷門禁、郵務、座位、修繕、用車或用品等需求類別。
- **服務據點配對** — 依員工位置、服務範圍與營業時間選出負責據點。
- **服務商能力配對** — 按技能、合約、可用時段與服務評價選擇內外部承辦方。
- **案件派工協調** — 設定優先級、承諾時間與負責人，遇到高風險需求送人工確認。
- **服務履約追蹤** — 追蹤接單、到場、處理與員工驗收，逾時即主動催辦。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 受理員工需求
2. 辨識服務類別
3. 選定服務據點
4. 配對合適服務商
5. 確認並派工
6. 追蹤服務結案

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
