# 關鍵技能流失預警器

> 結合人才離職風險與知識集中度，找出高衝擊技能缺口並提前安排傳承。

結合人才離職風險與知識集中度，找出高衝擊技能缺口並提前安排傳承。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **關鍵技能圖譜** — 映射關鍵任務、技能、專家與業務成果之間的依賴。
- **人才流失預測** — 綜合任職、績效與流動訊號評估關鍵人才風險。
- **知識集中偵測** — 找出僅少數人掌握且缺乏替代者的高集中技能。
- **衝擊缺口排序** — 依流失機率、替補時間與營運衝擊排列傳承優先級。
- **接班覆蓋設計** — 為關鍵技能配置接班人、導師與最低備援覆蓋。
- **傳承任務追蹤** — 追蹤影子學習、實作驗證與知識移交的完成度。

## 適合誰使用

- L&D 主管
- 部門主管
- 員工

## 運作流程

1. 建立技能依賴
2. 評估人才風險
3. 量測知識集中
4. 排序衝擊缺口
5. 配置接班覆蓋
6. 完成技能傳承

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
