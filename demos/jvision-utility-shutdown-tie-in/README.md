# 管線停供銜接作業台

> 協調既有水電、消防或弱電系統的停供與新舊管線銜接，管理影響戶、隔離範圍、復歸測試及通知回條，降低誤停、漏通知與復供失敗。

協調既有水電、消防或弱電系統的停供與新舊管線銜接，管理影響戶、隔離範圍、復歸測試及通知回條，降低誤停、漏通知與復供失敗。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **停供排程** — 管理系統、區域與核准停供時窗。
- **隔離規劃** — 標示閥件、盤體及新舊管線銜接點。
- **影響通知** — 追蹤受影響單位通知及回覆狀態。
- **作業放行** — 核對人員、備援與復歸條件。
- **切換紀錄** — 依步驟回報隔離、施工與復供時間。
- **測試結案** — 登錄功能測試、異常及業主簽認。

## 適合誰使用

- 機電工程師
- 工地主任
- 業主設施人員

## 運作流程

1. 提出停供
2. 盤點影響
3. 完成會簽
4. 發布通知
5. 執行切換
6. 測試簽認

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
