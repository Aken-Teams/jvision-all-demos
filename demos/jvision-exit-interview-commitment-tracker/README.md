# 離職承諾改善追蹤台

> 將離職面談中可行的管理改善承諾轉成具名任務，去識別化彙整重複原因，追蹤責任主管、期限與改善證據，避免面談完成後問題只停留在報告。

將離職面談中可行的管理改善承諾轉成具名任務，去識別化彙整重複原因，追蹤責任主管、期限與改善證據，避免面談完成後問題只停留在報告。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **議題總覽** — 查看去識別化離職主因
- **原因歸類** — 合併重複且可行動議題
- **改善承諾** — 建立責任人期限與成果
- **進度追蹤** — 檢視逾期阻礙和證據
- **成效驗證** — 比較行動前後指標
- **管理報告** — 呈現趨勢與未解風險

## 適合誰使用

- 人資夥伴
- 部門主管
- 管理階層

## 運作流程

1. 彙整議題
2. 確認原因
3. 承諾行動
4. 追蹤執行
5. 驗證成效
6. 管理檢討

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
