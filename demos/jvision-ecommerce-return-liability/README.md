# 電商退貨到倉判責台

> 串起退貨到倉、開箱驗貨、缺件拍照、責任判定與退款放行，協助倉管、客服及採購釐清顧客使用、錯寄或供應商瑕疵，避免誤退款與求償失據。

**產業別：**零售電商　|　**系統類型：**warehouse-wms

## 功能模組

- **到倉收件** — 建立退貨件與訂單關聯
- **開箱驗貨** — 記錄外觀功能與配件
- **證據整理** — 標註照片及缺損位置
- **責任判定** — 選定責任方與判定依據
- **退款放行** — 核准退款或暫緩處理
- **求償追蹤** — 追供應商平台補償結果

## 適合誰使用

- 退貨倉管
- 客服主管
- 採購人員

## 運作流程

1. 退貨收件
2. 執行驗貨
3. 建立證據
4. 會簽判責
5. 放行退款
6. 追蹤求償

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
