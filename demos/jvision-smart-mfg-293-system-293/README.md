# 股東會管理系統

> 把分散數據變成可下鑽、可決策的經營洞察

股東會管理系統提供股東會議程與議案管理、電子投票與視訊股東會支援、股東通知與公告自動發送。股務部依「議案規劃 → 股東通知 → 報到登記 → 開會表決 → 計票統計 → 議事錄申報」推進作業，優先解決「股東會籌備作業繁瑣且耗時」，法務部則以股東會籌備時效與電子投票參與率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**經營管理　|　**系統類型：**BI 商業智慧

## 功能模組

- **經營儀表板** — 關鍵指標即時總覽
- **趨勢分析** — 多維度趨勢與比較
- **指標下鑽** — 逐層鑽取到明細
- **平衡計分卡** — 策略目標與 KPI 對齊
- **AI 洞察** — 自動發現異常與機會
- **報表匯出** — 排程報表與分享

## 適合誰使用

- 股務部
- 法務部
- 投資人關係部

## 運作流程

1. 待釐清
2. 改善中
3. 核定確認
4. 已解除

- 決策資料覆蓋：52% → **86%**
