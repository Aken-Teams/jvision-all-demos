# 基準進度改版管制台

> 管理契約基準、核定修正版與內部趕工版的進度差異，要求每次改版說明工期、關鍵路徑及責任影響，避免用覆蓋舊檔方式失去延誤分析依據。

管理契約基準、核定修正版與內部趕工版的進度差異，要求每次改版說明工期、關鍵路徑及責任影響，避免用覆蓋舊檔方式失去延誤分析依據。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **版本總覽** — 並列契約、核定與內控進度版本。
- **差異比較** — 比對日期、工期、邏輯與完成比例。
- **關鍵路徑** — 檢視改版前後關鍵及次關鍵工項。
- **改版說明** — 逐項填寫調整原因與責任影響。
- **版本審批** — 會簽工地、專案與合約管理意見。
- **基準發布** — 凍結核准版並通知適用日期。

## 適合誰使用

- 排程工程師
- 專案經理
- 工地主任

## 運作流程

1. 匯入新版
2. 比較差異
3. 分析影響
4. 說明原因
5. 審核版本
6. 發布凍結

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
