# 鞋面外發成套回收台

> 供製鞋廠按鞋型、顏色與尺碼將裁片成套交付外發車縫廠，追蹤分批回貨、補片與不良返修，避免總數正確卻因單一尺碼短少無法配雙。

供製鞋廠按鞋型、顏色與尺碼將裁片成套交付外發車縫廠，追蹤分批回貨、補片與不良返修，避免總數正確卻因單一尺碼短少無法配雙。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **尺碼矩陣** — 查看各碼送回數
- **外發裝袋** — 建立袋號與數量
- **在外追蹤** — 顯示加工廠進度
- **回貨點收** — 分批核對色碼
- **成套配雙** — 找出單只短缺
- **加工核銷** — 排除短少不良量

## 適合誰使用

- 外發管理員
- 鞋面倉管員

## 運作流程

1. 裁片成套
2. 外發點交
3. 在外加工
4. 分批回貨
5. 配套補缺
6. 費用核銷

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
