# 貨櫃滯期費防控台

> 追蹤進出口貨櫃的免費使用期限、提櫃還櫃節點、文件阻塞與客戶責任，依預估費率排序急迫案件，協助物流業者在產生滯箱或滯港費前完成處置。

追蹤進出口貨櫃的免費使用期限、提櫃還櫃節點、文件阻塞與客戶責任，依預估費率排序急迫案件，協助物流業者在產生滯箱或滯港費前完成處置。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **貨櫃期限總覽** — 集中顯示免費期與急迫程度。
- **費率規則試算** — 依船公司規則估算累積費用。
- **阻塞原因處理** — 分類文件、查驗與派車問題。
- **提還櫃排程** — 安排提櫃、拆櫃及還櫃任務。
- **責任歸屬紀錄** — 保留客戶與協力商責任證據。
- **費用結案核對** — 比對帳單、豁免及還櫃證明。

## 適合誰使用

- 海運操作員
- 車務調度
- 帳務人員

## 運作流程

1. 建立貨櫃
2. 試算期限
3. 辨識阻塞
4. 安排提還
5. 確認責任
6. 核對結案

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
