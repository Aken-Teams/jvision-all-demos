**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **估驗總覽** — 查看期別金額與關卡
- **本期計量** — 登錄項次數量及依據
- **附件預檢** — 核對試驗照片與簽章
- **監造審查** — 記錄刪減退補和意見
- **機關核定** — 追蹤複審及核付狀態
- **現金流分析** — 預測入帳日與短收

## 適合誰使用

- 估驗工程師
- 監造人員
- 機關承辦

## 運作流程

1. 編製計量
2. 附件預檢
3. 承商簽核
4. 監造審查
5. 機關核定
6. 追蹤核付

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
