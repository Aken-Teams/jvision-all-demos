# 海關裁定申請包產生器

> 彙整商品規格、圖示與分類論證，快速產出可送件的海關裁定申請包。

彙整商品規格、圖示與分類論證，快速產出可送件的海關裁定申請包。

**產業別：**採購供應鏈　|　**系統類型：**legal-case

## 功能模組

- **申請商品案卷** — 集中商品用途、材質、組成、製程、產地與交易背景。
- **規格與BOM解析** — 從規格書和 BOM 擷取影響稅則分類的技術特徵。
- **圖示證物編排** — 整理外觀、剖面、組裝與功能示意圖並建立附件編號。
- **分類論證工作台** — 引用稅則註解、裁定先例與商品特徵，組成主張理由。
- **替代代碼比較** — 比較候選稅則代碼的適用條件、反證、稅率與申請風險。
- **裁定申請包輸出** — 產生申請書、技術摘要、附件目錄與引用完整性檢查結果。

## 適合誰使用

- 國貿主管
- 報關人員
- 業務

## 運作流程

1. 建立商品案卷
2. 確認關鍵特徵
3. 編排圖示證物
4. 形成分類論證
5. 評估替代代碼
6. 核定並輸出送件包
