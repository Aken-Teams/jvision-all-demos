# 變更設計成本試算台

> 針對設計變更同步盤點新增、取消、已採購及已施作項目，拆分材料、人工、機具、退料與沉沒成本，提供不同方案的淨增減額及預算影響供業主決策。

針對設計變更同步盤點新增、取消、已採購及已施作項目，拆分材料、人工、機具、退料與沉沒成本，提供不同方案的淨增減額及預算影響供業主決策。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **變更範圍** — 整理原設計、變更內容及影響區域。
- **增減項目** — 拆分新增、取消與數量變動工項。
- **採購盤點** — 確認已詢價、已下單與可退料狀態。
- **施作盤點** — 記錄已完成、施工中及尚未施工數量。
- **成本試算** — 計算淨增減、沉沒成本及間接費。
- **方案比較** — 並列替代方案的成本與工期影響。

## 適合誰使用

- 成本工程師
- 設計經理
- 採購人員

## 運作流程

1. 建立變更範圍
2. 拆分增減工項
3. 盤點採購承諾
4. 確認現場狀態
5. 試算方案成本
6. 提交方案決策

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
