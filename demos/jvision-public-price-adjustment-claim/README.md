# 公共工程調價請領台

> 依公共工程契約公式管理基期、指數、估驗數量與排除項目，逐期試算物價調整款、組裝請領附件並追蹤退補，避免漏期或少收。

依公共工程契約公式管理基期、指數、估驗數量與排除項目，逐期試算物價調整款、組裝請領附件並追蹤退補，避免漏期或少收。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **物價指數** — 維護基期與各期指數
- **調價條款** — 設定公式門檻和排除
- **估驗數量** — 匯入各期適用數量
- **調價試算** — 產生本期及累計金額
- **請領成冊** — 彙整計算表與附件
- **核定追蹤** — 處理監造機關退補

## 適合誰使用

- 估驗工程師
- 合約工程師
- 專案財務

## 運作流程

1. 解析條款
2. 更新指數
3. 匯入數量
4. 執行試算
5. 覆核送審
6. 追蹤核定

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
