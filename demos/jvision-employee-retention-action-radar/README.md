# 員工流失留才行動雷達

> 以擬真的出勤、年資、薪酬、職務異動、敬業度與團隊變化訊號，呈現部門及人才群的流失風險，並把風險轉成可追蹤的訪談、發展、調薪或工作改善行動。

**產業別：**人力資源　|　**系統類型：**analytics-bi

## 功能模組

- **組織風險雷達** — 以部門與人才群呈現風險分布、趨勢及資料可信度。
- **人才群探索** — 依年資、職類、績效或地點分析共同風險與變化。
- **風險因素解讀** — 說明影響風險的訊號、時間變化及不可直接下結論的限制。
- **關懷訪談準備** — 產生非定罪式訪談重點、開放問題與可提供的支持。
- **留才行動管理** — 建立發展、薪酬、輪調或工作改善措施並指定負責人。
- **成效追蹤中心** — 比較行動前後風險、完成進度與實際流動結果。

## 適合誰使用

- 人資夥伴
- 部門主管
- 人資主管

## 運作流程

1. 掃描風險
2. 探索人才群
3. 解讀因素
4. 準備關懷
5. 執行行動
6. 追蹤成效

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
