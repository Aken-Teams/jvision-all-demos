# 需求影響範圍分析器

> 連結需求到服務、資料、測試與文件，估算真實改動範圍及交付風險。

連結需求到服務、資料、測試與文件，估算真實改動範圍及交付風險。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **需求依賴圖** — 將需求拆成行為與限制，映射至程式庫、服務及上下游依賴。
- **服務影響掃描** — 辨識需修改或可能受回歸影響的 API、事件與執行服務。
- **資料變更分析** — 找出資料模型、遷移、血緣與相容性可能受到的影響。
- **測試覆蓋缺口** — 對照需求路徑與現有測試，指出需新增或更新的驗證案例。
- **文件同步清單** — 定位需更新的架構、API、操作手冊與發布說明。
- **改動規模估算** — 彙整跨團隊依賴、回歸範圍與交付風險，形成估算建議。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 解析需求邊界
2. 追蹤服務依賴
3. 評估資料變更
4. 盤點測試缺口
5. 確認文件更新
6. 核准改動估算
