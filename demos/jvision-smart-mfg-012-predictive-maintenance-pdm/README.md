# 預測性維護系統（Predictive Maintenance, PdM）

> 保養、維修、預兆到備品的設備全生命週期

預測性維護系統（Predictive Maintenance, PdM）提供振動/溫度/電流等感測數據監控、故障風險評分模型、剩餘壽命預測（RUL）。設備工程依「感測數據收集 → 特徵擷取 → 故障預測模型運算 → 風險告警 → 維護排程建議」推進作業，優先解決「定期保養造成過度維護或維護不足」，廠務則以非計畫停機率下降幅度與預測準確率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**設備維護　|　**系統類型：**CMMS 設備維護

## 功能模組

- **保養排程** — 預防保養自動排程
- **維修工單** — 報修、派工與完工
- **預兆診斷** — 設備數據異常預警
- **備品管理** — 備品庫存與領用
- **OEE 稼動** — 稼動與故障分析
- **履歷追溯** — 設備維護履歷

## 適合誰使用

- 設備工程
- 廠務
- 製造工程

## 運作流程

1. 待派工
2. 維修中
3. 試車確認
4. 復機完成

## 導入效益

- 非計畫停機：25小時/月 → **5.9小時/月**
- 保養準時率：77% → **92%**
- 備品缺料：10次/月 → **1.9次/月**
- 故障排除時間：88分鐘 → **27分鐘**
