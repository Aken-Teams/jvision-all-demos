# 倉儲波次出貨艙

> 收貨到出貨的倉內作業與庫存精準管理

協助揀貨波次、出貨、庫位與人力安排。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**倉儲物流　|　**系統類型：**WMS 倉儲管理系統

## 功能模組

- **入庫上架** — 收貨、驗收與智慧上架
- **揀貨出貨** — 波次揀貨、覆核與出貨
- **儲位管理** — 儲位規劃與庫容視覺化
- **庫存盤點** — 即時庫存、盤點與調撥
- **拉動補料** — 安全庫存與自動補貨
- **條碼作業** — PDA 掃碼即時作業

## 適合誰使用

- 倉管專員
- 倉儲主管
- 供應鏈經理

## 運作流程

1. 待盤點
2. 待補貨
3. 移庫中
4. 出庫完成

## 導入效益

- 揀貨作業工時：7.3小時/日 → **2小時/日**
- 庫存準確率：90% → **95%**
- 出貨延遲率：9% → **1.9%**
- 盤點工時：16小時/月 → **3.2小時/月**
