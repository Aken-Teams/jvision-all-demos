# 計程車隊代收結算台

> 勾稽企業簽單、平台趟次、車號、司機繳件與客戶請款，辨識重複、漏單及無效簽章，計算司機應付與車隊服務收入並處理退帳。

**產業別：**交通運輸　|　**系統類型：**finance-case

## 功能模組

- **簽單收件** — 彙整紙本電子單
- **趟次配對** — 連結車號司機
- **重複檢查** — 攔截重複請款
- **缺件追補** — 追蹤漏交簽單
- **雙向結算** — 計算應收應付
- **退帳結案** — 處理客戶爭議

## 適合誰使用

- 車隊結算員
- 企業客戶窗口
- 薪資人員

## 運作流程

1. 接收簽單
2. 配對趟次
3. 追補缺件
4. 確認客戶
5. 計算分潤
6. 完成結算

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
