## 功能模組

- **無主知識清單** — 集中顯示未指派、責任失效或權責不明的內容。
- **責任人推定** — 按作者、編修、引用與問題處理紀錄推薦人選。
- **貢獻關係圖** — 呈現候選人與知識主題間的實際貢獻依據。
- **指派情境比較** — 比較專業匹配、工作負載與組織責任的取捨。
- **責任確認邀請** — 向首選與候補人發送可接受、轉派或拒絕的邀請。
- **知識權責登錄** — 核准主要擁有者、代理人與定期複核週期。

## 適合誰使用

- 知識工作者
- 主管
- 客服

## 運作流程

1. 盤點無主知識
2. 檢視推薦人選
3. 核對貢獻依據
4. 選擇指派方案
5. 取得本人確認
6. 正式登錄權責

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
