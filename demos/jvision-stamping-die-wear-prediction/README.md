# 沖壓模具磨耗預測系統

> 彙整模具履歷、沖次、保養紀錄與模擬感測趨勢，預估刃口及導引零件的磨耗程度與剩餘壽命，協助台灣沖壓工廠提早安排檢修、備料及換模，降低突發停機、模具損壞與批次品質波動。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **磨耗監控總覽** — 以風險卡片、沖次趨勢與產線分布呈現所有模具的健康狀態。
- **模具健康剖面** — 查看刃口、沖頭、導柱等部位的磨耗分數、壽命與歷次維修紀錄。
- **壽命預測分析** — 模擬不同材料、速度及批量條件，呈現剩餘沖次與預測信賴區間。
- **風險告警中心** — 依嚴重度彙整磨耗告警，顯示可能原因、影響產品與建議處置。
- **保養排程管理** — 將預測結果轉為保養工單，安排停機時段、技師、備品與檢查項目。
- **模具履歷報告** — 比較保養前後狀態、故障間隔、維修成本與模具壽命改善成果。

## 適合誰使用

- 模具課主管
- 設備工程師
- 生產課長與維修技師

## 運作流程

1. 掌握模具風險
2. 檢查磨耗部位
3. 評估剩餘壽命
4. 研判異常原因
5. 安排預防保養
6. 追蹤改善成效

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
