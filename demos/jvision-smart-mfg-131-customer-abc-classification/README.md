# 客戶分級管理 Customer ABC Classification洞察站

依營收貢獻、獲利率與策略重要性將客戶分級（如ABC分類），作為資源投入與服務差異化依據。

- 原始系統：客戶分級管理 Customer ABC Classification
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、業務主管、財務部、管理層
- 工作流程：彙整客戶交易數據→計算分級指標→套用分級模型→產出分級結果→連動服務與拜訪策略
- AI 應用：客戶終身價值(CLV)預測、分級變動趨勢自動提醒
- 主要 KPI：高價值客戶留存率、分級準確度、資源投入效益、客戶貢獻集中度
- 代表產品：Salesforce Customer 360分析模組、Microsoft Dynamics 365 Customer Insights、自建BI分級模型
