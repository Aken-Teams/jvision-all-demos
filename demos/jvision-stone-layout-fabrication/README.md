# 石材排版加工追蹤台

> 串聯石材選板、立面排版、加工版次、裝箱編號、到貨驗色與安裝位置，管制天然紋理連續性及尺寸變更，避免舊版加工、跨區混箱或現場拆箱才發現色差。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **選板批次** — 記錄荒料、板材照片與色紋分組。
- **立面排版** — 配置片號、紋理方向及安裝位置。
- **加工下單** — 發布尺寸、邊型與核准版次。
- **裝箱追蹤** — 連結片號、箱號與出貨批次。
- **到貨驗色** — 比對樣品、色差、破損及錯件。
- **補片替換** — 維護補製片與原位置的替換關係。

## 適合誰使用

- 裝修工程師
- 設計監造
- 石材供應商

## 運作流程

1. 選定板材
2. 核准排版
3. 發布加工
4. 編箱出貨
5. 驗收到貨
6. 補片結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
