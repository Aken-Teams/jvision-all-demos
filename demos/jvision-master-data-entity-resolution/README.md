# 主資料合併與實體辨識中心

> 整合不同系統中的客戶、供應商、商品與據點主資料，由人工智慧辨識名稱變體、重複紀錄及可能屬於同一對象的資料，提供合併建議、人工覆核、黃金紀錄與來源追溯，降低重複建檔和報表誤差。

## 功能模組

- **來源資料盤點** — 查看各系統主資料來源、欄位對應、更新時間與品質。
- **疑似實體群組** — 將可能代表同一對象的紀錄聚合並顯示配對信心。
- **欄位比對室** — 並排比較名稱、地址、電話、編號與來源可信度。
- **合併決策台** — 接受、拒絕或調整合併建議並保留人工判斷理由。
- **黃金紀錄中心** — 管理每個實體的標準主檔、優先來源與欄位值。
- **追溯與復原** — 查看合併歷程、來源紀錄及可回復的版本差異。

## 適合誰使用

- 主資料管理員
- 資料治理人員
- 業務營運人員
- 資訊人員

## 運作流程

1. 盤點資料來源
2. 發現疑似實體
3. 比較欄位差異
4. 核准合併決策
5. 發布黃金紀錄
6. 稽核合併歷程

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
