# 維修積壓工單治理台

> 供維修主管彙整長期未結工單，依安全、產能、故障風險、料件與停機機會重新排序，安排清理衝刺並追蹤延後理由，避免積壓掩蓋設備風險。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **積壓總覽** — 呈現工單齡與風險分布。
- **優先評分** — 依風險及產能影響重新排序。
- **備料檢核** — 確認料件、工具與外包條件。
- **窗口媒合** — 配對停機時段與維修人力。
- **清理派工** — 建立衝刺批次並指派人員。
- **治理追蹤** — 分析延後原因與消化趨勢。

## 適合誰使用

- 維修主管
- 保養工程師
- 生產協調員

## 運作流程

1. 盤點積壓
2. 校正風險
3. 確認條件
4. 協調窗口
5. 發布派工
6. 檢討治理

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
