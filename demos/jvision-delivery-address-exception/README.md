# 配送地址疑義協調台

> 將司機回報的定位、門牌、園區入口與收件人疑義集中排隊，提供歷史簽收及授權地址比對，經客戶確認後發布可追溯的新配送指示。

將司機回報的定位、門牌、園區入口與收件人疑義集中排隊，提供歷史簽收及授權地址比對，經客戶確認後發布可追溯的新配送指示。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **疑義佇列** — 彙整現場回報
- **位置比對** — 比較訂單定位
- **歷史簽收** — 查看曾送入口
- **客戶確認** — 記錄授權改址
- **指示發布** — 回傳司機路徑
- **配送結案** — 記錄最終結果

## 適合誰使用

- 配送司機
- 調度員
- 客服人員

## 運作流程

1. 回報疑義
2. 比對資料
3. 聯絡確認
4. 決定處置
5. 發布指示
6. 完成簽收

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
