# 印刷電路板焊點缺陷檢測系統

> 使用擬真印刷電路板影像展示焊點外觀檢測，辨識少錫、多錫、錫珠、裂紋與潤濕不良等疑點，提供框選複核、缺陷分級、返修派工及批次品質統計畫面。

使用擬真印刷電路板影像展示焊點外觀檢測，辨識少錫、多錫、錫珠、裂紋與潤濕不良等疑點，提供框選複核、缺陷分級、返修派工及批次品質統計畫面。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **焊點品質總覽** — 以批次與缺陷類型呈現焊點品質及待處理數量。
- **板件影像清單** — 瀏覽模擬板件縮圖、檢測狀態與疑點數量。
- **焊點檢測工作區** — 放大焊點影像並顯示缺陷框、類型與信心分數。
- **缺陷分級複核** — 確認缺陷種類並依品質標準設定嚴重等級。
- **返修派工管理** — 建立返修工作單並模擬記錄處置與複驗結果。
- **批次品質報表** — 比較缺陷率、返修率及各類焊點問題趨勢。

## 適合誰使用

- 外觀檢驗員
- 品保工程師
- 返修技術員

## 運作流程

1. 掌握品質
2. 選擇板件
3. 檢查焊點
4. 確認分級
5. 執行返修
6. 分析批次

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
