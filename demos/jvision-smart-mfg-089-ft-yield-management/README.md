# FT Yield Management（最終測試良率管理）

> 從異常到改善的品質閉環與追溯稽核

FT Yield Management（最終測試良率管理）提供測試機數據即時採集、良率看板、Bin分佈分析。測試工程部依「測試數據採集→良率計算→Bin分析→異常判定→批次攔截處置」推進作業，優先解決「測試機數據量龐大難即時分析」，品保部則以最終測試良率與異常批次攔截率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 測試工程部
- 品保部
- 製程工程部

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉

## 導入效益

- 批號追溯時間：187分鐘 → **15分鐘**
- 客訴平均關案：21天 → **8.6天**
- 改善驗證率：64% → **92%**
- 重複不良率：5.9% → **2.1%**
