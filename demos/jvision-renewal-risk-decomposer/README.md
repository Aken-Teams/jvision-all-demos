# 續約風險分解器

拆解續約的價格、價值、產品、服務與關係風險，制定保留策略。觸發後建立案件

**產業別：**客服管理　|　**系統類型：**sales-crm

## 功能模組

- **續約風險總覽** — 依續約日、合約價值與流失機率排序重點帳戶。
- **五維風險分解** — 拆解價格、價值、產品、服務與關係風險占比。
- **價格價值落差** — 比較合約成本、使用成果、承諾價值與客戶認知。
- **產品服務診斷** — 分析採用缺口、產品障礙、工單品質與服務體驗。
- **關係網絡風險** — 辨識贊助者流失、決策者疏離與單點關係依賴。
- **保留策略作戰室** — 組合商務、價值、產品與關係措施並管理核准。

## 適合誰使用

- 客戶成功主管
- CSM
- 客服主管

## 運作流程

1. 篩選續約風險
2. 拆解風險構成
3. 核對價格價值
4. 診斷產品服務
5. 修補關係網絡
6. 核准保留策略

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
