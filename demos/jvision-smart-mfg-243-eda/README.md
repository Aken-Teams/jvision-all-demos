# EDA整合管理系統（電子電路設計整合平台）

> 訂單到入庫的製造現場全流程數位化

EDA整合管理系統（電子電路設計整合平台）提供電路原理圖與Layout版本管理、元件庫（Library）集中維護、設計規則檢查（DRC）流程整合。研發專案管理師、研發經理、技術長依「電路原理圖與Layout版本管理、元件庫（Library）集中維護、設計規則檢查（DRC）流程整合」推進作業，優先解決「元件庫版本不一致導致設計錯誤」，部門主管則以EDA整合管理洞察站處理結果確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**研發管理　|　**系統類型：**MES 製造執行系統

## 功能模組

- **工單管理** — 訂單轉工單、拆併單與工單派發
- **排程排產** — 依產能、交期、負載自動排程
- **現場執行** — 派工、報工與進度即時回報
- **設備稼動 OEE** — 稼動、效率、良率即時監控
- **品質入庫** — 檢驗判定、不良處置與入庫
- **AI 改善建議** — 異常摘要與瓶頸改善建議

## 適合誰使用

- 研發專案管理師
- 研發經理
- 技術長

## 運作流程

1. 規劃中
2. 執行中
3. 驗證中
4. 發布完成

## 導入效益

- 設計變更工時：8.3小時 → **2小時**
- 文件版本錯誤：6.1件/月 → **1件/月**
- 專案準時率：70% → **86%**
- 資料查找時間：29分鐘 → **5.3分鐘**
