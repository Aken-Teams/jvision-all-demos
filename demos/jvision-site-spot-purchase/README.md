# 工地零星採購比價台

> 整合工地臨時物料需求、供應商詢價、同規格比價、授權簽核、採買驗收與憑證歸檔，避免電話詢價與群組核准無法追溯，並管控拆單及超額採購。

整合工地臨時物料需求、供應商詢價、同規格比價、授權簽核、採買驗收與憑證歸檔，避免電話詢價與群組核准無法追溯，並管控拆單及超額採購。

**產業別：**營建工程　|　**系統類型：**procurement-srm

## 功能模組

- **需求登錄** — 建立工區、用途、規格、數量及需求期限。
- **詢價收件** — 彙整電話、訊息及報價單形成正式報價。
- **同規比價** — 校正稅別、運費、品牌及交期後並列比較。
- **額度簽核** — 依案場授權級距送交主管核准或退回。
- **採買到貨** — 追蹤下單、代購人、到貨數量與異常。
- **憑證結案** — 綁定發票、簽收照片及成本歸屬完成核銷。

## 適合誰使用

- 工地採購
- 工地主任
- 成本會計

## 運作流程

1. 提出需求
2. 取得報價
3. 完成比價
4. 核准採買
5. 點收到貨
6. 核銷歸檔

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
