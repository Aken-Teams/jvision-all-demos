# 建築勘驗備件確認台

> 依樓層與勘驗階段產生法定備件清單，管理申報書、簽章、施工照片、試驗報告與現場完成條件，於預約前完成缺件檢核及退件修正。

**產業別：**營建工程　|　**系統類型：**legal-case

## 功能模組

- **勘驗總覽** — 查看各階段申報與備件狀態。
- **法定清單** — 依勘驗類型產生必要項目。
- **文件備齊** — 彙整簽章、照片與試驗報告。
- **現場預檢** — 確認申報範圍實際完成條件。
- **缺件補正** — 追蹤格式、簽章及內容修正。
- **申報結果** — 記錄送件、勘驗與核准結果。

## 適合誰使用

- 建照專員
- 現場工程師
- 專案建築師

## 運作流程

1. 掌握勘驗時程
2. 建立備件清單
3. 彙整申報文件
4. 確認現場條件
5. 完成缺件補正
6. 提交勘驗申報

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
