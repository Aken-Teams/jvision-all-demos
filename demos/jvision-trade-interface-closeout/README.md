# 界面收頭責任協調台

> 針對門窗、外牆、天花、設備與裝修交界建立收頭項目，標記圖面依據、契約範圍、先後順序與主協辦工班，透過現勘決議和完成確認，避免各分包只做報價範圍而留下塞縫、封膠或修飾缺口。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **界面清冊** — 依空間與工種列出待處理交界。
- **範圍比對** — 並列圖說、標單與合約責任依據。
- **現勘協調** — 安排會勘並記錄各方意見。
- **責任定案** — 指定主辦、協辦與施工先後順序。
- **收頭驗證** — 以照片及檢查結果確認完成。
- **爭議裁定** — 處理拒作、追加與責任異議。

## 適合誰使用

- 工地主任
- 現場工程師
- 分包領班

## 運作流程

1. 盤點界面項目
2. 比對契約圖說
3. 召開現場會勘
4. 核定責任分工
5. 查核收頭成果
6. 結清責任爭議

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
