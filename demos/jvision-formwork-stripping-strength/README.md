# 模板拆除強度判定台

> 依樓板、梁柱與懸臂構件設定拆模條件，串接澆置時間、養護齡期、試體強度及支撐回撐方案，避免工班只憑固定天數提前拆除模板。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **拆模日曆** — 依構件顯示最早申請日與目前狀態。
- **條件設定** — 維護構件類型、跨度與拆模門檻。
- **強度彙整** — 對應試體結果與現場養護齡期。
- **拆除申請** — 申報範圍、順序、人力及預定時間。
- **回撐確認** — 核對回撐配置與保留期限。
- **拆模放行** — 簽認條件並記錄實際拆除結果。

## 適合誰使用

- 結構工程師
- 施工工程師
- 模板領班

## 運作流程

1. 設定門檻
2. 彙整資料
3. 提出申請
4. 檢查回撐
5. 核准拆模
6. 回報完成

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
