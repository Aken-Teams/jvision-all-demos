# 零結果診斷 Agent

診斷搜尋零結果源自內容缺口、詞彙、權限或索引問題，持續提升命中率。

**產業別：**企業協作　|　**系統類型：**analytics-bi

## 功能模組

- **零結果事件池** — 彙整無命中查詢、重試行為、使用情境與業務影響。
- **詞彙落差分析** — 比對查詢與企業術語，找出同義詞、縮寫、拼寫及語言差異。
- **內容缺口判定** — 確認主題是否缺少文件、文件已過期或尚未被正式建立。
- **權限阻斷診斷** — 以安全統計判斷是否因存取政策造成零結果且不揭露內容存在。
- **索引健康檢查** — 追查連接器延遲、解析失敗、分段異常與向量索引遺漏。
- **命中改善工單** — 產生詞庫更新、補文、權限修正或重建索引草案並追蹤成效。

## 適合誰使用

- 知識工作者
- 主管
- 客服

## 運作流程

1. 收集零結果查詢
2. 分析詞彙落差
3. 檢查內容缺口
4. 判別權限因素
5. 檢查索引鏈路
6. 執行命中改善

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
