# 旅宿房型主檔對映台

> 治理訂房、房務與各外部通路的房型名稱、代碼、床型及容納人數對照，讓拆併房型或改名時能逐系統確認同步結果。

治理訂房、房務與各外部通路的房型名稱、代碼、床型及容納人數對照，讓拆併房型或改名時能逐系統確認同步結果。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **房型主檔** — 查看標準房型與屬性。
- **通路對映** — 維護各平台房型代碼。
- **差異檢查** — 找出名稱與規格衝突。
- **影響分析** — 評估訂單、房務與庫存影響。
- **異動審核** — 核准拆併、改名與停用。
- **同步驗證** — 確認各端對映已生效。

## 適合誰使用

- 訂房主管
- 通路專員
- 系統管理員

## 運作流程

1. 提出異動
2. 盤點對映
3. 分析影響
4. 核准版本
5. 更新對映
6. 驗證生效

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
