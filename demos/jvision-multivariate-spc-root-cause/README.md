# 多變量製程異常導航器

> 將統計製程管制概念延伸到多項品質與製程參數，透過關聯圖、異常群組及根因路徑，協助工程師辨識單一管制圖不易發現的共同漂移，並快速鎖定可能影響來源。

將統計製程管制概念延伸到多項品質與製程參數，透過關聯圖、異常群組及根因路徑，協助工程師辨識單一管制圖不易發現的共同漂移，並快速鎖定可能影響來源。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **製程健康總覽** — 以產線、產品與時段呈現多變量製程健康狀態。
- **多變量異常地圖** — 用分群與距離視圖顯示參數共同偏移及異常樣本。
- **管制趨勢診斷** — 並列重要參數趨勢、管制界線與異常規則命中。
- **根因路徑導航** — 串接設備、配方、原料、班別與環境等候選原因。
- **改善情境驗證** — 模擬調整參數後的品質分布與風險變化。
- **處置追蹤看板** — 管理異常責任、改善措施、期限及驗證結論。

## 適合誰使用

- 製程工程師
- 品質工程師
- 產線主管與品質經理

## 運作流程

1. 監看製程健康
2. 確認異常群組
3. 診斷參數趨勢
4. 追查候選根因
5. 模擬改善方案
6. 驗證並結案

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
