# 汽修保養請款艙

> 保養、維修、預兆到備品的設備全生命週期

管理預約、技師派工、零件與請款。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**交通運輸　|　**系統類型：**CMMS 設備維護

## 功能模組

- **保養排程** — 預防保養自動排程
- **維修工單** — 報修、派工與完工
- **預兆診斷** — 設備數據異常預警
- **備品管理** — 備品庫存與領用
- **OEE 稼動** — 稼動與故障分析
- **履歷追溯** — 設備維護履歷

## 適合誰使用

- 服務顧問
- 維修技師
- 零件管理員
- 財務收款人員

## 運作流程

1. 待確認
2. 已派車
3. 行駛中
4. 到站完成

## 導入效益

- 派車規劃工時：4.1小時/日 → **1小時/日**
- 準時配送率：90% → **99%**
- 空車率：21% → **9.4%**
- 油耗異常反應：24小時 → **2.9小時**
