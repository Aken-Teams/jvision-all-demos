# 接班準備度證據板

> 以關鍵情境與技能證據衡量接班準備度，降低主管主觀判斷。跨系統彙整工作表現、學習與績效證據，讓接班差距、風險與培育行動可驗證、可追蹤。

以關鍵情境與技能證據衡量接班準備度，降低主管主觀判斷。跨系統彙整工作表現、學習與績效證據，讓接班差距、風險與培育行動可驗證、可追蹤。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **接班職位圖譜** — 建立關鍵職位、候選人與職能要求的接班關係。
- **情境證據卡** — 彙整候選人在關鍵任務中的實作成果與佐證。
- **技能可信度評分** — 依來源、時效與重複驗證程度計算證據可信度。
- **準備差距分析** — 比較職位門檻與候選人現有技能證據。
- **準備度解釋** — 說明影響準備度的正向、負向與異常因素。
- **培育行動編排** — 排序輪調、專案歷練與學習任務並追蹤成效。

## 適合誰使用

- L&D 主管
- 部門主管
- 員工

## 運作流程

1. 界定接班範圍
2. 檢視情境證據
3. 校準證據效力
4. 辨識能力缺口
5. 審閱準備度原因
6. 核定培育路徑

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
