# 業主保留款回收台帳

> 逐期彙整業主估驗保留款，拆解完工、驗收、缺失改善與保固等請領條件，管理到期提醒、開票、送件、退補及實際收款，避免完工後遺漏追收。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **保留款總覽** — 查看各專案餘額與回收風險。
- **逐期台帳** — 登錄估驗扣留與累計金額。
- **條件追蹤** — 管理驗收、改善及保固條件。
- **請領備件** — 彙整發票、證明與送件清單。
- **退補催收** — 追蹤業主意見與承辦回覆。
- **收款沖帳** — 核對入帳金額及未收差異。

## 適合誰使用

- 專案會計
- 合約管理員
- 專案經理

## 運作流程

1. 檢視回收風險
2. 核對扣留台帳
3. 確認請領條件
4. 備妥請領文件
5. 處理業主退補
6. 完成收款沖帳

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
