# 雷射焊接品質即時監測系統

> 以預先產生的製程時間序列模擬雷射焊接監測，整合功率、速度、溫度與熔池訊號，呈現品質警示、事件回放、工件判定及趨勢分析，協助產線快速定位異常時段並安排複檢。

以預先產生的製程時間序列模擬雷射焊接監測，整合功率、速度、溫度與熔池訊號，呈現品質警示、事件回放、工件判定及趨勢分析，協助產線快速定位異常時段並安排複檢。

**產業別：**生產製造　|　**系統類型：**operations-console

## 功能模組

- **製程監測看板** — 以模擬播放呈現工位狀態、品質分數、即時波形與警示。
- **多訊號波形分析** — 同步查看功率、速度、溫度及熔池訊號的時間序列。
- **異常事件回放** — 重播警示前後的模擬數據，標記事件起訖與可能原因。
- **工件品質判定** — 彙整各焊段分數與事件，完成允收、複檢或隔離判定。
- **警示規則管理** — 設定不同料號的訊號門檻、持續時間與警示嚴重度。
- **穩定度趨勢分析** — 比較班次、配方與料號的訊號波動、警示率及合格率。

## 適合誰使用

- 雷射製程工程師
- 產線領班
- 品質工程師

## 運作流程

1. 監看製程品質
2. 檢視訊號波形
3. 回放異常事件
4. 判定工件狀態
5. 調整警示規則
6. 檢討製程穩定

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
