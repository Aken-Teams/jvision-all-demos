# 射出機射壓異常監測系統

> 以預先建立的射出壓力曲線、批次紀錄與警戒規則模擬機台監測情境，呈現壓力尖峰、波動及曲線偏移，協助現場人員分級處置、比對可能原因並完成事件確認，不需串接真實機台也能完整展示流程。

以預先建立的射出壓力曲線、批次紀錄與警戒規則模擬機台監測情境，呈現壓力尖峰、波動及曲線偏移，協助現場人員分級處置、比對可能原因並完成事件確認，不需串接真實機台也能完整展示流程。

**產業別：**設備維護　|　**系統類型：**operations-console

## 功能模組

- **機台監測戰情板** — 用機台卡片呈現運轉狀態、射壓指標、警報數與生產批次。
- **射壓曲線檢視** — 檢視單次射出曲線、標準包絡線、關鍵峰值與階段時間。
- **異常事件中心** — 依嚴重度彙整尖峰、低壓、震盪與曲線偏移事件。
- **警戒規則設定** — 管理各產品的上下限、持續時間、偏差幅度與通知條件。
- **原因排查指引** — 依異常型態呈現可能原因、檢查步驟及模擬佐證資料。
- **處置交班紀錄** — 記錄處置內容、責任人、恢復結果與未完成交班事項。

## 適合誰使用

- 機台操作員
- 設備工程師
- 製程主管

## 運作流程

1. 巡檢機台
2. 檢視曲線
3. 分級事件
4. 調整規則
5. 排查原因
6. 完成交班

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
