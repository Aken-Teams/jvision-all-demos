**產業別：**資訊科技　|　**系統類型：**operations-console

## 功能模組

- **風險分級矩陣** — 按業務情境、傷害程度與不可逆性設定問題風險。
- **證據充分度門檻** — 定義引用數量、來源可信度與時效性最低要求。
- **拒答規則編排** — 組合政策規則與模型判斷，設定拒答觸發條件。
- **矛盾回應檢查** — 偵測檢索片段與模型答案之間的衝突。
- **專家轉介路由** — 將高風險或證據不足問題交由指定專業角色處理。
- **拒答情境驗證** — 以評測集測量誤拒、漏拒及安全回覆品質。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 界定風險
2. 設定證據門檻
3. 編排拒答策略
4. 檢查矛盾
5. 配置轉介
6. 驗證發布
