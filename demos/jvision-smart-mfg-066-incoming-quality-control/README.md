# IQC（Incoming Quality Control）

> 從異常到改善的品質閉環與追溯稽核

IQC（Incoming Quality Control）提供檢驗計畫設定、抽樣標準管理、檢驗結果登錄。品保部依「到貨掃碼→抽樣檢驗→結果判定→放行或退貨→數據歸檔」推進作業，優先解決「檢驗標準不一致」，採購部則以來料合格率與檢驗時效確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 品保部
- 採購部
- 倉儲部

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉

## 導入效益

- 批號追溯時間：173分鐘 → **16分鐘**
- 客訴平均關案：22天 → **9天**
- 改善驗證率：63% → **92%**
- 重複不良率：6.4% → **2%**
