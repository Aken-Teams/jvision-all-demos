# 商機健康度與成交預測平台

> 彙整模擬的客戶互動、階段停留、決策條件、競爭態勢與業務承諾，評估每筆商機健康度及預估成交機率。主管可辨識停滯與過度樂觀案件，調整資源並提高業績預測可信度。

彙整模擬的客戶互動、階段停留、決策條件、競爭態勢與業務承諾，評估每筆商機健康度及預估成交機率。主管可辨識停滯與過度樂觀案件，調整資源並提高業績預測可信度。

**產業別：**業務銷售　|　**系統類型：**sales-crm

## 功能模組

- **商機健康總覽** — 呈現健康分數、風險分布、金額與銷售階段的組合視圖。
- **單筆商機診斷** — 檢查需求、預算、決策人、競爭者及下一步等成交證據。
- **停滯風險清單** — 找出久未互動、階段超時、日期頻繁延後與缺少行動的案件。
- **成交機率分析** — 以可解釋因素呈現預測機率、人工判斷與差異原因。
- **預測情境模擬** — 切換承諾、最佳可能與風險情境，試算團隊預估營收。
- **預測檢討會議** — 依團隊整理待確認案件、決策事項與預測提交版本。

## 適合誰使用

- 業務代表
- 業務主管
- 營運分析人員

## 運作流程

1. 掌握商機組合
2. 補齊成交證據
3. 處理停滯商機
4. 校準成交機率
5. 模擬營收情境
6. 提交團隊預測

- 商機轉換率：18% → **27%**

- 客戶資料完整率：62% → **94%**
