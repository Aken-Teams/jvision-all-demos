# 旅宿團體房配額履約台

> 協助商務旅館管理旅行社與企業團體的保留房配額、釋房期限、入住名單、合約房價及履約落差，讓訂房與業務人員及早回收未使用房量並降低旺日空置損失。

協助商務旅館管理旅行社與企業團體的保留房配額、釋房期限、入住名單、合約房價及履約落差，讓訂房與業務人員及早回收未使用房量並降低旺日空置損失。

**產業別：**餐飲旅宿　|　**系統類型：**pos-frontdesk

## 功能模組

- **團體合約** — 建立合作方、房價、配額與取消條款。
- **配額日曆** — 檢視每日承諾、已用及待釋房量。
- **入住名單** — 追蹤房客名單、房型與特殊需求。
- **釋房期限** — 集中處理即將截止的未使用配額。
- **追加調整** — 記錄追加、縮減與房型替換申請。
- **履約分析** — 比較合作方使用率與房晚貢獻。

## 適合誰使用

- 團體訂房專員
- 收益經理
- 業務主管

## 運作流程

1. 建立團約
2. 配置房量
3. 匯入名單
4. 檢查期限
5. 核准異動
6. 檢討履約

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
