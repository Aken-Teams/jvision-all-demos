# 帷幕填縫膠批次台

> 供帷幕工班逐立面記錄底材清潔、底塗、填縫膠批號、施工日期與拉伸試驗，將氣泡、脫黏缺失綁定樓層格位並安排重打。

供帷幕工班逐立面記錄底材清潔、底塗、填縫膠批號、施工日期與拉伸試驗，將氣泡、脫黏缺失綁定樓層格位並安排重打。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **立面格位** — 查看填縫進度
- **膠材配發** — 連結批號效期
- **施工條件** — 記錄天候與底材
- **附著試驗** — 登錄拉伸結果
- **缺失重打** — 追蹤割除重作
- **立面放行** — 完成區段簽認

## 適合誰使用

- 帷幕工程師
- 品管人員

## 運作流程

1. 膠材驗收
2. 格位派工
3. 填縫施工
4. 附著抽驗
5. 缺失重作
6. 立面驗收

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
