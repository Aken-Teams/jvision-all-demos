# 模穴品質差異分析系統

> 針對多模穴生產的重量、尺寸、外觀與不良類型建立擬真檢驗資料，分析各模穴之間的品質分布、穩定度與偏移趨勢，協助快速鎖定異常模穴、比較可能原因，並追蹤調整或維修後是否恢復一致。

針對多模穴生產的重量、尺寸、外觀與不良類型建立擬真檢驗資料，分析各模穴之間的品質分布、穩定度與偏移趨勢，協助快速鎖定異常模穴、比較可能原因，並追蹤調整或維修後是否恢復一致。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **模穴品質總覽** — 以模穴矩陣顯示合格率、平均值、穩定度與異常狀態。
- **抽樣資料建檔** — 建立各模穴的重量、尺寸、外觀及不良類型擬真紀錄。
- **分布差異比較** — 用箱形圖與分布圖比較模穴間偏移、離散及離群情形。
- **異常模穴辨識** — 依公差、製程能力及同群差異標示優先處理的模穴。
- **影響因子分析** — 比較澆流位置、冷卻區域、模溫及維修紀錄與品質的關聯。
- **改善一致性驗證** — 對照改善前後數據，確認異常模穴是否回到群組水準。

## 適合誰使用

- 品保工程師
- 射出製程工程師
- 模具工程師

## 運作流程

1. 掌握差異
2. 建立抽樣
3. 比較分布
4. 鎖定模穴
5. 分析因子
6. 驗證一致
