# 工地吊裝時段協調台

> 供大型工地安排塔吊與移動式吊車的使用時段，整合工項優先序、吊物規格、樓層動線、協力廠商需求及安全前置條件，降低多工種搶用設備造成的等待與進度衝突。

供大型工地安排塔吊與移動式吊車的使用時段，整合工項優先序、吊物規格、樓層動線、協力廠商需求及安全前置條件，降低多工種搶用設備造成的等待與進度衝突。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **吊裝申請** — 登錄吊物、重量、樓層與需求時段。
- **條件審查** — 確認吊點、動線及安全文件。
- **時段排程** — 以時間軸配置吊車與工班。
- **衝突裁決** — 依工序影響與急迫性調整順位。
- **日計畫發布** — 通知工班定案時段與候補安排。
- **利用分析** — 檢討空等、延誤及插單原因。

## 適合誰使用

- 工地主任
- 吊裝協調員
- 工班領班

## 運作流程

1. 提出申請
2. 檢查條件
3. 配置時段
4. 解決衝突
5. 發布計畫
6. 回報實績

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
