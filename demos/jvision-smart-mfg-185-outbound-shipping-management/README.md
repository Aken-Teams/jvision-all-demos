# 出貨管理系統（Outbound Shipping Management）

> 收貨到出貨的倉內作業與庫存精準管理

出貨管理系統（Outbound Shipping Management）提供出貨訂單分批與波次規劃、揀補貨任務派工、出貨複核掃碼比對。倉儲部依「訂單匯入→波次規劃→揀貨→複核裝箱→單據產出→交運承運商」推進作業，優先解決「出貨錯發漏發時有發生」，業務部則以出貨準時率與出貨錯誤率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**倉儲物流　|　**系統類型：**WMS 倉儲管理系統

## 功能模組

- **入庫上架** — 收貨、驗收與智慧上架
- **揀貨出貨** — 波次揀貨、覆核與出貨
- **儲位管理** — 儲位規劃與庫容視覺化
- **庫存盤點** — 即時庫存、盤點與調撥
- **拉動補料** — 安全庫存與自動補貨
- **條碼作業** — PDA 掃碼即時作業

## 適合誰使用

- 倉儲部
- 業務部
- 物流部

## 運作流程

1. 待盤點
2. 待補貨
3. 移庫中
4. 出庫完成

## 導入效益

- 揀貨作業工時：6.7小時/日 → **2.1小時/日**
- 庫存準確率：92% → **99%**
- 出貨延遲率：8.8% → **1.9%**
- 盤點工時：17小時/月 → **3.1小時/月**
