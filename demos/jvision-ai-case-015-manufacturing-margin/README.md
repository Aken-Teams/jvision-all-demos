# 毛利成本導航儀

> 把料工費拆解成即時可操作的毛利洞察

將工時、材料、外包與良率轉換成成本與毛利洞察。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生產製造　|　**系統類型：**MES 製造執行系統

## 功能模組

- **毛利總覽** — 整體毛利率、毛利額與達成率即時看板
- **產品獲利矩陣** — 營收 × 毛利率散佈，辨識金牛與虧損品
- **成本結構拆解** — 售價→料→工→費→毛利瀑布拆解
- **訂單毛利分析** — 逐張訂單毛利與虧損訂單預警
- **價格 What-if 模擬** — 調價、換料、良率變動即時試算毛利
- **AI 毛利建議** — 成本異常摘要與提利改善建議

## 適合誰使用

- 成本會計
- 業務報價
- 廠長

## 運作流程

1. 成本歸集
2. 毛利拆解
3. 訂單診斷
4. 價格模擬
5. 決策核准

## 導入效益

- 毛利試算工時：6.5小時/單 → **0.8小時/單**
- 整體毛利率：21% → **28%**
- 虧損訂單佔比：14% → **4%**
- 報價成本準確率：72% → **94%**
