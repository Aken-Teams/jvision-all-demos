# BIM預留孔衝突銷項台

> 以樓層與構件彙整機電預留孔、套管及結構衝突議題，管理模型截圖、責任工種、解決方案、圖說修訂與現場銷項，避免未協調孔洞進入澆置階段後才鑿除返工。

以樓層與構件彙整機電預留孔、套管及結構衝突議題，管理模型截圖、責任工種、解決方案、圖說修訂與現場銷項，避免未協調孔洞進入澆置階段後才鑿除返工。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **模型衝突簿** — 呈現構件、管線與預留孔的碰撞位置。
- **樓層定位** — 依棟別、樓層、軸線及構件快速篩選。
- **方案協調** — 記錄改管、移孔、補強或拒絕開孔方案。
- **專業核定** — 由結構與機電專業確認最終處理方式。
- **版次同步** — 關聯核定模型、施工圖與變更版次。
- **現場銷項** — 以放樣及完工影像確認孔洞已正確施作。

## 適合誰使用

- BIM工程師
- 機電工程師
- 結構工程師

## 運作流程

1. 偵測衝突
2. 定位分類
3. 提出方案
4. 專業核定
5. 同步圖說
6. 現場銷項

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
