# 機具進退場檢點台

> 在租賃機具進場與退場時共同確認機況、附件、既有刮傷、證照及計費時點，保存雙方簽認，降低缺件賠償與逾期租金爭議。

在租賃機具進場與退場時共同確認機況、附件、既有刮傷、證照及計費時點，保存雙方簽認，降低缺件賠償與逾期租金爭議。

**產業別：**營建工程　|　**系統類型：**maintenance-cmms

## 功能模組

- **機具清冊** — 查看租約與場內狀態
- **檢點範本** — 依機型設定檢查項目
- **機況取證** — 記錄刮傷附件與儀表
- **證照查核** — 確認檢驗與操作資格
- **雙方簽認** — 確認責任及計費時點
- **退場停租** — 完成缺件處理與退場

## 適合誰使用

- 機具管理員
- 操作人員
- 租賃商代表

## 運作流程

1. 申報進場
2. 到場檢點
3. 雙方簽認
4. 使用追蹤
5. 退場檢點
6. 停租結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
