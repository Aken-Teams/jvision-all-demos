# 理賠準備金異動覆核台

> 追蹤理賠案件準備金估值版本、重大調整理由、結案釋放與人工分錄授權，聚合大額變動供財務及精算覆核，避免負債與監理報表失真。

追蹤理賠案件準備金估值版本、重大調整理由、結案釋放與人工分錄授權，聚合大額變動供財務及精算覆核，避免負債與監理報表失真。

**產業別：**金融保險　|　**系統類型：**finance-ledger

## 功能模組

- **案件準備金** — 呈現逐案估值與狀態
- **版本比較** — 比較前後金額與假設
- **重大異動** — 依金額比例標示風險
- **估值依據** — 保存醫療法律與理賠證據
- **結案釋放** — 檢查已結案件剩餘額
- **調整覆核** — 核准分錄與監理版本

## 適合誰使用

- 理賠人員
- 精算人員
- 財務主管

## 運作流程

1. 匯入準備金估值
2. 偵測重大異動
3. 補齊估值依據
4. 檢查結案釋放
5. 核准人工調整
6. 發布報表版本

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
