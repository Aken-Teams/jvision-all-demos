# 電商退貨商品判定台

> 將退回商品依外觀、包裝、配件及功能檢查結果，分流為重新上架、整新、折價、退供或報廢，並追蹤每筆價值回收。

**產業別：**零售電商　|　**系統類型：**operations-console

## 功能模組

- **退貨收件** — 建立退件批次與原訂單關聯。
- **狀態檢查** — 檢核外觀、功能、配件及包裝。
- **商品分級** — 依檢查結果判定可售等級。
- **處置分流** — 選擇上架、整新、退供或報廢。
- **價損核准** — 審核高價商品折損與例外處置。
- **回收分析** — 追蹤品類回收率及處置時效。

## 適合誰使用

- 退貨品管員
- 倉儲主管
- 商品經理

## 運作流程

1. 建立退貨批次
2. 執行商品檢查
3. 評定可售等級
4. 指定處置路徑
5. 核准價值損失
6. 完成回收入帳

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
