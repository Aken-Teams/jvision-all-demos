協助禮儀公司管理治喪案件的家屬需求、儀式方案、場地時段、供應項目、文件及收付款節點，以清楚任務分工降低高壓時程中的遺漏與溝通落差。

**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **案件總覽** — 呈現治喪節點、待辦與高風險異動。
- **家屬需求** — 記錄聯絡窗口、禁忌、宗教及特殊安排。
- **方案配置** — 組合儀式、用品、車輛與場地服務。
- **儀程排程** — 安排入殮、告別、火化與安奉等節點。
- **文件採辦** — 追蹤證明文件、申請及供應項目。
- **費用結案** — 核對合約、追加、代收付與尾款狀態。

## 適合誰使用

- 禮儀師
- 案件行政
- 營運主管

## 運作流程

1. 建立案件
2. 訪談需求
3. 確認方案
4. 編排儀程
5. 完成採辦
6. 核對結案

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
