# 社區包裹代收營運台

> 管理社區包裹從到件、住戶通知、冷藏或大型件分區、代理領取到逾期催領，協助櫃台快速定位物件並處理錯投、破損與長期占位。

管理社區包裹從到件、住戶通知、冷藏或大型件分區、代理領取到逾期催領，協助櫃台快速定位物件並處理錯投、破損與長期占位。

**產業別：**房地產與物業　|　**系統類型：**operations-console

## 功能模組

- **到件登錄** — 記錄物流商、收件戶別與包裹特徵。
- **儲位配置** — 分配一般、冷藏、大型及貴重物儲位。
- **住戶通知** — 追蹤首次通知、提醒與閱讀狀態。
- **領取核驗** — 確認住戶、家屬或受託人的領取權限。
- **異常處理** — 管理錯投、破損、無戶別及退回案件。
- **逾期盤點** — 列出占位過久包裹並安排催領。

## 適合誰使用

- 社區櫃台
- 物業主任
- 夜班保全

## 運作流程

1. 登錄到件
2. 配置儲位
3. 通知住戶
4. 核驗領取
5. 處理異常
6. 完成盤點

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
