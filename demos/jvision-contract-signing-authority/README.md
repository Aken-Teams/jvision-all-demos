# 承攬權限簽約稽核台

> 比對報價承諾、分包契約、用印申請與公司授權層級，攔截工地人員先簽後補、超額承諾或最終版本不一致，並保留例外核准與補正歷程。

比對報價承諾、分包契約、用印申請與公司授權層級，攔截工地人員先簽後補、超額承諾或最終版本不一致，並保留例外核准與補正歷程。

**產業別：**營建工程　|　**系統類型：**legal-case

## 功能模組

- **授權矩陣** — 維護職級、契約類型與金額權限。
- **待簽文件送審** — 提交報價、契約、附件及交易對象。
- **權限自動檢核** — 比對簽署人、金額與特殊條款門檻。
- **用印版本比對** — 標示核准版與最終版的文字差異。
- **例外核准** — 處理急件、超權及事後補正申請。
- **簽署成果歸檔** — 保存簽署版、日期與有效授權證據。

## 適合誰使用

- 合約管理員
- 法務人員
- 專案主管

## 運作流程

1. 提交待簽文件
2. 檢查授權層級
3. 辦理法律審閱
4. 核准用印版本
5. 完成簽署用印
6. 稽核成果歸檔

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
