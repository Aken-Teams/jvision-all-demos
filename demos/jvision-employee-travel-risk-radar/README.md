## 功能模組

- **差旅行程地圖** — 呈現員工所在城市、轉機點、住宿與後續移動路線。
- **目的地安全監測** — 追蹤治安、衝突、示威與官方旅遊警示的變化。
- **天候交通預警** — 評估極端天氣對航班、鐵路與地面移動的影響。
- **健康疫情監測** — 追蹤疫情趨勢、入境限制、檢疫與醫療量能。
- **罷工事件雷達** — 辨識航空、鐵路、機場與公共服務罷工的波及範圍。
- **行程調整模擬** — 比較改期、改道、撤離與取消方案的成本及風險。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 匯入差旅行程
2. 掃描外部風險
3. 評估員工曝險
4. 模擬調整方案
5. 核准行程異動
6. 通知並確認安全

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
