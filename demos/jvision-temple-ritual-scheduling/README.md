## 功能模組

- **法會總覽** — 查看梯次、受理量、校對與輸出進度。
- **牌位登錄** — 建立陽上、先亡、地址及功德項目資料。
- **資料校對** — 檢查缺字、重複、格式及關係欄位。
- **信眾確認** — 記錄校稿版本、回覆與修改內容。
- **壇位配置** — 依類型、梯次與區域安排牌位位置。
- **輸出交付** — 管理列印批次、補印與現場完成狀態。

## 適合誰使用

- 法會行政
- 知客人員
- 執事主管

## 運作流程

1. 建立法會
2. 登錄牌位
3. 執行校對
4. 取得確認
5. 安排壇位
6. 完成輸出

## 導入效益

- 活動籌備工時：20小時 → **5小時**
- 報名掌握率：65% → **94%**
- 物資盤點：6小時 → **1小時**
- 志工調度時效：3天 → **1天**
