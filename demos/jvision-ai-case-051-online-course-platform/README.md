# 線上課程成長艙

> 課程、學員、測驗到學習進度的教學管理

管理課程上架、購課、進度與學習回饋。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**教育　|　**系統類型：**學習管理平台

## 功能模組

- **課程管理** — 課程、單元與教材
- **學員管理** — 名冊、分班與出勤
- **作業測驗** — 派題、批改與成績
- **學習進度** — 進度追蹤與提醒
- **學習輔導** — 提問與輔導紀錄
- **證書結業** — 結業與證照管理

## 適合誰使用

- 教務專員
- 教務主任
- 機構負責人

## 運作流程

1. 待安排
2. 進行中
3. 待確認
4. 已完成

## 導入效益

- 排課作業工時：5.9小時/週 → **1.6小時/週**
- 作業批改時效：5天 → **1.1天**
- 出席掌握率：71% → **89%**
- 學習進度可視：47% → **86%**
