Tool reference

refund_order

在符合退款政策且具備授權的情況下，對指定訂單執行全額或部分退款。呼叫前應先取得明確的使用者確認。

refund_order(order_id, amount, currency, reason, idempotency_key) → RefundResult

參數定義

參數型別必要限制
order_idstring是格式 ORD-#####
amountnumber是大於 0，不得超過可退餘額
currencystring是ISO 4217 三碼
reasonstring是10–300 字元
idempotency_keystring是每次退款意圖唯一，保留 24 小時

安全使用範例

{ "order_id": "ORD-88216", "amount": 1280, "currency": "TWD", "reason": "商品未送達，顧客已確認退款", "idempotency_key": "refund_ORD-88216_20260822_a91f" }

限制與恢復

每筆訂單每日最多嘗試 3 次。若收到 MCP_TIMEOUT，必須使用相同冪等鍵重試；若收到 POLICY_DENIED，不得自行放寬金額或改用其他身分。
