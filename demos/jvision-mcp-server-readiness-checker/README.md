## 功能模組

- **Schema 相容驗** — 檢查工具輸入輸出型別、必填欄位與版本相容性。
- **錯誤契約測試** — 注入逾時、無效參數與下游失敗，驗證錯誤碼及回應結構。
- **授權邊界驗證** — 測試最小權限、租戶隔離、憑證範圍與拒絕存取行為。
- **冪等重試檢查** — 重送寫入請求並驗證冪等鍵、重複副作用與恢復策略。
- **工具文件校驗** — 比對工具描述、參數範例、限制條件與實際服務行為。
- **上架門檻評估** — 彙總阻斷缺陷、風險分數與修正優先序，產生就緒結論。
