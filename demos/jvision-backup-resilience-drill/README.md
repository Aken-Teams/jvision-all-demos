# 備份韌性災難復原演練台

> 集中盤點企業系統、備份副本與復原依賴關係，由人工智慧檢查備份缺口、規劃災難情境、模擬復原流程並產出演練報告，協助資訊人員在事故前確認關鍵服務能於目標時間內恢復。

集中盤點企業系統、備份副本與復原依賴關係，由人工智慧檢查備份缺口、規劃災難情境、模擬復原流程並產出演練報告，協助資訊人員在事故前確認關鍵服務能於目標時間內恢復。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **韌性總覽** — 彙整關鍵系統、備份健康度、復原目標與待處理風險。
- **依賴關係盤點** — 以拓樸圖呈現服務、資料庫、備份副本及復原先後關係。
- **備份風險檢查** — 辨識過期副本、單一儲存位置、排程失敗與復原缺口。
- **災難情境設計** — 建立勒索攻擊、機房中斷、誤刪資料等模擬劇本。
- **復原演練室** — 依劇本逐步執行任務、記錄耗時、阻礙與替代方案。
- **演練報告** — 比較目標與實績，整理缺失、責任人及改善期限。

## 適合誰使用

- 資訊主管
- 系統管理員
- 營運持續管理人員

## 運作流程

1. 掌握韌性現況
2. 確認復原依賴
3. 檢查備份缺口
4. 建立演練劇本
5. 執行復原演練
6. 追蹤改善結案
