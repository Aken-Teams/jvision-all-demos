# 跨廠調撥管理系統（Inter-Plant Transfer Management）

> 收貨到出貨的倉內作業與庫存精準管理

跨廠調撥管理系統（Inter-Plant Transfer Management）提供調撥申請與審核流程、調撥出貨與到貨確認、跨廠庫存帳務轉移。倉儲部依「調撥申請→審核→出貨→在途追蹤→到貨驗收→帳務過帳」推進作業，優先解決「跨廠調撥資訊不透明」，生管部則以調撥時效與在途庫存準確率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**倉儲物流　|　**系統類型：**WMS 倉儲管理系統

## 功能模組

- **入庫上架** — 收貨、驗收與智慧上架
- **揀貨出貨** — 波次揀貨、覆核與出貨
- **儲位管理** — 儲位規劃與庫容視覺化
- **庫存盤點** — 即時庫存、盤點與調撥
- **拉動補料** — 安全庫存與自動補貨
- **條碼作業** — PDA 掃碼即時作業

## 適合誰使用

- 倉儲部
- 生管部
- 財務部

## 運作流程

1. 待盤點
2. 待補貨
3. 移庫中
4. 出庫完成

## 導入效益

- 揀貨作業工時：7.1小時/日 → **2小時/日**
- 庫存準確率：93% → **99%**
- 出貨延遲率：8.6% → **1.9%**
- 盤點工時：16小時/月 → **2.9小時/月**
