# 配電故障預警巡檢系統

> 運用變壓器、開關盤與配電線路的擬真量測及維修紀錄產生故障風險評分，協助維護團隊解讀異常徵兆、建立巡檢優先序、安排人員路線，並以工單追蹤缺失處理。

運用變壓器、開關盤與配電線路的擬真量測及維修紀錄產生故障風險評分，協助維護團隊解讀異常徵兆、建立巡檢優先序、安排人員路線，並以工單追蹤缺失處理。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **設備健康總覽** — 彙整配電區域、設備健康分數、風險層級與維護待辦。
- **故障風險預警** — 列出高風險設備、可能故障模式、異常趨勢與影響範圍。
- **設備關聯圖譜** — 用單線圖式介面呈現上下游供電關係及故障可能波及的負載。
- **巡檢排程中心** — 依風險、技能、工時與區域編排巡檢日期、人員和檢查項目。
- **巡檢路線規劃** — 將同區任務組成巡檢路線，顯示順序、預估時間及必要工具。
- **缺失工單追蹤** — 記錄擬真巡檢結果、照片占位、缺失分級與修復結案狀態。

## 適合誰使用

- 電機維護工程師
- 巡檢班長
- 廠務主管

## 運作流程

1. 檢視健康態勢
2. 研判故障預警
3. 確認影響範圍
4. 安排巡檢班次
5. 規劃巡檢路線
6. 回報處理缺失

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
