# 保險通路獎金覆核台

> 依活動版本計算保單承保、繳費、撤銷及跨期補件對通路獎金的影響，攔截重發、未授權加碼與錯誤扣繳，提供逐人可追溯明細。

依活動版本計算保單承保、繳費、撤銷及跨期補件對通路獎金的影響，攔截重發、未授權加碼與錯誤扣繳，提供逐人可追溯明細。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **活動規則** — 管理期間門檻與加碼
- **合格保單** — 核對承保繳費與撤銷
- **獎金試算** — 逐人套用版本及級距
- **跨期調整** — 處理補件撤銷與追扣
- **主管覆核** — 檢查例外加碼與授權
- **付款扣繳** — 產出發放與稅務明細

## 適合誰使用

- 通路管理員
- 獎金會計
- 業務主管

## 運作流程

1. 鎖定活動版本
2. 彙整合格保單
3. 計算通路獎金
4. 處理跨期異動
5. 覆核例外金額
6. 完成付款扣繳

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
