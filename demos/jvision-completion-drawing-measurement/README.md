# 竣工圖現場校核台

> 在工項封閉與交屋前，依系統及區域核對竣工圖與實際管線、閥件、設備和檢修口位置，管理紅線修正、缺漏補測與版次會簽，確保交付圖資可供後續維運。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **校核分包** — 依棟別、樓層、系統及封閉時點建立工作包。
- **現場點核** — 逐點核對設備、閥件、管線與檢修口位置。
- **紅線修正** — 在圖面標記位移、增刪、改徑及編號變更。
- **缺漏補測** — 指派尺寸、標高、路徑與定位資料補測。
- **專業覆核** — 由施工、設計與監造檢查圖資可讀性及完整性。
- **交付版發布** — 鎖定核准版次並產出圖冊與移交清單。

## 適合誰使用

- 竣工圖工程師
- 機電工程師
- 監造工程師

## 運作流程

1. 建立圖面校核包
2. 執行現場點核
3. 標註圖實差異
4. 完成缺漏補測
5. 辦理專業覆核
6. 發布竣工交付版

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
