# 智慧現金流預測調度助手

> 彙整應收應付、薪資、稅款、貸款與計畫支出，建立短中期現金流預測，透過收付延遲與情境假設辨識資金缺口，並比較帳戶移轉、借款或付款調整等調度方案。

彙整應收應付、薪資、稅款、貸款與計畫支出，建立短中期現金流預測，透過收付延遲與情境假設辨識資金缺口，並比較帳戶移轉、借款或付款調整等調度方案。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **資金部位總覽** — 彙整各帳戶餘額、受限資金與可動用額度。
- **現金流預測** — 按週呈現營運、投資及融資收支與期末餘額。
- **收付假設調整** — 調整回款率、付款日、薪資、稅款及重大支出。
- **缺口預警中心** — 標示低於安全水位的日期、金額與主要成因。
- **資金調度模擬** — 比較帳戶移轉、動用額度及延後付款等方案。
- **調度核准作業** — 彙整成本、風險與調度指示供主管審批。

## 適合誰使用

- 資金專員
- 財務主管
- 會計主管與總經理

## 運作流程

1. 確認資金部位
2. 產生基準預測
3. 修正收付假設
4. 辨識資金缺口
5. 比較調度方案
6. 核准資金指示

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
