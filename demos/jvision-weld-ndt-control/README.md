# 焊道非破壞檢測台

> 以焊口編號整合焊工、施工日期、抽驗比例、檢測排程、報告判定與返修複驗，避免檢測報告對錯位置、漏抽焊道，或返修完成後未重新檢測便進入後續工序。

以焊口編號整合焊工、施工日期、抽驗比例、檢測排程、報告判定與返修複驗，避免檢測報告對錯位置、漏抽焊道，或返修完成後未重新檢測便進入後續工序。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **焊口圖台** — 定位構件、樓層與焊口唯一編號。
- **焊工紀錄** — 連結施焊人員、資格與施工日期。
- **抽驗選樣** — 依契約比例與規則產生檢測清單。
- **檢測排程** — 安排方法、時段及檢測廠商。
- **報告判定** — 登錄結果並比對焊口及驗收標準。
- **返修複驗** — 追蹤修磨、補焊與再次檢測。

## 適合誰使用

- 鋼構工程師
- 品管工程師
- 檢測廠商

## 運作流程

1. 建立焊口
2. 登錄施焊
3. 選定抽驗
4. 執行檢測
5. 判讀報告
6. 返修放行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
