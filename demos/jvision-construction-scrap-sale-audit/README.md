# 營建廢料變賣稽核台

> 管理廢鋼材等可變賣物料的分類、估重、詢價、過磅、出場及收款，建立現場、回收商與財務三方證據，防止少報重量或款項未繳回。

管理廢鋼材等可變賣物料的分類、估重、詢價、過磅、出場及收款，建立現場、回收商與財務三方證據，防止少報重量或款項未繳回。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **廢料清冊** — 查看類別位置與估量
- **回收詢價** — 記錄多家報價與條件
- **過磅核對** — 比較空重毛重與淨重
- **出場管制** — 確認車輛品項及數量
- **收款配對** — 核對匯款現金與發票
- **稽核追蹤** — 辨識低價少重與缺證

## 適合誰使用

- 材料管理員
- 採購人員
- 稽核人員

## 運作流程

1. 申報廢料
2. 取得報價
3. 核准出售
4. 過磅出場
5. 收取款項
6. 三方稽核

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
