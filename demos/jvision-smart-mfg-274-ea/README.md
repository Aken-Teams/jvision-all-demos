# 企業架構管理管理艙

以架構藍圖方式盤點企業IT應用、資料與基礎設施現況，支援IT投資規劃與系統合理化決策。

- 原始系統：企業架構管理平台（EA）
- 產業分類：智慧製造｜IT管理
- 使用部門：資訊部、資訊長辦公室、財務部、各事業處
- 工作流程：盤點現有應用與技術→建立架構地圖→分析重複/過時系統→提出優化路線圖→治理委員會審議→追蹤執行進度
- AI 應用：系統依賴關係自動探勘、技術債風險評分建議
- 主要 KPI：系統合理化完成率、架構標準遵循率、IT投資ROI、過時系統汰換進度
- 代表產品：LeanIX、Ardoq、Sparx Systems Enterprise Architect
