# 企業架構管理平台（EA）

> 服務工單、資產到即時監控的 IT 維運

企業架構管理平台（EA）提供應用系統清冊與依賴關係圖、技術債與過時系統標註、IT投資組合分析。資訊部依「盤點現有應用與技術→建立架構地圖→分析重複/過時系統→提出優化路線圖→治理委員會審議→追蹤執行進度」推進作業，優先解決「系統重複建置資源浪費」，資訊長辦公室則以系統合理化完成率與架構標準遵循率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**資訊科技　|　**系統類型：**IT 維運管理平台

## 功能模組

- **服務工單** — 事件/請求工單管理
- **資產管理** — IT 資產與軟體授權
- **即時監控** — 系統/網路健康監控
- **告警事件** — 告警彙整與分派
- **變更發布** — 變更與發布管理
- **服務報表** — SLA 與可用率報表

## 適合誰使用

- 資訊部
- 資訊長辦公室
- 財務部
