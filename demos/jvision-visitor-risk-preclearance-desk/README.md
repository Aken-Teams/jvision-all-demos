# 訪客風險預審台

> 依訪客身分、來源、來訪目的與進入區域預先分級，加速安全放行。＂ 服務估值風險

**產業別：**企業協作　|　**系統類型：**security-soc

## 功能模組

- **訪客身分解析** — 擷取姓名、公司、證件與聯絡方式並檢查一致性。
- **來源可信查核** — 核對受邀關係、公司背景、主辦人與歷史來訪紀錄。
- **來訪目的判讀** — 分類拜訪、維修、交付或稽核目的並辨識敏感事項。
- **進入區域評估** — 依申請區域、設備接觸與陪同要求計算暴露風險。
- **訪客風險分級** — 產生風險等級、信心分數、原因與補件建議。
- **預審放行決策** — 核准通行範圍、時段、陪同條件或轉交安全複核。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 建立訪客預審案
2. 核驗身分來源
3. 分析目的與區域
4. 產生風險分級
5. 處理高風險案件
6. 發布預審結果
