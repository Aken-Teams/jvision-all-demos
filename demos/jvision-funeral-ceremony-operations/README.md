# 禮儀治喪流程協作台

> 供禮儀公司管理治喪案件的家屬需求、儀式日程、場地物品、人員分工、文件申辦與尾款確認，讓多場同時進行的服務維持一致品質並避免遺漏。

供禮儀公司管理治喪案件的家屬需求、儀式日程、場地物品、人員分工、文件申辦與尾款確認，讓多場同時進行的服務維持一致品質並避免遺漏。

**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **治喪案件** — 彙整逝者資料、家屬窗口與服務方案。
- **儀式日程** — 安排接體、入殮、告別與火化時程。
- **任務協作** — 分派人員、期限與家屬確認事項。
- **場品準備** — 核對會場布置、用品與供應商交付。
- **文件申辦** — 追蹤證明、許可及火化相關文件。
- **費用結案** — 管理追加項目、尾款與服務回顧。

## 適合誰使用

- 禮儀師
- 治喪主任
- 行政人員

## 運作流程

1. 建立治喪案件
2. 編排儀式日程
3. 分派服務任務
4. 核對場品交付
5. 完成文件申辦
6. 確認費用結案

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
