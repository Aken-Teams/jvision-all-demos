# 閒置資金投資梯度助手

> 依現金期限、風險上限與流動性需求配置短期工具，提高閒置資金收益。

依現金期限、風險上限與流動性需求配置短期工具，提高閒置資金收益。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **可投資餘額測算** — 扣除營運緩衝與已知支出，計算可配置現金。
- **資金期限分桶** — 依每日、每週與每月現金需求建立到期梯度。
- **投資限制校驗** — 檢查信用評等、集中度、幣別與工具資格限制。
- **短期工具比價** — 比較存款、票券與貨幣市場工具的淨收益及風險。
- **梯度組合優化** — 產生兼顧收益、到期分散與可動用性的配置方案。
- **下單建議簽核** — 送審交易清單，保留報價依據並在失敗時撤回。

## 適合誰使用

- 財務長
- Treasurer
- 資金人員

## 運作流程

1. 確認可用現金
2. 設定期限梯度
3. 套用風險政策
4. 比較市場工具
5. 選定配置方案
6. 核准交易建議

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
