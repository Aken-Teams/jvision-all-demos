# MSA（Measurement System Analysis，量測系統分析）

> 從異常到改善的品質閉環與追溯稽核

MSA（Measurement System Analysis，量測系統分析）提供Gage R&R分析、偏倚/線性/穩定性研究、量測人員能力評估。品保部依「研究計畫設定→數據蒐集→統計分析→結果判讀→改善建議」推進作業，優先解決「量測數據可信度不明」，計量室則以Gage R&R通過率與量測系統重複再現性確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 品保部
- 計量室
- 製程工程部

## 運作流程

1. 待判定
2. 原因分析
3. 改善驗證
4. 已關閉

## 導入效益

- 批號追溯時間：191分鐘 → **14分鐘**
- 客訴平均關案：21天 → **9.2天**
- 改善驗證率：67% → **92%**
- 重複不良率：5.8% → **2%**
