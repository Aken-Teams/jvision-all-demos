# 工程測試試運轉管制台

> 管理機電系統完工後的單機測試、整合試運轉、測試前置條件、見證簽認及失敗改善，協助總包在移交業主前建立完整性能證據。

管理機電系統完工後的單機測試、整合試運轉、測試前置條件、見證簽認及失敗改善，協助總包在移交業主前建立完整性能證據。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **測試包總覽** — 依系統管理測試範圍
- **前置條件** — 確認圖說設備與環境
- **見證排程** — 安排測試與出席單位
- **結果紀錄** — 輸入讀值及測試判定
- **失敗改善** — 追蹤缺失原因與重測
- **移交簽認** — 彙整證據與核准狀態

## 適合誰使用

- 機電經理
- 品管工程師
- 業主代表

## 運作流程

1. 建立系統測試包
2. 確認測試條件
3. 安排聯合見證
4. 執行測試紀錄
5. 改善失敗項目
6. 完成系統移交

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
