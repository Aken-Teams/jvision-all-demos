> 供宮廟與宗教法人管理法會梯次、壇位席次、功德項目、登記資料、款項狀態及儀式名冊，讓服務台在有限容量下避免重複登記、漏列與金額差異。

**產業別：**宗教服務　|　**系統類型：**pos-frontdesk

## 功能模組

- **梯次席次** — 設定法會容量與壇位配置
- **功德登記** — 選擇項目並輸入祈福資料
- **款項核對** — 標記收款、退款與待補金額
- **儀式名冊** — 依梯次產生擬真唱名清單
- **登記異動** — 處理換梯、改名與取消需求
- **法會結算** — 彙整席次、項目及款項差異

## 適合誰使用

- 服務台人員
- 法會執事
- 廟務會計

## 運作流程

1. 設定法會梯次
2. 受理功德登記
3. 確認款項狀態
4. 編製儀式名冊
5. 處理登記異動
6. 完成法會結算
