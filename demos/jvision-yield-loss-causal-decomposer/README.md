# 良率損失因果分解器

> 分解材料、設備、參數與操作對良率損失的貢獻，鎖定改善重點。​

分解材料、設備、參數與操作對良率損失的貢獻，鎖定改善重點。​

**產業別：**生產製造　|　**系統類型：**quality-qms

## 功能模組

- **良率損失瀑布** — 按產品、批次、線別與缺陷類型拆解良率流失幅度。
- **製程因果網路** — 連結材料批次、設備狀態、參數變更與人員操作關係。
- **四因貢獻分解** — 量化材料、設備、參數與操作各自及交互作用的貢獻。
- **反事實驗證台** — 模擬替換材料或調整條件後，良率可能恢復的幅度。
- **改善焦點排行** — 依影響度、可信度、成本與可控性排序優先改善項目。
- **驗證試驗設計** — 產出製程試驗條件、樣本需求、成功門檻與停止規則。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 界定良率損失
2. 建構因果關係
3. 分解四因貢獻
4. 驗證關鍵假設
5. 核准改善焦點
6. 執行驗證試驗

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
