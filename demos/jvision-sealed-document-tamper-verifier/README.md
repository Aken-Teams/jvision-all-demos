## 功能模組

- **用印前指紋建檔** — 為核准版本建立雜湊、時間戳與文件識別碼。
- **版本差異比對** — 逐頁比較文字、數字、附件、頁序與版面變動。
- **關鍵欄位變更檢查** — 聚焦金額、對象、日期、義務與簽署欄位的差異。
- **印後完整性驗證** — 掃描已用印文件並核對核准版本與印章位置。
- **版本關聯圖** — 呈現草稿、核准稿、用印稿與外發稿之間的承接關係。
- **竄改疑警處置** — 彙整可疑變動，供管理員判定重印、作廢或升級調查。

## 適合誰使用

- 總務主管
- 行政人員
- 辦公室經理

## 運作流程

1. 鎖定核准版本
2. 建立文件雜湊
3. 執行用印
4. 比對印前印後
5. 複核可疑變動
6. 確認外發版本
