# 架構決策紀錄 Agent

> 從技術討論形成可追溯的 ADR，持續追蹤決策假設、後果與失效條件。

從技術討論形成可追溯的 ADR，持續追蹤決策假設、後果與失效條件。

**產業別：**資訊科技　|　**系統類型：**collaboration-pm

## 功能模組

- **架構討論聚合** — 彙整會議、Issue、PR與聊天中的架構討論及引用來源。
- **方案脈絡辨識** — 整理問題背景、限制條件、候選方案與權衡理由。
- **ADR 草案生成** — 依標準格式產生狀態、決策、理由及替代方案紀錄。
- **假設驗證清單** — 登錄支撐決策的技術與業務假設、指標及驗證期限。
- **後果影響追蹤** — 追蹤決策對服務、成本、維運、安全與團隊的實際後果。
- **決策生命週期** — 管理ADR提議、核准、取代、廢棄與重新評估狀態。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 收斂討論來源
2. 整理方案脈絡
3. 編修 ADR 草案
4. 登錄關鍵假設
5. 評估實際後果
6. 更新決策狀態
