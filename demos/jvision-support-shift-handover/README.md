# 客服交班風險管理台

> 將跨班別未結案件、客戶承諾、待回覆期限、重大故障與升級風險整理成結構化交班包，讓接班主管逐項確認承接人與下一步，避免資訊斷層。

將跨班別未結案件、客戶承諾、待回覆期限、重大故障與升級風險整理成結構化交班包，讓接班主管逐項確認承接人與下一步，避免資訊斷層。

**產業別：**客服管理　|　**系統類型：**service-desk

## 功能模組

- **待交班清單** — 彙整跨班未結工作
- **風險分級** — 標示重大與即將逾期
- **責任承接** — 指派接班處理人員
- **承諾脈絡** — 呈現客戶承諾與紀錄
- **接班確認** — 逐項確認資訊完整性
- **遺漏復盤** — 分析交班失誤原因

## 適合誰使用

- 客服組長
- 值班主管
- 一線客服

## 運作流程

1. 彙整案件
2. 標示風險
3. 補充脈絡
4. 指派承接
5. 確認接班
6. 復盤遺漏

## 導入效益

- 首次回應時間：30分鐘 → **5分鐘**
- 一次解決率：60% → **88%**
- 客訴關案：5天 → **2天**
- 滿意度：72% → **92%**
