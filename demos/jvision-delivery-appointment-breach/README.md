# 配送預約失約歸因台

> 比對預約時窗、司機到場、聯絡與客戶簽認，判斷早到、遲到、客戶不在或現場拒收，形成二次配送及違約費用依據，並分析失約根因。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **預約明細** — 查看承諾時窗與變更
- **到場證據** — 整理時間位置照片聯絡
- **時序還原** — 比較承諾與實際事件
- **責任歸因** — 裁定車隊客戶或現場
- **費用處置** — 核定重送費或補償
- **根因分析** — 比較路線客戶與司機

## 適合誰使用

- 客服人員
- 配送主管
- 客戶經理

## 運作流程

1. 建立爭議
2. 蒐集證據
3. 還原時序
4. 裁定責任
5. 處理費用
6. 檢討根因

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
