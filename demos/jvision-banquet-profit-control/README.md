# 宴會場次毛利管制台

> 協助飯店宴會與婚宴團隊整合場地檔期、桌數版本、菜單成本、臨時加購及場次結算，讓業務與餐飲主管在活動前掌握毛利缺口並追蹤待確認事項。

協助飯店宴會與婚宴團隊整合場地檔期、桌數版本、菜單成本、臨時加購及場次結算，讓業務與餐飲主管在活動前掌握毛利缺口並追蹤待確認事項。

**產業別：**餐飲旅宿　|　**系統類型：**pos-frontdesk

## 功能模組

- **宴會檔期** — 查看場地占用與場次狀態
- **報價版本** — 管理桌數及方案變更
- **菜單成本** — 試算食材與酒水成本
- **現場加購** — 登錄設備與服務追加
- **毛利警示** — 標示低毛利及漏收風險
- **場次結算** — 比較預估與實際損益

## 適合誰使用

- 宴會業務
- 餐飲主管
- 財務專員

## 運作流程

1. 建立場次
2. 編製報價
3. 核算成本
4. 登錄追加
5. 檢查毛利
6. 完成結算

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
