# 病理檢體補件追蹤台

> 集中管理病理檢體退件、缺件原因、原單位補件、重採決策與交班狀態，使每支檢體均可追到目前位置、責任人及處理時限，降低錯配與報告延誤。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **收退件台** — 登錄缺件檢體
- **缺失判定** — 標記補正要求
- **責任派送** — 通知原採檢站
- **流向追蹤** — 記錄交接位置
- **逾期升級** — 處理延誤風險
- **補件結案** — 驗證完整性

## 適合誰使用

- 病理科人員
- 採檢單位護理師
- 醫檢主管

## 運作流程

1. 登錄退件
2. 判定缺失
3. 通知補件
4. 交接檢體
5. 處理逾期
6. 驗收結案

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
