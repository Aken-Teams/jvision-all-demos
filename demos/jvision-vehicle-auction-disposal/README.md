# 退役車輛標售管理台

> 協助租車、客運與企業車隊辦理車輛退役評估、整備估價、標售批次、買方出價、文件過戶及處分損益，讓汰換流程具備一致標準與稽核紀錄。

協助租車、客運與企業車隊辦理車輛退役評估、整備估價、標售批次、買方出價、文件過戶及處分損益，讓汰換流程具備一致標準與稽核紀錄。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **退役清單** — 依車齡、里程、維修成本與殘值篩選汰換對象。
- **車況整備** — 記錄外觀、機件、附件與出售前必要整備項目。
- **估價底價** — 比較帳面價值、外部估價及建議標售底價。
- **標售作業** — 建立批次、邀請買方並彙整各輪出價。
- **成交過戶** — 追蹤核決、收款、交車及監理文件完成狀態。
- **處分損益** — 計算整備費、成交淨額與資產處分損益。

## 適合誰使用

- 車隊資產專員
- 採購主管
- 財務會計

## 運作流程

1. 提報車輛退役
2. 完成車況整備
3. 核定標售底價
4. 執行買方比價
5. 辦理交車過戶
6. 認列處分損益

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
