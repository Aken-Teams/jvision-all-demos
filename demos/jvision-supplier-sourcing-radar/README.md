# 供應商尋源與替代方案雷達

> 集中整理候選供應商、供貨能力、認證、區域與品類覆蓋，透過條件配對呈現新來源及替代方案。採購可用情境模擬比較成本、交期與風險，建立可追蹤的尋源名單與接洽優先序。

集中整理候選供應商、供貨能力、認證、區域與品類覆蓋，透過條件配對呈現新來源及替代方案。採購可用情境模擬比較成本、交期與風險，建立可追蹤的尋源名單與接洽優先序。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **尋源條件設定** — 設定品類、規格、產能、地區、認證與交期等篩選條件。
- **候選供應商雷達** — 以配對分數及能力標籤呈現符合條件的潛在來源。
- **替代方案比較** — 並列比較候選方案的成本、交期、認證與供應限制。
- **供應網路地圖** — 呈現供應商所在地、品類關係及單一來源集中情形。
- **資格驗證看板** — 追蹤保密協議、問卷、送樣、稽核及試產的完成狀態。
- **接洽行動清單** — 安排邀請、補件與追蹤任務，保留每次互動紀錄。

## 適合誰使用

- 策略採購
- 供應鏈主管
- 供應商開發人員

## 運作流程

1. 定義尋源條件
2. 探索候選來源
3. 比較替代方案
4. 檢查供應布局
5. 推進資格驗證
6. 確認接洽優先序

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
