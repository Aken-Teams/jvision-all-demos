**產業別：**財務會計　|　**系統類型：**operations-console

## 功能模組

- **日內資金時間軸** — 逐時呈現各銀行帳戶的預計收付與可用餘額。
- **短暫缺口預警** — 預測付款落點造成的瞬間負餘額與透支風險。
- **付款時點校準** — 比對付款批次、到期條件及實際入扣帳規律。
- **帳戶調撥規劃** — 產生跨帳戶、跨銀行與跨幣別的補位方案。
- **調度草案審核** — 集中檢視調撥金額、成本、限制與來源依據。
- **日內處置台** — 核准調撥或付款排序，並追蹤缺口是否解除。

## 適合誰使用

- 財務長
- Treasurer
- 資金人員

## 運作流程

1. 掌握日內部位
2. 確認缺口預警
3. 校正付款時點
4. 產生調撥方案
5. 審核處置草案
6. 核准並監控

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
