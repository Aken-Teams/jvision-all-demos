# 建照期限文件管制台

> 依建照案件集中管理開工、展期、變更設計與各階段申報的法定期限、應備文件、公文往返及補正意見，將每項責任與前置依賴排成時程，避免承辦異動或休假造成逾期失效。

依建照案件集中管理開工、展期、變更設計與各階段申報的法定期限、應備文件、公文往返及補正意見，將每項責任與前置依賴排成時程，避免承辦異動或休假造成逾期失效。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **建照案件** — 彙整許可字號、基地、主管機關與有效期間。
- **期限日曆** — 計算開工、展期、勘驗及變更申報節點。
- **文件套組** — 依程序列出表單、圖說、證明及簽章狀態。
- **責任催辦** — 分派顧問與內部承辦並設定代理處理人。
- **公文補正** — 記錄收發日期、補正要求與再次送件版本。
- **期限推演** — 期限或程序異動後重算下游影響與風險。

## 適合誰使用

- 建照專員
- 專案經理
- 設計顧問

## 運作流程

1. 建立案件
2. 展開期限
3. 盤點文件
4. 分派催辦
5. 送件補正
6. 重算預警

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
