# 校車乘車名冊管理台

> 供幼兒園與學校管理校車路線、學生乘車名冊、站點異動、接送授權及每日點名紀錄，以模擬狀態完成調度與異常追蹤，不依賴定位硬體也能展示完整作業。

供幼兒園與學校管理校車路線、學生乘車名冊、站點異動、接送授權及每日點名紀錄，以模擬狀態完成調度與異常追蹤，不依賴定位硬體也能展示完整作業。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **路線總覽** — 查看各路線、站點、乘載與異動提醒。
- **乘車名冊** — 配置學生固定路線、班次及上下車站。
- **異動申請** — 審核請假、換站與單次停搭需求。
- **接送授權** — 維護可接送人、關係及驗證備註。
- **每日點名** — 模擬記錄上車、未到、下車與交接狀態。
- **異常追蹤** — 處理漏點、錯站及未授權交接事件。

## 適合誰使用

- 校務行政
- 隨車人員
- 校車主管

## 運作流程

1. 檢視路線
2. 更新名冊
3. 審核異動
4. 核對授權
5. 執行點名
6. 結清異常

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
