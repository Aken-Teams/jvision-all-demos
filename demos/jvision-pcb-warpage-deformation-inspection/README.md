# 印刷電路板翹曲變形檢測

> 整理印刷電路板各量測點高度、板厚、尺寸與批次條件，將翹曲方向、變形程度及超規區域視覺化，協助品管快速判定允收結果，並追查料號與製程條件的異常趨勢。

整理印刷電路板各量測點高度、板厚、尺寸與批次條件，將翹曲方向、變形程度及超規區域視覺化，協助品管快速判定允收結果，並追查料號與製程條件的異常趨勢。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **翹曲監控總覽** — 彙整待檢板件、超規率、最大變形量與異常批次。
- **板面量測建檔** — 建立模擬量測點、高度值、板厚與批次製程條件。
- **變形圖譜分析** — 以等高圖及剖面圖呈現翹曲方向和超規區域。
- **允收判定工作台** — 依料號規格比較量測結果並記錄放行或不合格結論。
- **改善案件追蹤** — 建立原因調查、批次隔離及製程改善的追蹤事項。
- **翹曲趨勢報表** — 比較料號、板厚、製程與日期區間的變形趨勢。

## 適合誰使用

- 印刷電路板品管工程師
- 製程工程師與品質主管

## 運作流程

1. 確認異常概況
2. 建立量測資料
3. 判讀變形圖譜
4. 完成允收判定
5. 啟動改善追蹤
6. 檢討長期趨勢

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
