# 堆高機交班缺陷鎖車台

> 供工廠駕駛交班前檢查煞車、油路、貨叉、輪胎與警示器，重大缺陷立即鎖車並轉維修工單，修復複驗後才恢復可借用狀態。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **車輛總覽** — 查看可用鎖車狀態
- **交班點檢** — 逐項檢查車況
- **缺陷鎖車** — 禁止重大缺陷使用
- **維修工單** — 記錄故障處置
- **修後複驗** — 確認安全功能
- **交班履歷** — 追查駕駛與缺陷

## 適合誰使用

- 堆高機駕駛
- 維修技師

## 運作流程

1. 駕駛接車
2. 班前點檢
3. 缺陷分級
4. 維修處理
5. 安全複驗
6. 交班解鎖

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
