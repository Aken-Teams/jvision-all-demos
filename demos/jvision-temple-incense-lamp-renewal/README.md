## 功能模組

- **祈福項目** — 設定燈種、期間、費用與名額。
- **信眾名冊** — 管理姓名、生辰及聯絡資料。
- **到期續點** — 彙整可沿用的前期登記。
- **燈位配置** — 安排燈位並檢查重複占用。
- **款項核對** — 登錄收款、代辦與退款狀態。
- **安奉批次** — 整理儀式批次與完成清冊。

## 適合誰使用

- 宮廟服務台
- 會計人員
- 廟務主管

## 運作流程

1. 開放項目
2. 查找舊戶
3. 校對資料
4. 配置燈位
5. 核對款項
6. 完成安奉
