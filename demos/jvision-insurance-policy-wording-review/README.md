## 功能模組

- **條款草案** — 建立商品條款章節與版本基線。
- **版本比對** — 逐條顯示文字增刪及修訂來源。
- **會簽意見** — 彙整法務、精算與法遵審查意見。
- **依據連結** — 關聯精算假設、法規及內部政策。
- **核准流程** — 追蹤各層級會簽與退回事由。
- **正式發布** — 鎖定核准稿並控管使用版本。

## 適合誰使用

- 商品企劃
- 保險法務
- 法遵人員

## 運作流程

1. 建立草案
2. 執行比對
3. 跨部會簽
4. 處理衝突
5. 取得核准
6. 發布鎖版
