# 設備進場吊裝整備台

> 在大型機電設備到貨前，整合設備尺寸重量、運輸車輛、卸貨位置、吊點承載、搬運路徑、門洞與基座條件，逐項確認許可與責任人，避免設備抵達後才發現無法卸貨、通行或就位。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **設備批次** — 管理設備規格、包裝尺寸、重量與到貨時窗。
- **搬運路徑** — 分段標示卸貨、吊運、轉向、門洞與就位點。
- **吊裝條件** — 核對吊點、吊具、起重機能力與地坪承載。
- **現勘檢核** — 確認通道、臨設、基座、電源與保護措施。
- **障礙處置** — 指派門洞不足、占用或前置工程未完成事項。
- **進場放行** — 彙整簽認結果並發布設備進場作業單。

## 適合誰使用

- 機電工程師
- 吊裝工程師
- 設備供應商

## 運作流程

1. 建立批次
2. 規劃路徑
3. 核算吊裝
4. 聯合現勘
5. 排除障礙
6. 核發進場

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
