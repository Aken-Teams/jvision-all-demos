## 功能模組

- **檢索健康掃描** — 持續統計零命中、低相關與正確片段漏排等失敗訊號。
- **失敗案例剖析** — 重播查詢與檢索結果，對照評測集中的期望文件。
- **文件覆蓋診斷** — 判斷知識庫是否根本缺少回答問題所需的文件。
- **切塊失真診斷** — 辨識語意被截斷、上下文分離或結構遺失問題。
- **查詢與排序診斷** — 區分查詢改寫偏移、召回不足與重排模型誤判。
- **修復情境模擬** — 預估補文件、重切塊、改寫查詢或換排序器的成效。

## 適合誰使用

- AI 架構師
- 資料科學家
- 應用負責人

## 運作流程

1. 掃描失敗訊號
2. 重播失敗案例
3. 核對文件覆蓋
4. 檢查切塊品質
5. 隔離查詢與排序問題
6. 排定修復任務
