# 宮廟光明燈位管理台

> 供宮廟管理年度光明燈、太歲燈等燈種的燈位配置、信眾資料核對、批次安奉、牌位更正、到期續點及現場查詢，減少重號、錯字與漏安奉。

供宮廟管理年度光明燈、太歲燈等燈種的燈位配置、信眾資料核對、批次安奉、牌位更正、到期續點及現場查詢，減少重號、錯字與漏安奉。

**產業別：**宗教服務　|　**系統類型：**operations-console

## 功能模組

- **燈種燈位** — 管理燈區、編號、容量與可用狀態。
- **點燈受理** — 登錄信眾、祈福資料與燈種。
- **燈位配置** — 依規則批次排位並避免重號。
- **名牌校對** — 檢查姓名、生辰與牌位文字。
- **安奉進度** — 追蹤製牌、裝設與完成批次。
- **續點更正** — 辦理年度續點、換位與資料修正。

## 適合誰使用

- 宮廟櫃台人員
- 點燈組長
- 廟務主管

## 運作流程

1. 設定年度燈位
2. 受理信眾點燈
3. 執行燈位配置
4. 完成名牌校對
5. 確認安奉完成
6. 辦理續點更正

## 導入效益

- 活動籌備工時：20小時 → **5小時**
- 報名掌握率：65% → **94%**
- 物資盤點：6小時 → **1小時**
- 志工調度時效：3天 → **1天**
