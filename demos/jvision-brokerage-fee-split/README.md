# 房仲服務費拆帳台

> 管理成交案件的跨店聯賣、開發與銷售角色、服務費折讓及獎金拆分，並在撤銷成交時自動形成沖回待辦與確認紀錄。

管理成交案件的跨店聯賣、開發與銷售角色、服務費折讓及獎金拆分，並在撤銷成交時自動形成沖回待辦與確認紀錄。

**產業別：**房地產與物業　|　**系統類型：**sales-crm

## 功能模組

- **成交案件** — 查看物件、服務費與狀態。
- **角色分工** — 設定開發、銷售與協作人員。
- **拆帳規則** — 計算跨店及個人比例。
- **比例確認** — 收集參與人員簽認。
- **撤銷沖回** — 處理折讓與成交取消。
- **獎金結算** — 形成薪獎底稿與差異。

## 適合誰使用

- 店務主管
- 薪酬專員
- 房仲經紀人

## 運作流程

1. 建立成交
2. 確認角色
3. 計算拆帳
4. 取得簽認
5. 處理異動
6. 結算獎金

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
