# 利率重設風險雷達

> 追蹤浮動利率債務重設與現金流敏感度，協助財務團隊提前鎖定成本。

追蹤浮動利率債務重設與現金流敏感度，協助財務團隊提前鎖定成本。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **浮動債務簿** — 彙整貸款、循環額度、基準利率、利差與未償本金。
- **重設期限帶** — 按日期與幣別呈現即將重設的利率曝險集中度。
- **利率曲線情境** — 模擬升息、降息及曲線位移對利息成本的影響。
- **現金流敏感度** — 量化各期間利息支出、自由現金流與償債餘裕變化。
- **鎖息方案比較** — 比較固定化、掉期、上限選擇權及提前償還方案。
- **鎖定成本決策** — 形成核准用的交易時點、名目本金與成本區間建議。

## 適合誰使用

- 財務長
- Treasurer
- 資金人員

## 運作流程

1. 彙整浮動曝險
2. 定位重設高峰
3. 設定利率情境
4. 衡量現金衝擊
5. 比較鎖息工具
6. 核准鎖定策略

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
