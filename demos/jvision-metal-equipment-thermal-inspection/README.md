**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **巡檢路線** — 依廠區、設備與風險安排每日點位及完成進度。
- **熱像判讀** — 查看熱像與可見光對照，標註熱點、溫差及區域。
- **溫升趨勢** — 比較點位歷史基準、負載狀態與溫升變化。
- **安全分級** — 依溫差、設備類型與暴露情境評定風險等級。
- **派修處置** — 建立擬真維修任務、責任人、期限與安全措施。
- **改善驗證** — 以修前修後熱像及檢查表確認異常是否解除。

## 適合誰使用

- 設備巡檢員
- 維修工程師
- 工安管理人員

## 運作流程

1. 安排巡檢
2. 判讀熱像
3. 比對趨勢
4. 評定風險
5. 派發處置
6. 驗證結案

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
