# CAPA（Corrective and Preventive Action）

> 從異常到改善的品質閉環與追溯稽核

CAPA（Corrective and Preventive Action）提供問題登錄分類、根因分析工具（魚骨圖/5Why）、對策擬定與追蹤。品保部依「問題發起→根因分析→對策擬定→執行追蹤→成效驗證→結案」推進作業，優先解決「對策流於形式」，製程工程部則以CAPA平均結案天數與逾期率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**QMS 品質管理系統

## 功能模組

- **異常 / NCR** — 不良通報與處置追蹤
- **CAPA / 8D** — 矯正預防與根因分析
- **SPC 管制圖** — 製程數據即時管制
- **檢驗管理** — 進料/製程/出貨檢驗
- **FMEA** — 失效模式與風險評估
- **追溯稽核** — 批次追溯與稽核紀錄

## 適合誰使用

- 品保部
- 製程工程部
- 研發部

## 運作流程

1. 待確認
2. 已排程
3. 驗證確認
4. 已完成

## 導入效益

- 批號追溯時間：176分鐘 → **16分鐘**
- 客訴平均關案：21天 → **9.5天**
- 改善驗證率：65% → **92%**
- 重複不良率：6.2% → **1.9%**
