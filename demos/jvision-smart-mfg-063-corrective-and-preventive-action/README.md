# CAPA追蹤台

管理矯正與預防措施全流程，確保品質問題從根因分析到成效驗證有完整紀錄可追溯。

- 原始系統：CAPA（Corrective and Preventive Action）
- 產業分類：智慧製造｜品質管理
- 使用部門：品保部、製程工程部、研發部、採購部、生產部
- 工作流程：問題發起→根因分析→對策擬定→執行追蹤→成效驗證→結案
- AI 應用：根因建議、相似案例比對、對策有效性預測
- 主要 KPI：CAPA平均結案天數、逾期率、重複發生率、成效驗證通過率
- 代表產品：Sparta Systems TrackWise、ETQ Reliance、MasterControl CAPA、Intelex
