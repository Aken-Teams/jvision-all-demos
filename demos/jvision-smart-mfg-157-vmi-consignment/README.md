# 供應商寄售與入廠庫存預警塔

由供應商在客戶端維持約定安全庫存並依實際用量結算，降低雙方庫存與缺料風險。

- 原始系統：供應商寄售與入廠庫存管理系統（VMI/Consignment）
- 產業分類：智慧製造｜採購管理
- 使用部門：採購部、倉儲部、財務部、生產計畫部
- 工作流程：設定庫存水位 → 供應商補貨入廠 → 實際領用扣帳 → 定期結算 → 補貨循環
- AI 應用：AI 動態調整安全庫存水位、用量趨勢預測補貨建議
- 主要 KPI：缺料次數、庫存週轉率、寄售庫存結算準確率、補貨反應時間
- 代表產品：SAP Supply Chain Collaboration、E2open、Oracle SCM Cloud
