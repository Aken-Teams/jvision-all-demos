協助洗腎中心管理固定班次、床位安排、病人療程清單、檢驗追蹤、異常交班與申報前檢核，以純 UI 呈現多班次高重複醫療服務的營運節奏。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **班次床位** — 配置固定療程與臨時換班
- **到診檢核** — 確認病人狀態及前置事項
- **療程工作單** — 呈現處方、觀察與待辦紀錄
- **異常交班** — 記錄事件與後續追蹤責任
- **檢驗追蹤** — 提示週期檢驗與異常趨勢
- **申報檢核** — 檢查療程紀錄及必要欄位

## 適合誰使用

- 透析護理長
- 腎臟科醫師
- 申報人員

## 運作流程

1. 配置班次
2. 處理換班
3. 到診檢核
4. 紀錄療程
5. 醫療追蹤
6. 申報整備

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
