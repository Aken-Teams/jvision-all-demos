# 品牌主張證據庫

> 連結品牌與產品主張的有效證據、適用範圍及效期，支援合規行銷。

連結品牌與產品主張的有效證據、適用範圍及效期，支援合規行銷。

**產業別：**業務銷售　|　**系統類型：**legal-case

## 功能模組

- **品牌主張目錄** — 管理效能、永續、安全與市場領先等可用主張。
- **主張證據配對** — 將測試報告、認證、研究與客戶證言連至對應主張。
- **證據效期監測** — 追蹤證據到期、版本變更與適用市場限制。
- **使用條件判定** — 標示各主張可用的產品、地區、渠道與必要限定語。
- **佐證強度排序** — 依可靠度、時效性與因果關聯推薦最佳證據組合。
- **合規主張發布** — 核准主張證據包並提供可直接引用的合規表述。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 建立主張條目
2. 連結適用證據
3. 檢查證據效期
4. 判定使用條件
5. 選擇最佳佐證
6. 核准合規主張
