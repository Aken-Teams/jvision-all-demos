# 會後承諾追蹤器

> 把展會交換資料與會談承諾轉為可追責任務，避免高價值名單沉睡。

把展會交換資料與會談承諾轉為可追責任務，避免高價值名單沉睡。

**產業別：**業務銷售　|　**系統類型：**collaboration-pm

## 功能模組

- **名片交換整理** — 辨識名片、掃碼與報名資料，合併同一聯絡人的交換紀錄。
- **會談承諾萃取** — 從筆記與逐字稿找出寄送、介紹、報價及回訪承諾。
- **承諾任務編排** — 依承諾內容建立負責人、期限、素材與下一步任務。
- **名單歸屬協調** — 依區域、產品與既有客戶關係分派跟進人員。
- **跟進節奏台** — 安排個人化寄送與提醒，防止承諾逾期或重複觸達。
- **承諾兌現驗收** — 核對寄送、會議及 CRM 更新結果，確認承諾真正完成。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 整理交換資料
2. 確認會談承諾
3. 建立跟進任務
4. 協調名單歸屬
5. 執行跟進節奏
6. 驗收承諾結果

## 導入效益

- 商機轉換率：18% → **27%**
- 平均回應時間：26小時 → **6小時**
- 客戶資料完整率：62% → **94%**
- 報價逾期流失：9件/月 → **2件/月**
