# 同業比價分析 Competitive Quote Benchmarking

> 應收付、現金流到預算的財務即時掌握

同業比價分析 Competitive Quote Benchmarking提供競品報價資料庫建置、價格/規格比較表、市場行情趨勢追蹤。業務部依「業務回報市場/競品資訊→彙整建檔→產出比價分析→提供報價策略參考→追蹤輸贏單原因」推進作業，優先解決「業務憑經驗判斷競爭力缺乏數據」，產品部則以贏單率與報價競爭力指數確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**業務銷售　|　**系統類型：**財務會計系統

## 功能模組

- **應收帳款** — 開立、對帳與催收
- **應付帳款** — 請款、付款與對帳
- **現金流** — 資金調度與預測
- **預算管理** — 編列、控管與差異分析
- **固定資產** — 資產登錄與折舊
- **總帳傳票** — 傳票、拋轉與月結

## 適合誰使用

- 產品部
- 行銷部
