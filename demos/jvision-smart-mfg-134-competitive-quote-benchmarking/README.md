# 同業比價分析 Competitive Quote Benchmarking決策室

蒐集與分析競爭對手的市場報價、規格與交期資訊，協助業務制定有競爭力的報價策略。

- 原始系統：同業比價分析 Competitive Quote Benchmarking
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、產品部、行銷部、管理層
- 工作流程：業務回報市場/競品資訊→彙整建檔→產出比價分析→提供報價策略參考→追蹤輸贏單原因
- AI 應用：市場公開資訊自動蒐集彙整、輸單模式分析與預警
- 主要 KPI：贏單率、報價競爭力指數、輸單原因分析完整率、市場資訊更新頻率
- 代表產品：Klue、Crayon（多見於一般產業，電子業多採自建Excel/BI比價庫）
