# Agent 成本分攤中心

> 將模型與工具成本精準分攤至部門、流程、客戶及專案，支援內部計價。

將模型與工具成本精準分攤至部門、流程、客戶及專案，支援內部計價。

**產業別：**資訊科技　|　**系統類型：**finance-ledger

## 功能模組

- **成本歸屬規則** — 設定部門、流程、客戶與專案的成本歸屬條件。
- **模型用量計價** — 依 Token、請求量與模型費率計算推論成本。
- **工具呼叫計價** — 彙整 MCP、API 與外部工具的呼叫費用。
- **跨維度分攤** — 按比例、標籤或實際用量拆分共享成本。
- **內部帳單核對** — 檢視分攤明細、異常差額與責任單位。
- **計價週期結算** — 鎖定週期費用並產出 ERP 入帳資料。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 定義歸屬
2. 核定費率
3. 彙整用量
4. 執行分攤
5. 覆核帳單
6. 完成結算
