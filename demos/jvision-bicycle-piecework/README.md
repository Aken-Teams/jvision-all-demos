> 供自行車零件廠按沖床、研磨、拋光等工序記錄員工合格件數，跨日與跨人返工分開歸屬，避免重複計薪並揭露低良率產量。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **批次派工** — 分配人員工序
- **計件報工** — 登錄完成數量
- **合格確認** — 扣除抽驗不良
- **返工轉派** — 區分原作修復者
- **異常核對** — 查找跨日重複
- **薪資明細** — 彙整個人計件

## 適合誰使用

- 製造班長
- 薪資人員

## 運作流程

1. 工序派發
2. 作業報工
3. 品質抽驗
4. 返工分派
5. 班次核對
6. 月結核薪

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
