**產業別：**採購供應鏈　|　**系統類型：**operations-console

## 功能模組

- **待放行出貨池** — 集中顯示即將出貨且必須套用出口許可的訂單。
- **許可地點核對** — 比對核准收貨地、最終使用地與實際物流節點。
- **核准數量餘額** — 計算本次出貨後的許可數量、金額及分批使用餘額。
- **許可效期檢查** — 檢查報關、離境及預計到貨日期是否落在有效期間。
- **用途條件比對** — 核對最終用途、使用者、轉售限制與許可附帶條款。
- **出貨放行閘門** — 彙整核對結果並執行放行、暫停或人工覆核。

## 適合誰使用

- 國貿主管
- 報關人員
- 業務

## 運作流程

1. 選取待放行出貨
2. 核對許可地點
3. 確認數量餘額
4. 檢查許可效期
5. 審查用途條件
6. 執行出貨決策

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
