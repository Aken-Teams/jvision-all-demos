> 將顧問工時、行事曆、工作成果、合約費率與請款上限逐筆勾稽，找出重疊、描述不足、漏報及未核准費用，降低客戶退單與收入流失。

**產業別：**專業服務　|　**系統類型：**finance-case

## 功能模組

- **工時明細** — 檢視人員日期與時段
- **工作證據** — 連結會議成果與交付物
- **合約費率** — 套用角色費率與額度
- **異常稽核** — 找出重疊漏報與超額
- **經理覆核** — 退回描述或核准工時
- **請款批次** — 產出客戶帳單與明細

## 適合誰使用

- 顧問
- 專案經理
- 財務人員

## 運作流程

1. 提交顧問工時
2. 連結成果證據
3. 執行規則稽核
4. 補正工時疑義
5. 完成經理覆核
6. 產生請款批次

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
