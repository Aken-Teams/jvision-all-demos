# 派遣工時簽認請款台

> 將派遣公司工時表與現場班表、打卡及合約費率逐人勾稽，由領班確認正常與加班時數後產出可請款明細，降低姓名、費率和重複計時差異。

將派遣公司工時表與現場班表、打卡及合約費率逐人勾稽，由領班確認正常與加班時數後產出可請款明細，降低姓名、費率和重複計時差異。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **工時匯入** — 載入派遣商請款資料
- **人員配對** — 對應工號姓名與派駐單位
- **班表勾稽** — 比對打卡正常與加班
- **費率驗算** — 套用合約級別與加成
- **領班簽認** — 確認實際出勤與異常
- **請款核定** — 產出可付款明細與退件

## 適合誰使用

- 現場領班
- 人資人員
- 應付會計

## 運作流程

1. 接收請款
2. 配對人員
3. 核對出勤
4. 驗算費率
5. 完成簽認
6. 核定請款

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
