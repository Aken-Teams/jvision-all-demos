# 醫材借調歸還作業台

> 管理跨病房借調的儀器與可重複醫材，記錄借用人、用途、所在位置、清潔狀態及預計歸還時間，並以逾期隊列協助交班追收與重新派用。

管理跨病房借調的儀器與可重複醫材，記錄借用人、用途、所在位置、清潔狀態及預計歸還時間，並以逾期隊列協助交班追收與重新派用。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **可用查詢** — 尋找可借設備
- **借調登記** — 記錄用途人員
- **位置交接** — 更新所在單位
- **清潔確認** — 管制再用資格
- **逾期追收** — 催辦未還設備
- **歸還驗收** — 確認完整結案

## 適合誰使用

- 護理站人員
- 醫材管理員
- 感染管制人員

## 運作流程

1. 查找設備
2. 申請借調
3. 核准交付
4. 轉站交接
5. 完成清潔
6. 驗收歸還

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
