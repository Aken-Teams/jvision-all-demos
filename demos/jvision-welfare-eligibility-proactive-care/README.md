# 社福資格預審關懷平台

> 利用虛構家戶、所得、身分與既有福利資料，協助承辦人預先檢核可能適用的社福方案、缺件與衝突條件，並依脆弱風險建立主動關懷名單、訪談任務、轉介及後續追蹤，避免符合資格者漏接服務。

利用虛構家戶、所得、身分與既有福利資料，協助承辦人預先檢核可能適用的社福方案、缺件與衝突條件，並依脆弱風險建立主動關懷名單、訪談任務、轉介及後續追蹤，避免符合資格者漏接服務。

**產業別：**生活服務　|　**系統類型：**finance-case

## 功能模組

- **家戶受理** — 建立虛構家戶成員、生活概況、需求與同意紀錄。
- **資格預審** — 依模擬規則檢核適用方案、不符原因與待補資料。
- **福利方案庫** — 查詢給付對象、條件、排除規定與申請文件。
- **關懷名單** — 依脆弱因子與服務缺口排列主動關懷優先順序。
- **訪談轉介** — 記錄關懷訪談、需求評估及跨單位服務轉介。
- **服務追蹤** — 追蹤申請、補件、轉介、給付與家戶狀況變化。

## 適合誰使用

- 社福櫃台人員
- 資格審查員
- 社工員與督導

## 運作流程

1. 建立家戶資料
2. 執行資格預審
3. 查核福利規則
4. 排定關懷優先序
5. 完成訪談轉介
6. 追蹤服務結果

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
