# 新人到職條件清件台

> 依職務建立到職文件、資格、帳戶、座位及設備的跨單位清單，在報到日前追蹤缺件與責任人，對外籍或特許職務加做合法上工條件檢核。

**產業別：**人力資源　|　**系統類型：**hr-hris

## 功能模組

- **新人總覽** — 查看報到日與就緒風險
- **條件清單** — 依職務產生文件任務
- **資格核驗** — 檢查證照許可與效期
- **跨部門準備** — 追蹤帳號座位與設備
- **缺件協調** — 處理逾期與替代方案
- **到職放行** — 確認可報到及可上工

## 適合誰使用

- 招募人員
- 用人主管
- 行政人員

## 運作流程

1. 建立新人
2. 產生清單
3. 核驗資格
4. 完成準備
5. 處理缺件
6. 到職放行

## 導入效益

- 薪資作業工時：40小時/月 → **8小時/月**
- 出勤異常處理：30分鐘 → **5分鐘**
- 招募到位天數：45天 → **28天**
- 表單簽核時效：3天 → **1天**
