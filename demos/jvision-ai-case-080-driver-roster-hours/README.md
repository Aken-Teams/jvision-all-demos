# 司機工時排班所

> 派車、追蹤、簽收到成本油耗的車隊管理

安排班表、工時、休息與合規提醒。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**交通運輸　|　**系統類型：**TMS 運輸調度

## 功能模組

- **路線調度** — 派車與路線規劃
- **任務派車** — 任務指派與追蹤
- **即時追蹤** — GPS 定位與到貨
- **簽收回單** — 電子簽收與回單
- **成本油耗** — 油耗與成本分析
- **冷鏈溫控** — 溫度監控與告警

## 適合誰使用

- 站務調度
- 運務主管
- 營運經理

## 運作流程

1. 待確認
2. 已派車
3. 行駛中
4. 到站完成

## 導入效益

- 派車規劃工時：4.1小時/日 → **1小時/日**
- 準時配送率：90% → **99%**
- 空車率：21% → **9.4%**
- 油耗異常反應：24小時 → **2.9小時**
