# 大型機具證照排檢台

> 將吊車、挖土機、高空作業車等機具的檢查證、保險、操作人資格及進場工區集中建檔，依到期日和派工計畫預警，並在換場或換手時重新核對，避免證照過期、機證人不符仍排入作業。

將吊車、挖土機、高空作業車等機具的檢查證、保險、操作人資格及進場工區集中建檔，依到期日和派工計畫預警，並在換場或換手時重新核對，避免證照過期、機證人不符仍排入作業。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **機具名冊** — 管理機具識別、型式與所在工區。
- **操作人名冊** — 維護人員資格、雇主與可操作類別。
- **證件檔案** — 整理檢查證、保險及訓練文件。
- **人機配對** — 核對派工機具與操作人資格。
- **到期排程** — 預警證件到期及預定進場衝突。
- **排工阻擋** — 列示不得作業原因與補正進度。

## 適合誰使用

- 安衛工程師
- 機具管理員
- 施工主管

## 運作流程

1. 建立機具資料
2. 收錄人員資格
3. 彙整機具證件
4. 核對人機派工
5. 檢查到期風險
6. 解除排工阻擋

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
