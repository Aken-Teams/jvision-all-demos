# 水網漏損修復優先系統

> 以分區計量、壓力、流量及報修紀錄的擬真資料辨識疑似漏水區段，估算漏損量與影響戶數，協助維護團隊比較修復效益、排定探漏路線及工單優先序，降低無收益用水。

以分區計量、壓力、流量及報修紀錄的擬真資料辨識疑似漏水區段，估算漏損量與影響戶數，協助維護團隊比較修復效益、排定探漏路線及工單優先序，降低無收益用水。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **漏損態勢總覽** — 彙整供水分區、漏損率、疑似事件、影響戶數與處理進度。
- **管網風險地圖** — 在示意地圖呈現管線、閥門、疑似漏點及風險熱區。
- **漏點診斷分析** — 比較夜間流量、壓力變化與歷史事件，解釋漏損可能原因。
- **修復優先排序** — 依漏損量、影響範圍、道路條件與修復成本計算處理順序。
- **探漏任務排程** — 安排人員、區域、檢查方法與路線，模擬任務接受和回報。
- **修復工單驗證** — 追蹤開挖修復、復水及前後流量比較，確認漏損是否解除。

## 適合誰使用

- 管網維護工程師
- 探漏班長
- 供水營運主管

## 運作流程

1. 掌握漏損態勢
2. 定位疑似漏點
3. 研判漏損原因
4. 決定修復順序
5. 派發探漏任務
6. 驗證修復效果

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
