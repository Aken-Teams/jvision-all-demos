# 法律文件版本差異分析器

> 比對書狀與證據清單版本的實質變更，避免關鍵主張、引用或附件遭遺漏。

比對書狀與證據清單版本的實質變更，避免關鍵主張、引用或附件遭遺漏。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **書狀版本比對** — 逐段辨識新增、刪除、改寫與位置移動的法律文字。
- **主張變動辨識** — 判斷文字修改是否改變請求、抗辯、事實陳述或法律效果。
- **證據清單核對** — 追蹤證物編號、名稱、待證事實及附件狀態的版本差異。
- **引用斷鏈檢查** — 找出條文、證物與段落引用因改版產生的失效或錯置。
- **變更影響圖** — 呈現每項修改波及的爭點、證據、期限與後續文件。
- **定稿核准包** — 彙整重大差異、修訂理由及待確認項目供定稿簽核。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 選定比較版本
2. 解析書狀差異
3. 判定實質影響
4. 校驗證據引用
5. 審閱影響範圍
6. 核准定稿版本
