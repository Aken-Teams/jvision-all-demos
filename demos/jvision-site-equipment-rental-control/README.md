# 工地機具租期控管台

> 集中管理吊車、發電機、高空車等租賃機具的進場、計租、故障停計、續租及退場，依實際使用與閒置狀態主動提出停租，並逐筆核對租商月結帳單。

集中管理吊車、發電機、高空車等租賃機具的進場、計租、故障停計、續租及退場，依實際使用與閒置狀態主動提出停租，並逐筆核對租商月結帳單。

**產業別：**營建工程　|　**系統類型：**maintenance-cmms

## 功能模組

- **租賃清冊** — 管理機具、租商、費率與計租條件。
- **進場起租** — 記錄到場時間、點收狀況及起租依據。
- **使用追蹤** — 呈現工區配置、使用日及閒置天數。
- **故障停計** — 登錄故障期間與租金停計佐證。
- **停租退場** — 完成通知、點交、運離及結租確認。
- **帳單核對** — 比對租期、停計日與租商請款明細。

## 適合誰使用

- 機具管理員
- 工務工程師
- 成本會計

## 運作流程

1. 建立租賃條件
2. 點收進場起租
3. 追蹤使用狀態
4. 審認故障停計
5. 辦理停租退場
6. 核對月結費用

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
