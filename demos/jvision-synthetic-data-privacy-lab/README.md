# 合成資料隱私測試工坊

> 依真實資料的欄位結構與統計特徵產生不含真實個人的模擬資料，供測試、分析與模型開發使用。平台可設定生成條件、比較資料可用性、檢查隱私洩漏與偏差風險，並透過核准流程發布合格資料集。

依真實資料的欄位結構與統計特徵產生不含真實個人的模擬資料，供測試、分析與模型開發使用。平台可設定生成條件、比較資料可用性、檢查隱私洩漏與偏差風險，並透過核准流程發布合格資料集。

**產業別：**AI 工程平台　|　**系統類型：**operations-console

## 功能模組

- **資料樣板庫** — 選擇欄位結構、資料型態、關聯與預期使用情境。
- **生成條件設計** — 設定資料筆數、分布、限制條件及邊界案例比例。
- **合成資料產生器** — 預覽模擬生成進度、資料樣本與欄位統計摘要。
- **可用性比較室** — 比較原始特徵與合成資料的分布、關聯及覆蓋程度。
- **隱私安全測試** — 檢查重複樣本、近似個體、再識別與敏感推論風險。
- **資料集發布台** — 彙整測試結果、審核用途並管理版本與有效期限。

## 適合誰使用

- 資料科學家
- 測試工程師
- 隱私工程師
- 資料負責人

## 運作流程

1. 選擇資料樣板
2. 設定生成條件
3. 產生合成資料
4. 驗證資料可用性
5. 檢查隱私安全
6. 核准資料發布
