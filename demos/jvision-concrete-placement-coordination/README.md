# 混凝土澆置協調檢核台

> 依每次澆置區整合預估方數、預拌供應、泵車時段、試體需求、監造查驗與工班配置，在發車前檢查關鍵條件並管理臨時改量，降低待料、塞車或退料風險。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **澆置排程板** — 顯示各澆置區、日期、方數、工法與優先順序。
- **預拌供料計畫** — 安排供應廠、配比、車次間隔與出廠窗口。
- **泵車資源** — 配置泵車型式、進場位置、管路及作業時段。
- **澆置前檢核** — 確認模板、鋼筋、預埋、查驗、試體與人員條件。
- **車趟執行** — 呈現出廠、到場、卸料及退場的擬真車次狀態。
- **改量收尾** — 記錄追加減量、剩料處置及實際完成方數。

## 適合誰使用

- 混凝土工程師
- 預拌廠調度員
- 工地主任

## 運作流程

1. 建立澆置需求
2. 協調供料車趟
3. 配置泵車人力
4. 完成發車檢核
5. 執行澆置調度
6. 核對實際方數

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
