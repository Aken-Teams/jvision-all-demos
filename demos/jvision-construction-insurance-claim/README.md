# 工程保險事故理賠台

> 管理工地事故自保險通報、保單適用判斷、現場證據保全、損失估算、保險公司補件到理賠收款與追償，避免逾期通知或各部門重複蒐集同一批資料。

管理工地事故自保險通報、保單適用判斷、現場證據保全、損失估算、保險公司補件到理賠收款與追償，避免逾期通知或各部門重複蒐集同一批資料。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **事故通報** — 登錄時間、地點、損失與初步措施。
- **保單判讀** — 比對承保範圍、自負額與除外條款。
- **證據保全** — 彙整照片、紀錄、報案及關係人資料。
- **損失估算** — 整理修復報價、停工及第三人損失。
- **補件往返** — 追蹤保險公司要求與文件版本。
- **核賠收款** — 核對理賠決定、入帳及責任追償。

## 適合誰使用

- 風險管理人員
- 工地主任
- 財務人員

## 運作流程

1. 即時通報
2. 確認承保
3. 蒐集證據
4. 提出求償
5. 回覆補件
6. 核賠結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
