# 貨櫃延滯費管制台

> 供貨代與進出口物流團隊追蹤貨櫃免費使用期限、提領還櫃節點、延滯費試算、責任歸屬及減免申請，提前鎖定可能產生高額費用的進出口案件。

供貨代與進出口物流團隊追蹤貨櫃免費使用期限、提領還櫃節點、延滯費試算、責任歸屬及減免申請，提前鎖定可能產生高額費用的進出口案件。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **貨櫃總覽** — 查看到港、提領及還櫃狀態。
- **免費期日曆** — 計算各費目免費截止時間。
- **費用試算** — 按日階梯計算預估延滯費。
- **責任判讀** — 標記事件原因與責任關係人。
- **減免申請** — 整理申請理由及佐證文件。
- **費用分析** — 比較航線、客戶與船公司成本。

## 適合誰使用

- 進出口操作員
- 貨代主管
- 費用審核員

## 運作流程

1. 建立貨櫃案件
2. 計算免費期限
3. 更新提還節點
4. 預警延滯費用
5. 判定責任減免
6. 完成費用結算

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
