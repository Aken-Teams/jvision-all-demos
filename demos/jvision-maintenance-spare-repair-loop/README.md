# 維修備件送修周轉台

> 管理可修復備件從故障拆下、替代件領用、送外檢測、報價核准、修復驗收至回庫的循環，掌握待修資產、修復成本與供應商週期。

管理可修復備件從故障拆下、替代件領用、送外檢測、報價核准、修復驗收至回庫的循環，掌握待修資產、修復成本與供應商週期。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **拆件登錄** — 連結設備工單與故障備件序號。
- **替代領用** — 記錄替換件及設備恢復狀態。
- **送修批次** — 安排供應商、交期和點交清單。
- **報價審批** — 比較修復成本、保固與新品價格。
- **回件驗收** — 記錄測試結果和修復品質。
- **回庫處置** — 決定回庫、重修、索賠或報廢。

## 適合誰使用

- 維修工程師
- 備品管理員
- 採購專員

## 運作流程

1. 登錄拆件
2. 領用替代
3. 建立送修
4. 核准報價
5. 測試驗收
6. 完成處置

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
