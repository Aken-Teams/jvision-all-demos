# 尋源開發管理系統（Sourcing）

> 供應商協同、詢比議價到交期風險控管

尋源開發管理系統（Sourcing）提供潛在供應商資料庫建置、供應商初篩問卷管理、新料源開發專案追蹤。採購部依「需求確認 → 潛在供應商搜尋 → 初步評估 → 樣品驗證 → 正式導入」推進作業，優先解決「尋源仰賴個人經驗與人脈」，策略採購部則以新供應商開發週期與尋源成功率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**採購供應鏈　|　**系統類型：**SRM 採購供應商管理

## 功能模組

- **供應商管理** — 建檔、分級與績效評分
- **詢報價協作** — 線上詢價、比價與議價
- **採購訂單** — 請購、下單與交期追蹤
- **交期風險** — 缺料預警與到貨監控
- **供應商品質** — 進料檢驗與 SCAR 改善
- **綠色採購** — ESG 評分與永續採購

## 適合誰使用

- 採購部
- 策略採購部
- 研發部

## 運作流程

1. 待詢價
2. 比價中
3. 待核准
4. 驗收完成

## 導入效益

- 採購前置時間：12天 → **5.1天**
- 準時到貨率：79% → **94%**
- 缺料預警覆蓋：42% → **86%**
- 議價作業工時：8.2小時/週 → **2.1小時/週**
