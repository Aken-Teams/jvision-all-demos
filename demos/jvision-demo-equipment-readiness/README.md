## 功能模組

- **展示任務** — 查看拜訪日期與腳本
- **設備預留** — 配置主機配件與替代品
- **整備清單** — 檢查版本電量及耗材
- **彩排測試** — 記錄功能及情境結果
- **裝箱覆核** — 雙人清點並封存箱單
- **返還驗收** — 核對缺件損壞與維修

## 適合誰使用

- 售前顧問
- 業務助理
- 展示設備管理員

## 運作流程

1. 建立任務
2. 預留設備
3. 執行整備
4. 完成彩排
5. 裝箱交付
6. 返還驗收
