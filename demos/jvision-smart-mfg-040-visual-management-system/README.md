# 目視化管理系統（Visual Management System）

> 訂單到入庫的製造現場全流程數位化

目視化管理系統（Visual Management System）提供產線狀態即時看板、異常燈號/顏色提示、多站點狀態彙整顯示。現場作業依「現場數據採集 → 狀態視覺化呈現 → 異常提示觸發 → 現場處置 → 狀態歸檔分析」推進作業，優先解決「現場狀態資訊不透明」，製造工程則以異常反應時間與看板更新即時率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生產製造　|　**系統類型：**MES 製造執行系統

## 功能模組

- **工單管理** — 訂單轉工單、拆併單與工單派發
- **排程排產** — 依產能、交期、負載自動排程
- **現場執行** — 派工、報工與進度即時回報
- **設備稼動 OEE** — 稼動、效率、良率即時監控
- **品質入庫** — 檢驗判定、不良處置與入庫
- **AI 改善建議** — 異常摘要與瓶頸改善建議

## 適合誰使用

- 現場作業
- 製造工程
- 廠務主管

## 運作流程

1. 待排程
2. 生產中
3. 待品檢
4. 已入庫

## 導入效益

- 排程作業工時：8.3小時/日 → **1.5小時/日**
- 準時交付率：82% → **91%**
- 缺料停線次數：12次/月 → **2.8次/月**
- 設備稼動率：73% → **93%**
