# 工程保留款到期釋放台

> 彙整各期估驗保留款、驗收、缺失改善與保固條件，依合約計算可釋放金額並執行雙重覆核，避免重複付款或逾期未付。

彙整各期估驗保留款、驗收、缺失改善與保固條件，依合約計算可釋放金額並執行雙重覆核，避免重複付款或逾期未付。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **保留款台帳** — 查看合約及累計餘額。
- **到期條件** — 追蹤驗收與保固節點。
- **缺失確認** — 核對改善及扣留理由。
- **釋放試算** — 計算本次可付金額。
- **付款覆核** — 執行分級雙人核准。
- **釋放核銷** — 記錄付款及剩餘餘額。

## 適合誰使用

- 成本會計
- 合約管理員
- 專案經理

## 運作流程

1. 彙整餘額
2. 檢查到期
3. 確認缺失
4. 試算釋放
5. 核准付款
6. 完成核銷

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
