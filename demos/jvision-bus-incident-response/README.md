# 客運事故應變指揮台

> 供客運公司在車輛事故、乘客受傷或道路中斷時建立事件分級、聯絡清單、替代運能、旅客安置與後續調查，確保各單位依時限完成通報及復原。

**產業別：**交通運輸　|　**系統類型：**operations-console

## 功能模組

- **事件戰情** — 集中顯示事件等級、位置、影響與進度。
- **事故建檔** — 記錄人車狀況、初報來源與現場需求。
- **應變任務** — 依劇本分派救援、站務及聯絡工作。
- **替代運能** — 安排接駁車輛、駕駛與受影響班次。
- **通報紀錄** — 管理內外部通知對象、時限與版本。
- **復原調查** — 整理證據、原因、損失與改善事項。

## 適合誰使用

- 行控主管
- 站務督導
- 職安人員

## 運作流程

1. 確認事件
2. 建立戰情
3. 派發應變
4. 調度接駁
5. 完成通報
6. 調查結案

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
