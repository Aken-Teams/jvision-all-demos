# 零拷貝資料協作閘道

> 讓外部合作方透過受控查詢使用資料而不取得副本，降低協作外流風險。

讓外部合作方透過受控查詢使用資料而不取得副本，降低協作外流風險。

**產業別：**數據分析　|　**系統類型：**security-soc

## 功能模組

- **合作方工作區** — 建立隔離的合作空間並綁定組織、成員與合作目的。
- **可用資料產品選擇** — 挑選允許查詢的資料集、欄位、期間與敏感層級。
- **查詢政策設計器** — 設定列級、欄級、用途、時段與運算額度限制。
- **受控查詢工作台** — 讓合作方執行核准查詢且無法下載原始資料。
- **輸出洩漏檢查** — 檢查小樣本、重識別、敏感聚合與查詢拼接風險。
- **合作授權管理** — 核准存取期限、可用輸出與撤銷條件並持續監控。

## 適合誰使用

- CDO
- 資料工程師
- 資料管理員

## 運作流程

1. 建立合作申請
2. 選定資料產品
3. 設計查詢政策
4. 審核存取方案
5. 執行受控查詢
6. 驗證並釋出結果

## 導入效益

- 報表產出工時：16小時 → **1小時**
- 異常發現時效：3天 → **1天**
- 資料覆蓋率：55% → **92%**
- 決策反應時間：5天 → **1天**
