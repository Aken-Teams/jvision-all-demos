**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **資源目錄** — 管理實驗室、設備與容量條件
- **課程預約** — 提出班級、時段及資源需求
- **資格檢核** — 確認訓練、證照與使用權限
- **耗材準備** — 登錄課程用量與備料狀態
- **點交紀錄** — 保存課前課後設備檢查
- **異常追蹤** — 處理損壞、短缺與責任確認

## 適合誰使用

- 實驗室管理員
- 授課教師
- 系所助教

## 運作流程

1. 提出預約
2. 檢核資格
3. 協調資源
4. 準備耗材
5. 執行點交
6. 處理異常

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
