# 醫療轉診閉環管理台

> 協助診所管理轉出與轉入個案，彙整轉診原因、必要摘要、預約狀態、回覆報告及後續追蹤任務，避免病人在跨院所銜接過程中失聯或重複檢查。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **個案摘要** — 整理轉診所需病史與檢查摘要。
- **轉診申請** — 建立轉出、轉入目的及優先程度。
- **就醫安排** — 記錄接收院所、科別與預約時段。
- **資料交付** — 確認應附文件及交付完成狀態。
- **結果回覆** — 登錄回診摘要與接收院所建議。
- **後續追蹤** — 建立複診、用藥或檢查追蹤任務。

## 適合誰使用

- 診所醫師
- 個案管理師
- 櫃檯人員

## 運作流程

1. 判定轉診
2. 整理資料
3. 媒合院所
4. 完成預約
5. 收取回覆
6. 延續照護

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
