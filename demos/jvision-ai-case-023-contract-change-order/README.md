# 合約追加管制室

> 案件、庭期、合約到工時計費的法務管理

追蹤合約金額、變更追加與簽核狀態。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**營建工程　|　**系統類型：**法務案件管理

## 功能模組

- **案件管理** — 案件建檔與進度
- **庭期管理** — 開庭與期限提醒
- **合約管理** — 合約審閱與風險
- **工時計費** — 工時記錄與計費
- **文件管理** — 文件版本與檢索
- **案件追溯** — 全程紀錄與稽核

## 適合誰使用

- 工班專員
- 工班主管
- 營建工程主管

## 運作流程

1. 待釐清
2. 現場處理
3. 待查驗
4. 計價完成

## 導入效益

- 日報彙整工時：2.9小時/日 → **0.5小時/日**
- 進度落後預警：40% → **95%**
- 估驗計價天數：10天 → **3.8天**
- 缺失改善時效：7.3天 → **1.9天**
