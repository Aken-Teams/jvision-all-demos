# 校園團膳履約管理台

> 協助學校總務與營養師管理團膳菜單審查、食材文件、供餐數量、驗收紀錄、過敏餐需求及廠商缺失改善，讓每日供餐契約具備可追溯的履約證據。

協助學校總務與營養師管理團膳菜單審查、食材文件、供餐數量、驗收紀錄、過敏餐需求及廠商缺失改善，讓每日供餐契約具備可追溯的履約證據。

**產業別：**教育　|　**系統類型：**procurement-srm

## 功能模組

- **菜單審查** — 檢查營養配置、重複菜色及禁用食材。
- **餐數彙整** — 管理班級餐數、請假調整與特殊餐需求。
- **食材文件** — 核對來源證明、檢驗資料及效期。
- **到餐驗收** — 記錄溫度、份量、外觀及到餐時間。
- **缺失改善** — 通知廠商處理異常並追蹤改善證據。
- **履約評分** — 彙整扣點、違約事項與月度評核。

## 適合誰使用

- 學校營養師
- 總務人員
- 團膳廠商窗口

## 運作流程

1. 提交菜單
2. 審核內容
3. 確認餐數
4. 執行驗收
5. 追蹤改善
6. 完成評核

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
