# 建照條件履約檢核台

> 集中拆解建照附帶的交通、消防、綠建築與公共設施條件，管理期限、文件、責任單位及完成證據，避免交接漏項而延誤使用執照。

集中拆解建照附帶的交通、消防、綠建築與公共設施條件，管理期限、文件、責任單位及完成證據，避免交接漏項而延誤使用執照。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **履約總覽** — 查看條件狀態與期限風險
- **條件建檔** — 拆解公文要求與適用階段
- **責任分派** — 指定主責及協辦單位
- **證據收件** — 彙整圖說、證明與簽章
- **送件檢核** — 檢查缺件及版本一致性
- **取照分析** — 分析延誤原因與完成率

## 適合誰使用

- 開發專員
- 工地主任
- 法規承辦

## 運作流程

1. 建立條件
2. 拆解任務
3. 分派辦理
4. 上傳成果
5. 覆核送件
6. 追蹤取照

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
