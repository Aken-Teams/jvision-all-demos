# 工程變更報價比對台

> 以工項、數量與單價逐版比較工程變更報價，清楚標示新增、減作、替代與舊版回填，讓議價及核准都能追溯差額來源。

以工項、數量與單價逐版比較工程變更報價，清楚標示新增、減作、替代與舊版回填，讓議價及核准都能追溯差額來源。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **版本比對** — 呈現工項新增刪減。
- **數量差異** — 比較各版工程數量。
- **單價驗證** — 核對合約與議價單價。
- **減作檢查** — 辨識應扣未扣項目。
- **議價紀錄** — 保存雙方意見與回覆。
- **核定版本** — 封存最終金額與附件。

## 適合誰使用

- 成本工程師
- 專案經理
- 業主窗口

## 運作流程

1. 匯入版本
2. 比對工項
3. 驗算價量
4. 提出議價
5. 取得確認
6. 封存核定

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
