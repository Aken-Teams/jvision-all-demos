## 功能模組

- **模型流量檢視器** — 檢視即將送往外部模型的提示、來源應用與目的端模型。
- **商業實體偵測器** — 辨識人名、公司、料號、專案代稱與具敏感語意的內容。
- **匿名代換設計器** — 依實體類型設定遮罩、假名化、格式保留或不可逆移除。
- **代換前後預覽** — 逐段比較原文與匿名文本，確認語意可用性及殘留風險。
- **安全還原保管庫** — 隔離保存代換映射，僅對授權回應流程執行精準還原。
- **閘道政策控制台** — 按應用、資料類型與模型目的地設定放行、匿名或阻擋規則。

## 適合誰使用

- CISO
- AI 治理主管
- 資安分析師

## 運作流程

1. 攔截模型請求
2. 辨識敏感語意
3. 配置匿名策略
4. 核對代換結果
5. 授權回應還原
6. 發布閘道政策
