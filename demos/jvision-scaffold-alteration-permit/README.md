# 施工架拆搭許可台

> 把施工架新增、局部改架與拆除需求轉為可追蹤許可，串接影響工種、施工範圍、作業前檢點與完工查驗，避免未經核准改架造成墜落風險或妨礙其他工作面。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **拆搭申請** — 登錄區域、目的、範圍、需求日期與申請工班。
- **架體位置圖** — 在立面或樓層圖標示預計新增、異動及拆除區。
- **影響會勘** — 彙整受影響工種、通道、防墜與吊運條件。
- **許可簽核** — 依風險與前置條件核准、附條件核准或退回。
- **拆搭回報** — 由架班記錄施工人員、時間與完工照片。
- **使用前查驗** — 確認護欄、踏板、壁連座與通道恢復後放行。

## 適合誰使用

- 施工架領班
- 職安人員
- 現場工程師

## 運作流程

1. 提出拆搭需求
2. 確認架體範圍
3. 會勘作業影響
4. 核發拆搭許可
5. 完成拆搭施工
6. 查驗恢復放行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
