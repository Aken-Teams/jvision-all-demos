# 個人化商品推薦編排台

> 以擬真顧客分群與商品資料，協助營運人員規劃首頁、商品頁及購物車等版位的推薦內容，設定推薦邏輯、視覺順序與排除條件，並用模擬預覽比較不同客群看到的購物體驗。

以擬真顧客分群與商品資料，協助營運人員規劃首頁、商品頁及購物車等版位的推薦內容，設定推薦邏輯、視覺順序與排除條件，並用模擬預覽比較不同客群看到的購物體驗。

**產業別：**零售電商　|　**系統類型：**operations-console

## 功能模組

- **顧客分群中心** — 查看新客、回購客、高價值客等擬真分群特徵與人數分布。
- **推薦策略庫** — 設定熱銷、相似商品、交叉銷售與回購提醒等推薦策略。
- **版位編排畫布** — 拖曳配置首頁、商品頁與購物車版位，調整卡片順序與數量。
- **曝光條件管理** — 管理缺貨排除、品牌互斥、頻率上限與活動優先等限制條件。
- **客群情境預覽** — 切換不同顧客輪廓與頁面，預覽推薦結果及推薦原因。
- **版位成效分析** — 比較版位曝光、點擊、加購與模擬營收，找出待調整策略。

## 適合誰使用

- 電商營運人員
- 商品企劃
- 數位行銷人員

## 運作流程

1. 選定目標客群
2. 建立推薦邏輯
3. 編排頁面版位
4. 檢查曝光限制
5. 預覽分眾體驗
6. 追蹤版位成效

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
