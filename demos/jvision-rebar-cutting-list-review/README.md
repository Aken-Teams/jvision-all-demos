# 鋼筋料單核對追蹤台

> 管理鋼筋加工料單從圖說依據、形狀尺寸、支數與重量核算，到工地審查、退修及核准下料的完整版本；讓新版料單、修改註記與加工批次清楚對應，避免依舊版製作造成錯料與損耗。

管理鋼筋加工料單從圖說依據、形狀尺寸、支數與重量核算，到工地審查、退修及核准下料的完整版本；讓新版料單、修改註記與加工批次清楚對應，避免依舊版製作造成錯料與損耗。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **料單收件** — 彙整加工廠送審料單與預定下料日期。
- **圖說依據** — 核對樓層、區域及引用的結構圖版次。
- **料號核算** — 檢查鋼筋形狀、尺寸、支數、重量與搭接。
- **審查註記** — 逐列標示疑義、修正要求與責任回覆。
- **核准下料** — 鎖定可加工版本及核准數量與時間。
- **加工追蹤** — 連結核准料單與加工、出貨批次狀態。

## 適合誰使用

- 鋼筋工程師
- 工地主任
- 加工廠承辦

## 運作流程

1. 接收料單
2. 查核圖版
3. 核算內容
4. 退修回覆
5. 核准下料
6. 追蹤加工

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
