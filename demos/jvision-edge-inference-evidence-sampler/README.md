抽取代表性與異常推論樣本，在有限頻寬下保留足夠稽核證據。準確。

**產業別：**設備維護　|　**系統類型：**it-ops

## 功能模組

- **抽樣策略設計** — 依類別、置信度、時段及場域設定代表性抽樣配額。
- **異常樣本捕捉** — 優先保留低信心、規則衝突與罕見推論事件。
- **代表性覆蓋檢查** — 衡量樣本對裝置、環境、類別及模型版本的覆蓋程度。
- **回傳量預算器** — 在頻寬與儲存上限內最佳化影像、特徵與中繼資料回傳量。
- **敏感內容遮蔽** — 在離開裝置前移除身分資訊並套用資料保留規則。
- **推論證據批次** — 封裝可追溯的樣本、模型版本、判斷來源與完整性校驗。

## 適合誰使用

- IoT 架構師
- 設備工程師
- 場域主管

## 運作流程

1. 設定抽樣目標
2. 捕捉異常推論
3. 校驗樣本覆蓋
4. 壓縮回傳批次
5. 審查隱私界線
6. 發布證據批次

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
