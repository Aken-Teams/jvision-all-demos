# 供應商返利結算台

> 把供應商返利合約、銷售門檻、排除品項、退貨基礎與應收進度集中試算，協助採購及財務在季結前找出漏算與錯用條件。

把供應商返利合約、銷售門檻、排除品項、退貨基礎與應收進度集中試算，協助採購及財務在季結前找出漏算與錯用條件。

**產業別：**零售電商　|　**系統類型：**procurement-srm

## 功能模組

- **返利合約** — 管理費率、門檻與有效期。
- **適用品項** — 設定品牌及排除商品。
- **銷退基礎** — 彙整銷售與退貨淨額。
- **返利試算** — 依級距計算應收金額。
- **底稿覆核** — 檢查條件與例外調整。
- **請款追蹤** — 管理發票、折讓與收款。

## 適合誰使用

- 採購專員
- 財務會計
- 商品主管

## 運作流程

1. 建置合約
2. 圈選品項
3. 彙整銷退
4. 執行試算
5. 覆核底稿
6. 追蹤回收

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
