# 防水覆蓋前放行台

> 針對浴廁、屋頂、地下外牆等防水區域，在保護層或後續飾面覆蓋前集中確認試水、收頭、穿管補強、缺失照片及責任會簽，保留日後可追溯的隱蔽紀錄。

針對浴廁、屋頂、地下外牆等防水區域，在保護層或後續飾面覆蓋前集中確認試水、收頭、穿管補強、缺失照片及責任會簽，保留日後可追溯的隱蔽紀錄。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **防水區位** — 依棟別、樓層、空間及防水系統建立管制區。
- **試水紀錄** — 記錄試水範圍、起訖時間、水位及判定。
- **節點查核** — 檢查落水頭、管根、轉角與收頭補強。
- **隱蔽影像** — 依區位整理覆蓋前全景與節點照片。
- **缺失複驗** — 指派改善責任並追蹤複驗結果。
- **覆蓋放行** — 完成承商、品管與監造會簽後准予覆蓋。

## 適合誰使用

- 防水工程師
- 品管人員
- 監造工程師

## 運作流程

1. 登錄待覆蓋區
2. 完成試水紀錄
3. 查核細部節點
4. 建立隱蔽影像
5. 改善並申請複驗
6. 簽發覆蓋許可

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
