# 公共工程資源計畫台

> 依契約工項與預定進度編製人力、機具及主要材料需求曲線，檢查尖峰資源與施工產能是否匹配，並保留投標、開工及修正版間的假設差異。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **需求時程** — 按週呈現各工項人機料需求。
- **人力配置** — 設定工班人數、工率與班次。
- **機具配置** — 安排主要機具數量與使用期間。
- **材料曲線** — 推算主要材料分期需求與到場點。
- **產能檢核** — 比較工程量、資源供給與計畫產能。
- **版本送審** — 產出資源計畫表並保留修訂說明。

## 適合誰使用

- 排程工程師
- 施工計畫工程師
- 專案經理

## 運作流程

1. 連結工項
2. 設定工率
3. 推算需求
4. 檢查尖峰
5. 調整配置
6. 核定送審

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
