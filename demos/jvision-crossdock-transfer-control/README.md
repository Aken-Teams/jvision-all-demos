# 越庫轉運銜接管制台

> 供物流中心規劃到貨車次、暫存月台、拆併貨與續程車班的銜接，利用時間窗與異常處置畫面降低貨物落地等待及錯接目的路線。

供物流中心規劃到貨車次、暫存月台、拆併貨與續程車班的銜接，利用時間窗與異常處置畫面降低貨物落地等待及錯接目的路線。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **轉運總覽** — 查看進出班次與銜接風險。
- **到離排程** — 排列車次時間窗及優先序。
- **月台配置** — 指派進貨與出貨作業月台。
- **貨流編組** — 拆併貨物並綁定續程路線。
- **異常處置** — 處理遲到、短少與錯線事件。
- **轉運績效** — 分析停留時間與班次準點。

## 適合誰使用

- 轉運主管
- 月台調度員
- 理貨組長

## 運作流程

1. 檢視波次
2. 安排車窗
3. 配置月台
4. 編組貨流
5. 排除異常
6. 結算班次

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
