# 公共工程查驗停留台

> 從品質計畫與排程建立停留點和見證點，提前通知承商及監造，管理備查文件、到場結果與放行範圍，防止未查驗即覆蓋施工。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **停留點總覽** — 查看各工項查驗節點
- **查驗基準** — 設定文件與通知期限
- **查驗申請** — 預約監造到場時段
- **文件備查** — 確認試驗表單與圖說
- **到場放行** — 記錄結果與施工範圍
- **程序稽核** — 追蹤漏驗補表與退件

## 適合誰使用

- 品管工程師
- 監造工程師
- 現場工程師

## 運作流程

1. 建立節點
2. 提出申請
3. 文件預審
4. 現場查驗
5. 簽認放行
6. 程序稽核

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
