# BIM議題責任結案台

> 將模型碰撞與協調議題轉為具責任人、決議版本和現場影響的結案流程，同步檢查模型、施工圖與已施工狀態是否一致，避免只在模型中標示已修正卻未落實到現場。

將模型碰撞與協調議題轉為具責任人、決議版本和現場影響的結案流程，同步檢查模型、施工圖與已施工狀態是否一致，避免只在模型中標示已修正卻未落實到現場。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **模型議題總覽** — 依樓層、專業、嚴重度與期限檢視協調議題。
- **視點與衝突資訊** — 保存模型視點、碰撞物件、尺寸及影響區域。
- **責任決議** — 記錄主責專業、配合單位、方案與會議結論。
- **模型修正覆核** — 確認指定模型版本已依決議完成調整。
- **施工圖同步** — 檢查修正是否反映於核准施工圖及發行紀錄。
- **現場驗證結案** — 比對現場施工狀況後通過、退回或轉成變更。

## 適合誰使用

- BIM協調工程師
- 設計工程師
- 現場工程師

## 運作流程

1. 建立模型議題
2. 判定責任專業
3. 確認解決方案
4. 覆核模型修正
5. 同步施工圖版
6. 驗證現場結案

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
