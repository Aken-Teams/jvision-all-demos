# 旅宿團客入住整備台

> 針對旅行團抵達前的名單、房號、房卡、行李、餐食與特殊需求進行分工勾稽，集中處理缺件和臨時異動，縮短大批旅客到店等候時間。

針對旅行團抵達前的名單、房號、房卡、行李、餐食與特殊需求進行分工勾稽，集中處理缺件和臨時異動，縮短大批旅客到店等候時間。

**產業別：**餐飲旅宿　|　**系統類型：**operations-console

## 功能模組

- **抵達班次** — 掌握團號、車次、領隊與預計到店時間。
- **旅客名單** — 核對姓名、房型與特殊身分需求。
- **房號配置** — 完成同團鄰近、領隊房及例外調房。
- **房卡包裝** — 追蹤房卡、早餐券與迎賓資料備妥。
- **行李安排** — 建立行李標籤、卸載區與送房順序。
- **就緒檢核** — 彙整跨部門完成度與未解阻礙。

## 適合誰使用

- 團體訂房專員
- 櫃台領班
- 房務協調員

## 運作流程

1. 建立班次
2. 鎖定名單
3. 完成房配
4. 準備房卡
5. 安排行李
6. 確認就緒

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
