# 業主變更選配結算台

> 以戶別管理客變與選配項目的圖面版本、增減數量、價差、付款及退款，勾稽現場施工結果，避免做錯戶別、漏收追加款或重複退款。

以戶別管理客變與選配項目的圖面版本、增減數量、價差、付款及退款，勾稽現場施工結果，避免做錯戶別、漏收追加款或重複退款。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **戶別總覽** — 查看各戶客變狀態
- **選配建單** — 設定品項規格與價差
- **圖面確認** — 標示客變位置及版本
- **施工凍結** — 發布現場正式版本
- **價差結算** — 計算追加與退減金額
- **收退款項** — 追蹤收款退款與發票

## 適合誰使用

- 客變專員
- 現場工程師
- 應收會計

## 運作流程

1. 住戶選配
2. 技術確認
3. 價差核定
4. 版本凍結
5. 完工核對
6. 財務結算

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
