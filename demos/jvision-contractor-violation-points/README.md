# 承攬商違規記點台

> 依承攬商、人員與違規類型累積工安記點，連結照片、改善期限、複查結果及契約扣款門檻，協助工地辨識重複違規班組並一致執行停權或教育措施。

依承攬商、人員與違規類型累積工安記點，連結照片、改善期限、複查結果及契約扣款門檻，協助工地辨識重複違規班組並一致執行停權或教育措施。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **工安總覽** — 查看違規趨勢與高風險承攬商。
- **違規開立** — 記錄人員、位置、類型與照片。
- **記點規則** — 維護級別、點數及處置門檻。
- **改善追蹤** — 管理期限、責任人與改善回報。
- **現場複查** — 確認改善有效或要求再次處理。
- **處置執行** — 產生教育、停權或扣款清單。

## 適合誰使用

- 職安人員
- 工地主任
- 分包管理員

## 運作流程

1. 檢視風險
2. 開立違規
3. 計算點數
4. 回報改善
5. 執行複查
6. 核定處置

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
