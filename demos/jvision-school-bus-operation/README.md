# 校車路線營運管理台

> 協助學校或補習班管理校車路線、學生乘車名冊、停靠點、請假異動及司機交付事項，降低錯接漏接與臨時變更混亂。

**產業別：**教育　|　**系統類型：**logistics-fleet

## 功能模組

- **路線規劃** — 維護班次、停靠點與預估時間
- **乘車名冊** — 配置學生、上下車點及聯絡人
- **請假異動** — 處理停搭、換站與臨時加搭
- **班次交付** — 產生司機與帶車老師工作清單
- **乘車核對** — 記錄各站學生上車與下車狀態
- **路線分析** — 檢視載客率與異常事件

## 適合誰使用

- 教務行政
- 校車調度
- 帶車老師

## 運作流程

1. 蒐集需求
2. 編排路線
3. 確認名冊
4. 處理異動
5. 班次核對
6. 異常複盤

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
