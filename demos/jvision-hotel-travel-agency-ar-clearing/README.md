# 旅宿旅行社帳款核銷台

> 依團號、入住日期、房晚與改單紀錄配對旅行社付款，處理短付、併款、扣款及錯銷，縮短團體房應收帳款的未清天數。

**產業別：**餐飲旅宿　|　**系統類型：**finance-ledger

## 功能模組

- **團體帳單** — 查看旅行社與各團應收。
- **入帳明細** — 整理匯款與付款備註。
- **團款配對** — 依團號、日期及金額建議核銷。
- **短付調查** — 追蹤改單、扣款與折讓。
- **證據彙整** — 集中報價與往返信件。
- **核銷結案** — 確認沖帳與剩餘應收。

## 適合誰使用

- 應收會計
- 團體業務
- 訂房主管

## 運作流程

1. 建立應收
2. 匯入收款
3. 建議配對
4. 釐清差異
5. 核准折讓
6. 完成核銷

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
