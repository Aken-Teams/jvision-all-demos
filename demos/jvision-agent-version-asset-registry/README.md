## 功能模組

- **版本資產目錄** — 集中管理提示、工具、模型、政策與知識版本。
- **發布依賴圖** — 呈現每個 Agent 版本引用的完整資產關係。
- **版本差異比較** — 逐項比較設定、內容、權限與依賴變更。
- **發布快照封裝** — 將可執行組合封裝為不可變發布快照。
- **相容性驗證** — 檢查工具介面、模型能力與政策衝突。
- **版本重現回復** — 以既有快照重建環境或回復指定發布。

## 適合誰使用

- AI 平台負責人

## 運作流程

1. 登錄資產版本

3. 檢視版本差異
4. 執行相容驗證
5. 核准發布快照
6. 重現指定發布
