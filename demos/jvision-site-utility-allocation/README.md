# 工地水電分攤核算台

> 依分包進退場期間、電表或約定權重分攤工地臨時水電費，保存計算依據、異議和扣款簽認，避免漏扣、錯扣及完工結算爭議。

依分包進退場期間、電表或約定權重分攤工地臨時水電費，保存計算依據、異議和扣款簽認，避免漏扣、錯扣及完工結算爭議。

**產業別：**營建工程　|　**系統類型：**finance-ledger

## 功能模組

- **費用總覽** — 查看水電帳單與期間
- **分攤對象** — 管理分包進退場日期
- **分攤規則** — 設定表計比例與權重
- **月度試算** — 計算各廠商應負擔額
- **異議處理** — 保存證據和協議結果
- **扣款發布** — 產生計價扣款明細

## 適合誰使用

- 成本會計
- 工地行政
- 分包窗口

## 運作流程

1. 匯入帳單
2. 確認對象
3. 套用規則
4. 工程覆核
5. 處理異議
6. 計價扣回

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
