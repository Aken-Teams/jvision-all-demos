# 良率管理系統（Yield Management System）

> 訂單到入庫的製造現場全流程數位化

良率管理系統（Yield Management System）提供良率數據彙整分析、缺陷模式分類與熱點分析、良率損失歸因。良率工程依「測試/缺陷數據收集 → 良率統計分析 → 根因歸因 → 改善對策 → 效果驗證追蹤」推進作業，優先解決「良率異常根因分析耗時」，製程工程則以良率與缺陷密度確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生產製造　|　**系統類型：**MES 製造執行系統

## 功能模組

- **工單管理** — 訂單轉工單、拆併單與工單派發
- **排程排產** — 依產能、交期、負載自動排程
- **現場執行** — 派工、報工與進度即時回報
- **設備稼動 OEE** — 稼動、效率、良率即時監控
- **品質入庫** — 檢驗判定、不良處置與入庫
- **AI 改善建議** — 異常摘要與瓶頸改善建議

## 適合誰使用

- 良率工程
- 製程工程
- 品保

## 運作流程

1. 待排程
2. 生產中
3. 待品檢
4. 已入庫

## 導入效益

- 排程作業工時：7.5小時/日 → **1.4小時/日**
- 準時交付率：75% → **89%**
- 缺料停線次數：11次/月 → **2.8次/月**
- 設備稼動率：70% → **83%**
