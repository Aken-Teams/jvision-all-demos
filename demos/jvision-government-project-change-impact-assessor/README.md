# 政府專案變更影響助手

> 評估政府專案變更對範圍、時程、預算與契約程序的連鎖影響。確保變更決策正確且合規。

評估政府專案變更對範圍、時程、預算與契約程序的連鎖影響。確保變更決策正確且合規。

**產業別：**專業服務　|　**系統類型：**construction-pm

## 功能模組

- **變更提案工作台** — 描述變更原因、目標與擬調整內容，建立評估基準。
- **範圍影響圖** — 連結契約交付物、工作包、驗收條件與受影響關係人。
- **時程衝擊推演** — 計算里程碑、關鍵路徑與履約期限可能產生的位移。
- **預算變動試算** — 比較追加減金額、科目挪移與付款節點的財務影響。
- **契約程序檢核** — 判斷變更類型所需條款依據、核准層級與辦理文件。
- **變更包核准台** — 整合影響摘要、契約依據與修訂草案供協作核准。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 提出變更需求
2. 盤點範圍連動
3. 推演時程衝擊
4. 試算預算變動
5. 檢核變更程序
6. 核准並發布變更

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
