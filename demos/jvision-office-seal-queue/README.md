# 事務所客戶用印排隊台

> 將待用印文件、有效版本、印章種類、騎縫要求、急件順位與寄送結果排成可追蹤佇列，避免插單後簽錯版本或文件寄出無紀錄。

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **用印申請** — 上傳文件與用途期限
- **版本檢查** — 標示有效版與變更處
- **用印佇列** — 依截止風險安排順位
- **權限核准** — 確認印章種類與授權
- **蓋印點檢** — 核對頁數騎縫與附件
- **交付追蹤** — 記錄取件寄件及簽收

## 適合誰使用

- 案件承辦
- 印鑑保管人
- 事務所主管

## 運作流程

1. 提出用印申請
2. 確認有效版本
3. 審核用印權限
4. 排定用印順位
5. 執行蓋印複核
6. 完成交付簽收

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
