# 物業承攬商進場管理台

> 管理保全、清潔、維修等承攬商人員的資格文件、入場申請、作業區域、鑰匙領用與離場確認，讓物業端掌握每日外部人員與未歸還資產。

管理保全、清潔、維修等承攬商人員的資格文件、入場申請、作業區域、鑰匙領用與離場確認，讓物業端掌握每日外部人員與未歸還資產。

**產業別：**房地產與物業　|　**系統類型：**operations-console

## 功能模組

- **人員資格** — 管理證件、保險、訓練與有效期限。
- **進場申請** — 登錄日期、工作內容及預計人數。
- **區域核准** — 指定樓層、機房及禁止進入範圍。
- **換證領用** — 記錄識別證、鑰匙與門禁卡交付。
- **作業查核** — 由樓管確認現場條件與完工狀態。
- **離場清點** — 核對人員、證件與借用資產全數歸還。

## 適合誰使用

- 物業經理
- 保全櫃台
- 承攬商窗口

## 運作流程

1. 維護資格
2. 提出申請
3. 審核範圍
4. 辦理進場
5. 確認完工
6. 清點離場

- 報修處理：24小時 → **4小時**
