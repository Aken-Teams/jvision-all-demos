# 餐廳訂位收益管理台

> 整合訂位、桌型、用餐時段與訂金政策，協助餐廳安排翻桌、候補及團體席次，降低爽約與空桌，並以歷史假資料模擬各餐期的接待量與營收表現。

整合訂位、桌型、用餐時段與訂金政策，協助餐廳安排翻桌、候補及團體席次，降低爽約與空桌，並以歷史假資料模擬各餐期的接待量與營收表現。

**產業別：**餐飲旅宿　|　**系統類型：**pos-frontdesk

## 功能模組

- **餐期容量** — 查看各時段可售桌數與接待上限
- **桌位配置** — 執行併桌、拆桌及席次調整
- **訂金追蹤** — 管理待收、已收與退款狀態
- **候補名單** — 依人數與等候時間安排遞補
- **到店確認** — 模擬發送提醒並記錄顧客回覆
- **收益分析** — 比較餐期利用率與營收機會

## 適合誰使用

- 訂位專員
- 餐廳經理
- 營運主管

## 運作流程

1. 設定餐期容量
2. 配置訂位桌位
3. 確認訂金狀態
4. 管理候補遞補
5. 執行到店確認
6. 檢討餐期收益

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
