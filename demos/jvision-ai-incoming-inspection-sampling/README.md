# 智慧來料風險抽樣平台

> 整合供應商、料號、歷史缺失與批次條件，以人工智慧評估每批來料風險，建議抽樣水準、檢驗項目及處置方式，協助品管人員把有限檢驗資源優先投入高風險物料。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **待驗批次總覽** — 依到料時間、急迫性與風險分數排列今日待驗批次。
- **來料風險評估** — 呈現供應商、料號、變更與歷史缺失等風險因子。
- **智慧抽樣規劃** — 建議抽樣水準、樣本數、檢驗特性與允收門檻。
- **檢驗執行工作台** — 以擬真表單記錄尺寸、外觀及功能檢驗結果。
- **異常處置中心** — 模擬隔離、加嚴檢驗、退貨與供應商通知流程。
- **抽樣成效分析** — 比較節省工時、缺失命中率與風險模型表現。

## 適合誰使用

- 進料品管人員
- 品質主管
- 採購與供應商品質工程師

## 運作流程

1. 建立待驗清單
2. 判讀批次風險
3. 核定抽樣方案
4. 執行來料檢驗
5. 處理不合格批次
6. 回顧抽樣績效

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
