# 公共工程招標釋疑台

> 集中標案文件疑義、圖說與清單矛盾、現勘問題、提問截止日、機關回覆、補充公告及估價影響，讓投標團隊依正式釋疑調整範圍並留下決策依據。

**產業別：**營建工程　|　**系統類型：**legal-case

## 功能模組

- **文件疑義** — 標記招標文件、圖號、頁次與矛盾內容。
- **問題整併** — 合併跨部門重複提問並建立主題關聯。
- **內部審題** — 評估商務風險、提問措辭與送出必要性。
- **正式提問** — 產製機關格式並控管提問截止時間。
- **釋疑回覆** — 登錄正式答覆、補充公告及效力日期。
- **投標影響** — 派送估價、工期、工法與資格文件調整。

## 適合誰使用

- 標案經理
- 估算工程師
- 法務人員

## 運作流程

1. 提出疑義
2. 合併分類
3. 風險審查
4. 送出提問
5. 判讀回覆
6. 更新投標

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
