# 醫囑執行回寫補償台

> 比對醫囑來源、執行端與計價端狀態，串起電話補單、原訊息重送及取消，協助營運人員在不重複執行的前提下完成安全補償。

比對醫囑來源、執行端與計價端狀態，串起電話補單、原訊息重送及取消，協助營運人員在不重複執行的前提下完成安全補償。

**產業別：**醫療照護　|　**系統類型：**it-ops

## 功能模組

- **醫囑異常** — 呈現漏接重複與亂序
- **病人核對** — 確認身分就醫序與時點
- **代碼查驗** — 檢查醫囑項目與科別鍵
- **補償鏈路** — 串起原單人工單與重送
- **安全決策** — 判定補送取消或僅補計價
- **閉環確認** — 核對執行與收費結果

## 適合誰使用

- 醫療資訊人員
- 護理主管
- 計價人員

## 運作流程

1. 偵測醫囑異常
2. 核對病人醫囑
3. 查驗代碼鍵值
4. 還原人工補單
5. 核定補償方式
6. 確認執行計價

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
