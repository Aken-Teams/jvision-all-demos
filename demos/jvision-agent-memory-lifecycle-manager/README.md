# Agent 記憶生命週期管理器

> 治理 Agent 記憶的寫入、合併、過期、刪除與法遵保留，避免無限累積。

治理 Agent 記憶的寫入、合併、過期、刪除與法遵保留，避免無限累積。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **記憶寫入政策** — 依資料類型、敏感度與用途決定是否寫入。
- **語意去重合併** — 辨識相似、矛盾或重複記憶並提出合併方案。
- **保存期限管理** — 設定不同記憶類別的有效期與過期動作。
- **法遵保留鎖定** — 對訴訟、稽核或監管資料套用保留限制。
- **安全刪除佇列** — 集中審查到期、撤回同意與被遺忘請求。
- **記憶容量治理** — 分析容量成長、低價值內容與壓縮成效。

## 適合誰使用

- AI 平台負責人
- 流程主管
- 產品經理

## 運作流程

1. 制定寫入政策
2. 檢查新記憶
3. 整理重複內容
4. 配置保存期限
5. 審批刪除處置
6. 驗證容量成效
