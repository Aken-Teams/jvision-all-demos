# Agent 職責衝突偵測器

偵測 Agent 在申請、核准與付款流程中的不相容職責與舞弊閉環。

**產業別：**資訊科技　|　**系統類型：**security-soc

## 功能模組

- **Agent 職責盤點** — 檢視每個 Agent 的業務角色、可執行動作與代理身分。
- **不相容職責矩陣** — 定義申請、覆核、核准、建檔及付款間的互斥關係。
- **權限閉環分析** — 沿任務與工具鏈找出單一或共謀 Agent 可完成的舞弊路徑。
- **衝突案件研判** — 評估實際權限組合、使用頻率、交易金額與風險嚴重度。
- **緩解控制設計** — 提出拆權、雙人核准、限額、限時授權及額外監控措施。
- **修復驗證中心** — 重跑衝突規則與攻擊路徑，確認權限調整已切斷閉環。

## 適合誰使用

## 運作流程

1. 建立職責清冊
2. 維護互斥矩陣
3. 掃描舞弊閉環
4. 研判衝突風險
5. 核定緩解措施
6. 驗證閉環解除
