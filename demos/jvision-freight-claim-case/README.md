# 貨運貨損理賠管理台

> 管理運送破損、短少與污染案件，彙整簽收異常、照片、責任區段及求償文件，協助物流商在期限內完成判責與理賠。

**產業別：**物流運輸　|　**系統類型：**finance-case

## 功能模組

- **異常受理** — 建立破損、短少或污染案件
- **證據彙整** — 整理照片、簽收單與貨況描述
- **責任區段** — 還原交接節點與承運責任
- **賠付試算** — 依貨值與條款計算建議金額
- **理賠審核** — 進行責任及賠付層級核准
- **追償結案** — 追蹤付款、追償與結案文件

## 適合誰使用

- 客服理賠員
- 運務主管
- 財務人員

## 運作流程

1. 受理通報
2. 蒐集證據
3. 還原運程
4. 判責試算
5. 核准賠付
6. 追償結案

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
