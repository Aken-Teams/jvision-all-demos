# 揀貨路徑優化系統（Pick Path Optimization）

> 收貨到出貨的倉內作業與庫存精準管理

揀貨路徑優化系統（Pick Path Optimization）提供揀貨路徑演算法規劃、波次/批次/區域揀貨模式切換、揀貨任務動態分派。倉儲部依「訂單匯入→揀貨策略判斷→路徑演算→任務派工→揀貨執行→績效回饋」推進作業，優先解決「揀貨人員行走距離過長」，生管部則以揀貨行走距離與單位時間揀貨件數確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**倉儲物流　|　**系統類型：**WMS 倉儲管理系統

## 功能模組

- **入庫上架** — 收貨、驗收與智慧上架
- **揀貨出貨** — 波次揀貨、覆核與出貨
- **儲位管理** — 儲位規劃與庫容視覺化
- **庫存盤點** — 即時庫存、盤點與調撥
- **拉動補料** — 安全庫存與自動補貨
- **條碼作業** — PDA 掃碼即時作業

## 適合誰使用

- 倉儲部
- 生管部
- 資訊部

## 運作流程

1. 待盤點
2. 待補貨
3. 移庫中
4. 出庫完成

## 導入效益

- 揀貨作業工時：7小時/日 → **2小時/日**
- 庫存準確率：84% → **97%**
- 出貨延遲率：9.5% → **1.9%**
- 盤點工時：16小時/月 → **3.1小時/月**
