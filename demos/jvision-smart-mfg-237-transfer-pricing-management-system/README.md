# 移轉訂價管理系統（Transfer Pricing Management System）

> 應收付、現金流到預算的財務即時掌握

移轉訂價管理系統（Transfer Pricing Management System）提供關係人交易紀錄彙整、移轉訂價政策設定與模擬、常規交易利潤率比對(Benchmarking)。會計專員、財務經理、負責人依「關係人交易紀錄彙整、移轉訂價政策設定與模擬、常規交易利潤率比對(Benchmarking)」推進作業，優先解決「跨國關係人交易缺乏系統化紀錄」，部門主管則以移轉訂價管理預警塔處理結果確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**財務會計　|　**系統類型：**財務會計系統

## 功能模組

- **應收帳款** — 開立、對帳與催收
- **應付帳款** — 請款、付款與對帳
- **現金流** — 資金調度與預測
- **預算管理** — 編列、控管與差異分析
- **固定資產** — 資產登錄與折舊
- **總帳傳票** — 傳票、拋轉與月結

## 適合誰使用

- 會計專員
- 財務經理
- 負責人

## 運作流程

1. 待核對
2. 處理中
3. 待覆核
4. 已入帳

## 導入效益

- 月結作業天數：5.6天 → **1.9天**
- 對帳錯誤：7.5件/月 → **0.9件/月**
- 帳款逾期率：14% → **4.7%**
- 報表產出工時：15小時 → **0.9小時**
