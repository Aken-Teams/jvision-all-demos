# 製程參數反事實分析器

> 模擬製程參數變更的因果結果與不確定性，支援安全的製程改善決策。

模擬製程參數變更的因果結果與不確定性，支援安全的製程改善決策。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **參數情境設定** — 選擇配方、設備與可調參數，建立基準及反事實情境。
- **因果關係模型** — 呈現參數、環境、設備狀態與品質結果間的因果路徑。
- **反事實模擬** — 推估指定參數若改變時，產量、良率、週期與能耗的結果。
- **多目標權衡** — 比較品質、產能、成本、能耗及設備風險間的取捨。
- **不確定性分析** — 顯示預測區間、資料覆蓋程度與超出模型適用域的情境。
- **現場試驗方案** — 將候選參數轉為含護欄、停損條件與量測項目的試驗計畫。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 選定製程基準
2. 設定參數變更
3. 執行反事實推演
4. 比較目標權衡
5. 核准現場試驗
6. 同步試驗執行

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
