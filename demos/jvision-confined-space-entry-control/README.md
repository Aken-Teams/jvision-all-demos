# 局限空間進出許可台

> 針對坑井、槽體與地下空間管理作業許可、氣體檢測、通風、救援配置與人員進出清點，確保換班後仍能辨識尚未退出者。

**產業別：**營建工程　|　**系統類型：**security-soc

## 功能模組

- **作業總覽** — 查看開放空間與人員
- **環境檢測** — 記錄氣體數值與通風
- **救援檢核** — 確認器材人員和聯絡
- **人員資格** — 核對訓練及工作名單
- **進出清點** — 即時記錄進入與退出
- **許可關閉** — 全員退出後正式結案

## 適合誰使用

- 職安人員
- 監視人員
- 作業領班

## 運作流程

1. 提出申請
2. 檢測環境
3. 確認救援
4. 核准進入
5. 持續清點
6. 確認關閉

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
