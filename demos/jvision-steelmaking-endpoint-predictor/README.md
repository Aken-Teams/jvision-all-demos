# 煉鋼終點成溫預測器

> 利用吹煉批次、入爐條件、加料與副槍量測等擬真資料，預測終點碳含量、關鍵成分及出鋼溫度，並提供補吹或冷卻建議，降低重吹、過氧化與成分修正成本。

利用吹煉批次、入爐條件、加料與副槍量測等擬真資料，預測終點碳含量、關鍵成分及出鋼溫度，並提供補吹或冷卻建議，降低重吹、過氧化與成分修正成本。

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **爐次準備** — 確認鐵水、廢鋼、目標鋼種與吹煉條件是否完整。
- **吹煉監看** — 以階段進度與參數曲線呈現目前吹煉狀態。
- **終點預測** — 顯示成分、溫度預測值、信心區間及命中機率。
- **補正試算** — 比較補吹、加料或冷卻方案對終點結果的影響。
- **出鋼判定** — 彙整風險與限制條件，形成可解釋的出鋼建議。
- **偏差分析** — 依鋼種、班別及設備分析預測誤差與改善方向。

## 適合誰使用

- 煉鋼操作員
- 製程冶金工程師
- 煉鋼值班主管

## 運作流程

1. 建立爐次
2. 監看吹煉
3. 讀取預測
4. 試算補正
5. 決定出鋼
6. 檢討偏差
