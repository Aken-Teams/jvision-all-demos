# 建物設備主檔仲裁台

> 比對點交表、維保系統與財產帳中的設備編號、位置及狀態，透過人工裁決合併或保留關係，避免錯派維修、漏用保固與重複計列資產。

比對點交表、維保系統與財產帳中的設備編號、位置及狀態，透過人工裁決合併或保留關係，避免錯派維修、漏用保固與重複計列資產。

**產業別：**房地產與物業　|　**系統類型：**it-ops

## 功能模組

- **來源主檔** — 彙整各系統設備資料
- **候選比對** — 找出編號位置相似項
- **關聯檢視** — 查看工單保固與資產
- **仲裁工作台** — 決定主碼合併或分拆
- **影響模擬** — 預覽歷史與派工影響
- **對映發布** — 同步核准關係與版本

## 適合誰使用

- 物業設備主管
- 資產管理員
- 資訊人員

## 運作流程

1. 匯入設備資料
2. 產生比對候選
3. 查驗關聯紀錄
4. 裁決設備身分
5. 模擬發布影響
6. 發布對映版本
