## 功能模組

- **贊助權益帳本** — 整理攤位、冠名、媒體露出、演講與招待等贊助權益。
- **曝光價值計量** — 彙整現場、直播、媒體與社群曝光並校正重複觸及。
- **互動事件串接** — 連結掃碼、入場、下載、會談與內容互動至帳戶。
- **商機影響路徑** — 追蹤贊助接觸如何參與商機建立、推進與成交。
- **歸因證據圖譜** — 呈現曝光、人物、帳戶、商機與營收的可驗證關聯。
- **贊助 ROI 結算** — 比較歸因模型、成本與增量營收，產出可核准結算報告。

## 適合誰使用

- 行銷主管
- 內容團隊
- 成長經理

## 運作流程

1. 盤點贊助權益
2. 核算曝光價值
3. 串接參與互動
4. 追蹤商機影響
5. 驗證歸因證據
6. 核准 ROI 結算
