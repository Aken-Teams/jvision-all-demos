# ESG供應鏈盡職調查系統

> 供應商協同、詢比議價到交期風險控管

ESG供應鏈盡職調查系統提供ESG問卷與自評管理、第三方ESG評級資料整合、高風險供應商標記。採購部依「ESG問卷發送 → 供應商自評 → 第三方驗證 → 風險分級 → 改善追蹤」推進作業，優先解決「客戶ESG稽核要求日增」，永續發展部則以ESG問卷回覆率與高風險供應商占比確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**ESG 永續　|　**系統類型：**SRM 採購供應商管理

## 功能模組

- **供應商管理** — 建檔、分級與績效評分
- **詢報價協作** — 線上詢價、比價與議價
- **採購訂單** — 請購、下單與交期追蹤
- **交期風險** — 缺料預警與到貨監控
- **供應商品質** — 進料檢驗與 SCAR 改善
- **綠色採購** — ESG 評分與永續採購

## 適合誰使用

- 採購部
- 永續發展部
- 法遵部

## 運作流程

1. 待蒐集
2. 核對中
3. 查證確認
4. 揭露完成

## 導入效益

- 盤查作業工時：38小時 → **7.5小時**
- 數據完整率：56% → **89%**
- 減碳目標達成：47% → **83%**
- 用能異常反應：23小時 → **1.9小時**
