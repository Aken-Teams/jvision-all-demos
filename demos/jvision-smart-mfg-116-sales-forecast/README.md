# Sales Forecast 業務預測協作所

彙整業務人員與歷史數據，預估未來期間的訂單與營收，作為產銷排程與財務規劃依據。

- 原始系統：Sales Forecast 業務預測
- 產業分類：智慧製造｜業務管理
- 使用部門：業務部、業務主管、產銷規劃(PMC)、財務部、總經理室
- 工作流程：業務填報預測→主管審核彙整→與歷史數據比對→提供PMC/財務參考→期末覆盤校準
- AI 應用：時間序列銷售預測模型、異常預測值自動標記、客戶下單週期模式辨識
- 主要 KPI：預測準確率、預測偏差率、滾動預測更新頻率、產能匹配度
- 代表產品：SAP Integrated Business Planning、Anaplan、Microsoft Dynamics 365 Sales Forecasting
