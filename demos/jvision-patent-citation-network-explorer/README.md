# 專利引證網路探索器

**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **專利族檢索** — 依技術詞、申請人、分類號與法域建立待分析的專利集合。
- **引證網路圖譜** — 呈現前向、後向引證及跨專利族關係，支援逐層展開探索。
- **樞紐專利辨識** — 依引證中心性、成長速度與技術涵蓋度找出關鍵節點。
- **技術群聚解析** — 將專利依權利項語意與引證關係分群，命名核心技術主題。
- **競爭布局對照** — 比較申請人、法域、時間軸與技術群聚中的卡位差異。
- **核心技術清單** — 彙整高影響專利、判定理由、引用來源與後續研判建議。

## 適合誰使用

- 法務主管
- 專利工程師
- 法遵人員

## 運作流程

1. 建立探索範圍
2. 展開引證關係
3. 計算關鍵樞紐
4. 解讀技術群聚
5. 比較競爭布局
6. 確認核心技術
