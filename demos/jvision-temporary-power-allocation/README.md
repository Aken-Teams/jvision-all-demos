# 臨時用電配額管理台

> 依工區、樓層與臨時配電盤管理各分包的用電申請、設備負載、迴路配置及使用期間，以畫面模擬容量占用和衝突審查，避免任意增接造成跳電與待工。

依工區、樓層與臨時配電盤管理各分包的用電申請、設備負載、迴路配置及使用期間，以畫面模擬容量占用和衝突審查，避免任意增接造成跳電與待工。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **盤體台帳** — 管理配電盤、迴路及可分配容量。
- **用電申請** — 申報設備功率、區域與使用期間。
- **迴路配置** — 將核准設備配置至指定迴路。
- **負載試算** — 模擬各時段容量與尖峰衝突。
- **異常通報** — 記錄跳電、私接及超額使用。
- **到期清退** — 追蹤用電期限與迴路釋出。

## 適合誰使用

- 機電工程師
- 工地主任
- 分包領班

## 運作流程

1. 維護配電容量
2. 提交用電需求
3. 試算負載衝突
4. 核配使用迴路
5. 登錄用電異常
6. 到期確認清退

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
