# 地下管線試挖管制台

> 整合既有管線圖、會勘標記與試挖任務，逐點記錄開挖深度、實際管徑、材質及座標差異，完成保護措施與圖面回填後才放行後續大面積開挖。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **管線底圖** — 疊合圖資並標示高風險交會點與待確認區。
- **試挖點位** — 建立點位編號、預估深度、管種與試挖範圍。
- **會勘排程** — 協調管線單位、監造、測量及開挖班組到場。
- **現況實測** — 記錄實際位置、深度、管徑、材質與照片。
- **異常處置** — 追蹤未標示管線、位置偏差及保護或遷移措施。
- **圖資回填放行** — 更新竣工底圖並核准後續開挖範圍。

## 適合誰使用

- 土木工程師
- 測量人員
- 開挖工班領班

## 運作流程

1. 辨識試挖點位
2. 安排聯合會勘
3. 執行試挖作業
4. 完成位置實測
5. 處理圖況差異
6. 核准區域開挖

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
