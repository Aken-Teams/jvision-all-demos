# 租金調整授權管制台

> 將租金優惠、減讓、恢復日期與核准依據轉為可追蹤異動，讓開單前檢查優惠是否到期，避免口頭指示造成持續少收。

將租金優惠、減讓、恢復日期與核准依據轉為可追蹤異動，讓開單前檢查優惠是否到期，避免口頭指示造成持續少收。

**產業別：**房地產與物業　|　**系統類型：**finance-case

## 功能模組

- **租約基準** — 查看原租金與調整條款。
- **異動申請** — 登錄優惠、期間及原因。
- **影響試算** — 計算租期內收入減少。
- **分級授權** — 依金額與關係人覆核。
- **到期恢復** — 追蹤優惠結束與開單。
- **稽核軌跡** — 保存前後租金及核准。

## 適合誰使用

- 租務專員
- 物業會計
- 資產主管

## 運作流程

1. 提出調整
2. 核對租約
3. 試算影響
4. 完成核准
5. 更新開單
6. 到期複核

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
