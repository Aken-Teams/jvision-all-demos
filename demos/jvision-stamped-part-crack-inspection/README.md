> 以預先建立的沖壓件影像與擬真辨識結果，呈現表面裂紋、邊角破裂及延伸方向，協助品保人員快速複判、標註與追溯缺陷批次，並比較料號、模具穴位及製程條件，降低漏檢與不良品流出風險。

## 功能模組

- **檢測戰情總覽** — 呈現各產線檢測量、裂紋率、待複判數與近期異常批次。
- **影像複判工作台** — 放大零件影像、疊加裂紋框線與信心分數，供檢驗員判定。
- **缺陷標註管理** — 新增或修正裂紋範圍、方向、長度及缺陷類別，形成標註紀錄。
- **批次隔離追蹤** — 彙整異常件所屬批號、箱號與數量，模擬隔離、放行及報廢流程。
- **成因關聯分析** — 比較料號、模具穴位、班別與成型條件，找出裂紋集中組合。
- **品質報告中心** — 產出缺陷分布、複判一致率、批次趨勢及改善前後比較報告。

## 適合誰使用

- 品保檢驗員
- 製程工程師
- 品保主管與產線領班

## 運作流程

1. 掌握檢測狀況
2. 複判疑似裂紋
3. 修正缺陷標註
4. 管制異常批次
5. 分析裂紋成因
6. 提交品質報告

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
