# 工料代扣結算作業台

> 集中總包代墊的材料、人工、清運與修復憑證，逐筆取得責任工班簽認，避免漏扣或重複扣款，並銜接分包估驗付款。

集中總包代墊的材料、人工、清運與修復憑證，逐筆取得責任工班簽認，避免漏扣或重複扣款，並銜接分包估驗付款。

**產業別：**營建工程　|　**系統類型：**finance-case

## 功能模組

- **代墊憑證** — 彙整工料與清運支出。
- **責任工班** — 連結缺失與分包商。
- **現場簽認** — 取得責任及數量確認。
- **代扣試算** — 依估驗期彙總金額。
- **爭議處理** — 管理拒認及補充證據。
- **付款扣抵** — 形成分包付款調整。

## 適合誰使用

- 工務工程師
- 成本會計
- 分包窗口

## 運作流程

1. 建立代墊
2. 指定責任
3. 取得簽認
4. 彙總代扣
5. 處理爭議
6. 執行扣抵

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
