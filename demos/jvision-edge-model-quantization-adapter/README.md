比較邊緣模型量化後的精度、延遲與功耗，選出可部署版本。常用。

**產業別：**設備維護　|　**系統類型：**it-ops

## 功能模組

- **量化候選工坊** — 建立 INT8、INT4、混合精度等候選模型與校準設定。
- **精度退化測試** — 比較候選版本在場域資料上的準確率與關鍵類別召回率。
- **裝置延遲賽道** — 在目標晶片上量測冷啟動、單次推論與吞吐表現。
- **功耗熱區分析** — 呈現各工作負載的平均功耗、峰值與熱節流風險。
- **多目標取捨器** — 依精度底線、延遲預算與能源限制排序 Pareto 候選。
- **部署版本定版** — 產生含相容裝置、風險界線及回滾版本的發布建議。

## 適合誰使用

- IoT 架構師
- 設備工程師
- 場域主管

## 運作流程

1. 建立量化候選
2. 驗證精度底線
3. 實測裝置延遲
4. 量測能源代價
5. 選擇最佳取捨
6. 核准部署版本
