# 餐飲過敏餐點管制台

> 將顧客過敏需求轉成可追蹤的接單、廚房確認、替代食材、隔離製作與出餐覆核流程，保存交接紀錄，降低口頭傳遞造成的錯誤。

將顧客過敏需求轉成可追蹤的接單、廚房確認、替代食材、隔離製作與出餐覆核流程，保存交接紀錄，降低口頭傳遞造成的錯誤。

**產業別：**餐飲旅宿　|　**系統類型：**quality-qms

## 功能模組

- **需求登錄** — 記錄桌號、餐次、過敏原與嚴重程度。
- **菜色評估** — 判斷原料、醬料及共用設備風險。
- **替代方案** — 提出可承作菜色與替代食材供確認。
- **製作指示** — 產生隔離備製及器具清潔要求。
- **出餐覆核** — 以雙人核對確認餐點和服務對象。
- **事件紀錄** — 保存交接、異常及改善追蹤資料。

## 適合誰使用

- 外場領班
- 主廚
- 出餐口覆核員

## 運作流程

1. 登錄需求
2. 評估風險
3. 確認替代
4. 隔離製作
5. 覆核出餐
6. 留存結案

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
