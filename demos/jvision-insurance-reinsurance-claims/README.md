# 再保攤賠追收管理台

> 協助保險公司針對重大理賠辨識再保合約、計算自留與攤賠金額、整備通知文件、追蹤再保人確認及收款差異，避免漏報案件與回收延遲。

協助保險公司針對重大理賠辨識再保合約、計算自留與攤賠金額、整備通知文件、追蹤再保人確認及收款差異，避免漏報案件與回收延遲。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **重大賠案池** — 篩選可能觸發再保的理賠案件。
- **合約適用** — 比對合約期間、險種與責任層。
- **攤賠試算** — 計算自留額、分出比例與應收款。
- **案件通知** — 管理初報、續報與正式請款文件。
- **再保確認** — 追蹤再保人意見及爭議項目。
- **回收核銷** — 比對應收、實收及匯差。

## 適合誰使用

- 再保人員
- 理賠主管
- 保險財務

## 運作流程

1. 辨識重大賠案
2. 判定適用合約
3. 試算攤賠金額
4. 送出案件通知
5. 處理攤賠確認
6. 核銷回收款項

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
