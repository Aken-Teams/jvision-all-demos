# 靜電敏感元件倉儲管理智慧站

依ANSI/ESD S20.20標準管理靜電敏感元件的儲存、包裝與搬運環境，避免靜電損傷元件。

- 原始系統：靜電敏感元件(ESD)倉儲管理系統（ESD Sensitive Device Storage Management）
- 產業分類：智慧製造｜倉儲管理
- 使用部門：倉儲部、品保部、工程部
- 工作流程：ESD料件入庫標示→防靜電包裝→儲存環境監控→搬運稽核→異常通報→合規報表產出
- AI 應用：ESD合規稽核異常型態分析、高風險作業環節預警
- 主要 KPI：ESD合規稽核通過率、靜電相關不良率、防靜電包裝合格率、異常事件回應時效
- 代表產品：多整合於廠內ESD稽核制度與MES/QMS模組，另搭配3M、Desco等靜電監控設備
