# 商用租約選擇權管制台

> 協助商辦與店面資產管理團隊追蹤續租、提前解約、優先承租及租金調整選擇權，依合約期限產生待辦、比較財務方案並保留往來紀錄，避免錯過通知窗口造成租金或空置損失。

協助商辦與店面資產管理團隊追蹤續租、提前解約、優先承租及租金調整選擇權，依合約期限產生待辦、比較財務方案並保留往來紀錄，避免錯過通知窗口造成租金或空置損失。

**產業別：**房地產與物業　|　**系統類型：**legal-case

## 功能模組

- **租約台帳** — 登錄標的、承租戶及關鍵租約條款。
- **行權日程** — 顯示續租、解約及調租通知窗口。
- **方案試算** — 比較續租條件、租金變化與空置成本。
- **內部決策** — 彙整建議方案並進行簽核。
- **通知管理** — 產製並追蹤正式行權通知。
- **履約紀錄** — 保留回覆、協商及最終條件版本。

## 適合誰使用

- 資產經理
- 租賃專員
- 法務人員

## 運作流程

1. 建置台帳
2. 監控期限
3. 評估方案
4. 完成簽核
5. 發出通知
6. 更新結果
