# 補助經費核銷預審器

> 預審補助支出的資格、期間、科目與憑證，降低核銷遭剔除風險。提升核銷成功率與合規性。

預審補助支出的資格、期間、科目與憑證，降低核銷遭剔除風險。提升核銷成功率與合規性。

**產業別：**專業服務　|　**系統類型：**finance-case

## 功能模組

- **核銷批次總覽** — 依補助計畫、核銷期別與送件期限整理待預審支出。
- **支出期間檢查** — 檢查交易、付款與憑證日期是否落在可核銷期間。
- **經費科目判定** — 比對核定預算與補助規範，判斷支出科目及可報比例。
- **憑證完整度檢查** — 查驗發票、付款證明、驗收紀錄與必要附件是否齊備。
- **剔除情境模擬** — 模擬不同認列結果對補助款、配合款與預算餘額的影響。
- **送件修補清單** — 按剔除風險排列補件、改列與說明事項並同步負責人。

## 適合誰使用

- 標案經理
- 業務主管
- 計畫主持人

## 運作流程

1. 建立預審批次
2. 檢查支出期間
3. 判定經費科目
4. 核驗憑證附件
5. 模擬剔除影響
6. 核准送件清單

## 導入效益

- 案件文件工時：6小時 → **1.5小時**
- 期限掌握率：72% → **96%**
- 計費遺漏：10% → **2%**
- 進度查找時間：20分鐘 → **3分鐘**
