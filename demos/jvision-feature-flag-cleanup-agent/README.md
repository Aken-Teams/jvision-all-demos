# Feature Flag 清理 Agent

> 辨識已過期或無效的功能旗標，規劃可驗證、可核准的安全移除路徑。

辨識已過期或無效的功能旗標，規劃可驗證、可核准的安全移除路徑。

**產業別：**資訊科技　|　**系統類型：**it-ops

## 功能模組

- **旗標健康盤點** — 依最後切換時間、環境覆蓋率與程式引用辨識疑似過期旗標。
- **分支影響圖** — 展開旗標控制的程式分支、服務依賴與使用者情境。
- **使用情境模擬** — 模擬固定開啟、固定關閉及直接移除對流量與功能的影響。
- **安全移除路徑** — 生成程式修改、設定清除、文件更新與部署順序。
- **移除驗證計畫** — 配置單元、整合、回歸及觀測指標的驗證門檻。
- **清理執行中心** — 核准後建立變更任務、同步來源系統並追蹤旗標移除結果。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 掃描旗標
2. 確認影響
3. 模擬情境
4. 規劃清理
5. 設定驗證
6. 核准執行

## 導入效益

- 事件平均處理：120分鐘 → **30分鐘**
- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
- 資產盤點工時：20小時/月 → **4小時/月**
