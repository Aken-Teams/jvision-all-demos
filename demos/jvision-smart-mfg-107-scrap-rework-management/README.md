# Scrap/Rework Management（報廢重工管理）

> 應收付、現金流到預算的財務即時掌握

Scrap/Rework Management（報廢重工管理）提供報廢/重工單開立、處置方式判定、重工作業指導。生產部依「不良品判定→報廢或重工決定→作業執行→品質驗證→成本歸檔」推進作業，優先解決「重工品質未有效驗證」，品保部則以重工成功率與報廢率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**品質管理　|　**系統類型：**財務會計系統

## 功能模組

- **應收帳款** — 開立、對帳與催收
- **應付帳款** — 請款、付款與對帳
- **現金流** — 資金調度與預測
- **預算管理** — 編列、控管與差異分析
- **固定資產** — 資產登錄與折舊
- **總帳傳票** — 傳票、拋轉與月結

## 適合誰使用

- 生產部
- 品保部
- 製程工程部

## 運作流程

1. 待分派
2. 執行中
3. 驗證確認
4. 已完成

## 導入效益

- 批號追溯時間：191分鐘 → **14分鐘**
- 客訴平均關案：21天 → **9.2天**
- 改善驗證率：67% → **92%**
- 重複不良率：5.8% → **2%**
