# Jvision 藥局健保調劑申報 Demo

Jvision 藥局健保調劑申報 Demo，整合處方輸入、健保藥價更新、申報檢核、藥袋列印、部分負擔、歷史申報與藥品耗用分析。

## 線上 Demo

- 正式網站：[https://jvision-pharmacy-claim.vercel.app](https://jvision-pharmacy-claim.vercel.app)

![Jvision 藥局健保調劑申報 Demo 海報](docs/marketing/jvision-pharmacy-claim-poster.png)

## Demo 功能

- 處方調劑
- 申報檢核
- 列印報表
- 可操作的表單、按鈕、篩選或流程狀態
- 桌面、平板與手機 RWD 響應式排版

> 本站為產品功能展示用途，畫面中的人物、公司、金額與營運資料皆為示範資料。

## 操作方式

1. 開啟線上 Demo，先查看儀表板與營運摘要。
2. 依照頁面導覽切換主要功能區。
3. 操作新增、編輯、篩選、狀態切換或流程按鈕。
4. 使用不同螢幕尺寸檢視 RWD 操作介面。

## 技術架構

- Next.js
- React
- TypeScript
- Vercel Production Deployment

## 本機啟動

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

開啟 [http://localhost:3000](http://localhost:3000) 即可使用 Demo。

## 品質檢查

```bash
npm run build
```
