# 端點偵測與應變協作所

於員工電腦、產線工站PC等端點部署代理程式，即時偵測惡意行為並支援自動化應變隔離。

- 原始系統：端點偵測與應變系統（EDR/XDR）
- 產業分類：智慧製造｜IT管理
- 使用部門：資訊安全部、資訊部、產線工站管理單位
- 工作流程：端點部署代理程式→持續行為監控→威脅偵測告警→自動/人工隔離處置→鑑識調查根因→修補與強化防護
- AI 應用：未知惡意行為模式辨識、攻擊鏈自動關聯分析
- 主要 KPI：威脅偵測率、平均圍堵時間、端點覆蓋率、誤報率
- 代表產品：CrowdStrike Falcon、Microsoft Defender for Endpoint、SentinelOne、Trend Micro Apex One
