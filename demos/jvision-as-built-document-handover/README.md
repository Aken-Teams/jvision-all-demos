# 竣工圖資點交管制台

> 依契約與設施分類管理竣工圖、設備清冊、操作手冊、保固文件及模型成果，檢查格式、版次和現場一致性，完成監造、業主及維運單位分批點交。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **交付總覽** — 按專業與設施顯示文件完整度及點交狀態。
- **交件收件** — 接收分包竣工圖、清冊、手冊與保固資料。
- **格式檢核** — 檢查命名、版次、簽章、格式與契約份數。
- **現場抽核** — 比對圖資內容、設備標籤和實際安裝位置。
- **退補修訂** — 記錄缺漏原因並追蹤分包重新送件。
- **分批點交** — 建立點交包並取得監造、業主與維運簽收。

## 適合誰使用

- 圖管人員
- 監造工程師
- 業主維運人員

## 運作流程

1. 交付總覽
2. 交件收件
3. 格式檢核
4. 現場抽核
5. 退補修訂
6. 分批點交

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
