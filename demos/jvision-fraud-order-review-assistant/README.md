# 電商詐欺訂單覆核助手

> 將擬真訂單的付款、收件、裝置與歷史行為線索集中呈現，依風險規則產生可解釋警示，協助覆核人員比較關聯訂單、記錄判斷依據並做出放行、補件或取消決策，兼顧損失與誤攔風險。

## 功能模組

- **風險案件佇列** — 依風險分數、訂單金額、出貨期限與警示類型排列案件。
- **訂單證據摘要** — 集中呈現付款、裝置、地址、帳號與行為線索及風險解釋。
- **關聯訂單圖譜** — 視覺化共用電話、地址、裝置或付款特徵的模擬訂單關係。
- **人工覆核清單** — 依案件類型引導核對步驟，記錄通過、異常與待補資訊。
- **補件聯繫中心** — 選用訊息範本模擬要求身分或交易確認，追蹤回覆狀態。
- **決策與稽核紀錄** — 完成放行、補件、取消或升級決策，保留理由與操作軌跡。

## 適合誰使用

- 風險覆核人員
- 電商客服人員
- 資訊安全主管

## 運作流程

1. 領取風險案件
2. 閱讀風險證據
3. 比對關聯訂單
4. 執行覆核程序
5. 要求顧客補件
6. 提交最終決策

## 導入效益

- 告警分流時間：45分鐘 → **8分鐘**
- 事件平均處理：12小時 → **3小時**
- 弱點修補率：68% → **96%**
- 合規稽核工時：30小時/月 → **6小時/月**
