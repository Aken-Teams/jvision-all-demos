# 鷹架使用區域協調台

> 按立面、樓層與區段管理鷹架搭設狀態、使用工種、需求期間及拆架條件，協調泥作、防水、塗裝與帷幕作業，避免提早拆除後重搭或長期占用增加租費。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **立面分區** — 以立面、樓層及區段標示鷹架狀態。
- **使用申請** — 申報工種、期間及作業需求。
- **工序協調** — 排列同區各工種的使用先後。
- **拆架條件** — 確認收尾、查驗及後續需求。
- **搭拆派工** — 發布搭設、移架、加固及拆除工作。
- **租費分析** — 統計占用、閒置與重搭成本。

## 適合誰使用

- 工地主任
- 鷹架承商
- 專業分包領班

## 運作流程

1. 劃分鷹架區段
2. 提出使用需求
3. 整合工序排程
4. 執行搭設調整
5. 確認拆架條件
6. 結算占用成本

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
