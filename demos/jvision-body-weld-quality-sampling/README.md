# 車身焊點品質抽檢最佳化器

> 依車型、工位、焊接參數、電極狀態與歷史檢驗等擬真資料，預測車身焊點品質風險，規劃風險導向抽檢清單並模擬檢驗資源配置，提升高風險焊點覆蓋率。

依車型、工位、焊接參數、電極狀態與歷史檢驗等擬真資料，預測車身焊點品質風險，規劃風險導向抽檢清單並模擬檢驗資源配置，提升高風險焊點覆蓋率。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **焊裝風險圖** — 以車型、工位與班次呈現焊點風險分布及排行。
- **焊點預測** — 查看單點品質機率、影響參數與可信程度。
- **抽檢策略** — 設定法規、客規、風險門檻及最低抽樣規則。
- **抽檢排程** — 依人力、工時與檢驗方式產生班次抽檢清單。
- **檢驗登錄** — 輸入擬真的撕裂、超音波或外觀檢驗結果。
- **成效分析** — 比較命中率、風險覆蓋與不同策略的資源效益。

## 適合誰使用

- 焊裝品質工程師
- 製程工程師
- 檢驗班長

## 運作流程

1. 掌握風險
2. 檢視單點
3. 設定規則
4. 安排抽檢
5. 登錄結果
6. 評估策略

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
