# 旅宿退款憑證覆核台

> 把退款申請、原交易、取消原因、刷退證明與收入沖銷集中勾稽，透過分級授權防止重複退款、退錯工具及退款後未沖帳。

**產業別：**餐飲旅宿　|　**系統類型：**finance-case

## 功能模組

- **退款申請** — 彙整原因、金額及附件。
- **原交易勾稽** — 核對訂單與付款工具。
- **退款資格** — 檢查取消條款與已履約項目。
- **分級授權** — 依金額安排主管核准。
- **刷退驗證** — 確認支付後台處理結果。
- **沖帳覆核** — 核對收入與退款傳票。

## 適合誰使用

- 櫃檯主管
- 財務會計
- 稽核人員

## 運作流程

1. 提出退款
2. 核對交易
3. 審查資格
4. 核准退款
5. 驗證刷退
6. 完成沖帳

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
