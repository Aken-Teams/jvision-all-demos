# 工地人員證照預警台

> 集中管理各工地自有人員與分包工人的法定證照、回訓需求、適用作業及有效期限，於排班和進場前揭露缺件或即將到期狀態，避免無資格人員執行管制作業。

集中管理各工地自有人員與分包工人的法定證照、回訓需求、適用作業及有效期限，於排班和進場前揭露缺件或即將到期狀態，避免無資格人員執行管制作業。

**產業別：**營建工程　|　**系統類型：**hr-hris

## 功能模組

- **人員名冊** — 依公司、工地及工種整理人員。
- **證照建檔** — 記錄證別、證號、附件與有效期。
- **資格規則** — 對照工項所需證照與回訓條件。
- **到期日曆** — 呈現續證、回訓及健檢期限。
- **缺證預警** — 找出排班或進場資格不符者。
- **覆核放行** — 確認補件後恢復作業資格。

## 適合誰使用

- 職安人員
- 分包管理員
- 工地行政

## 運作流程

1. 名冊彙整
2. 證照上傳
3. 資格覆核
4. 到期提醒
5. 異常管制
6. 補件復核

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
