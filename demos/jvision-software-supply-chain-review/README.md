# 軟體供應鏈風險審查台

> 審查開源套件、軟體物料清單、建置來源與供應商元件風險，以人工智慧整理弱點、授權及完整性疑慮，協助研發團隊在發布前做出核准或阻擋決策。

**產業別：**研發管理　|　**系統類型：**security-soc

## 功能模組

- **軟體物料清單** — 依產品版本呈現套件、版本、來源、授權及直接或間接相依關係。
- **元件風險審查** — 集中檢視已知弱點、停止維護、可疑來源與授權風險。
- **相依影響分析** — 追查問題元件被哪些產品、服務與版本引用及影響層級。
- **發布安全閘門** — 依風險政策模擬核准、條件通過或阻擋發布的判斷。
- **替代方案比較** — 比較升級、替換、移除或暫時緩解方案的工作量與風險。
- **例外追蹤台帳** — 記錄風險接受理由、補償措施、核准人與重新審查日期。

## 適合誰使用

- 研發主管
- 軟體工程師
- 資安工程師
- 採購人員

## 運作流程

1. 建立清單
2. 辨識風險
3. 分析影響
4. 審查發布
5. 選擇替代
6. 管理例外
