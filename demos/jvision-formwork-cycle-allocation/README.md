# 模板週轉配置排程台

> 依樓層施工節拍、拆模條件與模板套數規劃牆、柱、梁、板模板的拆除、整修、轉運及再使用區段；當進度異動時快速重排供需，提早發現模板占用、短缺與工班等待風險。

依樓層施工節拍、拆模條件與模板套數規劃牆、柱、梁、板模板的拆除、整修、轉運及再使用區段；當進度異動時快速重排供需，提早發現模板占用、短缺與工班等待風險。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **模板資源池** — 管理各系統模板的套數、位置與可用狀態。
- **樓層需求表** — 依澆置節拍建立各區模板需求日期與數量。
- **週轉排程** — 安排拆除、整修、吊運及下一區組立時點。
- **衝突檢查** — 顯示同套模板重疊占用與數量短缺。
- **變更重排** — 模擬進度延誤後的替代套數與調度方案。
- **班組派工** — 發布每日拆模、清修、轉運及組立任務。

## 適合誰使用

- 模板工程師
- 排程工程師
- 模板分包領班

## 運作流程

1. 盤點模板
2. 建立需求
3. 配置週轉
4. 檢查衝突
5. 核定重排
6. 發布派工

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
