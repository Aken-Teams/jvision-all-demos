挑選資訊價值最高的缺陷影像供人工判定，以更少標註完成回訓。実際

**產業別：**生產製造　|　**系統類型：**quality-qms

## 功能模組

- **高價值樣本池** — 依不確定性、代表性與稀有度排序待判影像。
- **人工缺陷判定** — 提供影像縮放、框選與類別規則，快速完成判定。
- **判定分歧仲裁** — 集中處理多人標註不一致與模型規則矛盾。
- **訓練集增量編排** — 平衡新舊類別並組成可控的增量訓練資料集。
- **候選模型回訓** — 追蹤訓練任務、版本差異與類別表現。
- **模型驗證上線** — 通過影子測試後分階段部署，異常時回滾。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 挑選高價值影像
2. 執行人工判定
3. 仲裁判定分歧
4. 組成增量資料集
5. 回訓候選模型
6. 驗證部署版本

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
