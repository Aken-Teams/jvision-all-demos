# 供應鏈碳數據站

> 供應商協同、詢比議價到交期風險控管

收集供應商碳數據、佐證文件與缺漏提醒。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**ESG 永續　|　**系統類型：**SRM 採購供應商管理

## 功能模組

- **供應商管理** — 建檔、分級與績效評分
- **詢報價協作** — 線上詢價、比價與議價
- **採購訂單** — 請購、下單與交期追蹤
- **交期風險** — 缺料預警與到貨監控
- **供應商品質** — 進料檢驗與 SCAR 改善
- **綠色採購** — ESG 評分與永續採購

## 適合誰使用

- 永續管理師
- ESG 主管
- 總經理

## 運作流程

1. 待蒐集
2. 核對中
3. 查證確認
4. 揭露完成

## 導入效益

- 盤查作業工時：40小時 → **8.2小時**
- 數據完整率：58% → **93%**
- 減碳目標達成：53% → **83%**
- 用能異常反應：24小時 → **2.1小時**
