# 人事電子簽核系統（HR e-Workflow）

> 出勤、薪資、招募到績效的人資全流程

人事電子簽核系統（HR e-Workflow）提供表單流程設計器（可視化簽核路徑）、多層級簽核與代理人設定、行動裝置簽核推播。人資部依「員工提出申請 → 系統依規則轉送簽核 → 主管/HR逐層審核 → 簽核完成通知 → 資料同步至相關系統」推進作業，優先解決「紙本簽呈流程冗長且易遺失」，全體主管與員工則以平均簽核時效與逾期簽核件數確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**人力資源　|　**系統類型：**HRIS 人力資源系統

## 功能模組

- **出勤差勤** — 打卡、請假與加班
- **薪資計算** — 薪資、勞健保與報稅
- **排班管理** — 智慧排班與工時控管
- **招募任用** — 職缺、面試與報到
- **教育訓練** — 課程、證照與紀錄
- **績效考核** — 目標設定與考核流程

## 適合誰使用

- 人資部
- 全體主管與員工
- 稽核部

## 運作流程

1. 待處理
2. 主管確認
3. 人資執行
4. 歸檔完成

## 導入效益

- 薪資作業工時：42小時/月 → **7.7小時/月**
- 出勤異常處理：29分鐘 → **5.1分鐘**
- 招募到位天數：47天 → **26天**
- 表單簽核時效：2.9天 → **1天**
