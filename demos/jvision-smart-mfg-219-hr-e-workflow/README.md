# 人事電子簽核洞察站

將請假、加班、異動、獎懲等各類人事申請單導入電子簽核流程，取代紙本簽呈提升效率與可追溯性。

- 原始系統：人事電子簽核系統（HR e-Workflow）
- 產業分類：智慧製造｜人資管理
- 使用部門：人資部、全體主管與員工、稽核部、資訊部
- 工作流程：員工提出申請 → 系統依規則轉送簽核 → 主管/HR逐層審核 → 簽核完成通知 → 資料同步至相關系統
- AI 應用：簽核路徑異常/卡關自動偵測、智慧表單自動填單建議
- 主要 KPI：平均簽核時效、逾期簽核件數、電子化比率、系統使用率
- 代表產品：Kissflow、鼎新電子簽核、勤業/資誠導入之企業流程平台、群暉/自建OA系統
