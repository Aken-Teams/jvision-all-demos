# Cloud SPC Advanced Analytics智慧站

於雲端平台提供跨廠區、跨產線之進階統計製程分析，支援多維度製程能力比較與預測。

- 原始系統：Cloud SPC Advanced Analytics（雲端SPC進階分析）
- 產業分類：智慧製造｜品質管理
- 使用部門：製程工程部、品保部、集團品質總部
- 工作流程：多廠數據上雲彙整→進階統計分析→跨廠比較→異常預警→改善追蹤
- AI 應用：製程異常預測性分析、跨廠最佳實踐自動比對建議
- 主要 KPI：跨廠Cpk一致性、異常預測準確率、警報反應時效
- 代表產品：InfinityQS ProFicient、Q-DAS qs-STAT雲端版
