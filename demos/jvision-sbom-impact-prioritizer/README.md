# SBOM 影響優先器

> 結合可達性、暴露面與業務重要度排序 SBOM 弱點，優先修補真正風險。

結合可達性、暴露面與業務重要度排序 SBOM 弱點，優先修補真正風險。

**產業別：**資訊科技　|　**系統類型：**security-soc

## 功能模組

- **SBOM 元件圖譜** — 呈現元件版本、相依路徑、映像與部署工作負載。
- **弱點可達分析** — 判斷弱點函式是否能由產品實際執行路徑觸達。
- **暴露面判定** — 檢查網路入口、權限、執行環境與攻擊前置條件。
- **業務關鍵加權** — 依服務等級、資料敏感度與營收影響調整風險。
- **修補優先佇列** — 綜合利用可能性與業務衝擊產生可解釋排序。
- **修補驗證中心** — 追蹤升版、緩解與部署結果，確認風險確實下降。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 盤點受影響元件
2. 驗證程式可達性
3. 評估外部暴露
4. 標定業務衝擊
5. 核定修補順序
6. 確認風險解除

## 導入效益

- 事件平均處理：120分鐘 → **30分鐘**
- 系統可用率：97% → **99%**
- SLA達成率：85% → **98%**
- 資產盤點工時：20小時/月 → **4小時/月**
