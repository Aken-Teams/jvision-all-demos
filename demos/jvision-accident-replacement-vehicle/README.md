# 事故代步車銜接台

> 在營業車事故停駛後，依駕駛資格、營運需求、保險範圍與車輛配備媒合代步車，完成文件、油卡及領還交接，避免重複承諾或使用未納保車。

**產業別：**交通運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **事故需求** — 登錄停駛期間與營運需求
- **備車池** — 查看車型位置與可用時段
- **資格媒合** — 比對駕照營業及配備限制
- **保障核驗** — 確認保險與責任期間
- **領車點交** — 交付文件油卡及車況
- **還車結案** — 核對里程油量與實際費用

## 適合誰使用

- 事故專員
- 車隊調度
- 駕駛

## 運作流程

1. 建立需求
2. 搜尋備車
3. 核對資格
4. 確認保障
5. 完成領車
6. 還車結算

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
