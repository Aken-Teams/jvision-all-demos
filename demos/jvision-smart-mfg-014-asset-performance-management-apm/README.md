# 資產績效管理系統（Asset Performance Management, APM）

> 服務工單、資產到即時監控的 IT 維運

資產績效管理系統（Asset Performance Management, APM）提供設備健康度評分、可靠度分析（RCM）、資產風險矩陣。設備工程依「資產數據建檔 → 健康度/風險評估 → 優先序排定 → 維護策略調整 → 績效追蹤」推進作業，優先解決「資產投資決策缺乏數據依據」，廠務則以資產可靠度與生命週期總成本確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**生產製造　|　**系統類型：**IT 維運管理平台

## 功能模組

- **服務工單** — 事件/請求工單管理
- **資產管理** — IT 資產與軟體授權
- **即時監控** — 系統/網路健康監控
- **告警事件** — 告警彙整與分派
- **變更發布** — 變更與發布管理
- **服務報表** — SLA 與可用率報表

## 適合誰使用

- 設備工程
- 廠務
- 財務

## 運作流程

1. 待排程
2. 生產中
3. 待品檢
4. 已入庫

## 導入效益

- 排程作業工時：7.8小時/日 → **1.6小時/日**
- 準時交付率：80% → **99%**
- 缺料停線次數：12次/月 → **2.8次/月**
- 設備稼動率：77% → **84%**
