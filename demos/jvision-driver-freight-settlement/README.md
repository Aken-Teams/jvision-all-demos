# 貨運司機運費結算台

將調度趟次、紙本簽單、改點、空趟、等待及司機津貼逐趟勾稽，協助物流公司在月結前處理漏登、重複與臨時議價。

**產業別：**物流運輸　|　**系統類型：**logistics-fleet

## 功能模組

- **趟次總覽** — 查看派車與完成狀態。
- **簽單勾稽** — 連結交貨及司機回單。
- **改點空趟** — 記錄路線異動與原因。
- **等待費用** — 核對候時起訖證據。
- **結算差異** — 調查漏登及重複趟次。
- **司機應付** — 形成薪津或承攬付款。

## 適合誰使用

- 調度員
- 車隊主管
- 薪酬會計

## 運作流程

1. 彙入趟次
2. 核對簽單
3. 補充異動
4. 驗算費用
5. 處理差異
6. 核准結算

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 簽收回單時效：24小時 → **2小時**
