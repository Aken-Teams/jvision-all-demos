# 校車乘車收費管理台

> 供私校與補習班管理學生乘車方案、站點名單、學期異動、請假補扣款、隨車點名及家長費用明細，解決教務、交通承辦與出納資料不同步的問題。

**產業別：**教育　|　**系統類型：**education-lms

## 功能模組

- **路線站點** — 維護班次、站序與容量
- **乘車方案** — 設定學生單雙趟及期間
- **異動申請** — 處理換站停搭與臨時乘車
- **隨車點名** — 呈現上下車名單及異常
- **費用試算** — 依期間與異動計算退補費
- **收費覆核** — 產生家長明細及出納批次

## 適合誰使用

- 交通承辦
- 教務人員
- 出納人員

## 運作流程

1. 建立路線
2. 配置學生
3. 處理異動
4. 執行點名
5. 試算費用
6. 發布帳單

## 導入效益

- 排課作業工時：6小時/週 → **1.5小時/週**
- 作業批改時效：5天 → **1天**
- 出席掌握率：70% → **95%**
- 學習進度可視：45% → **90%**
