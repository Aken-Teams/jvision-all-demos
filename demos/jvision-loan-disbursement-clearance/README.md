# 貸款撥款條件清件台

> 把授信核准書中的撥款前條件轉為可驗證清單，追蹤擔保設定、保險、契約與自備款證據，對豁免、效期及未清項目執行分層管制。

把授信核准書中的撥款前條件轉為可驗證清單，追蹤擔保設定、保險、契約與自備款證據，對豁免、效期及未清項目執行分層管制。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **條件擷取** — 建立撥款清單
- **證據清件** — 收集前置文件
- **效期檢查** — 驗證文件有效
- **阻擋項目** — 顯示未清風險
- **豁免審批** — 管制例外解除
- **放行撥款** — 產生核准憑據

## 適合誰使用

- 授信經辦
- 撥款作業員
- 授信主管

## 運作流程

1. 建立條件
2. 分派清件
3. 驗證證據
4. 檢查阻擋
5. 核准豁免
6. 放行撥款

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
