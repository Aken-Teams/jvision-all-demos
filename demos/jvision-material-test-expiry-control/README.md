# 材料檢試驗到期台

> 依材料種類、供應商、進場批量與規範頻率自動形成應抽驗清單，追蹤取樣、送驗、報告期限及逾期處置，避免拆單漏抽或未取得合格報告便投入施工及申報估驗。

依材料種類、供應商、進場批量與規範頻率自動形成應抽驗清單，追蹤取樣、送驗、報告期限及逾期處置，避免拆單漏抽或未取得合格報告便投入施工及申報估驗。

**產業別：**營建工程　|　**系統類型：**quality-qms

## 功能模組

- **進料批次** — 彙整材料、供應商、數量與使用區域。
- **抽驗頻率** — 依規範門檻累計批量並計算應抽次數。
- **送驗案件** — 管理取樣、封樣、實驗室與預定回報日。
- **到期追蹤** — 呈現將到期、已逾期與催辦中的報告。
- **批次管制** — 限制未驗或不合格材料的使用與請款狀態。
- **試驗台帳** — 輸出批次、報告、結果與處置的完整履歷。

## 適合誰使用

- 品管工程師
- 材料工程師
- 監造人員

## 運作流程

1. 登錄進料批次
2. 計算應抽頻率
3. 建立送驗案件
4. 追蹤報告回收
5. 判定批次結果
6. 封存試驗台帳

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
