# 租約到期續退協調台

> 集中管理租約到期、續租報價、房東底價、退租通知、押金修繕與點交責任，讓資產管理團隊在期限前完成續退決策並保留完整協商版本。

**產業別：**房地產與物業　|　**系統類型：**legal-case

## 功能模組

- **到期總覽** — 依期限與風險排列租約
- **租約檔案** — 檢視條款與歷次版本
- **條件試算** — 比較底價與續租方案
- **協商紀錄** — 保存雙方回覆與承諾
- **退租清件** — 追蹤押金修繕及點交
- **結案覆核** — 確認續約或退租完成

## 適合誰使用

- 租賃管理員
- 資產經理
- 財務人員

## 運作流程

1. 盤點到期案件
2. 核對租約條款
3. 擬定續退方案
4. 記錄協商結果
5. 完成退租清件
6. 覆核結案

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
