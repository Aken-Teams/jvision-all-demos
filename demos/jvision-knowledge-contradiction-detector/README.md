## 功能模組

- **衝突總覽** — 依風險、主題與影響範圍排列待裁決矛盾。
- **規則差異比對** — 逐條對照不同文件中的門檻、條件與例外。
- **事實關係圖** — 呈現衝突主張、來源系統及相依知識節點。
- **影響範圍追蹤** — 找出引用矛盾內容的客服稿、工單與程式。
- **裁決工作台** — 編修 AI 裁決草案並指定權威說法與生效日。
- **裁決發布** — 核准後同步更正來源並保留舊規則關係。

## 適合誰使用

- 知識工作者
- 主管
- 客服

## 運作流程

1. 辨識高風險矛盾
2. 核對條文差異
3. 查明主張脈絡
4. 評估下游影響
5. 完成裁決提案
6. 核准並發布

## 導入效益

- 跨部門協調工時：8小時/週 → **2小時/週**
- 任務準時率：68% → **92%**
- 資訊落差：30% → **8%**
- 文件查找時間：20分鐘 → **3分鐘**
