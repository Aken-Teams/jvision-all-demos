# 殯葬場館檔期調度台

> 供殯葬服務業者統籌禮廳、冰存、誦經室、接駁車與工作人員檔期，處理家屬方案異動、場地衝突及跨場館轉移，確保治喪流程準時銜接。

供殯葬服務業者統籌禮廳、冰存、誦經室、接駁車與工作人員檔期，處理家屬方案異動、場地衝突及跨場館轉移，確保治喪流程準時銜接。

**產業別：**生活服務　|　**系統類型：**operations-console

## 功能模組

- **綜合檔期** — 以時間軸呈現場館、車輛與服務人員的占用狀態。
- **場地配置** — 依容納人數、宗教儀式及設備條件配置空間。
- **車輛調度** — 安排接體、家屬接駁及發引所需車輛。
- **人力班表** — 指派禮儀師、司儀、襄儀及場館服務人員。
- **異動協調** — 評估時間或方案變更對後續資源的連鎖影響。
- **場次交接** — 逐站確認布置、接待、儀式及撤場責任。

## 適合誰使用

- 場館調度員
- 禮儀主管
- 行政專員

## 運作流程

1. 建立治喪時程
2. 配置適用場地
3. 安排車輛任務
4. 排定服務人力
5. 處理臨時異動
6. 完成場次交接

## 導入效益

- 預約作業工時：3小時/日 → **0.5小時/日**
- 準時到府率：82% → **96%**
- 重工率：12% → **4%**
- 客訴關案：4天 → **1天**
