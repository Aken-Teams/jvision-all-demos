# VMI供應商管理庫存系統（Vendor Managed Inventory）

> 供應商協同、詢比議價到交期風險控管

VMI供應商管理庫存系統（Vendor Managed Inventory）提供庫存與用量資訊即時共享、供應商補貨建議與確認、寄售庫存(Consignment)管理。採購部依「庫存用量同步→供應商監控→補貨建議產生→確認補貨→到貨入庫→用量結算」推進作業，優先解決「傳統採購補貨反應速度慢」，倉儲部則以缺料次數與庫存周轉率確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**採購供應鏈　|　**系統類型：**SRM 採購供應商管理

## 功能模組

- **供應商管理** — 建檔、分級與績效評分
- **詢報價協作** — 線上詢價、比價與議價
- **採購訂單** — 請購、下單與交期追蹤
- **交期風險** — 缺料預警與到貨監控
- **供應商品質** — 進料檢驗與 SCAR 改善
- **綠色採購** — ESG 評分與永續採購

## 適合誰使用

- 採購部
- 倉儲部
- 供應商窗口

## 運作流程

1. 待上架
2. 銷售中
3. 簽核確認
4. 已結案

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：87% → **99%**
- 缺料預警覆蓋：38% → **86%**
- 議價作業工時：8小時/週 → **2小時/週**
