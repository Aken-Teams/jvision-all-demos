管理應用程式介面與模型情境協定工具的註冊、權限及呼叫政策，模擬攔截敏感資料外傳、越權操作與危險參數，讓企業安全導入人工智慧代理工具。

**產業別：**AI 工程平台　|　**系統類型：**security-soc

## 功能模組

- **介面工具目錄** — 登錄應用程式介面與模型情境協定工具的用途、擁有者及資料範圍。
- **代理權限設計** — 設定代理身分可使用的工具、方法、資料欄位及操作上限。
- **呼叫政策編排** — 建立敏感資料、危險參數、時段、頻率與人工核准規則。
- **請求安全測試** — 以擬真請求測試提示注入、越權、資料外傳及參數濫用情境。
- **高風險操作審核** — 讓負責人查看呼叫目的、參數與影響後核准或拒絕。
- **呼叫稽核追蹤** — 依代理、使用者、工具與政策檢索完整的模擬呼叫軌跡。

## 適合誰使用

- 人工智慧平台工程師
- 後端工程師
- 資訊安全人員

## 運作流程

1. 登錄工具
2. 配置權限
3. 建立政策
4. 執行測試
5. 審核操作
6. 追蹤稽核
