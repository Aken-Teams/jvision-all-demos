# 醫療轉診閉環追蹤台

> 協助診所管理轉出與轉入個案，整理轉診原因、摘要文件、預約狀態、回覆報告及後續處置，避免病人未就醫或檢查結果未回流，建立可追蹤的照護閉環。

協助診所管理轉出與轉入個案，整理轉診原因、摘要文件、預約狀態、回覆報告及後續處置，避免病人未就醫或檢查結果未回流，建立可追蹤的照護閉環。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **轉診清單** — 集中查看轉出、轉入及目前狀態。
- **摘要整備** — 整理病史、檢查與轉診問題。
- **就醫追蹤** — 登錄接收院所與預約進度。
- **個案提醒** — 追蹤未預約、未就醫與失聯個案。
- **報告回收** — 管理外院結果與缺漏文件。
- **後續閉環** — 安排回診並記錄醫師處置。

## 適合誰使用

- 診所護理師
- 轉診個管師
- 主治醫師

## 運作流程

1. 提出轉診需求
2. 整備轉診摘要
3. 協助完成預約
4. 追蹤個案就醫
5. 收回外院報告
6. 安排後續處置

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
