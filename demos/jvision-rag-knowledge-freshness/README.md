# 知識檢索新鮮度治理中心

> 治理檢索增強生成所使用的文件、切片、索引與引用證據；所謂檢索增強生成，是先搜尋企業知識再產生回答。平台可辨識過期或衝突內容、安排重建索引、測試問答引用，避免助理使用舊資料或無法提出依據。

**產業別：**AI 工程平台　|　**系統類型：**it-ops

## 功能模組

- **知識健康總覽** — 呈現來源新鮮度、索引狀態、衝突與引用風險趨勢。
- **知識來源清冊** — 管理文件版本、擁有者、有效日期與同步狀態。
- **內容衝突偵測** — 並排比較矛盾或重複片段並標示可能的有效版本。
- **索引更新佇列** — 安排文件切片、重新建索引及失敗項目的重試。
- **問答證據測試** — 以測試問題檢視答案、引用片段、相關性與完整性。
- **治理處置中心** — 分派過期、衝突與無證回答的修正責任及期限。

## 適合誰使用

- 人工智慧產品經理
- 知識管理員
- 資料工程師
- 品質審查人員

## 運作流程

1. 監看知識健康
2. 盤點知識來源
3. 處理內容衝突
4. 更新知識索引
5. 驗證回答證據
6. 追蹤治理改善
