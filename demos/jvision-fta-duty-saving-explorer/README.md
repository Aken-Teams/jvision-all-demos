# FTA 節稅機會探索器

> 比較供應、製造與出貨配置的 FTA 適用性，找出可落地的關稅節省方案。

比較供應、製造與出貨配置的 FTA 適用性，找出可落地的關稅節省方案。

**產業別：**採購供應鏈　|　**系統類型：**analytics-bi

## 功能模組

- **供應製造配置圖** — 組合供應地、製造廠、BOM 與銷售目的地形成分析情境。
- **FTA 規則匹配** — 比對各協定稅則、原產地規則與直接運送條件。
- **區域價值試算** — 依 BOM 成本與原產材料占比試算 RVC 等門檻。
- **關稅情境比較** — 並列現況與替代配置的稅率、稅額及資格差異。
- **節稅機會排序** — 按可節省金額、執行成本與成功機率排列方案。
- **布局提案包** — 產出建議配置、資格依據、缺口與預估回收期。

## 適合誰使用

- 國貿主管
- 報關人員
- 業務

## 運作流程

1. 建立配置情境
2. 匹配適用協定
3. 試算原產門檻
4. 比較關稅結果
5. 篩選節稅機會
6. 核定布局提案

## 導入效益

- 採購前置時間：12天 → **5天**
- 準時到貨率：82% → **96%**
- 缺料預警覆蓋：40% → **92%**
- 議價作業工時：8小時/週 → **2小時/週**
