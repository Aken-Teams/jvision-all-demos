## 功能模組

- **服務耦合地圖** — 以跨服務呼叫、共享資料與共同變更建立互動拓撲。
- **邊界異味雷達** — 辨識聊天式服務、循環依賴與分散式單體等切分異味。
- **共享資料剖析** — 追蹤跨域資料表、事件欄位與交易一致性的所有權衝突。
- **共同變更分析** — 從提交與需求紀錄找出經常綁定發布的服務組合。
- **重切情境模擬** — 模擬合併、拆分或移轉責任後的耦合與可靠性變化。
- **邊界改善藍圖** — 產出具優先序的服務重切方案、影響範圍與遷移步驟。

## 適合誰使用

- 工程主管
- 開發者
- 測試

## 運作流程

1. 建立服務拓撲
2. 篩選邊界異味
3. 核對資料所有權
4. 檢視共同變更
5. 比較重切方案
6. 核准改善藍圖
