# 供應商風險管理系統

> 供應商協同、詢比議價到交期風險控管

供應商風險管理系統提供供應商財務健康度監控、地緣政治/天災風險地圖、風險事件即時通報。採購部依「風險訊號監控 → 事件偵測 → 風險分級 → 通報示警 → 應變計畫啟動」推進作業，優先解決「供應商經營風險事後才發現」，供應鏈風險管理部則以高風險供應商占比與風險事件反應時間確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**採購供應鏈　|　**系統類型：**SRM 採購供應商管理

## 功能模組

- **供應商管理** — 建檔、分級與績效評分
- **詢報價協作** — 線上詢價、比價與議價
- **採購訂單** — 請購、下單與交期追蹤
- **交期風險** — 缺料預警與到貨監控
- **供應商品質** — 進料檢驗與 SCAR 改善
- **綠色採購** — ESG 評分與永續採購

## 適合誰使用

- 採購部
- 供應鏈風險管理部
- 財務部

## 運作流程

1. 待詢價
2. 比價中
3. 待核准
4. 驗收完成

## 導入效益

- 採購前置時間：12天 → **5.2天**
- 準時到貨率：82% → **99%**
- 缺料預警覆蓋：41% → **86%**
- 議價作業工時：8.3小時/週 → **1.9小時/週**
