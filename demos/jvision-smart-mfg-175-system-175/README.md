# 供應商風險管理追蹤台

整合財務、地緣政治、天災、營運等多面向風險訊號，即時監控供應商經營穩定性。

- 原始系統：供應商風險管理系統
- 產業分類：智慧製造｜採購管理
- 使用部門：採購部、供應鏈風險管理部、財務部、經營管理層
- 工作流程：風險訊號監控 → 事件偵測 → 風險分級 → 通報示警 → 應變計畫啟動
- AI 應用：AI 監控新聞與公開資訊預測供應商風險、供應鏈中斷情境模擬
- 主要 KPI：高風險供應商占比、風險事件反應時間、供應中斷次數
- 代表產品：Resilinc、Everstream Analytics、Interos、SAP Ariba Supplier Risk
