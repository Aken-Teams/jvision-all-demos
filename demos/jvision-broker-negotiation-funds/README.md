# 房仲斡旋金流管制台

> 整合斡旋金收款、要約版本、議價條件、買賣雙方簽認及失敗退款，讓房仲門店清楚掌握每筆款項用途、有效條件與應退期限。

整合斡旋金收款、要約版本、議價條件、買賣雙方簽認及失敗退款，讓房仲門店清楚掌握每筆款項用途、有效條件與應退期限。

**產業別：**房地產與物業　|　**系統類型：**finance-case

## 功能模組

- **斡旋案件** — 管理物件與買賣雙方
- **款項登錄** — 記錄收款及保管狀態
- **要約版本** — 比較並鎖定有效條件
- **議價進度** — 追蹤雙方回覆與期限
- **簽認清單** — 核對文件與授權完整性
- **退款結案** — 管制退款帳戶與簽收

## 適合誰使用

- 房仲經紀人
- 店長
- 出納

## 運作流程

1. 建立斡旋案件
2. 確認款項入帳
3. 維護議價版本
4. 核定有效要約
5. 執行成交或退款
6. 完成案件歸檔

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
