**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **耗用總覽** — 彙整待核項目
- **手術配對** — 連結病患與醫材
- **退補貨** — 核對退料及補貨
- **價格覆核** — 檢查合約計價
- **差異處理** — 分派異常責任
- **月結確認** — 產出結算證據

## 適合誰使用

- 醫材管理員
- 手術室護理師
- 醫務會計

## 運作流程

1. 檢視耗用
2. 配對手術
3. 核對退補
4. 覆核價格
5. 排除差異
6. 完成月結

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
