# 餐飲叫貨截單協調台

> 集中各門店叫貨、臨時加減量與供應商截單時間，提供版本鎖定、缺料預警及緊急調貨協作，避免採購收到多版需求而漏訂或造成短效原料過量。

集中各門店叫貨、臨時加減量與供應商截單時間，提供版本鎖定、缺料預警及緊急調貨協作，避免採購收到多版需求而漏訂或造成短效原料過量。

**產業別：**餐飲旅宿　|　**系統類型：**procurement-srm

## 功能模組

- **截單日曆** — 查看品類供應商截止時間
- **門店叫貨** — 填報數量與需求日期
- **版本封存** — 鎖定有效需求版本
- **缺口預警** — 顯示不足與過量風險
- **例外協調** — 處理逾時加減量與借貨
- **採購彙總** — 產出供應商訂購清單

## 適合誰使用

- 門店主管
- 採購人員
- 中央廚房

## 運作流程

1. 設定截單
2. 提報叫貨
3. 鎖定版本
4. 檢查缺口
5. 協調例外
6. 送出採購

## 導入效益

- 結帳等待：8分鐘 → **2分鐘**
- 翻桌率：70% → **90%**
- 備料浪費：15% → **6%**
- 訂位掌握率：65% → **94%**
