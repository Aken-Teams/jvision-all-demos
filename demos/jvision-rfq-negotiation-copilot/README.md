# 智慧詢比議價協作助手

> 把詢價條件、供應商報價與議價紀錄整合成一致的比較流程，協助辨識價格異常、條件差異與可談判空間，並產生議價重點及情境試算，讓採購在保留人工決策下提高談判效率。

把詢價條件、供應商報價與議價紀錄整合成一致的比較流程，協助辨識價格異常、條件差異與可談判空間，並產生議價重點及情境試算，讓採購在保留人工決策下提高談判效率。

**產業別：**採購供應鏈　|　**系統類型：**procurement-srm

## 功能模組

- **詢價案件建立** — 設定品項、數量、交期、付款條件與供應商邀請名單。
- **報價正規化** — 統一幣別、稅費、運費與計價單位以形成可比基準。
- **價格差異分析** — 呈現各品項價差、歷史區間與偏離基準的異常項目。
- **議價策略建議** — 依成本與條件差異整理談判目標、問題及交換籌碼。
- **條件情境試算** — 模擬數量、付款天期、交期及折扣變動的總成本影響。
- **決選核准紀錄** — 彙整議價回合、最終條件、選商理由與核准狀態。

## 適合誰使用

- 採購專員
- 品類經理
- 採購主管

## 運作流程

1. 建立詢價案件
2. 整理供應商報價
3. 分析價格差異
4. 準備議價策略
5. 模擬談判方案
6. 核准決選結果
