# 宮廟專款捐獻管理台

> 協助宮廟管理建廟、修繕、賑濟與指定科儀等專款捐獻，記錄用途限制、收據、預算動支、執行證據及對外徵信，避免專款與一般香油錢混用。

協助宮廟管理建廟、修繕、賑濟與指定科儀等專款捐獻，記錄用途限制、收據、預算動支、執行證據及對外徵信，避免專款與一般香油錢混用。

**產業別：**宗教服務　|　**系統類型：**finance-ledger

## 功能模組

- **募款專案** — 設定用途、目標、期間、承諾項目與負責委員。
- **捐獻登錄** — 記錄捐款人、金額、指定用途及收據狀態。
- **用途歸集** — 將收入與支出歸屬至正確的限制型專款。
- **動支審核** — 檢核請款是否符合募款用途及核決權限。
- **預算追蹤** — 比較募得、已用、承諾與可用的專款餘額。
- **徵信結案** — 整理捐獻名冊、執行成果及公開摘要。

## 適合誰使用

- 宮廟會計
- 管理委員
- 廟務人員

## 運作流程

1. 建立專款計畫
2. 登錄指定捐獻
3. 歸集專款帳務
4. 審核專款動支
5. 追蹤執行預算
6. 發布成果結案
