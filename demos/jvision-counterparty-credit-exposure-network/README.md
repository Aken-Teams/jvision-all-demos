**產業別：**財務會計　|　**系統類型：**finance-case

## 功能模組

- **集團關係穿透** — 辨識母子公司、實質控制人與關聯企業，建立交易對手群組。
- **曝險網路圖** — 以關係網呈現授信、應收、存款、衍生品與擔保連結。
- **多類曝險歸集** — 統一換算銀行存款、應收、融資與外匯交易的風險金額。
- **集中度預警** — 依集團、國家、產業與銀行維度偵測限額逼近與超額。
- **違約情境模擬** — 模擬降評、違約與關聯企業傳染對資金部位的影響。
- **曝險調整方案** — 最佳化限額、資金移轉、付款條件與避險配置建議。

## 適合誰使用

- 財務長
- Treasurer
- 資金人員

## 運作流程

1. 辨識關係
2. 檢視網路
3. 核算曝險
4. 審查集中度
5. 推演衝擊
6. 核准調整

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
