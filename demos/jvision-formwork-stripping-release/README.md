# 模板拆模條件放行台

> 把混凝土齡期、強度報告、支撐配置、拆模範圍及後續載重限制集中管理，讓現場在拆模前逐項確認條件並取得核准，避免趕工提早拆除造成變形或安全風險。

把混凝土齡期、強度報告、支撐配置、拆模範圍及後續載重限制集中管理，讓現場在拆模前逐項確認條件並取得核准，避免趕工提早拆除造成變形或安全風險。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **拆模看板** — 呈現各樓層待拆、退回與已放行區域。
- **齡期檢核** — 核算澆置日期、養護天數與預定拆模日。
- **強度佐證** — 關聯試體報告及設計要求強度。
- **支撐配置** — 標示拆除範圍與必須保留的回撐。
- **放行審查** — 逐項審查條件並記錄退補原因。
- **拆模回報** — 登錄實際拆模時間、照片及異常。

## 適合誰使用

- 土建工程師
- 品管工程師
- 模板領班

## 運作流程

1. 建立拆模區
2. 核對齡期
3. 附上強度
4. 確認回撐
5. 審查放行
6. 完成回報

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
