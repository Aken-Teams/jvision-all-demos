# 工地廢棄物清運管制台

> 管理工地廢土、營建混合物與可回收材料的申報量、清運車次、聯單佐證、處理場去向及承包商請款，建立可追溯的清運與異常閉環。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **清運需求** — 依工項與廢棄物類別建立需求。
- **資格查驗** — 檢查承運商及處理場文件。
- **車次排程** — 安排日期、車輛與預估載重。
- **聯單登錄** — 保存每車清運及收受佐證。
- **數量核對** — 比較申報、過磅和請款數量。
- **計價結算** — 按合約單價彙整可請款金額。

## 適合誰使用

- 工地主任
- 環安人員
- 工程會計

## 運作流程

1. 提出需求
2. 查驗資格
3. 安排車次
4. 完成聯單
5. 核對差異
6. 核定請款

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
