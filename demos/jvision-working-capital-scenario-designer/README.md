# 營運資金情境設計器

模擬庫存、收款與付款政策對現金的影響，驅動跨部門改善。36                              

**產業別：**財務會計　|　**系統類型：**analytics-bi

## 功能模組

- **庫存政策情境** — 調整安全庫存、補貨週期與週轉天數假設。
- **收款政策情境** — 模擬信用條件、催收強度與應收天數變化。
- **付款政策情境** — 模擬付款條件、折扣利用與應付天數變化。
- **現金影響橋接** — 拆解各政策對營運資金及現金釋放的貢獻。
- **跨部門方案組合** — 組合銷售、採購、供應鏈與財務改善措施。
- **改善目標承諾** — 設定現金目標、責任人、期限與追蹤節點。

## 適合誰使用

- 財務長
- Treasurer
- 資金人員

## 運作流程

1. 設計庫存政策
2. 設計收款政策
3. 設計付款政策
4. 檢視現金影響
5. 協調組合方案
6. 核准改善承諾

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
