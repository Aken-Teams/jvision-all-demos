# 手術室周轉排程台

> 協助手術中心安排房間、術式、醫護團隊與清潔周轉時段，以純 UI 假資料呈現延遲、插單、器械待備和術後床位條件，提升手術室使用效率。

協助手術中心安排房間、術式、醫護團隊與清潔周轉時段，以純 UI 假資料呈現延遲、插單、器械待備和術後床位條件，提升手術室使用效率。

**產業別：**醫療照護　|　**系統類型：**healthcare-clinic

## 功能模組

- **手術排程** — 查看房間與術式時段
- **團隊配置** — 安排醫師與護理人員
- **器械準備** — 確認器械包準備狀態
- **房間周轉** — 追蹤清潔與整備時間
- **插單協調** — 模擬急診手術插單
- **延遲分析** — 整理開刀延遲原因

## 適合誰使用

- 手術室護理長
- 排程人員
- 麻醉科協調員

## 運作流程

1. 建立排程
2. 配置團隊
3. 確認器械
4. 執行周轉
5. 處理插單
6. 檢討延遲

## 導入效益

- 候診等待：35分鐘 → **12分鐘**
- 回診完成率：70% → **92%**
- 申報退件率：8% → **2%**
- 紀錄作業工時：4小時/日 → **1小時/日**
