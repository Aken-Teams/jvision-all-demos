# 鋼筋續接器批次台

> 供鋼筋現場把續接器批號、施工位置、扭力值與抽驗試體連結，管理不合格批隔離及補抽，避免報告合格卻無法對回樓層接頭。

供鋼筋現場把續接器批號、施工位置、扭力值與抽驗試體連結，管理不合格批隔離及補抽，避免報告合格卻無法對回樓層接頭。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **批次總覽** — 連結材料與樓層
- **收料建批** — 登錄證明與數量
- **接頭配置** — 標記柱梁位置
- **扭力檢查** — 記錄現場實測
- **試體送驗** — 追蹤拉伸結果
- **異常隔離** — 圈選受影響接頭

## 適合誰使用

- 鋼筋工程師
- 品管人員

## 運作流程

1. 材料進場
2. 樓層配發
3. 接頭施工
4. 扭力抽查
5. 試體判定
6. 批次放行

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
