# 沖壓模具健康裂紋預警台

> 彙整沖次、保養、檢查照片、裂紋標記與異常事件等擬真資料，呈現汽車沖壓模具健康分數及裂紋風險，協助保全人員安排檢查、維修與備模，降低突發停線。

彙整沖次、保養、檢查照片、裂紋標記與異常事件等擬真資料，呈現汽車沖壓模具健康分數及裂紋風險，協助保全人員安排檢查、維修與備模，降低突發停線。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **模具健康榜** — 依產線、車型與風險排列模具健康分數及待辦。
- **裂紋地圖** — 在模具區域圖標記裂紋位置、長度與嚴重度。
- **劣化趨勢** — 比較沖次、負荷、維修與裂紋變化的時間關係。
- **壽命評估** — 顯示剩餘可用沖次、風險區間與影響因子。
- **停機規劃** — 比較立即維修、下次換模維修與備模切換方案。
- **維修閉環** — 記錄補焊、研磨、換件及修後檢查結果。

## 適合誰使用

- 模具保全人員
- 沖壓製程工程師
- 生產維修主管

## 運作流程

1. 篩選模具
2. 定位裂紋
3. 分析劣化
4. 評估壽命
5. 安排停機
6. 完成維修

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
