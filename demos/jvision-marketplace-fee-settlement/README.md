# 電商平台費用核算台

> 協助多平台賣家逐筆核對訂單貨款、成交手續費、廣告費、物流補貼、退貨扣款及平台撥款，快速找出短付與費率異常，建立可供財會覆核的結算依據。

協助多平台賣家逐筆核對訂單貨款、成交手續費、廣告費、物流補貼、退貨扣款及平台撥款，快速找出短付與費率異常，建立可供財會覆核的結算依據。

**產業別：**零售電商　|　**系統類型：**finance-ledger

## 功能模組

- **平台總覽** — 比較各平台銷售額、費用率與淨入帳。
- **訂單核算** — 拆解單筆訂單的收入、折讓與扣費項目。
- **費率規則** — 維護品類佣金、活動費與物流補助條件。
- **差異檢查** — 標示短付、重扣及不符費率的結算項目。
- **申訴追蹤** — 管理平台申訴證據、回覆期限與追回結果。
- **撥款預估** — 依結算週期預估各平台到帳時程。

## 適合誰使用

- 電商營運
- 財會專員
- 通路主管

## 運作流程

1. 彙入結算
2. 套用費率
3. 比對訂單
4. 處理差異
5. 提出申訴
6. 確認撥款

## 導入效益

- 補貨反應：24小時 → **4小時**
- 熱銷掌握率：60% → **92%**
- 缺貨率：12% → **4%**
- 結帳等待：6分鐘 → **1.5分鐘**
