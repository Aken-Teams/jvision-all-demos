# 維修安全許可交接台

> 供廠務維修在動工前管理斷電隔離、動火、高處及侷限空間等安全許可，串連風險辨識、措施確認、班次交接、暫停復工與完工解除，避免許可失效仍持續施工。

供廠務維修在動工前管理斷電隔離、動火、高處及侷限空間等安全許可，串連風險辨識、措施確認、班次交接、暫停復工與完工解除，避免許可失效仍持續施工。

**產業別：**設備維護　|　**系統類型：**maintenance-cmms

## 功能模組

- **許可總覽** — 顯示進行中、到期與暫停作業。
- **作業申請** — 定義設備、範圍、人員與工法。
- **風險辨識** — 選定危害及必要控制措施。
- **隔離檢核** — 記錄能源隔離點與驗證結果。
- **班次交接** — 確認人員、現況與許可延續條件。
- **解除復歸** — 驗收完工並依序解除安全措施。

## 適合誰使用

- 維修工程師
- 工安人員
- 值班主管

## 運作流程

1. 監看許可
2. 提出申請
3. 辨識風險
4. 確認隔離
5. 完成交接
6. 解除復歸

## 導入效益

- 非計畫停機：24小時/月 → **6小時/月**
- 保養準時率：75% → **96%**
- 備品缺料：10次/月 → **2次/月**
- 故障排除時間：90分鐘 → **25分鐘**
