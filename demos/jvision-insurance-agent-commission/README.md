# 保險佣酬覆核管理台

> 協助保險經紀與代理公司依保單狀態、佣金規則、組織歸屬及撤件追佣計算應付佣酬，並處理業務員異議與結算覆核。

協助保險經紀與代理公司依保單狀態、佣金規則、組織歸屬及撤件追佣計算應付佣酬，並處理業務員異議與結算覆核。

**產業別：**金融保險　|　**系統類型：**finance-ledger

## 功能模組

- **保單批次** — 彙整承保、停效、撤件與實收狀態。
- **佣酬規則** — 維護商品、期別與組織計算條件。
- **佣酬試算** — 呈現每筆來源、公式與拆分結果。
- **例外檢查** — 找出缺規則、負值與歸屬衝突。
- **異議處理** — 管理業務員提問、證據與調整決議。
- **結算覆核** — 核准應付、保留及追回明細。

## 適合誰使用

- 佣酬專員
- 財務主管
- 通路主管

## 運作流程

1. 建立批次
2. 套用規則
3. 檢查例外
4. 發布試算
5. 處理異議
6. 核准結算

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
