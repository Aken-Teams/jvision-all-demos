# 焊接飛濺缺陷檢測系統

> 利用預先準備的焊接工件影像與模擬辨識結果，標示飛濺位置、顆粒數量及缺陷等級，讓品保人員執行複判、建立返修任務，並分析產品型號與製程條件的缺陷趨勢。

**產業別：**品質管理　|　**系統類型：**quality-qms

## 功能模組

- **檢測任務總覽** — 呈現待檢、異常、複判與返修中的工件數量及分布。
- **工件影像檢測** — 在預置工件影像上標示飛濺位置、範圍與模擬信心分數。
- **缺陷分級複判** — 讓檢驗員確認缺陷等級、調整標記並填寫判定理由。
- **缺陷熱區分析** — 彙整不同焊道與工件區域的飛濺密度及常見位置。
- **返修任務管理** — 依缺陷嚴重度建立清理、補焊或重工作業及完成紀錄。
- **檢測品質報告** — 比較產品、機台、班別的缺陷率與複判一致性。

## 適合誰使用

- 外觀檢驗員
- 品保工程師
- 返修領班

## 運作流程

1. 掌握待檢任務
2. 檢視缺陷標記
3. 完成分級複判
4. 分析飛濺熱區
5. 派送返修任務
6. 回顧檢測表現

## 導入效益

- 批號追溯時間：180分鐘 → **15分鐘**
- 客訴平均關案：21天 → **9天**
- 改善驗證率：64% → **98%**
- 重複不良率：6% → **2%**
