# 未核准模型阻擋器

> 依使用者角色與資料類型即時阻擋未核准模型，或導向合規替代服務。

依使用者角色與資料類型即時阻擋未核准模型，或導向合規替代服務。

**產業別：**資訊安全　|　**系統類型：**security-soc

## 功能模組

- **核准模型目錄** — 維護可用模型、核准狀態、適用角色與資料限制。
- **角色權限比對** — 將 IAM 身分、部門與職務對應至模型使用權限。
- **資料敏感度判定** — 辨識請求中的資料類型及敏感標籤。
- **流量決策規則** — 組合角色、資料與模型條件，產生允許或阻擋決策。
- **合規服務導向** — 將不符政策的請求改送至核准模型或申請流程。
- **阻擋事件處置** — 分析被阻擋流量、政策命中原因與後續處置狀態。

## 適合誰使用

- CISO
- AI 治理主管
- 資安分析師

## 運作流程

1. 維護目錄
2. 建立政策
3. 模擬命中
4. 審核發布
5. 執行攔截
6. 處置事件

## 導入效益

- 告警分流時間：45分鐘 → **8分鐘**
- 事件平均處理：12小時 → **3小時**
- 弱點修補率：68% → **96%**
- 合規稽核工時：30小時/月 → **6小時/月**
