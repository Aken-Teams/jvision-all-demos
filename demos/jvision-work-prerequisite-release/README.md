# 工項前置條件放行台

> 把每項施工前必備的圖說、材料、試驗、隱蔽查驗及工作面條件做成放行關卡，未達標不得開工，避免封板後返拆與工班待工。

把每項施工前必備的圖說、材料、試驗、隱蔽查驗及工作面條件做成放行關卡，未達標不得開工，避免封板後返拆與工班待工。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **工項清單** — 查看待開工項目
- **條件範本** — 設定工項放行標準
- **證據查核** — 核對照片與試驗資料
- **阻擋事項** — 管理未完成前置作業
- **放行簽核** — 核准施工或條件例外
- **返工分析** — 分析漏檢與停等原因

## 適合誰使用

- 工務工程師
- 品質工程師
- 分包領班

## 運作流程

1. 套用條件
2. 提交證據
3. 現場查驗
4. 改善缺口
5. 核准放行
6. 追蹤成效

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
