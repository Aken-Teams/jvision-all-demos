# ESG永續管理預警塔

整合環境、社會、治理三構面數據，支援永續報告書編製與國際規範揭露。

- 原始系統：ESG永續管理平台
- 產業分類：智慧製造｜經營管理
- 使用部門：永續發展部、環安衛部、人資部、採購部、投資人關係部
- 工作流程：數據收集 → 指標計算 → 供應鏈盡調 → 報告草擬 → 第三方查證 → 對外揭露
- AI 應用：碳排放數據異常偵測與補值、永續報告自動生成草稿
- 主要 KPI：碳排放強度、再生能源占比、供應鏈盡調覆蓋率、報告準時發布率
- 代表產品：Workiva、SAP Sustainability Control Tower、Salesforce Net Zero Cloud
