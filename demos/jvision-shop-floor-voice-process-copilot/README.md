# 現場語音工序 Copilot

> 讓現場人員以語音免手持查 SOP、回報工序並取得即時指引。60字內

讓現場人員以語音免手持查 SOP、回報工序並取得即時指引。60字內

**產業別：**生產製造　|　**系統類型：**manufacturing-mes

## 功能模組

- **現場語音中控** — 在噪音環境辨識口令、設備、工單與工序語意。
- **SOP 語音查詢** — 依工單、機台與當前步驟朗讀適用作業規範。
- **逐步作業引導** — 以語音提示下一步、必要工具及完成條件。
- **異常口述回報** — 將口述異常轉成結構化缺陷、停機或品質紀錄。
- **高風險動作確認** — 辨識危險操作並要求主管語音或介面核准。
- **工序完成覆核** — 核對參數、回報與感測結果後完成工序過站。

## 適合誰使用

- 廠長
- 製程工程師
- 工業工程師

## 運作流程

1. 喚醒語音助手
2. 查詢作業規範
3. 執行步驟引導
4. 口述異常
5. 核准高風險處置
6. 覆核工序完成

## 導入效益

- 排程作業工時：8小時/日 → **1.5小時/日**
- 準時交付率：80% → **95%**
- 缺料停線次數：12次/月 → **3次/月**
- 設備稼動率：74% → **88%**
