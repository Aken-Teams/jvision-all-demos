# 公共標案釋疑控管台

> 在公共工程投標期限內集中拆解招標文件疑義，連結圖說、規範、數量表與契約條款，辦理內部審核、正式提問及機關答覆影響判讀，確保估價、工法與投標文件同步採用最新釋疑結論。

在公共工程投標期限內集中拆解招標文件疑義，連結圖說、規範、數量表與契約條款，辦理內部審核、正式提問及機關答覆影響判讀，確保估價、工法與投標文件同步採用最新釋疑結論。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **閱標疑義池** — 依文件章節集中登錄問題、原文與提出單位。
- **問題整併** — 合併重複疑義並釐清提問目的與優先級。
- **內部審核** — 檢查提問措辭、契約風險與是否暴露投標策略。
- **正式提問** — 管理送出版本、期限、收文證明與機關編號。
- **答覆判讀** — 解析機關回覆及更正文件的適用範圍。
- **影響同步** — 派發估價、工法、時程與投標文件更新任務。

## 適合誰使用

- 投標專案經理
- 估算工程師
- 法務契約人員

## 運作流程

1. 登錄閱標疑義
2. 整併提問清單
3. 審核提問風險
4. 送出正式釋疑
5. 判讀機關答覆
6. 同步投標內容

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
