**產業別：**專業服務　|　**系統類型：**legal-case

## 功能模組

- **市場上架總覽** — 依國家、通路與商品查看準備進度、風險等級及待辦事項。
- **內容在地化工作室** — 並排編修來源與目的語內容，管理術語、語氣及文化適配提示。
- **單位價格轉換** — 預覽尺寸、重量、幣別、稅費與價格顯示方式的轉換結果。
- **合規規則檢查** — 依擬真市場規則檢查警語、成分、產地、保固與限制用語。
- **文件與證明清單** — 管理檢驗報告、授權、標章與聲明文件的模擬狀態及效期。
- **審核上架交付** — 彙整差異、風險與缺漏，完成簽核並產生模擬通路資料包。

## 適合誰使用

- 跨境電商營運人員
- 內容編輯
- 法規與品保人員

## 運作流程

1. 建立市場任務
2. 完成內容在地化
3. 校正單位價格
4. 執行合規檢核
5. 備齊證明文件
6. 核准上架交付
