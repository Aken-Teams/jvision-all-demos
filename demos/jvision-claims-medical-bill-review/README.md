# 理賠醫療帳單審查台

> 將住院帳單項目依保單給付範圍分類，協助理賠人員核對病房、手術、材料與自費項目，標示重複申請及需補證明之費用。

將住院帳單項目依保單給付範圍分類，協助理賠人員核對病房、手術、材料與自費項目，標示重複申請及需補證明之費用。

**產業別：**金融保險　|　**系統類型：**finance-case

## 功能模組

- **帳單匯入** — 呈現模擬帳單與診療文件。
- **費用分類** — 分類病房、手術、材料及自費。
- **條款比對** — 對照保額、除外及給付限制。
- **重複檢查** — 標示跨單據重複申請項目。
- **疑義補件** — 產生待補文件與問題清單。
- **給付覆核** — 彙整建議給付及調整理由。

## 適合誰使用

- 理賠審查員
- 醫務顧問
- 覆核主管

## 運作流程

1. 接收帳單
2. 分類費用
3. 比對條款
4. 調查疑義
5. 發起補件
6. 核定給付

## 導入效益

- 案件平均處理：7天 → **3天**
- 風險檢出率：70% → **95%**
- 文件缺漏率：12% → **3%**
- 覆核作業工時：5小時/日 → **1小時/日**
