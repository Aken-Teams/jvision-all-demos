# 塔吊附著升節管制台

> 依樓層進度管理塔吊附著、頂升加節與檢查放行，集中最新版配置圖、構件批次、螺栓扭力、焊道查驗及作業人員資格，確保每次升節具備完整施工證據。

依樓層進度管理塔吊附著、頂升加節與檢查放行，集中最新版配置圖、構件批次、螺栓扭力、焊道查驗及作業人員資格，確保每次升節具備完整施工證據。

**產業別：**營建工程　|　**系統類型：**construction-pm

## 功能模組

- **升節計畫** — 安排塔吊高度、附著樓層與作業窗口。
- **圖說版次** — 管制附著配置與頂升程序最新版。
- **構件批次** — 核對標準節、螺栓及附著構件資料。
- **作業許可** — 確認人員資格、氣候及警戒範圍。
- **施工量測** — 登錄扭力、垂直度與焊道查驗。
- **啟用放行** — 彙整檢查結果並核准恢復運轉。

## 適合誰使用

- 機電工程師
- 塔吊廠商
- 職安人員

## 運作流程

1. 排定升節
2. 發布圖說
3. 備料檢核
4. 許可作業
5. 量測查驗
6. 恢復運轉

## 導入效益

- 日報彙整工時：3小時/日 → **0.5小時/日**
- 進度落後預警：40% → **90%**
- 估驗計價天數：10天 → **4天**
- 缺失改善時效：7天 → **2天**
