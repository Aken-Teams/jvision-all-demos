# 會計期間關帳鎖定台

> 協助企業依公司與帳簿管理月結檢核、子模組關閉、傳票截止、例外放行及期間重新開啟，完整保留申請與核准軌跡，避免報表發布後仍被未授權回寫。

協助企業依公司與帳簿管理月結檢核、子模組關閉、傳票截止、例外放行及期間重新開啟，完整保留申請與核准軌跡，避免報表發布後仍被未授權回寫。

**產業別：**財務會計　|　**系統類型：**finance-ledger

## 功能模組

- **關帳總覽** — 顯示各公司與模組關閉進度。
- **月結檢核** — 管理必要對帳及調整事項。
- **期間鎖定** — 設定模組、帳簿及截止時間。
- **例外申請** — 說明補帳原因與報表影響。
- **解鎖核准** — 執行限時、限範圍的授權。
- **變更稽核** — 追蹤解鎖期間的新增與修改。

## 適合誰使用

- 總帳會計
- 會計主管
- 內部稽核

## 運作流程

1. 檢視進度
2. 完成檢核
3. 鎖定期間
4. 提出例外
5. 限時解鎖
6. 稽核結案

## 導入效益

- 月結作業天數：6天 → **2天**
- 對帳錯誤：8件/月 → **1件/月**
- 帳款逾期率：15% → **5%**
- 報表產出工時：16小時 → **1小時**
