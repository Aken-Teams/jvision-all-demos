# 雲端組態攻擊路徑治理台

> 集中盤點雲端帳號、公開服務、網路規則與資料權限，找出錯誤組態及可被串連利用的攻擊路徑，協助資訊團隊依實際暴露風險安排修正與驗證。

**產業別：**資訊安全　|　**系統類型：**security-soc

## 功能模組

- **雲端資產地圖** — 依帳戶、環境、服務與負責人呈現模擬雲端資產全貌。
- **組態檢查中心** — 列出公開暴露、未加密、過寬規則及紀錄不足等問題。
- **攻擊路徑探索** — 視覺化外部入口、權限跳轉與關鍵資料間的可利用路徑。
- **修正效果模擬** — 預覽調整網路、權限或服務設定後消除的風險與可能影響。
- **治理任務看板** — 依資產負責人分派修正、例外申請及到期複核事項。
- **基準遵循報告** — 彙整各環境符合安全基準的比例、趨勢及未解決缺口。

## 適合誰使用

- 雲端管理員
- 資訊安全工程師
- 資訊主管

## 運作流程

1. 盤點資產
2. 檢查組態
3. 探索路徑
4. 模擬修正
5. 派發治理
6. 驗證遵循
