# 物業廠商進場管制台

> 管理維保、清潔與施工廠商的進場申請、人員名冊、保險文件、工作區域、門禁時段及離場點交，降低未授權作業風險。

**產業別：**房地產與物業　|　**系統類型：**security-soc

## 功能模組

- **進場申請** — 登錄工作內容、區域與預定時段。
- **人員名冊** — 核對廠商人員身分與資格。
- **文件審查** — 檢查保險、切結及必要證明。
- **門禁排程** — 設定可通行入口、樓層與期間。
- **報到管制** — 記錄到場、換證及臨時異動。
- **離場點交** — 確認工具、現場與證件交還。

## 適合誰使用

- 物業經理
- 保全主管
- 廠商窗口

## 運作流程

1. 提出進場申請
2. 審查資格文件
3. 核准門禁範圍
4. 辦理人員報到
5. 監控作業異動
6. 完成離場點交

## 導入效益

- 報修處理：24小時 → **4小時**
- 繳費即時率：70% → **94%**
- 巡檢覆蓋：60% → **95%**
- 公設調度工時：6小時/週 → **1小時/週**
