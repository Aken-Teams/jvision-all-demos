# 場站月台占用交接台

> 以班次延誤與實際進出更新月台占用，管理臨時換位、衝突裁定及交班確認，讓客運場站在班表失序時仍能清楚安排車輛與旅客引導。

以班次延誤與實際進出更新月台占用，管理臨時換位、衝突裁定及交班確認，讓客運場站在班表失序時仍能清楚安排車輛與旅客引導。

**產業別：**交通運輸　|　**系統類型：**operations-console

## 功能模組

- **班次看板** — 查看預計實際進出時間
- **月台配置** — 呈現占用與清場狀態
- **臨時換位** — 調整班次及原因
- **衝突處置** — 裁定重疊及優先班次
- **旅客通知** — 發布換位與引導資訊
- **交班確認** — 點交未到未離與封閉月台

## 適合誰使用

- 場站調度
- 月台人員
- 旅客服務員

## 運作流程

1. 監看班次
2. 配置月台
3. 處理換位
4. 裁定衝突
5. 發布通知
6. 完成交班

## 導入效益

- 派車規劃工時：4小時/日 → **1小時/日**
- 準時配送率：85% → **97%**
- 空車率：22% → **10%**
- 油耗異常反應：24小時 → **3小時**
